# 身份、复仇与权谋架构

## 0. 这是什么 / 不是什么

一个**人工填表 + 条件判断**的叙事设计流程，不是自动写稿器，也不是历史考据工具。

- 输入：作者的身份设定、复仇目标、权力结构、已有稿或大纲。
- 输出：按任务选用的**工作表**（默认 7 张；出现对应任务时再加载 3 张扩展表）+ 公开揭示检查表。
- 不做：不写正文、不评分、不预测平台数据、不判定历史真伪、不自动生成阴谋。

## 2. 触发 / 负触发

### 触发
- 主角要夺回/证明一个身份（王位、继承权、真名、清白），但读者不信。
- 复仇线只有动机宣言，没有可结算的代价与执行者。
- 权谋靠"他很聪明"推进，缺少制度摩擦与可交割物（委任、婚约、遗产、判决）。
- 面具/假身份在第一幕就被揭穿，或揭穿后没有后果。
- 结局只会"杀光敌人"，没有转化、清算或制度收束。
- **需要在不杀死对手的前提下毁掉对手**（R12 声誉毁伤路线）。
- **内部出现比敌人更难处理的激进同阵营者**（R13）。
- **计划执行到一半被主角自己都叫不出名字的力量改写**（R14）。

### 负触发（不要用）
- **纯动作冒险**：没有身份主张与权力结算，本 Skill 的表格会空转。
- **爱情主线**：身份误会服务于感情，不承担公共权力；改用情感类 Skill。
- **家庭伦理/日常**：没有制度场，R5–R8 不适用。
- **真实历史人物传记**：不能改公开结局；本 Skill 只能用于"架空/罗曼司"层，且需另做事实核查。
- **要求历史/法律准确性**：本 Skill 不提供考据，只提供叙事结构。

## 4. 执行路径：先条件判别，后选资料

1. **先定位身份类型**：本书的身份是**可更换的工具**（PG558：Scudder/Hannay 各换过 4 次以上身份，L298-299、L388-390、L1793-1827）还是**必须被证明的本质**（PG66749 的血统、PG60 的真名）。两者机制不同，不可混用同一套规则。
2. 定清目标：身份认可 / 卧底保密 / 联盟争取 / 权力转移 / 复仇结果 / 历史架空？确认主角当时已知事实、敌人的查验能力、读者应得的预期。
3. **身份主张 R1**：只有当主角需取得他人公开承认时才查证据链/承认者/反证；私人身份冲突不设"两个担保人 + 三件套"硬门。
4. **失踪或假死 R2**：查追查者收到什么、为何相信、有什么可复查的迹象。若作品没有验尸制度，改用传言、见证或信息封锁，不虚构官方程序。
5. **面具与识别 R3**：列不同角色知道什么、保密代价、泄漏时点与视角许可；**写明识别线索优先级**（无意识身体习惯 > 相貌 > 口供），允许"当面也认不出"的写法。
6. **情报 R4**：逐条核对"这条消息如何改变接收方行为"；双份指令只是诱敌分支。
7. **权力摩擦 R5/R6**：检查每步是否改变资源、合法性、组织规则或对手能力；同一场域有新筹码即可升级。
8. **联盟与复仇 R7/R8/R9/R12/R13/R14**：记真实动机、承诺与选择成本；不为加重戏剧而强令无辜者受害；旧敌转化仅当有先前动机与可观察行为支撑。
9. **结局与史实 R10/R11**：只有争取公共承认才需要公开观众与程序；私密揭示无需公审。历史事实单独查证。
10. **收口自检**：提出替代分支及限制后复核前后章连续性，输出 F/H/P 与待确认清单。

**扩展表加载条件**：只有出现"不杀而毁"、"内部派系冲突"、"计划被计划外力量改写"三类任务时才加载 T8/T9/T10；其余维持 7 表，不强制全填。

## 7. 失败出口

- **身份无人承认**：不直接否决主线；先识别谁有承认权、主角希望得到何种承认，缺关键证据则列待补证。
- **假死无官方程序**：看世界规则与追查链，改用失踪、错认、故意隐瞒等可信分支。
- **面具无人知晓**：可用读者与角色的信息差或有限视角，无需强行添加知情者。
- **情报没有两封信**：改用单条信息的不同解释；核心是行动因果而不是信件数量。
- **权谋没有切换场域**：若利益、权限或代价确实升级，不强制换场；若重复且无新变化再调整。
- **复仇没有第三方伤害**：不为悲剧硬制造无辜者受损；记录对角色身份、关系、社会或目标的真实影响。
- **声誉毁伤牌打不出去**（R12）：先查三件事——有没有**必须看见**的旁观者、有没有可拍照/可复述的现场物证、委托人能否事后否认；三者缺一，该方案只能写作失败尝试，不能当正解。
- **旧敌不可转化**：保留审判、逃离、谈判、对抗或开放结局。
- **历史证据不足**：不作历史核验声明；改明确架空假设或等待可信史料。
