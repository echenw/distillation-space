## R10 公开揭示要有观众与程序

**规则（P，条件化）**：只有当揭示需要获得公共认可、权力变更或社会传播时才设计观众、证据与程序。仅涉及私人关系的秘密可以在密室或单人对话中解决，不强制公开化或永久社会变化。

**证据（F，PG60 L10211–10213）**：
> "he had found time to get into some of the sumptuous clothes which he loved"

→ 揭示后先回到“可被看见的身份装束”，让公众重新识别他。

**证据（F，PG60 L10222–10227）**：
> "at the brilliant wedding of Sir Andrew Ffoulkes" / "the clothes Sir Percy Blakeney wore were the talk of the jeunesse dorée of London"

→ 婚礼是公开场：身份回归由社交仪式确认，而不是主角自述。

**证据（F，PG558 L876）**：
> "There were two columns about the Portland Place Murder"

→ 报纸是另一个公开场：主角读到自己被通缉的报道，公众认知成为压力与证据。

**操作（P）**：
1. 填“公开揭示检查表”：观众 / 程序 / 证据 / 谁被迫表态 / 揭示后的不可逆变化。
2. 只有实际需要公共证成时才设置可质疑的受众/传播渠道；不强制不能收买的观众。
3. 揭示前给读者一个可复核的证据；揭示后让一个旧关系永久改变（婚姻、继承、同盟）。
4. 不要用“所有人都惊呆了”代替程序；写清谁记录、谁裁决、谁传播。

**适用**：身份回归、复仇收束、权谋终局。

**不适用**：私密情感揭示（只需要一个人知道）；此时用小范围对话，不要搭公审台。

**反例**：主角在空房间里对反派说出真相，反派死了，世界不知道 → 身份主张没有公共后果。

**验收**：展示目标人物或相关群体的认知/决策为何改变；私密揭示可以只改变两人的关系。

## R11 历史架空用真实制度做压力，不拿真实人物做担保

**规则（P，条件化）**：使用真实历史背景时先区分已有可信史实、作者虚构和明确架空。历史制度如何运作需要另查资料；原著中的历史罗曼司写法只作叙事参考，不给真实制度背书。

**证据（F-AUTHOR，PG66749 L114–118，作者序）**：
> "it would be impossible for any narration, that should be confined to the incorporation of facts related by our old Chroniclers, to do it justice"

→ 作者明说：只靠史料事实不足以承担故事；但这句话支持的是“补私生活”，不是“改公开结局”。

**证据（F-AUTHOR，PG7412 L95–107，作者序）**：
> "The main purpose of its writer was to vindicate the just claims of the Tory party" / "without prejudice"

→ 作者把政治目的写在序里；历史小说可以带立场，但必须让制度摩擦可见，而不是让立场代替情节。

**操作（P）**：
1. 填“史实/架空边界表”：拟遵守的史实 / 明确偏离的设定 / 可信待考证制度 / 作者虚构部分。
2. 只在涉及真实权力动作时追踪制度后果；私人情感场景不必制造历史事件。
3. 真实人物只做“制度位置”的事，不做“无条件担保主角”的事。
4. 序言/后记标注架空范围；不把小说当史料。

**适用**：历史罗曼司、架空王朝、政治寓言。

**不适用**：纯架空奇幻（没有真实制度可借）；此时改用“自建制度”，并在设定集写清规则。

**反例**：真实国王因为欣赏主角的勇气，绕过继承法把王位给他 → 既不合制度，也不需要权谋。

**验收**：哪些是真实历史已核、哪些为作者设定、哪些未查应分别标明；不可用小说代替史料。

## 失败出口

- 身份主张缺可信承认路径 → 标当前目标与补证，不硬要求担保人。
- 假死无官方程序 → 检查追查者信息链，使用可信的失踪或误认逻辑。
- 面具无人知晓 → 可以保留信息差，不强加知情角色。
- 权谋只靠暗杀 → 审查资源和代价是否变化，不硬要求换场。
- 复仇无明示代价 → 审查已有的选择后果，不强制造无辜第三方伤害。
- 历史架空要改公开结局 → 标注架空，另做事实核查；本 Skill 不提供历史担保。

## 本批未覆盖

- 女性复仇主线的中段结构（PG1257 Milady、PG66749 Katherine）只读到章目/结尾。
- 现代中文网文/影视/游戏中的权谋语法未验证。
- 没有真实作者任务；GQ5 = NOT_PROVEN。


## 证据边界（外部复审 M6）

- R10：F 只展示公开装束/婚礼/报纸压力，没有同时展示“观众 + 程序 + 可复核证据 + 不可逆权力变化”四件套；四件套的**具体动作**是 P；规则内容为 H。
- R11：两段作者序只说明史料不足与政治目的，没有直接论述“用真实制度做压力、不拿真实人物担保”；规则内容为 H（跨族归纳）；具体执行是 P。

## NEW：叛变式披露（P，NEW 单源 PG15454，条件建议）

**规则（P，NEW 单源 PG15454）**：知情者公开本组织最高机密，动机写成「消除对人类的威胁」而非个人恩怨；披露者必须付出组织内的死刑代价，并预言「压迫不除，组织会以更强形态重生」——披露不等于问题解决，这是揭示类结局的反讽引擎。

**证据（F，PG15454 L5941–5945）**：
> "I urge this because love of liberty is such an inventive genius, that if you destroy one device it at once constructs another more powerful."

→ 叛徒的遗言把「揭露」与「无效」同时写下；组织被出卖后仍会再生。

**证据（F，PG15454 L5656–5662）**：
> "It is treason," was Belton's terse reply.

→ 拒绝方给出一句话边界（叛国/背誓），不长篇辩论；边界句要被结局兑现——Belton 依同一条边界回去受刑。
