# 06 · 胜利后的权力不等于同盟控制（PG50906 的反例，R13/R14）

**范围**：仅据《Savrola》PG50906 的已读文本推导叙事检查，不是现代政治军事或法律建议。F：原文事实，H：限定推导，P：小说场景诊断动作。

## F：起义前承诺与起义后失控

1. **提前行动失去上级控制**：Moret 的电报确认 Strelitz 未经 Savrola 授权率两千人越境，Savrola 无法让部下等完整准备好，只能以临时会议调度转入暴动（L3334-3337、L3481-3519）。
2. **领导者并非现场的全部 Owner**：Moret 为保护停战谈判而携白旗进入总统府，守军 Sorrento 射杀了他（L5035-5099）。随后 Tiro 发现 Moret 死后十五分钟仍有“Moret 正在进攻”的署名电报，推断革命军控制权已被他人夺走（L5660-5695）。
3. **合法性承诺能与胜利暴力冲突**：总统 Molara 投降前被群众击毙，Karl Kreutze 补枪并称不是谋杀而是处决（L5990-6060）。Savrola 以自己战伤争取群众注意，明确要求投降者接受公正审判（L6075-6133）。
4. **胜利后的同盟反噬**：舰队要求交出 Savrola，否则炮击城市（L6286-6296）。安全委员会却以二十一票对十七票决定威胁枪决战俘（L6348-6386）；Savrola 认为战俘受降不应成为政治人质，私下以火车送往境外（L6408-6428）。
5. **转移控制权反招报复**：Miguel 告密导致委员会计划逮捕 Savrola；他起初仍想亲自前往，最终在革命军军官告警后带 Lucile 离城（L6550-6647）。尾声叙述其日后重返政坛（L6683-6706），不能把此刻失败写成唯一结局。

## H：冲突而非公式

- R13 的“给激进盟友以角色、划纪律底线”只是尝试；从上述行动看，**角色分配不等于承诺可执行**，尤其在公开胜利后，领导者失去共同敌人的约束。
- R14 的“承认可控边界”有原文支撑，但原文展示了两次外部冲击：Strelitz 擅自提前行动、委员会在赢后不再服从。因此计划失控是有具体 Owner 和激励变化的，不是万能“意外反转”。
- R12 的名誉丑闻战法也可能引来私人复仇和政治暴力，不保证摧毁对手以后领袖获得稳定权力。

## P：改写/验收问题

1. 暴动或政变**行动前 / 行动中 / 胜利后**逐节点记录实际拥有命令权和物资权的人；别让一个会议口头决定自动变成全队服从。
2. 明确不同派别对抓捕、审判、释放俘虏的承诺是否一致，若冲突需有正式程序、物资或群众影响力支撑，不仅依赖主角“很聪明”。
3. 当同盟夺得权力时，复核它是否仍受原承诺约束；如果不受，写出逼迫领袖退出或牺牲利益的真实代价。
4. **失败出口**：如果新政权全员突然一致拥戴主角，却无联盟、监督、物资或程序支持，标注“权力连续性未证明”，请作者补具体保持/丧失控制的原因。
