# R2 分场、编号与连续性

## R2.1 场景的定义（最稳的一条，F）

- **场＝一次不停机、同一地点拍下的全部动作**（PG17903 L857-860；同书 L4353-4354 再次给出同一定义）。
- 新环境即新场景，须连续编号（PG76829 L751-765）。
- 多本长片从 Scene 1 直编到底，不按本重置（PG17903 L5567-5568：you start with Scene 1 and number straight through to Scene 200）。
- 地点的**最微小移动**也是新场（PG17903 L4200-4357：消防员登梯分两场；若摄影机 tilt 跟拍则一场；火车跟拍虽背景连变仍是一场）。别人进场不另起新场。
- 截图式插入（bust/close-up）自立场景号并单独编号（PG17903 L6122-6123；L5088-5089：需要的特写才写进稿并编号，纯画面效果留给导演）。

## R2.2 空间连续性（F）

- **不得硬跳**：不能让角色从自己办公室直接切到他人办公室，须先 exit 再 enter（PG76829 L802-809）。
- 同布景两场紧邻无间隔会成"魔法瞬移"，须中间插他景或说明字幕（PG17903 L4359-4445）。
- 双人物线用交叉剪辑推进：一场写甲、下一场闪乙，循环至高潮以保持两线平衡（PG76829 L811-816）。
- 场景要简短、不描写布景细节，交给导演（PG76829 L763-765）。

## R2.3 时间连续性（F）

- 银幕是 **now play**：现在可以是千年前，但必须"被重新活一遍，现在"（PG70937 L2092-2093）。
- 主体顺时序（PG70937 第九章立场：一切发生在 now，严格遵循时间顺序）。
- 允许的例外（三选一，且必须显式标记）：
  1. **cut-back**：回到先前放过的场景，用于并行线（PG17903 L4448-4529；源出章回"Let us now return to..."）。戒律：**不得借 cut-back 跑题**（L4531-4532）。
  2. **说明字幕**：一条 "A YEAR LATER." 即可完成跨年（PG17903 L1684-1686）；日夜跳必须插字幕（PG76829 L845-899）。
  3. **insert**：信件、电报、报剪（PG17903 L6789-6951）。
- **两地同时发生的事只能用 cut-back，不能用 fade 或 diaphragm**（PG17903 L5232-5248）。
- 回忆/梦境用 fade out → 插入场 → fade back，三场各编号（PG17903 L5125-5230）。

## R2.4 长度与场数（F）

| 项 | 数值 | 来源 |
|---|---|---|
| 一本满片 | 约 1000 英尺、约 20 分钟 | PG76829 L319-320 |
| 一本正剧场数 | 40–50 场 | PG76829 L559-576 |
| 一本喜剧场数 | 60–80 场 | 同上 |
| 每卷场数 | 25–50 场（另一口径） | PG17903 L258-280 |
| 喜剧长度原则 | 恰好等于其点子的长度，多一点都不行 | PG17903 L9267-9268 |
| 二本片 | 80–160 场，更受制片方欢迎（当年市场事实） | PG76829 L569-576 |

**注意**：尺数、本数、投稿口径是 1914–1919 年工业事实，**不是创作规律**；现代使用只取"场数密度"的相对含义（H）。

## R2.5 检查清单（P）

- [ ] 每一场都能答出"这是同一地点、摄影机没停吗"？
- [ ] 有没有从 A 空间直接切到 B 空间而没有 exit→enter？
- [ ] 同布景相邻的两场之间有没有插入物/字幕？
- [ ] 每次时间跳跃是否用了 cut-back／字幕／insert 之一并显式标记？
- [ ] 有没有把同步发生的事用淡入淡出连接（错）？
- [ ] 特写是否自立编号？
- [ ] 场号是否连编到底？

## R2.6 反例与边界

- 8 部戏剧密集使用 aside（PG70635 L296/336/381、PG59210 L572/574、PG1929 L1192/1317 等）：这是舞台约定，**不是连续性缺陷**；转成无声银幕时才需要整体替换为字幕/视线/物件。见 05 与 07。
- PG1109 L2745-2874（本轮亲读）用三层中继传话（L2794-2807）：是伪装—误认约定的产物，**不得当作通用分场法**。
