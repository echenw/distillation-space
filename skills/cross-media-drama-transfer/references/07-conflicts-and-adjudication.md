# R7 冲突与裁决：五组不许合并的分歧

使用规则：遇到下列任一组，**不得替用户选边**。写入输出时给 `A 案 / B 案 / 本 Skill 的默认值 / 需用户决定`，并把依据行号一并交付。

## 冲突 1：结局信息量

| | 主张 | 来源 |
|---|---|---|
| A（Phillips） | 必须把观众带进信任圈；不要靠结尾揭底制造惊喜，因为**一切按发生顺序放映** | PG70937 L3401-3403 |
| B（Esenwein & Leeds / Zuver） | 悬念不能过早泄露；结局不可过早可预测 | PG17903 L4059-4113；PG76829 L976-999 |

**默认值（H）**：因果链全程可见；结局是否可猜按体裁选择。二者不在同一层面——"看得见因果"≠"猜得到解法"。

## 冲突 2：节奏快慢

| | 主张 | 来源 |
|---|---|---|
| A（Freeburg） | 银幕的危险是"跑"不是"拖"；反对 touch and run | PG66049 L3351-3365、L3207-3215 |
| B（Esenwein & Leeds） | 喜剧要比正剧快三分之一到一半，每一场都得有戏 | PG17903 L9188-9238 |

**默认值（H）**：**分层处理**——整体镜头/剪辑速率按 A；**单场内的喜剧节拍**按 B。不在同一层，但输出时必须分开写，否则用户会收到相反指令。


## 关于"共识"的纪律

- 本轮**没有**把任何一组冲突合并成" consensus"。凡是只有单本主张的，标注为单一来源意见，不得写成"业界共识"。
- 只有**两本以上独立同向**的主张才升为 KEEP 级规则：如场的定义（PG17903 + PG76829）、空间不得硬跳（PG76829 + PG17903）、字幕为仆不为役（PG17903 + PG76829 + PG66049 的画面禁忌）、暗示而非再现（PG39973 自身三处）。
