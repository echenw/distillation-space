# Cross-Media Drama Transfer（跨媒介剧作改写）

把一个叙事作品从**散文/舞台剧**改写到**银幕剧本（无声片口径）或舞台落地方案**，或反过来判断"这个题材能不能改、该怎么改"。
本 Skill 是**由 Agent 执行、供作者逐条裁决的改写工作流**；不做批量重写，不给全文打分，不宣称改编后的商业效果。

## 1. 何时使用

- 用户要把小说/故事改成剧本（舞台本或分场剧本），或把舞台剧改成银幕本。
- 用户问"这个题材适合改成戏/改成片子吗"，需要判据而不是感觉。
- 用户已有初稿，需要按"场"的定义重切、查空间连续性、查时间跳跃是否被显式标记。
- 用户纠结某段信息该用动作、物件、信件还是字幕/说明来承载。
- 用户要结局与高潮的裁决（快乐结局是否必要、能否靠最后揭底）。
- 用户需要把剧本落到舞台：门、家具、走位、群众、布景取舍。
- 用户需要改编伦理判断：能不能借用某个点子、要不要取得授权。

## 2. 负触发：不要用本 Skill

- **漫画/漫画剧分镜、格序、页数节奏、网点与图像语言**：本任务 89 本来源中 0 本涉及，全部 `NOT_PROVEN`，直接说明无法回答。
- **有声片对白写作、现代剧本格式（Final Draft 体例等）、现代分镜/拍摄软件格式**：0 来源。
- **网文/短视频/现代剧集的平台体例与算法节奏**：0 来源。
- **现行版权与授权法律意见**：来源只有 1919/1923 年美国口径，只能给历史事实与"须另行核实现行法"的出口。
- 用户只要情绪安慰或市场预测。
- 用户要求"照抄某个已有改编版"——见 §7 改编伦理，须拒绝并给出合法替代路径。

## 3. 输入契约（缺什么就先问什么）

| 输入 | 必需 | 缺了怎么办 |
|---|---|---|
| 原作文本或足够细的情节描述 | 是 | 只有一句话时，只做"可转移性初判"，不做分场 |
| 目标媒介（舞台 / 银幕 / 二者比较） | 是 | 无法判断就并列给出两套检查，别替用户选 |
| 目标长度（独幕/多幕；一本/多本；或分钟数） | 否 | 有则按 §5.4 判定，无则给长度选择规则 |
| 体裁（正剧/喜剧/闹剧/悲剧） | 否 | 影响 §5.5 与 §5.7 的裁决，缺失时按正剧默认并标注 |
| 既有约束（成本、演员数、审查/受众禁忌） | 否 | 缺失时按 §5.6 给通用闸门，并注明"未考虑特定约束" |

## 5. 执行步骤

### 5.1 判可转移性（先做这一步，不判就不要动笔）
1. 抽掉台词：调度是否随之垮掉？垮的是"靠语言立住"的作品（PG13029 L1504-1507 点名莫里哀/易卜生/莎士比亚）。
2. 问一句：**离了对白与描述，这个题材还成立吗？** 成立即弃（对银幕而言）（PG17903 L8856-8907，同段点名侦探小说最不宜）。
3. 记住反向可能：spoken drama 的失败之作可能成为影院之星，银幕擅长叙事与史诗性的事件连续（PG13029 L1504-1507）。

### 5.2 承认"原作不是画面故事"
原始故事一般并不是一个画面故事，是分场把它变成影片（PG53117 L3151-3158）。所以改写＝重写，不是誊写。

### 5.3 分场
- 场＝一次不停机、同一地点拍下的全部动作（PG17903 L857-860、L4353-4354）；新环境即新场，须连续编号（PG76829 L751-765）。
- 多本长片从 1 号直编到底，不按本重置（PG17903 L5567-5568）。
- 开拍前写不动的细节交给导演，不要写满（PG76829 L763-765）。

### 5.4 长度
- 一本满片约 1000 英尺、约 20 分钟（PG76829 L319-320）；一本正剧 40–50 场、喜剧 60–80 场（PG76829 L559-576）。
- 每卷 25–50 场（PG17903 L258-280）。
- 喜剧长度＝"恰好等于其点子的长度，多一点都不行"（PG17903 L9267-9268）。

### 5.5 连续性
- 不得硬跳：不能从自己办公室直接切到他人办公室，须先 exit 再 enter（PG76829 L802-809）。
- 同布景紧邻无间隔会造成"魔法瞬移"，须插他景或说明字幕（PG17903 L4359-4445）。
- 时间主体顺时序；跳跃只允许 cut-back、说明字幕或 insert 显式标记（PG70937 L2092-2093；PG17903 L1684-1686、L4448-4558）。
- 两地同时发生的事只能用 cut-back，不能用淡入淡出（PG17903 L5232-5248）。

### 5.6 成本闸门
- 判据不是"贵不贵"，而是**这一场是否为情节展开所绝对必需**（PG17903 L7696-7697）。
- "几乎无事不能拍，但非皆可行"（PG17903 L7176-7178）；能回本就不嫌贵（L7654-7655）。
- 许多好情节因造价被退（PG76829 L943-971）；大思想才配大场景（PG76829 L1328-1330）。

### 5.7 结局与高潮
- 先定高潮再写（PG70937 L2671-2674）；完整情节＝三段论：Cause—Effect—Climax（L2496-2499）。
- "观众爱大团圆——除非团圆是被硬拽出来的"（PG17903 L2744-2745）；反对"火车失事式营救"，主张变形而非毁灭（PG13029 L2880-2894）。两说并存，按体裁裁决，见 §7。
- 主角即使行为不可赞同，也须始终配得上观众的同情（PG17903 L8998-9000）。
- 兴趣中心钉在一条主线上，不得让同情在场间漂移（PG17903 L4116-4197）。

### 5.8 舞台落地（若目标是舞台）
见 [05-stage-realization.md](references/05-stage-realization.md)：指示不足要从台词反推（王尔德）、指示过多要拆机械与文学（萧伯纳）、暗示而非再现、不拥挤也不过分对称。

### 5.9 画面层检查（若目标是银幕）
见 [06-pictorial-checks.md](references/06-pictorial-checks.md)：一物独动必夺目、重复须有变化、避免"一框两画"。

## 6. 输出合同

每次交付至少包含：

1. **结论行**：能不能改 / 建议媒介 / 建议长度（一句话）。
2. **证据行**：每条建议后面跟 `来源 PG + 行号`。没有来源的建议必须标 `H`（推导）或 `USER`（用户指定）。
3. **改写清单**：逐条给 `原作位置 → 目标处理 → 依据 → 风险`。
4. **缺陷表**：连续性缺口、无法可视化的点、成本风险、载体误用。
5. **裁决项**：凡遇到 §7 的冲突，写成 `A 案 / B 案 / 本 Skill 的默认值 / 需用户决定`，**不得替用户合并**。
6. **边界声明**：说明哪些部分来自 1914–1923 年口径、哪些已失效（尺数、投稿、审查清单、版权法）。

无法判定时改为"问题清单"，不擅自改稿。

## 7. 失败出口

| 情况 | 出口 |
|---|---|
| 用户要漫画分镜/现代影视体例 | 直接说本 Skill 无此来源（0/89），给出 `NOT_PROVEN` 与建议的替代路径 |
| 目标媒介未定 | 并列给两套检查，不替用户选 |
| 两条训诫冲突且用户不裁决 | 交付 adjudication memo（见 07），停在默认值 |
| 证据不足（例如某部戏剧的具体机制） | 标注 `NOT_PROVEN`，给出需要补读的来源与区间 |
| 用户要求借用他人情节/照抄改编版 | 拒绝，并给合法替代：只取 plot-germ 重塑（PG17903 L7463-7465、L9735-9737），改编版权作品须取得授权（PG76829 L1310-1312） |
