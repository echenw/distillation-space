# 示范（DESIGN_EXAMPLE，非真实用户任务）

两份示范只用于说明"证据怎么挂、裁决怎么写"。它们不是真实用户委托，也不是改编成果。

## 例一：判断一个题材能不能改到银幕（无声片口径）

**输入（构造）**：一个短篇——"侦探在开场前收到委托，靠三场审讯中的对白推理出凶手，最后一页揭晓凶手是死者的孪生兄弟。"

**执行**：

1. **抽台词测试**（PG13029 L1504-1507）：抽掉对白后，调度几乎不存在——三场审讯只剩"人坐着说话"。
2. **去描述自问**（PG17903 L8856-8907）：离了对白与描述，这个题材还成立吗？**成立即弃**；同段直接点名侦探小说最不宜（案发于开幕前、靠推理与对白），且银幕须按时序演出，演杀人必先见凶手行凶——既触审查，又早早泄底。
3. **结论**：按本 Skill 的口径，这一稿**不宜直接改为无声银幕本**。
4. **替换方案（不是判死刑）**：
   - 把"推理"外化为**动作与物件**：凶手留下的物件（PG17903 L4767-4768：bust 即放大物件；一手例见 PG4906 L389-397 用"信＋表"承载关系）。
   - 把"审讯"改为**可被看见的试探**：人物去做一件事，而不是说一段话（PG70937 L2029-2031：观众是来看一件事的）。
   - 若坚持保留推理，则把推理过程放在**开场之后**并按时序演出，接受"观众早知道凶手"的代价（PG70937 L3401-3403：银幕必须把观众带进信任圈）。
5. **裁决项**：是否接受"观众早知道凶手"？→ 交用户（见 07 冲突 1）。

**输出形态**：结论行 + 证据行（每行带 PG+行号）+ 替换清单 + 一条待用户裁决。

## 例二：一段分场的连续性与载体体检

**输入（构造）**：某舞台剧第二幕的分场草稿——
```
S12 书房：主人公读信
S13 银行办公室：经理签字
S14 书房：主人公把信烧掉
```

**体检**：

| 问题 | 判据 | 处理 |
|---|---|---|
| S12→S13 从自己书房直接切到他人办公室 | 不得硬跳，须先 exit 再 enter（PG76829 L802-809）；同布景紧邻无间隔会造成"魔法瞬移"（PG17903 L4359-4445） | 插入"主人公出门 / 街上 / 经理室门"等短场，或在 S13 前加说明字幕 |
| S14 又回到书房，与 S12 同布景相邻（中间只隔 S13） | 同上 | 若保留，须在 S13 与 S14 之间显式标记时间或插入他景 |
| 信件内容若靠字幕长篇转述 | 字幕越少越好是误读；要写到"非懂不可"（PG17903 L6425-6492），但优先用信件本身（L6789-6951） | 用信件 insert：一封 35 词把话说完的信胜过多条字条（L6806-6807） |
| "把信烧掉"这一动作是否与画面里其他运动冲突 | 全画面唯有一物动则必夺目（PG66049 L2960-2969） | 检查同框是否有火苗、窗帘飘动等抢注意的元素 |
| 场号是否连编到底 | 从 Scene 1 直编到底（PG17903 L5567-5568） | 是（本例已满足） |

**输出形态**：缺陷表（每条带来源行号）+ 改写建议 + 无待裁决项。

## 例三（反向）：不要把案例写成规则

PG4963 L2601-2800 把最强的动作（突袭、躲衣柜）**只作回顾而不演出**（L2694-2737）。
若据此写成"关键场面都应该转述"，就是**把单部作品的做法变成普适规则**——本轮在 §4 的 R1 裁决里明确拒绝了这种推广：它只能作为"转述是合法手段之一"的证据，不能反过来禁止正面演出。
同理，PG1109 L2794-2807 的"三层中继传话"是伪装—误认约定的产物，不得当作通用写法；PG4906 L517-549 的"一行一条理由"只属于那部戏的喜剧节奏。
