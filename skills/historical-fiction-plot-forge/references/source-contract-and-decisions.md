# 历史/罗曼司证据合同与决策协议（A-07-B02）

## 首先判真实历史还是虚构历史

- 作者提供真实年月、人物、法律事件 → 建 `可独立查验史料/小说人物所信/虚构化改动/尚无文献` 四栏，不能将 15 本旧罗曼司当史料；PG56562 L87–89 作者明确“no furniture for the scholar's library”，本来就不承诺学术准确。
- 作者采用完全架空王国 → 验证世界内部的时间轴、承诺、空间规则，不硬要求现实历史来源。
- 作者仅有 1 段文本 → 只给结构选择或指出缺失；不得宣称全书结局必坏。

## 六域按实际矛盾选 A/B，不必全部执行

1. **忠诚**：角色对王室、家族、教会、朋友的承诺冲突时，先写 `宣言/受益者/伤害者/见证与可改变的选择`，有信物可用票据，没信物也可凭行为决定。PG6407 L14443–14445 是 Roland 拒做对女王不利的事情；L14468 “拒绝信任则不能背叛”是他的**辩词 F**，并非所有信任均无责任的道德定理。PG6407 L8720–8723 剑的出鞘条件是**具体赠剑惩戒**，不是所有忠诚都必有一把剑。
2. **谶语**：PG10046 L91–93 预告“晴天失爱、雨天得之”，结尾 L9208 重提；这是字面应验与作者回扣的作品现象，足以推翻旧“必须误读才算成立”。对 A 字面宿命、B 误读反转、C 失效开放三种分别列“读者先知/角色行动/未来代价”。当真实历史事件不可能由预言验证时，谶语属于人物信念，不是史料。
3. **精神困局**：PG6407/PG79489/PG3350 历史作品以当时社会的“疯”标签处理不同人物，不能自动诊断真实精神疾病、把受困者简化成政治工具；分 `角色自述/旁人贴的标签/读者实际可观察行为/时代制度压力`。避免以受害者痛苦作为“反派自动赦免”的固定按钮。
4. **文书**：PG1461 通过两种来源争辩事件，PG24789 L199–201 奴隶标记与官簿暴露制度运作，PG1678 用冤案文书推进历史悬疑。需要历史检验时，文书只是小说机制 F，必须追外部真实史料；没有文书不意味着作者不得用口述/物件叙述。
5. **地形**：PG56562 的逃亡地理、PG5709 的军事前线与 PG2609 的路口，让双方在同样时空约束行动；不要求所有罗曼司都绘详细物理地图，作者可以保留雾、传闻或认知误差。输出 `位置/可达途径/角色知道什么/付出时间代价`。
6. **家族与动物视角**：PG271《黑骏马》从动物角度见人类伦理，不是历史军事史料；PG79489 家史与 PG1036 边疆短篇可为“经历层”与“世代层”提供对照。作者无需每个求婚设计名誉交换，优先保留人物真实选择。

## 公共历史语言的风险

- 殖民化、奴役与基于出身的所谓“血统法则”是当时叙事的权力观，不是现代写作通行规范；可写制度如何伤害角色，不能把偏见当成读者应采纳的史实。
- 原 P3 RE-05 “毒杀攻防工程链”只作为**虚构叙事的证言可靠性/怀疑与假药反转**处理，不提供现实投毒、规避鉴定方法。
- **失败出口**：小说还没设年份却索要“严格真实史料确认某裁判制度”，需要具体地区、时期和历史文献；现有小说源不足标 `NOT_PROVEN`。
