# 反例与冲突登记（使用前必读）

> 生产侧完整冲突登记（12 项）存本轮 notes/ 备查；此处收录对**使用者**有直接操作影响的条目，执行本文件不需要访问包外内容。

## 1. 灵异档位不可混档（硬约束）

PG170《The Haunted Hotel》把超自然当真实因果（显灵序次 P1、气味指纹 P2 为真证据链）；PG33230《The Gray Mask》把全部灵异还原为骗局（dictaphone+自演幽灵）。**同一本书内禁止混用两档**——" mostly 骗局+一件真灵异"会让读者无法建立预期。选档规则见 SKILL.md 表 1。混合只允许在档 3（两可留白）中以下列形式出现：叙述者自我拆穿+两版解释互相抵消+不下结论（PG170 结尾焚稿+问答体即档 3 的极端形态）。

## 2. "民间侦探抓捕"的程序越界

I1（solve/prove 分工）是 1889-1924 源文本的主流契约；但也有反例：PG67735 的 Sam 直接放走凶手（G5 知而不举）、PG57737 的 Tribunal 私刑处决（M3）。三者的共同点：**越权行为都有代价或边界**（放走≠赦免，结尾暗示逃亡溺亡；私刑由组织契约而非个人情绪背书）。使用者若让侦探个人随心意处刑，既失真也失道德坐标——私了必须走 G5 的"条件放逐"或 M3 的"组织契约"，不可即兴。

## 3. 天罚收束的巧合红线

M2 天罚谱系六型共用一条红线：反派必须"自己走到那里"。反例（失效形态）：反派平白站上悬崖然后崩塌——读者读作作者挪火。修法：让贪/慌/追/逃亡路线把角色自然送到死亡地点（PG67735 溺亡前有"他不会游泳"的前文确认；PG68091 毒自尽有鞋跟藏毒瓶的预谋铺垫）。

## 4. 目击反推的适用边界

E4 镜像反推（PG66446）依赖"目击者不识被目击者"。若你的场景里目击者与对象熟识，镜像衣物骗不过脸——此时改用 E2（物理天花板：雾/暗/距离）限制目击质量，而非强行镜像。

## 5. 时代偏见不迁移（硬约束）

源文本中的排华（PG33230 的帮派描写）、反德（PG57737 的战争背景）、反犹（PG170/PG68091 的放贷人形象）、殖民主义（PG67735 的澳洲赛马圈）话语**均未蒸馏为规则**。使用者复刻时代氛围时：①以具体反派个体替换任何群体标签；②不使用源文本的群体污名修辞；③必要时加作者注说明时代语境。本条为红线，违反即输出无效。
