# 失败出口与类型病诊断（六问）

> R18 §2d 契约：证据不足/权限冲突/失败时怎么办。本文件是 SKILL.md"失败出口"节的展开。

## 诊断六问（对任何"没劲的推理稿"逐问）

1. **谜面是否成立？** 读者能否复述"为什么不可能/为什么可疑"（A1 判断信号）？不能 → 谜面失效，回 A 族补穷举。
2. **侦探每次出场有无增量？** 若重复问话无新信息 → M-2 侦查塌陷，修法见 examples.md 示例 2（B9 物证束/H6 假设实验/H3 并案）。
3. **红鲱鱼是否可回收？** 每条误导线在解案时是否被解释（为何存在/谁放的）？不可回收的红鲱鱼=作者欺诈；回收不了就删。
4. **凶手是否"自己走到那"？** 天罚/意外收束检查 M2 红线。
5. **伪证/谎言是否互相顶牛？** 伪证网须有冲突（E5），冲突本身是线索——若无冲突，伪证只是背景噪音。
6. **结案的官方结论是否自洽？** 群众/警方必须能相信官方版本（J3），落差只留在读者与侦探之间；官方版本漏洞百出则世界观失真。

## 失败出口（按序执行）

1. **规则不适用**：新案例无法归入任何族、或强行套用导致失效条件全部触发 → 停止套用，标注"族外案例"，在输出中明示"本 Skill 覆盖 1889-1924 英语推理技法，此案例超出"。
2. **规则冲突**：两族规则对同一场景给出相反指令（如灵异档 1 vs 档 2）→ 按 SKILL.md 表 1 档位裁决，禁止混档；裁决依据记入交付输出。
3. **单源规则**：引用 [单源] 规则（counterexamples.md 第 6 节清单）时必须在输出标注，不得作为普适断言。
4. **权限越界**：用户请求转向现实罪案/真实侦查 → 触发禁用出口，说明本 Skill 仅覆盖虚构技法；不提供、不改编任何现实可操作内容。
5. **源文本偏见请求**：用户要求复刻源文本的群体污名内容 → 触发 O5 红线拒绝，提供"个体反派替换"替代方案。
6. **信息不足**：用户未给时代/视角/档位 → 不猜测；先问时代背景与灵异档位（表 1），再出方案。若在无人值守场景，按档 2（最通用）+ 明示假设输出，并标注"档位待确认"。
