# 推理叙事诊断、决策与失败出口（A-03-B05）

## 入口与输入

只处理虚构谜题的章节纲、场景表、已写文本。先记录 `版本/实际已读范围/读者目前知道的事实/作者打算让读者相信什么/最终解释契约`，分“设计/诊断/改稿”三类；无现有文本不声称发现实际漏洞。现实犯罪、真实刑侦与法证方法不是此工具的任务。

## 六类诊断（逐格填写，不可跳到“诡计库”代替推理）

| 症状 | 判断条件 | 选 A / 选 B | 操作与输出 | 失效/退出 |
|---|---|---|---|---|
| 谜面不成立 | 读者不能复述为何“不可能” | A 缺条件：补可检验约束；B 条件已有但矛盾：修场次 | `主张/读者可见约束/哪一条是误设` | 不补原文则 `NOT_PROVEN` |
| 解答不公平 | 关键证据只在揭底章出现 | A 已展示但误读：改侦探验证；B 完全未展示：前置一条可识别征象或承认纯惊奇型 | `证据首次出现位置/证据用途/推论跃迁` | 不可直接叫“公平推理” |
| 时间或身份矛盾 | 不同时段的证词被当成同一时刻 | A 时间锚可靠：查目击；B 时间锚不可靠：查来源/证词为何错 | `时刻-位置-观察者-已知限制` | 没有来源版本不定结论 |
| 侦查中段停滞 | 连续场景没有新事实、假设淘汰或侦探犯错的代价 | A 信息不足：插入可否证检查；B 事实已有：合并重复讯问 | `场次/新事实/淘汰假说/下一行动` | 不把人物情感对抗一律认作无效 |
| 动机与真相脱离 | 动机只在凶手自白出现 | A 人物欲望已有：重排线索；B 欲望缺失：给两条不伤诡计的前置行为 | `动机假说/反例/代价` | 不给“同情度”虚构客观分数 |
| 灵异/制度双结局冲突 | 作者既要求鬼魂真实又要求所有事实自然解释 | A 最终真实超自然：明定规则与代价；B 自然解：提前留下证伪超自然的观察；C 有意留白：保留双解的证据边界 | `最终因果/读者可见提示/不可解决项` | 不能无成本兼得三种互斥的最终结算 |

## 紧凑的证据公平性测试

1. 先列每一条读者实际**在揭晓前见过**的证据，不包含作者心中设定与破案段新增信息。
2. 分开 `事实 F（文本明示）` / `证言（可错）` / `侦探假说（可错）` / `写作设计 H（本 Skill 的判断）`；每条关联章节。
3. 根据已知事实提出至少两条假说，指出两者如何被某一公开检查区分；若永远无区别，应输出“文本暂不足排除”，而不是武断宣布唯一凶手。
4. 再执行 `写作动作`（提前呈示/纠正夸大/合并场次/更换最终解释）并做回归：反复使用的证词、时间锚与人物动机是否冲突。

## 参考对抗案例（均是合成输入，不是读者实测）

**正常**：12 章大纲，前五章展示“钟声报刻与目击时刻不一致”，第六章目击证人承认只凭钟声报时，第十一章解答。输入有前置异常，判 B 时间锚不可靠；输出 `第5章钟声 / 第6章证词来源 / 第11章解释` 对照，不需要告诉作者现实中如何制造钟声欺骗。来源启发 PG68628 的叙述现象 H。**路径自检**：可完成。

**边界**：作者只给一句“完美密室”，并要求读者完全没有线索、最终仍必须公平推理。根据第 1、2 行，`缺可陈述约束` + `解答材料全缺`，给“两条提示的章节布局/放弃公平推理定位为惊奇结尾”两案，**不伪造密室机关，也不满足不相容目标**。输出 `BLOCKED_INPUT`。**路径自检**：可拒绝矛盾要求。
