# Serialized Volume Planning（连载卷规划）

## 0. 这是什么

一个**人工填表 + 条件判断**的 workflow，并非自动化系统。

- 输入：作者/编辑给的设定、合同或排期、已有稿、前卷信息。
- 输出：**按任务选取的核心表**（卷槽位、卷末承诺、章节检查、开放线台账、容量、排产）+ **存在跨卷连续性时的复位检查** + 可选表（变奏/回顾分档/反馈日志）；以 §5 为准。
- 不做：不写正文、不评分、不预测销量/留存、不自动改稿、不建状态机、不含 scripts。
- 不能替代：作者对故事的选择、编辑对合同的判断、读者反馈的真实数据。

## 1. 证据底座：103 来源的三个不同事实

- P1 **来源身份**：当前 103/103 原始版与阅读版 SHA-256 匹配固定书籍元数据；额外按本工作区原始 manifest.yaml 验证阅读版 103/103 完全一致。这个结果只证明版本身份。
- P2 **全文阅读证据（2026-10-30 R04 复核口径，取代旧版“66/103 + 37 NOT_PROVEN”）**：**103/103 份均有连续区间级阅读证据**，分三档——① **87 份**由历史轮次的 `## L起-止` / `- 块N L起-止` 分块台账连续覆盖；② **6 份**由本轮（round-p4-final-2026-10-30）用 Read 实读补齐并通过 `kd32_ledger_gate.py` 机械核验（PG39576 / PG5978 / PG63483 / PG1142 / PG33148 / PG50975，合计 9,636 行）；③ **10 份**证据以 Markdown 表格、共享台账分片或自报分片形式存在（PG1752 / PG47901 / PG51127 / PG525 / PG1918 / PG91 / PG32328 / PG35443 / PG53607 / PG62010），本轮已逐本打开核对格式与自述状态，**可信但门禁不能解析**，故不计入门禁通过数。旧版“66/103”只是标题格式识别口径，不是未读证据；旧版“13 全文/8 定向/81 扫描、14% Token”是 R01 历史时点口径，不得当作当前 P2。见 [source-index](references/06-source-index.md) 与本轮 `notes/source-coverage.md`。
- **P2 仍要如实说的缺口**：上述 10 份非标准格式证据若要 103/103 机械通过门禁，还需补做格式归一或重读——本轮没做。引文自动回源抽样见 `notes/source-coverage.md` §2，其“查无出处”比例含抽取器假阳性，**不可当造假率**。
- **来源族和方法**：同系列/同作者/house name 不重复算独立支持。小说的 F 是已定位人物或**发行体例**，作者自述是个人经验，H 是有限跨书推论，P 是本工具的操作。13 条 active 规则（M01–M05、M07、M11–M15、M16–M17）仅限具体条件；**M06 维持 UNRESOLVED**；**M08 已 REVISE 为三路线判据（仍不给单一通则）**；M09/M10 普遍化结论继续 REJECT。
- **不可推断**：没有真实现代网文平台留存/销量/完读数据；期刊页数和每卷章数不是成功阈值，2026 年现代连载的节奏、开载策略、存稿量均不得按历史小说硬编码。真实产品验收和独立 GQ5 NOT_PROVEN。

## 2. 触发 / 负触发

### 触发（满足任一）

- 要开一个多卷系列：问“分几卷、每卷多少章、卷末怎么收、下一卷怎么接”。
- 已有连载出现“卷末像完结/下一卷没有入口/新读者不知道从哪进”。
- 卷内节奏疲劳：同一桥段反复、章末钩同型、配角没有变化、容量不断超支。
- 要审计跨卷伏笔/开放线，或判断哪些线该回收、哪些该关掉。
- 开载前要排产：容量、存稿、缓冲、备用结局、回顾方案。
- 要规划或诊断**一期/一号/一册的构成**（期刊、周刊、分册、连载单元）：正文切片怎么切、要不要填充栏目、下期预告带不带日期、过期号怎么补。（R04 新增，走 M16）

### 负触发（不要用）

- **单本闭合长篇**：只用 [01 §1](references/01-volume-architecture.md) 的单本分流与 [05](references/05-production-constraints.md) 的容量表；不建槽位表、不做续卷回顾、不设开放线。
- **短篇、单章、散文、无部无章的作品**：没有卷级边界，本 Skill 不适用。
- **没有连载约束的一次性作品**：不按“期/号/卷”排产。
- **纯文学实验、反情节、作者刻意不要钩子**：不要套 M03；只需知道这是负触发。
- **没有大纲，作者只要灵感/头脑风暴**：不生成卷纲、不编情节；只能给“假设表 + 需作者决定项”（见 §8）。
- **要求保证爆款、自动评分、自动写卷、自动判定读者反应**：超出证据与工具边界，直接说明做不到。

任务类型判据（避免把“诊断”做成“重写”）：
- **规划新卷**：还没有本卷稿，或只有设定/合同；输出表，不评判未写的文字。
- **诊断既有卷**：有已写/已发表的卷；先填表找结构缺口，再决定是否修。
- **修订失败期**：连续若干章出现同型钩、同节拍、回顾过长、复位过度或容量超支，且作者/编辑判断需要修；没有读者数据时只看结构信号，不看“评分”。
- **连续性审计**：至少两卷或一卷跨多部；核对时间线、人物状态、世界状态、开放线，不重写剧情。
- **开载前排产**：尚未开载；只填容量/开载检查表，不预测销量。

## 4. 最短执行路径：系列、卷、章节三个层级分开

1. **G1 作品单元**：单本/一个分册/系列卷/一条故事长线跨卷？明确用户自己承诺给读者的边界。单本时只做必要的部界和容量；持续系列时记录跨卷依赖，不强迫每卷独立结案。
2. **G2 闭合承诺**：本卷承诺的是案件结案、角色阶段变化、关系变化还是长期追捕的局部节点？已立项下卷可选择保留新入口；未立项也可保留角色未决，但不要把尚未承诺的未来卷写成已兑现。闭合、半开、全开由作者/出版契约选，不默认唯一。
3. **G3 生产条件**：合同有章数、截止和格式时先核容量；没有就用假设与范围，不伪造可行排期。已有稿先核真实长度再决定拆章/移场景。
4. **G4 跨层依赖**：新章节能否让卷内承诺推进？新卷是否改变既有角色/世界状态并继承已公开的事实？检查开放线具体下次动作、负担与回收选项，不按机械数量阈值自动关闭。详见 [跨卷/章依赖模型](references/08-cross-volume-dependencies.md)。
5. **按任务走最短路径**：新卷规划 01/05→03→按需 02/04；既有卷诊断 03→01→必要时 02；重复章节节奏修订 02/04→05；连载反馈或发布变更 05/07→03 检查真实数据与作者正典权威。输出原稿位置、F/H/P、竞争解释与回归。

## 7. 禁止项（硬边界）

以下不是“风格偏好”，是证据边界；违反即越出本 Skill 能支持的范围。

- **M06 升级路径（UNRESOLVED）**：不得写“每卷必须升级/加码”“必须换地图/换身份/换角色位置”。几种做法互相冲突（换地图/换身份/换角色位置，另有只换地图不提高赌注的反例），PG331/PG1401 甚至不提高赌注。作者问“该不该升级”，只能答“未裁决，需作者决定”。
- **M08 开载时点（R04 扩为三路线，仍不给单一通则）**：**三条**路线均有作者实践 F 证据——A 完稿再发+存稿缓冲（Trollope，并附“原则的技术理由：保有把开头适配结尾的能力”与“一生仅一次有记录的破例，此后从未再破”，PG5978 L3486-3522）；B 写至约半开载、以截稿日逼完成（Daudet，PG32328 L3289-3301）；**C 先在刊物连载验证、再决定出书方式**（匿名新作被出版商怀疑 → 自费印 600 册 + 委托发行，并把印刷账单付款时点排在回款之后，PG33148 L998-1009、L1017-1025）。仍不得写“某种路线普遍更稳”；判据表见 [07 §3](references/07-production-discipline.md)，开载检查表见 [05 §4](references/05-production-constraints.md)，选择由作者/编辑按判据做。
- **M09 闭合度（REJECT 作为通则）**：不得写“每卷必须擒反派/每章必须留钩/卷末必须有预告”。全闭合、半开、全开都有记录；用“闭合度旋钮”，不设法律。
- **M10 直觉式构思（REJECT 作为连载法）**：不得把“情节整块降临/先写末章/不逼稿”写成规划流程或生产建议；它只作为单本作者的个人风格备注。
- **不得把 26 本 Motor Matt、9 本 Merriwell、16 本 Nick Carter 当 26/9/16 份独立证据**；同族只计 1 族。
- **不得把出版社书目、卷末预告、订阅印花、书末广告当作者写作顺序**；它们是发行装置。
- **不得把 1900 年代种族刻板形象（如 Ping、华人帮会）当角色模板**；只能作为时代局限注记。
- **不得把现代网文/商业平台写成 F**；所有迁移标 H / NOT_PROVEN，并写验证缺口。
- **不得声称具备自动化执行、自动评分或自动状态机**；本包没有 scripts，所有表人工填写。

## 8. 失败出口

| 情况 | 能做的 | 不能做 / 退回 |
|---|---|---|
| **没有大纲** | 只填“假设表”：系列长度、闭合度、容量参数、常驻班底；列 3 个需作者决定项 | 不生成卷纲、不编情节、不假装已读前卷 |
| **没有前卷** | 只做本卷内检查（钩型、容量、卷末四问）；跨卷断言标 `UNVERIFIED` | 不写“前卷回顾”，不判断跨卷线是否回收 |
| **规则冲突** | 按优先级记录冲突：合同/已立项 > 单卷可读 > 变奏 > 排期；列冲突表，给两个可选方案 | 不硬套一条规则、不把冲突藏进“建议” |
| **作者要求无限续写** | 给“债务台账 + 回收节奏”的 H 方案；说明 ≤2 条只是历史样本的保守上限 | 不把 ≤2 当法律；不承诺留存/完读；不说“经验证明” |
| **作者拒绝任何开口** | 全闭合；转“独立卷/选集”模式；M02/M13 不适用 | 不硬加钩子、不制造假悬念 |
| **证据不足（现代平台/读者数据）** | 输出参数化表 + 验证缺口 + 需要什么数据 | 不给“应该怎样”的结论，不编现代样本 |
| **只有一句话设定** | 最多给问题清单与空白模板 | 不生成卷槽位/章数/结局 |

冲突时的默认顺序（只在没有合同硬约束时）：
