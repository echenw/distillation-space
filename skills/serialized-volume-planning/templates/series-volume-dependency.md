# 系列—卷—章节依赖矩阵（根据实际版本填写）

| 列 | 说明 |
|---|---|
| 作品与正典版本 | 用户提供/已发表章节，缺料 NOT_OBSERVED |
| series_goal | 长线问题/主题及不可破坏约束 |
| volume_id | 卷/季/分册的读者承诺和预计结束处 |
| chapter_id | 支撑此卷承诺的事件/场景定位 |
| character_state_before_after | 人物所知、目标、关系/权力前后变化 |
| world_state_before_after | 组织、地理、物件状态和制度规则变化 |
| open_line_id | 仅实际打开的悬念/承诺、首次出现卷章 |
| dependency_id | 兑现该线必须先发生的事件与消费者 |
| proposed_resolution | 回收、转化、延期、放弃的作者候选 |
| proof | F 原文定位 / H 推断 / P 建议严格分开 |
| next_action | 下一章/卷有意义的行动，不是必然钩子 |
| capacity_assumption | 合同定值与推断数值分离 |
| author_decision | 事实已确认 / 待补证 / 需选择 / 不适用 |

## 回归与结果
按前卷实际存在的行动、读者已经收到的承诺、后卷人物信息和版次逐项确认；发现冲突不伪造已修正，列可逆的 A/B 方案与影响范围。拒绝以“超过 2 条开放线”“没有一章缓冲”作为跨题材失败条件。
