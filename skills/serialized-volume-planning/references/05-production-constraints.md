# 05 生产约束：容量表、开载检查表、反馈日志

本文件处理“写多少、什么时候交、开载前看什么、反馈怎么记录”。卷架构见 [01](01-volume-architecture.md)，变奏见 [04](04-formula-and-variation.md)。返回 [SKILL](../SKILL.md)。

## 1. 适用边界

- 适用：合同/版式先定长度；周刊/分册/分卷；有截稿日；编辑可停单/砍篇幅。
- 不适用：无长度约束的开放连载；先写后拆章；以单本文学密度为目标（容量法会牺牲密度）。
- 先说明：本文件的“每章词数/页数”是**版式与排产参数**，不是叙事规律。PG47455 的“每章 5 页→16 章”是印刷规格，不能写成“每章必须 5 页”。现代平台的具体字数/更新频率若进入容量表，按 **H** 处理（见 §6）。

## 2. M07：容量先于情节

<!-- R13-CLAIM:M07 -->
**断言（M07 条件化）**：载体/合同容量已确定时先填可核数据，估算每章内容与交稿节奏；情节冲突时提出调节容量、删合子线、拆卷或重新约定范围等候选，不单方面保证“必须保留某个终点”。容量未定则只做假设和风险，不断言排期可行。

- **when**：合同/版式先定长度；周刊/分册/分卷；有截稿日；编辑按页/期计酬。
- **when_not**：无长度约束的开放连载；先写后拆章；以单本文学质量为目标；作者不能控制篇幅。
- **动作**：
  1. 填容量表：载体/版式、每章/每期词数、总章数/期数、总容量、钩位、交稿节点、缓冲章数、备用结局。
  2. 用算术核对：每章词数 × 章数 = 总容量；缓冲章是否包含在总章数内，要写清。
  3. 每 3 章核对一次实际词数/进度；超出计划时，先削减从属线数量或合并章节，**不移动主线终点**。
  4. 如果合同给的是页数，先换算成词数（按实际版式），不要把“页”当叙事单位。
  5. 把“未知参数”单独列出（如平台最终字数、编辑是否加页），不要假装已确定。
- **输出**：**容量表**

  | 载体/版式 | 每章/每期词数 | 总章数/期数 | 总容量 | 钩位 | 交稿节点 | 缓冲章 | 备用结局 | 假设/来源 |
  |---|---|---|---|---|---|---|---|---|
  |  |  |  |  | 每章/每期 |  |  | 有/无，分叉章 |  |

- **反例 / 边界**：
  - PG33148 419,954 / 425,361 的 Stevenson 有地图+章表，仍在第 16 章崩盘——容量表不保证执行。
  - PG5978 的 3 小时/日、每刻钟 250 词是 Trollope 的个人配额，不适用于需要现场调研的作者。
  - PG47455 的“5 页/章”是印刷规格，不是“每章必须 5 页”的叙事规律。
  - 容量与情节冲突时，先调从属线；如果作者拒绝删任何线，输出“超支算术 + 两个方案（加章/砍线）”，让作者选。
- **来源**：PG47455 L3867–3871（PARTIAL 95%，Cook 族：8.5×13 英寸纸、每章 5 页、80 张一篇→“thus there were always sixteen chapters”）；PG47455 L1356–1364（PARTIAL：两周一篇 40,000 词，忙时 30 天 3 篇）；PG5978 182,402（PARTIAL 9.9%，Trollope 族：页=250 词、逐词计数、按周分栏，周配额平均 40 页、低 20、高 112）；PG5978 404,700（PARTIAL：3 小时/日、每刻钟 250 词）；PG33148 425,361 / L7666（PARTIAL 12.2%，My First Book 编辑卷：Stevenson “Fifteen days … fifteen chapters”）；PG27621 L129–130（FULL，Duchess 族：一夜预演 3–4 章，次日誊写）。**4 族**。
- **置信**：中（4 族；含 1 本 95% 阅读，配额是个人证词）。
- **身份**：F（页/词/周配额与章数倒推）→ H（容量先定、由容量反推章数）→ P（容量表+每 3 章核对）。
- **R02 作者端证词补强**：Trollope 周配额簿（20–112 页/周浮动、页=250 词、逐词清点、昨日稿重读半小时）见 [07 §1](07-production-discipline.md)；参数是个人+时代排版，可迁移的只有“自定计量单位+逐日台账+浮动区间+重读”四件套结构（H）。M07 置信由中升高：4 族+1 本全文+作者自证。

### 2.1 容量表的算法示例（假设值，不是历史事实）

| 参数 | 值 | 说明 |
|---|---|---|
| 每章词数 | 2,600 | 作者/编辑给定，或按版式换算 |
| 总章数 | 30 | 合同/排期给定 |
| 总容量 | 78,000 | 2,600 × 30 |
| 缓冲章 | 4 | 含在 30 章内，还是额外，必须写清 |
| 交稿 | 6 个月 | 每月 5 章 |
| 备用结局 | 第 28 章分叉 | 合同允许时保留 1–2 期可提前收束 |

如果写到第 12 章发现每章实际 3,200 词：12 × 600 = 7,200 词超支；按 2,600 词/章，相当于多出约 2.8 章。处理顺序：合并 1 章、删 1 条从属线、把 2 章拆成 3 章（若合同允许加章）；**不要**把主线高潮提前或删掉。

## 3. 容量与其他表的联动

- 与 M01 槽位表：槽位表的目标词数/章数来自容量表；两表冲突时，先改槽位表的“计划容量”，不要改已签约的卷数。
- 与 M02 卷末四问：缓冲章是容量表的一行；没有缓冲章，卷末四问第 3 问直接判“否”。
- 与 M05 变奏表：同一节拍第 3 次通常先被容量挤掉；删节拍前先确认它不是主线账本的一部分。
- 与 M13 台账：开放线需要“下一卷动作”，也会占用下一卷容量；台账里加一列“预估章数”，防止下一卷超载。

## 4. M08：开载前检查表（不裁决路线）

**状态：已结构化（R02），仍不给单一通则。** 两条路线均有实名作者实践 F 证据：Trollope 的“先完稿再发”现已有**作者原话**（PG5978 L3485–3522，R01 所据“其子 Preface”口径升级；一生破例一次，理由=Cornhill £1000+6 周交首批，L3475–3522），并配存稿缓冲（L6687–6699）；Daudet 走“写至约半即开载”，以截稿日逼完成、放弃回改权（PG32328 L3289–3301）。**没有销量/质量对比数据；Stevenson 有章表仍崩盘的反例不变；本 Skill 不替作者选路线**，判据表见 [07 §3](07-production-discipline.md)。

只填表，不评分：

| 检查项 | 记录 | 备注 |
|---|---|---|
| 已完稿章数 |  | 实际完成，不是计划 |
| 存稿章数 |  | 可立即交付的章 |
| 缓冲深度（章） |  | 存稿能撑几期；0 是风险输入，不是自动结论 |
| 备用结局 | 有/无；从哪章分叉 | 合同允许时才有意义 |
| 截稿节点 | 每期/每卷日期 | 与缓冲深度对照 |
| 返工预算 | 时间/字数 | 编辑要求大改时用 |
| 合同条款 | 停单/砍篇幅/续订/改名/违约责任 | 决定作者有多少修改权 |
| 决策人 | 作者/编辑/平台 | 谁定开载路线，写清 |
| 上一个同类项目的实际结果 | 按时/延期/停单 | 只作参考，不作规律 |

**出口**：作者问“先完稿还是边写边载更稳”，回答“两条路线都有作者实证、没有质量对比数据，无法裁决”；给出 [07 §3](07-production-discipline.md) 判据表 + 本检查表，让作者/编辑按判据决定。不要写“缓冲 ≥3 章才安全”——那是未验证的 H。

## 5. M12：反馈日志（低置信，可选）

<!-- R13-CLAIM:M12 -->
**断言（M12 条件化）**：收到真实编辑/读者反馈时记录来源、样本、时间、可证事实、意见与成本，把它作为修改建议候选；作者决定是否采纳并核对已发表正典。备用结局及角色退场仅在作者目标和生产风险确有需要时设计，不固定一到两期。

- **when**：连载中；读者/编辑可直接接触作者；作者有修改权；合同允许调整人物/结局。
- **when_not**：完稿后一次性发布；作者无修改权；反馈只来自单一匿名渠道且无法核实。
- **动作**：
  1. 建反馈日志：日期、来源（读者/编辑/数据）、具体要求、影响范围（人物/卷长/结局）、代价、决定（采纳/拒绝/延后）、复核日期。
  2. 给常驻人物设退场机制：死亡/远行/降职/转岗/退居二线；在需要之前想好，不要临时杀角色。
  3. 仅在合同变化或断更风险足以影响读者承诺时准备候选提前收束方案，写明分叉时点、已发表事实和取舍；不得直接把候选写成正典。
  4. 单次反馈只记录，不立即改；至少等第二次同向信号或编辑正式要求。
  5. 不把“杀角色”当听取反馈的正面范式；Trollope 事后后悔，且两种回忆版本矛盾。
- **输出**：**反馈日志** + 退场机制清单 + 备用结局位置
- **反例 / 边界**：
  - PG5978 L6755：在俱乐部听到两位牧师抱怨“每部小说都重推同一批人物”，当场承诺“I will go home and kill her before the week is over”，随后照办，事后后悔。
  - PG32328 3048–3050 是同一事件的二手转述，且说法不同（“unknown critic abuse … I went home and killed her immediately”）；**不增加独立族**。
  - PG47455 1890–1891：编辑指定“at least one wedding and that in the beginning of the story”；3190–3191：出版社用电报下令“close up finally the adventures of the hero … to an appropriate end”。
  - PG74755 652288：写了二十年同一类故事的作者想转型，编辑“would not let him”。
  - 编辑配方被作者自己称为“little plot”；反馈能改变人物命运/卷长/收尾，但常是即兴/被动，不是规划。
- **来源**：PG5978 L6755（PARTIAL 9.9%，Trollope 族）；PG47455 1890–1891 / 3190–3191（PARTIAL 95%，Cook 族）；PG74755 652288（PARTIAL 4.5%，Anderson 族）；PG32328 3048–3050（PARTIAL 17.7%，Erichsen 二手汇编，不另计族）。**3 族**。
- **置信**：低（自述/回忆为主，且两种版本矛盾；只能作可选检查表）。
- **身份**：F（作者回忆/编辑电报）→ H（反馈可被记录、人物可预留退场、结局可留备用）→ P（可选，不作默认流程）。

## 6. 现代迁移（全部 H / NOT_PROVEN）

| 编号 | 迁移假设（H） | 本语料依据 | 为什么不能当 F | 需要什么才能验证 |
|---|---|---|---|---|
| T1 | “卷=付费/上架单元”可映射为“卷=订阅周期/完本单元” | M01 的编号槽位 | 现代平台按章付费/广告分成，无“号”零售；合同结构不同 | 平台合同、结算方式、卷级销售数据 |
| T2 | 三类章末钩可迁移为“追读钩” | M03 | 现代读者连续滑动、算法推荐；19 世纪读者隔周购买，钩子强度需求不同 | 章末留存曲线、A/B 钩型测试 |
| T3 | 容量表可迁移为“日更 2–4k 字/章”的排产 | M07 | 现代章长、更新频率、存稿文化不同；无现代样本 | 平台字数分布、作者存稿调查 |
| T4 | 闭合度旋钮可迁移为“完本/续作/番外”策略 | M02/M09 | 现代有完本奖励、连载中腰斩、IP 续作等新约束 | 完本/断更/续作的收益对比 |
| T5 | 开放线 ≤2 可迁移为“长线伏笔上限” | M13 | 现代长篇可达数百万字、数千章；上限可能不成立 | 长篇开放线数量与回收率统计 |
| T6 | 反馈日志可迁移为“评论区/数据面板驱动修改” | M12 | 现代反馈即时、可量化；19 世纪是俱乐部闲谈/编辑电报，颗粒度不同 | 评论/数据与修改决策的因果研究 |

**迁移写法（必须照抄这个句式）**：
`H（推断，未验证）：在 X 条件下，可能……；本语料只证明 1900–1925 年英美通俗连载中的做法，不证明现代网文有效。`

禁止写“现代网文也应该……”“经验证明……”。没有现代来源，就没有 F。

## 7. 失败出口

- **没有合同/字数**：容量表只填“假设值”，标 H；不给“排期可行”的结论。
- **没有大纲**：只给容量骨架（章数/每章词数/交稿节点），不填情节；列需作者决定项。
- **容量与情节冲突**：先砍从属线/合并章节；作者拒绝删任何线 → 输出“加章/砍线”两个方案与代价，让作者选。
- **作者要求“保证不超支”**：说明容量表是计划，不是保证；Stevenson 有章表仍崩盘。
- **作者要求“先完稿还是边写边载，你定”**：退回 M08；给 07 §3 判据表 + 本检查表，不替作者选。
- **没有反馈渠道/作者无修改权**：不用 M12；不要假装有读者数据。
- **现代平台具体字数/留存**：标 H / `NOT_PROVEN`；不给“应该日更多少”的结论。

## 8. M16（R04 新增）：单期 / 单册的载体构成检查

<!-- R13-CLAIM:M16-R04 -->
**断言（M16 条件化）**：当作品以"期 / 号 / 册"为单位发行时，**先把载体的物理构成查清，再谈情节边界**。一期的边界通常是载体决定的，不是情节决定的。

- **when**：期刊、周刊、分册、连载单元；一期内混有非虚构栏目或出版商目录；用户要决定"一期放多少正文"。
- **when_not**：单本精装、自出版单文件、无期刊载体 —— 此时载体不决定边界，**转 M14 只核发行承诺，不要套本节四层**。
- **动作**：填载体构成表；缺项写 `NOT_OBSERVED`，不要推测补成事实。

  | 构成层 | 本作品观察 | 作用 | 状态 |
  |---|---|---|---|
  | 正文切片 | 本期内正文到哪里为止；是否有明确的未完成标记 | 决定"一期"的情节边界 | 已观察 / NOT_OBSERVED |
  | 非虚构填充栏目 | 有无科普/说明/杂文页；占多少页 | 占据固定页数，不承担情节 | |
  | 同社其他系列目录 | 有无编号目录；是否互相导流 | 说明系列在出版商产品线里的位置 | |
  | 下期预告 | 有无；**是否带确切日期** | 读者的预期锚点 | |
  | 过期号补档入口 | 有无邮购/订购单/补号说明 | 新读者如何进场 | |
  | 版本留痕 | 有无校勘记/转写说明 | 改动是否逐条可查 | |

- **输出**：载体构成表 +（若带连续编号）卷槽位表。
- **来源（F，载体事实）**：PG50975 L4079-4083（本轮实读：正文以 `TO BE CONCLUDED.` 明示未完成）；L4088-4129 与 L4134-4183（两篇与情节无关的填充栏目）；L4188-4299（同社 MOTOR STORIES / TIP TOP WEEKLY / NICK CARTER WEEKLY 三种周刊的编号目录）；L4357-4413（已出版 / 即将出版分段，后四号带确切日期：7-12、7-19、7-26、8-2）；L4302-4336（每册 5 美分的邮购条款 + 可填写的过期号订购单）；L4426-4462（逐页校勘记）。
- **反例 / 边界**：PG42569（A. Hyatt Verrill 真名单行本，章末允许平稳换场，无目录页与下期预告）——**载体不同则本节不适用**，不得对单行本硬套六层。目录、预告、订阅印花是**发行装置**，只能说明载体如何组织，**不能**用来推断作者的写作顺序或创作方法。
- **置信**：载体事实 F（1 个出版商 + 1 条产品线，族去重后计 1 族）；"现代连载也如此"为 H / NOT_PROVEN。
- **身份**：F（载体构成）→ H（边界由载体决定的机制）→ P（载体构成表）。
- **与其他规则的关系**：先做 M16 判载体，再做 M03 谈章末钩（不同载体的钩需求不同，见 07 §5 的 5¢ 周刊 vs 真名精装书对照）；M16 的"编号 + 日期预告"是 M01 槽位表的载体级证据。

## 9. M17（R04 新增）：篇幅下限 vs 单期不冗长（比例法）

<!-- R13-CLAIM:M17-R04 -->
**断言（M17 条件化）**：当"必须覆盖确定篇幅"与"任何单期都不许冗长"同时成立时，**这两条互相冲突**；处理方式不是少写、也不是随意加料，而是**比例 + 附属于主线的次要情节 + 对话段单独检查**。输出是一张冲突表，不是单一建议。

- **when**：合同/平台给了篇幅下限（卷长、字数、期数），同时作品以分期方式发表（每期都不许被跳过）。
- **when_not**：无篇幅下限（短篇、中篇、无字数约定）——不做折算，直接按故事需要写。
- **动作**：
  1. 填"填充来源表"：`需要增加的篇幅 | 用哪一项填（比例 / 次要情节 / 人物扩充） | 与主线什么关系 | 对话段是否已检查`。
  2. 三项可核的检查：① 主线仍是一整条，但可以有多个部分；② 情节本身只需少数人物，可扩充到在众多人物中充分展开；③ 次要情节必须**通向主线的阐明**，不是平行支线。
  3. 对话段单列一行：对话是最容易离题的地方，逐段问"这段是否以某种方式服务于主线"。
  4. 软阈值：一旦作者自己感到"这里变长了"，记为需要复核的信号（不自动删）。
- **输出**：填充来源表。
