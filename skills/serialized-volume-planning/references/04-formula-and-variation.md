# 04 公式与变奏：可重复的骨架，不可重复的代价

本文件给一条可执行规则（M05）和四个**不能写成规则**的条目（M06/M08/M09/M10）。卷末闭合见 [01](01-volume-architecture.md)，容量见 [05](05-production-constraints.md)。返回 [SKILL](../SKILL.md)。

## 1. 适用边界

- 适用：编号系列、常驻班底、读者买“型号”而非单本、周刊/月刊节奏。
- 不适用：单本、角色成长型、悬念型（重复会立刻显形）、作者没有稳定班底。
- 先记住：**重复不是优点，是成本**。公式能降低读者进入成本，也会积累疲劳；本文件的目标是“可控变奏”，不是“越像越好”。
- 现代平台/类型是否适用，按 **H**；本语料的样本是 1900–1925 年编号系列，不是现代网文。

## 2. M05：读者辨识与跨卷变奏的平衡

<!-- R13-CLAIM:M05 -->
**计量口径（历史案例）**：本文件的“期”指一次发行单位（章节/分册/刊期），“卷”指承诺给读者的上层单元。旧版每卷 1–2 变量/每章不超过 1 项只是针对特定冒险出版物的设计假设，不是形式上的上限；人物、地点、敌人和节奏可协同变化。

**断言（M05 条件化）**：当系列依赖可识别节奏时先标稳定的主题/角色能力/承诺，再对变化的地点、角色功能、威胁、关系和代价做对照；只在重复没有新增因果时建议变奏，不设每章/每卷固定变化数量。

- **when**：编号系列；常驻班底；读者按系列/型号购买；周刊/月刊；每期需要可识别的“同一种东西”。
- **when_not**：单本；角色成长型；悬念型；作者没有稳定班底；每卷换主角/换类型。
- **动作**：
  1. 建“变奏表”：固定项（主角/班底/事件类型/章数）与可变项（场景/道具/对手/代价/盟友功能）。
  2. 对实际变动项逐项标对读者认知负担与故事承诺的影响；可同时改变场景和对手，但要保持因果清楚。
  3. 标明同节拍反复出现是否产生新行动、信息或代价；若重复本身是角色困境，也可以保留，不要求第二次必换代价。
  4. 若重复没有可解释的叙事作用再考虑删改；不要按第三次固定阈值裁剪真实变化。
  5. 疲劳诊断：同一救援/同一逃脱/同一载具故障/同一“敌方女儿”功能位/同一巧合，出现两次以上就标红。
- **输出**：**变奏表**

  | 固定项 | 本卷取值 | 可变项 | 本卷选择 | 第 1 次节拍 | 第 2 次（换代价） | 第 3 次（删/合并/理由） |
  |---|---|---|---|---|---|---|
  | 主角/班底/事件类型/章数 |  | 场景/道具/对手/代价/盟友功能 |  |  |  |  |

- **反例 / 边界**：
  - PG62072 两章几乎同构（设局—反杀—赌注落空），只换项目（棒球/拳击），已到公式疲劳临界。
  - PG74755 把标准杂志小说骂作“neatly wrapped packages … sawdust”。重复是成本，不是质量。
  - PG47455 的编辑自己抱怨旧配方“action was rarely varied”；出版社却仍以“same hero and the same class of incidents”续订——市场要重复，读者会疲劳，两者同时成立。
  - “一卷两次”是保守上限，不是实测最优；没有读者留存数据。
  - 旧版每卷 1–2 个/每期 1 个仅为历史比较值，不作章节编辑上限。
- **来源**：PG47455 L1117–1121（PARTIAL 95%，Cook 族：出版社以“the same hero and the same class of incidents”续订）；PG47455 L3888–3898（PARTIAL：三篇一组、各自完整、可合订）；PG27621 L89–95（FULL，Duchess 族：固定花园/花展/舞厅+一对年轻男女，“They are always young with me”）；PG61174 L4024–4291（FULL，Standish 族：正式棒球赛之间插入拳击、独木舟等竞赛段，每段完整且改变主线资源）；PG47901 89720–97720（PARTIAL，Matthews 族：同一“敌方女儿”功能位，Helen 的协助强度高于 Ysabel）；PG62072 207500–215500 与 273333–281333（PARTIAL，Standish 族：两章几乎同构，只换项目）。**4 族**。
- **置信**：中（4 族；上限是保守值，不是实测最优）。
- **身份**：F（同系列重复的节拍与变量）→ H（固定骨架+每卷 1–2 个可变项+第二次换代价）→ P（变奏表+疲劳诊断）。

### 2.1 什么可以固定，什么必须变

| 可以固定 | 必须变（至少一项） | 不要固定 |
|---|---|---|
| 主角、常驻班底、事件类型、章数、叙事视角 | 场景、道具、对手、代价、盟友功能 | 每章的“反转位置”、每卷的“最后一分钟救援”、反派的“逃跑方式” |

“固定”是为了让读者一眼认出系列；“变”是为了让读者不觉得白读。两者缺一不可。

### 2.2 疲劳诊断表

| 信号 | 检查问题 | 处理 |
|---|---|---|
| 同一节拍第 2 次 | 这次代价和上次有什么不同？ | 换代价；写不出就删 |
| 同一救援方式 | 被救的人/救援者/代价是否变化？ | 换救援者或让救援失败 |
| 同一反派逃跑 | 逃跑后是否推进了开放线？ | 进 [03](03-continuity-and-reset.md) 台账；否则改成被捕/转性 |
| 同一“敌方女儿”功能 | 她的协助强度/代价是否变化？ | 换功能位或减少戏份 |
| 同一载具故障 | 故障是否改变任务目标？ | 换故障类型或删 |
| 同一巧合 | 是否由人物选择造成？ | 改成选择后果；否则删 |

## 3. 未裁决：M06 升级路径（不要写成规则）

| 观察到的路径 | 文本例 | 它做了什么 | 它没做什么 |
|---|---|---|---|
| **同世界观加深/身份位置翻转** | PG2020 约 186248（被当作神）/ 432802（囚）/ 513235（盟友 Ja-don 登基） | 主角在同一卷内被误认为神、后成为囚；卷末参与拥立新王——身份/政治位置翻转，由当地信仰与政变解释 | 没有扩大世界观，只加深 |
| **赌注换成产权/生意** | PG51127 31878 / 56347 | 买下半个产权（31878）、付 500 美元（56347）、签合伙协议；冲突从“救人”变成“产权/破产” | 没有提高武力/地图等级 |
| **角色位置互换** | PG1752 453952–461952 | 中段把“施救者”改成“人质”，让妻子/部下承担行动 | 不是“主角更强”，是“主角被缴械” |
| **只换地图，不提高赌注** | PG331 446212–454212；PG1401 405687 / 428249 | 芝加哥→海盗船→南洋→墨西哥；新地图 Xuja/疯人城 | 赌注不累积，每次被俘都归零 |

**冲突**：这四条不能合并成“每卷必须升级”。PG1752 靠角色位置提高危险；PG2020 靠身份误认提高新奇；PG331/PG1401 只换地图、不提高赌注。三者都成立，但没有证据说明哪种对应哪种读者留存。

> PG2020 的三个定位分属三个窗口（约 186248 / 432802 / 513235），不是连续阅读；这里只用它识别“同一世界观内翻转”的做法，不证明整条弧线的因果完整。

**本表只用于识别作者已经在做哪一种，不用于推荐；不要按“路径 1/2/3”给下一卷排路线。**

**出口**：作者问“下一卷要不要升级/加码/换地图”时，只能回答：
1. 本语料**未裁决**，没有“必须升级”的规则。
2. 请作者先定“系列承诺”：读者买的是“同一主角的新地方”，还是“同一主角的更高代价”？这是作者/编辑决定，不是 Skill 能替的。
3. 如果作者选“只换地图”，记录为“遭遇链”模式，不要承诺赌注累积；如果选“角色位置互换”，检查是否削弱主角能动性。
4. **不得**把本表写成“三选一菜单”或“升级路线图”。

## 7. 失败出口

- **作者要求“每卷必须升级”**：退回 M06；说明未裁决；请作者定系列承诺，不替作者选。
- **作者要求“每卷必须擒反派/每章必须留钩”**：退回 M09；给闭合度三态与钩型检查，不写“必须”。
- **作者要求“先写末章/不逼稿”**：退回 M10；记录为个人风格，不用于排产。
- **作者要求“先完稿还是边写边载，你帮我定”**：退回 M08；只给检查表。
- **变奏表填不出来**：说明还没有稳定公式；先做 [01](01-volume-architecture.md) 的槽位与 [05](05-production-constraints.md) 的容量，不要硬造“每期一个花样”。
