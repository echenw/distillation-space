# 力量叙事：能力、选择与社会代价

本包由 26 部英语童话、奇幻、冒险公版小说作跨题材观察，**没有中国武侠/仙侠一手作品**。角色与世界能力来自用户作品正典，不能把英语故事的情节“变成中国仙侠典型”。

## 触发/不触发

创作或修订获得、受限、失去力量；审稿寻找突然越级、凭空能力、无代价的权力承认、前后冲突。负触发：真实武学史、道教史、武功训练、武器使用、游戏战斗数值优化；本 Skill 不声称这些领域有验证能力。

## 输入和权威

首先确认作者已有世界规则与版本、人物当前能力/信息、场景片段（若有）、改稿权限；`F`=实际用户正典或源书可回源观察，`H`=推测，`P`=候选行为，来源 F 与作者 F 严格分开。对未提供的境界、功法、数字标 UNKNOWN，不继承其他书的等级规则。区分 `F_author`（用户世界正典）、`F_source`（本批原著）、`POV_BELIEF`（角色对奇幻的判断）与 `METAPHOR`（诗性描述）；R13–R15 见 `05-counterexamples-and-boundaries.md`。

1. **先建立能力状态**：来源、用途、是否可逆、谁可使用、用户明确限制与代价，参见 [可填能力卡](templates/power-arc-state.md)。没有已知限制时不要虚构“固定三层功法”。
2. **让能力服务选择**：每一次使用后追踪人物目标、信任、资源、身体或关系，哪些实际变化；允许一次性成长、长期克制、倒退，不强制“三次升级”。
3. **核对环境与权力**：强者为什么不直接出手，或者为什么选择亲自出手？制度/门派为何承认这项能力？要有可观察的信号与反例，不靠纯数值授权。
4. **控制揭示**：重要能力如果解决此前困难，前文应有角色/读者可观察的约束或线索；单纯惊奇或寓言可允许未知，但不能声称已设定的规则被自动重写。
5. **回归与输出**：按“原文位置（如有）→违反哪条作者正典→F/H/P→两个可选修法→修订后需反查的场景”输出。结局处理主要因果，不强制制度化终局。

## 缺料或冲突

既有设定同时宣称“法术不可能无代价”与“主角无限次零代价使用”时，列最小冲突集合、给两条可行解释（代价被转嫁／设定例外经作者确认）、暂停最终判定；用户只让诊断时不可替作者改变正典。无正文不编造第 N 章中的问题；没有中文类型样本不能给某门派习俗的来源保证。
