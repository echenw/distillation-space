# 成长路径不是固定升级次数

本文件替换旧参考规则，保留 R1–R12 规则身份；`F` 文学观察 / `H` 设计推导 / `P` 可选执行动作不同层。现代中国武侠/仙侠的专有门派与境界术语不在这26本英语经典中得到一手证实。

## R5｜REJECT：行为判断

- **旧规则裁决：REJECT**；废弃原来的强制结构或固定数量；保留有证据可用的操作。
- **F**：PG7477 L2011–2196：Sladden 花积蓄买神秘窗、望见无法抵达的中世纪城市，试图用物件干预攻城却砸碎窗，故事没有三次法术晋级。
- **H**：物件使用可以以一次不可逆失败结束；只有状态/目标/代价发生变化的关卡才值得单列。
- **P**：废止“三次升级”固定次数；按每次获得/失去能力改变目标、受限条件或盟友后果安排必要场景，重复无变化时合并。
- **如何分支**：输入有作者确认的能力制度→按其规则限制动作；只有角色相信的传说→先标未证；两个设定冲突→列冲突、停依赖部分、请作者选定；无正文只作可选提案。
- **反例**：自我克制或退步也属于成长弧。
- **验收**：从具体原文位置复核力量来源、使用成本、可知前兆、承认者、受波及者及结局变化；不得编造数值或实际读者效果。

## R6｜REVISE：行为判断

- **旧规则裁决：REVISE**；废弃原来的强制结构或固定数量；保留有证据可用的操作。
- **F**：PG2325 L365–434：海底车事故被描述后，国王召首相查询修复，首相承诺第二天再开，人物并未在现场确认线路已修好。
- **H**：新信息和承诺不等于能力/奖励到账；读者要看动作如何被后续实际状态支持。
- **P**：奖赏只有在之后确实可被使用时才需要作为工具链提前可见；学习、信任或信息本身也可能是一次关卡结果。
- **如何分支**：输入有作者确认的能力制度→按其规则限制动作；只有角色相信的传说→先标未证；两个设定冲突→列冲突、停依赖部分、请作者选定；无正文只作可选提案。
- **反例**：独立单篇童话不必所有奖励套娃。
- **验收**：从具体原文位置复核力量来源、使用成本、可知前兆、承认者、受波及者及结局变化；不得编造数值或实际读者效果。

## R9｜REJECT：行为判断

- **旧规则裁决：REJECT**；废弃原来的强制结构或固定数量；保留有证据可用的操作。
- **F**：PG57 L106–210：魔法师亲自送 Aladdin 到洞口并索要旧灯，直接行动由物件位置与对 Aladdin 的利用决定，而非某种“上阶强者不得出手”的制度。
- **H**：权威能否出场由风险、目标、物件位置和世界设定决定，不应凭作家硬定代理出手。
- **P**：废止“高层不能亲自出手”；根据权威的能力、距离、动机和风险决定代理或直接行动。
- **如何分支**：输入有作者确认的能力制度→按其规则限制动作；只有角色相信的传说→先标未证；两个设定冲突→列冲突、停依赖部分、请作者选定；无正文只作可选提案。
- **反例**：直面权力人物也可公平，只需说明为何他到场。
