# 反例与跨文化证据边界

本文件替换旧参考规则，保留 R1–R12 规则身份；`F` 文学观察 / `H` 设计推导 / `P` 可选执行动作不同层。现代中国武侠/仙侠的专有门派与境界术语不在这26本英语经典中得到一手证实。

## R12｜KEEP：行为判断

- **旧规则裁决：KEEP**；保留原核心用途，但条件必须可观察。
- **F**：PG8395 L995–1009：关于至高神苏醒后的世界，叙述多次说“也许”；PG6021 L7845–7960 则将温暖写成星光隐喻，没有明示现代可测的魔法机理。
- **H**：神话中未定结局与日常诗性隐喻是有意的叙事类型，不是必须由量化法力参数解决的错误。
- **P**：保留并扩大反例判断：不把可逆变化、隐喻魔法、无需付费的奖赏全定为缺陷，检查具体任务与因果。
- **如何分支**：输入有作者确认的能力制度→按其规则限制动作；只有角色相信的传说→先标未证；两个设定冲突→列冲突、停依赖部分、请作者选定；无正文只作可选提案。
- **反例**：奇观、幽默或寓言有自己的局部契约。
- **验收**：从具体原文位置复核力量来源、使用成本、可知前兆、承认者、受波及者及结局变化；不得编造数值或实际读者效果。

## 类型边界与旧反例重判

保留“道具成瘾式成长、零代价万能变身、隐喻写成物理魔法、财富奇迹不受约束”作为**诊断信号**，而非自动缺陷：
- 若用户写童话寓言，魔法可以是隐喻且无需可量化成本；不要无故引入硬核数值体系。
- 若用户写规则驱动幻想，明示异常机制、早有前兆、角色与读者可复核限制。
- 若只有英文原著，中文门派、灵根、境界、武学史具体命名 = NOT_PROVEN；应由作者现有正典或独立中文类型材料提供，不翻译造证。
- 不提供真实危险武术训练指导；本包只负责叙事。


## R13｜新增：角色真身与假身须靠可核证据而不是名号自动转让

- **F（小说）**：PG58874 L8010–8026 真 Tarzan 见假冒者与 Jane 在营火前，呼喊名字后对方仓皇离开；L8665–8668 真身指认另一人冒名，并重获金子。小说本身含旧时代种族刻板描绘。
- **H**：名号、长相相似、追随者宣称与制度认可不完全等价，识破需要被场景允许的证据。
- **P**：在模板登记“谁凭什么认为是谁、谁见过证据、谁能实际撤销身份凭证、错误承认造成什么代价”；禁止借刻板族群形象判断真伪。
- **反例**：无人冒名的纯个人成长无需身份鉴定支线；本案例不构成中文宗门传承的通则。

## R14｜新增：同一词“魔法”可能指真实机制或情感隐喻

- **F（小说）**：PG6021 L11762–11801 用零花钱与星光做诗性联系，L15564–15580 的感应证据仅为人物言论；PG57 L106–210 则明示戒指精灵实际出手救人。
- **H**：相似的神秘措辞可以属于不同世界契约。强制给隐喻一套修炼等级会破坏原故事，忽视客观施法限制也会伤害规则驱动幻想。
- **P**：明确 `AUTHOR_CANON_MAGIC` / `POV_BELIEF` / `METAPHOR` 三种状态；只有用户正典承认外部可执行法则时才设计能力限制/可见代价。
- **反例**：纯寓言魔法可以只作为诗性表达；真实技能训练不由英语神话推导。

## R15｜新增：翻译来的神谱/旧时代偏见不能当中国仙侠世界观来源

- **F（小说）**：PG8395 L80–89 的 Fate/Chance 置于自创神话宇宙；PG58874 L6284–6288 描写种族化称谓和团体征伐；这些属于具体英语作品语境。
- **H**：神话身份、种族描述与社会压迫是文学材料而非当代人群属性/中文仙侠通用制度。
- **P**：若作者选择中国武侠/仙侠，世界观中境界/道统/师门只从用户已有文本或独立相应类型样本建立；跨文化借鉴只提有条件技法并保留历史偏见风险。
- **反例**：明确创作欧洲神话风格时可以直接使用经作者选择的神谱，但不要求它等于道教体系。
