# 场景、概述与时间

返回 [SKILL.md](../SKILL.md)。

## 1. 三种叙述单位

- **场景**：把读者放进相对连续的时空，呈现行动、感知、对话或关系变化。适合承载需要读者亲自经历的压力和转折。
- **概述**：压缩一段时间、重复行动、背景变化或低强度过程；它有三种正职——蓄势、压缩、定语气（见 §2）。适合交代结果、节省篇幅、建立跨度。
- **过渡**：连接两个叙述单位，说明时间、地点、人物状态或信息条件发生了什么变化。

场景不是“有对白的段落”，概述也不是“没有对白的段落”。判断依据是读者需要经历过程，还是只需要知道过程及其结果。

## 2. 选择场景还是概述

优先使用场景：选择会改变目标、关系、承诺或处境；读者需要亲自感受信息差、风险、阻力或不确定性；关键行动的顺序、迟疑、误判或反应本身有意义。

优先使用概述：重复行动结果相近；主要变化已经发生；背景、路程和例行事务不需要逐步体验；场景会拖慢主线且没有新的关系、信息或因果变化。

如果概述掩盖关键选择，改回场景；如果场景只重复已知信息，压缩为概述。两者可以交替。

概述的三种正职（PV-13）：**蓄势**——兑现之前，用概述把已经备好的东西摆出来：谁来了、什么在逼近、日常起了什么变化，读者带着期待进入下一个场景；**压缩**——重复行动、路程、背景变化和低强度过程，只交代结果；**定语气**——用叙述者的概括口吻给一段生活或一个时代定调，供后面的场景对照或反衬。三种正职可以混用，一段概述最好有一个主职，功能不清时就容易既拖又空。不只凭“场景能不能做”来判断一段概述：把全书改成场景，时间压不动，背景也撑不起来。

## 3. 场景／概述配比的可选试算区间（非统计标准）

下表只是帮助比较方案的**可选起点**，不是统计结果、行业标准、质量门槛或合格区间。超出区间完全可能是正确选择；不得仅凭比例判定作品好坏。

| 作品倾向 | 场景占全文的可选试算范围 | 概述占比的对应范围 | 使用提醒 |
|---|---:|---:|---|
| 强情节、悬疑、连续行动 | 60–75% | 25–40% | 关键行动和误判需要被经历；重复过程仍可压缩 |
| 心理、认知与关系变化 | 40–55% | 45–60% | 给内在变化留空间，也要让重要选择落到行动 |
| 群像、家族或代际跨度 | 25–40% | 60–75% | 用概述建立跨度，把少数关系转折写成场景 |
| 散文体、回忆体或全书几乎无完整场景的作品 | 0–15% | 85–100% | 比例低不是缺陷；功能检查照常进行（§2），形式实验按它自己的约定检查 |
| 高度戏剧化的形式实验 | 90–100% | 0–10% | 只有在形式目标支持时才采用，不是更高级的比例 |

试算时先统一计量单位（字数、段落数或页面数，选一种即可），再估算当前稿和目标稿。不要把场景数量与场景篇幅混为一谈，也不要把表中范围当成写作前必须达到的指标。试算只用于提出问题：哪些过程值得展开，哪些可以压缩，比例变化是否服务作品承诺。

## 4. 核心兑现时刻清单（可选规划工具）

长篇或多线作品可以先列出 **3–5 个核心兑现时刻**作为起点；短篇可能只需要一个，群像或多线作品也可能需要更多。这个数量不是普遍上限，也不是统计标准。

| 兑现时刻 | 需要提前建立的事实／关系／规则 | 预计位置 | 当前是否已准备 | 主要功能 | 是否与其他功能竞争 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

逐项检查：读者是否获得理解该时刻所需的信息；人物是否有理由作出选择；时刻是否兑现前文承诺而非临时引入新规则；同一场景的多个功能是否互相争夺注意力；不需读者亲历的功能能否移出场景。

## 5. 场景经济：删减、合并与拆分

场景是否有效，不按它承担了多少功能计分。检查它是否改变目标、阻力、信息、关系、承诺、资源、风险或读者判断。

- **删减**：删掉后因果、人物选择和读者理解不受影响，也没有有意的节奏或氛围作用。
- **合并**：两个场景承担同一变化，合并后行动顺序、视角权限和情绪转折仍清楚。
- **拆分**：多个功能争夺注意力，或不同时间／地点／视角需要不同铺垫和收束。
- **改为概述**：过程重复、结果相近，读者只需知道变化已发生。

不要为了效率删除必要的停顿、犹豫或沉默；如果它们改变人物判断或关系，就属于有效内容。

## 6. 让时间跨度可见

时间跨度可由明确标记，也可由连续变化呈现：年龄、身体状态、工作熟练度、季节、作息、物件磨损或归属、称呼、关系距离、承诺履行情况和共同记忆。

“几个月后”“多年过去”可以准确定位时间；如果作品还需要读者感到时间重量，再补充一两个可验证的变化。不要用装饰性细节堆叠代替真实状态变化。

## 7. 叙述的时间距离（PV-15）

时间距离不是故事里过了多久（那是 §6 的跨度），而是讲述站的位置离故事有多远：谁在讲、站在故事进程中的哪一刻讲、讲的时候离事件有多近。

| 讲述位置 | 读者被置于 | 常见用法 |
|---|---|---|
| 当时的当下 | 事还没定，事后的走向不透露 | 紧贴场景的限知叙述 |
| 回顾 | 讲述者活过了（或知道）结局 | 回忆体、框架叙事，可以带事后判断 |
| 讲述的当下 | “讲这件事本身”成为作品的一部分 | 有契机、有听众的讲述 |

检查三件：

- **为什么现在讲**：回忆体要给讲述一个契机（一次重访、一份遗物、一个纪念日），并说明为什么拖到今天才讲；读者拿到“回忆体天然知道结局”的设定后，会追问“你早就知道为什么不说”，这个账要认。
- **瞒不瞒结局**：讲述者知道结局，要不要让读者也知道，从头定好；中途改变，就是信息结构的一次切换，按 [information-control.md](information-control.md) §2 记账。
- **距离变化要重新锚定**：第一人称和第三人称都可以在当时、回顾和讲述的当下之间换距离；换的时候给读者一个标记——段落收束、新的一章，或 PV-07 的距离锚点——不让读者认不出此刻谁在讲。

“后来她才知道”“那时她还不知道”是一次提前揭示：它把叙述站到了事后，又把一个结果提前递给读者。用它之前查 `scene-conflict-and-rhythm`；除非全篇已经明确站在事后（[narrator-and-viewpoint.md](narrator-and-viewpoint.md) §4.2 的例外），限知的当下场景里不要忽然冒出这一句。

与跨越时间的分工：跨多少年、日子怎么写，是 PV-14（§6）；讲的人站在哪一刻、离事件多远，是本节（PV-15）。两件事都做，岁月感和讲述的位置才都成立。

## 8. 时间结构与叙述世界

封闭结构通常让事件围绕少数因果链收束；开放结构可以容纳多条人物线、不同观察位置和未完全解决的矛盾。两者都是结构选择，不代表作品质量等级。

若读者需要追踪单一因果，明确事件顺序和关键转折；若读者需要比较多个观察位置，标出时间、人物和信息来源；若结尾保留开放问题，区分有意留下的余地与尚未补齐的因果。

世界的边界由主体决定（PV-17），不按题材定：**开放**给主线外的人和事少量具体的独立存在——他们有自己的日程和小目标，不必都汇入主线（给三处左右与主线无关的生活是一个起点，[diagnosis.md](diagnosis.md) §4）；**封闭**把边界变成压力——主线外的东西进不来，人物的退路随情节收窄，紧张感由世界的窄产生。两种都合法；边界是否合适，看它和主体的匹配，不看它铺开的世界有多大。世界薄、聚焦者的生活看不懂时，先查是不是封闭过度（[diagnosis.md](diagnosis.md) §2 的 S7）。

## 9. 修订回查

- 场景是否承担必须被经历的变化？
- 概述是否压缩重复过程，却保留关键因果？
- 时间跳跃前后，人物年龄、物件位置、关系和知识是否连续？
- 关键兑现时刻是否提前准备？
- 配比试算是否只作为比较工具，没有被误用为硬指标？
