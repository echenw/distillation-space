# 场景、概述与时间（PV-12 至 PV-15、PV-17）

返回 [SKILL.md](../SKILL.md)。

## 1. 四个词

- **场景**：选定一个时刻和地点，读者直接看、直接听；不压缩时间和空间。
- **概述（全景）**：从高处扫过一段时间或一片生活，必然压缩。
- **图画**：材料经过某个心灵的反映呈现给读者；读者面向讲述者。
- **戏剧**：材料自己演出来；读者面向故事。

这组词描述虚构作品的核心剪辑语法，区分现场展现与宏观概括，不要和电影术语直接等同。

## 2. 场景的限制和正职（PV-12）

场景的本质是充分展开：场景里不能随意压缩时间和空间，它展示它所占据的全部时间和空间。由此有三个后果：

1. **贵**：场景演得鲜明，但按长度算演得慢。
2. **建立和兑现的负担**：读者还缺理解结果所需的承重信息时，场景要一边建立一边兑现，力量容易分散。信息也可以由本场的行动和冲突建立，所以这不是禁止建立型的场景。
3. **有上限**：背景、时代、群体，没法全靠场景承载；纯戏剧化的小说极少，深厚的历史与阶层背景很难仅靠现场对白完全撑起。

场景的核心职责是：了结一件已经悬置的矛盾，正面展示一个关键结果，给此前铺垫的效果最终加冕。用场景兑现时，进场景之前：
- 冲突已经明确；
- 赌注已经立起来；
- 读者在等一个结果。

场景里让结果发生，并留下一个不可逆的细节。

场景是全书的关节。经典结构的骨架往往由几个重大场景串联：盛大舞会、公共集会、剧院之夜、大教堂的秘密会面、临终决裂，每一场完成一个心理阶段并打开下一个不可逆阶段。兑现型的场景放在“一切已经备好”的地方，位置比数量重要。建立信息、呈现体验或抒情的场景可以更早出现，按它们自己的功能判断。

## 3. 概述的三种正职（PV-13）

1. **蓄势**：巴尔扎克式的预备图画，为后面的戏剧储备人物、环境和时间。
2. **压缩**：跨年、跨地、群体的反应。
3. **定语气**：全景本身可以是一种看法。全景概括可以将人物命运、社会变迁和环境背景融在一片从容宽广的回顾视野中。

判断：比较概述和场景在这里各自提供的压缩、距离、声音、反思和细节。同一材料也能写成场景时，概述仍然可以因为语调或结构而保留；只有它和目标不符、无益地重复或损坏因果时，才删掉或改成场景。

戏剧的经济原则：现场戏剧化呈现是创作的高光，在不需要的地方盲目挥霍对白与动作，反而会削弱核心决战的力量。做法：
1. 列出全书必须兑现的少数时刻（中篇三五处，长篇按卷或单元各列几处）。
2. 其余时刻按叙述距离、压缩的需要和要的体验，在场景、概述、对话摘要、侧写之间选，不因为它不是高潮就一律概述。
3. 一个场景可以兼有建立世界、呈现体验、解决冲突几种功能；功能互相争夺、使要的效果不清楚时，再分主次或拆场。

不同主体的倾向（方向，不是比例）：

| 主体 | 场景 | 概述 |
|---|---|---|
| 强情节、悬疑 | 承担大部分篇幅，负责兑现 | 过渡、时间，也可以整理线索、承载推断和反思 |
| 心理和认知变化 | 兑现转折 | 承载时间和反思 |
| 群像、世代 | 做关节 | 全景为主 |
| 纯戏剧的实验 | 几乎全部 | 极少；背景要靠所选的场景自己承载 |

## 4. 跨越时间（PV-14）

表现时间的形式：时间感不能靠干瘪空洞的宣告（如一排星号加一句“几年过去了”），而要通过物质与关系的沉淀体现出来。

两种时间效果：
- **流逝**：日子一天天过去，人在变。靠日常质地、重复、物件磨损、身体变化承载。
- **周期**：一代人兴起、衰老、让位。靠结构承载（开场和终场的对照）。宏大的时代流逝感如果缺乏清晰的结构闭环，容易变成散漫的生活长河，而缺少强有力的周期形式。

做法：
1. **建质地**：跨越之前，写一段“日子怎么过”的具体生活：房间、作息、季节、重复的动作。
2. **给锚点**：一个以后能回收的物件、习惯或身体细节。
3. **跨越**：可以只用一句（“五年就这样过去了”），也可以用概述、并置或前后场的对照。
4. **给变化**：给一个具体的细节，证明时间真的过去了：同一个物件磨旧了，同一个动作慢了。不一定紧挨着跨越的那一句。

在小说中，必须先用扎实的篇幅建立起特定家庭或机构固若金汤的单调日常，之后的“五年就这样过去了”才能在读者心中激起沉重的回响；缺乏前面的质地，时间跨度就只是一句无力的宣告。

检查：需要读者体验岁月的积累时，读者能不能说出“这段时间她是怎么过的”。只要标定新的时间位置时，直接写“五年过去”也能完成任务，不判失败。

## 5. 叙述的时间距离（PV-15）

- **第一人称回忆**：Lubbock 认为视点固定，时间也被回忆的距离固定。实际上第一人称同样可以在经历的当时、回顾和讲述的当下之间改变距离，也能压缩时间、重排叙述。叙述者已经知道结局时，可以交代为什么现在讲、讲的时候瞒不瞒结局；没有设具体的讲述场合，不必硬加解释。
- **第三人称限知**：视点固定在人物身上，但在时间上是自由的。可以写“当时”，也可以写“多年以后她才明白”。
- **书信和日记**：采用即时书信或日记体叙述时，将叙述时刻停在正在发生的事态当下，读者和人物一样不知道明天，极大增强悬疑紧迫感。

用法：
- 要拉开距离，用“后来她才明白”“多年以后”之类的标记，每个标记都要带具体内容。
- 要压强，把叙述压到当下，删掉没有作用的事后预告；有意的反讽、宿命感或双重时间，可以保留“后来”。
- “后来她才知道……”是一次提前揭示，会消耗悬念。用前先确认这个信息提前给出是有意的（见 `scene-conflict-and-rhythm`）。

## 6. 世界的边界（PV-17）

Lubbock：这完全取决于故事本身的性质。

- **开放**（托尔斯泰）：人物活在“我们的世界”里，主线之外的生活在继续。
- **封闭**（陀思妥耶夫斯基）：黑暗切断了外面，光全部打在意识的剧场上。

做法：
1. 主体需要连续性还是压强？
2. 开放：给少量与主线无关但真实的生活细节，起点是三处左右，不要多到稀释主线。
3. 封闭：把边界变成压力（谁进不来、什么出不去），而不是只是不写外面。

开放的世界放在悬疑、密室、心理压强类故事里可能泄气，也可能加强外部的威胁；封闭的空间也能承载世代或时代。按本作的主旨和效果判断，不按题材的名称判失败。

## 7. 时间跨度速查

| 跨度 | 主要工具 | 风险 |
|---|---|---|
| 几天 | 场景为主，少量概述 | 场景太密会拖 |
| 几个月 | 场景加季节过渡 | 天气过渡没有变化作用时会陈套；季节本身也能承载生活的质地 |
| 几年 | 质地图画加一句跨越 | 直接跳年可以清楚地推进；需要岁月感时另补质地 |
| 几代 | 周期结构（开场和终场对照）加代际视点 | 中段容易散；贯穿的物件、地点或别的结构联系都可以选 |

## 8. 自检

- 每个场景都标得出功能；拖慢效果的铺垫已经压成概述或并入别的场景。
- 高潮解决所依赖的承重信息，前文已经准备；高潮里新出现的只是不承重的信息。
- 需要岁月感的跨越点，有质地锚和变化锚。
- 用“某年过去”直接开新章时，确认这里只需要标定时间，或者前文已经写了日子。
- 时间跨度和场景密度匹配：大跨度可以借概述、并置或省略处理，不要求概述的比例一味增加。
- 世界边界和主体一致：开放不稀释，封闭不虚假。
