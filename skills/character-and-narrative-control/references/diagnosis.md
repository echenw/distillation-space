# 诊断、修改单与例外

返回 [SKILL.md](../SKILL.md)。来源行号见 [source-index.md](source-index.md)。

## 1. 诊断顺序

1. **范围**：读了哪些章节，没读哪些。只对读过的部分下结论。
2. **主体**（PV-01）：问题真的出在全书的关注点和叙述方式不匹配时，先澄清主体，不反复换人称。已经定位到一处视角、权限或声音的问题时，直接修，不把全书主体定稿当成一切改稿的前提。
3. **视点**（PV-02、PV-03）：谁在看？凭什么知道？读者知道此刻谁在看吗？
4. **合同**（PV-04、PV-05）：有没有越界？切换有没有收益和标记？
5. **信息**（PV-09 至 PV-11）：每一幕人物和读者各知道什么？揭示公平吗？
6. **场景与概述**（PV-12、PV-13）：场景在铺垫还是在兑现？概述在做场景做不了的事吗？
7. **时间**（PV-14、PV-15）：跨越前写了日子吗？
8. **世界边界**（PV-17）：和主体匹配吗？

只有构思、没有稿子时，不做“第几段有问题”的诊断，改做设计（SKILL.md §3 的选视角路径），并说明哪些判断要等有了稿子才能确认。

## 2. 十种症状

**S1 读者不知道谁在看**
- 原因：叙述权限不清；章内视角漂移；段首没有感知锚。
- 改法：写出叙述者的位置（PV-04）；固定一个聚焦者；在段首给感知锚（“她听见……”）。

**S2 切换很晕**
- 原因：切换不买回东西；切得太频繁；切在场景中间。
- 改法：每次切换写触发和收益，删掉纯交代性的切换，切换放到断点（PV-05）。

**S3 主角内心很平**
- 原因：用报告代替了需要的演出；判断的过程没有出现。
- 改法：需要读者看见判断过程的地方，把“她感到”改成可见的判断过程（PV-08）；重心在叙述者自身的变化时，可以比较第三人称限知的效果（PV-03），第一人称也可以自我剖析。

**S4 反转不成立，读者觉得被耍**
- 原因：双盲的惊奇没有线索；叙述者进了心却装不知道；前文没有公平线索。
- 改法：换不知情的叙述者，或补选择性讲述、自欺、不可靠的证据（PV-09、PV-10）；作品承诺公平解谜时，前文放一两处可回看的线索；揭示后让一两处旧场景改变意义（information-control §7）。

**S5 中段拖**
- 原因：场景在做铺垫；概述没有信息；时间靠宣告。
- 改法：每个场景标功能，拖慢效果的铺垫压成概述；需要岁月感的跨越前补质地（PV-12、PV-14）。

**S6 高潮没劲**
- 原因：高潮同时在建立和解决；需要的视点或信息没提前就位；前面把戏剧用光了。
- 改法：把高潮依赖的承重信息提前准备（PV-16）；删掉中段无益的场景，把最重的场景留给高潮（PV-13）。

**S7 世界很薄**
- 原因：封闭过度；聚焦者看不懂世界又没补光。
- 改法：开放型给少量主线外的生活；或补光、加第二视点（PV-17、PV-06）。

**S8 人物变老像换人**
- 原因：时间只有宣告，没有质地；变化没有锚点。
- 改法：跨越前写日常循环；跨越后用同一个物件或动作的变化证明时间（PV-14）。

**S9 结尾收不住**
- 原因：叙述者的位置悬在书外；结尾引入新信息。
- 改法：结尾需要的视点和信息提前就位（PV-16）；让结尾回到书内的某个眼睛（PV-04）。

**S10 全书像大纲**
- 原因：全是概述，没有兑现的场景；场景没有“已经备好的势”。
- 改法：选出几个必须兑现的时刻，写成完整场景；其余概述加判断和意象（PV-12、PV-13）。

## 3. 修改单示例

| 位置 | 症状 | 原因 | 规则 | 改法 | 代价 |
|---|---|---|---|---|---|
| 第 4 章第 3 段 | 越界：写了“他不知道她早已原谅” | 女主视点里写男主内心 | PV-04 | 改为女主看见的征候：“他把她的杯子洗干净，放回了原处” | 原句的确定性没了，读者要自己判断 |
| 第 7 章 | 切到反派只为交代“他派了人去码头” | 切换没有别的收益 | PV-05 | 改为主角在码头看见反派的手下 | 主角要提前出现在码头，需要一个理由 |
| 第 12 章开头 | “三年后”直接开章，人物像换了人 | 跨越前没有日子 | PV-14 | 第 11 章末补一段铺子里的日常，第 12 章首写同一把算盘磨亮了 | 第 11 章变长 |

“代价”一栏必须写。

## 4. 只能做一件事时

| 想要 | 做什么 |
|---|---|
| 让读者进入 | 固定一个聚焦者，删掉章内漂移 |
| 让读者紧张 | 让读者知道得比人物多（读者在前） |
| 让读者好奇 | 让读者知道得比人物少，但线索公平 |
| 让读者震惊 | 双盲加可回看的线索（风险最高） |
| 让读者感到时间过去 | 先写日子，再写“五年后” |
| 让高潮有力 | 高潮前把钥匙准备好，比如放在明处、当时看起来像杂物 |
| 让世界可信 | 给三处左右与主线无关的生活 |

## 5. 规则的例外

这些例外来自来源本身，用来防止把默认值当成禁令。

| 默认 | 例外 | 处理 |
|---|---|---|
| 少用无名全知（PV-04） | Lubbock 承认萨克雷的魅力能让读者忘掉缺陷，也承认天才可以随心所欲 | 按叙述权限、声音和主体的需要选全知或限知，不要求全知先证明自己是例外；“书不自足、重读变薄”是 Lubbock 的评价 |
| 少换视点（PV-05） | Lubbock 称赞《安娜·卡列尼娜》几乎人人都是视点中心；Forster 认为《荒凉山庄》《战争与和平》频繁切换也成立 | 多视角本身不是错误；检查每次切换的信息、距离、声音或复调作用，以及读者重新定向的成本 |
| 不用“几年过去了”（PV-14） | 巴尔扎克用“五年就这样过去了”成功 | 需要岁月感时，关键在前面的质地；只需定位时，这句话本身就够，不是禁用句 |
| 第一人称难以剖析自己（PV-03） | 自我暴露是主题时（《巴里·林登》），局限就是效果 | Lubbock 的偏好，不是禁令；第一人称可以自我剖析。他对《简·爱》的批评（看不出用第一人称的理由和效果）也只是他的看法 |
| 戏剧化是最高的方法 | Lubbock 自己承认《尴尬年代》这样的纯戏剧之作极少，纯戏剧难以承载背景 | 本 skill 不采纳“越戏剧化越好”的进步论 |
| 叙述者不现身 | 1926 年的选本里仍有第一人称叙述者公开对读者说话（“我把他们谈话的要点告诉你”） | 允许，但要说清叙述者的位置和可靠性 |

## 6. 作者坚持时

| 情形 | 处理 |
|---|---|
| 要写全知插话、元叙事、说书体 | 不纠正趣味。可以说明 Lubbock 担心的代价（视点悬在书外、重读变薄），给替代（人格化的叙述者、框架、说书人身份写进书里），由作者决定 |
| 写的是快节奏类型 | 侧写（PV-11）和时间铺垫（PV-14）妨碍本段要的速度或清晰度时，缩短、移位或改用直述；它们正承担悬念或情感作用时保留，不按“快节奏”的标签自动删 |
| 写的是群像或史诗 | PV-02、PV-05 的多中心条款优先，但每一章仍要有明确的聚焦者 |
| “受限”或“不可靠”就是主题 | 不补光（PV-06），改用反讽距离（PV-07）和不可靠叙述的证据（PV-10） |
| 规则和作者的直觉冲突 | 回到主体（PV-01）。规则是诊断工具，不是法令 |
| 证据不够 | 写明“无法判断”和缺什么（缺哪几章、缺作者的结局设想），不要猜 |

## 7. 误用本 skill

| 误用 | 后果 | 纠正 |
|---|---|---|
| 为凑一句主体砍掉复调 | 合法的多主体结构被压扁，人物变成主题的传声筒 | 复调、多主体或还在探索时，用几句话或一张关系图说清关注点；不因为暂时说不出主体就删线（PV-01） |
| 视角洁癖：每章只许一个视角，越界一律删 | 世界变薄，作者被迫用生硬的对话塞信息 | 补光和第二视点是合法的（PV-06） |
| 场景崇拜：把概述全改成场景 | 时间压不动，背景撑不起，节奏拖 | 按这一处的功能选场景、概述或混合（PV-12、PV-13）；全场景的实验按它自己的约定检查 |
| 反转靠藏 | 隐去叙述者已知的关键事实，违背了本作已经建立的可靠性或公平承诺 | 调整披露时机、关上意识、给出选择性讲述或不可靠的理由，或者换不知情的叙述者（PV-09） |
| 侧写过度 | 侧影一直重复同一种作用，要的理解或情感变化迟迟不来 | 删重、换侧影、提前点明或继续留白；“两三个侧影后点破”是一种对照方案（PV-11） |
| 把第三人称限知当高级 | 所有书往一个模子改，作者的声音被抹平 | 方法由主体决定（PV-01） |
| 把本 skill 当研究结论 | “研究证明第三人称限知最好”是伪共识 | 视角规则是 1901–1927 年手艺书的经验，心理和时间的卡来自小说个案；都不是实验结论 |
| 忽略类型契约 | 具体的手法压过了作品已经明确的速度、揭示或理解要求 | 本作的实际契约优先（SKILL.md §7）；不只凭类型标签预测弃读 |
| 诊断跳步 | 问题出在全书的关注点，却只反复换人称；或者为一处已经定位的视角问题，硬要先重定全书主体 | 按 §1 定本次的范围：整体的方法选择先澄清主体，局部的权限、定位、声音问题直接修 |

## 8. 不在本 skill 里诊断

- 作者还在决定全书的主体：先做 PV-01，不做全书的视角手术；局部的问题照常修。
- 问题其实是情节因果断裂：转 `story-architecture-and-longform-planning`。人物心理和动机的呈现，用本 skill 的 PS 卡（§9）。
- 问题其实是句子和语感：转 `line-editing-and-proofreading`。
- 伏笔和节奏的问题：转 `scene-conflict-and-rhythm`。
- 现实中的病名、诊断、疗法：不在本 skill 里做（[boundaries-and-ethics.md](boundaries-and-ethics.md) §1）。

## 9. 心理与时间的症状

先查本 skill 管的那一层，再按“先查”一栏回到对应的卡。改法是起点，不是唯一的修法。

| 症状 | 先查 | 改法 |
|---|---|---|
| 动机说不清，或者几个理由互相打架 | 每个说法的时点、听众、外证（PS-06） | 分版本记账，不急着抹平矛盾；矛盾本来就是人物的一部分时保留 |
| 证词各说各的，读者不知道信谁 | 知识表上“谁说、何时说、对谁说、外证与反证”四列（[testimony-and-self-justification.md](testimony-and-self-justification.md) 开头） | 补外证或反证；要读者公平地评价，就把后果和疑点放在前面（PS-03） |
| 情绪转得太突然 | 有没有看得见的触点，或者已经交代的新信息（PS-12） | 补一个触点，或者确认作者有意不解释 |
| 心理全靠独白，读者无感 | 身体感觉是否绑在视角和行动上（PS-10、PS-14） | 换成看得见的动作和身体感觉，必要的独白保留 |
| 每次恐惧都是冷汗加手抖 | 动作有没有区分力（PS-10） | 换成本场特有的动作或选择 |
| 沉默被写成性格 | 社会关系表上的成因（PS-18、PS-23） | 补成因，或者标“未知” |
| 贫困或疾病解释了一切 | 资源和关系的限制、反证（PS-19、PS-24） | 分开社会处境和心理推断 |
| 群体的恐惧来得太快 | 猜疑链少了哪几环（PS-22） | 补看见、听说、类比、梦、行动 |
| 丧失只靠一次告白或宣泄 | 有没有日常的小事承载（PS-28） | 加一件有规则、有终点的小事；或者确认告白就是本场的核心 |
| 转变像一夜治愈 | 行动、判断、后续有没有分开（PS-30） | 分开三层，留出代价 |
| 梦被当成诊断 | 梦前的触发和醒后的选择（PS-15） | 只写看得见的衔接 |
| 时间跳转和倒叙混在一起 | 世界时间和展示顺序两列（nonlinear-time §2） | 给展示顺序加标签，或者给一个稳定的叙述锚 |
| 闭环自相矛盾 | 改动前后的状态（nonlinear-time §3） | 改成同一个闭环，或者注明有意不可解 |
| 揭底不公平 | 读者已知一列，揭底前有没有可回查的痕迹（nonlinear-time §3） | 提前放一处信息，或者不再自称读者能推断 |
| 两条时间线认不出 | 每条线的识别信号（TM-06） | 用年份、物件、动作的承接，或者开场句的回声 |

改完之后回看三件事：
1. 知识表里没有哪一栏因此前后矛盾：谁在什么时候知道什么，仍然对得上。
2. 原来成立的人物矛盾、留白和有意的不可解，没有被顺手抹平。
3. 没有在文本之外引入病名、疗效或现实的因果判断（boundaries-and-ethics §3）。
