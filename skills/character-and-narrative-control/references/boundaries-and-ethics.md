# 人物心理的边界与伦理

返回 [SKILL.md](../SKILL.md)。视角规则自己的例外、作者坚持时怎么办、误用的后果，在 [diagnosis.md](diagnosis.md) §5 至 §7，这里不重复。

本 skill 用于文学人物和叙述的设计。现实中的医疗、科学、司法判断，不从文学案例里推出来。用户提出创作或改写的请求，就已经授权了这个范围内的工作，普通的、可以撤回的选择不再反复确认。

---

## 1. 范围

**可以写**：私密的体验、创伤之后关系的变化、悲伤、孤立、身份和社会的压力、冒险和成瘾行为的叙述、不可靠的见证、意象和意识流的片段。这些是文学的题材，不是病历上的诊断类别。可以写痛苦和恢复，也可以写长期的状态、有意的关系分离、继续生活、始终没有解释的自我。

**不在本 skill 里做**，要退出或另找来源：
- 真实个人的精神状态、诊断标准、病因、药物、治疗方案或危机分级：本 skill 没有专业资格，也没有现代医学的证据。
- 真实刑事案件里证言可不可靠的法医学判断：不拿小说去推断真实证人的可信度。
- 把临床疾病浪漫化成“艺术天才的代价”，把自伤或暴力写成浪漫的试炼，把弱势群体写成注定失常。
- 把殖民、种族、阶级或性别歧视的话语当成现代中立的旁白；历史原文里出现时，写明叙述者和权力的语境。

## 2. 四个争议

### 2.1 意识流，还是物件和传统叙述

空房间的物态描画与受困人物的私密意识流承担完全不同的任务：前者是叙述者从外部白描一个人的缺席与遗留物，后者是人物在现场试图解释自己受到扭曲的感知（PS-25、PS-27）。两者不能混为一谈，更不能统称为通用的“精神崩溃句法”。

**怎么做**：先定谁有感知的权限，再选外景还是内语；可以只用一小段意识流，也可以完全不用。章节的清楚和人物的体验冲突时，由作者定叙述距离（PV-07），不套机械的句长。

### 2.2 环境决定，还是人物自己选择

荒漠极端生存场景中的本能厮杀、阶层声誉与经济花费的苛刻约束、幻想题材中的异质象征，各自属于不同的戏剧机制。用“环境所迫”推导不出人物的每一次微观动作；反过来，断言“纯属个人道德责任”也会抹杀社会结构的系统性压迫。

**怎么做**：分别列出条件、谁控制它、人物怎样解释、他有过哪些选择、实际的后果（PS-20）。允许因果判断不了，不编造现代的统计规律。

### 2.3 帝国、种族与文化：叙述归谁

在历史与经典文学中，受奴役者曾被叙述语言贬损为“罪犯”或非人化的符号，带有鲜明的时代偏见与殖民意识。在创作与分析中，可以深入解构叙述偏见如何误导受众，但决不能不加反思地复制贬损性称谓、将其当作中立事实呈现，或将压迫与歧视进行浪漫化包装。

**怎么做**：标出话是谁说的、影响了谁、有什么反面的材料、人物有没有反驳的空间；遇到有害的原话，优先转述语境，不大段照抄。缺少相关文化的资料时，写明结论有限，不假定已经代表了那个群体。

### 2.4 历史上的病理说法，还是当代的诊断

古典小说前言中作者提出的生理刺激假说、早期医学从业者对文学角色的非专业评注、以及科幻设定中的假想记忆装置，属于完全不同的认知范畴。小说里的修辞性描写、叙事所需的病理假设与严谨的科学实证，是三个截然不同的层次，创作与批注中不可混同。

**怎么做**：这些材料只用来看“文学怎样写当年的病理想象”，不用来给真实的人贴标签，也不用来建议临床干预；需要现实依据时，用有资格的现代临床来源。

## 3. 创伤题材的伦理表

这是一套文学写作与叙事手艺的约定，不承担识别现实病症的功能。文学作品中对紧张、颤抖、失焦的描写，都只是小说人物的戏剧动作和叙述者的语言修辞，严禁用来对现实人物推断病名、评估风险或开具处方。

| 场景里的信号 | 可以做的创作处理 | 不支持的推论 | 出口 |
|---|---|---|---|
| 颤抖、沉默、退缩 | 写发生了什么、谁看见、对行动有什么影响（PS-12、PS-14、PS-23） | 创伤后应激、人格障碍、某种特定的病 | 没有原因时标“未知” |
| 沉默、不反抗 | 已经建立了压迫关系时，写看得见的成因：谁长期压制、谁在场、她付出过什么代价（PS-23） | “她本性顺从”“她其实愿意”“她内心平静” | 成因不明就标未知，不写性格结论 |
| 梦或旧事的联想 | 回看梦前的刺激和醒后的选择（PS-15） | 梦是创伤的诊断依据 | 象征叙事不必解码；梦不必然推动情节 |
| 用受罚来自辩 | 对照人物嘴上的说法和后果（PS-06、PS-29） | 痛苦必然带来救赎 | 不浪漫化自伤，保留拒绝和解的分支 |
| 旁人的关怀或原谅 | 写行为的选择、边界和长期的悬而未决（PS-30） | 爱情自动治愈；受害者必须原谅 | 允许拒绝和解；转变不等于悔改 |
| 受威胁或被暴力胁迫 | 分清谁有权力、谁加害、谁受害、还有什么可选的行动（PS-16） | 被迫的人也必须担责 | 写明外部的控制 |
| 人物自称“疯了” | 准确记下谁、什么时候、对谁说、想用它达到什么（PS-14） | 现实的医学诊断或病名 | 限定为人物或时代的说法 |
| 高度危险的行为（自杀、自毁） | 只写人物怎样美化和安排自己，并写出代价和没完成的事（PS-29、PS-30） | 把死亡或自毁渲染成美的完成 | 不提供方法细节，不写疗效或解脱的承诺 |

## 4. 十二个反例

前八条是为说明而提炼的情形；第 9 至 11 条是极端危机场景下的典型行为链条；第 12 条是从高强度心理对抗机制中归纳出来的创作补充范式。

1. 侦探细看帽子，可能是在职业取证：观察细节不一定是焦虑（PS-13）。
2. 一段梦只服务于荒诞的艺术：不必预示事件，也不必带来疗愈（PS-15）。
3. 沉默也可能来自疲劳、隐私或自我保护：不能凭沉默诊断创伤（PS-23）。
4. 新消息足以解释人物从哭到笑：不必硬加复杂的心理独白（PS-12）。
5. 接受帮助，不等于有义务原谅伤害自己的人：关系可以是转变的触点，但不能写成治愈的保证（PS-30）。
6. 可靠的叙述者不必全程不可信：不照搬一部书的自我辩护策略（PS-06）。
7. 手发抖，可能是冷、累或受了伤：不是解离或神经疾病的诊断（PS-14）。
8. 被胁迫的人没有真实的选择：不把受害者的行为道德化（PS-16）。
9. 她没有反抗，不等于她愿意：可能是长期受压制留下的反应；写成“她本性顺从”就错了（PS-23）。
10. 人物开始改变，不等于他已经悔罪：书里明写他没有为罪行悔改，仍保留着理论上的自我辩护（PS-30）。
11. 犯罪之后不一定走向自首和受难：同一部书里，另一个人物以自杀收场；“自首、受难、被爱更新”不是唯一的结构（PS-15、PS-29、PS-30）。
12. 对峙戏不一定要靠铁证：心理画像和能被反过来利用的解释，同样能驱动张力；把假认罪只归因为“心虚”是简化（PS-07）。

碰上反例时，先撤回对应的假设，写明要补什么证据、要作者定什么；不强行让所有题材都去生硬套用同一种极端心理对抗的叙事模式。

## 5. 结论的可信度

交付的判断，按下面五档说清：

| 档 | 意思 |
|---|---|
| 作品里写了 | 能在原文里定位，给出作品和位置 |
| 推断 | 从作品归纳的看法，不等于作者本人这样说，也不是经验规律 |
| 设计方案 | 给用户试用，可以不选 |
| 证据不够 | 来源或效果没有确认；写明缺什么，不下确定的结论 |
| 超出范围 | 临床、法律、现实病因，或授权不够；说明缺哪种专业来源或用户设定 |

小说里的观察只在文学层面有效，不能升级为医学上的“症状证据”。
