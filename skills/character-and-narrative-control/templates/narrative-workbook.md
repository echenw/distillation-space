# 人物与叙事工作簿

按任务填写，未知留空并注明；不是每次输出都要展示全部字段。字段别名允许共用同一记录，不重复建相互冲突的时间表。

## K0：统一信息与经历表（同一问题只维护这一份）

| 事件 ID | 世界/真实发生 T | 人物经历与记忆 M | 角色此时可知及来源 | 叙述者可知与选择披露 | 展示位置 O | 读者已知 K | 自述/旁人解释 | 外证、反证与未决 |
|---|---|---|---|---|---|---|---|---|
| E01 | | | | | | | | |

这张表合并 C03-R7、B10 RT-02/04/05/07/12 与 C-05 的共同记账动作；各规则下仍保留各自触发条件。外层转述、亲见与同源转述不能算三个独立证人。自述分当时与事后，并记听众和目的；角色遗忘只改变 M，作者倒序只改变 O，世界穿越才会改变 T。K 是读者在此处已获得的信息，不等同作者自己的完整设定。

揭示可以只改变角色、只改变读者，或同时改变两者；故意保留秘密不等于错误。只有作品承诺读者可以预先推理，才要求决定性痕迹可回查。人物视角可阶段性封闭，第一人称也可可靠、撒谎、选择叙述或自欺；采用哪种方式要与叙述契约一致。

## B-10 字段

# PT-01–PT-14 · 文学角色心理表现设计器

本模板中的“创伤/病理”等词只用于作者的**题材标签**，不用于诊断；未给资料的字段写 `UNKNOWN`，不自动给角色安排悲惨经历。完成每项时先列文本事实 F，再列编写者解释 H，最后列候选写法 P。

| ID | 作者应填写的问题 | 失败检查 |
|---|---|---|
| PT-01 题材焦点 | 角色具体面对的事件/压力、其自身称呼、作者要讨论的主题；时代/世界设定 | 是否用“有精神疾病”代替事件？若是退回事实 |
| PT-02 叙述位置 | 第一人称/第三人称/多层框架；当时和事后的认知差 | 角色能否真实知道该细节？ |
| PT-03 身体与物件 | 实际可见的环境/物件/感受、首次出现位置及后续变化 | 物件不在场却在下一场成为证据？ |
| PT-04 资源和社会条件 | 谁掌握住房、工作、钱、家庭或医疗/其他组织决策，拒绝何代价 | 是否将阶层/贫困误标疾病？ |
| PT-05 事件链 | 哪个事件引起新的选择或认知，而不是凭刻板“触发器” | 是否编造从未发生的创伤史？ |
| PT-06 语言组织 | 当事人平时怎样说话；受压场景语言为何有变化 | 是否规定精神困扰按本任务需要碎句、口吃、疯笑？ |
| PT-07 拒绝和主体性 | 人物能拒绝什么、能求助谁、希望保留什么隐私 | 沉默是否被无证据解释为不合作病理？ |
| PT-08 时间线（共用K0） | 事件真实顺序、人物知道顺序、读者得到顺序 | 是否把结尾首次出现证据当已前置？ |
| PT-09 结局 | 能承担的后果、可修复的关系、可以不修复的限制 | 是否强制“痊愈/毁灭/归零”四选一？ |
| PT-10 证词层 | 谁亲见、谁转述、谁有利益、谁被排除发言 | 是否将视角意见写为全知事实？ |
| PT-11 不可靠因素 | 缺信息/利益自护/记忆差别/外部强迫；与病理假设分离 | 是否默认不可靠=患病或说谎？ |
| PT-12 身体行动 | 感知之后角色采取的动作与他人回应 | 是否只堆砌身体症状而无关系变化？ |
| PT-13 呈现伦理 | 谁拥有自己经历的解释权、社会/文化词语是否归因 | 是否浪漫化痛苦、污名化群体？ |
| PT-14 缺料出口 | 哪条 F 不存在、需要原稿/设定/专业资料/授权哪一项 | 是否虚构 PG、临床机制或出版许可？ |

## B-10 字段（续）

# PD-01–PD-10 · 既有稿件静态诊断（文学审稿，不是医疗诊断）

| ID | 核查项目 | PASS 条件 | FAIL / NOT_PROVEN 的处理 |
|---|---|---|---|
| PD-01 | 哪个真实事件正在影响角色？ | 原稿中有位置和具体行为 F | 无原稿写 NOT_PROVEN，不编事件或病名 |
| PD-02 | 叙事视角/知道时点是否成立？ | 每个视角能得到信息，延迟有理由 | 列超知情句、回填最早可知场景 |
| PD-03 | 物件/场景是否连续？ | 重现时地点、所有权、颜色与关系有意义 | 只补确定必要的物理桥段 |
| PD-04 | 句法/重复是否服务压力？ | 有特定人物习惯和场合变化 | 不以短句判“崩溃”，减少浮夸表现 |
| PD-05 | 叙述者偏见与真实性是否分开？ | 人物愿望/社会流言与可验证事实分栏 | 不把“不可靠”作为精神病诊断 |
| PD-06 | 疾病/创伤词是否超出文学证据？ | 只呈现经验或有独立可信专业资料支持 | 删除确定性病名，保留场景现象 |
| PD-07 | 社会性/殖民/性别权力是否被归因？ | 被害者能动性和发言主体明确 | 不复制无框架羞辱/去人化词汇 |
| PD-08 | 意识流/非线性是否仍可读？ | 读者可定位视角、时序，或作者明确选择非可解路径 | 按用户目标选择不大幅扭曲文本的局部整理 |
| PD-09 | 结局是否兑现应有责任与选择？ | 后果可见，关系不被强迫恢复 | 给替代结局，不以恢复作为唯一成功 |
| PD-10 | 修订的 F/H/P 与回归 | 每条建议有原文行/场景、预期变化和副作用 | 缺来源标 NOT_PROVEN，未授权只给候选 |

**结论口径**：`STATIC_PASS / STATIC_REVISE / NOT_PROVEN / OUT_OF_SCOPE`。此表只审稿，不给现实患者临床评价。检查范围须包括确实看过的正文/提纲，别把未看过的章节称“无问题”。
