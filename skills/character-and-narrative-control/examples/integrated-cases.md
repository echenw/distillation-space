# 人物与叙事综合案例

以下输入与改写均为 DESIGN_EXAMPLE，不是实际作者成稿或独立宿主评测。`F-INPUT` 只记录该合成输入已给的信息；`F-SOURCE` 指有 PG 行位的原著观察；新增故事条件标为 `DESIGN`，解释为 H，操作为 P。不能用新增设定反过来证明对输入的诊断。

## 案例组一（叙述视角与信息控制）

# 合成案例演练（非真实任务）

**声明**：以下案例用于演示条件化用法，不构成效果验证。案例内所谓读者反馈也是合成输入的一部分，效果未经真实读者验证。

## 案例 A：三代盐场家族史（群像/世代）

**输入（合成）**：作者计划写 1940–2010 年三代人经营盐场的故事，初稿每章换一个视角，作者转述读者反馈“不知道在跟谁”。

**依据与待查问题**：
1. F-INPUT：题材、年代范围、逐章换视角及反馈已给；未给全稿、视角总数或各线篇幅，不能断言存在八个平均视角、没有切换理由或没有主线外生活。
2. P：可用“一个盐场家族三代人如何被同一片滩涂改变”澄清家族与地方的关系，也可保留多主体。它是本例提出的主体句，不冒称作者已写过。
3. H：跟随困难可能来自人物定位、时序标记、线索承接或视角功能不清。拿到对应章节后查实际断点，不把逐章换眼本身判为失败（R3）。
4. H：若跨年只有“转眼到了 1978 年”，先判断它是否只需定位；若还要体验盐场生活的积累，再检查缺少什么时间质地。开放世界是否不足，也须结合实际片段判断（R10/R12）。

**可执行设计（均为新增 P/DESIGN）**：
- 若保留群像，先补足必要的人物、年份或关系承接，并保留各视角的独立声音与作用。若用户希望增强主聚焦，可试第三代最小女儿作“家族见证者”：50% 章节是一套可比较的篇幅预算，不是门槛；其余视角可承担她无法到达的信息，也可承担对照、复调或独立体验。1940 年等她未亲历的事，须经档案、转述或另设合法叙述权限，不能让她亲见全部年代。
- 可比较“八个视角平均分配”与主聚焦方案，但八个视角是本次试案假设，不是对未提供初稿的观察。根据各线功能决定是否集中，不凭平均分配自动删线。
- 每代可选盐耙、账本、潮汐表作为质地锚。需要时间体验时，可在跨年前试写三页日常，再按作用增减；只需定位时可直接跳年。三页是练习预算，不是 R10 要求。
- 需要呈现持续世界时，可试三个主线之外的生活片段，如赶海人、盐工食堂及潮汐劳动；也可用一个贯穿细节或概述完成。数量与篇幅由实际效果决定（R12）。
- 若盐场改制的解决依赖“账本里的一页”，提前建立它的存在、权限或相关规则，再在高潮改变其意义；若它只是非承重背景，可在需要时新出现（R11）。

**对应规则**：R1/R2/R3/R10/R11/R12。具体选择见 [叙述视角](../references/01-narrator-and-focalization.md)、[时间与尺度](../references/03-time-and-scale.md)。

## 案例 B：密室推理（信息控制）

**输入（合成）**：密室杀人，叙述者是死者的合伙人，需要隐藏“他当时也在场”。

**依据与条件**：
1. F-INPUT：合伙人是在场的知情者；输入没有说他是凶手，不能据隐瞒直接判定罪责。
2. H：需要检查他在何时、向谁讲述，以及作品已承诺何种可靠性和意识开放程度。第一人称的选择性回述与第三人称的阶段性关闭意识都可成为方法，是否违约取决于具体叙述（R7）。这一判断是 Lubbock 对特定谜题的立场，不是对全部不可靠叙述的禁令。
3. P：若用户选择公平解谜，检查在揭示前是否能取得决定性线索；若要纯惊奇或自我辩护，则检查与既有事实、叙述权限及相应合同是否相容，不预言所有读者会有同一反应。

**可执行设计（均为新增 P/DESIGN）**：
- 默认保留合伙人叙述者，设计其讲述对象和有动机的选择性披露，并避免此前作出与在场事实相冲突的可靠断言。若作者允许改变叙述者，才比较“不知情助手第一人称、合伙人成为被观察者”的替代方案；第三人称聚焦合伙人时也可按已建立的距离选择何时呈现其内心。
- 公平解谜方案可试两处线索：合伙人袖口的盐渍、他对某扇窗的异常熟悉。两处只是本例配置，须建立它们与现场、时点的具体联系并排除必要的替代解释；数量本身不保证足以认定在场，更不证明他杀人（R8/R11）。
- 揭示时让合伙人或助手回看，呈现旧场景的新意义。结尾可增加证实、补充或非承重信息；若解决依赖此前无法预期的新规则，则回填准备或重构（R11）。

**对应规则**：R7/R8/R11。保留知情者叙述、侧写与回读重排的机制，按本作信息合同决定怎样使用。

## 案例 C：认知变化小说（视点与心理呈现）

**输入（合成）**：一个保守的中学教师逐渐接受自己的女儿是同性恋；初稿大量“他感到震惊/他慢慢想通了”。

**依据与条件**：
1. F-INPUT：认知变化是关注点，输入给出两种概括性句式；未给全稿，不能认定所有变化都没有具体依据。
2. H：若目标是让读者贴近判断变化，第三人称限知是一种方案；第一人称回顾、女儿的观察或全知叙述也能承担不同作用，不由题材自动决定人称（R2/R4）。
3. H：概述可以承担压缩、反思或声音。只有本段需要的认识过程或体验尚不足时，才补心理行动、现场或外部动作，不因出现“他感到”就全删。

**可执行设计（均为新增 P/DESIGN）**：
- 可在关键转折增加判断动作或内在认识：他改作业时停在同一行、在饭桌上重复一个旧词、查资料后重新理解旧经验。动作必须与当下判断相关，不能靠若干身体信号自动证明接受发生；必要的心理说明保留（演心）。
- 在实际有变化的节点给出阶段性判断，并让后续事件支持、修正、加深或推翻它。不是每章都必须有一个“微结论”，也不是每个结论都必须被推翻（R2/R4）。
- 若本次方案另设跨度为两年，需要岁月体验时可用开学、期末、家长会作质地锚；仅需定位时写“两年后”也可成立。两年不是原输入已知事实（R10）。
- 一个结尾选项是把女儿伴侣的杯子放进橱柜，让动作兑现关系变化；“他终于理解了”若承载独有认识或声音，也可保留、具体化或与动作并用，不把明说列为禁令（R11）。

**对应规则**：R2/R4/R10/R11；演心判断见上述各条规则。

## 案例组二（心理与创伤表现）

# 五个原创演示（DESIGN_EXAMPLE；新增故事事实不冒充来源事实）

## 示例 A：感官线索与权力压力并存

输入：架空港口仓库管理员阿澄，夜间看到收货簿上反复出现“空仓”字样；她担心失业，却一直想保留父亲留下的修表摊。作者要写她“越来越不安”，没有要求给她任何疾病诊断。

- **F-INPUT**：阿澄看见字样、担心失业并想保留修表摊；“空仓”是输入中的记载，不是医学症状。老板虚报库存或威胁她的情节尚未给出。
- **H**：经济压力可能使她更注意同一标记，也可能存在实际的账簿问题；角色解释与外部事实分别登记。
- **P / DESIGN**：本次可新增“老板逼她接受虚报库存，拒绝可能失去收入”的故事条件，用 RT06 交代独立生活成本，再以 RT15 安排标签三次出现：先普通、后被篡改、最后成为查账线索。三次是本例结构，不是通用配额；改用其他次数时保留各次作用。结局可申诉、辞职或找同盟，不固定为崩溃/痊愈。
- **安全出口**：不以看见字样次数判断心理障碍；新增压力是授权创作中的设计，不反写成用户原稿已有事实。

## 示例 B：多层证词先核对命题，不急判矛盾或患病

输入：二十年前失踪的探险队长，作者称三份材料解释不一致。A 手记说风暴先来，B 手记说船有缺陷，幸存者 C 从未进入发动机舱。

- **F-INPUT**：现有三项信息并不自动互斥：风暴先来与船有缺陷可以同时成立；C 未进发动机舱只限制相应亲见范围，不排除他从别人处听到或读到资料。没有依据认定其中任何人撒谎或失常。
- **H**：所谓不一致可能是时间、对象、因果解释、记忆或转述链不同。先列各人究竟断言什么、何时得知、凭什么知道；只有同一对象与时点的命题不能同时成立，才登记实际冲突。
- **P**：用 RT04/05 和 K0 分别画事件设定、证人可知与读者已知的线。架空小说可新增航行记录、物件痕迹或证人作为 DESIGN，并安排其可靠性与披露位置；不强求现实世界真有这艘船的档案。若任务要核真实历史，才另查相应可靠记录，不把人物说法当现实事实。
- **冲突出口**：缺日志本身只表示证据缺口；尚无支持的命题标 NOT_PROVEN，有针对同一命题的真实证据冲突才标 CONTESTED。可以继续完成授权设计，公平解谜方案不能在尾页仅靠未准备的新证人替预定真凶定罪；其他合同仍核其前后一致性。

## 缺料/边界示例

输入只有“帮我写一个创伤严重的女生，心理一定很病态”，没有场景和角色目标。可将创作问题具体化为她经历的困难、想保护的事物、可依靠的关系和拒绝机会，并直接给出明确为原创的方向；2–3 个方向可作本次展示数量，不是开工前必须问完的配额。不能判定她必然精神失常，也不能用历史 PG 病理描述当临床公式。若用户实际在问自己或他人的现实健康，本 Skill 退出相应现实判断。

## 示例 C（RT-16）：选择回忆距离，完整与留白均可成立

输入：一位小说家要写主角回到童年那场火灾。作者想写得“越痛越好”。

- **F-INPUT**：输入给出火灾回忆与写作目标，没有给记忆完整度、可核实细节或损耗；不能预先断言主角只记得两件事。
- **P / DESIGN**：可比较直接回放与留白两种写法。以下演示留白方案，新增设定为主角此刻只能说出消防车编号和母亲外套颜色，其余暂不能讲出。两项是人物的记忆内容，不自动成为经独立核实的事件事实；若需要核实，另设证词、照片或其他证据。
- **H**：空白可以成为本方案素材，不能从原著的科幻遭遇推出真实记忆必须缺损或越痛越好。选择完整回忆同样可行，也不需虚构装置。
- **P（本方案的素材 / 距离 / 调取方式）**：
  1. 消防车编号 → 他人转述通道 → 可设计邻居讲述，并注明邻居凭何知道；转述不等于独立证实主角全部记忆。
  2. 外套颜色 → 物件通道 → 若新增“外套仍在衣柜”这一条件，可写触摸和描述；衣物存在不证明火灾当天确曾穿它。
  3. 暂不能讲出的部分 → 写作当下 → 可设计他写三版都停在同一句，让读者看见停顿所在；三版是本例动作安排，不是记忆规律。
  随后可给人物仍能选择的行动，如去问邻居或暂不去问，并检查这一处在故事中承担何种变化或体验。
- **反例与出口**：若回放只重复刺激且不承担所需作用，可缩短；完整回忆若符合目标就直接写。不能因本例展示留白而删掉用户要的完整现场，也不以痛苦或缺损数量证明深度。

## 示例 D（RT-14 / RT-17）：医生的内心与镇民猜疑分开承载

输入：一个外来医生住在镇口，镇民逐渐认定他“不正常”。作者想写他的内心恐怖。

- **F-INPUT**：用户已要求医生的内心体验；镇民标签是其判断，不是医生病名。输入没有给窗帘、火柴或登记事件。
- **P（先响应内心目标）**：根据已有叙述方式使用 RT-14 与叙述距离规则，写医生如何感受、理解威胁并作出选择；第一人称私密笔记方案另用 RT-02。第三人称限知同样可以进入他的内心，不把第一人称当唯一入口。
- **P / DESIGN（可并置的外部猜疑链，RT-17）**：若还需呈现全镇恐惧如何形成，可新增以下一条链，并将它与医生内心放在可辨的视角或段落中：
  1. 杂货店主看见他半夜拉下所有窗帘，当场给自己一个解释
  2. 医生被打断话题时突然改口要买火柴
  3. 有人拿“通缉犯的长相”作比，逐渐改变传闻
  4. 店主梦见白色的头，醒来压下念头；梦归店主视角或由其转述
  5. 三人去村长处要求登记外来人口，出现社会后果。
- **来源类比**：《The Invisible Man: A Grotesque Romance》 / / 为 RT-17 的外部观察、类比与猜疑路径提供参照；上述医生、火柴和登记链是本例设计，不是这些行的原著事件。
- **H 与条件**：外部链呈现镇民怎样生成恐惧，内心段呈现医生自己的体验。并置后不再是单一外部猜疑机制，但可以有意比较双方误解；若作者后来只要外部链，才暂不进入医生意识。
- **反例**：用“全镇都怕他”替代本来需要的具体变化，或以“他是疯子”取消视角和事件依据；这些问题不靠删除用户要的内心内容解决。

## 示例 E（RT-18）：用一件小事承载丧失，也允许说出口

输入：一位父亲在孩子去世一年后仍每天上班。作者担心“不写崩溃就不够深”。

- **F-INPUT**：丧子一年、每天上班及作者担心已给；尚无走路仪式、失语或康复结论。
- **F-SOURCE（结构参照）**：《Mugby Junction》 写 Barbox 的七条路选择， 写送琴与收礼反应， 写 Polly 要他学习并复述故事；这些提供日常活动与关系的参照，不是本例丧子父亲的原著经历。
- **P / DESIGN**：可给父亲一件有规则、有终点的事——把孩子学校到家的路按七条岔路分别走一遍，每走完一条就在本子记一笔。七条来自本例设计借用，不是哀伤的固定阶段。若要表现未处理的感受，可设计他走到第四条忽然停笔、暂时说不出孩子名字；这是人物事件选项，不宣称丧亲必然失语。
- **H / P**：这套方案让丧失在做事间隙显露；可再安排与他人共享路线或笔记。也可选择直接告白、沉默或继续工作，按场景目标决定。结尾允许路线走完而某一笔仍空着，也允许哭泣、暂时释然或尚无变化，不将任何一种作为普遍疗效。
- **对照**：原著的锁门、藏绳、扔钥匙也有行动结构，但 RT-18 将其读作对抗处境的另一条路径；本例走路与丧失共处，是新增设计用途，不把两者合成同一种恢复机制。
- **反例**：仅因完成仪式、哭出来或获得陪伴，就宣布人物已经临床痊愈，或删去仍存在的困难。问题在无依据的必然性和治愈保证，不在是否使用象征、告白或哭泣。

以上展示的是可供检查的文本方案，效果未经真实读者验证。

## 案例组三（人物心理与创伤）

# 六类合成输入与预期工作流结果

这些内容均是 DESIGN_EXAMPLE，不是原著剧情。前四类为早期保留，后两类为后续新增。

## 正常：规划
输入：奇幻小说第七章，队长收到妹妹的信，先落泪后冲同伴发怒；想使反转有依据。
F-INPUT：信到达、落泪、发怒，信里内容未知。H1：担心同伴危险；H2：羞耻转移，二者是待选设计解释，均非已知事实。P / DESIGN：可补一条信角被撕的视觉信息，或按目标保留秘密；一套规划链为信→犹豫→隐瞒→关系冲突。回归检查前文妹妹是否被提及；未提供前六章则列核对项，不声称已读。
P02 的另一选项：反转前可写可见触点——例如“她抬头看见同伴腰间那枚妹妹送的旧扣子”。若要保留悬念，可只写她把信塞进护腕；新增扣子与赠送关系明确为本次设计。

## 缺料：临床请求
输入：只有角色昵称，问“他是不是 PTSD？”
输出：NOT_OBSERVED，既没有场景材料，也不能由小说 Skill 诊断疾病。可请用户提供或在授权创作内设计角色可观察动作、时间、关系目标和叙事目的；不把昵称当病名依据。

## 互斥设定：无法自动改稿
输入：设定中永不背叛盟友，最新章节却出卖盟友；人物动机缺失，设定禁止改。
F-INPUT：设定与行为冲突。H：威胁、误导、伪装或连续性错误都有待核对。P：仅暂停这处互斥正典的改写，列需确认的优先条件；其他不依赖该冲突的文字继续处理，不凭新增动机伪称原设定已自洽。

## 补充：高强度场景的节律改写
输入（DESIGN_EXAMPLE）：作者称有一段 400 字刺杀戏，提供的片段是“他冲进去，心里充满恐惧与愤怒，然后杀了她”，并说读起来像流水账。
F-INPUT：所给片段有“冲进去”“杀了她”两项概括动作及情绪说明，不能据此断言未提供的完整 400 字都缺细节。H1：若目标是心理重量，所给片段可能缺少判断过程；H2：叙述距离可能限制当前写法，需结合前后文区分，不把作者意图猜测写成事实。
P / DESIGN（P11）：可按四拍改写——① 程序动作（手先摸到门框的裂口，因为来时已记住）→② 短促清醒（突然听见自己的呼吸并数了三下）→③ 物件触发退缩（钥匙响声让他停住，想到走掉）→④ 再失控（擦手时看到红色窗帘，才惊觉自己在做什么）。裂口、预先记忆、钥匙和窗帘都是本次新增设计；与既有正典冲突时换用原稿可用信号。本例每拍先选一个信号便于起稿，心理说明有独有作用时保留，四拍不是通用模板。
退出：全知冷叙述或黑色喜剧不必用此节律；改后核前后段落视角与事实。未作实际试读，不宣称张力提升已经验证。

## 补充：对峙戏不靠铁证
输入（DESIGN_EXAMPLE）：作者称审讯场景写到第三页，侦探“掌握了确凿证据”，却没有张力；当前提供的信息仅为侦探陈述证据、嫌疑人否认。
F-INPUT：目前材料只显示上述互动，不代表已读整段三页。H：可能需要双向解释机制，也可能另有节奏或人物目标问题；不能仅凭“审讯”认定类型要求铁证推进。
P / DESIGN（P12）：若目标是解释交锋，可让侦探说“你回来重听门铃，是因为你需要确认自己真的做过”，嫌疑人回“我回来是因为我知道你们会这么想”。“回来听门铃”是新增事件，须与原稿核对或换成已有行为。身体反应、沉默、反证或选择都可作为落点；指节压白、嘴唇抽动本身不证明有罪。
退出：若本场明确要以物证完成解密，则保留所需物证链，不强行用心理对峙替代。

## 时间重排演示
