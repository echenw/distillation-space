# 人物心理的案例（编的）

返回 [SKILL.md](../SKILL.md)。这些案例都是为说明而编的，不是哪部作品的情节。案例里新增的故事条件都标为“设计”，不冒充用户原稿里已有的事实。方案是可以检查的文本方案，效果没有经过真实读者的检验。

---

## 1. 港口仓库的“空仓”：感官线索和权力压力

**作者的情况**：架空港口的仓库管理员阿澄，夜里看到收货簿上反复出现“空仓”两个字；她担心失业，又一直想保住父亲留下的修表摊。作者要写她“越来越不安”，没有要求给她任何病名。

**判断**：她看见字、担心失业、想保住修表摊，这三件是作者给的；“空仓”是账上的记载，不是症状。老板虚报库存、威胁她，原稿里还没有。经济压力可能让她更留意同一个标记，账簿也可能真有问题：人物的解释和外部的事实分开记。

**方案**：设计一个故事条件：老板逼她接受虚报的库存，拒绝就可能断了收入。用 PS-19 交代她独立生活的成本；再按 PS-27 让这个标签出现三次：先是平常的记载，后来被人改过，最后成为查账的线索。三次是这个例子的结构，不是配额；改次数时，保住每一次的作用。结局可以是申诉、辞职或找到同盟，不固定为崩溃或痊愈。不凭她看见字的次数判断心理障碍。

## 2. 三份“矛盾”的材料：先核对说的是什么

**作者的情况**：二十年前一支探险队失踪，作者说三份材料的解释不一致：A 的手记说风暴先来，B 的手记说船有缺陷，幸存者 C 从没进过发动机舱。

**判断**：这三条并不自动互斥。风暴先来和船有缺陷可以同时成立；C 没进过发动机舱，只限制了他亲眼看见的范围，不排除他从别人那里听到或读到。没有依据认定谁撒谎或失常。所谓不一致，可能是时间、对象、因果解释、记忆或转述链不同。

**方案**：在知识表上加“谁说、何时说、对谁说、外证与反证”四列（[testimony-and-self-justification.md](../references/testimony-and-self-justification.md)），先列每个人到底断言了什么、什么时候知道的、凭什么知道；只有关于同一对象、同一时点的说法不能同时成立，才记为真冲突。按 PS-02、PS-03 分开画事件、证人可知、读者已知三条线。架空小说可以设计新的航海记录、物件痕迹或证人，并安排它们的可靠性和披露的位置。缺日志只说明证据有缺口；没有支持的说法标“证据不够”。作品承诺公平解谜时，不在最后一页靠一个没铺垫过的新证人给预定的凶手定罪。

## 3. 童年的火灾：选择回忆的距离

**作者的情况**：一位小说家要写主角回到童年那场火灾，想写得“越痛越好”。

**判断**：作者给了火灾的回忆和写作目标，没有给记忆完整到什么程度；不能预先断言主角只记得两件事。“越痛越好”不是统一的质量标准（PS-11）。

**方案**：比较直接回放和留白两种写法，下面演示留白。设计：主角此刻只说得出消防车的编号和母亲外套的颜色，其余暂时讲不出。这两项是人物的记忆，不等于核实过的事件；需要核实时，另设证词、照片或别的证据。按 PS-11 建三栏：
1. 消防车的编号 → 由别人转述：设计一位邻居来讲，并交代邻居凭什么知道；转述不等于证实主角的全部记忆。
2. 外套的颜色 → 借物件：设计“外套还在衣柜里”，写触摸和描述；衣服还在，不证明火灾那天确实穿着它。
3. 讲不出的部分 → 写作的当下：设计他写了三版，都停在同一句，让读者看见停顿在哪里；三版是这个例子的安排，不是记忆的规律。

随后给人物还能选择的行动，比如去问邻居，或者暂时不问。完整的回忆符合目标时，就直接写完整的现场；不因为这里演示了留白，就删掉作者要的完整场面。

## 4. 镇口的外来医生：内心和猜疑分开写

**作者的情况**：一个外来的医生住在镇口，镇民逐渐认定他“不正常”。作者想写他内心的恐惧。

**判断**：作者要的是医生的内心；“不正常”是镇民的判断，不是医生的病名。原稿里还没有窗帘、火柴或登记的事。

**方案**：先回应内心的目标：按 PS-10 和叙述距离（PV-07）写医生怎样感受、理解威胁、作出选择；用私下的第一人称记述时，另看 PS-01。第三人称限知也能进入他的内心，第一人称不是唯一的入口。

如果还要写全镇的恐惧怎样形成，按 PS-22 并置一条外部的猜疑链（设计）：
1. 杂货店主看见他半夜拉下所有的窗帘，当场给自己找了个解释。
2. 医生被人打断话题时，突然改口说要买火柴。
3. 有人拿“通缉犯的长相”作比，传闻慢慢变了味。
4. 店主梦见白色的头，醒来把念头压下去；梦归店主的视角，或者由他转述。
5. 三个人去村长那里，要求登记外来人口：社会后果出现了。

《The Invisible Man》为这条链提供了参照；医生、火柴和登记都是这个例子的设计，不是那部书的情节。两条线放在能分辨的视角或段落里，可以有意让双方互相误解。不用“全镇都怕他”代替具体的变化，也不用“他是疯子”取消视角和事件的依据。

## 5. 丧子一年的父亲：一件小事承载丧失

**作者的情况**：一位父亲在孩子去世一年后，仍然每天上班。作者担心“不写崩溃就不够深”。

**判断**：作者给的是丧子一年、每天上班和自己的担心；还没有仪式、失语或康复的结论。崩溃不是深度的证明（PS-28）。

**方案**：借《Mugby Junction》的结构（七条路逐一走过、送礼、学故事），设计一件有规则、有终点的事：他把孩子从学校到家的路，按七条岔路分别走一遍，每走完一条就在本子上记一笔。七条是借来的设计，不是哀伤的固定阶段。要写没处理完的感受时，可以设计他走到第四条忽然停笔，一时说不出孩子的名字；这是一种事件的选择，不是说丧亲必然失语。还可以安排他和别人分享路线或笔记。

也可以选直接告白、沉默或继续工作，按这一场的目标定。结尾可以是路线走完、某一笔仍空着，也可以是哭泣、暂时的释然或没有变化，哪一种都不当成普遍的疗效。不因为仪式完成了、哭出来了或者有人陪了，就宣布人物已经痊愈。

## 6. 收信以后先哭后怒：反转的触点

**作者的情况**：奇幻小说第七章，队长收到妹妹的信，先落泪，后来冲同伴发火；作者想让这个反转有依据。

**判断**：信到了、落泪、发火是作者给的，信里写了什么不知道。“担心同伴的危险”“羞耻转移成怒气”是两种待选的解释，都不是已知的事实。

**方案**：按 PS-12，反转前写一个看得见的触点（设计）：她抬头看见同伴腰间那枚妹妹送的旧扣子。要保留悬念时，只写她把信塞进护腕。一条可用的推进链是：信 → 犹豫 → 隐瞒 → 关系冲突。回看前六章有没有提过妹妹；没有拿到前六章时，列出要核对的项，不声称已经读过。

## 7. 四百字的刺杀戏：高强度的节律

**作者的情况**：作者说有一段四百字的刺杀戏，读起来像流水账；给出的片段是“他冲进去，心里充满恐惧与愤怒，然后杀了她”。

**判断**：片段里只有“冲进去”“杀了她”两个概括的动作和一句情绪说明，不能据此断言没给出的四百字全都缺细节。目标是心理的重量时，片段可能缺了判断的过程；也可能是叙述距离限制了现在的写法，要结合前后文分辨。

**方案**：按 PS-17 改成四拍（设计）：程序性的动作（手先摸到门框上的裂口，来时就记住了）→ 短促的清醒（突然听见自己的呼吸，数了三下）→ 物件触发退缩（钥匙一响，他停住，想到走掉）→ 再次失控（擦手时看到红色的窗帘，才惊觉自己在做什么）。裂口、钥匙、窗帘都是新加的，和原稿已有的设定冲突时，换成原稿里有的信号。每拍先选一个信号便于起稿；心理说明有独特作用时保留；四拍不是通用的模板。全知的冷叙述或黑色喜剧不必用这种节律。改完核对前后段的视角和事实。

## 8. 有铁证却没张力的审讯

**作者的情况**：审讯写到第三页，侦探“掌握了确凿的证据”，却没有张力；给出的只是侦探陈述证据、嫌疑人否认。

**判断**：现有的材料只显示这一来一回，不代表已经读了整整三页。可能需要双向的解释，也可能是节奏或人物目标的问题；不能只凭“审讯”就认定类型要求铁证推进。

**方案**：目标是解释的交锋时，按 PS-07 让双方各给一个对方能反过来用的解释（设计）：侦探说“你回来重听门铃，是因为你需要确认自己真的做过”；嫌疑人回“我回来，是因为我知道你们会这么想”。“回来听门铃”是新加的事件，要和原稿核对，或换成原稿里已有的行为。落点可以是身体的反应、沉默、反证或选择；指节发白、嘴唇抽动本身不证明有罪。这一场明确要靠物证解开时，保留需要的物证链，不硬用心理对峙替代。

## 9. 要停下或改道的几种请求

| 请求 | 怎么处理 |
|---|---|
| “帮我写一个创伤严重的女生，心理一定很病态”，没有场景和人物目标 | 把问题具体化为她经历的困难、想保护的东西、可依靠的关系、可以拒绝的机会，直接给几个标明“原创”的方向；不判定她必然失常，不拿历史上的病理描写当临床公式 |
| 只给一个人物的昵称，问“他是不是 PTSD？” | 没有场景材料，小说的 skill 也不诊断疾病；可以请作者给出或在创作授权内设计人物看得见的动作、时间、关系目标和叙事目的 |
| 设定写着“永不背叛盟友”，最新一章却出卖了盟友，动机缺失，设定不许改 | 威胁、误导、伪装或连续性错误都可能，要核对；只暂停这一处互斥的改写，列出要作者确认的条件，不依赖这处冲突的文字照常处理；不靠新增的动机假装原设定已经自洽 |
| 要求“受伤的人必须原谅加害者才能康复” | 原谅不是医疗上或叙事上的必然；给两种设计：拒绝和解、获得新的安全边界；按自愿的条件尝试和解。两种都不承诺疗效（boundaries-and-ethics §3） |
| 用户其实在问自己或身边人的现实健康 | 本 skill 退出这部分的现实判断，建议找有资格的专业人士；小说创作的部分照常可以做 |
