# 人物塑造与叙事控制

管四件事：**谁在讲、从谁的眼睛看**（叙述者与视点），**读者和人物各知道什么、什么时候知道**（信息控制、证词与自辩），**人物的心理落在哪里**（动作、身体、沉默、物件、关系、说话的方式），**时间怎样走**（场景与概述、跨越时间、非线性和故事内的时间异常）。视角、信息和场景的规则是 PV 卡，时间机制是 TM 卡，人物心理、声口和弧线是 PS 卡。全书只用一张信息表（§2）。

## 1. 适用与转介

先判负触发，再定接不接。完整演示见 `examples/pov-cases.md` 例五「先判负触发」。

### 1.1 触发（接）

- 开新书或重构：选叙述者、主视点人物、人称、多视角方案。
- 写或改一场戏：守住这一场的视角，决定写谁的内心、写到多深，心理怎样落在动作和身体上。
- 设计反转、误会、秘密、悲剧反讽、不可靠叙述、多层证词、人物的自我辩解。
- 写人物心理：情绪反转、沉默和不反抗、钱和身份的压力、群体的恐惧、丧失、求罚、关系里的转变；创伤题材的写法和伦理。
- 写人物：几个人物的声口怎样分开、对白里的潜台词、人物弧、配角和对手各自想要什么。
- 设计时间：倒叙和交错、几代人的跨度、失忆和预知、时间旅行、平行世界、两条互为因果的时间线。
- 稿子有这些症状：不知道谁在看、视角越界、切换晕、内心像报告、反转像作弊、全书像大纲、跳年无感、动机说不清、情绪转得突兀、沉默被写成性格、时间线读不懂、几个人物说话一个腔调、对白把动机说破、配角像工具、对手像纸片人。

### 1.2 负触发（不接，先转介或停下）

- 要改句子措辞、对白标点、语感、错别字、体例或全稿校对：转 `line-editing-and-proofreading`。
- 伏笔位置与回收、悬念强度、章末钩子、一场戏的进出、动作打斗：转 `scene-conflict-and-rhythm`。
- 主线、多线、因果、删场、分卷和连载排产：转 `story-architecture-and-longform-planning`。
- 题材规则、机制、混合题材：转 `genre-fiction-craft`。
- 改编成舞台、影视、音频或互动形式：转 `cross-media-drama-adaptation`。
- 新作规划入口、成稿整体诊断、读者反馈、事实核验、不确定用哪个 skill：转 `fiction-planning-and-diagnosis`。
- 生成／修订／诊断推进模式卡、文风卡、表达约束卡；写「反 AI 味的约束卡」；按推进／文风／表达三轴审章节；已有文风卡或推进卡作为输入：产物是「给模型的卡」或审查框架是三轴，转 `preset-card-generation`。
- 真实的病名、诊断和疗法，真实证人的可信度：不在本 skill 的范围（[boundaries-and-ethics.md](references/boundaries-and-ethics.md) §1），退出那一部分；时间旅行在物理上可不可行，也不判断（[nonlinear-time.md](references/nonlinear-time.md) §5）。
- 只给梗概或只有构思，却要求逐段诊断、逐句定位：先要正文；只做构思层的设计，写明「证据不够」，不编位置和短引文。
- 要打分、评级，或裁定「唯一正确的视角／人称」：本 skill 给逐条建议和各自代价，不打分，由作者决定。

### 1.3 转给别的 skill

| 问题 | 转给 |
|---|---|
| 伏笔怎么埋和回收、悬念强度、章末钩子、松紧节奏、一场戏的进出、打斗 | `scene-conflict-and-rhythm`（本 skill 只决定谁知道、谁能看见） |
| 主线、多线、因果、删场、分卷和连载的规划 | `story-architecture-and-longform-planning` |
| 选题、读者契约、资料核验、读者反馈、不确定用哪个 skill | `fiction-planning-and-diagnosis` |
| 句子、对白的措辞、标点、语感、校对 | `line-editing-and-proofreading` |
| 推理的公平线索、恐怖与言情等题材的契约 | `genre-fiction-craft`（题材契约以它为准；本 skill 只核对视角和信息有没有守住契约） |
| 改成舞台方案、分场稿、镜头 | `cross-media-drama-adaptation` |
| 生成／修订／诊断推进模式卡、文风卡、表达约束卡；写反 AI 味的约束卡；按三轴审章节；已有文风卡或推进卡作为输入 | `preset-card-generation`（产物是「给模型的卡」或审查框架是三轴时转回） |

从 `genre-fiction-craft` 转入本 skill 的：全篇的人物动机、谁来讲、视角越界、时间模型。

从 `preset-card-generation` 转入本 skill 的：不写成卡、也不按三轴审的视角合同、人物声口、信息控制、叙述距离、人物知识边界、场景与概述、非线性时间。

## 2. 使用方式

- 宿主规定了输出格式，就按宿主的格式交付；没有规定时，用 §3 末尾的交付清单和 `templates/narrative-workbook.md`。
- 普通任务读完本文件就能做。需要细则、例子和例外时，只读 §6 里用得到的文件。
- 给了稿子就按稿子诊断，写明位置和短引文，不整段复制；只有构思就做设计；要求写正文或改写就写，不覆盖原稿，交付时用一两句说明视点、距离和省略了什么。
- 缺关键信息（比如主视点人物没定）时，先做合理的假设往下做，并标明“假设”；只有答案会彻底改变方案时才停下来问，一次最多问三个问题。没有稿子时，不声称做过逐段诊断。
- **一张信息表**：全书只维护 [information-control.md](references/information-control.md) §3 的知识表。涉及证词和自辩，加“谁说、何时说、对谁说、外证与反证”四列；涉及时间错位，加“世界时间、人物经历、展示顺序、读者已知”四列。空表在 `templates/narrative-workbook.md` §2。`scene-conflict-and-rhythm` 里一场戏的知情表，是这张表在一场戏里的切片。
- 文中的数字都是起点，不是门槛（narrative-workbook §7）。
- 规则是检查工具，不是品味标准。作者坚持某种写法时，说清代价和替代办法，由作者决定（[diagnosis.md](references/diagnosis.md) §6）。
- PS 卡是文学写法，不是临床知识：不给人物或真人下病名，不把文学的结局说成现实的疗效。用户其实在问自己或身边人的现实健康时，退出那一部分，小说的部分照常做。
- 自己编的例子要说明是编的；给作者的稿子新增的故事条件标“设计”，不冒充原稿已有的事实。

## 3. 最短路径

### 选视角（开新书或重构）

1. **主体**（PV-01）：谁、在什么处境里、发生了什么变化。复调或多主体时，用几句话或一张关系图说清关注点。
2. **视点中心**（PV-02）：列两到四个候选，选“他的经验就是这部作品的主体”的那个，不是戏份最多的那个。
3. **叙述位置**（PV-03）：先定叙述者站在哪里、凭什么知道，再定第几人称。
4. **视角合同**（PV-04）：写清能知道什么、不能知道什么、能进谁的意识。
5. **多视角时建切换账本**（PV-05）：每个额外的视点写明它买回了什么。
6. 交付视角方案卡（narrative-workbook §1）。

### 设计信息（反转、误会、秘密、证词）

1. **画知识表**（PV-09）：每个关键信息，谁知道、读者知道吗、什么时候揭示、揭示后改变什么。
2. **选合法的瞒法**（PV-09、PV-10）：换叙述者、限制视域、不可靠的叙述者、时间错位、暂时关上聚焦者的意识；和本作约定的公平与可靠性一致。
3. **有证词或自辩时**，在知识表上加四列，分版本记账（PS-01 至 PS-08）：更晚、更坦白的一版也不自动为真。
4. **揭示**（PV-11）：深层事实先侧写，需要时再点破；高潮需要的那只眼睛提前就位（PV-16）。
5. 伏笔的位置和回收清单，接着用 `scene-conflict-and-rhythm`。

### 写或改一场戏

1. **这场谁在看、能写什么**（PV-05、PV-04）：起点是一场一个视点，要换就放在场景的断点；只写视点人物能看到、听到、知道、推断的东西。
2. **这场做什么**（PV-12、PV-13）：兑现、建立还是跨越，选场景、概述或混合。
3. **心理落在哪里**：看得见的动作和话、身体的感觉（PS-10、PS-14）、盯住的细节（PS-13）、沉默（PS-23）；情绪反转要不要一个触点（PS-12）；高强度的场景怎样摇摆（PS-17）。
4. **内心演出来**（PV-08）：用注意、判断、动作和措辞代替“他感到”；距离在一场之内保持稳定（PV-07）。
5. 填人物心理场景卡（narrative-workbook §3）；交付时说明视点、距离和省略了什么。

### 写人物（声口、弧线、配角和对手）

1. **弧线的轴**（PS-33）：开篇他相信一件什么不对的事，哪些事逼他检验，结局走向哪一种。
2. **配角和对手**（PS-34、PS-35）：重要配角在这场想要什么；对手知道什么、要什么、为什么认为自己是对的。
3. **声口**（PS-31）：用词、句长、回避的话题、口头习惯；作者还没给台词样本时走「声口待定」，不编口吻。
4. **对白**（PS-32）：先写每个人想要什么、为什么不能直说，再写说出口的话。
5. 填人物声口与弧线卡（narrative-workbook §9）。

### 设计时间

1. **先分类**（[nonlinear-time.md](references/nonlinear-time.md) §1）：披露顺序的重排、记忆的重排，还是故事内的时间异常。
2. **在信息表上加四列**（nonlinear-time §2）：遗忘只改人物经历，倒叙只改展示顺序，真的穿越才改世界时间。
3. **只有真异常才选机制**（TM 卡），填时间机制卡（narrative-workbook §4）。
4. **跨越时间之前先写日子**（PV-14）；**定叙述的时间距离**（PV-15）。

### 诊断已有的稿子

按这个顺序：范围 → 主体 → 视点 → 合同 → 信息 → 场景与概述 → 时间 → 世界的边界 → 人物心理。各步的细则以 [diagnosis.md](references/diagnosis.md) §1 为准（拿到稿子先读那份）。整体的方法选择先澄清主体；局部的权限、定位、声音问题直接修，不等全书的主体定稿。对症状用 §4 和 diagnosis §2、§9；逐条审稿用 narrative-workbook §6 的十问。

### 交付

- 按任务挑：视角方案卡、信息表、人物心理场景卡、时间机制卡、修改单（narrative-workbook §1 至 §5）；写人物时加人物声口与弧线卡（§9）。
- 修改单的“代价”一栏必须写：每个改法都会动到别的地方。
- 判断按五档说清：文本中明确呈现、推断、设计方案、证据不够、超出范围（boundaries-and-ethics §5）。

## 4. 症状速查

| 症状 | 常见原因 | 先看 |
|---|---|---|
| 读者不知道谁在看 | 无名全知的叙述权限不稳定；章内视角漂移；段首没有感知锚 | PV-04、PV-05 |
| 视角越界 | 没有合同；为了交代信息临时“借脑” | PV-04 |
| 切换很晕 | 切换不买回东西；切在场景中间；没有标记 | PV-05 |
| 主角的内心很平 | 用报告代替演出 | PV-08、PV-03 |
| 世界很薄 | 聚焦者看不懂世界，又没有补光；世界过度封闭 | PV-06、PV-17 |
| 叙述被人物的语气吞没 | 没有反讽的距离 | PV-07 |
| 反转像作弊 | 违背了本作已经建立的可靠性或公平承诺 | PV-09、PV-10、PV-11 |
| 一揭秘就平了 | 直接说出事实，没有侧写 | PV-11 |
| 场景拖、像流水账 | 场景的功能不清，或者一场里分散了几个主功能 | PV-12 |
| 全书像大纲 | 全是概述，没有兑现的场景 | PV-12、PV-13 |
| 跳年无感、人物变老像换人 | 需要岁月感时，跨越前没有日子，跨越后没有变化的细节 | PV-14 |
| 高潮少了关键的一眼 | 高潮需要的视点或信息没有提前就位 | PV-16 |
| 动机说不清，几个理由互相打架 | 没有分版本记账：谁说、何时、对谁、外证 | PS-06、PS-01 至 PS-05 |
| 证词各说各的，读者不知道信谁 | 缺外证或反证；关键的后果和疑点放得太晚 | PS-02、PS-03 |
| 情绪转得突兀 | 缺看得见的触点或新的信息 | PS-12 |
| 心理全靠独白；每次恐惧都是冷汗加手抖 | 身体的感觉没绑在视角和行动上 | PS-10、PS-14 |
| 沉默被写成性格 | 没写社会和关系的成因 | PS-18、PS-23 |
| 贫困或疾病解释了一切 | 社会处境和心理推断混在一起 | PS-19、PS-24 |
| 群体的恐惧来得太快 | 猜疑链缺了环 | PS-22 |
| 丧失只靠一次告白或宣泄；转变像一夜治愈 | 没有日常的小事承载；行动、判断、后续没分开 | PS-28、PS-30 |
| 几个人物说话一个腔调 | 没给人物定用词、句长、回避的话题和口头习惯 | PS-31 |
| 对白把心里的动机直接说出来 | 说出口的和想要的没分开 | PS-32 |
| 人物弧立不住，结尾的转变像宣布 | 开篇没有一个要被检验的信念；转变没落到选择上 | PS-33、PS-30 |
| 配角像工具，对手像纸片人 | 配角没有自己想要的；对手的行动在他自己的信息和价值里不成立 | PS-34、PS-35 |
| 时间线读不懂 | 世界时间和展示顺序混在一起；两条线没有识别的信号 | nonlinear-time §2、§3；TM-06 |
| 闭环自相矛盾、揭底不公平 | 改动前后的状态冲突；揭底前没有可回查的痕迹 | nonlinear-time §3 |

每种症状的诊断和改法见 diagnosis §2（视角与信息）和 §9（心理与时间）。

## 5. 规则卡

每张卡的细则、例子和例外在对应的参考文件里。

### 叙述者与视点（`references/narrator-and-viewpoint.md`）

- **PV-01 先说主体，再选方法**：一句话说出谁、在什么处境、发生了什么变化，再判断重心在一个人的意识、一个群体或时代，还是一个待解的问题。复调或多主体时用几句话或一张关系图；暂时说不出主体也不删线。
- **PV-02 视点中心选“经验即主体”的人**：列两到四个候选，各写由他看读者多知道和少知道什么；记下放弃其他人的损失。群像和史诗可以多中心，读者始终要知道此刻谁在看。
- **PV-03 先定叙述位置，再定人称**：五种位置：无名全知、故事人物讲述、第一人称限知、第三人称限知、纯场景。第一人称也能自我剖析；自我欺骗、讽刺性自我暴露是主题时，第一人称的天然局限恰是效果所在。
- **PV-04 视角合同**：三层。能不能知道近乎硬性；距离可以调，变化要重新锚定；切换是一次交易，要记账。叙述者的位置要放进书里；保留无名全知时，叙述的权限稳定、清楚即可，不必换掉。
- **PV-05 每次切换都要买回东西**：记触发、收益、标记、代价；只为传一句信息的切换，改用目击、听说、推断或文件。短篇可以先试单一视点，长篇可在各条线提供独特信息时使用多个主视点；任何作品都要让切换有清楚标记和实际收益。
- **PV-06 限知补光只加目力，不加事实**：先判断“受限”是不是主题；是，就不补光，改用反讽距离。补光不能写进聚焦者不可能知道的事实。
- **PV-07 距离要稳定，变化要重新锚定**：每场定贴身、中距或远距；要让读者的判断高于人物，就保留人物的措辞，不评论，用事实性的细节或别人的反应映出他。距离太大，就成了作者嘲笑人物。
- **PV-08 把意识演出来**：需要读者看见判断的过程时，写注意落在哪里、停在哪里、怎么误判、做了什么、说法怎么变；一句准确的心理叙述有独特作用时可以保留，不要求每段都配外部的征候。也可以整场一致地关上意识。

### 信息控制（`references/information-control.md`）

- **PV-09 合法地瞒**：先画知识表，再选五种合法的方式之一。进入人物内心不等于必须公开全部思想；人物可以选择性叙述、撒谎或自欺，但要与作品的公平和可靠性契约一致（题材对公平和可靠性的约定以 `genre-fiction-craft` 为准，见 §1.3）。读者可以比人物知道得多。没有公平解谜的承诺时，故意保留秘密不是错，只要和已经建立的叙述权限相容。
- **PV-10 不可靠叙述要留下证据**：前后矛盾、他人的反应、物证、说漏的细节；不靠结尾作者突然宣布。不可靠也可以一直不解决。
- **PV-11 深层事实先侧写**：先给几个侧影，再回到日常表面；需要点破时，可以是一句由动作或对话触发的话，也可以是更长的解释或一个动作。两三个侧影是起点；也可以一直留白。
- **PV-16 高潮需要的眼睛和信息提前就位**：承重的视点、物件和信息在前文以当时别有用处的方式出现；高潮可以带来新的、不承重的信息，不能临时造一条承重的规则替人物解围。

### 场景、概述与时间（`references/scene-summary-and-time.md`）

- **PV-12 场景用来兑现；需要比较叙述密度时，可用参考文档中的可选配比区间作试算，不作质量门槛**：给场景标功能；兑现的场景，冲突已明、赌注已立。场景也可以建立信息、呈现体验；读者还缺承重信息时，一边建立一边兑现，力量容易分散。重要场景的位置比数量重要。
- **PV-13 概述有三种正职**：蓄势、压缩、定语气。不只凭“场景能不能做”来判断一段概述；把全书改成场景，时间压不动，背景也撑不起来。
- **PV-14 跨越时间之前先写日子**：需要读者体验岁月时，先用日常循环建立质地，跨越后给一个变化的细节。只要标定新的时间位置时，直接写“五年过去”也能完成任务。
- **PV-15 定好叙述的时间距离**：回忆体要说明为什么现在讲、瞒不瞒结局；第一人称同样可以在当时、回顾和讲述的当下之间变化距离。“后来她才知道”是一次提前揭示，用前查 `scene-conflict-and-rhythm`。
- **PV-17 世界的边界由主体决定**：开放给主线外的人和事少量具体的独立存在；封闭把边界变成压力。按本作的主旨和效果选，不按题材定。

### 非线性时间与时间机制（`references/nonlinear-time.md`、`references/time-mechanisms.md`）

先分三类、记四列（nonlinear-time §1、§2）；看、进入、搬动是不同的机制，不能互相代替（§4）。TM 卡是可选的写法，不是时间故事的必备件。

| 卡 | 用在 | 要点 |
|---|---|---|
| TM-01、TM-02 | 调查者就是罪魁 | 失忆让侦查者查到自己；写给失忆后自己的纸条成了罪证 |
| TM-03 | 喜剧化的时间规则 | 把“回去重做”规则化，生出制度上的矛盾 |
| TM-04、TM-05 | 闭环和越补越大的错误 | 结尾回扣开场的异象；每级补救引入更大的错误 |
| TM-06 至 TM-09 | 两条平行线 | 重复的锚点保证可读；动机倒置；只有文字能跨线；振荡的悬置 |
| TM-10、TM-11 | 用时间对付一个强者 | 送进他权力前提不存在的时代；复仇者的静默 |
| TM-12、TM-13、TM-15 | 未完成的稿子、两个时代互换 | 正文和续写笔记分层；身份交换；预装知识的缺口 |
| TM-14 | 穿越到有文本记载的过去 | 只在选了“历史固定”时，已知的文本才是剧本 |

| TM-18 | 两个时间域互为因果 | 选了等时，就给两个域各建事件时钟；不等时写明倍率 |

### 证词、自辩与解释权（`references/testimony-and-self-justification.md`）

- **PS-01 封闭的第一人称**：私下的记述露出公开场合不能承认的矛盾；不把短句和重复当成崩溃的症状。
- **PS-02 层层转述**：标出谁知道、谁不问、谁保护谁、保护让谁付出了什么；转述者的立场不是中立的事实。
- **PS-03 打乱时间的证词**：先评价结果再辨前因可以，但不用闪回暗示“有解释就无责”；关键的后果和疑点放在前面。
- **PS-04 参与者事后回望**：当时所见和事后承认分两栏；回望可以修正，也可以继续自欺。
- **PS-05 误判、流言、不愿承认**：三种成因分开记，不合成“不可靠”或“有病”。
- **PS-06 几个互相矛盾的理由**：每个版本标时点、听众、反证；言行矛盾不自动说明叙述者不可靠。
- **PS-07 对峙**：双方各给一个对方能反过来用的解释；类型要求铁证推进时不必用。
- **PS-08 反复的自我辩解**：写承诺、风险、事后自评、旁人的代价；不套“成瘾句式”，不下病名。

### 心理落在身体、动作和记忆上（`references/psychology-in-action.md`）

- **PS-09 开场就是身体的异常**：只在约定的幻想语境里不解释因果；分清隐喻和世界里真实发生的事。
- **PS-10 身体感觉绑在视角上**：写情境、理解、随后的行动和别的解释；“胸闷就是惊恐发作”不成立。
- **PS-11 回忆痛苦的距离是选择**：素材、距离、调取方式三栏；完整的回忆也成立，“越痛越好”不是标准。
- **PS-12 情绪可以连续转向**：要读者当场看懂反转，先给看得见的触点；有意不解释也可以。
- **PS-13 小物件抓住注意力**：先认出细节在本场的功能：收紧、失焦、职业观察或审美；不凭注视断言创伤。
- **PS-14 身体信号和自述的张力**：选有区分力的动作和时点对照；时代的医学用语照录，不当诊断。
- **PS-15 梦不是诊断工具**：记梦前的触发、梦里的意象、醒后的选择；梦不必然带来转折。
- **PS-16 主观的失控和文本的因果分开**：叙述者掌握人物不自知的因果是视角的权利；真实的胁迫存在时，不责备受害的人。
- **PS-17 高强度场景的摇摆**：程序动作、短促的清醒、物件触发、再次失控是一种顺序，可以改顺序和拍数。

### 资源、沉默与群体的压力（`references/social-pressure-and-silence.md`）

- **PS-18 拒绝是一种社会关系**：记每次要求的提出者、权力、拒绝的原话、后果、替代的渠道；话少不等于抑郁。
- **PS-19 钱和身份是真实的限制**：谁付钱、何时到期、拒绝失去什么；原材料没有的代价不自己发明。
- **PS-20 环境的压力链**：条件 → 解释 → 能选的行动 → 后果；“环境必定决定命运”不是普遍的因果。
- **PS-21 高压开场不靠污名**：先定矛盾、威胁和出口；口音不等于品格，有害的历史用词标明说话的人。
- **PS-22 群体的恐惧一步步搭起来**：看见 → 听说 → 类比 → 梦 → 行动；外部的链写不出被恐惧者的内心。
- **PS-23 沉默不等于一种动机**：已建立压迫时写看得见的成因，不明就保留未知；“她没反抗”不等于“她愿意”。
- **PS-24 社会处境和心理推断分开**：补资源和关系的限制、谁看见了什么、反证；不用单一原因解释全部行为。

### 物件、丧失与转变（`references/objects-loss-and-change.md`）

- **PS-25 空房间留下的痕迹**：先定镜头归谁；至少一个能在前文查到的细节；不凑“创伤的布景”。
- **PS-26 标题里的价值判词**：记标题的预期、正文第一次挑战它的事件、结尾接受还是翻转。
- **PS-27 反复出现的物件**：第一次的实物 → 第二次的关系 → 最后一次的行动或反转；变化绑在行为上，不绑在症状上。
- **PS-28 一件有结构的小事承载丧失**：有规则、有终点、能和人分享；也可以并用告白或沉默，不预设痊愈。
- **PS-29 求罚和被宽恕的张力**：写他想向谁证明什么、代价是什么；保留不和解、不自罚的分支。
- **PS-30 关系的改变不是一瞬间的治愈**：分开已经发生的行动、判断和后续；转变不等于悔改。

### 声口、弧线与群像（`references/voice-arc-and-cast.md`）

- **PS-31 声口要分得开**：用词范围、句长习惯、回避的话题、口头习惯；遮住说话人的标签仍分得出是谁。作者还没给台词样本时走「声口待定」，不编口吻。
- **PS-32 潜台词**：说出口的和想要的分开写；直白本身是性格时不算毛病，交代关键信息的对话要说清楚。
- **PS-33 人物弧以一个错误的信念为轴**：事件逼他检验；结局是改变、坚持并付出代价或堕落；人物不变而周围变了的故事也成立。
- **PS-34 配角有自己想要的**：重要配角每场有一个他想要的；只出场一次的功能性人物不必写。
- **PS-35 对手的逻辑在他自己那里成立**：按他掌握的信息和价值观行动，胜负落在两边的信息差上；自然力量式的对手要规则，不要动机。

## 7. 冲突时的顺序

1. **主体优先**：规则和主体的需要冲突，改规则（PV-01）。
2. **本作实际的约定优先于本 skill 的默认值**：作品明确选了公平解谜、某种情感的兑现或某种速度，就按它；不从“推理”“言情”的标签推定全部约定。
3. **作者的趣味不纠正**：要写全知插话、元叙事、说书体，说清代价和替代，由作者决定（diagnosis §6）。
4. **合同的第一层（能不能知道）近乎硬性**；距离和切换可以调整。
5. **现实层面的边界不让步**：不给真人下病名，不提供自伤的方法细节，不把文学的结局说成现实的疗效（boundaries-and-ethics §1、§3）。作品里的人物怎样看待受罚和赎罪，按 PS-29 写。

## 8. 适用边界与验证

- 本 Skill 提供叙事视角、人物心理、信息控制和时间组织方法，不保证作品效果或读者反应。
- 视点和叙述距离是设计选择；检查信息权限、转换标记、读者收益和连续性，不设固定人称或视点数量的硬门。
- 现实心理、临床、法律和历史事实需要独立核验；本 Skill 不提供诊断或专业意见。
- 没有真实读者测试时，不把对读者理解和情绪的判断说成已经验证。


## 9. 交付与失败出口

### 9.1 交付状态词

对作者交付只用三个状态词，不写内部状态码；依据不是状态词，作附件逐项附上：

| 状态词 | 什么时候用 |
|---|---|
| 已完成 | 检查已执行，且有稿件内可核的证据支持 |
| 未能核实 | 检查已执行，但结论依赖未核实的判断或缺失的输入，不能记作已完成 |
| 待作者决定 | 存在冲突、取舍或锁定内容矛盾，由作者裁决，不擅自覆盖 |

依据随每项附证据或稿件内可核位置（不是固定答案，也不是来源背书）。

三个状态词也用于逐编号台账的「状态」列（[narrative-workbook.md](templates/narrative-workbook.md) §8），依据填在同一行的「稿件证据位置」；「未知」是状态列的合法值，但不得把未知写成已完成。修改单的「代价」一栏必须写。

判断按五档说清（[boundaries-and-ethics.md](references/boundaries-and-ethics.md) §5），与交付状态词分层对应：「文本中明确呈现」记「已完成」，依据写稿件位置。「推断」是从稿件归纳的看法，稿件没有明写；「设计方案」还没有放进稿件试过；这两档都记「未能核实」，依据写推断靠的是哪几处、方案按的是作者哪条设定，并写明怎样才能确认（作者确认，或写进稿件后回看）。「证据不够」记「未能核实」并写明缺什么；需要作者取舍的记「待作者决定」；「超出范围」按 §9.2 退出那一部分、说明需要哪种专业核验或用户设定，这一项交付记「未能核实」并附转出说明，小说的部分照常做。

### 9.2 失败出口

遇到下面情况停下或转介，列问题清单交作者；完整演示见 `examples/pov-cases.md` 例五：

| 情形 | 出口 |
|---|---|
| 没有稿子、只给梗概，却要逐段诊断 | 先要正文；只做构思层设计，写明「证据不够」，不编位置和短引文 |
| 主视点人物、可靠性或公平承诺没定 | 先做合理假设往下做并标「假设」；只有答案会彻底改变方案时才停问，一次最多三个问题 |
| 人物还没有任何台词样本，却要定声口或写对白 | 走「声口待定」（PS-31）：只记已知的身份、处境和关系，不编口吻；对白先用占位标出每句的意图，等作者给样本或确认 |
| 坚持第一人称，又要读者知道主角不知道的事 | 给「读者在前」与「事后叙述」两版和各自代价，停在待作者决定，其余不冲突的修改照做 |
| 合同第一层判不清（越界还是合法切换） | 按 `references/narrator-and-viewpoint.md` §4.2 修法依次试；不借第三层切换放行第一层越界 |
| 跨越说不出人物是怎么过这段时间的 | 回到建质地那一步（scene-summary-and-time §6.2）；只需标定时间位置时直接写「几年过去」不算失败 |
| 要打分、评级、裁定唯一正确的视角 | 说明本 skill 给逐条建议和代价，不打分，由作者决定 |
| 要真实病名、诊断、疗法，或判断时间旅行的物理可行性 | 退出那一部分，小说的部分照常做（§1.2） |
| 对话或材料显示，所谓人物其实是用户本人或现实中的人，且可能处于即时危险 | 按 boundaries-and-ethics §6 先给一句现实求助指引，创作的部分回到文学层处理；小说人物身处险境照常写，不加提示 |
| 作者坚持全知插话、元叙事、说书体 | 不纠正趣味；说清代价和替代，由作者决定（[diagnosis.md](references/diagnosis.md) §6） |
| 已锁定的设定或已发章节与新方案冲突 | 只改可改的部分，列出最小冲突集合由作者裁决，不擅自覆盖 |
| 生成／修订预设卡、按三轴审章节 | 转 `preset-card-generation` |
| 作者不答或只回「你看着办」 | 按最小改动处理，逐条列出所做的假设，不擅自扩大改动范围 |

## 与其他 Skill 的协作边界

- `fiction-planning-and-diagnosis` 拥有原创故事的前提、结构、单元规划与整体诊断；本 Skill 不替它决定故事是否成立。
- 本 Skill 拥有人物目标、叙述权限、视角、关系变化、人物知识边界和时间连续性的检查；不负责把既有文本转换成舞台、影视或互动媒介结构。
- `cross-media-drama-adaptation` 拥有既有文本的媒介转换与互动分支结构；涉及人物知识、视角或时间线时，调用本 Skill 做角色层回归。
- `line-editing-and-proofreading` 拥有句子、段落和校对层面的语言编辑；本 Skill 提供人物声音与视角约束，不替代逐句编辑。语言修改会改变人物声音、叙述权限或视角时，它停在那一处转来本 Skill；本 Skill 判断后交作者确认。

互动叙事中，本 Skill 只检查每条路线内人物知道什么、何时知道、关系如何变化以及时间是否连续；玩家选择、状态变量和分支拓扑由 `cross-media-drama-adaptation` 负责。
