# 人物塑造与叙事控制

将人物的选择、说法、身体行动和叙述权限一起设计。先判断问题发生在哪一层，再取相应规则；不要把所有角色都写成不可靠，也不要把回忆、倒叙和物理穿越混在一起。

## 最短执行路径

1. 从请求中确定规划、诊断、改写或核证；已有稿仅以实际读过的段落为事实。创作请求允许提出清楚标注的原创设定，不把未给的病史、身份或前文伪装成已有正典。
2. 写出叙述契约：谁讲、谁看、当时或事后、现实或幻想、哪些秘密允许保留。局部任务可由段落推定暂定契约，不要求先填全书所有表。
3. 用统一信息表列事件事实、人物可知、叙述者权限、读者已知及证据来源。时间问题再展开 T/M/O/K；人物动机问题再展开自述、旁人解释、资源与选择。
4. 按下表读取规则的完整条件、原例和反例。相同信息表只建一次，跨问题共用事件 ID；相近但条件不同的规则保留分支。
5. 给最小可执行方案；遇互斥锁定设定只暂停受影响部分。需要作者决定的实质选择给 A/B 及代价，普通实现选择按现有目标推进。
6. 改写后核对知情时间、视角权限、人物可选行动、物件连续性、前后伏笔和声明的世界时钟。记录实际核过的范围；没有读者反馈就不声称效果已经证明。

## 与其他 Skill 的边界

本包独立包含上述工作必需的方法、模板与案例。全书因果和分卷结构由“02 故事架构与长篇规划”主责；具体场面的行动节拍由“03 场景设计与冲突节奏”主责；题材承诺与谜题公平性由“05 类型小说创作”主责。它们并非运行依赖。本包保留场景/概述方法，只负责叙述距离和信息安排，不另立一套情节结构或搏斗模板。

## 输出与证据

规划交蓝图，诊断交定位明确的问题，改写交实际文本并附必要说明；无需每次展示全部内部表格。需要解释时使用 F（原文可定位事实）、H（有反证的解释）、P（可撤销的创作动作）。文学人物说法、论著作者的审美判断、编者说明和未完成 Notes 分开标记。自拟例子标为 DESIGN_EXAMPLE；原著案例注明出处作品，不混作自拟情节。效果未经真实读者验证。

本包整合四个来源任务（叙事视角与信息控制、非线性叙事与时间设计、心理与创伤表现、人物心理与创伤）的全部有效知识；原规则编号保留命名空间。科学、医学、版权现状或现实司法问题需独立适格证据；无法证明的事实标 NOT_PROVEN，缺材料标 NOT_OBSERVED。真实健康问题退出文学推断。
