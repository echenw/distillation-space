# competition-underdog-arc（职业与竞技·逆袭弧）

## 0. 一句话
先把“谁裁决、按什么规则、输了失去什么”写清楚，再写主角有多惨；逆袭弧的燃料是可计量的劣势与可复述的能力，不是苦难本身。

## 1. 触发 / 负触发
### 触发
- 作者要写或改一个“职业/竞技逆袭”故事：学徒、工匠、记者、运动员、艺人、创业者、救援者等。
- 主角在资源、出身、身体、学历、记录或人脉上处于劣势，需要一次公开检验（比赛、评审、截稿、救援、投标、试镜）。
- 现有稿件有“训练—失败—再战—夺冠”的骨架，但缺规则、代价或对手逻辑。
- 需要检查“越界手段/导师代打/言情奖赏”是否把弧线写坏。
- 需要判断稿件里的“专家/权威/统计数字”是不是伪装的专业（走 R15）。

### 负触发（不要用本 Skill）
- 没有裁决机制的纯成长、纯言情、纯复仇、纯悬疑。
- 已成功人物的职业特写（如 PG23701 的画家素描）：可借鉴“能力细节”，但不是逆袭弧。
- 真实体育训练、医疗操作、法律诉讼的操作指南：本 Skill 只谈叙事，不提供现实建议。**PG717 里出现的自我用药剂量只能作为文本现象引用，不得转成任何现实用量建议。**
- 要求“保证爽感/保证夺冠”的商业定制：本 Skill 会要求写代价与失败可能，不服务无损登顶。

## 3. 核心概念
- **竞技场**：有裁决者、规则、资源门槛、退出代价的场域。没有裁决者 → 不是竞技弧，是职业成长。
- **裁决者**：不限于赛场评委。本批出现五类——赛场/评审委员会、编辑部、雇主委员会、名誉法庭（社交规范执法者）、资源分配者（分别见 PG6884、PG41154、PG17647、PG4645、PG64840）。
- **劣势**：可被第三方验证的资源/身份/身体/记录差距。可验证的事实优先；身份羞辱、社会压力、无形损失也可用情境证据表达。
- **公开检验**：主角能力被放到不可控的观众/权威前，结果同时可能证明或羞辱他。“公开”是**阈值**而非场地：同一行为私下被容忍、被看见一次就完了（PG6884）。
- **规则性失败**：由主角的具体判断/性格导致、可被后文修正的失败；不是纯陷害或纯运气。
- **误读型失败**（0.3.0 新增）：证据链已闭环但整体读错，必须预留一个可被外部记录复核的口子（PG17020）。
- **有代价结果**：胜利损失健康/关系/名誉/机会，或胜利被重新定义；本批次主证据无“无损登顶”。代价也可能是“职业性继续”——不被惩罚，只是降格使用（PG17020 L1693-1714）。

## 5. 最短执行路径（A 任务）
1. **写清裁决者类型**（R1/R13）：赛场评委／编辑部／雇主委员会／名誉法庭／资源分配者——先选一类，再写它按什么规则决定、拒绝的代价是什么。无外部裁决者则转职业成长路径。
2. **写劣势账本**（R2）：按具体资源、身份、健康/职业状态及记录困难列关键阻碍；可包括“职业资产被整体抵押”（PG6884 L2765-2766）与“嘴上理由和真实理由不一致”（PG41154 L5166-5169）。
3. **写技能训练四拍**（R3/R14）：致命错误的具体后果 → 单个动作分解 → 进阶环境 → 结业标志。可摘要跨过重复训练，不为配额编危险情节。
4. **写导师边界与受助者的拒绝权**（R4）：导师能提供什么、实际做了什么、承担何种责任；受助者知道自己拒绝了什么（PG6884 L4853-4856）。
5. **写对手/守门人的账本**（R5）：其利益、可支配资源、公开规则、实际行动；不强制对手胜局。
6. **写失败归因**（R6）：四栏——主角可控行为／外部或系统约束／尚无证据判因／**证据链闭环但误读**。只有第一栏写可学习的决策失败；第四栏必须留外部复核口。
7. **写公开检验与结果**（R7/R8）：写清实际评审与不受控变量；结果与报酬可以脱钩（PG717 L2521-2522）。
8. **过伦理关**（R9/R16）：越界后果三选一——制度惩罚／职业性继续／无后果继续——选一种并与故事已设制度自洽；不预设惩罚强度。
9. **过细节关与伪专家关**（R10/R15）：每个专业关键节点选必要且可靠的可见操作或事实；出现权威/统计/资质时核三部件。

## 8. 失败出口
- 写不出裁决者 → 不是竞技弧；改“职业成长/手艺展示”，不要硬造赛季。
- 没有真实赛制资料 → 只写职业场（评审/截稿/救援/委员会），不要编造排名、规则条款、训练数据。
- 无法判断裁决者类型 → 标 `TO_CONFIRM` 并把两种可能都列出，不暗中替作者选。
- 只有 STRUCTURAL 档案 → 只能做题材提示；不得生成 F 引文或“作者意图”。
- 证据冲突（越界后果强度、训练法、言情是否奖赏）→ 标 `UNRESOLVED`，在稿中保留开放性，不写成规则。
- 涉及体育赛制/青训/经纪/医疗/法律 → 标 `UNRESOLVED` 并另查权威资料，不得据小说推断。
- 真实作者未给稿件/反馈 → 本 Skill 只能做静态建议；GQ5=`NOT_PROVEN`，不得声称“真实任务已验证”。

## 9. 硬约束（FICTION_CASE）
- 本 Skill 的所有 F 都是**小说文本现象**，不是作者明示规则；人物做法（绑架、造假、殉道、把婚姻当配置、发假新闻）不得写成“作者认可”。
- 不编造行号、引文、章节名；不确定标 `UNVERIFIED`。
- 不把 PARTIAL 书说成全文；不把 STRUCTURAL 书说成已读；**不把“继承台账”说成“本轮实读”**。
- 不提供现实中的训练/医疗/法律/赛事操纵建议。
- **不得把单部小说的情节设计升格为所有作品都必须遵守的规则**：PG717 的严苛训练法、PG6884 的以酒殉情、PG17020 的假新闻、PG78245 的讽刺手法，都只在各自语境里成立，引用必须带边界说明。
- PG78245 通篇是讽刺，只作**识别信号与反例**，不得摘出任何一条当“职业应当如何”。
