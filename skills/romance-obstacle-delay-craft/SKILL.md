# 言情小说：障碍、误会与迟到的表白

本 Skill 把 18 部言情/爱情长篇（19 世纪至 20 世纪初，含 Hardy、George Eliot×2、Trollope×2、Cable、Howells、Stevenson、Lagerlöf、Burnett、Dell 等）里反复出现的机制，变成**可执行的诊断与改写动作**。它不是"言情套路清单"：本批材料里没有任何一条规则是"所有作品都必须遵守"的，冲突与例外写在 `references/conflicts-and-exceptions.md`，必须一起看。

## 1. 触发与负触发

**触发**（满足任一即进入）：
- 用户拿出一段恋爱关系场面，问"为什么写不动 / 为什么读者不信 / 为什么像套路"。
- 用户要让两个人分开或迟不表白，需要一个**站得住的障碍**。
- 用户写了误解、绯闻、名誉危机、拒绝求婚、牺牲成全，想知道下一步怎么走。
- 用户要求把一份单据、遗嘱、账目、婚约或流言写成推动关系的动作。

**负触发**（不要调用本 Skill，或只调用后立刻说明不适用）：
- 障碍来自**不可谈判的制度性暴力**（奴役、人身买卖、法律剥夺人格）：本批对此只有反例（PG2095），没有正向写法，见 `references/conflicts-and-exceptions.md` §1。
- 用户要的是**结局设计**：本批证据不足以支撑结局规则（PG380 未完成），见 §5 失败出口 E。
- 用户要的是纯粹的婚后家庭冲突、育儿或继母—女儿关系：本批只有旁证（PG76681、PG53864），不要用恋爱机制硬套。
- 用户没有给出任何具体文本或人物状态，只问"言情怎么写"：先要材料，不要凭空设计（§5 出口 A）。

## 2. 输入

- 必需：目标场面或章节（原文片段即可）、涉及的两个（或多个）人物、当前关系状态。
- 强烈建议：该场面里**每个人物不能说的义务**（承诺、债务、秘密委托）。
- 可选：作品的时代/法律环境（决定哪些障碍可谈判）。
- 区分三类身份并如实标注：**F**＝原文可核的来源观察｜**H**＝由观察推出的判断｜**P**＝建议执行的动作。不要把自己没核到的东西写成 F。

## 4. 执行步骤

1. **定位场面在链上的哪一环**：障碍 / 误会 / 清白危机 / 表白 / 牺牲。一幕可能同时占两环，先分开再判断耦合。
2. **查障碍的可执行性（R1）**：列出该障碍**改变了人物此刻能做的哪些具体事**。若看不出任何行为代价，提示“延迟表白的借口”；行动数量不是硬门槛，单一不可逆代价也可构成充分障碍。
3. **查误会结构（R2）**：确认误会至少分两层，且每层各自要付代价（行动、名誉、时间）。若只有一层，补一个"双方各自有不可透露的义务"（F：PG12280 L9413-9423、PG1214 L958-967）。
4. **查解套者（R3）与表白时点（R4）**：PG12280 的清白危机由有自身动机的第三方推动解决，但不能强制所有故事都必须付钱/回报或排除当事人自证；确认该故事的证据变化和时点理由。
5. **先做同意与安全判断**：若存在假工作机会、关闭出口、权力不对等下的婚约要求，按 `references/coercion-and-consent.md` 区分胁迫与自由选择，不把“婚约承诺”作为追求成功。
6. **交付改写**：按 §5 输出合同给出"最小改法 + 回归检查"，并明确写出哪些结论是 F、哪些是 H/P、哪些本批无法证明。

## 5. 输出合同

每次交付至少包含：

1. **定位**：这一幕落在链的哪一环（可多选）。
2. **判定**：逐条给出 R1–R6 的 PASS / FAIL / NOT_APPLICABLE，每条附"依据（来源 ID + 行号 + 它证明了什么）"。
3. **诊断**：指出问题所在的原文位置（行号或引文）、受影响的具体规则。
4. **最小改法**：不超过三处、可直接落到原稿的改动；不要重写全章。
5. **回归检查**：改完后要重新看哪一段（例如：改了障碍之后，表白场面是否还需要 R4 的那句话）。
6. **身份标注**：每条结论标 F / H / P。
7. **未决项**：本批无法证明的部分（见 §6）。

## 6. 失败出口

- **A 缺料**：没有原文片段或人物状态时，不设计障碍、不编造引文；只列出需要补的四项信息（场面、人物、关系状态、各人不可透露的义务）。
- **B 规则冲突**：不同作品给出相反结果（例如"迟到表白"在 PG12280 成立、在 PG59181 失败）时，不要强行统一；给出两条分支与各自的触发条件，交由使用者决定。
- **C 牺牲/道德账**：若要求写"成全对方"，必须同时写出受益者是谁（F：PG482 L731-753、PG12280 L11817-11820），否则判 FAIL 并给出反例。
- **D 出处查不到**：`references/source-index.md` 里查不到某条规则时，写 `SOURCE_INDEX_ROW_MISSING`，不要凭记忆补来源。
- **E 超出证据范围**：涉及结局规则、或障碍属于不可谈判的制度性暴力时，明确写 NOT_PROVEN 并停止给正向写法。
- **F 独立性提醒**：多个来源若出自同一部作品的不同章节，只算一份证据，不能当作多部作品的共识。
- **G 胁迫误读**：人物用虚假职业邀约将对方带入不可自由离开的私人空间，或用强迫婚约交换安全时，判定为胁迫情节，不写成正向追求；见 `references/coercion-and-consent.md`（PG59181 L9988-10200、L10839-10857）。
