# 冲突、例外与不适用（不要强行统一）

本文件列的是**本批材料里真的没有共识**的地方。遇到这些情形，必须把两条分支同时交给使用者，不要替他选，也不要说"综合来看……"。

## §1 障碍的可克服性：可谈判 vs 不可谈判

- **可谈判（本 Skill 适用）**：PG4969（限定继承，但女主角主张 L752-789"他继承产业并非自己造成"）、PG4599（嫁妆，L3194-3330）、PG12280（可被归还的产业与可重算的账目，L10320-10351、L11128-11159）、PG25727（贫穷被明说不是障碍，L439-472）。
- **不可谈判（本 Skill 不适用）**：PG2095 L284-292 把人的售价拆项计价，L538-549 写"上床时还属 Carr 先生，赌了一夜，今早不知属谁"。在这种情形下，沟通、牺牲、第三方解套都不构成解法。
- **判据**：先问"双方是否在同一法律/社会平面上拥有可执行的行动"。是 → 用 R1–R6；否 → 停止给正向写法，标注 NOT_PROVEN。

## §2 贫穷是不是障碍（真实冲突，不统一）

- PG25727 L439-472：作者直接写"在 Vagabondia，爱情不是面包黄油问题"，贫穷不构成障碍；危险的是女主角那种"真诚、尽兴、无所图谋"的坦率（L1251-1266）。
- PG16249 L938-1000：把缺乏经济独立的婚姻称作 "a legalized form of prostitution"（L987-988），并给出被供养者的对照（L1357-1395）。
- 两条都成立。**分支交给使用者**：若作品把"依赖"写成可被第三方定价的关系 → 贫穷是障碍；若写成共同的无产状态 → 不是障碍。

## §3 误解的来源不同 → 修法不同

- 来自**不可透露的义务**（PG12280 L9413-9423；PG1214 L958-967）：只能靠第三方行动修复（R3）；让两人谈话只会生成新一层（R2）。
- 来自**注意力错位**（PG1214 L958-967 男主复盘手术）：靠提供共享场景修复，不需要第三方。
- 判据：问"这两个人各自有什么**不能说的义务**"。答不出 → 误会只能靠愚蠢维持，判 FAIL。

## §4 迟到的表白：同一机制两种结局（保留冲突）

判据不是"迟不迟"，而是**求婚方是否解释了时点**、以及**是否把条件压价换成直接陈述**。两条分支都合法，由使用者按他要的效果选。

## §5 时间轴：婚前 vs 婚后（不做通则）

- PG361 L1-46：目录以婚礼开篇、以 "BY A BABY'S HAND" 收尾。
- PG53864 L233-277：主线是婚后育儿中的危机与和解。
- 其余作品张力在婚前或婚约期。
- 结论：本批**不支撑**"必须在婚前推进到订婚/结婚"；只要求"必须有等价的状态变化"（H，非 F）。

## §6 牺牲：本批的共识与它的边界

- 共识（唯一较强的一致）：牺牲不能只写成道德高地，必须交代受益者（PG482 L731-753 剪发无回报；PG12280 L11817-11820 归还即自救；L11062-11068 牺牲者自己也在核算）。
- 边界：这不构成"牺牲必然虚伪"的规则——PG12280 的归还在结果上确实救了对方；本 Skill 只要求**写出受益者是谁**。

## §7 明确 NOT_PROVEN 的部分

- 结局规则：PG380 未完成（题名即 AN UNFINISHED ROMANCE，L1-29），本批无足够样本。
- PG59181 的 **历史** L6001-12000 shard 台账不可信：91 条中 73 条行号错位，至少 16 条原文不存在（`Don’t go because I am here!` 在 L7804，原判为假阴性）。现已用 L6001-7200 的已验证台账以及本轮 L7201-12000 实读 16 块/16 引文 PASS 替代（2026-10-31 补齐 run 另有独立第二台账 8 块/16 引文 PASS 互为复核），相关规则仅取新证据，旧引用不采信。
- 方言转写的冒犯风险：本批只能证明它"被用来标记社会位置与信息缺口"（F），不能证明任何关于当代可接受性的结论（H）。

## §8 胁迫的知情性与自由同意

- PG59181 L9630-9704：画作售出被 Frances 当作赴伦敦工作的理由；L10839-10857：Montague 自承这是利用钱款制造依赖的谎言。
- PG59181 L9988-10200：她在以为是公共旅馆的场所被锁在私人房间里，明确要求离开，对方将离开与婚约捆绑。**被迫说出的婚约不等于自由同意**；不得当成普通的“迟到表白”或正向追求范例。
- PG59181 L10341-10590：Arthur 的暴力介入产生杀人危险；Frances 为保护生命说谎，使他误判她的意愿。两个危险事实应分开处理，不用一次救援洗白另一方的胁迫。
- 适用 F/H/P 与安全出口见 `coercion-and-consent.md`；这种复杂关系可被批判性描写，但不支持“控制越强爱情越深”一类通则。
