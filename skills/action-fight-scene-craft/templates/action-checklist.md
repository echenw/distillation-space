# 动作场面检查表（AC-01–AC-18）

用法：**开工前**填 A 组；**写完后**填 B 组；**回归时**只看 C 组。每行一个结论，不许合并。

---

## A 组：开工前（9 项）

| ID | 检查项 | 结论 |
|---|---|---|
| AC-01 | 场型：一对一 / 小队（伏击·追逃·突入）/ 群体（会战·溃退） | |
| AC-02 | 条件交付：谁在哪（相对位置，不是编制） | |
| AC-03 | 条件交付：唯一障碍或唯一出口是什么 | |
| AC-04 | 条件交付：双方还剩什么（弹药、马力、退路、人手） | |
| AC-05 | 这场戏的功能：证明代价 / 推进情节 / 展示性格 / 制造悬念 | |
| AC-06 | 主规则：选用哪一条 AF？为什么是它而不是相邻那条 | |
| AC-07 | 代价规则：这一下之后角色失去什么（伤、武器、关系、时间、名声） | |
| AC-08 | 视角与感官预算：POV 此刻能看/能听/能闻到什么，不能感知什么 | |
| AC-09 | 时代与技术约束：所有器械、通信、坐骑是否在设定的年代内可用 | |

---

## B 组：写完后（6 项）

| ID | 检查项 | 结论 |
|---|---|---|
| AC-10 | 每一次打击之后有没有写“读数”（对手的手/重心/距离变化），而不是连续动词堆叠 | |
| AC-11 | 有没有出现“抽象形容词代替身体细节”的地方（如“迅猛地 / 凌厉地 / 狠狠地”） | |
| AC-12 | 赢了之后有没有清场动作（压制、试探、问询），有没有诈死的可能性被处理 | |
| AC-13 | 伤口有没有三个坐标（入/出/失能后果）与一个处置动作 | |
| AC-14 | 武器/弹药计数有没有在结尾更新 | |
| AC-15 | 天助（巧合、外力、对手犯错）总共几次，每次有没有可见成本 | |

## C 组：回归（3 项）

| ID | 检查项 | 结论 |
|---|---|---|
| AC-16 | 读者能否用一句话说出“谁占上风、凭什么” | |
| AC-17 | 这一段是否能复述推进顺序（每两次切镜之间有一次可见的连锁因果） | |
| AC-18 | 是否出现了本 Skill 声明要转让的部分（现代武器细节、非虚构战史、影视镜头、真实格斗教学、纯 POV 声音设计） | |

若 AC-18 为“是”，停在本 Skill 边界外，明确转让，不要硬套。
