# 边界、未决冲突、硬排除与被否规则

## 1. 证据边界（超出即标 H / NOT_PROVEN）

## 2. 六组未决冲突（保留，不伪造共识）

1. **留活口 vs 先脱离威胁**
   - A：PG52141 H14“活体情报泵”——捕获或击杀前先过“关闭情报源”检查。
   - B：高风险近战的现实约束——留活口就是留下一把刀。
   - **分支**：目标当时的威胁等级决定。目标已失能且你有压制余裕 → A；仍在持械反抗或场上有第三方 → B。写进文本时要让读者看见你选了哪一支。

2. **宏观写物件 vs 微观写数字**
   - A：PG1059 H10“物证法写灾变”——禁伤亡总数，写具体物件。
   - B：PG14436 H9“工程官账本”——数字越多越可信。
   - **分层**：灾变面用 A（防通胀），军事程序用 B（质感）。两者层级不同，不可在同一段混用。

3. **喜剧能不能贴着动作发生**
   - A：PG1644 D3——残酷与喜剧严格分区。
   - B：PG10201——揪鼻子这种羞辱性动作被笑声卸掉火药，“动作—情绪—喜剧”三段位移。
   - **裁决**：结果可以喜剧化，过程不可以。

4. **死亡要不要给哀悼**
   - A：PG1644 H13——死亡反高潮，用静止画面收束，不给哀悼。
   - B：PG79716 H8——官方哀悼必须出现，冷漠本身就是内容。
   - **裁决**：喜剧/冒险系列用 A，严肃战争小说用 B。选哪支取决于作品类型，不是普适规律。

5. **信号与暴力的先后**
   - A：PG6015 H11“忠诚开关”——先信号（旗落/广播），后暴力。
   - B：PG1947——先侮辱升级（语言→掌掴→要求决斗），最后才是暴力。
   - **裁决**：群体转向用 A，个体恩怨用 B。同一部作品里两种都可以出现。

6. **战术原因 vs 机运（luck）**
   - A：PG52141 H1——决胜手必须是新装置或新信息。
   - B：来源自身大量依赖巧合（PG6015/PG11247/PG52141 的 D3 都承认 luck 过密）。
   - **裁决**：写作者可选，但必须记账——天助每本 1–2 次，每次可见成本。

## 4. 硬排除（红线）

1. **时代立场不可搬运**：来源含种族称谓、民族漫画、殖民视角、宗教敌意、性别工具化。**技法可吸收，语汇与立场一律 REFUSE。**
2. **伦理红线**：不得产出“以关怀话语降低他人戒心”的可操作步骤（PG79716 D2）。本 Skill 任何位置都不得提供此类规则。
3. **参数不可搬家**：骑兵冲锋、烽火信号、Very 手枪、火绳枪射程等皆属历史参数。迁移的是结构与心理，不是参数。
4. **不得把总结性统计当成 “Model True Input” 的证明**：证据是台账与行位，是“读到过”的证据，不是“全消费过”的证据。
