# Action & Fight Scene Craft（动作与打斗写法）

## 0. 这是什么

一个**人工诊断 + 条件判断 + 最小改写**的 workflow，不是自动引擎，也不生成招式。

- 输入：用户提供的真实文本、场次、大纲，或明确口述的场面设定。
- 输出：症状定位、选用哪条规则、按什么顺序改、改到什么程度算够，以及可选的**最小改写示例**（只在授权范围内）。
- 不做：不写整场打斗、不评分、不保证读者爽感、不自动改稿、不含 scripts、不教真实格斗或枪械操作。
- 不能替代：作者对暴力尺度的选择、编辑对市场的判断、真实的格斗/战术训练。

**证据底座一句话**：规则来自 82 部 1704–1950 年（主体 1880–1920）英语战争/冒险/历史小说的**阅读台账与证据卡**，其中 18 本被本轮深读并在原文核到行位，另 4 本做了定向扫描（有单点行位但未读透），其余 60 本只做了动作关键词扫描，其角色为“补充/未证明”，不作为规则主干。**19 世纪前的冷兵器与 1900 年前后的火器、海战、殖民地战争**是证据最厚的区域；**现代枪械、CQB、徒手格斗体系、影视动作编排零覆盖**，相关判断标 H / NOT_PROVEN。

## 1. 触发 / 负触发

**触发是给显式调用的路由，不是宿主自动加载。** 宿主是否加载由宿主决定；`agents/openai.yaml` 声明 `allow_implicit_invocation: false`。下列“满足任一”只用于**已经调用本 Skill 之后**的任务分流。

### 触发（满足任一）

- 写或改一场**近身格斗 / 决斗 / 白刃战**：不知道该写多少招、该停在哪、怎么写出“险”。
- 写或改**枪战 / 伏击 / 追逃**：视角该放哪、谁先开火、开火之后是什么。
- 写或改**会战 / 群体战斗 / 溃退**：怎么写规模而不写成数字堆，怎么写混乱而不写成看不清。
- 打斗读起来**像招式清单、像游戏日志、像动作电影分镜**，或**看完不知道谁在哪**。
- 打斗**没有后果**：打完就走、伤不结账、武器不消耗、情绪不换挡。
- 主角**太轻松**：每次都全身而退，读者不再担心。
- 要写**恐惧、怯懦、战后的闪回与失真记忆**，或要写**战斗被转述**的场面。
- 要判断**这个动作设计是否可信**（体能、武器、地形、时代是否对得上）。

### 负触发（不要用）

- **真实格斗/武术/枪械/CQB 教学**：本包是写作规则，不是技法或战术教材；任何“怎么打”都不作操作教学。
- **影视剧本、分镜、镜头设计、动作指导**：本包证据全是小说文本，没有镜头语言样本；只可作场面力学类比，标 H / NOT_PROVEN。
- **游戏关卡、战斗数值、技能树/命中率设计**：不属于本包接口。
- **非虚构战史、战役复盘、军事评论**：本包不做事实核验与因果论证；写真实战役请走非虚构流程。
- **现代（1945 年后）战术、特种作战、爆炸物与枪械操作细节**：证据窗口止于 1950 年前后，无来源，标 NOT_PROVEN。
- **时代立场与伦理判断的搬运**：来源作品含种族称谓、民族漫画、殖民视角与性别工具化，技法可吸收，**立场与语汇一律不带走**（见 §7 与 `references/scope-and-conflicts.md`）。
- **纯文字润色/校对/翻译**：句子与标点不在范围。
- **“帮我写一场打斗”且不给任何素材**：只能给检查清单与空白模板，不代编场面。

## 2. 输入权限

| 用户给了什么 | 可以做什么 | 不可以做什么 |
|---|---|---|
| 真实文本 + 明确范围（场/段/行） | 诊断、选规则、给最小改写 | 诊断未读部分；把推测写成文本事实 |
| 场次/大纲/口述设定 | 结构诊断与编排建议 | 假装读过正文；编造对白与细节 |
| 只有一句“这场打斗怎么写” | 给检查清单与模板 | 代写整场；声称“已帮你写好” |
| 明确授权改某段 | 在该段内做最小改写 | 越界改别的场、改结局、改视角 |

- **没有原文时**：只给检查清单与空白模板（`templates/action-checklist.md`），不虚构诊断。
- **不自动改稿**：默认输出“定位 + 规则 + 可选最小改写”；整场重写需用户明确范围与目标。
- **不覆盖原稿**：改写只在副本；原稿只读。

## 3. 任务路由

先判任务类型，再只读对应 reference；不要一次读完。

| 任务 | 首要 reference | 补读条件 | 缺输入时的出口 |
|---|---|---|---|
| **编排一场还没写的动作** | [rules.md](references/rules.md)（AF-01/02/03/04/05/09） | 群体 → AF-11/12；枪/夜 → AF-06；追逃 → AF-17 | 只给检查清单与空白模板；不代编场面 |
| **诊断已写的打斗** | [diagnosis.md](references/diagnosis.md) | 按症状查 rules.md 对应 AF；填 `templates/action-checklist.md` | 只给检查清单；不诊断未读文本 |
| **修订一场（改写/压缩/加大代价）** | [diagnosis.md](references/diagnosis.md) + [rules.md](references/rules.md) | 改后回归用 action-checklist | 只给定位与最小改写；不重写全章 |
| **不确定某技术细节是否可信** | [scope-and-conflicts.md](references/scope-and-conflicts.md) | 需要出处时查 [source-index.md](references/source-index.md) | 证据外直接标 H / NOT_PROVEN，不猜 |

**任务判据**：编排 = 还没有本稿；诊断 = 有已写文本，先证伪再判，**只输出严重度与最小验证动作，不改稿**；修订 = 已有诊断且用户给了改动范围，**做最小改动 + 回归检查**。

## 4. 最小工作流（3 步内开始）

1. **定场型**：一对一（决斗/格斗/对峙）｜小队（伏击/追逃/突入）｜群体（会战/溃退）。场型决定先读哪组规则。
2. **做一次“条件交付”检查**（AF-01）：读者在开始前是否知道①谁在哪 ②唯一障碍/出口是什么 ③双方还有什么武器/弹药。缺一项先补一项，不要先加招式。
3. **选一条主规则 + 一条代价规则**：主规则管“怎么写这一下”，代价规则管“这一下之后失去什么”。**没有代价规则的动作场面一律判不合格**。

输出形态：`定位（场/段/行） → 症状 → 选用 AF-xx → 最小改写（可选） → 回归检查项`。

## 5. 规则地图（18 条，正文在 rules.md）

| 组 | 规则 | 什么时候读 |
|---|---|---|
| 开场与空间 | AF-01 条件先于冲击、AF-02 一击之后的持戒、AF-11 连锁因果 | 任何战斗的开场；读者“看不清谁在哪” |
| 打击本身 | AF-03 白刃的力量学、AF-04 以险代伤、AF-05 生理细节替代形容词、AF-09 写伤给坐标 | 一对一/小规模；打斗像招式清单 |
| 视角与感官 | AF-06 听觉与声音反衬、AF-07 首枪非自主 | 夜战/林战/伏击；主角的恐惧写不出来 |
| 战后 | AF-08 清场与诈死、AF-10 武器是资产、AF-13 转述即失真 | 打完之后；后续情节要用到伤/尸/俘 |
| 规模与群体 | AF-11 连锁因果、AF-12 溃败用误判链、AF-18 反制回合制 | 会战、溃退、多单位协同 |
| 特殊壳体 | AF-14 荣誉对峙的第三选项、AF-15 喜剧与残酷分区、AF-16 领袖负伤与死亡位置、AF-17 声音倒计时与坏消息接力 | 决斗礼仪、喜剧动作、领袖之死、威胁与死讯 |

`rules.md` 是唯一权威版本；本入口只给地图。冲突与降级在 `scope-and-conflicts.md`；逐源行位在 `source-index.md`。

## 6. 输出合同

诊断/编排的输出至少含：①场型与范围；②症状或需求；③选用的 AF 编号与为什么；④**代价规则**（这一下之后失去什么）；⑤最小验证动作（怎么知道改好了）；⑥证据级别（F=有来源行位 / H=推断 / NOT_PROVEN=无来源）。

## 7. 失败 / 退出

| 情况 | 能做的 | 不能做 / 退回 |
|---|---|---|
| **材料不足**（无文本/只有一句设定） | 给检查清单 + 空白模板 | 不虚构诊断、不代编场面 |
| **目标冲突**（又要写实又要爽；又要短又要全） | 列两个方案 + 代价，让作者选 | 不平均、不偷偷替作者选 |
| **场型不适**（影视分镜/游戏关卡/非虚构战史/格斗教学） | 说明边界，转其他流程 | 不硬套小说规则 |
| **规则冲突未决**（留活口 vs 先脱离威胁；宏观写物件 vs 微观写数字） | 给分支条件与默认，标“未决” | 不合并成一条伪规则 |
| **证据范围外**（1945 年后、现代火器、徒手格斗体系、非西方武技） | 标 H / NOT_PROVEN，用通用力学问句 | 不假装有覆盖、不编样本 |
| **权限不足**（未授权改稿） | 只给定位与建议 | 不重写、不覆盖原稿 |
| **暴力尺度与伦理** | 只用“代价/后果/克制”三问处理 | 不产出“以降低他人戒心为目的”的可操作步骤；不搬运来源里的歧视语汇 |

**冲突时的默认顺序**（无硬约束时）：**读者能否定位谁在哪 > 动作是否有代价 > 可信（体能/武器/地形）> 节奏 > 文采**。

## 8. 证据边界与验证状态

- **时间**：1704（Defoe 系回忆录体）–1950；主体 1880–1920；**无 1945 年后的材料**。
- **语言/地域**：英语原文或英译；英、美、法、德、俄、西班牙；**无非西方一手材料**（殖民地题材全部是欧洲视角）。
- **类型**：战争小说、历史冒险、海军/骑兵/ frontier 小说、少年冒险、讽刺喜剧动作；**无武侠/仙侠/现代动作类型样本**。
- **来源类型**：全部为 **FICTION_CASE**（小说个案），无 METHOD（方法书）与 CRITICISM（批评）。因此所有规则都是**H（设计推断）**层级：不把“某本书这么写”说成“写作必须这么写”。
- **去重**：PG35926 与 PG69289 为同书异版，按 1 个来源族计。
- **验证状态**：本包为**静态交付**；真实作者任务本轮未运行（**NOT_RUN**），规则效果未证明（**NOT_PROVEN**）。没有 scripts、没有自动校验；所有表人工填写，结论可被作者/编辑推翻。
