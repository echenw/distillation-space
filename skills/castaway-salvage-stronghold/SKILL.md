# 落难・打捞・据点（Castaway Salvage & Stronghold）

## 1. 这个 Skill 解决什么
把"主角一直很惨"改造成"每一步都要重新算账"的可核查生存结构。核心不是堆灾难，而是让读者能回答四个问题：**现在有什么（清点）、怎么知道（计量）、据点凭什么守得住（工程）、下一次脱身靠什么被别人看见（信号与回执）**。

与同类 Skill 的分工：本 Skill 的强项是**清点建档、度量重建、据点工程与改制链、接触与信号载体**；若你要的是纯"威胁升级阶梯"或"士气/反讽"设计，同父类别的 `survival-crisis-escalation`（批次-03）更对口，两者可并用。

## 2. 触发 / 负触发
**触发**
- 设计或改写海难、荒岛、极地、内陆跋涉、疫病、城市灾变、文明级灾变、异星/外星落难类小说（长篇/短篇/章节群）。
- 诊断"落难后立刻就会过日子"（缺清点与计量）、"据点像无敌堡垒"、"打捞来的东西随用随有"、"求救靠巧合"、"群体一落难就自动有秩序"。
- 需要把生存写成工程问题（清点、改制、要塞化、水源与医学约束）或治理问题（配给、权威、异议、审判）。

**负触发**
- 真实应急、野外生存、医疗、救援操作建议（本 Skill 只谈叙事）。
- 纯冒险寻宝、纯战争、纯言情，且没有资源约束与伤亡代价的故事（此时只用 B02-R12/R13 的收束建议）。
- 要求引用本批次未读文本或超出证据底座的行号：拒绝编造，改引 `references/source-index.md` 的已读范围。

## 4. 体裁三分叉（先选这一类，参数完全不同）
| 体裁 | 账本单位 | 期限单位 | 主要失效模式 | 代表来源 |
|---|---|---|---|---|
| A 荒野/海难/极地/异星 | 人和工具、库存、水源 | 可观测环境信号（潮汐、雨季、进水速率、火山烟柱） | 容器与介质先坏、过度猎捕、季节窗口错过 | PG14917、PG21085、PG3702、PG63048 |
| B 城市/疫病灾变 | 户、街区、补给线 | 行政与物流（隔离期、供水干管、煤与电） | 制度性误报、机构容量被击穿 | PG11082、PG57904 |
| C 文明级灾变 | 知识、制度、语言 | 世代 | 知识失传、命名退化、权威断代 | PG11229、PG21970 |

选错分叉会导致规则互相打架：B/C 里套用"库存—耗率—期限"的荒野账本会失真（PG21970 的账本整体作废）。

## 6. 最短执行路径（默认 7 步）
1. **定体裁分叉**（A/B/C），写下账本单位与期限单位。
2. **清点建档**：在角色第一次必须做取舍之前完成清点与地形实测，且至少一项在中段被证伪（B02-R1）。
3. **重建度量**：无钟无秤时先造读数工具（天平、日晷、刻痕日历），再谈配给与排程（B02-R2）。
4. **立据点**：写清入口规则、弱点、后门与失守条件；后门必须可被对手反过来用（B02-R3、R4）。
5. **配改制链**：每件回收物 ≥2 种用途，其一延迟兑现，并写明哪一环最容易断（B02-R5、R6）。
6. **定接触与信号**：先定接触协议（试探/示强/第一枪），再定 ≥2 个有物理载体与回执的信号（B02-R7、R8）。
7. **立治理并收束**：任命、配给权、异议渠道、继任；结尾保留损失清单与后遗症（B02-R9、R10、R11、R12、R13）。

时间分配建议：清点 + 据点占设计时间的一半；改制链与信号是低成本高杠杆项，不要省。

## 7. 输出物表
| 输出 | 最小内容 | 验收（读者可核查） |
|---|---|---|
| 清点表 | 现有人/工具/库存/水源/医学项 + 误差来源 | 任取一项，读者能说出"少了它会先死在哪" |
| 度量重建方案 | 读数工具、单位、误差、被证伪处 | 时间/重量至少一次改变决策 |
| 据点规则卡 | 入口规则、弱点、后门、被谁反向利用、失守条件 | 攻防双方都能把规则当武器 |
| 改制链清单 | 每件回收物 ≥2 用途 + 明示失效点 | 失效点触发时情节不靠运气兜底 |
| 接触协议卡 | 试探方式、示强动作、允许开第一枪的条件 | 第一次接触场景可照卡演出 |
| 信号载体表 | ≥2 载体 + 射程/可见性论证 + 回执或延迟兑现 + 失败样例 | 获救不靠新信息，靠前文已存在的载体 |
| 治理规则卡 | 任命依据、配给权、异议渠道与代价、继任 | 权威更替不需要旁白解释 |
| 损失清单 | 不可逆损失 + 关系后遗症 + 被清零的社会身份 | 结局不是"全员获救即圆满" |

- 用户要求引用本批次未读文本或超出证据底座的行号：拒绝编造，改引 `source-index.md` 标注的已读范围。
- 故事不需要资源约束（纯言情/纯冒险）：只用 B02-R12/R13 的收束建议，不强行加清点表。
- 用户要求"每章都必须更惨"：先确认是否换掉了"所需能力"；同质加码会钝化（见 §10 冲突 1）。
- 冲突无法在本 Skill 内裁决时（如自我保存 vs. 种族保存）：**保留冲突并写出代价**，不要伪造共识。

## 10. 已知冲突（不得强行统一）
1. **自我保存 vs. 种族保存**：PG74142 行 328-329 明说自我保存只是"第二法则"；PG6014 走集体建村；PG1698 的集体以抽签吃人收场。三条路径都要保留。
2. **战略信息公开 vs. 保密**：PG6014/ PG21085 偏公开（换来程序正当性），PG1698/ PG63048 偏保密（换来短期秩序但积累爆发点）。二选一并写代价。
3. **英雄式求生 vs. 日常主义求生**：PG14917/PG63048 靠工程与战斗，PG35570/PG10859 靠重复家务。士气机制相反，不得混用。
4. **技术乐观 vs. 技术脆弱**：自制装置成功但作者常自嘲（PG3836 L7312-7316），且真空管会震碎（PG63048 L604-635）。唯一共识是"装置必须带明示失败点"。
5. **殖民视角**：PG54959 把岛民称"animals dressed in human skin"、PG54437 的赃物来自被掠船只。这类做法**不转成本 Skill 的正面规则**；采用时必须显式标注并写出道德代价。

**禁止**把单部小说的情节设计上升为通用规则：造筏撤离（PG35074 L5401-5468）只在该地形成立；每年升旗鸣炮（PG74418 行 287-297）是十年期据点产物；抽签（PG1698 行 4961）是配给彻底崩溃后的极端形态。
