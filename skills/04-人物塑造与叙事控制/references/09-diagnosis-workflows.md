# 人物与叙事诊断工作流

## 先定位问题层

无正文时根据已给设定提供原创候选，写明新增设定；有正文时定位已读版本和段落。分别记录文本事实、人物说法、叙述者断言、旁人猜测。仅在解释确实有竞争时列 H1/H2，不为凑数发明反说。锁定设定互斥时保留分支，只暂停依赖冲突的改动。

规划：自主目标 → 信息与资源 → 可见选择 → 他人回应 → 后果和未决。诊断：定位 → K0 或动作表 → 条件规则 → 反例 → 最小修订。改写：按用户已授权范围给实际文本 → 与相邻段回归。作者的形式选择可保留，不用“正确视角”统一其风格。

## 三项回归

这是谁的经验与解释？新增修辞改变了什么可理解的行动？去掉诊断性标签后，人物的处境、选择和影响是否仍成立？另核知情时间、物件地点与所有权、关系连续性、作者硬设定和时代词汇归属。

历史“缺主体就不可诊断”仅适用于重新选全书主体，不能阻塞局部视角修复。PD-01–10 与 C09 修订单已纳入工作簿；未经执行不写 STATIC_PASS，更不能写真实宿主或读者效果 PASS。
