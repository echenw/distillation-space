# 场景、概述与时间（PV-12 至 PV-15、PV-17）

返回 [SKILL.md](../SKILL.md)。来源行号见 [source-index.md](source-index.md)。

## 1. 四个词

- **场景**：选定一个时刻和地点，读者直接看、直接听；不压缩时间和空间。
- **概述（全景）**：从高处扫过一段时间或一片生活，必然压缩。
- **图画**：材料经过某个心灵的反映呈现给读者；读者面向讲述者。
- **戏剧**：材料自己演出来；读者面向故事。

这组词来自 Henry James，Lubbock 扩展了它们的含义。不要和电影术语直接等同。

## 2. 场景的限制和正职（PV-12）

Lubbock：场景里不能压缩时间和空间，它展示它所占据的全部时间和空间。由此有三个后果：

1. **贵**：场景演得鲜明，但按长度算演得慢。
2. **不能自己建立自己**：没有预备的场景要一边建立一边兑现，力量被浪费。
3. **有上限**：背景、时代、群体，没法全靠场景承载；连纯戏剧的典范《尴尬年代》，Lubbock 也承认这种书极少，背景很难用纯戏剧撑起来。

场景的正职：了结一件已经悬着的事，展示一个结果，给一个用别的手段做了一半的效果加冕。所以进场景之前：
- 冲突已经明确；
- 赌注已经立起来；
- 读者在等一个结果。

场景里让结果发生，并留下一个不可逆的细节。

场景是全书的关节。Lubbock 举《包法利夫人》：舞会、农展会、剧院之夜、鲁昂大教堂的会面、临终，这些场景就是全书结构的骨架，每一场完成一个阶段并打开下一个阶段。场景放在“一切已经备好”的地方，位置比数量重要。

## 3. 概述的三种正职（PV-13）

1. **蓄势**：巴尔扎克式的预备图画，为后面的戏剧储备人物、环境和时间。
2. **压缩**：跨年、跨地、群体的反应。
3. **定语气**：全景本身可以是一种看法。Lubbock 说萨克雷是“生活的画家”，人物、行动、背景都融在一片长长的回顾视野里。

判断：这段概述在做场景做不了的事吗？不是，就删，或者改成场景。

戏剧的经济：Lubbock 说戏剧是小说家的最高光，在不需要的地方挥霍它，就削弱了它在必要之处的力量。做法：
1. 列出全书必须兑现的少数时刻（中篇三五处，长篇按卷或单元各列几处）。
2. 其余时刻用概述、对话摘要、侧写。
3. 一个场景只承担一个主功能，不要在同一场里既介绍新世界又解决旧冲突。

不同主体的倾向（方向，不是比例）：

| 主体 | 场景 | 概述 |
|---|---|---|
| 强情节、悬疑 | 承担大部分篇幅，负责兑现 | 只做过渡和时间 |
| 心理和认知变化 | 兑现转折 | 承载时间和反思 |
| 群像、世代 | 做关节 | 全景为主 |
| 纯戏剧的实验 | 几乎全部 | 极少；背景会变薄 |

## 4. 跨越时间（PV-14）

Lubbock：要表现的是时间的形式，这比按顺序表现时间里的内容更多。他反对的是一排星号加一句没有依托的宣告：“几年过去了。”

两种时间效果：
- **流逝**：日子一天天过去，人在变。靠日常质地、重复、物件磨损、身体变化承载。
- **周期**：一代人兴起、衰老、让位。靠结构承载（开场和终场的对照）。Lubbock 认为托尔斯泰把流逝写到了极致，却没有把周期做成全书的形式。

做法：
1. **建质地**：跨越之前，写一段“日子怎么过”的具体生活：房间、作息、季节、重复的动作。
2. **给锚点**：一个以后能回收的物件、习惯或身体细节。
3. **跨越**：一句话（“五年就这样过去了”）。
4. **给变化**：紧接一个具体细节，证明时间真的过去了：同一个物件磨旧了，同一个动作慢了。

巴尔扎克在《欧也妮·葛朗台》里先用大段篇幅建立葛朗台家的日常，之后“五年就这样过去了”才成立。没有前面的质地，这句话就是 Lubbock 所斥的宣告。

检查：读者能不能说出“这段时间她是怎么过的”。说不出，就是跨越失败。

## 5. 叙述的时间距离（PV-15）

- **第一人称回忆**：视点固定，时间也被回忆的距离固定。叙述者已经知道结局，要说明为什么现在讲，以及讲的时候瞒不瞒结局。
- **第三人称限知**：视点固定在人物身上，但在时间上是自由的。可以写“当时”，也可以写“多年以后她才明白”。
- **书信和日记**：Richardson 写《克拉丽莎》，不想把她的激动推进过去、当成历史来处理，所以让叙述停在当下；读者和人物一样不知道明天。

用法：
- 要拉开距离，用“后来她才明白”“多年以后”之类的标记，每个标记都要带具体内容。
- 要压强，把叙述压到当下，删掉所有“后来”。
- “后来她才知道……”是一次提前揭示，会消耗悬念。用前先确认这个信息提前给出是有意的（见 `foreshadowing-and-rhythm`）。

## 6. 世界的边界（PV-17）

Lubbock：这完全取决于故事本身的性质。

- **开放**（托尔斯泰）：人物活在“我们的世界”里，主线之外的生活在继续。
- **封闭**（陀思妥耶夫斯基）：黑暗切断了外面，光全部打在意识的剧场上。

做法：
1. 主体需要连续性还是压强？
2. 开放：给少量与主线无关但真实的生活细节，起点是三处左右，不要多到稀释主线。
3. 封闭：把边界变成压力（谁进不来、什么出不去），而不是只是不写外面。

开放的世界放在悬疑、密室、心理压强类故事里会泄气；封闭的世界放在世代、时代类故事里会显得假。

## 7. 时间跨度速查

| 跨度 | 主要工具 | 风险 |
|---|---|---|
| 几天 | 场景为主，少量概述 | 场景太密会拖 |
| 几个月 | 场景加季节过渡 | 过渡全靠“天气”会俗 |
| 几年 | 质地图画加一句跨越 | 直接跳年，读者对时间无感 |
| 几代 | 周期结构（开场和终场对照）加代际视点 | 中段容易散，需要一个贯穿的物件或地方 |

## 8. 自检

- 每个场景都标得出功能；铺垫类场景已经压成概述或并入别的场景。
- 高潮场景只做最后一击，不承担新设定。
- 每个跨越点都有质地锚和变化锚。
- 没有用“某年过去”直接开新章，除非前文已经写了日子。
- 时间跨度和场景密度匹配：跨度越大，概述越多。
- 世界边界和主体一致：开放不稀释，封闭不虚假。
