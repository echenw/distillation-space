# 诊断、修改单与例外

返回 [SKILL.md](../SKILL.md)。来源行号见 [source-index.md](source-index.md)。

## 1. 诊断顺序

1. **范围**：读了哪些章节，没读哪些。只对读过的部分下结论。
2. **主体**（PV-01）：作者能用一句话说清吗？不能，先修主体，不做视角手术。
3. **视点**（PV-02、PV-03）：谁在看？凭什么知道？读者知道此刻谁在看吗？
4. **合同**（PV-04、PV-05）：有没有越界？切换有没有收益和标记？
5. **信息**（PV-09 至 PV-11）：每一幕人物和读者各知道什么？揭示公平吗？
6. **场景与概述**（PV-12、PV-13）：场景在铺垫还是在兑现？概述在做场景做不了的事吗？
7. **时间**（PV-14、PV-15）：跨越前写了日子吗？
8. **世界边界**（PV-17）：和主体匹配吗？

只有构思、没有稿子时，不做“第几段有问题”的诊断，改做设计（SKILL.md §3 的选视角路径），并说明哪些判断要等有了稿子才能确认。

## 2. 十种症状

**S1 读者不知道谁在看**
- 原因：无名全知没有人格；章内视角漂移；段首没有感知锚。
- 改法：写出叙述者的位置（PV-04）；固定一个聚焦者；在段首给感知锚（“她听见……”）。

**S2 切换很晕**
- 原因：切换不买回东西；切得太频繁；切在场景中间。
- 改法：每次切换写触发和收益，删掉纯交代性的切换，切换放到断点（PV-05）。

**S3 主角内心很平**
- 原因：用报告代替演出；第一人称承担了自我剖析。
- 改法：把“她感到”改成可见的判断过程，每段内心配一个外部征候（PV-08）；重心在叙述者自身的变化时，考虑改为第三人称限知（PV-03）。

**S4 反转不成立，读者觉得被耍**
- 原因：双盲的惊奇没有线索；叙述者进了心却装不知道；前文没有公平线索。
- 改法：换不知情的叙述者，或补不可靠的证据（PV-09、PV-10）；前文放一两处可回看的线索；揭示后让一两处旧场景改变意义（information-control §7）。

**S5 中段拖**
- 原因：场景在做铺垫；概述没有信息；时间靠宣告。
- 改法：铺垫类场景压成概述；每个场景标功能；跨越前补质地（PV-12、PV-14）。

**S6 高潮没劲**
- 原因：高潮同时在建立和解决；需要的视点或信息没提前就位；前面把戏剧用光了。
- 改法：把钥匙提前放进前文；高潮只做最后一击；删掉中段不必要的场景，把最重的场景留给高潮（PV-16、PV-13）。

**S7 世界很薄**
- 原因：封闭过度；聚焦者看不懂世界又没补光。
- 改法：开放型给少量主线外的生活；或补光、加第二视点（PV-17、PV-06）。

**S8 人物变老像换人**
- 原因：时间只有宣告，没有质地；变化没有锚点。
- 改法：跨越前写日常循环；跨越后用同一个物件或动作的变化证明时间（PV-14）。

**S9 结尾收不住**
- 原因：叙述者的位置悬在书外；结尾引入新信息。
- 改法：结尾需要的视点和信息提前就位（PV-16）；让结尾回到书内的某个眼睛（PV-04）。

**S10 全书像大纲**
- 原因：全是概述，没有兑现的场景；场景没有“已经备好的势”。
- 改法：选出几个必须兑现的时刻，写成完整场景；其余概述加判断和意象（PV-12、PV-13）。

## 3. 修改单示例

| 位置 | 症状 | 原因 | 规则 | 改法 | 代价 |
|---|---|---|---|---|---|
| 第 4 章第 3 段 | 越界：写了“他不知道她早已原谅” | 女主视点里写男主内心 | PV-04 | 改为女主看见的征候：“他把她的杯子洗干净，放回了原处” | 原句的确定性没了，读者要自己判断 |
| 第 7 章 | 切到反派只为交代“他派了人去码头” | 切换没有别的收益 | PV-05 | 改为主角在码头看见反派的手下 | 主角要提前出现在码头，需要一个理由 |
| 第 12 章开头 | “三年后”直接开章，人物像换了人 | 跨越前没有日子 | PV-14 | 第 11 章末补一段铺子里的日常，第 12 章首写同一把算盘磨亮了 | 第 11 章变长 |

“代价”一栏必须写。

## 4. 只能做一件事时

| 想要 | 做什么 |
|---|---|
| 让读者进入 | 固定一个聚焦者，删掉章内漂移 |
| 让读者紧张 | 让读者知道得比人物多（读者在前） |
| 让读者好奇 | 让读者知道得比人物少，但线索公平 |
| 让读者震惊 | 双盲加可回看的线索（风险最高） |
| 让时间过去 | 先写日子，再写“五年后” |
| 让高潮有力 | 高潮前把钥匙放在明处，当时看起来像杂物 |
| 让世界可信 | 给三处左右与主线无关的生活 |

## 5. 规则的例外

这些例外来自来源本身，用来防止把默认值当成禁令。

| 默认 | 例外 | 处理 |
|---|---|---|
| 少用无名全知（PV-04） | Lubbock 承认萨克雷的魅力能让读者忘掉缺陷，叙述者的人格足够强时全知是合法选择 | 保留全知时，说明代价：书不自足，重读会变薄 |
| 少换视点（PV-05） | Lubbock 称赞《安娜·卡列尼娜》几乎人人都是视点中心；Forster 认为《荒凉山庄》《战争与和平》频繁切换也成立 | 群像和史诗放宽，但主线结构要简单，每次切换仍要有收益 |
| 不用“几年过去了”（PV-14） | 巴尔扎克用“五年就这样过去了”成功 | 关键在前面的质地，不是禁这句话 |
| 第一人称不剖析自己（PV-03） | 自我暴露是主题时（《巴里·林登》），局限就是效果 | 默认值，不是禁令。注意 Lubbock 对《简·爱》的态度相反：他在那里既看不出用第一人称的理由，也看不出效果，只是不忍深究 |
| 戏剧化是最高的方法 | Lubbock 自己承认《尴尬年代》这样的纯戏剧之作极少，纯戏剧难以承载背景 | 本 skill 不采纳“越戏剧化越好”的进步论 |
| 叙述者不现身 | 1926 年的选本里仍有第一人称叙述者公开对读者说话（“我把他们谈话的要点告诉你”） | 允许，但要说清叙述者的位置和可靠性 |

## 6. 作者坚持时

| 情形 | 处理 |
|---|---|
| 要写全知插话、元叙事、说书体 | 不纠正趣味。说明代价（视点悬在书外、重读变薄），给替代（人格化的叙述者、框架、说书人身份写进书里），由作者决定 |
| 写的是快节奏类型 | 侧写（PV-11）和时间铺垫（PV-14）缩短；优先场景兑现（PV-12）和知识表（PV-09） |
| 写的是群像或史诗 | PV-02、PV-05 的多中心条款优先，但每一章仍要有明确的聚焦者 |
| “受限”或“不可靠”就是主题 | 不补光（PV-06），改用反讽距离（PV-07）和不可靠叙述的证据（PV-10） |
| 规则和作者的直觉冲突 | 回到主体（PV-01）。规则是诊断工具，不是法令 |
| 证据不够 | 写明“无法判断”和缺什么（缺哪几章、缺作者的结局设想），不要猜 |

## 7. 误用本 skill

| 误用 | 后果 | 纠正 |
|---|---|---|
| 为凑一句主体砍掉复调 | 合法的多主体结构被压扁，人物变成主题的传声筒 | 复调时说清几条线为什么必须并置（PV-01） |
| 视角洁癖：每章只许一个视角，越界一律删 | 世界变薄，作者被迫用生硬的对话塞信息 | 补光和第二视点是合法的（PV-06） |
| 场景崇拜：把概述全改成场景 | 时间压不动，背景撑不起，节奏拖 | 场景只做兑现，铺垫和跨越交给概述（PV-12、PV-13） |
| 反转靠藏 | 读者觉得被耍，重读价值没了 | 用合法的隐瞒方式（PV-09） |
| 侧写过度 | 读者疲惫，情感冲击被拖散 | 两三个侧影就点破（PV-11） |
| 把第三人称限知当高级 | 所有书往一个模子改，作者的声音被抹平 | 方法由主体决定（PV-01） |
| 把本 skill 当研究结论 | “研究证明第三人称限知最好”是伪共识 | 这些是 1901–1927 年手艺书的经验，不是实验结论 |
| 忽略类型契约 | 文学性规则压过类型承诺，读者弃书 | 类型契约优先（SKILL.md §7） |
| 诊断跳步 | 主体没定就改视角，反复返工 | 按 §1 的顺序 |

## 8. 不在本 skill 里诊断

- 作者还没决定主体：先做 PV-01，不做视角手术。
- 问题其实是人物动机不可信、情节因果断裂：转 `plot-architecture` 或 `fiction-craft`。
- 问题其实是句子和语感：转 `style-refinement-and-proofreading`。
- 伏笔和节奏的问题：转 `foreshadowing-and-rhythm`。
