# 叙事视角与信息控制

管四件事：**谁在讲、从谁的眼睛看**（叙述者与视点），**读者和人物各知道什么、什么时候知道**（信息控制），**哪些时刻演出来、哪些一笔带过**（场景与概述），**读者怎样感到时间在走**（时间与尺度）。

## 1. 适用与转介

用：
- 开新书或重构：选叙述者、主视点人物、人称、多视角方案。
- 写或改一场戏：守住这一场的视角，决定写谁的内心、写到多深。
- 设计反转、误会、秘密、悲剧反讽、不可靠叙述：决定谁知道、读者知道什么，怎样瞒而不作弊。
- 稿子有这些症状：不知道谁在看、视角越界、切换晕、内心像报告、世界很薄、反转像作弊、全书像大纲、场景拖、跳年无感、人物变老像换人。

转给别的 skill：
- 伏笔怎么埋、怎么回收，悬念强度、章末钩子、松紧节奏 → `foreshadowing-and-rhythm`。本 skill 只决定“谁知道、谁能看见”。
- 主线、多线、因果、删场 → `plot-architecture`；卷级和全书的连载规划 → `serialized-volume-planning`。
- 句子、对白、标点、语感 → `style-refinement-and-proofreading`。
- 从构思到修订的全流程 → `fiction-craft`。
- 人物动机和弧光：本 skill 只管从哪里看人物，不判断人物写得是否可信。

## 2. 使用方式

- 宿主任务规定了输出格式时按宿主格式交付；§6 的格式只在没有规定时使用。
- 普通任务读完本文件就能做。需要细则、例子和例外时，用 `skill.read` 读 §8 列出的参考文件。
- 给了稿子就按稿子诊断，指出具体位置（章节、段落、短引文，不整段复制）；只有构思就做设计；要求写正文就写，交付时用一两句说明视点和距离的选择。
- 缺关键信息（比如主视点人物没定）时，先给一个合理的假设往下做，并标明“假设”；只有答案会彻底改变方案时才问，一次不超过三个问题。
- 本文件的数字都是起点，不是门槛。类型、篇幅、平台习惯不同，就按实际调整。
- 规则是检查工具，不是品味标准。作者坚持某种写法时，说清代价和替代办法，由作者决定。

## 3. 四条最短路径

### 选视角（开新书或重构）

1. **一句话主体**（PV-01）：谁、在什么处境里、发生了什么变化。说不清就先收拢主体，不急着选视角。
2. **视点中心**（PV-02）：列两到四个候选人物，选“他的经验就是这本书的主体”的那个，不是戏份最多的那个。
3. **叙述位置**（PV-03）：先定叙述者站在哪里、凭什么知道，再定第几人称。
4. **视角合同**（PV-04）：写清能知道什么、不能知道什么、能进谁的意识。
5. **多视角时建切换账本**（PV-05）：每个额外视点写明它买回了什么。
6. 交付视角方案卡（§6）。

### 设计信息（反转、误会、秘密）

1. **画知识表**（PV-09）：每个关键信息，谁知道、读者知道吗、什么时候揭示。
2. **选合法的瞒法**（PV-09、PV-10）：换叙述者、限制视域、不可靠叙述者、时间错位、暂时关上聚焦者的意识。叙述者已经进了某人的内心，就不能再替他藏关键念头。
3. **揭示**（PV-11）：深层事实先侧写、后点破；高潮需要的那只眼睛提前就位（PV-16）。
4. 伏笔的位置和回收清单，接着用 `foreshadowing-and-rhythm`。

### 写或改一场戏

1. **这场谁在看**（PV-05）：起点是一场一个视点；要换，就放在场景断点。
2. **这场能写什么**（PV-04）：只写视点人物能看到、听到、知道、推断的东西。
3. **这场是兑现还是铺垫**（PV-12、PV-13）：兑现的写成场景；铺垫和跨越用概述。
4. **内心演出来**（PV-08）：用他的注意、判断、动作和措辞代替“他感到”；距离一场之内保持稳定（PV-07）。
5. 交付时说明视点、距离和省略了什么。

### 诊断稿子

按这个顺序，不跳步：主体 → 视点 → 合同 → 信息 → 场景与概述 → 时间 → 世界边界。前一步有问题，先修前一步；主体没定时做视角手术，只会反复返工。对症状用 §4，修改单格式见 §6。

## 4. 症状速查

| 症状 | 常见原因 | 先看 |
|---|---|---|
| 读者不知道谁在看 | 无名全知没有人格；章内视角漂移；段首没有感知锚 | PV-04、PV-05 |
| 视角越界（写出了视点人物不可能知道的事） | 没有合同；为了交代信息临时“借脑” | PV-04 |
| 切换很晕 | 切换不买回东西；切在场景中间；没有标记 | PV-05 |
| 主角内心很平 | 用报告代替演出；第一人称承担了自我剖析 | PV-08、PV-03 |
| 世界很薄、人物活在真空里 | 聚焦者看不懂世界又没补光；世界过度封闭 | PV-06、PV-17 |
| 叙述完全被人物语气吞没 | 没有反讽距离 | PV-07 |
| 反转像作弊、读者觉得被耍 | 叙述者进了心却装不知道；前文没有可回看的线索 | PV-09、PV-10、PV-11 |
| 一揭秘就平了 | 直接说出事实，没有侧写 | PV-11 |
| 场景拖、像流水账 | 场景在做铺垫工作；一场承担了几个功能 | PV-12 |
| 全书像大纲 | 全是概述，没有兑现的场景 | PV-12、PV-13 |
| 中段跳读 | 概述没有信息也没有语气 | PV-13 |
| 跳年无感、人物变老像换人 | 跨越前没有生活质地，跨越后没有变化细节 | PV-14 |
| 高潮少了关键的一眼 | 高潮需要的视点或信息没提前就位 | PV-16 |
| 结尾收不住 | 叙述者的位置悬在书外；结尾引入新信息 | PV-04、PV-16 |

## 5. 规则卡

每条：规则 → 做法 → 起点与例外 → 来源（行号见 `references/source-index.md`）。

### 叙述者与视点

**PV-01 先说主体，再选方法**
- 做法：用一句话说出谁、在什么处境、发生了什么变化。再判断重心在哪里：一个人的意识里、一个群体或时代里、一个待解的问题里。重心决定后面的选择。
- 例外：真正的复调（几条线并置本身就是主题）不压成一句，改为说清“这几条线为什么必须放在一起”。Lubbock 的“十个词”是修辞，不是字数限制。
- 来源：Lubbock。

**PV-02 视点中心选“经验即主体”的人**
- 做法：列两到四个候选，各写一句“由他看，读者多知道什么、少知道什么”。选那个“他的经验就是这本书的主体”的人，记下放弃其他人的损失。主体是“一个人和环境的对抗”时，优先选被挤压的一方。
- 例外：群像和史诗可以多中心，但读者始终要知道“此刻谁在看”。
- 来源：Lubbock（《包法利夫人》的主体在爱玛的经验里，不在她周围的事实里）。

**PV-03 先定叙述位置，再定人称**
- 做法：问叙述者站在哪里、凭什么知道、局限是什么。五种常用位置：无名全知、书中人物讲述、第一人称限知、第三人称限知、纯场景（只看得见、听得见）。人称只是位置的实现方式。
- 第一人称的默认限制：它很难把叙述者自己客观化，故事重心是叙述者本人的意识变化时，只能报告、不能演出，改用第三人称限知通常更好；主角可能死掉、需要几个人的内心时也不适合。
- 例外：“自我欺骗、自我暴露”本身是主题时，第一人称的局限正是效果（Lubbock 举《巴里·林登》）。
- 来源：Lubbock；Hoffman 编《Fiction Writers on Fiction Writing》中 Cain 的意见。

**PV-04 视角合同：能知道什么，不能知道什么**
- 做法：写三层。第一层，能不能知道：视点人物没看到、没听到、推不出来的事不写，包括别人的内心、远处同时发生的事、还没发生的结局、他不认识的东西的名字。第二层，距离（PV-07）。第三层，故意切换（PV-05）。不要用第三层的“切换自由”掩盖第一层的越界。
- 叙述者的位置要放进书里：第一人称、限知人物、书信日记文件、框架叙述者，都给出“他是谁、在哪、凭什么知道”。保留无名全知时，叙述的语气要有足够强的人格，让读者愿意听。
- 来源：Lubbock；Wharton；佚名《How to Write a Novel》（只写站在那个位置看得见的东西）。

**PV-05 每次切换都要买回东西**
- 做法：起点是一场一个视点，换视点放在场景或章节断点，并给出标记。每次切换记四项：触发（当前视点人物不可能知道或无法反应）、收益（单一视点拿不到的信息、判断、反讽或对照）、标记（分隔、章题、首句的感知锚）、代价（读者要重新定向、认同转移）。只为传一句信息的切换，改回原视点，用目击、听说、推断、文件让信息出现。
- 起点：短篇默认一个视点；长篇两到三个主视点；群像和史诗可以更多，前提是主线结构足够简单清楚。
- 例外：Tolstoy 在一场之内自由进出多人意识也不乱，是用主线的简单换来的自由；Forster 认为只要作者有能力把读者“弹”进去，频繁切换也能成立。即使放宽，每次切换仍要有收益。
- 来源：Lubbock；Wharton；Dowst；Hamilton；Forster。

**PV-06 限知补光只加目力，不加事实**
- 做法：聚焦者太笨、太小、太陌生，讲不全必要的世界时，先判断“受限”是不是主题。是，就不补光，改用反讽距离（PV-07）。不是，就补光：作者和聚焦者站在同一个位置，只把观察写得更准；或者加一个第二视点、一份文件、一段证词，承担他看不懂的部分。
- 边界：补光不能写进聚焦者不可能知道的事实。补多了，读者会感到“有人在替她说话”，限知就变成了全知。
- 来源：Lubbock（“眼睛后面有两个脑子”）。

**PV-07 距离要稳定，变化要重新锚定**
- 做法：给每场定一个叙述距离：贴身（用人物的词和语气）、中距、远距（叙述者的词）。一场之内保持稳定，变化的地方写清为什么变。要让读者的判断高于人物，就保留人物的措辞，不评论，在段落收束处放一个事实性细节，或者让另一个人物的反应映出她。
- 边界：距离太大，变成作者嘲笑人物，读者不再投入。
- 来源：Lubbock（福楼拜让爱玛始终保持在一定距离之外）；Wharton（视点人物的语域之外的东西不记录）。

**PV-08 把意识演出来，不要报告意识**
- 做法：把“她感到震惊”“他慢慢想通了”改成读者看得见的判断过程：她注意到什么、停在哪里、怎么误判、做了什么、换了什么说法。每段内心至少配一个外部可见的征候。
- 还可以暂时关上聚焦者的意识：只写他做什么、说什么，让他像其他人物一样被看。要整场一致地关，不能写到半句想法再截断。
- 来源：Lubbock（“看他在想，而不是收他的报告”；能演的地方不述）。

### 信息控制

**PV-09 合法地瞒：进了谁的心，就不能替他藏**
- 做法：先画知识表（每个关键信息：谁知道、读者知道吗、什么时候揭示、揭示后改变什么）。需要隐瞒时，选合法的方式：换一个不知情的叙述者；限制视域（他不在场就看不到）；不可靠叙述者（PV-10）；时间错位（回忆者选择按“当时不知道”来讲）；暂时关上聚焦者的意识（PV-08）。
- 读者可以比视点人物知道得多：限知不等于读者和人物同知，读者站在更好的位置上看懂人物，是反讽和紧张的来源。
- 边界：要瞒住凶手是谁，凶手就不能当视点人物：一旦进了他的心，就得全说。悬念的三种方式（悬疑、反讽、惊奇）怎么选，见 `foreshadowing-and-rhythm` 的 SU-04。
- 来源：Lubbock。

**PV-10 不可靠叙述要留下证据**
- 做法：书内给出叙述者不可靠的证据：前后矛盾、他人的反应、物证、他自己说漏的细节。结尾不靠作者突然宣布来揭穿，重读时能找到这些证据。
- 来源：Lubbock（《巴里·林登》的要点就是让叙述者不知不觉暴露自己）。

**PV-11 深层事实先侧写，后点破**
- 做法：病情、背叛、爱意、身份这类事实，先给几个侧影（她以为没人看见时的样子、一处解释不通的停顿、一个被回避的话题），然后回到日常表面，只留微小的扰动；最后用一句话点破，由人物的动作或对话触发，不用作者总结。
- 起点：两三个侧影。篇幅长、事实分量重时可以多；快节奏的类型压缩到一两个，或者直接给出。
- 来源：Lubbock（Henry James《鸽翼》：不径直走向事实，而是环绕它）。

### 场景、概述与时间

**PV-12 场景用来兑现**
- 做法：给每个场景标功能：铺垫、推进、兑现。进场景之前，冲突已明、赌注已立、读者在等一个结果；场景让结果发生，并留下一个不可逆的细节。铺垫类场景压成概述，或并入前一场。一场只承担一个主功能。
- 原因：场景不能压缩时间和空间，按长度算它很慢；没有预备的场景要一边建立一边兑现，力量被浪费。重要场景是全书的关节，位置比数量重要。
- 来源：Lubbock。

**PV-13 概述有三种正职**
- 做法：概述用来蓄势（为后面的场景准备人物、环境、时间）、压缩（跨年、跨地、群体反应）、定语气（全景本身是一种看法）。判断标准：这段概述在做场景做不了的事吗？不是就删，或者改成场景。
- 边界：把所有段落都改成场景，书会变成连续的对话，时间压不动，背景也撑不起来。场景越多，每一场的分量越轻；最重的时刻留给少数几处。
- 来源：Lubbock（戏剧是小说家的最高光，用在不需要的地方，就削弱了需要它的地方）。

**PV-14 跨越时间之前先写日子**
- 做法：跨年之前，用一段日常循环（作息、季节、重复的动作、磨损的物件）建立时间的质地；跨越只用一句；紧接着给一个变化后的具体细节（同一个物件旧了、同一个动作慢了）。检查：读者能不能说出“这段时间她是怎么过的”。
- 例外：“五年就这样过去了”这句话本身不坏，前面有质地，它就是省略号；没有质地，它就是空洞的公告。编年体可以用年表。
- 来源：Lubbock（巴尔扎克《欧也妮·葛朗台》）。

**PV-15 定好叙述的时间距离**
- 做法：第一人称回忆，时间被“回忆的距离”固定，叙述者知道结局，要说明为什么现在讲、讲的时候瞒不瞒结局。第三人称限知，视点固定在人物身上，时间可近可远：要拉开距离，用“后来她才明白”；要压强，把叙述压到当下，删去所有“后来”。书信和日记把叙述锁在当下，人物不知道明天。
- 边界：“后来她才知道”是一次提前揭示，会消耗悬念，用前先查 `foreshadowing-and-rhythm`。
- 来源：Lubbock。

**PV-16 高潮需要的眼睛和信息提前就位**
- 做法：列出高潮成立需要的视点、物件和信息，在前文让它们以当时有别的用处的方式出现；高潮只让它们以新的意义重现，不重新介绍。高潮需要从某个人物的眼睛看时，这个视点要提前建立。
- 来源：Lubbock（《包法利夫人》里查理必须“随时待命”，结尾才能从他的眼睛看）。

**PV-17 世界的边界由主体决定**
- 做法：问主体需要的是生活的连续性，还是封闭的压强。开放：给主线外的人和事少量、具体的独立存在。封闭：写清边界，并把边界变成压力（谁进不来，什么出不去）。两种都可以成立，开放不比封闭高级。
- 来源：Lubbock（托尔斯泰与陀思妥耶夫斯基的对照）。

## 6. 交付格式（没有宿主格式时）

**视角方案卡**：主体句；重心类型；主视点人物和理由；放弃的候选及损失；叙述位置与人称；视角合同（能知道、不能知道、能进谁的意识）；默认距离；其他视点及每个视点的切换理由；知识表中的关键信息。

**修改单**：每条一行。

| 位置 | 症状 | 原因 | 规则 | 改法 | 代价 |
|---|---|---|---|---|---|

“代价”一栏必须写：每个改法都会动到别的地方，写出来，作者才能判断值不值得。

## 7. 规则冲突时

1. 主体优先：规则与主体的需要冲突，改规则。
2. 类型契约优先于本 skill 的默认值：推理必须公平，言情必须兑现感情，快节奏类型的侧写和时间铺垫要缩短。
3. 作者的趣味不纠正：要写全知插话、元叙事、说书体，就说清代价（叙述者的位置悬在书外，重读时会变薄）并给替代（人格化的叙述者、框架），由作者决定。
4. 合同的第一层（能不能知道）近乎硬性；距离和切换可以调整。

## 9. 来源与可信度

- 主要来源是 Percy Lubbock《The Craft of Fiction》（1921），全书分析福楼拜、托尔斯泰、萨克雷、巴尔扎克、Henry James 等十九世纪欧洲长篇。Lubbock 认为小说方法在向“戏剧化”进步，本 skill 不采纳这种进步论：没有哪种视角天然更高级。
- 视角合同和切换（PV-03 至 PV-05）另有 Wharton、Hamilton、Dowst、Forster 等多部来源同向，较强；其余规则大多只有 Lubbock 一家，是一套可以检验的手艺假设，不是定律。
- 书中分析的小说是 Lubbock 的例证，不是独立来源。来源没有讨论类型小说、网文、现代主义之后的叙事和非西方叙事；`references/zh-and-serial.md` 是本 skill 的迁移建议，没有来源和读者数据支持。
- 这些规则没有在真实写作任务上验证过，不承诺读者效果。
