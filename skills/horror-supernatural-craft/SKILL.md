# Horror & Supernatural Craft（恐怖/怪谈创作法）

## P4 最终操作入口（Agent2 复核）

本 Skill 保留既有可执行流程与参考资料，并逐项复核原 M01–M22 并实质修正核心 references；另有 [精简条件规则](references/p4-field-guide.md)。按用户任务选择主分支，只加载该分支所需参考资料；原始叙事实例是 **F（作品现象）**，提炼为作者可以采用的流程属于 **H/P（设计推断/建议）**，不能写成原作者明确教过的方法。

**先识别**写作/策划/诊断/改写任务、已知受众媒介和人物事件；只有对既有稿件做位置诊断时才必须取得原稿，并确定允许改写的范围。输出合同：`任务路由 → 输入事实/缺口 → 选择的规则ID → 有位置的文本证据或来源 → 可执行方案（含反方案） → 交付物 → 尚未验证的风险`。当用户没给原稿时不能虚构段落位置；要求改稿时默认只给方案或非覆盖的新稿；涉及权利、历史真实或危险现实建议时，划清故事创作与现实事实边界。

**退出方式**：缺关键剧情信息，给最小补料清单和两条可选方向；用户目标相互冲突，保留两个条件分支和取舍，不捏造统一结论；超出本 Skill 的类型/年代/媒介/读者条件，说明不能支持的结论，必要时只提供明确标为推断的结构类比；效果与真实用户任务未验证时标 `NOT_PROVEN`。这不是自动触发、自动运行或保证创作效果的程序。


面向小说作者与写作 Agent 的**条件性恐怖创作方法**：超自然机制设计、恐惧感制造、物证对账、叙事框架、收束谱系、无鬼之恐的负空间。
本 Skill 是**工艺规则库**，不是作品摘要，也不提供"必灵配方"——每条规则带适用条件与反例。

证据基座：1886–1916 英语恐怖正典 26 部（含 1778–1807 哥特源头 3 部与 1904 日本怪谈转译 1 部），当前 P3 最终裁决与来源核验均已同步进实际 references；版本、许可与来源作用见 references/version-and-provenance.md 与 references/06-source-index.md。M01–M22 的最终状态以本包实际规则为准，不依赖 Round 外部 notes。

## 1. 何时使用

- 写恐怖/怪谈/哥特/灵异小说，需要设计超自然机制、闹鬼事件、诅咒/誓约/遗命结构。
- 需要制造恐惧感（不显形的憋蓄、不可描述之恶、感官受限场景、空间双重性）。
- 需要"证据级恐怖"：物证对账、笔迹/文书/遗物对合、文档框架。
- 需要设计解咒/收束（关系式解咒、反高潮、轻收的伤亡边界、道德审计）。
- 需要**无鬼之恐**（制度恶/人际恶/生理恶承担全部恐吓功能）的路线参考。
- 需要检查自己稿子的恐怖强度预算与调性合规。

## 2. 负触发：不要用本 Skill

- 用户要写的是**含恐怖元素的推理破案**（以谜题公平性为纲）——本 Skill 的物证服务恐怖而非谜题。
- 现代心理惊悚（therapist/Eye-tracking/药物剂量级写实）——语料止于 1916，现代适用性 `NOT_PROVEN`。
- 意识流纯文学、 Gore 惩罚恐怖（splatter）、规则怪谈（creepypasta 式"规则清单"本身即恐怖对象）——语料无对应证据。
- 喜剧为主的恶搞恐怖——本 Skill 的喜剧规则（references/05-negative-space-and-tone.md）只管理"许可区间"，不提供喜剧工艺。
- 需要跨类时间叙事结构设计——见 C-05 接口说明（§7），本 Skill 只提供恐怖语境的引用锚点。

## 3. 最短路径

1. **识别威胁机制**：可选三类范型、混合或暂不设定；混合需因果说明：
   - 纯恶单子（Hyde 式：无欲可成全，结局自毁）→ 走 references/01-mechanics-and-curses.md §1；
   - 欲望病理（Silence 式：恶=未被承认的欲望，解法疏导）→ references/01-mechanics-and-curses.md §4；
   - 情执宇宙（Hearn 式：恶=未了之情，解法仪式完成）→ references/01-mechanics-and-curses.md §5。
2. **定读者信息契约**：自然解释、保留未知或明确超自然可选；若反转，预留可回溯依据，不计算 10%——references/01-mechanics-and-curses.md §2。
3. **定框架与叙事者**：单视角即时 / 讲古框 / 文书链 / 多席接力——references/04-structure-and-narrators.md。
4. **设计入场与强度**：渐入或冲击开篇按目标选择；显隐按场景功能，而非次数公式——references/02-dread-and-atmosphere.md §1、§6。
5. **写完自查**：按读者契约决定是否需要可回溯物证和干预风险提示、收束调性（伤亡对账）——references/02-dread-and-atmosphere.md §7、references/01-mechanics-and-curses.md §4、references/05-negative-space-and-tone.md §2。

## 6. 输出合同

给用户的每条建议按固定四字段输出，不可只给结论：

```
定位：场景/章节 + 所用机制（复合规则 ID，如 M05/P148）
规则：条件性动作句（含 when / when_not）
风险：该规则在本稿的失效模式（引对应反例 R##）
出处：PG ID + 行号（或 卡·规则 ID）+ ≤15 词英文短引文
```

无法判断适用条件时，输出"问题清单"而不是硬套规则。

## 7. 失败出口

- 证据不足的请求（如"写当代都市怪谈该怎么写"）：声明语料边界，仅提供**可迁移的机制问题清单**，不伪装成实证规则；`modern_applicability: NOT_PROVEN` 不因请求强烈而改变。
- 与时间设计、推理谜题、现代心理惊悚等跨界需求：本 Skill 只给恐怖语境下可证的机制锚点；需要另一类专门能力时明确转介，不依赖本包外部 notes。
- 与其他恐怖 Skill 并存冲突（若有）：无跨 Skill 接口契约——本 Skill 未与其他 Main 的 Skill 约定共享接口，交叉引用仅单向指向上游证据卡。

## 8. 语料边界（最重要的三句话）

1. 本 Skill 的"恐怖"是 **1886–1916 英语正典谱系**（外加 1778–1807 哥特源头与 1904 日本转译各一）——它不涵盖现代恐怖的全部工艺，也不宣称这些规则在任何时代最有效。
2. 语料中有完整的**无鬼之恐**与**喜剧**传统——"恐怖必须闹鬼/必须吓人"不是本 Skill 的公理（M21 已 REJECT 显形通则）。
3. 每条规则的信用来自**行号可回查**：每项引用应沿 `06-source-index.md` 的来源身份，回到规则中的 PG ID + 行号短引文；P2 审计已单独证明底本 SHA、行数与 FULL 身份。
