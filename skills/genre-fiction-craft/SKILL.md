# 类型小说创作

把题材当作一组要解决的叙事问题。先确定用户要的是作品、诊断还是改稿，再读对应题材的规则和条件；不因为题材标签就强加固定的结局、角色身份、情节数量或价值判断。十四类可以单独用，也可以按需要合用。

## 1. 适用与转介

用：
- 为某一类题材构思、起草、诊断或修订：推理的线索与揭示、言情的阻力与结局、恐怖的威胁与解释、武侠玄幻的能力与代价、科幻的假设与后果、历史的史实承诺，等等。
- 判断题材承诺有没有兑现：读者被许诺了什么，作品有没有给。
- 混合题材时，分清哪个题材负责当前的交付，哪个只补机制。

转给别的 skill：

| 问题 | 转给 |
|---|---|
| 选题、读者契约、事实核验、读者反馈，不确定用哪个 skill | `fiction-planning-and-diagnosis` |
| 全书主线、多线汇合、分卷、连载排期 | `story-architecture-and-longform-planning` |
| 一场戏怎么写、冲突、伏笔、悬念、节奏、章末 | `scene-conflict-and-rhythm` |
| 全篇的人物动机、谁来讲、视角越界、时间模型 | `character-and-narrative-control` |
| 句子和对白的措辞、标点、校对 | `line-editing-and-proofreading` |
| 改成舞台方案或分场稿 | `cross-media-drama-adaptation` |

这些是可选的深化；完成题材任务需要的方法、模板和书目都在本目录里，不以装了别的 skill 为前提。

不在范围：现实的法律、医学、技术参数、当代行业规则和史实考据。虚构创作可以按明确的世界设定继续；确实需要现实结论时，只暂停依赖它的那部分，去查合适的来源，不把题材边界变成整项拒绝。

## 2. 使用方式

- 宿主规定了输出格式，就按宿主的格式交付。
- 普通任务读本文件和一个题材的 `guide.md` 就能做。需要具体规则、案例和模板时，只读 `guide.md` 指向的那几个文件。
- 一句设定也能起步，新加的前提标明是假设；只读了梗概，不说审过全文。没有原稿，不编“第几章有问题”。
- 缺关键信息时，先做合理的假设往下做；只有假设会彻底改变方案时才停下来问。
- 给了稿子就按稿子诊断，写明位置和短引文，不整段复制。授权改稿时实际改，交付时说明改了什么。
- 书里写了某件事，只证明这部作品这样写过，不证明现实规律或现代行业规范。人物的话不等于作者的意见。
- 自己编的例子要说明是编的，不和书中案例、作者的稿子混在一起。
- 没有真实读者测试，就不说恐惧、幽默、情感或商业效果已经证明。

## 3. 最短路径

1. **确定当前产物。** 从请求和材料里取得题材、阶段、文本范围、想保留的功能、已定的设定和允许修改的范围。
2. **按问题选主题材。** 用 §4 的路由表。主题材负责这次的交付，其他题材只补它真正解决的机制；没有几个题材的配额，也不把某类材料的缺失当成禁写的理由。
3. **读实际的规则。** 先读题材的 `guide.md`，再读选中规则的条件、例子、反例和模板。资料不够就标明假设，先做能做的部分；不凭目录名或摘要编规则。
4. **建一份共享的事实表。** 同一事件只记一次：世界里发生了什么、每个人物知道什么、叙述者披露了什么、读者已经知道什么、谁能选择或执行、资源与关系有什么变化。合用几个题材时用同一套事件编号和版本，不各建一套互相矛盾的设定。
5. **裁决规则。** 比较对象、条件、动作、限制和预期结果。完全等价的动作只做一次；条件不同的分支都保留；真冲突时按作者的目标和已定的事实选。
6. **交付实际的东西。** 要正文就写正文，要大纲就给能写的结构，要诊断就给位置、问题、证据、其他解释和修法。表格为作品服务，不代替作品。
7. **回看受影响的部分。** 核因果、知情权限、资源与物件、关系、世界制度、主题和对读者的承诺。只查了局部，就说只查了局部。

### 交付清单

结论；用了哪个题材的哪几条规则；依据是书中现象、推断还是建议；具体的方案或修改；没证实的部分；要作者决定的事；改后的回看。

## 5. 混合题材

| 请求 | 主题材与辅助题材 | 要分开维护的条件 |
|---|---|---|
| 宫廷谋杀与政治复仇 | 推理处理证据和推断；权谋处理承认、联盟和资源 | 有权裁决不等于有证据；推断出凶手不等于能执行惩罚 |
| 爱情与恐怖 | 看这次要写的是关系转变还是恐惧场面，选主题材 | 亲密关系的选择和异常威胁的限制不能互相替代；解释留白不等于关系动机可以随意断裂 |
| 穿越到历史社会 | 穿越处理进入、返回和优势；历史处理时代条件 | 旅行机制和史实分开标；架空分岔之后的后果，不能再说成真实的历史 |
| 科幻灾变求生 | 科幻处理假设和系统后果；求生处理资源和协作 | 作品里的技术假设和真实的生存建议分开；数量、单位、时间账要一致 |
| 少年体育或职业故事 | 儿童青少年处理可知、选择和成长；职业竞技处理训练、制度和竞争 | 不把孩子承担成人的责任当成必需的成长；不拿专业名词代替实际的行动 |
| 幽默探险 | 探险处理目标、路线和发现；喜剧处理叙述站位和节拍 | 幽默可以改变解释，但不自动免除已经建立的物理和资源后果；荒诞的约定另外写明 |

这些组合只是例子。同一件物品可以同时是线索、关系的象征和资源；分别记它的作用，不为了“跨题材”复制成三个不同的设定。

## 7. 冲突时的顺序

规则互相打架、又没有作者明确的要求时，按这个顺序取舍：作者已定的事实和授权 → 对读者的题材承诺 → 因果、知情和资源的连续 → 主题材的规则 → 辅助题材的规则 → 个案里的数字和偏好。真冲突就把分支和各自的后果写出来，请作者选，先做不受冲突影响的部分。

## 8. 来源与可信度

- 规则来自十四类题材的分类批次材料。书目以古登堡计划收录的英文小说为主，含部分英译本，大多是十九世纪到二十世纪前期的作品；中国的武侠传统、现代网文的系统和数值、当代市场偏好，这些材料证明不了。
- 武侠仙侠、言情、科幻三类是热门题材，各补了一个不来自书目的文件，写现代题材的通行惯例和连载写法：`cultivation-and-jianghu.md`（WX-81 至 WX-96）、`tropes-and-serial.md`（RO-36 至 RO-50）、`subgenres-and-worldbuilding.md`（SF-29 至 SF-39）。这些是写作方法和设计假设，没有书目或读者数据支撑。
- 规则和案例正文没有逐条标注书名。早先的版本把案例里的书名去掉了，这一版没有全部恢复：自动归属的错误多，标错书名等于编造出处。武侠、言情、科幻三类里，凡是回批次材料或按人物名在原文库里唯一对上一本书的案例，已经注了“PG编号”或“见 PG编号《书名》”；其余的出处要回到批次材料去查。书目在各题材的 `source-index.md`。
- 少数地方保留了书名、人物名或英文短引文（例如年代题材的六部小说、科幻题材几处容易弄错的出处）。英文短引文都已回原文核对。
- 同一作者、同一编者或同一传统的几部作品，不算互相独立的证据；“跨了几本书”不能代替论证。
- 旧作品里的种族、性别、阶级、残障与疾病的刻板印象，可以当文本立场分析，不当现实的因果或判断人物道德的依据。
- 所有“读者会……”的判断都是待验证的设计假设，不是读者研究的结论。是否采纳由作者决定。
