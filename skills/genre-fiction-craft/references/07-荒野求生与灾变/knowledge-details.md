# 题材细节库与全部独有机制

本库是当前可消费的展开；每行须与 SV 条件一起使用，已去除无依据强制配额与现实操作参数。

| 模块 | 对象、条件、动作与结果 | 证据边界 |
|---|---|---|
| 资源循环 | 密闭、末日或封闭据点：问来源、转换、消耗、废物/再生如何影响下一环；检查错误分层是否让资源不可用 | 单篇；来源声称的物理设定未核验，不输出物理定律 |
| 体力与里程 | 动物或长途故事把身体状态、口粮、行进成本联系；个体差异改变公平而非套统一日耗 | 人物/动物特定叙事 |
| 能力缺口 | 主角不会的事可通过求助、观察、协作、学习或回避呈现；不必每项都失败 | 单源 |
| 训练与工时 | 长周期成长用练习结果、材料与时间证明可达性；重复训练可压缩，失败原因需具体 | 单源工时不能跨作品照搬 |
| 追踪与断踪 | 选追踪剧情时，记录可见痕迹、解释人、备选解释、断踪成本；旧“读踪四判据”保留为该书框架，未提供四项全文不能补造 | SINGLE_SOURCE |
| 距离与冗余 | 对抗戏记录设定中的工具射程、可见性、故障与备用选择，保持跨场一致；不提供真实武器优化 | SINGLE_SOURCE |
| 撤离时机 | 比较留下/撤离的资源、路线与信息，旧“三条件”只作原卡名，具体阈值未获原文不可编造 | 水位触发；未给定位的部分 NOT_PROVEN |
| 被俘与逃离 | 记录控制权、押解空间、谈判/赎金、救援介入窗口、小艇链与代价；72小时、五环、两段式是旧个案标签，不普遍化 | 单源俘虏子类 |
| 决策记录 | 重大选择可记提议人、拍板人、依据、反对意见与复盘；小队可一句交代，不强设官僚程序 | 弱对照，单源 |
| 代价不对称 | 同一威胁对一方是生命、另一方是一顿饭；可揭示地位与视角差，不移植儿童零伤亡基调到所有成人小说 | SINGLE_SOURCE |
| 密闭载具事故 | 以危险来源、空间约束、系统相互影响和逃生选择组织场面；旧“断源/通风/减重/上浮”只记历史情节顺序 | SINGLE_SOURCE；不当现实程序 |
| 家庭技术分工 | 谁识材、谁提出用途、谁质疑、谁维护让同一资源变成关系戏；生活/节日/宗教安排属于人物文化 | 同作候选族，暂不多计独立源 |
| 前人遗产 | Cache、留言、遇难者舟船同时带资源、产权与伦理；说明能不能用、谁承担责任 | — |
| 信用补给 | 城镇/打捞故事中赊购、担保、拍卖、分成亦为资源链，金额与信用代价必须由设定给出 | 单源 |
| 产权威胁 | 模糊占有与正规权利改变谁能动用资源，不能把“发现”自动视为产权 | 不作法律意见 |
| 日常物错读 | 对方缺少该技术知识且角色确有解释过程时，伞、火柴等可造成误认；反转仍要呈现双方信息差 | SINGLE_SOURCE；殖民式“愚昧族群”不继承 |
| 动物作为线索 | 角色观察动物并推断环境，须保留误读和验证；小说方法不成为现实动物学或寻水指南 | — |

| 工具控制即权力 | 两人组中藏起桨斧或收走工具，既可保护也可剥夺行动；检验双方后果而非默认正当 | — |

## 同源、时代与历史状态

一批作品属同一神秘岛叙事链；四种 Swiss Family Robinson 版本依标题与来源说明作为同作候选并保守合并独立支持计数，完整版本关系仍需原书核验。相关续作不把“同世界”误作全文相同。不同版本定位各自保留，不能互换。

有来源的年代信息在简介、正文与索引不一致，以逐书题注为准而不声称全在 1882–1951；书目附录与正文分开。主要社会背景、主线不适用技术、主要城市图像仅作背景；不因书目数量就给所有规则背书。

有来源经历了覆盖范围从部分到声称全读的多个阶段；伪造/错位旧记录的撤回说明保留。“已覆盖”的声称不证明每条解释独立复核，也不证明已重读原著。配给段在最终规则内仍明确未重读，不能被全书状态抹平。少量单日求生片段保留但主线仍为身份翻案。
