# 执行流程与失败出口

1. 固定当前稿件和授权，填环境、人物、资源、技术、价值目标、读者与时间；UNKNOWN保留。没有正文只能做原创设计/检查清单，不能伪造段落。已经明确的授权无需再问。
2. 选择SV01压力模型。量化资源决定选择才建账；自然节律、身份与关系主线可用状态变化。分别记人物所知、读者所知与作者掌握的制度期限。
3. 建最小节点表：目标—信息—可行选择—决定—结果。只在节点依赖时加据点、工具、伤病、治理、信道或仪式卡。沿用既定物性与人物能力，超出事实依据的参数标EXTERNAL_VERIFICATION_REQUIRED。
4. 用冲突表选条件：公开/保密、封闭/撤离、弱者优先/牺牲、工程/日常、求援失败/外界偶遇。允许作者裁决价值目标；不能把有分歧当成强迫插入冲突场面的理由。
5. 诊断时引用真实位置，说明对象、适用条件、违反的正典/因果、最小修法与损失。没有缺陷只需说明成立条件；不能因没灭火、没近失、没伤残而机械报错。改写按授权生成正文候选，当前稿版本留存。
6. 交付选中的模板、依据、保守替代、未证项和下一步核验。复查库存变动有来源、单位一致、空间与工具状态连续、信息权限没有越界、信道与获救因果分清、结局回应承诺。

最小冲突无法裁决时只暂停依赖它的段落，列选项及代价；其余部分继续。要求现代真实生存/医疗/工程动作时本题材停止承担事实指导，但可继续完成文学结构；不得用古典小说做现实方案。原文不存在的规则引用或消费者实测，一律 NOT_PROVEN 而不补造。
