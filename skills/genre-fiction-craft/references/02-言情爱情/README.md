# 言情爱情：关系选择、社会阻力与情感后果

本题材整合七个同题材来源版本的规则、条件与反例。核心是把爱谁、能否在一起、是否愿意、如何相处、谁承担后果分开，再设计它们的联系。爱情可作为主线、副线或社会问题的一部分；婚礼、分离、独身、死亡与开放结局都按作者承诺使用。

| 当前任务 | 阅读入口 | 可交付物 |
|---|---|---|

| 构思人物与障碍 | [融合规则](fused-rules.md) RO02–08；[具体机制](knowledge-details.md) | 人物目标、阻力条件、选择与资源表 |
| 误会、信件、秘密与中间人 | RO09–13、RO17–24 | 信息分配、证据路线与场景卡 |
| 告白、拒绝、强迫与修复 | RO14–16、RO26–28 | 可辨认回应、边界及关系后果 |
