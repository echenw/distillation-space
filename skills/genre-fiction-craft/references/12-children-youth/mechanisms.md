# 具体机制与条件

返回 [guide.md](guide.md)。这里的条目单独就能用。故事内现象和推断、建议分开；推断和建议仍要符合 CY 规则。这些条目补足主规则里写得较短的机制。

| 原机制 | 当前条件、动作、结果 | 证据与边界 |
|---|---|---|
| A/B/C读者方案 | 低龄口述优先清晰指代、可复述行动和可感知意象；自主阅读可有跨章因果；YA前期可保留立场冲突与留白。按当前读者与媒介选，不作年龄认证 | 历史年龄分档，不作年龄认证 |
| 累加与回返 | 反复可累积、递变、重复同构或远距呼应；看每次对预期和行动的贡献，不规定三次 | 四次威胁句；回忆式再见 |
| 为什么型起源故事 | 从可见特征设谜，回溯角色选择与故事内后果，检查能否复述因果；身体惩罚仅属于特定寓言观念，不据此责备现实身体差异 | 不是生物学 |
| 惩罚与尊严 | 惩罚因果和维护尊严不是靠年龄自动二选一；按作品价值目标、儿童视角和后果处理，可并置其冲突 | 与不同目的的作品对照 |
| 转述链 | 标每层讲者知道什么、爱哪一类故事、有何偏好；可信口吻不等于事实保证 | 母牛讲者 |
| 成人接力 | 当故事有意把解释留给成人，明确求助或讨论对象及问题，不用“问妈妈”回避本来必要的因果；也允许其他可信照料者 | 仅该作品安排 |
| 跨文化物件 | 若陌生物影响行动，用语境、脚注或旁白解释到足以理解；不要求所有陌生词必须注释 | 陌生词加注释的例子 |
| 赠礼与封口费 | 赠礼、回报、收买在意图与接受条件上不同；写受助者意愿、拒绝权、名声和隐私成本 | 施舍与尊严的边界例 |
| 汤做坏与成人回应 | 失败可有幽默，保留返工与情绪；成人指出超出能力不应取消孩子的努力或全部后果 | — |
| 命名辨识 | 外观、习性、声音、关系都可帮助辨认；名称不预定道德与物种性格 | 标题层只证明命名，是作品价值投射 |
| 成人也会误读 | 儿童纠错、严肃推理与政治判断可成立；不因成熟内容就删成天真，不从一次例证推出发展定律 | — |
| 有权限的公开发言 | 表达主体性可以由制度邀请、成人许可和孩子自己的选择共同形成；许可不自动消灭主体性 | — |
| 示范行为 | 成人喂鸟或举枪是孩子观察到的行为模型；写动作与孩子理解，不让旁白自动宣布教化成功 | — |
| 奖惩判据 | 同样工作可因自愿/强迫被不同结算；可见奖惩、成人理由、孩子理解分别列，允许三者冲突 | — |
| 玩具情感与物理边界 | 破旧被爱、棉花无机械、无人时活动是不同契约；按所选世界持续执行，不合成单一法则 | — |
民间精灵与恶作剧异类的物性 | 具体行为和世界规则按本作设定建立；改编前先声明契约，不把某一故事的变形、入侵或离去方式普遍化 | —
| 秘密空间 | 孩子发现、照料和改变关系可呈现成长；花园不自动治疗创伤，跨物种理解保留“好像”的不确定性 | “好像”边界例 |
| 真实儿童记录 | 真实言语记录、成人转述、虚构内心分别标归属；不可把小说语言当心理测量 | — |
| 朗读音色提示 | 只在声音表现服务理解时标粗声、哀求声或动作提示；非所有对白都要舞台标记 | — |
| 可讲性 | 口述难可改编、分段或换材料；默读可回看、容纳复杂结构。少人物和物件入口只是低龄讲述选项 | — |
| 愚行链 | 喜剧可让听者预见错误，并让人物学习、求助或承担小后果；不用贬低群体或强制所有故事不讲教训 | — |
| 自夸声口 | 把自称与行为对照；名字代替“我”、同伴短反驳只是自夸式喜剧的一套可选手段 | 不强制每场自夸 |
| 字面漏洞 | 角色按字面使用规则、援引书本先例；写误解的逻辑和后果，不能把无知当唯一儿童声口 | — |
| 关系债务 | 赌局、归责、争吵、物损未结算时跨场保留；不是每场必须争吵 | — |
| 读者获得信息的时机 | 道具公开延期适合喜剧期待，隐藏用途适合悬念；都需存在与可用条件连续 | — |
| 险境时间 | 感官与主观时间可放慢；切在后果前、有限呈现伤害或救援恢复由目标决定 | — |
| 汇编与教学 | narrative/realistic/imaginative/scientific/historical是历史分类；可按场景、节日、难度、互动编排，不按性别强分兴趣 | — |
| 多种起源 | 分别归属传说，统一正典需作者选择；不将两种圣诞树起源拼成新历史事实 | 两种圣诞树起源的对照例 |
| 周期代价与共享资源 | 年年复发的伤或私藏导致资源关闭是可选长期后果；喜剧完整喜悦也可以成立 | — |
| 系列与出版形态 | 系列名、开本、小册行数、插图占位只支持体例观察；不能推出每章长度、插画配比或必有续集 | 体例观察，不作现代配比 |

## 有效条件与边界

方法论判断与叙事案例分开使用；同一情境被重复呈现，不按数量自动增加支持。个别旧证据（如章歌/挽歌）已撤回，不因后续补读而恢复；早期错引与降级观察也不得自动恢复。所列案例只适用于明确列出的作品与情节范围。

口述规则不直接证明YA恋爱主轴，涉及YA关系结构转相应题材；儿童视角与本题材通用条件仍可用。迁移到动画、播客、现代课堂，标明是推断，不能说故事里验证过。成人宗教或成人文学文本不进入儿童语言/年龄认证；成人自然主义只提供动物与危险场面，不作儿童语言模板。
