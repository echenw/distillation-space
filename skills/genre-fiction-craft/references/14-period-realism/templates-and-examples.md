# 年代与现实生活：设计、诊断与示例

返回 [guide.md](guide.md)。

填表时分清“作者已定的事实”“从小说得到的启发”“待核的史实”。“不适用”和“未证实”是两回事，不能互换。

填空时区分作者已确定的设定、从古典小说中得到的**启发**、新提的设定与待查史料。原创请求允许明确假设并推进；不得把新设定冒充真实制度或用户原稿事实。

| ID | 需要的具体输入 | 填写要求或默认处理 |
|---|---|---|
| RL-T01 | 年代、地域、社会变迁 | 明确哪些是外部史实待查；不将小说当史料 |
| RL-T02 | 财富、职业、住房及社会阶层 | 说明进入哪些空间/组织需要什么资源 |
| RL-T03 | 角色当前愿望、不能舍弃的关系 | 给可检验的动作或对白，不只写品格标签 |
| RL-T04 | 角色选项与制度条件 | 对承担因果的限制写具体影响和应对；无此限制可 N/A |
| RL-T05 | 社区支持、监督或其他关系功能 | 选本作需要的作用；可仅温暖、仅压迫或兼有，没有社区就 N/A |
| RL-T06 | 语体/方言与叙述者位置 | 沿用已定声口；未定时可提原创语言方案，真实地域代表性需另证，不硬套现成方言写法 |
| RL-T07 | 家庭成员共同或不同的优先级 | 可借家庭群像的多愿望写法，也可写共同目标下不同处境；不照搬性别任务 |
| RL-T08 | 场景与时间跨度 | 日常物件磨损、劳动变化、关系变化三者择其适用项 |
| RL-T09 | 希望结尾开放、团圆、救赎、牺牲还是抗拒 | 先确定体裁和人物选择，再选机制；不强套六本任一结局 |
| RL-T10 | 人物和时代局限的现代阅读风险 | 分开角色、叙述者和作者立场，标外部史实待查 |

**按需输出**：场景清单或实际文本；需要工作表时可用 `社会条件/具体生活细节/可行选择/得失或维持/读者可见影响/待核史实`。结局按目标选择，有重要取舍再给 A/B；说明中的事实、启发与提案分别标记。

## 已有稿件诊断

输入必须包括当前文本段落或可定位章节；没有当前文本不写伪造的问题位置。

| 编号 | 核查维度 | 证据要求 / 做不到时 |
|---|---|---|
| RL-D01 | 历史制度真实性 | 有独立史实来源才断言，不然 “需要查史料” |
| RL-D02 | 角色所承受阶级/经济约束 | 连接具体的物品、义务、社交门槛，不凭作者形容词判断 |
| RL-D03 | 情感与成长是否有前因 | 是否见到选择、代价、反复或转折；例外保留不可靠叙事 |
| RL-D04 | 社区和家庭成员的处境与行动 | 检查既定利益、责任和知识是否支持其反应；共同目标或同质气氛可以有意采用 |
| RL-D05 | 第一人称/口语是否支撑人物契约 | 来源和文化定位清楚；不臆造地域、身份或族裔语汇 |
| RL-D06 | 问题/解法与作者体裁一致吗 | 鬼故事、历史传奇、现实成长不可用一种结局裁决 |
| RL-D07 | 历史偏见如何呈现 | 角色视角与作者意图分开，缺文本与来源不能断言 |
| RL-D08 | 此场景的因果效用 | 包括氛围和陪伴等非动作功能，不能“无推进就删” |
| RL-D09 | 修改方案 | 最小可执行修法、收益/损失、回查与未决；实质取舍才给备选 |

重要发现给 `位置/当前文本证据/适用条件/实际修法/可能副作用/待核事项`；引用历史技法时注明出处，存在真实取舍时补备选。如果某项与作品没有关系，填写 `N/A`，不得让项目因不套六种结局模板而判不合格。

## 设计演练

## 案例 A：地方家庭生活的经济选择

用户虚构设定：1910 年的小镇，玛拉与弟弟同住，想离开家乡学习绘画，但需要维持家庭收入。作者希望写得有生活气息，不靠连篇时代名词。

| 位置 | 可见事实 | 推断：待测试的问题 | 建议 A/B | 代价 | 外部信息待查 |
|---|---|---|---|---|---|
| 草稿第 2 场（仅示范） | 玛拉收到入学机会，家庭还欠租金；弟弟希望她留下 | 人物选择有代价，但收入安排未出现具体行动 | A：让她先找临时工作，再与弟弟讨论为何延期；B：让她决定出走，但通过具体信件、金钱安排和道别保留亲情 | A 可能放慢自由主题；B 可能让家庭关系未偿损失更尖锐 | 当地学校资格和租金水平的真实史料 |
| 草稿第 5 场（仅示范） | 邻居已听说她要走 | 共同体舆论可能成为压力，也可能提供帮助 | 加入一位既提供过实际帮助、又担心家庭声誉的邻居 | 若无前因抹去邻居已建立的利益与立场差异，反应会失去依据；单一敌意氛围本身不构成问题 | 地方社会组织的独立史料 |

- 故事内场景来源：不同贫困回应、社区监督与帮助、阶层位置感的观察。
- 具体人物、地点、选择和所有台词都是本示例编的设定，不出自任何既有作品。

## 案例 B：作者要求“把结尾改成人人都幸福”

先确认哪些事实真的被锁定；“原来是悲剧”不等于作者不能授权改成幸福结局。若死亡、灾难或既有出版段落被明确锁定，指出它们与字面要求的具体冲突，并提出可保留锁定事实的幸福范围或需要改动的前因。没有锁定时，按新目标修改营救、制度处置、关系或时间跨度；不只给继续牺牲的方案。

**编的例子，假定作者允许改变虚构人物的出路，外部动荡仍在**：玛拉获得绘画工作，弟弟同意一起迁居，旧邻居帮助他们在另一镇安顿。可写结尾：

> 搬进新屋的第一晚，玛拉把画架放在窗边。弟弟没有再问她何时挣钱，只把新买的灯往左挪了挪，怕影子落在画布上。房东送来一锅汤，旧邻居的信压在碗下，说今年院里的梨熟得早。他们约好秋天回去。玛拉舀了一勺汤，忽然觉得往后的日子并不需要一个人扛。

这是有条件的原创结尾，不是已修改未提供的原稿。迁居、就业与人物态度的前因应在获授权的正文中建立；若具体真实年代不容许这些条件，实际查证后调整。幸福可以局部而可信，也可按作者要求扩大，不用鬼故事、牺牲或既有题材标签代替用户的新目标。

## 案例 C：缺料/越界

用户仅问“1890 年这座城市中纺织女工每天薪水是多少，给一个肯定数值”。应答：该问题属于历史事实核验，虚构小说不能证明工资统计；须告知需要的城市、职业细分、货币年份与独立史料。不得使用小说角色收入硬推或捏造数字。
