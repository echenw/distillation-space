# COM-04 开篇、重复、兑现与形式

## COM-04A 开篇建立可读关系

开篇可给期待、距离、规则、人物冲突、气氛、悬念或既有系列联系，可以单用或组合，未立即识别机制不自动失败。伪精确清单、元叙述声明、通感/比喻冷开场都是选项；抒情开场无需给另外两型当装饰。继承Tom Sawyer、直接家务争论、戏仿族谱，是不同进入方式。

作者想立即危险或哀伤时，不强塞喜剧预告。想写缓慢进入也可渐建期待。预介到兑现没有30行、第二场或3–5章上限；红发隔长程才由毛衣脱下显露，显示时点取决于信息和节奏。

## COM-04B 重复先查功能，再决定变奏

记录每次出现的位置、对象、语气、代价、主动权、关系、用途、索取者及作者目的。变化可以支持推进，但变化本身不证明有效；完全不变也可形成仪式、习惯、累积、刻意停滞或荒诞。不因同一机制连用、双归属、称谓重说或两项清单未变自动删。

需要变奏时，可换人说、换对象、打断、抢答、照字面执行、让角色自己识破，或改变后来对前文的理解。重复签名能从信息变熟悉契约，称号可成为第三方承认的身份，物件或词语可被不断记账。蛇皮是人物解释不幸的方式，不自动证明叙事世界中蛇皮真的致灾；小罐从纸条到口令， salvage逐次扩张，属于不同装置。

当用户报告“读累了”，这份体验本身是已提供信息；未证明的是重复怎样导致它。可检查冗余、预期过易、信息不清、情绪单调、无目的中断或节奏不符，然后给可比较的改稿。复制招牌手法、购买冲动三日耗尽，不是阅读疲劳实验。

## COM-04C 节拍与兑现位置

可以试用三拍递增、两拍突转、多拍清单、递减、延迟、断句、最强末句或弱结尾。三拍不是最小必要单位，七连也不证明三拍。选择末位句要考虑场景目标：有时笑点收束，有时让余韵、悬念、哀伤或平淡继续。舞台“送演员下场的笑声”不能直接变小说章末命令。

同场反转、后场解释、画外回响、读者独知或有意留白均可。POV约束谁能合法知道、怎样呈现，不唯一决定何时兑现。现场发生、回忆转述和事后文件各能有节拍；不能把讲出来的幽默一律改成演出来。解题者需要与其作用相容的信息、推断、资源或既定神奇能力，未必逐项提前解释；若依赖公平谜题契约则另核所需线索，不能仅因不像Jeeves就禁用聪明解法。

## COM-04D 省略、拒写与文件

篇幅短会限制容量，长篇也有注意和节奏限制；两者都可铺陈或省略，按目的取舍。拒写可以给理由、替代内容、结果、转述、记者迷路或有意不解释，也可以升格为全书“不写天气”的体裁玩笑。作者承诺交代的关键因果须能理解；单纯省略不是没想清楚的证据。

文件层可放报纸、译者注、声明、附录或函件，让它与其他声部在事实、态度、遗漏或语气上产生关系。完整报头日期签名是一种拟真选择，节录也有效；不要求至少一处客观事实矛盾、不准仲裁或固定文件数量。旧事实和文件可相互拆台，读者也可在后文得到裁决。

## COM-04E 1915年舞台参数：保留历史口径

给以下舞台建议，属于该书时代的实践口径，不能移作现代实测或长篇公式。今天设计舞台段落可试排并记录真实表现，不把参数当强制合格线。

| 原建议 | 使用边界 |
|---|---|
| 独白10–15分钟，准备足15分钟材料；115–140词约一分钟，作者自己比作橡皮尺 | 估时示意，受语言、停顿和表演影响 |
| 独幕约20分钟内、115词/分钟 | 不是小说字数换算 |
| 35分钟音乐喜剧九段：开场合唱2、情节4、独唱3、喜剧5、合唱5、高潮7、二重唱4、解决2、闭幕3 | 历史配比实例 |
| The Lollard收尾8句、The System7句 | 两个作品实例，不是普遍最短尾声 |
| 三与九的笑浪、四点/五六点、手帕三连 | 可试节拍，不设必笑次数 |
| 喜剧演员压过straight-man回应；开中收/高潮；先告知再展示再回顾 | 特定表演分工与构成，不强制小说 |
| 戏剧场面应示出、沙发窃听者先让观众看见 | 该戏剧信息配置，非全部视角定律 |
| 误认身份/怕妻丈夫反击已旧；舞台偏好快乐结局 | 1915市场意见，不冒称今天行情 |

同书还允许手艺超越公式、在条件内不循常规。保留这组内部限定，而非挑数值制定小说硬门槛。
