# 喜剧幽默：构思、诊断与改稿

返回 [SKILL.md](../../SKILL.md)。本题材的规则编号是 CO（CO-01 至 CO-07）；书目见 [source-index.md](source-index.md)。

先读这几句：
- 覆盖小说、连作、论辩讽刺和历史舞台材料。可操作的规则按对象放在 CO-01 到 CO-06；CO-07 是各书的案例和依据边界。
- 书里人物的话不等于作者的意见，更不是现代的行业事实。书中观察、解释或迁移、创作动作，分开写。
- 案例只是样本。笑点密度、疲劳阈值、市场效果和读者立场的变化，都没有实测支持。

## 一次任务的顺序

1. **问清要做什么。** 构思、判断、诊断还是授权改稿；记下现有文本、目标情绪和不能改的地方。信息够就直接做。只有一句“帮我写喜剧”，也可以选一个合理前提写短样，标明假设，不必先把体裁、视角、靶子都问齐。
2. **选机制。** 选一个或几个适用的机制，不全套。
3. **写方案或改稿。** 用户问“好笑吗”，可以给有文本依据的审美判断，说明这是判断，不是读者实验；要求提升幽默就实际改，不因为没法保证人人发笑而拒绝。
4. **回看。** 检查人物动机、信息渠道、因果、节拍和情绪。

## 交付

短任务不必硬交三张表和 A/B 两案。不同方向会改变主题时，给有差别的选项和取舍；作者已授权自主完成的，自己选一个合理方案继续。没有原稿不能伪造原句行号，可以给设计。
