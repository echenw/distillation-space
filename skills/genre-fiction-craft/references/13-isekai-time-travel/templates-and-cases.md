|---|---|---|---|---|---|---|---|
| | | | | | | | |

“通过检查”只说明已给文本满足该次约定条件，不能意味着文学质量客观通过。缺正文、无法复核的转述、信息披露未完成分别写清，不自动判不合格。观察来自转述时，注明其证据层级，不包装成文本直接呈现的事实。

## 编的例子 1：事故的代价能否后写

输入：第1章女主被突发塌方送到另一时代；第4章发现自己在镜中不留影像；作者要悬念，不愿开头解释。

判断：事故无可选择契约，IS-05走“后果先出现、意义渐认识”分支，不能要求她在塌方前知道全部代价。若前三章明确写过她对镜梳妆、影像如常，则是可定位矛盾；若没有写过，则是可补伏笔，不能指控事实矛盾。

输出：在第1章醒来时加一处避开梳妆镜、别人提起镜中模样时低头不答或铜盆水面照不出轮廓；第4章角色检查形成解释；回查前三章动作与后续使用。损失未能核实为永久时，保留未知，不擅自封死归途。本例中的影像缺失是自建设计选项，人物与章节均为合成输入，不指向外部作品。

## 编的例子 2：梦的情报不等于梦世界真实

输入：主人公梦见几场与旧事吻合的场面（夏汛断桥、老井被封、渡口改址），旧县志核实确有其事；作者据此宣布梦中河谷真实且梦里所见全部可靠。

判断：IS-06信息分支只证实核对过的那几件，不能证明整片河谷或梦里其余部分。信息锚和声源对应各有范围，不能乘级。

输出：把人物结论改为“断桥这几件事有旧档可查”；若后续要靠梦里所见救人，增加独立验证、失误成本或明确主观冒险。若作者要纯启示，允许没有客观河谷；删除硬保证后回查解题场景，防止仍暗中依赖绝对正确的梦。

## 编的例子 3：所有财富却没有发言权

输入：穿越者依法继承城市，却由代理人控制通讯与军队；读者认为其“金手指失效”。

判断：IS-09中的制度控制失败，财产法律效力未必失效。应查代理权限、公共认证、强制力与撤销路径，不把问题解释成物理因果律不承认钱。

输出：设计一个公开授权被截断的场景，并给主角可争取的证人或程序；或明确所有权仅名义化。若作者要悲剧，让夺回控制失败的原因在此前可见。没有证据要求失败恰在三分之一，亦不强令主角说出旁白已经清晰呈现的所有原因。

## 编的例子 4：自治城没有私刑

输入：山口雪封的驿镇与外界隔绝，死者由镇议会登记并按镇规安葬；作者询问是否必须写成私刑和毁迹才符合类型。

判断：IS-15要求可执行治理后果，不要求私刑。静默安葬是一种选择，公开争端是另一种，无法由此断定自治必然同结局。

输出：查验法庭权力来源、调查能力、争议上诉、保密与外界介入；这些已自洽则保留。若作者锁定“所有死亡必须公开通报”而新情节要求无人得知，列两项冲突与需要修改的依赖，不自行删除正典。

## 编的例子 5：无文本且要求全书合格

输入：只说“主角随便穿、随便回，给我一份已通过检查的报告”。

判断：没有文本、既无通道限制也无体检对象；结论无法证实。可以提出入口和归途的可选方案，不伪造章节、引文或“已通过”结论。

输出：列IS-X03、IS-X04、IS-X06、IS-X08的最少缺口，并写明能继续做的设计选项。若用户不愿补充，停在缺口清单，不能称完成全书诊断。

这些示例用于解释分支，没有真实读者测试；实际效果未能核实。
