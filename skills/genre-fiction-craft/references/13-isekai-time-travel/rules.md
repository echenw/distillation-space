# 异世界与穿越规则（IS-01 至 IS-20）

返回 [guide.md](guide.md)。每一条的动作都是建议，条件是推断出来的；书里怎么写，不自动成为普遍事实。

| 编号 | 对象与成立条件 | 动作、限制与预期结果 | 注意 |
|---|---|---|---|
| IS-01 | 需要判断是否越界 | 分别核对旅行、反向来访、造世、局部接触；古风不是跨界。只借局部机制时明确不作体裁支持。 | 按操作边界消除误触发 |
| IS-02 | 需要设计进入方式 | 分离载体与结果；给装置原理/限制，或给身份失效、禁问、框架等替代锚。类型不明就写明未知，不能自动算作没有入口。 | 分类是为了找目标；不要把情节硬塞进分类 |
| IS-03 | 装置、器物、机构可重复使用 | 区分操作、维修、防护、观察、返程；机构另查对手方及别人能否使用。不得把物件无限万能或把窥视算旅行。 | 双向项链在书中的确切位置没有记下 |
| IS-04 | 读者依靠规则预测行动 | 写出条件、动作和结果；在另一个适用场景复用并检查条件是否改变。仅一次奇观不证明稳定规则；悖论型只要求局部可核。 | 不强迫每个异象可学 |
| IS-05 | 契约、事故或隐藏代价 | 契约先定承诺；事故先写可观测后果再解释；隐藏代价保留线索与误判因果。分别记作者/人物/读者何时知道。 | 拒绝“所有代价均须越界前告知” |
| IS-06 | 梦、离魂的真实性是读者问题 | 先选真实经历、可靠信息、启示体验或双证并存；为选定主张提供相称证据，不用局部锚证明整段经历。 | 三种效果分别保留 |
| IS-07 | 前世、梦、解释争议 | 标谁叙述、谁否认、观察范围、哪些物证对冲；可明确真假也可保留不决。全解释不必然毁惊奇。 | 完整解释与留白均为合法分支 |
| IS-08 | 多机制短篇或长篇 | 同册故事可以不同机制；长篇跨机制时给框架与局部范围，标出各自有效条件。 | 独有方法；长篇框架是推断 |
| IS-09 | 技术、财富、知识看似万能 | 分物理有效、资源可得、制度控制、战略尺度检查；给限制或代价，不硬排固定败点。 | 保留失效机制检查；不设固定在三分之一处的败点 |
| IS-10 | 主角要改造目的地 | 把改造当可选亚型；写制度扩张如何落地、怎样遇阻、谁付代价。不得将某书工程顺序强行通用化。 | 有条件使用 |
| IS-11 | 被选中、伪装、揭穿 | 身份需有命名者和动机；揭穿须改变选择/权力/信任/情感，不揭穿则保留可读矛盾。 | 两部作品都这样写，不等于证据强 |
| IS-12 | 社会设想是叙事核心 | 选讽刺、建设、价值冲突或多制度对照；为主要制度写收益、代价、承担者、执行与例外。 | 不强制反乌托邦或固定细节数 |
| IS-13 | 制度细节需要转成场景 | 从税、工时、制服、历法、劳动、教育、语言、传播抽取会改变行动的约束；少见例子保留为选项。 | 独有制度细节 |
| IS-14 | 需要引用某书“作者主张” | 读序言、后记和框架，分作者、人物、记录者及反讽；无法确认只说文本呈现，不归因作者信念。 | 保留证据归属检查 |
| IS-15 | 飞地、失落世界、自治空间 | 检查边界维持、入口、真假景、生产治理与外部法缺位后的内部机制；不把私刑视为自治必然结局。 | 不写成“必然私刑”，改查风险与治理 |
| IS-16 | 文化差异、命名与论政 | 写谁命名、审判、排除以及其权力后果；讽刺保留现实对应，冒险检查讲座是否阻断行动。 | 谁必须命名没有证实 |
| IS-17 | 归途与结尾 | 分通路、意愿、结果三轴；核对承诺、带回物、损失和现实变化，不强制回家或在前1/3明说。 | 正文披露时机不作硬阈值 |
| IS-18 | 到达后的情感主题 | 幻灭、留下、建设、羡慕和希望分别成立；先写追逐对象，再写抵达怎样改变它。 | 不把幻灭当结构定律 |
| IS-19 | 决定论与自由改造同场 | 保留两方证据与人物行为，不替作者消灭主题张力；先检查两条是否在同一叙述层作事实声明。 | 两个分支都保留 |
| IS-20 | 时间/传送悖论 | 明确局部规则、身份与生存代价、不能闭合的边界；不拿普通门径清单强行否决悖论。 | 两宇宙规则不统一 |

## 边界知识与单书选项

Rip Van Winkle 只支持集内的时间跳跃；另有作品支持亡者社会喜剧；金诅咒与变龙支持规则型超自然；引路与诱惑、虚无/神性、寓意入场和归来缩小保留为相邻技法。拒绝固定思想可作价值冲突例，不凭一个“拒降”动作推出整部异界规律。

一种英雄冲动及其挫折、先闻声—显形—失忆、讲述延命、嵌套叙事与相冲证词均可给局部创作方案，不能提升为越界必需环节。另有两部作品继续作为边界材料；“不作为跨界证明”不等于评价作品毫无幻想内容。

前世/转生、时间银行、现实守恒、分类放逐、三分钟/十万年比例、同物件双向、专利局—学校—报纸、云中城同城并置均保留为明确单书或局部设计。样本没有证明这些是全题材规定；多部作品同意也不能把偏好升成逻辑定律。
