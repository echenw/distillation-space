# MY-02 证据、身份与证词：一套共同判断

## MY-02A 证据链与独立性

统一链为“来源/载体→原始观察→人物推断→替代解释→区分或反证→排除范围”。同时记录发生与形成时点、保管/转手、可篡改性、观察条件及谁有权采纳。证据可为物、言辞、记录、行为、空间或规则；不要求物证高于一切，也不预设量化与经验互斥。第三方记录、消耗物、目击没有固定可靠性排序。

号码、刻字、笔迹、身体特征不自动不可复制；所有权不等于使用人，物件在谁身上也不等于谁放置。多个相似特征可能被同一伪装或共同渠道控制。按实际竞争解释增加独立印证，而非凑两条或强造一条“不可临时改变”特征。足迹、创口常只能缩小行动/工具候选，不能直接推出身份、国籍、动机或性格。

### 流转与制造的专用分支

| 分支 | 保留的独有动作与案例 | 适用/反例 |
|---|---|---|
| 成套物与不合时序的成员 | 查系统、编号、日常使用、每手持有和转移；原著 的Monday剃刀出现在Tuesday，死者不自剃；四恶袖扣分给多人 | 编号差提示调查，不独定凶手；一次性工具也有流转，缺一手只降低相应推断强度 |
| 独特流通物 | 钱、刻字硬币、票据、信件依其特征追溯交换；编号钞票被调包；假眼内藏三便士字码币 | 不强制每次转手直演或120字复原；可由先前记录/痕迹推回，也须考虑复制和栽赃 |
| 库存缺失与补位 | 比较固定陈列、盘点、替代品、访问权限；冷门藏品位置可测试内部知识 | 没有陈列不等于不能查库存，可用账目或独立记忆；知道位置不等于盗窃 |
| 被毁资料 | 残片、附言、编号缺口、衣物夹层、抄件或数字副本；区分可反复复核与一次看见后只剩记忆 | 大衣口袋借据、烧余附言、显形即灭各有不同复核强度；不规定数字记录必无残留 |
| 铁证反向检验 | 对每件证据问谁有能力、机会和信息制造；以独立条件区分自然留痕与布置 | 四桩证据逐一被解释为栽赃；不能强制罪犯每案漏算一项，也不禁止偶然发现 |
| 微量组合 | 发夹、脚印、手帕、烟蒂等分别列无害解释再看联合条件 | 同旅馆/同用品渠道削弱独立性，不自动让全部组合毫无价值；不固定2–4件 |
| 借用物与随身物 | 借出理由、最后持有人、留置场景、回收或比对；绣名围巾、袖扣、纽扣、假牙与断指动作均可 | 借枪、纽扣/锁痕、牙具各有案例；共同用品、转让及伪造需另排 |
| 假设复现 | 把一个假说化为可比较的观察；记录条件差异、阴性与阳性结果的排除范围 | 床单无孔、窗痕复现；结果可多值或不确定，重复成功仅证可行，不独证实际由谁实施 |

## MY-02B 身份的可选装置

1. **顶替潜入**：外形、识别标记、声音、行为、暗语、纸面资格、共同记忆各按查验者实际使用启用。熟人会增加检验压力，不能自动宣判失败；三件套缺一也不必穿帮。面具、仿标记及应对是一个组合案例。
2. **身份缺口**：亲族、信件、照片、雇佣介绍与档案断裂可造成难查身份。书面推荐与失真照片说明信息依赖，不证明死者成为可任填空位。按时代与已设社会系统检查仍存痕迹。
3. **同名/远隔顶替继承**：文件、长久分离、旧相识、继承规则和法律承认分开。原著 的弃旧身份可变成勒索杠杆；旧相识是否揭穿取决于知识与行动。不得称文件齐全就法律无懈可击。
4. **病床或死者换人**：死亡确认与姓名确认是两条链；医生、领事、神父实际看到什么，依据床位还是熟识，探访如何受限。同症状病人、封闭环境、后来的牙医补盲各有案例保留。证人数不是可靠性公式。
5. **一人两角**：服饰、空间、时间、雇佣数量、口音和活动范围相容；有以换装及从未同场制造疑点的案例。“从未同场”仅为可检验假说，不充分证明同一人。
6. **替身顶罪**：自愿、酬金、胁迫和信念分开，列两人的能力、差异、可拒绝点及认定程序。答应顶替他人姓名不保证司法受骗；亲友接触/身体特征是核验分支，不强制任何探监必验。
7. **列车/船上错认时间**：本组案例共同包含女仆/主人衣物复制、显著小费吸引记忆、看似活着离开、体形反差与错误地点标记。按“实际被看者—被认作谁—何时—何地—何种观察”拆分。小费不等于收买者知情作伪；熟人、面貌、重影、行李、钱款和接站可支持或破坏解释。不能把所有目击一律说成被害人本人，这与女仆替身份支不一致；必须按具体观察事件填入，不能照抄。
8. **多层化名**：每层有使用场合与必要职业/文件，追踪共用物、旧识与记录交叉。三层只是案例，名称多时用警局/雇主/亲密关系区分，不给“绝不留痕”保证。

## MY-02C 证词、记忆和受限通道

证词拆为看/听/感觉到什么、自己推断、谁转述、后来获知、利益和感知限制。记忆被提醒不等于恢复真相；询问方式、串供、共同传闻和记错时间会改变证词。把推断混入描述，把真实片段错接，染血白裙/去渍/熨平事实被读错因果，三者用同一拆分表。

临终留言可真诚错误、直接指认、故意假话、未完成、编码或歧义。误认与“Natalie…not Joyce”多读法各成分支；清楚指认后仍可写证明、手段、救援和后果。血卡、托寄信保留预写/迟得/半解组合，不强迫每条遗言故意模糊。

对被忽视的儿童、仆役、病患与残障证人，画出可说、可被听见、可被受理的路径。错案可以靠层层拒听，也可以靠时间延迟、权力或误解维持；不需堵尽全世界渠道。从法院/警察/律师受阻改私约并邀警长；镜窗和码语是预先可知的替代通路案例。通路要在它承担严格公平解答前可用，不规定案发前数章。

机构问询可分开询问、记录时间与在场者、核自称“像看门狗”的证人与当时在厨房的盲区、要求具体报告，这些动作有原著案例保留。医生护士“职业骗子”的台词只表现该角色对机构口径的怀疑，不成为封闭机构全员说谎规则。

伪证可以护亲、护爱人、自保、勒索、职业压力或钱；相同动机也可有不同选择。保护性否认与反向操作各有案例。多证词可相互冲突，也可完全串好再由独立资料击破；不强制链内一人反水。

## MY-02D 自白的知识、收益与可证伪性

自白逐项核事实、非公开知识的来源、收益/压力、替代取得渠道与反证；知道细节可能来自共犯、泄密、现场旁观，不等于真凶专属。为钱编自白、假供与真供的不同阶段、自供后的解脱，都是情节选项。自白不是天然无效，也不必两次、一假一真或紧接死亡。

严格公平的唯一关键前提不能只靠终局首次自白补入；调查型故事可以由自白推进，再核可信度。真相、可证明、法域可采、裁决和执行各自记账，小说不认证任何现实“无授权必不可采”或“有自白即可定罪”规则。
