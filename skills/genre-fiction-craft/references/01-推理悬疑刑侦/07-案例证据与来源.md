# MY-07 案例证据与来源

## 案例读取范围

本文件汇集代表性案例及其适用限制，用于说明正文规则如何落到具体情节；不构成另一套独立规则。所列案例不穷尽全部推理悬疑作品。

## 需要保留的具体观察及其边界

| 可迁移的具体设计材料 | 应保留的限制 |
|---|---|
| 红领巾识别、后来认定目标；红帽和红珍珠形成颜色回声 | 颜色同类或同源不等于两条独立识别链 |
| 白袜马、相机状态、影像认人、服饰与断指 | “是你”早于具体识别依据公开时，严格解谜需检查是否给足可用信息；影像也需核取得与辨认条件 |
| 身体观察、候选名单、异常感官与握力、时间和皮肤痕迹 | 未先建立的非人能力不能临时充当严格解法；名单长度不自动公平；虚构身体观察不是医学定律 |
| 三十万美元保险调查动机、自白、法语字谜的揭示顺序 | 字谜在自白之后可作余韵或解释，不能回称读者早已能解；保额是本案量，不是商业规律 |
| 私密信息与相貌/亲缘识别 | 只在读取窗口未见回收，不能断言整书无回收；相貌需要替代解释 |
| 梦中声提供直觉、新闻公开私事、自白回收 | 梦不是独立证据；公开改变知情分布；不同作品的材料不能拼作同一案的证据 |
| 删节内容与烟味推断 | 删节须按读者契约评价；气味归属不当然唯一 |
| 射击判断中的看似失准与准确；尸体/鱼和时间线索 | 单书装置可以用，但不能因单例升普遍定律；不同作品的假尸体心理反应另核 |
| 假尸体与心理试探 | 反应有替代解释，不同案的假尸体不混成同一证据家族 |
| 选择性焚毁与概率推论 | 什么被留存/被毁取决于接触与目的；概率台词不提供普遍定量阈值 |
| N.Q.M. 圆牌、数字4与衣鞋反差；缩写的姓名/地址两解及借用衣物假说 | 观察、侦探解释与后续调查分层，只计一书 |
| baritsu 解释人物生还 | 是否违约取决于生还机制是否属于读者被承诺的核心可解谜题 |
| 距离叙述（200 英尺／60 码）可产生检验任务 | 两数换算不一致：200 英尺为 66⅔ 码；不默改原书引文，不据错换算推出时空结论 |
| 胎记；精神暗示叙述 | 此条未独立回原书复核，仅作创作参考 |
| 半烧信的可见/缺失内容 | 判断须按信件实际呈现的具体内容，不按推测补全 |

其他具体案例已随其操作条件进入 MY-01～05，而不是再贴一遍规则卡。

## 引用与身份边界

- 部分作品的作者归属已按题名页核实（如 Fergus Hume、Theodore Goodridge Roberts、Anthony Berkeley 及开头人物 Roger Sheringham 等），旧写法中的误归属不再沿用；这只是有限样本核对，不等于全部原著全文核验。
- 作品范围含早于 1889 年的记录；作者生卒年不能当作品发表年。
- 原著中的版权说明、历史取证规则、当时职业实践与角色观点只作来源背景；不能由它们推出当前法域的著作权、证据可采性或医学事实。
- 所列案例为代表性样本，不穷尽该题材的全部作品与写法；效果推测不能仅凭案例确定，需结合目标读者试读判断，不把虚构情节当作现实侦查、医学或法律事实。
