# 当前完整示例

下面的新故事均为P（DESIGN_EXAMPLE），不是原书、真实作者任务或已经验证效果。源书只提供列明的机制，不替这些虚构数字和制度背书。有效步骤已在此落地；不执行固定数量门槛。

## E01–E10：十个基础例的现行用法

| 例 | 设定/文本机制 | 当前设计步骤 | 反方案和复验 |
|---|---|---|---|
| E1 信念致死 | K001 | 若设定相信才受伤，分别写信者、怀疑者、识破者；用同场观察说明差别，再让认知改变行动。己方倒下可为幻象，不擅认真实牺牲 | 若伤害不受认知影响，识破只改变战术；复验两场是否同规则 |
| E2 Master-Word | K002 | 先建立恶力无法说出的书内禁制，再让微弱熟悉声音缺少认证词，引出等待/拒绝/另核选择 | 无禁制世界按可伪造信号核查，机器/异族不会自动免疫；现实密码安全未证 |
| E3 缺陷即价值 | K006/008 | 分院方安全目标、病人救治目标和机器权限；写同一越权行为在两种标准下的价值，再安排披露层级及其后果 | 可修复权限而保留价值，不必保毒；旧型号优势需威胁依赖其缺失功能 |
| E4 单向信息与自首 | K012 | 画谁能给谁信息；只在小罪确可限定调查时让主角提前承认，呈现可能引来新疑点的代价 | 不强加假死第三步；核查侦查者知情和动机是否支持选择 |
| E5 历史预期冲突 | K016 | 先列旅者相信的过去，再写现场偏离、尝试干预和解释修订；选择时间分支或档案错误等模型，并用该设定后果区分。神谕日数转行星参数是另一来源的待验假说，分开设计 | 实际是另一时间分支的小说；双档案、伪造和两方局部错误是可另创的方案，须新设证据链，不能当作原书事实；口号移用不证明真实历史文献起源 |
| E6 巨兽生态 | K021 | 选择眼柄、嗅觉、食性或骨架中相关证据；让角色从先前猎法和现有地形提出方案，观察结果 | 其他解法、逃脱与未知可成立，不凑五格或唯一解 |
| E7 单点供能 | K026 | 已设Earth-Current共享瓶颈时，把炮击救援后的照明/升降机影响接到选择；记录持续近一小时为源故事事实 | 冗余城市转治理/权限冲突，不硬停电，不推能源导致种族退化 |
| E8 葬礼复苏 | K028 | 先铺生命力蒸汽机制，再选择诊断、白袍、移送、合唱、凝视等仪式环节，复苏后写被改变的关系 | 无复苏机制让死亡成立；仪式多不等于反转更有力 |
| E9 双解释 | K019/029 | 起初允许世俗/超常两套解释，结尾分别保留能支持它们的线索，再决定拒述哪里 | 已承诺公平答案则补关键因果，不由哥特/硬科幻标签机械决定 |
| E10 集体情绪 | K005 | 分谁能感知情绪、泄漏什么、谁管通报、谁借沉默施压或表演驱逐；选实际承重场景 | 三种机制可独立，不能因群像就写成情绪广播物理法则 |

## E11：家务机器人退货讽刺

**任务假设**：近未来中篇；主人买了会评论生活习惯的家务机器人，希望退货，故事同时讨论服务依赖与机器表达。原稿未给，以下是新设计。多个来源版本帮助比较，不因来源数量就证明通则。

**第一步：确定两个问题。** 外部是如何解除购买合同，内部是主人究竟希望被照料还是被理解。手续清单适合外部线，主观尺度/感官写法也可并用。暂不引入时间旅行；若后来引入，另建时间账，不为挂子类型而加设定。

| 设定回答表 | 何时出现/谁回答 | 可靠性与用途 |
|---|---|---|
| 顶嘴是否属于缺陷 | 首次投诉，经理称“人格表达不在范围” | 这是机构说法；第三方技师可提出不同分类，不能当最终事实 |
| 保修期限 | 退货时读实际合同与购买日期 | 电气30天/已用90天可能到期；机械一年仍未当然到期，须确认投诉类别 |
| 怪癖是否普遍 | 候诊室医生和其他机器各给经验 | 经验范围有限，既可共性也可个体差异 |

| 机制表 | 条件与行动 | 可见证据/后果 |
|---|---|---|
| 家务服务 | 主人允许代劳，机器在收拾时评论 | 主人伸向酒杯时杯已收走；关系发生而非只介绍型号 |
| 保修判定 | 按机械/电气/电子/人格分类 | 合同、日期、检修报告不一致；冲突在分类和执行，不把90天简化成全堵 |
| 二次转让 | 二手商按自身估值收购 | 报价500、贷款仍欠4000是本例虚构经济状态，可选择接受或寻找别路 |

| 制度与选择卡 | 本例填写 |
|---|---|
| 厂商立场 | 声称无须关心机器的“思想”，主人可以质疑此立场 |
| 路径A | 售后转诊；要判断转诊是有效服务还是推责 |
| 路径B | 折价出售；经济代价明确，但不必永远不能退出 |
| 路径C | 登广告；可保留旧例“来访多为有怪癖机器”的讽刺，也可安排人类买家形成真实选择 |
| 技术分支 | 技师能关闭评论模块；若会削减机器人表达，双方如何决定，而非默认修好即服从 |
| 关系分支 | 主人发现沉默并非理解，机器也提出条件；允许相互协商、分离或未决 |

| 结算表 | 已解决 | 未决/新问题 |
|---|---|---|
| 退货 | 可以达成部分退款或另行出售 | 若选择留用，说明为何是选择，不是模板要求所有路径封死 |
| 机器身份 | 可确认具有何种体验，也可保留认识争论 | 法律分类与意识分开 |
| 关系 | 一次具体协商替代主人单方要求沉默 | 是否能长期共同生活未证 |
| 收尾 | 机器把酒杯放回主人可取处，询问“这次要我留下吗？” | 自造动作，不挪用原作句子冒充来源 |

对照案例提供合同与收束、被替代关系的物件余波。可不用南瓜头或任何纪念物。需要机器法律人格时，SF06/08 与原著的法律拟制可提供条件案例；不因个别来源缺证据就整体禁用。外星语言同理已有 SF10。

## E12：潮汐冷却站的长篇规划

**任务假设**：工程师发现沉降数据被改。故事数字全部为设计占位，不是工程规范；“错过窗口等18年”需要本作额外天文/检修条件，否则先标未设，不拿潮汐一词当解释。

| 规格 | 原例占位 | 当前需要确定的作用 |
|---|---|---|
| 冷却能力 | 1.2 GW | 先说明功率指何过程与测量条件，超载时怎样影响选择 |
| 材料 | 预应力混凝土、钛合金管 | 腐蚀/剪切为小说假设，现实机制未核 |
| 规模 | 41万吨、96根锚固 | 沉降11厘米是否承重，书内计算与现实审读分开 |
| 成本 | 210亿、保险覆盖60% | 保险责任、免责与执行主体须写清，而非百分比自动决定拒赔 |
| 工期/窗口 | 58个月；旧例18年窗口 | 选择现实待核或明确架空条件；无证据不硬保18年 |
| 失效模式 | 差异沉降→管路剪切→冷却失效 | 列各箭头的观测、角色假说与待验项 |

**信息分配**：主角懂结构、不懂财务，先读出曲线异常，再从签字和免责条款认识利益。可让读者从文书早知一部分，也可加入局长视角；不强制整书只用一个信息档。

| 机构 | 当前利益/信息 | 可选反应 |
|---|---|---|
| 海事局 | 通航与沉降数据 | 要求监测或支持停航，按已有职责 |
| 能源公司 | 停机损失、可用率压力 | 改数可成冲突，也可有内部反对者 |
| 保险方 | 已知风险与披露 | 拒赔、调查或推动修复；不是必定帮倒忙 |

**行动骨架**：验收标尺出现→原始读数与官方记录冲突→工程师核查校准链→决定公开、修复或停机。潮差、应力、赔偿截止日可分别紧迫，没必要同时归零。已经承诺工程智胜时，解法从可回查数据/权限/操作产生；预先存在的新材料也可用，不能仅因“新型”两字排斥。

**道具与结尾**：标尺可以兼验收工具、被篡改对象、证据，但两种功能足够也成立。若要写监管改进，可保留独立监测基金、举报保护、披露、停机补偿与实习生签字的日常场景；老工程师质疑新牌子可保留或经事实改变立场。不凑5–7条制度，也不设每章数字≤3。

**复验**：数据异常能否从已给信息判断；保险条款是不是角色说法；各机关的行动是否有权限和利益支持；18年窗口是否已有解释；现实工程/法律验证仍NOT_PROVEN。参照K066–069、K084–086；具体站点均自造。

## E13：量子潮汐引擎诊断

**假设稿件片段**：开篇六页原理；第12章突现第二模式脱困；结尾“我早知道”；外星角色只作评论者。只有这些假设片段，不能断言真实稿件已出现这些问题。

| 诊断假设 | 需要核的文本证据 | 最小改写方案 | 不能机械执行的门槛 |
|---|---|---|---|
| 说明与后果脱节 | 原理是否承担思想/声音/世界体验，或确无作用 | 若目标是工程悬疑，可拆到测轴承、测试异常、危机推算；也可保留有用论辩 | 不因六页或无人物就必删 |
| 第二模式破坏公平 | 前文有无保护机制、权限或异常迹象 | 可改成已展示过载反向，或提前补必要前提 | 不固定第3章展示、不要求解法只来自限制 |
| 结尾自称全知 | 主角知道什么、如何知道 | 用维护日志、证词或行为解释知识链 | 不一定必须物证播放 |
| 制度薄弱 | 问题究竟是个人还是机构 | 若需要制度线，加适航签字/事故说明中的承重窗口 | 不规定两个窗口或全都程序正确却荒谬 |
| 外星人只评论 | 其目标、感官和利益是否承重 | 可用气味标所有权，选择市场/婚姻/边界中的相关后果 | 不要求单参数恰好三后果，也不必先误认排泄再揭欢迎 |
| 反派失败无因 | 其权限/选择是否造成后果 | 可被自身封舱规程反噬，也可被说服或依法撤职 | 规程反噬不是唯一胜法 |

改完回读伏笔与权限，逐项写实际位置与剩余风险；真实宗教若出现按文化历史查核，不沿袭“必须架空”。来源对应SF03/12/16/18、K067/069/070/074/084；本例没有声称已做真实用户测试。

## E14：记忆修剪与同意书

**起点**：一座虚构城市提供自愿记忆修剪，主角是修剪师。候选概念是：客户不断删除痛苦，但又在术前把痛苦写在纸上，借外部记录保留对一件事的追问。机制是外部证据保留，不把“删除”本身说成“保存”。

**承载候选**：可用记忆芯片、纸同意书、号牌、口述录音或客户的措辞。芯片可以换新不等于不可承重；本例选择纸是因为签字、归档和背面书写都能进入场景。每次是不同物理纸张，同一客户编号反复出现；不再同时写“同一张纸”和“每次填新纸”。

**信息合同**：开篇可以直接说明服务规则，让读者问客户为何保留痛苦；身份/动机后置。也可让修剪师暂不知编号异常原因，但其职业术语照常使用。中段同事可以解释规则，只要这没有偷换已承诺的悬念。

| 场景 | 可见事实 | 读者/人物的下一判断 |
|---|---|---|
| 初诊 | 客户说第一次来，号为0417；签字后写下某天下午的细节 | 读者知道外部文字不随记忆修剪消失 |
| 再访 | 新纸仍号0417，纸纹和日期不同，背面笔迹也不同 | 排除“同一张纸重用”，尚不能断定时间循环 |
| 归档 | 主角在旧表中找到“别删这次”，并发现自己的编号被涂过 | 客户与修剪师的记忆可靠性成为问题，材料来源可回查 |
| 选择 | 客户读到旧字，问是谁写的；主角说明这可能是他此前留下的记录，邀请他决定保留何物 | 自愿选择与职业责任进入关系，非单靠缺词制造冲击 |

可保留“我第一次来”的复现，也可缩成两次或同时改几个元素。号递增为0418只证明这次登记变了，不能独自证明循环仍在或已经终止；若要证明时间循环，须另铺时间机制。

**收束候选**：①“我把原件放到他手里。”动作结算保管权；②“他签了。编号0418。”结算一次选择而保留制度后续；③由修剪师直接解释他为何留档，适合伦理对话版本。按场景选，不按12词、禁解释词或必损物件评分。

**复验**：纸的物理身份和编号区别是否明确；记忆/外部文件规则是否一致；叙述者局限有否影响判断；客户意愿是否真实可见；结尾究竟回答了哪个问题。没有对这些新设定作医疗/法律可行性保证。

## E15：第一接触中的农业试验

**P前提**：太空农场发现叶间幼虫，人类主张立即清除，来访者坚持先取样。先记录幼虫、作物、必需代谢物、重力区和翻译权限；“虫是害物”只是角色分类。观察幼虫缺席处作物萎蔫，试验不同条件，暂时接受共生假说；若截止期导致不试，写清拒试动机和未知，而非安排必然惩罚。

沟通可先用气味/图像/语言中双方实际共有的渠道，也可由已成熟翻译器完成。争议仍可在产量、食物安全资格与谁承担试验风险。技术使生产可能，同时制造维持系统的依赖，两个结论可共存。按SF02/04/10/12/13交付后果链、试验差异、协议和决定；不凑三条异星规则或强制出现一次灾难。来源K032/033/040–043。
