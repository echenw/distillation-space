# 科幻未来：规则、主体、社会后果与概念揭示

本题材整合五个同题材来源版本的规则、条件与反例。使用顺序是确定作品承诺，再选择承重机制。工程、寓言、行星冒险、异文化、制度讽刺、机器人、时间旅行与概念短篇可以混合。

| 当前任务 | 入口 | 可交付结果 |
|---|---|---|
| 构思与世界规则 | [融合规则](fused-rules.md) SF01–05、SF11–15 | 设定/后果/利益/边界表 |
| 机器、身份、第一接触 | SF06–10、SF20；[具体机制](knowledge-details.md) | 主体证据、核查与沟通场景 |
| 推理、说明、概念揭示 | SF16–21 | 信息合同、可回溯线索与揭示方案 |
| 冒险、关系、灾后和结局 | SF22–27 | 行动状态表、关系证据和分层结算 |
| 诊断与失败出口 | SF28、[流程](workflow.md) | 假设方案、分支与 NOT_PROVEN 隔离 |
| 完整执行/改稿 | [流程](workflow.md)、[模板](templates.md)、[现行示例](examples.md) | 原创方案或有位置的诊断与修订 |
| 历史条件与写作边界 | [历史边界](historical-boundaries.md) | 时代立场与现代写作的区分；关键原文更正 |

当前规则、知识细节、模板和示例可独立执行。个案中的“必须”和固定次数不应直接视为普遍要求。所列案例为代表性样本，不穷尽该题材的全部作品与写法，不声称真实宿主或市场效果已通过。

关键原文更正与不确定断言见[历史边界](historical-boundaries.md)。
