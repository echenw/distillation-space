# 现代言情：常见类型、感情线节奏与人设（RO-36 至 RO-50）

返回 [guide.md](guide.md)。

本文件补充现代中文言情和网络连载中的类型契约、感情线推进节奏、人物塑造与边界。这里的内容是可选写作方法和题材惯例，不是市场统计或读者效果保证；“读者会……”的说法都应作为待验证假设。类型名称可以帮助建立契约；不要照搬某一现成作品独有的人物和情节。

每条后面括号里注了对应的通用规则（RO-01 至 RO-35，见 [rules.md](rules.md)）。同性之间的言情同样适用这些方法，另外要按本作的时代和世界写清社会条件。

## 一、常见类型：每种类型承诺了什么

类型是对读者的承诺。先确定这部作品承诺的是哪一种，再看这一章有没有兑现它。可以混合，但主类型要清楚。

### RO-36 先确定类型承诺，再设计阻力

**什么时候用：** 开新书，或者读者说“和我想看的不一样”。
**怎么做：** 用下表选主类型，写下它的核心承诺和这部作品的主要阻力。阻力要和承诺对得上：甜宠的阻力不该是互相伤害，虐恋的阻力不该一次谈话就能解决。
**交付：** 一句话的类型承诺，加主要阻力和终局方向。
**注意：** 类型标签只是起点。同一类型里，阻力来源（外部的家庭、阶层、职业，还是内部的性格、创伤、价值观）决定了故事的气质（RO-02、RO-05）。

| 类型 | 核心承诺 | 常见阻力 | 要小心的地方 |
|---|---|---|---|
| 甜宠 | 关系稳定、互相珍视，看两人怎样相处 | 外部的小麻烦、身份差、工作；关系内部的阻力轻 | 没有阻力会变成流水账；“宠”不能写成控制 |
| 虐恋 | 强烈的情感代价，读者跟着痛 | 误会、立场对立、伤害、生死 | 虐要有原因和代价，不是作者随手折磨人物；伤害不能被包装成爱的证明 |
| 追妻火葬场 | 一方先伤人，后来付出代价、真正改变，才被重新接受 | 被伤害的一方不愿回头；伤人的一方要改的是根上的问题 | 改变要有证据；被伤害的一方有权不原谅；读者要的是“代价”，不是一句道歉 |
| 先婚后爱、契约婚姻 | 从没有感情的关系里慢慢长出感情 | 契约条款、彼此的边界、外人的眼光、各自的秘密 | 契约的条件和退出机制要写清；感情变化要落在具体的相处里 |
| 破镜重圆 | 曾经相爱、分开过的两人重新走到一起 | 当年分开的原因、这些年各自的变化、新的生活 | 当年的问题必须被正视和解决，不能靠时间自动抹平 |
| 欢喜冤家 | 互相看不顺眼，在斗嘴和交锋中靠近 | 立场、性格、竞争关系 | 斗嘴要势均力敌；不能一方一直羞辱另一方 |
| 青梅竹马、双向暗恋 | 早就有感情，看两人什么时候说破 | 不敢说、怕失去友情、时机、第三者 | 拖延的理由要可信；说破之后要有新的戏 |
| 职场、行业 | 爱情和事业在同一个场景里交织 | 职位差、竞争、职业规范、公私冲突 | 职业细节要可信；不能让工作只是背景板（RO-04） |
| 豪门、身份差 | 跨越阶层的关系 | 家族反对、财产、门第、自我怀疑 | 写清反对者实际能控制什么；金钱和意愿分开写（RO-04、RO-05） |
| 古言、宫廷 | 礼法和权力之下的感情 | 婚姻制度、家族利益、宫廷斗争 | 时代的规矩要一致；现代观念的人物要有来由（RO-32，史实转历史题材） |

### RO-37 甜宠：没有大阻力时，戏从哪里来

**什么时候用：** 写甜宠，或者读者说“太甜了没意思”“流水账”。
**怎么做：** 甜宠的戏来自“相处里的小变化”：第一次知道对方的某个习惯、第一次为对方妥协、第一次吵架又和好、第一次见对方的家人朋友。每一章至少给一个两人关系里的新东西。外部的阻力负责节奏，两人一起面对，关系就更近一步。
**交付：** 一张“第一次”清单，标在哪几章兑现。
**注意：** 宠的方式要和人物的性格一致；读者喜欢的是“这个人用他的方式在乎她”，不是钱和权力的堆砌。宠和控制的界线：替对方做决定、限制对方的社交和行动、不经同意介入对方的事业，即使出于好意，也是控制（RO-15、RO-19）。

### RO-38 虐恋和追妻火葬场：伤害、代价和改变

**什么时候用：** 写虐恋、追妻火葬场，或者读者说“男主（女主）这样都能原谅？”
**怎么做：** 分开四件事：伤害是什么、伤害者当时为什么这样做、他后来付出了什么代价、他真正改变的是什么。改变要落在行为上，并且要在没有人看着、没有回报的时候也成立。被伤害的一方回头，要给她自己的理由：不是因为对方痛苦，而是因为她看到了真实的改变，并且她自己愿意。
**交付：** 一张“伤害—代价—改变—接受”表，每一栏落到具体的章节。
**注意：** 读者最反感的是伤害很重、代价很轻、原谅很快。被伤害的一方也可以最终不原谅，这同样是一种完整的结局。伤害不能被写成爱的证明，强迫不能被后来的相爱追认（RO-15、RO-27、RO-28）。

### RO-39 先婚后爱和契约关系：条件、边界和退出

**什么时候用：** 关系从契约、联姻、假扮情侣开始。
**怎么做：** 写清契约的条件（期限、各自的义务、对外怎么说）、边界（哪些事不做）、退出的办法和代价。感情的变化要一点点越过这些边界：本来说好不干涉对方的私事，后来忍不住管了；本来约好期满离婚，后来开始害怕那一天。
**交付：** 契约卡，加一张“哪一章越过了哪一条边界”的表。
**注意：** 契约的存在本身就是悬念：期满那天会怎样？要提前埋下期满的时间点。越过边界之前，最好有一方意识到自己在越界（RO-07、RO-17）。

## 二、感情线的节奏

### RO-40 感情线的几个阶段

**什么时候用：** 规划一条感情线，或者读者说“进展太快”“太慢”。
**怎么做：** 把感情线分成几个阶段，每个阶段有自己的标志事件：

| 阶段 | 标志 | 这一阶段的戏 |
|---|---|---|
| 相遇 | 第一次见面，或第一次真正注意到对方 | 第一印象，最好和后来的认识形成反差 |
| 靠近 | 因为某件事不得不相处 | 发现对方的另一面，开始在意 |
| 暧昧 | 双方都有感觉，但没说破 | 试探、误会、吃醋、心跳的瞬间 |
| 确认 | 说破、在一起 | 告白、接受，或者被打断 |
| 危机 | 一个让关系面临破裂的事件 | 误会、外部压力、价值观冲突、秘密曝光 |
| 修复与承诺 | 两人共同面对，或者分开后重新选择 | 真正的理解和选择 |

每个阶段的长度按作品的类型和篇幅来定。
**交付：** 感情线阶段表，标出每个阶段的起止章节和标志事件。
**注意：** 不是每部作品都要走完所有阶段，也可以反复（确认之后又退回暧昧）。读者说“太快”，通常是某一阶段的标志事件缺了，比如没有靠近就直接告白；说“太慢”，通常是同一阶段重复了几次却没有新东西（RO-17、RO-19，长线排布转 `story-architecture-and-longform-planning`）。

### RO-41 心动的瞬间：写身体和细节，不写结论

**什么时候用：** 写暧昧、心动、亲密的场景。
**怎么做：** 不写“她心动了”，写让她心动的那个细节：他记得她随口说过的一件事、他在人群里先看向她、他递东西时手指碰到了一下。再写她的反应：身体的、动作的、说出口和没说出口的。
**交付：** 一场心动戏：触发的细节、她的反应、她怎么掩饰或者没能掩饰。
**注意：** 心动的细节最好是这两个人之间独有的，换一对人就不成立。亲密场景的尺度按作品的定位和平台的规范来，但同意始终要清楚：可以是含蓄的，不能是模糊的（RO-15、RO-21）。

### RO-42 糖和刀的搭配

**什么时候用：** 读者说“一直在虐”“一直在甜”，或者作者想规划情绪的起伏。
**怎么做：** 把每一章标成“糖”（关系变近、甜蜜）、“刀”（关系受伤、痛苦）或“平”（推进剧情）。看一段时间里的分布：长时间只有一种，读者就会麻木。刀之前给一点糖，刀才更痛；刀之后给一点糖，读者才有动力继续读。
**交付：** 一段章节的糖刀分布表，以及调整建议。
**注意：** 这只是一个检查工具，不是公式。主类型决定了大致的比例：甜宠以糖为主，虐恋以刀为主。重要的是每一刀都有原因，每一块糖都推动了关系（RO-19、RO-33）。

### RO-43 吃醋、误会和第三者：让它推动关系，而不是原地打转

**什么时候用：** 用吃醋、误会、情敌来制造冲突。
**怎么做：** 每一次吃醋或误会，都要让关系向前或向后走一步：通过这次误会，一方意识到自己的感情、两人第一次坦白、或者发现了对方的某个秘密。情敌要有自己的目标和理由，不只是为了制造误会而出现。
**交付：** 误会卡：起因、为什么没能马上说清、解开的方式、解开后关系有什么不同。
**注意：** 读者最反感“一句话就能说清却拖了十章”。拖延的理由必须可信：没机会说、说了对方不信、说出来会伤害别人、人物的性格就是不肯说。解开之后，读者想看的是两人怎样处理这件事暴露出来的问题（RO-09、RO-12）。

### RO-44 连载里的感情线：每章的推进和章末的钩子

**什么时候用：** 连载的感情线，读者说“这章没进展”。
**怎么做：** 每章检查一次：这一章里，两人的关系有没有一点点变化（多知道了对方一点、多了一次身体的接近、多了一个误会、多了一个共同的秘密）。章末可以停在关系变化的前一刻：他要说出口的时候被打断、她终于决定去见他。
**交付：** 每章的关系变化一行，加章末停在哪。
**注意：** 不是每章都要有大事，小变化也算。章末的钩子用多了会让读者疲倦，要隔一段时间兑现一次（单章节奏转 `scene-conflict-and-rhythm`）。

## 三、人设与边界

### RO-45 男女主的人设：势均力敌和各自的生活

**什么时候用：** 设计主角，或者读者说“女主（男主）太弱”“工具人”。
**怎么做：** 两个主角各填一张卡：自己的目标（爱情之外的）、擅长的事、弱点和伤口、对爱情的看法、在这段关系里最怕什么。两人的目标和弱点最好能互相触动：她的长处正好补上他的弱点，他的伤口正好被她的某个习惯碰到。
**交付：** 两张人设卡，加一张“两人怎样互相触动”的表。
**注意：** 势均力敌不是能力一样，而是两人在关系里都有自己的分量：都能做选择、都会付出、都可能伤害对方。一方只是另一方的拯救对象或奖品，关系就失衡了（RO-03、RO-13）。

### RO-46 霸总、病娇这类强势人设：魅力和越界的界线

**什么时候用：** 写强势的、占有欲强的人物。
**怎么做：** 分开人物的魅力和人物的越界。魅力可以来自能力、专注、只对她一个人的温柔；越界是不顾她的意愿：限制自由、监视、威胁、强迫。作品可以写越界，但要清楚它是越界：被越界的一方有反应，越界有后果，叙述不把它当成浪漫。
**交付：** 人物卡上加两栏：他的魅力在哪、他的越界在哪、作品怎样对待这些越界。
**注意：** 黑暗的关系可以写，但不要把强迫和控制写成“他太爱她了”的证明。是否把这种关系当成理想来推销，是作者要自己决定的价值问题；这里只要求作品自己知道它在写什么（RO-15、RO-28；涉及未成年人物时按 [CY-01](../12-children-youth/rules.md) 处理）。

### RO-47 女性成长线：爱情之外她要什么

**什么时候用：** 女主的故事只剩下恋爱，或者读者要“大女主”。
**怎么做：** 给女主一条和爱情并行的线：事业、复仇、家族、自我认同、某个具体的梦想。爱情线和这条线最好互相影响：爱情帮她成长，也可能让她面临选择；她在这条线上的成长，也改变了她在关系里的位置。
**交付：** 女主的双线表：爱情线和成长线在哪几章交汇、哪里冲突。
**注意：** “大女主”不等于没有感情或者感情不重要，而是她的选择推动故事。她不需要在每一场交锋里都赢（RO-02、RO-13）。

### RO-48 配角和 CP 群像

**什么时候用：** 有几对 CP，或者配角的感情线。
**怎么做：** 每对 CP 选一个和主 CP 不同的类型或阻力，形成对照。配角的感情线可以用来展示主角没有走的那条路。
**交付：** CP 对照表：每对的类型、阻力、结局，以及和主 CP 的关系。
**注意：** 副 CP 的戏不能抢走主 CP 的关键时刻。群像言情要按卷管理：每卷有一对的线是主线（RO-30）。

### RO-49 结局：读者被承诺了什么

**什么时候用：** 写结局，或者读者对结局不满意。
**怎么做：** 回到 RO-36 写下的类型承诺，检查结局有没有兑现。甜宠和大多数网络言情承诺的是“在一起”；虐恋可以是悲剧，但悲剧要有意义；开放结局要在前面就埋下伏笔。番外和后日谈可以补上读者想看的婚后生活和配角的结局。
**交付：** 结局对照：承诺了什么、结局给了什么、番外补什么。
**注意：** 违背类型承诺的结局（甜宠写成悲剧、HE 写成 BE），读者会觉得被欺骗；如果作者坚持，要在前面一路埋下预兆，让结局有迹可循（RO-29、RO-30）。

### RO-50 改稿时最常见的几个问题

**什么时候用：** 诊断一部言情稿子。
**怎么做：** 按下面的顺序检查，找到问题后回到对应的规则：

| 读者的反馈 | 可能的原因 | 先查 |
|---|---|---|
| 没有化学反应、不知道他们为什么相爱 | 心动的细节太泛，两人之间没有独有的东西 | RO-41、RO-45 |
| 进展太快、太突然 | 某个阶段的标志事件缺了 | RO-40 |
| 拖沓、原地打转 | 同一阶段重复，误会拖得太久 | RO-40、RO-43 |
| 男主（女主）不讨喜 | 越界被写成了魅力，或者没有自己的生活 | RO-45、RO-46 |
| 原谅得太容易 | 伤害重、代价轻、改变没有证据 | RO-38 |
| 结局不满意 | 没兑现类型承诺 | RO-36、RO-49 |
| 女主只会谈恋爱 | 没有爱情之外的线 | RO-47 |

**交付：** 按规则的诊断，加具体的修改方案；有原稿时写明位置（RO-35）。
