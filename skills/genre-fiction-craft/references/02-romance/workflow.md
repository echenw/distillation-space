# 设计、写作、改稿与做不到时

返回 [guide.md](guide.md)。

## 1. 固定当前工作对象

记录用户要构思、场景、章纲、续写、诊断还是重写，已有媒介/时代/人物/篇幅、爱情的结构位置、作者希望的结局或尚未决定之处，以及不能改的设定。没有稿件仍可原创；只有概要时不能报告具体句段缺陷。用户已授权的范围直接完成，不为填满模板反复停下来确认。

输出一段任务说明，例如：“为林澈一年外派与周岑照护责任设计八个可调整场景，关系可继续或结束，工作与照护均保留独立价值；没有原稿，以下是设计。”作者可以先定结局，也可以比较试写结果后选择。

现代言情先按 [tropes-and-serial.md](tropes-and-serial.md) 的 RO-36 定下类型承诺，再往下做。

## 2. 分关系、资源和资格

给关键人物分别写自己想做什么、想要怎样的关系、当前能决定什么。列实际相关的金钱、住所、职业、时间、照护、婚姻身份、家族与社群规则。区分唯一控制人、分散制裁、内在边界和无人可撤销的条件。每项记录对象、成立条件、可用动作、限制和预计结果；未确定处标假设，不强造一外一内或三种成本。不为凑阻力把本来支持人物的亲友硬写成反对者；阻力应与已建立的目标、资源和边界相接。

让金额进入场景前先问它是否真的改变人物选择；要写数字，就让它能被人物复述，复述时的语气比数字本身更重要。口号式的婚配要求可以由不同人物重复，但每个重复者都要有自己的利益，否则像合唱团。

输出人物目标表、阻力表及“关系愿意但资格不具备”“资格具备但不愿”“信息不全”“目标冲突”“尚未决定”等适用状态。现实制度若承重但未核，故事内先明确架空条件或保留待核点；不能借历史小说给现代法律结论。

## 3. 建信息、传递和证据表

分别写读者、当事人、家长、中间人、机构知道和误以为什么，何时得知。给关键秘密记归属、利益相关者和披露风险；给信件等记录真实性、传递、接收、解释与效力。单层误会可直接解决，多层要有不同因果，不用数量制造复杂。误读先分三类再修：对称错位，双方各有可指出的错误判断，一次新证据可以同时触及两侧；权力不对称，一方掌握住房、工作或安全等条件，另一方的判断受其影响，先恢复弱势方的自主，再谈解开误读；被制造并维持，有第三方在贴标签、递话或构陷，先拆制造机制，例如换一个信息源，或安排制造者在可被听见的场合自述其所作所为，再谈修复，并且不让制造者继续充当信息通道。判断项材料不足时逐项写未知，不自动落回“一场误会”的解法。对无力改变局面的持有人，保留悲剧/制度分支，不自动删信息差。

输出一条可实施的场景链及替代路径：本人解释是否足够；若不足，是证据、信任还是权力不足；新信息改变了哪层，其余冲突为何仍在。不同答案不能全部由“缺一封信”包办。

涉及申诉、指控或公开澄清时，先判受理方对争议结果有无利害关系。中立时，书面陈述、见证或文书可作候选载体，并核对发送者是否可能知晓该事实、材料是否到达、接收者有无验证机会；受理方本身就是当事一方或已卷入构陷时，向它申诉与“澄清信”两条路整体失效，改走让有权处置者当场对证或亲耳听到，并为可能被牵连的人预先安排退出路径。以婚姻或承诺交换争议撤回时，制度争点仍需独立解决，受影响的第三方要有机会质疑。

秘密场景可按三段安排：决定段写清持有人是否说、何时说，以及理由与代价预估；维持段让保密至少产生一次具体麻烦，例如错过一次见面或被第三人先知道；破裂或揭示段写清是谁选择透露、谁意外发现或哪项制度迫使公开，不把责任默认落在某一方的疏忽。

## 4. 设计相遇、互动、等待和转折

按作品选择初遇、旧识、关系中场或危机入口。每个承重场景记录入场关系/知识/情绪、人物尝试、回应和离场变化。变化可以小而内在，不必争吵、失去或权力易手。重复场景/信物需分清是否同一物、同一问题以及这次增加或维持了什么；静态余韵也可有意保留。

会变化的信物常见四类：会枯或会变色（用状态标记关系阶段）、会丢会还（丢失与拾还制造再遇）、会当会赎（进出当铺同时标记经济与关系的起落）、会传会错（误投、截留或迟到推动信息差）；选哪类由故事的时代与通信条件决定。若人物把信物解读为预兆，后文可以兑现、反驳或重新解释这层解读；信物只承担好看而不承担任何代价时，会退化成装饰。

等待、离场与返回记录双方承诺、期限是否已知、生活变化及实际行动路径。回归不是必要步骤，人物可以兑现离开。若作者要快速团圆、日常恋爱或纯内心冲突，不加与目标无关的外部磨难。

## 5. 写告白、拒绝与回应

先确定说的是感情、交往、结婚、契约还是身份声明，再选公开/私下、直说/含蓄/文书/代理。描述可辨认的自愿或压力，不将手势、眼泪、沉默、支付或第三人许可直接翻译为同意。拒绝可以一句话；若解释，按人物愿意透露的范围，不强加自责和代价。

输出完整候选场景，并说明哪些是作者设定、哪些是角色相信。若角色被锁住、受威胁或为救人而答应，保留其真实意图与控制条件；可继续写黑暗/复杂关系，但不要在分析里将其换名成自由同意。人物将来改变，需要另有新的选择证据。

坦白、告白或拒绝要成立，须同时具备出口与接收端：出口指当事人能说、能走；接收端指对方愿意听、听了不报复、也不把内容转用于伤害。另核两项：威胁或依赖是否仍在，拒绝之后当事人的生活能否延续。任何一项缺失，先补该缺口或如实记为未定，不把只有一半的退出写成已完成的选择。

长期搁置或迟到后的告白，给一个可读出的时点理由：条件变化、第三方介入、期限届满或失去了原先的借口，都可以解释为什么是现在；读者判断的是这一次的时点是否被解释过，不是迟不迟。同一场面里的两种动作分开写：用条件压价（强调对方缺少承受的能力或资格）得到的是对条件的回应，直接陈述此刻的意愿得到的是对意愿的回应；两条分支都能成立，选择哪条由作者定。

## 6. 分层结算

分别结算关系意愿、法律/经济资格、家族/社会承认、伤害修复、独立目标和未决争议。人物可得到净好转，不需要凑损失数；同时检查哪些得失真的由其选择导致。宽恕、澄清、停止复仇、追责和继续交往不自动绑定。

再选择停笔范围：婚礼、日常、离开、死亡余波、后日谈、明确停述或开放争议。关系结束而故事继续、关系延续而叙述停止都可以。婚后冲突和反高潮按需要选择；照护者、病者、孩子和第三者保有自己的生活，不能只作移除障碍的工具。

若终局是人物在外部障碍消失后仍选择不结合，按同一顺序搭：先写清障碍怎么真的消失（判决、期限届满、对方退出、继承落定），再让人物自己说出一个拒绝或放弃的句子，然后用一个旁人能看见的小动作把“不动”固定下来（转身回程、坐下不走、寄出、焚毁）。代价的呈现参考关系代价账本的“由谁说出”栏；让旁人看见具体损失，好过当事人自陈“我牺牲了很多”。事故与突发事件可以改变人物处境，但不能替人物作出这个选择（RO-29、RO-K060）。

## 7. 诊断和改写

有稿时按“具体位置→症状→作者目标→可能机制→修订→损益”交付。先区分故意慢、反复/执念、人物偏见、不可靠叙述与实际逻辑错误。不能把“第三章必改、评论不超5%、信件不超10%、误会一次/两层”这类固定阈值当失败标准。只有不同修订确有取舍时才并列方案，不为形式强造两案。

已有的例子写错了，就改动作、表格和结论本身。比如聘书只能证明收入，不能平白洗清罪名；救人时的假答应不能当接受；牧师抗不了舆论不能记“舆论失效”；死者前配偶不可能参与未设复生的复合。必要证据不足就缩小断言并保留待核，不用一段免责声明包住仍错误的步骤。

## 8. 交付合同与停止条件

交付包括适用规则ID、实际设计/候选片段或定位修订、关键假设、必要引用定位及未决项。若只求一个短场景，只交相关字段；需要完整章纲才展开多层表。原稿修改按用户授权进行；本题材的输出不声称市场验证或真人试读效果。

| 状态 | 触发 | 先完成能做的部分，然后 |
|---|---|---|
| 缺原稿 | 要逐句诊断却没原稿 | 给假设式设计或诊断框架，缺具体定位明确说明 |
| 交作者决定 | 价值或结局两案都成立 | 提供已写成的候选与取舍，由作者选择；不自动定其偏好 |
| 证据不足 | 定位冲突、现代制度/效果无证 | 保留来源范围或假设方案，列最小补证需求 |
| 回当前文本能裁定对错 | 当前文本核对能裁定错误 | 修全部当前入口，并说明修正前后的差异 |
| 本次完成 | 当前授权交付已具体完成 | 报实际交付范围与未验证项 |

某一部分做不到，不意味着整项任务停做；局部缺证与整体创作能力分开。本题材提供的是创作方法与历史机制材料，不替作者或现实制度裁定一切。

### 可证伪的公开承诺（可选装置）

在适合的关系线中，可让核心人物较早公开表达一个可被后续行动检验的立场，并在结尾兑现或有意识地反转。设计时明确：

- **承诺内容：**人物究竟承诺做什么或绝不做什么？避免只有情绪、没有行动含义的宣言。
- **检验条件：**什么事件、选择或期限会证明承诺是否成立？
- **代价与见证：**兑现或反转会付出什么代价，谁会看见结果？
- **结尾处理：**以行动兑现，或用有因果铺垫的选择反转；不能只由旁白宣布改变。

原创示例：人物公开说“我不会为了任何关系放弃自己的工作”，结尾的选择可以证明其坚持、调整边界或重新定义承诺。此装置不是每段恋爱线的必选结构。

另一种可选形式是让一方在关系最热时说出具体代价（例如“和我在一起，你可能要面对长期异地、公开身份或照护责任”），后文让其中一部分因果得到验证。预言必须基于当时可知的信息，不是宿命论；地位不对等时不能用它迫使对方当场接受。


### 三行关系基线（可选工作表）

为每个核心人物各写三行，帮助把抽象情感转成可观察的关系条件：

1. **我现在想从这段关系得到什么？**
2. **我目前不愿为这段关系付出什么代价？**
3. **在当前阶段，我实际能给这段关系什么？**

在重大事件、承诺、背叛或关系转折后更新三行。人物的答案可以矛盾或变化；不要把它当作固定人格标签，也不要强迫所有角色都能清楚表达。

### 关系初遇的五种机制

初遇可以由不同机制触发，选择最能暴露人物边界的一种：共同目标、利益冲突、误认/误会、共同见证某件事、或边界协商。初遇结束时至少留下一个可继续发展的事实：未解决的分歧、交换的承诺、共同秘密或下一次接触的理由。

**可选的具体入口载体：**拾物/误拾可引出好奇；当众受辱可留下不甘或权力问题（羞辱不是可靠的吸引手段）；隔界窥见可建立边界与禁忌；共读/共享小众兴趣可建立同盟；似曾相识可触发记忆或宿命感。它们是表面载体，不取代人物目标、同意与后续行为验证。

选用某个入口载体时的检查：拾物/误拾要给拾还者一个不必解释的在场理由，物件若承担身份或记忆功能，应属于实际持有者并带可回收的信息；当众受辱要承认被取笑者的感受，若取笑者是潜在恋爱对象，越界后果与被取笑者的边界要写进后续；隔界窥见的边界要具体（门、窗、帘、车厢），第一次给多少信息由当前悬念决定；共读或共享小众兴趣要能映射两人的核心分歧，不能只是掉书袋；似曾相识在后文要给出可验证的来由（旧照、旧信、共同熟人），否则像装神弄鬼，可以由一方质疑，也可以用行动检验。


### 间接介绍与第三方视角

追求者或潜在伴侣可以先通过他人的评价、行动或故事进入读者视野，但第三方介绍不能替代当事人的真实行为。让后续直接互动验证、修正或推翻旁人的印象；避免把社会声望当作人物品质的证明。

在告白或求婚场景中，被追求者也可以先复述、补完或替对方说出其来意，再决定回应。这能表现识别力与场面主动权，但不代表同意；随后仍要给出清楚的自愿答复或拒绝。


### 延迟送达的信件与信息

信件、留言或其他延迟信息可以制造时间差。规划时检查发送者、传递路径、中间人、延误原因、送达时机、阅读者解释和可核验的物理痕迹。信息延迟必须改变人物选择或读者理解，不能只靠误会拖延剧情。

若分离由外部日程决定，可明确调令、学期、航期、审理或约定日期，并给出可追踪的时长。把信件旅程拆成发送、中转/截留、送达与阅读时点，标记每一站谁知道什么、留下什么痕迹；不要只靠一句听错或误会把等待无限拉长。


### 叙述评论者的声音契约

若作品使用直接评论、对读者说话或带人格的全知叙述者，先明确其知识范围、语气、价值立场和介入边界。评论可以制造距离、幽默或判断，但不能在需要人物行动承担后果时替人物作结论。

若全知评论承担社会批评，可给评论者可辨认的人格：自嘲、讥讽、直接称呼读者或稳定的价值立场均可。人格化不等于必须插话，也不等于每个判断都正确；先确定知识范围和介入边界，避免评论变成无来源的论文腔。


### 障碍的最小表达

每个关键关系障碍可先压缩成一句话，并明确：阻碍者/阻碍力量、具体对象或规则、以及它阻止了什么行动。若一句话无法说明障碍，通常需要先拆清人物目标、资源和边界，再写复杂冲突。

**一人、一物、一句话**可作快速起步模板：一个有权拒绝或改变局面的行动者；一件双方争取、保管或无法交付的具体物件；一句给关系定性、暴露立场或造成伤害的话。三项可以缺一或替换，不是必须凑齐的公式。

展开障碍时再补两问：监视者是谁（谁知道、会告诉谁）；被发现或触犯后谁受损、损失什么。填不出“阻止了什么行动”，说明阻力还只是抽象的不方便。空间类阻力常见四种形态：物理硬锁（门锁、铁栏）、社会门禁（旅馆拒收、名册资格）、容器世界（船、庄园、学校这类吃住工作都在其中的封闭环境）、制度笼子（婚约、监护等身份本身把人锁住）；写哪一种由时代与设定决定，现代设定不必为浪漫强造门禁。

再查一层锚定：这条障碍挂在谁的什么上？若只挂在一件可被原谅、撤销或解释掉的旧事上，障碍会随那件事被抹平而一起消失，撑不起中段；这时给它换一个更持久的载体（仍在生效的承诺、制度资格、身份或持续的利益格局）。

替换或移除障碍时，回查所有依赖它的场面：为它推迟的告白、以它为理由的拒绝、围绕它的等待与让步，都要按新障碍同步改写；只换障碍不改依赖场面，人物会在已经消失的阻力前原地打转。


### 不回应的可观察动作

人物暂时不回应时，避免只写“沉默”。选择可观察动作表现其边界：停止某项互动、改变话题、拉开距离、延迟答复、转向第三方或明确要求时间。动作应符合人物处境，不把沉默自动解释为同意、拒绝或欲擒故纵。

### 权力不对等与回答压力

当一方掌握资源、职位、名声、居住或安全条件时，另一方的即时回答可能并不自由。设计场景时给出可退出的空间、考虑时间、独立求助或拒绝的实际后果；不要把沉默、顺从或被迫接受写成明确同意。

优先移除“必须现在回答”的压力：给期限、缓冲期、换场合、离场权或独立咨询的机会；第三方在场只有在能保护而非代替当事人决定时才有用。


### 关系代价账本

对关键承诺或关系选择，可用四栏检查：想得到什么、谁付出代价、代价何时发生、后果能否恢复。让代价落实到时间、资源、身份、信任或行动自由，不要只用抽象的“牺牲很多”代替。

结算时另用四栏账本：

| 损失 | 谁替谁支付/承担 | 能否结清 | 由谁说出或确认 |
|---|---|---|---|
| | | 可 / 不可 / 未定 | 当事人 / 第三方 / 后续行动 / 叙述者 |

空项写“未知”，不要编造；付出不自动形成索取爱的债。结合不等于账目两清：在一起的两个人也可能各欠一笔结不清的账。“能否结清”写“不可”时，给一条读者能核验的持续痕迹（仍在履行的义务、回不去的旧关系、改变了的相处习惯），不只靠人物口头宣称。
