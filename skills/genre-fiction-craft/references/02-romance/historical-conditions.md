# 历史条件、反例与写作边界

返回 [guide.md](guide.md)。

下面第一张表归纳历史题材中可能出现的偏见和制度条件，第二张表列出少量故事样本容易诱发、但不能据此成立的“规律”。两张表都不是禁止描写黑暗、暴力、控制或有偏见人物的清单。人物话语、叙述判断和作者的设计选择要分开；现实的医学、法律、族群与心理结论不能从虚构情境得出。

| ID | 对象 | 相关规则 | 处理条件与可用知识 |
|---|---|---|---|
| RO-HB01 | 血统决定倾向 | RO-32 | 保留说话者怎样以血统解释女子；不认证血缘决定道德或性欲。 |
| RO-HB02 | 匕首与嫁妆的交易 | RO-15/RO-04 | 可写威胁与经济条件共同施压；不要把危险工具/人身控制解释成同意。 |
| RO-HB03 | 母亲假服从而持续控制 | RO-05/RO-09 | 表面顺从与后续资源操控分账，不凭礼貌动作判权力已消失。 |
| RO-HB04 | 女性价值只在取悦 | RO-32/RO-03 | 作为时代/人物评价保留，当前人物仍可有与取悦无关的目标。 |
| RO-HB05 | 性工作者靠爱情获救赎 | RO-28/RO-32 | 描写社会污名与人物期待，不把性工作身份本身等同道德污点或以爱情作唯一救赎。 |
| RO-HB06 | 付钱过夜羞辱 | RO-15/RO-04 | 记录金钱如何被用于羞辱/报复及其后果，不当作有效惩罚恋人的建议。 |
| RO-HB07 | 决斗恢复荣誉 | RO-27/RO-32 | 保留荣誉制度及人物承担；暴力不能仅以社会习惯获得现实正当性。 |
| RO-HB08 | 反天主教及反爱尔兰偏见 | RO-32 | 区分角色用语、制度排斥和叙述距离，不把宗教/民族概括成天性。 |
| RO-HB09 | 母亲推向悬崖与复仇结尾 | RO-15/RO-29 | 可分析暴力的悲剧后果，不能据此规定母亲保护女儿必以杀戮或现代暗黑题材不可写。 |
| RO-HB10 | 女性被动性的全书判断 | RO-23/RO-35 | 这是对全书的解释性判断，不能据局部说每个选择都不存在；具体修订先定位场景与可行选项。 |
| RO-HB11 | 遗传性精神疾病解释 | RO-31/RO-32 | 保留故事内病因观，不当作现代诊断或家庭成员命定的证据。 |
| RO-HB12 | 种族化方言、表演与群体形象 | RO-22/RO-32 | 研究语音和表演的权力语境；迁移节奏功能不等于继承群体贬损。 |
| RO-HB13 | 赶走怀孕妻子 | RO-15/RO-30 | 把住房、经济、怀孕和信任作为不同后果，不能因后续和好而抹去排斥。 |
| RO-HB14 | 老姑娘羞辱 | RO-16/RO-32 | 保留社会称谓与人物反应，独身不自动失败或应受惩罚。 |
| RO-HB15 | 自我中心人物的厌女论述 | RO-23/RO-32 | 明确属于人物话语及可能的讽刺，不把全段自动归为作者赞同。 |
| RO-HB16 | 爱是对方所欠 | RO-26/RO-15 | 给予或承诺不自动产生亲密义务；可以让人物这样想，但分析要分清。 |
| RO-HB17 | 人物A实施致命伤害，并把死亡说成解放 | RO-31/RO-15 | 保留情节和人物之间对它的不同解释，不当成照护伦理或现实中的伤害方案；写这种结局，不必先安排一套道德惩罚。 |
| RO-HB18 | 残障作为奇观 | RO-31/RO-32 | 保留观看者的视角，也写出被观看者自己的主体性；不把残障只当成可以随便替换的障碍。 |
| RO-HB19 | 病弱继承人作清障物 | RO-31/RO-04 | 把病者自己的处境、财产权与他人获益分开；死亡后受益不等于受益者导致死亡。 |
| RO-HB20 | 阶级与血统优越 | RO-32/RO-05 | 保留家族制度与人物偏见，不认证阶层或血统本质优越。 |
| RO-HB21 | 女性只能以母职完成 | RO-30/RO-32 | 母职可重要但非唯一终点；婴儿失去后人物生活不因公式而必须另生孩子才完成。 |
| RO-HB22 | 意外财产解决一切 | RO-04/RO-29 | 继承可改变资格与选择，不能替当事人答应；偶然事件可用但需与作品承诺相容。 |
| RO-HB23 | 私奔一概幸福或一概毁灭 | RO-29/RO-25 | 不同作品后果不同，保留分支；核具体资源、家庭与意愿而非按私奔标签裁结局。 |
| RO-HB24 | 自称不配的女性 | RO-06/RO-23 | 区分内化污名、策略性自称与叙述认可；不把自贬语言当客观身份等级。 |

## 不要从少量样本推出的“规律”

下面这些说法，观察少量故事很容易归纳出来，但不足以证明它们是普遍规律。左栏是容易推出的错误结论，右栏是应当怎样处理。

| ID | 容易推出的错误结论 | 相关规则 | 应当怎样处理 |
|---|---|---|---|
| RO-HB25 | 长信是写作失败，或者长信不能超过篇幅的某个比例 | RO-10/RO-19 | 长信可以承担节奏、心理和交代资料的作用。有的故事会用很长的信承担节奏、心理和交代信息的作用；具体长度服从本作任务，不是上限。 |
| RO-HB26 | 疾病出场前必须伏笔两次 | RO-31/RO-19 | 按作品对读者的承诺，给出读者需要的认识条件；突发的疾病也可以成立。几部小说推不出伏笔的次数。 |
| RO-HB27 | 全知叙述者的评论不能超过固定比例 | RO-23/RO-33 | 评论可以是思想或讽刺的形式。有问题时找具体的重复或视角越界，不按比例删。 |
| RO-HB28 | 偷听和截信只是方便的情节工具 | RO-10/RO-15 | 列出人物怎样接触到消息、消息可不可靠、越了什么界、有什么后果。手段有效，不证明越权合理。 |
| RO-HB29 | 患病的第三者只是用来移除障碍的 | RO-31/RO-30 | 写出第三者自己的生活和照护处境。当前文本没写到的病情和意愿，不替它补。 |
| RO-HB30 | 人物反复说“我不配”只能写固定几次 | RO-06/RO-19 | 重复可以表现污名和执念。诊断时看每次有没有变化、重复起了什么作用，不按次数删，也不因此贬低人物。 |
| RO-HB31 | 为对方付出过，对方就欠了爱 | RO-26/RO-04 | 能用钱结清的债、承诺和不能索取的感情，三者分开。付出者自认为是债主，不证明对方欠他的爱。 |
| RO-HB32 | 传言必须半真半假才好用 | RO-09/RO-06 | 半真只是一种写法。完全编造的传言、完全属实却被拿来做道德评判的传言，都能撑起情节。 |
| RO-HB33 | 排练求婚只能写成讽刺 | RO-14/RO-21 | 可以写真诚、羞怯、练习说话或自恋，看人物的动机和实际说出口时的落差。 |
| RO-HB34 | 女主角如果长期处于被动顺应状态，一定无法引起共鸣 | RO-35/RO-32 | 诊断具体场景里人物的主动动机与选择空间，不能一笔抹杀人物在特定历史条件下的隐忍与挣扎。 |
| RO-HB35 | 在道德批判语境中用一句“特例/她是例外”，就试图洗清全篇人物污名 | RO-01/RO-32 | “特例”之说可以限制外推，但不能自动消除前文的偏见污名，更代替不了逐场建立的人物尊严。 |
| RO-HB36 | 写代理婚姻，必须先让人物请现代律师 | RO-07/RO-34 | 小说要写清作品里的婚姻规则；现实中的法律问题另外查。写虚构故事不必走现代的咨询流程。 |
| RO-HB37 | 人物意外继承巨额财富后，必须把财产全退回去才算拥有纯粹的爱情与自由 | RO-04/RO-15 | 新增财产与自由选择权分开处理，保留、分享或合理处置皆可，不强制把“放弃财产”当成证明真爱的唯一标准。 |

## 两处容易读错的场景

- 施压者能动用什么与它是否改动意愿：能决定聘任、住处、信件、见面、财产或婚姻资格的人，其施压只说明他阻挡了哪些行动，不说明当事人的意愿已经改变；旁人给拒绝起的名称属评判者一方的解释，落笔时要标明归属，也不要求每份压力都有唯一的解除者。见 RO-05、RO-16、RO-23、RO-K077、RO-E10。
- 旧关系结束后的资格争论：一个人的过去关系已经结束，旁人却把“他或她还配不配开始新的关系”当作公共议题；这类争论只代表评判者的立场，不等于当事人欠一个交代。可以写成新关系成立而争议未消，也可写成不成婚也不给结论；切忌强行补一个大团圆收尾把闲话全部压平，也不要先安排惩罚才许人物往前走。见 RO-29、RO-K109–110、RO-E14。


## 保留边界

- 本册只归纳两张表与两处场景条目写明的情境，不声称已穷尽该题材的作品与写法；这些说明对它没写到的作品和情节不作保证，也不外推为整部作品或其他作品的普遍规则。
- 效果推测不能仅凭案例确定，需结合目标读者试读判断，不把虚构情节当作现实法律、医学或史实结论。
