# 关系机制卡（RO-K001–RO-K120）

返回 [guide.md](guide.md)。每张卡是可选机制，按对应 RO 规则选择；不是逐卡执行的配额。内容以通用关系机制、使用条件和限制表达，不依赖具体作品或人物。

| 卡 | 规则 | 机制与使用边界 |
|---|---|---|
| RO-K001 | RO-04/RO-05 | 社会地位可能通过财产、职业、声望或家庭安排影响婚配。把人物评价与实际资源分开；薪资、职业和婚约不是同一指标。 |
| RO-K002 | RO-04/RO-25 | 财产未必能保护家庭成员；合同也不自动证明自由同意。分别检查签署压力、权利范围、执行主体和现实后果。 |
| RO-K003 | RO-05/RO-08/RO-10 | 亲属或第三方可以截取、阅读、转交或毁损通信，把信息控制变成关系阻力。记录收发链、知情时间和人物误以为谁沉默。 |
| RO-K004 | RO-05/RO-06 | 家庭可以通过早婚期待、财产协商、命名、雇佣和照护安排规定角色。障碍既可能来自明确命令，也可能来自人物内化的社会期待。 |
| RO-K005 | RO-03/RO-05/RO-33 | 限期、约定或试炼可以制造关系压力。写清谁有权提出条件、对方为何接受、是否能拒绝以及期限结束后的选择；不要把某个期限写成通用公式。 |
| RO-K006 | RO-09/RO-21 | 人物可能误读语气、隐瞒部分事实或给自己的行为找理由。先分开可核事实、表达方式和自利解释，再判断误会是否能通过提问解决。 |
| RO-K007 | RO-10/RO-12 | 匿名指控、流言或新闻会先改变声誉，再影响当事人的选择。指控传播不等于内容为真；澄清渠道、受众和利益关系都要交代。 |
| RO-K008 | RO-17/RO-07 | 等待可以是承诺，也可能被旁人视为不理性，或因工作、迁移和资源变化而难以兑现。分别记录人物解释、现实条件和承诺是否仍然有效。 |
| RO-K009 | RO-06/RO-30 | 污名可能让不同家庭成员承担不对称后果，尤其涉及孩子、照护者和非正式亲属关系时。分别写清生育、抚养、身份和责任，不把羞耻归给受影响者。 |
| RO-K010 | RO-06/RO-23 | 同一人物可能在不同社群中被评价为可靠、危险或有声望。记录评价者、信息渠道和各自掌握的事实，不把某一群体的看法当成客观结论。 |
| RO-K011 | RO-15/RO-32 | 强迫接触、要求伴侣服从、以嫉妒或暴力控制，都是关系中的控制行为。可分析人物反应和后果，不能包装成有效追求法；反抗、离开或求助是可能路径。 |
| RO-K012 | RO-15/RO-11 | 骚扰或侵犯发生时，现场是否有同伴、记录或可求助的人，会改变当事人的可行选项；没有第三人作证并不使伤害失效。 |
| RO-K013 | RO-29/RO-31/RO-33 | 预言、仪式和重大后果可以构成悲剧链。保留人物信念与实际事件的区别；不把自毁、死亡或受伤写成爱情真实性的必要证明。 |
| RO-K014 | RO-07/RO-08/RO-27 | 旧责任、保密义务和第三方知情利益可能冲突。判断秘密属于谁、谁承担后果、谁有权决定披露，不能只按恋人的即时需要处理。 |
| RO-K015 | RO-10/RO-24 | 照片、证书、登记或公开仪式可能改变身份与社会承认，但每种材料能证明的事项不同。分别检查真实性、制度效力、受众接受和后续行动。 |
| RO-K016 | RO-14/RO-24/RO-15 | 公开解除承诺、私下坦白和受压签约是不同场景。身体反应可以提示压力，但是否自愿须看完整情境；私密告白也不因缺少旁观者而失效。 |
| RO-K017 | RO-04/RO-25/RO-29 | 财富变化可能增强一方自主，也可能让另一方产生不配得感或资源依赖。把财产、意愿和关系承诺分开，不把贫穷或放弃财富设成爱情证明。 |
| RO-K018 | RO-20/RO-27/RO-29 | 戒指、信物、照片或自然意象可以承载不同程度的结束与记忆。选择哪些元素回收由作品目标决定，不要求每件物品都在结尾兑现。 |
| RO-K019 | RO-03/RO-05/RO-32 | 家庭期待、宗教/文化身份、职业目标和个人欲望可能同时约束选择。让冲突落到具体行动和资源，不假设人物只有一种正确优先序。 |
| RO-K020 | RO-10/RO-11/RO-21 | 编码式表达分为符号映射、解码和语义理解。解码成功不等于理解，更不等于收件人同意；符号规则和双方共享知识要先建立。 |
| RO-K021 | RO-18/RO-04/RO-33 | 人物可以想象缺席者、依赖共同兴趣或因资源合作而接近。想象、友谊和实际关系分开呈现，不把工作、帮助或共同爱好自动等同爱情。 |
| RO-K022 | RO-33/RO-14 | 喜剧、悲剧、惊险和日常语调可以在同一关系线中交替。标出每段场景的主要承诺，不要求整部作品只能维持一种语调。 |
| RO-K023 | RO-09/RO-13 | 新的信息可能让人物重新解释先前的拒绝或误判。变化不必意味着双方各有一半责任；保留责任不对称和实际伤害。 |
| RO-K024 | RO-09/RO-13 | 阶级偏见可能组织人物对他人的解释，也可能让人物误读自己的动机。写清谁作出判断、谁受影响、判断依据是什么。 |
| RO-K025 | RO-10/RO-14 | 信件可以重新排列指控、解释和事实，也可能在面对面谈话中更快解决。形式和长度服从信息复杂度，不设固定行数或篇幅比例。 |
| RO-K026 | RO-09/RO-12 | 第三人可能误读、转述或故意改写双方意图。不要只用恋人各自的目标解释全部误会；记录第三方的知识、利益和行动。 |
| RO-K027 | RO-15/RO-21 | 点头、沉默或顺从在威胁和隐瞒情境中可能被利用，不能仅凭外表推出同意。把当事人意图与他人声称的解释分开。 |
| RO-K028 | RO-10/RO-09 | 邮戳、笔迹、账本、口述或空间痕迹都可作为信息载体。使用时交代技术与接触条件，并区分载体真实、内容真实和解释可靠。 |
| RO-K029 | RO-12/RO-15 | 权威可能压制辩解或控制证据接收，但这不证明自我解释必然失败。可以寻找其他证人、改变沟通场合，或如实承认当前无法翻案。 |
| RO-K030 | RO-13/RO-26 | 人物的善意、友好或拒绝报复可能打破他人的预设。不要把一次反转扩大成普遍道德结论，也不要要求受影响者因此原谅。 |
| RO-K031 | RO-11/RO-08 | 秘密传递可以出于保护、恐惧、操控或维护他人安全。延迟披露时写清不同人物的动机、知情范围和重新判断保密权的条件。 |
| RO-K032 | RO-11/RO-16 | 间接暗示或第三方转述可以传递可能性，但不自动构成正式接受、授权或承诺。需要明确决定时，仍应让当事人表达自己的选择。 |
| RO-K033 | RO-14/RO-16 | 拒绝可以简短、明确，也可以同时表达感激。感谢帮助不自动转为爱情，拒绝也不因缺少长篇理由而失效。 |
| RO-K034 | RO-15/RO-16/RO-18 | 坦白、拒绝、表面服从、离开和第三方介入是不同动作。分别记录谁作出选择、是否有压力、实际后果是什么，避免把它们压成同一种自由决定。 |
| RO-K035 | RO-27/RO-13 | 道歉、重提旧事、停止报复或接受第三方帮助都可能参与修复。修复不等于恢复关系；受益也不取消边界和责任。 |
| RO-K036 | RO-07/RO-04 | 婚姻、合同或身份安排可能处理私人关系，也可能牵涉公共权利和第三方利益。写清它实际解决了什么，不能让私人承诺自动处分他人权利。 |
| RO-K037 | RO-04/RO-07/RO-12 | 关系可能被包装成筹款、投资或利益安排。分别检查资源流向、重复获利、信息不对称和追责障碍；不把个案处理方式推广成普遍原则。 |
| RO-K038 | RO-25/RO-30 | 社会改革、职位变化和私人结局可以并列，但叙述顺序不证明前者造成后者。若要建立因果，需写出中间行动和资源变化。 |
| RO-K039 | RO-08/RO-27 | 保密请求可能保护当事人，也可能控制他人。区分保密对象、期限、受影响者和撤回条件；不要把秘密本身当作忠诚证明。 |
| RO-K040 | RO-23/RO-24 | 私人空间可以承载协商、亲密或权力影响，但不意味着女性或弱势者只能在私下发挥作用。写清谁控制空间、谁能进入和谁能离开。 |
| RO-K041 | RO-12/RO-11 | 寻找证人、核实记录和公开否认都有成本。记录证人掌握的信息、参与风险和利益关系；虚构司法背景不等于现实法律建议。 |
| RO-K042 | RO-34/RO-17 | 续写可以承接人物处境、等待和未完成承诺，再引入新目标。致意、题注或署名不证明被提及者参与创作、拥有权利或授权。 |
| RO-K043 | RO-15/RO-11/RO-27 | 未经当事人同意的介入即使产生好结果，仍可能越界。区分帮助的动机、授权范围、实际效果和受影响者的感受。 |
| RO-K044 | RO-01/RO-34 | 标题、署名、版本或行业术语可以提示形式和权利边界，但不能单独证明创作参与或授权。涉及权利时另查适用规则。 |
| RO-K045 | RO-16/RO-17 | 不结婚、不再交谈或拒绝继续接触都可以是有效边界。人物以后可以改变，也可以不改变；不要把独身自动写成惩罚。 |
| RO-K046 | RO-14/RO-15/RO-21 | 问话、转移话题、重复确认和无言回应各有不同含义。非语言回应必须结合关系、权力和场景，不把沉默固定解释成是或否。 |
| RO-K047 | RO-21/RO-19 | 重复短语或同一问题可以改变谈话权力和情绪。每次重复是否增强、削弱或转向，由上下文决定，不设固定次数。 |
| RO-K048 | RO-03/RO-09 | 先听说、社会名声和未被认出会让登场携带既有期待。口述伤害是人物报告，未经另证既不能当全部事实，也不能当已证谎言。 |
| RO-K049 | RO-05/RO-06/RO-20 | 住房、工作、社交邀请、婚约和物件可以成为不同阻力载体。分别记录对象、执行人、拒绝权和实际影响，不把所有障碍都化成经济损失。 |
| RO-K050 | RO-07/RO-30 | 既有伴侣、婚姻身份或未解除的承诺会影响新的关系选择。身份和法律状态要先澄清，不以情感强度绕过现实责任。 |
| RO-K051 | RO-18/RO-19 | 空间、地点和时间意象可以承载缺席、等待或离开。选择与人物行动相关的少量元素，不按固定比例或章节位置安排。 |
| RO-K052 | RO-23/RO-13 | 有限视角允许人物只知道部分事实，也允许叙述者承认无法进入他人内心。怜悯、爱和猜测分开表达，不把推想写成确证。 |
| RO-K053 | RO-23/RO-15/RO-32 | 受害者自责或叙述者的讽刺不证明伤害没有发生。把人物自我评价、可观察行为和叙述立场分开，避免以自责撤销证据。 |
| RO-K054 | RO-15/RO-14 | 婚誓、求婚和亲密表达若发生在压力或威胁下，不能仅凭措辞认定自愿。第三方许可也不能替代双方当事人的回应。 |
| RO-K055 | RO-20/RO-09 | 同一物件反复出现时，意义可以变化，也可以保持不变。记录每次由谁持有、谁知道其意义和它怎样影响当前选择。 |
| RO-K056 | RO-20/RO-29 | 打碎、焚毁、归还或保留物件都可以成为关系动作。动作是否构成终结，取决于后续选择，不必强加额外信物。 |
| RO-K057 | RO-16/RO-25/RO-29 | 被拒绝、失去家庭支持或选择独身不应自动被写成惩罚。迅速成婚也不因篇幅短就自动低质量；检查人物意愿和后果。 |
| RO-K058 | RO-27/RO-29/RO-31 | 失去之后仍可能出现新关系，也可能没有。分开责任、悲伤、记忆和未来选择，不把复仇当成补偿的唯一形式。 |
| RO-K059 | RO-29/RO-33 | 劳动、照护和遗产可能影响人物时间与关系，但不能从先后顺序推断因果。记录谁承担劳动、谁控制资源和谁有权选择。 |
| RO-K060 | RO-19/RO-29 | 外部事故可以改变人物处境，但不能替人物作出婚姻或亲密决定。区分事件解围与意愿成立。 |
| RO-K061 | RO-01/RO-23 | 人物的梦境、谵妄或记忆可能改变其经验，却不自动构成客观事件证据。标明观察者、时间和可核实范围。 |
| RO-K062 | RO-01/RO-32 | 多作者合集或多叙述者结构要分别记录贡献者、叙述者和人物；不能把不同故事的角色、关系或设定合并成一条连续线。 |
| RO-K063 | RO-07/RO-08 | 秘密订婚或未公开承诺会对新关系形成责任压力。它既是信息问题，也是身份和义务问题；知道真相不自动解决选择。 |
| RO-K064 | RO-04/RO-07/RO-16 | 一方失去土地、职业或资源后，关系可能终止，也可能重谈。退出关系不需要另一方授予许可；双方的实际责任仍需分别处理。 |
| RO-K065 | RO-05/RO-08 | 继承条件、资源限制和求爱承诺可能相互冲突。记录谁知道条件、谁有权披露、谁承担后果，避免把保密义务写成单方正当。 |
| RO-K066 | RO-05/RO-06 | 无意泄露、恶意揭露和受压披露具有不同责任。区分说话者、传递者、受众和信息的真实程度。 |
| RO-K067 | RO-03/RO-09/RO-33 | 绅士身份、职业标签或外貌可能造成误认；后续证据可以修正第一印象。误认要符合观察者当时的知识和感官条件。 |
| RO-K068 | RO-07/RO-16 | 关系解除和自愿同意是不同事项。双方可以协商结束，也可以独立作出决定；不把结束关系写成必须由权力持有人释放。 |
| RO-K069 | RO-05/RO-15 | 第三方伪造信息、限制行动或安排会面，可能改变关系和继承。分别判断授权、欺骗、强制程度及受影响者是否有选择。 |
| RO-K070 | RO-09/RO-23 | 感官限制会改变人物识别身份和理解关系的方式。写清其可获得的信息和可能误差，不把一种感官经验推广成普遍规则。 |
| RO-K071 | RO-03/RO-31 | 词语、称谓和礼貌表达可能有字面与语境两层含义。让误解来自人物可理解的知识差异，不靠作者临时改变词义。 |
| RO-K072 | RO-09/RO-21 | 外部障碍解除后，人物仍可以选择不重逢。关系弧可以完成在拒绝、记忆或离开，不以复合作为唯一闭合。 |
| RO-K073 | RO-18/RO-29 | 意愿、传递、送达和实际后果并非同一件事。通信延迟时记录每一站的时间、知情者和可能的截留，不把计划当成已发生。 |
| RO-K074 | RO-18/RO-26 | 照护或医疗日程会影响等待，也可以是人物独立生活的一部分。延迟可能来自疲惫、意愿或信任，不只来自外部事故。 |
| RO-K075 | RO-29/RO-31 | 金钱、家族要求和个人价值可能同时影响婚配。具体数字必须有单位和制度背景，不以富贫二分替代人物选择。 |
| RO-K076 | RO-25/RO-27 | 父母、监护人和家族长辈拥有的权力不同。温和不等于没有控制，强硬也不自动有可谅解理由；写清动机和手段。 |
| RO-K077 | RO-25/RO-31 | 家庭可以用服从、利益或忘恩指控施压。明确拒绝不会因压力而失效；叙述应区分施压者的解释与当事人的意愿。 |
| RO-K078 | RO-04/RO-07 | 爱与感激不同，疾病、照护和金钱付出也不是回应义务。受助者可以接受帮助而不承担恋爱债务。 |
| RO-K079 | RO-04/RO-29 | 排演求婚、夸张比喻或提前表达可能出于焦虑和准备。把语言表演与真实决定分开，不能把排演当成已经同意。 |
| RO-K080 | RO-30/RO-04 | 祝贺、旧承诺、代言和截信都可能泄漏信息。记录谁知道什么、谁有利益、泄漏发生在哪个环节，不套用固定步骤。 |
| RO-K081 | RO-06/RO-12 | 求婚、拒绝和自由要求必须结合说话对象、权力差和现实退路判断。称呼或感叹不能单独证明自愿。 |
| RO-K082 | RO-06/RO-24 | 法律身份、私人称呼、契约和誓言可能互相冲突。先确定适用制度和权利主体，不把场景动作简化成普遍法律结论。 |
| RO-K083 | RO-23/RO-10 | 人物可能在胁迫中说谎以保护自己或他人。分析其知道什么、试图保护谁以及可行退路，不要求人物先拥有完整知识和完全自由。 |
| RO-K084 | RO-23/RO-29 | 限嗣继承、婚姻条件和家族财产会把关系与资源权利相连。历史制度需按故事设定核验，不能冒充现代法律。 |
| RO-K085 | RO-04/RO-05/RO-27 | 婚姻结局可以是和解、独立生活、悲剧、开放或讽刺。不同音调都能成立，不按富裕/贫穷推导唯一结局。 |
| RO-K086 | RO-16/RO-29/RO-03 | 第一次争吵、婚后私密空间和金钱协商可以展示日常结构。婚姻也可以直接作结，不必添加冲突来证明真实。 |
| RO-K087 | RO-07/RO-23/RO-28 | 亲属称谓和婚姻身份的并置可能暴露利益计算。日记、转述和旁观者补述各有立场；作者评论与人物判断应分开。 |

## 编码式表达：解码、理解与回应（RO-K020 卡的展开）

1. 先定义符号映射和接收者可能掌握的共同知识。
2. 把编码、解码和语义分组分成不同步骤；接收者可能完成替换却仍不理解完整句意。
3. 第三方可以帮助解释，但解释只解决信息问题，不代表收件人同意。
4. 最终回应仍由收件人自主决定；若场景存在权力差，先提供拒绝和延迟答复的空间。
