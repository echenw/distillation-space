# 具体机制（RO-K001 起）

返回 [guide.md](guide.md)。每项是可以按条件选用的知识，动作由对应的 RO 规则限定；不是要逐卡执行的配额。

| 卡 | 规则 | 具体机制、动作与限制 |
|---|---|---|
| RO-K001 | RO-04/RO-05 | 社会地位可被描述为挣得或买得，婚配也可被家庭看作阶层存续。把这种评价归给人物/叙述语境，再写实际资源；薪资、职业和婚约不互相等同。 |
| RO-K002 | RO-04/RO-25 | 财产未必保护家庭成员；母亲没有因此得救与之后的婚姻交易不是同一个命题。签下的合同可改变证据地位，但仍要检查签署是否受压及其制度效力。 |
| RO-K003 | RO-05/RO-08/RO-10 | 亲属买通、截取、阅读、烧毁来信，把通信控制变成关系阻力；这与公开反对不同。确认收发链及当事人误以为谁沉默，不能只写一位强势家长。 |
| RO-K004 | RO-05/RO-06 | 母亲把早婚视作愚蠢、家族通过婚产协商干预，商业父权又以命名、雇佣和闲置女儿规定角色。人物可能把世人看法内化，障碍不必始终由某人发令。 |
| RO-K005 | RO-03/RO-05/RO-33 | 长者借眼镜和规则迫使半年不得追求，可以承担喜剧控制；使用时保留谁有能力要求、对方为何遵守及期限。期限是该情节条件，不是通用爱情试炼长度。 |
| RO-K006 | RO-09/RO-21 | 猜错可能是人物倾向，既不说谎又不揭露可能制造推断空间；一方声称分手只是双方方便，未必代表另一方真实想法。先分事实、措辞和自利解释，再决定误会是否可由提问解决。 |
| RO-K007 | RO-10/RO-12 | 匿名指控与新闻可能先塑造声誉；先读信再判断，是特定人物的认知修正路径。不要把转述的指控当事实，也不要求所有澄清都经报刊。 |
| RO-K008 | RO-17/RO-07 | 长期等待可以被当作神前已婚的承诺，也可被旁人称作疯狂、被长者劝退，或因职业漂泊而难兑现。记录每个人的解释与现实变化，不能从一种等待评价推出唯一正确时长。 |
| RO-K009 | RO-06/RO-30 | 污名可以让女性被要求承担双方的罪，让孩子背负出身羞耻，让抚养孩子的姊妹失去婚配机会。写清生母、养育者和孩子不是同一主体；人物关于世人会原谅什么的断言不是普遍真理。 |
| RO-K010 | RO-06/RO-23 | 同一男人在一处被认作英雄、在另一处是恶人，声誉有社群与信息范围；丈夫受到流言影响，也不表示流言内容已真。把评价主体和信息渠道写明。 |
| RO-K011 | RO-15/RO-32 | 强吻、要求妻子服从、嫉妒挥鞭、殴妻和刀具威胁属于原作中的控制/暴力场面。可分析人物反应和后果，不能包装成被历史证明有效的追求法；反抗、离开或求助是一组已有路径，不是每个受害者必须当场完成的证明。 |
| RO-K012 | RO-15/RO-11 | 醉酒堵门强吻后女子摇铃召人，与制作人动手动脚后第三人指认，是两种不同支持条件。现场有无同伴改变可行选项；没有第三人作证并不使受害无效。 |
| RO-K013 | RO-29/RO-31/RO-33 | 预言、仪式与婚礼夜刺伤、精神崩溃、死亡及消失形成悲剧链。保留宗教/命运语调与具体事件，不把它总结成爱情必须以自毁证明、施害者必须以某种惩罚结账。 |
| RO-K014 | RO-07/RO-08/RO-27 | 婚姻不能自动取消旧责，知情后拒绝恢复旧关系也可成立。秘密属于谁与谁有权知道分开判断；对子女的牵连不能仅用恋人的情感需要决定。 |
| RO-K015 | RO-10/RO-24 | 墓碑照片、埋葬证书和后续公开婚礼可以先处理身份再处理社会承认；教区婚姻记录与法院未能证明则是另一种证据落差。文件效力取决于争点，不能统称一张纸让所有人原谅。 |
| RO-K016 | RO-14/RO-24/RO-15 | 公开解除承诺、婚前私下坦白和受压签约是不同场景。微小颤抖可以提示压力，但是否自愿须看完整情境；私密告白不需因没有旁观者而判失败。 |
| RO-K017 | RO-04/RO-25/RO-29 | 女子继承财富后男人感到不配，与家族破产后达成和解，是相反的资源方向；选择爱情高于金钱身份也不说明一切爱情须弃财。列财产和意愿分别如何变化。 |
| RO-K018 | RO-20/RO-27/RO-29 | 戒指留到被另一枚替代、旧关系被潮汐意象抹去、笑声修复尴尬、新关系替代旧计划，能承担不同程度的结束。物件和意象不必全部在婚礼兑现。 |
| RO-K019 | RO-03/RO-05/RO-32 | 父亲心意与自身欲望、宗教/族裔情境可同时约束选择；普通人的恋爱也可通过幻灭后看见日常伴侣而成立。青春荣耀褪色可改变自我叙事，不必自动抹去感情。 |
| RO-K020 | RO-10/RO-11/RO-21 | 编码式示爱有三层：从数字按字母表顺序替换（9=I），得到未分词INEVERSAWYOUBUTONCEILOVEYOUEDITHINWOOD；Captain替换成功却读不出句意，Tracer划词为I NEVER SAW YOU BUT ONCE. I LOVE YOU. EDITH INWOOD。解码、理解、当事人回应分开。另有爱上友人之妻与照护职责，须保留已有关系和劳动，不让一项自动替代另一项。 |
| RO-K021 | RO-18/RO-04/RO-33 | 想象缺席的Wally可促成认识，版权或工作资源构成独立生活条件；“恋爱总有人吃亏”是喜剧人物评价。走私与地牢为惊险背景，不因存在便证明爱情强度。 |
| RO-K022 | RO-33/RO-14 | 儿童、饭店或代理人可介入喜剧告白；凶兆与仪式可支撑悲剧；法律身份与欺诈可使爱情进入惊悚。三种节奏可以混合，不要求整部只选一种语调。 |
| RO-K023 | RO-09/RO-13 | 第一次求婚中态度被理解为轻蔑，长信重排对Wickham与Jane事件的认识，随后自我评价改变。对方的问题不同，不把认识改变写成双方各错一半。 |
| RO-K024 | RO-09/RO-13 | Emma对Harriet的阶级推断展示自我欺骗怎样组织解释，不是每对恋人都各误会一半的证据。保留偏见者与被影响者的不对称。 |
| RO-K025 | RO-10/RO-14 | Darcy信开头明确不是再次求婚，再按指控重新排序；另一作品面对面沟通直接奏效。信长与场面长是该形式选择，不设置必须约两百行、总篇幅百分比或一切不能当面说的门槛。 |
| RO-K026 | RO-09/RO-12 | Maggie被Barney制造为告密者，Casey之后的说明改变判断；Larry知道Dick是目标，其他人又有自己的误判。预设双方意图并不能穷尽第三人的错误理解。 |
| RO-K027 | RO-15/RO-21 | 点头和沉默在威胁/隐瞒情境中被利用，不能从外表直接推出同意。把当事人意图与他人声称的解释分别写；这不否定别的场景中明确自愿的非语言回应。 |
| RO-K028 | RO-10/RO-09 | 假Chicago邮戳与笔迹制造书信真实性，典当账本暗码提供另一种信息载体；脸面识别、电话偷听、壁橱藏身又各有进入与验证条件。使用时交代技术和空间可行性，不能按道具数量证明真。 |
| RO-K029 | RO-12/RO-15 | 警方威逼并压制辩解说明接收者的利益与权力问题，不能推成自我解释必然失败或所有文书无效。可另找证人、改变接收场合或承认当前无力翻案。 |
| RO-K030 | RO-13/RO-26 | 被设计的目标反而友善接待，会冲击预设；父亲关系也能改变选择。小说人物关于事件而非词语改变人的说法仅为一种解释，语言、反思与行为可共同起作用。 |
| RO-K031 | RO-11/RO-08 | Hunt假装陌生人传递信息，Duchess保留身份担心Larry软化、Maggie受影响与Joe的暴力，延迟有不同动机。后续又承认无权要求对方继续保密，体现保密权可重新判断。 |
| RO-K032 | RO-11/RO-16 | 长辈转述“不承诺永不嫁”使求婚者获得希望，但它不是正式接受；秘密通信也可能伤人。传递的是可能性还是授权，需要分别记录。 |
| RO-K033 | RO-14/RO-16 | 一句话即可终止追求的明确退路，与表达感激共同存在；独立选择也可伴随代价。拒绝不因缺少长篇理由而失效，感激不自动转为爱情。 |

| RO-K037 | RO-04/RO-07/RO-12 | 诈骗的速度、手续费与可重复使用构成商业模型；婚配也被纳入计划。案卷与警方的利益影响追责，拒绝起诉还涉及Isabel声誉与无法证明的共谋，不能据此认定无需追责的普遍原则。 |

## RO-K020 编码示爱：完整的两步解码与回应边界

原文数字为：

`9–14–5–22–5–18–19–1–23–25–15–21–2–21–20–15–14–3–5–9–12–15–22–5–25–15–21–5–4–9–20–8–9–14–23–15–15–4`

1. Captain识别数字代表字母表次序，例如9对应I；依次替换成功。
2. 得到`INEVERSAWYOUBUTONCEILOVEYOUEDITHINWOOD`，因为未分词，他仍说没有意义，不知道如何拆开。
3. Tracer接过笔，划成`I NEVER SAW YOU BUT ONCE. I LOVE YOU. EDITH INWOOD.`；技术替换与语言分组是两项不同帮助。
4. 迁移到创作时可用这种“局部成功仍需另一种知识”的中介结构；读到明确告白仍不是已经给出恋爱同意。若新故事要回应，另写接收者的自由选择。
数字和字符串为源例，不是新编；具体中介机制可迁移，是否适合目标作品仍为设计判断。
