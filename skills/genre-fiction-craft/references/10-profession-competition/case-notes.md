# 职业竞争机制与边界（PR-07）

返回 [guide.md](guide.md)。本文件整理职业题材可迁移的机制，不是某一行业的统计报告，也不代表所有行业都遵循同一规则。

| 机制 | 可迁移的设计价值 | 边界与反例 |
|---|---|---|
| 职业身份与尊严 | 工资、头衔、制服、工种和社会评价可能互相冲突；人物可以重视劳动本身，也可以拒绝被职业标签定义。 | 不能用收入、顾客评价或某个职业判断人格价值。 |
| 进入门槛与筛选 | 考试、推荐、作品集、资历和实际任务可能采用不同判准；筛选结果会影响机会和自我评价。 | 单次淘汰不证明能力不足；淘汰比例不是所有行业的标准。同一套准入制度可以只做三件事里的两件：定注册条件、把考核权交给同业、却不要求同业真开考。缺的那一件让排斥合法化，写清谁因此被挡在外面，以及他们靠什么继续工作。 |
| 不可能任务与权力 | 管理者可能用不合理期限、模糊目标或不对称资源制造失败。 | 不把残酷测试写成有效管理；也不假设所有严格要求都出于恶意。测试给别人造成的实际代价要有人在场承认或抗议，承认之后人物仍可接受或执行；省掉这一交代，读者容易把情节当成作者本人的立场。 |
| 客户需求与产品拆解 | 客户描述、真实需求、可交付产品和商业语言可能不一致。 | 人物对客户的判断是其视角，不是市场调查结论。判断可以逐条写下，让后面的场景兑现它或推翻它；被推翻时保留人物当时看到的线索，不倒过来当成先见之明。 |
| 观察能力与行业知识 | 专业判断常来自长期观察、身体经验、工具熟练度和情境知识。 | 不把单个专家的自述当成行业共识；关键专业事实需核验。 |
| 资产、合同与现金流 | 交易额、佣金、回款、成本、股份、投票权和实际控制权可能分离。 | 金额要有单位、周期和触发条件；股权比例不自动等于控制权。 |
| 署名、身份与作品归属 | 笔名、匿名投稿、代笔、版权、编辑和传播者可以形成不同责任链。 | 署名不自动证明全部创作参与；致意不等于授权。 |
| 媒体标准与公共责任 | 独家、截稿、编辑分工、消息源保护、广告收入和事实核验可能冲突。 | 记者、编辑或机构的立场不能直接代表全部行业；报道未刊不等于事实不存在。伦理压力可以排出先后：让人物先替所在组织压下一次自己知道的事，再在更大的诱惑面前拒绝，两次的差别显示立场怎样形成，第一次不必写成不可饶恕的污点。承载结论的那件东西，例如稿子、样本或账页，也可以当成各方争夺的对象来写。 |
| 工会与集体行动 | 劳动者可以通过组织、罢工、协商或拒绝参与改变权力关系。 | 不把所有组织都写成正义，也不把个体拒绝参与自动归为背叛。 |
| 训练、错误与授权 | 学徒、实习生和新人需要练习、反馈、监督与逐步授权。 | 高风险岗位不能把错误当成长仪式；虚构医疗或工程流程不作为现实指南。 |
| 赞誉与能力证据 | 头衔、奖项、客户推荐和同行评价可以带来机会。 | 赞誉不是能力证明；也不要求高手必须被所有人认可。被当作专家这件事本身不能反复变现：名望只买到第一次机会，下一次检验要落在可交付的东西上，名望与能力之间的差才有情节重量。可复核的手艺是少数能在多次委托之间累积的资产，宣传只改变第一次评价的框架。 |
| 艺术身份与商业生存 | 创作理想、收入、市场包装、职业合同和社会评价可能彼此冲突。 | 不把商业成功等同艺术质量，也不把拒绝商业合作等同道德优越。一次低于自我定位的买卖也能承担理想与生计的落差：写清这单付多少、占多久、怎样交货，落差就在这张单子上。 |
| 工作强度与身体代价 | 工时、轮班、疲劳、伤病、通勤和照护责任会改变职业选择。 | 不把过劳、饮酒或自我牺牲包装成专业精神；生理细节需核验。 |
| 技术改进与安全责任 | 设备、流程和生产效率可能提高，也可能制造新风险或转移成本。 | 不提供现实破坏或危险操作步骤；事故原因需分开记录假设与证据。要让一件只为减少伤害的投入被掌钱的人接受，给他能核算的三项：留住多少人手、效率怎样变化、出事时谁负责；同时给他明确的处置权，否则现场判断压不过产量逻辑。 |
| 声誉、流言与公共形象 | 新闻、广告、客户口碑和同业传闻可以改变机会。 | 流言传播不证明内容真实；声誉恢复也不自动修复实际损害。写一条传闻怎样变成公众认定的事实，按步骤换载体：私下议论、看似能作证的物件、标题、公众假定；每一步都要有新的可观察东西接手。 |
| 导师、赞助与依赖 | 导师可以提供机会、资源、训练和背书，也可能控制信息或要求忠诚。 | 感激不等于服从；帮助成功不自动证明越权合理。 |
| 职业转向与退出 | 辞职、转行、停业、退休或拒绝晋升都可以是主动选择。 | 不要求人物必须通过失败才转行；也不把职业身份视为永久人格。离开的人可以只留在同行席间的一句话里，成为这行记住失败的方式；不必另设正式追认或公开纪念，也不必让每个退出者都被重新评价一次。 |

## 证据与写作边界

- 人物的行业判断、报价和自述只证明人物这样说，不自动成为现实行业数据。
- 历史工资、货币、工时、设备和法规需要独立核验；没有核验时标明为虚构参数或待核。同一条观察换到另一个行业只是候选，不是通则；机制表里的边界与反例标的是适用范围，不比正面写法更高级，用哪一侧取决于本作要写哪种冲突。
- 一个行业中的制度不能直接外推到另一个行业；同一行业也可能因地区、时期和岗位不同而变化。
- 竞争故事不必以胜出结束；未获奖、拒绝机会、保持匿名或离开行业都可以是完整结局。
