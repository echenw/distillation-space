# PR-06 工作表、诊断与修正案例

## PR-06A 按需要取用的工作表

这些字段是思考工具，不是每次必须填满的问卷。相关字段未知时写“未知”或“未证实”；不存在或本场无关时写“不适用”。例子里新增的设定要标明是新设定，不把故事内引文冒充用户原稿的事实。按症状查表之后一次只改一层：同一轮里不同时重写大纲、人物和文风，改完这一层回看下一层，免得一处修好、别处反而站不住。

| 工作表 | 字段 | 何时使用 |
|---|---|---|
| 职业作用卡 | 作者承诺；职业改变的选择；背景/共同/主要；本场是能力与认可、资源与伦理分配，还是职业中断的问题；本场风险与身体代价；行话与随身物 | 定位写作重点，不给整书贴永久类别 |
| 进入与认可链 | 机会；资格/访问；已有能力；成果；谁观察/判断；其权限；渠道；决定；每项补“此刻因此不能做什么”与“哪一环可由本人改变” | 能力与机会或名望不相称 |
| 学习卡 | 目标能力；起点；方法/材料；反馈；支持与约束；调整；下一次实际应用 | 能力跃迁需要说明 |
| 工序图 | 输入；动作；产物；交接；检查；责任；时间/资源限制 | 过程影响结果 |
| 人员网络 | 人物工作；能提供/拒绝什么；利益/职责；知情；关系变化 | 团队、导师、行业组织 |
| 账与合同表 | 金额/非现金资源；单位和周期；到期；触发条件；权利/义务；例外；实际决定者 | 钱或协议改变选择 |
| 比赛/检验卡 | 目标；资格；规则；资源；观察方式；判准；裁决；申诉；奖励/后果 | 正式或非正式检验，按场景省略 |
| 失败复盘 | 预期；行动；信息；前提；环境；结果；责任范围；后得信息；可改环节 | 区分推断错误、失误和外部限制 |
| 关系与结局账 | 各方要什么；兼容条件；可协商部分；得到/失去/未变；谁评价；后续 | 选择、职业中断与收束 |
| 修稿单 | 已读范围；原句/场位；证据；问题状态；实际修法；来源/边界；回看位置；两条备选改法及各自的人物成本 | 一次实际交付 |

原十二类诊断在本体系的去向：只有职业标签→PR-01A；术语无动作→PR-02C；进入过顺→PR-01B（先确认是否承诺阻碍）；训练跳跃→PR-02A；生态单薄→PR-02C；钱模糊→PR-03；赛事规则冲突→PR-04A；成功只靠旁人→PR-02B（核分工而非禁援助）；伦理无后果→PR-05A（不强惩罚）；职业/关系偏轴→PR-01A/05A；结局强行修复→PR-05C；时代偏见当真理→PR-05B。严重度由实际承诺冲突和影响判断，不因缺一张表自动“致命”。本目录内的修法按承重顺序取用：先定职业在这段里承担什么，决定要不要保留职业线；再补进入资格与训练交代；再补工序与钱；再补检验、伦理与代价；最后收到结局与偏见这一层。这是取用先后，不是必须走完的五步流程，前一层没定时不急着改后面。改完按改动对象回看对应场位：动资格回看入场链条与最终结果，动合同回看触发条件与兑现，动能力回看训练依据与后续应用，动关系回看谁知情、谁同意。收口再答三项自检：谁点头才算数、这一次谁付账、职业明天消失人物还能自称什么。每类症状再配两栏：这一类允许的修订方向，和它容易诱导出的硬造内容，例如危险操作细节、虚构的法规条款、非死即败的结局；两栏都填不出，说明这条症状在当前稿里并不成立。

## PR-06B 六场逆袭骨架的可选用法

需要完整成长竞争弧时，可按“处境与目标—机会/规则—练习或准备—挫折与新认知—检验—结果与后续”规划。每场写人物选择、信息变化、资源和关系；可合并、倒序、跳过训练、无挫折或多轮竞争。私练、成熟高手、制度小说不必套此骨架。改变目标也不必证明主角技不如人；获奖与职业机会可以分开兑现。

## PR-06C 原创演示场景

以下场景用于演示工作表如何落地，属于本 Skill 的原创设计示例，不代表真实行业规则。

### 1. 报馆与保密消息

记者收到一条可能影响公共安全的消息，距离截稿只剩一小时。消息源要求匿名，编辑要求独家，法务提醒内容尚未核实。先列出消息源亲历范围、可独立核验的事实、可能伤害、发布窗口和更正机制。记者可以选择暂缓、局部刊发、继续核验或拒绝发布；任何选择都要承担可见后果。

### 2. 竞技赛事与外行观察

新人参加一场规则公开的比赛，观众只看见比分，裁判能看到动作细节，教练掌握训练史。将比赛规则、身体风险、现场观察和赛后解释分开。受伤不自动证明选手判断错误，获胜也不证明训练方法适合所有人。

### 3. 学徒训练与高风险工作

实习人员在监督下完成一项高风险任务，发现自己尚未掌握关键步骤。记录授权范围、现场监督、复核机制、错误影响和升级路径。教学错误不能被浪漫化为“成长必须付出的代价”；现实医疗、工程和安全操作需专业规范。

### 4. 房产交易与董事会控制权

经纪人促成一笔交易，合同写明佣金，但回款、税费和交割时间尚未确定；公司股东持股较多，却未必控制董事会。分别记录成交额、到账金额、成本、表决权、任免权和利益冲突。不要把持股比例直接写成控制权。

### 5. 创作合同与署名

创作者签订一份包含工资、选项期、署名、改编权和工作条件的合同。对方提出以宣传机会替代部分报酬。分别记录金钱、权利、期限、撤回条件和实际创作参与；不能把赞誉当报酬，也不能把署名当完整授权。

### 6. 公开规则的烘焙竞赛

**原创设定：** 三名评委、三轮匿名评分、九十分钟现场制作；队伍最多六人，允许少于六人参赛。比赛前公布评分项、设备限制、过敏原处理和申诉流程。匿名评分与赛后曝光奖励分开，不能把曝光条件暗中塞进盲审。时间预算可先拟为准备、制作、复核三段，再按菜品和场地调整；比例不是行业标准。

参赛者需要在复杂主题、稳定交付、身体状态和设备故障之间选择。复杂方案失分、设备故障和身体限制分别分析，不合并成“主角判断错”。若规则变更，应说明由谁授权、何时通知、是否适用于所有队伍。

### 7. 技术升级与停产决定

工厂可以通过升级设备提高产量，但新设备依赖稀缺材料，维护人员也需要培训。分别记录试点规模、故障率、维护成本、员工安全、旧设备退出条件和停产风险。小规模成功不能自动证明全面切换安全。
