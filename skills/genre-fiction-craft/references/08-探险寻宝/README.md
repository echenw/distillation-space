# 探险寻宝：目标、证据、行动与结算

先看作品要让谁追求什么、凭什么相信、怎样抵达、谁承担损失，再选择藏宝、海盗组织、取证、极境、科技谜题、制度悬念和叙述形式。目标可为财富、知识、人、地点、归乡或生存。

| 任务 | 当前入口 | 交付 |
|---|---|---|
| 构思目标和世界 | [融合规则](fused-rules.md) AT01–03、AT10；[细节库](knowledge-details.md) | 带正典条件的目标与行动链 |
| 地图、谜题、失踪 | AT04–05、[流程](workflow.md) | 线索持有/误读/验证表、知识分布 |
| 海盗、团队、潜行、求生 | AT06–09；细节库 M04–M16/M25 | 权责、资源、路线与后果 |
| 科幻/制度/伦理 | AT10–13、AT18 | 解释层级、权利分账、冲突分支 |
| 语调、框架与终局 | AT14–17；细节库 M21/M26–32 | 信息节奏、叙述装置与分层结算 |
| 诊断/改稿 | [模板](templates.md)、[当前完整示例](examples.md) | 原文位置、最小修法、回归项 |

当前规则、细节库、模板和示例共同承担有效知识。所列案例为代表性样本，不穷尽该题材的全部作品与写法；个案中的“必须”和固定阈值不应直接视为普遍要求；现代适用性与消费者行为效果应结合目标受众验证。
