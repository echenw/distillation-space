# 有效独有机制与历史条件库

这些卡供实际设计使用；M/RE 编号用于关联本包内部规则，适用性以 AT 规则为准。无法定位到具体文本的内容只作创作假设，不作为原著事实。每卡的动作都可缩减为有用的一项，不附数量配额。

## 二、第二批来源的18条旧编号在当前的有效分支

| 旧RE→当前 | 保留动作、反例与来源 |
|---|---|
| RE01→AT14 | 第二人称“无聊→危险”可作体验式开场，普通人偶入也可；第一人称出身地理构成反例。第三批来源无第二人称样本不等于禁用，沉浸效果待证。 |
| RE02→AT05 | 报道只有不相关简讯能暗示被压下的事件；假伤情信→助手报告绑架把失联作为可更新信息。可隐去答案但不伪造已知材料。 |
| RE03→AT11/14 | 死刑换命可作依赖赦免权、雇佣和执行力的特殊虚构交易，撤销普遍模板，不因第三批来源零例宣告写法无效。展示敌内分歧，不能冒充同一机制正证。 |
| RE04→AT10 | 塞壬等神话功能移到太空有历史先例；变形机器先有外壳线索后飞越瀑布。保留人物神话/科学并列解释，不强制遗迹科技化。 |
| RE05→AT04 | 标题物象可反复改义，不设三现。红石先通排水道、缺字与新碑改变位置；相关旧锚不在第二批来源，不作独立验证。 |
| RE06→AT14 | ON THE BEACH是落魄处境，可组合化名、未知前史和共同困境，不可误读成所有故事必须海滩地理开局。家庭村镇为反例。 |
| RE07→AT14 | 全预告目录把悬念从什么转为如何；也可只给地点或留白。跨批历史旁证不作重复计数。 |
| RE08→AT08 | 变装可涉及脸、姿态、声音、思维习惯（有历史先例）；援救与再次潜入的通道因潮水暗礁失效。训练或外援解释能力，勿只贴“伪装大师”。 |
| RE09→AT09 | 退休杂货商旧技能、少年摸索偷取火种、摄影师职业反射是不同素人资源，不要求都有同一成长弧。 |
| RE10→AT10/17 | 终章人物对Robur是科学家还是魔鬼争论，可保留能源未知；雷暴毁艇与幸存者报告已经结算事件。 |
| RE11→AT04 | 字母、纹章、胎记、信物/徽号可引身世；保存链、复制、解释和权利分开。原著的Y徽号；旧亚麻布锚不在第二批来源，不恢复独占主线硬令。 |
| RE12→AT14 | 歌谣/章尾诗提供地方记忆与余韵；依它解谜才要求传承和解码。章末诗是局部形式，非每章必须。 |
| RE13→AT14/10 | 感官线索可连接梦、越界与现实，也可有意跳切；醒来推测被下药仍未证实，太阳定位附航向未变条件。旧祈祷梦例未证，不作依据。 |
| RE14→AT16/17 | 年长女性口述/死亡闭合是可选框架，不能据一类来源形态强迫叙述者死；幸存报告提供明确反例。 |
| RE15→AT17 | 未归、目标到达、关系去向与运送结算可各自开放/闭合。“未回来”为历史候选；运输、婚礼、伙伴去向不构成婚礼必需。 |
| RE16→AT14/17 | 丢弃名单/信/刀、拒绝自述可用行动结尾；Betty指出缺字却靠语言推进。沉默理由可多样，不要求所有角色都道德高尚。 |
| RE17→AT09 | 日期、方向、天气与缺失日能控制信息；海图/日志可能被操纵。原著的书名作者旁题不能单独证明整本日志体；时表被风暴打乱，定位带条件。 |
| RE18→AT14 | 演出与主线主题对应时可映照角色反应；歌剧例为待证候选。静默与环境声同样有效，不强制终章演出。 |

## 三、第三批来源独有机制：通过条件加入以上主流程

| 机制 | 具体保留和边界 |
|---|---|
| N1/N2目标/证据路由 | 海上图志、太空仪表、制度文书、荒野口述按真实功能选择；青春泉/长生技术目标、湖底无武器困境、新闻先行定性、进入圣井即犯禁各自保留。不把同一目录或“技术目标”机械分类为互斥类型；氧气60分钟是故事数字。 |
| N3正当性独立 | 法庭剥掉“合法战争”说辞、法外绅士信用、婚姻被指为亵渎、压抑啜泣改变法庭同情，展示授权/程序/关系/伦理不同层。 |
| N4物证可改写 | 船改名、货标伪造、玉坠复制抬价、祖图水手笔迹仍不足尽信；加复核可能，不强制每件物证真的伪造。 |
| N5制度时序 | 搜寻无残骸与消息延迟相接；头奖最后抽、一票不中两次、六瓮逐位出号、差45号的接近感，使悬念无需地理谜题。保留“823752号中奖者Siegfrid”作为源报告片段，不凭此断言最后头奖结果。 |
| N6非标准结算 | 婚礼与棺材同置、已买新娘饰物却认为婚约无望、旁观叙述者自嘲非英雄，均可重估成功，不证明婚礼不能结算。 |
| 独占/分散 | 一人见过宝物和三人知道位置是不同作品的信息结构，不是真正逻辑冲突；在一作内可有合理传递。知情者还会死亡，改变调查路线。 |
| 海图/撤离 | 海图定位自救、未记载礁石、祖图可疑、人力与物资清单、翻船遮阳展示不同可用性；不把古小说航海数字认证成现实。 |
| 声音四用 | 岸歌接死讯、起锚歌中断、半唱地名、鼓点译Morse和边界通信，各有凶兆/警报/身份/信息功能；读者未知译码不等于人物也不能依声音判断。 |
| 伪装成功与失败 | 宴会冒充使节被抓、剪发男装、仪式化换装、货物/航线/船名伪装、被看穿可给技能具体边界；无需每次失败。 |
| 多种框架/开场 | 步行离乡、酒馆人物、山间客栈、湖底、接舷战；日志幸存、虚构编者援引回忆录、非英雄自评。旧例子可选而不按篇幅固定。 |
| 讽刺与信念 | Space Rays卷首明示滑稽模仿；黑池五万年前智慧是另一作内部正典；黑陨石护符又是人物信念。不由体裁标签直接裁真伪。 |

## 四、跨题材接口与读者辅助

时间账本、时区反转、秒针倒计时、日记切换保留为时间结构接口；鬼地掩护可接恐怖，间谍/洗白可接身份权谋。混用时仍按信息持有者与世界条件检查，不把接口当外部文件必需。地图、词汇表、航海术语表可按读者需要附，不设强制数量。戏仿的异域头衔、一见钟情、赌场救美、暴力恋爱背景、连续绑架、英雄被擒、易容、赎身、讣告式结局、情绪武器夸张是可检查的成规；有新功能和后果仍可采用，不列为绝对禁写清单。
