# 历史语境、社会假设与证据边界

返回 [guide.md](guide.md)。本文件帮助区分时代立场、人物话语、叙述判断、架空制度和现实事实；不是禁写清单。

| 主题 | 可迁移的分析问题 | 边界 |
|---|---|---|
| 血统阴谋与替罪 | 金融、政治或社会危机如何被转嫁给某个族群？谁制造标签，谁从中获益？ | 血统阴谋是偏见话语，不是事实证据；不把角色指控写成群体本质。 |
| 殖民、占领与土地清空 | 谁声称土地无主，谁有权登记、拒绝或迁移？谁承受制度变化？ | 角色表示愿意接受统治，不自动代表被统治者真实同意；保留被排除者的声音和选择。 |
| 种族化能力与等级 | 人物如何用肤色、身体标记、语言或出身解释他者？标记消失后，制度是否仍在？ | 移除外在标记不等于消除结构性歧视；不把虚构身体差异当现实能力规律。 |
| 性别资格与人格符号 | 谁能进入机构、继承财产、公开发言或获得职业？身体、声音和婚姻身份如何被当作资格？ | 可以呈现时代偏见，但不能推荐歧视为聪明制度；私人关系不自动产生法律资格。 |
| 优生与完美标本 | 谁定义“完美”，谁被排除，谁控制生育、婚配或身体选择？ | 美貌、健康和能力不能由单一权力者定价；不得把优生观念当科学结论。 |
| 自毁忠贞与人格依附 | 忠诚话语如何与依赖、恐惧、自我惩罚或权力不对等结合？ | 不由某个悲剧结局推导机器必须自毁、爱情必须殉葬或受害者必须牺牲。 |
| 集体感染与偏见消除 | 外在标记、疾病或身份符号改变后，群体关系是否真正改变？ | 未经同意的身份抹除、制度未变和权利未恢复，仍是未解决的问题。 |
| 技术奇迹 | 纯氧、药物、反重力、意识迁移、换脑或其他装置解决了什么问题？ | 只按故事内部规则分析；现实可行性需独立核验，不把虚构装置写成科学事实。 |
| 制度方案 | 政体、利息、货币、照护、劳动和债务如何分配权力与资源？ | 架空制度不是现实政策效果验证；要写执行、申诉、退出和受影响者。 |
| 单一装置与样本边界 | 一个角度、仪式、器物或测量方式是否只在特定设定中成立？ | 单个案例不能升格成普遍规律；同类装置也不必在每部作品中出现。 |

## 解释时的四层区分

1. **人物话语：** 角色相信、声称或误解了什么。
2. **叙述呈现：** 读者实际看到、听到或能够推断什么。
3. **世界规则：** 故事内部哪些机制被确立，哪些仍是猜测。
4. **现实事实：** 历史、法律、医学、物理和社会学主张是否有独立证据。

角色焦虑、亲情投射、对职业/制度的判断和政治口号都可以是有效人物材料，但不自动成为世界观定律。被迫劳动、身份替换、疾病、遗传或身体控制等情节，要区分受害者处境、执行者解释和制度责任；不提供现实伤害或治疗操作。

## 保留边界

- 角色偏见可作为时代立场或批判对象呈现，不得作为现实群体结论。
- 材料类型、版本差异和转述层级要区分；二手概述不包装成直接观察。
- 没有证据的技术和社会效果标为设定假说，不补造精确数字。
- 目标读者效果需实际试读；历史案例不能代替现代市场或用户研究。
