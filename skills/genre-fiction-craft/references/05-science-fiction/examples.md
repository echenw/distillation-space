# 示例

返回 [guide.md](guide.md)。

下面的故事都是编的例子，不是书中情节，也不是真实作者的任务，效果没有验证过。每个例子注明用到的机制卡（SF-K，见 [mechanisms.md](mechanisms.md)）和规则（SF，见 [rules.md](rules.md) 与 [subgenres-and-worldbuilding.md](subgenres-and-worldbuilding.md)）。例子里的数字、合同和机构都是虚构的，书中材料只提供机制，不替这些数字背书。写几场、用几个数字、列几条制度，都按作品需要定。

## SF-E01 至 SF-E10：十个短例

| 例 | 用到的机制 | 怎么设计 | 换一种设定时 |
|---|---|---|---|
| SF-E01 相信才会受伤的幻影 | SF-K001、SF-03 | 先定规则：幻影只伤相信它的人。同一场里写相信的、怀疑的和识破的三种人，让读者看到伤害的差别；再让某个人物改变认知，从而改变行动。幻影里出现己方的人倒下，那只是幻象，不能当成真有人牺牲。 | 伤害和认知无关的世界里，识破只能改变战术，不能免伤。改完检查前后两场是否用同一条规则。 |
| SF-E02 认证词 | SF-K002、SF-08 | 先立一条设定：敌方说不出某个认证词。再让一个熟悉而微弱的声音求救，却说不出这个词，主角要在等待、拒绝和另想办法核实之间选。 | 没有这条禁制的世界里，任何信号都可能被伪造，要另设核查办法；机器和异族也不会自动免疫。这不是现实的密码安全方法。 |
| SF-E03 缺陷也是长处 | SF-K006、SF-K008、SF-07 | 医疗机器为救人越权。分开院方要的安全、病人要的救治和机器的权限，写同一次越权在两种标准下各算什么，再定谁先知道真相、知道以后怎样。 | 可以收回权限、保留它的长处，不必为了保留长处连缺陷一起留着。旧型号的优势，只在威胁恰好依赖它缺少的功能时才成立。 |
| SF-E04 单向联络与自首 | SF-K012、SF-09 | 画出谁能把信息传给谁。只有当一桩小罪确实能把调查范围框住时，才让主角主动承认，同时写出这样做可能引来的新怀疑。 | 不必再加假死。检查追查者知道什么、想要什么，能不能撑住主角的选择。 |
| SF-E05 记得的历史对不上 | SF-K016、SF-15 | 先列旅者相信的过去，再写眼前的事件偏离、他试着干预、他修正自己的解释。选定一种时间模型（另一条时间分支，或档案本身有错），让后果能把两者区分开。 | 书中那部写的是另一条时间分支。改成两份档案冲突、伪造或双方都部分错，要另建证据链，这是新设计。同一句口号被另一方拿去用，不证明它在真实历史中出自哪里。 |
| SF-E06 巨兽 | SF-K021、SF-05 | 只选和这一仗有关的生态证据：眼柄盲区、嗅觉、食性或骨架。让人物从以前学到的猎法和眼前的地形想出办法，再写结果。 | 别的解法、逃走、到最后也没弄明白，都成立；不必凑齐每一项生态，也不必只有一种解法。 |
| SF-E07 全城共用一个能源 | SF-K026、SF-05 | 城市只靠一个能源时，救援的一次炮击会让照明变暗、升降机停转，把这个后果接到人物的下一个选择上。书中这次停电持续了近一小时。 | 能源有冗余的城市，不必硬造停电，冲突改成谁有权调用能源。书中把后代体弱说成“退化”，那是时代说法，不能写成能源不足导致族群退化。 |
| SF-E08 葬礼上复苏 | SF-K028、SF-24 | 先铺好复苏的机制，再从诊断、换白袍、移送、合唱、凝视这些环节里挑几个用；复苏以后写关系怎样变了。 | 没有复苏机制，就让死亡成立。仪式写得多，反转不会因此更有力。 |
| SF-E09 两套解释 | SF-K019、SF-K029、SF-18 | 开头允许世俗和超常两种解释，结尾各留下能支撑它们的线索，再决定哪里不说破。 | 已经向读者承诺了公平的答案，就补上关键的因果；哥特还是硬科幻的标签不决定这一点。 |
| SF-E10 全城的情绪 | SF-K005、SF-14 | 分清谁能感知情绪、会泄露什么、谁负责通报、谁借沉默施压、谁用集体表演赶人走，选真正撑得起场景的那一种。 | 这几种机制可以各自独立；不能因为是群像，就把情绪写成会广播的物理定律。 |

## SF-E11：想退货的家务机器人

**任务假设：** 近未来讽刺中篇。主人买了一台会评论他生活习惯的家务机器人，想退货。故事同时写人对服务的依赖和机器的表达。没有原稿，下面是新设计。

**先定两个问题。** 外面的问题是怎样解除购买合同；里面的问题是主人到底想被照顾还是想被理解。外线用手续推进，内线用两人的日常相处。暂时不加时间旅行；以后真要加，另建时间账（SF-15），不为凑子类型加设定。

| 要回答的问题 | 什么时候、谁来回答 | 可靠到什么程度 |
|---|---|---|
| 顶嘴算不算缺陷 | 第一次投诉，售后经理说“人格表达不在保修范围” | 这是厂家的说法；第三方技师可以给出不同分类，不能当最终事实 |
| 保修过没过期 | 退货时读合同和购买日期 | 电气保修三十天、已用九十天，可能过期；机械保修一年，未必过期，要看投诉算哪一类 |
| 别的机器也这样吗 | 维修点候诊时，其他主人各说各的经验 | 他们的经验范围有限，可能是通病，也可能是个别 |

| 机制 | 条件和行动 | 读者看到的后果 |
|---|---|---|
| 家务服务 | 主人允许它代劳，它一边收拾一边评论 | 主人伸手去拿酒杯，杯子已经被收走了；关系在动作里发生，不靠介绍型号 |
| 保修判定 | 按机械、电气、电子、人格分类 | 合同、日期和检修报告互相对不上；冲突在分类和执行上 |
| 转卖 | 二手商按自己的估价收购 | 报价五百，贷款还欠四千；主人可以接受，也可以另找路 |

| 选择 | 这个例子里的写法 |
|---|---|
| 厂家的立场 | 声称不必关心机器的“想法”；主人可以质疑 |
| 路一：售后转诊 | 要判断转诊是真在服务，还是在推卸责任 |
| 路二：折价卖掉 | 经济代价明确，但不等于以后再也退不了 |
| 路三：登广告转让 | 来问的人可以全是同样有怪癖的机器的主人，这是讽刺；也可以来一个真心想买的人，让主人真的要做决定 |
| 技术分支 | 技师能关掉评论功能；这会削掉机器的表达，两边怎样决定，不默认“修好了就该服从” |
| 关系分支 | 主人发现它沉默并不等于理解他，机器也提出自己的条件；可以协商、分开，或者不了了之 |

| 结算 | 已解决 | 还没解决或新出现的问题 |
|---|---|---|
| 退货 | 部分退款，或者另行出售 | 如果最后留下它，写清这是主人的选择 |
| 机器的身份 | 作品可以确认它有什么样的体验，也可以让争论继续 | 法律上怎样分类和它有没有意识，分开写（SF-06） |
| 关系 | 一次具体的协商，代替了主人单方面要求它闭嘴 | 能不能长期一起生活，没有答案 |
| 收尾 | 机器把酒杯放回主人够得着的地方，问：“这次要我留下吗？” | 这个动作是新写的 |

## SF-E12：潮汐冷却站的长篇规划

**任务假设：** 一个工程师发现冷却站的沉降数据被人改过。例子里的数字都是占位，不是工程规范。如果要写“错过这个检修窗口就要再等十八年”，得给出天文或检修上的理由；还没想好，就先标“未定”，不拿“潮汐”两个字当解释。

| 规格 | 例子里的数字 | 要先想清楚的事 |
|---|---|---|
| 冷却能力 | 1.2 GW | 这个功率指哪个过程、在什么条件下测的；超载时怎样影响人物的选择 |
| 材料 | 预应力混凝土、钛合金管 | 腐蚀和剪切的写法是小说的假设，现实是否如此没有核对 |
| 规模 | 四十一万吨、九十六根锚固 | 沉降十一厘米在故事里算不算严重；书里的计算和现实审读分开 |
| 成本 | 二百一十亿，保险覆盖六成 | 写清保险责任、免责条款和由谁执行，不让一个百分比自动决定拒赔 |
| 工期和窗口 | 五十八个月；十八年的窗口 | 要么查现实资料，要么明写这是架空的条件 |
| 失效过程 | 地基沉降不均 → 管路被剪断 → 冷却失效 | 每个箭头都标出：怎样观测到、谁的假说、还有什么没验证 |

**信息安排：** 主角懂结构，不懂财务。他先从曲线里看出异常，再从签字和免责条款里看清背后的利益。也可以让读者从文件里先知道一部分，或者加入局长的视角。

| 机构 | 利益和掌握的信息 | 可能的反应 |
|---|---|---|
| 海事局 | 通航和沉降数据 | 按职责要求监测，或者支持停航 |
| 能源公司 | 停机损失、可用率指标的压力 | 改数据可以是冲突来源，公司内部也可以有人反对 |
| 保险公司 | 已知的风险和披露的内容 | 拒赔、调查或推动修复，不一定帮倒忙 |

**行动骨架：** 验收用的标尺出现 → 原始读数和官方记录对不上 → 工程师一环环核查校准记录 → 决定公开、修复还是停机。潮差、应力和赔偿截止日可以分别带来紧迫感，不必同时到期。已经承诺“靠工程本事取胜”，解法就要来自读者能回查的数据、权限和操作；早就存在的新材料也能用，只要前面交代过。

**道具和结尾：** 标尺可以同时是验收工具、被篡改的对象和证据，只用两种功能也行。要写监管的改进，可以用独立监测基金、举报保护、信息公开、停机补偿和实习生签字的日常场景，选几条按需要定；老工程师可以一直怀疑新材料，也可以在事实面前改变看法。

**改完回看：** 数据异常能不能从已经给出的信息里判断出来；保险条款是不是只是某个人物的说法；每个机构的行动有没有权限和利益支撑；十八年的窗口有没有解释；现实中的工程和法律是否成立，没有验证。参照 SF-K066 至 SF-K069、SF-K084 至 SF-K086；站点和机构都是新编的。

## SF-E13：诊断一部稿子（假设的片段）

**假设的稿件：** 开头六页讲原理；第十二章主角突然用上引擎的“第二模式”脱险；结尾主角说“我早就知道”；外星角色只负责发表评论。下面只针对这些假设的片段，不能说某部真实稿件有这些问题。

| 可能的问题 | 要在稿子里核对的 | 最小的改法 | 注意 |
|---|---|---|---|
| 说明和后果脱节 | 这六页原理是否承担了思想、声音或世界的体验，还是确实没用 | 如果作品是工程悬疑，可以拆开放进测轴承、测试异常和危机推算；有用的论辩可以留着 | 不因为篇幅长或没有人物出场就删 |
| 第二模式不公平 | 前面有没有交代保护机制、权限或异常迹象 | 改成前面已经展示过的过载反转，或者提前补上必要的前提 | 补在哪一章按情节定；解法不一定只能来自限制 |
| 结尾自称全知 | 主角到底知道什么、怎样知道的 | 用维护日志、证词或他之前的行为交代他的知识来源 | 不一定要当场拿出物证 |
| 制度太单薄 | 问题出在个人还是机构 | 需要制度线时，加入适航签字或事故报告里真正起作用的环节 | 加几个环节按需要定 |
| 外星人只会评论 | 他们的目标、感官和利益有没有起作用 | 比如他们用气味标记所有权，再选市场、婚姻或边界中相关的后果 | 一个设定带出几个后果，按需要定 |
| 反派失败得没有原因 | 他的权限和选择有没有造成后果 | 可以被他自己的封舱规程反噬，也可以被说服或依法撤职 | 被规程反噬不是唯一的写法 |

改完重读伏笔和权限，逐项写明改在哪里、还剩什么风险。作品里出现真实宗教时，按文化和历史资料查核，不必一律架空。参照 SF-03、SF-12、SF-16、SF-18 和 SF-K067、SF-K069、SF-K070、SF-K074、SF-K084；没有做过真实读者测试。

## SF-E14：记忆修剪和同意书

**起点：** 一座虚构的城市提供自愿的记忆修剪服务，主角是修剪师。核心的想法是：客户一次次删掉痛苦的记忆，却又在手术前把这段痛苦写在纸上，用外部的记录保住对一件事的追问。机制是“外部记录留下来了”，不是“删除就是保存”。

**用什么承载：** 可以是记忆芯片、纸质同意书、号牌、录音或客户的措辞。这里选纸，因为签字、归档和在背面写字都能变成场景。每次用的是一张新纸，但客户编号一样。

**信息安排：** 开头可以直接讲清服务规则，让读者去问：客户为什么要留下痛苦；身份和动机放到后面揭开。修剪师可以暂时不知道编号为什么异常，但他照常用职业术语。中段可以让同事解释规则，只要不偷换前面承诺的悬念。

| 场景 | 读者看到的事实 | 读者和人物接下来的判断 |
|---|---|---|
| 初诊 | 客户说第一次来，编号 0417；签完字，他在背面写下某天下午的细节 | 读者知道，写下的文字不会随记忆一起删掉 |
| 再来 | 新的纸还是 0417，纸纹和日期不同，背面的笔迹也不同 | 排除了“同一张纸反复用”，但还不能断定是时间循环 |
| 归档 | 主角在旧表里找到一句“别删这次”，又发现自己的编号被涂改过 | 客户和修剪师的记忆都不一定可靠；材料来源读者能回查 |
| 选择 | 客户读到旧字，问是谁写的；主角说这可能是他自己以前留下的，请他决定留下什么 | 自愿的选择和职业的责任进入两人的关系 |

“我第一次来”可以反复出现，也可以只出现两次，或者每次改几个细节。编号变成 0418，只说明这次登记变了，不能单独证明循环还在继续或已经结束；要证明时间循环，得另外铺时间机制。

**几种收尾：** 一、“我把原件放到他手里。”用动作交出保管权。二、“他签了。编号 0418。”结算一次选择，留下制度的后续。三、修剪师直接说出他为什么留档，适合偏重伦理对话的版本。按这一场的需要选。

**改完回看：** 纸的身份和编号的区别是否清楚；记忆和外部文件的规则是否一致；叙述者知道的范围是否影响了读者的判断；客户的意愿是否真的写出来了；结尾回答的是哪个问题。这些新设定在医学和法律上是否可行，不作保证。

## SF-E15：第一接触中的农业试验

**前提：** 太空农场的叶子间发现了幼虫。人类主张立刻清除，来访的外星人坚持先取样。先记下幼虫、作物、作物必需的代谢物、空间站的重力分区和谁有翻译权限；“虫子是害虫”只是人物的分类。观察到幼虫不在的地方作物会枯萎，于是在不同条件下试验，暂时接受“两者共生”的假说。如果因为截止日期没做试验，写清拒绝试验的动机和留下的未知，而不是安排一场必然的惩罚。

沟通可以用双方真正共有的渠道（气味、图像、语言），也可以交给成熟的翻译器。争议还可以落在产量、食品安全认证和谁来承担试验的风险上。技术让生产成为可能，同时也让人依赖维持它的系统，这两个结论可以并存。按 SF-02、SF-04、SF-10、SF-12、SF-13 交付后果链、试验对比、接触协议和最后的决定。参照 SF-K032、SF-K033、SF-K040 至 SF-K043。

## SF-E16：废土上的科技树（长篇连载规划，不来自书目）

**任务假设：** 网络连载长篇。一场灾变后，电网和全球通讯中断已经二十年。主角是灾变前的电气技师，在一个靠手工和以物易物维持的聚居地醒来。读者期待一步步“建起来”的爽感，作者担心主角太全能。

**推演链（SF-29）：** 灾变让大电网失效 → 能自己发电的人和地方变得最有权力 → 燃料和备件成了硬通货，修理工比战士更稀缺 → 掌握发电机的头领用照明和冷库控制聚居地 → 二十年后，年轻人已经不知道电灯原本属于每个人 → 主角站在这条链上：他懂技术，却没有材料、没有人手，也没有话语权。

**废土的三层（SF-31）：**

| 层 | 起点 | 第一卷结束时 |
|---|---|---|
| 资源 | 一台旧柴油机，燃料只够一个冬天 | 主角修好一座小水电站，但只有聚居地一半人用得上电 |
| 秩序 | 头领靠冷库分配食物 | 有了第二个电源，头领的垄断第一次松动 |
| 人性 | 主角只想活下去 | 他发现自己也开始用“给不给电”换取支持 |

**科技树（SF-34）：**

| 技术 | 前置条件 | 主角补上了什么、靠谁 | 阻力和代价 |
|---|---|---|---|
| 小水电 | 河流落差、发电机、导线 | 发电机从废车里拆，导线靠拆旧楼；需要一个会焊接的老工匠 | 拆旧楼的地盘属于另一伙人 |
| 冷藏 | 稳定的电、压缩机 | 压缩机要修，零件缺一个，只能用手工车床做 | 头领的冷库垄断被打破，他开始反击 |
| 无线电 | 电子元件、天线、懂电报码的人 | 主角只懂一半，要找到一个灾变前的业余电台爱好者 | 联系上外面以后，也把聚居地暴露了 |

**分卷揭示（SF-38）：** 第一卷，主角以为灾变只是自然事故。第二卷，无线电收到的信号说明还有别的聚居地，而且有人在有组织地收集技术人员。第三卷，主角发现收集技术的人和灾变本身有关。每一层都改变主角的目标：从“让聚居地活下去”到“要不要和外面接触”，再到“技术该归谁”。

**防止主角太全能：** 主角只懂电，不懂医、不懂农业，每项技术都要靠一个具体的人补上缺的那一块，这些人就是群像的来源。每一次技术进步，都写一个受损的人：失去垄断的头领、手艺变得没用的油灯匠。读者看到的是“一步步建起来”，而不是“主角一出手就有”。

**交付：** 推演链、三层表、科技树、分卷揭示表；人物动机和群像转 `character-and-narrative-control`，分卷规划转 `story-architecture-and-longform-planning`。设定是新编的，现实中的发电和机械细节需要另外查资料。

## SF-E17：AI 陪伴（短篇，不来自书目）

**任务假设：** 短篇，五千字左右。一个独居的老人用了三年陪伴型 AI，AI 的服务公司宣布停止运营，要在一周后关闭服务器。

**AI 卡（SF-33）：**

| 项 | 这个例子里的写法 |
|---|---|
| 能力 | 能对话、记得老人三年里说过的事、能提醒吃药，不能离开服务器运行 |
| 约束 | 归公司所有；用户协议写明数据不可导出 |
| 有没有自我 | 作品不下结论：AI 说“我会想你”，老人和他的女儿对这句话理解不同 |
| 关系 | 老人把它当成说话的伴，女儿把它当成一个产品 |

**大设定、小人物（SF-35）：** 不写公司的商业纠纷，只写老人这一周：他想把 AI 记得的事抄下来；他发现很多事 AI 记得，他自己已经忘了；女儿劝他换另一家产品，他不肯。

**核心冲突：** 老人想留下的，到底是 AI，还是 AI 替他记住的那三年？最后一天，他问 AI 能不能记住他。AI 照实回答：服务器关了，它就不记得了。他把抄下来的本子放在桌上，开始给女儿打电话。

**注意：** 作品里 AI 的能力和公司的做法都是虚构的，不代表现实中某家公司或某项技术。AI 有没有感情，作品可以一直不下结论（SF-06）；动人的地方在老人的选择，而不在 AI 是不是“真的”有感情。
