# 执行流程与做不到时

返回 [guide.md](guide.md)。

## 1. 建立最小任务框

从用户已有信息记录创作/诊断/改写、篇幅媒介、目标读者、人物目标、正典规则、叙述方式和可修改范围。未给设定可提出带假设的创意；未给原稿可原创，但不能报告具体原稿缺陷。不要为填写表格阻断已能完成的工作。

## 2. 将问题拆到承重对象

从SF-02–15选择实际相关的装置、意识、身体、知识、制度、生态或时间对象。记录对象、成立条件、可观察变化、角色可选行动、限制与期待结果。不同对象不合并成一条万能规则；相似规则在对象/条件/动作/限制/结果均相同才去重。世界内自洽、现实正确与价值判断分别列证据。

## 3. 选信息安排和来源层

记录读者已知、每个视角可知、说话者可能错在哪里。工程可给量纲与误差，寓言可保留未知，制度可给日常与资格，概念短篇可给语义变化；可混合。书里的现象、机制解释、新稿与迁移，分开标明。精确原文引用使用书名、版本与章节定位；定位不足时不伪造。

## 4. 将规则变成可写场景

挑知识卡中与目标最接近的机制，改变人物、装置与情境，而不是搬用原句。填入谁观察、如何解释、作何选择、状态如何变化。若当前机制需要限制，说明为何该边界影响后续；若不需要，不硬造受害者或倒计时。重要条件尚有分歧时，给替代写法，例如万能门转所有权冲突，或规则智胜转未知恐怖；用户目标已清楚则直接完成所选方案。

## 5. 结算承诺

分别检查事件结果、概念认识、关系、制度与价值承诺。读者被许诺的公平答案需要前提或解释；刻意开放可以保留多解。结尾可以长可以短，不用三层物证/一物三用/十二词验收。重复说明是否删，取决于其是否仍承担人物、节奏、论辩或情绪功能。

## 6. 有依据的诊断与复验

| 检查 | 何时算命中 | 最小修法 | 做不到时 |
|---|---|---|---|
| 设定与行动脱节 | 作品承诺由设定推动，却找不到承重后果 | 补一个选择、反馈或关系；也可确认设定只承担奇观 | 纯审美/论说目标可不修 |
| 临时解套 | 已承诺规则智胜，却靠没有线索的新能力获胜 | 补必要前提、改变解法或明确改变信息合同 | 悲剧/不可知不强塞漏洞 |
| 说明节奏 | 对当前阅读目标重复或过早，且有实际稿证据 | 移到问题出现处、改视角、保留论辩或缩段 | 没原稿只给候选诊断 |
| 机器/身份 | 把可伪造信号或机构声明当最终事实 | 区分叙述可靠性、权限、记忆与法律 | 可靠内视已设意识时无须再凑证据 |
| 社会扁平 | 作品需要系统解释而只给无因反派 | 补执行、利益、反馈或救济 | 个人恶人/寓言角色也可以成立 |
| 接触换皮 | 差异被承诺承重却不影响任何经验 | 补感官、分类、礼仪或利益中的相关一项 | 人类相似性是主题时不判失败 |
| 关系突变 | 没有足够的对话、选择、照护或目标证据 | 补承重互动、调整变化幅度或保留不可靠判断 | 不强塞共同战斗/牺牲 |
| 重复与导语 | 对当前悬念没有所需作用或误改问题 | 改变信息/关系/节奏；调整预告对象 | 仪式、停滞、情感重复可保留 |
| 留白 | 实际承诺需答案而前提或收束缺失 | 补关键证据或明确说明 | 多解合同可保持未决 |

复验回答“哪处原文、哪个条件、改变什么、哪些承诺仍未完成”，不只打勾。还没回读的写“未复验”；没有实际用户测试的写“未测”。不要因一个案例不适用停掉全部任务。

## 交付

任务与假设 → 选用SF/K卡及案例来源 → 实际文本证据或原创设定 → 具体方案/新稿 → 反方案与条件（存在重要取舍或用户要求比选时） → 承诺核对 → 书中事实、现实和效果里没验证的范围。诊断与修改权限分开，用户已授权修改则完成相应改动，不重复求许可。
