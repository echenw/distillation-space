# 乌托邦双轨

### 乌托邦的双轨检查

设计理想社会时同时呈现两条轨道：

- **系统轨：**制度如何提供安全、资源、公平、效率或共同目标？
- **个人轨：**个体为此付出什么、放弃什么、如何协商例外？

只写系统收益会像宣传，只写个人代价会失去制度吸引力。让两条轨道在具体人物选择中发生冲突。

**可选收束三件套：**至少让读者看到制度参数（如资格、配给、劳动、资源或执行方式）、一组日常体感细节，以及一个能提出外部质疑的人/群体/反例。参数条数不设门槛，质疑者也不必是反派；重点是让制度如何运作、普通人怎样生活、异议如何被回应都可见，避免只剩宣言。

### 机制账本

每个关键技术或制度机制可先用通用四项：输入条件、运行过程、可观察输出、成本/失效边界。若超常能力承担主要因果，再补专用机制账本：

| 能力 | 触发条件 | 必然可观察物证/副作用 | 受损者 | 可逆性/不可撤销性 |
|---|---|---|---|---|
| | | | | |

空项写“未知/尚未设定”，不要凭空制造伤害或不可逆代价。还要记录谁能使用、谁承担后果、哪些人被排除，以及角色如何验证机制运行。
