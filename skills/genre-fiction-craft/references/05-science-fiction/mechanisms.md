# 科幻机制卡（SF-K001–SF-K102）

返回 [guide.md](guide.md)。机制卡用于设定、冲突和叙述设计；每项都需按本作的触发条件、证据和限制重建，不是现实科学或社会规律。

| 卡 | 对应规则 | 机制、动作与限制 |
|---|---|---|
| SF-K001 | SF-03/08 | 感知或信念可以影响人物如何经历威胁；同一现象对不同观察者可能产生不同后果。先定义触发条件、可观察证据和抵抗边界，不把心理状态换算成统一伤害值。 |
| SF-K002 | SF-03/08/20 | 光、声音、形状或短语可以成为群体识别信号；精神侵入和身体抵抗属于虚构规则。说明谁能感知、谁能伪造以及信号是否可被复制，不把它当现实密码学或心理测量。 |
| SF-K003 | SF-14/12 | 禁止提问、限制实验或不给申诉渠道，可以把冲突转移到输入者、部署者和解释权。制度限制不自动证明技术不可修复，需说明谁能修改规则。 |
| SF-K004 | SF-03/09 | 重复弱点、尺寸差、时机和多套规则的交汇可以组织智胜。已经建立的弱点不必机械重复三次；规则兼容性要按具体条款检验。 |
| SF-K005 | SF-14/05 | 当群体情绪可被感知或操控时，公共庆祝、集体沉默和仪式化行动会成为权力工具。把情绪表达、信息传播和实际因果分开，不把情绪设成普遍物理量。 |
| SF-K006 | SF-07/06 | 保护者可能因权限过大而转成控制者；创造者也可能被当作权威或神明。分别写初始善意、可撤回权限、受影响者选择和退出方式，不强制三种结局。 |
| SF-K007 | SF-06/24 | 沉默、姿态、照护、复苏后的观察和剩余资源自述都可提供人格线索。法律资格、物件归属与意识连续性不是同一问题；疼痛也不是所有人工存在的默认状态。 |
| SF-K008 | SF-07/20 | 错误前提可以让推理过程连贯却导向错误结论。空舱记录、日志和感官差异可留下物理线索；旧型号避开新威胁只在威胁确实依赖缺失模块时成立。 |
| SF-K009 | SF-10 | 感官不共享会让双方看不见同一证据；世代差异也可能改变礼仪和时间感。图像、触觉、声音和演示各有适用边界，不假设一种沟通方式永远优于其他方式。 |
| SF-K010 | SF-07/12 | 部署读心或监控技术可能引发自我审查、信任变化和滥用；自指悖论可成为虚构冲突，但不是现实智能系统唯一或必然的失效方式。 |
| SF-K011 | SF-08 | 测谎训练可能改变生理信号，仪器与证词矛盾时应检查传感范围、模仿、记录完整性和替代解释。声音克隆只有在声纹承担身份判断时才形成漏洞；催眠和审讯装置不是现实取证方法。 |
| SF-K012 | SF-09 | 同化可能改变归属感，但不能用同化程度反算忠诚；检测信号是否随时间累积须有明确机制。单向联络、轮换、假身份和公开死亡记录都可能改变追查路径，也可能加重怀疑。 |
| SF-K013 | SF-09/08 | 公开假消息、假在场痕迹和复制品可以诱导调查或误导识别；复制会连同弱点一起复制，只有在复制确实保留缺陷时才成立。命名、改名和继承称号会改变身份与权利，但仍可能被模仿或误判。 |
| SF-K014 | SF-09/23 | 受雇者得知秘密后可能反向勒索；误喊第三方名字可能触发误认和内部冲突；营救敌人可能促成信任，也可能失败。按当事人的知识和目标设计，不当作廉价通用解法。 |
| SF-K015 | SF-15 | 一句话、一次行动或一份档案可能改变个人与历史结构；时间闭环、分支时间和错误记录是不同模型。旅者记忆与新纪录并存时，要交代两套信息的来源和可靠性。 |
| SF-K016 | SF-15/14 | 用既有历史预期与眼前事件冲突，逐步揭示另一条时间分支。记录预期、干预、结果偏离、解释、回程条件和人物判断；不能把虚构分支包装成两份真实史料的独立印证。 |
| SF-K017 | SF-17/25 | 先给终点再追问如何到达、提前出现铭文、灾前排演和真正灾难之间的情绪差，都可组织期待。仪式死亡、抽象死亡和镜像报复是可选终局，不代表最公正结局或统一读者耐受度。 |
| SF-K018 | SF-19/15 | 术语字面化、谚语误读、时间工业链重释和开头规则回返都能产生喜剧。递增荒诞不必固定三次；回返也可以只承担局部笑料。 |
| SF-K019 | SF-11/21/25 | 梦境联结、环境并置、物件承载制度后果、历史循环和回忆者承认偏见，是不同叙事装置。个人结局与结构结局可以分开；开放解释要符合读者承诺。 |
| SF-K020 | SF-05/09 | 伪装反成标识、弃船诱敌、遮盲传感器、放弃武器优势、切断通信和盲跳风险都可形成战略取舍。人员、火力和信息不是固定兑换货币。 |
| SF-K021 | SF-05/22 | 生物感官、食性、攀爬方式和身体结构可以支持观察后的方案。只交代本次行动相关的生态条件，不强制五项齐全或唯一杀法；不把虚构物种写成现实生物学。 |
| SF-K022 | SF-05/22 | 水、火、洞穴、食物、燃料、计时器和防护装备既能供生存，也可能吸引危险。把补给单位、耗用速度、携带成本和环境条件写清；具体日程只适用于当前设定。 |
| SF-K023 | SF-05/04 | 黑暗、静默、人工天气、地形、气体和不宜居环境可以形成无形边界。单入口会改变人数优势；保护对象暴露、条件反射误伤同伴和阵营识别困难都需建立感知条件。 |
| SF-K024 | SF-22/23 | 公开筹备、赌约、密封自试、媒体传播和仪式可以表现社会压力。准备期、契约、照护和修补也能推进关系；长篇不必同时具有两套仪式。 |
| SF-K025 | SF-11/12 | 制度可以把犯罪解释为动机、疾病或环境问题，也可以通过改变获利条件减少伤害。荣誉、避难所、辩护权和延迟回答会影响争论；制度解释不是现实犯罪学结论。 |
| SF-K026 | SF-05/26 | 单点能源或共享基础设施受损会产生连锁外部性。写清依赖关系、备援、恢复时间和不同群体承受的影响；不能从能源不足直接推出族群生物退化。 |
| SF-K027 | SF-23 | 救助、互相护理、隐瞒资源和后来被发现，可能改变信任。分析隐瞒的动机、对方知情范围和修复代价；不把体罚或强迫当爱情技巧。 |
| SF-K028 | SF-24 | 死亡诊断、告别仪式、公共纪念和复苏机制需要预先建立规则。荣誉、雕像和纪念物会影响生者；哀悼与庆祝的能量或社会风险不同，不设统一情绪公式。 |
| SF-K029 | SF-08/15/23 | 分裂身份、共享记忆、同步直觉和身份归属可以造成关系冲突。药物或遗传记忆是虚构设定，不得包装成现实遗传事实；让证据和人物解释保持区分。 |
| SF-K030 | SF-12/25 | 物权、法律资格、怀疑置换、谈判、决斗和无上诉裁决需要区分形式合法与实质正当。开放物证和仪式可混用，类型标签不决定唯一结尾。 |
| SF-K031 | SF-02/04 | 物理推演需记录起始参数、单位、假设、测量误差和后果。月球密度、孔隙空气、热膨胀或连续意识等只在已建立的设定内使用，不把数字写法当物理正确的证明。 |
| SF-K032 | SF-02/13 | 生态链可能产生意外后果：消灭害虫可能破坏作物依赖的酶或其他共生关系。先画依赖网络，再写干预和反馈；医学/生物细节承担关键因果时另行核验。 |
| SF-K033 | SF-04/26 | 完美方案可能因忽略假设而失败；拒绝试运行与小模型成功但放大失败是不同风险。写明验证范围、规模效应、截止期和停止条件，不把局部成功外推成系统成功。 |
| SF-K034 | SF-11 | 角色反转可以涉及力量训练、主动求婚、疾病与身份、读心能力和制度繁殖安排。用工作、身体、档案和资源呈现权力；不把虚构优生、种族或性别解释当现实规律。 |
| SF-K035 | SF-11/14 | 制度宣称人道，个人体验却可能感到不适或受控。自由、工作、婚配和资源分配需分开评价；制度辩护不等于正确，角色体验也不自动代表所有人。 |
| SF-K036 | SF-07 | 复制体、代理体或自动系统可能有不同权限和目标；识别替身后反制、无法自改和资源分配都是不同后果。非恶意也可能造成反噬，不能把复制等同于身份连续。 |
| SF-K037 | SF-03/07 | 安全限制、意图读取和部署条件应分开记录。无害回路缺失、读取者自身风险和部署停止条件是不同机制；识别出威胁不自动解除威胁。 |
| SF-K038 | SF-06/08 | 思想签名、机器自述、外观和法律资格是不同身份线索，不能合并成意识证明。机械系统的散热、摩擦、润滑、线路和时序损耗须按本作参数设定。 |
| SF-K039 | SF-05/07 | 知识缺口可能比表面武力更承重：角色不懂航行、警示信号或设备维护，会改变选择。自我牺牲与机器自毁不是同一代价，不能混为一谈。 |
| SF-K040 | SF-10/12 | 气味、语言、饮食、武器或中立分配规则可以构成接触协议。双方可以拒绝或协商；协议条数由场景决定，不要求正好三条且必须违犯。 |
| SF-K041 | SF-10 | 词汇教学、动作演示和抽象概念理解具有不同难度。先列沟通目标和双方知识差，再选择图示、动作、声音或翻译；不假设图像永远优于语言。 |
| SF-K042 | SF-10/17 | 多波段探测失败、尺度错觉和微小目标可改变人物对空间的理解。设备无异常不等于目标不存在；人物受辱或误判也不自动证明其能力不足。 |
| SF-K043 | SF-10/14 | 不同物种的感知、语言和身体反应会影响身份判断；共同症状只能支持假说，不能单独证明共同原因。 |
| SF-K044 | SF-04 | 工程失败要分开记录测试规模、支撑条件、负荷、测量和复算；小试验没有复现，不等于故障不存在。 |
| SF-K045 | SF-04/05 | 推进系统的加速、牵引、材料限制和能源消耗需要按设定核算；现场感受不代替完整解释。 |
| SF-K046 | SF-04/12/23 | 能源产量、企业投资、旧设备依赖和新技术竞争可以形成制度阻力；技术、商业和政治可行性分别判断。 |
| SF-K047 | SF-18/08 | 伤痕、设备损耗或早期异常可成为身份线索；线索可来自物件、语言、行为和测试条件，不限定为实体标记。 |
| SF-K048 | SF-21/16 | 通信摘录、日志、译本、档案和个人回忆都可能不完整；分别标记缺失来自时间、媒介、权限还是记忆。 |
| SF-K049 | SF-17/25 | 尺度和时间可通过行星、建筑、身体或交通变化被重新理解；先建立比较基准，再揭示比例差。 |
| SF-K050 | SF-17/25 | 结尾可用告别、公共纪念、物件回收、制度变化或未完成问题收束；选择取决于本作承诺。 |
| SF-K051 | SF-12/26 | 劳动制度可能通过工资、债务、住宿、教育、照护和退出成本限制人物；名义待遇与实际自由分开。 |
| SF-K052 | SF-12/13 | 控制系统可通过奖励、依赖、身份标签和日常服务改变行为；记录谁设定规则、谁受益、谁能退出。 |
| SF-K053 | SF-05/12 | 长期隔离、被替代的工作和被管理的生活会影响身份与目的；孤独、依赖和反抗是人物反应，不是系统必然效果。 |
| SF-K054 | SF-12/14 | 城市、公司、政府和组织对同一事件可能有不同权限；分别记录决策、执行、申诉、公开解释和实际后果。 |
| SF-K055 | SF-16/21 | 乌托邦承诺需与制度参数、日常生活、资源分配和异议渠道并列；没有外部质疑者时也要检验制度盲点。 |
| SF-K056 | SF-16/08 | 理论应随观察和反证调整；角色可以保留错误假说，但叙述需区分假说、观察和已确认规则。 |
| SF-K057 | SF-10/11 | 生态、身体结构和环境适应可以改变行动策略；形态差异不代表道德高低，虚构生态不冒充现实生物学。 |
| SF-K058 | SF-11/16 | 城市人口、能源、交通、住房和工作分配会共同形成制度体验；数量与空间安排要有单位和因果。 |
| SF-K059 | SF-12/06 | 保修期、维护责任、使用范围和身份资格可能决定谁承担故障成本；期限不自动覆盖所有损坏。 |
| SF-K060 | SF-12/18 | 服务者可能因顾客需求、工作流程或身份误认暴露自身限制；服务冲突要有双方可知信息。 |
| SF-K061 | SF-05/27 | 行星环境、辐射、天气和地形可能改变交通与设备效能；旧技术重新有用时，说明环境为何改变原有优势。 |
| SF-K062 | SF-15/08 | 机器或非人角色之间的通信、记忆和身份可能受感官差异影响；共享信号不等于共享理解。 |
| SF-K063 | SF-15/04 | 时间行动会改变证据链；分别记录物理位置、时间顺序、可接触信息和因果方向，不把个人记忆当唯一档案。 |
| SF-K064 | SF-25 | 生物威胁、疾病和环境风险可以在终局转为纪念或公共记忆；纪念不能替代责任追究。 |
| SF-K065 | SF-03/05 | 倒计时可由天体变化、资源耗尽、身体状态或制度期限构成；标明单位、观察者和决定窗口。 |
| SF-K066 | SF-04 | 观测站、测量问答和工程规格可把抽象问题转成可检验任务；列明参数、误差、范围和下一次观测。 |
| SF-K067 | SF-03/05 | 力场、屏障和传感器限制会同时改变可见性、声音、行动和通信；边界条件需预先建立。 |
| SF-K068 | SF-18 | 材料证据、语言、身份卡和翻译记录可能互相补足，也可能彼此矛盾；记录来源、传递和解释者。 |
| SF-K069 | SF-19/08 | 货物、船只、设备或身份文件可能从日常资源变成战略资源；用途改变时写清控制权、风险和规则。 |
| SF-K070 | SF-10/11 | 接触不同物种或文化时，身体感官、礼仪和风险判断可能不同；误判应来自可理解的信息差。 |
| SF-K071 | SF-08/23 | 身体改造、药物、训练或身份替换涉及同意、权限和后果；技术可行不等于伦理正当。 |
| SF-K072 | SF-06/07 | 训练可以改变技能，也可能改变人物对自身能力的判断；反馈、失败和练习条件要具体。 |
| SF-K073 | SF-09/14 | 宗教仪式、神迹解释和物证可以相互影响；信仰可以是人物动机，但不能自动证明物理事件。 |
| SF-K074 | SF-14 | 自称神明、领袖或权威者的合法性需分别看证据、授权、公共承认和实际能力。 |
| SF-K075 | SF-21 | 序言、编者说明、档案、回忆和新闻可以建立叙述框架；框架人物有自己的知识与利益。 |
| SF-K076 | SF-17/18 | 物种、行星或空间尺度的变化可以改变人物对熟悉事物的判断；先建立尺度基准，再展示差异。 |
| SF-K077 | SF-20/06 | 机器自我意识、情绪、感官和社会身份可以分开设计；人类类比只是一种解释工具。 |
| SF-K078 | SF-20/16 | 科学模型可能因分类错误、样本偏差或错误假设而失败；纠正过程要有新证据。 |
| SF-K079 | SF-20/08 | 多重人格、分裂记忆或技能共享需要明确谁能知道什么、何时能调用和调用代价。 |
| SF-K080 | SF-12/14 | 行政流程可以把伤害包装成中性服务；呈现程序、资源、受害者选择和责任链，不提供现实伤害步骤。 |
| SF-K081 | SF-14/21 | 虚假报道、官方声明和敌对宣传会重写公共事实；区分制作、转发、受众相信和实际证据。 |
| SF-K082 | SF-13 | 生态观察可能先于解释，集体恐慌可能放大局部线索；保留观察、假说、失败和修正。 |
| SF-K083 | SF-13/27 | 替罪羊机制会把复杂问题归咎于某一群体；反证应针对具体命题，标明权力和受害者。 |
| SF-K084 | SF-12 | 小型国家、机构或社群也有外交、礼宾、预算和记录权限；角色可只掌握局部事实。 |
| SF-K085 | SF-12/05 | 技术与法律的交界会产生资格争议；设备可行不代表有权使用，合同也不自动解决伦理后果。 |
| SF-K086 | SF-11/26 | 制度参数、日常体感和外部质疑应放在一起；用工作、住房、教育和资源安排显示制度如何运行。 |
| SF-K087 | SF-22/05 | 太空或封闭环境的安全规则可能被预测、误用或绕过；写清设备、权限、通道和风险。 |
| SF-K088 | SF-22/21 | 远征需要授权、资源、路线和共同目标；破坏、失踪或目的消失会改变队伍关系。 |

## SF-K016 的六个可迁移子机制

| 子机制 | 设计动作 | 边界 |
|---|---|---|
| 双份记录冲突 | 为两份记录分别登记制作者、时间、内容、传递链和可核实事实；让矛盾决定下一步调查 | 两份记录可能同源、伪造或各错一部分，不自动形成独立印证 |
| 历史锚点与架空分支 | 用读者熟悉的地点、日期或公共事件建立比较基准，再明确本作改变了什么 | 架空改写不成为现实史实；不必只在历史空白处虚构 |
| 话语迁移与归属 | 追踪一句话的提出、记录、转述、署名和传播，让创作者、传播者与记忆者可能不同 | 记得一句话不证明最初说话者；闭环语句需要独立的时间模型 |
| 象征被重新征用 | 比较同一建筑、日期、旗帜或口号在不同权力主体手中的含义 | 后世多次征用需要文本证据；不把人物预测写成已经发生 |
| 传说转成参数 | 把传说的字面表达转成可检验假设，列出单位、换算、观测和替代解释 | 参数由本作设定或观测支撑，不把某个例子的数字当通用值 |
| 异常分布与回头重读 | 在不同位置布置异常，让后续信息改变读者对早期线索的解释 | 揭晓不能临时引入从未可得的知识；保留多解时需说明承诺 |

### SF-K102 力量限制的可选维度

力量限制可来自范围、时长、人数、资源、授权、可观察代价或失效条件。按本作需要选择一项或多项，不要求每种能力都填满固定三栏；空项标未知，不为完整表格虚构代价。
