# MY-06 可裁剪工作表与修正案例

返回 [guide.md](guide.md)。

以下字段用于记录一次推理设计或诊断。一次任务只选影响本次判断的表；未知不是零、未写不是不存在、设计方案不是原稿事实。不以凑齐表格代替正文交付。

## MY-06A 建案和诊断表

| 表 | 字段 | 如何使用与出口 |
|---|---|---|
| 任务卡 | 已读版本/范围；题材与时代；目标读者承诺；作者目标；可改位置；禁动事实；待定设定 | 缺稿可做设计预设；依赖原稿的诊断写明“没有原稿，不能判断”；不擅扩改稿授权 |
| 答案命题 | 谁/做了什么/何时何地/如何/为何；哪些属于核心谜题；哪条是作者已定事实 | 不将所有字段强制变读者测验；开放项明确开放范围 |
| 人物候选 | 身份与关系；动机/机会/能力的实际依据；可见行为；知道什么；误信什么；隐瞒什么；替代解释 | 候选数量、每人秘密数及嫌疑权重按作品需要；缺某项不是自动排除 |
| 线索账 | 编号；原稿位置；观察原貌；发现者；读者可见部分；初解；真解；其他解释；区分信息；终局用途 | 感官细节、证词、文书与元信息分型；同源线索不可假装独立；严格契约查核心信息是否可用 |
| 信息时间链 | 发生、感知、记录、转述、人物知悉、读者获知、推断与行动时点；每段可靠性 | 不要求所有时点有精确钟数；说明顺序、时区/钟差或区间就足够时不伪造精度 |
| 时空边界 | 入口/出口/视线/间隔；谁检验；方式和权限；盲区；可能改变边界的动作；前提可信度 | 人物误排可以推翻；作者已保证的客观事实不能无说明反写；死者/施害者/工具/作用时点分别看 |
| 因果与替代 | 观察；候选因果；各解释预测；已知区分点；缺失点；可行核查；能证明与不能证明的范围 | 一条决定性证据可以够，多条同源也可以不够；不强制两种物证、三本书、两名专家 |
| 证物流转 | 形成；持有/接触；复制/替换/污染；存放/运输；检验；使用者；尚存副本或旁证 | 缺口降低相关推论强度，按具体替换可能评价；不是全案自动无效，也不保证连续即真实 |
| 证词与表达 | 原话；说话对象/目的；直接观察或转述；省略/虚构/误认；诱导条件；独立核对；角色/读者各自能知 | 片段可作线索；定案需解释其指向；人物说谎、叙述者省略分别按契约处理 |
| 检验或陷阱 | 要检验的命题；预期反应；非罪犯也可能反应的原因；观察权限；结果；替代解释；伦理/程序后果 | 不能把恐惧、镇静、逃跑或“自投罗网”直接等同犯罪；小说里用过不等于现实合法有效 |
| 调查场景 | 进入前假设/资源/关系；行动和阻力；取得或失去的信息；反应/决策；未变项；下一步 | 可推进知识、关系、风险或主题；重复问话/仪式不因未新增物证自动删，先看其实际功能 |
| 收束账 | 读者理解；人物理解；证据状态；机构裁决；公开版本；私人代价；未偿承诺；后续风险 | 多种结局维度可并用；不把知道凶手=能逮捕=能定罪=已获正义 |

## MY-06B 专门装置补充字段

- **痕迹/足迹**：先在场景中定义可留下与可保存痕迹的材料、天气、通行及清理条件，再记录形状、方向、覆盖关系、步幅、负重等真正给出的属性。无痕只有在本应有痕且检查可靠时才支持排除；国籍、阶层或性格不能由步态直接推出。进入—停留—离开可有未知段，不强制每段一件物证。
- **消耗计时**：初始量、开始时刻、速率条件、中断/补充/替换、结束观察和误差。蜡烛/烟/炉火提供区间须有对应设定；“三个条件齐全”也不是万能充分条件。
- **食物与接触**：分配、先后、份量、实际摄入、共享/独享、接触机会、检测与替代路径。某人没中毒可约束路径，不能自动指认下毒者；虚构药理另标，真实药理需另核。
- **身体与医学**：观察者能力、观察条件、时间误差、已有病史、死因假说、检验限制与本作世界规则。伤口主要支持工具/作用方式，身体标记还要排模仿、误认和记录问题；不由本资料给现实诊断。
- **密室和不在场**：封闭对象、封闭时间、目击范围、钟表来源、行动/作用/发现时刻、验证者及可被误排的前提。清单可证伪“密闭”本身；不要求先认定真密室再给自然出口。
- **文件/录音/密码**：载体、作者/保管者、生成时点、复制和编辑能力、密钥或识读规则、内容何时对谁可用、真实性与内容真伪分别验证。仅让读者看见一封信存在，不等于已公开用于唯一解的关键句。
- **身份/伪装**：主张、观察者旧识、可变/较稳定/制度登记标记、语言/动作训练可能、代认者利益、公开资料传播、识别后谁有权认定。两个名字不自动两个人，不同时间出现也不证明同一人。
- **误导复核**：误导来自事实歧义、人物误解、叙事选择还是故意说谎；它是否在当前契约内；真相后能否重读成立；是否需要修正文或调整承诺。无需每个红鲱鱼都回连凶手。

## MY-06C 历史设计案例的修正用法

### 1. Ferngate 庄园：线索多不等于排除链完整

**保留的原创设定**：1926 年，Adrian Vane 在书房中弹，门被称为从内反锁；侄女 Clara、管家 Mott、医生 Ryle、摄影师 Trant、与 Clara 订婚的律师叙述者 Hugh 都与死者有关。原线索有窗边由外向内的泥迹、左手手套/裸露右手、缺铜脚的摄影三脚架、规则鸟足迹、钟面 10:07 与 9:45 餐铃、未亮的暗房红灯。

**当前诊断**：两时刻相差 22 分钟只是算术，未证明有人拨钟；枪登记属于死者不排除医生接触；钥匙在死者口袋不排除管家使用或复制；干披肩不足以排除 Clara；脚印形态、铜脚、白袜、焰火与凶案的连接若终局才补，不是已设伏线；门如何封闭也尚无解释。原“Trant 已被两链证明”的结论撤销。

**实际修法**：保留这些观察，但为每个排除补“它排除了什么替代、依据何在”；缺失处直接记未知。若作者预定 Trant，可设计能够在授权章节提前出现的区分信息，并逐项核查其他人可否同样产生，不能把预定身份写成证据。若不扩写相关场景，本次交付应是候选案与补写清单，不能标唯一解通过。此例用于诊断推断断层，原人物与道具不是其他小说必须照搬的模板。

### 2. 丢失手稿：找回位置与证明意图分开

**设计预设**：档案室有相同盒子，下午有人搬动，夜间检查位置；后续找到手稿。盒体相同、搬动与某段无人进入，能支持误放解释，但未独立排除故意隐藏后返还。若纸条压痕、旧标签或登记轨迹作为区分点，须先让读者知道足够内容并核其形成时间。能够找回手稿不自动证明没有犯罪意图；证据只够定位时，人物可暂不确定动机。

### 3. 剃刀、护士与屋内死亡

**设计预设**：战时乡宅访客喉部受伤死亡，门内锁；护士先发现；一组七把有星期标记的剃刀，而死者平时不自剃。摘要没给足迹或出口不能据此宣布后半案作废。星期编号是观察，尚不能证明当天只有某人拿过；护士平静可能来自职业经验。先问此案承诺解死因、身份还是密室，再补相关持有与接触链；专家可正确解题，无需人为插入另一专家反驳。资料不给医学确定性或具体作案工程。

### 4. 医生助手叙述，读者在三分之一处猜中

读者早猜不等于不公平或作品失败。先确定作者要惊奇、参与解题还是知凶后的悬念，再核实际原稿。没有原稿，不能宣布已有“三处说谎”“十分钟钟差”或“迟到的遗嘱”；它们只能是可选原创预设。可比较叙述者省略、误导性真话、直接说谎分别与契约的关系；一次留白、八千字门槛、必须有文件或侦探失误均不成立。过于具体的发言可能暴露内部知识，也可能来自事先获知，需核信息路径。

### 5. 仅改开头与揭晓的公寓案

**原请求范围**：退休法医顾问，读者第八章猜出；只改开头与揭晓。原演示新增止吐药、九十分钟、内锁、18:40 签收、处方底联和瓶批号，必须标成“预设”，不能说原稿已经有。签收证明某次交付，未必证明现场出口；购买药物不是犯罪；底联编号和生产批号是不同系统，需要真实映射及接触/使用链才有指向。

**在范围内的交付**：开头明确可核观察和读者承诺，揭晓只使用已建立且可区分的关联。若关键桥段只能放第三章，先给待授权建议，不擅改第三章；两处无法修复时说明具体依赖，仍完成可做的局部修文。顾问真实专业推理可以构成解法，不强降为氛围装饰。

### 6. 同床位医院连案

**设计预设**：三名病人在同床位死亡，常规尸检未给答案；护士卧底成为第四名。步态可模仿时单独指认薄弱，问题在可区分性而非“不足两条”；新增器械创口也不自动指向持用者。煮沸只可能影响特定痕迹，库存、调拨与接触记录仍可用；匿名消息可以是真线索。

把“发生了什么”“谁造成”“目前可证明什么”“机构如何处理”拆开；严格公平只约束作者承诺的核心字段，补充性动机可后述。外来调查者可先盲读证据再看旧名单，不必永久拒绝旧材料。面包丸诱试是原书虚构装置，不能称其当然合法、医疗可行或反应即定罪；本案例不提供现实药理与人体试验方案。

### 7. 1908 年伦敦案：隐藏出口与处置混写

**保留预设**：黑函、保险利益、雨伞、蜡钥匙、检修口、女仆擦肩及妻子选择。若检修口是真出口，却在前文被作者当作完整客观列表排除，终局偷加不公平；若是人物未检查处，可以揭示误排，但严格契约需让读者获得检验该前提的机会。第二章擦肩不自动公开出口机制。雨伞与不同门的钥匙关系若未建立，不能用“都是钥匙”串成因果。

公开司法与私人和解可分阶段，但不能同时声称已完成正式逮捕定案，又仅凭妻子一句“不追究”就让同一制度当然撤销。可选：机构确已受理且结果按已定制度处理；或人物有解释但证据不足，采取私人关系选择；或明确另有制度权力与程序。妻子的意愿是重要行动条件，不能冒称普遍法律否决权。

### 8. 中段问话反复与钟点伏线

三十至四十五章连续审问、动机二十章已明，不自动要求每四五章做一次实验或新增三件微物证。逐场核知识、立场、风险、合作与情感是否变动；无目的重复可删并，刻意压迫、停滞或仪式可保留。第八/十/十二章同一问答：第十章无新作用可并；第十二章若改变关系仍可留。钟点在第二/五/八章出现，应核每次观察是否让读者形成可用时间关系，不把“三次出现”或“先异常后解说”当充分必要条件。

## MY-06D 交付文本模板

```text
任务／作者目标／已读范围：本次可改范围与实际承诺：定位与观察：解释与替代解释：诊断状态：成立／条件成立／证据不足／不适用
实际修文或设计（新增事实显式标记）：为何能改善本次目标，何时会失效：案例来源（书中观察或本作设计；新演示标“编的例子”）：回看：信息、时空、身份、保管、程序、人物后果
仍缺的具体材料或待作者取舍：
```

不把模板状态预填为已完成，不以来源自带的检查记录替代本次核查。对无法核验的现实事实，保留虚构前提或提出外部核查项；其余已授权创作继续完成。
