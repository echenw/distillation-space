# 历史架空：史实承诺、制度行动与私人命运

返回 [SKILL.md](../../SKILL.md)。本题材的规则编号是 HI（HI-01 至 HI-90）。

先读这几句：
- 这里给的是有条件的创作方法。小说里写了什么、作者或编者怎么说、人物相信什么，分开记。
- 小说写到的法律、日期、头衔和物价，不等于史实；要当真，得另找外部史料。
- 案例只是样本，不穷尽这个题材。效果没有经过读者测试。

## 工作顺序

1. **界定输入。** 记录用户要规划/诊断/单场景，已提供文本和版本、只审或可改、时代地域、人物与公开结果中哪些已定。缺年代但正在写人物选择时，可以用显式假设先完成结构方案；只在缺失项会改变结论时询问。无稿不能声称发现某章具体错误。
2. **立叙事承诺。** 选择真实历史环境中的虚构、完全虚构世界、明确结果改写或混合；不是互斥标签考试。写清哪项读者会当真、什么有外部史料、什么只在小说里成立。来源不足时留研究任务，并给可用的虚构分支。
3. **找承重因果。** 用“谁在何时知道什么、获准做什么、拥有什么、选择什么、改变谁的处境”描述卡住处。只加载会改变这一问题的规则；不要把六个执行文件的全部规则一次套齐。
4. **画出实际链。** 对文书分真实性、接受、执行；对行动分知识、权限、资源、时限；对信念分说法、相信者、行为、观察结果。若规则冲突，按对象与条件分支，不用先验的单一模式压平。
5. **写可审阅成果。** 完成场景、事件表或修订段，不只交原则。写清触发、选用的 HI 编号、具体动作、产出、失败或替代、来源和没验证的部分。案例库展示如何完成这条链。
6. **回查承诺与边界。** 验证新解法没有暗中更改史实承诺、权限、时间与所持信息；真实人物的拟作文件要明确小说身份；偏见不能从角色语言升级为叙述事实。先修具体接缝，再处理文风。
7. **到适当停止点。** 未证的史实可以阻断一个事实断言，但不必阻断整个虚构任务。交已完成可用分支、确切待核问题及补证会改变什么；不捏造日期、法律、引文或资料。

## 依据分五种

- **小说文本**：某个版本里发生了什么、出现了什么；人物说法、传闻、叙述者判断和作者前言再分开。小说写了某条法律或精确日期，不等于这条法律或这件事真实存在。
- **外部史料**：史料支持的历史判断，要记下材料的身份、版本、范围和争议。这个目录以小说技法为主，代替不了这一步。
- **用户设定**：用户定下的世界事实，可以指导创作，但不自动成为史实。
- **推断与建议**：从观察提出的机制推断和这一次的动作。多部小说用了相似方法，也不证明对所有作品有效。
- **证据不足**：可以给分支设计，不把“未知”改成“禁止”。

引用当前文本时分清作品和版本；同一段场景的重叠来源只算一次；同一作者的其他作品，不能只凭作者名合成一条证据。

## 做不下去时

| 发现 | 下一动作 |
|---|---|
| 真实年代/头衔/法律缺证 | 暂停该事实断言，给研究问题或标明虚构的替代设定 |
| 凭证真实却无人执行 | 查接受者、权限与利益；补执行机制或承认真实也无法救济 |
| 意外解围替代了主角选择 | 补已存在的能力/关系/程序；或把意外作为新困境而非无条件奖励 |
| 反派似乎全知 | 补他实际获取的信息和可错部分；若全知是世界设定则核其边界 |
| 道具、预言、仪式只剩标签 | 明确它改变认知、资格、行动、情绪或主题的哪一项；若只是意象可以保留其意象功能 |
| 历史败局被归咎给虚构私生活 | 分开人物归罪与叙述因果，补外部证据或声明架空分歧 |
| 偏见/疾病/暴力被当普遍真理 | 回到具体说话人、受影响者和文本后果；选择适合本作的叙述回应 |
| 规则里出现人数、字数、回合的硬阈值 | 查它是不是本作真有的约束；没有证据的配方改成可调参数 |
