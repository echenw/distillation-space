# 生存与灾难机制库

返回 [guide.md](guide.md)。每项按当前设定的条件使用；资源数字、工程参数和现实操作需独立核验。

| 模块 | 对象、条件、动作与结果 | 边界 |
|---|---|---|
| 资源循环 | 密闭、灾后或封闭据点：追踪来源、转换、消耗、废物和再生如何影响下一环；检查污染或错误分层是否让资源不可用。 | 物理设定需核验；不把单一故事的资源模型当现实定律。 |
| 体力与里程 | 将身体状态、口粮、行进成本和环境联系；个体差异改变公平，不套统一日耗。 | 动物和人物有不同生理条件；关键生理数字需核验。 |
| 能力缺口 | 主角不会的事可通过求助、观察、协作、学习或回避呈现；不必每项都失败。 | 不把无能当成唯一制造冲突的方法。 |
| 训练与工时 | 长周期成长用练习结果、材料与时间证明可达性；重复训练可压缩，失败原因需具体。 | 工时和成长速度不能跨岗位、人物和环境照搬。 |
| 追踪与断踪 | 记录可见痕迹、解释人、备选解释和断踪成本；人物可以误读线索。 | 不补造未建立的追踪规则，不提供现实规避追踪的操作步骤。 |
| 距离与冗余 | 对抗戏记录设定中的工具射程、可见性、故障与备用选择，保持跨场一致。 | 不提供真实武器优化；虚构参数不外推。 |
| 撤离时机 | 比较留下/撤离的资源、路线、信息和人员风险；明确谁能决定、谁承担后果。 | 未给出的阈值标未知，不编造水位、时间或概率。 |
| 被俘与逃离 | 记录控制权、押解空间、谈判、救援介入窗口、可用工具链和代价。 | 不套固定小时数、环节数或逃脱公式；不提供现实逃脱或暴力操作指南。 |
| 决策记录 | 重大选择可记提议人、拍板人、依据、反对意见与复盘；小队可一句交代。 | 不强设官僚程序；记录形式服从团队规模。 |
| 代价不对称 | 同一威胁对一方是生命，对另一方可能只是时间或资源；揭示地位与视角差。 | 不把儿童故事的低伤亡基调移植到所有成人题材。 |
| 密闭载具事故 | 以危险来源、空间约束、系统相互影响和逃生选择组织场面。 | 不把虚构顺序当现实应急程序；真实安全知识需专业来源。 |
| 家庭技术分工 | 谁识材、谁提出用途、谁质疑、谁维护，让同一资源成为关系戏；日常、节日和信仰安排属于人物文化。 | 不把家庭分工写成性别本质。 |
| 前人遗产 | 遗留物、留言、遇难者装备或旧设施同时带资源、产权与伦理；说明能否使用、谁承担责任。 | 发现不自动等于拥有；遗物也可能危险或无法确认来源。 |
| 信用补给 | 城镇、避难所或运输故事中，赊购、担保、拍卖和分成也是资源链。 | 金额与信用代价由设定给出，不把虚构价格当市场数据。 |
| 产权威胁 | 模糊占有与正式权利会改变谁能动用资源；分别记录持有、使用、保管和所有权。 | 不作现实法律意见；发现不自动视为产权。 |
| 日常物错读 | 对方缺少某项技术知识时，普通物件可能被误读；反转要呈现双方信息差。 | 不把误读归咎于某个群体的“愚昧”；避免殖民式本质化。 |
| 动物作为线索 | 角色观察动物并推断环境，须保留误读和验证；动物行为可以提示变化。 | 小说方法不成为现实动物学、寻水或野外生存指南。 |
| 火的双向性 | 求被看见与躲避追踪时，同一烟柱有相反价值；公开信号与暴露成本一并记录。 | 不强制所有故事都出现火或烟。 |
| 偶然动作追认 | 临时动作后来承担关键功能，之后才被人物系统化；前因须在场。 | 不等于作者可临时加外挂；关键结果需有可回看的条件。 |
| 外界行动作信道 | 失散队伍、留存痕迹或第三方记录可形成后场兑现；接触不等于及时救援。也可以写一条按逾期触发的固定寻找流程：谁该回来、谁去查、查到什么程度才升级，每一级都对应一个具体人和一件具体工具；流程被跳过或迟了一级，就是近失或彻底落空的现成原因。 | 交代信道如何产生、谁能看到和延迟多久。 |
| 机构容量与谣言 | 公开消息、供水、病床、封控和物流互相影响；谣言与事实分开记录。 | 容量数字和公共卫生细节需核验；单一地区不能代表所有制度。 |
| 知识与语言遗失 | 文明级灾变可用职业转变、失传程序和代际记忆表现尺度。 | 不套几天口粮表；知识遗失需有传递和学习条件。 |
| 工具控制即权力 | 两人组中收走工具，既可保护也可剥夺行动；检验双方后果而非默认正当。 | 工具控制不自动等于恶意；要看授权和替代选择。 |
| 价值排序 | 铁器、文具、繁殖资源、珠宝或记忆物的价值因环境改变；留一件无实用价值物也可揭示身份与情感。 | 不用固定价值表；人物价值判断可能不同。 |
