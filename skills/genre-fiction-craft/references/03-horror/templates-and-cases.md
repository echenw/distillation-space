# 可填写模板、条件案例与历史独有材料

返回 [guide.md](guide.md)。

空白处不是配额；填多少由任务决定。案例分三种：**书中案例**（从书里归纳的）、**书中案例，核过原文**、**编的例子**。编的例子不算书中证据，也不证明读者效果。

## HO-T01 威胁与终局工作表

| 字段 | 要填的内容 | 缺失时怎样继续 |
|---|---|---|
| HO-T01-01 任务合同 | 构思/章纲/起草/诊断；作者目标、可改范围、已有有效功能 | 缺稿可设计，不能编造现稿诊断 |
| HO-T01-02 威胁与损失 | 实体/空间/人/流程/心理；实际失去什么 | 给有实质区别的备选，不强塞怪物 |
| HO-T01-03 起因与关系 | 起因的时间/地点/事件；受影响者如何被选中（关系、血缘、行为、随机或未知）；动机、受益者、受损者 | 起因可未知，已知的行为链仍须清楚；不把遭遇当作受害者有罪的证明 |
| HO-T01-04 四层认识 | 确证规则、角色信念、观察事件、未知 | 保留未知，不补虚构的事实 |
| HO-T01-05 感知与显形 | 谁从何感官取得什么；时段、地点、触发条件、形态与出现频率；感官余像是否关联源起；显形改变什么 | 无须一次/末段才显形；局部或直接都可；关联源起是设计选项 |
| HO-T01-06 痕迹 | 前态、变化、见证、替代解释、证明范围；有关场次留下什么，终局回收哪项 | 不规定一个或多个物证，不要求每幕产出物证 |
| HO-T01-07 传播/递进 | 通路、权限、关系或资源怎样变化 | 不要求三级、三次或逐章死亡 |
| HO-T01-08 反制 | 可伤/可退/可封/可替代/可离开/可容纳/暂不可知；条件、操作步骤及失败分支 | 不用“肉身比例”推算可杀性；步骤可简可繁，不必付出代价 |
| HO-T01-09 代价与修复 | 谁承担、何时、可否恢复，或明确无偿恩惠 | 不强加不可逆损失 |
| HO-T01-10 证词链 | 每人亲见/听闻/否认；材料文类、原件与转引、矛盾及改变说法的时点；独立性待核 | 不设三人两源门槛，矛盾不自动证明有人说谎 |
| HO-T01-11 空间/时间 | 路径、权限、封锁、误认、时钟或回环；领域的感官特征、进入和逃离条件 | 无相关作用时可略；空间特征不等于超常机制已确证 |
| HO-T01-12 解释合同 | 要定案的是事件/身份/机制/动机/宇宙原因哪一层；解释者的动机、依据与解释时点 | 给竞争解释及缺口；可不解释，不强制四项排除 |
| HO-T01-13 四轴终局 | 兑现、解释、余留、人物与社会后果；作品中的复仇/悲剧/混合伦理怎样影响结局 | 不按物种指定唯一惩罚；伦理的变化须有语境，不强制全篇单一宇宙论 |
| HO-T01-14 同情与责任 | 谁受害、谁解释自己、谁可以宽恕、谁承担后果 | 不用苦衷抵销受害事实 |
| HO-T01-15 语气与时代重构 | 报告/古物/怪诞/敬畏/喜剧；历史立场与作者立场；移到新年代后制度、种族/性别/医学再现需怎样调整 | 不把残障、族群、性别当邪恶捷径；历史偏见可呈现，但须辨明谁持有此立场 |
| HO-T01-16 证据与退出 | 章节/场景定位；事实、设计、解释分开；证据不足之处与补证需求 | 先交不依赖疑点的部分 |

原有 16 个观察字段全部有逐项承接：强度间隔由 HO-T02-09 承接，机制失效由 HO-T01-16、HO-T02-11、HO-T02-12 承接。“形态次数上限、肉身公式、所有解咒代价、固定四项排除、最低见证人数”已从字段内撤销，不能通过旧字段名称恢复。

| HO-T02-02 本场任务与恐怖机制 | 求证、接近、逃离、照护、谈判、仪式、等待、解释、告别或其他；本场采用显形、纠缠、罪案、领域闭合或其他机制 |
| HO-T02-03 入场认识与权限 | 人物和读者各知道什么；能看/听/接触什么 |

| HO-T02-11 失效诊断与修订取舍 | 读者可能识破什么：有意让读者先知，还是机制穿帮；具体修法及增强、失去的功能；存在重要取舍或要求比选时比较 A/B |
| HO-T02-12 场景出口与验证退出 | 事件如何接入下一场：行动、问题、余波、时间跳跃或停顿；所需稿件/原文/作者选择；效果未测 |

原有模板的位置、类型、感官、自救、物件、显形、证词、规则、缓冲、道德、证据、失败、时代偏见、出口字段均在此保留。“道具≤1”“结尾只出现一次”不作要求。场景不因超额而自动失败。

## HO-T03 现稿诊断单

先写作者所选的终局与语气，再写真实稿件的问题位置。每项使用下列记录：

```text
诊断 ID：原稿位置与实际观察：作者目标 / 已有效功能 / 不可改项：判断的条件（为什么这是本稿问题，而非风格差异）：证据：原稿位置；必要时章节/场景定位，事实、设计、解释分开：建议修改：具体动作；预期影响；会失去的功能：备选修改（存在重要取舍、反信号或要求比选时）：具体动作；预期影响；会失去的功能：未确定项：作者选择 / 缺正文 / 来源待核 / 效果未测：建议采用与保留理由：
```

诊断可按以下对象选用上表字段：题材与语气定位；诅咒、禁问、遗物或框架形成的吸引力；显形与感官呈现；威胁变化与自救条件；证词的文类、矛盾和倒戈时点；解释者动机及解释时点；强度间隔；伦理关系；结局的物证呼应和有意拒述；巧合发生位置与作用；时代重构；具体规则对应的修订处方。每个诊断仍需填真实原句和本稿适用条件。

巧合按其承担的因果作用检验：建立困境、改变局面、作为作品主题或用无铺垫办法解开已经承诺的难题，不按超过一次判错；结局不限定四选一；不以同情、完全解释或婚姻结尾为自动降级。

## HO-T04 证据链和反解释表

| 主张 ID | 原始观察/原件 | 知情者及权限 | 转引链 | 直接支持什么 | 不能支持什么 | 竞争解释/反证 | 状态 |
|---|---|---|---|---|---|---|---|
| 自填 | 精确到对象、时间、位置 | 亲见/听闻/推测 | 同一原件则关联，不重复计独立 | 事件/身份/机制等 | 不跳层 | 能覆盖与缺口 | 事实/设计/解释；已知/未知/证据不足 |

书出自同一作者、同一选集或同一传统不自动判相关；同一报道的重印、同一人转述则记录共享底层来源。没有追查过是否真正独立，就写明“来源关系未查”。

## HO-C01 继承衣物如何从同一题材分成两种故事（编的例子）

**输入**：继承旧外套后出现亡亲呼声；作者想保留家庭恩怨但未定鬼是否真实。**方案 A**：外套纽扣藏有催债人暗号，亲属借传说阻止继承人调查；结尾解释声音来源但保留过去的胁迫。**方案 B**：声音只要求在一个具体节日把食物送到旧住处，履行后关系变化，但所有人对声音来源仍有不同理解。

**可执行场景**：人物先以为口袋里是钥匙，实际摸出一张被水浸过的名单；是否让名单有超常来历由终局合同决定。证据写其物态与持有者，不把“湿”直接等同死者。反制不预设付命或三次尝试。书里的方法保留遗赠、临终要求和家庭关系分支；不把示范冒充书中情节。

## HO-C02 护理院交班：从感官清单改为责任与权限（编的例子）

**原来的设计材料**：交班册被删页、两种手迹、湿脚印、铃声、腕上瘀痕、影子数和开门。**改法**：将每项绑定问题：删页遮住谁授权转房；两手迹是不同班次还是补写；湿脚印是否因清洁路线产生；腕痕是否来自看护而非鬼。若影子数承担超常分支，必须由有观察权限的人看到并说明灯位。

**场景落点**：护士选择先开门救人还是先保全交班记录，两条行动都会改变证据和照护。不能要求恰好三痕迹、75% 才升级、只出现一次实体、结尾仅留一项未知。**反方案**：所有痕迹都有自然原因，但交班制度仍让无人愿意承担救助责任。护理者和病人各有立场，不以疾病本身作邪恶标记。

## HO-C03 修复录音的档案员（编的例子）

旧目录的录制日期早于一次失踪，两种笔迹来自不同时期，几个证人的叙述年份冲突。先建事件时间与材料制作时间两轴；再比较拼接、记忆偏差、目录错录、未知声音四种解释。修复音频只增加可听内容，不自动识别发声者。

可改为档案员发现“失踪后录音”其实是早期蜡筒的转录日期；这一解答保留伤害的现实原因。也可让该解释只能处理时间，不能解释录音中的私人称谓。修改几场由原稿功能决定，不固定三场；不知道底层原件时，所有转录不算独立佐证。

## HO-C04 医生、密封信与身体变化（书中案例）

门后声音、破门、日常室内物件与不合身衣服让调查从空间转向身份；镜子、断钥匙、改写遗嘱及笔迹分别承担不同主张。封信的开启条件控制解释时点；代词裂隙和写作被另一自我打断改变叙述权限。药物杂质解释操作的不稳定，但不自动为道德心理作终极裁决。

可借用“行动高点—普通房间—异常细节—解释高点”的顺序，也可提前展示变身，改为预知危险。前者不是所有恐怖必须的起伏。

## HO-C05 屋宅裂缝与朗读回声（书中案例，详例）

景物理性分析未能消除不适；石材尚完整与整体衰败、裂缝提供不同层次的异常；自我放大的恐惧、症状与《Haunted Palace》 互相映照。误葬信息、尸身红润使读者获得不同于人物的判断空间。

朗读故事与屋内声音同步，认罪和宅体崩溃回收前设。保留“文本中另一个故事与现场声音互文”这一独有机制；不将裂缝出现次数或声音对应数写成配额，也不禁止有功能的重复。

## HO-C06 婚姻、监护和继承的囚室（书中案例，详例）

Alice 进入 Squirecourt，门锁提供出入关系；秘密婚姻、黑帘、三名前任让预兆同时有情感与制度含义。纸隔墙和储物空间提供解释路径。

Charles 死亡、第一妻子的揭露、真继承人在农场、婴儿替换、肖像与两次医生来访等自白，把凶宅感重新连接到婚姻与财产权。保留制度、人物与空间的三条因果链；不要求每章恐怖、不强制三次巧合或“有婚礼就降级”。

## HO-C07 见证与替代床位（书中案例，详例）

第一故事从见证声明、车声与死亡时序，转入丈夫禁令；第一妻子已在屋内与身份信息改变读者知情，丈夫的说法制造关系性压迫；镜门与险差一寸需要空间连续性。

另一个故事的密室、监护遗嘱、睡位误替、拒杀同谋分属不同链，不能合成书里的同一个事件。新作借床位替代时要给搬动、误认或安排的前因；不能让恰好换床自动救出主角。

## HO-C08 迁移者与失物清单（书中案例，详例）

购地新闻先提供日常社会变化；水泵、新路、失物和修改痕迹/时间各能有普通解释。组合后形成需要新的归因的问题，机构解释、无花与犬、寄生得失进一步改变判断。

普通反制失败，银火与护身物丢失有特定条件；结尾以新地名复现开篇，使局部胜利与外部延续并存。不能抽成“每怪必怕银”“一定先死人”“恰好四异常”；保留最后句式与地名变化这一结构。

## HO-C09 车上尸体的错误身份（书中案例，核过原文）

雨夜把尸体装袋放上车；道路颠簸使它在两人之间撞动。冷湿接触、体积错觉、犬吠累积不适；停车提灯后发现不是预期的女人。二人认出 Gray 后跳下，灯破熄灭，马受惊载尸疾驰。

**可迁移动作**：先让运输中的自然运动成立，再用身份不可能改变其意义；未知的是置换或显现的原因。**撤销动作**：“尸体自行逃走”不存在；“结尾用冷档案”不适用此现场。该书前部评论和后部小说分开：供尸情节、Jane、全部被谋杀、共谋等场景；此前法律机器、钟表、帮派评论不合并为同一小说叙事。

## HO-C10 选集里的六种材料链（书中案例，详例）

| 篇目或局部 | 因果/信息动作 | 保留的边界 |
|---|---|---|
| Mrs. Veal | 私人衣料增加可核信息；又提出营销解释 | 私密细节可被质疑，不能自动裁决幽灵 |
| Canon Alberic | 姿态、图画、手、异语分步改变认识 | 不把外语本身当邪恶，只写人物权限 |
| The Haunted House | 规则、犬、足迹、锁室、信|的磁力/意志是解释立场；停表与犬损失分开 |
| Banshee |旁人听见而受害者未听 | 不同听者的权限可承担悲剧，不要求每人一致 |
| Pan / 山羊足迹 | 具体图像或痕迹 | 不因都含民俗就合成同一底层证据 |
| 否认鬼与报纸材料 |的鬼否认鬼、男孩面白，以及的报刊材料 | 反讽口吻与新闻载体有不同可靠度，不能拼成共同见证 |

## HO-C11 反恐怖边界也能提供有效装置（书中案例）

有作品用鬼作比喻；圣洁城堡、床上活人、假死与手帕身份可供误认与空间设计，却不证明全书是超常恐怖。《The Open Window》 用精准谎言让正常回家被重读，死亡征兆另属篇目。管风琴—长袍—暖触与假死揭示可支持感官反转。

惊奇、精神尺度、第三影、少年归来、巨人死亡和花的终章，保留敬畏与损失而不强加恶意。无鬼、拘禁、抗争与茶试验，保留纯人类压迫分支。

## HO-C12 隐形袭击与验尸官（书中案例，附改写设计）

验尸官框架、日记/报道、看不见的攻击、山狮/癫痫判决并排除日记、不可见颜色理论，分别属于程序、经验和理论。借成“猎人小屋”新稿时，人物可以只知道地面压痕与伤，不可让他知道另一地点的实验结果。

自然判词可合理但不能覆盖全部文字；也可成为作品最终解释。新加的猎人、武器或仪器都标明是编的。书中的程序说法不是现实的医学或司法指南。

## HO-C13 预言不是必须发生的未来（书中案例，附反例）

有的作品写逃避与应验，是悲剧路线；也有作品写可以改变的未来。若新稿设孩子将死，人物改变生活而孩子活下来，可以成立；不能为了“不可逆代价”硬把他写死。红羽与最后呼吸则是另一组严格状态标记。

**反例**：把红羽的每次变化与“施法者必被反噬”“Marley 也被同咒击中”合并。正确做法是逐一记录文本里的触发与承担者，后者只是道德锁链，不能补作咒术机制的跨源验证。

## HO-C14 黑魔法的物态变化（书中案例，核过原文）

粉笔圈内似 Joris 的形体在火中挣扎，无法越界；Theirry 在记忆推动下抓起它，手指受灼，火变灰，手中是焦木。可以观察“接触后的物态证据改变了对刚才景象的理解”，但仍须分别记录人物看见的形体和接触后的物件。

“ΚΑΣΣΙΤΕΡΟΙΟ 与百合验证”在原文里找不到，不算这部书的案例。作者想设计百合验证仪式，可以当作新的设计，不说出自这部书。

## HO-C15 温情、持续与有条件回归（书中案例）

家中旧主人、狗与家庭相册把恐惧转为关系；真实狗的替代与幽灵肖像不互相取消。善意邀请和回归测试可支持继续往来。原作由 Milly 的既有关系完成修复，后来保护儿童。

可借这些机制写“幽灵留下，但活人的关系改变”，也可选择告别。无须强迫未知不解、无辜者死亡或永久离开来证明题材资格。“温情鬼必须离开”的硬式被这些反例推翻。

## HO-C16 古宅供选择的四种终局（编的例子）

**共同输入**：年轻继承人被禁止问前房客，走廊每晚有开门声，遗书似乎能解释失踪。**A 人类阴谋**：钥匙磨损、监护收益和信的制作时间揭示具体人；恐惧落在合法关系的控制。**B 规则幽灵**：前房客要求一项已建立的归还，执行后不再阻门，起源仍不知。**C 开放**：信证明囚禁，门声只在单一叙述者材料中，结尾保留来源争议。**D 温柔持续**：前房客保护后来者，主角改变屋内规则而幽灵仍在。

四者不是唯一结局菜单，也不按人/鬼程度规定。显形、证人、仪式、巧合和章节比例由具体因果安排，不采用 1/4、3/4、三证人、两至四仪式或三巧合上限。

## 待核语境不丢弃，但不冒充精确证据

七室与钟、说教/物质残留/持家幽灵、伪科学与凝视武器、梦戏/手稿模式/修复释放，以及 Wendigo 的气味、Green Tea 的信件监视、Walpole 的巨人复仇等，只有作为语境或候选技法的提示，未取得足以精准归因的原文定位。它们只作语境、证据不足，保留为提问：该感官是否有识别功能？文字复制是否改变权限？修复是否解除旧封存？不写成已经核验的作品事实。

## HO-C17 假神迹中的真实消息与自参与（书中案例）

真实的职位空缺消息加固了骗局，书中把人扮成 St. James 引导战斗；这本书是冥界讽刺游记，不因此改判全书恐怖。可迁移的是“真实无关细节提高假主张的可信度”，检验时应问真实消息是否真正证明神迹。

书中主角发现给自己订棺、签名、付款的人正是自己，恐惧来自对自身参与流程的重读；救出、司法结算与假钻石完成自然解释。保留职业程序和文书作为虚构可信度材料，不复述下药剂量为现实方法。伪造商人信则是另一种由叙述者主动引爆的欺骗，不与无意自参与混同。

## HO-C18 可见性的关系、创造者和被讲述者（书中案例）

原作提供可见性关系的讨论；拒担保与“道德之真”不同于实物证据。 Walton—Victor—造物三层叙述、弃责与造物者/造物关系，把“谁有权描述怪物”变成伦理问题。梦游自述显示第一人称可以受限而不可靠；前言明确采用本土荒野，与古堡原型是素材选择分支。

原作让店主拒绝留宿，同时有人正在编集来客的事实；诱惑和自我敌人关系给框架另一种压力：人物进入一个已在被他人书写的故事。新作可让材料搜集改变人物行为，不必规定所有人都相信怪物。

## HO-C19 声音负空间与无法一次清除的痕迹（书中案例）

原作以应有而缺的蹄声/装备声和仅存轻响突出集结方式，点名让身份、罪与服役关系由固定答话显现；温热肌肤和死者身份构成双重身体判断，报纸名单负责另一层时空核对。信或不信的外框不禁止出现实物。
再生的头发被另一人见证、血袍分别让痕迹难以抹去；久未响钟和代偿是特定宗教/伦理结算，不推广为普遍“禁令必须代价具体化”。足消失、绿泥偶像留下，是替换而非完全撤证。

## HO-C20 日常灾难、异常尺度与荒诞并置（书中案例）

原作用磨坊倒塌的巨大尘云与安全平庸的上班日对照；牧师警告不与灵建立亲密关系是人物宗教判断。房屋与反复迁出建立气氛，动物感知是另一个观察通道；动物害怕不自动证明机制。

沙进入缝隙、荒漠仿佛注视人，让尺度与侵犯发生联系；刻意扣留异象精确性质。巨盔、画框与法老拒婚、魔鬼抱怨，保存荒诞与敬畏的材料，不规定对手不能说话或人物越小效果越好。

## HO-C21 假鬼之后的真警告与非同时成立的解释（书中案例）

原作以真人扮鬼及惊吓女仆结算一段误认； Abbot 与后续预测属于另一条信息链。前一段揭假不能自动否定后一段，也不要求每个揭假故事都加真鬼。

电报、护士、来客与车夫，亲吻死者，各自解释部分经验，不能由“多段证词”直接合成为一个全知版本。该书另有伤痕与虐待情节；妻子被收治与丈夫夸耀要保留施害与叙述权关系，不能只当作气氛装饰。

## HO-C22 奇异生物、民俗医者与接力故事（书中案例）

John Silence 的疗法在为人物自述；动物探针和宇宙尺度材料可供角色功能设计，不能升格为现实治疗或作者的有效方法。猫迎/犬惧与其他动物线索保留差异，不强制所有动物一致反应。

Austin→Villiers→Clarke 传递、知识差、铭文和拉丁记录可以同场共存；单个死亡扩至社会恐惧改变关系范围。最后阶段可拓宽侵入范围而保持规则一致，不能把“开始影响更多人”自动命名为无条件传染。
