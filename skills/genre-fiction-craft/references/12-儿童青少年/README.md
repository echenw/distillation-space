# 儿童青少年创作：读者、行动、讲述与后果

以儿童能够知道、选择和承担什么为主轴，把朗读方法、故事结构、成长叙事、动物与玩具幻想、汇编编排整合到同一流程。适用于构思、起草、诊断、改编和故事会准备；真实年龄认证、医学教育效果、危险实操不由本题材文件判断。

先读 [融合规则](fused-rules.md)，随后按 [工作流](workflow.md) 选任务；交付使用 [统一模板](templates.md)。[操作示例](examples.md) 展示正常、缺料、冲突、边界四种输入。

| 任务 | 实际读取 | 输出 |
|---|---|---|
| 新故事或长篇结构 | CY01–CY07、CY10；当前细节库的读者与因果段 | 所求故事或结构、读者条件、行动链、设定契约与后果；重要条件未定或要求比选时给分支 |
| 写儿童声音或修订视角 | CY03、CY09、CY12；当前细节库的声口与权限段 | 可知信息表、最小改写、反向检查 |
| 朗读或故事会 | CY01、CY02、CY08、CY11；当前细节库与改写例材F | 讲述检查表、删改理由、现场纠错与反应预案 |
| 危险、欺凌、尊严问题 | CY04、CY07、CY12；改写例材A/E | 风险/求助/成人责任、后果与保守分支 |
| 合集、旧作改编 | CY02、CY06、CY11；当前细节库的汇编与多来源解释段 | 编排维度、改编保留/删除表、多起源归属 |
| 题材独有机制与形态观察 | CY13；当前细节库与改写例材 | 起源故事、转述链、成人接力、命名、奖惩、玩具契约、愚行链等机制的对象/条件/行动/后果 |

完整有效细节见 [当前细节库](knowledge-details.md)，原例的现行步骤见 [改写例材](revised-legacy-examples.md)，统一模板保留各字段的用途。

这里提供人工/Agent执行的写作流程。没有自动年龄模型、保证儿童喜欢的配方或已完成的读者实测；实际效果保持 NOT_PROVEN。
