# 小说创作的规划、诊断与自检

把一部作品从素材带到可写、可诊断、可修订。四类主要工作：**规划新作、起草场景或章节、诊断成稿、修订与删减**，每类都从同一步开始：先定赛道（FC-01）。另有三组配套的工具：**成稿自检**（CL 测试）、**现实断言的核验**（RS 卡）、**读者反馈与试读**（RF 卡）。

## 1. 适用与转介

用：
- 带着素材、构思、梗概或一句想法，问怎么写成小说、短篇或连载。
- 场景任务：“写这一场”“把这一章续上”“这个转折怎么落地”。
- 给出成稿或片段，问哪里有问题：中段为什么塌、人物为什么假、开头为什么抓不住、说教味为什么重。
- 要删到多少字、要重排结构、连载太长怎么收。
- 历史、职业、地方题材的事实契约，引语、统计、原型、“首创”这类现实断言要不要查、怎么查。
- 收到评论、编辑意见或读者反馈，不知道该不该改；想做一次试读。
- 不确定该用哪个写作 skill 的时候。

需要专项深入时转给别的 skill：

| 问题 | 转给 |
|---|---|
| 主行动、终点、因果与巧合、多线汇合、场景功能、删场的细则；分卷和连载的规划 | `story-architecture-and-longform-planning` |
| 一场戏的进出与约束、伏笔与兑现、悬念强度、章末钩子、松紧节奏、结尾余味、打斗 | `scene-conflict-and-rhythm` |
| 谁来讲、视角越界与切换、信息控制、场景与概述、跨越时间、人物心理的呈现 | `character-and-narrative-control` |
| 句子、用词、标点、对白格式、校对 | `line-editing-and-proofreading` |
| 推理、恐怖、言情等题材的契约和专项技法 | `genre-fiction-craft` |
| 改成舞台方案、分场稿、镜头 | `cross-media-drama-adaptation` |

不在范围：非虚构的写作、翻译、排版出版、影视剧本格式和分镜、游戏和互动叙事、诗歌歌词；现代的销量预测和市场数据；现实中的医疗、法律、科学结论。舞台和戏曲只取能迁移的结构（幕、折的收束，大收煞）。

## 2. 使用方式

- 宿主规定了输出格式，就按宿主的格式交付；`templates/` 的表只在没有规定时使用。
- 普通任务读完本文件就能做。需要分支细则、反例和来源时，只读 §6 里用得到的文件。FC 规则的正文分在四个 `rules-` 开头的参考文件里，按编号找。
- 给了稿子就按稿子诊断，带位置（章、节、段）和短引文，不整段复制；只给了构思就做规划。
- **要求写正文就写。** 场景的目标、阻力、前后文缺了哪一项，先补一个合理的假设并标“假设”，写完把假设列出来请作者确认。
- 缺赛道的信息时，给两三个赛道方案和各自的代价，按最可能的一个往下做，标“暂定”；只有答案会彻底改变方案时才停下来问，一次最多问三个问题。
- 保留的底线：不编造“稿里有”的问题或引文；改写在副本或修订单上做，不覆盖原稿；整章重写、改结局、换视角先给方案，作者同意再动；作者的意图声明不等于文本已经做到；“读者会……”都是待验证的假设，不说成研究结论；没有真实的读者反馈，不声称读者效果已经验证；不复制受版权保护的原文。
- 文中的数字都是起点，不是门槛。

## 3. 最短路径

### 第一步都一样：定赛道（FC-01）

写下四项：篇幅（字数或章数的区间）、媒介（印刷、连载、舞台、口头）、类型（现实、传奇、侦探、言情、玄幻、寓言、速写等）、交付（一次读完、追更、现场）。再写一句读者承诺（CL-01 的契约两行）。缺项标“暂定”。后面的规则只在这个赛道里生效：短篇的规则不直接上推到长篇，反过来也一样。

### 规划新作

1. 胚故事（FC-02）：谁、在什么困境里、做了什么不可逆的选择、读者最后带走什么。
2. 统一的方式（FC-03）：短篇用一个主导效果取舍；长篇用主行动统一，加上语调和母题的统一。
3. 终点（FC-04）：短篇定终场的画面和末句的方向；长篇和连载定终局的状态。
4. 入口（FC-05）：人物、情境、终局、效果，按素材里先出现的选；人物用三场景预测检验（CL-05）。
5. 主线与次线（FC-06）：主行动句；每条次线反转或补足主线的哪一点、在哪里交汇。
6. 单元（FC-07、FC-08）：场景、概述、过渡怎么配；章末、幕末怎么收。
7. 开篇（FC-09）、结尾模式（FC-10）、类型契约（FC-20）。历史、行业、地方题材先定事实契约（CL-06），列出要核的现实断言（RS 卡）。
8. 交付规划表（`templates/novel-plan.md`）。

### 起草场景或章节

1. 场景卡四项：目标、阻力、结果（局面怎么变）、前后文的接口。缺的先补假设。
2. 视角合同（FC-11）和读者已知度（FC-12）。
3. 可信度（FC-13）、细节的剂量（FC-14）、文体的调子（FC-15）、主题从行动里长出来（FC-16）、类型承诺（FC-20）；设定和景物通过人物出现（CL-03）。
4. 写。章末按 FC-08 收。
5. 交付正文，加几句说明：用了哪些假设、视点和距离、章末留下的问题。

### 诊断成稿

1. 写清范围：读了哪些，没读哪些；只对读过的部分下结论。
2. 按 §4 的症状找规则或测试；每条发现带位置和短引文；先试着推翻它（作者是不是有意这样写），推翻不了再下判断。
3. 定严重度：动到主行动、终点、因果的先修；场景和章末其次；句子最后。
4. 每条给最小的验证方法和修改方向。交付诊断报告（`templates/diagnosis-report.md`）或自检报告（§5 末尾）。

### 修订与删减

1. 先冷却，再分层改：结构 → 场景 → 句子 → 校对（FC-17、CL-13）。
2. 删减先分对象（事件和场景、句子和词、解释和点题、人物和支线），逐类问：是否改变主行动、是否唯一承载必要的事实、是否服务语调或人物，再决定删、压、并、留（FC-19、CL-09）。
3. 只说“太长”、没有目标字数时，给两三个删减方案和代价，请作者选。
4. 改动留痕、可以回退；交付修订单（`templates/revision-sheet.md`）。

### 核验现实断言

1. 先定事实契约（CL-06）：在声明的范围内求准确、明确的架空，还是世界内部的设定；可以按对象分层。
2. 把断言拆成单条，按类型选证据（research-and-verification §2、§3）。
3. 逐条对照 RS-01 至 RS-14 的“什么时候查”，命中的都做。
4. 每条给六种结论之一（在声明的范围内核实、有限支持、有争议、被推翻、无法核实、虚构设计），写出限定语；拿不到原件时，不说“已经查过权威来源”。

### 处理反馈与试读

1. 每条反馈保留原话、来源、读过的范围、利益关系，拆成可回查的观察、偏好、没有依据的预测（reader-feedback §1）。
2. 对照读者契约：目标读者真正的理解障碍优先处理；审美分歧给几个方案，不票决（RF-01、RF-10）。
3. 没有反馈时，交付试读的方案（RF-11），不交“读者已认可”的结果。

## 5. 规则卡

FC 规则的细则、反例、依据和可信度在四个 `rules-` 文件里，每条一个最小示例在 `examples/rule-examples.md`；CL 测试的细则在 `self-check-` 文件里；RS 卡和 RF 卡的全文在各自的文件里。

### 赛道与骨架（`references/rules-premise-and-structure.md`）

**FC-01 先判赛道**：动笔或诊断前，先给作品标篇幅、媒介、类型、交付四项；所有后续规则只在这个标签内生效。四种赛道：短篇、单线、一次读完；长篇、连载、多线；舞台和戏曲；口头和银幕。跨赛道借用规则时，要重新确认它在新赛道里成立。

**FC-02 从素材到一句胚故事**：写场景之前，把素材压成一句可以检验的话：谁、在什么困境里、做了什么不可逆的选择、读者最后带走什么。情节和情境驱动的短篇、类型小说，已经有一个必须发生的场面或危机；人物驱动的长篇和探索稿，人物能生成后果，终局可以暂时未定；速写和印象式作品，主导的是语调、画面、语言的节奏，不是事件。

**FC-03 单一效果只管短篇**：短篇、独幕、轶事用一个主导效果决定取舍；长篇、多线、速写改用“主行动统一，加上语调和母题的统一”。不要把短篇的单一效果上推到长篇。

**FC-04 结局先行：短篇定终场，长篇定方向**：短篇和单线在起草前定终场的画面和末句的方向，倒推因果；长篇和连载只定终局的状态，允许在章节里发现；发现式写作可以先写，但“结尾要由开头逼出来”是所有长度的验收标准。

**FC-05 人物与情节：先判入口，再双向校验**：不规定人物永远优先或情节永远优先。按素材里先出现的东西选入口（人物、情境、终局、效果），选定后双向校验：情节是否逼人物改变，人物是否促成转折。

**FC-06 一条主脉，次线要交汇**：先写主行动句；每条次线说明它反转或补足了主线的哪一点、在哪里交汇，答不出就删或并。链条式的流浪汉故事和故事集是例外，靠人物或框架统一。

### 单元、开篇与结尾（`references/rules-units-and-endings.md`）

**FC-07 场景、概述、过渡按功能配**：把稿子拆成三种单元：场景（当下的冲突）、概述（压缩信息）、过渡（时间流逝）。关键的对抗写成场景；低价值的场景降为概述；长篇的时间跨度用过渡承接。

**FC-08 单元末三查**：每章、每幕、每折末查三件事：状态有没有变，留下了什么能兑现的问题，是不是被读者提前猜到又拖着。长篇和连载“暂时解决一件，留下一件没解决”；单场的短篇只要一个总收束；戏曲有小收煞和大收煞。

**FC-09 开篇契约**：开头一到三段交代谁要紧、何时何地、什么调子和类型、留下什么问题。晚入场（从冲突中间开始）是印刷短篇的默认，不是所有体裁的法则：说明性的、历史的、传记式的、需要先建世界的作品可以从头写。

**FC-10 结尾先选契约再选型**：闭合型（类型、古典、舞台）、解谜型（侦探、悬疑）、开放型（文学、现代）、仪式型（戏曲的大收煞）。两条通用的验收：结尾要潜伏在开头里；高潮之后只解释还没解开的地方。

### 起草（`references/rules-drafting.md`）

**FC-11 视角：信息合同、距离稳定、切换代价**：视点人物能知道什么、不能知道什么，全篇一致；叙述距离要可辨，变化时重新锚定；每次故意切换都要有触发、收益、标记、代价。起点：短篇一个视点，长篇两三个（这是 Wharton 一家的建议），群像和史诗可以更多。细则转 `character-and-narrative-control`。

**FC-12 先画知识矩阵，再配悬念**：先定读者、人物、作者各自知道什么，再选方式：悬疑（读者知道得比人物少）、反讽（读者知道得比人物多）、惊奇（读者和人物同步获知）。读者已经从标题、简介、类型惯例知道的事，不按“读者不知道”来写。

**FC-13 可信度契约与巧合审计**：先定可信度契约：写实、悲剧、侦探要逼真；传奇、幻想、童话、闹剧可以放弃逼真，但要守内部逻辑；真实事件改编不能以“真事”为由跳过铺垫。巧合可以作前提和起点，不能作危机的解结。

**FC-14 细节少而准，按视角过滤**：具体化不是堆细节。选三到五个能暗示整体的细节（起点值），按视点人物此刻会注意什么过滤，删掉真实但无用的。快节奏的情节驱动作品，一句能成像就够。

**FC-15 文体：清晰得体是底线**：底线是清晰、得体、可以朗读；在此之上按类型调高低，朴素或华丽都可以。不把“短词”“简洁”当成唯一的法则；人物的口语和方言服从人物。

**FC-16 主题从行动里长出来**：主题从人物的选择和后果中长出来；寓言、道德故事、宣传和教育作品可以明示教训，按它们自己的契约验收；讽刺靠反差，不靠说教。

### 修订、工作方式与规则层级（`references/rules-revision-and-method.md`）

**FC-17 修订工序：冷却、单稿、分层改**：完稿后先放一段时间，再按结构 → 场景 → 句子 → 校对分层改；改动留痕、可以回退；不把“改得多”当质量。连载和截稿压力下可以缩短冷却，但不用“没时间”跳过结构检查；只是句子别扭、结构成立时，轻度修订就够。

**FC-18 工作习惯**：固定日课、随手记素材、长篇先搭分段骨架、起草和修改分开。卡壳时改做低负荷的任务（整理素材、补人物卡、改上一章），不硬等灵感。

**FC-19 删减先分类**：删削不是越短越好。先分四类对象，逐类问是否改变主行动、是否唯一承载必要的事实、是否服务语调或人物，再决定删、压、并、留。氛围、速写和文学性强的作品里，细节和语调本身就是效果；但不拿“氛围”当理由保留赘笔。

**FC-20 类型契约**：把类型当作和读者的约定，不是本体上的硬边界。写之前列三到五个必要的特征和承诺，写完逐条验收；市场和审查的约束单独列，不和手艺混在一起判断。

**FC-21 规则要有条件和反例**：每条规则都要说得出它属于哪一层（结构、文体、天赋）、在哪里适用、什么时候失效、反例是什么。遇到大师犯规，登记为例外，不升格为新规则。作者坚持某种写法时，说明代价，由作者决定。

### 成稿自检（CL 测试）

每个测试回答一个问题，只发现问题，不替作者下结论。细则在 `self-check-` 文件里，来源是 Crawford 和 Besant 两书，主要参考 Crawford 和 Besant 两书。

**定位**（`references/self-check-contract.md`）
- **CL-01 读者契约两行**：“本书提供___，不提供___”；“本书以___为完成标准”。第一行具体到谁想要什么、什么挡着、读者在等哪个答案；第二行是修改时的优先级。Crawford 把小说看作闲暇里的“智性的艺术奢侈品”，Besant 把它看作和姐妹艺术并列的艺术；两种看法回答不同的问题，本 skill 不裁决。
- **CL-02 说教检查与反读测试**：标出主语是“我们”“人们”的段落、能划出论点句的段落、删掉后故事不变的段落，逐段问能不能改成人物的选择、代价和后果。反读测试只检查文本是否留有开放的解读，不是合格的必要条件。讽刺、寓言和明说以论辩为方法的作品不适用。
- **CL-14 分清可检查的手艺和不能检查的判断**：观察、描写、取舍、场景、人物的清晰度可以检查；趣味、发明、戏剧感、读者是否被打动不能。不承诺按规则写就能成功，也不用“艺术不可教”拒绝练手艺。

**人物与材料**（`references/self-check-character.md`）
- **CL-03 设定和景物要通过人物出现**：逐段问谁在看、它怎样压迫或帮助人物；答不出就压缩成随动作或对白出现的细节。世界观驱动的奇幻科幻、自然写作，或者设定本身就是对手时，不删，改写成人物要付的代价和要过的障碍。
- **CL-04 经验账本**：细节可核查（这个阶层怎么说话、这个职业怎么办事）、反应可理解。不等于“作者必须亲历”，也不等于“只能写自己的阶层、性别、职业”。发明的细节承担关键因果时，补研究或降为背景。
- **CL-05 人物三场景预测和删名测试**：把主要人物放进三个还没写的场景，预测他说什么、做什么、在哪里犹豫；预测不出，先补人物卡和他的秘密历史。这是练习，不能用模型自编的答案证明人物已经立住。
- **CL-06 事实契约与借材**：纪实、改写、虚构三种契约可以按对象分层；人性和反应必须可信，承担关键因果的物质和制度细节不能错；借材记来源，不整段照搬。要核的断言转 RS 卡。
- **CL-07 人物双审**：一审设定上成立（按体裁，由作者定），二审反应上可理解（所有体裁都要过）。二审不过时，补规则、代价、后果，不补设定说明。

**场景与取舍**（`references/self-check-scenes.md`）
- **CL-08 场面表与“从台下看”**：每章列地点、在场者、目标、转折、章末问题，再写一句读者此刻看见、听见、在等什么。以内心、思辨、抒情为主的小说不必为了“像戏”改成对话。
- **CL-09 无功能才删**：给每段、每场标功能：推进、说明人物、调节、都不是；先删“都不是”。关系、认知、情绪的变化也是推进；氛围本身是目的时不删。
- **CL-10 留下的场景要写完**：有没有具体的感官细节、人物的反应、新问题或新决定，有没有作者替人物总结意义的句子。先决定这一场该不该存在（CL-09）。
- **CL-11 故事与人心双栏**：事件栏记变化、转折、新信息，人心栏记读者在不在意人物会怎样；两栏都弱、且有文本依据时才建议重写。弱情节的作品把“悬念”换成“期待”。

**语言与修订**（`references/self-check-language.md`）
- **CL-12 复述测试**：请试读者复述看到了什么、谁和谁是什么关系、此刻在等什么；关系对、画面不同可以接受。没有试读者时只是自检的假设。
- **CL-13 修订遍数与停止条件**：先结构遍，再句子遍（删修饰、抽象换动作、朗读、删作者表演，都是可选的检查）；修改不再改善意思和节奏时停，记下理由。次数不是质量。

### 事实核验（`references/research-and-verification.md`）

- **RS-01 至 RS-03（证据够不够）**：个例要主张普遍，补样本并写明规模和收集者；全称断言查样本和幸存者偏差；数字的位数不自带可信度。
- **RS-04 至 RS-07（证据指的是不是这件事）**：代理指标只支持它验证过的推论；剪报和汇编的独立性按底层原件算；译本、版次、译法是出处的一部分，题署、著录、考定分层；判断虚构还是记录之前，先定它在成书年代被归入哪一类。
- **RS-08 至 RS-11（归属、首创与时间）**：笔名对应真名本身要证明；原型属实和情节虚构分开；“已有、尚无、首创”固定对象和时间并标核查时点；“首创”之争先分层。
- **RS-12 至 RS-14（谁说的、怎么拿到的）**：趣味、热度、被采用或被退稿都不是真假的证据，也不是免查的理由；相关和机制要和因果分开；记录者的位置决定他能看见什么。

### 读者反馈（`references/reader-feedback.md`）

- **RF-01 至 RF-03（Lewes）**：先分清作品向谁说话；看清、真诚、美是三个提问的方向，不是评分表；销量量的是读者的范围，不能替代受众契约。
- **RF-04 至 RF-06（Overton）**：批评者的断言不等于文本证据；销量的说法要问单位；讽刺的文学立场不是通用的伦理命令。
- **RF-07 至 RF-09（Anderson）**：不同的生活经验不被一个“标准读者”抹平；人物不为取悦读者而扭曲；收入和表达的冲突没有统一的规范，给 A / B 两案由作者裁决。
- **RF-10 至 RF-12（流程）**：反馈的归类顺序；小规模的真实试读；交付与停下的条件。

## 7. 冲突时

- 两个症状互相矛盾（比如“删太多”和“中段塌”）：分别列证据和代价，请作者定优先级，不平均折中。
- 规则之间的冲突（19 条）和各赛道的条件，见 `references/scope-and-conflicts.md`。只有一家来源的参数（四分之三处、中点照面、字数、章数、两三个视角）只作默认值，不作门槛。
- 来源是评论家对作品的反推时，不写成作者的方法。
- Crawford 和 Besant 的分歧（小说是消遣的商品还是艺术、人物必须真实还是可以不可能、内容的尺度）由作者决定。
- 商业上的可读和表达的完整冲突时，给两案和代价，由作者裁决（RF-09）；市场的约束不当作艺术的规则（FC-20）。
- 事实和虚构冲突时，按作者定的事实契约（CL-06）：纪实的部分改正，架空的部分写明偏离点，虚构的设定只校内部一致。

## 8. 交付前自查

- 赛道四项写了吗？暂定的标了吗？
- 每条诊断或建议有文本证据吗？没有的标了“证据缺口”吗？
- “读者会……”标成假设了吗？有没有把没做过的试读写成结果？
- 现实断言给了结论和限定语吗？拿不到原件的，没有说成“已经核实”吧？
- 原稿保留了吗？改动的范围和作者的授权一致吗？
- 写正文时补的假设列出来了吗？
- 有没有把单一来源的参数当成门槛，把类型契约当成硬边界？

## 9. 来源与可信度

- **FC 规则**：是构思、结构、起草和修订的手艺规则，每条写明适用条件、反例和可信度，见 `rules-` 文件；它们是可以检验的假设，不是定律。
- **CL 测试**：只有 Crawford（1893）和 Besant（1884 年讲稿）两书，是十九世纪英国小说观的手艺建议；两书的分歧由作者自主决定。
- **RS 卡**：从四本 1920 年前后的新闻写作手册、文学史和政治论著的做法里归纳，是本 skill 的设计，不是这些书的主张。
- **RF 卡**：来自三本十九世纪到 1925 年的批评论著；RF-10 至 RF-12 的流程是本 skill 的设计。
- 证据薄弱的地方：当代网文和平台、长篇系列的跨书结构、非西方的现代小说、影视和互动叙事、现代的读者研究和销售数据。相关的判断是保守的默认值。
- 这些规则和测试没有在真实的写作任务上验证过，不承诺发表、签约或读者效果。
