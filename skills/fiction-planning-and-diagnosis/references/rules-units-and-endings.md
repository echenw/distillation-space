## FC-07 场景 / 概述 / 过渡：三种单元，按功能配比

- **层级**：结构（场景调度）；对话/描写的剂量另受 FC-14、FC-15 与 K-16 约束。
- **规则**：把稿子拆成“场景（当下冲突）、概述（压缩信息）、过渡（时间流逝）”三种单元；关键对抗必须是场景，低价值场景降为概述，长篇时间跨度用过渡页承接。
- **用在**：全篇都是概述，读者不进戏；全是场景，篇幅爆炸；时间跳跃生硬；中段发闷；该演出来的对峙被一句“他们谈了谈”带过。
- **看什么**：
  - 每段是否有连续的时间/地点/人物动作；
  - 是否存在“该演出来的对峙”被概述；
  - 是否有“只交代后来怎样”的长段；
  - 时间跳跃处是否有锚点（季节、身体、物件）；
  - 连续单元是否只加码、无缓解（K-13：短篇兴趣不减；长篇允许缓解，但须服务更大张力）；
  - 对话是否只在高潮/转折处承担主要功能（书面叙事；舞台另算）。
- **分支**：
  - **A 场景优先**：区分信号 = 冲突当面发生、信息在对抗中交换、人物当场做选择；反信号 = 没有对抗、只是解释、人物在复述已知信息。
  - **B 概述优先**：区分信号 = 信息量大、时间跨度长、次要过程、需要快速交代；反信号 = 把高潮/转折也概述掉、读者被挡在戏外。
  - **C 过渡优先**：区分信号 = 两次高潮之间需要“时间过去”的感觉、需要呼吸；反信号 = 过渡无信息、纯拖延、只是“后来呢”的填空。
  - **A/B 区分**：问“这段是否有人当场想要什么并遇到阻力？”有 → 场景；没有但信息必要 → 概述；只是时间流逝 → 过渡。
- **怎么做**：
  1. 逐段标 `单元类型`：场景 / 概述 / 过渡。
  2. 标 `功能`：推进主行动 / 揭示人物 / 提供必要信息 / 制造时间感 / 纯装饰。
  3. 关键对抗若是概述 → 改写为场景（谁在场、想要什么、谁阻止、代价）。
  4. 场景若是纯信息/纯装饰 → 降为概述或删。
  5. 长篇两次高潮之间补 过渡：写“季节/日常/身体变化”，但必须携带新信息（-1605 “colourless and quiet”）。
  6. 检查配比：短篇/动作场景多、概述少；长篇/跨年过渡多；对话只在高潮/转折处（，书面叙事；舞台 K-16 相反）。
- **交付**：`单元表`（段号/type/function/字数）、`场景转概述记录`、`过渡记录`。
- **反例**：
  1. ** 内部 23 人反对描写、6 人主张全描写**：配比无统一标准。处置：不规定“场景必须占多少”，只按功能与读者进入方式判断；把“比例”当诊断假设，不当硬门。
  2. ** 的 tale/sketch 可以以概述为主**：强行场景化会破坏文体。处置：先按 FC-01 判赛道；tale/sketch 允许概述为主，但仍须“有某事在发生”。
  3. ** 过渡要“colourless and quiet”**：不是无信息；纯拖延的过渡应删。处置：过渡必须携带时间/关系/身体变化中的至少一项新信息。
  4. ** “If I use more than one sentence of description I wince.”**：这是快节奏作者的反信号，不是通则。处置：动作短篇可极简；现实主义/氛围文本不照搬。
- **适用范围**：长篇/连载/多线最需要；短篇只需“关键场景 + 必要概述”；舞台没有“概述”，只有台词/动作/暗场；电影用镜头/剪辑替代；印象主义/速写可弱化场景对抗，但不能没有 tone 的推进。
- **卡住时**：分不清某段是场景还是概述 → 用“是否有人当场想要什么/被什么阻止”判定；仍分不清，标“混合单元”，先不删，留到结构层再看。关键对抗写不成场景（缺对抗力量）→ 回到 FC-05 补情境对抗，不硬写对话。
- **依据**：
  - -3292 描写随叙事逐项发生、不能一次做完
  - -1605 “not fearing to go slowly”；“colourless and quiet”
  - -1205 “It should be reserved for the culminating moments”（作者主张，对白，书面）
  - -11192 日常细节建立可信
  - -5391 “If I use more than one sentence of description I wince.”（作者主张，反信号）
- **冲突**：NONE（“三单元”作为诊断词汇无来源反对；配比冲突归 K-03/K-13/K-16）。
- **可信度**：中（词汇可复用；比例无定量证据）。

## FC-08 单元收束：章 / 幕 / 折末的“暂解 + 未解”

- **层级**：结构（单元边界）。
- **规则**：每个单元末做三查：状态是否改变、留下什么可兑现的问题、是否被读者提前预判又拖延；长篇/连载要“暂解 + 钩子”，短篇只要一个总收束。
- **用在**：章末平淡；读者不追下一章；幕末像断在原点；折末没有“且听下回”；连载每章都在重复“危机—解除—再危机”。
- **看什么**：
  - 单元首末状态是否同一；
  - 末句是否封死或留白墙；
  - 是否给出“cue for curtain”却继续演；
  - 下一单元是否兑现上一单元的承诺；
  - 读者是否早已预判却一直被拖。
- **分支**：
  - **A 章/幕/折/连载**：区分信号 = 分单元交付、读者会中断、需要下次进入的理由；反信号 = 一次读完的短篇、单元只是排版切分。
  - **B 单场短篇/印象主义**：区分信号 = 只有一个总收束、不需要章末钩子；反信号 = 为分章而分章、每段都硬留悬念。
  - **C 舞台/戏曲**：区分信号 = 幕/折有演出停顿、观众会离场/换景；反信号 = 案头阅读本、无演出停顿。
  - **A/B 区分**：问“读者是否真的会在这里停下？”会 → A；不会 → B。网络连载/周更按 A，但钩子必须兑现。
- **怎么做**：
  1. 列 `单元收束`：每章/幕/折的最后一场、最后一句。
  2. 三查：`状态变化`（人物处境/认知是否变）、`未解的问题`（读者带走什么未解）、`延迟检查`（是否已被预判却拖延）。
  3. A：若状态未变，改末事件使状态改变；若没有问题，留一个可见的下一步或明确谜题；若已预判，删拖延或补更强回报。
  4. 长篇/连载：在“小收煞”处“宜紧忌宽”，但不得靠虚假悬念；下一单元必须兑现。
  5. 全书/全剧末：“大收煞”要先解扣再起一次波澜，且不留“包括之痕”。
  6. B：只检查总收束是否完成主导效果，不强行加钩子。
- **交付**：`单元收束表`（unit/state_changed/open_question/delay）、`兑现记录`（承诺→兑现）。
- **反例**：
  1. ** “opening out”**：反高潮/开放结尾可以成立；此时“未解”是设计，不是缺陷。处置：先声明结尾契约（FC-10），再判断“未解”是否被承诺。
  2. **-5462《Wild Duck》省掉“揭穿”必看场面**：改写反响仍成立；说明“幕末必须有大场面”不是硬规则。处置：若省略能产生更强反响，允许省略，但要在下一单元兑现后果。
  3. **-4827 悬念终须兑现**：为钩子而钩子、下一章不兑现，读者感到被骗。处置：每个 `未解的问题` 进 `兑现记录`，标兑现章；不兑现的钩子删。
- **适用范围**：长篇/连载/分幕剧/传奇强；短篇单场弱；戏曲“小收煞/大收煞”是类型专属，迁小说标为推断；印象主义/速写可以无章末钩子，但要有 tone 的收束。
- **卡住时**：章末三查全“否” → 该章可删/并；若作者坚持保留，给它一个“状态改变”或“新信息”，否则标为装饰章。钩子写不出 → 不要用“突然出现一个人/一声枪响”硬造；改问“下一章最想知道什么”，写进 `未解的问题`。
- **依据**：
  - -3283 “An act… ought to consist either of a minor crisis, carried to its temporary solution”
  -  “宜紧忌宽”（作者主张，中文引文，戏曲）
  -  “七情俱备”（作者主张，中文引文，戏曲）
  - -4062 “the quicker you terminate it the better”
  - -2567 “I map everything out in advance.”（作者主张，长篇分节）
  - -1605 过渡页
- **冲突**：有条件（K-06 闭合/开放；K-11 舞台迁移）。
- **可信度**：中（舞台/戏曲证据强，小说章末是类比；缺连载数据）。

## FC-09 开篇契约：首段四职，晚入场不是通则

- **层级**：结构（入口设计）。
- **规则**：开头 1–3 段（通常 2–3 段；操作默认）要交付“谁要紧、何时何地、什么调/什么类型、留下什么问题”；晚入场是印刷短篇的默认，不是所有体裁的法则。
- **用在**：开头软、读者进不去；编辑说“前三段没有故事”；说明性/历史叙事被要求“直接开打”；舞台开场交代生硬；框架故事不知从哪起。
- **看什么**：
  - 首段末读者是否知道时间/地点/主角；
  - 是否知道这是什么类型/什么情绪；
  - 是否有一个可追的问题；
  - 背景信息是否织进动作，而不是成块说明；
  - 第一段删掉后，故事是否仍能懂。
- **分支**：
  - **A 晚入场（短篇/动作/商业）**：区分信号 = 有一个正在发生的场面可切入、前史可在动作中补；反信号 = 读者需要先懂一套规则/历史/族谱，晚入场会变成谜语。
  - **B 从头写（说明性/历史/传记/世界构建）**：区分信号 = 理解门槛高、需要典型场合/典型一天先给秩序；反信号 = 前史只是作者舍不得删、秩序段没有任何张力。
  - **C 舞台开场**：区分信号 = 观众需要人物关系/前情，且可以用动作/对白承载；反信号 = 用对话硬灌说明、人物只为交代而存在。
  - **D 框架故事**：区分信号 = 需要一个“为什么现在讲”的理由、框架本身有压力；反信号 = 框架只是装饰、删掉不影响。
  - **A/B 区分**：问“读者不懂前史，是否就看不懂当下的动作？”不懂 → B；懂 → A。不是按“高级/低级”选。
- **怎么做**：
  1. 写 `首段约定`：四职各一句；缺哪项补哪项。
  2. A：从“第一次不可逆的动作/对话”切入；把前史拆成 1–3 处动作中的信息。
  3. B：从“典型场合/典型一天”开头，先给秩序，再打破；不要为了“晚入场”跳过必要规则。
  4. C：把 exposition 改成人物当下的利益冲突（谁想从谁那里得到什么）。
  5. D：框架要给出“讲述者为什么现在讲”的压力；否则删框架。
  6. 自检：删掉第一段，故事是否仍能懂？若能懂，第一段可能只是装饰；若不能懂，检查是否信息过载。
- **交付**：`开篇约定`（who/where-when/tone-type/question）、`进入点`、`交代记录`（信息→承载动作）。
- **反例**：
  1. ** 要“尽可能晚”，同书  又要“从故事开头写起”**：书级未调和，不能当通则。处置：按 A/B 条件选，引用时标明同书矛盾，不拿单句当普遍律。
  2. **-656《Rip》两层框架、两段静态写景仍成立**：框架/多层叙事可以违反“晚入场”。处置：D 分支先给“为什么讲”的压力，静态写景可留。
  3. ** 舞台开场每个要点说三遍**：因观众迟到/不专注；小说无此强制力。处置：只在 C 分支/现场演出使用；小说不得把“说三遍”当 exposition 规则。
  4. ** 允许 withheld 开头**：但要求足够技巧与回报（-3547）。处置：刻意悬置必须写清“读者被扣住的是什么问题、何时回报”；否则改晚入场。
- **适用范围**：印刷短篇/商业小说取 A；说明性/历史/传记取 B；舞台取 C；框架故事取 D。1900–1920 的“晚入场”是杂志市场习惯，不是跨时代法则；“首段 2–3 段”是历史默认，不是硬门。
- **卡住时**：四职写不全 → 先写“谁+何处+什么不对劲”三句，不写完整开头；若三句也写不出，说明素材还没有人物/处境，回到 FC-02。A 分支找不到“正在发生的动作” → 改 B 的典型场合，或写三个候选入口让作者选。
- **依据**：
  - -1847 “Begin as late in the story as you possibly can.”（混合文本）
  - -369 “begin at the beginning of the story”（混合文本，反例）
  - -2888 “will seldom comprise more than two or three paragraphs”
  - -3521 第一段给时间/地点/主角
  - -879 “unless you have a salamander to show him”
  - -2111 舞台开场三遍法（作者主张，舞台）
- **冲突**：有条件（K-11； 书级 两说）。
- **可信度**：高（“首段四职”跨来源一致）；中（“晚入场”只在短篇/商业语境成立）。

## FC-10 高潮与结尾：四种模式，先选契约再选型

- **层级**：结构（结尾契约）。
- **规则**：结尾不是一种；先按类型契约选模式（闭合/解谜/开放/仪式），再做两条通用验收：结尾须 latent 于开头、高潮后只解释未解点。
- **用在**：结尾收不住；高潮后还在解释；侦探结尾没解谜；文学结尾被要求“给个交代”；戏曲/舞台收场散；开放结尾被读者当成没写完。
- **看什么**：
  - 高潮在哪一场；高潮后还有几段；
  - 未解问题是“需要解释”还是“需要留白”；
  - 开头埋的意象/问题是否回收；
  - 类型读者期待的是“答案/团圆/余味/惊叹”；
  - 删掉最后一段，结尾是否仍成立。
- **分支**：
  - **A 闭合型（类型/古典/舞台）**：区分信号 = 读者要答案/团圆/正义、高潮与结论可同时；反信号 = 开放会显得未完成、类型承诺被违背。
  - **B 解谜型（侦探/悬疑）**：区分信号 = 有一个必须解释的机关、谜面已在前文抛出；反信号 = 解释会杀死余味、机关靠巧合。
  - **C 开放型（文学/现代）**：区分信号 = 结尾要“扩张”而非“收口”、开头已埋 latent image；反信号 = 线头未收是作者失控、开放只是写到哪算哪。
  - **D 仪式型（戏曲/舞台大收煞）**：区分信号 = 需要“七情俱备”的收场、逐人给落点；反信号 = 只靠总结陈词、先解扣后没有新波澜。
  - **A/B/C/D 区分**：先问“读者被承诺的是什么”（答案/机关/余味/仪式），再选型；不以“开放更高级/闭合更成熟”排名。
- **怎么做**：
  1. 写 `结尾约定`：读者被承诺的是答案、团圆、余味还是惊叹。
  2. 标 `高潮场` 与 `高潮后的材料`：只保留“未解点”的解释；其余移入番外/删。
  3. A：高潮与结论尽量同时；若必须收束，限一段。
  4. B：把机关解释放在高潮后，但用动作/对白承载，不用说明书。
  5. C：检查 `潜伏意象` 是否回收；开放不等于任意收笔。
  6. D：先解扣，再起一次波澜，收时逐人给落点，不念总结。
  7. 通用验收：删掉最后一段，结尾是否仍成立？成立则结尾是补的；不成立则检查是否只解释了未解点。
- **交付**：`结尾约定`、`高潮场`、`高潮后的材料`、`潜伏意象`、`结尾检查`。
- **反例**：
  1. ** “Not completion. Not rounding off but opening out.”**：开放结尾成立；但 Forster 也承认“几乎所有小说结尾都弱”。处置：C 分支必须检查 latent image 与线头，不把“开放”当免检。
  2. **《Lady, or the Tiger?》开放是为幽默效果**：作者自己把它标为例外。处置：若用开放，写清“为什么这个类型/效果需要不揭”；否则按 A/B 收。
  3. ** 侦探必须解释**：先抛谜面、倒推机关；不能用“开放”逃避解谜。处置：B 分支的机关必须可回读、可验证；不能靠巧合。
  4. ** 古典戏曲要团圆**：“七情俱备”；现代小说不必。处置：D 分支只用于戏曲/仪式型舞台；不把“团圆”当所有叙事的要求。
- **适用范围**：短篇/独幕/商业类型偏 A/B；侦探必须 B；文学/现代可 C；戏曲/舞台可 D。四者不是进化阶段，不能按时代排名；K-06 作为“哪种更好”的普遍命题 两说。
- **卡住时**：说不清 `结尾约定` → 先问“读者读完最想得到什么：答案、团圆、余味、惊叹？”四选一；仍选不出，标“结尾未定”，不要写结尾。结尾写完但删掉最后一段仍成立 → 结尾是补的；回到 FC-04 检查 `终场/终局状态` 与 latent image。
