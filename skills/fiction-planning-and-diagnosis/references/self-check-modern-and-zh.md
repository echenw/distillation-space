# 中文写作、网文与现代题材的迁移

返回 [SKILL.md](../SKILL.md)。

以下是把通用策划与诊断方法迁移到中文、网文和现代题材时的工作假设，不是平台规则或读者研究结论；按具体作品调整。

## 1. 中文与网文

| 场合 | 用哪项测试 | 怎么用 |
|---|---|---|
| 书名、简介、标签、开篇几章 | CL-01 | 这些就是公开的读者契约。检查开篇是否兑现了简介承诺的东西（身份、金手指、核心冲突、情绪基调）；承诺了“爽”，前几章就要有对应的兑现，承诺了“虐”，就不要先写成轻喜剧 |
| 说教味、“爹味”、借人物之口讲大道理 | CL-02 | 标出主角或长辈的长段道理，问能不能换成一次选择和代价；读者能划出来当“金句”的段落，常常删掉后故事不变 |
| 玄幻、仙侠开篇的世界观介绍，境界、势力、地图一次讲完 | CL-03 | 只留主角此刻会碰到的那一层：他被哪一级境界压着、被哪个势力挡着；其余等人物碰到时再出现 |
| 行业文、职业文（医生、律师、刑警、电竞） | CL-04 | 账本只记承担关键因果的程序和术语，请从业者复核；普通的氛围细节不必逐条考证 |
| 历史文、穿越文、架空王朝 | CL-06 | 先写事实契约：正史、架空、半架空。穿越者带来的现代知识（造纸、火药、制度）属于“物质和制度”清单，承担关键因果的要经得起推敲 |
| 人设立不住、工具人 | CL-05 | 三场景换成本书题材的场景：宗门大比、被冤枉、分资源；删名测试特别适合检查多人对话的群戏 |
| “降智”：人物为了推动剧情做出不合智商和性格的事 | CL-07 | 二审不过。补他这样做的理由和代价，或者改情节，而不是让他突然变笨 |
| 水文、注水 | CL-09 | 标不出三类功能（推进/说明人物/调节）的段落（即“都不是”）先删；日常和感情戏标成“调节”或“说明人物”，有功能就留 |
| “每章都在赶路”“这几章没内容” | CL-11 | 双栏表里两栏都弱的章节，优先重写；章末钩子转 `scene-conflict-and-rhythm` 的 SU-15 |
| 日更定稿 | CL-13 | 至少保留朗读这一遍；句子层的中文细则转 `line-editing-and-proofreading` |

## 2. 其他现代场合

| 场合 | 处理 |
|---|---|
| 二次世界奇幻、科幻 | CL-03 改为“世界通过人物的代价显现”；CL-07 只审反应可理解，不审字面可能 |
| 弱情节、氛围型、文学性强的小说 | CL-09、CL-11 先重新定义“推进”和“悬念”，不机械删离题 |
| 多视角、群像 | 人物清晰度（CL-05）可以照用；视角切换转 `character-and-narrative-control` |
| 跨阶层、跨性别、跨族群的写作 | 不要预设作者必须具备某种身份才能书写某类人物；通过适当研究、访谈和熟悉该群体的读者审读，检查事实与视角 |
| 时代感、年代细节 | 弱化年代细节只是一种美学选择，不是规则；年代质感在很多类型里本身就是乐趣 |
| 青少年、儿童读物 | 儿童与青少年作品的尺度由目标读者、作品承诺和平台要求共同决定，不套用成人小说的默认值 |
| 投稿、出版、平台签约 | 1884 年的出版建议一律不采用；本 skill 不预测市场 |
| AI 辅助写作 | 测试可以用在 AI 生成的初稿上，尤其是 CL-02（说教）、CL-03（设定堆砌）、CL-05（千人一面）；句子层的 AI 腔转 `line-editing-and-proofreading` |
