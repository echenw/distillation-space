# 语言与修订（CL-12、CL-13）

返回 [SKILL.md](../SKILL.md)。

两书只在两点上讨论语言：语言是印刷小说唯一的媒介（Crawford）；风格就是手艺，靠反复修改（Besant）。句法、视角、语域、节奏、对白格式不在两书里，相应的工作转给 `line-editing-and-proofreading` 和 `character-and-narrative-control`。

## 1. 语言是唯一的媒介

Crawford：印刷的书里，作者除了语言没有别的媒介；目标是让读者按自己的立场，把部分或全部想象出来的东西看得像事实一样分明。“手段很多，都服从于语言，目标始终只有一个。”他紧接着说，这里不是研究方法的地方，所以他没有给出语言层的方法。

这不等于“语言技巧不重要”，也不等于“两书没有任何语言评价”：Crawford 劝过要灵巧地处理语法、仔细地选词，也赞赏语言能时而简朴、时而锋利、时而热烈、时而崇高。只是这些都不是可以照做的程序。

## 2. 复述测试（CL-12）

1. 选一段需要读者“看见”的文字：一个场景、一组人物关系、一个空间。
2. 请一两位试读者读完复述：他们看到了什么，谁和谁是什么关系，此刻在等什么。
3. 和作者的构想对照：

| 结果 | 说明 | 处理 |
|---|---|---|
| 复述不出来 | 文字没有形成画面或关系 | 改词、删歧义、补空间和动作 |
| 复述出的人物关系不对 | 结构或人物的问题，不是用词的问题 | 回到 CL-05、CL-08 |
| 画面不同，关系对 | 正常 | 接受；不追求所有读者看见同一个画面 |

没有试读者时：作者隔几天自己复述；或者让模型只根据文字复述，再和作者的构想对照。模型的复述只是代理，不能代替真实读者。

不适用：刻意陌生化、刻意晦涩的文本，“看得分明”不是它的目标；把这类文本改透明，读者看懂了，声音却没了。

## 3. 修订轮次（CL-13）

Besant 的“风格”不是风格类型，是手艺的标准：每一场写完、不草率、反复重写；没有哪种风格粗糙到用心下功夫也美不起来。他也警告，风格压过情境就会显得做作，带上时下的腔调和怪癖。

| 轮 | 目标 | 做法 | 什么时候算完 |
|---|---|---|---|
| 0 结构 | 场景、人物、因果 | 先做 CL-08 至 CL-11，不在句子上花功夫 | 该删的场景删完，人物的目标清楚 |
| 1 删修饰 | 去掉堆叠的形容词、副词 | 删掉不影响意思的；把“非常”“极其”“十分”删掉试读 | 删了意思不变，就保持删除 |
| 2 抽象换动作 | “他很焦虑”变成看得见的东西 | 抽象的词换成动作、物件、身体反应 | 读者能看见，而不是被告知 |
| 3 朗读 | 找重复句式、卡顿 | 出声读；标出喘不过气、绕口、重复的句子 | 读起来顺，意思不变 |
| 4 删作者表演 | 炫学、警句、插科打诨 | 问：这句服务人物和情境，还是服务作者？ | 删掉或压低以后，场景更清楚 |
| 5 停 | 不再改善 | 修改不再改善意思和节奏时停 | 记下停的理由 |

- 记录每章重写了几遍，但次数不是质量。Besant 问一位年轻作者某页重写了几遍，她说一气写成、从没回头读过；他要说的是“没有回读”是问题，不是“次数越多越好”。
- 过度打磨会磨掉生命和声音。
- 不要把“不许有一句草率的话”变成“每句都要华丽”：要的是不草率，不是装饰。

不适用：口述体、即兴写作、刻意粗粝或口语化的风格。日更连载可以降低强度，但不要放弃回读。

中文句子层的细则（句式、用词、的地得、标点、对白格式、AI 腔套话），在完成第 0 轮以后转 `line-editing-and-proofreading`。

## 4. 方言和外语：读者成本，不是禁令

Crawford 承认每个作者都有权使用手里的材料；他批评的是方言占了一半以上篇幅的极端用法，不是全面禁用。他说方言近于双关、难以翻译、口头讲述时更沉闷，这是 1893 年标准英语书市的判断。

本 skill 只保留两个问题：
- 这段方言、术语或外语的理解成本有多高？它服务人物或情节吗？
- 默认读者是谁？设限的是平台、市场，还是作者自己？

方言写作可以成为一部作品的主要美学，地域写作和类型写作甚至可能以方言为卖点。不要把“方言必然缩小读者”写成禁令，也不要把方言的篇幅当成质量指标。
