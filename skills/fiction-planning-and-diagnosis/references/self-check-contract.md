# 契约、道德立场与可教性（CL-01、CL-02、CL-14）

返回 [SKILL.md](../SKILL.md)。本文件帮助作者明确读者承诺、作品完成标准和可执行的修订边界；不替作者决定商业目标或审美优先级。

## 1. 读者体验与艺术完成标准（CL-01）

| 问题 | 读者体验视角 | 艺术完成视角 |
|---|---|---|
| 作品提供什么 | 读者实际会得到的冲突、情绪、趣味、知识或体验 | 作品在人物、场景、语言、形式和结构上如何完成 |
| 首要检查 | 读者是否知道自己在读什么，开篇是否兑现承诺 | 形式、声音和结构是否服务作品目标 |
| 失败信号 | 宣传承诺与正文不符；读者期待的核心问题没有回应 | 作品以“艺术”为由拒绝检查结构、表达或完成度 |
| 不能推出 | 读者偏好可以替代艺术判断 | 艺术目标可以成为不清晰或不完整的借口 |

两种视角回答不同问题，不必合并成一个口号。作者可以让作品同时承担娱乐、审美、思考和情感目标；若目标冲突，明确优先级和代价。

**作者决定程序：**

1. 分别写下读者实际会得到什么，以及作品以什么标准完成。
2. 标明哪些是明确承诺，哪些只是作者希望达到的效果。
3. 若选择强读者承诺，仍检查人物、场景和语言质量；若选择形式实验或艺术探索，仍检查读者能否理解其规则。
4. 暂时无法决定时，把两种标准并列记录，先完成不受该决定影响的检查。

## 2. 两行读者契约（CL-01）

用两行话把读者承诺和修改优先级写清楚：

- 读者契约：作品提供什么具体冲突、体验或乐趣；明确不提供哪些内容。
- 完成标准：作品以人物、场景、语言、结构或形式中的哪一项为主要完成标准。

第一行不是题材标签，而是读者实际会得到的东西：谁想要什么、什么挡着、读者在等哪个答案。第二行不是艺术宣言，而是修改时的优先级：人物和事件冲突、语言和场景冲突时，哪一项先让步。

**例：**作品提供一个女人回到海边小镇、决定是否出售母亲旧房子的家庭冲突，不提供一篇没有决定的风景游记；以人物选择和场景压力为主，不以景物描写数量为标准。

**不适用：**纯游戏、纯形式实验或以体验过程为主的作品，契约可以就是“玩”或“探索”。不要用契约逼作者添加情节或道德结论。

### 2.1 定位卡（开稿前定位的交付格式）

开稿前定位做完，交付一张定位卡，五项各占一行：

| 字段 | 填什么 | 细则位置 |
|---|---|---|
| 读者契约两行 | 作品提供___，不提供___；完成标准以___为准 | 本文件 §2 |
| 道德立场 | 道德意义靠人物的选择和后果呈现，还是要讲出一个论点 | 本文件 §3 |
| 事实契约 | 纪实、改写或虚构，可以按对象分层 | `self-check-character.md` §4.1 |
| 主要人物的三场景预测 | 每个主要人物在三个未写场景里的预测是否成立 | `self-check-character.md` §3.1 |
| 待作者决定的事项 | 暂时不选的分歧、拿不准的契约，逐条列出 | 本文件 §1 的作者决定程序 |

- 预测不出的人物：先写人物卡和秘密历史再写正文，定位卡上如实标“未知”或“待作者决定”，不把未知写成已完成。
- 作者坚持“设定就是主角”时，在「事实契约」一行写明这是另一种契约，再继续其余测试。
- 定位卡是开稿前的约定，不是验收单；改稿自检按契约两行逐章回看（整稿自检的顺序见 `self-check-diagnosis.md` §1）。

## 3. 说教、道德氛围与明确论辩（CL-02）

| 层 | 是什么 | 处理 |
|---|---|---|
| 说教或论文式表达 | 叙述者直接训诫；人物只负责复述论点；结尾另加结论 | 尝试改成人物选择、代价和后果；若不能服务作品目标，考虑删去 |
| 道德氛围 | 人物的选择、代价、后果，以及对他人处境的回应 | 保留并通过场景和人物反应呈现，不必靠旁白解释 |
| 明确论辩或教育承诺 | 作品从一开始就承诺论证、劝说、寓言或教育 | 可以明示主题，但仍要让行动、例子和结论之间保持一致 |

### 3.1 说教诊断表

| 段落 | 它断言什么 | 主语是谁 | 能否变成选择加代价 | 处理 |
|---|---|---|---|---|
| 某段旁白 | 读书才能改变命运 | “我们这一代人” | 能：人物必须在继续工作与接受学习机会之间作出选择 | 改写为场景 |

### 3.2 反读测试

文本是否允许一个与作者结论不同、但在人物处境和事实条件下仍合理的解读？如果完全不允许，检查作品是否正在论证而不是叙事。这个测试不是硬门：寓言、宣传、教育和明确论辩可以限制解释空间，但要让这种限制属于读者契约。

### 3.3 适用边界与反方向错误

- 讽刺、寓言、明说以论辩为方法的作品，契约本身可以包括论辩。
- 作者明确要写劝世文或教育作品时，先说明目标和代价，不要擅自改写成隐晦小说。
- 反方向错误：把人物所有道德困境都删成“没有立场”，读者会不知道为什么要在意；有道德立场不自动等于说教。

## 4. 可教与不可保证的部分（CL-14）

| 可以检查、可以练习 | 不能靠规则保证 |
|---|---|
| 观察、描写、取舍的过滤、场景、人物清晰度、反向提纲、重写 | 趣味、发明、戏剧感、读者是否被打动、最终取舍是否选对 |

- 不承诺“按规则写就能成功或畅销”。
- 不用“艺术不可教”拒绝练习手艺，也不把天赋当作进入创作的门槛。
- 结构和语言可以提供判据与练习；审美判断需要作者在具体作品中承担选择。

### 4.1 被退稿或成绩不佳时

1. 把问题分成手艺项和市场/渠道项。
2. 手艺项逐项给出当前文本中的位置、观察结果和可执行改法。
3. 市场项只说明现有信息能否支持判断；没有数据时不预测销量，也不把一次拒稿当作艺术质量的证明。
4. 修改后重新检查当前版本，不继承旧版本的通过结果。

出版、合同、税务、会计和法律问题转交相应专业流程；本 Skill 不提供此类专业意见。
