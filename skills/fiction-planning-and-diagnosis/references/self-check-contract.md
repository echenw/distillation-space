# 契约、道德立场与可教性（CL-01、CL-02、CL-14）

## 1. 两种小说观（CL-01）

| 问题 | Crawford（1893） | Besant（1884） |
|---|---|---|
| 小说是什么 | 可以出售的商品，属于“智性的艺术奢侈品”：诉诸智识，满足艺术的要求，只在闲暇时娱人 | 和绘画、雕塑、音乐、诗并列的艺术，是它们的“姐妹和同侪” |
| 首要目的 | 让读者觉得有趣、被吸引；小说家是“公共娱乐者” | 艺术上的完成；受普遍的法则支配 |
| 失败怎么看 | 违背了和读者的契约，不吸引人 | 市场上的失败不等于艺术上的失败 |

两栏都不是纯粹的立场：Crawford 也要求小说满足艺术的要求、有伦理的基础；Besant 也承认小说在大众眼里地位低，没有学院也没有奖项。

**为什么不合并成“既是商品又是艺术”**：两栏回答的是不同的问题（读者买什么；小说在艺术里处于什么位置），合并以后会同时丢掉两边的约束：有人用“商品”为低完成度辩护，有人用“艺术”为没人能读辩护。

**作者决定的程序**：
1. 两栏各写一句，不加褒贬。
2. 问作者：这本书的读者契约属于哪一栏？完成标准属于哪一栏？
3. 选“消遣”：仍要问完成度，不能拿商品当低完成度的借口。
4. 选“艺术”：仍要问读者，不能拿艺术当没人读得下去的借口。
5. 作者暂时不选：两栏并列写进定位卡，标“待作者决定”，先做其余测试。

## 2. 读者契约两行（CL-01）

Crawford 说，作者和读者之间有一份默认存在的不成文契约：一本书以小说的名义出售，读者买的是小说，不是一堂智性的道德课。

```
读者契约：本书提供___（具体的人类冲突或乐趣），不提供___（论文、说教、社会方案）。
完成标准：本书以___（人物、场景、语言、结构）为完成标准。
```

- 第一行不是类型标签，是读者实际会得到的东西：谁想要什么、什么挡着、读者在等哪个答案。
- 第二行不是艺术宣言，是修改时的优先级：人物和事件冲突、语言和场景冲突时，谁让步。
- 每章回看：这一章兑现了契约的哪一部分？删掉人物以后论证仍然成立，说明写成了论文。

例：

```
读者契约：本书提供一个女人回到海边小镇、决定卖不卖母亲老房子的家庭冲突，不提供一篇没有决定的海边游记。
完成标准：以人物的选择和场景的压力为完成标准，不以景物描写的多少为标准。
```

不适用：纯游戏、纯形式实验，契约可以就是“玩”。不要用契约逼作者加情节或加道德。

## 3. 说教的三层（CL-02）

两书都反对说教，但说法不同：
- Crawford：把小说变成智性的道德课，违背了契约，在通常情况下就是一种欺骗；“在一切艺术里，道德教训都是错误”。但他允许小说培养趣味、净化心灵、让读者思考。
- Besant：现代英国小说几乎总是从自觉的道德目的出发，这几乎成了英国小说的法则；但“说教小说是最不可取的”。他说的“法则”指作品弥漫着的道德意味，不是“每本书都要写一个论题”。

| 层 | 是什么 | 处理 |
|---|---|---|
| 说教、论文、替政策代言 | 叙述者直接训诫；议题论证；人物变成论点的例子 | 改成人物的选择、代价、后果；改不了就删 |
| 道德氛围 | 人物的选择、代价、后果；对他人处境的同情 | 保留并鼓励；通过场景和人物反应呈现，不靠旁白 |
| “小说必须有自觉的道德目的” | Besant 对 1884 年英国小说的描述加认可 | 不作为规则 |

### 3.1 说教诊断表

| 段落 | 它断言什么 | 主语是谁 | 能否变成选择加代价 | 处理 |
|---|---|---|---|---|
| 第 3 章第 2 段 | 读书才能改变命运 | “我们这一代人” | 能：让她把录取通知书藏起来，第二天去厂里报到 | 改写 |

### 3.2 反读测试

文本允许一个和作者结论相反的合理解读吗？完全不允许，它可能仍是一篇论文。这个测试是本 skill 加的。

注意 Crawford 自己在书里也会滑进说教，并且承认“我自己也正在犯其中一个错误”：反说教本身也可能变成一种表演。

### 3.3 不适用和反方向的错误

- 讽刺、寓言、明说以论辩为方法的作品，契约本身就包括论辩。
- 作者明确要写劝世文：说明代价，由作者决定，不悄悄改写。
- 反方向：把人物所有的道德困境都删成“没有立场”，读者会不知道为什么要在意。也不要把 Crawford 的话读成“小说不得有任何道德意义”。

## 4. 可教与不可教（CL-14）

Besant 的话前后有张力：他一面说小说的法则可以像和声、透视、比例的法则一样精确地传授；一面说“规则造不出小说家”，艺术本身既不能教也不能传，选择的本领也教不会。他并没有交付一条精确的法则。Crawford 更谦虚：他说自己的回答只能是意见，但承认这门艺术的诀窍数不胜数，有的容易学，有的难以模仿。

| 可以检查、可以练 | 不能检查 |
|---|---|
| 观察、描写、取舍的过滤、场景、人物清晰度、反向提纲、重写 | 趣味、发明、戏剧感、读者是否被打动、取舍是否选对 |

- 不承诺“按规则写就能成功、能畅销”。
- 不用“艺术不可教”拒绝练手艺，也不把天赋当门槛。

### 4.1 被退稿、成绩差时

1. 把问题分成手艺项和市场项。
2. 手艺项逐项给测试结果、证据位置、改法。
3. 市场项只说明本 skill 不能判断；Besant 自己的说法是市场失败不等于艺术失败。他关于投稿的具体建议（好稿必被接受、被六家拒绝就放弃、绝不自费）属于 1884 年的出版条件，不采用。
