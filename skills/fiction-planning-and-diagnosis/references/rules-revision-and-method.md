读法：
- 每条规则包含：层级、规则、适用场景、观察信号、分支与反信号、操作步骤、交付、反例、适用范围、卡住时的处理和验证边界。不要把一条规则压成一句口号。
- 规则是诊断与练习工具，不是成功保证；真实写作效果和读者反应仍需在具体作品中验证。
- 范围：28 本材料标称 1808–1929 年，主体是 1888–1928 年英美印刷市场的小说作法、短篇工艺、舞台和戏曲，加上古典文论；非西方的现代小说、当代的类型工业、网络长篇和系列、影视和互动叙事、读者实验都没有覆盖。越出这个范围的，标为推断或未证实。
- 规则的效果尚未通过真实写作任务或受控读者测试验证；把它们作为可检验的工作假设，不当作效果保证。

## FC-17 修订工序：冷却、单稿、分层改

- **层级**：流程（生产工序）+ 结构/文体（分层对象）。
- **规则**：完稿后先冷却，再按“结构→场景→句子→校对”分层改；用单稿留痕，改动可回退，不把“改得多”当质量指标。
- **用在**：初稿写完不知从哪改；越改越乱；改到失去判断；誊清后找不到原句；一上来就改句子，结构问题没动。
- **看什么**：
  - 距完稿多久（是否冷却）；
  - 能否说出每场功能；
  - 改稿是否从结构开始；
  - 是否有可回退的原句；
  - 改动是否只动描写/对白，不动结构。
- **分支**：
  - **A 重度修订（长篇/结构问题）**：区分信号 = 场景功能不清、因果断、主线不成立；反信号 = 只是句子别扭、结构其实成立。
  - **B 轻度修订（短篇/文体问题）**：区分信号 = 结构成立、句子/节奏/细节问题；反信号 = 改句掩盖结构缺陷、越改越花。
  - **C 连载/截稿**：区分信号 = 时间受限、必须按期刊/平台节奏交付；反信号 = 用“没时间”跳过结构检查。
  - **A/B 区分**：先做“每场功能一句话”测试；说不出 → A；说得出但句子差 → B。顺序不能倒。
- **怎么做**：
  1. 冷却：完稿后放置数日到数周，不读。
  2. 以“陌生人稿”视角通读，标出“读者会不懂/不信/不想读”处。
  3. 结构层：逐场写功能；删/并/补；检查因果链与结尾 latent。
  4. 场景层：视角合同、细节剂量、对白是否只在高潮/转折。
  5. 句层：朗读、删套语、改主动词、一句一强调。
  6. 校对：错字、事实、格式。
  7. 单稿留痕：改动写在同一份稿上，保留原句以便回退。
- **交付**：`修订记录`（层级/段落/原句/改句/理由）、`冷读记录`、`回退点`。
- **反例**：
  1. **-3143 修订 0 到 20+ 次并存**：修订次数不是质量指标；处置：不把“改得多”当敬业，也不把“零改稿”当天才；按结构需要决定。
  2. **创作速度与质量无稳定对应关系**：处置：不把“慢工”当必然保证，也不把“快写”当必然草率；按完成度与结构检查判断。
  3. **“自然会妙”**：对某些文本，过度修改会磨掉生气；处置：句层改动设“回退点”，改后朗读；若失去语气，回退。
  4. **连载/截稿**：工序可压缩，但不能用“没时间”跳过结构检查；处置：C 分支至少做“每场功能 + 结尾 latent”两项，句层可后补。
- **适用范围**：职业书面写作/长篇/连载强；短篇可缩短冷却；口头/即兴/截稿新闻弱；“修订提升质量”本身 未证实；没有对照实验。
- **卡住时**：说不出每场功能 → 不要进入句层；先做结构层（FC-06/07/08）。改到失去判断 → 停止，冷却/换读者/换顺序；不要用“再改一版”解决判断疲劳。没有可回退原句 → 先建版本副本，再动稿。
- **冲突处理**：按 [scope-and-conflicts.md](scope-and-conflicts.md) §2 条件分流；未定时保留选项与代价。

## FC-18 工作习惯：日课、素材簿、分段骨架、卡壳处理

- **层级**：流程（生产策略）；不是艺术价值判断。
- **规则**：把写作当可管理的工作：固定日课、随手记素材、长篇先分段骨架、起草与修改分离；卡壳时改做低负荷任务，不硬等灵感。
- **用在**：等灵感；三天打鱼两天晒网；长篇写到中段迷路；卡壳后放弃；初稿和修改混在一起，越写越慢。
- **看什么**：
  - 是否有固定写作时段/字数；
  - 是否有素材簿/闪念记录；
  - 长篇是否有分段骨架；
  - 卡壳时是否有替代任务；
  - 起草与修改是否混在一起。
- **分支**：
  - **A 职业/长篇/连载**：区分信号 = 固定交付、结构复杂、需要持续产出；反信号 = 偶发短篇、一次成型、没有交付压力。
  - **B 偶发/短篇/口述**：区分信号 = 事件驱动、一次成型、口述/即兴；反信号 = 长期项目、复杂结构、需要跨月管理。
  - **C 卡壳**：区分信号 = 失去方向/人物不真/结构未定；反信号 = 只是懒/疲劳/外部打断。
  - **A/B 区分**：问“这个项目是否需要跨月管理？”需要 → A；不需要 → B。不是按“专业/业余”分。
- **怎么做**：
  1. 设 `日课量`（时间或字数），低到能持续；“whether you are in the mood or not”。
  2. 建 `素材簿`：情节/人物/描写/对白分栏；闪念即时记。
  3. 长篇：先 `分段图`（8–9 段为历史默认，非硬门；逐段人物/动作/场景），允许写作中长大或缩小。
  4. 起草与修改分离：初稿只前进，不回改；修改另开时段。
  5. 卡壳：改做低负荷任务（场景卡、素材整理、读同类作品）；或换环境（换地恢复，属推断）。
  6. 每周复盘：完成量、卡点、下周一段目标；不把“写得多”当质量。
- **交付**：`日课量`、`素材簿索引`、`分段图`、`卡壳记录`（卡点/替代任务/恢复方式）。
- **反例**：
  1. **边写边发现的弹性**：刚性骨架不是起笔必需；处置：B 分支允许无骨架起步，但长篇卡壳时要补 `分段图` 或至少“下一段目标”。
  2. **休息与持续写作**：写不动时可以休息，也可以改做低负荷任务；按作者状态、交付期限和项目节奏选择，不把固定日课当道德要求，也不把停笔当万能方法。
  3. **-3143 零修订/一次成型**：日课/骨架不是唯一正当工作法；处置：不把“每天写”当质量证明；允许一次成型，但要另做结构检查。
  4. **有作者靠口述写作**：工具与流程不同；处置：口述作者用录音/转写/口头场景卡，不照搬纸面日课。
- **适用范围**：职业书面写作/长篇/连载强；短篇/偶发/口述弱；“日课”是生产策略，不是艺术价值判断；没有当代写作行为数据，完成率效果 未证实。
- **卡住时**：设不出 `日课量` → 改设“本周三次、每次 30 分钟”的最小承诺；仍做不到，先不设产量目标，只做素材/场景卡。卡壳且低负荷任务无效 → 回到 FC-05/06 检查人物/主线，不要用“硬写”掩盖结构问题。
- **冲突处理**：按 [scope-and-conflicts.md](scope-and-conflicts.md) §2 的 K-07、K-12 条件分流；未定时保留选项与代价。

## FC-19 删减诊断：先分类删除对象，再决定删/压/并/留

- **层级**：结构和文体（删减对象跨层）。
- **规则**：删削不是“越短越好”；先分四类对象（事件/场景、句子/词、解释/点题、人物/支线），逐类问“是否改变主行动、是否唯一承载必要事实、是否服务语调/人物”，再删/压/并/留。
- **用在**：稿子太长；编辑要求删 20%；删了之后情节断裂；保留了大量“真实但无用”的细节；连载越写越长，支线收不回。
- **看什么**：
  - 删除对象属于哪一类；
  - 删掉后主行动是否改变；
  - 该信息是否有第二个载体；
  - 该细节是否服务语调/人物；
  - 删除后读者是否还能重建。
- **分支**：
  - **A 情节驱动**：区分信号 = 主行动/因果链优先、每个事件都要改变条件；反信号 = 删掉的是唯一因、删后因果断裂。
  - **B 氛围/素描/文学**：区分信号 = 细节/语调本身是效果、删描写即毁；反信号 = 以“氛围”保留赘笔、细节不同调。
  - **C 商业短篇**：区分信号 = 篇幅经济、读者要快速进入；反信号 = 删到人物扁平、删到类型承诺失效。
  - **A/B/C 区分**：先按 FC-01 判赛道；再用“删掉后主行动/语调/人物哪个受损”判断。三者不能同时最大化。
- **怎么做**：
  1. 列 `待删候选`：每条标类型（事件/句子/解释/人物）。
  2. 逐条三问：改变主行动？唯一承载必要事实？服务语调/人物？
  3. A：改变主行动者留；唯一因者留；其余删/压。
  4. B：服务语调者留，但检查是否同调；不同调者删。
  5. C：先删解释/重复，再压次要场景，最后才动人物。
  6. “必要但无趣”者只压缩不删（-1328）。
  7. 删后复读：主行动是否仍清楚、人物是否仍可信、语调是否仍统一。
- **交付**：`删减表`（对象/类型/三问/处置）、`压缩记录`。
- **反例**：
  1. **要求 “typical, to be inclusive”**：不能因体面/篇幅删掉生活面向；处置：B 分支保留“生活面向”的细节，但按语调同调筛选；不把“短”当唯一目标。
  2. **素描的魅力在 atmosphere**：删描写即毁；处置：B 分支先保 tone，再压重复；不按情节驱动标准删素描。
  3. **真实但无用的细节要求删去**：与“保留真实”冲突，按类型裁决；处置：A/C 分支删真实但无用；B 分支看它是否服务 tone。
  4. **对“必要但无趣”只压缩；“善删者字去而意留”**：不是越短越好；处置：必要信息保留，压缩表达；删后意缺则回退。
- **适用范围**：短篇/商业/舞台强；长篇/文学/素描弱；删除对象随体裁变（事件/句子/解释/人物）；连载还要考虑已发布承诺，不能回改已出版章节。
- **卡住时**：三问答不清 → 先不删，标“承重待定”；用“抽掉这一段，复述主行动”测试。删后主行动断裂 → 回退，改为压缩/合并；不要用“补一句解释”掩盖删错。作者拒绝删 → 给“删/压/并/留”四方案及代价，让作者选。
- **冲突处理**：按 [scope-and-conflicts.md](scope-and-conflicts.md) §2 的 K-01、K-03 条件分流；未定时保留选项与代价。

## FC-20 类型契约：必要特征 + 读者承诺 + 市场约束分层

- **层级**：结构（读者契约/市场层）；不是本体论。
- **规则**：把类型当“读者契约 + 教学检索”，不是本体论硬边界；写前列 3–5 个必要特征与承诺，写后逐条验收；市场/审查约束单独列，不与技艺混判。
- **用在**：投稿被退“不符合类型”；类型读者失望；想跨类型但不知代价；把市场禁忌当艺术规则；类型混合不知按哪类验收。
- **看什么**：
  - 读者买这个类型时期待什么（答案/团圆/恐怖/知识/代入）；
  - 作品是否兑现 3–5 个必要特征；
  - 偏离是否有补偿；
  - 退稿理由指向技艺还是市场/审查；
  - 类型混合时，主导处理是哪一类。
- **分支**：
  - **A 商业/类型投稿**：区分信号 = 明确类型契约、读者预期强、平台/刊物有惯例；反信号 = 作者只想借类型外壳、必要特征缺失且无补偿。
  - **B 文学/跨类型**：区分信号 = 有意偏离并给出补偿（更强的效果/人物/主题）、目标读者清楚；反信号 = 用“文学”掩盖没写好、偏离没有代价说明。
  - **C 市场/审查约束**：区分信号 = 退稿理由指向广告/发行/审查/字数/禁忌；反信号 = 真是技艺缺陷，却怪市场。
  - **A/B/C 区分**：先判“退稿/失望的原因是特征缺失、偏离无补偿，还是市场约束”；三者分栏，不混成“写得不好”。
- **怎么做**：
  1. 写 `类型约定`：3–5 个必要特征 + 读者承诺 + 可偏离项。
  2. 标 `市场约束`：字数、结局、禁忌、审查；与技艺问题分栏。
  3. 逐条验收：必要特征是否兑现；偏离项是否有补偿（更强的效果/人物/主题）。
  4. A：不兑现必要特征就改；B：保留偏离，但写清代价与目标读者。
  5. 退稿分析：先判“技艺/市场/审查”；市场问题不改技艺，技艺问题不怪市场。
  6. 类型混合：按“主导处理”判类（编者判词），不按局部元素。
- **交付**：`类型约定`、`市场约束`、`偏离记录`（偏离/补偿/代价）、`退稿诊断`。
- **反例**：
  1. **“clumsy separations”**：小说理论 认为 novel/romance 二分对创作者无意义；处置：类型作契约工具，不作本体论；跨类型按主导处理验收。
  2. **“not possible to make a hard and fast definition”**：类型无硬定义；处置：必要特征列 3–5 个即可，不追求穷尽；类型混合允许重叠。
  3. **反“快乐结局”，但承认市场压力并自我怀疑**：两种说法都无统计；处置：快乐结局按 K-17 两说处理，先声明目标市场，不写成“读者都要”。
  4. **五条否定律**：这是 1920 年代美国杂志市场，不是普遍道德；处置：只作历史市场约束，不作当代创作法则。
- **适用范围**：1911/1900 印刷市场类型学；现代跨类型、网络长篇、影视类型需另立契约；类型作为教学/市场工具有效，作为本体论无效；3–5 个特征是操作默认，不是类型定义。
- **卡住时**：写不出 3 个必要特征 → 先写“读者买这个类型时最想得到什么”一句，再反推 3 个特征；仍写不出，标“类型未定”，不要用类型规则验收。退稿原因说不清 → 分“技艺/市场/审查”三栏，逐条找证据；没有证据的栏标“未知”。
- **冲突处理**：按 [scope-and-conflicts.md](scope-and-conflicts.md) §2 的 K-10、K-17 条件分流；未定时保留选项与代价。

## FC-21 规则层级：判据、条件、反例，不输出无条件步骤

- **层级**：元规则（元规则；约束本文件与其他流程的写法）。
- **规则**：每条规则必须标层级（结构/文体/天赋）、适用域、失效条件、≥2 反例、可观察信号；遇到大师犯规，登记为例外，不升格为新规则。
- **用在**：写 Skill/教程/诊断清单；两人各引一条规则互相否定；新手问“到底听谁的”；看到大师犯规就想改规则。
- **看什么**：
  - 规则属于结构层还是文体/天赋层；
  - 是否有明确适用域；
  - 是否能说出至少两个反例；
  - 是否把“某大师这样做”当成“所有人都应这样做”；
  - 是否把“反规则”变成新教条。
- **分支**：
  - **A 结构层**：区分信号 = 可拆解、可检查（因果、场景、视角、结尾）；反信号 = 只有品味判断、无法指出文本证据。
  - **B 文体层**：区分信号 = 可诊断、难立法（清晰/节奏/语域）；反信号 = 用“风格”掩盖结构问题。
  - **C 天赋/判断层**：区分信号 = 不可教、只能练（音感、眼光、幽默）；反信号 = 把不可教当不作为的借口。
  - **A/B/C 区分**：问“这条规则能否用文本证据检查？”能 → A/B；不能 → C。C 层不写成步骤，只写训练/阅读建议。
- **怎么做**：
  1. 给规则打 `层`（结构/文体/才能）。
  2. 写 `范围`（篇幅/媒介/类型/时代）与 `失败条件`（≥2）。
  3. 写 `可观察的信号`（读者/编辑能看到什么）。
  4. 写 `反例`（至少两个真实反例）。
  5. 遇到大师犯规：记入 `例外记录`，注明“有意/无意、代价、是否可学”；不改规则。
  6. 两条规则冲突：按 FC-01 赛道分流；不能平均，也不能“辩证统一”。
- **交付**：`规则卡`（layer/scope/signals/branches/failures/counterexamples/confidence）、`例外记录`。
- **反例**：
  1. **大师可有意犯规、新手须全守**：“大师豁免”不能变成“人人可犯规”；处置：例外登记，不升格为规则；新手仍按结构层检查。
  2. **“no one rule applies to all writers alike.”**：任何“唯一正确方法”都被同一编者的问卷否定；处置：每条规则带条件/反例，不写“必须”。
  3. **“the gist of the matter always escapes.”**：规则只能逼近，不能穷尽；处置：给判据与检查，不承诺“照做就成”。
  4. **反公式却输出 18 条主张**：反规则也会变成规则；处置：把“反公式”本身也标为条件性立场，不写成新教条。
- **适用范围**：教学/诊断/编辑场景适用；大师创作/实验作品不适用；结构层比文体层更可教；跨时代须重标；本 Skill 不评价“艺术价值”，只做可观察诊断。
- **卡住时**：一条规则说不出两个反例 → 降为“假设”，不进入 FC 的正式规则；若已写入，标“证据不足”并移入待验证清单。两条规则冲突且无法按赛道分流 → 保留争议，给安全出口，不强行统一。
- **冲突处理**：按 [scope-and-conflicts.md](scope-and-conflicts.md) §2 条件分流；未定时保留选项与代价。
