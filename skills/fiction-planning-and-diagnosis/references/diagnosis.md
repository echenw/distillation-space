# 诊断工作流：从症状到可观察证据

> 适用：已有成稿/片段/梗概，要定位问题、给严重度、给最小验证与修改方向。
> 不适用：无稿要求“看出问题”（给检查清单和取样要求，不编造文本问题）、逐句校对（转校对）、直接改稿（转 `references/revision.md`）、非虚构/剧本格式。
> 规则细节见 FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；本文件只给“症状 → 证据 → 规则 → 分支 → 最小验证 → 严重度”。

---

## 0. 诊断前置（缺一不可）

1. **有文本，且取样范围与结论匹配：** 做整稿结构诊断时，至少取开篇、中段、结尾各一段，并取一处视角切换或关键转折；未完结的连载还没有“结尾”可取时，取已发布部分最近一次状态改变处替代，并把“结尾未写”写入 DR-12 的证据缺口，不以“完整结构诊断”名义交付。做片段/单场诊断时，只检查用户提供的范围，不把局部现象外推为全书问题。只有梗概 → 只做规划层诊断（主行动/线/终点/类型），不做句段诊断。
2. **有版本**：记录稿本标识/日期/字数；同一诊断只针对一个版本。
3. **有范围**：全书/前 10 章/某一场；不写“整本都有问题”而不给范围。
4. **有证据**：每条判断至少一处位置 + 短引文；结构性缺失（如“没有主行动”）可用“抽线/复述失败”作证据，但要说明方法。片段输入下发现疑似全书级的症状时，测试只在所给范围内执行，结论写“在所给范围内成立/不成立 + 方法”，全书级判断标“未覆盖，待补取样”，不外推。
5. **不越权**：诊断只给定位、证据、分支、建议、最小验证；不直接重写全文。

**卡住时**：无文本 → 不编造稿中的问题；给出取样要求（贴哪几段：开头、转折场、结尾）和 `templates/diagnosis-report.md` 空表供自查；作者描述了症状，就按描述列可能原因和改法，标“按描述推测”，不进诊断报告的症状/证据字段（无文本时不填 DR-04…DR-11），并索取原稿。只有梗概 → 只做规划层诊断（主行动/线/终点/类型），不做句段诊断：填 DR-01/02/04/05/06/07/12，DR-03 与 DR-08 按梗概层纪律照填——DR-03 以梗概文本为证据源（位置 + 短引文；结构性缺失写“测试方法 + 结果”，如主行动句复述失败、承诺-兑现对照落空），DR-08 填梗概层可完成的检查（主行动复述、承诺-兑现对照、抽线测试）；DR-09 建议照常给。全表标“句段层未诊断”，句段层未覆盖项写入 DR-12。

## 1. 严重度与证据强度（分开写）

| 严重度 | 含义 | 处理 |
|---|---|---|
| **阻断** | 不改就无法继续写/读：主线不成立、视角合同大面积破裂、结尾承诺不兑现、巧合解结 | 先修；修完再谈句段 |
| **重要** | 影响阅读体验/类型承诺，但故事仍成立：中段塌、人物工具化、开篇无契约、类型失约 | 这一稿就改 |
| **建议** | 局部/风格/剂量：个别句段、细节过多、语域小跳 | 可选；不阻塞交付 |

**证据强度**单独标：

- **强**：多处文本证据 + 结构测试失败（如抽线后主线不变）。
- **中**：一处文本证据 + 作者确认/上下文支持。
- **弱**：只有读者感受/编辑直觉，尚无文本证据 → 标“待验证”，不升为结论。

严重度高不等于证据强；证据弱时先做最小验证，不要直接下“阻断”。

## 3. S1 无主行动

**可观察证据**

- 无法用一句话说出“谁要什么、谁阻止、失败代价”；
- 每条线都能单独成篇，抽掉任一条主线不变；
- 事件按“然后”排列，缺少“因此”；
- 读者/编辑复述故事时，只能列事件，说不出“这故事在干什么”。

**对应规则**：FC-06（主行动/多线）、FC-02（胚故事）。

**分支判断**

- A 单主线：若有一个核心决定/危机，但被次线淹没 → 删/并次线，突出主行动。
- B 多线交织：若多条线本应共享终局，但没有交汇 → 补交汇场/共享决定；补不出 → 降为次线。
- C 链条式：若本来就是一串相对独立的段落故事（流浪汉式），不强行加总汇聚；改验“每站是否改变主角处境”。

**最小验证**

1. 让作者/读者用一句话复述主行动；复述不出 → 证据成立。
2. 抽线测试：抽掉一条线，复述主线；完全不变 → 赘线。
3. 事件链标注：每环标“因此/然后”；“然后”超过一半 → 因果不足。

**建议**

- 先写 `主行动`，再决定删/并哪条线；不要先改句子。
- 若主行动写不出，退回 FC-02 的 `胚故事`，不要用“主题”代替行动。

**严重度**：阻断。主行动不成立时，场景/句段修改都是局部美化。

## 4. S2 中段塌

**可观察证据**

- 中段连续多章/多场是概述，没有当场冲突；
- 每章末状态不变，或只是“又得到一条线索”；
- 次线与主线没有交汇，删掉也不影响；
- 高潮/大结过早（后段只收果）或过晚（前段原地打转）；
- 读者能预判下一步，却被拖延。

**对应规则**：FC-07（场景/概述/过渡）、FC-08（单元收束）、FC-04（终点/倒推）、FC-06（主线/次线）、FC-12（信息增量）。

**分支判断**

- A 场景不足：关键对抗被概述 → 选 2–3 场改成场景（谁在场/要什么/谁阻止/代价）。
- B 过渡过多：时间跨度需要过渡，但过渡无新信息 → 补“关系/身体/目标”变化，或删。
- C 次线无交汇：次线不改变主线条件 → 删/并/降背景。
- D 终点不清：中段不知道往哪走 → 回到 FC-04 写 `终局状态` 或至少“最后决定”。
- E 同一种阻碍再来一遍：中段的冲突只是换了地点和对手，问题的性质没有变 → 让冲突改变问题本身：给一条改变判断的新信息、让盟友反目、让人物发现目标本身错了。系列单元剧可以重复结构，但每个单元的赌注要不同。

**最小验证**

先做反向大纲（一章以上的稿子）：逐场写一句“这场改变了什么”。写不出的、和前面某场重复的、换个顺序也不影响的，都是要查的场景；再按下面几项定位。不到一章的短稿不需要。

1. 做 `单元表`：每章/场标 场景/概述/过渡；中段概述占比过高 → 证据成立。
2. 做 `单元收束表`：每章末 state_changed；连续 3 章“未变” → 中段塌。
3. 做“删一章”测试：删掉中段一章，主线是否更清楚？更清楚 → 该章可删/并。
4. 做“信息增量”表：每章读者多知道哪件会影响下一步的事？连续两章无增量 → 中段重复/塌。
5. 标 `主汇合`：若主线汇聚在 3/4 处，检查前段是否蓄因、后段是否只收果；这是操作默认参考，不是硬门。

**建议**

- 先补“状态改变”，再补“新信息”，最后才考虑加事件/加人物。
- 不要把“中段塌”误判为“字数不够”；加字数不解决状态不变。

**严重度**：阻断（连续多章无状态改变）；局部拖沓可降为重要。

## 5. S3 人物工具化

**可观察证据**

- 人物只在需要时出现，交付信息/推动机关，然后消失；
- 换掉他/她，情节几乎不变；
- 人物没有独立于主角目标的欲望；
- 视角切到他/她，只是为了传一条主角不知道的信息；
- 人物决定由作者需要解释，而非处境/性格。

**对应规则**：FC-05（入口/双向校验）、FC-11（切换收益）、FC-14（视角过滤）。

**分支判断**

- A 功能人物：只承担信息/对照 → 删/并，或给一个与功能冲突的私人目的。
- B 入口错配：人物是为情境硬塞的“玩偶” → 按 FC-05 B 分支重造情境对抗，或改人物入口。
- C 视角工具：切过去只为传信 → 改回主视角，用动作/对白让信息自然出现。
- D 类型需要扁人物：喜剧/类型配角可扁，但要有辨识度与可信欲望；不强行“圆”（K-15 两说）。

**最小验证**

1. 三决定测试：能否说出人物三处“只有他会这样”的决定？说不出 → 工具化风险高。
2. 删人测试：删掉该人物，主行动是否改变？不变 → 功能可合并。
3. 切换账本：该人物的视角场是否有 `收益`（单视角拿不到的东西）？只有信息 → 工具化。
4. 遮名测试（扁人物）：遮住名字，读者能否认出是谁？认不出 → 连扁人物的辨识度也不足。

**建议**

- 先给人物一个“与主线目标冲突的私人欲望”，再决定留/删。
- 重要配角各写一行“他在这场想要什么”，按 `character-and-narrative-control` 的 PS-34 检查；只出场一次的功能人物可以不写。几个人说话一个腔调时，转 PS-31 定声口。
- 不要用“加背景故事”解决工具化；背景不改变当下选择。

**严重度**：重要；若主角/对手工具化并导致主线不成立 → 阻断。

## 6. S4 视角失守

**可观察证据**

- 限知视角写出人物不可能知道的事（别人内心、远处发生的事、结局）；
- 同一场景无标记滑入多人内心；
- 切换无场景/章节/排版标记；
- 语域突然比视角人物更有文化/更抽象；
- 切换只买回一条信息，没有范围/反讽/对照收益。

**对应规则**：FC-11（三层：信息合同/距离/切换交易）。

**分支判断**

- A 信息越界：无 marker/benefit → 判缺陷；改由动作/对白/推断承载，或删。
- B 距离跳变：语域/距离变化但未重新锚定 → 补锚定句/场景标记，或改回同一意识。
- C 故意切换：有 trigger/benefit/marker/cost → 保留；缺任一 → 补或改回。
- D 全知/群像：合法，但不得在同一场景无标记滑入多人内心；用场景/章节分隔。

**最小验证**

1. 逐段知识审计：每句信息问“视角人物此刻怎么知道？”答不出 → 越界。
2. 切换账本：每个切换填四格；缺 benefit 或 marker → 缺陷。
3. 朗读切换段：读者是否被“弹出”？弹出 → 补强度/标记，或改回。
4. 遮住章节标题：读者是否知道现在是谁在看？不知道 → 标记不足。

**建议**

- 短篇优先改回单一 reflector；必须切换时用框架/书信/档案。
- 长篇不要用“多视角”当“作者想写谁就写谁”的借口；每次切换记账。

**严重度**：大面积/主线信息靠越界 → 阻断；局部/一次切换 → 重要。

## 7. S5 开篇无契约

**可观察证据**

- 首段/前三段没有“谁要紧/何时何地/什么调/什么类型/什么问题”；
- 背景信息成块说明，人物在介绍世界而非行动；
- 读者不知道为什么要继续读；
- 删掉第一段，故事反而更清楚；
- 晚入场缺失或过度：要么从族谱/历史讲起，要么一上来全是谜语。

**对应规则**：FC-09（首段四职/晚入场条件）。

**分支判断**

- A 晚入场缺失：有一个正在发生的动作可切入 → 从第一次不可逆的动作/对话开始，前史拆 1–3 处。
- B 需要从头写：理解门槛高/历史/世界构建 → 用典型场合/典型一天，先给秩序再打破。
- C 舞台：exposition 生硬 → 改成人物当下的利益冲突。
- D 框架：框架无压力 → 给“为什么现在讲”，否则删。

**最小验证**

1. 四职检查：who/where-when/tone-type/question，各一句；缺 2 项以上 → 证据成立。
2. 删首段测试：删掉第一段，故事是否仍能懂？能懂 → 第一段可能是装饰。
3. 首段信息盘点：每句背景信息标“承载动作”；没有承载 → 说明块。
4. 读者问题：读完前三段，能否说出一个可追的问题？说不出 → 契约缺失。

**建议**

- 不要用“加一个爆炸/尸体”解决开篇；先补四职，再选入口。
- 商业投稿可把“开篇无契约”升为阻断；文学/慢热可降为重要，但仍要给读者一个可追的问题。

**严重度**：重要；商业投稿/类型小说可阻断。

## 8. S6 结尾欠账/拖沓

**可观察证据**

- 高潮后还有大段解释/总结/人物后续；
- 前面埋的承诺（谜题/关系/意象）没有兑现；
- 结尾引入新问题/新人物，超出读者承诺；
- 删掉最后一段，结尾仍成立（说明结尾是补的）；
- 开放结尾没有潜伏意象/线头收束，读者觉得“没写完”；
- 高潮与结论相隔太远，读者兴趣已过。

**对应规则**：FC-10（结尾契约/四型）、FC-08（单元收束/大收煞）、FC-04（终点/倒推）。

**分支判断**

- A 闭合型：高潮后只留未解点解释；其余删/移番外；高潮与结论尽量同时。
- B 解谜型：机关解释放高潮后用动作/对白承载；不能靠巧合。
- C 开放型：检查潜伏意象/线头；开放不等于任意收笔。
- D 仪式型：先解扣再起波澜，逐人给落点，不念总结。

**最小验证**

1. 承诺-兑现表：每个 `未解的问题`/伏笔标兑现章；未兑现 → 欠账。
2. 删末段测试：删掉最后一段，结尾是否仍成立？成立 → 结尾是补的。
3. 高潮后段落计数：超过“解释未解点”所需 → 拖沓。
4. 结尾契约检查：读者被承诺的是答案/团圆/余味/惊叹？结尾给的是哪一种？错配 → 重选型。

**建议**

- 先补承诺，再删解释；不要用“再加一个反转”掩盖欠账。
- 若作者要开放，必须写清“为什么这个类型/效果需要不揭”，并检查潜伏意象。

**严重度**：阻断（承诺不兑现/类型错配）；局部拖沓可重要。

## 9. S7 巧合解结

**可观察证据**

- 关键证据/人物/救援在危机处“恰好”出现；
- 巧合直接决定胜负/生死/婚配；
- 前文没有铺垫，或铺垫只在巧合前一段；
- 人物意志/前史因果可以被替代，但作者选了偶然；
- 类型契约并不豁免（写实/悲剧/侦探）。

**对应规则**：FC-13（可信度契约/巧合位置/类型豁免）。

**分支判断**

- A 写实/悲剧/侦探：巧合在解结 → 改为人物意志/前史因果；改不出 → 换事件/换解结方式。
- B 传奇/幻想/闹剧：类型豁免，但内部规则要一致；不能用类型解释人物动机突变。
- C 真实事件改编：当奇事写，让人物也惊讶；补双倍铺垫。
- D 巧合在前提/起点：可留；它设定世界，不解决危机。

**最小验证**

1. 位置审计：每个巧合标前提/转折/解结；解结处 → 高风险。
2. 替代测试：删掉巧合，危机是否仍能由人物/前史解决？不能 → 它承担了解结。
3. 铺垫检查：巧合前是否有至少两处可回读的因？没有 → 补因或换事件。
4. 类型检查：类型契约是否明确放弃逼真？没有 → 按 A 处理。

**建议**

- 把“恰好”改成“人物制造/前史留下/对手失误”，并让代价可见。
- 不要用“命运/天意”解释，除非前文已建立命运框架。

**严重度**：写实/悲剧/侦探 → 阻断；闹剧/传奇 → 建议（但内部逻辑不一致仍重要）。

## 10. S8 类型失约

**可观察证据**

- 类型契约的 3–5 个必要特征缺失；
- 读者承诺（答案/团圆/恐怖/知识/代入/惊叹）没有兑现；
- 偏离没有补偿，或补偿只是“这是文学”；
- 退稿理由指向类型/市场，但作者当成技艺问题；或反之；
- 类型混合时，按局部元素判类，导致验收标准错位。

**对应规则**：FC-20（按 `genre-fiction-craft` 的题材契约核对，它没有写到的特征记进规划表的类型约定；市场约束分层）。

**分支判断**

- A 商业/类型投稿：必要特征缺失 → 改；偏离无补偿 → 补/删。
- B 文学/跨类型：有意偏离 → 写清补偿与目标读者；没有补偿 → 按失约处理。
- C 市场/审查：退稿理由指向字数/结局/禁忌 → 与技艺分栏；不要改结构去迎合无法确认的市场。
- D 类型混合：按主导处理判类，不按局部元素。

**最小验证**

1. 契约清单：3–5 个必要特征逐条勾；缺 2 项以上 → 失约。
2. 读者承诺句：读完能否说出“我得到了什么”？说不出 → 承诺模糊/未兑现。
3. 偏离日志：每个偏离写补偿/代价；没有 → 失约。
4. 退稿分栏：技艺/市场/审查三栏，各找证据；无证据 → 标未知。

**建议**

- 先确认“这是给谁看的类型”，再谈文学性；不要用“跨类型”掩盖必要特征缺失。
- 市场约束不要写成艺术规则；艺术偏离也不要怪市场。

**严重度**：重要；商业投稿/类型承诺完全缺失可阻断。

## 11. S9 文体空泛

**可观察证据**

- 抽象名词/名词化堆叠，主语/主动词不清；
- 形容词多于动作，句子“漂亮但可删”；
- 细节像清单，没有主导印象；
- 主题句直接点题，人物替作者讲道理；
- 朗读拗口/单调，读者要回读才懂；
- 文体问题掩盖了结构问题（场景无目标/无转折）。

**对应规则**：FC-15（文体底线）、FC-14（细节/具体化）、FC-16（主题/点题）。

**分支判断**

- A 句段问题：结构成立，只是句子绕/套语多 → 句层修（朗读、主谓、删套语）。
- B 细节问题：细节无主导印象/视角过滤 → 按 FC-14 删/压/排序。
- C 主题问题：点题句过多、人物口播 → 按 FC-16 删/改为选择。
- D 结构掩盖：文体华丽但场景无目标/无转折 → 不要句层打转，回 FC-07/FC-08。

**最小验证**

1. 抽样 300–500 字，标每句主语/主动词；名词化/无主语占比高 → 句段问题。
2. 朗读测试：是否要回读才懂？是 → 断句/换词。
3. 删形容词测试：删掉装饰性形容词，事件是否受损？不受损 → 可删。
4. 结构对照：这场是否有目标/阻力/转折？没有 → 文体问题可能是结构问题的症状。

**建议**

- 先修结构，再修句子；不要用“润色”掩盖场景不成立。
- 文体底线是清晰/得体/可朗读；“好文体”不可立法，不承诺“改了就像某大师”。

**严重度**：建议；若文体问题掩盖结构缺陷/读者无法理解 → 重要。

## 12. 诊断报告的写法（对应 `templates/diagnosis-report.md`）

每条症状写成一个 DR 块：

1. **DR-01 范围**：全书/章节/场；不写“整体”。
2. **DR-02 版本**：稿本标识/日期/字数。
3. **DR-03 证据**：位置 + 短引文 + 观察；结构性缺失写“测试方法+结果”。
4. **DR-04 症状**：用本文件的 S1–S9 名称，不自造术语。
5. **DR-05 规则**：主规则 + 辅助规则。
6. **DR-06 分支**：A/B/C/D；写“为什么选这个分支”。
7. **DR-07 严重度**：阻断/重要/建议；证据强度另标。
8. **DR-08 最小验证**：一条可在 15–30 分钟内完成的检查。
9. **DR-09 建议**：定位 + 方向 + 可选最小改写（1–3 句）。诊断里不整章重写；作者要改写，转 `references/revision.md`，另起版本。
10. **DR-10 回归项**：改后必须仍成立的东西（主行动/视角合同/承诺兑现）。
11. **DR-11 未决**：需要作者决定的价值/范围/类型问题。
12. **DR-12 证据缺口**：没看到的章节/没验证的读者反应/未覆盖的类型。

**DR-SUM**：3–5 句，只写“最阻断的 1–2 项 + 下一步 + 未决”，不重复所有细节。

## 13. 诊断纪律

- 不把“我不喜欢”写成“结构缺陷”；先找文本证据。
- 不把“读者会……”写成事实；标为推断。
- 不把操作默认值（3/4、2–3 视角、3–5 细节、字数/章数）当硬门；只作默认参考。
- 不把类型契约当本体论；类型失约要看读者承诺，不看出身。
- 不把评论或个案推断当作者方法；诊断建议要标明“这是推断”。
- 不在同一份报告里既诊断又重写；重写转 `references/revision.md`，并需授权。
- 诊断效果 **未能核实**；本 Skill 不提供自动评分/读者预测。

## 三问回归：结构、证据与不交付

完成诊断或修订后，逐项回答：

1. **取样是否覆盖变化点？** 至少检查开篇、中段、结尾，并选取一处视角切换或关键转折；若缺少全文或某一段，明确标记未覆盖，不推断全书状态。
2. **越界迁移是否有证据？** 若把小说方法迁移到舞台、影视、互动叙事或具体平台，是否区分原媒介事实、迁移推断和待验证事项？无依据时转交对应媒介 Skill，不伪装成通用规则。
3. **不交付是否写清？** 对未授权或不属于本 Skill 的工作，是否列明不交付的专用格式、术语体系、流程、模板、技术实现、专业结论和结果保证，并给出正确 Owner？

### 验证回执字段

每项任务必须记录：真实输入（原文范围与版本）、预期结果、实际结果、证据位置、执行范围、限制、状态和未解决影响。状态只用 SKILL.md §9 的三个词填写：已完成、未能核实、待作者决定；依据记在「证据位置」。对作者交付按 SKILL.md §9 的交付回执模板声明；本字段清单是同一份回执的留底字段，不并列成两份回执。历史回执只适用于当时的输入与版本，不自动继承。
