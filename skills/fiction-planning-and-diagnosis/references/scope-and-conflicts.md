# 条件、冲突与证据边界

> 本文件回答三个问题：什么条件下用哪条规则；19 条冲突在消费端怎么取；哪些参数只是默认值/历史值，不能当硬门。
> 规则全文在FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）。本文件不新增来源。

## 1. 长度 / 媒介 / 类型条件总表

| 条件 | 较强规则 | 较弱/禁用 | 备注 |
|---|---|---|---|
| **短篇（约 ≤10,000 词，历史约定）** | FC-03 A 单一效果；FC-04 A 终场；FC-09 A 晚入场；FC-11 A 单 reflector；FC-19 删减 | 多线/群像的完整工序；长篇过渡页 | 字数界线是 1900–1926 市场约定，不是当代平台标准 |
| **中篇 / 长 short-story（两三条线、一个高潮）** | FC-03 C 中间态；FC-06 A/B 混合；FC-04 A/B 按终点清晰度选 | 把“单一效果”上推为“只能一条线” | 不设统一字数界线；按“是否只有一个高潮”判 |
| **长篇（≥50,000 词，历史约定）** | FC-06 B 多线；FC-03 B 整体统一；FC-04 B 终局状态；FC-07 过渡；FC-08 章末；FC-13 巧合审计 | 短篇的“晚入场/一句一效果”硬套；每章都要独立高潮 | 长篇多线的完整工序未覆盖，标 未证实 |
| **连载 / 周更** | FC-08 A 暂解+钩子；FC-18 A 日课/骨架；FC-19 C 商业删减；FC-20 A 类型契约 | 把“钩子”当虚假悬念；回改已发布章节 | 平台数据/读者留存未覆盖；钩子必须兑现 |
| **舞台 / 戏曲** | FC-08 C 幕/折收束；FC-06 拉幕汇聚；FC-12 B 观众预知；FC-13 巧合审计；FC-16 B 明示教训 | 小说的内心描写/概述/自由间接；李渔声容/居室/饮馔 | 迁到小说一律算推断；只借结构层级 |
| **口头讲述** | FC-09 D 框架/钩子；FC-15 可说可听；FC-12 现场注意力 | 书面复杂句/脚注/回看；电影剪辑 | 口头材料只作媒介边界，不作小说通则 |
| **银幕 / 影视** | 只借 FC-06/07/10 的结构类比 | 剧本格式、分镜、镜头表、互动分支 | 本 Skill 不交付影视格式；1916 无声片材料只作历史 |
| **现实主义 / 悲剧** | FC-13 A 巧合最严；FC-14 A 具体化；FC-16 A 主题从行动 | 闹剧式巧合豁免；纯奇“probability not called for” | 写实不等于“细节越多越真” |
| **传奇 / 幻想 / 童话 / 闹剧** | FC-13 B 类型豁免但内部逻辑；FC-15 B 允许华丽；FC-10 C/D 开放/仪式 | 用“类型”掩盖人物动机突变；用“纯奇”跳过内部规则 | 类型豁免不是无规则 |
| **侦探 / 悬疑** | FC-10 B 解谜；FC-12 A 保密；FC-13 A 巧合最严；FC-20 A 契约 | 舞台“观众全程知道”搬进悬疑；开放逃避解谜 | 侦探是先抛谜面、倒推机关，不是先写结局画面 |
| **寓言 / 道德故事 / 宣传** | FC-16 B 可明示；FC-20 B 类型契约 | 把“说教必败”当绝对律；把寓言当小说验收 | 教训必须由行动兑现 |
| **速写 / 印象主义** | FC-03 C tone 统一；FC-07 B 概述为主；FC-14 C 细节同调 | 强行情节化/高潮化；按情节驱动删细节 | 速写可无高潮，但不能无“某事在发生” |
| **类型混合** | FC-20 按主导处理判类；FC-01 并列标签分别验收 | 按局部元素判类；取平均 | 跨类型/当代类型工业未覆盖 |
| **儿童 / 教育叙事** | 只借 FC-16 B、FC-09 D 的框架 | 把成人小说的性/暴力/复杂结构当通则 | 儿童文学覆盖极薄，标 未证实 |
| **非虚构 / 史传 / 新闻** | 不在本 Skill 范围；只借 FC-13 C 的“按实”边界 | 把小说“似真”标准套史传；把史传“按实”套小说 | 明确拒绝，不冒充专业交付 |

## 2. 19 条冲突（消费者版）

> 每条只给一个裁决。“有条件”的写清在什么条件下取哪一方；“两说”的给一个稳妥的默认做法。禁止写“两者都重要”“辩证统一”“各有道理”。

| # | 争点 | 裁决 | 条件（取哪方） | 稳妥做法 / 不要这样写 |
|---|---|---|---|---|
| K-01 | 单一效果 vs 多重目的 | 有条件 | 短篇/单线/独幕/轶事 → 单一效果；长篇/多线/速写/印象主义 → 主行动统一 + 语调/母题统一 | 不写“单一效果是所有叙事通则”；不写“长篇不需要统一”；速写作为独立类型 vs 短篇一型要分清 |
| K-02 | 人物先行 vs 情节/结局先行 | 有条件 | 按素材入口选：人物/情境/终局/效果；选后做双向校验 | 不写“人物永远优先/情节永远优先”；不把 James 的 doctrine 当因果；不把 115 人问卷多数票当法则 |
| K-03 | 描写剂量 | 有条件 | 现实主义/氛围 → 具体化；情节驱动/动作 → 少而准；无论哪方先按视角过滤 | 不写“细节越多越真”；不写“描写越少越好”；删“真实但无用” |
| K-04 | 视角一致性 | 有条件 | 信息权限=合同（近硬）；距离=可调但重新锚定；切换=交易（trigger/benefit/marker/cost）；短篇 1 reflector，长篇 2–3 默认 | 不写“禁止一切切换”；不写“视角随便切”；不把 Forster 的“视角非中心”当“视角不重要” |
| K-05 | 巧合能否解结 | 有条件 | 巧合可作前提/起点/日常纹理；写实/悲剧/侦探中不可作危机解结；类型豁免须内部逻辑；真事须补铺垫 | 不写“巧合一律禁止”；不写“类型可以随便巧合”；不把“真发生过”当免罪符 |
| K-06 | 闭合 vs 开放 | 两说 | 作为“哪种更好”的普遍命题保留争议；操作按 `结尾约定` 分型：闭合/解谜/开放/仪式 | 安全出口：先声明读者承诺再选型；不按时代排名；开放须 latent、线头有收束；不写“开放更好/闭合更成熟/两者都对” |
| K-07 | 自然 vs 工艺 | 有条件 | 成品判据取“自然”（无斧凿、语域统一、朗读顺）；生产过程取“工艺”（冷却、分层、删爱句） | 不写“好文章是改出来的”作普遍命题；不写“自然就是不改”；二者不可互证 |
| K-08 | 纪实 vs 似真 | 有条件 | 史传/新闻/目击 → 按实；小说/传奇/童话 → 内部自洽；纯奇 → 可放弃 probability，不可放弃内部逻辑 | 不把“俗皆爱奇”当小说戒律；不把“虚构可以随便编”当自由 |
| K-09 | 道德目的 | 有条件 | 小说/短篇 → 主题从选择/后果长出；寓言/道德故事/宣传/教育 → 可明示，但须行动兑现；讽刺 → 标记足够 | 不写“说教必败”作绝对律；不写“小说必须无道德”；不把价值立场当事实 |
| K-10 | 类型硬边界 | 有条件 | 类型作契约/教学工具：写前列 3–5 必要特征+承诺；写后验收；混合按主导处理 | 不写“类型有硬边界”；不写“类型无意义”；不把 1911 年前 34 型表当现代类型学 |
| K-11 | 晚入场 vs 从头写 | 有条件；同一本书里两说并存 | 印刷短篇/动作/商业 → 晚入场；说明性/历史/传记/世界构建 → 从头/典型场合；舞台 → 动作/对白；框架 → 先给讲述理由 | 不写“晚入场是普遍律”；不写“必须从开头写”；不把舞台三遍法搬进小说；引 单句要标同书矛盾 |
| K-12 | 规则可教性 | 有条件 | 结构层可教（因果/场景/视角/结尾/主行动）；文体层半可教（清晰/得体/节奏可诊断）；天赋/判断层不可教（音感/眼光/幽默） | 不写“写作无规则”；不写“照步骤就能写好”；输出判据+条件+≥2 反例，不输出无条件步骤 |
| K-13 | 张力单调上升 | 有条件 | 短篇/独幕：兴趣不减；3,000 词内不设前置缓解（历史默认）；长篇：允许缓解，但服务更大张力；高潮前减速≠张力下降 | 不写“张力只能升”；不写“长篇可以随便松”；不把“减速”当“降张力” |
| K-14 | 读者预知 vs 保密 | 有条件 | 舞台/戏剧反讽 → 读者多于人物；侦探/悬疑 → 读者少于人物；惊奇 → 同步后揭晓；普通叙事 → 按场景分层 | 不写“读者知道越多越好”；不写“绝不能泄露”；不把舞台预知搬进悬疑；所有“读者会”标为推断 |
| K-15 | 扁人物 vs 圆人物 | 两说 | 不排名；按功能选：次要/喜剧/类型人物可扁；承担道德危机/长时间变化的主角需圆；先声明术语 | 安全出口：扁人物问“遮名能否认出”；圆人物问“是否做过可信的意外”；不写“人物必须圆/扁人物更高级”；不把 Forster 分类当价值等级 |
| K-16 | 对白地位 | 有条件 | 舞台/戏曲/影视 → 对白承载情节与人物；书面小说 → 对白留给高潮/转折，日常信息用叙述压缩；共同底线：台词符合人物立心 | 不写“对白越少越好”；不写“对白可以随便多”；不把李渔“宾白等视”直接搬进小说；全对话体须强理由 |
| K-17 | 快乐结局 | 两说 | 市场偏好与艺术逻辑不可通约；先声明 `目标市场` 与 `结尾约定`：商业类型按市场契约，文学/作者电影按逻辑结局 | 安全出口：市场型仍须“逻辑上可能”；逻辑型须接受市场代价；不写“读者都要快乐结局”；不写“快乐结局庸俗”；不把 1920 年代美国杂志偏好当普遍规律 |
| K-18 | 单一效果粒度 | 有条件 | 整篇级：短篇/独幕；场/段级：长篇/多幕，每场可有小效果但服务整体；**禁止跨层合并** | 不写“三种说法是一回事”；不写“短篇写法可套长篇”；不把“每场一个主脑”当“整篇只能一个效果” |
| K-19 | 词句难度 | 有条件 | 文学/论说/高教育读者 → 得体优先，允许长句/抽象词；商业/动作/年轻读者/口头 → 短词短句优先；共同底线：主动词、具体名词、删套语 | 不写“短词永远更好”；不写“长句更高级”；不把 Quiller-Couch 的“得体”当风格相对主义 |

## 3. 单来源参数清单（只能作默认/可选/历史值）

> 以下参数在 28 本中只有单一来源、或只是操作默认。**不得写成硬门**；用时应写“默认参考/历史约定/作者可选”。

| 参数 | 来源/性质 | 在 Skill 中的用法 | 不能怎么用 |
|---|---|---|---|
| 短篇约 1,000–10,000 词；长篇 ≥50,000 词 | 1900–1926 市场约定；非统计 | 只作赛道初判；允许作者改标 | 不能拿来退稿/判定“不是长篇” |
| 章数 / 每章字数（如 40 章、每章 3,000 字） | 无独立来源；平台/刊物惯例 | 只作作者/平台自定；示例数字不作规则 | 不能当结构硬门；不能由章数反推质量 |
| 大结/主汇聚在约 3/4 处 | -2385（单来源；Hamilton 把侦探除外） | 只作长篇结构默认参考；侦探/开放式另算 | 不能当“必须 75%”的硬门 |
| 中点照面（中点必须让主角与对手正面相遇） | 28 本来源里没有可以回读的独立依据 | **不收入规则**；如作者自选，标 未证实 | 不能写成普遍结构律 |
| 长篇 2–3 个 reflector | （单来源） | 只作默认；群像/史诗可多，但每次切换记账 | 不能当“超过 3 个就错” |
| 长篇先分 8–9 段骨架 | -2567（单来源自述） | 只作可选工作法 | 不能当“必须 8–9 段” |
| 每场 3–5 个具体细节 | 操作默认，非来源原话 | 只作删减排序的默认 | 不能当“少于 3 个不具体/多于 5 个就错” |
| 从终场倒推 3 个因果环 | 操作默认 | 只作短篇规划的最小链 | 不能当“只能 3 环” |
| 开头 2–3 段（可压到 1 段） | （历史市场） | 只作默认；可按媒介/类型调整 | 不能当“第 4 段还没进故事就失败” |
| 3,000 词内不设前置缓解；≥10,000 词可减压 | -3569（历史/单来源） | 只作短篇/长篇节奏默认 | 不能当硬性字数门 |
| 历史小说单卷 5–8 万字 | -2236（1890 年代英国市场，已过期） | 只作历史注；不进入规则 | 不能用于当代字数判断 |
| 34 型叙事 / 短篇九类 | 1911 年前的手册、1900 年的杂志分类 | 只作历史分类注 | 不能当现代类型学 |
| 舞台开场“每个要点说三遍” | -2111（商业剧场） | 只作舞台历史注 | 不能搬进小说 |
| 突发写作瓶颈与创作节奏波动 | 经验自述（属推断） | 只作“卡壳可换环境/换节奏”的参考 | 不能当产量/速度标准 |
| 列 5–7 个候选事件 | 操作默认 | 只作胚故事练习 | 不能当“必须 5–7 个” |
| 短篇默认一个 reflector | 多来源倾向，但仍是默认 | 只作短篇起点 | 不能当“短篇绝不能切换” |
| 每条规则 ≥2 反例 | FC-21 格式要求 | 只作写作格式 | 不是“两个反例就证明规则有效” |
| 每章末都要钩子 | 连载惯例；无读者数据 | 只作连载默认 | 不能当“所有章都必须悬念” |

## 4. 证据边界

### 4.1 材料范围

- 规则体系提炼自经典叙事手册、编剧工艺、诗学文论，涵盖小说架构、短篇机制与长篇规划法则。
- 市场语境：1900–1926 英美印刷市场、杂志短篇、商业剧场；不是当代出版/平台。
- 来源类型：方法书、评论、作品与编者判词、分类和书目及市场资料，另有混合的文本；依据里怎么标见 §4.3。
- 同作者/转引/同编者已去重：Clayton Hamilton 的两本只算一个来源，转引 Hamilton 的不另算；Hoffman 编的两本只算一个来源；同书多段只算 1。

### 4.2 能支撑 / 不能支撑

| 域 | 状态 | 能说什么 | 不能说什么 |
|---|---|---|---|
| 短篇/中篇的构思、结构、场景、人物、视角操作、文体、修订 | **较强** | 可用 FC-01…FC-19 的条件式判据 | 不能保证效果/读者反应 |
| 长篇的“主行动/多线/过渡/结尾”诊断 | **中等** | 可做结构诊断与删减方案 | 不能给“完整长篇多线工序”；群像/系列/世界观未覆盖 |
| 舞台/戏曲的结构类比 | **中等** | 幕末暂解、拉幕汇聚、大收煞等结构层级 | 不能把舞台/戏曲规则直接当小说规则；声容/居室等不迁移 |
| 视角理论 | **弱** | 信息合同、距离、切换代价的操作层 | 不能给 Genette/Booth 级聚焦类型学、不可靠叙述者、自由间接引语 |
| 类型小说 | **弱/历史** | 类型作读者契约/教学检索；1911 前分类样本 | 不能给现代悬疑/科幻/奇幻/言情/恐怖/网文的必要特征；不能把 1920 美国市场当普遍 |
| 修订实证 | **弱** | 冷却、分层、单稿留痕的工序自述 | 不能证明“修订提升质量”；无草稿对照/过程日志/版本比较 |
| 读者反应 | **无实验** | 只能作设计假设，标为推断 | 不能写“读者研究支持/读者都会/读者留存会提高” |
| 非西方现代小说 | **缺** | 中国古典文论只作结构/文体参照 | 不能称“跨文化通用”；日本/印度/阿拉伯/非洲/拉美未覆盖 |
| 影视/互动/游戏 | **缺/历史** | 1916 无声片只作历史证据；结构类比标为推断 | 不能交付剧本格式、分镜、互动分支、影视类型契约 |
| 儿童文学 | **很弱** | 只借框架/道德故事的边界 | 不能给儿童小说结构论 |
| 翻译/多语 | **缺** | 无 | 不能给翻译叙事学 |
| 出版/营销/合同 | **缺** | 无 | 不交付；市场约束只作历史注 |

### 4.3 依据的种类

| 依据里怎么标 | 含义 | 用法 |
|---|---|---|
| 不标 | 作者明说的方法或主张 | 可以直接转成判据，但仍带条件 |
| 评论 | 评论、理论、批评判断 | 可以作判据；转成步骤属于推断 |
| 作品 | 作品里的现象、编者的判词 | 只作现象和例证；升格为方法属于推断 |
| 分类资料 | 分类表、书目、市场资料 | 只作历史和检索，不作普遍规则 |
| 推断 | 从评论反推、跨领域迁移、作者无法验证的自述 | 不写成“作者的方法”或“研究结论” |
| **未证实** | 效果/因果未证明 | 所有规则效果、修订收益、读者反应 |
| **位置核对过** | 依据的原文和位置在整理证据时回读核对过 | 不是效果验证 |
| **编写的示范** | 设计示例 | 不是真实客户稿/真实运行 |

### 4.4 不许做的外推

1. 不把“短篇单一效果”写成“所有叙事只有一个效果”。
2. 不把“晚入场”写成“所有小说都必须从中间开始”。
3. 不把“舞台观众预知”写成“悬疑应泄底”。
4. 不把“1920 年代美国杂志偏好（快乐结局、五条否定律、读者健忘）”写成“读者普遍想要/普遍如此”。
5. 不把“大师这样做”写成“人人应这样做”；例外登记，不升格。
6. 不把评论或作品现象反推出来的东西写成“作者的方法”。
7. 不把单来源参数（3/4、2–3 视角、3–5 细节、字数/章数）写成硬门。
8. 不写“研究支持/数据表明/读者实验证明”，除非真的引用了受控研究（本 Skill 没有）。
9. 不把类型契约当本体论硬边界；不把市场约束当艺术规则。
10. 不用“开放/闭合/扁/圆/快乐结局”的价值判断替代条件判断（K-06/K-15/K-17 两说）。
