# 整稿自检、作者的情形与误用

返回 [SKILL.md](../SKILL.md)。

## 1. 整稿自检的顺序

| 步 | 测试 | 通过的信号 | 产出 |
|---|---|---|---|
| 1 | CL-01 契约 | 说得出读者得到什么、不得到什么；每章兑现了契约的一部分 | 契约两行 |
| 2 | CL-02 说教 | 没有删掉后故事不变的议论段；反读测试有余地 | 说教诊断表 |
| 3 | CL-03 设定与景物 | 每段设定都说得出谁在看、怎样压迫或帮助人物 | 并入删留清单 |
| 4 | CL-05、CL-07 人物 | 三个未写场景都预测得出；删名后认得出说话人；行为都能从欲求和处境理解 | 人物预测表、双审表 |
| 5 | CL-04、CL-06 细节来源 | 承担关键因果的细节都有来源；事实契约写明 | 经验账本 |
| 6 | CL-08 场面 | 每章五项填得出；“从台下看”的句子不靠叙述者解释 | 场面表 |
| 7 | CL-09、CL-10 删与补 | 没有“都不是”的段落；留下的场景都过了写完检查 | 删留清单 |
| 8 | CL-11 故事与人心 | 每章两栏至少一栏强，弱的一栏按体裁补了 | 双栏表 |
| 9 | CL-12 复述 | 试读者复述出的人物关系与构想一致 | 复述记录 |
| 10 | CL-13 修订 | 结构遍完成后才进入句子遍；停的理由记下了 | 修订记录 |

只读了部分章节时，只对读过的部分下结论，并写明没读的范围。

## 2. 作者的各种情形

| 情形 | 处理 |
|---|---|
| 只有一个念头或一种氛围，说不出谁想要什么、什么挡着、结局付出什么代价 | 帮作者写一页梗概：先给两三个候选的人物目标和阻碍，请作者选；选定后再做 CL-01 和 CL-05 |
| 只有设定，没有人物目标 | 做 CL-03；世界观驱动的作品改写成人物代价。作者坚持“设定就是主角”时，在定位卡上写明这是另一种契约，继续做其余测试 |
| 人物动机不明，三场景预测不出 | 先帮作者写人物卡和秘密历史，再回到正文。作者说“人物对我也是未知的”时，区分“对读者隐藏”（可以）和“作者也不知道”（需要先想清楚） |
| 关键因果靠刻板印象，资料又查不到 | 降为背景，或者改事实契约（纪实改为改写）；给出最小的研究方案（CL-06） |
| 两种创作取向冲突，作者拿不定 | 两栏并列写出适用条件和代价，由作者选；暂时不选，标“待定”，先做其他测试 |
| 要现成的类型套路、节拍模板、市场预测 | 本 skill 不提供现成套路、节拍模板与市场预测（按这一章自己列节拍见 `drafting.md` §11）；结构转 `story-architecture-and-longform-planning`，章末与场内节奏转 `scene-conflict-and-rhythm`；题材契约以 `genre-fiction-craft` 为准，它没有写到的特征记进规划表的类型约定，题材专项技法转 `genre-fiction-craft` |
| 弱情节、反情节的文学作品 | 不套用 CL-09 的“推进”，先按 CL-11 重新定义功能 |
| 作者要写劝世文，或者要“绝对没有道德意义” | 前者说明契约上的代价，由作者决定；后者只删说教，不强加道德氛围 |
| 越改越死 | 用 CL-13 的停止条件，记下停的理由，不再加轮次 |
| 被退稿、成绩差，作者要一个“好不好”的判断 | 按 CL-14 把手艺和市场分开，只给可以核查的手艺项 |

## 3. 作者决定的事项

1. 小说观：以“消遣”还是“艺术”为完成标准（CL-01）。
2. 道德立场：氛围还是论点（CL-02）。
3. 人物的字面可能性：写实约束，还是奇幻、寓言的放宽（CL-07）。
4. 事实契约：纪实、改写、虚构（CL-06）。
5. 经验边界：哪些材料必须研究，哪些可以发明（CL-04）。
6. “推进”的定义：事件、情绪、主题、声音、世界（CL-09、CL-11）。

## 4. 只能靠试读的判断

| 判断 | 为什么测试给不了结论 | 测试能给什么 |
|---|---|---|
| 是否有趣、是否被打动 | 这是读者的反应，不是文本的属性 | 双栏表的弱项 |
| 人物是否在作者心里“长”清楚了 | 作者的内心状态无法观察 | 三场景预测 |
| 取舍是否选对 | 审美取舍无法由规则保证 | 只能指出明显没有功能的部分，并说明删改的代价 |
| 风格美不美 | 评价性判断 | 修订记录，只是代理 |
| 经验的边界 | 亲历不是创作许可的唯一条件；陌生题材需要研究和审读 | 记录核验方式与不确定项 |
| 失败是市场的还是艺术的 | 市场结果和文本手艺是不同问题 | 手艺项清单与实际市场数据分开 |
| 历史和虚构的比例 | 由作品的事实契约决定，不设固定比例 | 事实契约 |
| 道德氛围和说教的分界 | 取决于作品是否承诺明确论辩，以及主题是否由行动兑现 | 三层拆分和反读测试 |
| 方言值不值得 | 取决于读者和语境 | 理解成本的问题 |
| 读者是否看见了作者的构想 | 意图无法直接观察 | 复述对照 |

## 5. 误用本 skill

| 误用 | 后果 | 纠正 |
|---|---|---|
| 把“人物必须像真人”当规则 | 奇幻、寓言、类型人物被一刀切 | 只审“反应可理解”（CL-07） |
| 把“不推进就删”当规则 | 氛围、抒情、离题全被删光，书没有味道 | 无功能才删（CL-09） |
| 把“小说必须有道德目的”当规则 | 每本书都被要求讲道理 | 只区分说教和道德氛围（CL-02） |
| 把三场景预测当成质量判断 | “预测得出”被误当成“写得好” | 它只说明人物清楚（CL-05） |
| 把修订次数当质量 | 作者被要求一遍遍重写，越改越死 | 用停止条件（CL-13） |
| 以为 CL 测试覆盖了语言层 | 句法、视角、节奏没人管 | 句子转 `line-editing-and-proofreading`，视角转 `character-and-narrative-control`，节奏转 `scene-conflict-and-rhythm` |
| 把同一种惯例的重复表达当成共识 | 单一传统或相似意见被误当成普遍规则 | 回到适用条件、反例和实际文本 |
| 承诺“按测试改就能成功” | 作者把手艺清单当成成功保证 | 按 CL-14 分清可检查和不可检查的部分 |
