## 4. 引用与定位约定

1. **行号**：只用于“整本阅读版”的定位；换版本需重新定位。
2. **短引文**：每条 ≤40 词；英文逐字，中文按底本字形（PG23822 繁体、PG25471 简体）。
3. **不引用**：工作笔记、工作区的绝对路径、未回读的页码/索引。
4. **依据的种类**：见 [scope-and-conflicts.md](scope-and-conflicts.md) §4.3；评论和作品现象转成步骤时属于推断。
5. **效果**：所有规则的效果都未证实；依据的位置核对过；没有在真实写作任务上运行过。
6. **不新增来源**：本表未列的作品/理论，不得在 Skill 中冒充依据；需要时标“未覆盖”。
