# 起草工作流：把场景卡写成可读的当下冲突

> 适用：已有场景目标/前后文，要写出一场戏、一章、一个片段；或续写连载的下一章。
> 不适用：连场景目标都还没有的构思阶段（先用 `references/planning.md` 定目标，或者按 §0 补出假设再写）、已有成稿要诊断（转 `references/diagnosis.md`）、整章结构重写（转 `references/revision.md`）。
> 规则细节见FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；本文件只给起草时的顺序、可观察检查与卡住时。

---

## 0. 起草前：场景卡必须有四项

缺了哪一项，先补上再写：作者能回答，就请作者填 `templates/scene-plan.md` 的 SP-02…SP-05；作者要求直接写，就补一个合理的假设并标“假设”，写完后把这些假设列出来请作者确认。

| 项 | 问法 | 没有时 |
|---|---|---|
| 目标 | 这场谁想要什么？要具体到“这场结束前必须拿到/阻止/掩盖什么”。 | 先回规划的主行动/次线，确认这场服务哪条线；作者不在场时，按主行动推一个具体目标，标“假设” |
| 阻力 | 谁/什么在阻止？阻力是否也在推进自己的目标？ | 先造一个对抗力量再写，否则只是解释 |
| 转折 | 这场结束时，处境/认知/关系改变了什么？ | 只是“交换信息”的，改为概述或并入别场 |
| 功能 | 这场服务主行动/人物/信息/时间感中的哪一项？ | 说不出功能的纯装饰场，建议删或并入别场，由作者定 |

**可观察检查**：用一句话复述“某人想要 X，但 Y 阻止，最后 Z 变了”。复述不出 → 场景未成立。

**卡住时**：四项缺两项以上 → 先把缺的项列给作者，每项附两三个候选；作者要求直接写，就选一组标“假设”，写成探索稿，稿头注明“探索稿，假设见文末”，写完列出待确认项。探索稿不要当定稿交付。

## 1. 定单元：场景还是概述（FC-07）

**判断信号**

- 有人当场想要什么并被阻止 → 场景。
- 信息量大、时间跨度长、次要过程 → 概述。
- 只是时间过去 → 过渡。

**动作**

1. 在场景卡 SP-06 标 `场景` / `概述` / `过渡`。
2. 关键对抗必须是 `场景`；若写成 `概述`，改写成“谁在场、要什么、谁阻止、代价”。
3. 纯信息/纯装饰的场景 → 降为概述或删。
4. 长篇两次高潮之间需要过渡 → 写“季节/日常/身体变化”，且携带新信息。

**可观察检查**

- 这场有没有“当场”的动作/对话/选择？没有 → 不是场景。
- 这场的信息是否只能靠人物说？是 → 改成对抗中的信息交换，或降为概述。
- 过渡是否只写“后来过了几个月”？是 → 加一个新信息（关系变了/身体变了/目标变了）。

**卡住时**：写不成场景（缺阻力）→ 回到 SP-03 造阻力；造不出 → 降为概述，不要硬写对话。场景全是概述 → 标“叙述距离过远”，回到 FC-07 选 1–2 场关键对抗展开。

## 2. 定视角（FC-11）

**判断信号**

- 这场由谁看？他/她此刻能知道什么、不能知道什么？
- 是否需要进入别人的内心？若需要，是信息必需，还是为了省事？
- 叙述距离是贴身、中距还是远距？和上一场相比是否跳变？
- 切换处有没有场景/章节/排版标记？

**动作**

1. 写本场 `视角约定`：能知道/不能知道/能进入谁的意识。
2. 写 `距离表`：本场距离；若变，写“为什么变”。
3. 若切换：填 `切换账本` 四格（trigger/benefit/marker/cost）；缺一格就不切。
4. 短篇默认一个 reflector；必须切换时，优先用框架/书信/档案。
5. 写完朗读切换段：读者是否被“弹出”？弹出 → 补标记/补强度，或改回同一意识。

**可观察检查**

- 逐段问“这句话的信息，视角人物此刻怎么知道？”答不出 → 越界。
- 有没有“他突然想到/她不知道的是”这类作者越界句？有 → 改由动作/对白/推断承载。
- 语域是否突然比人物更有文化/更抽象？是 → 降回人物语域，或明确叙述者在场。

**卡住时**：写不出 `视角约定` → 先选一个 reflector，把信息限制在他/她可见范围；故事必须跨地同时发生 → 改多 reflector/全知，并逐次记账。切换无 benefit → 不切；改由当前视角人物目击/听说/推断。

## 3. 定信息差与悬念（FC-12）

**判断信号**

- 读者此刻知道什么？主角/对手/配角知道什么？
- 读者是少于人物（悬疑）、多于人物（反讽）、与人物同步（惊奇），还是按场景分层？
- 揭晓点在哪？揭晓后改变什么？
- 读者是否已从类型惯例预知？

**动作**

1. 画本场/本章的 `知识表`（读者/主角/对手/关键配角 × 关键信息）。
2. 选 `悬念方式` A/B/C/D；写一句“读者此刻最想知道什么”。
3. 定 `揭示点`：每个秘密何时说、由谁说、说完改变什么。
4. 检查：A 是否已被类型惯例预知；B 是否只剩等待；C 揭晓是否只补常识；D 是否全篇一个知识状态。
5. 所有“读者会……”句标为推断；不写“读者研究支持”。

**可观察检查**

- 本场结束时，读者是否多知道了一件“会影响下一步”的事？没有 → 信息增量不足。
- 读者知道的事，是否让下一场更紧张？没有 → 可能只是解释，不是悬念。
- 揭晓后，人物处境是否改变？没有 → 揭晓太早/太轻。

**卡住时**：填不满知识矩阵 → 先填“读者/主角/对手”三行；仍填不满 → 信息设计未定，不写揭晓。A 分支读者已预知 → 改 B（读者知道人物不知道）或改冲突；不靠隐藏信息硬撑。B 分支读者只剩等待 → 缩短/提前揭晓，或给人物一个新代价。

## 4. 定可信度与巧合（FC-13）

**判断信号**

- 这场有没有偶然相遇/误递/同时到达？
- 它出现在前提、转折还是解结？
- 它是否直接决定胜负/生死/婚配？
- 有没有人物意志/前史因果可以替代？
- 类型契约是写实、传奇、幻想还是闹剧？

**动作**

1. 写本场 `可信度约定`（写实/不可能但自洽/夸张取笑）。
2. 列 `巧合`：位置/作用/替代方案。
3. A 写实/悲剧/侦探：与危机重合的巧合 → 改为人物意志/前史因果。
4. C 真实事件：当奇事写，让人物也惊讶；补双倍铺垫。
5. B 传奇/幻想/闹剧：保留奇迹，但检查内部规则是否前后一致；不用“类型”解释人物动机突变。

**可观察检查**

- 删掉这个巧合，危机是否仍能由人物/前史解决？能 → 巧合可留；不能 → 它承担了解结，按 A 改写。
- 读者会不会停下来问“怎么这么巧”？会 → 补因或换事件。
- 类型内部规则是否前后一致？不一致 → 先修规则，不修概率。

**卡住时**：说不清可信度契约 → 按最严的写实处理，标“契约未定”。巧合在解结且改不出人物因 → 换事件/换解结方式；不要用“命运/天意”解释，除非前文已建立命运框架。

## 5. 定具体化与细节（FC-14）

**判断信号**

- 本场要让读者记住的一个印象是什么？
- 每个细节服务定位/人物/气氛/象征/信息中的哪一项？
- 这个视角人物此刻会注意这个细节吗？
- 删掉后读者是否还能重建空间/气氛？

**动作**

1. 写 `主导印象`（一句）。
2. 列 `细节`，标功能；按视角过滤（不会注意 → 删，即使生动）。
3. A 现实主义/氛围：留 3–5 个能暗示整体的细节（操作默认）；用一个具体物承载抽象。
4. B 情节驱动：压到一句可成像；删不影响行动的描写。
5. C 速写/印象主义：所有细节同调；不同调者删。
6. 做“一次成图”测试：读者能否在脑中一次成形。

**可观察检查**

- 本场细节是否超过 5 个且都同等用力？是 → 排序，只留能暗示整体的。
- 有没有“作者查资料”式细节（地质/历史/工艺说明）？有 → 删或压，除非它是人物会注意的。
- 删掉一个细节，读者是否还能知道在哪/发生什么？能 → 可删。

**卡住时**：写不出 `主导印象` → 先不写描写，回到场景目标；没有目标 → 描写必散。细节都“很重要” → 强制排序只留三个，删掉的进 `删减记录`，看是否真的损失。

## 6. 定文体与句段（FC-15）

**判断信号**

- 每句的主语/主动词是否清楚？
- 有没有名词化、套语、装饰性形容词？
- 词级是否与事件相称（小事用大词/大事用轻词）？
- 朗读是否拗口、单调、换气困难？
- 有没有“漂亮但可删”的句子？

**动作**

1. 朗读本场；标拗口/换气/重音落错处。
2. 找每句主语与主动词；名词化改动词，抽象名词换可触物。
3. 做“音高检查”：一句话复述发生了什么；比较词级是否高于事件。
4. 删套语、同页换称呼、装饰性形容词；删“得意句”前先判断它是否承担转折/揭示。
5. B 类型/浪漫/纯奇：允许华丽，但每处华丽必须服务事件/人物；否则降调。
6. C 人物口语/方言：只暗示、不记音；语域与人物教养/场景一致。

**可观察检查**

- 把这段改成平实句，事件是否受损？受损 → 可保留华丽；不受损 → 降调。
- 朗读时是否要回读才懂？要 → 断句/换词。
- 是否连续三句以上同一句式？是 → 变节奏，但不要为变化而变化。

**卡住时**：朗读仍拗口且改不动 → 标“风格问题”，不要继续在句层打转；回到结构/场景，确认是否在用华丽掩盖缺失的冲突。语域与人物不符 → 先写人物三行小传（处境/欲望/教养），再改台词，不直接“加方言”。

## 7. 定对话功能（FC-07、FC-16 + K-16）

**判断信号**

- 这段对话在做什么：推进冲突/揭示人物/传递必要信息/制造节奏？
- 是否只是“他们谈了谈”的替代品？
- 每句台词是否符合人物立心（此刻想要什么、怕什么）？
- 书面叙事：对话是否只在高潮/转折处承担主要功能？舞台/影视：对话是否承载情节且可听可说？

**动作**

1. 给每段对话标 `功能`；没有功能的删/并。
2. 把“信息说明”改成“利益冲突”：谁想从谁那里得到什么，谁不说。
3. 书面叙事：日常信息用叙述压缩；对话留给高潮/转折；全对话体是实验，须有强理由。
4. 舞台/影视/戏曲：对白承载情节与人物；一人一腔、可听可说；信息织入冲突。
5. 检查台词是否替作者解释主题；是 → 删或改成人物在压力下的选择（FC-16 A 分支）。

**可观察检查**

- 删掉这段对话，情节是否仍成立？成立 → 它可能只是装饰/信息，考虑压缩。
- 每句台词是否换个角色也能说？能 → 人物声音未成立。
- 对话是否在“互相解释观众已知的事”？是 → 改成对抗或删。

**卡住时**：对话只承担信息 → 改为概述，或造一个“谁想从谁那里得到什么”的冲突；造不出 → 这场可能不需要对话。台词换谁都能说 → 先写人物此刻的欲望/恐惧，再改台词；不要靠加口音解决。

## 8. 守类型承诺（FC-20）

**判断信号**

- 本场/本章是否兑现类型契约的 3–5 个必要特征？
- 读者承诺（答案/团圆/恐怖/知识/代入/惊叹）是否被推进？
- 有没有偏离？偏离是否有补偿？
- 是否把市场/审查约束误当技艺问题？

**动作**

1. 对照 `类型约定` 逐条勾：本场兑现了哪一条？没有 → 补一个 beat，或确认这场不属于该契约。
2. 若偏离：写 `偏离记录`（偏离/补偿/代价）。
3. 不把“类型”当借口：类型豁免也要内部逻辑（FC-13）。
4. 若本章是连载：检查章末是否兑现上一章承诺（FC-08 `兑现记录`）。

**可观察检查**

- 读者读完本场，是否得到该类型承诺的一点进展？没有 → 类型失约。
- 偏离是否有“更强的效果/人物/主题”作为补偿？没有 → 改回契约或删偏离。
- 是否用“文学”掩盖没写好？是 → 回到结构/场景检查。

**卡住时**：写不出 3 个必要特征 → 标“类型未定”，不拿类型规则验收；先写“读者最想得到什么”。必要特征与作者意图冲突 → 给两条路（遵守/有意偏离+补偿），不替作者选。

## 9. 收束场景/章末（FC-08）

**判断信号**

- 本场结束时，人物处境/认知/关系改变了什么？
- 留下什么可兑现的问题？
- 读者是否早已预判却被拖延？
- 下一场/下一章是否兑现本场的承诺？

**动作**

1. 写 `状态变化`（一句）。
2. 写 `未解的问题`（读者带走的未解）。
3. 做 `延迟检查`：是否已被预判却拖延？是 → 删拖延或补更强回报。
4. 长篇/连载：章末“暂解 + 钩子”；钩子进 `兑现记录`，标兑现章。
5. 短篇/单场：只检查总收束是否完成主导效果，不强行加钩子。

**可观察检查**

- 本场首末状态是否同一？同一 → 这场没有推进。
- 末句是否封死或留白墙？封死 → 下一场无入口；留白墙 → 读者不知道为什么还要读。
- 钩子下一章是否兑现？不兑现 → 删/改。

**卡住时**：状态未变 → 改末事件使状态改变；改不出 → 这场可删/并。钩子写不出 → 不用“突然出现一个人/一声枪响”硬造；改问“下一章最想知道什么”。

## 10. 开篇场景（FC-09）

**判断信号**

- 首段/首场是否交付：谁要紧、何时何地、什么调/类型、留下什么问题？
- 背景信息是否织进动作？
- 这个赛道适合晚入场/从头写/舞台动作/框架？
- 删掉第一段，是否仍能懂？

**动作**

1. 写 `开篇约定` 四职。
2. A 晚入场：从第一次不可逆的动作/对话切入；前史拆 1–3 处动作信息。
3. B 从头写：典型场合/典型一天，先给秩序再打破。
4. C 舞台：exposition 改成人物当下的利益冲突。
5. D 框架：先给“为什么现在讲”的压力。
6. 自检：删第一段是否仍能懂；若能懂，第一段可能只是装饰。

**卡住时**：四职写不全 → 只写“谁+何处+什么不对劲”三句；三句也写不出 → 素材还没有人物/处境，回规划。A 找不到动作 → 改 B 的典型场合，或写三个候选入口。

## 11. 起草循环（不要边写边改）

1. **只前进**：初稿不回改；遇到未定处用 `[?]` 标记，不停下来查资料/改前面。
2. **每场一卡**：写完一场，填 SP-01…SP-12；不写“以后再说”。
3. **当天不精修**：句层修改另开时段；初稿只保证“目标/阻力/转折”成立。
4. **卡壳**：回到场景卡；若四项缺，转规划；若四项齐全但写不动，换视角/换入场点/写概述版再展开。
5. **每章一检**：章末三查（FC-08）；不通过不加新钩子。

**可观察检查**：初稿里 `[?]` 是否超过每场 3 个？超过 → 场景准备不足，回场景卡。是否在同一场反复改句超过 15 分钟？是 → 违反“起草/修改分离”，停。

**卡住时**：写不动且场景卡完整 → 换入场点（从阻力方/从物件/从对话切入）写 200 字试探；仍写不动 → 这场可能不需要，删/并。整章写不动 → 回 `references/planning.md` 检查主行动/次线交汇。
