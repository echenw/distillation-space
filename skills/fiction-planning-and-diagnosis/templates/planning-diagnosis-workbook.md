# 输出模板

## 一、核验范围（每次必写）

- 请求用途与可用来源：
- 目标作品 / 版本 / 时间 / 地区：
- 实际访问的原始文件或网页 + **访问日期**：
- 不能访问的资料、授权情况与决定：
- 本次需要的说服/打动与可复核/可复制任务各是什么；可兼有，只有实际取舍相斥时进入C-2裁决：

## 二、逐条 Claim（每条独立记录；允许空值 / UNKNOWN）

| 字段 | 待填内容 |
|---|---|
| Claim ID + 原文定位 | C-001 / 原第 N 句 |
| 可检验的原子断言 | 单一对象、单一数值 / 事件 / 关系 |
| 类型 | 日期 / 统计 / 引文 / 归因 / 因果 / 版本归属 / 虚构设定 |
| 时间与版本 | 年月、地域、书或数据的版本；未知写 UNKNOWN |
| 支持来源及定位 | 作者或机构、名称、版本、链接或页行、实际访问状态 |
| 命中的核查动作 | 勾 R06–R19 中实际做过的编号 |
| 反证 / 限制 | 不同口径、依赖同源、对立原件或缺失 |
| **核查时点** | "已有/尚无/首创"类断言必填（R15）；其余写 N/A |
| **来源自陈的证据边界** | 来源自己声明的局限，原样抄；无则写"未声明" |
| 核验状态 | VERIFIED_FOR_SCOPE / SUPPORTED_WITH_LIMITS / CONTESTED / NOT_VERIFIABLE / CONTRADICTED / FICTIONAL_DESIGN |
| 判断说明 | 为什么是这个状态；不复制模型推测当事实 |
| 建议句 / 作者决定 | 有编辑权限才直接应用；否则为候选 |
| 下一次最小补证 | 去哪个源、查哪一版、哪一段；无需求写"无" |

## 三、整体摘要

- 已核条数 / 待核条数 / 阻断公开确定性断言的点。
- 可安全继续使用的材料，以及未执行的检查（例如"未实际打开链接 X"）。
- 命中最多的核查动作编号，提示本次材料的主要风险类型。
- 不用"全对 / 全错"替代逐条判断。

改完回查定位与相邻句；未判定的反证先保留条件句或报道式归因。
