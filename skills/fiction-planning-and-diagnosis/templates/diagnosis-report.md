# 诊断报告（diagnosis-report）

> 用途：一条症状一个 DR 块；先证据、再规则、再分支、再严重度/最小验证/建议。
> 规则见 FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；症状口径见 `references/diagnosis.md`。无文本 → 只填 DR-01/02/12 和取样清单，不填 DR-04…DR-11（取样清单并入 DR-12 或附在报告首行）；只有梗概 → 走 `references/diagnosis.md` §0 的梗概分支（DR-01…09、DR-12 照填，全表标“句段层未诊断”），与“无文本”是两种情形，不混用。

| 字段 ID | 字段 | 填写内容 | 状态 | 稿件证据位置 | 依据/说明 | 转出去向 |
|---|---|---|---|---|---|---|
| DR-01 | 诊断范围（全书/章节/场；不写“整体”） |  |  |  | 范围越具体，证据越可回读 | |
| DR-02 | 版本/稿本（标识/日期/字数） |  |  |  | 同一诊断只针对一个版本 | |
| DR-03 | 证据（位置 + 短引文 + 观察；结构性缺失写测试方法+结果） |  |  |  | 每条判断至少一处；不整段复制 | |
| DR-04 | 症状（S1–S9 名称，不自造术语） |  |  |  | 无主行动/中段塌/人物工具化/视角失守/开篇无契约/结尾欠账/巧合解结/类型失约/文体空泛 | |
| DR-05 | 对应规则（主规则 + 辅助规则） |  |  |  | 如 FC-07/08、FC-11、FC-13 | |
| DR-06 | 分支判断（A/B/C/D + 为什么选） |  |  |  | 不写“两者都重要” | |
| DR-07 | 严重度（阻断/重要/建议）+ 证据强度（强/中/弱） |  |  |  | 严重度≠证据强度；证据弱先做最小验证 | |

| DR-09 | 建议（定位 + 方向 + 可选最小改写 1–3 句） |  |  |  | 默认 L1；作者要改写时转修订，另起版本 | |
| DR-10 | 回归项（改后必须仍成立：主行动/视角/承诺/类型） |  |  |  | 先写回归，再改 | |
| DR-11 | 未决（需作者决定的价值/范围/类型/结局） |  |  |  | 不替作者决定 | |
| DR-12 | 证据缺口（没看到的章节/未验证的读者反应/未覆盖类型） |  |  |  | 标“未知/未覆盖”，不假装已看 | |
| DR-SUM | 结论摘要（3–5 句：最阻断 1–2 项 + 下一步 + 未决） |  |  |  | 不重复所有细节 | |

## 严重度口径

| 严重度 | 含义 | 处理 |
|---|---|---|
| 阻断 | 不改就无法继续写/读：主线不成立、视角合同大面积破裂、结尾承诺不兑现、巧合解结 | 先修；修完再谈句段 |
| 重要 | 影响体验/类型承诺，但故事仍成立：中段塌、人物工具化、开篇无契约、类型失约 | 这一稿就改 |
| 建议 | 局部/风格/剂量：个别句段、细节过多、语域小跳 | 可选；不阻塞交付 |

## 证据强度口径

| 强度 | 含义 | 处理 |
|---|---|---|
| 强 | 多处文本证据 + 结构测试失败（抽线后主线不变等） | 可下结论 |
| 中 | 一处文本证据 + 上下文/作者确认 | 可给重要/建议；阻断需谨慎 |
| 弱 | 只有读者感受/编辑直觉 | 标“待验证”，先做 DR-08 |

## 填写纪律

1. 一条症状一个块；不要把“中段塌 + 人物工具化 + 文体空泛”塞进一行。
2. DR-03 的位置要能回读（章/节/段/行）；结构性缺失写“测试方法 + 结果”。
3. DR-06 只选一个主分支；其他分支写“为什么不选”。
4. DR-07 的“阻断”要谨慎：证据弱时先做 DR-08，不直接判死。
5. DR-09 默认只到 L1（定位+建议+可选最小改写）；L3/L4 需明确授权。
6. DR-12 必须写：没看到的章节、没验证的读者反应、没覆盖的类型；没有缺口也要写“已覆盖范围”。
7. 每行的「状态」与「稿件证据位置」：状态按交付状态词填“已完成／未能核实／待作者决定”，允许填“未知”；“未知”是合法值，但不得把未知写成已完成。稿件证据位置是这一行状态的依据，只指用户当前稿件内的可核位置（如“第 5 章第 3 场”），没有就填“未知”；不指向任何来源编号或包外路径。
8. 报告末尾说明：这是基于文本的诊断，不替代作者的判断，也不预测读者反应。
