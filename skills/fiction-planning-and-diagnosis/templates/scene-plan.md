# 场景计划单

> 用途：起草前把一场戏的“目标/阻力/转折/功能”定死，避免写成解释或漂亮但无用的段落。
> 规则见FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；起草流程见 `references/drafting.md`。每场一卡；未定项写“未定/待补”。

| 字段 ID | 字段 | 填写内容 | 依据规则 | 写不出的出口 |
|---|---|---|---|---|
| SP-01 | 场号/章号/时间线 |  | FC-07 | 写不出 → 先定位它在主线/次线的位置 |
| SP-02 | 目标（这场谁想要什么，结束前必须拿到/阻止/掩盖什么） |  | FC-05、FC-07 | 写不出 → 回规划确认这场服务哪条线；或按主行动推一个目标，标“假设” |
| SP-03 | 阻力（谁/什么阻止；阻力自己的目标） |  | FC-05、FC-07 | 写不出 → 造对抗力量；造不出 → 降为概述 |
| SP-04 | 转折（结束时处境/认知/关系变了什么） |  | FC-07、FC-08 | 写不出 → 这场没有推进；删/并 |
| SP-05 | 功能（推进主行动/揭示人物/必要信息/时间感） |  | FC-06、FC-07 | 写不出 → 纯装饰，删 |
| SP-06 | 概述或场景（场景/概述/过渡） |  | FC-07 | 分不清 → 用“是否有人当场想要什么”判定 |
| SP-07 | 视角（谁看/能知道什么/不能知道什么/切换标记） |  | FC-11 | 写不出 → 先选一个 reflector，限制信息 |
| SP-08 | 信息增量（读者/人物各多知道什么；揭晓点） |  | FC-12 | 写不出 → 这场可能只是重复已知信息 |
| SP-09 | 文体要点（主导印象/细节 3–5/语域/句段风险） |  | FC-14、FC-15 | 写不出 → 先不写描写，回到 SP-02 |
| SP-10 | 对话功能（推进冲突/揭示人物/信息/节奏；谁想从谁那里得到什么） |  | FC-07、K-16 | 写不出 → 对话只承担信息，改概述或删 |
| SP-11 | 后文调用（本场埋的伏笔/承诺/意象，何时兑现） |  | FC-08、FC-10 | 写不出 → 标“无调用”；不要硬埋伏笔 |
| SP-12 | 处置（写/删/并/压/补；理由） |  | FC-07、FC-19 | 写不出 → 先不写；回到结构层 |

## 填写说明

1. **SP-02/03/04 是硬三角**：缺一项，这场不成立。不要用“气氛很好”替代转折。
2. **SP-05**：一场只承担一个主功能；可以顺带第二个，但不能“什么都想要”。
3. **SP-06**：关键对抗必须是场景；如果写成概述，问“为什么不敢演”。
4. **SP-07**：写清“能知道/不能知道”；切换要填 trigger/benefit/marker/cost（可附在卡后）。
5. **SP-08**：信息增量不是“读者知道了更多字”，而是“知道了一件会影响下一步的事”。
6. **SP-09**：主导印象一句；细节 3–5 个是默认，不是硬门；按视角过滤。
7. **SP-10**：每段对话标功能；没有功能的删/并；书面叙事对话留给高潮/转折。
8. **SP-11**：伏笔/承诺进 `兑现记录`；不兑现的钩子删。
9. **SP-12**：处置只有写/删/并/压/补；不要用“再想想”当处置。

## 起草前最低标准

- SP-02/03/04/05 齐全；
- SP-07 能回答“能知道/不能知道”；
- SP-08 至少一条“影响下一步”的信息；
- SP-10 每段对话有功能；
- SP-12 有明确处置。

缺 2 项以上 → 先补卡；作者要求直接写，就补假设并标“假设”，写完列出待确认项；怎么补都不成立，说明结构有问题，回规划。
