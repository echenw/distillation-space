# 小说规划单（novel-plan）

> 用途：把“赛道 → 胚故事 → 终点 → 入口 → 主线 → 单元 → 开篇 → 类型 → 视角 → 章末 → 判断权/风险”落成可回读的规划。
> 规则见FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；流程见 `references/planning.md`。本表只记录**决定与依据**，不写完整场景。
> 未定项写“未定/待补”，不要用套话填满；单来源参数（3/4、2–3 视角、3–5 细节、字数/章数）只作默认，不作硬门。

## 填写说明

1. **NP-01/02 先于一切**：没有赛道，不引用比例/字数/视角数量。
2. **NP-03**：短篇写 `效果`（一句情绪/问题）；长篇写 `主行动`（谁要什么/谁阻止/代价），可另写 `效果`。
3. **NP-04**：短篇 A 写终场画面；长篇 B 写终局状态；发现型 C 标“初稿后补”。
4. **NP-05**：只选一个主入口；其他入口可作辅助，但不要四个都写。
5. **NP-06**：每条线必须有 `功能` 与 `交汇点`；没有交汇的线不进入主线。
6. **NP-07**：关键对抗必须是场景；纯信息/纯装饰降为概述 或删。
7. **NP-08**：四职各一句；晚入场/从头写按赛道选，不按“高级/低级”。
8. **NP-09**：3–5 个必要特征是操作默认，不是类型定义；偏离必须写补偿。
9. **NP-10**：短篇默认一个 reflector；长篇 2–3 是默认，不是硬门；切换要记账。
10. **NP-11**：所有“读者会……”标为推断；不写“研究支持”。
11. **NP-12**：连载/长篇要“暂解 + 钩子”；短篇只要总收束；钩子进 `兑现记录`。
12. **NP-13**：价值/范围/类型/结局归作者；编辑只能给条件与代价；市场约束与技艺分栏。
13. **NP-14**：单来源参数只作默认；例外登记，不升格为新规则。

## 规划完成的最低标准

- 能用一句话说出 `主行动` 或 `效果`；
- 能说出终点（终场/终局状态/最后决定）；
- 每条次线有 `功能` + `交汇点`；
- 首段四职齐全；
- 类型契约有 3–5 个必要特征；
- 视角合同能回答“能知道/不能知道”；
- 章末策略能回答“状态变了什么/留下什么可兑现问题”。

缺 3 项以上 → 不进入起草；输出“规划未成立”清单。
