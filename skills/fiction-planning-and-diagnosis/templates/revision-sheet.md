# 修订单（revision-sheet）

> 用途：一次修订单只管一个范围/一个层级；先写回归项，再动稿。默认只到“定位+建议+可选最小改写”，不越权重写。
> 规则见FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；修订流程见 `references/revision.md`。未授权项写“未授权”，不要先改后问。

| 字段 ID | 字段 | 填写内容 | 依据/说明 |
|---|---|---|---|
| RV-01 | 修订目标（要解决的具体问题，不写“改好一点”） |  | 对应诊断 DR-04/DR-05；一单一个主目标 |
| RV-02 | 范围/版本（全书/章/场；v1→v2；已发布/未发布） |  | 已发布章不回改；只做后续补偿 |
| RV-03 | 证据定位（章/节/段/行 + 短引文 + 问题） |  | 每条改动可回读；不整段复制 |
| RV-04 | 修订层级（结构/场景/句段/校对） |  | 先结构→场景→句段→校对；不跳层 |
| RV-05 | 删减对象类别（事件/场景、句/词、解释、人物/支线） |  | FC-19 四类；一类一行 |
| RV-06 | 承重段（不能删的唯一因/关键转折/类型承诺） |  | 先标承重，再谈删；唯一因不能删 |
| RV-07 | 处置（删/压/并/留；补/移） |  | 四选一；不用“改写得更好”代替删除 |
| RV-08 | 最小过渡（删/并后需要的 1–2 句桥；谁交代/用什么动作） |  | 过渡必须携带新信息；不写说明块 |
| RV-09 | 改写级别（L0 定位/L1 建议/L2 最小改写/L3 整场/L4 结构重排） |  | 默认 L1；L3/L4 需明确授权 |
| RV-10 | 回归项（改后必须仍成立：主行动/人物/视角/承诺/类型/文体） |  | 先写回归，再改；逐项勾 |
| RV-11 | 版本记录（v1→v2；改了什么/为什么；rollback_point） |  | 单稿留痕；每版至少一个回退点 |
| RV-12 | 未决/授权（需作者决定的价值/范围/结局；授权级别） |  | 未授权 → 只出方案，不动正文 |

---

## 改写级别

| 级别 | 交付 | 何时使用 |
|---|---|---|
| L0 定位 | 指出位置/症状/证据，不改字 | 诊断、作者自己改 |
| L1 建议 | 定位 + 方向 + 可选方案 | 默认 |
| L2 最小改写 | 1–3 句示范，标“可选” | 作者要求举例/句段问题 |
| L3 整场重写 | 重写一场，保留原场对照 | 明确授权 + 结构/场景已定 |
| L4 结构重排 | 新大纲/章序/线表，不直接写全文 | 明确授权 + 先出方案 |

## 删减四类对象

| 类别 | 例子 | 先问 | 处置 |
|---|---|---|---|
| 事件/场景 | 整场追逐、整章支线、重复危机 | 改变主行动？唯一因？ | 删/并/压/留 |
| 句子/词 | 套语、重复解释、装饰形容词 | 删后意思缺？服务节奏？ | 删/压 |
| 解释/点题 | 作者总结、人物口播主题、背景说明块 | 有第二载体？删后行动成立？ | 删/压/改动作 |
| 人物/支线 | 功能人物、无交汇次线、重复对照 | 删后主线变？唯一信息？ | 删/并/降背景 |

## 回归 6 项（填入 RV-10）

1. 主行动仍清楚（一句话复述 + 抽线测试）。
2. 人物仍可信（三决定 + 删人测试）。
3. 视角合同未破（知识审计 + 切换账本）。
4. 承诺已兑现（`兑现记录` 逐条勾）。
5. 类型契约仍成立（3–5 必要特征 + 偏离补偿）。
6. 文体底线（朗读 + 主谓抽样）。

## 填写纪律

1. 一单一个主目标；不要把“结构重排 + 句段润色 + 校对”混在一单。
2. 先填 RV-06 承重段，再填 RV-07 处置；承重未标，不删。
3. RV-08 过渡只补删/并造成的断裂；不要用过渡掩盖删错。
4. RV-09 与授权匹配；默认 L1，不擅自 L3/L4。
5. RV-10 在动稿前写；改完逐项勾，失败回退 `回退点`。
6. RV-11 记录“改了什么/为什么/回归结果”；修订次数不是质量指标。
7. 末尾说明：修订的效果要靠回读和试读检验；“改得多”不等于“改得好”。
