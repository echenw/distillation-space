# 两个 DESIGN_EXAMPLE

> **DESIGN_EXAMPLE — 非真实任务，未运行验证。**
>
> 下面两例是用本 Skill 的规则做的**设计示例**，不是真实用户稿件，也没有做读者测试；效果未经验证。示例中的草稿、人物、历史细节均为虚构，只用于演示诊断步骤。

---

## 例 A：景物描写过多、人物没有目标

**标记：DESIGN_EXAMPLE A。**

### A.1 输入（虚构草稿，约 300 字）

> 海崖上的风从早吹到晚。灰色的云压得很低，海面像一块铅。海鸥在崖壁间盘旋，叫声清亮而短促。灯塔立在远处，白色的塔身被盐雾咬出斑驳的痕迹。潮水退去，露出黑色的礁石，礁石上挂着海草，像湿漉漉的头发。阳光偶尔从云缝里漏下来，把海面照成一片碎银。
>
> Mira 沿着崖边的小路走。她把手插在外套口袋里，摸到一把钥匙。她想起母亲。母亲以前也在这条路上走。路边的野草长得很高，风吹过来，草叶擦过她的裤脚。她停下来，看了一会儿海。
>
> 小镇的广场上，Lena 在咖啡馆门口等她。两人拥抱，说了几句天气。Lena 说，房子的事不急。Mira 说，嗯。她们又看了一会儿海。

### A.2 G0：先写契约

```
读者契约：本书提供一个女人回到海边小镇卖母亲房子的家庭冲突（卖/留、记忆/钱）
不提供一篇没有决定的海边游记。
艺术标准：以人物选择与场景压力为完成度标准，不以景物描写数量为标准。
```

诊断限于所给片段：海边氛围已展开，卖/留目标及 Lena 的利益尚未明示。本例为尽早进入家庭决定而选择强化这部分；这不证明后文也没有冲突，更不把安静开篇视为自动失败。下表的删减、句数和新增情节均是这一改写方案的设计选择。

### A.3 F03：人性兴趣审计

| 段落 | 谁在看 | 如何压迫/帮助人物 | 处置 |
|---|---|---|---|
| 海崖/云/海面 | Mira | 无；只是背景 | 压缩成 1–2 句，绑到「她不想回来」 |
| 海鸥 | 无 | 无 | 删 |
| 灯塔/盐雾 | Mira | 可作「房子也被盐雾咬坏」的维修压力 | 保留 1 句，绑到卖房理由 |
| 礁石/海草 | 无 | 无 | 删或移到后文作 relief |
| 阳光/碎银 | 无 | 无 | 删 |
| 钥匙 | Mira | 直接绑到「母亲的房子」 | 保留并提前 |
| 野草/裤脚 | Mira | 可作身体记忆 | 保留 1 句 |
| 广场/咖啡馆 | Mira/Lena | 可作冲突场景 | 改写为「买家来信」场景 |

### A.4 F06：场面表（当前 vs 修改）

| 项 | 当前 | 修改后 |
|---|---|---|
| 地点 | 海崖、广场 | 母亲房子的厨房（有海景窗） |
| 在场者 | Mira、Lena | Mira、Lena、买家的信 |
| 目标 | 无 | Mira 想尽快卖；Lena 想留 |
| 转折 | 无 | 信里说母亲生前答应把房子留给 Lena |
| 章末问题 | 无 | Mira 还会卖吗？她为什么没被告知？ |

### A.5 F05：人物三场景测试

| 人物 | 葬礼 | 借钱 | 被误解 | 预测是否成立 |
|---|---|---|---|---|
| Mira | 安排流程、不哭、躲开亲戚 | 先替人垫钱，再后悔 | 不解释，直接走开 | 设计假设可用：本设计假设中以回避动作和办事呈现；不是临床分类 |
| Lena | 哭、抓着人说话 | 开口借，觉得理所当然 | 当场反驳，翻旧账 | 设计假设可用：本设计假设中直接表达冲突 |
| 买家 | 不参加 | 按合同办事 | 出示文件 | 设计假设可用：功能型，但有一句自己的话 |

上述反应是补写的设计假设，用来比较人物可能的选择；模型能填表不证明原稿人物已成立。还需回查正文是否准备了这些反应。买家可以维持功能角色；若其声音对本场关系有用，再补一句有辨识度的话。

### A.6 F07：场景删除清单

| 场景/段落 | 功能 | 处置 |
|---|---|---|
| 海崖全景（约 100 字） | 氛围 | 压缩为 2 句，绑到「她不想回来」 |
| 海鸥/礁石/阳光 | 氛围 | 删；留 1 个细节作后文 relief |
| 钥匙 | illustrate | 提前到第 1 段 |
| 广场拥抱/天气 | relief | 改写为「买家来信」冲突 |
| 咖啡馆对话 | illustrate | 保留，但让 Lena 说出「你从来不管」 |

### A.7 输出：修改清单

1. **在本例选定的早段位置（150字只是方案数字）**给 Mira 一个目标：她约了买家，今天要签字。
2. 把海崖全景压成 2 句，绑到「她不想回来」；删海鸥/礁石/阳光。
3. 把「钥匙」提前；它是母亲房子的物证。
4. 把咖啡馆改成厨房：买家来信 → Lena 说母亲答应过她 → Mira 沉默。
5. 章末给新问题：「她还会卖吗？她为什么没被告知？」
6. 保留 1 段海景作 relief，放在冲突之后，也可试验放在开头并比较节奏。
7. 若本场需要买家的独特立场，可补一句有辨识度的话；只承担交易功能时无需为免于“功能人物”而扩写。

### A.8 风险

- **过度纠偏**：全删景物会变成事件骨架，失去海边小镇的氛围。保留 1 段 relief，且让它服务人物（房子被盐雾咬坏 = 维修压力）。
- **把 Lena 变成 plot device**：她需要自己的欲求（留下房子/留住姐姐），不只是「阻止卖房」。
- **契约可能不同**：如果作者真正想写的是「一个地方的诗意肖像」，那契约应写明；此时 F03/F07 要按 world-primary/氛围小说重定义（E7），不能机械删景。
- **不能自动判定**：读者是否被海景打动、Mira 是否「可爱」、修改后是否更好——这些需要读者测试，示例不声称已验证。

## 例 B：历史小说，但作者完全不想查资料

**标记：DESIGN_EXAMPLE B。**

### B.1 输入（虚构对话）

> 作者：「我要写 12 世纪围城。我不想查资料，反正读者也不知道。人物和情节好看就行。」

### B.2 第一步：fact contract（F10）

| 选项 | 含义 | 对作者的要求 | 适用 |
|---|---|---|---|
| A documentary | 尽量准确 | 关键事实/制度/物质细节要研究；错误要改 | 以历史真实为卖点 |
| B alternate | 明确改写 | 写清改了什么、为什么；内部自洽 | 架空历史/历史奇幻 |
| C invented | 内部自洽 | 不承诺史实；人物反应仍可信 | 二次世界/寓言 |

选择A时，承重现实断言仍需可核依据；可以利用已有可靠材料而非强制新增所有研究活动；「读者不知道」不是契约。

### B.3 第二步：经验/借用边界表

| 细节 | 类型 | 是否关键因果 | 处置 |
|---|---|---|---|
| 围城的水/食物能撑多久 | 物质/制度 | 是（决定投降时间） | 查与水粮因果相称的可靠资料，或把该对象改为明确架空设定（如魔法水井）并记录影响；不迫使全书统一改契约 C |
| 城墙为什么倒 | 军事/工程 | 是 | 必须研究，或改成明确的 alternate 设定 |
| 谁有权决定投降 | 法律/封建制度 | 是 | 必须研究；不能用现代「市长决定」替代 |
| 伤口感染/医疗 | 物质 | 可能是 | 选择适合该历史问题的可靠来源，不强制只用一手材料；不能靠影视常识 |
| 服装剪裁/颜色 | 物质 | 通常否 | 可借、可简略；标来源；不要整段贴 |
| 歌曲/谚语 | 文化 | 通常否 | 可借；注意时代错置 |
| 主角的家族秘密 | 纯发明 | 是（人物驱动） | 可发明；但反应要可信 |
| 一个虚构的私生兄弟 | 纯发明 | 是 | 可发明；但要符合继承/法律规则，否则关键因果错 |

### B.4 第三步：按承重问题选择研究渠道（H）

如果作者选 A，先列水粮、城墙、投降权限和继承制度中尚未解决的具体问题，再从下列渠道选取足够且相关的证据。它们是可组合的本例方案，不是三本书加一次访谈的最低配额；已有可靠材料能回答的问题无需为凑数重复研究。

1. 需要日常制度背景时，可查该时期的社会史或日常生活史，定位衣食住行、法律、军事的相关章节。
2. 需要围城时间线与权力结构时，可查该地区/战争的可靠通史，并与本案年代、地点核对。
3. 需要原始措辞、具体制度或相应证据时，选读编年史、书信或法令的相关段落；不一律以一手材料替代可靠研究。
4. 书面材料仍有关键缺口且具备合适渠道时，可访谈研究者或博物馆教育员，围绕未决疑问提问并记录出处。30–60 分钟只是可选安排，访谈不是继续写作的门槛。
5. 把研究结果写成**承重事实及其证据/可简略的背景/尚待核查项**；对未决处可标记或改用不依赖该事实的写法，继续其余正文。

### B.5 第四步：作者裁决

| 选项 | 作者要做什么 | Skill 做什么 |
|---|---|---|
| 继续 documentary | 按具体承重疑问取得相应证据；已有材料足够时不新增配额 | 帮建事实契约/清单；按已授权研究范围查证，未决项局部标记 |
| 对相应对象采用 alternate/invented | 明示偏离或发明的对象及其影响；可与其他对象的 documentary 契约并存 | 帮标改动与内部依赖；人物反应按本项目 F11 契约检查 |
| 暂停或换题材 | 不写历史小说，或换题材 | 退出；不伪造研究 |

### B.6 输出：边界表 + 风险

**输出**：

```
事实契约：按 B.2 的 documentary / alternate / invented 给各承重对象标注；可按对象混合
必须准确：围城水粮、城墙倒塌原因、投降决定权、继承法
可以简略：服装剪裁、歌曲、家具、天气
纯发明：主角家族秘密、私生兄弟（需符合继承法）
研究来源：与承重问题相称的书面来源；访谈可选；标来源；不整段贴
```

**风险**：

- 「读者不知道」不能代替已承诺的真实性。承重错误可能破坏信任或使情节因果不成立；本例没有测量真实读者反应，不宣称所有读者都会作同一判断。
- 「人性古今相似」只支持**反应**可理解，不支持**制度**可以乱写；封建继承/法律/军事后勤不能靠现代常识替代。
- 如果作者既拒绝为 documentary 承重断言取得依据，也不愿标明偏离或发明 → 触发 **E4（经验缺口）** 或 **E5（契约未决）**；对实质缺口保持待核，继续不依赖该事实的可写部分。
- 对已明确采用 alternate 或 invented 的对象，历史细节可以改，但**内部一致性**和**人物反应是否需要可理解**仍按该项目契约检查（F10/F11）。

## 两个示例的共同说明

- 两例都只演示**诊断与修改清单**，不声称改后更好。可先核查文本是否落实所选目标；若主张目标读者反应或改写收益，还需相应验证（N1/N10）。
- 两例都没有使用自动评分/自动改稿；本 Skill 没有 scripts。
- 两例都刻意保留了「风险」与「退出」：诊断不是命令，作者可以选择不同契约。
- 效果未经真实任务验证。
