# 研究与读者反馈案例（自建示例）

返回 [SKILL.md](../SKILL.md)。以下情境均为自建示例，用于展示如何拆分事实、推断和读者反应；不对应真实作品、作者或调查。

## Case A · 两个日期指向不同事件

草稿写一座公共建筑于 1912 年开放。一个记录写 1911 年举行揭幕仪式，另一个记录写 1912 年开始对公众开放。

**核查：** 先区分揭幕仪式和正式开放。若正文只需要年份，选择与叙述事件对应的年份；若需要精确日期，说明两条记录描述的不是同一事件。不要把日期差异直接当成记录互相矛盾。

## Case B · 读者测试发现因果桥缺失

三名试读者都理解人物离开车站，却无法判断下一场为什么直接发生在医院。三条反馈指向同一个因果空档。

**核查：** 这不是读者是否喜欢题材的问题。文本缺少人物如何到达医院、为何选择那里或谁通知了他们的桥接信息。补最小必要动作，再用同一段落复测。

## Case C · 小样本问卷被误当成普遍偏好

作者在一个兴趣社群发出短问卷，多数答题者偏好快速开篇，于是作者准备让每章都从动作场景开始。

**核查：** 样本是自选的，且来自同一社群。结果最多描述这组答题者的偏好，不能证明所有目标读者都喜欢相同开篇。应分别测试理解、兴趣和持续阅读，不把一个指标替代另一个。

## Case D · 原型真实，情节仍然虚构

作者说明主角的职业参考了一位真实从业者，但人物的家庭、关键决定和最终结局均为虚构。

**核查：** 把“职业原型是否真实”和“故事事件是否真实”拆开。前者可以核对公开职业资料；后者属于虚构设计，不要因为原型存在就把整段剧情标成真实事件。
