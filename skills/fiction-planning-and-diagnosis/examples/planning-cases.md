# 设计示例（编写的示范）

> 本文件是 **设计示例**，不是真实客户稿、不是真实运行记录，也不证明任何效果。人物、情节、字数均为演示用虚构数据。
> 每个示例按“输入 → 分支判断 → 输出 → 卡住时”走一遍，用来展示如何把 FC 规则的条件与模板字段落地；不是“标准答案”。
> 示例中出现的“建议/可选改写”均为 L1–L2 级别；没有授权不做整章重写。

---

## 示范 1：规划短篇

### 输入

- 6,000 词文学悬疑，单主角，杂志一次读完；编辑要“紧、冷、最后一句有余味”。
- 素材：一名夜班护士发现病人床头柜的锁被撬过；病人昏迷；抽屉里有一封写给护士本人的信。
- 作者最先想到的是“那封信被打开的一刻”（终局画面），不是人物小传。
- 类型承诺：悬疑 + 文学余味；不是侦探解谜，不需要警察破案。

### 分支判断

| 判断 | 选择 | 依据 |
|---|---|---|
| 赛道 | A 短篇/单线/一次读完；medium=印刷；genre=文学悬疑；delivery=一次读完 | FC-01 A |
| 单一效果 | A 适用：≤10,000 词、单线、单一主导情绪（“她是否敢知道真相”） | FC-03 A |
| 终点 | A：终场画面 = 她拆信/不拆信的那一只手；末句方向 = 她把信放回抽屉还是带走 | FC-04 A |
| 入口 | C 终局入口：信必须被打开/被处理 | FC-05 C |
| 主线 | A 单主线：护士要决定是否读信；阻力 = 病人可能醒来/医院规矩/她自己的恐惧 | FC-06 A |
| 开篇 | A 晚入场：从她发现锁被撬的动作切入 | FC-09 A |
| 结尾 | A 闭合型 + 余味：信的内容给出一个答案，但最后一句留下一个物象 | FC-10 A/C 混合需明确主契约：先闭合，再余味 |
| 视角 | A 单 reflector（护士） | FC-11 A |

### 输出（填入 `templates/novel-plan.md` 的字段）

- **NP-01 赛道**：`篇幅=6,000 词；媒介=印刷杂志；类型=文学悬疑；交付方式=一次读完；读者承诺=“紧 + 冷 + 最后一句余味”`。
- **NP-02 篇幅**：6,000 词，单线，3 场主戏 + 2 段过渡；不设章。
- **NP-03 单一效果/主行动**：`效果=读者读完不敢立刻判断护士是勇敢还是自欺`；`主行动=护士要决定是否读一封写给自己的信，代价是可能失去工作/自我形象`。
- **NP-04 终点**：`终场=她坐在值班室，拆开信，只读到第一行，手停住`；`末行方向=把信折回/放进抽屉，动作代替结论`；`潜伏意象=开头被撬的锁`。
- **NP-05 入口**：`入口类型=C 终局`；`入口证据=作者先想到“拆信的一刻”`；双向校验：`情节逼人物=是`（读信逼她面对自己过去的选择），`人物促成转折=是`（她选择不报警/不交信，改变后果）。
- **NP-06 各线**：单线；次线只有“病人女儿来探视”作为对照，功能=提供另一种真相版本，交汇=在第二场门口相遇，交换“谁在撒谎”的信息。
- **NP-07 结构单元**：场1 发现锁（场景）；场2 女儿探视（场景）；过渡1 夜班日常（过渡，带“医院广播/手部消毒”的新信息）；场3 拆信（场景）；结尾一段（概述/余味）。
- **NP-08 开篇契约**：who=夜班护士；where-when=凌晨两点、ICU 值班室；tone-type=冷、近距离、悬疑；question=“信里是什么，她为什么不敢看”。
- **NP-09 类型契约**：3 个必要特征=①一个具体秘密；②读者比护士晚知道；③结尾给出一个答案但保留余味；可偏离=不设侦探/不解释全部动机；补偿=用护士的选择替代破案。
- **NP-10 视角合同**：单 reflector 护士；能知道=她看到的/听到的/自己想的；不能知道=病人昏迷中的内心、女儿在走廊外的电话；不切换。
- **NP-11 信息差**：`知识表`：读者=不知道信的内容；护士=知道信封笔迹但不敢确认；女儿=知道一部分；`悬念方式=A 悬疑`；`揭示点=场3 拆信读第一行`。
- **NP-12 章末策略**：无章；场末三查：场1 状态变（锁被撬→她开始怀疑）；场2 状态变（女儿说出一个名字→她确认信与自己有关）；场3 状态变（读/不读的选择做出）。
- **NP-13 判断权**：信的内容/护士是否读，归作者；编辑只能要求“紧/冷/余味”，不能替作者定道德结论。
- **NP-14 风险**：单来源参数“3 场主戏”是操作默认，不是硬门；若 6,000 词容不下，压场2 为 概述；若结尾余味不清，改闭合型（读信后给明确答案），不硬加开放。

### 卡住时

- 若作者说不出“信里是什么” → 不要写场3；先写“信的第一行”三种版本，选一个能改变护士选择的。
- 若终场画面写不出 → 改问“最后一个不可逆的动作是什么”；仍写不出 → 退回 FC-02 重写 `胚故事`。
- 若作者既想要闭合又想要开放 → 先定主契约（闭合），余味只放在最后一句物象；不把“开放”当免检。

## 示范 2：规划双线长篇

### 输入

- 120,000 词，双时间线：1976 年的母亲线 / 2024 年的女儿线；家族秘密；商业历史小说；单本完结，非连载。
- 素材：母亲线先出现“一张缝纫纸样被烧掉”的画面；女儿线先出现“她回到老屋，发现同一张纸样的复印件”。
- 作者想写“两代女性如何被同一个秘密塑造”；编辑要求“两条线必须交汇，不能各写各的”。
- 类型承诺：家族秘密 + 历史质感 + 情感落点；不是悬疑破案。

### 分支判断

| 判断 | 选择 | 依据 |
|---|---|---|
| 赛道 | B 长篇/多线/单本；medium=印刷；genre=商业历史；delivery=一次读完 | FC-01 B |
| 整体统一 | B：主行动统一 + 母题（缝纫纸样/针脚）统一；不要求单一效果 | FC-03 B |
| 终点 | B：`终局状态=女儿选择公开/不公开秘密，母亲线的纸样被重新缝成一件东西` | FC-04 B |
| 入口 | A 人物入口（女儿想知道母亲为什么烧纸样）；母亲线用 B 情境入口（1976 年的工厂/婚姻困境逼她选择） | FC-05 A/B 分线使用 |
| 主线 | B 双线交织：女儿线=寻找真相；母亲线=掩盖真相；交汇=三次（纸样、名字、老屋） | FC-06 B |
| 开篇 | A 晚入场（女儿回老屋发现复印件）；母亲线第一章用 B 典型一天（工厂午休/缝纫机） | FC-09 A/B 分线 |
| 结尾 | A 闭合型（秘密被解释）+ 母题回收（纸样变成一件衣服） | FC-10 A |
| 视角 | B 两个 reflector：女儿/母亲；每次切换有章节标记 | FC-11 B |
| 信息差 | D 分层：读者知道母亲线的一部分，女儿不知道；母亲线内部有读者也不知道的秘密 | FC-12 D |
| 类型契约 | 3 个必要特征=①双时间线的因果交换；②历史细节服务人物选择；③情感落点；补偿=不靠悬疑反转 | FC-20 A/B |

### 输出（填入 `templates/novel-plan.md` 的字段）

- **NP-01 赛道**：`篇幅=120,000 词/约 40 章；媒介=印刷；类型=商业历史/家族秘密；交付方式=一次读完；读者承诺=“两代人的秘密如何改变她们的选择”`。
- **NP-02 篇幅**：40 章，双线各约 20 章；每 8–10 章一个弧；3 个交汇点。
- **NP-03 单一效果/主行动**：`主行动=女儿要弄清母亲为什么烧掉纸样；母亲要保住秘密/保住女儿；失败代价=失去彼此`；`主次=女儿线主导（寻找）、母亲线支撑（掩盖）、工厂群像对照`；`母题=缝纫纸样/针脚`。
- **NP-04 终点**：`终局状态=女儿知道秘密后选择不公开，但把纸样缝成一件衣服；母亲线最后一场把烧纸样的手停住`；`关键转折=①女儿发现复印件；②母亲线揭示纸样对应的人；③两线在同一老屋相遇`；`潜伏意象=第一章被烧的纸样边角`。
- **NP-05 入口**：`入口类型=A（女儿）/B（母亲）`；`入口证据=女儿先出现“回老屋”的动作；母亲先出现“工厂午休”的处境`；双向校验：女儿线 `情节逼人物=是`（真相逼她重新选择与母亲的关系）；母亲线 `人物促成转折=是`（她烧纸样的决定造成女儿线的缺失）。
- **NP-06 各线**：两条主线；次线=工厂女工群像（功能=对照/提供时代信息；交汇=母亲线第二次交汇；无独立收束）；`主汇合=约 3/4 处（老屋），前段蓄因、后段收果`——3/4 只作默认参考，不硬卡。
- **NP-07 结构单元**：每章 1–2 场；1976 线多用场景（工厂/厨房/缝纫机）；2024 线多用场景 + 必要 概述（调查/车程）；两线之间用 分章，不用同一章内切换。
- **NP-08 开篇契约**：第一章 who=女儿；where-when=2024 年老屋；tone-type=潮湿、旧物、克制的悬疑；question=“复印件为什么和母亲烧掉的一样”。第二章 who=母亲；where-when=1976 年工厂午休；tone-type=噪音、汗、规矩；question=“她为什么要烧掉纸样”。
- **NP-09 类型契约**：3 个必要特征=①双线因果交换（不是平行散文）；②历史细节服务人物选择（不是背景展览）；③情感落点（不是破案）；可偏离=不设反派/不设大反转；补偿=用两代人的选择对照替代悬疑爆点；`市场约束=单本 12 万字、结局需情感闭合（商业历史读者）；不写审查/平台禁忌未知`。
- **NP-10 视角合同**：两个 reflector：女儿（2024）、母亲（1976）；每章只进一个意识；切换用章节标题/年份标记；不进入对方内心，除非有书信/录音作为载体；`切换账本`：每次切换 trigger=时间线需要、benefit=两代对照、marker=年份章题、cost=读者重新定向。
- **NP-11 信息差**：`知识表`：读者=知道母亲线的一部分、不知道纸样对应的人；女儿=知道复印件、不知道母亲为什么烧；母亲=知道全部但不说；`悬念方式=D 分层`；`揭示点=第 12 章（纸样对应的人）、第 28 章（母亲烧纸样的原因）、第 36 章（女儿选择）`。
- **NP-12 章末策略**：每章末三查；1976 线章末多为“暂解 + 新问题”；2024 线章末多为“发现 + 代价”；两线交汇章末必须改变主行动；钩子进 `兑现记录`，下一章兑现。
- **NP-13 判断权**：母亲是否值得同情/女儿是否公开秘密，归作者；编辑可要求“两线必须交汇”，不能替作者定道德判断；历史细节的取舍归作者，但需标“查证/未查证”。
- **NP-14 风险**：双线各写各的（无因果交换）→ 最大风险；母亲线历史细节过多→ 压成 概述；3/4 汇聚是默认参考，若两线在 2/3 处交汇更强，可改；12 万字可能容不下工厂群像→ 群像降为背景。

### 卡住时

- 若两条线找不到 3 个交汇点 → 不要写 40 章；先做“交汇表”，少于 2 个 → 改单线或合并母亲/女儿为一个人。
- 若 `终局状态` 写不出 → 写“最后谁必须做一个什么决定”；仍写不出 → 标“终点未定”，先写 3 个里程碑转折。
- 若 12 万字目标与双线不匹配 → 给三个方案：压成 9 万字单线、扩成 15 万字双线、改成两本；不硬塞。
- 若作者拒绝让两线交汇 → 明确告知“这不是双线结构，是两篇中篇拼合”；不冒充完成。

## 示范 3：诊断“中段塌 + 人物工具化”

### 输入

- 90,000 词侦探长篇，已写完；第 12–19 章读者反馈“看不下去”；助手角色只在需要时出现，递线索；前 11 章节奏紧。
- 作者说：“第 12–19 章我加了三个新嫌疑人，想让中段更热闹，但越写越散。”
- 文本样本：第 13 章整章是主角与助手在咖啡馆“梳理线索”；第 16 章切换到助手视角，只为了展示他偷听到的一句话；第 19 章末尾主角“突然想到”凶手是谁。

### 分支判断

| 症状 | 证据 | 主规则 | 分支 | 严重度 |
|---|---|---|---|---|
| 中段塌 | 第 13 章全概述；第 12–19 章主角处境未变；三个新嫌疑人无交汇 | FC-07/08、FC-06 | A 场景不足 + C 次线无交汇 | 阻断 |
| 人物工具化 | 助手只在递线索；删掉他，主线几乎不变；第 16 章切换只买回一条信息 | FC-05、FC-11 | A 功能人物 + C 视角工具 | 重要（若主角依赖他破案则阻断） |
| 结尾巧合 | 第 19 章“突然想到”无前文因 | FC-13 | A 写实/侦探，巧合在解结 | 阻断 |

### 输出（填入 `templates/diagnosis-report.md` 的字段）

- **DR-01 范围**：全书 90,000 词，重点第 12–19 章；前 11 章/第 20 章后只作对照。
- **DR-02 版本**：`draft-v3`，日期/字数由作者提供；本示例不伪造。
- **DR-03 证据**：
  - 第 13 章：整章为“他们谈了谈”，无当场对抗；主角目标仍是“查清凶手”，状态未变。
  - 第 16 章：视角切到助手，只展示他偷听到一句话；切换前无场景/章节标记；切换收益=一条信息。
  - 第 19 章：主角“突然想到”凶手；前文无对应铺垫。
- **DR-04 症状**：S2 中段塌；S3 人物工具化；S7 巧合解结。
- **DR-05 对应规则**：FC-07、FC-08、FC-06；FC-05、FC-11；FC-13。
- **DR-06 分支**：
  - S2：A 场景不足（第 13 章该演成对抗）+ C 次线无交汇（三个新嫌疑人没有改变主线条件）。
  - S3：A 功能人物（助手只递线索）+ C 视角工具（第 16 章切换只买信息）。
  - S7：A 写实/侦探，巧合在解结。
- **DR-07 严重度**：中段塌=阻断；人物工具化=重要（若助手是破案唯一通道则阻断）；巧合解结=阻断。证据强度：中段塌=强（多处文本+状态未变）；工具化=中（文本+删人测试）；巧合=强（位置+无铺垫）。
- **DR-08 最小验证**：
  1. 做第 12–19 章 `单元表`：标场景/概述；若是概述 ≥ 一半 → 中段塌成立。
  2. 做 `单元收束表`：每章末 state_changed；连续 3 章“未变” → 成立。
  3. 三决定测试：助手能否说出三处“只有他会这样”的决定？不能 → 工具化风险高。
  4. 切换账本：第 16 章填 trigger/benefit/marker/cost；缺 marker/benefit → 视角工具。
  5. 巧合位置：第 19 章“突然想到”标解结；删掉它，危机是否仍能由前文解决？不能 → 巧合解结成立。
- **DR-09 建议**（L1，不重写）：
  - 第 13 章：改成一场“主角逼助手交出他隐瞒的线索”的对抗（目标/阻力/转折），把“梳理线索”变成“谁在撒谎”。
  - 第 16 章：改回主角视角，让助手在场上说出/隐瞒；若必须保留助手视角，加章节标记，并给他一个“偷听会害到谁”的代价。
  - 三个新嫌疑人：每人写“他改变了主线的哪个条件”；写不出 → 删/并/降背景。
  - 第 19 章：把“突然想到”改成前文两处可回读的因（助手隐瞒 + 嫌疑人时间线矛盾）；补一场主角验证的戏。
- **DR-10 回归项**：主行动仍清楚；助手若保留，必须有独立欲望；第 16 章切换有 marker/benefit/cost；第 19 章的解结有前文因；侦探类型契约（谜面/机关/解释）仍成立。
- **DR-11 未决**：助手是否保留/合并为主角的一部分？三个新嫌疑人是否删到只剩一个？第 19 章是否改成“主角设局验证”而非“想到”？这些归作者。
- **DR-12 证据缺口**：未读第 1–11 章全文（只作对照）；没有读者样本；没有作者对助手功能的意图说明；类型契约（本格/社会派）未确认。

### 卡住时

- 作者拒绝删三个新嫌疑人 → 要求每个写“改变主线条件”；写不出 → 降背景，不进入主线。
- 作者坚持助手只递线索 → 明确“这是功能人物，不是角色”；可保留但不得给他独立视角/弧线。
- 作者不愿改第 19 章 → 标“巧合解结”为阻断，说明类型承诺受损；不替作者改结局。
- 无法确认类型契约 → 先问“本格/社会派/硬汉”，再定解结标准；不混判。

## 示范 4：修订超长连载

### 输入

- 400,000 词，120 章，周更连载；前 80 章已发布，后 40 章未发布；目标压到 300,000 词；读者反馈“中段重复、支线太多、主角升级感变弱”。
- 作者要求：“不要改已发布章节；不能断更；不能删掉主角的关键升级/感情线；每章末还要有钩子。”
- 类型：升级流 + 群像 + 感情线；平台契约未明。**该类型超出 28 本证据覆盖，本示例只演示删减/回归流程，不证明类型规则。**

### 分支判断

| 判断 | 选择 | 依据 |
|---|---|---|
| 删减对象 | 四类：重复解释（句子、解释）、无交汇支线（人物、事件）、重复危机（事件）、可并章（场景） | FC-19 |
| 修订层级 | 结构层优先：弧线/承重/承诺；句层最后 | FC-17 |
| 回归 | 已发布承诺、主角升级/感情线、类型契约、章末钩子 | FC-20 + FC-17 |
| 版本/例外 | 已发布章不改；未发布章可重排；例外登记（哪些钩子必须保留） | FC-21 |
| 连载约束 | 不能断更；钩子必须兑现；不以“番外”填主线欠账 | FC-08 |

### 输出（填入 `templates/revision-sheet.md` 的字段）

- **RV-01 目标**：400,000 → 300,000 词（-25%）；中段重复/支线过多；主角升级感变弱；不改已发布 1–80 章。
- **RV-02 范围/版本**：`serial-v1`（已发布 1–80）→ `serial-v2`（未发布 81–120 重排）；已发布章只做“后续补偿”，不回改。
- **RV-03 证据**：第 30–45 章重复解释“境界体系”3 次；第 50–60 章两条支线（商会/师门）无交汇；第 70–80 章连续 5 章同一类型危机；第 90–100 章主角升级事件被 概述 带过。
- **RV-04 层级**：结构层（弧线/支线/章末）；场景层（升级/感情关键场）；句层（重复解释/回顾）。
- **RV-05 删减对象**：
  - 事件/场景：重复危机 3 场 → 合并为 1 场升级危机；无交汇支线 2 条 → 删 1 条、并 1 条。
  - 句子/词：重复解释“境界体系” → 保留首次，后两次压成一句。
  - 解释/点题：作者总结“他明白了力量的意义” → 删，改为选择/代价。
  - 人物/支线：商会线无交汇 → 降背景；师门线保留，因它改变主角身份。
- **RV-06 承重段**：主角三次关键升级（第 20/55/95 章）、感情线两次转折（第 40/85 章）、已发布 80 章的章末钩子承诺。
- **RV-07 处置**：删（重复解释/无交汇支线）、压（重复危机/过渡）、并（商会线并入师门线/两章并一章）、留（升级/感情/已发布钩子）。
- **RV-08 最小过渡**：删支线后，在未发布章补 1–2 句“商会退出/师门接手”的过渡；不回改已发布章；用角色对话/结果交代，不写说明块。
- **RV-09 改写级别**：L1 建议 + L2 最小改写（未发布章）；L3/L4 需作者明确授权；已发布章 L0 只标注。
- **RV-10 回归项**：①主线升级链仍清楚；②感情线两个转折仍在；③已发布 80 章的承诺在后续兑现；④类型契约（升级/群像/感情）仍成立；⑤章末钩子仍有进入下一章的理由；⑥主角动机未被删到不清。
- **RV-11 版本记录**：`serial-v1`（原稿，只读）→ `serial-v2-outline`（弧线/删减方案）→ `serial-v2`（未发布章改写）→ `serial-v3`（句层/校对）；每版保留 `回退点`（关键章原段）。
- **RV-12 未决/授权**：作者是否允许删商会线？是否允许把两条支线合并？是否接受“已发布章不回改、只补后续”？平台是否允许重排未发布章？——未确认前只做方案，不动正文。

### 卡住时

- 删支线导致已发布承诺无法兑现 → 不删；改为“降背景 + 后续补偿”，并在 `兑现记录` 标欠账。
- 目标 300,000 词与承重段冲突 → 重设目标（350,000）或分卷；不硬删升级/感情线。
- 作者还没同意结构重排 → 先出 `serial-v2-outline` 给作者选；同意后再写正文。
- 平台/合同不允许改已发布章 → 明确“已发布不可改”，只做后续；不假装回改。
- 删完后章末钩子全平 → 补“下一章最想知道什么”，不靠突然事件硬造；钩子必须兑现。
