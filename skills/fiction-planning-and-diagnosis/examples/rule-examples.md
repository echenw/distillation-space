# 逐条规则最小示例（编写的示范）

> 本文件为 FC-01…FC-21 每条给一个最小可执行示例，固定四行：输入 → 分支判断（为什么走 A 不走 B）→ 输出（字段/表）→ 卡住时。
> 全部是编写的示范：人物、字数、情节均为演示用虚构数据；不是真实客户稿，不是真实运行记录，不证明任何效果。
> 规则全文与依据见 FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；字段落点见四张模板（`templates/novel-plan.md`、`templates/scene-plan.md`、`templates/diagnosis-report.md`、`templates/revision-sheet.md`）。示例只演示“怎么落条件”，不是标准答案。

---

## FC-01 先判赛道：篇幅 / 媒介 / 类型 / 交付

- 输入（编写）：80,000 字、周更、现实悬疑、手机阅读；作者问“能不能按短篇那样只写一个高潮”。
- 分支：走 B 长篇/连载，不走 A 短篇——多个不可合并的利害、章节钩子、追更交付；A 的反信号（多线、跨年、每章钩子）全部命中。
- 输出：`赛道: {篇幅: "80,000 字 / 40 章", 媒介: "连载", 类型: "现实悬疑", 交付方式: "追更", 读者承诺: "每章一个可兑现的追问"}；借用的规则: []`。
- 卡住时：若 `类型` 与 `交付方式` 未定 → 给短篇/长篇/舞台三方案与代价，不写具体场景与比例。

## FC-02 从素材到“一句胚故事”

- 输入（编写）：素材是“夜班护士发现病人抽屉里有一封写给自己的信”，但事件只能按“然后”排。
- 分支：走 A 情节/情境入口，不走 B 人物驱动长篇——已有必须发生的场面（拆信）和外部压力（病人昏迷、医院规矩）；B 需要跨月人物生长，本稿没有。
- 输出：`胚故事=护士必须决定是否拆开写给自己的信，代价是失去工作或自我形象`；`效果=读者不敢立刻判断她是勇敢还是自欺`；`不可逆的变化=拆/不拆`；`事件链=[发现锁被撬→因此怀疑→因此找到信→因此必须选择]`。
- 卡住时：写不出 `胚故事` → 不写场景；列“人物/情境/终局/效果”四堆，指出哪堆最先出现；四堆都空 → 只给素材整理任务。

## FC-03 单一效果：短篇的取舍判据，不是跨篇幅通则

- 输入（编写）：6,000 字单线悬疑，作者想同时写“爱情遗憾 + 医院黑幕 + 自我救赎”三个效果。
- 分支：走 A 单一效果，不走 B 长篇多线——≤10,000 字、单线、一个高潮；三条效果没有各自独立收束，B 的“主行动 + 语调统一”在这里用不上。
- 输出：`效果单位=整篇`；`效果句=她是否敢知道自己是谁`；`相争的效果=[爱情遗憾（冲突）→删/并；医院黑幕（支撑）→降为背景；自我救赎（主导）→留]`；`删除记录` 记三场删/并理由。
- 卡住时：说不出 `效果句` → 先不删，回 FC-02 重写 `胚故事/效果`；仍说不清 → 改问“读者读完最想带走的一个问题”。

## FC-04 结局先行：短篇定终场，长篇定方向

- 输入（编写）：6,000 字侦探短篇，作者先想到“凶手是叙述者”的揭晓，但说不出最后一场。
- 分支：走 A 短篇/单线，不走 B 长篇/连载——一个终场、一个危机、一个可预设的揭示；B 的多线与章节发现不适用。
- 输出：`结尾模式=终场`；`终场=她在值班室读到自己写的报案记录`；`末行方向=把记录折回抽屉`；`三环因果=[信→锁→值班记录]`；`潜伏意象=开头的撬锁痕迹`。
- 卡住时：A 写不出终场 → 改问“最后一个不可逆的动作是什么”；仍写不出 → 退回 FC-02 重写 `胚故事`。

## FC-05 人物—情节：先判入口，再双向校验

- 输入（编写）：素材最先出现的是一对男女被困在停摆电梯里；两人都只有职业标签，换谁都能演。
- 分支：走 B 情境入口，不走 A 人物入口——人物不能生成后果（无三处“只有他会这样”的决定），但情境本身含对立力量（幽闭 + 其中一人带着不能曝光的文件）。
- 输出：`入口类型=B`；`入口证据=作者先想到电梯故障`；`处境的压力=文件暴露/救援时间`；`情节逼人物=是`；`人物促成转折=是`（她选择毁文件）。
- 卡住时：双向校验皆“否” → 停止细化情节，先给人物一个会反抗情境的欲望，或改情境对抗力量。

## FC-06 主行动与多线：一条主脉，次线须交汇

- 输入（编写）：120,000 字双时间线；次线“妹妹调查失踪”目前只在主题上和主线相似。
- 分支：走 B 多线交织，不走 A 单主线——次线在第 18 章交出证据，反转主线嫌疑人的条件，且有自己的小高潮；若它不改变主线条件，就降为 A 的背景或删。
- 输出：`主行动=姐姐要在诉讼时效前证明父亲无罪，阻力是唯一证人失踪`；`线=[妹妹线：功能=反转，交汇点=第 18 章证据交换]`；`主汇合=第 26 章庭审`；`删减记录` 记删掉的第三线。
- 卡住时：写不出 `主行动` → 先不列线，回 FC-02 填“最想要的东西 + 最大阻力 + 失败代价”；次线无 `交汇点` → 删/并。

## FC-07 场景 / 概述 / 过渡：三种单元，按功能配比

- 输入（编写）：一章 4,000 字，全部用概述交代“他们谈判失败”，包括全书的第一次正面对峙。
- 分支：走 A 场景，不走 B 概述——这场有人当场想要什么（停战）并遇到阻力（对方要交出证人）；B 只适用于信息量大、时间跨度长的次要过程。
- 输出：`单元表=[段1 场景/推进主行动/900 字；段2 概述/必要信息/300 字；段3 过渡/时间感/200 字]`；`场景转概述记录`；`过渡记录` 带“季节/身体/物件”之一。
- 卡住时：分不清场景/概述 → 用“是否有人当场想要什么/被什么阻止”判定；仍分不清 → 标“混合单元”，先不删；写不成场景（缺阻力）→ 回 FC-05 补对抗。

## FC-08 单元收束：章 / 幕 / 折末的“暂解 + 未解”

- 输入（编写）：周更连载第 12 章末，主角回到本章开头的位置，读者没有下一章理由。
- 分支：走 A 章末，不走 B 单场短篇——读者会在章末真实停下（追更）；B 只适用于一次读完、无单元切分的稿。
- 输出：`单元收束表=[第12章/状态变化=否→改末事件/未解的问题=谁寄出第二封信/延迟=已预判→删拖延]`；`兑现记录` 把“第二封信”标到第 14 章兑现。
- 卡住时：三查全“否” → 该章删/并；若坚持保留 → 给它一个状态改变或新信息，否则标为装饰章；钩子写不出 → 不用“突然一声枪响”硬造。

## FC-09 开篇契约：首段四职，晚入场不是通则

- 输入（编写）：历史小说开篇直接写城门口混战；读者不认识两方阵营，也不知道谁在打谁。
- 分支：走 B 从头/典型场合，不走 A 晚入场——读者不懂前史就看不懂当下的动作（A 的反信号命中）；B 先给“典型一天”的秩序再打破。
- 输出：`开篇约定={谁: 守城书记官, where-when: 围城第三日清晨, tone-type: 冷峻纪实, 问题: 他会不会开城门}`；`进入点=典型换防`；`交代记录=[阵营→换防口令；粮尽→粥棚]`。
- 卡住时：四职写不全 → 先写“谁 + 何处 + 什么不对劲”三句，不写完整开头；三句也写不出 → 回 FC-02。

## FC-10 高潮与结尾：四种模式，先选契约再选型

- 输入（编写）：侦探短篇，作者想用“开放式结尾”收，但前文已抛出密室机关。
- 分支：走 B 解谜，不走 C 开放——类型承诺是答案，机关已在前文抛出，开放会违背契约；C 只适用于开头已埋潜伏意象、线头可收的文学稿。
- 输出：`结尾约定=答案`；`高潮场=地下室对峙`；`高潮后的材料=只解释密室手法两段`；`潜伏意象=第一章的钟表`；`结尾检查=删末段仍成立→末段是补的`。
- 卡住时：说不清 `结尾约定` → 问“读者要答案/团圆/余味/惊叹”四选一；仍选不出 → 标“结尾未定”，不写结尾。

## FC-11 视角：信息合同 + 距离稳定 + 切换代价

- 输入（编写）：6,000 字限知短篇，作者想中途切到对手脑内，交代他为什么藏信。
- 分支：走 A 单 reflector，不走 B 多 reflector——一个意识可承载全部信息，切过去只为传一句话（B 的反信号）；改用护士目击/听说/推断。
- 输出：`视角约定={能知道: 护士所见所闻所想, 不能知道: 病人内心与走廊外电话}`；`距离表=贴身`；`切换账本=[]`；`视角越界=[]`。
- 卡住时：写不出 `视角约定` → 先选一个 reflector，把信息限制在其可见范围；若故事必须跨地同时发生 → 改多 reflector/全知，并逐次记 `切换账本`。

## FC-12 读者已知度：先画知识矩阵，再配悬念

- 输入（编写）：悬疑短篇，标题已暗示“丈夫是凶手”，但正文仍按 A 悬疑写“读者不知道”。
- 分支：走 B 反讽，不走 A 悬疑——读者已从标题预知（A 的反信号），紧张感应改为“妻子会不会发现”；若坚持 A，则改标题与冲突。
- 输出：`知识表=[读者: 丈夫是凶手；妻子: 不知；丈夫: 知]`；`悬念方式=B`；`揭示点=妻子在第 3 场发现车票`；`读者的问题=她会不会说破`。
- 卡住时：矩阵填不满 → 先只填读者/主角/对手三行；A 分支发现读者已预知 → 改 B 或改冲突，不靠隐藏信息硬撑。

## FC-13 可信度审计：似真、巧合、类型豁免

- 输入（编写）：写实短篇，侦探在结局靠“一辆出租车恰好经过”抓到凶手。
- 分支：走 A 写实，不走 B 传奇/闹剧——契约是“可能发生”，巧合出现在解结并直接决定胜负（A 的反信号）；B 只适用于明确放弃逼真且内部规则自洽的类型。
- 输出：`可信度约定=可能发生`；`巧合清单=[出租车/解结/改为前文埋过的值班司机]`；`铺垫记录=第 2 场司机登记表`。
- 卡住时：契约说不清 → 按写实/不可能但自洽/夸张取笑三选一，选不出按最严写实；解结改不出人物因 → 换事件，不用“命运/天意”。

## FC-14 具体化与细节剂量：少而准，按视角过滤

- 输入（编写）：1900 年代廉租公寓场景，作者查了 12 个历史细节；视角是饿了一天的孩子。
- 分支：走 A 现实主义，不走 B 快节奏——氛围与阶层真实是这场的效果；B 的“一句可成像”会删掉承载命运的细节；但仍按孩子此刻会注意什么过滤。
- 输出：`主导印象=油腻的冷`；`细节表=[煤油味/气氛/是；墙纸霉斑/人物/是；房东的怀表/信息/是]`；`删减记录` 记删掉的 9 个查资料细节。
- 卡住时：写不出 `主导印象` → 先不写描写，回 FC-07 确认场景目标；细节都“很重要” → 只留三个，其余进 `删减记录`，看是否真损失。

## FC-15 文体：清晰得体是底线，节奏是耳朵的事

- 输入（编写）：类型言情高潮戏，作者把句子改得极平实，编辑说“力度没了”。
- 分支：走 B 类型/浪漫，不走 A 说明散文——文体本身承担效果，华丽与事件相称；A 的反信号（声音/气氛为主）命中。
- 输出：`文体底线={清楚: 是, 得体: 是, 可读: 是}`；`句子记录=[原句/改句/理由]`；`语域检查=高语域但主动词清楚`。
- 卡住时：朗读仍拗口且改不动 → 标“风格问题”，停止句层打转，回结构/场景；语域与人物不符 → 先写人物三行小传再改台词。

## FC-16 主题/道德：从行动长出，类型例外明示

- 输入（编写）：小说结尾，女主在车站对朋友说“所以人必须对自己诚实”，前文没有对应选择。
- 分支：走 A 小说，不走 B 寓言/道德故事——类型没有承诺“教训”，点题句是人物口播作者结论（A 的反信号）；B 只在类型契约明确要教时允许明示。
- 输出：`主题问题=她能不能承受自己说过的话`；`证明场=她替朋友作伪证后又撤回`；`声明记录=[删“人必须诚实”→改为她在压力下改口]`；`类型例外=无`。
- 卡住时：写不出 `主题问题` → 先不写主题，从 `证明场` 反推“这场选择在回答什么”；删点题句后主题消失 → 回 FC-05/06 补选择与后果。

## FC-17 修订工序：冷却、单稿、分层改

- 输入（编写）：80,000 字初稿刚写完，作者想立刻逐句润色。
- 分支：走 A 重度修订，不走 B 轻度——说不出每场功能（结构未成立），B 只适用于结构成立、仅句子/节奏问题；先冷却再分层。
- 输出：`修订记录=[结构层/第 7 场/原功能不明/改为“让证人翻供”/因果断]`；`冷读记录`；`回退点=第 7 场原稿`。
- 卡住时：说不出每场功能 → 不进句层，先做结构层（FC-06/07/08）；改到失去判断 → 停止、冷却/换读者；无回退原句 → 先建版本副本再动稿。

## FC-18 工作习惯：日课、素材簿、分段骨架、卡壳处理

- 输入（编写）：100,000 字连载，作者“有灵感才写”，中段卡住两周。
- 分支：走 A 职业/长篇，不走 B 偶发/短篇——跨月交付、结构复杂；卡壳属 C，改做低负荷任务并补分段骨架。
- 输出：`日课量=每天 40 分钟或 300 字`；`素材簿索引=情节/人物/描写/对白`；`分段图=8 段（历史默认，可增减）`；`卡壳记录=[卡点=第 5 段动机/替代=场景卡/恢复=换环境]`。
- 卡住时：设不出 `日课量` → 改“本周三次、每次 30 分钟”；仍做不到 → 只做素材/场景卡；低负荷无效 → 回 FC-05/06 查人物/主线，不硬写。

## FC-19 删减诊断：先分类删除对象，再决定删/压/并/留

- 输入（编写）：120,000 字要删到 90,000；候选是“导师前史”支线，但它是最后背叛的唯一因。
- 分支：走 A 情节驱动，不走 B 氛围/素描——主行动/因果链优先；B 只在细节/语调本身是效果时保留；唯一因不能删，只能压。
- 输出：`删减表=[导师前史/事件/改变主行动=否/唯一因=是/处置=压成两段回忆]`；`压缩记录`；重复解释删。
- 卡住时：三问答不清 → 先不删，标“承重待定”，用“抽掉这段复述主行动”测试；删后主行动断裂 → 回退改压缩/合并。

## FC-20 类型契约：必要特征 + 读者承诺 + 市场约束分层

- 输入（编写）：投稿被退“不符合悬疑”，作者想改标“文学跨类型”。
- 分支：走 A 商业/类型投稿，不走 B 文学/跨类型——必要特征（公平线索、可解答案）缺失且无补偿；B 需要有意偏离 + 补偿 + 明确目标读者。
- 输出：`类型约定={必要特征: 公平线索/可解答案/危机升级, 承诺: 读者可参与推理, 可偏离: 无侦探}`；`市场约束=字数/投稿栏目`；`偏离记录=[]`；`退稿诊断=技艺`。
- 卡住时：写不出 3 个必要特征 → 先写“读者买这个类型最想得到什么”一句再反推；仍写不出 → 标“类型未定”，不用类型规则验收。

## FC-21 规则层级：判据、条件、反例，不输出无条件步骤

- 输入（编写）：有人主张“每场都必须有反转”，理由是某大师每场都反转。
- 分支：先判层级，走 A 结构层检查（可指出文本证据），不走 C 天赋/判断层；该主张只有 1 个大师例、无 ≥2 反例，按本条降为“假设”，不升格为规则。
- 输出：`规则卡={层: 结构, 范围: 短篇/连载待定, 信号: 每场是否有状态改变, 分支: A 结构层（B/C 未用）, 失败: 无反转但状态改变, 反例: 待补 2 个, 可信度: 低}`；`例外记录=大师例外登记`。
- 卡住时：一条规则说不出两个反例 → 降为“假设”，不进正式规则；若已写入 → 标“证据不足”并移入待验证清单。
