# 设计示例（DESIGN_EXAMPLE）

> 本文件是 **设计示例**，不是真实客户稿、不是真实运行记录，也不证明任何效果。人物、情节、字数均为演示用虚构数据。
> 每个示例按“输入 → 分支判断 → 输出 → 失败出口”走一遍，用来展示如何把 现行融合规则 的条件与模板字段落地；不是“标准答案”。
> 按本例任务范围提供规划/诊断/修订；明确改稿授权即可执行相应范围，不用旧L级别另设许可门。

## DESIGN_EXAMPLE 1：规划短篇

### 输入

- 6,000 词文学悬疑，单主角，杂志一次读完；编辑要“紧、冷、最后一句有余味”。
- 素材：一名夜班护士发现病人床头柜的锁被撬过；病人昏迷；抽屉里有一封写给护士本人的信。
- 作者最先想到的是“那封信被打开的一刻”（终局画面），不是人物小传。
- 类型承诺：悬疑 + 文学余味；不是侦探解谜，不需要警察破案。

### 分支判断

| 判断 | 选择 | 依据 |
|---|---|---|
| 赛道 | A 短篇/单线/一次读完；medium=印刷；genre=文学悬疑；delivery=一次读完 | RC-01 A |
| 单一效果 | 本案选择聚焦单线与主导情绪（“她是否敢知道真相”） | RC-03 A |
| 终点 | A：终场画面 = 她拆信/不拆信的那一只手；末句方向 = 她把信放回抽屉还是带走 | RC-04 A |
| 入口 | C 终局入口：信必须被打开/被处理 | RC-05 C |
| 主线 | A 单主线：护士要决定是否读信；阻力 = 病人可能醒来/医院规矩/她自己的恐惧 | RC-06 A |
| 开篇 | A 晚入场：从她发现锁被撬的动作切入 | RC-09 A |
| 结尾 | A 闭合型 + 余味：信的内容给出一个答案，但最后一句留下一个物象 | RC-10 A/C 混合需明确主契约：先闭合，再余味 |
| 视角 | A 单 reflector（护士） | RC-11 A |

### 输出（填入 工作簿NP字段 的字段）

- **NP-01 赛道**：`length=6,000 词；medium=印刷杂志；genre=文学悬疑；delivery=一次读完；reader_promise=“紧 + 冷 + 最后一句余味”`。
- **NP-02 篇幅**：6,000 词，单线，3 场主戏 + 2 段过渡；不设章。
- **NP-03 单一效果/主行动**：`effect=读者读完不敢立刻判断护士是勇敢还是自欺`；`main_action=护士要决定是否读一封写给自己的信，代价是可能失去工作/自我形象`。
- **NP-04 终点**：`terminal_scene=她坐在值班室，拆开信，只读到第一行，手停住`；`last_line_direction=把信折回/放进抽屉，动作代替结论`；`latent_image=开头被撬的锁`。
- **NP-05 入口**：`entry_type=C 终局`；`entry_evidence=作者先想到“拆信的一刻”`；双向校验：`plot_forces_character=是`（读信逼她面对自己过去的选择），`character_causes_turn=是`（她选择不报警/不交信，改变后果）。
- **NP-06 各线**：单线；次线只有“病人女儿来探视”作为对照，功能=提供另一种真相版本，交汇=在第二场门口相遇，交换“谁在撒谎”的信息。
- **NP-07 结构单元**：场1 发现锁（scene）；场2 女儿探视（scene）；过渡1 夜班日常（transition，带“医院广播/手部消毒”的新信息）；场3 拆信（scene）；结尾一段（summary/余味）。
- **NP-08 开篇契约**：who=夜班护士；where-when=凌晨两点、ICU 值班室；tone-type=冷、近距离、悬疑；question=“信里是什么，她为什么不敢看”。
- **NP-09 类型契约**：本案选择的3个特征=①一个具体秘密；②读者比护士晚知道；③结尾给出一个答案但保留余味；可偏离=不设侦探/不解释全部动机；补偿=用护士的选择替代破案。
- **NP-10 视角合同**：单 reflector 护士；能知道=她看到的/听到的/自己想的；不能知道=病人昏迷中的内心、女儿在走廊外的电话；不切换。
- **NP-11 信息差**：`knowledge_matrix`：读者=不知道信的内容；护士=知道信封笔迹但不敢确认；女儿=知道一部分；`suspense_mode=A 悬疑`；`reveal_points=场3 拆信读第一行`。
- **NP-12 章末策略**：无章；场末三查：场1 状态变（锁被撬→她开始怀疑）；场2 状态变（女儿说出一个名字→她确认信与自己有关）；场3 状态变（读/不读的选择做出）。
- **NP-13 判断权**：信的内容/护士是否读，归作者；编辑只能要求“紧/冷/余味”，不能替作者定道德结论。
- **NP-14 风险**：“3场主戏”是本例设计预算，不是硬门；若 6,000 词容不下，压场2 为 summary；若结尾余味不清，改闭合型（读信后给明确答案），不硬加开放。

### 失败出口

- 信内容未知时可生成第一行的几种候选，或设计始终不展示内容的方案；依用户目标选择，不禁止先试写场3。
- 终场未定时可问最后的选择/状态，也可先试写人物与情境；明确哪些节点仍待探索，不强制重写premise。
- 若同时要闭合与开放，区分秘密回答、人物选择和未来关系：不同层面可以分别收束/开放，余味不必限最后一句。

## DESIGN_EXAMPLE 2：规划双线长篇

### 输入

- 120,000 词，双时间线：1976 年的母亲线 / 2024 年的女儿线；家族秘密；商业历史小说；单本完结，非连载。
- 素材：母亲线先出现“一张缝纫纸样被烧掉”的画面；女儿线先出现“她回到老屋，发现同一张纸样的复印件”。
- 作者想写“两代女性如何被同一个秘密塑造”；编辑要求“两条线必须交汇，不能各写各的”。
- 类型承诺：家族秘密 + 历史质感 + 情感落点；不是悬疑破案。

### 分支判断

| 判断 | 选择 | 依据 |
|---|---|---|
| 赛道 | B 长篇/多线/单本；medium=印刷；genre=商业历史；delivery=一次读完 | RC-01 B |
| 整体统一 | B：主行动统一 + 母题（缝纫纸样/针脚）统一；不要求单一效果 | RC-03 B |
| 终点 | B：`terminal_state=女儿选择公开/不公开秘密，母亲线的纸样被重新缝成一件东西` | RC-04 B |
| 入口 | A 人物入口（女儿想知道母亲为什么烧纸样）；母亲线用 B 情境入口（1976 年的工厂/婚姻困境逼她选择） | RC-05 A/B 分线使用 |
| 主线 | B 双线交织：女儿线=寻找真相；母亲线=掩盖真相；交汇=三次（纸样、名字、老屋） | RC-06 B |
| 开篇 | A 晚入场（女儿回老屋发现复印件）；母亲线第一章用 B 典型一天（工厂午休/缝纫机） | RC-09 A/B 分线 |
| 结尾 | A 闭合型（秘密被解释）+ 母题回收（纸样变成一件衣服） | RC-10 A |
| 视角 | B 两个 reflector：女儿/母亲；每次切换有章节标记 | RC-11 B |
| 信息差 | D 分层：读者知道母亲线的一部分，女儿不知道；母亲线内部有读者也不知道的秘密 | RC-12 D |
| 类型契约 | 本案选择的3个特征=①双时间线的因果交换；②历史细节服务人物选择；③情感落点；补偿=不靠悬疑反转 | RC-20 A/B |

### 输出（填入 工作簿NP字段 的字段）

- **NP-01 赛道**：`length=120,000 词/约 40 章；medium=印刷；genre=商业历史/家族秘密；delivery=一次读完；reader_promise=“两代人的秘密如何改变她们的选择”`。
- **NP-02 篇幅**：40 章，双线各约 20 章；每 8–10 章一个弧；3 个交汇点。
- **NP-03 单一效果/主行动**：`main_action=女儿要弄清母亲为什么烧掉纸样；母亲要保住秘密/保住女儿；失败代价=失去彼此`；`hierarchy=女儿线主导（寻找）、母亲线支撑（掩盖）、工厂群像对照`；`motif=缝纫纸样/针脚`。
- **NP-04 终点**：`terminal_state=女儿知道秘密后选择不公开，但把纸样缝成一件衣服；母亲线最后一场揭示烧毁前保存信息的选择；复制方式与年代条件需核查`；`milestone_turns=①女儿发现复印件；②母亲线揭示纸样对应的人；③同一老屋的空间/物件连接两个年代；若安排2024年母女相见，须另立母亲仍在世的事实`；`latent_image=第一章被烧的纸样边角`。
- **NP-05 入口**：`entry_type=A（女儿）/B（母亲）`；`entry_evidence=女儿先出现“回老屋”的动作；母亲先出现“工厂午休”的处境`；双向校验：女儿线 `plot_forces_character=是`（真相逼她重新选择与母亲的关系）；母亲线 `character_causes_turn=是`（她烧纸样的决定造成女儿线的缺失）。
- **NP-06 各线**：两条主线；次线=工厂女工群像（功能=对照/提供时代信息；交汇=母亲线第二次交汇；无独立收束）；`major_convergence=本案暂在约3/4处让老屋信息互相解释，前段蓄因、后段收果`——3/4只是本案草图，不硬卡。
- **NP-07 结构单元**：每章 1–2 场；1976 线多用 scene（工厂/厨房/缝纫机）；2024 线多用 scene + 必要 summary（调查/车程）；两线之间用 chapter break，不用同一章内切换。
- **NP-08 开篇契约**：第一章 who=女儿；where-when=2024 年老屋；tone-type=潮湿、旧物、克制的悬疑；question=“复印件为什么和母亲烧掉的一样”。第二章 who=母亲；where-when=1976 年工厂午休；tone-type=噪音、汗、规矩；question=“她为什么要烧掉纸样”。
- **NP-09 类型契约**：本案选择的3个特征=①双线因果交换（不是平行散文）；②历史细节服务人物选择（不是背景展览）；③情感落点（不是破案）；可偏离=不设反派/不设大反转；补偿=用两代人的选择对照替代悬疑爆点；`market_constraints=单本120000词、结局需情感闭合（商业历史读者）；不写审查/平台禁忌未知`。
- **NP-10 视角合同**：两个 reflector：女儿（2024）、母亲（1976）；每章只进一个意识；切换用章节标题/年份标记；不进入对方内心，除非有书信/录音作为载体；`switch_ledger`：每次切换 trigger=时间线需要、benefit=两代对照、marker=年份章题、cost=读者重新定向。
- **NP-11 信息差**：`knowledge_matrix`：读者=知道母亲线的一部分、不知道纸样对应的人；女儿=知道复印件、不知道母亲为什么烧；母亲=知道全部但不说；`suspense_mode=D 分层`；`reveal_points=第 12 章（纸样对应的人）、第 28 章（母亲烧纸样的原因）、第 36 章（女儿选择）`。
- **NP-12 章末策略**：每章末三查；1976 线章末多为“暂解 + 新问题”；2024 线章末多为“发现 + 代价”；两线交汇章末必须改变主行动；期待进payoff_log，在适合的位置回应，不要求紧接下一章。
- **NP-13 判断权**：母亲是否值得同情/女儿是否公开秘密，归作者；编辑可要求“两线必须交汇”，不能替作者定道德判断；历史细节的取舍归作者，但需标“查证/未查证”。
- **NP-14 风险**：双线各写各的（无因果交换）→ 最大风险；母亲线历史细节过多→ 压成 summary；3/4汇聚是本案选择，若两线在 2/3 处交汇更强，可改；120000词可能容不下工厂群像→ 群像降为背景。

### 失败出口

- 交汇点数量不足不自动失败；列因果、物件、主题和空间关系，决定保留交织、改对照或重构。不要为凑数把跨代人物硬合为一人。
- 若 `terminal_state` 写不出 → 写“最后谁必须做一个什么决定”；仍写不出 → 标“终点未定”，先写 3 个里程碑转折。
- 若 120000词目标与双线不匹配 → 给三个方案：压成 90000词单线、扩成 150000词双线、改成两本；不硬塞。
- 作者不要求事件交汇时，可选择对照或框架双线；本案编辑若明确要求因果互联，应列目标冲突与可行方案，不能冒称唯一双线结构。

## DESIGN_EXAMPLE 3：对“中段塌＋人物工具化”作有限输入诊断

### 输入与证据身份

作者描述作品为已完成90,000词的侦探长篇，并转述读者对12–19章“看不下去”的反馈；又说加了三个新嫌疑人后更散。现有材料只有三项情节概述：13章在咖啡馆梳理线索，16章切到助手视角让其偷听一句话，19章主角“突然想到”凶手。没有这三章正文，也没有其他章节；不能把概述中的省略当成原稿缺失。

### 候选机制

| 反馈或概述 | 可以提出的检查 | 仍不能断言 | 规则 |
|---|---|---|---|
| 中段“看不下去” | 新嫌疑人是否改变认识、关系、风险或节奏 | 整个中段无状态变化、全是概述或已阻断 | RC-06/07/08 |
| 助手递线索、一次独立视角 | 此功能是否足够，切换有何信息或声音收益 | 删去助手主线不变；功能人物必然失败 | RC-05/11 |
| “突然想到”凶手 | 推断由何信息触发，是否符合实际谜题契约 | 前文绝无铺垫，或仅凭此词已证明巧合解结 | RC-13 |

### DR完整输出

- **DR-01 范围**：只读作者提供的概要与转述反馈；未审全稿、整个中段或三章正文。
- **DR-02 版本**：示范记为draft-v3；日期、实际字数与正文版本仍待核。
- **DR-03 证据**：逐项保存“咖啡馆梳理”“助手偷听一句话”“突然想到”这些输入说法，标USER_DESCRIPTION；不新增“他们谈了谈”“无对抗”“状态未变”等假引文或假观察。
- **DR-04 症状**：S2中段松散、S3人物功能单一、S7解结可信度均为待验证候选，不是已确认Finding。
- **DR-05 规则**：RC-06/07/08检查组织与场景功能，RC-05/11检查助手与切换，RC-13检查巧合位置及因果。
- **DR-06 分支**：13章可能是重复回顾，也可能完成认识重组；嫌疑人可能是无关增殖，也可能形成社会或主题结构；助手可有单一而必要的功能，独立视角可只为信息但仍有效；19章可能是已有线索的顿悟，也可能缺乏支持。
- **DR-07 严重度**：尚不能定阻断。若确认关键解答违背已承诺的公平条件，影响可能高；若只是偏好的速度或人物复杂度不同，则按目标选择。证据强度与影响分别记录。
- **DR-08 最小验证**：取得相关正文及必要前文；做12–19章unit_table和unit_end_table，检查概述、认知、关系与停留作用；对助手作欲求/行动/信息/关系的删除影响比较，三处决定只是可选练习；填16章trigger/benefit/marker/cost；追踪19章推断的输入、思维过程、验证与实际公平契约。不以50%、连续三章或两个线索为硬线。
- **DR-09 建议**：若13章确为无新增作用的回顾，可试写“主角要求助手交出隐瞒线索”的对抗版；若16章切换确实妨碍目标，可改回主角观察，也可保留助手视角并加强其信息意义；若新嫌疑人未承担需要的功能，可删、并、降背景或补真实关联；若19章缺因，可用助手隐瞒与时间矛盾作为新设计候选，再安排验证。以上均是H候选，不能当原稿已有剧情。
- **DR-10 回归**：保留作者要的主行动、社会/人物维度、助手功能与声音；核切换后的知识权限，检查线索、推理与所选结尾承诺，不强制每章当场对抗。
- **DR-11 未决**：作者希望保留哪些嫌疑人和助手功能、是否承诺公平解谜；已有授权足以选择时可按证据实施，无需逐项重问。
- **DR-12 缺口**：未见全文及三章正文；读者反馈为转述、无样本细节；未核前文线索或删除影响；人物功能和类型契约尚不完整。
- **DR-SUM**：先取得最小必要文本验证上述三个机制；当前可交候选与检查表，不发布“中段塌已证实”结论。

### 失败出口与可继续部分

作者保留三个嫌疑人时，检查其因果、人物、主题或社会作用；不能只因未改变主线而强降背景。作者选择功能性助手时按所需复杂度保留。作者不改第19章时，只有在读过相应前文且确认与明确承诺冲突后，才报告具体风险；未核前文只能保留未决。缺失资料只暂停相关事实型诊断，不阻止创作候选方案。

## DESIGN_EXAMPLE 4：在已发布范围锁定下压缩连载

### 输入与可行性

400000词、120章的周更作品，前80章已发表且禁止修改，后40章可改；希望总量300000词，不能断更，保留关键升级/感情线，每章末保留作者要求的阅读期待。旧位置30–45章解释重复、50–60章商会/师门支线、70–80章同型危机，均只能诊断而不能在本次删改。90–100章未发表，关键升级被摘要处理，是可改候选。

先取得已发表80章实际词数B：未发表预算=300000−B。若B≥300000且还需后续正文，原目标在不改已发表部分的限制下不可实现；若B<300000，须检查剩余预算能否承载升级、感情、回收和必要过渡。原400000总量不能推算前80章占比，不能默认每章等长。

### RV-01–12输出

| 字段 | 具体方案与限制 |
|---|---|
| RV01目标 | 总量减100000词；只有81–120章可删改，最终可行性待B与承重预算 |
| RV02版本范围 | serial-v1已发表1–80章固定；v2针对未发表部分重排，锁定边界保持 |
| RV03证据 | 旧30–80章的问题作为避免未来重复的依据；待读81–120实际文本找可删内容，不能拿旧章当削减清单 |
| RV04层级 | 必要时联动剩余弧线、场景、句段；不机械先删副线 |
| RV05对象 | 只在81–120删重复解释、合并功能重复危机、压过渡；第90–100关键升级可展开，同时从别处节省。商会/师门过去剧情不删除 |
| RV06承重 | 已发表20/55章升级与40章感情事实保持；未发表95章升级、85章感情转折及80章末承诺保留或按用户许可等效实现 |
| RV07处置 | 对剩余每段标删/压/并/留；改变未来商会职能或与师门合作需在正文建立，不改其已发表历史 |
| RV08过渡 | 只补必要因果/关系/信息连接；商会退出、师门接手都是拟议事件，须在授权内写清后果，不能一句话抹掉既有承诺 |
| RV09改写范围 | 依用户明确压缩要求实际修改未发表部分；已发表仅注记。无须对已授权范围重复申请/许可 |
| RV10回归 | 升级链/感情转折/已发布承诺/人物动机/作者指定章界期待/新预算与更新排期 |
| RV11版本记录 | 保留原稿与改后可比较版本；大纲方案和已改正文分开，不将计划当产物 |
| RV12缺口 | 已发表词数B、未发表各段实际长度与平台真实限制尚缺。已明确“不改前80章”的授权不再反问确认 |

### 失败与候选

100000词若无法从可改部分节省，具体说明缺口，比较总量350000、缩短后续弧、分卷等方案；分卷只改变容器，不能假装减少总词数。已发表伏笔不能通过删除历史消失，可在未来兑现、转化或明确放弃并承担后果。无法保证不断更时，给实际可交稿量和修订排期，不空报可行。

此例只有方案和演示输入，尚无400000词正文、实测B或实际压缩稿；输出状态是DESIGN，未执行的改稿/回归不得记PASS。

## 附：四个示例的共同点

1. 先判赛道，再选规则；没有“通用小说法”。
2. 每个输出都落到模板字段，不写散谈。
3. 每个示例标缺料与可继续的设计；不把虚构提案当原稿事实，也不因普通空白拒绝创作。
4. 3场、40章、3个交汇和3/4汇聚仅为各例方案，不设统一默认。
5. 示例不声称真实运行；效果 NOT_PROVEN。

> **使用说明**：示例均为 DESIGN_EXAMPLE；固定章节数/场景卡/单线/结局只用于该示例，不作为跨作品的标准。
