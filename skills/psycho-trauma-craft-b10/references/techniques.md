# 技法分域：按叙事任务而非疾病标签选路径

## 路由 A · 身体与物件（RT-01/14/15）

`先定作品现实契约 → 身体异常是客观情节还是主观比喻 → 具体感觉与动作 → 他人的回应 → 行动后果`。PG5200 L4–12 是反事实变形；PG4240 L282–317 是感官与情绪关系；PG1952 L512–628 是一位受限叙述者对壁纸的解释。三者不等价；必须注明世界观和叙述者身份。

## 路由 B · 私密声音/拒绝（RT-02/03/09）

`角色想表达的事 → 谁禁止或拒绝倾听 → 使用何种声音/行为 → 别人的解释与真实权力 → 角色可选择下一步`。PG1952、PG11231 与 PG2197 在社会关系、时间体量和文类上不同。不能把拒绝工作、第一人称陈述或反复赌博统一叫“创伤症状”。

## 路由 C · 层级与证词（RT-04/05/07/12）

画三条线：`事件真实时间 | 人物可知时间 | 读者获知时间`。每条证词标明亲见或转述、当事人利益、后来是否有新信息；PG219 的帝国叙述边界与 PG5658 的责任重评、PG64317 的回顾式倾斜不是同一个修辞装置。多层叙述有时减少、有时增加可信度，不设固定单调方向。

## 路由 D · 金钱与制度（RT-06/10/11）

在场景中记录 `房屋/衣着/工资/债务/法规/阶层称谓/可退出渠道`；然后问“这限制了什么实际选择”。PG284 L221–227、PG165 L12887、PG447 L2948 显示不同的物质与社会压力；粗口、职业和贫富不是心理诊断标签。要同时识别叙述者可能的偏见。

## 路由 E · 缺席、记忆与标题（RT-08/13/15）

物件至少出现两次，确保物理连续与情境变化可复查；标题只设期待，不自动判人物品格；PG5670 L1189 的缺席与 PG143 L5–10 的副题用途不同。作者可用意象，也可以让人物直接表达，不能把一种技巧规定为唯一写法。

## 路由 F · 跨书冲突与反例

到 [72-source-differences](72-source-differences.md) 比较不同文类、社会时点与叙述人。若来源是 SF 记忆枪、1840 年代病理假设、历史医学评论或殖民时代去人化叙述，只能当小说/历史话语，不能用来确定临床事实。若用户要求实证心理学概念，暂停本 Skill 的推断部分，要求可信现代专业证据。

## 路由 G · 素材调取的安全距离（RT-16）

`素材是什么 → 用什么通道调取（转述/物件/他人证词/时间） → 调取后人物还能做什么选择 → 产出里是否仍有冲突`。
PG32353 L694–699 演示“无损耗调取”的失败（L745 “No conflict. No guts.”）。**调取必须与再体验分离**；不要用“写得更痛”当质量指标。

## 路由 H · 集体恐惧的建构链（RT-17）

`谁先看见 → 谁听见 → 谁用了什么类比 → 谁做梦 → 谁据此行动`。PG5230 L291–298 / L411–412 / L467–468 是完整样本。
每环只写外部动作；不给被恐惧者内心独白；结尾交代社会后果。**与以被恐惧者为中心意识的作品（RT-02/RT-14）机制不同，不可互换。**

## 路由 I · 用有结构的小事承载丧失（RT-18）

`给人物一件有规则、有终点、可与人共享的事 → 让创伤在做事的间隙回来 → 允许结尾仍未痊愈`。
PG27924 L1067–1070（选路）/ L1130–1136（送琴）/ L1398–1399（学故事并复述）。对照 PG1952 L758–766：同样是“有结构的小事”，但指向对抗而非共处，两条路径都要能说清区别。

## 快速回归三问

1. 这处感知/行为是谁的经验？有无把旁人偏见写成全知事实？
2. 新增修辞是否真正改变读者能够理解的角色行为，还是只叠加“昏暗/冷汗/破碎句式”？
3. 若删除诊断性标签，情节是否仍能让人物的选择、处境和影响清晰？若不能，补实际关系与事件而非更强标签。
