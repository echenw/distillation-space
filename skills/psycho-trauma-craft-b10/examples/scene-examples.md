# 两个原创演示（DESIGN_EXAMPLE；不是来源事实）

## 示例 A：感官线索与权力压力并存

输入：架空港口仓库管理员阿澄，夜间看到收货簿上反复出现“空仓”字样；她担心失业，却一直想保留父亲留下的修表摊。作者要写她“越来越不安”，没有要求给她任何疾病诊断。

- **F**：老板逼她接受虚报库存，拒绝将失去收入；“空仓”是仓库确实出现的标签，不是客观医学症状。
- **H**：她因经济压力而对同一个标记越来越敏感；也可能只是老板故意更改账簿。角色对事件的解释与外部事实分开。
- **P**：用 RT06 给出独立生活成本、RT15 让标签三次出现（先普通、后被篡改、最后成为实际查账的行动线索）；结局可申诉、辞职或找同盟，不固定为崩溃/痊愈。
- **安全出口**：不以“看见字样次数变多”判断某种心理障碍，也不为“更戏剧化”虚构自伤或伤人行为。

## 示例 B：多层证词互相抵触，不等于有人患病

输入：二十年前失踪的探险队长，三份手记解释不一致。A 手记说风暴先来，B 手记说船有缺陷，幸存者 C 从未进入发动机舱。

- **F**：A/B/C 的文字不相容，C 无法亲见发动机；无权直接认定任何一人撒谎或失常。
- **H**：可能是时间点、记忆、立场或抄写差异，不是医学或法医学判定。
- **P**：RT04/05 画事实线、各证人可知线、读者已知线；必要的反证仅来自现实有效的航行记录，不可将小说人物说法写成确定性事实。
- **冲突出口**：若缺原始航海日志，保留 `CONTESTED/NOT_PROVEN`，不在尾页虚造新证人以“证明”预定真凶。

## 缺料/边界示例

输入只有“帮我写一个创伤严重的女生，心理一定很病态”，没有场景和角色目标。应首先改写为“她经历的可见困难是什么、想保护什么、她有哪些可靠关系与拒绝机会”，给 2–3 个不强制诊断的原创方向；不能判定她“必然精神失常”，不能用历史 PG 病理描述当临床公式。若用户实际在问自己或他人的现实健康，本 Skill 退出并转向有资质的帮助渠道。


## 示例 C（RT-16）：让角色“回到那段记忆”，但保留损耗

输入：一位小说家要写主角回到童年那场火灾。作者想写得“越痛越好”。

- **F**：主角能说出的只有两件可核实的事——消防车的编号、母亲当天穿的外套颜色。其余是空白。
- **H**（解释）：空白本身就是素材的一部分；把它补成连续回忆，等于给人物装上了 PG32353 那种“无损耗检索”（L694-699），结局会是 L745 的 “No conflict. No guts.”。
- **P**：建三栏 `素材 / 安全距离 / 调取方式`——
  1. 消防车编号 → 距离：他人证词（邻居转述） → 方式：转述，不进入现场；
  2. 外套颜色 → 距离：物件（衣柜里那件还在） → 方式：触摸与描述，不回忆；
  3. 空白 → 距离：时间（写了三版都停在那一句） → 方式：让读者看见他停在哪里。
  随后必须给人物一个**仍可选的行动**（去问当年的邻居 / 不去问），并检查这一处是否还有冲突。
- **反例**：连续三页第一人称现场回放 + 生理细节堆砌 → 情绪泛滥但人物没有选择，冲突反而消失。
- **出口**：若作者坚持要“完整现场”，需明确这是世界设定（如无损记忆装置），并承担 RT-16 反例的后果。

## 示例 D（RT-17）：让全镇怕一个人，而不写他在想什么

输入：一个外来医生住在镇口，镇民逐渐认定他“不正常”。作者想写他的内心恐怖。

- **F**（外部动作链，照 PG5230 L291-298 / L411-412 / L467-468）：
  1. 谁先看见：杂货店主看见他半夜拉下所有窗帘（L291-298 的误视模式，当场给自己一个合理解释）；
  2. 谁听见：他被打断话题时突然改口要买火柴；
  3. 谁类比：有人拿“通缉犯的长相”作比（L411-412）；
  4. 谁做梦：杂货店主半夜梦见白色的头，醒来自己压下去；
  5. 谁行动：三人去村长处要求登记外来人口。
- **H**：恐惧不来自医生的内在，而来自这条链；作者一旦写他的内心独白，机制就从“集体建构”退化为“惊悚自白”。
- **P**：每环只写可被第三方复述的话与动作；不给医生内心；结尾交代社会后果（登记、驱逐、或什么也没发生但关系已不可逆）。
- **反例**：用“全镇都怕他”一句代替链条；或用“他是疯子”一次性解释完。
- **出口**：若作者要的是医生的第一人称，则改用 RT-02/RT-14，本条不适用。

## 示例 E（RT-18）：写丧子，不写告白

输入：一位父亲在孩子去世一年后仍每天上班。作者担心“不写崩溃就不够深”。

- **F**（照 PG27924 L1067-1070 / L1130-1136 / L1398-1399）：他给自己定了一件有规则、有终点的事——把孩子学校到家的路按七条岔路分别走一遍，每走完一条就在本子上记一笔。
- **H**：创伤不在告白里回来，在做事的间隙回来——走到第四条时他忽然无法说出孩子的名字；本子上那一笔空着。
- **P**：给这件小事 `规则 / 终点 / 可与人共享的对象`；让创伤在间隙出现（忘词、走错、停下）；允许结尾七条走完但那一笔仍空着。
- **对照**：PG1952 L758-766（锁门、藏绳、扔钥匙）同样“有结构的小事”，但指向对抗；两者区别要能说清——一件是与丧失共处，一件是与被囚禁对抗。
- **反例**：把这件事写成疗愈的象征道具，或在最后一条路上安排他哭出来并“释怀”。

以上检验的是文本协议可读性，不是对真实模型宿主执行结果的独立评测（GQ5 NOT_PROVEN）。
