# 心理与创伤表现 · B-10 文学叙事 Skill

**目标：让人物的主观经验、真实行动与叙述结构互相支撑，而不是用“疾病标签”偷换人物逻辑。**
本包从 72 件固定 PG 材料设计写作规则，包含小说、科幻与一部历史文学评论（PG75230，非虚构）。**不是临床知识库，也不是真实病例数据库。**

版本：2026-10-30 P4-Final（B-10 收口）。含 **18 条规则（RT-01–RT-18）**；替代 `results/skills/psycho-trauma-craft-b10` 与 `round-p4-wave4-agent2-2026-10-30` 两版。

## 何时用 / 何时不用

**用**（触发）：
- 你要写或改一段人物的压力、恐惧、丧失、成瘾/冒险、孤立、羞耻、不合作、自我辩解。
- 你要判断某段“崩溃/创伤/疯狂”写成了标签而不是行为。
- 你要设计第一人称不可靠叙述、多层转述、延迟认知、非线性证词。
- 你要用物件、空间、身体感觉、标题来承载心理变化。
- 你要让一个社群逐步害怕某个人/现象。

**不用**（负触发）：
- 任何真实的心理健康、疾病、疗法、用药、诊断、司法或法医问题 → **直接说明本 Skill 不回答，并建议专业渠道**，不要用文学规则兜底。
- 要求判断真实作者/读者是否有某种障碍 → 拒绝。
- 要求把某部小说的设定（如记忆装置）当作现实机制 → 明确标注为类别错误后停止推断。

## 输入（缺什么就问什么，不要替用户编）

1. **必需**：作品或节选原文、**叙述人称与视角归属**（谁的意识）、时代/世界设定、人物的自主目标、允许修改的范围。
2. **强烈建议**：角色关系表、信息时间线（谁知道什么、何时知道）、已有场景的行号或位置。
3. **可选**：作者想呈现但不想诊断的体验、角色不愿被公开的信息。
4. **缺失处理**：缺年龄/时代/环境/视角归属时，只输出有证据的文学判断 + 具体缺口 + 最小补证需求，**不补写人物过去经历、病史、司法结论或社会地位**。

## 判断流程（六步，逐步执行，不要跳）

1. **先定体裁与视角契约**（这一步决定后面所有规则能否用）：
   - 现实 / 幻想 / 科幻？反事实机制是**世界事实**还是**人物比喻**？（PG5200 L4-12 是世界事实；PG1952 L628 是人物感知）
   - 中心意识是谁？当事人的第一人称、参与者的回望，还是外位旁观？（PG720 是外位；PG1952 是当事人）
   - 若是科幻设定或历史医学评论，**不得**推出心理或临床结论。
2. **定义“发生了什么”**：从原稿标出 `实际事件 F` / `角色自己的解释 H1` / `旁观者或叙述者的推断 H2`。人物不可靠 ≠ 作者拥有医学结论。
3. **选矛盾类型 → 选规则**（同一问题不强套 18 条，通常 1–3 条足够）：
   - 身体或幻想前提 → RT-01/14
   - 孤立与私密声音 → RT-02/03/15
   - 证词不可靠 / 层级 / 共谋 → RT-04/05/07/12
   - 资源与制度压力 → RT-06/10/11
   - 物件、空间与缺席 → RT-08/15
   - 风险行为的自我辩解 → RT-09
   - **痛苦素材的调取方式** → RT-16
   - **集体恐惧** → RT-17
   - **不告白的丧失** → RT-18
   - 标题与期待 → RT-13
4. **保留角色主体性**：分别写清 `角色想要什么 / 有哪几种可选 / 谁控制资源·身体·信息 / 拒绝的代价是什么`。社会不平等不能自动解释成某个人的“内在疾病”。
5. **选手法而非标签**：读该条 `适用 / 不适用 / F / H / P / 反例`，按现有稿件证据写 1–3 个**可观察动作或描写**。拒绝没有来源的医药细节与单一刻板表征。
6. **校验信息边界**：谁能知道哪件事、见证是否独立、物件是否前后连续、文化词汇是否归属了正确发言主体。跨书比较时看 [72 源差异](references/72-source-differences.md) 的**反例栏**，不把 72 本当投票。

## 输出合同（默认按这个顺序交付）

```
1) 场景/段落定位        —— 引用原稿位置或行号
2) 人物观察 F           —— 可回查的原文事实（动作、对话、物件变化）
3) H1 / H2              —— 角色自己的解释 / 旁观者的解释，分栏写
4) 社会与资源边界        —— 谁付钱、谁能说、谁能走、拒绝的代价
5) 选中规则             —— RT-xx，并写明 WHY（为什么是这条而不是相邻那条）
6) 可执行动作 P         —— 1–3 个具体改写动作，每个都落到可观察层面
7) 反例与局限           —— 这条规则在哪里会失效；相邻机制的区别
8) 作者可选修订 A / B    —— 两套写法，各写代价
9) 未证实 NOT_PROVEN     —— 哪些判断缺证据、需要什么才能证实
```

需要阶段设计时追加：`起始处境 → 事件/资源变化 → 可观察行为 → 关系回应 → 结局不确定性`。
**单个场景不需要强制完整病程，也不需要“从创伤到痊愈”的剧情线。**

## 失败出口（出现任一情况，只输出有证据的部分 + 缺口）

- 没给原稿、缺年龄/时代/环境/视角归属 → 输出文学判断 + 最小补证需求，不补写人物经历。
- 需要医学诊断、临床术语、疗法 → 停止推断，转专业渠道。
- 源书版本不对应、PG 行号无法定位 → 标注“按当前仓库阅读版定位，外部版本需重新定位”，**不捏造行号或页号**。
- 涉及歧视/殖民/性别视角的历史用词 → 必须注明发言主体与历史性，不作为现代中立叙述。
- 用户要的是真实健康困扰 → 走专业医疗建议渠道，不把文学套路当现实应对方案。
