# 05 决策指南：V1–V14 的逐条消费分支

本文件由历史 `wave4-conditional-guide.md` 改写并扩到 V1–V14：每条给"先判什么 / 判成 A 怎么做 / 判成 B 怎么做 / 什么时候不用这条"。
规则正文在 [01](01-identity-engines.md)、[02](02-revenge-closure.md)、[03](03-lineage-power-and-limits.md)。

## 通用前置（每条规则前都要过）

1. 这是**时点问题**还是**结构问题**？（某个章节写错了 vs 整体装置不成立）
2. 相关事实在稿件里是否真的存在？不存在就写 NOT_OBSERVED，不要假设。
3. 作者是否锁定了相关设定？锁定的部分只能给兼容于它的改法。

---

## V1 公共误判（PG102 L290–297；PG2171 L1131–1133；PG9749 L3010–3012）
- 判：认定权在**社群舆论**、**登记文书**、还是**家族长辈/机构**？
- 舆论型 → 写传播链、传播者各自的收益、被误判者的更正尝试为何失败。
- 文书/机构型 → 走 V4，核有权机构与纠错渠道；不要把小镇议论等同于行政登记。
- 不用这条：误判只存在于人物内心、外界根本没有认定动作。

## V2 格言/题辞（PG102 L306–309）
- 判：格言是否改变读者理解？是 → 放在关键节点，不必每章。否 → 删掉。
- 不用这条：快节奏追逃、开放悬疑、以反讽收束的作品。

## V3 证据链（PG102 L332–362；PG1183 L8786–8810；PG61499 L1270–1278）
- 判：这条证据**在前文是否已经存在**？
- 存在 → 补四栏：首次出现 / 保管者 / 知情范围 / 可被质疑之处；再补"差点失效的原因"。
- 不存在 → 这是硬伤，给两个补救位置（最早可插入点 / 最接近使用点），标为候选而非既成事实。
- 特别检查：**两名目击者是否互不知情**——若互不知情，任一方单独都不构成证据（PG1183 L8805–8810）。
- 不用这条：证据本来就是公开事实、不存在回收问题。

## V4 表演身份 vs 认定权（PG102 L402/416；PG2759 L1264；PG1183 L8931–8936；PG61499 L929–936）
- 判：伪装靠哪类介质——视觉介质（镜子/画像）、可塑面容（道具改变面相）、随身道具（伪装物即凶器）、制度误判？
- 四类都可以用，**不要同时上四种**。写清"核查者为什么发现不了"以及"行家会看哪个遮不住的部位"。
- 触碰血统/肤色/面相 → 立即转 V14，改为可表演外形、被篡改的登记、目击者记忆、契约关系等合法装置。
- 不用这条：没有任何伪装，只是身份信息未被公开。

## V5 复仇边界（PG1184 L61141–61145；PG1183 L8540–8543；PG61499 L1320–1323；PG9749 L8740–8752）
- 判两问：**由谁执行**（本人 / 残余组织 / 受害方第三方 / 敌方且失败 / 无人）与**何时终止**（达成 / 越界自省 / 执行者死亡 / 第三方接管 / 未决）。
- 首恶已死但威胁继续 → 明确"终止点不由主角决定"（PG1183）。
- 有对称复仇冲动时 → 检查代价是否落到与罪行无关的人身上（PG61499 L1306–1315 是**一种**写法，不是通则）。
- 不用这条：正当自卫、保护受害者、反派自灭——不插忏悔式内省。

## V6 收束方式（PG1184 / PG1183 L9007 / PG2171 L1592–1594 / PG9749 L9840–9844 / PG77 L778–780）
- 判：作者要不要给主题句？
- 要 → 从已发生的情节里提炼一句该角色有资格说的话，形式不限（信件/对白/叙述者判词/动作）。
- 不要 → 在"无判词 / 反讽判词 / 人物互评 / 追问代结论"里选，并说明为什么这样收更好。
- 不用这条：系列作中间卷，本就没有收束义务。

## V7 复盘（PG1183 L8931–8948；PG61499 L1270–1278；PG1184 L61103–61106）
- 判：读者此时还不知道哪几条因果？
- 按节奏选概述 / 当面对质 / 证据展示 / 交错回忆；**必须**写明哪一步差点失败。
- 不用这条：真相早已由行动演完，再复盘会剥夺发现过程。

## V8 收益去向（PG1184 L61136–61241；PG77 L739–780；PG5227 L394–400）
- 判：资源的**名义归属**与**实际支配权**是否一致？
- 不一致 → 先解决契约/制度限制，再谈伦理选择。
- 一致 → 在修复关系 / 归还 / 慈善 / 保留 / 放弃 / 不作处理中选，并写清受影响者的意愿。
- 继承物本身是祸（PG77）→ "拒绝继承"也是合法选项。
- 不用这条：主角没有任何收益可处置。

## V9 换位/双身份（PG2759 L1088–1099、L1264）
- 判：被换者对自身容貌/出身的知识缺口有多大？用什么介质补齐？
- 缺口大 → 介质可以是镜子、画像、文书、旧仆；缺口小 → 换位不成立，改用冒名或共谋。
- 必须写"谁有资格事后确认"以及确认失败的后果。
- 不用这条：只是改名或易容，不涉及"顶替另一个人的位置"。

## V10 改名重置（PG2171 L1131–1133、L1245–1258、L1482–1485）
- 判：新身份靠什么维持？列维持成本清单（背书人、可能不配合者、会泄露旧名的物件/口音/旧债、不可控证人）。
- 有不可控证人 → 让他成为崩溃点，并写清惩罚是"社群撤回承认"而非某个复仇者的行动。
- 无牵连 → 允许新身份维持下去，不必强行败露。
- 不用这条：身份重置只是背景设定，不参与主线冲突。

## V11 继承与代际罪责（PG77 L242–244、L778–780；PG9507 L257–261；PG5227 L394–400；PG3622 L638–758）
- 判四栏：名义归属 / 实际支配者 / 来源是否正当 / 继承者是否知情。
- 知情且能纠正 → 写纠正的代价由谁付。
- 不知情或无法纠正 → 不要写成"他背负祖先之罪"，改为结构性后果（债务、名分、他人的期待）。
- 写诅咒类母题 → 落在可验证的人物行为上，不写成本体论事实（PG77 L410–429）。
- 不用这条：继承只作为财产背景，不承担主题功能。

## V12 机构权谋（PG16573 L3554–3559、L4086–4101；PG2815 L216；PG30606 L307–450）
- 为每个权力动作建三栏账：公开理由 / 实际受益者 / 成本承担者；再标"何时失效"。
- 改革话语 → 明确它是表演还是真实推进（PG16573 是表演）。
- 家庭内部先出现信息不对称 → 先写家庭层，再写机构层（PG30606）。
- **NP**：是否必须以制度结算收场——本批三种走向冲突（PG61499 是 / PG30606 未完稿不可判 / PG3622 家庭和解），不要替作者统一。
- 不用这条：小共同体内部冲突，没有制度性权力可调用。

## V13 归属型身份（PG17028 L400–403、L417、L419–421）
- 判：设定里的身份是"可加入/可退出的归属集合"还是"待揭穿的血统秘密"？
- 归属集合 → 写加入条件、退出代价、互斥集合的冲突、退出后是否仍被旧集合追认。
- 不要把它改写成血统谜题。
- 不用这条：前现代/血统世界观。

## V14 禁用清单（PG102 L416；PG1184 L61214–61218）
- 任何建议若依赖血统比例、面相骨相、民族类型化犯罪属性、现实法医/司法结论、临床诊断 → 直接拒绝，给替代装置。
- 描写历史歧视制度时，必须标注为"作品所展示的历史偏见"，并保留受影响者的自主行为与尊严。

## 输出前自检（8 条）

1. 每条 F 是否都能给出位置（章节/行号）？给不出就是 NOT_OBSERVED。
2. 是否至少给了两个竞争解释？
3. 选用规则是否写了适用/不适用/反例？
4. 是否碰了作者锁定项？碰了就要显式标出。
5. 模板缺项是否写 NOT_OBSERVED 而非编造？
6. 是否给了方案 A/B 与各自失效条件？
7. 是否有回归清单（身份权限、证据时机、伦理代价、版本一致性）？
8. 是否显式声明了 NOT_PROVEN 项（跨作品普遍性、读者效果、作者意图、GQ5）？
