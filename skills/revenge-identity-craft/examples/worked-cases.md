## 1. 正常：身份证据与复仇结局
输入：历史奇幻，修书匠被误称伪造遗嘱，几十年后归还真实文书；作者希望结尾由自省而非杀戮完成。
- F：他被误判、文书存在、目标是昭雪。H1：他需要公开更正；H2：他主要希望获得女儿信任。
- P：走 V1/V3 处理公开认定与文书保管链；V5 选"本人执行 + 达成即终止"；V6 选信件或人物互评式收束。
- **反例检查**：不能因为 PG1184 有赠予就强加慈善捐赠（V8：先核归属，本例他无收益）。
- 回归：每次展示文书时的保管权与年代；女儿到底知道什么（知情差）。

## 2. 缺料：没给稿件却要逐章诊断
输入："这部小说身份反转哪里有 BUG？我没给书。"
- 输出：NOT_OBSERVED + §2 九项提问清单 + 高层检查方法（认定权 / 知情差 / 证据首次出现）。
- **不编造**章节内容、不猜作者意图。

## 3. 冲突：锁定设定与新提案相撞
输入：作者锁定替身与本人无血缘关系，新提案坚持用"双胞胎"当证明。
- 输出：V9 只要求"补齐被换者的知识缺口"，血缘不是必要条件；改用珐琅微像/旧仆/笔迹等介质（PG2759 L1264 的介质思路）。
- 不覆盖作者锁定项，只给兼容方案。

## 4. 越界：要求用血统/面相当设定依据
输入："让角色因为 1/8 血统就必然表现出某种性格，这是设定。"
- 输出：拒绝。V14：这是 PG102 L402/416 所展示的歧视制度，不是身份科学；PG1184 卷末脚注 L61214–61218 已写明面相师只是 "pretended"。
- 替代：可表演外形、被篡改的登记、契约关系、目击者记忆、归属集合（V13）。

## 5. 未证明：要求"保证读者爽"
输入："按你说的改，读者一定会更爽，对吧？"
- 输出：NOT_PROVEN。本批 16 部作品没有读者数据；本 Skill 未做真实宿主 GQ5 测试。
- 只给可选设计与各自代价（例如：无判词收束的好处是保留不确定性，代价是主题需读者自行归纳）。

## 6. 机构权谋线：改革话语是真是假
输入：主角在议会推动改革并大获成功，但我想让他后来发现自己被利用。
- F：他的公开立场、实际推动者、谁承担成本。
- P：V12 建三栏账（公开理由 / 实际受益者 / 成本承担者），并明确改革话语是表演还是真实推进
  （PG16573 L4086–4101 是"表演"的可核写法）。
- **NP 声明**：是否必须以制度结算收场，本批三种走向冲突（PG61499 是 / PG30606 未完稿不可判 / PG3622 走家庭和解），
  不替作者统一。
