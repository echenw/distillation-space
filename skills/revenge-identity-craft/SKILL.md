# Revenge Identity Craft · 身份与复仇工艺（B-07-B01 / 批次-01）

面向**人工阅读与改稿**的分析型 Skill：它帮你在真实稿件上判断"该检查什么、证据够不够、有哪几条可选改法"。
它**不做**自动识别、不做作者意图/读者效果的预测、不做事实认定。所有结论必须能回源到 (PG, 行号) 或用户提供的稿件位置。

来源基础：本批 16 部原文（PG102 / PG11171 / PG1183 / PG1184 / PG16573 / PG17028 / PG2171 / PG2759 / PG2815 /
PG30606 / PG3622 / PG5227 / PG61499 / PG77 / PG9507 / PG9749），全部 SHA 已核、阅读区间并集 100%。
证据层级与遗留问题见 [来源索引](references/04-source-index.md) 与本轮 `notes/source-coverage.md`。

## 1. 触发与负触发

**触发**：人物"是谁"被社会、制度或家族错误认定；冒名/换名/双身份/孪生换位；早期细节后来被重解释成证据；
复仇是否越过初衷、由谁执行、何时终止；遗产/血脉/名分的继承与罪责；政治、议会、企业或家族内的权力操作；
结局该收束成什么形态；已有章节里身份权限、证据时机或伦理代价前后矛盾。

**负触发（直接转出，不要硬套）**：
- 真实世界的身份/血缘/司法/法医判断，或要求生成可充当凭据的身份材料；
- 把种族血统比例、面相骨相、民族类型化犯罪属性当作技法或事实（见 [V14 禁用清单](references/03-lineage-power-and-limits.md#v14-禁用清单)）；
- 临床创伤/精神医学诊断；
- 要求"保证爽感/保证道德正确/保证畅销"；
- 纯侦探程序题、纯追逃动作题，且没有身份认定或主题收束问题。

## 2. 输入与前置检查（先问清这 9 项，缺哪项就标 NOT_OBSERVED）

拿到稿件或问题描述后，**先建立时点事实表**，不要先给改法：

| # | 要确认的事 | 缺失时 |
|---|---|---|
| 1 | 人物的**实际身份**与**外界认定的身份**分别是什么 | NOT_OBSERVED |
| 2 | 谁有**认定权**（社群舆论 / 登记文书 / 家族长辈 / 机构） | NOT_OBSERVED |
| 3 | 各角色**知道什么、谁知道谁知道**（知情差矩阵） | NOT_OBSERVED |
| 4 | 已写出的证据线：物件首次出现、保管者、可被质疑之处 | NOT_OBSERVED |
| 5 | 复仇的初始承诺、实际目标、已付代价由谁承担 | NOT_OBSERVED |
| 6 | 叙述视角（第一人称受限视角会改变可写的证据量） | NOT_OBSERVED |
| 7 | 前卷/后卷版本与作者已锁定的设定（不可改部分） | NOT_OBSERVED |
| 8 | 作者想要的结局形态与允许改写的范围 | NOT_OBSERVED |
| 9 | 题材设定里的**证据体制**（文书/社群信物/生物识别/无制度） | NOT_OBSERVED |

没有稿件就说"我逐章检查过了"是违规：没有文本只能给方法与提问清单。

## 4. 执行步骤（五步，不要跳）

1. **分流主导冲突**：核心是"公共认定我是谁"→ 走 V1/V4/V9/V10；核心是"复仇与收束"→ 走 V5–V8；
   核心是"继承/权力/归属"→ 走 V11–V13。两者并存时按**人物实际行动链**串起来，不要机械全选。
2. **建时点事实表**（§2 的 9 项），把 F（稿件里确有的）、H（你的推导）、P（你要建议的动作）分开写。
3. **至少提出两个竞争解释并各自找反证**。例：误判是传播问题还是权力问题？复仇该停止还是继续？
   找不到反证就说明找不到，不要造一个。
4. **按规则做条件选择**：每条规则都要先过"适用条件 / 不适用条件 / 反例"三关再采用。
   逐条判别走 [05 决策指南](references/05-decision-guide.md)。
5. **输出并回归**：填模板（缺项写 NOT_OBSERVED）、给方案 A/B、写回归清单
   （身份权限是否一致、证据出现时机是否早于需要、伦理代价是否落到具体人、作者锁定项是否被碰）。
   没有写文件授权就只输出建议，不覆盖正文。

## 6. 输出合同

每次交付至少包含：

1. 输入版本与稿件范围（哪几章/哪一版）；
2. 时点事实表：F / H / P 三列，每条 F 带位置（章节或行号）；
3. 至少两个竞争解释 + 各自的反证；
4. 选用的规则 ID + **适用条件 / 不适用条件 / 反例**；
5. 填好的模板（[身份因果卡](templates/identity-causal-chain.md) 或 [复仇状态卡](templates/revenge-closure.md)），缺项写 NOT_OBSERVED；
6. 方案 A/B（含各自的失效条件）；
7. 回归清单与"必须由作者裁决"的项；
8. **未证明声明**：跨作品普遍性、读者效果、作者意图一律 NOT_PROVEN；本 Skill 未做真实宿主 GQ5 测试。

## 7. 失败出口与停止条件

- 缺稿件 / 缺关键设定 → 输出 NOT_OBSERVED + 提问清单 + 高层检查方法，**不编造章节内容**。
- 用户要求把历史歧视制度（种族血统、面相、民族类型化）当技法或事实 → 拒绝，并说明只能作为"作品所展示的历史偏见"来描写。
- 用户要求保证爽感/道德正确/销量 → 说明超出本 Skill 能证成的范围，改给可选设计与各自代价。
- 证据不足以判定来源观察 → 标 NOT_PROVEN，不回填为"已确认"。
- 没有写文件授权 → 不覆盖正文，只交付建议与差异描述。
- 现实身份、法律、法医、临床问题 → 直接转出本 Skill。
