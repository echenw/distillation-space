# 29 本跨来源融合：支持、反例与差异

本文件只做 P3/P4 层的跨来源归纳。29 本当前都已有 FULL 阅读证据，但“被读完”不等于“每本都必须支持同一规则”。本包只把可回到当前正文、且能解释适用边界的材料提升为 H/P。

## 1. 支持：公平性更像信息权利，不像固定线索配方

### 观察 → 推断分层
- PG73618 把红领巾、弹孔/口径判断等信息分散在发现与调查阶段：读者可以先看到 OBS，再观察人物如何解释。
- PG70979 的相机状态、马匹/服装识别说明同一个“身份”可以由多种可见信息承载，但多个相似点仍可能被同一伪装策略控制。
- PG55511 的枪伤场景把衣物状态与人物法证判断写在一起，恰好说明审稿时必须拆 `观察` 与 `解释`，不能把人物台词自动视作事实。

**H**：比“至少两条硬线索”更稳定的共性，是读者能够区分原始观察和人物推断。  
**P**：决定性证据统一写成 `OBS → INF → ALT → TEST`。

### 叙事知识边界
- PG583 在序言中明确声明多人只从各自知识继续叙述，是强显式契约。
- 其他作品不一定有这种序言，但仍会通过谁在场、谁看见、谁拿到文件来限制知识。

**H**：多视角公平性的核心不是“必须写契约”，而是知识边界稳定。  
**P**：标 `亲历 / 推断 / 转述 / 后获知`，检查 POV 是否突然越权。

### 专业规则应先成为读者可用规则
- PG72816 在使用 mixed melting-point、单位换算等专业机制前，把操作原理或推理工具写进文本。
- PG75049 的专家/药物段落也展示专业信息如何成为调查材料，但长讲义与现实科学正确性是另一个问题。

**H**：专业解法若是唯一钥匙，读者至少要先得到故事内部足以使用的规则；“专家说所以如此”更像调查悬疑，不是 strict fair-play。  
**P**：真实专业事实另核，本 Skill 只审信息披露。

## 2. 反例：有线索不等于读者拥有解法

- PG64596 显示一个非人感知者可能拥有“人类不知道的整套感官”。如果最后答案依赖未定义的新感知能力，即使前文有很多实体线索，读者仍不拥有同等规则。
- PG75049 的插图说明说明副文本也会改变披露顺序；正文里“公平”但插图先泄底，整体阅读体验仍不同。
- 大型名单本身并不自动公平：PG64596 的名单约 150 人。没有筛选维度时，“候选都出现过”仍不足以形成可解性。
- 历史 PG223 ledger 的拼接错引说明“有行号”也不等于可信证据；P4 必须回到当前正文核短锚。

## 3. 差异：不同子类型需要不同公平契约

### 短篇/杂志侦探
往往依赖一两个高压缩的可见物件或身份反转。审计重点是“必要事实是否提前出现”，不要求复杂嫌疑矩阵。

### 长篇证词/多 POV
重点转为知识来源与删节规则：谁能证明什么、转述是否被当成亲历、叙述顺序是否制造了作者私有信息。

### 封闭候选/黄金时代式多假设
重点是候选空间和竞争解释。候选可很多，但应在揭示前能够逐步排除；不能到结尾才引入此前不可知的人/机制。

### 科幻/超自然/非现实机制
关键不是“现实不可能”，而是故事规则是否提前建立、限制是否稳定。未建立的万能能力破坏 strict fair-play；提前公开且可推演的非现实规则可以成立。

## 4. 不提升为 P 的内容

- 历史作品中的具体法证结论、警务做法、私刑、非法拘束、种族/阶级刻板：只留作 F 或风险样本。
- “读者一定能猜中”“某种线索数量更畅销”“严格公平一定更好看”：当前无消费者/市场数据，`NOT_PROVEN`。
- 29 本逐书差异不被压成一个统一时代“规范”；本包只抽取能跨不同叙事形态维持的审计不变量。
