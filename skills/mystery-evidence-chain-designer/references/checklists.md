# 可执行清单（直接照表跑，逐项打勾或标"缺失"）

## L1 结案前·负向排除清单（公平性自检）

来源：PG70964 L77-115（Chesterton 序言，本轮实读）。原是 1926 年针对当时流行套路的反制话语，**不是跨时代普适禁令**——若你的题材正面使用国际阴谋/组织犯罪（如冷硬派、间谍推理），把对应条目改为"必须提前交代组织的能力边界与代价"，而不是简单禁用。

| # | 检查项 | 通过条件 |
|---|---|---|
| 1 | 没有用"遍布世界的秘密会社"兜底 | 反派的能力边界在正文里被具体交代过 |
| 2 | 没有用国际外交/政治红 tape 遮蔽核心谜题 | 政治层是动机，不是解法 |
| 3 | 没有在结尾从"新西兰冒出来的兄弟" | 所有关键人物在案发前已登场且可被记住 |
| 4 | 没有把罪责推给从未被记住的小人物 | 凶手至少有一次被读者注意到的场景 |
| 5 | 没有让职业罪犯替私人罪行顶罪 | 顶罪若存在，须是人物主动选择且有各自不同的保护对象 |
| 6 | 没有让六个人分做同一件谋杀 | 分工若存在，每人的动作都有独立证据 |
| 7 | 没有用"都是误会、没人真想杀人"收场 | 若要降格为意外，须预置：持械动作 + 受害者主动前扑 + 第三方目击 |
| 8 | 秘密不在最后一页才出现 | "秘密在中心"（PG70964 L114）——关键真相在中段已可被推出 |
| 9 | 误导所用的物证与解答所用的物证是同一批 | 凡用于误导的物证，结局必须用同一件物证换一个绑定对象解扣，不得引入新物证（PG74210 末块验证） |
| 10 | 每个反转都留下可观察后果 | 同一事实两次翻转时，第二次必须给出可观察后果，否则像诡辩（PG74210 L5197-5209 → L5504-5523） |
| 11 | 侦探没有靠结尾新事实取胜 | 侦探的隐瞒必须兑现为旧物由来或早年误判的自陈（PG74210 L8298-8312） |
| 12 | 伏笔可被回读 | 关键伏笔放在"反派一个看似无意义的小动作"上，且事后由主角复述回收（PG74441 L4323-4324、L5642-5648） |

## L2 现场章清单（写或改现场章时跑）

1. 现场介质是什么、何时形成？（雪/泥/尘/湿地板）→ 形成时刻未交代先补。
2. 勘查者自己的轨迹是否已排除？（A1）→ 未排除则后面所有足迹推理作废。
3. 进入方式 / 停留时长 / 离开方式各有几条可核证据？（A2）→ 缺一项就补一项物证。
4. 现场是否被整理过？与"急救/家属搬动"的说法是否冲突？（A4）
5. 第一发现人的可疑点是什么：是"在场时间"还是"冷静程度"？（PG74210 L2699-2722：专业镇定反而成疑点，但须承认训练可作解释）
6. 是否配了至少一条失败/污染事件？（H3）

## L3 时间线清单

1. 死亡/案发时刻由什么给出：消耗型计时物（B1）、第三方记录（B2）、还是目击（F1）？优先级 B2 > B1 > 目击。
2. 若用消耗物：规格、起点、剩余量三项是否都写了？缺一项只写区间。
3. 若用第三方记录：是机构书面交付还是人物转述？能否被代发/伪造？
4. 时间锁定后，封闭嫌疑集是否重排过？（PG73711 L1170-1187：重排后叙述者发现自己也在其中——这一步要写出来）
5. 是否存在"应当存在却没有"的记录可作反证？（PG71589 L740-745）

## L4 视角章自检表（第一人称 / 侦探视角）

| # | 检查项 | 通过条件 |
|---|---|---|
| 1 | 叙述者是否可能隐瞒 | 明确其隐瞒动机（保护、自保、羞耻） |
| 2 | 隐瞒靠"省略"还是"谎言" | 优先省略；若说谎，须给出会被戳穿的具体点 |
| 3 | 被省略的时段能否被读者回推 | 有钟表刻度/他人证词/机构记录可回推 |
| 4 | 读者能否在重读时发现 | 至少有一处在初次阅读时"读得通、重读时另有意思" |
| 5 | 推翻叙述的第三方文件是否预先埋过 | 遗书/手稿/信件的存在在正文前段已交代 |
| 6 | 叙述者的自我辩护是否留了破绽 | 一句"多余的具体细节"（PG70964 L5389-5397：管家从未说过的那句转述） |

## L6 公平性回读测试（作者自检，5 步）

1. 把凶手名字遮住，从第一章重读，标出所有"指向真凶"的句子。
2. 数一数：这些句子里有多少在初次阅读时能被当作普通叙述？（>0 才算公平）
3. 检查每一个"读者不可能知道的时刻"（密室里的动作、凶手的私人动机）是否都有替代证据。
4. 检查巧合密度：超过两处"恰好"就让读者出戏，须改为制度性或习惯性原因。
5. 若第 2 步为 0：不要靠"侦探后来发现"搪塞，回到 L1 第 9 条补同一批物证的第二重绑定。
