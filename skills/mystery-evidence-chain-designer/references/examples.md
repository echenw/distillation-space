# 端到端样例（两份，按 SKILL.md §6 输出合同的六段格式）

样例里的"稿件"是虚构的用户来稿摘要，用于演示怎么把规则落到具体判断上；来源锚点指向真实原文。

---

## 样例一｜设计：乡村宅邸密室割喉，第一发现人是护士

**用户来稿摘要**：一战期乡间宅邸，男客夜宿次日晨被发现死于割喉；门从内锁、窗全闩；第一发现人是当晚值班护士；凶器是一把剃刀，宅里有成套七把（周一至周日）；死者是城里人，从不自己刮胡子。

### 1. 判定
谜面归两类：**密室/无侵入**（C1）+ **自杀-他杀定性**（D1）；配套跑 **A1 现场保护**、**A2 三固定**、**G1 保管链**、**F1 证词净化**。视角未定，按长篇处理。

### 2. 检查清单结果
| 规则 | 结果 | 依据 |
|---|---|---|
| A1 现场保护 | **缺失** | 稿件没写谁先进门、从哪侧进、勘查者自己的足迹如何处理。参照 PG70964 L406-441、L603 必须补 |
| A2 三固定 | 部分具备 | 出口有（门/窗/仆役区未列），停留时长无时间戳，离开方式未写。参照 PG74210 L2646 先把"外部入侵排除"写成一条独立结论 |
| C1 密室四步 | **踩中失效风险** | 稿件只说"窗全闩"，没给通道清单（仆役区、天窗、暗门），按 PG70964 L1876-1882 先证"确为密室"，否则读者会自己找暗门 |
| D1 五查 | 部分具备 | 有"死者从不自剃"（PG74210 L3562-3572 同型），但缺专家互驳——按 PG74210 L1470-1471 → L2501-2508，先给强法医结论再让第二位专家指出"入刀点不可判" |
| G1 保管链 | 具备且很好 | 成套剃刀带日期差是强锚点（PG74210 L1368-1370）；但须按末块自评"收缩"——习惯只用于缩小候选，最终归属落在"谁借用了现场遗留的凶器"，不是"谁拥有" |
| F1 证词净化 | **缺失** | 护士的陈述里没区分"看到"与"推断"；按 PG74210 L7650-7656 可让她观察全部属实、因果读反 |

### 3. 改写方案（按优先级）
1. **补现场章三步**：进门路线与铺设物、只观察不推测、勘查者自痕登记（A1）。这是硬前置，不做后面全废。
2. **补通道清单**：把门、窗、bolt、仆役区、天窗逐条勘验并让仆人证词一致，然后写"外部入侵排除"（A2/C1）。
3. **给凶器加时间差**：沿用成套编号，让出现的那一把与当日不符（G1）。
4. **把护士写成"真观察/错推论"**：她看到的四个现象全真（染血衣物、去渍、熨平、姓名缩写），只有因果读错（F1）。
5. **加一次专家互驳**：让第二位专家拆掉"惯用手"结论，使案件回退为开放（D1）。

### 4. 来源锚点
- PG74210 L707-724（验尸庭程序）、L1368-1370（成套剃刀）、L2501-2508（专家互驳）、L2646（外部入侵排除）、L2699-2722（第一发现人的"冷静程度"）、L7650-7656（真观察/错推论）。
- PG70964 L406-441、L603（现场保护与自痕入基线）、L1876-1882（反密室）。

### 5. 风险与反例
- 最大风险：把"成套剃刀的所有者"直接等于凶手——PG74210 末块已自评"须收缩"，真凶是借用现场遗留凶器的人（L8084-8092）。
- 次要风险：结局若用"双镜高窗 + 瘫痪者指认"式的高巧合装置（PG74210 L8004-8013），须提前数章交代镜子与高窗，否则判作弊。
- 时代：1918 年电话需经总机、共用线路可旁听；现代改写须换成通话详单/门禁并交代取证合法性。

### 6. 未决项
- 护士是否为唯一发现人？若是，她的"冷静"须给出训练背景解释（医护/军警），否则读者会认为作者硬安。
- 凶手动机尚未定：若走"身份曝露型"（旧识凭一处纹身认出自己），须先让读者相信其改过自新的诚意（PG74210 L8084-8092 的可迁移部分）。

## 样例二｜修改：第一人称助手叙述，读者说"早就猜到凶手"

**用户来稿摘要**：医生助手第一人称，全程陪同侦探；结尾揭示助手本人是凶手。读者反馈：读到三分之一就猜到了。

### 1. 判定
归 **F2 省略式不可靠叙述** + **F1 证词净化** + **H3 失败并列**；用 L4 视角自检表与 L6 回读测试定位问题。

### 2. 检查清单结果
| 检查项 | 结果 | 依据 |
|---|---|---|
| 隐瞒靠省略还是谎言 | 稿件用了三处明显谎言（时间、行踪、物件） | PG69087 L10453-10460：真正有效的是"全真 + 留白"，谎言反而容易被察觉 |
| 省略时段可回推 | **缺失** | 稿件没有给出关键十分钟的钟表刻度；PG69087 给了"二十分钟到九点 / 差十分钟九点"两处刻度才敢留白 |
| 初次阅读自然、重读有第二义 | **缺失** | 三处谎言在初次阅读时都显得突兀 |
| 侦探视角是否有失败 | **缺失** | 按 H3 至少补一条侦探的失败或误判（PG2852 L2799-2813、PG66627 L7486-7534） |
| 第三方文件预先埋过 | 缺失（结尾才出现遗书） | PG70964 L5740-5834 的教训：仅靠遗书单点支撑，物证仍薄 |

### 3. 改写方案
1. **把三处谎言改成两次留白**：删掉直接否认，改为"我做了那一点必须做的事"式的笼统句，并在别处给出该时段的时钟刻度（PG69087 L10472-10474）。
2. **把破绽放在一句多余的具体细节上**：例如助手转述了一句"受害者说困"，而这句话只有现场的人才会知道（PG70964 L5389-5397）。
3. **预先埋第三方文件**：让遗书/手稿的存在在前段被提到（一次即可），结尾才由它推翻（PG70964 L4983-5041 → L5740-5834）。
4. **给侦探配一次失败**：例如一次验证链被"转交"击穿，且失败被如实保留（PG2852 L2799-2813）。
5. **用 L6 回读测试验收**：遮住凶手名字重读，若"指向真凶"的句子在初次阅读时读得通、重读时另有意思，才算通过。

### 4. 来源锚点
- PG69087 L10415-10416（手稿原打算写成"波洛的失败"）、L10453-10460（省略而非谎言）、L10462-10466（延迟装置 + 声音分离）、L10489-10509（封口与代价）。
- PG69845（有罪隐瞒者第一人称；三条线索先立后破）。
- PG70964 L5389-5397（多余细节反噬）、L4983-5041（侦探自信叙述）、L5740-5834（遗书推翻）。

### 5. 风险与反例
- 若只做第 1 步而不做第 3 步，读者会判"作者作弊"——省略时段无法回推时，F2 直接失效。
- 若把助手写成全程说谎，F1 的"证词净化"就失去意义：读者会开始逐句核对，反而更早猜到。
- 封口处置必须填 L5 代价表：本书样本是叙述者自裁并把处置权托付侦探（PG69087 L10489-10509），代价最高，不要无代价照搬。

### 6. 未决项
- 用户的读者群是否已读过同类作品？若读过 PG69087，还需再给一层（例如让侦探视角本身也有隐瞒）。
- 篇幅若只有短篇（<8000 字），F2 只能保留一次留白，第二次会显得拥挤。
