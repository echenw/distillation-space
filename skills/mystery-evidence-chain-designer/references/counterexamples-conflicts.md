## 2. 明确被拒的候选（不要在建议里复活）

1. **把"封存真相"当作应然规则**（裁决 REJECT）：四本给出四种互不兼容的处置——社会不信任下的封口（PG1720 L813-827）、书面供状换离境的私了（PG55782 L6323-6324、L8895-8906）、为死者名誉与体制体面封卷（PG70964 L5880-5887）、叙述者自裁托付第三方（PG69087 L10489-10509）。唯一可检验的要求是**必须明写代价**。
2. **时代侧写术**（裁决 REJECT）：颅相学（PG2852 L300）、"西班牙血统"性情论（PG2852 L7309-7310）、笔迹判性别（PG63340 L4249-4254）、"红发即同一人"（PG63340 L4039-4086）、"遗传发疯"解释犯罪（PG66627 L8051-8053）。
3. **私刑 / 诈供 / 以自己为饵**（裁决 REJECT）：PG17866 L5955-6044、L6786-6793；PG71589 L692-709；PG63340 L7581-7586。属类型惯例，不是合规取证或风险评估流程。
4. **以方言/行话作准入凭证**（裁决 REJECT）：PG55782 L7795、L8031-8032，1902 年定型化刻板书写。
5. **把设定律当物证**（不适用）：机器人不能伤人（PG72197 L113-120）、瞳孔定死时（PG71589 L143-157）、公园完全封闭（PG72197 L104-111）——只在设定内成立。

## 3. 未证明（NOT_PROVEN，不要写成规则）

- **尸体替身 / 死亡时间伪造族**：PG1720 L3713-3723（"It was a dead man who sat fishing there all day"）与 PG74210 L3077、L3239-3249（假尸施压）机制不同——一是时间伪造，一是心理施压。历史卡片自设门槛"需三本以上独立来源"，本轮未达，保持 NOT_PROVEN。
- **能力伪装（"精准地打偏"）**：仅 PG1720 L720-733、L774-785 单本，单来源不成族。
- **物证"操作者习惯"决定归属**：PG74210 末块已自评"须收缩"——习惯信息只用于缩小候选，本书真凶并非剃刀所有者（L8084-8092）。

## 4. 四处保留的冲突（不做调和）

1. **公开 vs 封存**：PG74441 全书以公开推理赛制为前提（L564-580），结尾却拒刊反派日记（L5961-5970，理由"细节会变成普通罪犯的武器"）；PG70964 序言却说批评者的首要职责是不泄底（L77-87）。三者互相拉扯，本 Skill 不判定谁对，只要求作者选定后**在文本内自洽**。
2. **异常优先 vs 噪声风险**：PG2852 L7166"越离奇越要细查" 与 PG70964 L1913-1915"多余线索会把人带离要件"是相反的处方；取舍取决于对手是否主动投放线索（H2）。
3. **封口伦理**：见 §2.1，四种处置互不兼容。
4. **时代技术的可采性**：X 光（PG74441 L3778-3804）、硝酸银染发鉴证（PG73597 L2402-2435）、笔迹判性别（PG63340）——三者在各自年代都被写成"科学"。统一口径：**结构可迁移、结论不可迁移**。

## 5. 时代与体裁边界（写作前先确认）

- 本批年代跨度 1868–1962，法域跨越英美。凡"可采性/程序/起诉"条款一律降为叙事条款；写现代刑侦题材须另行取证。
- 哥特/灵异装置（磷光巨犬 PG2852 L6719-6725、灰衣鬼 PG54273 L1629-1667）在文本内都被给出自然解释，可作"恐怖—解释"结构样本，不可作现实鉴识依据。
- 廉价本与连载体（PG63340、PG2013 的章节节奏）以动作密度与巧合密度换节奏，其"推理"常靠对手内耗（PG63340 L6674-6677 自陈"所有线索都由罪犯提供"）或直接推翻先前假说（PG2013 L3925-3930），作技法来源须降权。
- 科幻短篇（PG71589 751 行、PG72197 442 行）的可用技法集与长篇不同：单点反转 + 极小封闭集，不要套长篇的多线索延迟回收。
