# 适用范围与冲突裁决 — historical-fiction-craft-b03

## 1. 适用范围
适用：以真实历史时期为背景的小说/短篇的构思、起草、诊断、修订——史实配比、时代细节、真实人物入书、悬案改编、编年纪律。
不适用（负触发）：
- 纯架空世界（无真实历史锚点）。
- 历史学术论文/传记：本 Skill 的小说来源不能代替专业史料。
- 把虚构人物/事件冒充真实历史事实发表。
- 未经标注地复制殖民、族群、性别或宗教压迫立场。

## 2. 来源族去重
- Scott 族 4 本（PG5353/PG7853/PG1606/PG5950）：同作者/传统不按四个独立方法来源计权。
- Stevenson 族 3 本（PG421/PG848/PG14133）：同作者系列分别提供实例，不自动形成三份独立共识。
- Dumas PG18997：终卷与铁面人装置均是单作 F，迁移效果 NOT_PROVEN。

## 3. 冲突裁决（消费者版）
### C6 真人物入书 vs 虚构载体
- Collins 的“虚构载体”是作者方法 F；PG421/PG1606/PG5950 等展示真人物、虚构人物可以在同一叙事中共存。
- **裁决：CONDITIONAL** — 不做二选一硬门。逐项标记真人物行动为“有来源 / 合理填补 / 纯小说虚构”；虚构人物可承担史料空白处的自由行动。若作品是架空史，在分歧点后说明哪些真人物行为属于改写。

### C7 忠实编年 vs 架空分歧
- **忠实历史分支**：与情节直接相关的核心事件日期/结果不无声明移动；称谓、叙述辅助和压缩手法按读者理解需要处理，不存在“脚注最多两处”的来源依据。
- **架空/反事实分支**：先保留现实基线，再明确分歧点；分歧点之后允许因果扩散，但不能把改写结果回填成现实史实。

### C8 结果先知 vs 悬念保密
- 回忆录式副题可提前给部分结果，把悬念转成过程/代价；悬疑身份、未解因果或作者承诺保密的结局可以继续隐藏。
- **裁决：CONDITIONAL** — 不要求“什么全部公开”，按叙事合同选择暴露范围。

### C9 知情者与来源类型
- 边缘知情人、司法文书、书信、传闻、后世作者判断可以并列，但不是同一可信层。
- **裁决：CLAIM-BASED** — 先问“这个来源能证明什么”。人物见闻可证明其所见/所信；制度文书可证明记录或制度动作；传闻只能证明传闻存在；小说作者声称“authenticated facts”只是作者 F_CLAIM，仍需独立史料核验才能当历史事实。

### C10 历史立场与现代迁移
- 来源中的殖民、种族、性别、阶层和宗教立场可作为历史语境 F 或反例；不因来源 FULL 而变成现代创作规范。
- **裁决：CONTEXTUALIZE** — 保留需要的时代冲突与人物视角，同时让叙事区分“角色时代信念”与“作品无条件背书”。

## 4. 历史悬案与史料引用门禁
1. 先分 `KNOWN / CONTESTED / UNKNOWN / INVENTED`。
2. 引文记录作者、材料类型、年代、争议程度；小说中的“史料引文”不自动取得真实性。
3. 忠实历史小说只在 UNKNOWN/CONTESTED 中做有标记的小说化填补；若要推翻已证事实，转入显式架空分支。
4. 真实人物的重大犯罪、私德或动机若无可靠依据，只能作为明确虚构/传闻层处理，不能以本 Skill 的小说来源冒充历史结论。

## 5. 真实人物审计
- 有来源行动：可写事实层，同时保留来源不确定性。
- 合理填补：可写小说层，但避免把心理推断包装成档案事实。
- 纯虚构行动：忠实历史分支需避免制造可被误认的重大现实主张；架空分支需落在已声明分歧点之后。

## 6. 时代局限重构点
1. 历史贬称/族群语汇：需要出现时说明语境和说话者，不自动复制为旁白规范。
2. 帝国怀旧/天定命运：可作为角色或时代信念，与其他视角/后果并置。
3. 女性被动/献祭结构：不当成“历史题材必须如此”；人物能动性按史料与小说设定分别处理。
4. 宗教党派叙事：区分角色立场、作者史料姿态与可核事实。
5. 方言：按可读性和人物区分使用，不设固定密度。

## 7. 证据不足不立硬律
- 占星预言、歌剧主题镜、祖母框架等单源现象只作 F/H 候选。
- 单作、同作者系列、作者自述都不能靠数量包装成跨传统共识。
