# 模板：历史人物入书审核表（Real-Figure Audit）

> 每行独立可填（RF-01..RF-12）。用于把真实历史人物写入小说前的合规审查。

| ID | 字段 | 填写内容 |
|---|---|---|
| RF-01 | 人物（生卒年/身份） | |
| RF-02 | 史料清单（传记/记录/书信） | |
| RF-03 | 人物出场事件（来源/记录类型/不确定性） | |
| RF-04 | 台词与抉择（有来源/合理填补/纯虚构；忠实史或架空分支） | |
| RF-05 | 与虚构主角的关系（恩人/对手/君主） | |
| RF-06 | 后人名誉风险（诽谤边界） | |
| RF-07 | 性格刻画与史载性格的偏差说明 | |
| RF-08 | 时间线核对（出场日期与史料一致） | |
| RF-09 | 史料空白处的小说行动（虚构标签/与已证事实是否冲突） | |
| RF-10 | 时代语汇（称谓/头衔准确性） | |
| RF-11 | 来源说明计划（导言/后记/脚注/附录，按需） | |
| RF-12 | 失效出口（史实冲突时撤回方案） | |
