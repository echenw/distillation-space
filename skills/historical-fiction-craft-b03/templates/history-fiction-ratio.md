# 模板：史实-虚构配比表（History-Fiction Ratio Planner）

> 每行独立可填（HF-01..HF-14）。

| ID | 字段 | 填写内容 |
|---|---|---|
| HF-01 | 历史时期与地点（起讫年） | |
| HF-02 | 真实编年事件表（按情节需求核验关键节点，不设固定数量） | |
| HF-03 | 主角位设计（虚构/真人/混合；对应 RH-02/RH-04 来源边界） | |
| HF-04 | 真人物清单（史料依据/行动边界） | |
| HF-05 | 虚构主角与真实事件的接触点 | |
| HF-06 | 悬案/传说（KNOWN/CONTESTED/UNKNOWN/INVENTED；忠实史或架空分歧） | |
| HF-07 | 时间错位清单（必要时说明称谓变动，次数可变） | |
| HF-08 | 时代细节载体（服饰/交通/法律/货币） | |
| HF-09 | 信物/母题（可选的母题再次出现/重释计划） | |
| HF-10 | 地下网络/机构（史实依据） | |
| HF-11 | 群像清账计划（尾声） | |
| HF-12 | 时代局限重构点（殖民/性别/宗教） | |
| HF-13 | 失效出口（编年冲突时怎么办） | |
| HF-14 | 读者辅助（词汇表/导言考据） | |
