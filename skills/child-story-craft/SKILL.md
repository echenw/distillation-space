# Child Story Craft（儿童故事工艺）

## P4 最终操作入口（Agent2 收口）

本 Skill 保留既有可执行流程与参考资料，并添加一份从本批次原文中裁决的 [精简条件规则](references/p4-field-guide.md)。按用户任务选择主分支，只加载该分支所需参考资料；先读 references/version-and-provenance.md 了解最新 P2 收口与版本；原始叙事实例是 **F（作品现象）**，提炼为作者可以采用的流程属于 **H/P（设计推断/建议）**，不能写成原作者明确教过的方法。

**必须先获得**任务（写作/策划/诊断/改写）、目标受众与媒介、已知人物/事件/规则及原稿（诊断时必需），并确定允许改写的范围。输出合同：`任务路由 → 输入事实/缺口 → 选择的规则ID → 有位置的文本证据或来源 → 可执行方案（含反方案） → 交付物 → 尚未验证的风险`。当用户没给原稿时不能虚构段落位置；要求改稿时默认只给方案或非覆盖的新稿；涉及权利、历史真实或危险现实建议时，划清故事创作与现实事实边界。

**退出方式**：缺关键剧情信息，给最小补料清单和两条可选方向；用户目标相互冲突，保留两个条件分支和取舍，不捏造统一结论；超出本 Skill 的类型/年代/媒介/读者条件，说明不能支持的结论，必要时只提供明确标为推断的结构类比；效果与真实用户任务未验证时标 `NOT_PROVEN`。这不是自动触发、自动运行或保证创作效果的程序。


## 0. 这是什么

人工填表 + 条件判断的设计/诊断 workflow，并非自动化系统。
- 输入：目标年龄段、讲述/阅读形态、已有稿或设定。
- 输出：**讲述检查表 + 故事配比表**（模板 §7）+ 路由读取的规则。
- 不做：不擅自覆盖旧稿或替用户决定年龄分级合规，但经明确授权可写原创故事、不含 scripts。

## 2. 触发 / 负触发

### 触发
- 写"讲给儿童听"的故事或故事集（口述稿/有声稿）。
- 儿童小说叙事者设计：虚荣自吹、字面主义、危险场景分寸。
- 故事集配比：说教与无判断图景的平衡。
- 已有稿被评"说教太重/危险太吓/笑点落空"。

### 负触发
- 青向（YA）恋爱/成长主轴：冲突机制不同。
- 教材/科普文体。
- 成人文学中的童年回溯叙述。
- 要求"保证孩子喜欢/年龄分级认证"：超证据边界。

## 4. 最短执行路径（1 个门）

**G1 形态**：成品是"被讲出来的"（story-hour/有声）还是"被读的"（默读文本）？
- 被讲 → 01 中适合该讲述者的规则可选，尤其 S3 错误纠正不能按旧硬约束。
- 被读 → 01 的 S3/S4/S5 降级为作者侧节奏参考；02 适用。
- 两者兼（读后可讲选段）→ 以 01 为主、02 为辅。
