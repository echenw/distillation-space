# 中文段落、句子与用词（SR-01 至 SR-12、SR-16）

返回 [SKILL.md](../SKILL.md)。英文对应规则见 SKILL.md §6 列出的四份英文参考文件。

本文件把 Strunk 的原则迁移到中文，并加入中文编辑的通行做法。每条都写了“不适用”。不适用的情形和规则本身同样重要：小说里大量“病句”其实是人物声口或作者的刻意安排。

例句都是为说明而编写的，不出自任何作品。

## 判断声口的三个问题

改任何一句之前先问：

1. 这句是叙述还是对白？对白和贴近人物的内心独白，默认保留人物的说法。
2. 这个“毛病”在全稿里是偶然一次，还是反复出现？反复出现、而且分布有规律，多半是作者的风格。
3. 改了以后，语气、强度、节奏变不变？变了就只提建议，不直接改。

## SR-01 一段一事

**做法**：叙事段以一个动作单元、一个场景焦点或一个意思为单位。一段里混了两件不相干的事，就拆开；同一条因果被切成几段，读者跟不上，就合并。

**例**：
- 原：他推开门，屋里没人。桌上的茶还冒着热气。三天前师父说过要去南边，路上可能要走半个月。他记得那天下着雨。
- 问题：前两句是眼前的场景，后两句跳到三天前的回忆，回忆又和“茶还热”这个疑点有关，但挤在一段里，疑点被冲淡了。
- 改：前两句单独成段，让“茶还热”停在段尾；回忆另起一段。

**不适用**：网文的短段、一句一段的节奏，是平台阅读习惯，不必合并成“规范段落”。作者用单句段制造停顿时保留。说明性段落才默认要有主题句；叙事段落不硬加主题句。

**对应**：EN-20、EN-21、EN-23。

## SR-02 对白换人另起段

**做法**：每换一个说话人另起一段，哪怕只有一个字。说话人的动作、神态写在他自己那一段里。

**例**：
- 原：“走吗？”李青问。“不走。”老周头也不抬。
- 改：
  “走吗？”李青问。
  “不走。”老周头也不抬。

**不适用**：同一个人连续说话，中间插一个动作，通常留在同一段；作者想要停顿时才拆开。剧本格式不按这条。

**对应**：EN-24。

## SR-03 修饰语和主语对得上

**做法**：句首的介词短语、“作为……”短语、分句，它暗含的施事要和主句主语一致。不一致或缺主语时，二选一：改主句主语，或把句首改成完整分句。

**例**：
- 原：作为一名医生，病人的安危永远放在第一位。（“作为医生”的是人，主语却是“病人的安危”）
- 改：作为一名医生，她永远把病人的安危放在第一位。
- 原：通过这次谈话，使他明白了自己的处境。（“通过……使……”吃掉了主语）
- 改：这次谈话使他明白了自己的处境。／通过这次谈话，他明白了自己的处境。

**不适用**：对白里的口语省略（“看见没，门开着”）不是病句。古风、半文言的句式按作者风格处理。

**对应**：EN-11。

## SR-04 成分齐全、搭配得当

**做法**：查三类确定的病句——缺成分（缺主语、缺宾语中心词）、搭配不当（主谓、动宾、修饰语和中心词不搭）、句式杂糅（两种说法拼在一起）。

**例**：
- 搭配：改善了生活水平 → 提高了生活水平；他的脸上露出了惊讶和一丝不安的神色 → 不改（“惊讶”和“一丝不安”都能修饰“神色”）。
- 杂糅：这件事的原因是因为他太大意 → 这件事的原因是他太大意／这件事是因为他太大意。

**不适用**：人物说话本来就不完整、不讲语法时保留。意识流段落的断裂是手法。拿不准是不是病句时，列为问题，不改。

**对应**：无直接对应；属于中文编辑的通行检查。

## SR-05 语序清楚，副词辖域明确

**做法**：
- “只、都、也、不、又、才、就”放在它真正修饰的成分前面。
- 多层定语太长时，拆句或把一部分移到后面。
- 代词离所指太远、可能指两个人时，换回名字。

**例**：
- “我只见过他两次”（见的次数少）和“只有我见过他”（见过的人少），意思不同。改之前先问作者想说哪一个。
- 原：那个站在门口穿着灰大衣手里攥着一封信的男人终于开口了。
- 改：门口站着个穿灰大衣的男人，手里攥着一封信。他终于开口了。
- 原：老陈和小周吵了一架，他摔门走了。（谁走了？）
- 改：老陈和小周吵了一架，小周摔门走了。

**不适用**：作者故意把关键信息压到最后制造悬念的长句（见 SR-07）可以保留，但要说得出它的作用。

**对应**：EN-16。

## SR-06 被动按段落主语选择

**做法**：先看这一段主要在说谁，说谁就让谁作主语，再决定用主动还是被动。不是见“被”就改。
- 中文“被”字句多带不如意的色彩（被打、被骗、被发现）。中性事件用“被”常显得别扭：他被选为班长 → 他当选了班长。
- 欧化被动可以改：他被告知会议取消了 → 有人告诉他会议取消了／他听说会议取消了；这种做法被认为是错误的 → 大家都认为这样做不对。
- 双重被动一定拆开：这批货被要求被检查两次 → 这批货要检查两次。

**不适用**：这一段的主题就是受事时（整段都在写那封信的下落），“信被人拆过了”就是对的。施事不知道或不重要时保留被动。

**对应**：EN-12、EN-13。书里的标题是“用主动语态”，正文接着说这不等于完全放弃被动，被动常常方便、有时必要。所以这里采纳“按主语选择”和“拆双重被动”两条。

## SR-07 要强调的放句末

**做法**：中文的新信息、重点通常落在句末。把想让读者记住的词放在最后；句尾是旧信息、虚词或附加说明时，调整语序。

**例**：
- 原：那个名字，林晚，他终于说出了口，在沉默了很久之后。
- 改：沉默了很久，他终于说出了那个名字——林晚。

**不适用**：
- 不是每句都要追求金句结尾。连着几句都用重音收尾，节奏反而单调。
- 段落最后一句：说明性段落的末句给出本段的重要后果，既回扣了主题，又落在句末，不必二选一；末句的新东西不属于本段时，移到下一段或改成过渡。叙事和高潮段按作者要的效果处理（见 EN-22）。

**对应**：EN-17、EN-22。

## SR-08 连续同型句要换

**做法**：连着三句以上同一个句式（“他……。他……。他……。”或一串“……，然后……，接着……，又……”）时，换掉其中几句的结构：合并成一句，换主语，改成短句和长句交替。改到单调感消失为止，不必每句都改。

**例**：
- 原：他走进屋子。他放下包。他打开了灯。他看见桌上有一封信。
- 改：他走进屋子，放下包，打开灯——桌上有一封信。

**不适用**：作者有意的排比、重复和短句连击（打斗、追逐、情绪爆发）保留。“三句”只是扫描时的提示，不是规定。

**对应**：EN-19。

## SR-09 并列的东西外形一致

**做法**：并列的词语词性和结构一致；关联词两边结构相同；列举时要么每项都带量词或介词，要么都不带。

**例**：
- 原：他既是一个好父亲，又很爱自己的工作。
- 改：他既是个好父亲，也是个尽职的医生。／他爱孩子，也爱自己的工作。

**不适用**：为了强调或节奏，有意变换句式时保留。

**对应**：EN-15。

## SR-10 删不起作用的词，不是越短越好

**做法**：每删一处都问：删掉以后，意思、范围、语气变不变？不变才删。常见可删的：
- 语义重复：凯旋归来、亲眼目睹、悬殊很大、大约……左右、涉及到、过分溺爱、免费赠送。
- 空转结构：进行了讨论 → 讨论了；作出了决定 → 决定了；开始哭了起来 → 哭了起来；对……进行调查 → 调查……。
- 多余的“一个”：他是一个很好的人 → 他人很好。
- 多余的“的时候”“了”“着”“地”：当他回到家的时候 → 他回到家时。
- 一个意思拆成好几句慢慢说：合并成一句，合并后检查限定条件有没有丢。

**不适用**：
- “只、都、仅、除非、除了、几乎”等限定范围的词，删了会改变意思。
- 人物说话啰嗦是性格时保留。
- 不设字数上限，不为了短删掉证据、反例或必要的过渡。

**对应**：EN-25、EN-26。

## SR-11 具体、确定、可感，但不添事实

**做法**：抽象的评价和概括（“他很生气”“环境很恶劣”“那段时间很难熬”）在需要读者“看见”的地方，可以换成能看见、能听见的动作和细节。只补能改变读者画面的那一两个，不堆形容词。

**例**：
- 原：他很生气。
- 改（上下文已写过他把茶杯攥得很紧）：他把茶杯往桌上一顿，茶水溅了一手。

**不适用**：
- 原文没有的事实不能替作者编。需要新事实才能具体时，标成问题：“这里想写他做了什么？”
- 节奏快的段落、概述性的过场，抽象概括本来就是合适的写法。
- 网文和通俗小说里适度的直接陈述（“他怒了”）是读者接受的节奏，不必每处都改成动作。

**对应**：EN-27。

## SR-12 套话整句重写，不换同义词

**做法**：套话的问题不在用词，而在没说出具体的意思。换个同义词，句子还是空的。先问这句到底想表达什么，再整句重写；说不出具体意思时，考虑整句删掉。

常见的 AI 腔和网文套话（编辑经验，不是来源规则）：

| 类型 | 例子 | 处理 |
|---|---|---|
| 神态模板 | 嘴角勾起一抹弧度；眼中闪过一丝寒芒；眉头微微一皱 | 问这个表情在这一刻说明什么，换成这个人物特有的反应，或者删掉 |
| 气氛模板 | 空气仿佛凝固了；时间仿佛静止了 | 写在场的人具体怎么了（谁停下了筷子，谁没接话） |
| 情绪直陈 | 心中五味杂陈；一股暖流涌上心头 | 写引起情绪的那个具体东西，或者让人物做出与情绪相符的动作 |
| 比喻堆叠 | 一段里连用几个“仿佛”“宛如”“犹如” | 留最准的一个，其余删掉 |
| 段尾升华 | 这一刻，他终于明白了……；也许这就是成长吧 | 让上文的事件自己说话，删掉总结句 |
| 程式化起句 | 与此同时；不知过了多久；就在这时 | 偶尔用可以，连续使用时换成具体的时间或动作衔接 |

**不适用**：人物对白里的套话可能正是人物性格（爱说场面话的人）。类型小说的部分固定说法是读者期待的标记，不要一律清除；只处理重复出现、已经失去意义的那些。

**对应**：EN-28（书中要求陈词整句重写，不做一词替换）。

## SR-16 改动可回退，作者有最后决定权

**做法**：
- 每处修改都能对回原句。直接交付改稿时，附主要改动清单。
- 会改变语气、强度、命题范围或人物声口的修改，只作为建议。
- 两种改法各有道理时（例如段尾收束还是留新意），给出两版和各自的代价，由作者选。
- 作者已经否决过的修改，后面不再反复提。

**对应**：流程编排，不是书中原有的规则，见 [workflow.md](workflow.md)。

## 中文没有直接对应的 Strunk 规则

- **时态（EN-18）**：中文没有时态变化。对应的检查是时间标记前后一致：“了、着、过”和时间词有没有让读者弄错先后。
- **逗号与从句（EN-01–EN-05）**：英文的插入语逗号、限制性从句、逗号粘连规则不能照搬。中文一逗到底的长句另按 SR-08 和 SR-05 处理；中文标点见 [zh-mechanics.md](zh-mechanics.md)。
- **1918 年的用法清单（EN-29）**：只与英文有关。
