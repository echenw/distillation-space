# 英文段落与强调

每条规则按「规则 / 用于 / 怎么做 / 不用 / 反例 / 检查 / 自拟例 / 出口」写。「用于」和「不用」是区分条件：先判断这一处落在哪一边，再决定改不改。例子都是为说明而自创的。

## EN-17 段落的中心

- **规则**：一个段落通常围绕一个主要推进任务组织；转向新论点、时间、说话人或场景时，可考虑另起一段。
- **用于**：说明、论辩、报告、评论；一段里有两个互不相干的话题；段末跑到另一个话题。
- **怎么做**：给每段写一个短语概括它讲什么（不是抄首句），标出每句支持哪个话题；不支持任何话题的句子列为删或移的候选；按话题拆或并，不按字数拆。
- **不用**：小说段落可以按声音、节奏、视角和情绪变化组织，不必每段都有显式主题句；单一事件或单一想法的短文可以整篇一段；网页和屏幕文字的短段是载体差异，不是错误。
- **反例**：自拟一段同时讲「审批流程」和「天气风险」，两句各说一件事；每两句切一段把因果链切断。
- **检查**：拆并后确认每个话题仍完整、因果没被切断、离题句有去处。
- **自拟例**：一段写「三人核对清单」，另起一段写「核对后才发现少了一页」。
- **出口**：拆段会改变叙述节奏、或话题边界有两种划法时，给两版，停在待作者决定。

## EN-18 段落长度

- **规则**：段落长度服务阅读节奏和信息组织，没有通用的固定句数。
- **用于**：过长段落混合多个动作或论点；过短段落被无意切碎。
- **怎么做**：检查过长段里是不是混了多个推进任务，过短段是不是被排版习惯切碎；按意思调整，不按句数调整。
- **不用**：网页、屏幕和纸本文字的阅读条件不同；不要把屏幕写作习惯强加给长篇叙事；不设句数指标。
- **反例**：自拟把一段完整叙述按「每段不超过几句」切成五段；把两个不同场景硬并成一段以凑长度。
- **检查**：调整后通读，确认阅读节奏改善、没有把有意的长段或短段抹平。
- **自拟例**：一段连续写同一个动作，直到动作结束或视角切换才另起段。
- **出口**：作者以短段为固定风格时，保留并只标出可能被读成笔误的切分处。

## EN-19 过渡

- **规则**：段落之间的逻辑、时间或视角关系应足以让读者跟上；有时靠顺序即可，有时需要过渡句。
- **用于**：前后段是补充、转折、因果、时间推进、地点转换或有意跳跃；读者可能跟不上时。
- **怎么做**：先标明前后段的关系，再判断现有顺序是否足够；需要过渡超过一句时，让过渡单独成段。
- **不用**：不要为了显式连接而添加重复的连接词；有意留白可以成立；不要给每段都套一个公式化起句。
- **反例**：自拟每段都以「与此同时」开头，连续几段重复同一个连接；把有意的时间跳跃补成解释句。
- **检查**：删掉新加的过渡词再读一遍，若仍跟得上，说明过渡多余。
- **自拟例**：前后段用「清单核对完」与「少了一页」的因果自然衔接，不必另加连接词。
- **出口**：分不清是作者有意跳跃还是漏写过渡时，给「保留留白」和「补过渡」两版，停在待作者决定。

## EN-20 单句段落

- **规则**：单句段落可用于强调、转折、停顿或独立回应，但过度使用会削弱其效果。
- **用于**：文章、报告里出现单句段；段落之间需要过渡；指南式短条。
- **怎么做**：判断这一句的功能——过渡、对话、条目还是孤立细节；前三类可留，孤立细节并回相邻段或扩写；说明它为何需要独立。
- **不用**：标题、列表、对白和文学碎片不按普通说明文标准机械处理；不要把单句段当成「强调」的万能手段。
- **反例**：自拟把一条孤立的次要细节单独写成一行制造「余味」；把网页文案里所有短段都并成厚块。
- **检查**：数一数单句段是否集中出现、每一处是否说得出独立理由；说不出就并回。
- **自拟例**：转折处单起一段 `That was the last time the gate stayed open.`（自拟）
- **出口**：作者以单句段为固定节奏时，保留并在交付说明里写明代价。

## EN-21 对话段落

- **规则**：常见小说格式会在说话人变化时另起段，以帮助读者辨认发言者。
- **用于**：小说和非虚构对白；说话人切换；对白里夹叙述动作。
- **怎么做**：逐轮核对说话人、动作插入和引号范围；叙述动作跟随它所属说话人的段落；同一人连续说话中间插一个动作，通常仍在同一段。
- **不用**：剧本、聊天记录、群聊和实验性多声部文本可能使用不同格式；不要把一个说话人的连续话轮无信号地切成多段。
- **反例**：自拟把两个人的话挤在同一段，读者分不清谁在说；为了「视觉节奏」把一句话拆成三段却不标明换人。
- **检查**：遮住提示语读一遍，确认每句话仍能归到正确的人。
- **自拟例**：换人另起段，动作跟人走：`"Not yet." Ravi set the cup down.`
- **出口**：多声部或实验格式下分段规则不适用时，说明哪些项不适用，停在待作者决定。

## EN-22 强调与排版

- **规则**：斜体、粗体、全大写、破折号和独立段落都能改变强调强度，应有稳定功能。
- **用于**：辨认语气、术语、内心声音或结构层级；同类强调在全稿里含义不一。
- **怎么做**：逐项检查强调是否承担同一功能；把只在局部出现一次的强调列为待统一项，不静默套用。
- **不用**：排版规范以项目格式为准；不要把出版样式差异当成语法错误；人物声音里的夸张写法保留。
- **反例**：自拟同一份稿子里斜体一会儿表示内心声音、一会儿表示书名；把作者偶发的大写词全改成斜体。
- **检查**：列一张「强调形式 → 功能」对照，确认全稿一致。
- **自拟例**：内心声音统一用斜体，术语统一用粗体（自拟体例）。
- **出口**：强调功能定不下来时列几种体例与代价，停在待作者决定。

## EN-23 段落回归

改段后检查：说话人是否清楚、时间和地点是否连贯、段落中心是否变化、强调层级是否过密、过渡是否重复，以及是否误把有意留白改成解释。

- **检查**：把本轮所有段落改动列成一行一条，逐条读改前与改后两段；任何一条说不出「为什么这样拆／并」，就回退。
- **出口**：回读发现改动改变了叙述顺序或信息先后，撤销该处，改为建议交作者决定。

## EN-39 主题句与段落功能

- **规则**：说明和论辩段落通常以主题句开头或靠近开头，中间解释、证明或展开，末句强调主题或给出重要后果；叙事、描写和动作段没有这个默认。
- **用于**：说明、论辩、评论、报告；段落有明确论点需要导航；说明段缺主题句读者会迷路。
- **怎么做**：先判断段落功能（说明／叙事／描写／对白）；说明段没有主题句时，补写或改写首句；叙事段没有主题句时先问是否真需要，不硬加；检查中间句是否解释、证明或展开主题。
- **不用**：叙事、描写、动作段常无主题句；对白、单句段、标题不套用；不要给每段套「最……的是」一类公式；不要把动作场景改写成「论点加论据」。
- **反例**：自拟每段都以 `The most important point is…` 开头，形成固定腔调；自拟把一场追逐戏改成先给论点再举例。
- **检查**：补写主题句后确认它没有替作者新增判断或结论，只是把段落已有的意思点明。
- **自拟例**：说明段首句 `Two checks failed before the list was signed.`（自拟），后两句分别讲这两次核对。
- **出口**：补主题句需要作者没有给出的结论时，停下并把「这一段想说明什么」列为问题，不代作者立论。

## EN-40 段末的两种处理

- **规则**：说明和论辩段落的末句若给出本段主题的重要后果，回扣主题与末位强调同时成立，不必二选一；只有末句的新东西不属于本段主题时才需要取舍。
- **用于**：编辑说明、论辩段落的最后一句；作者在「收束」与「转向」之间选择。
- **怎么做**：先写本段主题，判断末句和主题的关系：是主题的重要后果或强调就保留，不改成重复首句；是离题或次要细节就移到下一段、改成过渡或删去；分不清是有意转向还是写跑了题，给 A／B 两版。
- **不用**：叙事、描写、高潮段按作者要的效果处理，末句可以留悬念或新意；作者有意用离题制造效果时不自动删；不自动选「金句结尾」，也不自动复述开头。
- **反例**：自拟每段末尾补一句「这正说明……」；自拟把无关的新细节硬塞到段末制造「余味」；自拟把主题内的新后果误判成与回扣冲突。
- **A／B 分支与出口**：末句关系判断不清时，A 版「回扣主题或给后果」、B 版「把新信息放末句」，两版都写成可回退的最小改动，列各自代价，停在待作者决定；作者选定前哪一版都不落到正文里，其余修改照做。
- **检查**：确认选择没有改变事实、没有把本段主题外的新信息伪装成后果。
- **自拟例**：本段讲「两次核对都失败」，末句 `The list went out unsigned.` 是主题的重要后果，保留即可，不必再加一句回扣。
