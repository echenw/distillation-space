# 伏笔、悬念与节奏

管三件事：**读者在等什么**（悬念），**等到的东西前面有没有埋好**（伏笔与兑现），**紧张和放松怎么排**（节奏）。

## 1. 适用与转介

用：
- 设计一个短篇、一章或一场戏的铺垫、悬念、高潮和收尾。
- 稿子有这些症状：开头抓不住、中段塌、悬念靠藏着不说、伏笔像硬塞、反转像作弊、高潮不响、章末没人想往下看、结尾拖沓或没有余味、通篇都在“炸”读者麻木了。
- 连载的章末钩子、伏笔回收清单。

转给别的 skill：
- 谁来讲、从谁的眼睛看、视角越界 → `narrative-pov-information-control`。本 skill 只用到“读者和人物各知道什么”。
- 主线、多线、因果、删场等整体结构 → `plot-architecture`；卷级和全书的连载节奏 → `serialized-volume-planning`。
- 句子、对白、标点 → `style-refinement-and-proofreading`。
- 推理小说的线索公平性：本 skill 只检查“揭晓后回看是否成立”，不判定谜题是否公平。

## 2. 使用方式

- 宿主任务规定了输出格式时按宿主格式交付；本文件的表格只在没有规定时使用。
- 普通任务读完本文件就能做。需要细则、例子和例外时，用 `skill.read` 读 §6 列出的参考文件。
- 作者给了稿子，就按稿子诊断，指出具体位置；只给了构思，就做设计；要求写正文，就按下面的规则写，并在交付时简短说明伏笔埋在哪里。
- 缺关键信息（比如还不知道结局）时，先给一个合理的假设往下做，并标明“假设”；只有假设会彻底改变方案时才停下来问。
- 本文件里的数字都是起点，不是门槛。类型、篇幅和平台习惯不同，就按实际调整。

## 3. 三条最短路径

### 设计（从构思到可写）

1. **定终点**（SU-01）：写下最后一拍——最后一个画面或一句话，加上读者合上书时的情绪。长篇写这一章或这一单元的终点。写不出时，先给两三个候选。
2. **定高潮**（SU-02）：最后一拍扩成全篇代价最高的一场；其余场次标 1–5 的强度，前面不能有同类更强的场次。
3. **画知识表**（SU-04）：读者、主角、对手各知道什么；决定这一段靠悬疑（读者知道得少）、反讽（读者知道得多）还是惊奇（揭晓时同步）。
4. **抛问题、排阶梯**（SU-03、SU-05）：开头就让读者知道在等什么；通往高潮的问题或事件逐级加码，每级只升一种代价。
5. **埋伏笔**（SU-06 至 SU-08）：高潮和揭晓用到的东西提前出现一次，出现时另有当下的用处；需要误导时，误导要能在回看时找到反证。
6. **排节奏**（SU-10 至 SU-14）：一个阅读单元一个主峰；峰前可以放一个短的松弛，紧接急转。
7. **收尾**（SU-15 至 SU-18）：连载章末留一个真问题；全篇结尾先结算承诺，再在效果达成处停。

### 诊断和修改（已有稿子）

1. 先读完给定范围，记下读者在每个位置“在等什么”。说不出来的地方，就是悬念断了。
2. 按 §4 的症状表找对应规则，逐条写：`位置 | 症状 | 原因 | 规则 | 改法 | 代价`。
3. 改法先选最小的：移动一个信息的位置、加一处伏笔、删一段解释，然后才考虑重排场次。
4. 改完回看：揭晓前的伏笔还在吗？新加的伏笔有当下的用处吗？高潮仍然是最强的一场吗？

### 章末和结尾检查（连载、长篇）

1. 列出每章最后一场、最后一句。
2. 每章三查（SU-15）：状态变了吗？留下了什么真问题？这个问题读者是不是早就猜到、却一直被拖着？
3. 把每个钩子记进兑现日志（SU-16）：哪章抛出、哪章回答。连续几章是同一个问题，说明中段没有进展。
4. 全篇或全卷的结尾按 SU-17 结算。

## 4. 症状速查

| 症状 | 先看 | 常见原因 |
|---|---|---|
| 读者不知道在等什么 | SU-03、SU-04 | 问题没有早给；知识表里读者一栏是空的 |
| 悬念靠“作者不说” | SU-04、SU-07 | 把惊奇写成了藏信息；揭晓后回看不成立 |
| 读者早就猜到了 | SU-04、SU-05 | 类型惯例已经告诉读者答案；阶梯第一级就是最高级 |
| 伏笔像硬塞 | SU-06 | 伏笔出现时没有别的用处，只是在“提醒读者” |
| 反转像作弊 | SU-06、SU-07、SU-08 | 前文没有可回看的线索；靠叙述者撒谎；异常没有现实解释层 |
| 高潮不响 | SU-02、SU-06 | 前面有同类更强的场次；高潮场同时在建立设定 |
| 中段塌 | SU-05、SU-11 | 阶梯不升级、只重复；没有松弛和急转的落差 |
| 通篇都在炸，读者麻木 | SU-10 | 一个单元多个主峰；峰值类型从不变化 |
| 转折了但读者没感觉 | SU-12 | 用“他突然明白了”通知读者，没有可见的标记 |
| 情绪跑调 | SU-14 | 基调没定，意象各说各的 |
| 章末没人想往下看 | SU-15、SU-16 | 章末状态没变；钩子是切断句子而不是真问题 |
| 结尾拖沓或像说教 | SU-17、SU-18 | 效果达成后还在交代；寓意在中途就被说破 |
| 结尾欠账，读者问“后来呢” | SU-17 | 开篇的承诺没有结算 |

## 5. 规则卡

完整说明、例外和例子见参考文件；括号里是主要来源（详见 `references/source-index.md`）。

### 伏笔与兑现（`references/setup-and-payoff.md`）

- **SU-01 终点先行**：动笔前先知道最后一拍和它的情绪，再倒推必需的事件；不在必需清单里的降为可选。短篇定终场，长篇定方向和本单元终点。不适用：发现式写作的作者可以先写，但改稿时必须补上终点再回头删。（Poe；Hamilton；Klickmann；Wharton 等）
- **SU-06 伏笔要有当下的用处**：高潮和揭晓用到的人、物、信息、能力，提前以“看似无关”的方式出现一次，出现时另有别的功能；揭晓后，前文至少两处获得新意义。不适用：太显眼会被猜到，太隐蔽读者会觉得被骗——请一个没看过大纲的人读一遍。（Lubbock；Poe）
- **SU-07 误导可回溯**：把 A 写成像 B，来延长好奇；误导要推动当下的动作，修正时给新证据，回看时能找到当时就在的反证。不靠叙述者隐瞒自己知道的事。同类误导的起点是不超过两次，第二次要升级。（Poe）
- **SU-08 异常配现实解释层**：超常、离奇的事，先给一条现实的解释线（天气、习性、误会、人为），留可回查的细节，让超自然读法成为读者的选择。不适用：设定本来就是奇幻或玄幻时，改为守住设定内部规则的一致。（Poe）

### 悬念与揭晓（`references/suspense-and-reveal.md`）

- **SU-03 问题早给，答案晚给**：开头就让读者知道他在等什么；中间只加阻力，不换问题；答案留到最后。（Hamilton；Klickmann；Lope de Vega）
- **SU-04 先画知识表，再选悬念方式**：行是读者、主角、对手，列是关键信息。读者知道得少是悬疑（快感来自“能不能解决”），知道得多是反讽（来自“他会不会发现”），同步揭晓是惊奇（来自“怎么会”）。同一条线索只选一种，不要“读者都知道了、人物还装不知道”。（Archer；Hamilton；Flickinger；Lubbock 等）
- **SU-05 阶梯加码**：通往高潮的问题或事件分几级，第一级是日常、低代价的，此后每级只升一种代价（亲密、损失、不可逆）。常用三到六级。不适用：动作场面改成同一目标、障碍逐级加码；喜剧的代价换成尴尬程度。（Poe）
- **SU-09 收紧空间或时间**：把关键事件放在边界清楚的小空间或限定时间里，每升一级就收紧一次。不适用：以移动为结构的故事（公路、逃亡），改为“移动中的封闭单元”（车厢、船舱）。（Poe）

### 强度与节奏（`references/intensity-and-rhythm.md`）

- **SU-02 高潮是强度上限**：高潮先定，作为全篇的标尺；前面若有同类更强的场次，要么降级（缩篇幅、降修辞、移走信息），要么把它升为新高潮并重排。降级只降强度，不降因果必要性。不适用：多峰值的冒险和网文爽点结构，每章内部仍只有一个主峰，章与章之间换峰值类型（动作、情感、信息）。（Poe）
- **SU-10 按阅读单元排强度**：短篇的单元是全篇，长篇是章或场景。一个单元一个主峰；相邻单元的主峰换类型；强度不可能持续拉满，连续高压会让读者麻木。（Poe）
- **SU-11 松弛与急转**：在通往高潮的路上放一个短的轻拍（一个玩笑、一个笨拙细节、一段日常），紧接着急转。轻拍由人物发出，不是叙述者嘲笑人物；急转之后不再回到同一个轻拍。不适用：很短的单一场景，插入松弛会稀释唯一的峰值。（Poe；Barrett）
- **SU-12 转折先给可见标记**：转折前给人物一个身体、感官或动作上的标记，让读者跟着转；删掉“他突然意识到”“他终于明白”；转折后加速，少解释。（Poe）
- **SU-13 母题重复：本体不变，语境变**：选一个短的固定元素（一句话、一个动作、一件物品），每次出现换语境和所指，本体不改；第一次出现要平淡。次数以读者认得出、又不厌烦为准。中文可以借同韵、同句尾、同一称呼来预演。（Poe）
- **SU-14 先定基调**：先用一个词定这一篇或这一场的情绪，再选意象和题材；不服务基调的意象删掉。不适用：多线长篇每条线可以有自己的基调；拼贴式喜剧靠基调断裂取效。（Poe）

### 章末与结尾（`references/chapter-ends-and-endings.md`）

- **SU-15 单元末三查**：状态变了吗？留下什么真问题？这个问题是不是早被读者猜到、却一直在拖？分次阅读（连载、日更、分卷）的章末留一个未解的真问题；一次读完的短篇只需要一个总收束。钩子是“需要回答的问题”，不是把句子切断。（Archer；李渔；Klickmann）
- **SU-16 钩子必须兑现**：每个钩子记进兑现日志（抛出章、回答章）；下一单元要兑现上一单元的承诺；不兑现的钩子删掉。连续三章章末是同一个问题，说明中段没有进展。（Hamilton；Klickmann）
- **SU-17 结尾两步**：先把开篇许下的承诺（欲望、谜题、威胁、关系）逐条结算；再找到效果完全达成的那一句，试删其后全部。多线长篇允许收束段，但每段结算一条线；系列的单卷末尾可以留钩子。（Hamilton；Shedlock；Chunn；Klickmann）
- **SU-18 潜流与末行**：保留一条不解释的暗线（一个物件、动作或话），它不承担破案、救人这类情节功能，只承担意义；象征义不要在中途由人物说破，压到最后。不适用：寓言、儿童文学和需要明说寓意的作品，改为开头明示寓意、每次变奏加深。（Poe）

### 交付前（`references/diagnosis.md`）

- **SU-19 数一数再判断**：交付前数一遍：主峰几个、在哪；阶梯每级升了什么；母题出现几次、语境是否都变了；钩子是否都有兑现章；结尾在效果达成后还写了多少。数字只用来发现问题，不是及格线。

## 7. 冲突时的顺序

规则互相打架、又没有作者的明确要求时，按这个顺序取舍：终点和高潮（SU-01、SU-02）→ 读者在等什么（SU-03、SU-04）→ 伏笔可回看（SU-06、SU-07）→ 节奏（SU-10 至 SU-14）→ 修辞性的手法（SU-13、SU-18）。两种做法各有代价时，给作者两个方案，由作者选。

## 8. 来源与可信度

- Poe 的规则来自他对自己一首诗的创作回顾。同一卷的编者序就指出，这份回顾可能是事后的建构，Poe 自己也承认作者通常无法还原写作步骤。因此这些规则是可检验的手法，不是 Poe 的写作史，也不是定律；适合短篇和单场景，用于长篇时以章或场景为单元。
- 悬念、章末、结尾的规则（SU-03、SU-04、SU-15 至 SU-17）有多部 1609–1929 年的写作和戏剧手册互相印证，舞台证据比小说强；连载章末是从舞台幕末类比过来的。
- 所有“读者会……”的说法都是设计假设，不是读者研究的结论。是否采纳由作者决定。
