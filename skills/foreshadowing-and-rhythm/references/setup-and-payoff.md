## SU-01 终点先行

**规则**：动笔前先知道最后一拍——最后一个画面或一句话，以及它要留给读者的情绪；再从那里倒推必需的事件。不在必需清单里的事件，降为可选。

**怎么做**：
1. 写一到三句“最后一拍”。只写画面、动作或一句话，不写主题总结（“他终于明白了亲情的可贵”是论文，不是画面）。
2. 旁边写一个情绪词：不甘、释然、发冷、怅然。
3. 列出三到五个“要到达这一拍必须先发生”的事件。
4. 逐段倒推：读者要先知道哪件事，才会相信下一步？每段标一个“积势动作”，标不出的删掉或合并。
5. 检查终局是不是“意外但唯一正确”：如果读者能轻易想出另一个同样成立的结局，说明前文还没有把它锁定。

**篇幅不同，定的东西不同**：
- 短篇、单章、单场景：定终场画面和最后一句的方向。
- 长篇、连载：只定终局状态（谁最后得到或失去了什么），允许章节在写作中发现；每个单元（章、卷）定自己的终点。
- 侦探、推理：先抛谜面，但作者必须知道谜底和机关，再从谜底倒推第一步。

**例外**：
- 发现式写作的作者（先写再找结尾）可以照常写初稿，但改稿时要补上终点，再回头删掉与它无关的部分。
- 真实历史、传记题材，结局不能改：改为先定“讲到哪里为止”。
- 反例：Trollope 自述连载时边写边编情节（PG38887 L2541）；Stribling 说写长篇时“结尾并不清楚地在心里”（PG61625 L2941）。说明先定结局是一种工序选择，不是道德要求。

**检查**：不看稿能复述最后一拍；最后一拍里有具体的动作或物件；每一场都能回答“它怎样把人物推向这一拍”。

**依据**：
- Poe：情节必须推到结局才动笔，“every plot, worth the name, must be elaborated to its dénouement before anything be attempted with the pen”（PG55749 L105–107）；作品“开始于结尾”（L359–360）。
- Hamilton：叙事在结构上必须先完成，才能在写作上开始（PG30183 L2558–2560）；“he must see the end of his story from the beginning”（PG30776 L2187）。
- Klickmann：高潮从第一句起就必须在作者心里（PG36837 L4993–4994）。
- Wharton：“no conclusion can be right which is not latent in the first page”（PG72446 L1802–1803）。
- 另有 PG38887 L1108–1109、PG72910 L3034–3035、PG61625 L1138–1139 同向。

## SU-06 伏笔要有当下的用处

**规则**：高潮和揭晓要用到的人、物件、信息、能力，提前出现一次；出现时它看起来另有用途，读者不会觉得“这是伏笔”。揭晓之后，前文至少有两处获得新的意义。

**怎么做**：
1. 列出高潮或揭晓需要的两三把“钥匙”：谁知道什么、手里有什么、东西在哪。
2. 在前三分之二的篇幅里，让每把钥匙以另一种用途出现一次：一件道具先用来做别的事；一个信息先以闲谈、玩笑或误会的形式出现。
3. 高潮时让钥匙带着新意义重现，不重新介绍。
4. 揭晓后回看：哪两处前文因此获得了新意义？找不到，说明伏笔不够；只有一处而且太显眼，说明会被猜到。

**伏笔太显眼和太隐蔽的判断**：
- 太显眼：伏笔出现时，叙述停下来特别描写它，或者人物无缘无故提起它。改法：让它卷进当下的动作里，或者用一个更醒目的东西遮住它。
- 太隐蔽：揭晓后读者翻回去也找不到，或者伏笔只出现在一句无关紧要的描写里。改法：让它在另一个场景里再出现一次，换一种用途。
- 拿不准时，请一个没看过大纲的人读，问他事后能不能找到伏笔、事前有没有猜到。

**例外**：
- 纯惊奇（读者事先不知道有问题，见 SU-04）仍然需要可回看的线索；没有线索的惊奇会伤读者的信任。
- 叙述者本身不可靠时，可以合法地暂存信息，但结尾要给出他不可靠的证据。

**检查**：每个揭晓都能在前文找到至少一处伏笔；每处伏笔出现时都有当下的功能；删掉伏笔所在的那句，当下的场景是否还成立（成立说明伏笔藏得自然）。

**依据**：
- Lubbock：结局要用到的人物“must be held in readiness”（PG18961 L2097–2098）；故事的高潮早早就存放在前面的描写图景里（L5360–5366）。
- Poe：首次出现的固定元素要平淡（PG55749 L270–281 的用法），意义在后面逐次积累。
- 回看线索的数量（“至少两处”）是本 skill 的操作建议，不是来源原话。

## SU-07 误导可回溯

**规则**：用一次误认（把 A 当成 B）延长好奇。误认要推动当下的动作；修正时给出新证据；事后回看，能在当时的段落里找到反证。不靠叙述者隐瞒他明明知道的事。

**怎么做**：
1. 写清三件事：角色以为是什么 / 实际是什么 / 读者此刻被允许知道到哪一步。
2. 让误认推动一个动作：开门、追出去、叫人、做出错误的决定。
3. 修正误认时给一个新的物证或新的感官信息（声音更近、更具体），而不是叙述者一句“其实我早就知道”。
4. 同类误认的起点是不超过两次；第二次要升级（更近、更贵、更不可逆）。

**例子（Poe 的诗）**：乌鸦拍窗先被写成“有人敲门”（PG55749 L429–430 说明这样写是为了延长好奇）；第一次开门，门外只有黑暗（L596）；第二次是低语和回声的假线索（L605–606）；随后声音更近、更具体，来自窗格（L612–613）。每一步都可以回查。

**例外**：
- 需要读者全知的讽刺叙事，误认会削弱反讽。
- 推理小说按公平性惯例要求线索及时出现时，误导不能挡住关键线索。

**反例**：叙述者故意略去关键事实，事后说“我早看见了”。这不是误认，是作弊。需要隐瞒时，改用限知视角（角色自己判断错了），或者明确使用不可靠叙述者。

**检查**：重读误认发生的那一段，能找到“当时就存在的反证”。

## SU-08 异常配现实解释层

**规则**：故事里出现超常、离奇的事时，先给它一条完全现实的解释线（天气、动物习性、误会、机关、人为），在正文里留下可以回查的细节，让“超自然的读法”成为读者的选择，而不是作者强加的。

**怎么做**：
1. 给异常写两三条现实解释，至少两条能在正文里找到细节支撑。
2. 让角色先按现实解释行动一次：检查窗户、问对方是谁、找机关。
3. 不删超自然读法，但始终保留“也可能是巧合”的通道。
4. 结尾要点明超自然时，只点明它的意义，不改写已经发生的物理因果。

**例子**：Poe 先让夜里起风暴，给乌鸦进屋找一个理由（PG55749 L435–436）；全诗保留一层“完全可以解释”的读法（L491–492）；诗里明说乌鸦只会说这一个词（L664），重复因此有了现实依据。

**例外**：高奇幻、玄幻、科幻等设定本身就超常的作品，现实解释会破坏世界规则。此时改为守住设定的内部规则：异常要符合已经交代过的规则，或者它本身就是对规则的揭示。

**检查**：重读时，读者能指出至少两个“当时就可以这样解释”的细节。
