# 复仇与代价账本（RC-1 / RC-2 / RC-3）

本批最重要的一条裁决：**"复仇必须由受害者本人执行并清算到具体加害者"不是通用规则，只是四条分支之一。**
16 部里同时具备"身份伪装 + 个人复仇清算 + 权谋机器"的作品一部也没有。

## RC-1 复仇分支判定（三条全 ✓ 才走"清算"）

| 条件 | 判据 | 证据 |
|---|---|---|
| ① 加害者可指名 | 能写清"谁做的、在何场合、凭什么权力" | ✓ PG965（Boxtel 的三次犯罪可逐项指认，L7229-7235）；✗ PG2802（驱逐由法庭、警长、白人定居者共同完成，L7321-7329） |
| ② 受害者握有可执行杠杆 | 物证、武力、舆论位、准入权，四者至少其一 | ✓ PG965（第三颗球茎 + 教父的焚信原件，L8492-8560）；✗ PG2480（Razumov 的杠杆是"被识破即死"，是负资产） |
| ③ 叙事需要一个可归因的结算对象 | 结局要回答"这笔账算在谁头上" | ✓ PG965；✗ PG3608（结算对象是制度，L1664-1666） |

缺任何一条 → 改走下列分支（不要硬凑清算）：

- **逃离分支**：目标从"扳倒"改为"脱身并重建生活"。F：PG2802 L11106-11154（"日出前我想离开"）、L8160-8171（改名＝另起身份）。
- **制度抗争分支**：把个人账变成公共议题。F：PG433 L5918-5930 / L6008-6012（以禁令与起诉为教材）；PG3608 L1664-1666（真正的敌人是捍卫现状的同伴）与 L22049-22053（唯一 remedies 是生产资料的公有与全国性组织）。
- **自我清算分支**：加害者自己供认，代价仍落在自己身上。F：PG2480 L11985-12002、L12015-12017、L12184-12187。
- **牺牲分支**：以自我牺牲中断伤害链，不留清算对象。F：PG60627 L2498-2502（"要么这个人，要么这个姑娘"）、L2646-2649（以威胁逼退对方）。

## RC-2 代价账本：每一次"扳倒别人"都要写付账人

模板（每一行动一行）：

```
行动：<谁对谁做了什么>
直接代价：<谁失去什么>
外溢代价：<旁观者/后代/社群失去什么>
未付账项：<谁本该付却没付>   ← 这一格空着就是漏洞，除非作者有意为之
```

- 刻意让代价全落在受害者一侧，是合法写法而非漏洞，但必须写清楚"这是刻意的"。F：PG2802 L13517-13521、L7472-7473（"有福的是极幼与极老，因为他们死了"）。
- 反过来，加害者全身而退而旁观者付账，若不写出作者意图，就是机制漏洞。F：PG60627 L3151-3200（迁走者病死、留下者被丛林吞没）。
- 复仇成功的代价常落在复仇者最想保护的人身上。F：PG965（Boxtel 在会场倒毙，L9982-9989；而清白者活下来）。
- 代价也可以不由人付，而由"名字"付：PG2802 L9858-9860（婚姻登记把 Ramona 写成 Majella Fayeel，这个名字从此消失）。

## RC-3 结算形态：先选形态，再倒推证据链

| 形态 | 含义 | 前置证据 | 来源 |
|---|---|---|---|
| 复位 | 正位恢复，主角退出舞台 | 官方口径改写 + 知情者封口 + 主角的放弃 | PG95 L6006-6025、L6429-6455 |
| 清算 | 加害者被指认并付出代价 | 可指名 + 可执行杠杆 + 有裁决者 | PG965 L9971-9980、L10027-10032 |
| 耗损 | 真相已明，但无人复位 | 伤害不可逆（死亡、残疾、失名、失地） | PG2480 L12184-12187；PG2802 L13308-13309、L13517-13521 |
| 悬置 | 转入下一阶段，本账不结 | 运动/制度仍在运行 | PG433 L6008-6012；PG9840 L20638-20639（文本中断） |

反例（**不要**默认封闭复位）：
- PG2158：主角卧轨自尽（L22901-22953），秩序恢复但主角不在场。
- PG3608：无个人结局，以运动式终句收束（L27235-27245）。
- PG60627：村落被丛林收回（L5682-5760 台账概述，本包只作 H 使用）。

## 与"法律/制度救济"的边界

本批 16 部**没有任何一部**把正式法律程序写成主角的正义来源：
PG965 靠亲王口头裁断（L10027-10032）；PG60627 的法庭是构陷场所（L3871-3897）；PG2802 无救济（L12432-12434、L12545-12547）；PG433 的起诉与禁令是压迫工具（L5918-5930）。
→ 若用户要求"交给法律解决"，走 SKILL.md §5 的 F-5 出口：声明未证明，要求用户自行给出制度设定。
