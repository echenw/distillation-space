# 未决冲突登记（X-1 … X-4）

这些冲突在本批内部**无法统一**。本文件的职责是阻止把它们压成一句口号。
遇到用户要求"统一成一条规则"时，走 SKILL.md §5 的 F-4 出口。

## X-1 结算该归因于个人复仇，还是制度抗争？

- 个人侧：PG965——加害者可指名、有物证、有裁决者，清算成立（L9971-9980、L10027-10032）。
- 制度侧：PG2802（L7321-7329、L13517-13521）、PG60627（L672-695、L3871-3897）、PG3608（L1664-1666）——受害者没有可指名的对手，也没有可用的杠杆。
- **不统一的理由**：两者的差别不在道德判断，而在"加害者是否可指名 + 是否有可执行杠杆"（`revenge-cost-ledger.md` RC-1）。
- **选择条件**：先跑 RC-1 的三条；三条全 ✓ 才走个人清算，否则走制度抗争/逃离/牺牲分支。
- **禁止**：不得写"复仇是弱者的正义"或"制度抗争更高级"这类统合判断。

## X-2 个人德性 vs 派系机器，谁决定成败？

- 机器胜：PG7374——德性完好、无丑闻的 Harrington 仍被席位交易击败（L5981-5982、L6140-6158）。
- 自我胜：PG1047——Remington 的崩塌源于欲望与自我分裂，而非对手（L11218-11231、L12669-12672）。
- 勉强撑住：PG2158——公爵靠"厚脸皮"与同僚兜底维持到多数消失（L15231-15233、L27707-27710）。
- **不统一的理由**：三部作品的权力出资方不同（跨国资金／党内提名／党内多数）。
- **选择条件**：先填 `power-machine.md` PM-1 的三格，按"出资方是谁"决定德性的权重。
- **禁止**：不得写"只要正直就能赢"或"正直毫无用处"。

## X-3 世俗权谋 vs 神话/宗教式权力重构

- 世俗侧：PG433、PG7374、PG2158、PG1047、PG9840——党派、资金、报界、档案。
- 神格侧：PG73677——权力由信条、仪式、圣地与"活神"身份重构（L3367-3369、L15053-15061、L17183-17184）。
- **互不迁移**：神格轴的"身份被公开神格化"与伪装轴的"身份必须隐藏"是相反机制；世俗权谋的"对价交换"在神格轴里没有对应物。
- **选择条件**：看作品中权力是否需要**信众的内化认同**（神格轴）还是只需**席位与资金**（世俗轴）。

## X-4 劳动叙事：控诉同伴 vs 组织夺权

- PG3608：最尖锐的控诉指向被压迫者自己——"他们才是敌人，因为他们不仅默默服从，还捍卫现状"（L1664-1666）。
- PG433：给出可执行的组织 Program——先夺市，再夺县、区、州（L4035-4038）。
- **张力保留**：前者是对同伴的伦理控诉，后者是对 Program 的规划，两者不属同一层面。
- **禁止**：不得合成"既要唤醒工人又要组织夺权"的口号；若要同时写，必须分别给出场景与代价（见 `revenge-cost-ledger.md` RC-2）。

## 附：本批明确"未证明"的一项

**R8 制度性正义**：本批没有任何一部把正式法律程序写成主角的正义来源（PG965 靠个人裁断；PG60627 的法庭是构陷场所；PG2802 无救济；PG433 的起诉是压迫工具）。
因此"交给法律解决"在本技能中为 **NOT_PROVEN**，只能作为反派工具写入，不能作为结算出口。
