# 权力机器（PM-1 … PM-5）

用于派系型、群像制度型，以及任何"主角要撬动一个组织"的场景。
**核心方法：把机器拆成三个可核查部件，拒绝"权谋靠聪明"的抽象写法。**

## PM-1 三部件：出资方 / 记档方 / 广播方

每次写权谋场景，先填这三格：

| 部件 | 要回答 | 证据 |
|---|---|---|
| 出资方 | 谁给钱，钱换到了什么 | PG433 L4484-4485（"各帮各捐了两万五千元"）；PG7374 L5119-5139（跨国资金与代理权） |
| 记档方 | 谁掌握名单、账目、档案，谁能写进去也能划掉 | PG7374 L5119-5139（万余姓名的政治 ledger）；PG1296 L85-86（"公职者的行为是公共财产"＝账目的正当性来源） |
| 广播方 | 谁能把一件事变成公共事实 | PG2158 L18811-18813（报界社论）；PG433 L5918-5930（三报同调＋禁令） |

三格填不出 → 这台机器在本作里不存在，主角也就无从撬动；先补机器，不要先写聪明话。

## PM-2 派系的真实边界：没有"盟友"，只有"待价而沽的席位"

- 派系能做到的极限是交换席位与豁免，不是兑现理想。F：PG433 L4686-4688（改革运动是老板为自身利益组织的骗局）；PG7374 L5981-5982（"你若同意反对自由贸易，我就把你做成参议员"）。
- 组织权可以借名望换取。F：PG9840 L1470-1492（"给我您的名望与影响，组织全由我承担"）。
- 因此写联盟戏时，必须写出**对价**：谁让出什么、谁拿到什么、违约时谁先被卖。F：PG7374 L6140-6158（"我相信他是被卖了"）。

## PM-3 秘密为何致命：看有没有"广播机构"

判定顺序：
1. **有广播机构**（报界 / 党机器 / 法庭 / 庇护网络）→ 个人秘密是主风险，必须安排"谁广播、广播后第一个后果是什么"。
   F：PG1047 L11218-11231（"这是政治自杀"）、L13395-13492（私怨被升级为公共攻势）。
2. **只有交易型派系、无广播机构** → 风险来自站队与对价，不来自道德。F：PG7374 L4482-4502 + L6140-6158（无丑闻仍落败）。
3. **小共同体、两者皆无** → 秘密通常不致命。F：PG1296 L3033-3034（权威命令已不足以治人，靠记录与程序而非丑闻）。

反例登记：PG1806（栽赃被反向拆解，L822-829）说明"有广播机构"也可以被主角利用——但解法是 §ID-4 的三步，不是运气。

## PM-4 工具不是中性的：先问"准入权在谁手里"

对每个工具（法庭、许可、登记、报界、教会、慈善）先答两问：
1. 谁能决定"谁可以使用它"？
2. 误用的代价由谁承担？

- 准入权在对方手里 → 该工具是伤害来源，不能写成主角可动用的手段。F：PG60627 L672-695（chena 许可）、L3871-3897（伪造赃物构陷）；PG2802 L12432-12434（登记册）、L13517-13521（陪审团不会为印第安遗孀定白人罪）。
- 弱势方唯一的杠杆是把压迫工具**反向**使用，且必须写出代价。F：PG433 L6008-6012（多恩反而要维持禁令，因为禁令起了团结工人的作用）。
- 荒诞型司法（无辜仍被罚金、程序自毁）不能当作"制度纠错"来写。F：PG18972 L485-507、L658-659。

## PM-5 反派动机：嫉妒只在"近距离同类竞争者"里可靠

- 可靠：同行、邻居、同学、同一沙龙/同一选区。F：PG965 L2016-2020（郁金香从爱好变成痛苦来源）；PG7374 L4539-4541（"没有比受伤的虚荣之怨恨更甚者"）；PG2802 L3462-3463（"种子开花了，Ramona 有了一个敌人"）。
- 不可靠：跨阶级的制度性伤害。F：PG3608 L1664-1666（压迫者不是嫉妒者，是制度与自愿为奴的同伴）；PG60627 L621-623（债务才是村子的主发条）。
- 机器内的生存条件：厚脸皮比清白更能续命。F：PG2158 L15231-15233（"谨慎但不怯懦、大胆但不冒险，最重要的还是厚脸皮"）。

## 本文件禁写的三条

1. 不要写"主角凭一场演说翻转派系"——PG7374 的演说赢得掌声，选举仍被交易决定（L6140-6158）。
2. 不要写"制度会纠错"——本批无一部支持（见 `conflict-ledger.md` X-3 / R8）。
3. 不要写"只要拿到证据就能翻案"——证据能否生效取决于准入权（PM-4）；PG965 的翻案靠的是个人裁断（L10027-10032）。
