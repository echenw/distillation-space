# 身份·复仇·权谋 小说机制工作台

面向"身份置换 / 复仇清算 / 权力机器"这一题材标签的小说写作与改稿。
本技能来自 16 部来源的逐本阅读与融合（`B-07-B03`），每条规则都能在 `references/source-index.md` 回查到作品与行号。

**先记住一条最重要的事实**：这 16 部里，同时满足"身份伪装 + 个人复仇清算 + 权谋机器"三要素的作品**一部也没有**。
所以本技能不提供"身份复仇小说必须怎样"的铁律，而是提供**分轴判定 + 条件分支 + 反例**。
把任何一部作品的情节设计升格成通用规则，都会被其余作品推翻（反例集中在 `references/conflict-ledger.md`）。

## 1. 触发与负触发

**触发**（任一）：
- 用户在写/改一部含冒名顶替、隐秘出身、双重身份、告密背叛的小说；
- 用户问某个复仇或权谋设定"为什么不成立""下一步合不合理""怎么收尾"；
- 用户要求诊断草稿里身份、秘密、派系、代价四条线索是否自洽；
- 用户要设计"谁在骗谁、谁付代价、谁最后知道"。

**负触发**（明确不做）：
- 现实政治、选举、组织斗争的操作建议——本技能只处理虚构叙事机制；
- 非虚构、散文、剧本以外文体且不涉上述机制；
- 只要求"续写一段"而不给任何机制信息——先走 §5 失败出口 F-1；
- 要求把单部作品的情节（如《黑郁金香》的翻案、《弗兰姆》的反向拆解）当成所有作品必须遵守的规则——走 F-4。

## 4. 执行步骤

### 流程 D｜诊断（有草稿/设定，阶段=草稿·改稿）

1. **D1 定权力轴**（`id-disguise-engine.md` ID-1）
   看"被人相信的身份"在本作里是不是被争夺的稀缺资源：
   - 是 → **伪装轴**（判据：有人凭身份拿到准入、有人因身份被排除）；
   - 身份是被外界强加的污名、主角无从选择 → **污名轴**（不要套伪装规则）；
   - 身份被公开神格化/仪式化 → **神格轴**（不参与世俗权谋规则）；
   - 重点是制度与群体而非个人身份 → **群像制度轴**；
   - 重点是党派、资金、报界 → **派系轴**。
   反信号：若四条都不明显，先别加机制，把问题回给用户（F-3）。
2. **D2 找身份资源**：谁因身份获得准入、谁被排除。证据形态：名单、介绍信、许可、婚配、俱乐部、宾客册。
3. **D3 查秘密的广播机构**（`power-machine.md` PM-3）：秘密之所以致命，是因为存在能把它变现/广播的机构（报界、党机器、法庭、庇护网络）。
   - 有机构 → 秘密是主风险，必须安排"谁会广播、广播后的第一后果"；
   - 只有交易型派系、没有广播机构 → 风险来自交易与站队，不是道德；
   - 小共同体、两者皆无 → 秘密通常不致命，别硬写成灭顶之灾。
4. **D4 判定复仇分支**（`revenge-cost-ledger.md` RC-1）：三条同时成立才走"复仇清算"——加害者可指名、受害者握有可执行杠杆、叙事需要一个可归因的结算对象。缺一条 → 走逃离/制度抗争/自我清算分支。
5. **D5 代价核算**（RC-2）：为每一次"扳倒别人"写下付账人。若所有代价都落在旁观者与后代身上，而主角全身而退，就是机制漏洞（PG2802、PG60627 的写法恰好相反：代价全在受害者一侧，这是**刻意的**，不是漏洞——诊断时要先问作者意图）。
6. **D6 输出诊断表**（见 §6），每条给 `位置 → 问题 → 依据（规则 ID + 来源行号）→ 最小修法 → 回归检查`。

### 流程 P｜设计（阶段=构思）

1. 先让用户选结算形态（RC-3：复位 / 清算 / 耗损 / 悬置），再倒推证据链与揭示时机——不要默认大团圆或默认清算。
2. 按 ID-2 搭伪装契约：伪装者要什么、谁有资格拆穿、拆穿后的第一后果由谁承担。
3. 按 ID-3 设信息不对称的三级（当事人 / 对手 / 读者），并明确每级在何处被打破。
4. 按 PM-1、PM-2 给权力机器三个可核查部件：出资方、记档方、广播方。
5. 按 RC-2 写下代价账本；按 X-1 确认本作的"归因方式"（个人 vs 制度）并保持一致。

### 流程 R｜修订（阶段=改稿·收尾）

1. 定位到原句/原段（行号或可检索片段），不引用就不改。
2. 只做最小修改：改机制缺口的那一处，不顺手重写风格。
3. 回归检查：修改是否破坏已建立的（a）身份准入规则、（b）广播机构的能力边界、（c）代价账本、（d）结算形态。任一破坏 → 回退并改用另一条分支。

### 难例（DESIGN_EXAMPLE，非真实用户任务）

> 用户："我的主角顶替了一位遇刺的贵族进入宫廷，半年后想让真正的凶手当众认罪。"

走流程 D：D1 定轴＝伪装轴（宫廷准入＝身份资源）；D3 关键问题——宫廷里有没有能把"他是冒牌货"广播出去的机构（摄政会议、报界、教会）？有，则凶手不需要证据，只需把秘密交给那个机构即可反杀，主角的"当众认罪"计划缺乏第一后果设计（PM-3）。
D4 复仇分支：凶手可指名 ✓；但主角握有的杠杆是"被识破即死"的负资产，不是可执行杠杆 ✗ → 按 RC-1 不能走"复仇清算"，应改为"自我清算/逃离/换轴"。
输出：给两条可选改法（① 先夺走广播机构，再谈清算；② 改走耗损结算），并标出各自的代价账本与回归检查。

## 5. 失败出口

- **F-1 缺正文/缺阶段**：只给检查清单（§4 的 D1–D5 问题列表），不假装读过、不给针对具体文字的结论。
- **F-2 未定结算形态**：不替作者决定；列出四种形态各自需要的前置证据（RC-3），请作者选。
- **F-3 机制不明显**：把问题退回给用户（"你这部里身份是被争夺的资源，还是被强加的污名？"），不强行套轴。
- **F-4 要求普遍化单部作品规则**：拒绝，并给出该规则的反例清单（`conflict-ledger.md`）。
- **F-5 要求"交给法律/制度解决"**：本批 16 部**没有任何一部**把正式法律程序写成主角的正义来源（R8＝NOT_PROVEN）。必须明确告知：这是本技能未证明的出口；若用户坚持，要求其自行给出该作品的制度设定，并把后果写清楚（PG2802、PG60627 中程序正是伤害来源）。
- **F-6 要求现实政治建议**：说明不在职责内，退回虚构叙事层面。
