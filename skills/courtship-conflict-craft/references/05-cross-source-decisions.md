## 2. 新旧关系与否决理由

旧 Skill 10/10 个规则保留编号但全部 REVISE；未保留"唯一新证据同时击破双误读""长信按固定格式""每个创伤三仪式""所有劝谏必须睡帽场景""卷一前 10% 必须复述""家族献辞替代授权"等泛化表达。不是删除古典个案，而是把它们从必然性宣告改为有适用条件的素材。若用户明确想复刻古典文风，仍可选择这些载体，但必须保护人物自主权和历史/版权边界。

本轮额外否决/限制的旧有默认：

- 默认"披露真相更好" → 改为按归属、授权、知情权、安全风险四项判断（PG3321 L5951-5983、L8962-8969）。
- 默认"沉默/点头=默认同意" → 一律记为未核实（PG3321 L2472-2474、L6855-6864、L8013-8019）。
- 默认"说服/救援是善意且有效" → 改为须登记第三方代价与失控出口（PG3321 L6014-6021、L6323-6325、L7642-7647、L11428-11429）。

## 3. 信息反例与缺料检查

- 完全单侧误判：R1 不适用，使用 R2 的证据传递与 R5 退出权。
- 受威胁签承诺：R4 不能解释为同意；先限制第三方权力。
- 关系自愿但侵害第三方财产：R7 不因婚约解决制度争议。
- 结局成功却发生独立死亡：R8 不强加无证据因果。
- 续书授权不明：R10 仅讨论原创结构，不传播受限母本内容。
- **误读由第三方制造（本轮新增）**：先拆制造机制，再谈误读修复；不得让制造者继续充当信息通道（PG3321 L7611-7630、L10292-10371）。
- **受理方即加害方（本轮新增）**：不走文书/申诉，改走旁听与当场对证，并预先安排被牵连者的退出（PG3321 L2246-2259、L11118-11130）。

## 4. 本轮保留的未决冲突（不伪造共识）

1. **披露 vs 不披露**：Duchess 先决定永不告知、后撤销；Maggie 得知后反过来要求不告知生父。三者理由都成立且互不相同，本 Skill 不给统一答案，只给判断项。
2. **干预 vs 尊重意愿**：Larry 明确准备"违背 Maggie 自己的意愿去救她"（L7642-7647），而当事人事后评价这次干预"给了他需要的那一记震动"（L11180-11188），同时手法被第三方自嘲为"卑劣手段"（L11428-11429）。保留正面结果与手法批判并存。
3. **报复 vs 修复**：Larry 否决报复（L8595-8612），但书中其他人（Hannigan、帮派）选择终身追杀（L10994-11005）。本 Skill 只要求写出选择与理由，不裁定哪种正确。
