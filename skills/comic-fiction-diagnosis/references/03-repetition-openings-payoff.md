## B1-05 · 重复包袱的变化维度（REVISE · 原定量表述被拒）

**F（支持"必须变"）**
- PG7471 L96-114 → L1285 → L1637：同一组"唱歌救场／被揭穿"反复出现，但代价逐级升级——第一次是面子（后台被"Sh-h!"打断），第二次是关系（Ray 亲自上台把他"pole-axed"），第三次是职业（结尾一句 "No... stay where you are. Profession overcrowded."）。

**F（反方向：不变也能成立，只要逻辑关系在变）**
- PG968 L2393-2424：家族混战连续出现却仍然好笑，因为每次配对的逻辑关系不同；L2468-2511 点明——他们彼此厌恶，却一致憎恨 Tigg，因为"他不属于这个家族"。

**被明确拒绝的表述**
- "每 N 章必须换一次机制""每 X 段必须有一个笑点"：**本批没有任何数据支撑阈值**。PG968 的家族混战与 PG7471 的短篇集都证明密度与间隔不是判定标准。

**P**
- 每个重复包袱填一次四选一检查：
  `对象变了? / 代价变了? / 语气变了? / 谁掌握主动权变了?`
- 四项**全**为"否" → 该次重复需要重做或删除。
- 四项任一为"是" → 保留，并在表里记下变的是哪一项。
- 不给数字，不给频率建议。

## B1-09 · 陈述句本身可以是包袱（KEEP · 有条件）

**F**
- PG74437 L456-457："Genuineness only thrives in the dark. Like celery."
- PG74437 L665："My gramophone and my Ford car are better than yours."
- PG74437 L851-855：家族胸像随血统推进呈现"ever profounder imbecility"。
- PG1892 L293-294："It was against my principles, but I find that principles have no real force except when one is well fed."

**条件（缺了就会塌）**
- 整部作品必须先建立"说话即演出"的契约。PG74437 L1142-1168 已经让 Thriplow 对着镜子给自己挑角色（修女／寄宿学校女生／兰开夏女工），读者接受了"每句话都是演出"。
- 放到 Wodehouse 的动作场景里，同样的句子会显得作者在插话。

**H**
- 陈述型笑点成立依赖"读者预先接受说话即演出"这一场景契约（无读者数据）。

**P**
- 判断体裁预期（动作型／陈述型，见 SKILL §4 G3）。陈述型才启用本条。
- 每条陈述句必须紧跟一个可被指认的对象（一个人、一件物、一种处境），否则只是格言。

## B1-10 · 题目／口号／童年口头禅的反转回收（KEEP · 有条件 + 反例）

**F（正例）**
- PG6837 L1302-1305：童年拔牙时 Uncle Chris 反复说 "Be a little warrior, Jill!"（书名出处）；L15017-15022 结局在屋顶，楼下没一个人知道她是世上最幸福的女孩，无知被判为 "Abysmal"。
- PG3756 L38："It wasn't Archie's fault really." → L213-216 第一章结尾 "I'll never set foot in _that_ bally place again!" / "But nothing in this world is certain."

**反例（不要强行要求）**
- PG7471 L1873-1874：Wilton 承认"there isn't any Amy. I invented her"——这个反转故意不回收任何前文口号，因为那位主角就是靠虚构活着。给"靠虚构活着的角色"加回收会破坏人物。

**P**
- 列出全稿所有题目式／口号式／口头禅式的句子，确认至少一条在结局被**语义反转**地回收（不是原样重复）。
- 若主角是"靠自我虚构维持"的类型，跳过本条并写明原因。

## C2' · 期待差（迁移改写：载体从"信件"改为"可验证的承诺"）

**F**
- PG5786 L171-191：两人裹着毯子在窗边等日出，怀疑"日出卡住了"、怀疑酒店在捉弄他们，最后 Harris 跳起来揭穿——"我们一直看的是昨晚太阳下山的地方"；L207-210 随后写观日台上翻着红色 guide-book 认山的游客，"这是我见过的最凄惨景象之一"。
- PG32152 L1246-1247：主客在门口互让先行，僵持到最后"两人同时侧身进门，结果互相撞得不轻"。
- PG3756 L191 → L213-216：Archie 当着旅馆老板骂 "bally rotten hotel" 并被赶出，随即发誓再也不踏进去——下一句就是 "But nothing in this world is certain."

**改写理由**
- `comic-engine-craft` 的 C2 把"信件"写进断言。本批**找不到书信是必要载体的证据**（PG6684 L859-880 的书信是信息放大器，不是落差载体）。改为："先给出一个能被验证是否兑现的承诺。"

**P**
- 写三样东西：一个前置承诺 → 一个与之不相称的行动 → 一个后来被重用的细节。

## C10' · 开篇（迁移改写：从"建期待"扩为"给出一种可核对的承诺"）

**F（支持"建期待"）**
- PG1051 L18-27：开篇议论——五千年科学昌盛，却无人写出关于"衣服"的根本哲学。
- PG1892 L24-28：第一条日记即定型（"这个长头发的新造物……老是跟着我"）。
- PG5786 L92-133：目录已把结构笑点先交给读者（"Proposed Adventure / Reading-up Adventures / Adventures Postponed"）。

**补反例**
- PG968 L164-232：故意用戏仿族谱开篇（家族直系源自亚当夏娃、与火药阴谋攀亲）。这不是"建期待"，而是"建讽刺距离"。

**改写后的规则**
- 开篇必须让读者拿到**一种**可核对的承诺，三者选一：
  1. **期待**（会兑现 / 会落空）；
  2. **距离**（叙述者在戏仿某种文体，读者据此判断可信度）；
  3. **规则**（这个世界的荒诞法则是什么）。
- 三者都没有 → 读者在第一章结束时不知道该用什么态度读，这是最常见的"开篇抓不住人"。

## C9' · 兑现位置（迁移降级：从"服从 POV"改为"选择项"）

**F（明确反例，故降级）**
- PG7105 L252-268、L282-290：Huck **就在现场偷听**，知情差不靠后场兑现，而靠"读者比 Huck 多知道一分"。
- PG8164 L6550-6573：Jeeves 先说"我想了很久，暂时没有结果"，事后才说明方法（L6860-6864）——谜底是被**主动延后**，不是被视点决定。

**改写后的规则**
- 兑现位置是**选择项**，不是被 POV 强制推导的结果：
  - 同场反转（读者与人物同时知道）
  - 跨场回响（后场兑现）
  - 不兑现留白（有意不兑现，留作主题）
- 选择依据是"你想让读者在哪一刻站得比人物高"，不是"POV 要求什么"。
