# 条件分支总表、不可调和冲突、不适用清单与单来源清单

本文件是 `supernatural-power-craft` 的**边界与冲突说明**。规则正文一律在 `rules.md`；
本文件不维护规则的第二个版本。

## 1. 适用 / 不适用

### 1.1 适用（本 Skill 能处理）

- 虚构叙事里的**超自然/超常能力**：法力、血脉、器物、天赋、异界体质、变形、长生。
- 与之直接挂钩的：**作者已经写下的条款**（代价、禁制、赠与、所有权、誓言）。
- 任务形态：**规划 / 诊断 / 核账 / 边界判断**（见 SKILL.md §3）。

### 1.2 不适用（本书/本 Skill 都不处理）

| 对象 | 为什么不适用 | 替代走向 |
|---|---|---|
| 爽点设计、留存率、市场/销量预测 | 本批无教诲文献、无读者数据 | 转市场/编辑流程 |
| 章节结构、节奏、钩子、视角、声音 | 属情节/叙事层 | 转情节架构类 Skill |
| 地理/历史/货币/种族设定集编纂 | 本 Skill 只处理"力"的条款 | 转世界观类流程 |
| 境界分层、金丹、渡劫、宗门制等当代类型规约 | RC-10：本批 25 本无一本支持 | 如实说明超出证据，转出 |
| 影视分镜、镜头语言 | 无样本 | 转出 |
| 游戏数值、关卡、状态机、平衡性 | 无样本 | 转出 |
| 句段润色、校对、翻译 | 不在范围 | 转语言精修类流程 |
| 真实非虚构材料的事实核验 | 本 Skill 处理虚构内部一致性 | 转资料核验流程 |

### 1.3 本批内**不适用**的几本书/几条线（明确列出，避免误用）

- **PG71195 的远征—革命政治线**：共产主义密谋、将被"牺牲"以坐实文件的代表们——
  这些是政治讽刺线，与本 Skill 的机制层不在同一层。**不进证据。**
  该书只有"Opar 遗产律（男性矮壮多毛近猿，女性苗条光洁）"被 RC-07 引用。
- **PG7838 的多数篇目**：象征性讽刺小品（画廊、流派、器物），不是设定；
  只有《潘神之墓》进入 RC-07。
- **PG10441 全书**：作者把它写成喜剧，"心灵电流"是被嘲弄的对象。
  它只在 RC-01 / RC-02 里作为**反例**出现，**不得当作可用的设定模板**。
- **PG53988 / PG92 / PG71372 的赎金线**：这是**另一套代价记账**（可还清），
  只在 RC-02 的④式出现；不得拿来支持"悲剧性代价"的结论。

## 3. 不可调和的冲突（并列保留，不伪造共识）

### 3.1 冲突一：力量是否被社会承认（承载 RC-09）

- **方向 A（重分类）**：PG33913 把天使定为 mattoid / lunatic；
  PG56889 承认巫术不可预测；PG48860 用五先令罚款压制魔法。
  → **社会不膜拜，它把力量重新分类并据此处置。**
- **方向 B（制度化）**：PG169 的"井之仆"、PG71316 的 Cathne 祭政合一、
  PG71195 里 Opar 被当作可知的军事目标。→ **力量是公开的统治基础。**
- **裁决**：两条都证据充足，**不统一**。用 CC-01 的 SIZE 分支处理。
  **在输出里不要写"一般认为力量会被社会边缘化"**——那是不存在的共识。

### 3.2 冲突二：违反后果能否免除

- PG641 给了完整的"违反—补救"通道（地窖三瓶）。
- PG2825 / PG22247 给的是"违反即终局"。
- **裁决**：用 CC-02 分支。没有第三种处理。
