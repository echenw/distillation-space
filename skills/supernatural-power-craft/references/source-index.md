# 来源索引：25 部作品与规则实际引用的行号

本索引随 Skill 包独立可读：**不引用轮次笔记、不写本机路径**。
§1 是 25 行逐源表（每源一行，可逐行核对）；§2 是规则→来源覆盖；§3 是被列为不适用的书目。

## 0. 定位读法（务必先读）

- **L** = 每部原著 `整本阅读版.txt` 的行号（从文件开头计），**不是原书页码**。
  行号基准：25 本合计 **178,848 行**。换版本会漂移；重找方法＝PG 编号 + 引文片段检索。
- **引文**：英文引文逐字，≤40 词；标"转述"的句子不是逐字引文。
- **来源类型**：25 本 `material_role` 全部为 **`FICTION_CASE`**（作品现象）。
  **这些书证明"作品里发生了什么"，不证明"作者主张应当怎么写"。**
  由它们上升的规则一律标 H（推导）。
- **取证深度**：
  - **L1**＝本轮把该书的台账正文逐块读完（5 本：PG496、PG163、PG33913、PG2825、PG10441）。
  - **L2**＝本轮按 10 组机制模式从台账正文做正则抽取并回源复核 key citations（20 本）。
    **L2 证据足以说明"书中确有该机制"，不足以声称本轮逐块读完该书。**
- **独立来源数**按不同 PG ID 计；同一本书多段只算 1。
- "适用限制"中的"不覆盖"指本 Skill 不能用该书证明的主题，不是对该书价值的评价。
