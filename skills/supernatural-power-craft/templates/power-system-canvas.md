# PS 力量体系画布（PS-01 – PS-12）

用法：**每个 ID 独占一行**，一行写不下就在该行下开子表。写不出的行留空并标注 `未定`，
**不要为了填满而编造**。完工后把 `未定` 的行汇总成一张缺口清单交回作者。

前置：先在开头写一句——**本结论来自 25 部 1850–1930 年代英文虚构作品的现象归纳**。
