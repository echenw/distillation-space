# DR 诊断 / 核账报告（DR-01 – DR-10）

用法：每个 ID 独占一行。**诊断**与**核账**共用本表；核账时 DR-05/06/07 是主表。
一切严重度都建立在**实际读过的文本**上——没读过的部分标 `未覆盖`，不得判为缺失。

前置：先在开头写一句——**本结论来自 25 部 1850–1930 年代英文虚构作品的现象归纳**。

## 输出纪律

- 转述的句子**不加引号**；只有逐字核对过的片段才能加引号。
- 严重度不得因"看起来不像炫 revisado"而抬高；**只看已经写下的条款**。
- 每份报告以"未做的事"结尾：未读范围 / 未解决的问题 / NOT_PROVEN 的规则。
- 规则效果 NOT_RUN、NOT_PROVEN：不写"这样改读者一定会买账"。
