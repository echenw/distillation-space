# 表达

表达管句子层面的通病，其中大部分就是常说的 AI 味。本文用于写作后的自查、改稿、审稿，以及编写表达约束卡。

## AI 味的五个来源

逐词替换治不好 AI 味，因为它不是用词问题，是五种写作倾向的结果。改稿针对倾向，不针对单个词。

| 来源 | 表现 | 处理方向 |
| :--- | :--- | :--- |
| 取最常见的搭配 | 库存表情、现成比喻、空泛大词 | 给这个位置一件只有本场景才有的事来写 |
| 同一件事说两遍 | 动作之后解释，结尾总结 | 已经演出的不再说 |
| 追求形式整齐 | 三连、对照句、长度均匀的段落 | 句子和段落跟着内容走 |
| 急于收束 | 升华、预告式旁白、情绪一步到位 | 停在事情上，不停在评论上 |
| 人物之间没有摩擦 | 话说得完整得体，人人一个腔调，冲突当场说开 | 让每个人想要不同的东西，并且有人得不到 |

## 病灶表

每一行包含四项，依次是识别信号、判据、同位替代、不可改成的过度形态。判据不成立时可以保留原句。

### 词与短语

| 病灶与识别信号 | 判据 | 同位替代 | 不可改成 |
| :--- | :--- | :--- | :--- |
| **库存反应**：嘴角勾起一抹弧度、眼底闪过一丝异色、瞳孔骤缩、倒吸一口凉气、心头一颤、指节发白。构式：“一抹／一丝＋抽象名词”，“情绪词＋心头、眼底” | 整句搬到别的书里照样成立；同一种反应在一章内第二次出现 | 这个人在这个场合的反应：他看了哪儿，手里在做什么，说了句什么 | 把“深吸一口气”“不由得”这类常用词一并禁用；换成另一套固定动作 |
| **垫词成串**：仿佛、似乎、某种、微微、缓缓、淡淡、轻轻 | 删掉后句意不变 | 删除；确有程度差别时把差别写出来 | 一个不留，句子生硬 |
| **空泛大词**：无尽的、深邃的、难以言喻的、前所未有的、令人窒息的 | 换一个描写对象照样能用 | 名字、数目、位置、磨损 | 每样东西都配数字的虚假精确 |
| **现成比喻**：像一把刀、如潮水般、像断了线的风筝 | 直说能说清；或喻体不是视角人物会想到的东西 | 直说。直说说不清时用人物熟悉的事物作比，一场戏至多一处 | 禁绝一切比喻 |

### 句式

| 病灶与识别信号 | 判据 | 同位替代 | 不可改成 |
| :--- | :--- | :--- | :--- |
| **对照句式**：不是……而是……，与其说……不如说……，没有……只有…… | 前半句否定的说法此前没有人提出过 | 直接说是什么 | 改掉对白中真实的反驳 |
| **三连与排比**：三个并列形容词、三个排比句、“他想起了……想起了……” | 最后一项没有新信息 | 有几项写几项 | 误伤誓词、咒语、歌谣、条文、公文、演讲 |
| **揭示式标点**：破折号、冒号、省略号成堆，用来制造停顿 | 同一种用法在一页内反复出现 | 用句号断开，或把要揭示的内容写成动作 | 一个不用 |
| **判词句**：“这是一种……的感觉”“他是那种……的人” | 叙述者下了结论，前文没有演出 | 写出能让读者自己得出结论的事 | 删除视角人物自己的判断 |

### 段落

| 病灶与识别信号 | 判据 | 同位替代 | 不可改成 |
| :--- | :--- | :--- | :--- |
| **模板段**：每段都是一句动作、一句心理、一句环境 | 连续三段结构相同 | 按内容分段，换了动作的人就换段 | 为打破整齐打乱清楚的顺序 |
| **段末短句收尾**：每段以一个单独成行的短句结束 | 删掉该句，段落意思不变 | 停在动作或对白上 | 所有段落都突然中断 |
| **长度均匀**：句长、段长接近 | 整页看不出快慢 | 动作快处短，因果和思绪处长 | 硬拆半句，堆砌单行 |
| **感官清点**：视觉、听觉、嗅觉依次各一句 | 细节与人物此刻的处境无关 | 一场戏选两三样人物正在用或正在看的东西 | 不写任何环境 |

### 对白

| 病灶与识别信号 | 判据 | 同位替代 | 不可改成 |
| :--- | :--- | :--- | :--- |
| **话说得太全**：句子完整，有头有尾，各自等对方说完 | 这个人此刻不会把话说到这个程度 | 半句、打岔、答非所问、用动作代替回答 | 人人说谜语；调查、教学、汇报中必要的完整说明被拆碎 |
| **为读者补课**：“你也知道，三年前我们……” | 对话双方都已知道 | 把背景拆进争执、试探和行动 | 删到读者缺少必要信息 |
| **提示语换花样**：冷冷道、沉声道、淡淡一笑道，一句一换 | 提示语承担了本应由台词承担的语气 | 用“说”；听得出是谁就省略 | 全篇没有任何提示语，分不清说话人 |
| **人人同腔**：遮住名字分不出谁在说 | 两人的台词互换后不违和 | 按此刻想从对方那里得到什么来区分：称谓、绕不绕、接不接话 | 按职业或身份分配口头禅 |
| **说得太准**：人物准确说出自己的感受和动机 | 这句话像事后分析，不像当场说的 | 嘴硬、说反话、说别的事 | 重要态度也不许直说 |
| **借人物讲道理**：人物谈人生、谈意义 | 这段话不是说给眼前这个人听的 | 用他自己的话，对眼前的人说 | 删除人物的全部看法 |

### 场景与章节

| 病灶与识别信号 | 判据 | 同位替代 | 不可改成 |
| :--- | :--- | :--- | :--- |
| **演完再解释**：动作之后补一句“这说明他很在意” | 前文已经用行动或对白交代 | 删除 | 后一句改变了解释、关系或决定时不算复述，保留 |
| **结尾总结与升华**：“他知道，这只是开始”“这一刻，她终于明白了”“命运的齿轮开始转动”。位置：段末、场景末、章末 | 这一句是评论，不是正在发生的事 | 停在动作、对白或一个未解决的问题上。章末钩子用事情来挂，不用感慨来挂 | 删到结尾没有落点 |
| **预告式旁白**：“他不知道的是……”“多年以后他才懂得……” | 视角人物此刻无从知道 | 删除；需要悬念时让读者看见一件人物没有留意的事 | 全知叙述是本书的明确选择时不算 |
| **情绪标签**：“他感到一阵愤怒”“心中五味杂陈” | 删掉情绪词后，这一段读不出这份心情 | 他在这种情绪里做了什么、说错了什么、注意到了什么 | 每种情绪都配一个身体动作；快节奏处一句直说反而更好 |
| **情绪一步到位**：得知消息后立刻给出完整反应 | 反应没有迟滞和反复 | 嘴硬、迟钝、过一阵才反应 | 每次都拖延 |
| **人人得体**：冲突当场说开，各方都讲理 | 场景结束时没有人吃亏，也没有人改变 | 让一方得不到想要的东西 | 为冲突而冲突 |
| **群体同声**：“众人震惊”“全场哗然” | 群体只有一种反应 | 挑一两个人写各自的反应 | 逐个写遍在场所有人 |
| **章章同式钩子**：每章结尾是同一种悬念 | 连续三章结尾节拍相同 | 按本章实际发生的变化选择落点 | 取消所有章末落点 |
| **开场套式**：以天气、时间、醒来开场 | 开场内容删掉后不影响理解 | 从事情开始的地方进场 | 开场没有任何定位信息，读者不知身在何处 |

## 改写示例

改写保持事实不变，只使用场景中已有的材料。场景中没有可用材料时，把新增内容标明为建议。

改前：

> 他的杯子还在沥水架上。周敏握紧了拳头，指节微微发白，心头涌上一股难以言喻的酸涩。“我没事。”她淡淡地说，嘴角勾起一抹苦涩的弧度。这一刻，她终于明白，有些人注定只是过客。

改后：

> 他的杯子还在沥水架上。“我没事。”周敏说。她把杯子拿下来看了看，又放回去，杯口朝下。

改动：删除库存反应（握拳、指节发白、嘴角弧度）、垫词（微微、淡淡）、情绪标签（难以言喻的酸涩）和结尾升华。情绪交给场景里已有的杯子。事实没有变化：杯子还在，她说没事。

## 写成卡：表达约束卡

通用方法见 [card-method.md](card-method.md)，交付前检查见 [card-pitfalls.md](card-pitfalls.md)。

### 格式

用户指定了格式时以用户为准。未指定时使用评测所用格式：

- 正文第一句以“正文”二字开头。规划任务也会读到这张卡，所以要写明只管小说正文。范围只写这一次，不在每条后重复。
- 正文不超过 300 字。
- 一张卡只管一种通病。
- 分行书写，一条一件事。

### 结构

字数有限，按下列顺序取舍，排在前面的优先保留：

1. 范围与主张，一句话。
2. 病灶，包括名称、出现位置、三到八个原词或坏句、一句构式。
3. 判据，一条原理判据，覆盖列不完的变体。
4. 替代，同一位置改写什么。
5. 放行范围，封闭列举，与被禁对象不同类。确需放行同类写法时给出额度。
6. 护栏，这条约束被执行过度的形态。

这六项是写卡时的检查顺序，不是卡上的标签。写进卡里时每项改成一句完整的话，句子自己带“不要”“应当”“可以”，不用“病灶”“判据”“不算”作行首标签。

### 本卡种的注意事项

- 常用词不列入禁用词表。禁构式和重复，不禁单个常用词。
- 不把规划、大纲、分析文字纳入管辖。
- 不用“少”“尽量”“适当”作约束，写明条件或额度。
- 字数允许时给一组改前改后；字数不允许时，把原词和替代方向直接写进条款。

### 示例卡

下面这张卡用于说明做法。为同一通病写卡时重新设计，不照搬。

```markdown
# 正文表达：情绪不贴标签

正文不要用情绪词替人物报告心情。规划里可以照常写“此处主角愤怒”。

- 要改的是“他感到愤怒”“她心中五味杂陈”这类句子。情绪词配上“心头”“眼底”的写法要改，演完再补一句标签也要改。
- 判断办法是删掉情绪词再读，读不出这份心情就应当重写这一段，换个词不算改。
- 应当写他在这种情绪里做了什么、说错了什么、留意到什么。内心可以直接写，要写具体的念头，比如在盘算什么、想起了哪件事。
- 可以保留对白里人物自己说出的情绪，次要人物可以一笔带过。快节奏处可以直说一句“他慌了”，一场戏最多一句。
- 不要给每种情绪都配一个身体动作，握拳、发抖、泛红轮着用也是套路。
```

这张卡使用的做法：

| 位置 | 做法 |
| :--- | :--- |
| 第一句以“正文”开头 | 范围声明只写一次 |
| 两个原句加“情绪词配位置” | 原句少而准，另加构式，防止近义替换 |
| “判断办法是删掉情绪词再读” | 原理判据，写作者无法自行认定 |
| “应当写他……做了什么、说错了什么、留意到什么” | 同位替代，句首带“应当” |
| “可以保留”三项 | 封闭列举；前两项与被禁对象不同类，第三项同类所以给了额度 |
| 末条“不要给每种情绪都配一个身体动作” | 反向护栏，点名过度执行的形态 |
| 每条都是完整的句子，没有标签和冒号 | 作者只看行首也能分清要做和不要做，见 [card-method.md](card-method.md) 第 7 节 |
