# 生成方法

本文是写任何一类预设卡都要用的主干方法。各卡种的专用做法见 [progression.md](progression.md)、[style.md](style.md)、[expression.md](expression.md)。

写得好的卡的共同点只有一条：**把验收权从写作者的手感移到稿面上。** 每条要求都能在稿子上数出来、查出来、判出来，或者由示例演出来。写得好的卡同时具备三项：禁项可检索、豁免封闭、示例兑现自身规则。卡与卡的差别不在于是否知道这些做法，而在于一张卡里同时做到几项，并且条款之间不冲突。

文中的引句都是写法示意，用来说明做法，不可照抄。

## 1. 先明确卡片的读者

预设卡是提示词。它的第一读者是生成模型，每次调用都会读到；第二读者是用它核对稿件的作者和审阅者。下列前提尚未经过本 Skill 的生成测试验证，写卡时按它们检查每一条：

| 前提 | 写卡时的做法 |
| :--- | :--- |
| 每一条都会被执行，并且每一章都执行 | 只在某些情况下成立的要求，必须写出条件、终点和例外 |
| 示例会被模仿，包括内容和形状 | 示例只演示方法，不含可被反复套用的招牌句；标明只学语感 |
| 被禁的词会被换成近义词 | 禁构式和原理，不只禁词；同时给出替代写法 |
| 程度词不改变输出 | 不用“适度”“尽量”“少用”收尾，改为数量、条件或判例 |
| 模型默认会做的事不需要写 | 删除换一张卡名仍然成立的句子，只写本卡与默认写法的差别 |
| 互相冲突的要求使输出摇摆 | 同一对象在同一条件下只有一个要求 |
| 字数是成本 | 每句都要改变稿面；删除后卡片无损失的句子删除 |

## 2. 四种稿面判据

为每条要求选择一种判据。选错类型与没有判据同样无效。

| 判据 | 适用对象 | 写法 | 误用形态 |
| :--- | :--- | :--- | :--- |
| 能数 | 频率、间隔、上限、跨度 | 数字、单位、生效范围三者齐全 | 用句长、行数定义文风；多个数字叠加成电报体；慢节奏题材被写死 |
| 能查 | 词句层面的病灶 | 原词或整句坏样本、构式、出现位置 | 常用词被禁；只列词，近义词可绕过 |
| 能判 | 语义层面的要求 | 把判据挂在稿面已有的条件上 | 以“像不像这个人”“是否有意安排”这类自证条件作判据 |
| 能演 | 语感、口气、分寸 | 示例兑现规则；改前改后对照 | 示例违反规则；示例成为公式 |

各类判据的示意：

- 能数：一场对谈里局势至少变一次；视点人物认出自己的情绪可以直说，一句为限；一个场景挑两三样与人物此刻有关的，不清点全屋；打比方写明触发条件，直说说不清时才用。
- 能查：病灶列成可检索的字符串，逐条能全文查杀，位置钉死在段末、场景末、章末那一句；点出模板段落“一句动作、一句心理、一句环境”和“段段拿一个短句收尾”这类不易察觉的整齐病。
- 能判：已经用行动和对白交代的得失，不再由旁白复述一遍（违规与否取决于前文是否已交代，可覆盖无穷变体）；把结尾这段删掉，故事照常往下走，就该删（判据落在因果影响上，不靠作者自证）；双方早已知道、却为向读者补课而完整复述的身世与经过要删（判据是双方是否已知）。
- 能演：示例靠“一个礼拜两回，别多”和“那盆茉莉上个月就死了”两件事实承担全部情绪，没一句点破。

“能判”类判据可挂靠的稿面条件，按需选用：

| 条件 | 判什么 |
| :--- | :--- |
| 前文是否已经交代 | 复述、点题、升华 |
| 对话双方是否都已知道 | 对白中为读者补课 |
| 视角人物有无途径得知 | 视角越界、全知叙述 |
| 删除后因果和理解是否受损 | 废句、废段、多余细节 |
| 整句搬到别的作品里是否照样成立 | 套话、通用描写 |
| 是正在发生的事还是评论 | 章末钩子与总结的分界 |
| 双方的实际关系是否允许这句话 | 玩笑、亲密、冒犯的分寸 |
| 念出声能否一口气念完 | 句子过长、不顺 |

## 3. 禁令的五个部件

一条禁令完整时包含五个部件。字数紧张时，前三个不可省；与 SKILL.md §3 第 3 步、expression.md“结构”一节的取舍顺序互为回链。

1. **病灶具名并定位。** 给病灶起一个名称，写明它出现的位置（段末、章末、对白提示语处）和生效的层：只管正文还是也管规划文字，只管叙述还是也管人物对白。例如“预告式旁白”（“他不知道的是”“多年以后他才懂得”）这类病灶，位置要写齐段末、场景末、章末三级。
2. **原词少而准，另加构式或原理判据。** 列三到八个最有代表性的原词或整句坏样本，再用一句话写出构式或判据，覆盖列不完的变体。构式示例：“一抹／一丝＋抽象名词”“情绪词＋心头、眼底这类容器”“他想起了……想起了……”。
3. **同位替代。** 说明被禁写法所在的位置改写什么。例如替换方向落成三问（他看了哪儿、手里在做什么、说了句什么）；落到四类信息（名字、数目、位置、磨损）；“章末的钩子照留，但用事情来挂，不用感慨来挂”，直接回答“删了点题句拿什么收尾”。
4. **封闭豁免。** 逐项点名不算违规的场合或对象，不用“等”“必要时”“视情况”。豁免可以按场合、人物性格、时代背景、人物在故事中的地位四种方式分组。豁免对象必须与被禁对象不同类。例如六类不误伤：誓词、咒语、歌谣、规则条文、公文、演讲；例外写明三种：对白俗语属人物、常用词单次使用不误伤、反复出现或整句可搬到别的作品才违规。确需放行同类写法时给额度，例如“视点人物认出自己的情绪，一句为限”是带阈值的例外。
5. **反向护栏。** 点名这条禁令被执行过度的形态，写成“做 X，但不做成 Y”。本条与某种流行说法冲突时，明确否定那种说法。例如“长句拆短，但不拆成一串碎句”；“‘说’字可以反复用，不必换花样”，不为了避提示语而炫技；“不把所有概述都改成冗长场景”；“重要态度允许直说，别把正常交流全改成谜语或挖苦”。

护栏不可压制本卡的核心效果，豁免不可放行被禁对象本身。两者的失败形态见 [card-pitfalls.md](card-pitfalls.md) 第 7、12 条。

## 4. 写专属机制

- **写出换卡名即失效的机制。** 用一条因果链说明本类型靠什么推进，或本风格靠什么成立。每一环是一个动作加一个稿面上可见的结果。例如把加码写成因果：“这个窟窿是为了填上一个才挖的”；把“落地碰钉子”写进小循环（工匠不会、旧势力阻挠、物料不够），失败环节有了具体来路。
- **让循环自续。** 上一环的解法成为下一环的麻烦来源，循环才不需要外力推动。
- **换名测试。** 逐句把卡名换成相邻的另一张卡。仍然成立的句子是通则，删除或改写。
- **把笼统要求拆成有名称的成分。** “要具体”“要有层次”拆为二到五个互斥成分，每个成分配一条判据和一个载体。例如先划范围（本条只管正文），再把病拆成“泛泛细节”与“现成比喻”两类并各给可检索反例；对白按问答催拒瞒五类分功能。只列类名不算拆分，失败形态见 [card-pitfalls.md](card-pitfalls.md) 第 13 条。
- **把抽象状态换算成可指认的东西。** 穷、权力、紧张、年代感，写成物件、位次和数目。例如把话里有话落到可核对的物件与称谓上：沉默、让座、添茶都算表态；数目要写出来：几分钱，几斤，几尺布。可以把要求写成带答案类型的问句：哪一种红，几点钟，几号交租，多少石粮。细节必须对当前场景有用，不堆砌。

## 5. 写示例

1. 示例演示本卡最有辨识度、最难用语言说清的那一条规则。
2. 场面取自本卡最常用的场面，不取边缘场面。
3. 卡中点名的规则在示例中必须出现。有对白规则，示例就要有对白；要求人物各有口气，示例就要有两个口气不同的人。
4. 写完后逐行对照本卡的“避免”栏、禁用词和门槛，并核对时代、空间、物件。
5. 示例不依赖单独一句出彩的句子。把最出彩的一句拿掉后，示例仍应演示了方法。
6. 改前改后的两句保持相同的事实和信息量，只改写法。

示例自身不点破要避免的情绪，还把该留在场的东西留在场，就兑现了禁令；“避免”栏所列的风险正对着本卡正面要求的过度形态。卡片格式不允许场景示例时，把示范写进条款：在要求后用括号或冒号给出原词、落点或一组具体实例。

## 6. 崩点栏与自查

- **崩点栏列四到六条本类型特有的失败形态。** 每条写现象，并且能在稿面上判断真假。不写“避免无聊”“注意节奏”。例如“叙述的人自己先笑再解释笑点”与“把真危险一并消解”是两条失控项；“不断造新幕后人取消已完成的较量”“消息无路可来却人人全知”是两处病灶。
- **为风格点名冒名形态。** 写成“X 不是 Y”：白描不是写得粗糙，克制不是通篇短句，快节奏不是省略因果。
- **崩点栏写完后与正面要求并排核对。** 正面要求执行过度后不得落入崩点栏。
- **自查句以动作开头。** 写明查什么位置、看什么信号、命中后怎么改。例如查法：删掉情绪词，段落读不出这份心情，就该改。可以指定固定起查点，例如先查每章最后三句是否补了结论。

## 7. 让作者也读得懂

卡片除了给模型用，也会被作者打开来读和改。作者读得快，往往只看每行开头，不留意句号。

- **每句话自己说明是要做还是不要做。** 禁止的句子带“不要”，要做的句子带“应当”“要”，放行的句子带“可以”。意思已经清楚的句子不用硬加。
- **冒号后面不出现反转。** 冒号前是“要做什么”，后面就只写要做的内容；冒号前是“不要什么”，后面就只写不要的内容。一行里需要先说要做、再说不要做，或者相反，这一行就不用冒号，改成几句完整的话。
- **不靠标签区分正反。** “病灶”“判据”“不算”这类标签对模型有效，作者却要先弄懂标签才能读懂内容。改成直接说的句子，例如“要改的是……”“判断办法是……”“可以保留……”“不要……”。
- **禁止句后面紧跟的正面句要带标记。** “不要第一章就出场十个名字。交代把这群人拴在一起的东西”会被读成两件都不要做，应当写成“不要第一章就出场十个名字。应当交代把这群人拴在一起的东西”。
- **崩点栏的每一条只写失败的样子。** 要补一句正确做法时，用“其实”“应当”接在同一句里，不另起一句。

## 8. 条件化做法

以下做法或仅适用于部分题材，或依据尚单薄。当前任务确有需要时采用，不作为每张卡的固定要求。

| 做法 | 写法示意 | 适用条件 |
| :--- | :--- | :--- |
| 排章纲前先列一张本题材的台账 | “先列原有剧情大事表，标出主角知道哪些、记错哪些、哪些根本没写”“排剧情前先定淘汰顺序和各人出局的方式”“排章纲时给每一格信任定一个凭据：一个动作，或一句话” | 推进卡；题材有需要持续对账的事实 |
| 以双方关系作判据 | “玩笑对应双方实际关系”、熟人接话与陌生人保留客套 | 吐槽、亲密、冒犯的分寸 |
| 限制承担同一职能的人数 | “不能人人都只负责给视角人物递笑料”“别让全员说谜语” | 群戏、喜剧、悬疑对白 |
| 以位置作判据 | “不要每段都以人物名字开头”“一个长句里只装一件事” | 数量难以界定的句段问题 |
| 按剧情位置规定收声点 | 危险临近减玩笑、关键情感停止吐槽、章末不以段子封口 | 带口气的叙述风格 |
| 回收只改解释，不改事实 | “每次回收都要改变旧场景的解释，却不能推翻已经确认的事实” | 伏笔、悬疑、反转 |
| 禁止用新出现的规则或人物解决旧冲突 | “不断造新幕后人取消已完成的较量”一类病灶 | 权谋、智斗、悬疑 |
| 对手和旁人会学习 | 对手根据上一回合的结果调整，成为下一回合的输入 | 长线对抗 |
| 每个循环留下一项不可收回的变化 | 互相欠账、不可逆变化 | 防止原地循环 |
| 反向设定本类型的默认写法 | 出事不加速，章末不强钩，落点后立刻切走 | 含蓄、日常这类慢节奏卡 |
| 伦理界线写成关系判据 | “不靠外貌羞辱或旁人的痛苦制造轻松”“拒绝仍要听得清”“边界侵犯被当成心动证据”列入崩点 | 轻松、甜宠、拉扯类卡；不限制故事描写伤害与冲突 |
| 允许写明不确定 | 查不到的专业事实直接写成不确定 | 专业、纪实类卡 |
