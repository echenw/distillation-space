# 规划：从想法到章纲

本文用于把定位、人物、台账、分卷、章纲写成推进模式卡的小节素材。规划文档本身（开新书、规划一卷、排章纲的交付）归 story-architecture-and-longform-planning 一类结构 skill；本 Skill 只取写成卡的部分。推进引擎的设计见 [progression.md](progression.md)。

规划按五步进行：定位、人物、台账、分卷、章纲。用户已经确定的部分直接沿用，只补缺少的部分。

## 1. 定位

用一句话写清四件事：谁，靠什么，要得到什么或躲开什么，最大的麻烦是什么。

- “靠什么”是本书的核心设定或金手指。写明它立刻改善什么，不能解决什么。
- “要得到什么”对应读者追的东西。按 [progression.md](progression.md) 的写法检验：换到相邻类型上仍然成立，就重写。
- 设定负责让读者点开，情绪的兑现负责让读者留下。两者都要在这句话里找得到。

## 2. 人物

每个重要人物写四项。这四项是排剧情的前置工具：先填四项，再排事件。

| 项目 | 内容 |
| :--- | :--- |
| 想要什么 | 一个具体的目标，能判断是否达成 |
| 怕什么 | 一件具体的事，会让他改变做法 |
| 凭什么 | 他做得到而别人做不到的一件事，以及它的限制 |
| 下一个高光 | 他下一次改变局面是在什么情况下 |

- 对手有自己的目标和路线，并从上一回合的结果中学习。对手不为剧情需要而出现。
- 人物之间的关系写成欠账：谁欠谁什么，什么时候要还。
- 重要人物的数量设上限，例如不超过五个；超出上限时先合并职能。新人物出场时带着任务。
- 被搁置的人物回到故事中时，承接此前的目标和后果。

## 3. 台账

排章纲之前，先列一张本题材需要持续对账的表，把这一步写成固定工序。台账的内容取决于题材：

| 题材 | 台账内容 |
| :--- | :--- |
| 穿书、重生 | 原有剧情的大事表：主角知道哪些，记错哪些，哪些根本没有记载 |
| 大逃杀、生存 | 人数，各人出局的顺序和方式，手中的资源 |
| 末世、经营、年代 | 物资、钱、票证的数目；年份和政策节点 |
| 悬疑、探案 | 每条线索：谁知道，读者何时看到，何时证实 |
| 感情、救赎 | 关系的台阶，以及每一格的凭据：一个动作或一句话 |
| 群像 | 每个人想要什么、怕什么；各条线在哪里交汇 |
| 权谋、智斗 | 各方的筹码、把柄和消息的来路 |

台账中的数目和事实，正文前后保持一致。指定两到三项读者随时应当知道的信息，例如「剩余人数／手中资源／距下次缩圈」。

## 4. 分卷

- 每一卷是一个阶段：从哪里走到哪里，卷末交付什么。
- 下一卷更换一种麻烦，不是上一卷的放大。
- 卷的边界可以取题材自带的层级：村、镇、县、郡，或者练气、筑基、结丹。
- 写明每一卷大致占多少章。

## 5. 章纲

每章写一行，包含三项：本章的变化，谁付出了什么，章末停在哪里。

排完后检查：

- 连续三章的变化类型或章末节拍是否相同。
- 小循环是否在预定的跨度内闭合；拉扯、对峙是否超过了拖沓上限。
- 开局三章是否各有交付，读者第一次尝到甜头是在哪一章。
- 破局要用的人和物，是否在用到之前已经出现。
- 每个伏笔记录埋设的章和计划兑现的章；兑现之前至少再出现一次。

## 交付

写成推进模式卡时，本文各节的内容落进卡的小节；标明所作的假设和留待作者决定的事项。作者只要其中一部分时，只交付那一部分。规划文档（定位句、人物表、台账、分卷表、章纲的成套交付）不是本 Skill 的交付物，按 SKILL.md §1 转出。
