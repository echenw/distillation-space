# 推进

推进回答一个问题：**这条剧情线靠什么往前走，读者追的是什么。** 它决定事件、认知和关系怎样变化，不决定句子怎么写。

本文用于规划一本书、一卷或一条剧情线，判断一章的推进是否成立，以及编写推进模式卡。

## 设计一条推进线

规划时依次确定下列七项。编写推进模式卡时，它们就是卡的各个小节。

### 读者追的是

用一句话写读者的期待，写清谁，靠什么，得到什么或躲开什么。应当写期待，不要写主题。把这句话换到相邻类型上仍然成立，就重写。

- 不合格：`读者追的是：主角的成长和精彩的冒险。`
- 合格：`读者追的是：一个没靠山的人靠小心和算计，从比他强的人手里活下来，每次多带走一点东西。`

这句话是全卡的校准线。后面每一节都要服务它，任何护栏都不能把它压掉。

### 适用

写卡时必填，规划单本书时可以略过。只列共用同一种循环的题材，并写明常作主线还是副线。两种节奏不同的题材不并列。

### 推进循环

- **小循环**写成三到五环的箭头链。每一环是一个动作加一个稿面上可见的结果。至少有一环是受阻或失败，并写明阻力从哪里来。最后一环留下下一圈的起因。
- **写明跨度和终点。** 跨度给范围（一到三章）；终点用本类型的最小变化单位定义，并说明什么才算变化了一个单位。只写章数不写终点，会把节奏写死；只写终点不写章数，无法排产。全篇的章数刻度保持一套，小循环与大循环之间能够换算。
- **写明拖沓上限。** 拉扯、试探、对峙这类可以无限延长的循环，写出“超过几章没有新变化算拖沓”。
- **慢节奏题材**（日常、年代、治愈）放宽跨度，以变化定义终点，不强制每章冲突。
- **大循环**写一卷或一个阶段从哪里走到哪里，卷末交付什么，下一阶段换了什么。命名阶段时写明每段大致占几章，否则只是目录。
- 卡中有两条线（事件线与谜团线、事业线与感情线）时，写明它们在哪一环交汇。

### 开局

逐章布置头三章各交付什么，并写明读者第一次尝到本模式甜头是在哪一章。作副线时，指这条线刚出现的那几章。开局拆到章级：第一章给任务和第一处异常，第二章给本模式独有的机制，第三章给一次损失和相应的所得。

### 加码

- 列出有名称的升级来源和换档条件。每升一档应当更换一种麻烦，可以换对手、筹码、代价或场合。只放大数值不算升级。台阶可以取题材自带的层级：村、镇、县、郡，或者练气、筑基、结丹。
- 旧办法在新限制下失效，并写明失效原因。不定期作废，也不作废主角已经赢得的成果。
- 代价随收益上升。有金手指时写明它立刻改善什么，不能消除什么。
- 写明本模式靠什么保持可信：循环自带“他凭什么知道，凭什么抢得到”一类的公平性判据。

### 每章落点

- 写成封闭清单并规定下限，例如四种可验收结果：多一样东西、少一个隐患、多知道一条消息、提前躲开一次风险；或写成“账要动：钱、时间、体力、关系，至少一项有了新数目”。
- 清单中不留“或其他进展”“或一个决定落定”这类兜底项，它会使下限失效。
- 写明本模式最该写足的那一下是什么。
- 章末按本章实际发生的变化选择落点，不规定每章同一种钩子。给出的落法要来自不同的节拍：外来的新情况、主角未完成的选择、代价到账、新信息改变旧判断。写明哪种章可以不设钩。

### 容易写崩

列四到六条本类型特有的失败形态，每条一句，写现象。应包含：本模式被写成另一种模式的迹象；主角、对手或配角的失真；本类型的作弊手段（梦境、预言、全知旁白、临时出现的新规则或新幕后人）。写完后与前四节并排核对，正面要求执行过度后不得落入本栏。

卡里用到常见的套路（开局、升级、反转的老桥段）时，写明这一次和读者见过的有什么不同：人物、代价、视角、结局至少变一项。致敬或戏仿可以刻意保留原样。题材承诺本身以 `genre-fiction-craft` 为准。

## 机制条款

推进是否可信取决于以下机制，不取决于配额。按题材选用。

| 条款 | 写法 | 示意 |
| :--- | :--- | :--- |
| 收益与代价同条 | 每次得手，在同一条里写明交出了什么；数目前后一致 | “出门一趟写清三样：带了什么去，换回什么，丢了什么” |
| 状态结转 | 列出换场景后不得清零的状态：伤势、暴露、消耗、承诺、已得成果、被搁置人物的目标 | 伤势、暴露、弹尽粮绝不在换场景后清零 |
| 信息分层 | 区分亲眼所见、他人转述、主角推测、已经证实；写明读者此刻知道什么 | 让读者知道目前已确认什么、仅是谁的说法 |
| 公平 | 破局所用的人和物先行出现；可以隐藏信息，不可以临时制造信息 | “提前至少一章埋下影子” |
| 证据存续 | 假说被推翻后，仍然成立的证据保留 | 不能把整段调查作废 |
| 对手自主 | 对手按自己的路线和线索行动，并从上一回合学习 | 竞争者不凭剧情需要突然出现在每个关口 |
| 读者常驻信息 | 指定读者随时应当知道的两到三项 | “剩余人数／手中资源／距下次缩圈” |

## 各类型的引擎要点

下表是设计起点，不是定稿。规划或写卡时逐项核实，用自己的话重写，并补足本表没有的内容。“最小变化单位”用于定义小循环的终点。

| 类型 | 读者追的是 | 最小变化单位 | 最易出现的失败 |
| :--- | :--- | :--- | :--- |
| 通用剧情推进 | 想要的东西一次比一次近，也一次比一次难 | 一处局部障碍 | 写成任何类型都成立的骨架 |
| 暗线伏笔 | 早先不起眼的东西后来变了意思 | 一次触碰或一次回收 | 回收推翻已确认的事实；靠梦境、预言作弊 |
| 升级流 | 变强后压过此前压不过的人 | 一次实力提升得到验证 | 对手只是更大的数字；升级没有代价 |
| 凡人流 | 没靠山的人靠谨慎和算计活下来并有所得 | 多一样东西或少一个隐患 | 主角突然豪赌；机缘白送 |
| 系统流 | 任务与奖励的兑现，奖励带来的新玩法 | 一个任务的完成或失败 | 系统替主角做决定；奖励只加数值 |
| 无敌流 | 别人何时知道、知道后怎样反应，以及实力解决不了的事 | 一次认知落差兑现 | 硬造威胁；反应戏千篇一律 |
| 打脸逆袭流 | 被看轻的人亮出实力，对方当众改口 | 一次从压低到翻盘 | 对手降智；压抑过久不兑现 |
| 重生复仇流 | 带着前世的账逐笔讨回，改动又带来未知 | 讨回一笔、保住一样或核实一条消息 | 预知永远准确；复仇对象不反击 |
| 反派流 | 抢在原定主角之前拿走机缘，并应付反扑 | 截下一处机缘或化解一次反扑 | 主角从不失手；中途洗白 |
| 迪化流 | 主角随口一句被旁人越解读越深 | 一次误读升级 | 旁人降智；误会被当面解释清楚 |
| 马甲流 | 多重身份何时暴露、谁先发现 | 一层身份遇险或揭开 | 暴露被无限拖延；各身份互不影响 |
| 种田经营流 | 从少到多的积累看得见 | 一项产出或一笔进账落定 | 数字无依据暴涨；只有丰收没有困难 |
| 基建争霸流 | 新东西落地后换来的新打法和新版图 | 一项建设从立项到见效 | 只翻倍产量；落地没有阻力 |
| 权谋官场流 | 位置、把柄、消息的易手 | 一项筹码易手 | 消息无来路却人人知情；不断新增幕后人 |
| 职业流 | 专业难题由专业手段解决 | 一个案子或项目过一个关口 | 术语堆砌；主角永远正确；事实错误 |
| 直播文娱流 | 作品亮相的一刻和各方反应 | 一次亮相及其反响 | 反应刷屏代替内容；对手愚蠢 |
| 竞技赛事流 | 一场比一场硬的比赛 | 一场比赛或一项准备落定 | 只写结果不写战术；逢赛必胜 |
| 规则怪谈流 | 哪条规则是真的，违反了会怎样 | 确认一条规则的真假或边界 | 规则随剧情改口；用新规则救场 |
| 无限副本流 | 每个副本的新机制和通关方式 | 副本内一处局部障碍 | 副本只换外观；副本间状态清零 |
| 诡异民俗流 | 禁忌从何而来，破了规矩如何收场 | 摸清一条禁忌的来历或代价 | 民俗细节前后不一；法术万能 |
| 末世求生流 | 物资、安全、人手的此消彼长 | 三者之一发生变化 | 物资无限；伤病清零；人性只有恶 |
| 悬疑探案流 | 线索怎样拼成答案 | 一次判断被证实、推翻或收窄 | 隐藏关键线索；靠巧合或自白破案 |
| 智斗流 | 双方互相预判，谁多想了一层 | 一次交手的胜负和信息得失 | 对手降智；事后才告知读者的布置 |
| 探险寻宝流 | 下一处关口后面是什么 | 过一处关口或得一条路线信息 | 伤病缺水不影响行动；竞争者总是恰好出现 |
| 大逃杀生存流 | 谁活到最后，谁在何时出局 | 人数或同盟发生一次变化 | 不写战术；出局随意 |
| 窒息惊悚流 | 没有解法，退路一条条被堵 | 一条退路被堵或一个依靠失效 | 给出解法后变成解谜；威胁过早露面 |
| 甜宠流 | 两人一次比一次近的确定感 | 一个举动被对方接住 | 甜没有来由；误会拖着不解 |
| 恋爱拉扯 | 进一步退半步的不确定 | 关系向前或向后移动一格 | 拉扯过久没有新变化；越界被当作心动 |
| 追妻火葬场 | 亏欠方付出代价，另一方凭什么松口 | 一次补偿被拒或被部分接受 | 几十章同一种拒绝；自伤强迫被当作深情 |
| 宫斗宅斗流 | 在规矩之内怎样赢 | 位置、把柄或人手的一次变化 | 对手愚蠢；靠外力兜底 |
| 大女主流 | 她自己拿到权、钱、人、名、本事 | 到手一样并付出一样 | 资源由男性递送；没有代价 |
| 快穿流 | 每个世界一个任务和不同的解法 | 小世界内一个任务节点 | 世界只换外观；跨世界主线停滞 |
| 穿书同人流 | 知道剧情的人改命，哪些改得了 | 改变一个命运条件 | 原著知识永远准确；改动没有连锁后果 |
| 救赎流 | 一个人一点点被拉回来 | 信任前进或后退一格，并有凭据 | 施救者完美；创伤一次谈话治愈 |
| 年代生活流 | 特定年代里日子怎样一点点过好 | 家里一项实际改善 | 没有年代专有名词；老物件清单 |
| 日常流 | 熟悉的人和地方里的小变化 | 一件小事办完 | 硬加大冲突；流水账 |
| 沙雕搞笑流 | 歪逻辑撞上正经世界 | 笑点引擎的一次新用法，并且故事前进一步 | 叙述者先笑再解释；真危险被一并消解 |
| 群像流 | 多个人各自想要的东西互相碰撞 | 一个局部关系改变 | 轮流写个人传记；人物回归时状态清零 |
| 小人物现实困境流 | 普通人被钱、时间、体力、关系挤压，怎样撑过这一关 | 账上一项有了新数目 | 把穷人写成完人；作者出面议论 |

## 写成卡：推进模式卡

通用方法见 [card-method.md](card-method.md)，交付前检查见 [card-pitfalls.md](card-pitfalls.md)。

### 格式

用户指定了格式时以用户为准。未指定时使用下面的默认格式：

- 第一行以“读者追的是：”开头，第二行以“适用：”开头。
- 之后五个小节，顺序固定：推进循环、开局、加码、每章落点、容易写崩。
- 卡内正文 500 到 700 字，不含标题行。每次调用都会带上这张卡，篇幅就是成本。
- 不放场景示例。示例会被生成模型当作剧情照搬。示范写进条款：在要求后直接给出原词、落点或一组具体实例。
- 一张卡只写一种引擎。题材组合由“主线一种模式、副线各一种模式”表达，不在一张卡里混写两种引擎。
- 大白话，短句，祈使句。不写“可以考虑”“视情况”。

### 示例卡

下面这张卡用于说明做法。为同一类型写卡时重新设计，不照搬。

```markdown
# 规则怪谈流

读者追的是：纸上的规则哪条是真的，违反了会怎样，主角怎么在规则的缝里活到天亮。
适用：规则怪谈、伪人、收容类题材作主线；无限副本中的单个怪谈作副线。

## 推进循环

- 小循环（一到三章一圈）：拿到一条规则 → 遇到规则没写清的情况 → 用小动作试探 → 有人或有东西付出代价 → 确认它的真假。一圈的终点是多确认一条，不是多发现一条。
- 大循环（一个场所一卷）：规则看似能守 → 两条规则冲突 → 立规则的一方另有目的 → 用规则反制或逃离。卷末留一个没解开的疑问。

## 开局

- 第一章：拿到规则，并看见一个人违反后的下场，写到身体或位置的变化。
- 第二章：必须在两条规则之间选一条守。
- 第三章：确认第一条假规则，代价是一个帮手或一条退路。

## 加码

- 规则的麻烦依次更换：含糊 → 冲突 → 被人改过 → 守规则本身是陷阱。每换一档，旧的验证办法失效。
- 试探的代价逐档加重：物件，旁人，主角自己的一段记忆。
- 已确认的规则不得更改；新规则出现前要留有痕迹。

## 每章落点

- 每章至少落实一项：多确认一条规则，少一个可信的人，少一条退路。
- 写足试探的那一下：做了什么小动作，周围哪样东西变了。
- 章末停在本章实际变化的那一项上：确认了规则，停在它的下一处含糊；少了人，停在他留下的东西上。

## 容易写崩

- 规则随剧情改口，或用从未出现的规则救场。
- 恐怖只靠“诡异”“令人窒息”这类形容词。
- 每次试探都猜对，没有人付出代价。
- 给每条规则补上来由，怪谈变成解谜。规则只确认真假，不解释。
- 同行的人只负责出局，没有自己的打算。
```

这张卡使用的做法：

| 位置 | 做法 |
| :--- | :--- |
| “一到三章一圈”“一圈的终点是多确认一条” | 跨度与终点同时给出，终点由最小变化单位定义 |
| “有人或有东西付出代价” | 循环内含受阻环节，代价进入行动链 |
| 开局三条 | 逐章布置 |
| 加码第一条 | 有名称的台阶，每档更换一种麻烦，旧办法失效 |
| “已确认的规则不得更改” | 公平条款，禁止临时制造信息 |
| 每章落点第一条 | 封闭清单加下限，无兜底项 |
| 章末一条 | 按实际变化选择落点，不规定固定钩子 |
| “规则只确认真假，不解释” | 为小循环的“确认”和崩点栏的“解谜”划出界线，避免两处冲突 |
