# 写章节与场景

本文用于写新章节、续写和写单场戏。输入通常是章纲或一句任务说明。推进的设计见 [progression.md](progression.md)，文风见 [style.md](style.md)，表达自查见 [expression.md](expression.md)。

## 1. 动笔前确认四项

| 项目 | 要确认的内容 |
| :--- | :--- |
| 本章任务 | 这一章发生什么，交付给读者什么 |
| 前文状态 | 人物在哪里，知道什么，身上带着什么：伤、物件、承诺、未了结的事 |
| 视角 | 跟谁写，他有途径知道什么 |
| 文风 | 用哪种口气。未指定时按“一句一件事、按发生顺序写、谁在哪里做什么一读即明”来写；定位、写明它不做什么与冒名形态见 [style.md](style.md) 的“定位”与“各风格的辨识点与冒名形态”表（清楚利落行） |

缺少的内容先从上下文中找。找不到的关键项，在交付时说明所作的假设，不为此中断写作。

给模型的上下文按层给：先给卡片（推进、文风、表达），再给状态账本（上表的前文状态），再给本章节拍，最后给上一章最后一段原文。不要把整本大纲一股脑塞进去；宿主上下文够大时可以多给，但要分层标明哪一层是什么。

## 2. 确定本章的变化

- 章末与章首相比，局面、关系、认知、资源中至少一项不同。能用一句话说出这个变化，再动笔。
- 说不出变化的章，回到规划去解决，不靠文笔填充。
- 变化要有人付出代价，或留下后果。
- 本类型读者追的那样东西，在这一章里给了多少，写在哪一场。

## 3. 安排场景

写整章前先列节拍：每拍一句，写谁想要什么、发生了什么改变；拍数按章长定，作者确认后再展开。作者想即兴往下写时不强制。

- 每场戏回答三个问题：谁想要什么；谁或什么挡着；结果改变了什么。结果有三种：得到，没得到，得到了但付出了别的。
- 从事情开始的地方进场，变化落定就离场。过场一句带过。
- 上一场的结果是下一场的起因。场与场之间是“所以”或“但是”的关系，不是“然后”的关系。
- 背景信息拆进行动和争执，用到时才给，一次只给够用的量。
- 破局要用的人和物，在用到之前已经出现过。

## 4. 写作

**开头。** 三句之内让读者知道谁、在哪里、正在做什么。不以天气、时间、醒来开场，除非它们就是事情本身。

**动作。** 写清谁做了什么，结果如何。多人同场时及时点明行动的人，不用泛指的“他”“那里”“那件事”。

**对白。**

- 每句台词有一个目的：问、答、催、拒、瞒。说不出目的的台词删除。
- 对话双方想要的东西不同。一方想要，另一方给或者不给。
- 人物不互相讲述双方都知道的事。
- 人物之间的差别来自此刻想从对方那里得到什么，体现在称谓、绕不绕弯、接不接话上。
- 提示语用“说”；听得出是谁就省略。

**细节。** 一场戏选两三样人物正在用或正在看的东西。他注意到什么，说明他在想什么。

**情绪。** 写人物在这种情绪里做了什么、说错了什么、注意到了什么。节奏快的地方一句直说就够。情绪有迟滞：人会嘴硬，会过一阵才反应过来。

**内心。** 应当写具体的念头，比如在盘算什么、在犹豫什么、想起了哪一件事。不要写情绪的综述。

**视角。** 只写视角人物有途径知道的事。别人的心思通过言行来推断，可以推断错。

**详略。** 本类型读者追的那一下写足，过程性的内容压缩。

## 5. 收尾

- 停在动作、对白或一个没有解决的问题上。
- 不总结，不预告，不升华。
- 章末的钩子用事情来挂，不用感慨来挂。
- 大爽点兑现的那一章，章末落在余波中的一个新变化上，不另起一场新危机。
- 慢节奏题材的章末可以落在一件做完的事上。

## 6. 自查

按顺序进行，前一项没有通过时先解决前一项：

1. **变化。** 用一句话写出本章变了什么。写不出，回到第 2 步。
2. **连续性。** 伤势、物件、承诺、已知信息与前文一致；视角没有越界。
3. **表达。** 按 [expression.md](expression.md) 的病灶表检查。先查每场戏和每章的最后三句，再查对白，再查段落的形状。
4. **过度纠正。** 检查是否出现一串碎句、人人说谜语、没有任何情绪、流水账。

## 续写

- 先读前文的口气：人称、句子长短、对白习惯、称谓。沿用，不另起一种口气。
- 承接前文留下的状态和未了结的事。
- 新章开头不要复述前情。需要前情时，由人物当前的行动带出来；隔了很久才更新的连载，可以有一句话的提醒。
- 不引入此前没有出现过的设定、人物或规则来解决已有的问题。

## 篇幅

- 按用户指定的篇幅写。
- 篇幅不够时，增加场景内的行动和阻碍，不增加感慨和环境描写。
- 篇幅过长时，先删复述和过场，不删变化和代价。
