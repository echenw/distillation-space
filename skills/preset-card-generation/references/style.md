# 文风

文风回答一个问题：**已经定好的故事，用什么口气写出来。** 它不决定故事的目标和结果。

本文用于确定一本书的文风、模仿一段文字的口气、按指定文风写作，以及编写文风卡。

## 设计一种文风

一种文风由下列八项确定。编写文风卡时，它们就是卡的各个小节。

每个小节只写本风格与其他风格的差别。“短句为主”“描写生动”这类任何风格都成立的句子不写。

### 定位

先用几个词写出读感，再写适合的题材。默认文风同样需要定位，写明它不做什么。

### 叙述

- 人称和叙述距离确定为一种。本书另有设定时写“以本书为准”，不写“或”。
- 写明叙述者有权知道什么，例如：新视角只写本人实际所知，局部改写不扩大原有视角范围，不能把镜头拉远当作随意全知的理由。
- 写明叙述者有没有自己的口气。
- 允许换视角时写明条件和入口，例如：开头两句内让读者知道现在跟的是谁；平时一场只跟一人，大事临头才几行一换。

### 句子与段落

- 写清哪里短，哪里反而要长。
- 用词的雅俗用三到五个原词示意。不给封闭词表，封闭词表本身会造出一种新的腔调。
- 段落按职责划分，例如换了动作的人就换段，不按行数划分。
- 卡里有多个数字时，合起来读一遍：全部满足时的稿子是否仍是想要的文体。

### 对白

- 写这个风格里人怎么说话：话多话少，直说还是绕。
- 身份和关系从称谓和没有说出口的部分体现，例如：自称与敬语分档，臣、下官、本官各成一档；关心用埋怨说，配上称呼表，做出“场面上是一套、回屋里是另一套”的语域切换。
- 人物之间的语言差别按“此刻想从对方那里得到什么”区分。不按职业或身份分配固定句式。
- 需要时为提示语单独写规格。
- 主要人物各自的声口（用词范围、句长习惯、回避的话题、口头习惯）在 `character-and-narrative-control` 的 PS-31 定，文风卡引用它，不另立一套。还没有台词样本时，文风卡只写这个风格里人怎么说话，人物声口标“声口待定”，不替人物编口吻。

### 描写

感官要选，不要列。视觉之外也可以写声音、气味、触感，每处只用最能代表这一刻的一两种。感官本身是情节线索时，可以写细。

写笔墨花在哪里，哪里一笔带过，情绪由什么承载，例如：打斗写势和结果，一剑出去，山怎样，人怎样，不逐招报名；大事落在具体的政令、银钱与人头上，不落在形容词上。

### 节奏

写场景怎么进、怎么收，哪里慢、哪里快。每个手法带使用条件。一个手法写得越好用，越需要条件和次数上限，否则会在每一场戏里出现。

### 示例

按 [card-method.md](card-method.md) 第 5 节写，并满足：

- 演示本风格最有辨识度的那一条写法，场面取自本风格最常用的场面。
- 卡中有对白规则，示例就有对白。卡中要求人物口气不同，示例就有两个口气不同的人。
- 写完后逐行对照本卡的“避免”栏和各项门槛：示例违反自身规则是最常见的交付缺陷，不因为示例是最后一步就凭手感写。

### 避免

写本风格最常见的写坏方式，带具体坏例。必须包含冒名形态：看起来像本风格，实际已经退化的写法。前面每条正面要求的过度形态，应在本栏出现，或在该条款中已有护栏。

## 模仿一段文字的口气

1. 通读样本，按叙述、句子与段落、对白、描写、节奏五项各记下两三条稿面上的事实：用什么人称，离人物多近；句子在哪里短，在哪里长；人物说话绕不绕；笔墨花在哪里；场景怎么进、怎么收。
2. 每条事实附一处样本原句作依据。找不到依据的不写。
3. 用这些事实写一小段新内容，再与样本逐项对照，修正偏差。
4. 只学写法，不搬样本中的人物、情节和句子。

## 各风格的辨识点与冒名形态

下表是设计起点，不是定稿。写作时按辨识点落笔，并避开冒名形态；写卡时辨识点落实为条款，冒名形态写入“避免”栏。

| 风格 | 辨识点 | 冒名形态 |
| :--- | :--- | :--- |
| 清楚利落 | 一句一件事；按发生顺序写；谁在哪里做什么一读即明 | 流水账；一串碎句；清楚到没有口气 |
| 快节奏爽文 | 开场即入事；动作与结果紧挨；反应戏短 | 省略因果；用感叹号加速；碎成单句成段 |
| 第一人称口语 | 一个具体的人在讲；只讲他知道的；带偏见和说话习惯 | 口头禅重复；知道得比本人应知的多；频繁对读者喊话 |
| 玄幻仙侠 | 境界与天地的尺度；打斗写势和结果；称谓分辈分 | 动辄天地变色；逐招报名；祭文腔 |
| 轻快吐槽 | 叙述带态度；笑点之后接行动；玩笑合乎双方关系 | 全员讲段子；严肃处仍在调侃；以外貌羞辱取笑 |
| 历史权谋 | 言外之意落在称谓、座次、沉默上；大事落在政令、银钱、人头上 | 人人深不可测；解说每个停顿；“目光如刀”式形容 |
| 悬疑怪谈 | 只写看得见的异常；正常细节中错一处；不解释 | 全员说谜语；靠“诡异”“阴森”形容；隐瞒已经看见的事实 |
| 推理探案 | 只陈列可核对的事实；观察与推测分开 | 事后才给线索；侦探全知；以评价代替证据 |
| 专业纪实 | 流程与术语准确；外行能懂；数字有来处 | 术语堆砌；虚假的精确；说明书腔 |
| 现言甜宠 | 心动落在一个举动被接住；对话有来回 | 没有来由的宠爱；堆砌身体部位；拒绝被写成默许 |
| 古言 | 浅文言实词配白话虚词；称谓自称分明；写景点到为止 | “眸光一冷”式滥调；通篇四字格；现代词混入 |
| 年代烟火 | 数目和物价写出来；称呼带年代；关心以埋怨的口气说 | 老物件清单；怀旧滤镜；方言词表造腔 |
| 细腻情感 | 情绪落在改口、迟疑和小动作上；内心念头具体 | 情绪说明书；一句留白催泪的公式；只有内心没有动作 |
| 含蓄克制 | 事实承担情绪；写完即走不点明；话越重越家常 | 通篇短句的假冷调；省略到读不懂；固定使用同一个小动作 |
| 日常治愈 | 过程写足；小事有回应；不顺心的事允许留在场 | 人人好到不真实；细节堆成菜谱；烦恼必须当章解决 |
| 市井白描 | 只写看得见听得见的；不评价；连接词照常使用 | 写得粗糙；逐件报物品；破旧等同悲惨 |
| 多视角群像 | 各视角的称呼、在意的事、盲区不同；开头点明跟谁 | 所有视角一种腔调；按职业贴标签；镜头拉远变全知 |
| 冷面讽刺 | 叙述不动声色；讽刺来自流程和措辞的反差 | 作者出面挖苦；每段抖机灵；讽刺对象脸谱化 |

## 写成卡：文风卡

通用方法见 [card-method.md](card-method.md)，交付前检查见 [card-pitfalls.md](card-pitfalls.md)。

### 格式

用户指定了格式时以用户为准。未指定时使用下面的默认格式：

- 第一段是定位：读起来的感觉，适合的题材。
- 之后七个小节，顺序固定：叙述、句子与段落、对白、描写、节奏、示例（只学语感，不搬内容）、避免。
- 示例是一段原创文字，四到八行，每行以大于号加一个空格开头。不出现真实的作品、作者、平台名。
- 卡内正文 600 到 750 字，不含标题行。
- 不写生成、改写、审阅的操作规则和输出格式。
- 不布置剧情任务，不规定每章推进多少事。这属于推进模式卡。
- 不重复表达约束卡已经管的通病（套话、总结、情绪标签），不建立第二套表达约束。

### 示例卡

下面这张卡用于说明做法。为同一风格写卡时重新设计，不照搬。

```markdown
# 市井白描

平、实、不下判断，读起来像站在摊子边上看。适合市井生活、小人物、现实题材。

## 叙述

- 第三人称，一场戏只跟一个人，写他看得见、听得见的，不进别人心里。本书另定人称时以本书为准。
- 叙述者不评价，不替人物总结。

## 句子与段落

- 用口头说得出的词：说“借”不说“筹措”，说“没吭声”不说“沉默不语”。
- 句子长短跟着事情走。连着的动作写成一句，“就”“才”“又”照常用，不为显得冷硬删掉。
- 换一个人动作就换段。

## 对白

- 人说话只说半截，要紧的那句常常绕开。
- 钱、斤两、日子直接报数：“三块五”“后天”。
- 提示语用“说”，听得出是谁就省掉。

## 描写

- 一场戏点名两三样东西，而且是人物正在用、正在看的。不把屋里清点一遍。
- 旧和穷照实写，不加“破败”“凄凉”。破旧不等于悲惨。
- 叙述里不写情绪词，写他接下来手上做的事；人物自己嘴里说的不算。同一种小动作一章只用一次。

## 节奏

- 进场从一个动作开始，不先交代天气和时间。
- 事情办完就收，停在最后一个动作或一句话上。
- 讨价、等人、排队这类过程可以写长；赶路、睡觉一句带过。

## 示例（只学语感，不搬内容）

> 老周把秤盘往她眼前送了送，秤杆翘得高高的。
> “二斤三两，算你二斤。”
> “上回你也这么说。”她没接，伸手去翻筐底的梨。
> “底下的一样。”
> “一样你让我翻。”
> 老周不说话了，摸出半包烟，又塞回去。
> 她挑出两个带疤的搁在一边：“称吧。”

## 避免

- 白描写成粗糙：句子缺主语，前后不连。
- 把物件一件件报出来，却没有人去碰。
- 叙述者出面感慨日子艰难。
- 人人说话一个腔调，分不出谁是摊主谁是买主。
```

这张卡使用的做法：

| 位置 | 做法 |
| :--- | :--- |
| “一场戏只跟一个人……以本书为准” | 视角确定为一种，并限定信息权限 |
| “说‘借’不说‘筹措’” | 用少量原词示意用词，不给封闭词表 |
| “不为显得冷硬删掉” | 反向护栏，点名过度执行的形态 |
| “点名两三样”“一章只用一次” | 数量带单位和范围 |
| “人物自己嘴里说的不算” | 禁令限定在叙述层，对白不受限 |
| 示例七行 | 有对白，两人口气不同，报了数目，物件三样且都被使用，结尾停在一句话上，没有情绪词 |
| “避免”四条 | 冒名形态和正面要求的过度形态 |
