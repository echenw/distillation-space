# 来源索引与定位口径

[A-01的29源身份](sources/A-01-identities.md)与[B-01的103源身份](sources/B-01-identities.md)保留任务书目；[规则原锚点](sources/rule-evidence.md)保存各旧规则的原Skill文件/物理行号及PG原文行号或字符偏移。

L是原阅读版物理行号，C≈及裸大数是原索引字符偏移；不同电子版本可能漂移。PG ID相同不保证文本字节相同。现行SP的直接修正已有定向原文回读；未定向回读的PG锚点继承原Skill并标来源记录，不能宣称本轮逐条原著核验。

版本、历史覆盖/PASS与独有历史差异的处理记录位于总目录provenance和audit；运行本Skill不依赖这些档案，核心方法与模板在本包内。已证错误不能仅靠保留旧记录继续执行；见[裁决](12-decisions-and-boundaries.md)。
