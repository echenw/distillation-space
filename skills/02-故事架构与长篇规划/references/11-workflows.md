# 执行流程：规划、诊断、修订和连载审计

## 1. 规划

记录材料、任务、载体/读者、版本与范围；把缺失和可创作的空白分开。明确新建故事的请求可以生成候选人物、事件和结局，候选不冒充原资料。

1. 从人物、环境、行动、问题或声音进入，形成初步组织原则（SP01–03）。
2. 选择纸面/心中/发现式或混合工序；已知终点可逆推，未知就标探索范围（SP02、05）。
3. 记录全篇关键节点及多线关系，区分高潮、解结、余波；不套固定比例（SP04、06）。
4. 已有真实容量时与节点联查；容量未定可给范围和假设（SP19）。
5. 设计开篇的阅读入口、信息时序、场景贡献与结尾回应；单次阅读和分期阅读按实际需要分支（SP07、10–14）。
6. 多卷时加入层级、版本、角色/世界状态、开放线和可选发展方向（SP15–18）。
7. 有排期、反馈或载体任务再加载产能、首发、备用结局与载体表（SP21–25）。
8. 交付具体大纲/章卷计划及未定项；按任务需要选字段，不强制填尽所有表。

## 2. 诊断

**D0 范围**：作品、版本、实际已读/未读范围、用户关切、可修改范围。原稿未提供时只做给定提纲或假设诊断。

**D1 竞争解释**：先考虑题材、实验意图、读者契约、交付方式、版本或有意隐藏；“未证明是实验”不能反推“必是缺陷”。

**D2 证据**：记录具体位置、准确引文/转述、结构事实与读者反应的来源。结构关系可以核证，效果判断仍需区分推断和真实反馈。

**D3 判据**：选择当前条件下适用的SP规则，说明未采用其他路径的理由；同段可以有不同问题，但不把同一根因重复计数。

**D4 影响与验证**：依不修会损失的理解、因果、承诺或用户目标定优先级；不按出现三次、在开头/结尾或占固定百分比自动升级。用并排场景、删除试读、因果表、知情表或版本比对检验。

**D5 交付**：位置→问题→依据→竞争解释→最小建议→受影响依赖→未决项。要修稿时继续执行，不能只递交报告。

| 症状 | 首查 | 竞争解释与最小验证 |
|---|---|---|
| 开篇失去方向 | SP07、03 | 慢热/框架/声音是否本来就是入口；比较删首段的实际损失 |
| 中段平、重复 | SP10、18、21 | 停顿/仪式/生活流可能有价值；并列功能和情感变化 |
| 巧合解结 | SP08–09 | 体裁偶然性、埋线、人物选择及世界机制；核结果的具体前因 |
| 多线失焦 | SP03–04、17 | 对照/编年不必因果汇合；分线列组织关系和承诺 |
| 章末无力 | SP12 | 安静收束、同场连续、完整单元；查看期待是否有后续变化 |
| 结尾拖长/欠账 | SP06、13 | 必要余波、人物愿望落空、开放结尾；逐条核作者实际承诺 |
| 判断声音冲突 | SP14 | 不可靠叙述/反讽可有意；并排叙述评语、事件与读者信息 |
| 场景似无功能 | SP10、20 | 氛围、声音、审美和对照也可成立；试删后查所有价值而非只查调用 |
| 跨卷矛盾/忘账 | SP16–17 | 未知前卷、候选未采用、预测非事实；核正典版本与实际传讯 |
| 排期/容量不稳 | SP19、22–23 | 计量单位、返工、合同未定、库存不可交付；复算实际差额 |

OOC专项使用既有人物事实、当前压力、可选行动、代价与后果四栏；不足处记待证，不能“一栏缺失=动机没展示”或把作者意图当原因。完整心理诊断可交Skill04，本包保留完成结构审计所需最小方法。

## 3. 修订

W0记录版本和锁定项；保护用户未授权内容。W1确认实际根因及任务范围。W2按需要选择结构、场景、句段或联动修订。W3实施有效且可回看的改动，记录新设信息。W4检查直接依赖。W5交付实际改稿、变更理由和验证边界。

结构层可移动起点、重排支点、删合/改挂支线、改因或改果、调整容器/粒度；场景层可移信息、改变行动顺序、合并相似功能或保留有价值停顿；句段层可压缩重复、抽象解释和冗长列举。各层都须尊重用户保留的人物声音、主线、意象或既有版次。

删并的四类承重：因果条件、必要信息、关系/情绪变化、主题/节奏回声。另核即时语调与审美价值，不能因为未被后文调用就判无用。摘要可压缩时间，仍应保留说话者、关键动作和语言高点；列举/排行/说明是否删除取决于功能。

回归只检查受实际改动影响的内容：前提与结果是否仍相接，人物是否知道应知信息，删掉伏笔的回收是否改妥，已立承诺是否重定义，旧台账是否更新，章号/词数是否复算，语调和保留项是否还在。未实际生成二稿不能写二稿通过。

## 4. 系列与生产的专用路径

新卷：单元与承诺→容量/排期若存在→前卷状态→开放线→章界/变奏按需。既有卷：实际卷首卷末→状态与承诺→依赖→必要改法。重复节奏：并列功能/代价→判断保留或变奏→复核容量。开载：实际可交稿量→修改权/期限→首发时点→缓冲/备用方案。载体：原刊构成与电子转写层分开→正文可用容量→发行边界。

连续性审计保留时间线、人物、世界、开放线、回顾一致性五项；表格只是正文投影，不构成第二正典。已发表内容不可回写时在后卷处理；用户授权重版修订时可具体执行并清楚区分版次。

## 5. 完成与退出

交付与任务一致；定位可回查；每项关键推断带条件；尚缺资料仅阻塞对应断言。无真实文本、读者数据、修订产物或运行记录时如实标未知/NOT_PROVEN。未知效果不阻止合理创作提案，未知事实不允许伪造。
