## 骨架 1：PG175《The Phantom of the Opera》—— 全解释型长篇

**来源**：Leroux 1910，10,407 行。`carrier=FICTION`。

### 结构拆解
1. **四层叙述**（L142-160）：史家 → 经理回忆录 → 波斯人手稿 → 女主手书。每层只见一部分。
2. **契约**（L1206-1209）：月薪两万法郎 / 年廿四万 —— **C7 代价单位化**（月→年自动换算）。
3. **日常到可笑的规则**（L1689-1699）：三下敲门、脚凳、椅面朝下。
4. **声音先行，身体功能背叛**（L3028-3033）：歌声被 "co-ack!" 打断 —— F3。
5. **临终自白**（L9765-9869）→ **物证压回**（L10194-10201）：I3 + **E6**。
6. **冷档案收束**（L3057、L9920-9922）+ **余数落在物证**（戴戒指的骷髅）：G2 + G3。

### 可迁移步骤
1. 定兑现度轴位 = **1**（全兑现全解释）。
2. 选 S3（人的意图）为主来源，S1（超自然）为**伪装**来源。
3. 立契约，并把代价换算成一个单位（C7）。
4. 立 2–3 条日常到可笑的规则（C3），让世界像在真实运行。
5. 用四层叙述分配信息（B4），读者每层只多知道一点。
6. 升级打在身体功能上（F3），不打在怪物强度上。
7. 结尾给自白，然后**同一单元内**用物证压回（E6）。
8. 解释 90%，余数落在物证（G3）。

### 失效条件
- 删掉余数 → 变冒险小说。
- 自白后不压回 → 感伤洗白（E6）。
- 四层叙述超过 4 层 → 读者失去锚点。
- 中途换代价单位（月→年→次）→ 结算感消失（C7）。

## 骨架 2：PG68569《The Wyvern Mystery》—— 家族哥特长篇

**来源**：Le Fanu 1869，15,937 行。`carrier=FICTION`。

### 结构拆解
1. **法律-性秘密地基**（L11831-11836、L15706-15719）：重婚 + 调包 + 继承 —— J3。
2. **建筑即凶器**（L8559-8567、L8895-8897）：纸糊壁橱门 = 杀人通道，且**先给读者看过** —— D1。
3. **仆役/方言信息层**（L6640-6641）：真相从厨房先漏 —— J4。
4. **冷面执行者**（L15148-15149）：「silent, cold, orderly」—— **A5/A6 制度性恐怖**、**B7 量化细节**（以"有序"这一可观察特征定人）。
5. **凶兆线不解释**（L3538-3749）：人祸全解释，凶兆不解释 —— G6。
6. **临终供词 + 认子**（L15686-15725）：I3。
7. **短恐怖 + 长日常**（L8843-8929 → L9039-9130）：F4。

### 可迁移步骤
1. 定轴位 = **1**（全兑现，但凶兆不解释）。
2. 选 S3 为主来源，留 S1 作不解释的余量（G6）。
3. 用法律-性秘密作长篇地基（J3），不要靠巧合推进（A4 零和账本）。
4. **先把建筑通道给读者看过**，再让它成为凶器（D1）。
5. 把信息层交给仆役（J4），真相从边缘先漏。
6. 执行者写成"冷 + 有序"（B7），不要写成狂暴。
7. 恐怖段 ≤1 章，前后用家务/账目放松（F4）。
8. 临终供词后，用继承/物证结算（I3）。

### 失效条件
- 法条过多 → 变诉讼（J3）。
- 建筑通道未提前给读者看 → 变密室诡计而非恐怖（D1）。
- 把凶兆也解释掉 → 失去宿命感（G6）。
- 巧合过多（重婚 + 调包 + 认子全靠偶遇）→ 巧合过量失败模式。

## 骨架 3：PG932《The Fall of the House of Usher》—— 短篇同构

**来源**：Poe 1839，789 行。`carrier=FICTION`。

### 结构拆解
1. **宅即人**：宅的病征 = 人的病征（L126-130）—— D1 的同构变体。
2. **读者先于叙述者知道**（L520-525）：读者先看见征兆 —— B5。
3. **全兑现不解释**：Madeline 立于门口，以倒塌兑现（轴位 2）。

### 可迁移步骤
1. 定轴位 = **2**（全兑现不解释）。
2. 选 S2（被浸透的地点）。
3. 让宅与人的病征同步，读者先看见宅的病（B5 + D1）。
4. 不给解释，让倒塌同时结算人与宅。

### 失效条件
- 短篇里塞入多层叙述 → 撑不住（B4 适合长篇）。
- 事后补解释 → 变成哥特说明文。

## 骨架 4：PG12828《Two Ghostly Mysteries》—— 伪文献 + 痕迹反证

**来源**：Le Fanu 1836/1851，2,682 行。`carrier=FICTION`。

### 结构拆解
1. **痕迹反证**（L112-140）：空院无车辙、雪面平整 —— D4。
2. **日常物件背叛**（L1030-1039）：镜子自行移开露出壁洞 —— D5（D7 的部分实现）。
3. **三异常一结论**（L112-146）：F1，异常互相冲突。
4. **凶兆线**（L545-564）：G6。

### 可迁移步骤
1. 定轴位 = **1** 或 **2**（本篇偏 2）。
2. 用痕迹反证建立"来过但不该来过"（D4）。
3. 三条异常必须互相冲突，第四条无法解释（F1）。
4. 留一条不解释的凶兆（G6）。

### 失效条件
- 四条异常同类型 → 读者当成巧合堆叠（F1）。
- 痕迹写成推理线索 → 转悬疑（三问第二问）。

## 骨架 5：PG23535《The Invaders》—— 短篇密度型

**来源**：Ferris 1951，887 行。`carrier=FICTION`。

### 结构拆解
1. **三异常一结论**（L124-126、L306-315）：F1。
2. **官方错误答案**（L479-490）：B2。
3. **反制先由失效建立**（L628-630）：C4。
4. **零和账本**（L556-589）：A4。

### 可迁移步骤
1. 短篇优先密度（F1），不优先强度。
2. 让官方给出最合理的错误答案（B2），但要在读者已知另一部分真相之后。
3. 反制手段先失效，再给唯一有效手段（C4）。
4. 每次推进都要有代价（A4）。

### 失效条件
- 密度型无结论（第四条不够强）→ 读者只感到零散。
- 官方错误答案给太早 → 读者以为文本在犯错（B2）。

## 骨架 6：**PG30729《The Body-Snatcher》+ 批评卷** — 双载体示范（本版新增）

**来源**：Stevenson，9,414 行。**双载体**：
- `carrier=FICTION`：L8641–9396（756 行，短篇）。
- `carrier=NONFICTION`：L131–8640（8,510 行，批评散文）。

### 6A 短篇部分（`carrier=FICTION`）—— 共犯与物流

**结构拆解**
1. **框架叙述**（L8649-8668）：小旅馆四固定客 + 有秘密的老酒鬼。先给异样，再给身世。
2. **名字触发失态**（L8698）：「as if a man had risen from the dead」。
3. **一句耳语追问**（L8809）：「Have you seen it again?」—— E3 信息扣留，**后文由错尸反转兑现**。
4. **日常异常**（L8915）：「singular freshness of the bodies」—— 先让读者自己起疑。
5. **具名冲击**（L8939）：「That is Jane Galbraith!」
6. **一句话揭底**（L8999）：「practically speaking, all our subjects have been murdered」—— **B3 职业程序**。
7. **共犯逻辑**（L9112-9113）：「The more things are wrong the more…」
8. **不可逆**（L9152）：「If you begin, you must keep on beginning」。
9. **物流恐怖**（L9354）：「some unnatural miracle had been accomplished」—— 雨、麻袋、狗吠。
10. **错尸反转**（L9382）：「That is not a woman」→ 熟人脸。
11. **冷收束**（L9392-9396）：尸体在马车里跑掉，**无道德总结** —— G2（本版为**次级样本**）。

**可迁移步骤**
1. 定轴位 = **2**（全兑现不解释）。
2. 选 S3（人的意图/共犯）。
3. 共犯阶梯：看见 → 收钱 → 记账 → 动手，**每步只小一点**（R2）。
4. 恐惧由**普通物流**制造，不写血腥。
5. 结尾**不解释、不加道德总结**（C5 冲突裁决）。

**失效条件**
- 主角必须保持清白时（共犯链要求读者代入）。
- 读者对物流细节不熟悉时（麻袋/马车/狗吠的压迫感依赖共同经验）。

### 6B 批评部分（`carrier=NONFICTION`）—— 六个可迁移装置

> **警告**：以下六项的载体是**历史批评散文**，不是小说。迁移时必须换结算方式（历史/法律/医学），且**只能作 COND/H 级线索**。

1. **团伙退场表（K1）** —— L4893「they all go with a clog about their feet.」
   - 迁移：为每个同伙排定落网时序，**每节只收一人，间隔递减**，最后收首恶。
   - 失效：团伙 ≤2 人。

2. **程序化作案（K2）** —— L4804-4806「It was ten o'clock when they mounted the ladder; it was about midnight before Tabary beheld them coming back.」
   - 迁移：给钟点（起点 + 终点，中间留白）+ 工具分工 + 分赃数额；全程陈述句，不评价。
   - **失效**：激情犯罪；写成操作手册（**只取叙述结构**）。

3. **囚禁对照法（K3）** —— L5049「basket into a noisome pit, where he lay all summer, gnawing hard crusts」
   - 迁移：囚室内只给 1–2 个感官残片；每节插入一条**外部世界照常运转**的消息。
   - 失效：囚徒无外部信息来源。
   - **特别注意**：原文是真实历史人物的遭遇，读者会产生**同情**；迁移到虚构时必须切断这一同情来源，否则同情取代恐惧。

4. **自白 + 压回（E6）** —— L8370（自白）→ L8442-8445（压回）
   - 迁移：先写动人的自白，再**在同一叙事单元内**放一条不带评价的事实。
   - 失效：需要读者持续同情该人物时。

5. **公私反差（E7）** —— L8469（周日使人恐惧）+ L8253（周一与人同泣）
   - 迁移：同一种措辞强度，两个真实场景，一个公众一个私人；**不要让叙述者点破**。
   - 失效：只有声明没有场景；反差被叙述者点破。

6. **代价单位化（C7）** —— L3297「The cost of a thing…is _the amount of what I will call life_」
   - 迁移：把代价换算成一个可数单位（生命量/时间/金额/次数）并给出换算。
   - 失效：纯气氛型无契约时。

**另可作为"不要做什么"的对照（L1）** —— L995「unprincipled avidity after effect」：为出效果而造假最不可饶恕。与 PG11074 L772「Nothing happened.」对读，可得完整判断：**宁可不给效果，也不造假**。
