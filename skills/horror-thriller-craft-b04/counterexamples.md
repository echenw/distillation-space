# 边界反例对照表 — v2

本批 27 源中有 9 个边界/混合样本（10 源）。它们不是"恐怖失败品"，而是**控制组**：用来证明恐怖的必要条件、测试道具能否迁移、暴露恐怖所需的"未拆余量"。
用法只有四种：**负定义 / 装置迁移 / 对照技法 / 降权证据**。边界源不得单独支撑 CORE 规则。

**本版变动**：边界样本由 8 个增至 **9 个**——PG30729 由"MIXED（评论未读）"升为 100% FULL 后，其落位从"降权证据（名义）"明确为"**装置迁移 + 降权证据**"双重落位。

## 2. 九个边界样本逐条

### 2.1 PG13314《Barford Abbey》—— 感伤书信体（非恐怖）

- **三问**：不可交涉？否。不可结算？否（信件/身份/婚配可解）。留余量？否（婚礼+慈善宴收束）。
- **文本现象**：猝死"不可怕"（L54）；庄园=圣地（L262-266）；ghost 只作明喻（L1182-1186、L3366-3369）；全书唯一实写 horror 是床下男人（L5071-5076）。
- **可借**：① 现实惊吓"床下有人"（身体临近+不可见）；② 假死+认尸错误制造悲痛；③ 喜剧配角泄压。
- **不可借**：把古堡/书信/夜当恐怖充分条件；把"ghost/apparition"词频当显灵证据。

### 2.2 PG269《Beasts and Super-Beasts》—— 讽刺集

- **三问**：不可交涉？否（鬼多为骗局/玩笑）。留余量？偶有（蹼足印）但被笑点收编。
- **可借**：把恐怖机关"拆开"给读者看（"The Open Window" L1279-1366），正好暴露恐怖所需的"未拆余量"。
- **不可借**：把讽刺的消解当恐怖手法。

### 2.3 PG9964《The Centaur》—— 自然神秘

- **三问**：不可交涉？弱（"被带走"而非被杀）。不可结算？否（医学 syncope）。留余量？强。
- **可借**：敬畏 vs 恐怖的区分；第三身影（L2273-2299）；少年"归去"（L4443-4454）。
- **不可借**：把 awe 译成 evil 会降级为道德剧（Machen 自认此为失败）。

### 2.4 PG6761《Ferdinand Count Fathom》—— 流浪汉小说

- **三问**：第一问在伪显灵段落成立，但全书以讽刺/团圆结算。
- **可借**：伪显灵三阶段（L13823-14153）；假死骗局（L14238-14263）；活人出棺（L15009-15014）。
- **不可借**：把团圆结算当恐怖收束。

### 2.5 PG9468《Anna St. Ives》—— 雅各宾书信体（混合）

- **三问**：第一问在卷六–七成立（囚禁、疯人院、毒茶），第二问部分否（法律/医学收束）。
- **可借**：① 世俗化哥特（城堡→租屋，鬼→伪造信，诅咒→债务/继承）；② 反派的委婉语；③ 受害者在最无助时正面抗辩但不脱险。
- **不可借**：把全书当恐怖；前五卷的论辩/婚恋与恐怖无关。

### 2.6 PG30729《Stevenson 文集卷三》—— MIXED（**本版重写**）

> **v1.0.0 旧条目作废**（旧版："评论/杂文未读；本卡只覆盖短篇，评论部分 NOT_READ"）。PG30729 现已 100% FULL（L1–9414）。

- **判定**：`MIXED_NONFICTION_CRITICISM_90.4% + FICTION_CASE_HORROR_8.0%`。L131–8640（8,510 行）为九篇文学/人物批评散文；L8641–9396（756 行）为恐怖短篇。
- **四用落位**：
  - 用法 1 负定义：**否**——其短篇三问全过，不是负定义样本。
  - 用法 2 装置迁移：**是（主要）**——团伙程序、刑讯、囚禁、共犯阶梯可迁移；**必须换结算方式**（历史/法律/医学），不能靠"史料可信"生效。
  - 用法 3 对照技法：**部分**——Knox 篇"公开教义 vs 私人行为"分裂暴露人物可信度的构造。
  - 用法 4 降权证据：**是（主要）**——90.4% 为非虚构，整卷不得当恐怖语料计入。
- **能借（七类）**：① 共犯阶梯；② 物流制造恐惧；③ 错尸反转；④ 团伙退场表；⑤ 程序化作案；⑥ 囚禁对照法；⑦ 制度机器/代价单位化/量化细节/自白压回/公私反差/以熟为奇。
- **不能借**：把九篇评论当恐怖语料；把时代立场（Knox 篇的女性观是**被批判对象**、Villon 篇的阶层污名、Yoshida 篇的东方主义转述）转为规则；把 Villon 篇的犯罪程序写成操作手册。

### 2.7 PG35153 / PG78106 —— Machen 自传性文论（非虚构）

- **可借**：① "敬畏≠邪恶"的区分；② "三层解释"配方（民俗+伪科学+更坏的修正）；③ "先定情绪，再找最小事件"。
- **不可借**：把作者自述当规则；两书自述互相冲突，以成品为准。

### 2.8 PG14099 —— 证言汇编（非虚构）

- **可借**：① 证言三件套（谁说的/谁还看见/哪里不能保证）；② 先拆假鬼再留余数；③ 琐碎、无目的、带小脾气的鬼细节。
- **不可借**：把汇编里的"真实"当小说情节证据；把余数论证当逻辑证明。

### 2.9 四个非虚构源的**关系说明**

PG30729 批评部分、Machen 两书、PG14099 构成本批四个非虚构源。作者不同、形态不同（文学批评 / 诗学自传 / 证言汇编），**来源族去重时不合并**；但共享硬约束：**不得单独支撑任何 CORE 规则**。

**唯一放宽**：PG30729 批评部分的论述对象是已出版的虚构作品（雨果的小说），其"恐怖如何被制造"具有跨作品观察性质，可信度略高于纯自述。**A7 与 L1 两条**允许"1 个非虚构源 + 1 个小说源"即构成 COND。此放宽不适用于其他规则。

## 3. 迁移检查清单

迁移任何边界道具前，逐条回答：

1. 原样本的**结算方式**是什么？（法律 / 医学 / 社会 / 道德 / 复活）
2. 我的文本的结算方式是什么？
3. 两者**是否相同**？若相同 → 换皮，禁止。
4. 若从 NONFICTION 迁移（PG30729 尤其），**同情来源是否已被切断**？（历史真实人物的遭遇会产生同情，而同情会取代恐惧）
5. 若迁移犯罪程序（K2），**是否只取叙述结构而未取操作细节**？
