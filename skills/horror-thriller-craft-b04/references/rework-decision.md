# 兑现度、解释深度与来源层级：返工执行协议（B04）

## 输入合同

输入仅为作者实际提供的故事类型/目标效果/章节或场景文本及已读范围；输出为 `威胁来源 | 兑现强度 | 解释强度 | 具体代价 | 有效余数 | 两套场景方案及取舍 | 来源级别 | 失败出口`。缺正文时只规划，不判某章失败。每项 **F** 来源现象独立列明；从作品归纳机制必须标 **H**；作者可执行的改变标 **P**。

## 三个独立轴（修复旧 P3 C1/C2/G3 捆绑）

1. **兑现轴 V**：V0 从未具象出现；V1 出现一个可见实体；V2 错兑现（等待 A、揭示 B）。问用户“这篇恐怖来自等待、直面，还是预期落空”，**不以长短篇直接禁止 V2**。PG11074 L3131–3132 在文本中讨论 `Nothing happened` 的原因；PG932 L776–780 以实体与宅体变化兑现；PG30729 L9389–9393 揭示熟悉的死者而非预期对象。三者是对照故事 F，不是效果排行。
2. **解释轴 E**：E0 留白；E1 解释风险机制但保留一项悬念；E2 全解释。PG175 的舞台机械与身份谜为强解释的作品范例，PG9964 L12–14 用知识不可达制造敬畏（不等于特定怪物已被证实）。**“90%”仅比喻，不是数学阈值**；为悬念强留 10% 会破坏已经承诺的侦探式收束。
3. **余数轴 R**：R1 可触的物证/异物，R2 叙述者信念或记忆，R3 社会制度仍照常运作，R0 无余数。PG1289 L36–40 故意把日间正常环境与鬼屋预期倒置；PG35153 L446–449 是作者回忆的诗学意图而非成品；二者不能证明“余数只能物证”。

**选择法**：作者要求证明怪物真实 → V1 + E0/E1 + R1/R2；作者要求解释型怪谈 → V1/V2 + E2 + R0/R3；作者要求“没发生却后怕” → V0 + E0/E1 + R2；作者要温情收束 → 可以 V1 + E2 + R0，不强留威胁。输出必须说明另一种选择放弃了什么。若要求同一事实既被完全自然解释又必须客观超自然，先列两种终局契约，不能两者均标“已完成”。

## L1/L2/边界：同卷必须拆开

- **L1 小说**：`PG30729 L8646–9396` 是《The Body-Snatcher》，可观察共犯、医学职业信誉、错尸/叙述空白；只计一个小说来源族。
- **L2 非虚构**：`PG30729 L1–8640` 为人物与历史评论，L4893 的“fugitives captured”不是恐怖小说情节；只能作为写作启发或历史批评论述，不等同虚构恐怖的跨书验证。
- **同作者/非虚构**：PG35153、PG78106 是同作者自传与创作意见，只计一个独立思想族；PG14099 鬼故事集与导言要分层；PG17893 的类型评论不可当成全体作品的类型定义。
- **控制反例**：PG13314 感伤、PG269 讽刺、PG9964 敬畏、PG9468 混合体裁、PG6761 流浪汉及 PG30729 非虚构部分不作为独立“恐怖规则核心票”。它们的价值是揭示：恐惧可以由弱解释、反讽或伦理后果产生，拒绝一体通用。

## 场景修订与失败出口

- **先定损失**：每一场写读者原信念、新观察、人物付出的真实关系/资源/认知成本（而非单纯音效更大）。同机制三次重复但损失没有变化 → 优先修改“代价/可信度/选择”，不是加怪物数量。
- **再选线索**：需要回读证明的恐怖 → 前置可检验的痕迹；追求不可说的敬畏 → 不强造物证。小说里可有真灵异也可有假灵异；不据表面鬼影预先定终局。
- **输出**：`场次/读者知识/威胁来源/上次与本次损失/兑现轴V/解释轴E/余数轴R/修改 A 与 B/失败出口`；若只有“鬼屋很吓人”一句，输出空白表并要求材质，不伪称诊断。
