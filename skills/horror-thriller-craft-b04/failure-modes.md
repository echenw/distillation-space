# 失败模式与不可声称清单 — v2

本文件记录四类东西：**本批证据不足以支持的断言（NOT_PROVEN）**、**1910 年前后文本的时代伤害**、**可复现的结构性失败**、**本版新增的"效果饥渴"**。
用途：改稿时逐条排查；引用本 Skill 时不要越过这些边界。

---

## 1. NOT_PROVEN（不得写进规则）

| 断言 | 为什么不能写 | 本批反证/限制 |
|---|---|---|
| "恐怖必须靠 jump scare / 短句" | 本批 1786–1951 文本几乎不用现代 jump scare；无法证明 | PG932/PG175/PG68569 均以长句、慢节奏成立 |

## 2. 时代伤害（只登记，不采纳）

### 2.1 残疾/疾病作为"恶的标记"

- PG68569 L6465-6467：Bertha 的脸"pitted with the small-pox and deadly pale"，天花麻脸被写成恐怖来源。
- PG68569 L6941-6945：失明被写成"更方便作恶"。
- PG68569 L6503-6510：癫痫、酗酒、年老被并置为"该死不死的怪物"。
- PG17893 的方言拼写把黑人/乡下人的口音写成滑稽。
- PG175 L10109-10110：Erik 被"作为活尸展览"。

**处理**：这些是 1869/1910 年的写法，不是技法。现代写作若要用"身体异常"制造恐怖，改写为"身体功能的失控"（F3），不要用"残疾=恶"。

### 2.2 性别暴力与"浪漫化胁迫"

- PG9468 L17742-17747：把强奸写成宗教诅咒与"horrid satisfaction"（后者逐字可查；此处概述用语不作引文）。
- PG68569 L1244-1298：六十岁监护人强吻养女，被写成 grotesque 的求婚（概述用语，求婚情节见该区间原文）。
- PG175 L4863："I am a kind of Don Juan, you know!" —— 怪物以"爱"为名的占有，容易被读成浪漫。

**处理**：写"胁迫"时，必须让受害者的抗辩/后果占足篇幅；不要把"被爱"当暴力的免责。

### 2.3 阶级/种族/国族刻板

- PG68569 的"Dutchwoman/Vrau"口音与"外国=阴险"。
- PG14099 的"证言人层级"以"ladies and gentlemen"为标准，排除底层证词。
- PG13314 的仆人喜剧（Morgan）以阶级口音取笑。

### 2.4 **PG30729 的时代立场（本版新增，必须单列）**

PG30729 全书 90.4% 为批评散文，内含大量时代立场。**一律不转为规则**：

- **宗教仇恨语**：称 Elizabeth 为"occidental star"、称 Mary 为"horrible monster Jezebel of England"（L7412-7413、L8264）。
- **阶层污名**：Villon 篇对"mauvais pauvre"的描写（L5196-5201）——「I would not go down a dark road with him for a large consideration」。
- **东方主义转述**：Yoshida 篇（L3984-3994）自述"it was but my hand that held the pen"，转述自日本人口述，带 19 世纪东方视角。
- **性别立场**：Knox 篇引述的"Women are weak, frail, impatient, feeble, and foolish"（L7381）——**这是史蒂文森引述并批判的对象，不是他的主张**；引用时必须保留这层关系，不得当作可采纳判断。

**处理原则**：引用 PG30729 时，先判断该句是"史蒂文森的裁决"还是"他引述并批判的对象"。后者只可作叙述者立场的样本，不可作规则。

## 3. 可复现的结构性失败

### 3.1 解释焦虑（收束阶段倒空）

- **症状**：怕读者不懂，把所有东西都解释掉，收束后读者泄气。
- **解法**：G3（解释 90%，余数落在物证）；C2 解释深度由类型承诺决定。
- **对照**：PG17893 导论明言鬼故事"the underlying mystery remains"，拒绝用解释补效果。

### 3.2 巧合过量

- **症状**：推进靠"恰好"，读者停止推理。
- **解法**：F1 要求异常互相冲突（不是同类型重复）；A4 要求零和账本（每次推进有代价）。

### 3.3 感伤洗白

- **症状**：反派临终自白把恶改写成"爱而不得"，读者原谅了他。
- **解法**：I3（临终自白必须被物证压回）；**E6（本版新增，更一般）：任何自白都要在同一叙事单元内被事实压回**。
- **对照**：PG30729 L8370（自白）→ L8442-8445（压回）是机制最完整的一例。

### 3.4 规则自相矛盾

- **症状**：前文立的规则在后文被自己打破，读者不再投入。
- **解法**：C4（反制先由失效建立）；C7（代价单位统一，不要中途换单位）；A1（伪装来源只选一层）。

### 3.5 **效果饥渴（本版新增，制造阶段加料）**— 规则 L1

- **症状**：为了让读者害怕，硬造一个前文规则体系推不出来的异象。读者一旦识破，恐怖立即失效。
- **诊断**：逐个异象问"它由前文的哪条规则/代价推出？"若答不出，就是加料。
- **解法**：删掉，或给它一个在前文已存在的机制。宁可少给一次惊吓。
- **对照**：PG11074 L772「Nothing happened.」——宁可不给效果也不造假；因兑现度轴位（轴 0）前后一致，读者不觉得被骗。
- **故意违反**：喜剧/反类型（PG6995）可靠违反规则生效，但那是**声明过的**违反，不是偷偷加料。

**与解释焦虑的关系**：同一病症的两端——L1 是**加料**（制造阶段），解释焦虑是**倒空**（收束阶段）。

### 3.6 **载体误用（本版新增，PG30729 专项）**

- **症状**：把批评散文里的技法样本当成小说成品证据，或把历史真实人物的遭遇直接搬进虚构而保留其"真实"带来的同情。
- **后果**：① 非虚构源单独支撑 CORE（违反硬约束）；② 同情取代恐惧。
- **解法**：① 引用 PG30729 且行号在 L131–8640 时标注 `carrier=NONFICTION`；② 迁移犯罪程序（K2）只取叙述结构不取操作细节；③ 迁移囚禁（K3）时切断"真实人物"这一同情来源。

### 3.7 **量化细节失效（B7 专项）**

- **症状**：给了数字但读者无感。
- **原因**：数字无对照基线。
- **解法**：必须给起点基线（"起初只有一次"）并让它随时间变化。

## 4. 使用本 Skill 的禁止清单

1. 不得把 NOT_PROVEN 的断言写成规则（见 §1）。
2. 不得用非虚构源（PG35153 / PG78106 / PG14099 / PG30729 批评部分）**单独**支撑任何 CORE 规则。
3. 不得引用 PG30729 的时代立场作为写作建议（见 §2.4）。
4. 不得把 Villon 篇的犯罪程序写成操作手册（只取叙述结构）。
5. 不得把"制度恐怖优于超自然"写成价值排序（NOT_PROVEN）。
6. 不得在写动人的自白后不压回（E6）。
7. 不得为了"出效果"硬造无根异象（L1）。
