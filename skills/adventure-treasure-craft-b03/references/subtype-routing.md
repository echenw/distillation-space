# 子类型路由（第 1 步，不可跳过）

## 为什么必须先路由

- **F**：任务清单对本任务写明 `batch_is_workload_partition_not_new_semantic_genre: true`；
  `批次来源清单.json` 写明 `no_semantic_genre_reclassification: true`。
- **F**：30 部里真正的"海上/荒岛寻宝"只是一部分。**PG13527《Ticket No. "9672"》全书没有寻宝物件**——
  核心是一张彩票与一艘失踪的船，悬念由开奖制度产生（L5800-5808 头奖留到最后抽出、一票不中两次）。
- **H**：把羊皮纸海图、仪表读数、彩票号码三种证据系统硬并成一套，会产出大量假规则。
- **P**：先判子类，再决定用哪一组机制；不能跨子类强制。

## 判定顺序（自上而下，命中即停）

1. 目标物是**技术/能量/长生/异界规则**吗 → B。
2. 目标物是**埋藏的财宝/沉船/遗迹**，且主要交通是船 → A。
3. 目标是**穿越、追踪、送达、取证、赶上某个时间** → C 或 E；有明确藏宝点才归 A。
4. 是**短篇集**且主线是生存/部族/荒野 → D。
5. 都没有 → E，并明确告诉用户"本书没有寻宝机制，下面按非寻宝传奇处理"。
