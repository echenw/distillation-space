# 示范（DESIGN_EXAMPLE，非真实用户任务）

三份示范只用于说明"证据怎么挂、裁决怎么写"。它们不是真实用户委托，也不是改编成果。

## 例一：判断一个题材能不能改到银幕（无声片口径）

**输入（构造）**：一个短篇——"侦探在开场前收到委托，靠三场审讯中的对白推理出凶手，最后一页揭晓凶手是死者的孪生兄弟。"

**执行**：

1. **抽台词测试**（PG13029 L1493-1503）：输入概要只说明依靠对白推理，尚无完整调度可供实际抽台词测试；因此标为语言依赖风险，而非已证明三场没有动作。
2. **去描述自问**（PG17903 L8856-8907）：离了对白与描述，这个题材还成立吗？**必须依赖对白或描述且无法重构时才放弃直接无声改编**；同段讨论侦探小说的困难，L8864–8865 保留能以动作清楚讲述的例外（案发于开幕前、靠推理与对白），历史作者担心顺序直接演出会泄底，但不由此推出银幕必须顺叙或必须展示凶手面孔。
3. **结论**：目前概要需先展示推理如何转成可感信息，不能仅据概要判定无法改编；直接搬三场长对白有明显载体转换任务。
4. **替换方案（不是判死刑）**：
   - 把"推理"外化为**动作与物件**：凶手留下的物件（PG17903 L4767-4768：bust 即放大物件；一手例见 PG4906 L389-397 用"信＋表"承载关系）。
   - 把"审讯"改为**可被看见的试探**：人物去做一件事，而不是说一段话（PG70937 L2029-2031：观众是来看一件事的）。
   - 一种方案是先露凶手，转为追查过程的悬念（对应Phillips偏好）；另一种方案保留凶手身份，先展示可回查的物件和行动，再揭解法。无声形式不要求二者只能选前者。
5. **本例选择（H/P）**：保留结尾身份揭示，采用公平线索方案：前段合照显示兄弟二人；证词声称死者独生时，侦探拿照片试探，嫌疑人遮住另一人的脸；中段同一旧伤在一张早年照片与嫌疑人手上对应；末段将照片、遗留物与身份陈述并置。具体证据是否足以唯一识别仍待完整案情设计，不冒称已完成公平性验收。

**输出形态**：结论行 + 证据行（每行带 PG+行号）+ 替换清单 + 本稿选择及尚待补全的案情条件。

## 例二：一段分场的连续性与载体体检

**输入（构造）**：某舞台剧第二幕改为无声片的分场草稿——
```
S12 书房：主人公读信
S13 银行办公室：经理签字
S14 书房：主人公把信烧掉
```

**体检**：

| 问题 | 判据 | 处理 |
|---|---|---|
| S12→S13 切到另一个地点的另一个角色 | PG76829 L802–809 的移动要求针对同一角色，L811–816 允许双人物交叉切换 | 保留并行切换，按需要交代两线时间关系，不强插主人公出门 |
| S14 回书房，S12 与 S14 之间已有银行场 | PG17903 L4383–4417 针对同布景直接紧邻且状态突变，S13 已是他景 | 不判连续性错误；仅在经过时间仍难懂时补提示 |
| 信件内容若靠字幕长篇转述 | 字幕越少越好是误读；要写到"非懂不可"（PG17903 L6425-6492），但优先用信件本身（L6789-6951） | 用信件 insert：一封 35 词把话说完的信胜过多条字条（L6806-6807） |
| "把信烧掉"这一动作是否与画面里其他运动冲突 | 全画面唯有一物动则必夺目（PG66049 L2960-2969） | 检查同框是否有火苗、窗帘飘动等抢注意的元素 |
| 场号是否按选定格式连续 | PG17903 L5567–5568的全片连编惯例 | 片段S12–S14连续；未见Scene1及全片，不能声称全片已满足 |

**输出形态**：缺陷表（每条带来源行号）+ 改写建议 + 已知片段结论与全稿未见部分的限制。

## 例三（反向）：不要把案例写成规则

PG4963 L2601-2800 把最强的动作（突袭、躲衣柜）**只作回顾而不演出**（L2694-2737）。
若据此写成"关键场面都应该转述"，就是**把单部作品的做法变成普适规则**——本轮在 §4 的 R1 裁决里明确拒绝了这种推广：它只能作为"转述是合法手段之一"的证据，不能反过来禁止正面演出。
同理，PG1109 L2794-2807 的"三层中继传话"是伪装—误认约定的产物，不得当作通用写法；PG4906 L517-549 的"一行一条理由"只属于那部戏的喜剧节奏。
