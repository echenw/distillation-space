# 示例：三个真实任务形态怎么用本 Skill

> 所有 F 级引用均来自本轮 **V 级**来源（已过门禁）。行号可直接回源核对。

## 例 1（正常）：写一篇"夜里有人在楼下说话"的怪谈短篇

**输入**：第一人称、有限视角、3000 字内，目标是"不安 + 余韵"，不接受死亡。

**执行**
1. **框架**（R1）：她是租客，房屋管理处的维修工单是她唯一能给别人看的东西 → 叙述权限与可核对事实都成立。
2. **指示物**（R22，取自 PG23308）：设"厨房水龙头下方瓷砖的干湿"作指示物——她每晚睡前擦干，次日清晨总是湿的。临界点写成"连续第七天仍未干"。
3. **排除**（R23，取自 PG22246）：她请维修工拆开下水管、用食用色素试漏、关总阀过夜；结果"Everything was in perfect order"式阴性。
4. **归属核验**（R21，取自 PG792）：她记下每次声音的次数与内容，并核验同一时刻楼上住户的状态（"nothing extraordinary has happened"式对照）。
5. **感官**（R6，取自 PG22246）：先写瓷砖的凉与潮（触觉），再写霉味（嗅觉），最后一次才写看见（或不写）。
6. **解释**（R12）：保留双解——声音可能是排水管共振，也可能是别的；确定的只有"瓷砖第七天仍未干"。
7. **处置与结算**（R26/R27，取自 PG1668 + PG23379）：她搬走并申请把该户封存；结算落在她与房东的关系改变（她第一次书面要求留证）。

**产出最小字段**：读者体验 = 不安 + 余韵；框架 = 租客 + 工单；指示物 = 瓷砖干湿（临界第 7 天）；
排除 = 拆管/色素/关阀（阴性）；核验 = 声音编号 + 楼上同期状态；解释 = 双解；处置 = 封存 + 搬离；
活人结算 = 她开始书面留证。

## 例 2（边界）：用户要"鬼其实是活人"的反转

**输入**：已有月光下白裙女子的段落，想反转成真人。

**检查**（R25，取自 PG22246 第二篇）：
- 有没有可核对的身份线索？必须至少两条。范本：她是邻居（L1425-1426）、当晚确实结伴擅入（L1487-1491）。
- 有没有同期状态核验（R21）？她走散的时间点要能被同行者证明。
- 反转后前面提交的物证是否被抹掉？按 R10，**不该抹掉**——范本里她确实进过庄园、那张脸确实被看见。

**若缺线索**：不要硬转，改为 R12 未定式，给出所有人同意的确定项（范本：PG22246 L949-950 "It was dead, anyhow."）。

## 例 3（失败出口）：规则型诅咒写崩

**症状**：主角每次遇险都靠"新发现一条古老条款"脱身。

**处理**（本 Skill 会拒）：
- 退回 R22：只保留**一条**可判定规则 + **一个**指示物，写明不可逆临界点。
- 应用 R24（取自 PG23308 L514-516）：写明规则是否豁免施术者；若豁免，必须给出文本内理由并让它付出对价。
- 其余"条款"降级为 FICTION_CASE（人物相信的规则），不进世界法则栏（R13）。
- 若角色必须脱险，改用 R26 的"承受代价"或"替换"，而不是新增规则。

## 例 4（负触发）：用户要"让读者真的害怕的惊吓点子"

本 Skill 不做效果预测（P5/GQ5 本轮未试验）。可以提供的是信息释放结构与证据链设计；
任何"读者一定会吓到"的承诺都不在本 Skill 的输出范围内。

## 例 5（新增，2026-10-31 补齐 run）：用户要写"许愿忘掉创伤"的交易型怪谈

**输入**：第三人称，中篇，主角想借超自然交易忘掉丧亲之痛，不许写成"一觉醒来一切美好"。

**执行**（R29，取自 PG644；读数用 R22）：
1. **价码写成传播义务**：不写"他失去记忆"，写"他必须把它给出去"——范本：Phantom 宣告"The gift that I have given, you shall give again, go where you will."（PG644 L892-893）；他靠近谁，谁就先忘记同类的事。
2. **给传染装读数**：每次探访后写一个可观察变化——对方"passed his hand across his forehead"、觉得屋里气氛变了（L1607-1612）；再扩散到孩子（L1653）与老人（L2605-2618）。读者靠"谁变了"数进度。
3. **堵死自撤**：让主角当场追问"能否撤销"，得到否定答复（L2822-2838 "No"/"Nothing"）——不可逆由问答钉死，不由旁白宣布。
4. **善意即传播**：主角去道歉、去探病、去帮忙，每一次善意都是一次感染——悲剧感来自"做对的事也在杀人"。
5. **解除走规则外**：交易覆盖不到的第三方（范本：唯一"不为自己记忆所苦"的 Milly，L313-333 事前已铺）间接化解（L3793-3796）；不要让主角靠意志或新条款翻盘（R14/R24）。
6. **结算**（R27）：恢复记忆的是主角，但真正被写的是他此后如何对待被他伤害过的人；超自然一方最后状态可以不交代。

**产出最小字段**：交易条款（忘掉什么 + 给出义务）、传播条件、读数（谁变了）、临界与不可逆声明、规则外解除者及其事前特质、活人结算。
