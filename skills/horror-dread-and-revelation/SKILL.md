# 恐怖惊悚怪谈：恐惧积累与揭示（horror-dread-and-revelation）

## 1. 这个 Skill 解决什么

把"吓人"拆成四件可检查的事：**框架与证词（谁在说、凭什么信）**、**痕迹与指示物（读者能自己推算什么）**、
**排除与归属（怎么判定是超自然、是误认、还是未定）**、**处置与代价（结束时谁变了）**。

它不提供怪物设定库，也不提供感官递进公式。本批次 28 部原文来源已具备覆盖全书的可回源台账，其中既有本轮新读也有历史实读继承。已独立核对的具体故事里，
"实体先出场"与"痕迹先出现"两种写法都存在，感官顺序也各不相同——
因此本 Skill 约束的是**信息释放与证据链**，不是题材或节奏模板。

## 2. 触发与负触发

**触发（满足任一）**
- 要写/改一篇恐怖、惊悚、怪谈、灵异小说，需要安排悬念节奏或解释位置。
- 已有草稿但"不吓人""结尾泄气""解释像说明书"。
- 需要判断某个恐怖桥段该明写还是留白。
- 需要判断某个显现该写成"真鬼""误认活人"还是"保持未定"。
- 规则型/诅咒型设定写崩（判据太多、例外太多、主角靠新解释脱险）。

**负触发（不要用）**
- 纯血腥 / 猎奇场面描写，无认知设计需求。
- 恐怖喜剧、恶搞、模仿秀（本 Skill 会要求严肃的证据链，反而拖慢）。
- 非虚构的民俗记录、真实案件写作。
- 需要"怪物设定数值 / 能力表"的任务（本批次证据不支持通用设定库）。
- 需要真实读者恐惧效果预测（本 Skill 未做 P5/GQ5 实测）。

## 3. 输入（明确要求）

必须提供，否则先向用户索取：
1. **文本**：待改草稿 / 待诊断段落，或"从零写"的创作意图说明。
2. **意图**：目标读者体验（不安 / 惊惧 / 哀伤 / 余韵）、篇幅、视角（第一人称 / 有限第三人称 / 全知 / 档案体）。
3. **子类**：超自然悬疑 / 怪物在场 / 心理与日常压迫 / 规则型诅咒 / 留白诡异。
4. **约束**：不可触碰的内容、目标读者年龄层、是否允许死亡与不可逆代价。

可选：已有的世界观规则、系列前作的既定事实、必须保留的场景。

## 5. 条件化恐怖工作模型（可选，不是固定配方）

- **超自然悬疑**：框架与证词 → 痕迹 → 物理排除（R23）→ 归属核验（R21）→ 解释位置（R9–R12）→ 处置（R26）。
- **怪物在场 / 生存恐怖**：可以先让实体出场，再用空间、资源与选择累积风险；不强制痕迹先于实体（R5）。
- **心理与日常压迫**：可以没有怪物、没有视觉峰值；用关系、制度与信息不对称制造压力。
  （例子：PG8492 L4484-4518 的日常对话突然被切断；PG11438 L501-1000 从河岸环境的不安逐步升级；PG53686 L2901-3480 的制度性囚禁与"伪自由"楼梯——每层逃脱通向更深的牢笼。三者是不同故事的条件案例；PG2520 历史记录虽通过来源门禁，但不据书名推断机制。）
- **规则型诅咒**：先设指示物与不可逆临界点（R22），再决定操作者是否被豁免（R24）。
- **误认路线**：若走"其实是活人"，必须提前埋可核对的身份线索（R25）。
- **收束**：封存 / 改认知 / 替换 / 承受代价（R26），并把结算落在活人身上（R27）。

本 Skill 不提供任何百分比、次数或固定感官排序阈值。

## 7. 最短执行路径（7 步）

1. **先定目标体验**：若是解谜/揭示型，写一句“新证据改变了读者对前文什么理解”；若是持续环境恐惧或不确定性，明确需要保留的未知，不强造揭秘。
2. **定框架**：叙述权限、讲述动机、可核对事实（R1）。不强求"不情愿"（R2）。
3. **选证据负担**：规则/解谜型可设可追踪指示物与临界点（R22）；环境/心理型可用场景对照、关系改变或不可验证的征兆，不强造量化状态。
4. **排感官**：按 POV 与子类选一到两种感官；触觉/嗅觉可用来延后视觉（R6）。
5. **按需要排除与核验**：若结尾要主张超自然确定发生，检查物理反证、证人同期状态或自证痕迹（R23/R21），可择其适用者；若主题就是证据与结论冲突，保留不可判定的那部分（PG23172），不强制三件套。
6. **选解释位置或不解释**：延迟（R9）/ 回撤（R10，别抹去已提交物证）/ 扩大（R11，标为推想）/ 双解（R12）/ 仅确认可观察后果。
7. **选处置与结算**：封存 / 改认知 / 替换 / 承受等是常见选择（R26），写清重要角色或环境有哪些可观察改变；若作品故意不确认超自然实体，结尾可保持其状态未知。

## 8. 输出合同

| 输出 | 内容 | 验收 |
|---|---|---|
| 框架表 | 叙述者 / 记录方式 / 讲述动机 / 可核对事实 | 第三人称也可无编者壳，但权限必须写清 |
| 指示物或痕迹清单（规则型必选，其他可选） | 状态量、观察者、临界点或可见后果 | 有规则的故事应让读者理解已建立的规则；没有规则的故事不补造数值 |
| 排除与核验记录（主张确定结论时重点） | 有哪些排查项、已知结果与剩余矛盾；见证人与自证痕迹按情节择用 | 不把证人数量或机械排查设为全题材必要门槛 |
| 信息释放表 | 段落 × 读者已知 × 角色已知 | 区分 POV 与读者已知，可以同知 |
| 解释位置说明 | 延迟/回撤/扩大/双解 + 残留未解项 | 不能用"其实是幻觉"一句收尾 |
| 处置与结算 | 已采取行动及角色/关系/环境后果 | 可保留实体状态未知；不强制唯一“胜利”或固定四式 |
| 风险清单 | 按出现的证据冲突、视角矛盾或定案风险自查 | 只列真实存在的风险，不凑数 |

## 10. 失败出口

- **找不到"读者最终会知道什么"**：可能是成功的氛围恐怖，无需虚构新真相；改用 R5/R22 设可见指示物，或放弃本 Skill。
- **解释只能靠"其实是幻觉/精神病"**：这是回撤式的廉价版；按 R10 逐项回查已有物证，或按 R12 改为未定。
- **规则型设定写崩**：退回 R22 + R13，精简到一条可判定规则与一个指示物；其余改成"人物相信的规则"（FICTION_CASE）。
- **主角只能靠临时新规则脱险**：按 R24 检查操作者是否被豁免；若必须脱险，改为 R26 的"承受代价"或"替换"。
- **"是鬼还是人"无法定案**：按 R25 补齐可核对线索；补不上就不要定案，用 R12 保留未定并给出所有人同意的确定项。
- **越写越像说明文**：把说明分散到不同可信渠道（R3），并确保每次说明都改变一个决定。
- **拿不到原文行号做证据**：停止引用，改用自己的稿内定位；不要把本 Skill 的 PG 行号当成自己作品的依据。
- **引用补证来源**：PG10832/11438/19337/2706/4046/644/8377/8694 已达到来源行段门禁，但必须引用已被原文证实的具体段落；不因 FULL 就自动采纳旧笔记全部推断。

## 11. 边界与禁止

- 不把人物做法、叙述者信念、时代偏见写成"作者明示规则"。本批次文本含 19 世纪种族 / 性别刻板描写
  （如 PG35587 的仆人口音、PG8492 L116-117 的排外政策清单），它们是 FICTION_CASE，不是写作建议。
- 不把“门禁 PASS”当作对旧内容的全面语义裁决；PG25016 等继承段落必须区分编者说明、角色自述和叙述者可见事实。
- 不承诺"按本 Skill 写就一定恐怖"；本 Skill 只约束信息释放与证据链，不保证题材新鲜度，也没有实测读者数据。
- 不提供真实伤害、跟踪、私刑、逃避调查或仿效仪式的操作指导；恐怖应止于虚构与审美判断。
