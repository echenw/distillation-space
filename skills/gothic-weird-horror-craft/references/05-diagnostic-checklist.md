# 诊断自检表（用于"我的稿子为什么不吓人 / 结尾为什么塌"）

用法：按 §1 判档，按 §2 逐条打勾，按 §3 判分，按 §4 给处方。
**不要在没拿到原稿的情况下给段落位置**（SKILL.md §8 出口 A）。

---

## §1 先把档位反推出来（不知道作者意图时也能做）

| 问 | 若答"是" |
|---|---|
| 结尾是否给出了 mundane 解释？ | A2（人为犯罪） |
| 是否有角色宣称"这是超自然的"且未被否证？ | A1 |
| 恐怖是否集中在主角自己身上发生了什么变化？ | A3 |
| 恐怖是否表现为"没人再理他/制度失效"？ | A4 |

| 再问 | 若答"是" |
|---|---|
| 主角怕的是被杀？ | F1 |
| 怕的是不再被认出？ | F2 |
| 怕的是被抛弃？ | F3 |
| 有具体罪证且无法清除？ | F4 |
| 有更大的东西在注视他？ | F5 |
| 证据链断在中间、结尾不补？ | F6 |

## §2 硬检查项（每条都要能指出位置）

1. **契约一致性**：C1 / C2 / C3 各选了什么？有没有中途切换？（`02` 有切换代价表）
2. **升级三阶段**：散落征兆 → 单点确认并被否认 → 规则失效。缺哪一段？（T2）
3. **负空间**：恐怖对象的描写是否超过 2 个具体视觉形容词？（T1）
4. **证据链最短环**：哪一环最弱？是有意放弱的，还是漏了？（T3）
5. **声音签名**：恐怖有没有一个可重复的声音？进场/退场各用了吗？（T5）
6. **角色功能**：是否只有"受害者 vs 怪物"？缺哪个功能位（见证/传导/施咒/解咒/裁决/记录）？（T8）
7. **禁令具体性**：若有禁令，是否给了具体时刻与代价？（T10）
8. **结尾类型**：属于反转 / 留问 / 双重身体 / 物证替换 / 半收 / 停在旁人 中的哪一个？（T9）

## §3 判分口径（粗筛用，不是质量总分）

| 项 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 归因档 | 说不出 | 能说出但前后不一致 | 全篇一致 |
| 恐惧对象 | 说不出 | 有多个但未定主档 | 单一主档并贯彻到高潮 |
| 解释契约 | 结尾没定 | 定了但中途变 | 开篇即定，全篇一致 |
| 可信度契约 | 无 | 有但与调性冲突 | 三选一且与调性匹配 |
| 调性 | 混杂 | 主体一致但有漂移 | 全篇一致 |
| 升级 | 单点爆炸 | 两段 | 三段齐全 |
| 负空间 | 全靠正面描写 | 混合 | 主体靠负空间 |
| 证据链 | 无 | 有但最短环是漏洞 | 最短环是有意设计 |

**判读**：≤6 分 → 档位/契约问题（回到 `01`、`02`）；7–11 分 → 技术问题（回到 `03`）；≥12 分 → 只剩打磨。

## §4 常见处方

| 症状 | 处方 | 依据 |
|---|---|---|
| 不吓人 | 定恐惧对象档 + 改负空间 | T1 / `01` §2 |
| 结尾塌 | 先定 C1，再选 T9 的一种 | `02` §C1 / T9 |
| 读者说"被骗了" | 若归因是 A2 → 补伏笔公平性；若是 A1 → 检查是否误用了 A2 的伏笔 | R2 / PG1147 L2410-2420 |
| 中段塌 | 补升级第二阶段（单点确认**并被否认**） | T2 / PG10966 L2568-2597 |
| 调性忽冷忽热 | 定 C3，删掉反向段落或改写成人物视角 | `02` §C3 |
| 解释太多/太少 | 按 C1-a/b/c 重选一次并统一 | `02` §C1 |
| 想写"无鬼之恐" | 走 A4 + C3-b，用关系与制度承担恐吓 | PG2548 L1585-1593；PG4387 全篇 |

## §5 本表的边界

- 本表判的是**结构一致性**，不是文学质量；判高分不等于写得好。
- 本表来自 18–20 世纪初英语语料，对现代背景、影视/游戏媒介、规则怪谈等形态适用性 `NOT_PROVEN`。
- 若用户目标是"谜题公平性"，本表不覆盖，应转推理向 Skill。
