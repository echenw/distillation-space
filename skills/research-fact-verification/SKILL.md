# 资料研究与事实核验

核实**断言**，不是给整篇文章打真假分。本 Skill 提供的是"Agent 依证据操作"的工作流：拆 Claim → 选检查动作 → 取证据 → 判状态 → 出表。
它**不是**自动事实检测器、**不是**检索插件、**没有**真实性认证引擎；没有来源时不以模型记忆补足。

**判断对象与机器的分工**：你负责拆断言、选动作、读原文、写依据；本 Skill 负责告诉你每种断言该查什么、查到什么程度算够、查不到该怎么说。

## 触发 / 负触发

**触发**："帮我核实/查证这句话""这个日期/数字/引文对不对""这是史实还是虚构""这个来源可信吗""两个版本说法冲突，怎么办""这段里哪些能当真""这段报道有没有夸大""我要把它写进小说/报道，先核一遍"。

**负触发（不要用本 Skill 顶替）**：
- 需要联网检索而环境无检索工具 → 不要假装在检索，走"失败出口"第 1 条，输出最小补证清单。
- 医疗、法律、金融、安全、个人名誉的高风险结论 → 本 Skill 只整理材料并标边界，明确要求由合格专业人独立核验。
- 纯审美评价、纯架空设定一致性、纯文风润色 → 改用写作/编辑类 Skill；架空设定只按 `FICTIONAL_DESIGN` 校内部一致。
- 用户只要"写得更好看"而明确不关心真假 → 不主动展开核验流程。
- 要判定某作品"该不该出版/该不该发" → 本 Skill 只给证据状态，不做发布决策。

## 输入（缺哪项就先问哪项，不要猜）

1. **待核文本**（原文片段或文件定位）+ **用途**：研究 / 小说素材 / 报道 / 一般咨询。
2. **时间与地域范围**：断言涉及的年代、地区、截至时点。
3. **可访问的来源**：原始文件路径或可访问链接；同名作品必须确认作者、版本、出版时间、页/行。
4. **允许的检索范围**：能不能联网、能不能打开付费/登录内容、能不能外传私有材料。
5. **是否允许修改原文**：只审查 → 只出判断与候选修订；明确允许编辑 → 才可改动指定文件。
6. **要哪一种成果**（影响体裁与证据密度，见冲突 C-2）：说服/打动读者，还是可复核/可复制。

用户的断言是**待核对象**，不自动升格为事实；权威机构的陈述同样要先过独立性检查。

## 执行步骤（按顺序做，不要跳）

### 第 1 步　原子化：拆出 Claim

逐句拆出人物、事件、日期、数字、因果、归因、直接引语、作者意见。一句含多个可检验断言 → 拆成多个 Claim ID。
审美判断、架空设定、价值主张**不**强作事实认证，标 `FICTIONAL_DESIGN` 或"不需核"。
同时给出每条 Claim 的**类型**：日期 / 统计 / 引文 / 归因（谁说）/ 因果 / 版本归属 / 虚构设定。

### 第 2 步　按类型选检查动作（核心，不要凭感觉）

先查 [source-derived-checks](references/source-derived-checks.md)。它给出 14 条按"触发条件 → 怎么做 → 依据 → 不做的后果"写好的动作，分成四组：

| 组 | 回答的问题 | 动作 |
|---|---|---|
| A 证据够不够（量） | 这个证据能撑起"普遍如此"吗 | R06 典型性、R07 全称断言的样本与存者偏差、R08 精度≠准确 |
| B 证据指的是不是这件事 | 检出来的东西等于我主张的东西吗 | R09 代理指标、R10 同源拼料、R11 译本/著录层级、R12 文体时代错置 |
| C 归属、首创与时间 | 谁写的、谁先做的、现在还是这样吗 | R13 笔名归属、R14 多主张原型、R15 核查时点、R16 首创分层 |
| D 谁说/怎么拿到 | 记录者是谁、站什么位置 | R17 趣味性/采用不是证据、R18 相关≠因果、R19 观察者位置 |

一条 Claim 常常同时命中多组；全部命中的都要做，做完才进第 3 步。
按断言类型的证据门槛与回读次序见 [research-protocol](references/research-protocol.md)。

### 第 3 步　取证据并回源

- 记录实际访问的东西：文件名/链接、**访问日期**、版次、页行或可稳定回查的段落；引语必须逐字回查。
- 计数独立性时追问**底层原件**：三篇报道若都转引同一份声明，只算 1 个来源（R10）。
- 能访问原件就先记录发布/更正记录与版本；访问不到就写"尚待原件核对"，**不得**说"已检索权威源"。

### 第 4 步　判状态

`VERIFIED_FOR_SCOPE` / `SUPPORTED_WITH_LIMITS` / `CONTESTED` / `NOT_VERIFIABLE` / `CONTRADICTED` / `FICTIONAL_DESIGN`。
定义与"拆分真假和意义两个问题"的要求见 [research-protocol](references/research-protocol.md) §3。
有冲突先分型再处理，见 [conflict-and-versions](references/conflict-and-versions.md)：时点 / 对象 / 范围 / 来源依赖 / 无出处 / 剩余真冲突。
**不投票、不平均、不杜撰第三种说法**；无法裁决就并列标 `CONTESTED`。
语气肯定不提升等级，来源自陈的局限也不自动降级（冲突 C-4）——只看可回源的证据。

### 第 5 步　出表

默认按 Claim ID 出核查表，字段与整体摘要见 [templates](references/templates.md)。
本轮新增两个必填字段：**核查时点**（R15）与**来源自陈的证据边界**（C04-R02）。
若涉及敏感个体或医疗/法律/安全决定，注明材料边界并建议合格专业核验，不从叙述行为推断诊断。

### 第 6 步　按需改稿（只在有授权时）

逐条列"原说法 → 限定句/删去 → 因由与证据 → 是否改变角色立场"，再回查定位与相邻句，
防止把"某人曾声称"改成"客观发生"。未判定的反证先用条件句或报道式归因，不作强确定性发表。

## 输出合同

1. **核查范围**：用途、目标作品/版本/时间/地域、实际访问的文件与时间、不能访问的资料与原因。
2. **逐条 Claim 表**（默认格式，见 [templates](references/templates.md)）：
   `Claim ID + 原文定位 | 原子断言 | 类型 | 时间与版本 | 支持来源+定位 | 命中的检查动作(R06…R19) | 反证/限制 | 核查时点 | 来源自陈的证据边界 | 状态 | 判断说明 | 建议句/作者决定 | 下一次最小补证`
3. **整体摘要**：已核几条、待核几条、阻断公开确定性断言的点、可安全继续使用的材料、未执行的检查。不用"全对/全错"替代逐条判断。
4. **未访问链接必须显式写"未实际打开"**。

## 失败出口（触发即停，交付缺口而不是编造）

1. **原文拿不到 / 无检索权限**：标 `NOT_VERIFIABLE`，给最小补证清单（去哪个源、查哪版、哪一段），不猜答案。
2. **版本不明**：不引；先确认作者、版次、译本与译法再动（R11）。
3. **引文找不到出处**：去引号改为转述并标"译意/转述"，不得保留引号或伪造页行。
4. **两份"证据"实为同源**：降为 1 源，说明依赖链（R10）。
5. **真冲突无法裁决**：并列 `CONTESTED` 并写清还缺什么，不投票。
6. **授权不足**：只出判断与候选修订，不改文件。
7. **高风险领域缺专业证据**：整理材料 + 指出必须由专业人员独立核对的部分。
8. **只有模型记忆**：一律 `NOT_VERIFIABLE`，不得凭记忆写"据某资料"。

通用失败诊断与修复见 [failure-modes](references/failure-modes.md)；
带真实来源位置的用法示例见 [examples](references/examples.md)。

## 边界与来源说明（必须随 Skill 一起读）

- 本 Skill 的**制度性内容**（六档状态、冲突判定树、14 条检查动作）是本轮编制者从四份可回读材料作出的**设计 P**，不是这四本书共同主张了什么；其实际效果未经真实宿主任务验证（NOT_PROVEN）。
- 四本来源的身份、SHA、行号定位、许可与"不可外推"清单见 [source-index](references/source-index.md) 与 [source-boundaries](references/source-boundaries.md)。
- 行号是**本项目阅读版**行号，不是印刷页码；外部使用者按书名与版本重新定位，不得伪造命中。
- 美国公有领域标签不构成对其他法域的许可承诺；再传播前独立核权。
