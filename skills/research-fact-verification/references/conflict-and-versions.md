# 证据冲突与版本判定

## 先分型，再处理

1. **时点冲突**：同一数字是当时统计还是后来修订？核日期、截止时间与同口径数据。合法修订 → `VERSIONED`，两版并列，不判任一方造假。
2. **对象冲突**：同名人物、同名地区、译名、作者与编者是否被混为一谈？按对象身份与时间轴拆 Claim，不能把不相干的两条消息平均。
3. **范围冲突**：地方样本 vs 全国推断、事实报道 vs 评论、原文 vs 译本。保留各自适用的范围。
4. **来源依赖**：两份资料是否都引同一底稿？同源转述不算两证独立（R10）。一份更正了底稿时，记录更正链。
5. **层级冲突（本轮新增）**：争的是题署、目录著录还是考定结论？还是拿意译当原文？（R11）先定层级。
6. **首创冲突（本轮新增）**：按"下水 / 首次运行 / 是否以该机制为主 / 是否定期规模化 / 是否商业可持续"分层（R16），逐层给答案，不给不分层的唯一结论。
7. **文体时代错置（本轮新增）**："它是小说"与"它在当时被当作事实记录"可以同时成立（R12）。按判断时点分别陈述。
8. **原件真伪 / 无出处**：查图像扫描、出版信息、版权页、章节与同页上下文；无法取得时只标未核，不能借作者名气认证。
9. **剩余真冲突**：分别列 A/B 的原话、版本、反证与目前无法解决的点；状态 `CONTESTED`，不选更顺耳的一方。

## 不可统一的冲突（保留，不要抹平）

本 Skill 的来源之间存在真实分歧，编制者**不**把它们合并成一条规则。消费者按情境选择：

## 候选修订策略

| 事实条件 | 输出方式 | 禁止行为 |
|---|---|---|
| 原始资料已更新 | "按某机构 YYYY-MM-DD 版……；此前版为……" | 隐藏版本差别 |
| 学界不同年代有争议 | "某书认为……，另一研究反驳……；本次未决" | 拿旧研究当现代共识 |
| 新闻引用采访者自述 | "据受访者称……" | 当作第三方已核实 |
| 仅有小说情节与史书人物同名 | 标为创作设定待核史实 | 把小说桥段当历史记录 |
| 原型属实而情节虚构并存 | 拆两条 Claim（R14） | 因原型属实而认证整段情节 |
| 编造的内容后来成真 | 保留"当时为假"与"后来为真"两个时点（R15） | 用后来的真反推当初为真 |
| 用户要唯一结论但两独立原件冲突 | 说明哪项证据尚需补、暂停唯一结论 | 靠多数、热度或模型推测裁决 |

若用户希望把不确定的素材用于虚构，标 `FICTIONAL_DESIGN`，并把已核历史事实与创作填补分开；允许想象不意味着允许虚构参考来源。
