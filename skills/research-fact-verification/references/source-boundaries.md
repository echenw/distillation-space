# 版本、来源与许可边界

本 Skill 的**制度性内容**（六档状态机、冲突判定树、R06–R19 核查动作）是当前编制者从四份可回读材料作出的**方法设计 P**，
不是声称这些书共同发明了现代事实核查标准。四本来源的**观察 F** 与编制者的**推导 H** 在每一处都分开标注。
本 Skill 不随包分发原著。

## 原始材料固定性与引用规则

- 四件均以项目中的 PG ID、真实书名、作者和 `整本阅读版.txt` 固定版本；SHA 见 [source-index](source-index.md)，编制轮次已实测对齐。
- 书目和行位是**本项目阅读版定位**，不冒充其他网站或印刷页码；外部消费者无法访问该版本时应按书名、版本重新定位原文，不能伪造命中结果。
- 项目元数据将 Gutenberg 原件标为**美国公有领域**，并明确不对其他法域、后出的翻译或编订版本授予许可；再次传播前独立核权。
- 本 Skill 的流程与模板系重新编写，未引入原著大段原文（示例文件里的引文均为短段并标行号）；其存在不自动授予任何第三方素材的再分发权。
- F 是"该书在该处写了什么"，H 是编制者的比较判断，P 是具体查证工作流；对未知主张保持 `NOT_VERIFIABLE`。
- **静态结构验证不证明**本 Skill 已被真实宿主选中或有效提高核验正确率；R06–R19 的效果为 NOT_PROVEN。

## 外推红线

1. 不把单部作品的具体考据结论上升为普遍规律（例如不得由"现存汉人小说多伪托"推出"古书都不可信"）。
2. 不把某一部小说的情节设计变成所有作品都必须遵守的规则。
3. 不把 1920 年代的行业机制当现状。
4. 不把写作/投稿建议当核验方法。
5. 不宣称四本书共同主张了任何现代核验制度。
