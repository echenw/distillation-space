# 模板：闹鬼/诅咒机制设计器（Haunting Designer）

> 每行独立可填（HD-01..HD-16）。用于设定一个完整的超自然机制，避免中期自相矛盾。

| ID | 字段 | 填写内容 |
|---|---|---|
| HD-01 | 恐怖源类型（亡灵/受诅物/活人同化/地方意志/心理） | |
| HD-02 | 源起事件（何时/何地/何罪） | |
| HD-03 | 选择受害者的标准（道德/情感性/血缘/随机） | |
| HD-04 | 显形规则（时段/地点/条件/频率） | |
| HD-05 | 感官余像清单（嗅/印/声/温度——各对应源起） | |
| HD-06 | 实体化形态与次数（≤1，出现位置） | |
| HD-07 | 可杀性裁定（半肉身可杀/纯灵只能解除——scope C1） | |
| HD-08 | 解除程序（可数步骤+每级代价） | |
| HD-09 | 解释策略（不解释/四点排除/动机完备的解释） | |
| HD-10 | 证词矩阵（≥3 源，≥2 矛盾，各自文类） | |
| HD-11 | 物证链（每幕留下什么，终局回收哪件） | |
| HD-12 | 道德宇宙论（复仇型/悲剧型——全篇一致） | |
| HD-13 | 领域规则（地方 note、空间指纹、逃逸闭合方式） | |
| HD-14 | 时代框架重构清单 | |
| HD-15 | 剂量表（强恐怖场景间隔安排） | |
| HD-16 | 失效出口（机制穿帮时的兜底写法） | |


## P4 可变分支与退出

本模板的数量、场次、次数均为可调整的工作量示例。先判断读者承诺、证据类型和叙事目标；支持直接冲击、未知留白、复仇/悲剧/混合伦理机制；若证据不足，输出待核假设或保留原稿，而不自动改稿。
