# 模板：恐怖稿件诊断表（Manuscript Diagnosis）

> 每行独立可填（MD-01..MD-12）。用于对既有稿件的类型学诊断与修订处方。

| ID | 字段 | 填写内容 |
|---|---|---|
| MD-01 | 稿件类型定位（哥特/怪谈/灵异/心理惊悚/黑色喜剧） | |
| MD-02 | 引力核心判定（诅咒条文/禁问/遗物/框套——是否成立） | |
| MD-03 | 显形审计（实体显形次数与位置；感官余像是否充足） | |
| MD-04 | 升级台阶审计（感官通道是否分级；自救封锁是否对应） | |
| MD-05 | 证词审计（源数/矛盾/文类/倒戈时刻） | |
| MD-06 | 解释策略审计（未解释期长度；解释者动机） | |
| MD-07 | 剂量审计（连续强恐怖间距；缓冲场景清单） | |
| MD-08 | 道德宇宙论一致性（有无混用） | |
| MD-09 | 结局审计（四选一；物证呼应；拒述句 ≤1） | |
| MD-10 | 巧合清单（每处巧合标注位置；>1 即处方） | |
| MD-11 | 时代框架重构处方 | |
| MD-12 | 修订处方（按规则编号 RG-xx 逐条开出） | |


## P4 可变分支与退出

本模板的数量、场次、次数均为可调整的工作量示例。先判断读者承诺、证据类型和叙事目标；支持直接冲击、未知留白、复仇/悲剧/混合伦理机制；若证据不足，输出待核假设或保留原稿，而不自动改稿。
