# 模板：恐怖场景规划表（Dread Scene Planner）

> 填写说明：每行一个独立可填字段（DS-01..DS-14），不得合并。用于起草或诊断任一恐怖场景。

| ID | 字段 | 填写内容 |
|---|---|---|
| DS-01 | 场景在全书结构中的位置（第几幕/章） | |
| DS-02 | 本场景的恐怖类型（显形/纠缠/仪式/罪案/领域闭合） | |
| DS-03 | 已向读者开放的感官通道（视/听/嗅/触/温差） | |
| DS-04 | 本场景封锁的自救行为（祷告/求救/逃离/告知） | |
| DS-05 | 恐惧化日常物（≤1 件，附"指向性动作"） | |
| DS-06 | 实体显形？（是=终幕一次 / 否=感官余像清单） | |
| DS-07 | 证词与目击者（谁看见/谁否认/文类） | |
| DS-08 | 超自然规则位（本场景执行哪条"准入条款"） | |
| DS-09 | 缓冲安排（前一场强恐怖后的间隔场景） | |
| DS-10 | 道德宇宙论检查（复仇型/悲剧型——本场景谁可被伤） | |
| DS-11 | 物证产出（本场景留下什么可回收的物证） | |
| DS-12 | 失效条件（读者在此场景可能识破什么） | |
| DS-13 | 时代框架重构点（种族/性别/医学再现） | |
| DS-14 | 场景出口（进入下一场景的钩子） | |


## P4 可变分支与退出

本模板的数量、场次、次数均为可调整的工作量示例。先判断读者承诺、证据类型和叙事目标；支持直接冲击、未知留白、复仇/悲剧/混合伦理机制；若证据不足，输出待核假设或保留原稿，而不自动改稿。
