# 跨媒介剧作改写

## 职责与依据

交付可执行的改编方案、分场稿与修改依据。承接已经存在的故事，首先确定哪些叙事功能必须保留、哪些表达方式必须更换。本 Skill 的专责是**媒介转换**；结构规划、人物设计或小说场景诊断可以单独完成后作为输入，但使用本包不需要安装其他 Skill。

规则来自 B-02 的七部历史创作手册及原 Skill 保存的戏剧案例。原作观察、历史作者主张与本次转换建议分别标为 **F（来源观察）、H（编纂推断）、P（本稿建议）**；作者确定的剧情记为作者约束。单部案例不是普遍规律，同书多个引文不增加独立来源数。案例身份以核对后的元数据为准：PG41750 是 Pinero 的《The Magistrate》，不是《圣诞颂歌》的改编本；从狄更斯《圣诞颂歌》改编的舞台本是 PG41739（Barnett 的《A Christmas Carol; Or, The Miser’s Warning!》）。

## 输入与缺料分支

确认原作文本或详细梗概、目标媒介、保留的核心因果与人物、已有改写授权；有演员数、舞台条件、片长、成本或受众要求时一并采用。普通未定细节可以给标明假设的方案。

- 只有一句话：交付可转移性初判和需要补充的事件，不伪造原作分场。
- 未定媒介：并列舞台与无声视觉方案，比较表达损失，不宣称用户已经选定。
- 现代有声电影、漫画格序、短视频平台规范：可以使用本包提供的条件性动作、因果与注意方法；所请求的专属格式与工业规则为 **NOT_PROVEN**，需要另给规范或另行取证。不能把历史规范机械套用。
- 事实、法律、权属材料缺失：只标明需要核验的具体事项；历史美国版权条款不构成当前法律判断。用户提供或获授权的材料可按授权改写，不能把任何情节借鉴一概判为侵权。要求照抄某个已有改编版或直接借用他人情节时，不照抄，改给只取故事内核（plot-germ）重塑的替代；判据与授权边界见「舞台实现」参考的版权边界。

## 执行流程

1. **固定改编合同。** 列原作必须保留的决定性行动、人物关系和情绪目标。不能把作者锁定的事实当作可任意删改的材料。
2. **判转移，做表达替换。** 对每个关键段落问：它依赖对白、解释还是可见行动？目标是无声视觉时，依赖声音的信息需转成动作、物件、可见后果、字幕或结构安排；不依赖对白的段落同样可以改编。目标是舞台或有声媒介时，可以保留或改写台词、声音、转述与约定性旁白，再按现场可感知性和信息时点判断效果。
3. **重写成目标单位。** 原始故事一般并不是一个画面故事；是分场把它变成影片。改写＝重写，不是誊写。早期手册的“场”接近一次不停机的拍摄单位；舞台场与现代影视场次另以目标规范定义。记录每单位地点、人物、当下目标、可感知动作、信息变化、前后状态与转场依据。相同角色跨地点才检查其移动交代；不同人物的并行切换不自动构成瞬移。
4. **安排信息与高潮。** 因果可懂和谜底可猜分别检查。高潮来自前因与人物选择；类型允许何种结局由原作合同决定。短片的密度、喜剧场内节拍与全片剪辑速率分开处理。
5. **检验可实现性。** 舞台检查入口、家具、道具流向、群众分组和有理由的动作；画面检查注意焦点、运动方向、文字与动作是否争抢理解。成本取舍先问该效果的剧情作用，再给更简实现。
6. **修改并回读。** 每项修改定位原段与目标场，说明原功能、修法、收益、损失与来源；回读相邻场和高潮，确认没有新增泄底、时空错误或人物动机跳变。无改写授权只给建议。
7. **处理未决。** 目标与作者约束已经足以选择时直接给有条件建议。演员示范等没有通用胜负依据的偏好保留选项；仅暂停依赖未决选择的部分，继续其他可执行项。

## 输出合同

使用工作表交付：结论、保留功能、分场或转换方案、来源与推断身份、具体修改、未核实项、待作者决定、修后检查。适用时附舞台图示或镜头重点说明；本包不伪称自动生成拍摄软件工程、视频或市场成绩。

历史数字（场数、英尺、词数、排练次数、群众人数）、单一导演偏好与旧审查习惯保留在参考的明确历史分支，均不能作为现代作品的统一硬门槛。缺少现行规范时如实写 NOT_PROVEN。
