# 改编的案例（编的）

返回 [SKILL.md](../SKILL.md)。下面的输入都是为说明做法而编的，不是真实的委托，也不是改编成果。规则见各参考文件里的 AD 卡。

---

## 一、判断一个侦探短篇能不能改成无声画面

**输入**（编的）：侦探在开场前收到委托，靠三场审讯里的对白推理出凶手；最后一页揭晓，凶手是死者的孪生兄弟。

**做法**：

1. **抽掉台词**（AD-02）：输入只是梗概，没有完整的调度，不能真的“抽掉台词”测试；先记为“依赖语言的风险”，不说三场审讯里没有动作。
2. **对照侦探故事的四条顾虑**（AD-03）：推理靠对白；罪案发生在开场之前；按时间顺序演会过早露出凶手；揭晓放在最后。Esenwein & Leeds 当年就说过，情节能用动作讲清楚就可以改，后来长字幕也让许多侦探片成功了。所以结论不是“不能改”，而是“要先说明推理怎样变成看得见的信息”。
3. **替换方案**（AD-04、AD-06、AD-16）：
   - 把推理外化为动作和物件：凶手留下的物件用近景交代。
   - 把审讯改成看得见的试探：让人物去做一件事，而不是说一段话。
   - 揭晓的方式有两种：先让观众知道凶手，悬念转成追查的过程（Phillips 的路子）；或者保留身份揭晓，先给可以回查的物件和行动，最后才揭开。无声形式不要求只能选前一种。
4. **本例的选择**（建议）：保留结尾的身份揭晓，用公平线索：前段一张合照里有兄弟二人；证词说死者是独子时，侦探拿出照片试探，嫌疑人下意识遮住另一个人的脸；中段，一张早年照片上的旧伤和嫌疑人手上的伤对得上；末段把照片、遗留的物件和身份陈述并列。证据够不够唯一指向凶手，要等完整的案情设计，不说已经验证了公平性。

**交付**：结论一行，加证据行（每行附依据）、替换清单、本稿的选择和还要补的案情条件。

## 二、一段分场稿的连续性与载体检查

**输入**（编的）：某舞台剧第二幕改成无声片的分场草稿：

```
S12 书房：主人公读信
S13 银行办公室：经理签字
S14 书房：主人公把信烧掉
```

| 问题 | 判断 | 处理 |
|---|---|---|
| S12 到 S13 切到另一个地点的另一个人 | 移动交代只针对同一人物；两人在两地并行切换是允许的（AD-08、AD-09） | 保留并行切换，需要时交代两条线的时间关系，不硬插主人公出门 |
| S14 回到书房 | S12 和 S14 之间已经隔了银行一场，不算同一布景紧邻（AD-08） | 不判为连续性错误；只有经过的时间仍然看不懂时才补提示 |
| 信的内容要不要用长字幕转述 | “字幕越少越好”不对，字幕不足一样会毁片；但信件本身就能承担（AD-13、AD-16） | 插入信件近景，用一封三十来个词把话说完的信 |
| 烧信时同框有没有别的运动 | 唯一在动的东西会抢走注意（AD-31） | 检查同框有没有火苗之外的闪动、飘动的东西抢走注意 |
| 场号是否连续 | 选了历史编号格式时，全片从 Scene 1 连编（AD-07） | S12 到 S14 是连续的；没看到全片，不说全片已经合格 |

**交付**：问题表（每条附依据）、改写建议、对已知片段的结论和“全稿没看到”的限制。

## 三、不要把个案写成规则

《Moral》里，有人被逼躲进衣柜的事不在台上演，只在后来的对话里被说破（AD-06）。

如果据此写成“关键场面都应该转述”，就是把一部戏的做法变成普遍规则。它只能证明“转述是合法的手段之一”，不能反过来禁止正面演出。同理，《Erdgeist》把死亡放在门后，是这一部戏的选择，不是“死亡都要放到场外”。

## 四、要求照抄已有的改编版

**输入**（编的）：“把某部畅销小说的电影版剧本照着改成我们剧团的舞台本，台词能用的都用上。”

**判断**（AD-29）：
- 不照抄已有改编版的剧本，也不整段搬用台词。
- 改给两种方案：取得小说和改编版的授权以后再改；或者只取故事内核，重新设计人物、事件和台词，改到看不出是从那个版本来的。
- 标出要核实的事项：小说和电影剧本各自的版权状态、剧团演出的地点和性质。现行的法律问题建议找专业意见。
- 不把任何情节上的相似都判成侵权，也不给法律结论。
