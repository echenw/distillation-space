# 改编案例（自建示例）

返回 [SKILL.md](../SKILL.md)。以下情境均为自建示例，用于演示媒介转换、信息顺序和连续性检查，不对应真实作品或真实制作项目。

## Case A · 一篇短篇侦探故事能不能改成无声短片

**故事设定：** 一位失踪者留下三件物品：一张被折过的车票、一把旧钥匙和一封没有寄出的信。调查者逐步发现，车票的日期和钥匙的使用痕迹并不一致。

**改编检查：**

1. 推理是否依赖人物长篇解释？如果是，试着让调查者对照物件、位置和行动。
2. 失踪事件是否需要直接呈现？如果故事的重点是调查，先呈现结果也可能成立。
3. 若按时间顺序呈现会提前揭示身份，可以调整披露顺序，但不能隐瞒观众已经看到的关键证据。
4. 揭晓时要回收车票、钥匙和信件的作用，不能临时增加一件此前没有出现的物品。

**两种可行的揭晓方式：**

- 让观众先知道谁留下物件，悬念转为调查者何时发现；
- 保留身份揭晓，先给可回查的物件和行动，最后再解释它们之间的关系。

无声形式不要求只能选择第一种。选择哪种取决于作品对公平推理和惊奇效果的承诺。

## Case B · 把一段室内对话改成分场稿

**故事设定：** 两个人在办公室争论一份文件是否应该交出去。文件在桌上，电话不断响，第三个人一直没有进门。

**改编检查：**

- 文件是否需要被观众看见？若文件内容不重要，只需呈现谁拿着它、谁阻止交出。
- 电话的作用是什么？它是打断对话、提供新信息，还是制造时间压力？
- 第三个人不进门是否有明确功能？若没有，就不要为了增加悬念而保留一个无意义的等待。
- 两个人的空间位置和文件的归属是否连续？每次移动是否改变权力或选择？

## Case C · 时间跳跃与场景连续

**故事设定：** 人物在雨夜离开车站，下一场已经在几个月后的海边。观众需要知道时间过去了，但不需要知道这几个月中的每一天。

**改编检查：** 用季节变化、衣着、物件状态或一句简短的时间提示建立跳跃；只保留与下一场行动有关的变化。不要把移动过程全部演出来，也不要让观众误以为两场是同一天。

## Case D · 用户要求照抄一个现成改编版

**任务边界：** 用户提供一段现成改编稿，要求逐镜头复制。应先确认用户是否有权使用该文本和具体表达；若授权不明确，不能直接复制受保护的表达。可以继续帮助分析其结构功能，再根据用户提供的原作和授权范围独立设计方案。

## Case E · 冲突取舍：保留全部内心独白，又不许用旁白

**任务（自建示例）：** 把一部第一人称中篇改成剧本。作者提出两条要求：人物的内心独白全部保留，同时不得使用画外音、解说等旁白通道。

**先判冲突：** 小说里的内心独白靠叙述通道成立；剧本里「人物心里的声音」要么改成可演的内容，要么借用一条画面上的文字通道，而后者被作者排除了。这是两条要求互相顶住，不是改稿技巧问题，先交裁决备忘，不动稿。

**两条路线（各有代价，都不替作者定）：**

- 路线 A：把内心独白改写成可演的内容——人物在动作里露出（反复检查同一件物品、对无关小事反应过度、在关键的话前停住），部分句子转成对他人说出的话。代价：自省句子会变形，纯内心的一部分内容丢失。
- 路线 B：把最要紧的少数几段独白改成屏幕文字或字幕（文字插入不属于旁白），其余独白按路线 A 处理。代价：文字打断表演节奏，用量一大，观看会变成阅读。

**失败出口：** 两条路线都做不到「全部保留」，冲突交作者选；作者不答或只回「你看着办」时，按路线 A 出一个样例段落，逐条列出所做的假设，两版都不整稿铺开，不擅自扩大改动范围。

**负面回归：** 选定任一版后回查三件事——原独白承担的信息是否仍有落点；人物的关键决定是否仍然可理解；是否为了「可演」给人物添加了原作没有的行为习惯。没有落点的内容列清单，标「未能核实」，交作者决定删留。
