# R4 情节、高潮、结局与兴趣中心

## R4.1 历史情节定义（F-AUTHOR）

以下保留训诫作者的规范观点。采用因果集中、危机解决型结构时可转为检查；议论、群像、抒情、开放结构不必服从同一定义。

- 情节＝把故事引向危机、再迅速导向结局的**工作计划**；没有需要解开的 complication 就没有真情节（引文：returns home--there is no plot here, though there is plenty of plot material）。
- 三要素：**preliminaries**（其逻辑基础称 motivation）→ **complication** → **denouement**。
- 观众不仅要"看见"发生了什么，还要被"说明为何"发生。
- 另一套相关而不完全等价的说法：**Cause—Effect—Climax 的三段论**；"开端见因、发展感其果、高潮无可避免其结局"。
- 主题要简单到能用几句话说完，其余全是贡献性材料。

## R4.2 历史作者的高潮先行法（F-AUTHOR）

- 构造与解法的最高原则是**始终自觉地预知并预示**目标使命、各部分之和与决定性行动。
- 从结局开始写：先找到高潮/决定性行动，以此为目的写每一场。
- 行动曲线：Zuver建议不以快速动作开场，逐级升至 anti-crisis → crisis → anti-climax → climax。
- Esenwein与Leeds建议高潮线是一串上升的浪，每峰后须有小缓流。
- Zuver要求危机逐级增强、主角不轻易取胜。
- 该手册对当时连续惊险剧serial要求每集末是惊险顶点；普通长片每本末不必。

**当前操作（H/P）**：因果型改编检查结局是否由已建立的行动、条件和选择充分支撑，不要求唯一逻辑必然。悲喜、开放、偶然或变形结尾按用户目标与体裁契约选择。已有证据足以选择时继续执行，只有决定性目标冲突才列待决项。

## R4.4 信息量与悬念（冲突区，见 07）

- Phillips在其顺序呈现假定下要求把观众带进信任圈。
- Esenwein & Leeds：悬念不能过早泄露；不得在早期埋会误导观众以为关涉结局的细节；但若结局有人死于心脏病，就在两三个双用途场景里顺带 register 其弱。
- Zuver：结局不可过早可预测。
- 悬念过量之弊："suspense, carried too far, becomes first tiresome and then amusing"。

**裁决（H/P）**：故事内因果、向观众披露的先后、是否承诺可预先推理是三项不同选择。可以先给后果后揭原因；公平谜题需足够线索，纯惊奇不冒称可预解。两派在具体揭示时机上仍可能有真实取舍，不能宣称自动消除冲突。

## R4.5 历史作者对兴趣中心与同情的主张（F-AUTHOR）

- Esenwein与Leeds主张影戏持续聚焦单一主角（举《罗密欧与朱丽叶》实由 Juliet 主导，并批评欧洲片让同情在夫、妻、友之间三度漂移）。
- 同书要求不认可主角行为时仍保持同情。
- 同书要求动机充分到"令观众觉得罪若不得不然"（对《The Bells》的分析）。
- 最动人的戏剧效果来自**把人物与他最渴望却未满足的状态对照**。
- "Violent action will always excite and thrill the mind; but it takes passive repression to move the soul."
- 死亡不嫌多，前提是它为情节之正当而必然的展开所必需。

## R4.6 反例与边界（F，一手）

- 专员用"今晚八点释放"设期限而不展示执行，并把执行细节推给幕后——**结局可以靠承诺与期限成立，不必靠场面**。
- 主角把"不能被人看见"置于"救人"之上——**动机层级可由社会声誉压过动作**，与"主角须值得同情"形成张力，需按体裁裁决。

## R4.7 可执行动作（P）

1. 按所选结构写决定性行动、认识或收束，并说明其由何种前因支持，哪些偶然或开放部分是刻意选择。
2. 若采用三要素结构，映射原作的准备、纠葛、收束及位置；其他结构明确其组织方式。
3. 检查单主角或群像的兴趣分配是否符合目标；换中心不自动是错误。
4. 用R4.3解释相关分歧。已有作者约束时直接选用；确需比较时才给不同结局方案，不强制每次三案。
5. 检查悬念是否与实际契约相容：误导线索可用，但不能把已承诺的可靠事实任意推翻；暂藏原因不等于故事内无因果。

边界与复查共用 [条件裁决](07-conflicts-and-adjudication.md) 的执行说明；本页采用条件已写入各条规则。
