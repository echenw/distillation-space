# R7 冲突与条件裁决：五组需分别判断的主张

使用规则：不可压成无条件共识。现有目标和作者约束足以选择时，说明条件与理由后继续；决定性条件未知才保留待决。写入输出时给 `A 案 / B 案 / 本 Skill 的默认值 / 需用户决定`，并把依据一并交付。

## 冲突 1：结局信息量

| | 主张 | 来源 |
|---|---|---|
| A（Phillips） | 必须把观众带进信任圈；不要靠结尾揭底制造惊喜，因为**一切按发生顺序放映** | — |
| B（Esenwein & Leeds / Zuver） | 悬念不能过早泄露；结局不可过早可预测 | — |

**当前裁决（H/P）**：分别记录故事内因果、披露顺序和可推理承诺。先后披露的要求可能直接冲突；选择公平谜题时保留足够先前线索，选择惊奇时不承诺提前可解。不要求所有原因全程对观众可见。

## 冲突 2：节奏快慢

| | 主张 | 来源 |
|---|---|---|
| A（Freeburg） | 银幕的危险是"跑"不是"拖"；反对 touch and run | — |
| B（Esenwein & Leeds） | 喜剧要比正剧快三分之一到一半，每一场都得有戏 | — |

**当前裁决（H/P）**：先确定作者各自讨论的是镜头可读性、场内动作还是整体喜剧速度；这两段不天然只属不同层次。不同对象可并用；同一段快切与充分观看发生竞争时，按笑点理解、节奏与画面任务试排方案。旧固定“A管整体、B管单场”无充分证据，撤回。历史“三分之一到一半”不作现代速度阈值。

## 冲突 3：结尾形态

| | 主张 | 来源 |
|---|---|---|
| A | 观众爱大团圆，除非是被硬拽出来的 | — |
| B | 无论多悲都要走向 happy ending | — |
| C | 反对"火车失事式营救"；真正的结尾应是变形（transfiguration）而非毁灭或营救 | — |

**当前裁决（H/P）**：因果型结尾需获得充分支撑，不必是唯一必然后果。悲喜与变形是不同评价轴，可以组合；根据实际目标选择，保留各作者的不同立场。

## 冲突 4：演员指导

| | 主张 | 来源 |
|---|---|---|
| A（De Mille） | 绝不要告诉演员该怎么演 | — |
| B（Lubitsch） | 相信示范给演员看 | — |
| C（Milne 的评语） | 若每位导演都示范，最终只会得到全组对导演的机械模仿 | — |

**当前裁决**：先利用已知的导演风格、演员经验与任务目标。可用语言目标、示范、共同探索或混合方式；示范有清晰度收益和机械模仿风险。资料足够时提出有理由的方案，缺决定性条件时才保留未决，不自动停工询问。

## 关于"共识"的纪律

- 本包不把不同历史主张冒称共识；可兼容的不同对象保留条件分工，真正同对象冲突保留选择。凡是只有单本主张的，标注为单一来源意见，不得写成"业界共识"。
- 单一来源可支持有条件的历史方法，不设至少两本门槛。同书三处仍只是一部来源。场的定义、移动交代、字幕与画面注意各按原条件判断；原著的“暗示而非复制”保留为该书的舞台原则，不称多源共识。

## 本稿执行边界与复查

F 表示历史作者主张或原作观察，不表示所有年代、媒介、体裁都适用。把采用条件写进改编工作表；场数、英尺、字数、人数及排练次数只在对应历史方案适用。修后回读前后场，核对信息能否被感知、行动有无因果及转场是否可懂；未支持的现代格式标 NOT_PROVEN。按下游任务需要使用，不能据此给出现行法律或市场效果结论。
