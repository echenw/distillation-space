# 画面检查：构图、运动、节奏与氛围（AD-30 至 AD-34）

返回 [SKILL.md](../SKILL.md)。先写出观众在关键画面中应该注意什么，再检查构图、光线、运动和时长是否支持这个目标。本文件管画面设计；焦段、机型、承重等镜头执行参数属于现实制作事实，按 SKILL.md 的边界标为需专业核验，不在本文件下结论。清楚不是唯一目标；有意的含混、拥挤或不稳定构图也可以成立，但要说明它服务的效果。

## AD-30 · 构图：让观众看见关键戏剧元素

- **规则**：画面需要有可辨认的视觉优先级。若多个元素争夺注意力，观众可能被次要背景吸引而错过正在发生的关键行动。
- **怎么做**：每个关键画面写下“观众第一眼该看到什么”，再看构图、光线、景深和运动是否把注意力引到那里。若需要同时看到前景和背景，明确二者的关系。
- **不要这样用**：不把“清楚”当作唯一目标；有意的含混、拥挤或视觉竞争要写明效果，避免只是意外混乱。

## AD-31 · 运动：方向一致，注意力有主次

- **规则**：运动会吸引观众注意。画面中唯一运动的元素可能比静止的主角更抢眼；相邻镜头里的运动方向也需要保持可理解的空间关系。
- **怎么做**：每一场查有没有无关运动抢走注意；相邻镜头里人物和物体的方向是否自洽；跨轴或方向反转是否有意图和提示。
- **不要这样用**：次要运动不都是多余的，它可以丰富画面。只在它抢走关键信息或破坏空间连续时处理。

## AD-32 · 节奏：重复要有变化，地点要有功能

- **规则**：地点、动作和视觉母题可以重复；每次重复应带来新信息、关系变化、空间意义或情绪累积。地点过多、每处只出现一次且没有功能，会削弱环境的整体感。
- **怎么做**：查重复出现的元素是不是每次都带着变化；地点太多、每处一闪而过时，考虑合并到少数几个反复使用、逐渐加深的地点。
- **不要这样用**：不要设置固定的地点数量或重复次数。故事需要旅程和空间变化时，地点多也可能是必要的。

## AD-33 · 一框两画、表演简化与意象过度解释

- **规则**：三个常见风险：
  1. **前景与背景竞争**：纵深画面中，靠镜头太近的运动可能让观众同时追踪两个互相竞争的视觉中心。
  2. **把表演误当作面部表情**：情绪可以由身体、姿态、节奏、动作和空间关系表达，不必只靠脸部特写。
  3. **把意象解释得太满**：有些诗性或象征性画面可以留给观众想象，不必逐一转成字面说明。
- **怎么做**：查纵深画面里前景的运动会不会把注意力劈成两半；查特写和全身动作各承担什么表达；查有没有用画面或对白解释了本来可以保留的意象。
- **不要这样用**：这些是诊断提醒，不是硬禁令。前景运动、夸张表演或字面化意象在特定风格中都可能有效。

## AD-34 · 氛围：先确定效果，再选写实程度

- **规则**：氛围由表演、光线、声音、构图、场景和剪辑共同建立。写实和风格化都能营造可信的氛围；关键是观众是否感受到作品想要的效果。
- **怎么做**：每一场写下希望观众感受到什么，再选写实、风格化或混合处理。检查场景、表演和声音是否朝同一个方向工作；若刻意冲突，说明其目的。
- **不要这样用**：不把“导演负责氛围”当作编剧可以不写画面重点的理由；改编稿里关键的视觉效果仍要写清。

## 检查清单

- [ ] 每一场的视觉优先级是什么？
- [ ] 有没有无关运动抢走注意？
- [ ] 相邻镜头里的方向和空间关系是否自洽？
- [ ] 重复的元素有没有带来变化？
- [ ] 前景和背景是否互相竞争？
- [ ] 特写和全身动作各承担什么表达？
- [ ] 想要的氛围效果是什么？写实、风格化还是混合？
