# 情节、高潮、结局与同情（AD-18 至 AD-22）

返回 [SKILL.md](../SKILL.md)。本文件主要用于有明确行动线和因果收束的改编。议论、群像、抒情或开放结构可以采用不同组织方式，不必强行服从单一危机模型。

## AD-18 · 情节是一份因果工作计划

- **规则**：情节不只是事件清单，而是把人物、处境、动机、纠葛和结局组织成可理解的行动链。
- **怎么做**：把当前故事映射成三栏：准备（人物、处境、动机）→ 纠葛（目标受阻、选择和代价）→ 收束（行动结果和后果）。每一栏标出相应场景。映射不上的部分，先问是不是作品有意采用的组织方式。
- **不要这样用**：作品本来就没有中心纠葛时，不硬造一个；先和作者确认改编是否要改变结构。事件很多不等于情节完整；人物关系或观念变化也可以构成主要行动。

## AD-19 · 先找到高潮，再安排递进

- **规则**：在需要集中高潮的作品里，先确定决定性的行动或认识，再检查前面的场景是否逐步增加信息、风险、代价或选择压力。
- **可选曲线**：问题逼近 → 危机 → 暂时缓解或假性收束 → 最终高潮。它是一种安排，不是所有作品都必须采用的四段公式。
- **怎么做**：先写下高潮，再检查每一场离它近了还是远了；把高潮前的场景排成递进序列。小惊喜和小高潮可以成为台阶，但不必每场都提高强度。
- **不要这样用**：逐级上升不是唯一结构；作者要的是平缓、循环或多峰结构时，按作品目标安排。

## AD-20 · 结局的不同形态

| 结局方向 | 适用条件 | 风险 |
|---|---|---|
| 圆满或和解 | 作品建立了修复关系、达成目标或共同生活的承诺 | 若结局是硬拽出来的，会削弱人物选择和前文代价 |
| 悲剧或失去 | 核心因果指向不可逆的损失，且前文已建立代价 | 不能只为制造冲击而临时增加灾难 |
| 人物发生变形 | 作品的主要问题是信念、身份、关系或责任发生变化 | 变形必须在行动中可见，不能只靠结尾一句总结 |
| 开放或悬置 | 不确定性本身是作品承诺的一部分 | 不能用开放结尾逃避已经承诺要解决的核心问题 |

- **怎么做**：因果型的改编，检查结局是不是由前面建立的行动、条件和选择撑住的，不要求它是唯一必然的结果。悲剧、喜剧、开放和变形是不同评价轴，可以组合，按作者的目标和体裁选。
- **不要这样用**：不要求所有改编都变成大团圆；也不把悲剧或震撼当成更高级的结尾。

## AD-21 · 悬念与信息量

- **规则**：分开三件事：故事内部的因果、向观众披露的先后、是否承诺观众可以提前推理。可以先给后果、后揭原因；要做公平的谜题，就留足前面的线索；做纯粹的惊奇，就不承诺观众能提前解开。
- **延迟的边界**：悬念延迟过久而没有新信息，会从紧张变成疲劳或滑稽。每次延迟都应增加风险、改变解释或影响人物选择。
- **突发事件要提前铺垫**：若结尾需要人物因既有身体状况、事故风险或长期压力而突然倒下，可以在前文不抢戏的场景中建立可感知的迹象。铺垫服务戏剧可信度，不构成医学判断；现实病因和治疗需独立核验。
- **怎么做**：回查结局里的病发、事故、巧合或关键消息，前面有没有足够但不抢戏的铺垫。区分人物知道什么、观众知道什么，以及作者承诺了哪种揭示方式。
- **不要这样用**：不能只靠隐藏观众本应知道的信息制造悬念；也不能把所有原因都提前说明，破坏作品选择的惊奇结构。

## AD-22 · 兴趣中心与同情

- **规则**：需要清晰主线的作品，应让观众知道当前场景由谁的目标或行动主导；双主角和群像可以轮流成为中心，但转换要可辨。
- **动机与同情**：观众不必赞同人物，但需要理解其深层动机、处境和代价。负面人物也可以因保护家人、维护承诺或承担责任而获得复杂的情感理解。
- **克制与情感**：密集的暴力动作会短暂刺激注意力，持续重复则让观众习惯化；有时克制、等待和不采取行动更能推动情感。选择取决于人物和场景，不是禁止动作。
- **怎么做**：检查兴趣分配和目标是否一致：单主角作品的主线是否清楚；群像作品的几条线是否有意安排。观众不认同主角时，查动机有没有交代到让人理解。
- **不要这样用**：换兴趣中心不自动是错；群像和双主角是合法选择，只是要有意为之。理解人物动机也不等于替其行为开脱。
