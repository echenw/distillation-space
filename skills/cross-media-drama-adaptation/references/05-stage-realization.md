# R5 舞台落地：指示、走位、群众、布景

来源主体：《How to Produce Amateur Plays》（Barrett H. Clark, 1923）。本页以其系统舞台制作论为主要方法来源；其余来源分别有剧作、电影方法和画面评论等身份，不能统称为被落地的戏剧对象。

## R5.1 先读透文本：指示不足与指示过多（F）

- **指示不足**（王尔德《不可儿戏》）："The first point to be noticed is that the stage directions are not sufficient."必须从**台词与隐含动作**反推出入口、家具与道具：房间至少两扇门（后中通门厅、右前中），茶桌置于右后以免与沙发同侧拥挤；Lane 上茶后托盘放回桌上、从哪边下场、Jack 的帽子外套手套由谁收。
- **指示过多**（萧伯纳《You Never Can Tell》）：指示"more than sufficient"，同时面向导演、舞台监督、道具、布景、演员**与读者**，对导演反而散漫难用；必须把**机械要素与文学氛围分开**。
- 因此：安排舞台前**必须极仔细通读指示与台词**，初图只作底稿。
- 第三种情况：真实提示本的重印（Henry Arthur Jones《The Liars》），材料细节通常准确，只需按舞台与演员条件微调。

## R5.2 Clark的走位与构图主张（F-AUTHOR）

- 变化无穷但**仍有确定原则**。
- 舞台应如画面讲究平衡构图；所有走位都写进各自剧本。
- **不可拥挤，也不可过于对称齐整**。
- Clark要求动作有理由，并追求观众不察觉导演安排的自然效果。
- 用极简示意图记调度：台词旁加标记并另画一图，使记词与记动作同步。

## R5.3 群众（F）

- 造"千军万马"不必真用大批人：该书给出八到十二人妥善调度的方案。
- 作者建议三到六人一组的分组调度，并在人群中安插两三个 leader 带头。
- 《凯撒》论坛一场几乎无指示，暴民调度全靠导演，台词里的 "Silence!" 即暗示此前有喧闹。

## R5.4 Clark的布景与灯光美学（F-AUTHOR）

- 总纲：**"尽可能简单地达成效果；暗示，不要试图再现"**；"剧场艺术的基本原则是暗示而非复制"。
-莎士比亚在简背景前最好；《错中错》公爵府只需镀金椅与白漆长凳，公共场地空无一物反而更像公共场所。
- 脚灯与顶排灯"bad, because it is false, unnatural, and above all unnecessary"；四面布光会使舞台过亮并产生扭曲阴影。
- 三种基本布景：垂幕与高屏／写实家具／七英尺屏风。
- 服装以美观协调为纲，莎剧不必拘泥历史准确。

## R5.5 aside / 旁白这一类舞台专属约定（F，边界）

- 8 部戏剧密集使用 aside（全剧多个场景位置；此处不逐条定位）。
- 它依赖"观众听得到、同台者听不到"的约定。**适用性裁决**：不能说"禁止旁白"。
- 转无声银幕时，口述aside的字面形式需要新的呈现；有声片、漫画或其他舞台风格也须检查目标媒介是否保留该约定。按功能选择视线、物件、字幕、内心声或其他可用载体，不设全媒介固定优先级；来源直接覆盖的无声/舞台方案与其他迁移H分开。
- 同理，原著 的"三层中继传话"是伪装—误认约定的产物，不得当作通用写法。

## R5.6 排练与节奏（F）

- 首次通读、不要求表演；第二次起 blocking out。
- 该书的业余全长剧排练建议为至少四周、每周五次三小时。
- 业余演出最大毛病是**张力不连贯、节奏拖沓**；最后八到十次排练专打磨层次、起伏与高潮。
- 除表演彩排外须有一次**布景与灯光彩排**。
- 提示员须逐行跟戏随时提词。

## R5.7 版权边界（F，历史口径）

- 未获授权演出版权剧，**参与者集体担责**。
- 这是 1923 年美国口径；**现行法须另行核实**，本 Skill 不给法律意见。

## R5.8 检查清单（P）

- [ ] 门的数量与位置是否从台词反推出来了？
- [ ] 动作是否有人物、节奏、构图或其他表演理由？无功能且妨碍目标时才删；形式化、象征或间离表演不必伪装自然。
- [ ] 群众分组是否适合场地与戏剧目的？3–6 人一组及 leader 是历史方案，不是硬门槛。
- [ ] 拥挤、对称或不平衡是否有明确效果，是否妨碍可见性和执行？不把Clark的偏好当所有舞台风格禁令。
- [ ] 布景各项是否承担功能，其复杂度与效果、场地及成本是否相容？不以删至最少为唯一目标。
- [ ] aside/旁白在目标媒介里是否仍然成立？不成立时的替换手段是什么？
- [ ] 版权状态是否已核实（现行口径）？

边界与复查共用 [条件裁决](07-conflicts-and-adjudication.md) 的执行说明；本页采用条件已写入各条规则。
