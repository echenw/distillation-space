# 单场戏模板（5 类高频场景）

每份模板给：节拍序列 + 必须出现的检查项 + 来源锚点 + 常见崩法。

---

## S-1 落难首日（登陆 / 弃船后的 24 小时）

节拍：
1. **清点**（先给资产清单，再给危机）—— PG60632 L82-96：橡胶筏 + 全部仪器捆上筏，再写船沉。
2. **给坐标**（概率与截止时间）—— PG60632 L105-120：距陆地 800 英里、补给数日、希望押在主航线。
3. **恢复秩序**（火/食/干衣，按 R-A 档位选其一）—— PG12170 L698-717（寒带先火）。
4. **第一项失败**（不是大灾难，而是小东西不对）—— PG33903 L582-596：最后一张火柴被用来点烟。
5. **环视并发现**（陆地 / 人迹 /  threat）—— PG33903 L7809-7811（烟柱）、PG215（归营读景先兆）。

检查项：每步都有完成判据；至少一处小失败；有一处让读者能自己推算的数字。
常见崩法：第 4 步缺失（一路顺利）、或第 2 步缺失（只有"很危险"没有量）。

---

## S-2 据点建成与失守

节拍：
1. **选址四指标**（背风 / 干燥 / 可封口 / 近淡水）—— PG61600 L2018-2031。
2. **可封出入口**（巨石可内外开合）—— PG69191 L1664-1670。
3. **撤退载具在哪**（两者若冲突，明写）—— PG24859 L6391-6407 + 撤退船。
4. **倒计时上墙**（弹药 / 粮 / 水还能撑几次）—— PG61600 L6216-6219。
5. **失守方式**：不是被强攻，而是**内部程序冗余**——行刑前争论、换岗空隙、或"敌人假装退走"。

来源锚点：PG61600-B22（假撤退：独木舟白天退走、夜间借涨潮折返）；PG69191-B49（行刑前地点多议 = 程序本身成了拖延）。
常见崩法：据点只有"结实"，没有出口计划、没有倒计时。

---

## S-3 搜救近失（擦肩而过）

节拍：
1. **信号就位**（最高 / 最白 / 最持续）—— PG33903 L7809-7811。
2. **误读**（环境或文化原因）—— PG159 L4448-4453（火山名声使烟被当成地质现象）；PG393（持矛奔跑 → 被判定为野人）。
3. **搜救方认真搜过但仍没看见**（关键：不是敷衍）—— PG69191（搜救队沿谷地仔细搜索，落难者就在崖上）。
4. **留下可复核物证**（带坐标的日志 / 一件器物）—— PG393 L7238-7241（玩具茶具 + 经纬度，七年后才对上）。
5. **延后兑现**：物证在很久以后才起作用，或永远没起作用。

检查项：搜救方必须写得尽职；误读必须有具体原因；必须留下物证。
常见崩法：写搜救方粗心（廉价）、或写"恰好被看见"（巧合）。

---

## S-4 分配冲突（谁先拿）

节拍：
1. **资源进入稀缺区**（给出明确存量）。
2. **第一次让步**（某角色让出自己那份）。
3. **第一次抢夺或隐瞒**（另一角色独饮 / 私藏）。
4. **争执当场不解决，由后果解决**。
5. **后续反噬**（被救者记恨 / 让出者付出代价）。

来源锚点：
- PG50723 L1544-1578（船长独饮杜松子酒 vs 老水手把最后一滴让给病弱者："He had given all--every drop to the young girl."）。
- PG159 L119-147（水尽 → 抽签吃人 → 落签者反悔动武）。
- PG4271（幼儿的水不减，掌水者从自己份里分给他）。
- PG62382-R3（牺牲算术：命令 → 执行 → 当场解释 → 幸存者记恨 → 后续反噬）`SINGLE_SOURCE`。

常见崩法：全员无私（不真实）、或全员自私（单一）；或冲突当场被说服解决（把后果抹掉）。

## S-5 灾难窗口（倒计时戏）

节拍：
1. **≥3 项物理量**（气压 / 云色 / 涌浪 / 死寂 / 下沉量 / 震动频率）。
2. **有人不信**（权威否认或仪器损坏）—— PG50723-B5（气压计损坏，船长凭经验否认）。
3. **给出截止时间**。
4. **按截止时间安排撤离/加固**（每一步都要消耗资源）。
5. **兑现或半兑现**（窗口略偏，但方向正确）。

来源锚点：
- PG50723 L2194-2222："this island goes in less than forty-eight hours"（原卡自注：属人物判断，非作者论断，引用时必须保留该保留）。
- PG8991（冰面每次下沉 6 英寸，可逐次测量）。
- PG24859（气压急降 / 云色 / 涌浪 / 死寂）。
- PG393（铅色云 / 鸟乱飞 / 远处如人群喧响 / 风停 = 风眼）。

常见崩法：只有"他有种不祥的预感"；或窗口给得精确却从未被验证。
