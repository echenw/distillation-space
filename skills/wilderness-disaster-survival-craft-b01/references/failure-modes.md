## 快速判定顺序（时间不够就走这 5 步）

1. 问"读者能自己推算还剩几天吗？"→ 否 → R-B。
2. 问"这一段里有没有一样小东西不对？"→ 否 → R-D。
3. 问"被突破时人从哪走？"→ 答不出 → R-E。
4. 问"倒计时有几项物理量？"→ < 3 → R-F。
5. 问"谁让了、谁藏了？"→ 都没有 → R-H。

## 诊断输出格式（每次必须给这些）

- 命中项编号 + 对应正文位置（行号或段落）。
- 每一项：修复动作（具体到改哪一句）+ 用到的规则 ID + 来源锚点。
- 若某项标 `SINGLE_SOURCE`，明确写出"单一来源，未获交叉印证"。
- 若某症状在本批 28 份里找不到对应锚点 → 写 `NOT_PROVEN`，不给结论。

## 不适用的诊断请求（走失败出口）

- "请给我真实野外求生建议" → 本技能来源是 1882–1951 虚构叙事，不是手册。
- "一个人一天到底要喝多少水" → 不给常数；给模板并说明常数随载具/气候/体质变化。
- 现代背景（GPS / 卫星 / 直升机）下的信号与搜救 → 本批规则整体重估，只保留误读/近失。
