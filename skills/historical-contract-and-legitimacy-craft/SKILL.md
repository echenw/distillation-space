# 历史契约与合法性工程（A-07-B05）

18 部历史小说 / 历史架空 / 历史罗曼司**全文实读**（Scott×6、Stevenson×2、Haggard、Stowe、Orczy、Isham、Burroughs、Kipling、John Reed Scott、Derreaux、Cather、Wiggin；19–20 世纪英语文本，208,681 行 / 2,682,954 o200k Token），归并为 **12 个独立来源族**，提炼 **11 个规则族**（33 ADOPT / 4 CONDITIONAL）、1 条 REJECT、5 条红线 R1–R5、6 条真实冲突 X1–X6。本 Skill 内 66 条引文**逐条回读原文核验：66/66 命中（100%）**（方法见 `references/05` 末节）。

**与同父任务 Skill 的分工**：`批次-06` 那一份以"缝隙虚构"（虚构人物嵌入真实事件、不改结果）为主轴。本批 18 源里出现了**三类**而不是两类文本——① 缝隙虚构（PG82 / PG4966 / PG6406 / PG6944 / PG1377 / PG1711 / PG70124 / PG30939 / PG31916）；② **纯虚构世界**（PG43076 的 dreamland、PG24973 的洪水前太古、PG40034 的虚构公国 Valeria、PG8147 的 Kafiristan）；③ **被误划入的当代题材**（PG20749 / PG24 / PG1033）。因此本 Skill 的主轴换成**契约**（你向读者承诺哪一种真）与**合法性工程**（在没有真实锚点时，可信度从哪来）。

**来源性质**：全部来源为 `FICTION_CASE`。绝大多数规则是从**文本现象（F）**升格的**推断（H）**。**但本批与同父批次不同**：PG82 / PG4966 / PG6406 / PG43076 / PG1711 的引言与作者注里**确有作者本人关于取材、选时代、改稿政策、注释策略、地理处理、史料采信的自陈**，本 Skill 标为 `F-AUTHOR`。引用时说"这些文本里可复现的做法是……"或"作者在该书前言里自陈……"，**不得**说"某某作家教导应当……"（作者明确教授写作方法仍 NOT_PROVEN）。

## 3. 执行步骤（五步主流程）

**步骤 1 — 立契约（必做，最先做）**
在副文本里写清楚三件事：① 哪些人物/事件为真、哪些为虚构（A1 句式）；② 你是"缝隙虚构"还是"纯虚构世界"（§前言的三类）；③ 若违反史实，写明违反点 + 为什么 + 限定范围（A6 / R4）。
- 走缝隙虚构 → 用 B1 硬锚点 + A3 副文本清单。
- 走纯虚构世界 → 用 A2 免责句 + B5 模糊纪年 + D6 内部自洽。**不要在 dreamland 契约下硬塞年份**（X1）。

**步骤 2 — 铺副文本（五格）**
按 A3 逐格填：底本（legend / family tradition / obscure historical fact）→ 场景所在地的真实程度 → 哪些情节确有事实根据 → 词汇表 → 古俗与民间迷信注。缺哪格明说缺。
注释另按 A4 准入：只在**通史查不到**处加注，且 sparing hand（X5：注释克制，副文本详尽，层级不同）。

**步骤 3 — 建冲突与合法性**
把冲突落进制度与文书（D1–D6）：文书可被毁（D2）、后法可撤前法（D3）、顺序不可颠倒（D5）、终场须四重合法性（D4：书面法令 → 当事人认领 → 器物仪式 → 众口拥立）。
同时给每一方写成本账（C1–C3）：对立双方同等真诚（C1），敌方控诉要能落到一个事件 + 一组名字（C2），支持者也不无私（C3）。

**步骤 4 — 定人与定世界**
真实人物走 F1–F6（四层命名、群像降格、信仰重写、原型登记）并受 R1 / R2 约束；身份线走 K1–K4（血缘由习俗定义、身份由他人承认、真相可被管理、器物即合法性）。
世界走 E1–E6（只取轮廓、劝阻按图索骥、未亲历降密度、交界地位、禁忌地名、无人干预的物件开局）与 I1–I4（失落感、衰败的可计数支出项、伪编年声明、时间距离副标题）。

**步骤 5 — 收束并复核红线**
终场用 D4 或 F/J 族结算；最后逐条核对 R1–R5，并回答"这条规则来自几部作品"（R5）。命中 §6 任一失败出口即停手并如实标记。

## 5. 输出合同（每次应用须交付五项）

1. **选用规则 ID 列表**（A1…K4；单源证据标 `[单源]`）。
2. **每条规则在本作的具体化**：触发事件 / 操作改写 / 产出物。
3. **失效条件核对**：该规则的 when_not 在本作设定下是否闭合；未闭合标 `风险`。
4. **证据锚点**：至少一条 `PG ID + 行号 + 逐字短引文`；**不得用"一般来说"替代**。
5. **边界声明**：涉及结果改写 / 真实人物 / 暴力与偏见 / 非西方题材 / 当代题材时，逐项标 ADOPT / CONDITIONAL / REJECT / NOT_PROVEN。

**引述措辞**：说"**在这些文本里可复现的做法是……**"；引用作者前言时说"**该书前言里作者自陈……**"。**不得**说"某某作家教导/主张应当……"。
