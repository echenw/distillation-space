# 儿童青少年叙事：孩子做得到的选择，与不能被抄走的时代立场

本 Skill 是**创作与审稿工具**，不是教育学、医学、心理学或正式年龄分级模型。
29 本古典英语儿童文学里含有过时的族群、性别、阶级与惩戒观念；作品中的叙述 **F** 不能被升级成现代儿童发展、健康或安全事实，**也不能把某一部的情节设计当成所有作品都必须遵守的规则**。

## 触发 / 负触发

**触发**：儿童 / 中童 / YA 成长故事、动物拟人、玩具与幻想契约、家庭与学校冲突、亲子朗读或讲述脚本、旧稿里的儿童视角与伦理问题、节日汇编与分级编排。

**负触发**：真实心理健康或发育诊断；法定监管年龄与合规判断；儿童危险活动的实操步骤；纯成人作品且无儿童视角；要求把"文学观察"当年龄适配认证；要求复刻旧文本的种族化命名或殖民表述。

## 先确认的输入（缺哪项就标 UNKNOWN，不要猜）

1. 故事目标与体裁：单卷叙事 / 汇编合集 / 讲述脚本 / 改写本。
2. 目标读者或朗读形式（可 UNKNOWN）。
3. 已有正文、大纲、版本与授权范围（是否允许改稿）。
4. 孩子实际能做什么、谁在监管、谁能进入关键地点。
5. 情绪与危险内容的范围，以及是否要求"儿童必须原谅 / 必须获救"。
6. `F`（用户正典或可回源小说短例，须区分二者）/ `H`（推断）/ `P`（候选修改）三栏是否都填得出来。

## 执行步骤（按顺序做，不要跳）

1. **定体裁与受众**：单卷 / 汇编 / 讲述脚本先分清——三者的收束与编排要求不同（R20、R19）。
2. **定谁在看世界**：写孩子已知、误解或有权不说的事；成人知道更多，不等于叙述要由成人代讲。
3. **给可达成的行动**：孩子可以观察、提问、探索、结伴、求助；写明谁有钥匙 / 工具 / 离开权。关键行为不能靠"成年人恰好不在"完成。
4. **给行动配代价**：胜利要附带会重复出现的代价，或让损失落在共享资源上（R21）；不要"打赢就结束"。
5. **按使用方式调语言**：朗读用短句、清晰指代、可控重复；YA 可容纳双层含义与未解释暗示。**没有读者实测就不声称某年龄必然理解**（R19）。
6. **危险有界**：不给可模仿的操作步骤；给实际后果、退出路径、求助对象，并交代成人保护或不作为的原因（C03）。
7. **标立场而非抄立场**：对性别、阶级、殖民、惩戒、惊吓教育的旧表述，标出"这是谁的判断（角色 / 叙述者 / 编者）"，再决定是否保留为历史距离（C04、R17）。
8. **收束**：回应孩子的选择与关系后果即可；不强制挽歌、不强制章末教训、不强制续集伏笔（RC-02 / RC-07 / RC-13）。

## 缺料、冲突与失败出口

- **年龄未知** → 输出"亲子朗读"与"青少年自主阅读"两套**选项**并说明差异，标 UNKNOWN，不做年龄认证。
- **设定自相矛盾**（例如"孩子没有外出权限"＋"独自夜穿荒野"）→ 先列最小冲突，给求助 / 改时间 / 换场景三种方案，不暗中改用户正典。
- **读者素材不足** → 只给原创可选方案，并声明未做真实儿童试读。
- **涉及真实儿童健康或安全** → 转介专业来源，不依据这些古典小说作事实判断。
- **用户要求复刻旧文本的种族化命名、殖民优越或"买下 / 处置儿童"的情节** → 明确拒绝原样复刻，给出"保留结构、替换表述"的替代方案（见 [scope-and-conflicts.md](references/scope-and-conflicts.md)）。
