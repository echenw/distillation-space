# 诊断/修订样例与反例（重写旧RE具体外壳）

**例A：海上宝藏线索**。F 用户设定“潮汐只在清晨露出礁石文字”，有航海日志记载地点。H：如果主角夜里抵达，不能立即读字。P：转向等待潮位/寻找当地经验者/检查日志时间是否记错。正确输出要有路线与成本，而不是编造月相或当地现实潮汐数据。

**例B：失落遗迹发现**。F 小说描述某面孔的石刻、主角有一个记号。H：石刻也可能为后世仿制。P：把发现者、观察时间、下一验证、误判者列出来；是否属于文化遗产不要靠“第一个看到的人就拥有”。文案风格可借 PG12190 L456–457 的发现场景，不能当历史学证明。

**例C：高危行动**。F PG63353 L7526–7527 角色评估大型伤亡风险。H：完成目标与保护无关人员冲突。P：给选择撤离/谈判/冒险，明确谁承担后果，不能让“主角天选”自动消除伤亡。

**反例集**：强制第二人称开局、三现标题意象、每章歌谣、死刑换命/旁白死亡、沉默英雄、无消耗瞬移、地图凭空出现、一封信证明宝藏所有权，均不是已证普遍法则。场景可以合理选用部分手法，但须由用户材料与叙事目标决定。
