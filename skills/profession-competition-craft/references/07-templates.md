# 07 可填写模板：职业账本 / 场景卡 / 门禁表

## 本文件解决什么

SKILL.md 给出判定规则，本文件给出**可以直接照抄填空的三张表**。每格要么填具体内容，要么填 `待补`；只有本稿承重字段实际缺失才触发 SKILL.md 的失败出口，不适用栏可以标 N/A。

---

## 一、职业账本（8 栏）

用法：定轴为 A/B 档后，写第一个职业场景之前填完。职业承重列（工作交付、评价者、失败代价）缺失时转 **X7**（要求文本或标未证）；不能仅因固定数量空列强降 C 档。C 档只需填前三栏（LEDGER-A/B/C）。

| 字段 ID | 栏位 | 要写什么 | 反例信号 |
|---|---|---|---|
| LEDGER-A | 职业 / 时点 | 具体岗位、行业阶段、地域 | "医生 / 律师"四个字 |
| LEDGER-B | 收入结构 | 底薪、计件、佣金、奖金、灰色收入 | 只写"赚得不多" |
| LEDGER-C | 工时 / 周期 | 日 / 周 / 季、截稿、赛期、农时 | 永远有空谈恋爱 |
| LEDGER-D | 渠道 / 客户 | 谁付钱、谁介绍、谁抽成 | 客户从天而降 |
| LEDGER-E | 署名 / 归属 | 作品 / 专利 / 功劳归谁 | 主角全揽 |
| LEDGER-F | 风险 / 身体 | 工伤、失眠、成瘾、暴力、失业 | 受伤不影响工作 |
| LEDGER-G | 门槛 / 资格 | 执照、考试、推荐、编制 | 想进就进 |
| LEDGER-H | 术语 / 物件 | 3–7 个可操作词、1–2 个随身物 | 术语词典堆砌 |

| 字段 | 内容 |
|---|---|
| LEDGER-A | 1890 年代伦敦小说家（三卷本时代末期） |
| LEDGER-B | 版权买断 75 镑，销量达标再付 25 镑（L6647-6648） |
| LEDGER-C | 每天四张稿纸、六十张一册、四十五天一本（L5130-5131） |
| LEDGER-D | 出版商 — 经纪人 — 租书商；广告与书店决定销量 |
| LEDGER-E | 版权归出版商；匿名评论由编辑指派 |
| LEDGER-F | 失眠、脑力枯竭、病死（L5167-5168、L19659-19693） |
| LEDGER-G | 无执照，但需评论人与租书商认可（L4379-4403） |
| LEDGER-H | 稿纸、三卷本、校样 |

| 字段 | 内容 |

## 二、场景卡（8 栏）

用法：每个职业场景一张。第 6 栏（钱与时间）没填具体数字 → 失败出口 **X12**。

| 字段 ID | 栏位 | 要写什么 | 反例信号 |
|---|---|---|---|
| SCENE-A | POV | 谁在看，内行还是外行 | 视角飘忽 |
| SCENE-B | 目标 | 这场要拿到什么 | "他想证明自己" |
| SCENE-C | 门禁 | 谁挡、为什么挡 | 没人挡 |
| SCENE-D | 操作步骤 | 3–6 步，读者能复述 | 只有结果 |
| SCENE-E | 行话 | 不超过 3 个，每个配动作 | 术语堆砌 |
| SCENE-F | 钱与时间 | 具体数字 / 期限 | "很多 / 很快" |
| SCENE-G | 对手或守门人的利益 | 他真正怕 / 要什么 | 单纯的坏人 |
| SCENE-H | 这场付出的代价 | 身体 / 资产 / 关系之一 | "他很累" |

### 填法示例（报馆第一天，据 PG9300 / PG13731）

| 字段 | 内容 |
|---|---|
| SCENE-A | 新人记者 Jennie（内行者找工作，但对该报馆是外行） |
| SCENE-B | 见到主编并拿到一个可署名任务 |
| SCENE-C | 门房：预约制与一个玻璃哨亭（L164-168） |
| SCENE-D | 问清主编动线 → 改从门房入手 → 在隔壁房间听到线索 → 转手做成独家 → 被要求十五分钟重写开头 |
| SCENE-E | 独家、校样、截稿 |
| SCENE-F | 每天四张稿纸对比；十五分钟重写一段（PG13731 L121-125） |
| SCENE-G | 城市编辑怕被同行抢先、怕版面开天窗 |
| SCENE-H | 署名被放在末尾；欠了门房与线人的人情 |

## 三、门禁表（3 层）

用法：主角每次进入新行业 / 新岗位 / 新赛场填一次。任一层的"守门人利益"为空 → 失败出口 **X9**。

| 字段 ID | 层 | 门禁是什么 | 守门人 | 守门人的利益 | 通过凭证 |
|---|---|---|---|---|---|
| GATE-A | 物理门 | 门房 / 前台 / 片场窗口的一句话拒绝 | 门房 / 前台 | 怕丢工作、怕被上面怪罪 | 一句话术 + 一个物件 |
| GATE-B | 资格门 | 一条能被念出来、能被钻空子的规则 | 编制 / 执照 / 考委会 | 同行利益、门槛租金 | 规则条款 + 缺口 |
| GATE-C | 证明门 | 一次可被第三方核验的交付 | 主编 / 主考 / 裁判 | 截稿、通过率、胜负 | 独家 / 花瓶 / 手术 / 战绩 |

### 填法示例（新闻业，据 PG9300 / PG3472 / PG3669）

| 字段 | 内容 |
|---|---|
| GATE-A | 门房玻璃哨亭；"有预约吗？没有就见不到。"（PG9300 L164-168）｜利益：怕失职被开除 |
| GATE-B | 正式编制 vs 女士专栏（PG9300 L408-454）｜利益：编辑部控制人力成本与版面｜缺口：外勤任务可绕开编制 |
| GATE-C | 一篇印出来、上了街、别家没有的独家（PG9300 L879-880）｜利益：主编要抢在别家之前 |

### 填法示例（影视业，据 PG3472）

| 字段 | 内容 |
|---|---|
| GATE-A | 片场大门与选角窗口，连续十天只得到"今天没有，也许下周"（L2093-2096）｜利益：窗口的职责是减少人流 |
| GATE-B | 类型选角：保加利亚将军、塞尔维亚外交官，要求"站出来要像"（L3312-3316）｜利益：类型匹配与预算 |
| GATE-C | 一次上镜并被看片室辨认出来（随后 $7.5/日 → $75/周）；或被制片人认定为"像某某 + 多一点" |

## 四、填写自检

1. 三张表中与**本稿类型**有关的字段足以支持因果和读者辨认（不适用项 N/A）→ 可以进入下一步；不得硬造三层门禁。
2. 职业账本的**承重字段可验证**即可规划场景；其余不适用字段标 N/A，缺真实行业事实标 NOT_PROVEN。
3. 若交付、评价或代价等**本稿承重字段**全缺，走 X7；其他空格不触发固定失败阈。
4. 场景卡 SCENE-F 为空 → 走失败出口 **X12**。
5. 门禁并非本故事核心时允许 N/A；若明确存在对抗门禁且看不到守门人为何拒绝，再走 X9。
6. C 档只要求 LEDGER-A/B/C；其余栏属不适用，**不要为了填满而硬造晋级线**。

## 五、审查表（输出格式第 3 项）

| # | 审查项 | 判定取值 |
|---|---|---|
| 1 | 轴档是否正确（三问结论是否与实际职业决策一致） | PASS / REVISE |
| 2 | 职业核心证据是否可得 | F/H/P 已分层 / 承重字段缺失→待补 |
| 3 | 门禁是否三层且守门人各有利益 | PASS / REVISE |
| 4 | 工序能否被读者复述 | PASS / REVISE |
| 5 | 钱是否改变过一次选择 | PASS / REVISE |
| 6 | 竞技是否有规则、战术、裁判与赛后 | PASS / REVISE / N/A |
| 7 | 伦理选择是否有代价，作者是否容许改革或妥协 | PASS / REVISE / N/A |
| 8 | 代价是否落在身体 / 资产 / 关系 | PASS / REVISE |
| 9 | 结局是否有因果支持；制度改革不能凭空宣布成功 | PASS / REVISE |
| 10 | 是否把时代偏见当作者结论 | PASS / REVISE |
| 11 | 读者反应 / 市场有效性的任何断言 | **NOT_PROVEN** |

**任一项 REVISE → 整体 REVISE；缺读者 / 市场证据 → NOT_PROVEN，不冒充 PASS。**

---

## 六、边界

- 三张表是**填写工具**，不是评分表；填满不等于写得好。
- 字段 ID 只用于检查"是否填完"，不用于自动评判内容质量。
- 本 Skill 没有任何脚本来自动校验这些字段；若将来要做"职业账本校验器"，需另立 automation 能力与测试，本轮不存在此类能力。
