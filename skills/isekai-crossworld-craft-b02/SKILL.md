# 异世界与穿越：机制诊断与设计（批次-02）

本批次 27 部集中在三类越界：**梦 / 离魂 / 前世**（PG1853、PG5114、PG6073、PG7814、PG78126、PG9817、PG9956）、**时间与社会制度**（PG12163、PG32256、PG46173、PG48690、PG49207、PG69637、PG67575）、**技术赠礼与代价**（PG8394、PG1355），另有三部不含越界要素（PG288、PG12176、PG75817）作为外边界。

**核心判断不是"能不能穿过去"，而是这五项：入口类型是否被声明、可返回性是否在开局说定、代价是否前置、世界是否承认主角的因果律、制度差异是否落在可点名的细节上。** 本批次与批次-01 最大的不同在于：梦通道占了多数，而梦通道是否可信取决于**有没有可核查的锚**（R13），这是本批次首立的规则。

规则全部来自 27 部已全量核验的公版文本，逐条带 PG 编号与行号，见 `references/rule-verdicts.md`。**只有一部作品支持的断言一律标 H，收进 `references/conflicts-and-exceptions.md`，不得当通则执行。**

## 1. 触发与负触发

**用本 Skill 当**：用户在写/改/评一部小说，且主角发生下列之一——
- 进入另一个世界、异界、仙境、亡者之域、寓言国；
- 位移到另一个时代（休眠、时间银行、时间战争、前世记忆）；
- 梦、离魂、假死、通灵作为通道（本批次主力类型）；
- 身体或意识转移到另一星球 / 另一物种；
- 进入一个被重新组织的社会（乌托邦、反乌托邦、共同体实验、按癖好分类的群岛）并被要求遵守其规则。

**不要用本 Skill**：
- 不含任何越界要素的写实或历史小说——本批次的 PG288（L308-326 作者自述写的是过去时代）、PG12176（L782-802 现实法国小镇）、PG75817（L1140-1152 丛林法则）就是这种，核账里记为"不适用"。把它们算成异世界证据是错误。
- 只问文字润色、章节节奏、人物对话，与越界机制无关。
- 需要法律意见（版权、公有领域判定）——本 Skill 明确不提供。
- 用户要的是某部具体作品的情节复述或考据，而不是机制规则。
- **当代（20 世纪后期至今）异世界/穿越的商业惯例与读者预期**——本批次 27 部全部是 1785–1935 年间的公版文本，据此推当代惯例必错，见 §6。

## 2. 输入（必须先拿到什么；缺哪一项就走 §6 失败出口）

1. **越界类型**（七选一，见 `references/mechanism-taxonomy.md` §1）：装置 / 契约机构 / 灾害事故 / 睡眠梦 / 离魂假死 / 记忆前世 / 无入口（被编排或投射）。
2. **可返回性**（三选一）：可返回 / 不可返回 / 返回即损失（朋友已死、无人认得、记忆被抹）。
3. **代价是否已前置**：主角在越界前是否被明确告知要付什么（本批次里 PG4405 L501-516 是正例，PG12163 是反例）。
4. **世界是否承认主角的因果律**：主角带来的技术、财富、知识在这个世界里算不算优势。
5. **制度差异清单**（若写社会设想类）：税 / 工时 / 货币 / 制服 / 历法 / 劳动分派 / 入学年龄 中至少两项的具体写法。
6. **用户真正要的产出**：诊断报告 / 修改方案 / 从零设计 / 规则裁决。

第 1、2、3 项是硬门槛。拿不到就先问，不要替用户假定——本批次里"代价没说定"正是 PG12163 主角醒来即落入自己名下体制、却无行动自由的直接原因（`references/source-index.md` PG12163 条）。

## 4. 执行步骤

**通用五步（任何路线都要走）**

1. **填 intake 表**——按 §2 六项逐条记下用户的答案；没答的标 `UNKNOWN`，不许猜。
2. **定越界类型**——在 `references/mechanism-taxonomy.md` §1 里对上号；对不上就说明这是未见类型，按"无入口"处理并要求用户补代价。
3. **跑规则体检**——按路线对应的 `rule-verdicts.md` 条目逐条判 `PASS / FAIL / N/A`。每条必须落在具体章节上，不要给泛泛评价。**注意裁决等级**：KEEP 类（R4、R9、R10、R13、R14、R15、R16）可作硬检查项；REVISE 类必须用"改写后的可执行版本"判，不许照原句判；REJECT 类不许当检查项，只能作"别这么做 + 替代做法"；R7 标 H，不得作硬检查项。
4. **查反例**——把判定为 PASS 的条目拿到 `references/conflicts-and-exceptions.md` 里对照；若该条目在本批次内有反例，必须把反例写进输出（这是本 Skill 与"通用写作建议"的区别）。
5. **按 §5 输出合同交付**。

**路线专属动作**

- A（体检）：逐项给 PASS/FAIL/N/A 与行号级修改建议；FAIL 项必须给出"改成什么"，不能只说"这里有问题"。
- B（锚点审计）：先问"这个梦/离魂留下什么可核查的锚"——时间锚（PG7814 L12232-12235：数月经历对月亮只升高两三小时）、声源锚（PG7814 L12291-12293：异世界的声音 = 现实中的歌声）、信息锚（PG9817 L6042-6052：梦里听到的是真实发生过的旧日谈话）。三种锚至少要有一个；一个都不给就必须明确写成"启示型"，并接受读者不必信。
- C（因果律审计）：先让用户回答"这个世界承不承认主角的因果律"（三档：承认 / 部分承认 / 不承认），再据此决定优势上限；**必须至少写一次失败**（R16 依据：PG8394 L1066-1073 被自己的金子压垮、PG12163 L6601-6609 财产换不来行动自由）。
- D（出口设计）：从三态里选一并在开局就声明；之后不得无代价翻转（R3 依据：PG7814 L12171-12178 可返回 vs PG9956 L4778-4788 返回即损失 vs PG1853 L504-509 得不到）。
- E（制度落地）：至少落两项制度细节，且**为每一项配一条代价**（R14）；风景描写排在第二位（R9 依据：PG12163 L1319-1336/L6043-6071/L6601-6609、PG49207 L2197-2200/L2230-2281、PG48690 L455-483、PG69637 L1803-1812）。
- F（权威溯源）：先读该书的后记/序言/框架叙事，判断书中制度是不是作者主张（R15 依据：PG7814 L12499-12503 作者自陈 "I do not say that I believe it myself"；PG67575 L11519-11547 叙述者消失、由记录者署名）。作者明确否认的，只能引作写法范例，不能引作主张。
- G（解释权）：若保留不可裁决，必须写明"谁在否认、否认到什么程度"，或给一条读者可自行核对的物理锚（R6 依据：PG7814 的歌声锚；PG1853 L504-509 的"让它失效"写法）。

## 5. 输出合同

每份输出都必须含这六块，缺一块就不算交付：

1. **intake 表**：§2 六项，含 `UNKNOWN` 标记。
2. **越界画像**：类型 + 可返回性 + 代价是否前置 + 有无锚（梦通道必填），一句话。
3. **规则体检表**：每条给 `PASS / FAIL / N/A`，附 `rule-verdicts.md` 的规则编号、裁决等级与依据来源+行号。
4. **反例与分歧**：至少列一条本批次内与该方案相反的作品处理；没有就写"本批次内无直接反例"（不许编）。
5. **可执行修改清单**：逐条写"第 X 章 / 第 Y 处 → 改成什么 → 依据规则编号"。
6. **未证明项**：明确列出哪些判断只有单部作品支持（标 H），哪些超出本批次 27 部（标 NOT_PROVEN）。

## 6. 失败出口

- **intake 拿不全** → 停在 §2，把缺的项作为问题返回给用户，不要进入体检。理由：R10（代价前置）与 R3（可返回性声明）都依赖开局信息，事后补等于重设计。
- **用户要求"把某部作品的 X 设计当作所有作品都必须遵守的规则"** → 直接拒绝并引 R11 + `conflicts-and-exceptions.md` §5，给出该设计的反例作品。
- **用户的作品不含越界要素** → 退出并说明本 Skill 不适用，不要硬套（本批次 PG288 / PG12176 / PG75817 就是被这样排除的）。
- **需要的判定超出本批次 27 部来源**（尤其：当代类型的商业惯例、非英语圈异世界/转生套路、影视与网文生态） → 在输出里标 `NOT_PROVEN`，不编造规则。
- **涉及版权/公有领域判定** → 说明本 Skill 不提供法律意见，须按文本与司法辖区逐本复核。
