# FIN — 财政、契约与可掉包凭证

用当情节由钱、赔款、赎金、年金、珠宝、嫁妆或"一份值多少钱的文件"驱动。

## 必做检查

1. 数额**可计**：给出能落到纸上的数字，不许只写"一大笔钱"。
2. 数额**可搬运**：写清怎么运、由谁运、运到哪、途中会不会被查。
3. 数额**可掉包或伪造**：真改成假、假充真、给别人做"同样一套"。
4. 至少**两个不相干的持有人**各自接触过这件凭证（模式 A 的硬性条件）。
5. 写清**账目单位**：是谁家的账（国家／家族／商铺／个人），单位错了整个冲突就散。

## 三条来源支持的用法（不许混为一谈）

|---|---|---|

## 可掉包凭证的三种写法（P）

- **以假换真**：真珠宝留作家用，假珠宝充当门面（PG2681 L10088-10096）。
- **以名字换人**：一个体面的名字可以立刻降低怀疑，让追查者撤回（PG135 L24117-24121）。
- **以亲属称谓换案情**：一句"她祖父来接走的"把拐带案改成家事（PG135 L24107-24110）。

## 反向限制：凭证不一定能定案

PG411 给出反例：电报说某人卖了秘密（L2589-2593），契约说只是"假装进攻后撤回"（L2645-2648），
两份文件同场被当众朗读，内容互斥却无人追究；最终真相由当事人翻供（L2730-2747）而非凭证决定。
**若选这条路线，必须在选域时写明走模式 B，并补非凭证收束路径（权力翻转／暴力失控／程序化偶然）。**

## 常见错（诊断用）

- 只写"巨额财富"、"无法计算的价值" → 违反 FIN-1，情节的重量读者感受不到。
- 钱能在两个国家之间瞬间转移而没有运输链、没有查禁风险 → 违反 FIN-2。
- 结局押在一封信／一张票据上，但这件东西只在主角手里出现过一次 → 违反 FIN-4，属模式错位。
