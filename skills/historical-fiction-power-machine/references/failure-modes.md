# FAIL — 失败出口与五类常见死法

卡壳或被质疑时按这个顺序自检，不要跳步：

1. **凭证挂点**（`finance-and-instrument.md`）→ 2. **目标函数**（`reputation-target.md`）→
3. **承诺 vs 财产**（`oath-marriage-inheritance.md`）→ 4. **谣言发源人**（`rumor-and-narrative.md`）→
5. **伪装代价**（`disguise-cost.md`）→ 6. **模式是否换乘**（`conflicts-and-exceptions.md`）。

## 五类死法与修复路径

### 死法 1：结局押在凭证上，却没人真正看过凭证
症状：最后一封信／票据决定一切，但全文只有主角一个人碰过它。
修复：给凭证安排**第二个不相干的持有人**（抄写员、邮差、当铺、敌人），并在他手里也写一次细节（PG135 L24047-24057、L24107-24110、L24117-24121；PG31484 L4093-4130）。
若改不了：改走模式 B，明确写出非凭证收束路径（权力翻转／暴力失控／程序化偶然，PG411 L2730-2747）。

### 死法 2：敌人的动机只写"他恨主角"
症状：高潮场面华丽但读者不知道对手到底要什么。
修复：写出**目标函数**（名声 / 性命+合法性 / 无敌人），并让高潮地点与它匹配（PG2785 L6089、L6049-6052）。

### 死法 3：一句誓言解决了所有问题
症状：主角说"我发誓"，财产阻力、家长反对、运输困难随即蒸发。
修复：把承诺与生效条件分成两栏；给每次爽约一次可见成本（PG5202 L466、L1372、L1286-1357；PG2681 L5153-5179 vs L14973-14981）。

### 死法 4：谣言传遍全城却无发源人
症状：所有人突然都知道某件事，谁也不知道是谁先说的。
修复：给一个具体发源人与获取渠道，再给两级中转与每级的加减料（PG34660 L7207-7217、L7219-7243；PG2681 L15100-15102）。

### 死法 5：伪装的代价写错了规范
症状：中世纪冒险里主角因换装开始哲学追问"我是谁"，读者出戏。
修复：代价改写到该社会最敏锐的规范上——中世纪写体力与笑料、近代／边疆写性别体面、间谍背景写长期情感开支（PG31484 L6058-6118；PG6668 L2754-2756、L2903-2935）。

## 停止点（什么时候该停手并交给用户）

- 用户问的是真实历史事件／人物的事实 → 停手，说明本包不做史学鉴定。
- 需要地形追逐、谶语主线或毒药攻防 → 停手，转 B02 包。
- 涉及现实中的侦查、追踪、取证、安防或任何可致伤害的实施 → 停手，不提供。
- 需要引用的时代语料无法在当代语境下改写 → 停手，说明理由并给用户替代结构（`era-sensitivity.md`）。
- 单源候选项（PG7987 的替代取证）被当作确定规则用 → 停手，标注"待核对"后再继续。
