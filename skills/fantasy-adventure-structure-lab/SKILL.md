# 奇幻/冒险结构实验室（fantasy-adventure-structure-lab）

## P4 专项操作入口（Agent B 静态修订）

本 Skill 保留既有可执行流程与参考资料，并添加一份从本批次原文中裁决的 [精简条件规则](references/p4-field-guide.md)。按用户任务选择主分支，只加载该分支所需参考资料；原始叙事实例是 **F（作品现象）**，提炼为作者可以采用的流程属于 **H/P（设计推断/建议）**，不能写成原作者明确教过的方法。

**必须先获得**任务（写作/策划/诊断/改写）、目标受众与媒介、已知人物/事件/规则及原稿（诊断时必需），并确定允许改写的范围。输出合同：`任务路由 → 输入事实/缺口 → 选择的规则ID → 有位置的文本证据或来源 → 可执行方案（含反方案） → 交付物 → 尚未验证的风险`。当用户没给原稿时不能虚构段落位置；要求改稿时默认只给方案或非覆盖的新稿；涉及权利、历史真实或危险现实建议时，划清故事创作与现实事实边界。

**退出方式**：缺关键剧情信息，给最小补料清单和两条可选方向；用户目标相互冲突，保留两个条件分支和取舍，不捏造统一结论；超出本 Skill 的类型/年代/媒介/读者条件，说明不能支持的结论，必要时只提供明确标为推断的结构类比；效果与真实用户任务未验证时标 `NOT_PROVEN`。这不是自动触发、自动运行或保证创作效果的程序。


## 0. 这个 Skill 是什么、不是什么

**是什么**：一个把 26 份 Project Gutenberg 叙事作品（共 179,094 行；旧台账的 175,984 行是区间统计，不等于可信 FULL）的**文本现象**转成**可执行设计规则**的规则库与诊断器。各规则必须受本轮 P4 条件性裁决约束；每条规则都给出：触发条件、判断信号、操作步骤、输出、失效条件、反例、来源锚点（PGID + 原文行号 + 逐字短引文）。

**不是什么**（三条硬边界，越界必须声明）：

1. **不是写作教程的作者原话**。本批 26 份来源全部是 `material_role: FICTION_CASE`（小说叙事作品），`edition_note` 明示 "narrative CASE ONLY, not prescriptive craft advice"。规则里的"让你做 X"是从**作品里实际发生了什么**归纳出的设计方法（H/P 级），不是"作者教我们这样做"。
2. **不是中国武侠知识库**。任务归属 04-武侠仙侠玄幻题材，但本批实际材料是西方奇幻/童话/冒险与东方奇谭的英译。**内功修炼体系、门派谱系、江湖秩序、武学境界层级一律 NOT_PROVEN、不在本 Skill 范围内**（与批次-01 结论一致）。
3. **不是历史/民族志来源**。各书的时代偏见（殖民视角、种族刻板、性别本质主义、血统天命论等）一律**仅记录、不蒸馏**，见各 references 末尾"红线"节与 08。

## 1. 触发条件（什么时候用这个 Skill）

满足任一即进入：

- 作者要**设计**：力量/功法体系及其代价；门派、朝堂、宗门的制度压迫与钻营；冒名/错认与揭底；誓言、契约、禁制；奇遇链与试炼序列；恐怖与去魅；结局收束。
- 作者要**诊断**已有稿子的结构问题，典型主诉：
  - "我的主角太强了，冲突没了"→ 01（R001/R002）
  - "反派只有坏，没有重量"→ 02（R020/R022）+ 06（R104/R106）
  - "身份揭底没人信"→ 03（R041/R046/R047）
  - "誓言/契约写了但没张力"→ 04（R060/R062/R067）
  - "旅程变成赶路清单"→ 05（R080/R083）
  - "恐怖写不出来/写出来像闹剧"→ 06（R105/R107/R109）
  - "结尾收不住"→ 07（R132–R145）
- 作者给出一段大纲或正文，要求"按本批证据评估并给出可执行改法"。

## 2. 负触发（什么时候**不要**用这个 Skill）

命中任一必须**先声明不适用**，再决定是退出还是只借局部机制：

- **要写中国武侠的内功/境界/门派谱系/江湖规矩** → 不适用（见 §0 边界 2）。只可借用**与题材无关的结构机制**（如 R060 契约字面主义、R061 镜像惩罚），并注明"机制借用，非题材知识"。
- **要考据真实历史、宗教、民族志、科技史** → 不适用。本批材料的年代/文化陈述不可当事实来源（PG310 的获得性遗传、PG592 的原住民浪漫化、PG3527 篇二的中国想象外壳）。
- **非虚构、学术、商业写作** → 不适用。
- **要沿用本批的时代偏见修辞**（血统天命、种族蔑称、"疯王"精神病隐喻、抢婚本能、婚姻交易化）→ **拒绝**。见 08 红线清单与拒绝出口 F4。
- **要求"这个规则一定有效 / 已实测提高作品质量"** → 不适用。本 Skill 未经真实作者任务验证（GQ5 = NOT_PROVEN），见 §7。

## 6. 失败出口（F1–F5，命中即照此行动，不要硬答）

- **F1 输入不足**：诊断/评估请求没给材料 → 只回「判定」段，列出缺失项与最小可用输入示例，停止。
- **F2 证据不足**：请求的部件在本批 26 源内无可核锚点（例如"内功境界层级"）→ 回：`NOT_PROVEN`，说明本批材料边界（§0 边界 2），并给出**不写为规则**的显式声明。禁止用通用写作常识冒充本批证据。
- **F3 本批内冲突未裁决**：所选部件在本批存在相反裁决（见 08 的 U 系列）→ **必须把两方都给作者**，附各自书号与行号，并给出"按基调选用"的判断依据；**不得择一冒充共识**。
- **F4 触碰红线**：请求要求沿用本批的时代偏见修辞、或要求把红线内容当作技法/事实 → 拒绝，说明该内容在本批仅作历史记录，并给出可替代的中性机制（若存在）。
- **F5 超出体裁**：请求涉及非叙事写作、考据、或真实任务效果验证 → 说明不适用（§2），GQ5 为 NOT_PROVEN（§7），不做效果承诺。
