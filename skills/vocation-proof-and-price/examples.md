# 三个可直接套用的样例（含失败出口样例）

## 样例 A｜P 轴：主角"明明很强却没人理"

**用户给**："我的外科主角技术全书最强，但没人请他，读者说不可信。"

**定轴**：P 轴（证明）。职业引擎强度 A（职业推动主冲突）。

**诊断**（症状 P1）：只有能力门，没有兑现门。

**最小改法 1**：加一位"点头者"——科室主任/转诊网络里的老医生，给他一个利益（他推荐新人会稀释自己的权威）。主角第一次用错策略（直接展示技术），第二次才调整（先接下没人要的夜班病例）。
- 人物成本：主角必须承认自己前三年是在"等被看见"，而不是"在精进"。
- F 支撑：PG1056 ✅L9413-9414（守门人）、PG23108 ✅L2871-2873（雇主压制副业）。

**最小改法 2**：把"技术最强"改成"在某个窄口径上最强"（只做某一种术式），让能力可被第三方复述。
- 人物成本：主角要放弃"全能"的自我形象。
- F 支撑：PG2725 2547-2620（闭门发明一种器械）、2676-2731（同行起立）。

**兑现机器清单**：科室主任（点头 → 得到转诊流量；不点头 → 维持自身权威）｜病人家属（点头 → 得到解释；不点头 → 无损失）｜院方（点头 → 需要一台成功案例做宣传）。
**代价账本**：N/A（本场未触及）。
**收场型**：N/A。
**F/H/P**：诊断与两条改法的支撑为 F；"读者会觉得可信"是 **H**（无读者数据）。
**VERIFY_REAL_WORLD**：转诊机制、术式名称、医院职称体系——本批无当代语料，须另查一手材料。

## 样例 B｜L 轴：职业与关系二选一

**用户给**："女主要么去外地驻场三年，要么留下照顾家人，我写不出选择。"

**定轴**：L 轴（代价）。

**诊断**（症状 L1）：没有付账人，只有"两边都想要"的犹豫。

**最小改法 1**：让**女主自己付账**，且让叙述者承认这是代价——她去了，三年后回来发现关系已被时间改写，不是被谁破坏。
- F 支撑：PG3364 6608-6679（结局旁白仍承认她牺牲了 career；反向用法：让她得到 career 而失去关系，并让旁白承认）。
- 对照：PG8664 5199-5206 / ✅L5348-5350 是"关系吞掉职业并写成胜利"的写法——**两种都成立，取决于你要哪一版的代价**。

**最小改法 2**：让**亲近者付账**——留下照顾的人替她承担了本来不该承担的后果，她因此始终无法把这次选择讲成"牺牲"。
- F 支撑：PG5764 ✅L4508-4519（主张的代价落在家人身上）。

**不要把三种写法混成"兼顾"**：本批三个相反答案（PG8664 关系吞职业→胜利；PG3364 关系吞职业→叙述留下旁白；PG20085 职业吞关系→✅L6584-6585 明确"必须选"）。选一个，写到底。
**F/H/P**：支撑为 F；"这样更有感染力"为 H。
**VERIFY_REAL_WORLD**：驻场制度、外派年限——须另查。

## 样例 C｜E 轴：失明/伤残之后

**用户给**："我的画家主角失明了，后面不知道写什么。"

**定轴**：E 轴（失能）。

**诊断**（症状 E1 + E2）：把失能当成句号，且痛点只写了收入。

**最小改法 1（改换执行方式）**：让她成为另一个人的"眼睛"——不是退出，是把职业的执行方式换掉。先秘密训练，再由第三方告知。
- 人物成本：她必须放弃自己的作品；文本必须**明说**这是放弃，不能悄悄略过。
- F 支撑：PG8664 ✅L5348-5350；5366-5394；5574-5589；✅L6230（被容忍比被嘲笑更难受）；6588（开腹观摩晕倒）。

**最小改法 2（继续做）**：带伤继续，但把"继续"写成一次具体的、有风险的动作，并让她付出关系代价。
- F 支撑：PG2725 ✅L3253-3255；3239-3256。

**痛点三层，选一层写到底**：
- 身份：PG8664 ✅L4862-4865「What _is_ a man without a man's work?... I'd rather be dead!」
- 日常：PG8664 4818-4830（四点听见钟响以为要去工作）
- 关系：PG2876 ✅L6051-6053（同行当着面判他"out of the race"）

**不要写**：失明 → 三个月后靠听觉成为更伟大的画家（训练蒙太奇，症状 E3）。
**F/H/P**：支撑为 F；"读者会被打动"为 H。
**VERIFY_REAL_WORLD**：视觉康复、辅助技术、职业再训练——本批为 1900 年代虚构设定，须另查权威资料。

## 样例 D｜失败出口：只给了职业标签

**用户给**："主角是个医生，帮我诊断一下职业线。"

**命中**：X7（只有职业标签）＋ 部分 N7（无场景）。

**正确输出**（不是硬凑诊断）：
```
定轴：未定（缺职业场景，无法判断 P/L/E）
停止诊断原因：没有可定位的职业场景，无法判断这台"兑现机器"是否存在。
请补三项：
1. 至少一个职业场景（成稿片段或大纲中的一场）
2. 具体职业：岗位名 + 年代 + 地域（"医生"不算）
3. 一句话类型承诺：读者将看到被承认 / 被索价 / 被剥夺 中的哪一种
在补齐之前，本 Skill 不输出任何诊断结论；不自动补手术流程或科室制度（VERIFY_REAL_WORLD）。
```
**理由**：PG351 的菲利普与 PG3364 的 Grace Breen 同为"医生"，职业线结构完全不同——前者是职业选择的反复，后者是性别信任门槛。没有场景就定轴，等于把某一本书的情节设计当成通则。
