# 反例与边界（什么时候不要照本 Skill 的正面建议做）

## 1. 反例：满口术语、零交付（PG2460 是标本用法）

Theobald 能完整拆解一个题材的 form / colour / expression / composition（386-396），二十年未交付，且：
- ✅L196-201：「I have never sold a picture!」
- ✅L406-414：「A great work needs silence, privacy, even mystery」
- 571-581：旁人预言他的画布"只是一团不连贯的划痕与涂渍"（互文 Balzac《未知的杰作》）

**不要把它当"训练不足"来改。** 如果你想写的就是这样一个人，正面建议（补交付、补曝光）会毁掉它。这时应做的是：让读者清楚这是**有意为之的未交付**，并给出代价（贫穷、被嘲笑、自我神话）。

同族反例：PG351 ✅L15434-15438「It would have interfered with my work.」/「What work?」/「My inner life.」——"内在生活"作为拒稿理由是自欺，但文本把它写成自欺而不是笑料，这是处理方式的关键。

## 2. 反例：名声来自你宣称鄙视的东西（PG11584）

Markham 宣称不画"漂亮"肖像（3032-3048），名声却建立在丝绸缎面光泽的经营上；奉承的肖像顾客愿付高价，而他自评那是"一幅相当糟糕的 Markham"（9117-9145）。

**不要"修正"成一致。** 这种自我分裂就是职业线的张力来源。若你把它理顺（让他要么彻底商业、要么彻底清高），人物立刻变扁。

## 3. 反例：制度是可以被改成功的（PG1350）

本批最强的反例，直接证伪"制度永不可改革"：
- ✅L1125-1126：七百人 → 两千人
- 1104-1144 灌溉；1715-1776 制革场/车匠/鞍匠；1869-1933 三集市
- 1152-1210 收费规则：富人自动多付、穷人分文不取

**条件**：写出反对者（教会对迁走白痴病人的攻击、冷枪）、批准者、以及医生自己付的代价（自我惩罚式苦修）。缺任何一项就会变成"强行修复"。

## 4. 反例：改革实验可以自我推翻（PG7502）

跨阶级 Social Union 的本意是融合，结果反过来证明了"阶级联合在当前条件下 impossible"（✅L6123-6126）。牧师 Peck 本人辞去圣职去教书、必要时进厂（7647-7671）。

**不要为了"人物有成长"而让实验成功。** 失败且被诚实记录，比成功更有说服力。

## 5. 反例：不可量化的劣势同样成立（PG3364）

病人一句"我要男医生"（✅L1492-1496）无法量化，却驱动每一次诊疗。
**不要因为"没法写成数字"就删掉这类劣势。**

## 6. 边界：不要把单本机制写成通则

| 只在 1 本出现的机制 | 出处 | 正确用法 |
|---|---|---|
| 完整赛制（场地/观众/战术/绝杀/骨折） | PG13152 2033-2252 | 标 `SINGLE_SOURCE`；其他 22 本的裁决不在赛场 |
| 冷战科幻的"金星代表"最后通牒 | PG25086 484-505 | 不参与职业规则归纳 |
| 破产者戴绿帽示众的立法构想 | PG1942 6077-6091 | 是**角色的主张**，不是史实 |
| 反疫苗政治与疫苗政策 | PG5764 35-55 | 作者自陈是政治预言；任何现实结论 → `VERIFY_REAL_WORLD` |
| 战地记者行会技能清单 | PG2876 682-691 | 讽刺夸张，可作质感写法借鉴，不可当职业要求（`NOT_PROVEN`） |
| "守门人是失败者" | PG1056 ✅9413-9414 | 是 Martin 的角色论断，同书另有机械性解释（`NOT_PROVEN`） |

## 7. 边界：本 Skill 明确不覆盖

- 职业引擎强度定轴（A/B/C）与 F1–F12 失败模式 → 用 `批次-01/profession-competition-craft`
- 逆袭弧（劣势账本、规则性失败、有代价结局）→ 用 `批次-02/competition-underdog-arc`
- 虚构职业（奇幻公会 / 科幻学院）的世界观规则 → 本 Skill 只给可信度结构
- 现实行业合规、医疗、法律、投资 → `VERIFY_REAL_WORLD`
- 当代平台劳动 / 零工经济 → 语料为零（1833–1958）
