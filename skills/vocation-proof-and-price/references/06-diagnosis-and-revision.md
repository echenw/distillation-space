# 06 诊断与改稿表

用法：先定轴（P/L/E，可多轴），再按症状查表。每次只改一层，不要同时重写大纲、人物与文风。
严重度：**致命**（职业不成立 / 主角无决策 / 规则自相矛盾）→ 必须改；**结构**（兑现机器、代价账本、训练、钱、裁决场缺失）→ 优先改；**质感**（术语、行话、物件不足）→ 可后改。

## P 轴症状

| # | 症状 | 诊断 | 最小改法 | 证据 |
|---|---|---|---|---|
| P1 | 主角"明明很强却没人理"不可信 | 只写了能力门，没写兑现门 | 列点头者清单，给每人一个利益 | PG1056 ✅9413-9414；PG15431 ✅12769-12773 |
| P2 | 突破像天上掉下来 | 缺门槛悖论的解法 | 写"无名者必须先被承认才能被承认"，给本作解法 | PG20085 ✅9663-9667 |
| P3 | 裁决者类型选错 | 同行型故事里买热搜 / 市场型故事里靠同行服气 | 先判裁决者（市场/同行/制度），再选自证方式 | PG2876 ✅6510-6519 vs PG1942 7003-7039 |
| P4 | 竞技场只有"激烈" | 把裁决场窄化成赛场 | 写裁决者 + 可复述判准 + 输了失去什么，不要求赛制 | PG13152 2033-2252（本批唯一赛制） |
| P5 | 术语很多却无人信 | 有名词无交付 | 让主角交付一件可复述的成品，或按 PG2460 写成反例 | PG2460 ✅196-201；PG351 ✅15434-15438 |
| P6 | 主角副业被写成人人喝彩 | 雇主/同行通常排斥分心 | 写"雇员应只惦记雇主生意"的压制，副业只能私下推进 | PG23108 ✅2871-2873 |

| # | 症状 | 诊断 | 最小改法 | 证据 |
|---|---|---|---|---|
| L1 | 职业与关系抢人，写成"兼顾" | 没有付账人 | 指定付账者（优先主角或其亲近者） | PG20085 ✅6584-6585 |
| L2 | 行业批判喊口号 | 叙述者宣判而非人物交锋 | 让具体的人执行与反驳，用一个荒谬类比顶回去 | PG7502 ✅7914-7915 |
| L3 | 反派倒台，行业就好了 | 代价只由反派付 | 让主张者本人或其亲近者付代价 | PG5764 ✅4508-4519 |

| # | 症状 | 诊断 | 最小改法 | 证据 |
|---|---|---|---|---|
| E1 | 职业中断后没戏可写 | 把失能当成句号 | 三选一：继续 / 改换 / 退出，选完写到底 | 见 `05-disability-and-exit.md` |

## 改稿输出模板（复制使用）

```
用户文本范围：<章节/场景>
定轴：P / L / E（可多轴）｜职业引擎强度：A / B / C（来自批次-01；未判则写"未判"）
症状编号：<P1/E4/...>
原场景失效证据：F（PG + 行号 + 引文）或 N/A
最小改法 1：<改哪一场>｜人物成本：<谁失去什么>
最小改法 2：<备选>｜人物成本：<谁失去什么>
兑现机器：谁点头 / 他得什么 / 他失什么（N/A）
代价账本：谁付 / 付什么 / 叙述者是否承认（N/A）
收场型：继续 / 改换 / 退出（N/A）
F/H/P 标记：<逐条>
作者目标冲突：<作者明确不准改的场景>
VERIFY_REAL_WORLD：<现实待核清单>
回归核对：<改完后要回看的章节>
```

## 自检三问（改完必答）

1. 我有没有写出**谁点头才算数**？没写 → P 轴未闭环。
2. 这一次胜利/失败，**谁付账**？付完之后叙述者承不承认？没写 → L 轴未闭环。
3. 如果这份职业明天消失，主角**还能自称什么**？答不出 → E 轴未闭环。
