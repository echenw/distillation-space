# 异世界与穿越：机制诊断与设计（批次-01）

面向"主角离开本世界"的小说。**核心判断不是"能不能穿过去"，而是：入口类型、可返回性、代价是否前置、世界是否承认主角的因果律、制度差异是否落地。** 这五项的取值组合决定一部作品是否会塌。

本 Skill 的规则全部来自 27 部已全量核验的公版文本，逐条带来源与行号，见 `references/rule-verdicts.md`。**凡只有一部作品支持的断言都标为 H（推导）或收进 `references/conflicts-and-exceptions.md`，不得当作通则执行。**

## 1. 触发与负触发

**用本 Skill 当**：用户在写/改/评一部小说，且主角发生了下列之一——
- 进入另一个世界、异界、仙境、亡者之域、神话国；
- 位移到另一个时代（未来或过去），无论是装置、休眠、梦还是事故；
- 身体或意识转移到另一星球/种族；
- 进入一个被重新组织的社会（乌托邦、反乌托邦、共同体实验）并被要求遵守其规则。

**不要用本 Skill**：
- 作品不含任何越界要素的写实小说（同批次里 PG2360《The Riddle of the Sands》、PG10882《The Eagle's Shadow》、PG1200《Gargantua and Pantagruel》就是这种，核账里记为"不适用"）。把它们算成异世界证据是错误。
- 只问文字润色、章节节奏、人物对话，与越界机制无关。
- 需要法律意见（版权、公有领域判定）——本 Skill 明确不提供。
- 用户要的是某部具体作品的情节复述或考据，而不是机制规则。

## 2. 输入（必须先拿到什么；缺哪一项就走 §6 失败出口）

1. **越界类型**（五选一，见 `references/mechanism-taxonomy.md` §1）：装置 / 灾害事故 / 器物 / 无入口（被编排或投射）/ 内心投射。
2. **可返回性**（三选一）：可返回 / 不可返回 / 返回即损失（死亡、失忆、被清除）。
3. **代价是否已前置**：主角在越界前是否已被明确告知要付什么。
4. **世界是否承认主角的因果律**：主角带过来的技术、知识、体质差，在这个世界里算不算优势。
5. **制度差异清单**（若写社会设想类）：税/工时/货币/制服/历法/劳动分派 中至少两项的具体写法。
6. **用户真正要的产出**：诊断报告 / 修改方案 / 从零设计 / 规则裁决。

第 1、2、3 项是硬门槛。拿不到就先问，不要替用户假定——本批次里"没说定代价"正是 PG18460 主角失败的直接原因（`references/source-index.md` PG18460 条）。

## 4. 执行步骤

**通用五步（任何路线都要走）**

1. **填 intake 表**——按 §2 六项逐条记下用户的答案；没答的标 `UNKNOWN`，不许猜。
2. **定越界类型**——在 `references/mechanism-taxonomy.md` §1 里对上号；对不上就说明这是未见类型，按"无入口"处理并要求用户补代价。
3. **跑规则体检**——按路线对应的 `rule-verdicts.md` 条目逐条判 PASS / FAIL / N/A。每条必须落在具体章节上，不要给泛泛评价。
4. **查反例**——把判定为 PASS 的条目拿到 `references/conflicts-and-exceptions.md` 里对照；若该条目在本批次内有反例，必须把反例写进输出（这是本 Skill 与"通用写作建议"的区别）。
5. **按 §5 输出合同交付**。

**路线专属动作**

- A（体检）：逐项给 PASS/FAIL/N/A 与行号级修改建议；FAIL 项必须给出"改成什么"，不能只说"这里有问题"。
- B（因果律审计）：先让用户回答"这个世界承不承认主角的因果律"（三档：承认 / 部分承认 / 不承认），再据此决定技术优势的上限；**必须至少写一次失败**（R2 依据：PG18460 L703-750）。
- C（出口设计）：从三态里选一并在开局就声明；之后不得无代价翻转（R3 依据：PG55 L2408-2410 vs PG58798 L1263-1274）。
- D（制度落地）：至少落两项制度细节；风景描写排在第二位（R9 依据：PG44074 L2581-2593、PG44307 L3919-3922）。
- E（解释权）：若保留不可裁决，必须写明"谁在否认、否认到什么程度"（R6 依据：PG66409 L2792-2805 的遗孀条款写法）。

## 5. 输出合同

每份输出都必须含这六块，缺一块就不算交付：

1. **intake 表**：§2 六项，含 `UNKNOWN` 标记。
2. **越界画像**：类型 + 可返回性 + 代价是否前置，一句话。
3. **规则体检表**：每条给 `PASS / FAIL / N/A`，附 `rule-verdicts.md` 的规则编号与依据来源+行号。
4. **反例与分歧**：至少列一条本批次内与该方案相反的作品处理；没有就写"本批次内无直接反例"（不许编）。
5. **可执行修改清单**：逐条写"第 X 章 / 第 Y 处 → 改成什么 → 依据规则编号"。
6. **未证明项**：明确列出哪些判断只有单部作品支持（标 H），哪些是本次没读到的（标 NOT_PROVEN）。

## 6. 失败出口

- **intake 拿不全** → 停在 §2，把缺的项作为问题返回给用户，不要进入体检。理由：R10（代价前置）与 R3（可返回性声明）都依赖开局信息，事后补等于重设计。
- **用户要求"把某部作品的 X 设计当作所有作品都必须遵守的规则"** → 直接拒绝并引 R11 + `conflicts-and-exceptions.md` §5，给出该设计的反例作品。
- **用户的作品不含越界要素** → 退出并说明本 Skill 不适用，不要硬套。
- **需要的判定超出本批次 27 部来源** → 在输出里标 `NOT_PROVEN`，不编造规则；本 Skill 不声称代表整个体裁。
- **涉及版权/公有领域判定** → 说明本 Skill 不提供法律意见，须按文本与司法辖区逐本复核。
