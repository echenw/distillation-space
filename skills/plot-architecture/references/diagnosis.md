# 诊断工作流：从症状到可核对的判断

本文件只负责“已有稿/大纲，要找结构问题”。规划见 `planning.md`，修订见 `revision.md`。规则正文在 `rules.md`；此处只引用 `RC-xx`。

## 0. 前提与权限

- **必须有真实文本**：章节、场次、段落或至少逐章大纲，并能给出章/场/行号。没有原文时，只能给检查清单与空白 `diagnosis-report.md`，不能给“诊断结论”。
- **不自动改稿**：诊断的输出是“定位 + 证据 + 分支 + 严重度 + 建议 + 最小验证动作”；改写要用户明确要求并给范围（见 `revision.md`）。
- **版本要写清**：稿名、版本/日期、总章数/总场数、读了哪些范围。未读部分标 `UNREAD`，不假装全书诊断。
- **读者反应只作线索**：作者/编辑转述的“读者说太巧/中段闷”是线索，不是证据；必须回到文本找可观察事实。

## 1. 诊断顺序：先证伪，再判缺陷

### D0 定范围与版本

写清：文本标识、版本、总长度、实际读过的范围、未读范围。范围不清，严重度一律降一级（最多“建议”）。

### D1 先证伪（强制）

每个症状先问“它可能不是缺陷吗”，至少排除以下解释：

| 可能的“不是缺陷” | 需要什么证据才能排除 | 排除不了时 |
|---|---|---|
| 类型惯例（喜剧巧合、童话奇迹、闹剧误解） | 文本是否明示类型契约；读者是否被提前告知 | 不判缺陷，改问“类型契约是否清楚” |
| 有意为之的实验（开放结尾、静止场、离题、反情节） | 作品是否把“不闭合/不推进”主题化；是否有读法信号 | 标 `UNRESOLVED`，不给“应改” |
| 载体不同（单行本 vs 连载；口述 vs 阅读） | 交付方式；读者是否在段落间离开文本 | 不套错规则（尤其 RC-10） |
| 版本/删节/翻译造成 | 是否有完整版；是否译者/编者改动 | 标 `UNVERIFIED`，不判作者结构失败 |
| 读者/编辑的个人口味 | 是否能指出具体段落与结构后果 | 不升级为“阻断” |

**先证伪的写法**：在报告中写“我试图用 X 解释，但文本缺 Y，因此仍判缺陷”，或“X 成立，撤销该症状”。不能只写“我觉得”。

### D2 收集文本证据

每个症状至少给 3 类事实：

1. **定位**：章/场/行号；引文 ≤40 词或准确转述。
2. **结构事实**：场初/场末状态、人物欲求、阻力、信息分布、承诺是否兑现。
3. **后果**：读者因此不知道什么/不信什么/不再等什么。后果要能回指具体段落，不用“读者会觉得无聊”这种概括。

### D3 映射规则与分支

按症状查下表，再读对应 `RC` 的分支；不要用一条规则解释所有症状。一个症状可能对应 2–3 条规则，按“最直接的那条”先判，其余列为“同时检查”。

**场景多时（中段塌、场景无功能、群像/多线）先填 `templates/scene-table.md` 的 `ST-01`–`ST-08`（场号/POV/欲求/阻力/场末变化/功能/后文调用点/处置）；连载或分幕作品的章末检查填 `ST-14`–`ST-19`。** 场景表是收集事实的工具，判定仍回到本文件的症状与严重度口径。

### D4 定严重度与最小验证动作

严重度见 §2；最小验证动作必须是**人工可执行、能证伪判断**的动作（写一句话、删一段试读、列事件表、做删线测试），不是“再改改看”。

### D5 给建议与回归检查

建议只写“改哪里、改成什么结构关系、为什么”；不写整段重写。回归检查列出“改后必须重跑哪条规则/哪张表”。

## 2. 严重度口径

| 级别 | 判据 | 典型例子 | 处理 |
|---|---|---|---|
| **阻断** | 读者无法建立基本契约或结局无法成立；不修则作品不可读/不可信 | 首章读完仍说不出谁要什么；结尾靠一个同时解决三个问题的巧合；主线承诺完全未兑现；判断权在结尾自相矛盾 | 先修；修前不做局部润色 |
| **重要** | 结构成立但中段/多线/章末明显失效；修后可读性显著变化 | 连续三场无变化无功能；双线无共同问题也无对照；连载章末连续三章同一问题；结尾有 1–2 条副线欠账 | 排入修订；可与阻断项一起修 |
| **建议** | 局部效率/节奏问题；不改也能成立 | 单场可并入相邻场；一个假钩子；一处过场太长；一个次要承诺兑现场偏晚 | 有余力再修；不掩盖阻断项 |

**升级规则**：同一症状出现 3 次以上（连续三场无功能、连续三章同问题、连续三次靠巧合）→ 升一级；出现在开篇/结尾/主线 → 升一级；只出现在副线且不影响主落点 → 降一级。

## 3. 症状索引

| 症状 | 首选规则 | 同时检查 | 默认严重度 |
|---|---|---|---|
| 开篇无契约 | RC-04 | RC-01、RC-09 | 阻断 |
| 中段塌 | RC-07 | RC-01、RC-10、RC-13 | 重要（连续三场则阻断） |
| 巧合解结 | RC-06 | RC-05 | 阻断（解结处；开局巧合不判） |
| 多线失焦 | RC-08 | RC-01 | 重要（无共同问题则阻断） |
| 章末无力 | RC-10 | RC-09 | 重要（连载）；单行本不判 |
| 结尾拖沓/欠账 | RC-11 | RC-04、RC-12 | 欠账阻断；余赘重要/建议 |
| 判断权分裂 | RC-12 | RC-11 | 重要（结尾自相矛盾则阻断） |
| 场景无功能 | RC-07 | RC-14 | 建议（连续三场则重要） |

## 4. 逐症状诊断

### 4.1 开篇无契约

**可观察证据**
- 首段/首场只有环境、履历、议论、世界观说明；找不到一个正在发生的动作或一个可陈述的欲求。
- 读完首章，仍不能说出“谁要什么、被什么挡、这是什么类型”。
- 首段信息密度高，但删掉后读者对故事的理解不变（说明它没有承担契约）。
- 基调与结尾相反且无对照意图（例如开篇滑稽、结尾肃穆，但无过渡）。

**可能规则**：RC-04（主）；RC-01（主行动是否清楚）；RC-09（是否把“延迟揭示”误当“延迟契约”）。

**分支判断**
- A 动作开场：首句是动作/异常事实 → 检查动作是否服务主角欲求；若只是路人打架，仍不合格。
- B 人物开场：首句是能定性格的台词/习惯动作 → 检查欲求是否在首段出现；只有怪癖没有欲求，不合格。
- C 环境开场：首段有可感细节 → 检查同段是否引入人与其欲求；没有则不合格。
- 若作者主张“延迟揭示”：只允许藏答案，不允许藏问题；首章内必须给“我在等什么”。

**最小验证动作**：把首段遮住，从第二段读起，问“我知道谁要什么吗”；再恢复首段，问“首段是否让我更清楚，而不是更糊涂”。两次都答不出 → 契约缺失。

**输出严重度**：阻断（首章契约缺失）；若首章末已补出契约，仅首段不合格 → 重要。

**建议修改方向**：把背景后置或压进动作/对白；首句只服务一个主元素；给一句可复述的欲求；不要用“神秘感”代替契约。

---

### 4.2 中段塌

**可观察证据**
- 连续三场/三章：场末局面与场初相同，功能栏空白或只写“氛围”。
- 支线人物增多，但没有一条支线能说出“推进主行动哪一步”。
- 读者/编辑说不出“现在离终点更近了吗”。
- 重要事件挤在前两章或最后两章，中段只剩重复的追逐/对话/回忆。

**可能规则**：RC-07（主）；RC-01（副线挂载）；RC-10（连载章末）；RC-13（容器与中段配比）。

**分支判断**
- A 推进：场末有决定/揭示/关系变化/损失 → 不是塌，可能只是节奏慢；转查 RC-10。
- B 非推进但有功能：铺垫/揭示/松气/主题回声/时间跨越 → 功能必须在后文被调用；调用点找不到 → 仍算 C。
- C 无功能：删掉后无一处需补写 → 删并；连续三场 → 中段结构问题。
- 若副线挂不上主行动 → 先按 RC-01 改挂/删并，不要用“加快节奏”掩盖结构缺失。

**最小验证动作**：任选连续三场，逐场写“场初状态 → 场末状态”；三场都相同，再做“删场测试”：删掉中间一场，后文是否有因/回声受损。无受损 → C。

**输出严重度**：重要；连续三场 C 或中段占全篇 40% 以上且无推进 → 阻断。

**建议修改方向**：合并同功能场；把“铺垫”改成“带阻力的行动”；给中段一个不可逆的小结算（RC-03 的章级小解结）；按容器压缩副线数（RC-13）。

---

### 4.3 巧合解结

**可观察证据**
- 解结处出现：电报、临终忏悔、偶遇、误认、失散亲人重逢、恰好听到关键话、恰好有钥匙。
- 该巧合同时解决两个以上独立问题（如“找到凶手 + 洗清主角 + 恢复继承权”）。
- 前文没有对应的恩惠/物件/信息；也没有同量级异常副线；世界规则未明示。
- 删掉巧合，结局立刻不成立（说明它是承重，不是装饰）。

**可能规则**：RC-06（主）；RC-05（事件是否由前文推出）。

**分支判断**
- A 开局/加压：巧合把人物推入麻烦 → 可接受，不判缺陷；只检查它是否给了人物一个真问题。
- B 解结：巧合替人物解决麻烦 → 必须走 B1 前债 / B2 配平 / B3 世界规则。
- B1：前文是否施恩/赠物/透露信息，且与破障同域？有 → 合法；无 → 补付账。
- B2：主线是否本身是孤例，且有一条同等异常、可信的副线作保？有 → 合法；无 → 补配平或改因。
- B3：作品是否明示“这类事在此世界会发生”，且规则前后一致？有 → 合法；无 → 不能临时立法。
- 三条都做不到 → 改因（让主角自己造成）或改果（让巧合失败）。

**最小验证动作**：列“巧合清单”：位置、解决几个问题、前文付账处、路径。若“解决 ≥2 个独立问题”且“付账处”为空 → 判阻断。

**输出严重度**：解结处 → 阻断；中段用于加压 → 建议/不判；喜剧/童话且类型契约明示 → 不判，最多建议“别让巧合同时解决太多”。

**建议修改方向**：优先 B1（最便宜）：把巧合改成前文已出现的人/物/信息；B2 只适合主线本来离奇的作品；B3 只适合奇幻/童话；都不行则改因/改果，不换一个更巧的机关。

### 4.4 多线失焦

**可观察证据**
- 两条线各自有主角/欲求/终点，但读者说不出“它们共同在问什么”。
- 两条线在事件上零接触；只有主题词相似。
- 结尾各自收束，最后一章像两篇短篇拼在一起。
- 删掉一条线，另一条结局完全不变（B 型）或主线直接不成立（其实是 A 型承重线）。

**可能规则**：RC-08（主）；RC-01（副线挂载）。

**分支判断**
- A 因果汇合：存在一个事件同时结算两线 → 检查该事件是否真的“同时”结算，而不是先结一条再结另一条。
- B 对照并置：无共同事件，但共享一个问题（中点照面可选，不是判型条件）→ 检查共享问题是否能用一句话写出；写不出 → C。
- C 伪多线：只是“同时发生”，无共同问题、无交汇 → 合并为一条，或改成“同时性编织”（只求读者看出同时发生）。
- 短篇强戏剧故事 → 多线不合法（RC-01 失效条件 3），直接判 C。

**最小验证动作**：做“删线测试”：删掉一条线，重述另一条的结局；改变 → A；不变但失去对照 → B；完全无影响 → C。再做“一句话共享问题”测试；B 型写不出 → 降 C。

**输出严重度**：重要；B 型无共享问题、A 型无共同事件却硬收在一起 → 阻断。

**建议修改方向**：A 型补“共同落点”，倒推两线起点；B 型补共享问题与各自收束（中点场可选，不强制）；C 型合并或改同时性编织。不要用“主题相似”宣布统一。

### 4.5 章末无力

**可观察证据**
- 章末只是把句子切断，或重复“欲知后事如何”，没有新问题。
- 连续三章末是同一问题（“他能救出她吗”），中段没有新信息。
- 重要事件挤在前两章，后面章末只剩日常。
- 章末问题是假问题：下一章开头就自动消失，没有代价。

**可能规则**：RC-10（主）；RC-09（问题是否早给）；RC-03（全篇解结时点）。

**分支判断**
- 先判载体：A 分次交付（分章连载/分幕/日更；有声书分章只作载体类比，标 H）→ 章末应有真问题；B 一次性交付（单行本）→ 章末可收束，不判“无力”。
- A 型：章末问题属主线还是副线？两者都可以，但必须是“下一章要回答”的真问题。
- 连续三章同一问题 → 不是钩子弱，是中段无进展；转 RC-07/RC-01。
- 章末问题下一章开头自动消失 → 假悬念；删掉或改成有代价的问题。

**最小验证动作**：把每章末最后一段单独抄出，遮住下一章，问“我现在必须读下一章吗？为什么？”；答不出“要回答的具体问题” → 假钩。连续三章同一答案 → 中段问题。

**输出严重度**：连载 → 重要；单行本 → 不判（最多建议删假钩）；连续三章同问题 → 重要偏阻断。

**建议修改方向**：把“总结句”改成“新事实/新决定/新代价”；问题必须能在一两章内部分回答；不按字数机械埋点；单行本删掉为钩而钩的句子。

### 4.6 结尾拖沓/欠账

**可观察证据**
- 欠账：读者仍在问“到底谁/结果如何/那条线呢”；开篇承诺没有兑现场。
- 余赘：主承诺已兑现，后面还在写“后来他升职/结婚/搬家”；删掉后故事仍成立。
- 多线长篇：末章逐线交代，但每段只是“下落”，没有结算一个变化。
- 结尾引入新问题/新人物/新威胁，冲淡主承诺。

**可能规则**：RC-11（主）；RC-04（承诺是否在开篇给出）；RC-12（判断权是否在结尾变更）。

**分支判断**
- A 欠账：承诺未兑现且非故意 → 不是留白，是失败；补结算或回改开篇。
- B 余赘：承诺已兑现，仍在写 → 找“效果完全达成”的句子，试删其后全部。
- C 多线长篇：允许收束段，但每段须结算一条线；只交代下落 → 余赘。
- 故意不兑现 → 必须让“不兑现”成为主题并在末段明示；不能假装兑现。

**最小验证动作**：列“开篇承诺 → 兑现场 → 状态”三列表；再从结尾往前逐段删，删到“变化已发生、代价已付”的那句为止，读一遍；若删后更完整 → 原文余赘；若删后出现“后来呢” → 原文欠账。

**输出严重度**：欠账 → 阻断；余赘 → 重要（超过全篇 10%）或建议（一两段）；多线收束段只交代下落 → 重要。

**建议修改方向**：先补欠账，再删余赘；不要用“尾声”掩盖未结算的主线；多线收束每段必须有一个变化/代价，不是履历。

### 4.7 判断权分裂

**可观察证据**
- 一边用叙述者明说“他这样做是对的/坏人不配好下场”，一边在结尾留白、拒绝判断。
- 结局奖惩结构与叙述者的道德宣言相反（说“善恶有报”，实际好人倒霉且无反思）。
- 反讽作品没有任何“读法信号”，读者不知道作者站哪边；或儿童读物突然出现成人式犬儒。
- 删掉最后一段议论，故事意义完全改变（说明判断权原本靠议论撑着，事件没有承担）。

**可能规则**：RC-12（主）；RC-11（结尾承诺/效果）；RC-05（人物转向是否有因果）。

**分支判断**
- A 叙述者裁决：有明示评断，结局按奖惩结算 → 检查是否与目标读者共识一致；不一致 → 改结局或改读者群。
- B 事件裁决：无明示评断，后果承担评价 → 检查后果是否足够清晰；需要旁白解释才懂 → 不是 B，是 A 没写清。
- C 读者裁决：多视角、拒绝结论 → 检查是否有“读法信号”；没有 → 易被误读，补一个画面/选择。
- 一边说教一边留白 → 判断权分裂；必须选一个，删掉不属于它的评断句。

**最小验证动作**：标出全篇所有评断句与奖惩结构；删掉最后一段议论，重读；意义仍成立 → B/C；意义崩塌 → A（或补事件后果）。再看 A 的奖惩是否与目标读者共识一致；不一致就是价值冲突，不是技法问题。

**输出严重度**：重要；结尾同时宣布两种相反判断、或儿童/类型契约被违背 → 阻断。

**建议修改方向**：先选判断权（A/B/C），再删不相容的评断句；A 型不要假装留白，C 型不要偷偷说教；价值立场交作者，本 Skill 只检查一致性。

---

### 4.8 场景无功能

**可观察证据**
- 场末与场初相同：没人做决定、没揭示、没关系变化、没损失。
- 功能栏只能写“氛围/很美/介绍背景”，且后文没有调用点。
- 删掉该场，后文不需要补写任何过渡。
- 连续三场都是“人物聊天/走路/回忆”，没有阻力。

**可能规则**：RC-07（主）；RC-14（删并）；RC-01（该场是否服务某条线）。

**分支判断**
- A 推进：有变化 → 保留，写清变化。
- B 非推进但有功能：铺垫/揭示/松气/主题回声/时间跨越 → 必须能指出后文调用点；指不出 → C。
- C 无功能：删或并入相邻场。
- 静止场/纯抒情场：若功能是“思辨密度/音乐性”，在功能栏写明，并确认全剧另有推进机制；不能连续三场都靠这个理由。

**最小验证动作**：做“删场测试”：删掉该场，读前后两场；若衔接不需要新写过渡 → C；需要一句过渡 → 可能 B（承重的铺垫/时间跨越）；需要整段补写 → A。

**输出严重度**：建议；连续三场 C、或该场占全篇 15% 以上 → 重要；删掉后主线断裂 → 不是 C，回 RC-01。

**建议修改方向**：C 类先并入相邻场，不能并则删；B 类补“后文调用点”，否则降 C；A 类把变化写清，不要用“气氛”掩盖没有事件。

## 5. 专项：不能只凭印象判 OOC/崩坏

“人物崩了”是最容易被滥用的诊断。判 OOC 之前，必须能给出以下四项事实；缺任何一项，只能判“动机未展示”，不能判“人物不一致”。

| 项 | 要写什么 | 缺了会怎样 |
|---|---|---|
| 1. 已建立的人物事实 | 此前哪一章/哪一场显示他的欲求、恐惧、底线、说话方式；给行号/引文 | 缺 → 可能只是读者没读到，不是人物崩 |
| 2. 触发压力 | 本场发生了什么新事件/新代价；压力是否足够大 | 缺 → 人物没有理由改变，判“作者意志”而非 OOC |
| 3. 可选行动 | 本场他至少还有一个符合旧性格的选择；他为什么没选 | 缺 → 无法证明“违背”，只能证明“没写清” |
| 4. 代价与后果 | 这次选择让他失去什么；后文是否承认这个代价 | 缺 → 改变没有重量，属于“转折未落地” |

**三种要分开**
- **OOC（不一致）**：第 1 项成立，第 2 项没有足够压力，第 3 项存在更符合旧性格的选择，文本却选了相反 → RC-05 的 B 类“外部偶然/作者意志”。
- **成长/反转（合法）**：第 1 项有种子（哪怕很小），第 2 项压力足够，第 4 项付出代价 → 不是 OOC，最多是“转折铺垫不足”。
- **动机未展示（呈现问题）**：第 1 项或第 3 项缺失，读者看不出理由 → 补一场“选择前的压力/代价”，不要改人物性格。

**最小验证动作**：把该人物在转折前后的两场戏并排，写“他要什么/怕什么/放弃什么”；再写“如果他是旧性格，本场会怎么做”；两种做法都成立且文本没有给压力 → 判“动机未展示”，不判崩坏。

## 6. 诊断报告的最小输出

用 `templates/diagnosis-report.md`，至少填 `DR-01`–`DR-10`；报告级未决项与证据缺口汇总到 `DR-SUM`（不是 `DR-10`，后者是每条发现的未决项）。

- 范围与版本、文本证据（章/场/行）、症状、适用规则、分支判断、严重度、最小验证动作、建议修改、回归检查、未决项。
- 每个症状一行；同一段文本只报一次，不按“症状数”重复计费。
- 未读范围、无法核实的版本、读者转述，全部进“未决项”，不混进结论。
- 场景多时同时填 `templates/scene-table.md` 的 `ST-01`–`ST-08`；连载/分幕的章末检查填 `ST-14`–`ST-19`；做了删场测试则填 `ST-20`–`ST-24`，结论回写 `DR-09` 回归检查。

## 7. 诊断阶段的禁止项

- 不凭印象判“OOC/崩坏/读者会弃书”；没有四项事实就不下这个结论。
- 不把类型惯例（喜剧巧合、童话奇迹、连载钩子）判成结构缺陷；先过 D1 证伪。
- 不用“节奏慢/不够抓人”代替具体证据；必须指出哪一场、缺什么变化、后果是什么。
- 不把单来源参数（3/4、中点照面）当硬指标；它们只作默认值/可选项。
- 不诊断未读的章节；不把大纲的推测写成文本事实。
- 不在诊断阶段直接重写全文；改写另走 `revision.md` 并需用户授权范围。
