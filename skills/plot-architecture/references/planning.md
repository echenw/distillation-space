# 规划工作流：从素材到可写的骨架

本文件只负责“还没有稿，或只有素材/大纲”的规划。诊断既有稿见 `diagnosis.md`，修订见 `revision.md`。规则正文在 `rules.md`；此处只引用 `RC-xx`，不复制条件与反例。

## 0. 先收输入（四项，缺一不可假装齐）

规划不是从“写什么”开始，而是从“手上有什么”开始。先填下表；未知就写 `UNKNOWN`，不要用推测补成事实。

| 输入项 | 要问作者/编辑 | 已给（填写） | 缺失时怎么办 |
|---|---|---|---|
| 点子/素材 | 一句话说清“谁、想做什么、被什么挡”；或给一个画面/新闻/人物 |  | 只做 RC-16 的三要素卡，不进入结构 |
| 容器 | 载体、总字数/时长、章/幕数、交稿或连载节奏 |  | 标 `UNKNOWN`；按 RC-13 的 B 支自定预算，并注明“暂定” |
| 目标读者 | 年龄、类型期待、读者契约（要教训/要开放/要连载追读） |  | 标 `UNKNOWN`；RC-12 暂不裁决，只列选项 |
| 作者工序 | 已有大纲？只在脑中？边写边找？ |  | 按 RC-15 三问现场判定；答不出默认 A（外部大纲） |

**判断信号**：四项至少各有一句具体值（可标 `UNKNOWN`，但要知道缺哪项）。
**写不出的失败出口**：缺点子/素材 → 只做三要素卡；缺容器 → 自定预算并标“暂定”；缺目标读者 → 判断权只列选项；缺工序 → 默认 A。
**输出字段**：输入表（四项）+ `PA-01`（工序/版本）+ `PA-07` 容器暂记（未知则 `UNKNOWN`）。

**输入权限**：只处理用户提供的真实文本、大纲、章节或明确口述的素材。用户没有给原文时，最多给检查清单与空白模板，不虚构人物、事件、结局，不声称“已诊断”。

## 1. RC-16：三要素与矛盾句（入口自由）

**判断信号**
- 能写出三行具体的话：`谁（要什么/怕什么）`、`做什么（一个可拍成画面的动作）`、`在什么条件下（时间/地点/规则/阻力）`。
- 能写出矛盾句：`A 想要 X，但 Y 使 X 不可能`。
- 素材里有一个真正的反转/矛盾，不只一个“奇观”。

**写不出的失败出口**
- 三行有一行空 → 回素材层补，不进结构；输出只填 `PA-02` 的三要素卡，其余字段 `UNKNOWN`。
- 矛盾句写不出 → 判断“素材无戏”；请作者换素材或补冲突，不替作者编一个。
- 只有世界观/设定/奇观 → 明确说“还不能写情节”，给三条补素材的问句（谁要什么、谁阻挡、失败代价是什么）。

**输出字段**：`PA-02` 三要素卡 + 矛盾句 + 入口类型（A 人物 / B 事件 / C 胚情节）。

## 2. RC-01：一句主行动与副线挂载

**判断信号**
- 能写出一句：`某人想要 X，因为 Y 受阻，最终在 Z 事件上结算`。
- 每条副线能写出一句“它把 X 推进/阻断了哪一步”。
- 删掉任一副线，主落点仍“被挣得”（变轻但不倒）。

**写不出的失败出口**
- 主行动句写不出 → 退回第 1 步；不要用“本作探讨人性”之类主题句冒充主行动。
- 副线标不出挂载步 → 先试改挂（换动机/换时序），不能则删、并或降为过场；不保留“主题相似但事件零接触”的线。
- 两条线各有独立终点且无共同事件 → 不强行合并；转 RC-08 的 B 型（对照并置），写共享问题与各自收束（中点场可选，不是 B 型成立条件）。

**输出字段**：`PA-03` 主行动句 + `PA-04` 逐线挂载表（线名/终点/挂载步/承重或对照/删并建议）。

## 3. RC-15：工序选择（纸面/心中/发现）

**判断信号**
- 能回答三问：终点是什么？中点转折是什么？谁在推进？
- 作品是否闭合型、是否多线、是否有硬容器、是否多人协作。
- 作者过往完成率与改稿轮数（作者自述，标“自述”）。

**写不出的失败出口**
- 三问有一问答不出 → 先补答案，再选工序；不把“我不写大纲”当风格。
- 作者选 C（发现式）但作品是闭合型/多线/硬容器 → 记录风险：完稿后必须补 RC-05 审计；不强迫改工序，但把“结尾靠巧合”的风险写进 `PA-12`。
- 多人协作/接龙 → 只能定“本卷终点”，不假装全系列终点已知。

**输出字段**：`PA-01` 工序（A/B/C）+ `PA-05` 终点句（暂用）+ 中点转折句（暂记 `PA-12`，定稿后进 `PA-06`）+ 改稿审计责任。

## 4. RC-02：终点句与倒推链

**判断信号**
- 能写出一句：`谁，在什么事件后，失去/得到什么，且不可撤销`。
- 能逐段回答“读者必须先知道什么，才会相信这一步”。
- 终局是“意外但唯一正确”：读者不易想出第二个同样成立的结局。

**写不出的失败出口**
- 终局句写不出 → 先判作品是否 B 型（开放/探索）；是 → 不强行终点先行，改在完稿后做 RC-05；否 → 停在这一步，不进入场景分配。
- 终局可被任意改写而不影响前文 → 前文没有为它积势；先补“积势动作”，不要靠结尾加解释。
- 终局需要新增一个前文从未出现的人物/规则才能成立 → 回第 1 步补素材或改终局；不在结尾空降。

**输出字段**：`PA-05` 终局句 + 倒推链（段/章 → 必须先知道的事实）+ 删并清单。

## 5. RC-03：起点、打结、解结三点时间轴

**判断信号**
- 能写三行：`起点（第一场发生在哪一刻）`、`打结（哪件事让局面不可逆）`、`解结（用什么手段、在第几场）`。
- 能判型：A 单场次/观众预知；B 散文虚构要后果；C 商业舞台看成不成；D 命题推演。
- 观众对“事情办完”的定义是否包含埋葬/审判/清算。

**写不出的失败出口**
- 三行写不出 → 回第 4 步；没有终局就没有“解结”。
- 判型犹豫 → 用两个候选时间轴各写一遍，比较“前史是否过长/解结是否只剩两页/是否开场泄底”；仍不能判 → 标 `PA-06 = UNKNOWN`，按 B 的默认值试排，但在 `PA-12` 记“未定”。
- 作品是连载单章 → 不套全篇 3/4；改用 RC-10 的章末小解结。

**输出字段**：`PA-06` 三点时间轴 + 类型判定（A/B/C/D）+ 需挪动的场次。**3/4 只作 B 型默认值，不是硬门。**

## 6. RC-13：容器参数与分段预算

**判断信号**
- 容器有硬参数：载体、总词数/总时长、章/幕数、单章上限、交稿/更新节奏。
- 现有素材的体量能与容器对上；各部分有配比。
- 分段大致相等；若有一段更长，应是中段（PG36837 L2955-2957，默认值）；不写死百分比，不取历史数字平均值。
- 超出容器时，作者愿意二选一：删内容或换容器。

**写不出的失败出口**
- 没有任何容器 → 走 B 支：自定预算并显式写“暂定”；不编造“行业标准”。
- 只有历史数字（7,500 词/32 页/3,000–6,000 词/10–20 章）→ 只放“历史参数”栏，不作当代规范；不取平均值。
- 容器与故事体量冲突（如 8,000 词要装五条线）→ 先按 RC-13 缩放粒度（减副线/配角/场景），不删因果脊；仍装不下 → 换容器或改故事规模，让作者选。

**输出字段**：`PA-07` 容器参数表 + 分段预算（段/章 → 词数/场数）+ 超限处置。

## 7. RC-04：开篇契约

**判断信号**
- 首段/首场能复述：谁要什么、被什么挡、这是什么类型。
- 首句主元素可辨（动作/人物/环境），基调与结尾同一调性。
- 删掉首段，读者仍知道“这是什么故事”。

**写不出的失败出口**
- 契约句写不出 → 开篇不合格；不要用“氛围很美”通过；回第 2 步确认主行动。
- 首段只有背景/履历/议论 → 把背景后置或压进动作/对白；不在首段加“悬念句”冒充契约。
- 采用延迟揭示 → 确认“问题”已给、“答案”才藏（RC-09）；否则读者不知道在等什么。

**输出字段**：`PA-08` 首段契约句（谁/要什么/挡什么/类型）+ 主元素 + 基调词 + 后置背景清单。

## 8. RC-08：多线汇合（仅多线时）

**判断信号**
- 两线各自一句“谁要什么、终点是什么”。
- 是否存在一个动作同时结算两线（婚礼/审判/死亡/揭露）。
- 若没有：两线是否共享一个问题；中点是否有跨线照面（可选，不参与 A/B/C 判型）。

**写不出的失败出口**
- 判不出 A/B → 先做“删线测试”：删掉一条，另一条结局是否改变；改变 → A，不变但失去对照 → B，完全没有影响 → C（伪多线，合并或改同时性编织）。
- 两线只有“同时发生” → 不宣布“多线结构”，按 C 处理。
- 短篇强戏剧故事 → 不插支线（RC-01 失效条件 3）；多线本身不合法。

**输出字段**：`PA-04` 增补汇合类型（A/B/C）+ 两线终点 + 共同落点或共享问题 + 各自收束（中点场可选，不设也成立）。

## 9. RC-09 / RC-10：信息差与章末钩（按载体）

**判断信号**
- 读者能说出“我在等 X”；主线策略是 A 悬念或 B 惊奇，同一线程不混用。
- 若为分次交付：每章末有一个“下一章要回答”的真问题；重要事件分布均匀。
- 若为一次性交付：章末可收束，不必抛钩。

**写不出的失败出口**
- 读者不知道在等什么 → 回第 7 步补“问题”（inkling）；不要靠藏信息制造惊奇。
- B 型惊奇没有可回看的线索 → 补两处前文线索，或改成 A 型悬念。
- 单行本被要求“每章留钩” → 拒绝；按 RC-10 的 B 支改为阶段性收束。
- 连续三章同一问题 → 中段无进展；回第 2 步检查副线/人物关系是否推进。

**输出字段**：`PA-09` 信息差表（谁知道什么/读者知道什么/何时知道）+ 主线策略（A/B）+ inkling 位置 + 兑现场 + 回看线索清单；如连载，再加 `ST` 表的章末问题列。

## 10. RC-11 / RC-12：结尾承诺与判断权

**判断信号**
- 开篇承诺能逐条列出（欲望/谜题/威胁/关系），每条有兑现场或“故意不兑现”的理由。
- 能指出“效果完全达成”的那一句；删其后段落，故事仍成立。
- 判断权能三选一：A 叙述者裁决 / B 事件裁决 / C 读者裁决；全篇评断句与奖惩结构一致。

**写不出的失败出口**
- 承诺列不全 → 回第 7 步重读开篇契约；不能凭记忆列。
- 承诺未兑现且非故意 → 补结算场或回改开篇承诺；不把欠账说成“留白”。
- 判断权选不出 → 这是价值决定，交作者；本 Skill 不替作者选道德立场，只要求“选一个并保持一致”。
- A 型奖惩与目标读者共识不一致 → 改结局或改读者群，不硬写“善恶有报”。

**输出字段**：`PA-10` 承诺结算表（承诺/兑现场/状态）+ 截断点 + 回补理由 + `PA-11` 判断权声明（A/B/C）+ 评断句清单 + 奖惩结构表；未决的价值问题进 `PA-12`。

## 11. RC-07：首轮场景表（可选，但推荐）

**判断信号**
- 已有章/场清单；每场能填“谁要什么/阻力/场末变化/功能类型”。
- 每场至少有一个后文调用点，或明确标“过场”。

**写不出的失败出口**
- 还没有场景，只在大纲层 → 不编场景；只输出 `PA-03` 的挂载表，场景表留到初稿后。
- 场末无变化且功能空白 → 标 C（删并）；连续三场只有氛围 → 节奏风险，回第 5 步检查打结点。
- 单场只服务一条副线 → 按该线判“变化”，不按全篇判。

**输出字段**：`templates/scene-table.md` 的 `ST-01`–`ST-08` 首轮表（可只填已存在的场）。

## 12. 规划顺序清单（可逐项打勾）

使用法：每步完成后在“状态”栏写 `DONE` / `PARTIAL` / `UNKNOWN`；`UNKNOWN` 不得当成 `DONE`。通过标准是“能拿出该步输出字段”，不是“感觉想清楚了”。

| # | 步骤 | 规则 | 必须拿出的输出 | 通过标准 | 写不出时的出口 | 状态 |
|---|---|---|---|---|---|---|
| 1 | 收输入 | — | 点子/容器/读者/工序四项表 | 四项均有值或明确 `UNKNOWN` | 只做三要素卡，不进结构 |  |
| 2 | 三要素 | RC-16 | 三要素卡 + 矛盾句 + 入口类型 | 三行各是一句具体的话；矛盾句成立 | 回素材层，不编情节 |  |
| 3 | 主行动 | RC-01 | 主行动句 + 逐线挂载表 | 每条线能标“推进哪一步”；删线测试通过 | 删/并/改挂；或转 RC-08 B 型 |  |
| 4 | 工序 | RC-15 | 工序声明 A/B/C + 终点句 + 中点转折句 | 三问能答；工序与作品类型不冲突 | 先补终点/中点；答不出默认 A |  |
| 5 | 终点 | RC-02 | 终局句 + 倒推链 | 终局不可逆；倒推每段有“必须先知道” | 判 B 型或停在结构前 |  |
| 6 | 时点 | RC-03 | 起点/打结/解结 + A/B/C/D | 三点能落在具体场次；判型有判据 | 标 `UNKNOWN`，按 B 试排并记未定 |  |
| 7 | 容器 | RC-13 | 容器参数表 + 分段预算 | 总量与分段能对上；超限有处置 | 自定预算并标“暂定”；不编标准 |  |
| 8 | 开篇 | RC-04 | 契约句 + 主元素 + 基调 + 后置背景 | 首段能复述谁/要什么/挡什么/类型 | 回主行动；不合格不写开篇 |  |
| 9 | 多线（如适用） | RC-08 | 汇合类型 + 两线终点 + 共享问题或共同落点（中点场可选） | 删线测试能判 A/B/C | 合并或改同时性编织 |  |
| 10 | 信息/章末（如适用） | RC-09 / RC-10 | 信息差表 + 章末问题清单 | 读者能说出在等什么；每章末是真问题 | 补 inkling；单行本删钩 |  |
| 11 | 结尾/判断权 | RC-11 / RC-12 | 承诺结算表 + 截断点 + 判断权声明 | 每条承诺有状态；判断权三选一 | 欠账补结算；判断权交作者 |  |
| 12 | 场景表（可选） | RC-07 | `ST-01`–`ST-08` 首轮表 | 每场有变化或写明功能 | 无场景则留到初稿后 |  |

**最小交付集**：`PA-03`（主行动 + 挂载表）、`PA-05`（终点句）、`PA-06`（三点时间轴）、`PA-07`（容器）、`PA-08`（开篇契约）、`PA-11`（判断权）+ `PA-12`（未决项）。其余字段可先 `UNKNOWN`，但要在 `PA-12` 列出“还缺什么、由谁决定”。

## 13. 规划阶段的禁止项

- 不替作者决定道德立场、结局善恶、读者群；只给选项与代价（RC-12）。
- 不把历史篇幅数字当当代标准（RC-13）。
- 不把“3/4 高潮”“中点照面”写成硬门；它们分别是 B 型默认值与可选结构（RC-03、RC-08）。
- 不在缺少原文时编造人物、场景、对白或“诊断结论”。
- 不把规划表当成作品质量保证；表格只检查结构缺口，效果仍未验证（NOT_PROVEN）。
