# 信物经济 + 道具时机（A/F 族细则）

来源主锚：PG503/PG640（Lang 族，双卷合并）、PG51219、PG5745、PG10892、PG71370、PG23344、PG72938。

## A 族：信物经济学

### A1 信物梯度系统
- 触发：需要一条跨越年度/多阶段的长程线索。
- 操作：①设三级递增材质或品类（铜→银→金；苹果→梨→李）；②每年/每阶段发一枚，同时标记时间与价值层级；③主角贴身保管、展示但不解释；④终局把全套亮出，完成身份揭示（三苹果=三年=真公主）。
- 输出：读者可数的等待感；终局的身份铁证。
- 失效：信物无内在意义（随便什么珠子）则读者不关心去向；须让每级信物本身承载一段记忆。
- 锚点：PG503 三夜三果/三苹果；PG51219 L652-1832。

### A2 信物多态转换
- 触发：单一信物要走完整个故事弧。
- 操作：同一信物依次经历 ①定情/承诺（赠出）→②伪证工具（被敌方征用为欺骗证据）→③归还（真相大白时奉还）→④复用（重新戴上/传给下一代）。每次转换写一个仪式性场景。
- 输出：信物成为剧情节拍器；转换点即章节高点。
- 失效：转换少于三次时只是道具；确保至少三态。
- 锚点：PG10892 L13900-13912/19911-19913/20926；PG5745 Great Medicine；PG71370 R3。

### A3 信物通行证
- 触发：低地位主角需要跨阵营通行/免死。
- 操作：①百年前（或多年前）散布预言"持此符者将至"；②信物本身平凡（兽牙/旧币）；③持有人不知其效力，权威方见符自跪；④效力随转移而转移（赠出即让渡）。
- 输出：预言自实现装置——世界为信物预先让路。
- 失效：高魔世界信物满天飞时失效；须保持"此符仅此一枚"的稀缺。
- 锚点：PG5745 P1。

### A4 伪证载体亚型
- 触发：反派骗局需要物证。
- 操作：把最神圣的信物从持有者手中"借走"（以传递消息等正当名义），随后作为"死者遗物"呈上。信物越神圣，伪证越不可疑。
- 输出：受骗者的直觉抗辩被物证压倒。
- 失效：受骗者曾亲眼见过信物易手过程则穿帮。
- 锚点：PG10892 B4（三重伪证律的物证环节）。

### A5 物件传记
- 触发：全书冒险松散、需要一条隐秘因果轴。
- 操作：①造物主赋予物件原初意图（延迟到终局揭示）；②物件经无意识持有者流转（≥4 手）；③至少一次"认假为真"推动重大事件；④终局由原主揭晓来历，各手意义倒放。
- 输出：散珠成串的回收快感。
- 失效：物件过贵重则无人肯让它流转。
- 锚点：PG71370 L431-7587；PG640 物形纪念碑（L10833-11319）；PG5745 武器谱系。

## F 族：强力道具时机学

### F1 一次性道具时机律
- 触发：主角获得限定次数的强力道具（一件法宝/一次神迹）。
- 信号：作者想立刻用掉它换爽点。
- 操作：①先安排 2-3 次主角自力化解的危机；②用重复句式提醒道具在场（"怀里的玉符还烫着"）；③在角色说出"再无他法"之后启用；④启用即高潮，不留第二次。
- 输出：道具的高潮分量+读者对主角能力的认同。
- 失效：爽点前置体裁（快节奏网文）按其惯例早用——本规则默认不适用，见 counterexamples。
- 锚点：PG23344 L192-424。

### F2 代差武器单点释放
- 触发：外来者携优势技术/武力进入低武世界。
- 操作：①声明存在但不演示（背囊里的火器/传说中的剑法）；②立使用禁区（只对绝境/非人敌）；③释放选最大情绪压力点，一击即止；④事后以"护身符/天雷"消化，本地人无法复制；⑤全书仅此一次。
- 输出：冲突张力保留+一次救场爽点。
- 失效：群像多人各持代差武器时互相抵消，需收敛为单人持有。
- 锚点：PG72938 L6942-6968。

### F3 三夜试炼节律
- 触发：需要紧凑的递增试炼单元。
- 操作：三个夜晚/三次任务，每夜独立成章且恐惧/难度递增；前两夜忍耐+收集信息；第三夜以新认知破局。
- 输出：节律感+第三夜的释放。
- 锚点：PG503 三夜组（白猫三年三任务/黑牛三夜/玻璃山三日）。

## 使用检查单
- [ ] 信物是否三态以上？是否有一手"伪证"或"被夺"的暗礁？
- [ ] 一次性道具启用前，主角是否自力解决过 ≥2 次？
- [ ] 代差武器是否守住"单次+不解释+不可复制"？
- [ ] 梯度信物的每一级是否各承载一段可回忆的具体经历？
