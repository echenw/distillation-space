# 骗局工程 + 验证装置 + 冒名替身（C/J/K 族细则）

来源主锚：PG10892（Dawn）、PG61837、PG640、PG71370、PG70830、PG72938、PG9191、PG1597、PG90。

## J 族：骗局与真相工程

### J1 三重伪证律
- 触发：需要让深爱/深信者相信一个假死讯或假背叛。
- 操作：三链闭合——①口头断言（自称目击者）；②笔迹文件（伪造绝笔信，笔迹须似）；③信物（从持有者处骗得的贴身之物作为"遗物"）。三链中任一环"ring true"程度不足即露破绽（过度表演/措辞失真）。
- 输出：直觉抗辩（"他若死我岂能活着"）被三重物证压倒。
- 失效：受骗者见到"死者"本人；或三链中有一链可被独立核验（如医生可在场）。
- 锚点：PG10892 L14996/L15048-15054/L15012-13。

### J2 隔离前置律
- 触发：对目标人物实施长期欺骗或逼婚/夺产。
- 操作：在主骗局落地前，逐点移除其倾诉网络——乳母/闺蜜/知情仆役以"为你好"的名义（辞退/调离/断供）清除；每清除一人给一个体面理由。
- 输出：目标在信息孤岛上只能接收骗局的输入。
- 失效：清除动作太急太狠会惊动目标；须分批"合情合理"。
- 锚点：PG10892 L12116-12160。

### J3 善中介污染律
- 触发：需要向目标提出一个明显有利于提案者的要求。
- 操作：让最无嫌疑的善人（牧师/老仆/恩师）转述该提议，并附上善人自己的犹豫背书（"我也不知该不该说"）；目标事后把善意当证据。
- 输出：受害者把污染源错当净化源。
- 失效：善人知情过度会反水；只让他转述不知情。
- 锚点：PG10892 L15631-15636；PG72938 构陷延迟破解。

### J4 假死三层道具
- 触发：主角需要"被认定死亡"脱身。
- 操作：①衣物调换（与同级体型者互换）；②死法物证（现场留与死法一致的自制工具）；③葬俗可乘（确认敌方处置尸体的方式使辨认不可能：喂兽/火化）；④以新身份在原地公开活动一次验证。
- 输出：全城搜捕自动解除。
- 失效：尸体必然被亲属验看时穿帮。
- 锚点：PG61837 L6023-6290。

### J5 假安讯律
- 触发：灾难/反转即将到来。
- 操作：在灾难前一段安排一个低权威信源带来的好消息（老车夫"今早还见着她，气色好得很"），主角松一口气——下一页即是深渊。
- 输出：落差抬高的崩塌感。
- 失效：好消息来源太权威（主角亲眼所见）则失去"险些为真"的质地。
- 锚点：PG10892 L16599-16604；PG90 双盲失散。

### J6 谣言自乘律
公开否认=坐实。对有害谣言在**此单例人物语境中**可选择放任（"让他们说去"）或转移（制造新话题）；若必须处理，用行动而非声明。
- 锚点：PG10892 L14141–14143（人物主张“驳斥反会让人相信”，不是对所有谣言的事实实验）。

### J7 竞争性解释护身
- 触发：主角落入无法逃脱的敌手且武力权力均无优势。
- 操作：①列出敌方社群已有的两种对立解释（神使/恶魔）；②让两派各有权威与信众；③立裁决规则（"自然死者=凡人"类）；④主角行为不主动证伪任何一方。
- 输出：濒死危机转为制度性僵局。
- 失效：敌方出现第三种解释权威（真正的神职/测谎机制）。
- 锚点：PG61837 L97-108。

### J8 猜疑自证引擎
- 触发：写妒忌/偏见/妄想视角。
- 操作：①植入无据怀疑触发点；②让角色主动罗列"证据"，每条另配一个无辜解释（读者可见、角色无视）；③叙述者一句普遍化评论点破机制；④真相以最平淡物件（一叠账单）揭穿。
- 输出：读者获得对妄想机制的免疫性认知。
- 锚点：PG9191 L4399-4470。

### J9 集体谎言机制
群体自欺须有维持机制：验证物属性+否认即自认缺陷的社交成本+体系外破局者（孩子/外来者/疯者）；揭示后制度惯性照旧（冷收尾）。
- 锚点：PG1597 L44-224。

### J10 真相的物件通道
被禁声（誓言/威胁）者向中立物件（马首/铁炉/三滴血）倾诉，倾诉被第三方偷听——物件+窃听的组合通道是童话世界的"取证程序"。
- 锚点：PG503 P5。

## C 族：识别与验证

### C1 验证装置双因子
- 触发：世界观内存在幻化/易容/替身威胁（"谁是自己人"成为悬念）。
- 操作：①设计验证物+验证语双因子；②为不可伪造性给出设定内硬解释（生理特征/灵魂烙印/契约）；③作者确定装置的可靠度、已展示的例外与谁有权知道；④每次绕过须发生状态/信任损失，并让读者有机会比较过去的成功与失败。**不存在“最多一次”通用阈值。**
- 输出：识别戏有规则可依。
- 失效：无硬解释的验证装置=无张力；无前置征兆地反复被绕过才会使承诺失去可信性；允许故意失败的制度，但应显示代价。
- 锚点：PG70830 L351-359、L830-847。

### C2 技能即测谎器
把生存技能转用于人际识谎：以"蹄印新旧"式的物证判读对抗口头叙事——技能展示与情节机关合一。
- 锚点：PG90 P4。

### C3 替身败露三通道
冒名顶替的戳破并发于：最无知者（婴儿拒认/宠物低吼）+最边缘者（听墙者持有变形口诀类物证）+最亲近者（配偶闻哀歌起疑）；三线汇于一次当众复原。
- 锚点：PG640 L5379-9851。

### C4 语言双向闸门
被假定语言不通→当面听取机密→由同伙以"陌生语言翻译"名义自由转述；遇质疑降级为"我在教他，他太笨"。
- 锚点：PG61837 L4789-4972。

## K 族：冒名/双身/变形

### K1 冒名四段弧
假扮（技艺纯熟展示）→自认（"他已自认为此人"的内心独白）→事故洗牌（击头/失忆清空自认）→当众揭穿（真身归来公开指认）。
- 锚点：PG61837 L86-93、L8591-8619。

### K2 双身接管
容貌全同的冒名者在真身死后选择沉默，以死者的名字活着并承担其哀悼——替身戏的伦理重量型写法（非喜剧）。
- 锚点：PG71370 L5487-8735。

### K3 变形物理余数
体型变化保留一项不匹配（力量不减而重量减半）→生成新的动作语法（过冲/失准）；恢复时间不可测+预兆症状+地点约束=内置倒计时引擎。
- 锚点：PG61837 L5397-8268。

## 使用检查单
- [ ] 骗局的三链是否闭合？最弱一链是否会"ring false"？
- [ ] 目标的倾诉网络是否已被分批隔离？
- [ ] 验证方式的局限/失败样本是否在角色与读者已知范围内交代？
- [ ] 假安讯的信源权威是否够低？
