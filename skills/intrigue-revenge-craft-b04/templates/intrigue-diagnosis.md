## 判定与回归
- 首先按用户任务决定哪些 ID 适用；没有政治/宗教冲突时对应行标"不适用"，不能无中生有。
- ID-02：史实/法律判断只标"本 Skill 未核"，不得依据小说确证。
- ID-03：**先判定机制类型**（天生相像 / 工程替换 / 短暂误认），再填认知矩阵。写工程替换时必须回答"退出后他还是不是原来那个人"。
- ID-04/06：受压迫者视角及叙述偏见是重点；不能以历史宣传作品证明压迫正确。被压迫者必须有自己的目标，不能只作为旁观叙述的对象。
- ID-05：讽刺对象必须是**制度**而非患者；把"公开说法"与"私下知道"分列，并留一个可被检验的反证。
- ID-07：填四组信息（可检验主张 / 谁核实 / 追随者得失 / 怀疑者风险）+ **退出路径**：先回答"是否存在可执行契约"，再选第三方担保式或信任式。有真实信仰且未行骗的角色不贴"骗子"标签。
- ID-08：重聚先填**未披露的义务与可核验的缺口**，再谈分歧；拒绝重组是合法结局。
- ID-09：突然到场的人/物只有已经建立并可见因果时才合理；如果是寓言或童话神迹，按作者类型约定处理。
- ID-11：四问 —— 谁持有记录 / 谁能改 / 改后谁受益 / 什么改不掉。四问全无答案时需在正文补一个约束，否则冲突会滑向"谁嗓门大谁赢"。
- ID-10：给具体原文定位、触发的 RM、最小候选修法、不采用理由，复核前后章谁能知道什么和行动代价。
- 结尾必须写三栏状态：**已证 / 待证 / 需作者裁决**。任何一条都不得因"打包完成"或"SHA 正确"而写成已证。
