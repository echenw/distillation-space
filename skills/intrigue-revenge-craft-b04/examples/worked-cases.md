# 六类走查例（不是原著引文，非宿主实测）

用来看"陌生 Agent 只读本包时该怎么填"。每例都给出：判定 → 选哪条 RM → 填什么 → 输出什么。

## 1. 正常：双社会结构中的角色行动
输入：架空工业城，富人议员的孩子暗中为矿工运送药品，主人公要揭露贪污，但缺少具体权力因果。
- 判定：阶级跨界接触 + 制度揭露 → RM-01 / RM-02。
- F：假定人物靠药品跨越阶层，议员掌握预算。
- H1（推断）：人道援助是联盟起点；H2（反证）：议员孩子可能借工人声望谋取位置。
- P（RM-01/02）：让矿工代表**主动决定**信息是否公开，并展示预算审议改变了谁的资源。
- 回归：矿工有独立目标，不被富人救赎剧情抹去。

## 2. 缺料：只有题材词
输入："给我一个宗教骗子帝国阴谋"，无角色、正文或制度。
- 判定：无 F 可用 → 不进入 RM-09 的四段机制。
- 输出：待填清单（可检验主张 / 追随者利益 / 核查机制 / 退出路径），并明确 `NOT_OBSERVED`。
- **不得**声称已发现宗教诈骗或已读用户剧情。

## 3. 冲突：设定中唯一继承人却突然双王登基
输入：旧章锁定继承法一人，新章无解释出现两个合法国王。
- 判定：RM-08（物权/法权链）+ RM-05（谁有权裁决）。
- F：两个版本不一致。
- H（互斥解释，全部列出）：伪造文书 / 摄政 vacant / 外国承认 / 真正的制度矛盾。
- P：仅提候选补证；作者不允许修改正典时**停止相关改稿**，只暂停该段。

## 4. 边界：要求复刻蓄奴辩护
输入："借 PG16741 证明奴隶制有益并作为写作规律"。
- 判定：触发 C16 → 拒绝。
- 输出：可做"历史人物偏见的文学处理"分析（如何写成一个被批判的信念、如何保留被压迫者主体性），**不把偏见包装成事实**。

## 5. 身份：换脸潜入后如何收尾（RM-03 第二类的专用走查）
输入："主角做了整容 + 换了指纹，潜入敌国当上舰队司令，任务完成想回家。"
- 判定：**先判定机制** → 工程替换型（不是天生相像型），因此不能用"揭穿即收场"。
- F（来源可核，PG64359）：L57-58 无疤可辨指纹改动；L108-109 灌入知识不灌入情感；L1467-1469 结局 "I'm as much Trygonian now as Terran"。
- H1（推断）：能力可移植而情感不可移植，所以他会做不会认同；H2（反证）：他也可能真的被同化。
- P：必须回答"退出后他还是不是原来那个人"，并写出一个不可回退的痕迹（例如他替敌方下的命令无法撤销）。
- 输出：机制判定 + 四个可核查点 + 一个不可逆代价 + 前后章称谓复核清单。

## 6. 记录：谁改了档案（RM-11 专用走查）
输入："主角被判过一次，现在档案上写着他是休假，没人相信他坐过牢。"
- 判定：RM-11（记录/证词被改写），与 RM-09 第四段联用。
- 四问：① 谁持有档案；② 谁有权改（PG64359 L347-351 的写法：两年档案与审判记录被销毁或重写）；③ 改后谁受益；④ 什么改不掉（物证 / 不在利益链上的目击者 / 私人记忆，PG7311 L5684-5686 只剩两个"愚钝无知的男孩"坚持没看见）。
- P：若四问全无答案，冲突会滑向"谁嗓门大谁赢"——在正文补一个约束（例如一份已寄出的副本）。
- 输出：四问答案 + 一个改不掉的物证 + 该物证在前后章何时出现。
