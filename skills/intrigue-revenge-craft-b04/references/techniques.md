# 十类操作技法：从 RM 规则到实际判断

选择相关一节，与 [rules.md](rules.md) 对应 RM 号配合；这些流程不是固定题材的任务配额。**一次只取需要的 1–3 条。**

## A. 阶级与资源（RM-01）
先画权力资源图：两边各拥有什么、进不去哪里、依赖哪位中介。再检查跨界事件改变了谁的可执行选项。两群体之间原本就有稳定通道时，改写为**各自内部**的等级，不强迫贫富二分。

## B. 揭黑（RM-02）
找第一手可见物：劳动事故、合同、病房排队、日常收入，写出人物因它做出什么选择；只有作者议论、没有情节推进时补一个场景。只出现负面景观而没有具体人的选择，会沦为"痛苦观光"，需给人物自己的目的。

## C. 身份替身（RM-03）— **先判定机制**
1. **天生相像型**（PG1145）：画认知矩阵 —— A / B / 读者谁知道真相、何时可能验证、揭穿谁损失什么；前传秘密会影响续作合法性时，核对旧版时间。
2. **工程替换型**（PG64359）：回答"谁做的、留下什么痕、能力可移植而情感不可移植、退出后他还是不是原来那个人"。样本：L57-58 无疤可辨指纹改动；L108-109 灌入知识不灌入情感；L1467-1469 结局自我认同已被改写。
3. **短暂误认型**（喜剧/冒名向）：只写揭示时点与成本，关闭政治后果分支。
三类不要互相套用；**第 2 类的代价不可逆**，不要用第 1 类的"揭穿就收场"来收尾。

## D. 反战（RM-04）— **写制度，不写滑坡**
分两层：① 公开说法（颂词、社团、勋章）用什么**可证伪的断言**支撑；② 私下谁知道那是假的（受勋者本人发笑、边缘职业角色拆台）。
再写**服从如何被训练与被奖励**（PG19353 L7526-7532：机构按军事编制管理，医生必须穿军装才能让他服从），并把身体的代价与精神的代价分列（L7628-7635 filariasis）。
讽刺对象必须是制度，不是患者；是否保留讽刺由作者决定。

## E. 虚构政体（RM-05）
写邻国利益、政体裁决流程、资源与合法性边界；问一句"冲突是否必须通过这个制度才成立"。不需要时削弱设定表，避免虚构国百科取代主线。尺度放大到星际帝国也不免除这些要求（PG64359 L138-156）。历史真实国家须独立考据。

## F. 多视角与可靠性（RM-06 / RM-07）
分开每个叙述者的**亲见事实、推测、愿意遮盖的利益**，以及被压迫者的实际选择。对历史上的反奴隶制文本与为奴隶制辩护的文本，不制造虚假的"两个观点同等可信"；见 [scope-and-conflicts.md](scope-and-conflicts.md)。

## G. 继承杠杆（RM-08）
定位物权 / 占有 / 交付 / 继承争执的不同环节，明确谁能核实、谁相信错判。除非题材明确，不凭十九世纪英美小说推出当代财产法。

## H. 权威与追随者（RM-09）— **四段 + 退出**
1. 约束从哪来（追随者还是权威本人）；退出路径是否双向被封（PG7311 L4127-4134）。
2. 升级由谁推动；权威是否开始自欺（L4273-4292）。
3. **退出怎么设计**：先回答"是否存在可执行契约"——有 → 第三方担保 + 公开承诺（L4493-4527）；无 → 只能信任，并把"凭什么信任"写清楚（PG64359 L1119-1124）。
4. 事后谁会重写说法（→ RM-11 / 技法 J）。
把"可检验的主张、追随者利益、传播者声望、怀疑者遭遇"分列；**区分"虚假行为"与"正当的真实宗教信仰"**，不能以群体身份推断欺骗。

## I. 重聚（RM-10）— **先核验**
逐个核对旧盟友的：① 各自经历过什么；② **未披露的义务**；③ 现在的目标；④ 不可兼容的忠诚；⑤ 重聚后哪一次选择真正改变了本线后果。
第一场戏可以是互相试探（PG1259 L6005-6020：被收养青年为何酷似 Athos、为何从不提 Grimaud、隐藏家产暗示的野心），不一定是叙旧。重组 / 拒绝 / 背离都是合法结局。

## J. 记录与证词（RM-11）— **四问**
1. 谁持有记录（档案、审判笔录、账簿、影像）？
2. 谁有权改？改的程序是什么（PG64359 L347-351：两年档案与审判记录被销毁或重写，本人官方身份被改成"休假中"）？
3. 改后谁受益？
4. 有什么改不掉 —— 物证、不在利益链上的目击者、私人记忆（PG7311 L5684-5686 只剩两个"愚钝无知的男孩"坚持没看见）？
四问全无答案时，冲突会滑向"谁嗓门大谁赢"，需要补一个约束；不要把它写成"记录总会被改写"的 cynical 通则。

## K. 污点储存（补充手法，来自 PG693）
把角色一次不显眼的失分（拒诊、撒谎、受贿）交给对手保存，等到他谋求某个位置时集中兑现（PG693 L410-474）。要点：失分必须**当时可被人看见**，且兑现路径要在前文埋过。

## 诊断失败与修订
有原文 → 给段落定位、F、H1/H2、要测试的反证、候选 P 与前后章回归；没有原文 → 交场景待补清单而不声称改过；史实争议 → 显式外部核验状态 `NOT_PROVEN`。
