# 小说定位与成稿自检

一组可以直接在稿子上做的检查。每个测试回答一个问题，给出做法、该改的信号、不适用的情形。测试只发现问题，不替作者下结论。

## 1. 适用与转介

用：
- 开稿前：说清这本书给读者什么、不给什么；道德立场是氛围还是论点；历史、行业、地方题材先定事实契约；主要人物能不能预测。
- 改稿自检：说教味重；设定或景物喧宾夺主；细节像抄来的，或者一看就是外行；人物立不住、千人一面、行为说不通；读者不知道人在哪；稿子太长、读者跳读；场景潦草、用总结收尾；只有事件没有人心，或者反过来；不知道定稿前该改几遍。
- 作者问“按这些规则写能不能成”：分清可以检查的手艺和不能检查的判断（CL-14）。

转给别的 skill：
- 从构思到修订的全流程、多来源的规划方法 → `fiction-craft`。
- 情节结构、因果、多线 → `plot-architecture`；伏笔、悬念、章末 → `foreshadowing-and-rhythm`。
- 视角、信息控制、场景与概述的分工 → `narrative-pov-information-control`。
- 句子、用词、标点、对白格式 → `style-refinement-and-proofreading`；卷级连载 → `serialized-volume-planning`。

## 2. 使用方式

- 宿主任务规定了输出格式时按宿主格式交付；§6 的格式只在没有规定时使用。
- 普通任务读完本文件就能做。需要模板、例子和例外时，用 `skill.read` 读 §9 列出的参考文件。
- 给了稿子就按稿子检查，指出具体位置（章节、段落、短引文，不整段复制）；只有构思就做开稿前定位；要求改写就改写，交付时说明依据哪几项测试。
- 缺关键信息时先给合理的假设往下做，标明“假设”；只有答案会彻底改变结论时才问，一次不超过三个问题。
- 测试是代理：预测得出人物，说明人物清楚，不说明人物写得好；复述得出画面，说明读者看见了，不说明写得美。读者是否被打动、取舍是否选对，只能靠试读（§7）。
- 文中的数字都是起点，不是门槛。作者有最终决定权；作者坚持某种写法时，说清代价和替代办法。

## 3. 三条最短路径

### 开稿前定位

1. **读者契约两行**（CL-01）。
2. **道德立场**（CL-02）：这本书的道德意义靠人物的选择和后果呈现，还是要讲出一个论点？
3. **写实、历史、行业题材**：先定事实契约（CL-06），再列关键因果需要哪些细节、从哪里来（CL-04）。
4. **主要人物**：三场景预测（CL-05）；预测不出，先写人物卡。
5. 交付定位卡（§6）。

### 改稿自检

按顺序做，前面没过，后面先不做：

1. 契约兑现了吗（CL-01）
2. 说教（CL-02）
3. 设定和景物（CL-03）
4. 人物（CL-05、CL-07）
5. 细节来源（CL-04、CL-06）
6. 场面（CL-08）
7. 删与补（CL-09、CL-10）
8. 故事与人心（CL-11）
9. 复述（CL-12）
10. 修订遍数（CL-13）

结构问题先于句子问题：前八步有问题时，不要先在句子上花功夫。

### 作者问“这样写能不能成”

用 CL-14 把问题分成两类：可以检查的手艺项，逐项给结果和改法；不能检查的判断，说明只能靠试读和作者自己的判断。不预测市场成绩。

## 4. 症状速查

| 症状 | 先做 |
|---|---|
| 说教味重，叙述者在讲道理 | CL-02 |
| 开头大段世界观或风景，人物还没出场 | CL-03 |
| 行业、历史细节像抄来的，或者一看就是外行 | CL-04、CL-06 |
| 人物立不住，像工具人，说话千人一面 | CL-05 |
| 人物的行为说不通，只能用“设定如此”解释 | CL-07 |
| 读者不知道人在哪、谁在场 | CL-08 |
| 稿子太长，读者跳读 | CL-09 |
| 场景潦草，用一句总结收尾 | CL-10 |
| “不知道接下来会怎样”，或者“不关心这些人” | CL-11 |
| 读完复述不出画面或人物关系 | CL-12 |
| 越改越死，或者初稿直接交 | CL-13 |
| 被退稿、成绩差，作者问稿子到底好不好 | CL-14 |

## 5. 测试卡

每条：做法 → 该改的信号 → 不适用 → 来源（行号见 `references/source-index.md`）。

### 定位

**CL-01 读者契约两行**
- 做法：写两行。“读者契约：本书提供___（具体的人类冲突或乐趣），不提供___（论文、说教、社会方案）。”“完成标准：本书以___（人物、场景、语言、结构）为完成标准。”第一行写读者实际会得到什么，具体到谁想要什么、什么挡着、读者在等哪个答案；第二行是修改时的优先级，人物和事件冲突、语言和场景冲突时谁让步。每章回看：这一章兑现了契约的哪一部分。
- 信号：读者能一句话说出作者想说什么，却说不清谁身上发生了什么；或者只有事件，没有可说的经验，契约只剩一张爽点清单。
- 两种小说观：Crawford 把小说看作供人在闲暇时消遣的“智性的艺术奢侈品”，作者和读者之间有一份不成文的契约；Besant 把小说看作和绘画、雕塑、音乐、诗并列的艺术。两种看法回答的是不同的问题，本 skill 不裁决。选“消遣”一栏，仍要问完成度；选“艺术”一栏，仍要问读者。
- 来源：Crawford；Besant。

**CL-02 说教检查与反读测试**
- 做法：标出这几类段落：主语是“我们”“人们”“社会”的；读者能划出论点句的；删掉之后故事不变的。逐段问：能不能改成一个人物的选择、代价和后果？能就改，不能就删。然后做反读测试：文本允许一个和作者结论相反的合理解读吗？完全不允许，它可能还是一篇论文。
- 分三层处理：说教和论文，改成人物的选择或者删；道德氛围（人物的选择、代价、后果，对他人处境的同情），保留；“小说必须有自觉的道德目的”，不作为规则，那是 Besant 对 1884 年英国小说惯例的描述。
- 不适用：讽刺、寓言和明说以论辩为方法的作品。作者明确要写劝世文时，说明代价（Crawford 认为这违背了与读者的契约），由作者决定。也不要反过来把人物的道德困境删成“没有立场”，读者会不知道为什么要在意。
- 来源：Crawford（“the moral lesson is a mistake”）；Besant（“the preaching novel is the least desirable of any”）。

### 人物与材料

**CL-03 设定和景物要通过人物出现**
- 做法：逐段问两个问题：谁在看？它怎样压迫或帮助人物？答不出来，就压缩成一两个随动作或对白出现的细节。
- 信号：开篇大段风景或设定；设定章可以单独当旅游指南或百科词条；删掉之后人物关系不变。
- 不适用：世界观驱动的奇幻和科幻、自然写作，或者设定本身就是对手（城市、气候、制度）。这时不删，改写成人物必须付出的代价、必须通过的障碍、被迫改变的选择。
- 来源：Besant（人性兴趣必须完全吸收其他一切）；Crawford（自然和艺术只能作人物的布景）。

**CL-04 经验账本：细节可核查，反应可理解**
- 做法：把“经验”落成两项检查。细节可核查：这个阶层怎么说话、这个职业怎么办事、这个地方有什么物件，有没有来源？反应可理解：人物在这个处境下的欲求、恐惧、选择，读者能不能理解？这不等于“作者必须亲历”，也不等于“只能写自己的阶层、性别、职业”。
- 记账：场景、关键细节、来源（亲历、观察、访谈、文献、发明）、是否承担关键因果、处置。发明的细节承担关键因果时，补研究或者降为背景；只作氛围时可以保留。研究笔记不要整段贴进正文。
- 不适用：奇幻、科幻、寓言不要求字面上的经验，但要求心理真实。
- 来源：Besant（“never to go beyond your own experience”，他自己随后给历史小说开了例外）；Crawford（他说得更留余地：“我几乎要说……”）。Besant 劝乡村姑娘别写驻军生活这类身份限制，本 skill 不采纳，改用研究、访谈和请熟悉该群体的读者审读。

**CL-05 人物三场景预测和删名测试**
- 做法：把每个主要人物放进三个还没写的场景（葬礼、借钱、被误解，或者换成本书题材里常见的三个场景），预测他会说什么、做什么、在哪里犹豫。预测不出来，先写人物卡和他的秘密历史（他怎么看自己，别人不知道他什么），再写正文；已经写了还模糊，就删掉、合并或重新设定。
- 辅助测试：删掉对白里的名字，读者还认得出谁在说话吗？首次出场只给一两个辨识特征，加一个动作或一句话；口头禅和小动作不能代替人物，最好换成一句只有他会说的话。
- 不适用：刻意保持神秘的人物（对读者隐藏，不是对作者也未知）；寓言和讽刺里的扁平人物；只承担一个功能的配角（但仍要预测得出他的一句话）。
- 来源：Besant（人物要一天比一天清楚，不然就“kill and bury him”；最差的办法是靠口头禅）；Crawford（人物要在作者心里走动、说话）。

**CL-06 事实契约与借材**（历史、行业、地方题材）
- 做法：先定事实契约。纪实：关键事实、制度、物件可核查，错了要改。改写：写清改了什么、为什么改，内部自洽。虚构：不承诺史实，人物反应仍要可信。再列两张清单：人性和反应，必须可信，不能用“古人就是那样”搪塞；物质和制度细节，可以借、可以略写，但承担关键因果的不能错（一场仗为什么输、一条律法为什么能杀人、一桩婚事为什么退不掉）。借材从书信、报纸、日记、随笔、同时代的小说里取日常细节，改写后使用并记下来源，不整段照搬。
- 注意：“人性古今相似”只支持人物反应可以理解，不支持制度和文化差异可以抹平。
- 来源：Crawford（历史事实是限制，责任全在作者）；Besant（必须描写的时候就得借；《罗慕拉》的布景有误，仍因人物研究而伟大）。

**CL-07 人物双审：设定上成立，反应上可理解**
- 做法：两审分开。一审设定可能性：这个人物或世界在本书的事实契约里成立吗？按体裁，由作者定。二审反应可理解：他为什么这样选，读者能不能从他的欲求、恐惧、处境理解？所有体裁都要过。二审不过时，补规则、代价、后果，而不是补设定说明。
- 信号：写实的角色突然做出不合性格的事，比怪物更破坏幻觉；用“设定如此”解释角色为什么没有欲求、没有代价、没有选择。
- 两书的分歧：Besant 要求人物必须真实，是现实生活中可能遇到的；Crawford 允许不可能的人物做不可能的事，只要有“一点人性”，但他也说不该造完全不可能的人物和处境。本 skill 只取两者共同的一点：反应可理解。
- 来源：Besant；Crawford。

### 场景与取舍

**CL-08 场面表与“从台下看”**
- 做法：每章列五项：地点、在场者、目标（谁想要什么）、转折（新事实、新决定、新问题）、章末问题。再写一句“从台下看”：读者此刻看见什么、听见什么、在等什么。这句话只能靠叙述者解释（“他感到很矛盾”）时，改成动作、对白或人物之间的距离。
- 不适用：以内心、思辨、抒情为主的小说，概述和反思是主要方式，不要为了“像戏”改成对话。必要的时间跨度不要为了“看得见”压成一场戏（场景与概述的分工见 `narrative-pov-information-control` 的 PV-12、PV-13）。
- 来源：Besant（小说像一出戏，作者要不断问“从台下看是什么样”）；Crawford（小说是口袋舞台，要制造好戏的幻觉）。

**CL-09 无功能才删**
- 做法：给每段、每场标一种功能：推进（新事实、新决定、新问题、关系变化）、说明人物（欲求、恐惧、矛盾）、调节（喜剧、抒情、喘息、氛围）、都不是。先删“都不是”；通读一遍，缺信息时补回最少的。氛围段和离题段，先写出它的功能（情绪、主题、声音、世界），再决定删留。
- 信号：能整段跳读不影响理解；对白可以移给任何一个人物；插曲和主线没有因果。
- 不适用：鬼故事、抒情小说里，氛围本身就是目的。不要把“推进”窄化成事件密度，关系、认知、情绪的变化也是推进。
- 来源：Besant（不推进故事、不说明人物、不显出隐藏力量的描写、插曲和对话，都应当删去）。本 skill 放宽为“无功能才删”，因为 Besant 同时要求每一场都写完，而且很多场景在构思时就该舍掉，不必写出来再删。

**CL-10 留下的场景要写完**
- 做法：每个保留的场景问四个问题：有没有一个看得见、听得见、闻得到的具体细节？有没有一个人物反应（他做了什么、没做什么，而不是“他很生气”）？结尾是新问题、新事实、新决定，还是一句总结？有没有作者替人物总结意义的句子？
- 先决定这一场该不该存在（CL-09），再谈写没写完。
- 来源：Besant（每一场，不管多不重要，都要完整、仔细地写完，不许草率）。

**CL-11 故事与人心双栏**
- 做法：每章填两栏：事件栏（变化、转折、新信息）和人心栏（读者在不在意人物会怎样）。两栏都弱，重写；事件栏弱，按体裁补事件；人心栏弱，补人物的后果、代价和关系变化。起点：每章至少一个新事实、新问题或新决定。
- 弱情节的作品：把“悬念”换成“期待”，把“事件”换成认知、关系、情绪的变化。
- 来源：Besant（故事就是一切，读者要想知道接下来会怎样）；Crawford（小说要从头到尾吸引读者，但打动人心靠人物）。两人把不同的东西放在第一位，本 skill 按体裁和契约定优先级。

### 语言与修订

**CL-12 复述测试**
- 做法：选一段需要读者“看见”的文字（场景、人物关系、空间），请一两位试读者读完后复述：看到了什么、谁和谁是什么关系、此刻在等什么。复述不出来，改词、删歧义、补空间和动作；复述出的人物关系不对，那是结构或人物的问题，不是用词的问题；画面不同但关系对，可以接受。
- 没有试读者时：作者隔几天自己复述，或者让模型只根据文字复述，再和作者的构想对照（只是代理）。
- 不适用：刻意陌生化、刻意晦涩的文本。
- 来源：Crawford（印刷小说除了语言没有别的媒介，目标是让读者把想象的东西看得像事实一样分明）。

**CL-13 修订遍数与停止条件**
- 做法：先做结构遍（CL-08 至 CL-11），再做句子遍：删修饰（不影响意思的形容词、副词，“非常”“极其”）→ 抽象换动作（“他很焦虑”换成看得见的动作、物件、身体反应）→ 朗读（找重复的句式、喘不过气和绕口的地方）→ 删作者表演（炫学、警句、插科打诨：这句服务人物，还是服务作者？）。修改不再改善意思和节奏时停，记下停的理由。次数不是质量。
- 句子层的细则（中文句式、用词、标点、对白格式）转 `style-refinement-and-proofreading`。
- 不适用：口述体、刻意粗粝的风格。日更连载可以降低强度，但不要放弃回读。
- 来源：Besant（风格就是手艺：不许有一句草率的话；再粗糙的风格，用心下功夫都能变美；但风格压过情境会显得做作）。

**CL-14 分清可检查的手艺和不能检查的判断**
- 做法：可以检查、可以练的：观察、描写、取舍、场景、人物清晰度、反向提纲、重写。不能检查的：趣味、发明、戏剧感、读者是否被打动、取舍是否选对。本 skill 的测试只覆盖前一类，不承诺按规则写就能成功，也不用“艺术不可教”拒绝练手艺。
- 被退稿或成绩差时，把手艺诊断和市场分开，只给可以核查的手艺项。Besant 自己就说市场上的失败不等于艺术上的失败。
- 来源：Besant（“Rules will not make a man a novelist”；艺术本身既不能教，也不能传）；Crawford（自称所说只是意见）。

## 6. 交付格式（没有宿主格式时）

**定位卡**：契约两行；道德立场（氛围还是论点）；事实契约（纪实、改写、虚构）；主要人物的三场景预测；待作者决定的事项。

**自检报告**：每项测试一行。

## 7. 只能靠试读的判断

读者是否觉得有趣、是否被打动；人物是否在作者心里“长”清楚了；取舍是否选对；风格美不美；经验的边界在哪；失败是市场的还是艺术的；历史和虚构的比例；道德氛围和说教的分界；方言值不值得；读者是否看见了作者的构想。

这些问题，测试只给信号，不下结论。需要结论时，建议作者找两三位目标读者试读，问具体问题（“读到这里你在等什么”“你觉得他为什么这样做”），而不是问“好不好看”。

## 8. 两书的分歧与不采纳的说法

由作者决定的分歧：
- 小说是供人消遣的商品，还是与姐妹艺术并列的艺术（CL-01）。
- 人物必须真实，还是可以不可能（CL-07）。
- 内容尺度：Crawford 承认左拉伟大但粗粝，Besant 把“玷污人性”的作者排除在艺术家之外。这由作品和平台决定，不是手艺规则。

不作为规则的历史主张：小说必须有道德目的；人物必须像真人、不得超出个人经验；所有段落都必须推进情节；语言只是媒介，所以语言技巧不重要；小说法则能像和声、透视一样精确传授；好稿必被接受、被六家拒绝就该放弃、绝不自费出版；非历史小说不该写有年代感的细节，方言必然缩小读者，各民族的小说家有高下；小说应以爱情为主、干净甜美。这些可以作为十九世纪英国小说观的背景了解，原文位置见 `references/source-index.md`。

## 10. 来源与可信度

- 两本书都是十九世纪末英语“小说艺术”论争里的作品，作者都是当时的畅销小说家。两书一致的地方，是同一传统内部的会合，不算两个独立来源的互证。
- 两书没有系统的语言层方法：没有讲句法、视角、语域、节奏。本 skill 的语言部分只有“语言是唯一的媒介”和“风格就是反复修改”两点，其余转给兄弟 skill。
- 各测试的具体做法（两行模板、三场景、三色标记、双栏、复述测试、修订轮次）是本 skill 根据两书原则设计的操作，不是作者原话。
- `references/modern-and-zh.md` 是本 skill 的迁移建议，没有来源和读者数据支持。这些测试没有在真实写作任务上验证过，不承诺读者效果。
