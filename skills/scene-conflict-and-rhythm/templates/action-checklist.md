# 动作场面检查表（AC-01–AC-18）

用法：**开工前**填 A 组；**写完后**填 B 组；**回归时**只看 C 组。逐项写适用、结果或N/A；重复字段复用统一表。

---

## A 组：开工前（9 项）

| ID | 检查项 | 结论 |
|---|---|---|
| AC-01 | 场型：一对一 / 小队（伏击·追逃·突入）/ 群体（会战·溃退） | |
| AC-02 | 条件交付：谁在哪（相对位置，不是编制） | |
| AC-03 | 条件交付：关键障碍或出口是什么 | |
| AC-04 | 条件交付：双方还剩什么（弹药、马力、退路、人手） | |
| AC-05 | 这场戏的实际功能：后果 / 推进 / 性格 / 悬念 / 感官体验 / 其他；可兼有多项 | |
| AC-06 | 主规则：选用哪一条 AF？为什么是它而不是相邻那条 | |
| AC-07 | 后果规则：这一下之后有哪些收益、损失、持续状态或未知（伤、武器、关系、时间、名声）；无损胜利可成立 | |
| AC-08 | 视角与感官预算：POV 此刻能看/能听/能闻到什么，不能感知什么 | |
| AC-09 | 时代与技术约束：所有器械、通信、坐骑是否在设定的年代内可用 | |

## B 组：写完后（6 项）

| ID | 检查项 | 结论 |
|---|---|---|
| AC-10 | 若本场需要追踪优势变化，是否在关键处给足身体、位置或距离读数；连续动作可承担速度或混乱，不要求每次打击后停顿 | |
| AC-11 | “迅猛地 / 凌厉地 / 狠狠地”等概括是否完成本场声音或信息功能；仅在仍缺所需体验、对象或变化时补具体细节 | |
| AC-12 | 赢了之后若战后风险有关，是否有适量局面确认与后果；不要求每场诈死 | |
| AC-13 | 伤口位置、能力影响与处置是否在首次相关时清楚且前后一致（医学细节另核）；允许轻伤、延迟发现和不需本场处置，不限一个动作 | |
| AC-14 | 武器、弹药或其他资源在相关使用时是否与已设状态相容；可用准确数量或足够清楚的定性状态，不要求结尾逐项更新 | |
| AC-15 | 若巧合、外力或对手犯错相关，登记其次数、作用与前因，检查是否破坏本作因果承诺；可有后果，也可无直接成本 | |

## C 组：回归（3 项）

| ID | 检查项 | 结论 |
|---|---|---|
| AC-16 | 需要看清优势时，关键依据是否可从文本复述；“一句话”可作自检练习，不是配额，未实际试读不冒称读者已理解 | |
| AC-17 | 按实际叙述目标，关键决策与变化能否跟随；有意限知可保留未知，不要求每两次切镜补一次因果 | |
| AC-18 | 是否出现了本 Skill 声明要转让的部分（现代武器细节、非虚构战史、影视镜头、真实格斗教学、纯 POV 声音设计） | |

若 AC-18 为“是”，将超出证据或职责的具体部分交给相应资料核验或 Skill；本场仍属本 Skill 的创作与修订继续完成，不因局部转交整项停工。
