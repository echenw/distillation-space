# 伏笔与兑现（SU-01、SU-06、SU-07、SU-08）

返回 [SKILL.md](../SKILL.md)。

## SU-01 终点先行

**规则：** 动笔前可以先确定最后一拍——最后一个画面、动作或一句话，以及它要留给读者的情绪；再从那里倒推必要事件。这是规划工具，不是所有写作方法的硬要求。

**怎么做：**
1. 写一到三句“最后一拍”，尽量使用画面、动作或具体物件，不用主题总结代替场景。
2. 标出目标情绪，例如不甘、释然、发冷或怅然。
3. 列出到达这一拍必须先发生的事件和信息。
4. 逐段倒推：读者要先知道什么，才会相信下一步？
5. 检查是否存在同样成立的替代结局；若有，决定是否保留多解，或补足前置条件。

**篇幅不同，定的东西不同：**
- 短篇、单章、单场景：可先定终场画面和最后一句的方向。
- 长篇、连载：可先定终局状态，也允许在写作中发现；每个阅读单元另定自己的结束状态。
- 推理作品：作者应先确定谜底和机关，再检查读者是否能接触必要线索。

**例外：** 发现式写作可以先写初稿，改稿时再确定终点；真实历史或传记题材可以先定叙述截止位置，不改已发生的结局。

**检查：** 不看稿能复述最后一拍；最后一拍有具体动作或物件；每个主要场景都能说明它怎样影响终局或读者体验。

## SU-06 伏笔要有当下的用处

**规则：** 后续揭晓需要的人、物件、信息或能力，可以提前出现；首次出现时应有当下功能，不能只为未来埋线索。

**怎么做：**
1. 列出揭晓所需的关键条件：谁知道什么、谁持有什么、物件在哪里、规则如何运行。
2. 让条件以自然方式进入当前场景，例如正在使用的工具、闲谈、误会、工作流程或人物习惯。
3. 揭晓时让旧信息获得新意义，不要重新介绍一套临时规则。
4. 事后回看：前文是否有可定位线索？它是否既能支持揭晓，也不至于过早暴露答案？

**伏笔太显眼和太隐蔽：**
- 太显眼：叙述停下来特别强调，或人物无缘无故提起。可让它参与当前动作，或与更醒目的信息并列。
- 太隐蔽：揭晓后仍找不到前置线索。可增加一次不同语境的出现，或降低唯一解承诺。
- 不确定时，用真实试读检查读者能否回看线索；模型模拟不等于读者实验。

**例外：** 惊奇结构可以延迟解释，但揭晓仍应有可回查的条件；不可靠叙述可以暂存信息，但要让读者有机会识别其知识边界。

## SU-07 误认与修正可回查

**规则：** 误认可以延长好奇、制造反讽或推动关系。先写清是谁误认：人物、叙述者，还是读者也被引向同一判断。误认要改变某个选择；修正时给出新的依据。

**怎么做：**
1. 记录被误认对象、实际情况、各方当时凭什么判断、何时修正。
2. 让误认推动动作、决定、情绪或读者期待；不必每次都落到行动。
3. 修正通道可以是新观察、第三方信息、文件、行动结果或人物自我纠正。
4. 回看前文：误认是否符合人物当时的知识和感官条件？

**边界：** 不靠叙述者隐瞒他明明知道的事实；也不要求所有误认都由恶意造成。真实误读、信息延迟和故意欺骗要分开。

## SU-08 保留两种读法时，配一条现实解释线

**规则：** 若希望读者同时保留超自然解释与现实解释，两条解释都要有可观察支持和边界；不能只靠不解释制造含混。

**怎么做：**
- 列出解释 A 和解释 B 各自能解释的事实、不能解释的部分和需要的假设。
- 让人物依据其知识选择相信某一解释，但不把人物信念直接当成作品结论。
- 结尾可以确认一条、保留两条或拒绝裁决；选择应符合类型契约。

**边界：** 多解不等于任意解；如果两条解释都能解释全部事实，需说明作者希望保留的张力。公平解谜承诺与开放式恐怖承诺不同，不能混用标准。
