# 场景单位（SC-02 至 SC-05、SC-09 至 SC-11）

返回 [SKILL.md](../SKILL.md)。这些规则的来源是戏剧评论和剧场史，用到小说是类比；具体的操作步骤是本 skill 的建议。

---

## SC-02 离场时有什么变了

**规则**：诊断一场戏是不是在空转时，比较它进场和离场的状态。状态差可以是下面六种里的任何一种，不必是外在的胜负：读者知道的事、关系的远近、道德责任落在谁身上、期待、情绪、意象或模式。

**怎么做**：
1. 写下进场和离场时这六项各是什么。
2. 六项都没有变化时，先问这是不是目标：观察、仪式、停滞、间奏都可能是有意的。是有意的，记下它的功能，不判错。
3. 找不到任何变化、也说不出功能时，按 SC-14 问作者要它做什么，不要自动判成“废场”。

**例外**：体验性的抒情、意识流、间奏性的场景，可以只改变氛围或重复一个模式。只给了一句话、没有正文时，不做这项诊断。

**依据**：Burton 把 story 定义为对人的遭遇的一种处理，给人统一、并向一个确定的终点生长之感——说的是整部作品；拿它推出“每一场都要有状态差”，是把范围放大了。单元层面只有一条较弱的线索：有一类作品人物和对白都弱，处境的安排仍然能让它成立（这句原话没有在原文里找到）。所以本条是检查工具，不是来源的结论。

## SC-03 冲突由约束产生，不必编一个坏人

**规则**：每场戏写出四样东西：人物要什么 / 此刻拿不到它的具体约束 / 有哪些可选的行动 / 每个行动要付什么代价。约束不必由任何角色发出。

**怎么做**：
1. 约束从这些里挑，可以多选：空间、制度、承诺、沉默、身份、出身与继承、贫困、理想与现实的落差、时间差、同一个环境把两个人塑成相反的样子。
2. 写明这一场的推动力是哪一种：环境的压力 / 压力累积到翻转 / 人物和语言本身。不要默认只有一种。

**例子**：阶层与生存环境的无情挤压——贵族傲慢与平民被生存环境磨硬的冷酷在密闭空间内正面碰撞；外部小镇的目光与邻里舆论如同无处不在的监视之网，迫使压力不依赖具体某个人，而是源于无处可逃的共同体环境。

**不要继承的部分**：Goldman 的书是有立场的社会批评，它把冲突普遍归因于阶级和经济结构。这个归因不能当成所有题材的默认解释（见 [scope-and-conflicts.md](scope-and-conflicts.md) §1 的“作品靠什么推动”）。

**检查**：四样东西都写得出来；约束是具体的（“雾太大，看不见对岸”），不是抽象的（“命运”）。

## SC-04 跳接、桥接与主动留白

**规则**：一个结果发生在场外或两章之间时，记下读者凭什么相信它：看得见的行动、物证，还是可信的转述。题材需要的时间跨度超出了篇幅或体裁能承载的长度时，先考虑换题材或换处理法，不要只补一句转述了事。

**怎么做**：每一处跳接记三件事：
1. 结果依赖的通道：可见的行动、物证、可信的转述。
2. 暂时隐瞒的是什么。可以是有意的，但要记下来。
3. 读者回头核对时，能看到什么痕迹。

超现实、梦境、非线性的作品可以主动打破线性因果，但交付时写明“这是本作的契约”，不让读者把它当成疏漏。

**依据**：时间跨度与体裁承载边界——当人物的核心转变跨越漫长岁月时，如果将其压缩在幕后完成并假定发生了奇迹，读者的可信度便会被透支。事件的发展应当与场景能直接呈现的物理时间相协调。

**迁到小说（推断）**：小说不受“不能演出数年”的约束，同一个题材在小说里不必放到场外；但小说有注意力和篇幅的约束。跨越几年时，判断读者需要什么样的时间、人物或意象的桥；主动的留白也可以成立。

## SC-05 现场写，还是放到场外

**规则**：默认把关键的行动写在场内；有理由时放到场外，并留下物证、声音、证词或人物的反应。用一个问题来选：读者需要亲眼看见什么？

**怎么做**：
- 读者需要目击抉择的伦理代价或身体代价 → 场内。
- 未知本身产生恐惧、必须保守秘密、细写会破坏节奏 → 场外，并留下痕迹。
- 两样都要 → 一部分写在现场，一部分留白。
- 需要比较两种通道时，列出各自的收益和损失；作者已经定了通道，就直接落实，并说明关键代价。不要只给一句“展示，别讲述”。

**依据**：舞台直接展示 vs 场外留白——默认原则是能展示则展示（行动胜于陈述）；但例外是极端凶杀、神圣崇高或无法在台上逼真呈现的可怕变故，放在场外由在场者的惊骇反应反衬，效果反而远胜直接拙劣的扮演。

**反例**：所有暴力细节都展示，反而可能削弱恐惧；纯叙述的历史文本也有它自己的契约（见 [scope-and-conflicts.md](scope-and-conflicts.md) §1）。

## SC-09 先找约束，再定结构

**规则**：每一种结构形态都是某个约束的解；约束不存在时，照抄形态没有意义。先写下本章要解决的约束，再决定怎么组织。幕数和要素清单不是必须遵守的。

**怎么做**：
1. 写明本章的组织方式（下列之一，或自创）：进入—受阻—改变 / 地理或视角交叠 / 意象回环 / 问题—证据—新解释 / 倒数计时 / 双线对撞。
2. 写明每个单位要解决的约束是什么。
3. 写明退出条件：这一章结束时必须已经交付什么。
4. 分节、断章的理由从这些里挑：时空跳换、信息量已满、需要给读者喘息、一次完整的行动结束了、视角要换手。挑不出来，说明边界本身要重定。
5. 用外来术语时先给定义。连“场景”这个词都不统一：有的传统指换景，有的指人物进出场（这句原话没有在原文里定位到）。

**不要当作必须遵守的**：梵剧的五要素、五转接和 64 个分支，欧洲的五幕、三幕，“必须 N 幕”——都不是散文小说的结构必守项。它们可以作为历史方法资料，是否有用看本作的任务。

**依据**：结构分幕的合理功能——戏剧分幕与分场是为了处理宏大情节的阶段性更迭、换景与调度，给受众适度的节奏喘息；反对为了机械套用“五幕法”或“三幕法”而强插毫无戏剧生气的过场离别。

## SC-10 章链表

**规则**：需要登记多章之间的因果和回收时，用一张章链表。它就是兑现日志（SU-16）加两栏：时空与视角的桥、对下一章的约束。不另建第二张表。

**表头**：`章 | 前章的承诺 | 本章兑现或转移了什么 | 仍悬置、计划在哪章回收 | 时空与视角的桥 | 对下一章的约束`。

**怎么做**：
1. 每一处跳接都说得出它依赖哪一条看得见的因果，或者标明是本作的契约。
2. 打算后面揭开的，记下回收点；选择永久留白的，记下它的功能，不虚构“将来一定回收”。

**例外**：碎片式的作品和故意打乱顺序的悬疑，仍要检查后面是否用意象或关联收住；不是所有延后的解释都等于没收。

**依据**：这是本 skill 的组织方法，不是来源里的制度；它对读者的效果没有验证过。

## SC-11 章末和场末的四种出口

**规则**：按“下一章、下一步必须发生什么”来选这一章或这一场的出口：
- 下一章必须回应一个危机 → **后果或抉择**。
- 这一步改变的是关系的意义 → **重新理解**。
- 要让读者停在哀伤或美感里 → **余韵**。
- 这一步主要是信息的位移 → **知道的事变了**。

**怎么做**：先用 SU-15 的三查判断这一章末要不要留问题，再从四种出口里选。出口还要权衡时，比较第二个候选；目标已经明确时直接选，并记下理由。

**例外**：每一章都用悬念句收尾，会破坏抒情、伦理反省和人物独处的节奏。结尾不必承担结构上的高潮，也不必承担说教或悬念，它可以只把主题和情感收住。

**依据**：Burton 说压力增加到“断裂点”时，可以由不止一种手法产生“电击般的变化”：言语、行动、场面的交织，情绪凝成一个舞台画面，或者事件和人物心理的意外逆转。Weygandt 说 Synge 的戏里结构是最不出色的成分，但结构总能清楚地揭示由情感和主题产生的动作；Synge 也没有说教，甚至没有道德化的痕迹。Haigh 记下雅典竞赛里抽到最后一个演出被认为有利——这条完全绑定评奖制度，推不出“章序影响读者记忆”，不用。
