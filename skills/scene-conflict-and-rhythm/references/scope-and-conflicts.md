# 适用范围与冲突边界

返回 [SKILL.md](../SKILL.md)。

## 1. 先区分目标，再裁决呈现方式

### 长谈与行动

长谈可以改变计划、关系、信息和权力，因此可以构成行动；若只展示修辞而不改变任何选择，也可能阻塞行动。判断时先写明谈话的功能，再决定保留、压缩或改为动作。不要把“长谈”本身判为好或坏。

### 先看媒介，再选呈现通道

小说可以叙述多年，也要决定篇幅和桥接；舞台、影视、游戏和互动文本有不同的空间、时间、表演和信息限制。必要时缩小时间跨度、改变题材或换用转述；不要把某媒介的限制机械搬到另一媒介。

### 缺少关键目击，与没有功能的叙述不同

若关键目击者不在场或无法看见，这是信息权限设计；可选择可信转述、事后得知或明确换视角，并交代信息从哪里来。若已有叙述却不推进事件、信息、关系、声音或体验，才评估删减。不能把缺少目击误判成冗笔，再删成读者无法理解的因果空洞。

### 作品靠什么推动

三种主驱动不合并：

| 主驱动 | 主要压力 | 优先检查 |
|---|---|---|
| **事件/情节驱动** | 事件改变目标、条件或风险 | 因果、阻力、行动升级、后果 |
| **人物/关系驱动** | 选择、欲望、承诺和关系位置推动变化 | 人物能动性、代价、关系变化 |
| **氛围/语调驱动** | 感知、节奏、意象、空间或声音构成主要体验 | 基调一致性、感官层次、静态段功能 |

同一作品可以混用，但要标明当前场景的主次。空间、制度、时间等属于阻力条件，不等同于作品的主驱动分类。

### 分类清单与人物/叙述者评价

理论清单从属于作品想创造的情感和戏剧张力；为了凑齐分类而硬插离别、冲突或转折，可能破坏结构。人物说“某类人都……”是角色话语；叙述者直接归类是叙述立场。分别记录说话者、位置、距离和上下文。重复出现同一说法不构成独立印证，也不自动升级为作品认可的事实。

### 强度峰值与慢场景

强度阶梯和代价检查只在作者希望推高某个峰值时使用。慢场景、过场、抒情段、仪式和有意停滞的场景，不受“每场都必须损失/付代价”的约束；先看场景目标和体验功能。无损胜利、无变化观察或余韵都可能成立。

### 单一证据与经验参数

仅由单一案例支持的经验，只能作为低置信度的设计假设，并写明该案例与当前任务的相似条件；不得写成体裁规律。多个转述同一案例不算独立验证。强度等级、轻重拍、段落数量等数字只作练习值，不写成统计阈值。

### 形态是约束的解

舞台演员数量、换装时间、观众视线、布景能力、镜头条件、交互输入和文本篇幅，都可能影响形式。先写当前媒介的实际约束，再设计形态；不因历史形式曾经存在，就把它当成当代作品的必要结构。

## 2. 场景规则在不同体裁中的适用

| 体裁 | 可以用 | 要调整或不用 |
|---|---|---|
| 短篇、单场景 | 按目标选择场景规则 | 不按字数范围决定能否使用 |
| 长篇、连载 | 以场景或章为单元使用；卷级节奏转长篇规划 | 不照搬“一次读完”的假设，不要求每章单峰 |
| 诗 | 可借用节奏、意象和转折诊断 | 格律、押韵、分行不在本 Skill 范围 |
| 明说寓意的作品 | 节奏规则照用 | 是否明说按契约调整；儿童文学不等于必须明说 |
| 承诺公平解谜的推理 | 检查线索、视角和信息权限 | 氛围暗线不能代替公平线索；解谜公平转类型小说 Skill |
| 中文口语叙事 | 大多数场景规则 | 声音可用同韵、同句尾、称呼或语气变化，不照搬外语语音做法 |

## 3. 规则的证据范围

| 方面 | 覆盖 | 不覆盖，使用时标明“未核实” |
|---|---|---|
| 时间与技术 | 可分析任何已设定的虚构时代和媒介条件 | 现实武器、急救、工程参数与现代技术操作 |
| 动作类型 | 可分析冷兵器、枪械、追逐、群体行动和非暴力冲突的叙事功能 | 现实武器操作、战术、伤害和规避执法的步骤 |
| 地域与语言 | 可分析文本中已建立的社会、语言和文化条件 | 未经核验的非西方制度、语言和武技事实 |
| 类型 | 战争、冒险、喜剧、悬疑、科幻及其他虚构场景 | 未覆盖题材的专门技术规范和现实行业流程 |
| 证据 | 本 Skill 的机制是创作诊断工具 | 不能凭机制卡证明某种动作在现实中可行或有效 |

## 4. 动作场面的六组取舍

1. **留活口还是先脱离威胁：** 按人物目标、信息需要、撤离/求助/制服条件和已建立的即时威胁选择。活口可能留下信息，死亡或逃脱会关闭部分通道。这是叙事因果分析，不是现实处置建议。
2. **大场面写物件还是写数字：** 物件呈现个人经验，数字交代规模或制度视角；可以单用或并用。没有“不许写总数”或“数字越多越可信”的规则。
3. **喜剧能否贴着动作发生：** 可以严格分开，也可以让笑声改变紧张和羞辱的含义。按作品的语调契约选择，不宣布黑色幽默一律不能用。
4. **死亡要不要哀悼：** 按死亡在本作中的功能、叙述距离和制度主题选择哀悼、静止、反高潮或其他形式。题材名称不决定选项。
5. **信号和暴力的先后：** 旗号、钟声、广播、侮辱、挑衅和突然袭击都可能改变局面；只在机制已建立时使用对应顺序，不把单一例子当公式。
6. **战术原因还是运气：** 可以写运气，但检查它是否替代人物选择、破坏已立承诺或临时增加规则。巧合的次数没有通用配额。

## 5. 硬排除

- 不把种族、民族、宗教、性别或殖民偏见当现实规律；如需呈现，标明是人物/制度立场并展示后果。
- 不把叙事分析变成针对现实对象的伤害、武器、逃避追查或危险操作方案。
- 不把虚构参数搬进现实；迁移的是结构、心理和信息关系，不是参数值。

## 6. 不写成通用规则的说法

| 说法 | 处理 | 原因 |
|---|---|---|
| 职业压倒爱情或某类人物必然牺牲关系 | 不采用为通则 | 是具体人物选择，不是跨题材规律 |
| 两类角色必须构成二分 | 不采用为通则 | 角色关系可以重叠、变化或拒绝分类 |
| 宝藏/谜题必须具备固定数量的参数 | 只作样例 | 参数随设定变化，没有统一清单 |
| 伏笔必须在固定篇数后回收 | 保留方法，不设门槛 | 回收节奏取决于悬置时长、读者记忆和当前承诺 |
| 救援必须在资源耗尽前某个固定时间到达 | 降为可选节奏件 | 具体时间取决于空间、资源和故事目标 |
| 动物必须承担固定数量的叙事职能 | 降为可选支线件 | 动物可以是感知者、行动者、情感锚，也可以没有这些功能 |
| 死亡必须反高潮 | 按功能和语调选择 | 不限定某个题材 |
| 技术说明必须独立成节 | 按信息任务和叙述节奏定 | 独立说明、嵌入叙述或省略都可能成立 |
