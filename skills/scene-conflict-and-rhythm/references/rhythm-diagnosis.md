# 诊断、修改单与节奏审计（SU-19）

返回 [SKILL.md](../SKILL.md)。

## 1. 诊断流程

1. **确定范围**：读了哪些章节或段落，没读哪些。只对读过的部分下结论。
2. **标“读者在等什么”**：每隔一场（或每章）写一句读者此刻在等的东西。写不出来的位置，就是悬念断了的地方。
3. **画两张表**：知识表（SU-04）和强度表（每场 1–5，SU-02）。长稿只画主线。
4. **对症状**：按 SKILL.md §4 的症状表找规则，记下证据——引稿子里的短句或场景位置，不整段复制。
5. **选最小的改法**：优先移动信息的位置、增加一处伏笔、删掉一段解释；然后才是增删场次；重排结构放在最后。
6. **回看**：按 §3 的审计表数一遍，看改法有没有带来新问题。

没有稿子、只有构思时，不做“稿子里第几段有问题”的诊断，改做设计（SKILL.md §3 的设计路径），并说明哪些判断要等有了稿子才能确认。

## 2. 修改单格式

没有宿主格式时，每条修改建议写一行：

| 位置 | 症状 | 原因 | 规则 | 改法 | 代价 |
|---|---|---|---|---|---|
| 第 3 章末 | 章末没人想往下看 | 章末状态和章首相同，问题在上一章已经回答 | SU-15 | 把第 4 章开头“信被调包”的发现前移到第 3 章末 | 第 4 章开头需要重写一个过渡 |
| 第 7 章 | 反转像作弊 | 凶手是会计这件事，前文没有任何可回看的线索 | SU-06 | 在第 2 章的账本场景里，让他“顺手”改了一个数字 | 读得仔细的读者可能提前猜到；可以同时加一个误导（SU-07） |

“代价”一栏必须写：每个改法都会动到别的地方，写出来，作者才能判断值不值得。改之前先写下这一段原有的功能（人物、气氛、伏笔、节奏、象征），在“代价”里写清改法会动到其中哪一项（SC-13）。

## 3. 节奏审计表（SU-19）

交付前数一遍。数字只用来发现问题，不是及格线；“起点”一栏是常用的默认值，类型和篇幅不同可以调整。

| 项目 | 起点 | 实际 | 说明 |
|---|---|---|---|
| 每个阅读单元的主峰数 | 1 | | 多于 1 时，检查是否在互相抢戏 |
| 相邻单元主峰类型是否重复 | 不重复 | | 连续同类峰值容易麻木 |
| 阶梯级数 | 3–6 | | 每级新增的代价是否各不相同 |
| 高潮之前有没有同类更强的场次 | 没有 | | 有的话，降级或改为高潮 |
| 每个揭晓能找到的伏笔数 | 至少 1，最好 2 | | 0 就是作弊风险 |
| 每个伏笔出现时的当下用途 | 有 | | 没有就是“硬塞” |
| 母题出现的次数与语境 | 每次语境不同 | | 语境相同的重复可以删 |
| 钩子都有兑现章 | 是 | | 见兑现日志（SU-16） |
| 连续同一章末问题的章数 | 不超过 2 | | 3 章以上说明中段没进展 |
| 效果达成后的篇幅 | 很短 | | 主要是交代下落时，试删（SU-17） |
| 象征义是否在中途被说破 | 选了延迟理解时：否 | | 说破了，删掉解释句，或者改成人物只说对一部分（SU-18） |
| 末段占全篇的比例 | 很小 | | 拖沓时，前移信息或删解释 |
| 实际阅读时长 | 试读才写 | | 没有试读就写“未测”，不按字数推算 |

数字的来历：Poe 说这首诗打算写到“大约一百行”，实际是 108 行，18 节、每节 6 行，长度是数过的；末节 6 行，占全诗 5.6%。早先的版本给过一组练习值：母题在短篇里 4–8 次、长篇单元里 8–15 次，阶梯 4–6 级，末段不超过 15%，象征义在 85% 之后才显现，一次读完不超过 45 分钟。它们都没有普适的验证，只能当上表“起点”一栏的参考，不当及格线。同一种代价逐级加重，也算有增量。

## 4. 作者坚持时

| 情形 | 处理 |
|---|---|
| 作者给不出结局 | 先写最小版本：只要“最后一个画面加一个情绪词”，不要情节；仍然写不出，给两三个候选结局，各写一句代价，请作者选。设计可以先往下做，标明“结局待定”。 |
| 作者坚持每章都要炸 | 说明代价（强度不能持续，读者会麻木，SU-10），给替代：每章一个主峰但轮换类型，大峰值稀疏放置，中间插入短的松弛（SU-11）。最后由作者决定。 |
| 作者要“绝对精确的方法” | 说明这些规则是检查工具，不是公式。Poe 声称这首诗的每一步都可以回溯，没有一处出于偶然或直觉；可他同一篇文章里也说，作者通常无法回溯自己得出结论的步骤，编者序也怀疑这份分析是事后虚构的。 |
| 类型要求明说寓意（寓言、儿童、宣传） | 跳过 SU-18，改为开头明示寓意、每次变奏加深。 |
| 多线并进 | 每条线各建一个阶梯（SU-05）；共享同一个母题时，确保它在各线的含义不冲突；不能共享就各用各的。 |
| 作品是诗 | SU-02、SU-13、SU-14、SU-18 可以直接用；SU-09 慎用；SU-08 只在要保留两种读法时用；格律、押韵和分行不在本 skill 范围。 |
| 证据不足，无法判断 | 写明“无法判断”和缺什么（缺哪一章、缺作者的结局设想），不要猜。 |
