# 场景与动作的诊断（SC-01、SC-12 至 SC-14）

返回 [SKILL.md](../SKILL.md)。伏笔、悬念和节奏的诊断流程、节奏修改单和节奏审计见 [rhythm-diagnosis.md](rhythm-diagnosis.md)；这里管场景和动作。两边各有自己的修改单：节奏与伏笔的诊断用 rhythm-diagnosis §2 的表，场景与动作的症状诊断用本文件 §6 的表。

---

## 1. SC-01 先问目标，再套规则

**规则**：诊断之前，先按这一章或这一场要的效果判断要不要改。已经奏效的选择，不因为不合某条惯例就去“纠正”。

**怎么做**：
1. 从请求和材料确定这一场要的效果；分开记已有的反馈、文本里看得到的现象、还不知道的事。请求已经清楚时，不为了开工重复提问。
2. 有依据显示效果已经达到、又没有相反的证据时，保留这个选择。用户另有连续性、格式之类的目标，继续查那些目标。没有读者数据，不说“已经验证”。
3. 已经看到目标和效果之间的落差，或者用户要求改写、文本里又有可以定位的问题时，进入 SC-12 找机制。缺少效果数据不妨碍按授权修改，只是不把推测的效果写成事实。
4. 不说“违反规则 X，所以必须改”。

### 先识别本场的主驱动

诊断前先回答“这场戏主要靠什么驱动”。三种模式不合并、不打综合分；可以混用，但要标明主次：

| 主驱动 | 可观察重心 | 优先检查的判据 |
|---|---|---|
| **情节/事件驱动** | 事件改变目标、条件或风险，人物被推向下一步 | 因果是否连贯、阻力是否有效、行动是否升级、结果是否改变后续选择 |
| **人物/关系驱动** | 人物的选择、欲望、承诺或关系位置推动变化 | 选择是否属于人物、代价是否真实、关系是否发生可辨变化 |
| **氛围/语调驱动** | 感知、节奏、意象、空间或声音本身构成主要体验 | 基调是否一致、感官与节奏是否有层次、静态段是否兑现体验目标 |

同一作品不同场景可以切换主驱动。氛围驱动的场景不因外部事件少就自动判为“无功能”；情节驱动也不能只靠氛围描写代替因果。此分类回答“作品/场景由什么推动”，SC-03 的空间、制度、时间等约束分类回答“阻力从哪里来”，两者不要混为一表。

**例外**：作者要求对齐一整套惯例或格式（比如投稿格式）时，合规本身就是目标之一。输出里写明“这是外部要求”，不把它说成某条规则的证据。

**判断边界**：惯例只能帮助诊断，不能替代作品目标。非常规写法若兑现了本作的情感、叙述和形式承诺，就不因偏离常规自动判错；仍要检查它是否产生了作者想要的效果。

## 2. SC-12 场景症状：先做区分检验，再选改法

| 症状 | 区分检验 | 改法 | 什么时候不改 |
|---|---|---|---|
| 人物聊完毫无变化 | 读者知道的事、谁占主导、人物相信的东西，有没有变 | 给人物一个此刻的真实意图，或者让对方拒绝并带来后果 | 哲思、礼仪、哀伤的场景可以缓慢地变；先过 SC-01 |
| 突然的胜利、病愈、和解 | 这个结果依赖哪一条此前看得见的因果桥 | 补伏笔、补后果，或者改用可信的场外转述（SC-04） | 魔幻、预言、寓言的契约允许奇迹；不按个案定罪 |
| 对白像背景手册 | 谁在此时为什么需要说这些 | 把信息移到做决定、隐瞒或试探的时刻（SC-07） | 戏仿、说书体、辩论型的作品可以讲道理 |
| 动作很多，却不紧张 | 风险、目标、看得见的证据是不是一直没变 | 调整代价和可选的行动，而不是加更多追逐 | 动作本身就是要的感官体验 |
| 多章跳接看不懂 | 时间、视角、物证缺了哪一座桥 | 补一条读得出的痕迹，同时保留谜面（SC-10） | 非线性叙事可以延后解释，但要在章链表上登记回收 |
| 说“太慢”，却没给正文 | 有没有给出目标、段落和对节奏的期待 | 只给检查表，不做针对正文的诊断 | 写明缺正文、要补什么（SC-14） |

**怎么用**：
- 先过 SC-01。已经达到目标的选择，不因为形式不合惯例就进入纠错；别的明确修改目标或看得见的问题，照常处理。
- 采用的机制要能指到文本里的位置，推断写明是推断。存在会改变改法的竞争解释时，才列出两种解释和区分的办法；机制已经有充分的文本依据时，不凑第二种。没有具体依据的说法，只能当待查的假设。

**判定说明**：核心转变若全放在幕后完成，读者可能缺少理解变化的过程（SC-04）；但极端凶案、不可见威胁也可能通过场外反应间接呈现（SC-05）。本表用于比较呈现方式的条件与代价，不预设哪种效果更强。

## 3. 动作场面的八种症状

先排除别的解释，再下判断。重要的诊断附上位置和文本依据；只有数量本身相关时才计数；推测不写成文本事实。

严重度：
- **高**：关键的定位或前因在文本里缺失，或者已有真实反馈显示重要的理解受阻。没有反馈时，对读者的影响写成推断。
- **中**：可信度或代价缺失，可以列为修改候选。
- **低**：风格上的偏好，可改可不改。

### 症状 1：打斗像招式清单

- **表现**：连续的动词句（“他劈、她格、他再劈、她旋身”），没有停顿，读者记不住谁占上风。
- **检查**：把每一句按“谁的身体的哪个部位动了”重述一遍，标出说不清、又确实妨碍本场目标的句子。不设“超过三句”之类的阈值。
- **规则**：AF-02、AF-03、AF-05。
- **最小改法**：动作的重复遮住了优势的变化时，压缩中间的动作，留下必要的接触、身体或位置的读数和结果。连续的招式承担速度、专业感或混乱时，保留。
- **回看**：本场需要读者追踪优势时，文本能不能支持一句“谁占上风、凭什么”的复述。这是自检，不是读者测试。

### 症状 2：看完不知道谁在哪

- **表现**：人物突然出现在背后；地形在段落之间变了；出口的数量前后不一致。
- **检查**：逐段标出每个人相对于对手、相对于相关出口、障碍或参照物的位置，找断开的地方。
- **规则**：SC-08、AF-11；限知视角用错了，加 AF-06。
- **最小改法**：在第一次需要理解行动的地方，补上谁在哪、相关的障碍或出口、可用的资源；已经开打，也可以用一句话重新定位（“他背对着门，她隔着桌子”）。
- **回看**：按需要画出关键人物和物件的相对位置，看移动能不能连起来。点数多少随场面定。

### 症状 3：打完没有后果

- **表现**：打完就走；伤口到下一场不影响任何动作；缴获的武器从不计数。
- **检查**：在后果第一次相关的位置，核对处置、能力、资源、关系或知识的持续状态。不是每场都涉及所有项，关键的后果也可以延后才被发现。
- **规则**：AF-08、AF-10。
- **最小改法**：补上真正缺失、又影响后面的处置、状态或关系。可以写成战后的一段、后面场次里的行动、一句概述，或者延后的揭示。
- **回看**：后面用到时，伤、资源、关系和已经立下的状态相不相容。

### 症状 4：主角太轻松

- **表现**：多处受伤还能很快恢复；每次危机都有外来的巧合解围；对手从不调整。
- **检查**：登记每次“天助”（外力、巧合、对手犯错）的作用和代价，不因为超过两次就判过量。检查伤和已经设定的身体、世界规则相不相容；轻伤、超常的恢复、本场用不着那项能力，都可以不产生战术上的限制。
- **规则**：AF-18 的边界、AF-10。
- **最小改法**：偶然的解围破坏了因果上的承诺时，补前因、换解决方式、写出后果，或者调整契约。暴露位置、失去资源、欠下人情是可以选的后果，不是每次好运都要付费。
- **回看**：改法有没有解决已经确认的问题，人物的选择和世界规则还成不成立。无损的胜利本身可以成立。

### 症状 5：恐惧的写法和要的体验对不上

- **表现**：“他感到前所未有的恐惧”“一种巨大的压迫感”。
- **检查**：先看这句心理概述是不是已经完成了信息或声音上的功能。任务还需要具体的威胁或体验时，找出缺的是什么：触发、认识、感官、行动还是关系。
- **规则**：AF-07、AF-05、AF-06。
- **最小改法**：从时间感变形、感官变窄、不合时宜的念头、心理上的认识、对白、行动里，选几样补上具体的作用；有独特意义的情绪词保留。
- **回看**：文本有没有给出本作需要的恐惧对象、变化或不确定。不以禁用“害怕”为标准；读者的真实感受要另外验证。

### 症状 6：大场面写成一堆数字，或者一团烟

- **表现**：只有编制和伤亡数字；或者反过来，全是烟雾，没有一条能跟着走的变动。
- **检查**：按本场目标核对需要跟随的关键决策、后果和视角的转换。目标是追踪因果时，找出断点；目标是局部见闻或有意的混乱时，检查这种限制前后一不一致。不要求一条全知的因果线贯穿到底。
- **规则**：AF-11、AF-12、AF-10；要加入感官，加 AF-17。
- **最小改法**：需要追踪因果时，挑出关键的决策和后果串起来。数字可以承担判断、规模、冷峻的语气或制度的视角，不要求每处变动写成同一个样子。
- **回看**：按实际的叙述目标，读者能不能理解关键的变化；有意的限知可以保留未知。

### 症状 7：技术细节失真或时代错置

- **表现**：武器的操作、弹药的携带、马的行为、通信的方式，和设定的年代对不上。
- **检查**：把出现的器械、通信手段、坐骑逐一列出，核对它们的年代和物理约束（后坐、装填、射程、续航）。
- **规则**：AF-10；AF-14 里“用稳定的物理背景托住荒诞”的那种契约；[scope-and-conflicts.md](scope-and-conflicts.md) §3 的证据边界（现实武器与参数不在覆盖内，使用时标明“未核实”）。
- **最小改法**：保留作品的年代。超出可靠资料的枪械、通信或战术，另找资料核实，或者降低描写的精度；核实不了的，写明“未核实”，并限定受影响的结论。架空的技术可以作为明确的设定继续写，不冒充真实的史实。
- **回看**：每一个技术名词，能不能用设定年代里的一件实物解释清楚。

### 症状 8：喜剧和残酷撞在一起

- **表现**：杀人的过程配搞笑的比喻；严重的失能被拿来插科打诨。
- **检查**：标出笑点的对象、叙述者站在哪里、笑点落在过程还是结果上，判断它有没有破坏本作已经定下的语调、人物或后果。位置本身不判对错。
- **规则**：AF-14、AF-04。
- **最小改法**：目标确实要求严肃的伤亡时，把笑点移到前后的狼狈上，或者换叙述者的站位；目标是黑色幽默时保留，并检查因果和语调。
- **回看**：读者笑的同时，还知不知道这件事有多严重。

## 4. SC-13 改之前，先保存原有的功能

**规则**：改之前，先抄下位置，写下这一段原有的功能和用户想保留的东西（人物、气氛、伏笔、节奏、象征），再选和问题相称的改法。

**怎么做**：
1. 有重要的取舍时，才并列两种方案：**小改**（补一个动作、补一处提示、改一处视角，不动结构）和**结构改**（重排顺序、换视角、把现场改成场外或者反过来）。不是每一处都交两个方案。
2. 对采用的改法，以及确实需要比较的候选，记下收益、可能失去的氛围和伏笔、对下一章的影响。这些写进修改单的“代价”一栏。
3. 按授权的范围交付：用户只要局部就改局部，授权了全稿就完成全稿。只有实质的语义歧义或互相排斥的条件，才暂停受影响的那一部分，其余照常交付。
4. 自己编的例子要说明是编的；和原稿比较时，写清改动前后哪一项状态变了。不把本 Skill 自建示例当成用户提交文本的证据。

**边界**：这是修订工作纪律，不是创作效果规律。

## 5. SC-14 退出与边界

**规则**：遇到下面六种情况，按对应的方式收住：
1. **没有稿子**：只做假设式的设计，不声称做过逐段诊断。
2. **没有修改文件的授权**：只给文本，不写文件。
3. **作者已经定下的文学实验、非写实的契约**：优先于本 skill 的任何规则。
4. **核心的价值取舍还没定、也没有授权代选**：列出选项；已经授权创作，或者能合理推定作者意图时，给标明“候选”的方案。
5. **现实的技术、医学、法律问题**：不给伪装成事实的建议。
6. **效果的判断**：没做过读者试验，就写成待验证；本地的文本检查不是读者试验。

停下的时候，用下面三种说法之一，并写明补上什么才能继续：
- **缺材料**：缺哪一章、哪段正文、作者的哪项设想；补上后可以做什么。
- **要作者定**：哪一项取舍，各自的代价。
- **证据不够**：哪个判断没有依据，尤其是从一种媒介推到另一种媒介的效果。

**边界**：这是权限与诚实的约束。

## 6. 交付格式

场景与动作的修改单格式：`位置 | 症状 | 原因 | 规则 | 改法 | 代价`；按节奏诊断流程做的修改单用 [rhythm-diagnosis.md](rhythm-diagnosis.md) §2 的另一套表。动作场面另加两项：**场型**（一对一 / 小队 / 群体）和**后果**（这一下之后的收益、损失、持续状态，或者还不知道的）。需要逐条展开时，可以写成下面这样（编的例子）：

```
位置：第 5 章，“她退到窗边”一段起
场型：一对一
症状：打斗像招式清单（严重度：中）
原因：连续六句只有劈、格、闪，读不出谁占上风
规则：AF-02（不是 AF-03：这里没有争夺器械的问题）
后果：她的左手腕扭伤，下一场开门时要用到
改法：压缩中间四句，保留第一次接触和最后一击，补一句打完之后的对峙
代价：少了一点速度感；原段落“窗外的雨”这一处气氛保留
回看：能不能用一句话说出谁占上风、凭什么
```
