# 场景设计与冲突节奏

管三件事：**一场戏怎么成立**（进场的条件、约束、行动或观察、离场时变了什么），**读者在等什么**（伏笔、悬念、节奏、章末与结尾），**动作怎么写才有因果**（打斗的读数、后果、资源、群战）。场景的规则是 SC 卡，伏笔与节奏是 SU 卡，动作是 AF 卡。

## 1. 适用与转介

用：
- 设计一章、一场戏，或者一个短篇的铺垫、悬念、高潮和收尾。
- 场景的症状：空转、跳接生硬、突然的胜利或和解、对白像背景手册、长谈拖沓、看不清谁在哪。
- 伏笔与节奏的症状：开头抓不住、中段塌、伏笔像硬塞、反转像作弊、高潮不响、通篇都在“炸”、章末没人想往下看、结尾拖沓或欠账。
- 动作的症状：打斗像招式清单、打完没有后果、主角太轻松、恐惧只有形容词、大场面是一堆数字或一团烟。
- 连载的章末钩子和兑现日志。

不接（负触发，先转介或停下）：
- 问题落在下面转介表的任何一行：不在本 skill 做，按表转介。
- 要打分、评级、批量自动替换，或裁定“唯一正确”：本 skill 给逐条建议，不打分。
- 没有稿子却要求逐段诊断：不出定位式结论，先要正文，或改做设计路径。
- 作者已达成目标的选择、实验文体和非写实契约：按 SC-01 保留，不因为不合惯例去“纠正”。
- 非叙事文本（说明书、论文、报告）的结构重排：不接，本 skill 只处理叙事文本的场与章。
- 游戏关卡、战斗数值、技能树/命中率设计：不归本 skill；要改编成互动形式归 `cross-media-drama-adaptation`，数值与关卡系统本身不在这套写作 skill 的范围。

转给别的 skill：

| 问题 | 转给 |
|---|---|
| 全书主线、多线汇合、分卷、卷末的收与接、跨卷伏笔、容量与排期 | `story-architecture-and-longform-planning` |
| 人物动机与心理、谁来讲、视角越界（全篇级）、全篇的信息控制、非线性时间（全篇级）、创伤；对白的潜台词与人物声口 | `character-and-narrative-control`（本 skill 只用到“这一场谁知道什么”；单场内的视角标记、知情差与倒叙场仍按本 skill 处理） |
| 选题、读者契约、资料核验、读者反馈、不确定用哪个 skill | `fiction-planning-and-diagnosis` |
| 句子、对白的措辞、标点、校对 | `line-editing-and-proofreading` |
| 推理的线索公平、恐怖与言情等题材契约、武侠仙侠的武打体系 | `genre-fiction-craft` |
| 改成舞台方案、分场稿、镜头 | `cross-media-drama-adaptation` |
| 生成、修订或诊断推进模式卡、文风卡、表达约束卡，写“反 AI 味的约束卡”，按推进／文风／表达三轴审章节 | `preset-card-generation` |

从 `genre-fiction-craft` 转入本 skill 的：一场戏怎么写、冲突、伏笔、悬念、节奏、章末。
从 `character-and-narrative-control` 转入本 skill 的：伏笔怎么埋和回收、悬念强度、章末钩子、松紧节奏、一场戏的进出、打斗；对白里塞满背景和设定、一场戏里的对白怎样排布和交锋（SC-07、SC-15）。
从 `preset-card-generation` 转入本 skill 的：单场设计、强度节奏、章末钩子这类不写成卡、也不按三轴审的问题。

**职责边界**：本 Skill 负责场景/章节内部的冲突、节奏、动作呈现和钩子写法；不维护全书承诺清算、卷级闭合、跨卷开放线或系列容量台账，这些由 `story-architecture-and-longform-planning` 的 PL/SV 规则负责。本 Skill 的 SU-15/SU-16 只处理单元内的钩子与兑现，不替代 SV-08 的跨卷记账。场景修改会改变全篇视角、信息控制或全书结构时，暂停这一处，转对应 skill 确认。

真实的格斗、战术、武器、医学和历史参数不在本 skill 的范围：小说里的写法只说明个案，要用到现实结论时，另找资料核实。

## 2. 使用方式

- 宿主规定了输出格式，就按宿主的格式交付；没有规定时，用 §3 末尾的交付清单和 `templates/` 里的表。
- 普通任务读完本文件就能做。需要细则、例子和例外时，只读 §6 里用得到的文件。
- **先问目标**（SC-01）：这一场要什么效果、哪些不能改。已经达到目标的长谈、慢章、没有冲突的场景，不因为不合惯例就改。
- 给了稿子就按稿子诊断，写明位置和短引文，不整段复制；只给了构思就做设计；要求写正文或改写就写，不覆盖原稿，交付时说明改了什么、伏笔埋在哪里。
- 缺关键信息时，先做合理的假设往下做，并标明“假设”；只有假设会彻底改变方案时才停下来问，最多问三个问题。没有稿子时，不声称做过逐段诊断。
- 文中的数字（级数、次数、比例、时长）都是起点，不是门槛；1–5 是同一篇内部的相对自评，不是测量结果或跨作品量表。
- 所有“读者会……”的判断都是待验证的设计假设，不是读者研究的结论；不承诺追读、完读或留存。
- 自创示例要明确标记，不和用户提交的稿件混在一起。
- 复杂操作（峰值冲突、跨章重排、伏笔与兑现一起改、多线强度）按 `references/rhythm-diagnosis.md` §6 的判断标准、步骤和诊断到修订的闭环走；完整自创难例见 `examples/scene-cases.md` 用例 5。

## 3. 最短路径

### 设计一场戏或一章

1. **目标**（SC-01）：这一场要的效果、不能改的东西。
2. **单位**（SC-02、SC-03）：进场和离场时，读者知道的事、关系、责任、期待、情绪、意象各是什么；人物要什么、此刻的具体约束、可选的行动、各自的代价。观察和静止的场景不强制有行动。
3. **知情与空间**（SU-04、SC-06、SC-08）：一张知情表，写读者、行动者、视角人物各知道什么；需要时补相对位置、障碍、出口和资源。
4. **场内还是场外**（SC-04、SC-05）：读者需要亲眼看见什么；放到场外的，留下物证、声音、证词或反应。
5. **组织方式**（SC-09）：先写下本章要解决的约束，再选组织方式，写明退出条件。
6. **出口**（SC-11、SU-15）：后果或抉择、重新理解、关系转向、余韵、知道的事变了；分次阅读的章末留一个真问题。
7. **章链**（SC-10）：跨好几章时，在兑现日志上加“时空与视角的桥”“对下一章的约束”两列。

### 设计伏笔、悬念与高潮（短篇或一个单元）

1. **终点**（SU-01）：写下最后一拍的画面或一句话，加上读者合上书时的情绪；写不出时先给两三个候选。发现式写作可以先写，改稿时补上终点再回头删。
2. **高潮**（SU-02）：单峰目标下，给前面每一场标 1–5 的相对强度，高潮是唯一的 5 分；前文有同类更强的场次时，按 SU-02 给「降级前文」和「重定峰值」两条路由，各写代价，由作者裁决（见 `examples/scene-cases.md` 用例 5）。多峰结构每个单元标一个主峰、写明主次。
3. **悬念方式**（SU-03、SU-04）：开头就让读者知道在等什么；按知识表选悬疑、反讽或惊奇。
4. **阶梯**（SU-05）：适合递增时逐级加码，每一级写清升了哪一种代价。
5. **伏笔与误认**（SU-06 至 SU-08）：揭晓要用到的东西提前出现一次，出现时另有用处；误认要能回查；要保留两种读法时，配一条现实解释线。
6. **节奏**（SU-10 至 SU-14）：一个阅读单元一个主峰；需要时放一个短的松弛再急转；转折给看得见的依据；母题本体基本不变、语境变；先定基调。
7. **收尾**（SU-15 至 SU-18）：章末三查；钩子记进兑现日志；结尾先结算承诺，再在效果达成处停；要余味时留一条不说破的暗线，并检查它在收束处出现一次、中途没有被说破。

### 写或改一场动作戏

1. **场型与功能**：一对一、小队还是群体；这场戏承担后果、推进、性格、悬念还是感官体验。
2. **条件**（SC-08）：谁在哪、关键的障碍或出口、双方还剩什么。故意不给条件时，写明张力来自误解。
3. **主卡**：一对一用 AF-02、AF-03、AF-05；不能见血用 AF-04；看不见用 AF-06；第一次动手用 AF-07；群战用 AF-11、AF-12；转述用 AF-13；决斗与喜剧暴力用 AF-14；技术对抗用 AF-18。
4. **后果**（AF-08、AF-10）：伤、资源、俘虏、关系、知识，在下一场第一次相关的地方对上。
5. **复核**：用 `templates/action-checklist.md`。

### 诊断已有的稿子

1. 写明读了哪些部分。先问目标（SC-01）：已经奏效的选择保留，记下它的功能。
2. 按 §4 找症状，写修改单：`位置 | 症状 | 原因 | 规则 | 改法 | 代价`（场景与动作用 `references/scene-and-action-diagnosis.md` §6 的格式；按节奏诊断流程做的修改单用 `references/rhythm-diagnosis.md` §2 的另一套表）。场景症状先做区分检验（SC-12），动作症状见 `references/scene-and-action-diagnosis.md` §3。
3. 改之前写下这一段原有的功能（SC-13）。改法先选最小的：移动一个信息、补一处伏笔或痕迹、删一段解释；然后才考虑增删场次或改结构。
4. 改完回看：空间、因果、知情、承诺和被改动的后果；伏笔与节奏按 SU-19 数一遍，含 `references/rhythm-diagnosis.md` §3 表下的象征检查。

### 交付

按任务交必要的部分，不把所有表都塞给只要正文的人：
- **设计**：场景卡、知情表，需要时加章链和出口的选择。
- **诊断**：修改单，每一条写依据和代价。
- **改写**：改好的正文、关键的差异、仍然要作者决定的事。
- **证据不够**：写明缺什么、哪些部分可以先做（SC-14）。
- **状态词**：对作者交付只用「已完成 / 未能核实 / 待作者决定」三个词，依据作附件逐项附上；不把「未能核实」「待作者决定」写成「已完成」（见 §9）。

## 4. 症状速查

| 症状 | 先看 | 常见原因 |
|---|---|---|
| 一场戏聊完没有任何变化 | SC-02、SC-03 | 进场和离场的状态相同；人物此刻没有真实的意图，对方也没有拒绝 |
| 突然的胜利、病愈、和解 | SC-04、SU-06 | 结果没有看得见的因果桥 |
| 对白像背景手册 | SC-06、SC-07、SC-15 | 信息不在做决定、隐瞒或试探的时刻出现 |
| 人物互相讲早就知道的事 | SC-15 | 信息是说给读者听的，没有放进追问、误解或不知情者的提问里 |
| 对白一问一答，规规矩矩 | SC-15 | 冲突里每句都在完整回答上一句；台词没有各自的意图 |
| 长谈拖沓 | SC-07 | 没有改变设计；语体和说话人不相称；不服务本作的情感 |
| 人多的场乱成一团 | SC-08 | 每个人都有完整的台词和动作，镜头没有焦点 |
| 多章跳接看不懂 | SC-04、SC-10 | 时间、视角或物证缺一座桥 |
| 关键行动被一笔带过 | SC-05 | 读者需要目击的代价放到了场外，又没留痕迹 |
| 看不清谁在哪 | SC-08、AF-11 | 共同定位没给，或者给了又被打乱 |
| 读者不知道在等什么 | SU-03、SU-04 | 问题没有早给；知识表里读者一栏是空的 |
| 悬念靠“作者不说” | SU-04、SU-07 | 把惊奇写成了藏信息；揭晓后回看不成立 |
| 读者早就猜到了 | SU-04、SU-05 | 类型惯例已经给出了答案；阶梯第一级就是最高级 |
| 伏笔像硬塞 | SU-06 | 伏笔出现时没有别的用处 |
| 反转像作弊 | SU-06、SU-07、SU-08 | 前文没有可回看的线索；叙述者隐瞒他明明知道的事 |
| 高潮不响 | SU-02（降级前文／重定峰值两条路由）、SU-06 | 前面有同类更强的场次；高潮场同时在建立设定；读者还不在乎这个人，不知道他会失去什么 |
| 中段塌 | SU-05、SU-11 | 阶梯不升级、只重复；没有松紧的落差 |
| 通篇都在炸，读者麻木 | SU-10 | 一个单元有好几个主峰；峰值的类型从不变化 |
| 转折了，读者没感觉 | SU-12 | 转折没有读者看得见的依据 |
| 情绪跑调 | SU-14 | 基调没定，意象各说各的 |
| 章末没人想往下看 | SU-15、SU-16 | 章末状态没变；这一章没推进任何一条线；钩子是把句子切断，不是真问题；连续几章用同一种钩子 |
| 结尾拖沓或像说教 | SU-17、SU-18 | 效果达成后还在交代；寓意在中途被说破 |
| 结尾欠账，读者问“后来呢” | SU-17 | 开篇的承诺没有结算 |
| 打斗像招式清单 | AF-02、AF-03、AF-05 | 没有停下来读谁占上风、凭什么 |
| 打完没有后果 | AF-08、AF-10 | 伤、资源、关系到下一场不起作用 |
| 主角太轻松 | AF-18 的边界、AF-10 | 巧合解围代替了选择；对手从不调整 |
| 恐惧只有形容词 | AF-05、AF-06、AF-07 | 缺触发、感官或行动上的依据 |
| 大场面是一堆数字或一团烟 | AF-11、AF-12 | 没有一条能跟着走的因果线 |
| 器械、通信和年代不符 | AF-10 | 历史参数没有核实（`references/scope-and-conflicts.md` §3） |
| 喜剧和残酷撞在一起 | AF-14、AF-04 | 笑点的位置和本作的契约冲突 |

## 5. 规则卡

完整的说明、适用条件、反例和操作步骤在参考文件里；括号里是本 Skill 的内部规则编号。

### 场景单位（`references/scene-units.md`）

- **SC-02 离场时有什么变了**：比较进场和离场：读者知道的事、关系、道德责任、期待、情绪、意象或模式，任何一项变了都算，不必是外在的胜负。都没变时先问是不是有意的（观察、仪式、停滞、间奏），是就记下功能，不判错。
- **SC-03 冲突由约束产生**：写出人物要什么、此刻拿不到它的具体约束、可选的行动、各自的代价。约束可以是空间、制度、承诺、贫困、身份，不必编一个坏人。
- **SC-04 跳接要有桥**：结果发生在场外或两章之间时，记下读者凭什么相信它：看得见的行动、物证或可信的转述。题材的时间跨度超出篇幅时，先考虑换处理法；主动的留白写明是本作的契约。
- **SC-05 现场写，还是放到场外**：默认把关键的行动写在场内；未知本身产生恐惧、必须保密、细写会破坏节奏时放到场外，并留下痕迹。用一个问题来选：读者需要亲眼看见什么？
- **SC-09 先找约束，再定结构**：每种结构形态都是某个约束的解。先写下本章要解决的约束和退出条件，再选组织方式；五幕、三幕和其他结构清单不是必守项。
- **SC-10 章链表**：兑现日志（SU-16）加“时空与视角的桥”“对下一章的约束”两列，不另建第二张表；日志的“属于主线还是副线”并入“仍悬置、计划在哪章回收”的格内，“回答方式”并入“本章兑现或转移了什么”的格内，不另加列。（本 skill 的方法）
- **SC-11 章末和场末的五种出口**：后果或抉择 / 重新理解 / 关系转向 / 余韵 / 知道的事变了。关系转向要写清下一单元形成的关系约束；每章都用悬念句收尾，会破坏抒情和独处的节奏。

### 知情、长谈与空间（`references/scene-information-and-space.md`）

- **SC-06 三层知情**：读者已知 / 行动者已知 / 视角人物此刻能说出的，三样分开记，加在 SU-04 的知识表上；全场只用这一张知情表。
- **SC-07 长谈三问**：改变了一项设计吗？语体和说话人相称吗？服务本作要制造的情感吗？三问都过，不因长而删；抒情、礼仪、哲思的段落按它自己的功能检查。
- **SC-08 空间与定位**：从人物此刻能感知什么、下一步要选什么出发。群战开打前，共同定位写一次，再补障碍、出口和资源；一对一的突发事件可以故意不给，因为张力来自误解。人多的场只让两三个人有完整的动作和台词，其余用群体反应带过，镜头每次只跟一个焦点。
- **SC-15 对白：每句有意图，可以不接话**：重要对话里每一句都在要东西、拒绝、试探、掩饰或攻击；没有意图的寒暄删掉或压成概述，建立日常质感的可以留一两句。冲突对话里打断、答非所问、沉默都是回应；交代关键信息的对话要答清楚。人物互相讲彼此早就知道的事，改成冲突中的追问、误解，或让不知情的人来问；仪式性场合的重述保留。潜台词转 `character-and-narrative-control` 的 PS-32。

### 伏笔与兑现（`references/setup-and-payoff.md`）

- **SU-01 终点先行**：动笔前可以先知道最后一拍和它的情绪，再倒推必需的事件；不在必需清单里的降为可选。短篇定终场，长篇定这一单元的终点。发现式写作可以先写，改稿时补上终点再回头删。
- **SU-06 伏笔要有当下的用处**：高潮和揭晓要用到的人、物、信息、能力，提前出现一次，出现时另有别的功能；揭晓后，前文至少有两处获得新的意义。删掉伏笔所在句，当下场景仍成立才算藏得自然。
- **SU-07 误认可回查**：先写清是谁误认——人物、叙述者，还是读者也被引向同一判断；误认要改变某个选择，修正时给出新的依据。不靠叙述者隐瞒他明明知道的事实。
- **SU-08 两种读法配现实解释线**：要保留超自然与现实两种解释时，两条解释都要有可观察支持和边界；人物信哪一条是人物的选择，不当作作品的结论。

### 悬念与揭晓（`references/suspense-and-reveal.md`）

- **SU-03 问题早给，答案晚给**：开头就让读者知道他在等什么；中间只加阻力，不换问题；答案按本作承诺安排。
- **SU-04 先画知识表，再选悬念方式**：读者知道得比人物少、或与人物同等无知，是悬疑，快感来自“能不能解决”；知道得多是反讽，来自“他会不会发现”；同步揭晓是惊奇，来自“怎么会”。同一条线可以有主导方式，也可在明确转折处改变。
- **SU-05 阶梯加码**：适合递增悬念的故事，通往高潮的问题或事件分几级；开头可以是日常、低代价的一级，此后逐级加大亲密、损失或不可逆的程度，每级写清主要升了哪一种代价。级数按篇幅和节奏调整，不设固定门槛；动作场面可以用障碍阶梯，喜剧可以升级荒诞、地位或尴尬。
- **SU-09 收紧空间或时间**：需要集中注意一个局部事件时，放进边界清楚的空间或限定的时间，标出边界、出入口、人物和关键物件的相对位置。从边界进入、范围逐步收窄、结尾固定在一处，是三种可以分开选的做法。

### 强度与节奏（`references/intensity-and-rhythm.md`）

- **SU-02 高潮是强度上限**：单峰目标下高潮先定，用 1–5 的相对自评标前面每一场（数字只在同一篇里比较，不是测量结果）；前文有同类更强的场次，降级或改为新高潮。**降级只降强度、篇幅、修辞，不降因果必要性、信息量、人物动机**；「削弱前文」不等于「中段注水」。检查：单峰目标只有一个 5 分，高潮之后没有无意中更强的新刺激。多峰结构每个单元一个主峰、单元之间换峰值类型。峰值冲突给「降级前文」「重定峰值」两条路由，由作者裁决，不擅自改已锁定章节。写情绪高点之前，先检查读者是否已经在乎这个人、知道他会失去什么；开篇的强情绪事件可以先给，关系后补。
- **SU-10 按阅读单元排强度**：短篇的单元是全篇，长篇是章或场景。一个单元一串短的效果和一个主峰；强度不可能持续拉满，连续高压会让读者麻木。不设固定峰值次数或字数阈值。
- **SU-11 松弛与急转**：高压之后给照护、整理或短暂安全，让后果进入人物生活；急转要有一条能回查的触发条件。不把安静场景判为拖沓。
- **SU-12 转折给看得见的依据**：转折可以突然，事后要能指出它依赖的条件；读者没猜到，不等于可以临时补规则。
- **SU-13 母题重复：本体基本不变，语境变**：选一个短的固定元素，每次出现换语境和所指；第一次出现通常写得平淡、带着当下的功能。次数以读者认得出、又不厌烦为准；中文可以借同韵、同句尾、同一个称呼。
- **SU-14 先定基调**：用效果先行的写法时，先用一个词定这一篇或这一场的情绪，再选题材、意象和词；意象可以强化、反衬或打断基调。也可以从新奇的题材或语言出发，再找基调。

### 章末与结尾（`references/chapter-ends-and-endings.md`）

- **SU-15 单元末三查**：状态变了吗？留下了什么真问题？这个问题是不是早被读者猜到、却一直在拖？分次阅读的章末留一个未解的真问题；一次读完的短篇只需要一个总收束。钩子是需要回答的问题，不是把句子切断。每章至少推进一条线（主线、感情线、成长线、悬念线中的一条）。
- **SU-16 钩子必须兑现**：每个钩子记进兑现日志（抛出章、回答章）；下一单元兑现上一单元的承诺；不打算兑现的钩子删掉。连续多章章末都是同一个问题，检查中段是否有进展。钩子的类型在危险、疑问、揭示、情感、反转之间轮换，不规定周期。
- **SU-17 场景/章节结尾两步**：只结算当前场景或章节承接的承诺，再找到本单元效果完全达成的那一句，试删其后内容。高潮之后可以留一个短的余波场，让读者看到改变之后的人物或世界；只交代下落的段落照删。全书承诺结算转 `story-architecture-and-longform-planning` 的 PL-11；卷级闭合与入口转 SV-04/SV-05。
- **SU-18 潜流与末行**：作品要含蓄的余味时，可以保留一条不说破的暗线；象征义延后显现，结尾落在具体的画面或固定元素上。同一个物件可以兼作线索，但象征读法不能代替破案、救人所需的证据。检查用作暗线的意象或物件在收束处出现一次、中途没有被解释句说破。要明说寓意的作品，改为开头明示、每次变奏加深。

### 动作与打斗（`references/action-and-fight.md`）

AF 卡全部是从小说个案归纳的推断，不是真实的格斗、战术或医学知识。

- **AF-02 打完一击之后**：换写对手的姿态、我方对下一步威胁的警戒、要不要追；长句连击可以写速度和失控。
- **AF-03 近身白刃**：谁控制持械的肢体 → 位置和力量的条件 → 结果；三项可以合写、换序、省略。
- **AF-04 以险代伤**：不能见血的场面，写离致命多近和对方的反射，伤害留到这一场之外。
- **AF-05 用身体的变化代替强度形容词**：手松、腿弯、呼吸变、擦拭器物；有独特作用的心理叙述保留。
- **AF-06 看不见时靠声音**：知情表加感官范围；用音色、音量、方向和声音的缺席推进。
- **AF-07 第一次开枪，身体先于意志**：第一次动手发生在宣告决心之前，事后补解释，写出落差；身体和意志一致也成立。
- **AF-08 赢了之后**：确认局面、处理余患；伤势约束后续行动时，选定伤在哪、影响什么、怎么处置，不知道就标“待核”。
- **AF-10 武器是会减少的资产**：资源改变可选行动时记账；用完、丢掉的不能无故恢复；数字不重要时写定性状态。
- **AF-11 群战：一个决策接一个物理后果**：给读者一条能跟着走的因果线；新兵视角可以有意打破。
- **AF-12 溃退**：可指认的失误 → 具体的误判 → 放弃动作；纪律的差异写成动作的差异。
- **AF-13 转述**：先判断转述者知道什么、记得什么、想要什么，听的人期待什么；失真和隐瞒分开。
- **AF-14 荣誉对峙的第三条路**：亮出本事、拒绝杀人；公开认可要先立规则和见证人；喜剧暴力和死亡哀悼按本作契约选。
- **AF-16 领袖负伤或死亡**：命令变短、最后托付，或者安排接手；没人接手也是分支。
- **AF-17 声音倒计时与坏消息接力**：立一条感官可判断的规则，再兑现、中止或错过；死讯的传递记下知情人、通道和误差。
- **AF-18 回合制的反制**：每回合记谁占优、怎么反制、哪个条件变了；公平的胜负要事先给足信息；警惕天助过密。

### 诊断与交付（`references/scene-and-action-diagnosis.md`、`references/rhythm-diagnosis.md`）

- **SC-01 先问目标，再套规则**：先按这一场要的效果判断要不要改；已经奏效的选择不因为不合惯例去“纠正”。不说“违反规则 X，所以必须改”；作者要对齐外部格式时，写明这是外部要求。
- **SC-12 症状 → 区分检验 → 改法**：每个场景症状先做一个区分检验，再选改法，并写明什么时候不该改。（本 skill 的方法）
- **SC-13 改之前先保存原有的功能**：写下这一段承担的人物、气氛、伏笔、节奏、象征，再选和问题相称的改法；有重要取舍时才并列小改和结构改。（本 skill 的方法）
- **SC-14 退出与边界**：没有稿子不声称逐段诊断；作者已定的实验和非写实契约优先；现实的技术、医学、法律不给伪装成事实的建议；效果判断写成待验证。停下时写明缺什么、要谁定、补上什么才能继续。（本 skill 的方法）
- **SU-19 数一数再判断**：交付前数一遍：主峰几个、在哪；阶梯每级升了什么；母题出现几次、语境变没变；钩子都有没有兑现章；结尾在效果达成后还写了多少；用作暗线的意象或物件在收束处出现一次、中途有没有被说破。数字只用来发现问题，不是及格线。

## 7. 冲突时的顺序

规则互相打架、又没有作者明确取舍时，按这个顺序取舍：本作的目标和契约（SC-01）→ 终点和高潮（SU-01、SU-02）→ 读者在等什么（SU-03、SU-04、SC-06）→ 因果和伏笔可以回看（SC-04、SU-06、SU-07、AF-08）→ 节奏（SU-10 至 SU-14）→ 修辞性的手法（SU-18）。两种做法各有代价时，给作者两个方案，由作者选。条件冲突与取舍见 `references/scope-and-conflicts.md` §1。

## 8. 适用边界与验证

- 本 Skill 提供叙事与场景设计方法，不替代现实中的战术、武器、医疗或法律专业判断。
- 涉及具体历史技术、文化制度和专业事实时，单独核实；不能核实时明确标记。
- 所有关于观众反应的判断都是设计假设。没有实际试读或测试时，不宣称效果已经验证。
- 规则是诊断工具，不是评分标准；保留作者明确选择的风格和结构。

## 9. 交付状态词

对作者交付只用三个状态词；依据不是状态词，作附件逐项附上：

| 状态词 | 什么时候用 |
|---|---|
| 已完成 | 检查已执行，且有稿件内可核的证据支持 |
| 未能核实 | 检查已执行，但结论依赖未核实的判断、设计假设或缺失的输入，不能记作已完成 |
| 待作者决定 | 存在冲突、取舍或锁定内容矛盾，由作者裁决，不擅自覆盖 |

依据随每项附证据或稿件内可核位置（不是固定答案，也不是来源背书）。

三个状态词也用于逐编号台账的「状态」列，依据填在同一行的「稿件证据位置」；「未知」是状态列的合法值，但不得把未知写成已完成。不把未验证的效果判断写成通过。

## 10. 失败出口

| 情形 | 出口 |
|---|---|
| 没有稿子、只有构思 | 改做设计路径；不出「稿子第几段有问题」的定位式诊断，写明哪些判断要等有了稿子才能确认 |
| 只说「这一章节奏慢」，不给正文 | 先要正文，先给检查清单，不臆断原因 |
| 峰值冲突（前文比预定高潮更强） | 按 SU-02 给「降级前文」和「重定峰值」两条路由，各写代价，停在待作者决定，不擅自改已锁定章节 |
