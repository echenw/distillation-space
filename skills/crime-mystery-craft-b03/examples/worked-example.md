# 示例：一次完整走法（虚构 request → 本 Skill 的四块输出）

> 本例的请求与稿子都是**演示用的虚构材料**，不来自任何一本来源；规则锚点才是真实的。

## 请求

> 我在写一栋公寓里的毒杀案。侦探是退休法医顾问。读者在第 8 章猜到了凶手。
> 我不想大改，能不能只改开场和揭晓？

## 第 1 步 · 判定（G1–G3）

- **G1 读者契约**：作者希望在揭晓时读者仍能被打到，而本稿采用正式的毒物检验链 → 定为**可解型**。
- **G2 不可能性来源**：本案没有"不可能"成分（公寓 + 毒杀），**跳过 R11a/R11b**，改判需要处理的是 R1 与 R5：现场只有死者一人，所以 R1 退化为"尸体姿态 + 时间窗"。
- **G3 收尾契约**：作者选**制度闭合**（走 PG57066 路线）→ 那么自白不能作为唯一承重墙（R8）。

## 第 2 步 · 命中规则

| 命中 | 信号 | 依据 |
|---|---|---|
| R1 | 发现尸体一段只有"她倒在桌边，脸色发青" | PG59126 L173-188 的做法是先把坐标写死 |
| R4 | 揭晓靠"顾问说杯子里的沉淀物是同一种" | PG57066 L8585-8590 要求有一件**不可替换的流通物** |
| R3 | 第 8 章被猜到：因为"她提前买了止吐药"和"她知道他胃不好"被直接串起来 | PG58820 L4258-4264 |
| R8 | 结尾依赖凶手的自白 | PG55313 L6977-6999 的假自白反例 |
| R13 | 退休法医顾问的专业腔承担了全部解题 | PG72948 L104-112 / PG66756 的处理 |

## 第 3 步 · 输出四块

### 1) 判定

可解型 / 无不可能性来源（仅 R1 退化版 + R5） / 制度闭合。

### 2) 案件设计表（填完的关键格）

```
A. 案发场景
  - 空间坐标（R1，退化版）：桌→椅→门的相对位置；死者坐姿；手边之物
  - 不可观察窗口（R2）：死者最后一次服药到被发现之间的 90 分钟
  - 现场方向（R5）：门是从内侧反锁的 → 但快递在 18:40 签收，构成"出口"读法
B. 不可能性：无（不选 R11a/R11b）
C. 误导（R3）：切断的联想 = "她买止吐药"→"她知道他会吐"
                插入事件 = 一场与呕吐无关的邻里纠纷（真实但不相关）
D. 证据链（R4）：不可替换物 = 药店留存的处方底联编号（唯一属性）
E. 侦探与入局（R10）：正式委托（物业方），由此他不知道死者与被告的私密史
F. 收尾（G3）：制度闭合；自白只作为补强，承重由处方底联完成（R8）
```
