# Crime / Mystery Craft（推理悬疑刑侦写作工艺 · 批次-03）

## 0. 这是什么

一份**人工填表 + 条件判断的设计/诊断 workflow**，不是自动化系统，也没有脚本。

- **输入**：你已有的设定或稿子（案件类型、侦探类型、篇幅、目标读者契约），或一句具体问题（"我的揭晓太弱""读者提前猜到了""密室怎么立得住"）。
- **输出**：一张**案件设计表**（§7 模板）+ 一张**线索记账表** + 按路由读取的规则动作。
- **不做**：不写正文；不预测销量/读者命中率；不提供真实侦查、法律程序或现代法医知识；不声称本批 30 本书"证明了"什么规律。

### 证据边界（先读这一条，否则后面的规则会被误用）

本批 30 份来源的 `material_role` **全部是 `FICTION_CASE`**（30/30，见 `references/05-source-index.md`）：小说作品，不是写作教材。

- 因此本 Skill 里**每一条规则都是 H（由可观察叙事现象升格的推断）**，不是作者讲授的方法，更不是跨作品实证律。
- 唯一接近"方法陈述"的原文是**角色台词或叙述者信条**（例如 PG807 的相面术、PG58820 的"防联想"论、PG59369 的柔道放松观）；它们一律按"角色自我主张"使用，并在规则里标出**当场被打回的那一句**。
- 覆盖与可信度：**30/30 台账区间满覆盖（254,635/254,635 行）**；27 本 `TRUSTED_FULL`（区间满 + ≥3 条英文逐字引文回源命中），PG68951 / PG71521 / PG807 为 `FULL_MINQ`（区间满但仅 1–2 条英文逐字引文命中）。明细在本包内的 `references/05-source-index.md`（该表已逐来源完整列出行数/覆盖/块/引文命中/可信度，**只安装本 skill 目录时以它为准**）；同批机器可读明细位于轮次根目录 `../../notes/p2-source-verification.json`（相对本文件的路径），**不在 skill 包内**，只安装 skill 目录时打不开——此时请用上面的 `references/05-source-index.md` 表。权利与许可见 `references/05-source-index.md` §权利与许可。
- 来源族去重：Fergus Hume 6 本（PG55313/55617/55783/56087/56385/56841）算 1 族，Fred M. White 2 本（PG56960/57066）算 1 族，Natalie Sumner Lincoln 2 本（PG68810/69004）算 1 族 → **30 本 = 23 个独立证据族**。只被单族单本支持的规则，置信不得超过"单族单本"。
- **F/H/P 标记**：F = 原文可定位事实（带 PG + 行号）；H = 叙事机制推断；P = 你要执行的动作。规则正文里逐条标注。

## 1. 触发 / 负触发

### 触发
- 设计一个推理/悬疑/刑侦案件的骨架（谁死、谁查、读者知道什么、何时揭晓）。
- 已有稿子"太早被猜到""揭晓没力""密室立不住""物证链断了""结尾收不住"。
- 在"公平可解"与"氛围惊奇"之间选不定。
- 想给侦探一个身份/入局方式，并想知道它会锁死哪些信息。
- 想判断某个技法在这批材料里有没有先例、有没有反例。

### 负触发（不要用本 Skill）
- **真实案件、真实侦查流程、法律咨询**：本批全是虚构作品，且其中多部以**误判、冤狱、陪审团悬案**为情节（PG59126、PG55617）。
- **现代法医/刑侦技术准确性**：最新来源为 1961 年（PG71521），此后的 CSI 化、DNA、数字取证一概不在证据内。
- **单句梗、段子、纯恶搞**：无案件结构需求。
- **"保证读者猜不到"**：超出证据边界。本 Skill 只能告诉你**这批作品用什么手段延后联想**，不能保证效果。
- **要求"作者原意"**：30/30 为 FICTION_CASE，无作者自述，作者意图一律 NOT_PROVEN。

## 3. 最短执行路径（3 个门，按顺序过）

**G1 读者契约**：你要的是哪一种？
- **可解型**（读者凭文本能推）→ 必须走 R1 与 R4，揭晓时物证链要一句话闭合。
- **氛围型**（惊奇/悬念优先，允许分期坦白）→ 必须走 R7 与 R9，并在文本里**自己承认过隐瞒**（PG1685 L95-99 就是范例）。
- 两者**不许混用**：一批来源里，PG1685 明示"侦探在庭上只说部分真相"，而 PG57066 用钞票号码把整条链摊开给读者——它们各自自洽，混用会两头不讨好。

**G2 不可能性的来源**（若你的案子有"不可能"成分）：
- 靠**结构**（气密保险箱、船舱、封死的房间）→ `02 §R11a`，先给结构再给尸体。
- 靠**视域不对等**（A 看得见 B，B 看不见 A 的地板）→ `02 §R11b`，先把视线关系画出来再写动作。
- 靠**出口而非入口**（现场是被"撬出"的）→ `02 §R5`。

**G3 收尾契约**（三选一，互不兼容，见 `03 §C2`）：
- 制度闭合（陪审/判决/当众复原）；
- 制度未闭合而侦探已动手（PG59126：陪审团悬案，凶手已被锁在寄宿屋）；
- 正义不闭合（PG66756：破案而无凶可惩；PG55617：结局仍保留未解层）。

## 5. 执行步骤（拿到一个真实请求时照做）

1. **判类型**：确认是"设计"还是"诊断"；若是诊断，先要稿子的①案发场景 ②嫌疑人名单 ③读者已知的线索清单 ④当前揭晓段落。缺任一项就先问，不要猜。
2. **过 G1–G3**（§3），把三个选择写进案件设计表；G1 没选定就**不许**开始改稿。
3. **按路由读对应 reference**，逐条对照"判断信号"列，勾出命中规则。
4. **做线索记账表**（§7 模板）：每一行 = 一条线索 × 出现位置 × 读者视角可见性 × 揭晓时由谁复原。**任何一条"读者视角不可见却在揭晓时被用作关键"的线索必须改写或补种。**
5. **写输出**：按 §6 输出合同交付；不写正文。
6. **自检三条**：①每处改动是否都能指回某条规则？②是否把某本单书诡计当成了通则（对照 `03 §7` 拒收清单）？③是否出现了"作者意图"式断言（一律禁止）？

## 6. 输出合同

每次交付固定四块，缺一块算未完成：

1. **判定**：读者契约（可解型/氛围型）+ 不可能性来源 + 收尾契约（G1–G3 三选一）。
2. **案件设计表**（§7 模板填完）。
3. **线索记账表**：行 = 线索；列 = 首次出现位置 / 谁看见 / 读者可见性 / 揭晓复原者 / 是否依赖读者不可见信息。
4. **动作清单**：逐条写"改哪里、改成什么、引 R几、失效条件是什么"，并标明每条是 P（执行）还是 H（推断）。

**禁止**：只给"这里可以更悬疑一点"这类无锚点建议；每条动作必须能指回 R1–R14 中的一条（R14 用于"这条不该做"的否决判定）。

## 7. 模板：案件设计表

```
A. 案发场景
  - 空间坐标（R1）：谁站在哪 / 尸体姿态 / 手中或身上之物（R12）
  - 不可观察窗口（R2）：凶手离场放在哪一段不可观察时间里
  - 现场方向（R5）：入口还是出口是舞台

B. 不可能性（若有）
  - 结构型（R11a）物理前提：
  - 视域型（R11b）视线关系（谁看得见谁的哪一部分）：

C. 误导
  - 要切断的联想（R3）：读者会把 X 与 Y 连起来 → 用哪件事打断
  - 只许"切断联想"，不许"让角色说谎"（R3 失效条件）

D. 证据链
  - 不可替换的流通物（R4）：物件 / 唯一性来源 / 揭晓一句话复原句
  - 官方错误叙事（R7）：谁先给出错误说法 / 由哪件物证推翻

E. 侦探与入局（R10）
  - 入局方式：社交误传 / 官方委托 / 亲眼撞上 / 误认到手
  - 由此锁死的信息边界：他能合法隐瞒什么、不能隐瞒什么
  - 专业腔处理（R13）：是真方法还是道具

F. 收尾
  - 契约（G3）：制度闭合 / 制度未闭合侦探已动手 / 正义不闭合
  - 自白处理（R8）：是否使用自白；若用，是否另有物证独立支撑
  - 自我限缩（R9）：本作承认了哪一条方法在此失效
```

## 8. 失败出口

| 情况 | 怎么办 |
|---|---|
| 用户要真实侦查/法律/现代法医 | 明确退出：本批 30 本全是虚构，且多部以误判为情节；建议另找专业来源 |
| 用户问"作者当时是不是想……" | 答 NOT_PROVEN：30/30 为 FICTION_CASE，无作者自述 |
| 请求超出 13 条规则（如"帮我设计本格二十四条守则"） | 说明本批没有守则类材料；可给的只有 H 级机制推断 |
| 稿子的核心装置来自单本（如"气密保险箱密室"） | 按 `03 §7` 拒收清单提醒：这是单本设计，不是通则；若要模仿需自行承担可迁移性 |
| 线索记账表里出现"读者不可见的关键线索" | 判为不可解；给出 R1/R4 补种方案或建议改签"氛围型"契约 |
| 找不到任何命中规则 | 直接说"这批材料不支持该问题"，不要套一条相近规则凑数 |
