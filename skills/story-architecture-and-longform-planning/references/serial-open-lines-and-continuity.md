# 跨卷的线与连续性（SV-08）

返回 [SKILL.md](../SKILL.md)。空白表在 [serial-tables.md](../templates/serial-tables.md)。

先分清两个词：
- **入口**：下一卷的第一步（SV-05 的开口）。有了新任务，不等于又开了一条待解的线。
- **开放线**：跨卷没结的承诺，下一卷要推进或回收。

## SV-08 开放线记账：少、可回收、每卷推进

**规则**：跨卷的线要能回收；下一卷已定时，每卷至少推进或回收一条旧线。写不出下一步动作的线不开。

**加设定前先查冲突**：新增设定前，先和已有设定、已发布的章节核对一遍。还没有发布的草稿可以改旧设定，但要记下改了什么；已发布的按“用后文接住”处理。

**用在**：系列卷、分卷连载里有跨卷主线；下一卷已定或很可能定；读者可能跳着读。

**怎么做**：
1. 建开放线台账（serial-tables.md §5）。每条线只写一个“下一卷必须推进什么”；写不出就关掉或改成氛围性伏笔。
2. 优先选择可执行的开放线：

| 线的类型 | 下一卷可执行的动作 |
|---|---|
| 在逃的人或宿敌 | 追捕、谈判、策反、和解、放弃追查 |
| 被关押或受限制的人 | 审问、转移、交换、营救、释放 |
| 身世、财产或承诺 | 兑现、核验、揭穿、争夺、放弃 |
| 地图、坐标、密码或物件 | 破解、抵达、验证、被抢、销毁 |
| 未完成的关系 | 重谈承诺、修复、决裂、拒绝继续 |

| 不宜直接开 | 问题 | 先做什么 |
|---|---|---|
| 没有接口的“神秘组织” | 写不出下一步 | 先落到一个具体的人、物或可观察行动 |
| 没有执行者的“古老预言” | 只能解释，不能回收 | 改成能验证的事实、物件或选择 |
| 主角不知道自己是谁，却没有线索 | 下一卷只能靠新设定 | 先给一个可调查的线索，或明确这是身份主题而非谜题 |
| 每卷再加一个更大的幕后黑手 | 只增不减 | 停开；先回收或关闭旧线 |

3. 记录活动线状态（开、推进中、待回收、已关闭）。两三条可作为初始管理目标，但不是硬上限；篇幅越长可以越多，台账和容量比数字重要。
4. 每卷末更新：推进、回收、转性或关闭至少一条旧线；若本卷刻意不推进，写明原因和下次检查点。
5. 超载时选出本卷真正活动的线，其余明确关闭、延后但不承诺，或转成独立单元；不用“以后会解释”挂账。
6. **转性**：旧对手成为客户、盟友或照护者，也算处理一条线；台账里写明“转性”，并说明新关系仍有哪些边界。
7. 和 SV-05 联动：SV-05 的“一个口”是本卷末新开的入口；台账统计全部活动线。台账已满时，卷末的口优先用于回收、转性或关闭。
8. 和容量联动：每条线在下一卷要占篇幅，台账加一列“预估章数”，防止下一卷超载（SV-13）。

**产物**：开放线台账；接手旧稿或要改动前面卷次的铺垫与回收时，加填系列—卷—章依赖矩阵（[serial-tables.md](../templates/serial-tables.md) §12）。

**不用**：单本闭合；下一卷没定（已有的线在本卷内关掉或转成单元）；纯单元剧，作者明确要每卷完全独立。

**卡住时**：
- 没有前卷：只建本卷台账；跨卷判断标“未能核实”，不算进活动线。
- 作者要开很多条线：照意图列出，同时写明每条在哪卷推进、哪卷收；收不进容量表时，请作者选出当前活动线，其余明确延后。
- 某条线收不回来：明确关掉（人物退出、承诺撤回、调查终止）或转成独立单元；不要用“下一卷会解释”挂着。
- 卷已发表、没法补交代：在下一卷开头用一段桥段补，不改已发表内容。

## 连续性检查流程

输入：至少两卷的卷末、卷首、人物表和章目；没有前卷就只查本卷。

1. **时间线**：每卷起止时间、地点、载具或据点状态；标出跳跃和矛盾。
2. **人物状态**：谁知道什么，谁受伤、离开、升职或死亡；查有没有被无意复位（SV-06）。
3. **世界状态**：组织、地点、载具能不能用；复位的方式是否前后一致。
4. **开放线**：逐条填台账；每条有没有“下一卷动作”和“最晚回收卷”。
5. **前情一致性**：卷首回顾和上一卷末是否矛盾；有没有把没发生的事写成前情（SV-07）。
6. **视点线**（多视点作品）：每条视点线在哪卷加入、哪卷收；单场视角问题转 `character-and-narrative-control`。
7. **输出**：时间线、人物、世界、开放线四节结论；每条带章号或短引文；附开放线台账。

只写人工判断和文本证据位置。查不到的写“未能核实”，不当作通过。
