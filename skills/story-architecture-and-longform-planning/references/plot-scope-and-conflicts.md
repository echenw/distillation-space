# 范围、条件分支与冲突（消费者版）

本文件回答三个问题：**什么时候用哪条分支、哪些冲突仍未决、规则适用边界在哪里**。规则正文在 `references/plot-rules.md`；此处只给消费者需要的选择条件与安全出口。

## 1. 条件分支总表

### 1.1 PL-03 高潮与解结的时点

| 分支 | 选择条件（预知度 × 后果需求 × 载体） | 起点 | 打结/解结 | 不适用/代价 |
|---|---|---|---|---|
| **A 单场次、观众预知** | 神话/史剧/改编；观众已知故事，要看“怎么做完”；事情办完=当场结束 | 从危机顶点开演，前史压成开场 | 解结可在本场后段 | 套到散文虚构 → 前史过长、人物无成长空间 |
| **B 散文虚构、要“后果”的重量** | 读者关心“之后怎样”；要清算、余波、代价 | 从较早处开始 | 打结约 3/4，末 1/4 解结（默认值，不是法则） | 套到 A → 前史拖沓；把 3/4 当硬指标 → 所有作品一个节奏 |
| **C 商业舞台、以“成不成”为悬念** | 观众不知道结果，买票看结果 | 从较早处开始 | 解结留末场 | 套到 B → 解结只剩两页；末场前泄底 |
| **D 命题推演型** | 转折本身是命题，后文演“必然后果” | 可从开场末转折 | 转折前置，后文演后果 | 套到 B → 开场即泄底 |

**判定顺序**：先问“观众已知多少”，再问“他们要看的是一件事，还是这件事的后果”，最后问“载体是否要求末场解结”。三问不能合并成一个“高潮位置”。

### 1.2 PL-08 多线汇合

| 分支 | 选择条件 | 结构 | 结尾 | 不适用/代价 |
|---|---|---|---|---|
| **A 因果汇合** | 存在一个事件能同时结算两线（婚礼/审判/死亡/揭露） | 定共同落点，倒推两线起点 | 一个总落点 | B 强并为 A → 人物去解决不属于自己的问题，动机不通 |
| **B 对照并置** | 无共同结算事件，但两线共享一个问题；中点照面可选，不是 B 型成立条件 | 共享问题 + 各自收束（中点场可选） | 两个终点，但须在同一场/同一画面并置 | A 误判为 B → 结尾断成两截；把“主题相似”当共享问题 → 伪多线 |
| **C 伪多线** | 只是“同时发生”，无共同问题、无交汇 | 合并为一条，或改“同时性编织” | 不宣布“多线结构” | 硬造汇合 → 造作；硬拆同时性 → 丢失新闻式并行效果 |

**判定顺序**：先做“删线测试”，再问“能否一个动作结算”，最后才考虑中点照面。**中点照面是一种可选结构，不是硬门，也不是 B 型成立条件；缺中点不判 C、不合并。**

### 1.3 PL-12 判断权归属

| 分支 | 选择条件（读者契约） | 文本做法 | 代价/防线 |
|---|---|---|---|
| **A 叙述者裁决** | 儿童、寓言、通俗连载、道德剧；读者共享该道德体系 | 明说教训/诗性正义；结局按奖惩结算 | 易说教；与读者共识不一致时，改结局或改读者群，不硬写 |
| **B 事件裁决** | 成人文学、悲剧；读者接受“后果即评价” | 只写行为与后果；叙述者退场 | 易冷；后果必须足够清晰，不能靠旁白补 |
| **C 读者裁决** | 反讽、现代主义、多视角；读者接受开放 | 多视角并置，拒绝结论；给“读法信号” | 易被误读；没有读法信号就是判断权分裂，不是 C |

**判定顺序**：先标全部评断句与奖惩结构，再做“删掉最后一段议论”测试。删掉后意义仍成立 → B/C；崩塌 → A（或补事件后果）。**不得一边说教一边留白。**

### 1.4 PL-15 工序选择

| 分支 | 选择条件 | 动作 | 失败模式 |
|---|---|---|---|
| **A 外部大纲** | 闭合型、多线、硬容器、新手、多人协作 | 写一页骨架（主行动、终点、中点、各线落点） | 过度规划 → 人物变工具；用骨架代替场景 |
| **B 心中大纲** | 成熟作者、短篇、文体驱动；能口述终点与中点 | 不强制纸面；把答案写成三句话存档 | 自述不可核；长篇多线容易中途失忆 |
| **C 发现式** | 人物/语言驱动、过程即目的 | 先写；完稿后强制 PL-05 因果审计 | 结尾靠巧合；中段无事；把“没想清”当风格 |

**判定顺序**：三问——终点是什么？中点转折是什么？谁在推进？有一问答不出 → 先补答案，再选工序；答不出且作品闭合 → 默认 A。

| 规则 | 分支 | 一句话选择条件 |
|---|---|---|

| PL-02 | A 闭合型 / B 开放探索型 | 读者关心“会不会”还是“怎么会” |

| PL-05 | A 内部必然 / B 外部偶然 | 换相反结果是否要改写前文 |
| PL-06 | A 开局加压 / B 解结付账（B1/B2/B3） | 巧合的位置与解决几个独立问题 |

| PL-10 | A 分次交付 / B 一次性交付 | 读者是否在两次阅读之间离开文本 |
| PL-11 | A 欠账 / B 余赘 / C 多线收束 | 承诺是否兑现；效果是否已完成 |

| PL-14 | A 承重 / B 余赘 / C 总括段 | 删掉后后文因/回声是否受损 |

## 2. 13 条冲突的消费者摘要

> 读法：**按条件** 必须按条件选一边，禁止写成“两者都重要”；**未定** 不写成规则，只给安全出口。冲突编号仅用于本文件内部定位，不对应外部来源编号；此处只给消费者需要的裁决条件与安全出口。

| ID | 冲突 | 裁决 | 消费者规则 | 选择条件 | 禁止/安全出口 |
|---|---|---|---|---|---|
| C-01 | 单一主行动 vs 双线汇于主结 | 按条件 | PL-01 | 短篇/强戏剧/单主角 → A 单行动；长篇/多卷/双线 → B 一落点多支流；判据是删线后主落点是否仍被挣得 | 不得写“单线多线都对”；不得把主题相似当副线 |
| C-02 | 解结在末场 vs 约 3/4 vs 开篇即顶点 | 按条件 | PL-03 | 按预知度 × 后果需求 × 载体选 A/B/C/D；3/4 只是 B 的默认值 | 不得把 3/4 当硬门；不得写“高潮可早可晚” |
| C-03 | 先写计划 vs 有机生成 | 按条件 | PL-15 | 闭合/多线/硬容器/新手/团队 → A；成熟短篇 → B；人物/语言驱动 → C + 完稿审计 | 不得写“有计划更好但也可随性”；必须给三选一判据 |
| C-04 | 人物先行 vs 事件先行 | 按条件 | PL-16 | 核心是“人做什么选择” → A 人物；核心是“发生了什么” → B 事件；核心是“一个反转” → C 胚情节 | 不得写“人物和事件都重要”；必须选入口并承担其失败模式 |
| C-05 | 结构可被清单穷举 vs 形式由内生成 | 按条件 | 全 Skill 的使用边界 | 初学/商业类型 → 规则作脚手架；成熟/文学/实验 → 规则只作诊断清单；作品只剩“正确”而无“必然” → 退回 B | 不得承诺“照做即好”；规则是检验器，不是生成器 |
| C-06 | 结尾必须闭合 vs 停在微妙处/开放 | 按条件 | PL-11 | 商业短篇/类型/连载单卷/儿童 → 承诺必须兑现；文学短篇/开放结构 → 可不解答，但须停在效果完成处并主题化 | 不得写“可以开放也可以闭合”；必须判“承诺是否被故意悬置” |
| C-07 | 诗性正义/道德落点 vs 不辩护/无教训 | 按条件 | PL-12 | 儿童/寓言/通俗连载/道德剧 → A 叙述者裁决；成人文学/悲剧/反讽 → B 事件裁决；多视角 → C 读者裁决 | 不得写“道德与艺术要平衡”；立场交作者，Skill 只查一致性 |
| C-08 | 框架/离题是否合法 | **未定** | 无规则（不进 16 条） | 当前可用的判断材料在“预先确定结尾”和“允许离题”之间显示不同适用条件，但不足以推出普遍规则；单个反讽性作品只能说明一种表达选择 | **安全出口**：闭合型情节小说默认不用框架/离题；若坚持，必须先写“单篇自足 + 读者契约 + 不闭合本身承担主题”三项，再动笔；不得写成“框架应当收/不应当收” |
| C-09 | 巧合是失败标志 vs 合法装置 | 按条件 | PL-06 | 开局/加压 → A 可用不付账；解结 → B 必须 B1 前债 / B2 配平 / B3 世界规则 | 不得写“巧合要用得巧”；必须判位置与付账方式；一个巧合解决 ≥2 个独立问题 → 几乎必败 |
| C-10 | 章末抛问题 vs 强情境后“降落” | 按条件 | PL-10 | 隔期阅读/分幕/日更 → A 抛真问题；连续口头讲述/一次讲多个故事 → B 降落再抬下一段 | 不得同时“抛问题”又“降落”；同一段落只能选一个方向 |
| C-11 | 篇幅数字互斥（8,000 / 7,500 / 3,000–6,000 / 10–20 章） | 按条件 | PL-13 | 有硬容器 → 按该容器当代参数反推；无硬容器 → 自定并显式写出 | 禁止把历史数字写成“短篇/长篇标准”；禁止取平均值（平均值不对应任何真实载体） |
| C-12 | 假定观众天真 vs 要求研究读者 | 按条件 | 无规则；作验收动作 | 初稿/喜剧/大众类型 → A 假定“聪明但没耐心”；定稿/投稿 → B 用真实读者或目标刊样本检验 | 不得写“既要有深度又要通俗”；阶段不同，标准不同 |
| C-13 | “规则系统不可自洽” vs “系统万无一失” | 按条件（元层） | 全 Skill 的置信声明 | 交付规则 → A 必须带失效条件/反例；使用者自述系统成功 → B 按“自述不等于效果验证”折价 | 不得把创作者的自我评价当作效果证明；不得删掉失效条件 |

**未登记为冲突的三处误报**（不要当冲突处理）：“计划 vs 不计划”常是“脑中清晰 vs 纸上解算”的混淆；“高潮位置正相反”可能是“起点”与“揭示时点”两轴混淆；“先定终局方向相反”可能只是两种工序，不是两个方向。

## 3. 规则适用边界

### 3.1 现实事实与虚构规则分开

- 规则卡处理情节、因果、人物选择、信息控制和篇幅分配；不替代现实法律、医学、工程、平台条款、市场数据或历史考据。
- 需要现实结论时，单独核验当前有效的一手资料；没有核验就标“未核实”，不要把虚构参数写成现实事实。
- 媒介差异会改变场景、时长、互动和信息呈现；不要把舞台、电影、游戏或连载的限制直接外推到其他媒介。

### 3.2 长篇多线需要按作品验证

- 跨卷弧线、章群节奏、视点轮换、时间跨度和多卷伏笔回收，必须结合当前作品的容器、读者契约和人物目标判断。
- PL-01、PL-02、PL-03、PL-08、PL-13 可以作为诊断问句和保守默认，不是“长篇法则”。
- 跨卷问题标“推断/待验证”；没有完整卷纲或正文时，不声称已经验证因果汇合和伏笔回收。

### 3.3 数字只作可调整的默认值

| 参数 | 当前用途 | 边界 |
|---|---|---|
| 主结约在 3/4 | PL-03 B 型的初始定位 | 可前移或后移；按情节类型、后果和载体调整，不作硬门 |
| 中点照面 | PL-08 B 型的可选结构 | 不是 B 型成立条件；缺中点不判失败 |
| 分段预算先近似均衡 | PL-13 的可选试算起点 | 不写死百分比；不要求中段更长；若某段更长，须由该段承担的结构功能解释 |
| 诊断严重度阈值（中段 40%、余赘 10%、单场 15%） | `plot-diagnosis.md` §4 的阻断/重要判据 | 默认值，可按作品、载体与升级规则调整，不作硬门 |
| 章末问题 | PL-10 A 型的分次交付方式 | 单行本或一次读完的作品不必每章留钩子 |
| 情境作为入口 | PL-16 的一种起点 | 不是情节定义，也不是唯一入口 |
| 恩惠、信息或物件推动巧合兑现 | PL-06 的可选路径 | 需在本作中提前建立，不能临时补规则 |
| 总括情境段 | PL-14 的压缩技巧 | 不是必须保留所有长段 |
| 每场像全剧缩影 | PL-07 的诊断问句 | 不是“每场必须三段落” |
| 连续口述后的降落 | PL-10 B 型的载体处理 | 只在连续口述等情境下使用，不搬到连载章末 |
| 诗性正义 | PL-12 A 型的叙述者裁决 | 是一种读者契约，不是现代默认 |

### 3.4 不要把重复案例误当多次验证

- 同一案例在多个文件重复出现，不构成多项独立验证。
- 人物话语、叙述者判断、创作者说明、文本中发生的事件和现实数据，是不同证据层级。
- 同一作品内的重复桥段可以证明该作品重复使用某种结构，但不能单独证明读者效果或行业规律。
- 类型惯例、作者偏好和平台要求可能影响设计，但不能替代当前作品的实际验收。

### 3.5 置信与效果验证

- 本 Skill 的规则是创作检查工具；没有真实读者测试时，不声称恐惧、幽默、情感、留存或商业效果已经验证。
- “高”表示规则的条件、边界和失败出口较清楚，不表示效果已被实证。
- “中/低”表示规则仍依赖特定类型、载体或假设；使用时要标明条件，不升级为通则。
- 没有完整稿件时，只能给规划建议或检查清单，不编造文本证据和诊断结论。

## 4. 参数和规则的安全用法

| 项目 | 默认用法 | 不得做的事 |
|---|---|---|
| 高潮时点 | 先按目标选择 A/B/C/D，再用比例作临时定位 | 把 3/4 写成所有作品必须遵守的标准 |
| 多线汇合 | 先做删线测试，再判断共同事件能否结算两线 | 把主题相似当成因果汇合 |
| 中点照面 | 作为可选结构，按人物和事件是否需要决定 | 把它写成所有多线结构的必需条件 |
| 篇幅比例 | 作为初稿预算，后续按场景功能调整 | 把历史页数、字数、章数搬成现代规范 |
| 章末钩子 | 按分次阅读和本章承诺选择 | 为了留存强度而把每章都切断在半句话 |
| 叙述者裁决 | 按目标读者和作品契约决定 | 一边明说教训、一边又声称完全开放而不处理矛盾 |
| 规则置信 | 明确条件、反例和未验证项 | 用“规则已写进 Skill”代替实际任务测试 |

## 5. 本文件的禁止项

- 不把单个作品的做法写成普遍读者规律。
- 不把历史篇幅、出版规格或当代平台指标混为一谈。
- 不把创作者自报、角色信念或营销文案当成读者效果证明。
- 不用“都重要”“视情况而定”掩盖必须作出的条件选择；给出判据、代价和安全出口。
- 不在缺少正文时编造章号、场次、对白、原稿行号或诊断证据。
