# 修订工作流：用可删除性删，用最小改动修

本文件只负责“已有稿要改”。规划见 `references/plot-planning.md`，诊断见 `references/plot-diagnosis.md`。规则正文在 `references/plot-rules.md`；此处按 `PL-xx` 引用，流程中就近复述的关键条件以规则正文为准。核心是 PL-14：**删什么由“后文是否受损”决定，不由“舍不舍得”决定**。

## 0. 授权、版本与工作副本

修订比诊断多一层权限：**默认不改用户原文**。

| 事项 | 默认 | 需要用户明确授权才能做 |
|---|---|---|
| 指出位置与问题 | 可以做 | — |
| 给修改建议（结构关系，不写全文） | 可以做 | — |
| 给“可选最小改写”（1–3 句/一小段） | 可以做，须标明“可选、可拒绝” | — |
| 改整场/整章/整条线 | 不做 | 明确范围（哪几章/哪条线）与目标（删/并/移/改结局） |
| 改叙述视角、人物声音、文体 | 不做 | 单独授权；本 skill 不负责声音专项 |
| 覆盖原文件 | 不做 | 不提供；只在副本上操作，保留原稿 |

**版本记录**：改前记稿名、版本/日期、字数/章数；改后记同一组数字。没有版本记录，回归检查无法判断“改了什么”。

**工作副本**：所有删改先在副本上做；原稿只读。不要把“删掉试试”直接写回用户文件。

## 1. 修订顺序：先诊断，再定层级，最后动最小处

1. **W0 冻结**：记录版本、范围、目标（例如“从 12 万字压到 9 万字”“修中段三章”“改结尾”）。
2. **W1 诊断**：按 `references/plot-diagnosis.md` 找症状与严重度；没有诊断直接改，容易把承重段删掉。
3. **W2 选层级**：结构修订 / 场景修订 / 句段压缩（见 §3）。一次只选一层；不要一边删章一边润句。**W2/W3 的试删与并入用 `templates/plot-scene-table.md` 的 `ST-20`–`ST-24` 记录**（候选场 / 删后是否需新过渡 / 后文因与回声是否受损 / 结论 / 回补或保留理由）。
4. **W3 最小改动**：先删/并/移，再补最小过渡；不重写整段，除非用户授权。每做一次删场测试，就把结果写进 `ST-20`–`ST-24`，不凭记忆记“删过”。
5. **W4 二稿回归**：重跑 PL-07 场景功能表与 PL-05 事件—因对照表；动了主线/结尾/开篇时加跑对应规则（见 §4）。
6. **W5 记录**：每个改动写“位置 / 原功能 / 改动 / 回归结果 / 未决项”。没有记录的改动不算完成。

## 2. PL-14 核心：可删除性测试

### 2.1 步骤

1. **列段落地图**：段号/场号、起止行、这一段在做什么、后文调用点（哪个事件/主题/人物关系依赖它）。
2. **标候选**：没有调用点的段/场先标 B（余赘）；有调用点的标 A（承重）；把整个情境说尽、信息密度高的一段标 C（总括段）。
3. **试删**：在副本上删掉 B 段，读前后接缝。
4. **判接缝**：
   - 不需要新写过渡，后文也没有因/回声受损 → 确认删除。
   - 需要一句过渡 → 补**最小过渡**（一句/一个从句），不恢复整段。
   - 需要整段补写，或后文某事件失去因 → 该段其实承重，标回 A，改写而不是删。
5. **复查**：删完后重跑 PL-07（每场是否仍有变化/功能）与 PL-05（事件—因是否仍成立）；不通过则回滚该次删除，不硬保“删了多少”。

### 2.2 承重段识别（A 类的四种载荷）

| 载荷 | 判据 | 例子 | 处置 |
|---|---|---|---|
| 因果载荷 | 后文某事件靠它提供因/伏笔/物件/信息 | 第三幕的钥匙在第一章被赠予 | 保留；可压缩，不可删因 |
| 回声载荷 | 主题/意象/人物关系在后文重复出现，靠它第一次立住 | 开篇的河流在结尾重现 | 保留至少一个“锚点句” |
| 节奏载荷 | 高压后的松气/低压后的蓄势；删了会让下一场失去对比 | 大战前的安静晚餐 | 可缩短，不可全删；确认下一场仍有压力 |
| 对照载荷 | 双线/群像中提供对照面 | B 线的失败映照 A 线的选择 | 保留对照点；可合并场次 |

**反信号**：因为“写得美/我花了很久”而保留 → 不是结构理由；因为“读者可能想知道”而保留 → 先查它是不是承诺（PL-11），不是承诺就是余赘。

### 2.3 最小过渡回补

- 只补“读者需要知道的那一句”：时间跳跃、地点转换、因果连接、人物状态变化。
- 不补“解释为什么删得好”；不补新的支线；不借机加设定。
- 过渡句优先放在被删段的前后场内部（动作/对白），不另起一段说明。
- 补完后读接缝：如果过渡句比被删段更突兀，说明删错了，回滚。

### 2.4 压缩长文本：保留什么

- 优先保留 C 类“总括情境”段：它把整个局面说尽，删了就丢信息。
- 保留原文语言峰值（最强的一句/一个意象）；删清单、重复、官阶/乐器式枚举、同义堆叠。
- 不把长句一律砍短；不把具体细节换成抽象总结；不删到“光秃轮廓”。
- 压缩后核对：事实是否仍在、因果是否仍连、语气是否仍是同一叙述者。

## 3. 三个修订层级：最小改动与回归

| 层级 | 什么时候用 | 最小改动 | 不要动 | 必跑回归 |
|---|---|---|---|---|
| **结构修订** | 主线/副线/结局/时点/多线关系出问题；中段大段无功能；容器严重超限 | 移动/合并/删除一个结构单元（一场、一章、一条线）；改一个落点；不重写整章 | 不改人物声音、不改已成立的世界规则、不换类型 | PL-07、PL-05、PL-01、PL-11；多线加 PL-08；开篇加 PL-04；时点加 PL-03；超限加 PL-13；解结靠巧合加 PL-06；工序未定先跑 PL-15 |
| **场景修订** | 单场无变化/功能不明/阻力太弱/信息给错 | 改四栏中的一栏：欲求、阻力、场末变化、功能；保留场的地点/人物/主要动作 | 不改前后场的因果；不新增副线；不借机扩写 | PL-07、PL-05、PL-09（若改信息）；连载加 PL-10 |
| **句段压缩** | 句子/段落冗余、重复、节奏拖；字数超限但结构不动 | 删余赘句/重复段；合并同义句；补一句过渡 | 不删承重段；不改事件顺序；不换叙述者 | PL-14 接缝检查、PL-07（场功能不变）、PL-05（因仍在） |

### 3.1 结构修订的最小动作

- **删一条线**：先用 PL-01 的删线测试确认它不是承重墙；删后把它的“功能”转给主线（一个物件/一句信息/一个代价），不直接消失。
- **合并两场**：保留两场中“变化更大”的那场，把另一场的阻力/信息压进它的对抗里；不要写成两段拼接。
- **移一场**：只移动，不改内容；移动后检查时间线、人物位置、信息顺序（PL-09）。
- **改结局**：先改“终局句”，再倒推需要补的因（PL-02/05）；不要只改最后一段。
- **改开篇**：先写契约句（PL-04），再决定删/移哪些背景；不要把整章重写成动作戏。

### 3.2 场景修订的最小动作

- 场末没有变化 → 加一个“决定/揭示/损失”，或把该场并入相邻场；不要加无关动作充数。
- 阻力太弱 → 让阻力来自一个已建立的人物/规则，不新造反派。
- 功能不明 → 在功能栏写明“铺垫/揭示/松气/主题回声/时间跨越”，并指出后文调用点；指不出 → 降为 C。
- 信息给错（读者早知/晚知）→ 只挪“揭示时点”，不改事件本身（PL-09）。
- 单场内部无“交代—纠葛—收束” → 合并或砍掉中段，不强行三段式。

### 3.3 句段压缩的最小动作

- 先删“重复解释同一件事”的第二段；保留第一次。
- 删“形容词堆叠/官阶/乐器式枚举”，保留最具辨识度的一个细节。
- 把“总结句”改成“动作/对白”，或直接删；不要把总结改成更长的解释。
- 每删一段，读接缝；需要过渡就补一句，不补整段。
- 不删“总括情境”段与语言峰值；如果非删不可，先确认它不是承诺/伏笔（PL-11/05）。

### 3.4 结构修订的三个补读规则（PL-13 / PL-06 / PL-15）

结构修订不只跑 PL-14；以下三条必须在 W2 选层级时补读，避免“删得对但改错层”。

#### PL-13 换容器 / 缩放粒度

删无可删仍超限（或改结局后体量对不上）时，二选一——换容器（改词数/章数/交付方式，须显式记录新参数与代价）或缩放粒度（减副线数、配角数、场景密度，**不动因果脊**）。先缩放、后换容器；不许“先写完再想办法”。分段预算可先按三段近似均衡试算；若某段更长，须由其结构功能说明，不把中段设为默认最长段，也不写死百分比。回归：新预算与容器对得上；缩放只发生在粒度层。

#### PL-06 改因 / 改果

删线、并场、改结局之后，若解结仍靠巧合，先判位置（开局/加压 vs 解结）。解结巧合走 B1 前债 / B2 配平 / B3 世界规则；三条都做不到 → **改因**（让主角自己造成）或**改果**（让巧合失败），不许换一个更巧的机关。回归：重列巧合清单（位置 / 解决几个独立问题 / 付账处 / 路径）；解结处不得留“解决 ≥2 个问题且无付账”的巧合。

#### PL-15 工序确认

动结构前重问三问——终点是什么？中点转折是什么？谁在推进？有一问答不出 → 先补答案再改；发现式作者（C 型）的结构修订只做 PL-05 审计 + 最小改动，不借修订强行改成大纲式。回归：工序声明未被悄悄改变；终点句与中点转折句仍能写出。

## 4. 二稿回归（强制）

修订完成后，至少重跑以下两张表；动了对应结构再加跑：

| 回归项 | 怎么做 | 通过标准 | 不通过时 |
|---|---|---|---|
| **PL-07 场景功能表** | 重填每场“谁要什么/阻力/场末变化/功能/后文调用点” | 每场有变化或写明功能；无连续三场 C | 回滚该次删并，或补功能 |
| **PL-05 事件—因对照表** | 重列事件，逐条写“因在哪” | 关键事件都有前文因；无“作者需要” | 补伏笔或改事件，不硬解释 |
| PL-11 承诺结算 | 重列开篇承诺与兑现场 | 主承诺全兑现；副线有交代或故意不兑现 | 补结算或回改开篇 |
| PL-04 开篇契约 | 重读首段，写“谁/要什么/挡什么/类型” | 一句能写出；基调与结尾同调 | 回改开篇 |
| PL-01/08 主行动/多线 | 重写主行动句；做删线测试 | 每条线能挂到主落点；A/B 型判据仍成立 | 改挂/合并/转 B 型 |
| PL-13 容器 | 重算总词数/章数/分段预算；检查缩放只动粒度 | 新预算与容器对得上；因果脊未变 | 换容器或继续缩放，不删因果脊 |
| PL-06 巧合 | 重列全部巧合与位置、解决几个问题、付账处 | 解结巧合都有 B1/B2/B3 或已改因/改果 | 补付账或改因/改果 |
| PL-15 工序 | 重问终点/中点转折/谁在推进；对照原工序声明 | 三问能答；工序未被修订悄悄改掉 | 先补答案，再动结构 |
| PL-03 时点 | 重写起点/打结/解结 | 三点仍落在具体场次；没有因删改而提前泄底 | 挪场或改类型 |
| PL-09/10 信息/章末 | 重画信息差表；抄每章末问题 | 读者仍知道在等什么；章末问题非假钩 | 补 inkling/改钩 |
| PL-12 判断权 | 重标评断句与奖惩结构 | 全篇仍是一个判断权；结尾未偷偷换边 | 删不相容评断句 |

**回归记录格式**：`改动位置 | 改动类型 | PL-07 结果 | PL-05 结果 | 其他回归 | 结论（通过/回滚/待定）`。没有回归记录的修订，只能标“未验证”。

## 5. 输出格式：定位 + 建议 + 可选最小改写

默认给三件套，不给“全文新版”：

1. **定位**：章/场/行号；引原句 ≤40 词（或准确转述）。
2. **问题与建议**：用哪条规则卡（`RC`，即 PL 编号）、分支是什么、最小改哪里、不动什么。
3. **可选最小改写**：只改点名的那 1–3 句/一小段；标明“可选、可拒绝”；不改人物声音与视角。

若做了删场/并场，附 `templates/plot-scene-table.md` 的 `ST-20`–`ST-24` 记录（候选场 / 是否需新过渡 / 因与回声是否受损 / 结论 / 回补理由）；它是修订与回归的证据，不是第四个交付物。

示例格式（不是真实案例）：

```
定位：第 7 章第 2 场（示例位置）
问题：场末无变化；功能栏空白（PL-07 C 类）
建议：并入第 8 章开场，保留“她发现钥匙是假的”这一揭示；不新增人物
可选最小改写：把那句总结句改为她放下钥匙的动作（1 句）
回归：PL-07 该场删除后，第 8 章仍需“假钥匙”信息 → 改为并入而非全删
```

**越权红线**
- 不把“建议”写成“我已经帮你改好全文”。
- 不在未授权时改结局、视角、人物关系、世界规则。
- 不借修订加入自己的主题/道德判断（PL-12 交作者）。
- 不删用户原稿；所有试删在副本。
- 不声称“改完就会更好”；只声称“结构关系是否更清楚”，效果仍未证实。

## 6. 失败/退出

| 情况 | 能做的 | 不能做 / 退回 |
|---|---|---|
| 没有用户稿件，只有“帮我改好” | 给诊断清单，说明需要作者补哪些文本；作者给了范围和目标，就在副本上改写 | 不编造稿里没有的“文本证据”，不覆盖原稿 |
| 没有修订目标（字数/范围/优先级） | 先做诊断，按严重度排序；给三个可选目标及代价 | 不擅自定“砍一半” |
| 作者拒绝删任何内容 | 改走“场景修订”：加变化/并场/移信息；结构问题标“未解决” | 不硬删、不表面压缩 |
| 作者要求保留所有副线 | 做 PL-01 挂载表；不能挂的线标“并列/番外”，不冒充副线 | 不把无关线强行汇合 |
| 作品以繁复/氛围为效果 | 只做接缝检查与局部重复删除；结构表只作参考 | 不按“砍一半”经验值删 |
| 规则与作者意图冲突 | 记录冲突：规则 A vs 作者意图 B；给代价与替代 | 不宣布规则优先；作者对故事有最终决定权 |
| 版本不明/删节本 | 标 “未核”；只对已读范围给建议 | 不诊断未读部分 |

## 7. 修订阶段的禁止项

- 不把“可删除性测试”做成“凭感觉删”；每次删除必须有调用点检查与接缝试读。
- 不把“砍一半”当测量；它只是新手经验值（PL-14）。
- 不在结构未定时做句段润色；先修因果/场景，再压句子。
- 不用“过渡段”掩盖结构断裂；过渡只补读者必须知道的一句。
- 不删数据、不覆盖原稿、不把试删写回用户文件。
- 不声称修订后效果已验证；本 skill 只有静态规则，真实效果未证实。
