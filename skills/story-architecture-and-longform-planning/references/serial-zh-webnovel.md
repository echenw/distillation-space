# 用到中文网文

返回 [SKILL.md](../SKILL.md)。

本 skill 的依据是 1884–1925 年英美的编号丛书、周刊和分部长篇，没有中文网文样本，也没有读者数据。下面是迁移建议：每张卡在网文里对应什么、怎么用。单章字数、更新频率、上架节点等参数，以作者所在平台的规则和合同为准；本 skill 不回答“应该日更多少”。

## 1. 对应关系

| 本语料里 | 网文里 | 卡 | 怎么用 |
|---|---|---|---|
| 编号丛书的一号、一本合订卷 | 一部书里的一卷：一个大剧情（一张地图、一个副本、一个案子、一个阶段目标） | SV-01 | 网文多数是“一部书分卷连载”，卷末默认留入口。全闭合只出现在完本、改成单元剧，或者下一卷确定换主线时 |
| 卷首书目、下一号预告 | 卷名、卷首简介、作品简介、更新公告 | SV-02 | 卷名用同一句式；卷表的“节点”写上架、加更、请假等计划 |
| 三种部界 | 换地图（旅行任务型）、同一座城同一条时间线（连续型）、一卷一个案子（系列型） | SV-03 | 换地图的那一卷交代谁跟来、谁留下，修为、资源、身份带过去多少 |
| 闭合度 | 卷末的大剧情收尾 | SV-04 | 下一卷就是同一本书的下一段，通常半开；连续追同一个仇人的可以全开，但要让本卷有一笔结清的账 |
| 先结账、再开口 | 卷末高潮之后的收尾章 | SV-05 | 结账写成读者能核对的：比赛名次、案子告破、仇人伏法、境界突破、拿到手的东西；口只开一个，写成一个动作 |
| 复位世界、不复位角色 | 回到宗门、公司、学校的日常 | SV-06 | 战力、身份、关系、伤势不回退；不用失忆、封印修为来“复位”；给配角一个不可逆的变化 |
| 续卷回顾 | 新卷第一章 | SV-07 | 读者多是连着追的，一两句能力句或关系句就够。长期断更后回归，或者新卷换了大地图和班底，才需要长一点的前情；前情放进一个当下场景里，不另写大段复述。作者的话里的前情提要不算正文 |
| 开放线 | 坑、伏笔 | SV-08 | 台账比数字重要。百万字的书，活动线可以多于三条，但每条都要写得出下一步动作和最晚回收卷；写不出的先别挖 |
| 章末落幕 | 断章 | SV-09 | 日更读者连着读，同一种断法更容易被看穿：三种收法轮换，下章首句落地。断在一个点上，不断在半句话上 |
| 每期不拖 | 水、注水 | SV-10 | 每章写一句“本章推进了什么”；字数不够宁可短，不灌设定和重复的心理活动 |
| 套路与变化 | 套路、爽点循环（打脸、升级、夺宝、救人、揭身份） | SV-11 | 固定骨架，每卷换一两样；同一爽点第二次要换代价或换对象，第三次删掉或写出理由 |
| 要不要升级 | 境界、战力、地图、势力的升级 | SV-12 | 先定系列承诺：读者买的是新地图、更高代价、身份翻转，还是经营。不默认“每卷必须升一级”；赌注要配得上这一卷的字数 |
| 容量先于情节 | 单章字数、日更字数、每卷字数、上架或入 V 的节点、全勤之类的平台规则 | SV-13 | 参数照平台规则和合同填；每三章对一次实际字数；超了先删从属线 |
| 开载路线、存稿 | 存稿再发、边写边发；断更、请假 | SV-14 | 开书前填开载检查表；存稿能撑几天写清；请假和断更的预案写进去 |
| 反馈日志 | 评论区、段评、书友群、订阅和追读数据 | SV-15 | 进日志，等第二个同向信号；一条差评不改主线；人物退场先写预案 |

## 2. 要多想一步的地方

- **卷是不是售卖单位**：网文多按章计费，卷不单独卖。卷表照样有用，用来排剧情阶段和更新计划。
- **章长**：本语料一章两三千英文词（Cook 的丛书每章 5 页）。网文单章字数按平台习惯和作者节奏定，不要把英文词数换算成中文字数来套。
- **更新越密，回顾越短，章末收法越要轮换。**
- **长篇的线数**：本语料是十几到几十本的有限丛书。几百万字的长篇，三条的上限可能不成立；“最晚回收卷”一栏更要紧。
- **读者数据**：本 skill 不预测订阅、追读、完读。用数据做决定时，写清用了哪一项、和什么比。
- **时代局限**：这些丛书里有种族刻板形象（比如 Motor Matt 里的华人少年仆从 Ping、侦探丛书里对华人的蔑称和“秘密巢穴”），只能当时代注记，不能当人物或情节模板。

## 3. 写法

迁移时写成：“在（平台、更新节奏、类型）条件下，可以先试（做法）；依据是（卡号）在百年前英美连载里的做法，网文里没有验证过。”不要写“网文都应该……”或“经验证明……”。
