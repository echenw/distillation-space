# 套路与升级（SV-11、SV-12）

返回 [SKILL.md](../SKILL.md)。空白表在 [serial-tables.md](../templates/serial-tables.md)。

先记一句：**重复不是优点，是成本。** 套路降低读者进入新一卷的成本，也会积累疲劳。目标是可控变化，不是越像越好，也不是每卷都更大。

“期”和“卷”的口径：一期是一次发表的单位（一章、一个分册、一个刊期）；一卷是一个编号卷或合订卷，通常含多期。

## SV-11 套路：固定骨架，每卷只换一两样

**规则**：固定主角、班底、事件类型或叙述方式，让读者认得出系列承诺；每卷可以选择一两项关键元素作为变化焦点；这是便于规划的可选起点，不是硬性配额。同一节拍再次出现时，改变代价、人物关系或结果，不只换场景名称。

**用在**：编号系列、常驻班底、重复任务类型；第二卷以后。

**怎么做**：
1. 建套路与变化表（serial-tables.md §7）：固定项写一列，可变项写一列。

| 可以固定 | 每卷可变化 | 不宜机械固定 |
|---|---|---|
| 主角、常驻班底、核心类型、叙述方式 | 场景、道具、对手、代价、盟友的作用 | 每章反转位置、每卷最后一分钟救援、反派逃跑方式 |

2. 可先选一两项变化焦点，分到不同章节；数量按系列承诺、篇幅和本卷任务调整，不必在同一章里同时更换所有元素。
3. 标出本卷同一节拍出现几次。第二次检查代价、关系或信息是否不同；只换项目不算真正变化。
4. 第三次重复时，考虑删掉、合并，或写出“这次为什么非重复不可”。
5. 疲劳信号出现时检查：

| 信号 | 问自己 | 处理 |
|---|---|---|
| 同一节拍再次出现 | 这次的代价和上次有什么不同？ | 换代价；说不出就删或合并 |
| 同一种救法 | 被救的人、救人的人、代价变了吗？ | 换功能，或让这次救援失败 |
| 同一种逃跑 | 逃跑之后推进了哪条线？ | 进台账（SV-08）；否则改成被捕或转性 |
| 同一个功能位 | 角色这次帮了多少、付出什么？ | 换功能位，或减少戏份 |
| 同一种故障、同一种巧合 | 它改变了任务目标吗？ | 改成选择的后果；否则删 |
| 老面孔反复登场 | 这次给了他新的处境吗？ | 换处境，或安排退场（SV-15） |

**产物**：套路与变化表。

**不用**：单本；以人物成长或悬念为主要卖点、重复会立刻显形的作品；每卷换主角、换类型的系列。

**卡住时**：变化表填不出来，说明还没有稳定套路；先做卷表（SV-02）和容量表（SV-13），不硬造“每期一个花样”。

## SV-12 升级不是必选，先定系列承诺

**规则**：下一卷要不要加码，先定系列承诺：读者买的是“同一个主角去新地方”“更高的代价”“身份和位置翻转”，还是“经营和产权”。升级不是唯一方向。

**用在**：作者问“下一卷要不要升级、换地图、提高赌注”；数值、战力或赌注越写越大收不住。

**怎么做**：
1. 写下系列承诺：读者每卷期待什么持续不变，什么可以变化。
2. 从以下几种方向选择一种为主：

| 方向 | 主要变化 | 需要检查 |
|---|---|---|
| 换地方 | 新地点、新规则、新对手 | 是否每卷都从零开始；上一卷代价有没有带来 |
| 身份和位置翻转 | 人物从被追捕者变成谈判者，或从盟友变成责任承担者 | 翻转是否有前置原因，是否改变人物选择 |
| 换成经营和产权 | 冲突从营救转成所有权、经营、责任或控制权 | 读者是否接受赌注种类变化；规则是否解释清楚 |
| 代价加大但主角不变强 | 主角失去资源、身份或选择空间 | 是否通过后果升级，而不是临时增加能力 |
3. 赌注要配得上篇幅：花大量篇幅追的目标，应在人物生活或故事结构中有相应分量。
4. 选定后写进卷表（SV-02）的“本卷主事件”，并在套路与变化表（SV-11）里标出变化项。
5. 不把上表当路线图，不必每卷轮流使用不同方向。

**不用**：单本；作者已经定了系列承诺。

**卡住时**：作者要“每卷必须升级”，照做前先说明代价（数值膨胀、旧对手失效、世界规则不断补丁），并给一个“换地方不加码”或“换赌注种类”的替代方案。
