# 分卷连载规则卡（SV-01 至 SV-15）

返回 [SKILL.md](../SKILL.md)。本文件是分卷连载规则的完整卡片：规则 → 怎么做 → 例外和起点 → 示例与应用说明。分支细则、卡住时、短引文和可信度在各自的参考文件里：SV-01 至 SV-07 见 [serial-volume-and-closure.md](serial-volume-and-closure.md)，SV-08 见 [serial-open-lines-and-continuity.md](serial-open-lines-and-continuity.md)，SV-09、SV-10 见 [serial-chapters-and-installments.md](serial-chapters-and-installments.md)，SV-11、SV-12 见 [serial-formula-and-escalation.md](serial-formula-and-escalation.md)，SV-13 至 SV-15 见 [serial-production.md](serial-production.md)。



### 形态与分卷

**SV-01 先定形态，再谈分卷**：动笔前回答两问：哪种形态？下一卷（或下一段）定了没有？单本闭合：一本写完，不打算续，只用 SV-03、SV-13。系列卷：每卷是一本或一号，能单独读，班底跨卷，用全部卡。一部书分卷连载（多数网文）：全书连续，卷是剧情阶段，卷末通常留入口，续卷回顾很短。连续追捕：一条主案跨多卷，不要求每卷结主案，但每卷要结一笔局部账。下一卷没定，按单本处理。

**SV-02 卷表先于故事**：卷是排期或售卖单位，或者作者要按计划交稿时，先填卷表：卷号、卷名（同一句式换关键词）、本卷主事件、篇幅、闭合度、下一卷第一步、节点、状态。没定的卷只写卷号，不填入口；已写的卷只改状态，不改历史。多视点作品加一列“本卷视点线”。

**SV-03 卷界按主线类型切**：连续时间线按关系或危机阶段切，下一卷接着上一卷的那一夜写；旅行和任务按地点、阶段切，换地点、跳时间、交代谁跟来谁留下；系列卷按结账和开口切（SV-04）。三种切法不混用。不追求等长，末卷可长可短，阶段完整就行。叙述者在终卷死去、换人续写，是终卷手法，中间卷不用。

### 卷末与卷首

**SV-04 闭合度看“下一卷定没定”和“本卷许诺了什么”**：全闭合、半开、全开都有成立的例子，不是一条升级路线。下一卷已定：留一个入口；没定：全闭合；连续追捕：可以全开，新读者靠下一卷的回顾进来（SV-07）。宿敌可以活着离场而本卷照样全闭合。作者问“哪种更好”，答：都成立，看合同和下一卷，没有读者数据。

**SV-05 先结账，再开口**：卷末先让读者核对本卷的账（比分、破案、追回的钱、获救的人、抵达的地方），再开下一步。口只开一个，而且是一个动作：密令、委任、实物、坐标、一张纸条，不是一个新组织或“新的危险正在逼近”。结账和开口之间隔一个收束动作：一段对话、一次结算、一个人物的选择；不必单独留一章。卷末四问有一问不过，先修本卷，不留给下一卷补。

**SV-06 复位世界，不复位角色**：卷末把能继续干活的基线还原：据点、组织、载具、班底；机构的决定可以“暂缓”，不撤销。角色的能力、关系、声望、伤亡留下来。至少留一个不可逆的变化，最好落在配角身上（起点）。两种毛病：每卷回到同一基线、同一种救法（复位过度）；上一卷的伤和债消失（复位不足）。

**SV-07 续卷开头：先落当下，再补前情，再回当下**：续卷第一章先给一个现在时的场景（谁、在哪、在做什么），再用一段回顾补前情，然后回到当下。回顾三块：人物点名、上一卷结了什么、现在要做什么。长短按读者隔多久回来：可跳读、隔得久用长版（本语料两例约五千和七千字符）；连续追读用一两句能力或关系句。可以写一句同时对老读者和新读者说的话。

### 跨卷的线

**SV-08 开放线记账：少、可回收、每卷推进**：每条跨卷线写清：是什么、哪卷开、下一卷必须推进什么、最晚哪卷收、怎么收。只开写得出下一步动作的线：在逃的人、被关的人、身世和财产、半张地图或坐标。活动线到两三条就停开新线，先收或关旧线（起点）。线可以转性：旧反派变成客户或朋友，转性后不再记为债。无名组织、没有执行者的预言，先落到一个具体的人或物再开。

### 章与期

**SV-09 章末落幕，下章落地**：分次读的章，末尾把动作推到一个点上收住，三种收法：来了一个人或一个声音（得是本章的线上的，不是凭空闯入）；提出一个要回答的问题；判定一个新事实。下一章第一句交代时间、地点或谁在动，不复述上章。同一种收法连着三章，换一种或改成场景收束（起点）。最后一章让位给卷末入口（SV-05）。一次读完的书、同一场景连着写的章可以平收。钩子怎么写、怎么兑现，转 `scene-conflict-and-rhythm` 的 SU-15、SU-16。

**SV-10 每一期都不能拖**：分期发表，每一段都要单独站得住，至少推进一件事。写的人自己觉得长了，读者一定也觉得。对话要推着故事走；事件要多，不能是旧的；情节可以简单，但要醒目。注水和删段的判据转 `fiction-planning-and-diagnosis`。

### 套路与升级

**SV-11 套路：固定骨架，每卷只换一两样**：固定主角、班底、事件类型和篇幅，让读者认得出；每卷换一两样（场景、道具、对手、代价、盟友的作用），分到不同的章，不在同一章里一起换（起点）。同一节拍在一卷里第二次出现要换代价；第三次删掉、合并，或者写出必须重复的理由。重复是成本：编辑一边要“the same hero and the same class of incidents”，一边嫌旧稿“the action was rarely varied”。

**SV-12 升级不是必选，先定系列承诺**：要不要加码，先问读者买的是什么：同一个主角去新地方？更高的代价？身份和位置的翻转？经营和产权？四种都有例子，加代价的例子靠施救者被俘，不靠主角变强；没有证据说哪种更好，作者定。选定后检查：换地图会不会让每段都从零开始；加代价会不会拿走主角自己动手的机会。赌注要配得上篇幅。

### 生产

**SV-13 容量先于情节**：合同、版式或更新节奏先定了长度，先填容量表：载体、每章字数、总章数、总字数、钩位、交稿节点、缓冲章、备用结局，再由容量推章数。每三章对一次实际字数。超了先删从属线、并章，不挪主线终点。容量表是计划，不保证写得完。别人的数字不照搬，可以借的是结构：自定计量单位、逐日记账、配额有上下限、动笔先重读昨天的稿。

**SV-14 开载路线按条件选，有存稿再开**：两条路线都有作者走过。完稿再发，保留“让开头配合结尾”的余地（Trollope，一生只破例一次）；写完若干章就开载，用截稿日逼自己写完，代价是不能回头改（Daudet）。按三个条件选：首发能不能推迟？是不是靠截稿日才写得完？故事依不依赖前期埋下的伏笔？边写边发，开载检查表里写清存稿能撑几期。

**SV-15 反馈先进日志，不直接进稿**：连载中记反馈日志：日期、来源、具体要求、影响什么、代价、决定、复核日期。单条反馈只记不改，等第二个同向信号或编辑的正式要求。常驻人物预先想好退场方式；合同允许时，留一两期能提前收束的备用结局。
