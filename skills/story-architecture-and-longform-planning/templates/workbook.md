## PA-01–12 情节画布

| ID | 字段 | 填写口径 |
|---|---|---|
| PA-01 | 作品、版本、任务和工序 | 范围、已读/未读、载体、目标读者、纸面/心中/发现式或混合。 |
| PA-02 | 素材与矛盾 | 行动者/群体的欲求和恐惧；外在行动或心理选择；环境/规则；入口和阻力。 |
| PA-03 | 组织原则 | 主行动、核心问题或时间/框架/声音组织；承诺、结果与可变范围。 |
| PA-04 | 逐线关系 | 因果、对照、编年/框架或混合；起终点、挂载、独立价值；中点会面可选。 |
| PA-05 | 终点候选 | 谁在何事后得到/失去/未决什么；依赖事实、可变结局、删并风险；可UNKNOWN。 |
| PA-06 | 关键节点 | 起点、打结、高潮、解结和余波；各自事件、功能、位置；无固定比例。 |
| PA-07 | 容量预算 | 词/字/页/时长、部幕章期、版式、硬约束/假设、交期、超限选项。 |
| PA-08 | 开篇入口 | 欲求/问题/声音/情绪/环境/框架；当前需要的信息、后置内容和预期。 |
| PA-09 | 信息时序 | 人物、叙述者、读者各自所知；提示、揭露、悬念/惊奇/反讽可并存。 |
| PA-10 | 承诺回应 | 作者引导的期待与人物愿望分开；已兑/转化/放弃/有意未解及余波/截断。 |
| PA-11 | 判断层次 | 叙述者评语、事件结果、人物判断与读者解释；一致/反讽/分歧信号。 |
| PA-12 | 未决项 | 缺文本/版本/决定/数据；影响字段、谁可决定、当前可继续部分。 |

## ST-01–24 场景、章界与删并

| ID | 字段 | 填写口径 |
|---|---|---|
| ST-01 | 场号 | 与当前稿件一致，可给新增场临时ID并标DESIGN。 |
| ST-02 | 视角/时空 | 所知位置与当前时空；不适用与未知分别标记。 |
| ST-03 | 欲求/注意方向 | 主动者要什么或此场注意什么。 |
| ST-04 | 阻力 | 人物/环境/规则等；无阻力不自动失败。 |
| ST-05 | 场末状态 | 决定、信息、关系、损益、无变化或有意悬置。 |
| ST-06 | 功能 | 推进、铺垫、揭示、松气、回声、时空压缩、声音/氛围或其他。 |
| ST-07 | 后续调用/即时价值 | 所需后文定位，或当场审美/情绪价值；无调用不自动删。 |
| ST-08 | 处置 | 保留/改写/并入/移位/删/待核及理由。 |
| ST-09 | 子检查场号 | 只展开与问题有关场景。 |
| ST-10 | 交代 | 谁/哪/何时/注意什么；可以不显说。 |
| ST-11 | 纠葛 | 阻力、转折或有意静止。 |
| ST-12 | 收束 | 变化、余韵、钩或连续动作。 |
| ST-13 | 缺项意义 | 是否真妨碍当前功能；不凑三项。 |
| ST-14 | 章/期编号 | 单本和连载按需要使用。 |
| ST-15 | 已解决 | 已答问题、阶段行动或情感完成。 |
| ST-16 | 仍期待 | 新旧问题、余韵或无悬念；不强迫下一章回答。 |
| ST-17 | 所属线/功能 | 主线、副线、关系、声音等；没有主副标签不等于假钩。 |
| ST-18 | 回应位置 | 后续具体位置、部分回应、有意延后或未知。 |
| ST-19 | 误导风险 | 预期是否被无故撤销、重复、冲突；有意风格单列。 |
| ST-20 | 删并候选 | 一场或有关联的一组；说明测试范围。 |
| ST-21 | 接缝 | 需要何种过渡及原因；补写长度不直接决定价值。 |
| ST-22 | 价值损失 | 因果、信息、关系、情绪、回声、语调、审美。 |
| ST-23 | 结论 | 承重/可压/摘要/移置/余赘/保留/待核，不以一项自动判。 |
| ST-24 | 回补或保留理由 | 实际改动、位置、词数变化及余留风险。 |

用ST01–08建场景表，ST09–13展开相关场，ST14–19查章界，ST20–24记删并。功能图例：A推进；B1铺垫；B2揭示；B3松气；B4主题/关系回声；B5时空压缩；B6氛围/声音；C暂未识别功能。C不自动等于应删；重复、静止和美感可有独立作用。

## DR-01–10 与 DR-SUM 诊断

| ID | 字段 | 填写口径 |
|---|---|---|
| DR-01 | 范围版本 | 总长度、已读/未读、目的、交付、日期。 |
| DR-02 | 文本证据 | 实际章场行、短引或准确转述、结构事实、反馈来源。 |
| DR-03 | 症状 | 流程中症状可扩展；不同问题不机械合成一条。 |
| DR-04 | 规则 | 适用SP及必要条件；旧RC/M可用于追溯。 |
| DR-05 | 竞争解释 | 何种非缺陷解释成立/待证/被证据排除；未知不当反证。 |
| DR-06 | 影响 | 不改会损失什么，优先级据实际影响。 |
| DR-07 | 验证动作 | 并排、删场试读、信息/因果表、版本比对等可执行动作。 |
| DR-08 | 修改 | 具体位置和结构关系；已有改写授权可直接交实际修订。 |
| DR-09 | 回归 | 实际改动的消费者节点与必要复核；不强制所有表重跑。 |
| DR-10 | 发现级未决 | 本条缺文本/数据/决定、依赖及临时处理。 |
| DR-SUM | 报告级缺口 | 跨发现未读范围、版本不明和价值选择，与DR-10分开。 |

OOC附表：既有事实｜当前压力｜可选行动｜代价/后果｜原稿位置｜竞争解释；缺项先判断是否确实需要，标待证而非自动定性。
