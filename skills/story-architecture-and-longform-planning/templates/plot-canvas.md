# Plot Canvas（情节画布）

**用法**：先填 §1 的 `PA-01`–`PA-12` 字段行（每个 ID 独占一行；不知道写 “未知”，并在 `PA-12` 说明缺什么、由谁决定）。`PA-04`/`PA-06`/`PA-09`/`PA-10`/`PA-12` 的重复项目再填 §2–§6 的展开表。**留空不等于完成。** 本表是人工工作纸，不含脚本、不自动校验；字段 ID 供逐项核对，不保证填完即写出好作品（效果未证实）。

**版本**：作品：__________｜稿/大纲版本：__________｜日期：__________｜填写人：__________

## 1. 字段清单（PA-01–PA-12，每 ID 一行）

| 字段 ID | 字段 | 填写口径 | 填写 | 状态 |
|---|---|---|---|---|
| PA-01 | 作品、版本与工序（PL-15） | 作品名/工作名、版本/日期、任务类型（规划/诊断/修订）、载体与目标读者、工序（A 外部大纲 / B 心中大纲 / C 发现式）、本次范围与未读范围 |  |  |
| PA-02 | 三要素与矛盾句（PL-16） | 行动者（要什么/怕什么）、行动（一个可拍成画面的动作）、环境（时间/地点/规则/阻力）、矛盾句 `A 想要 X，但 Y 使 X 不可能`、入口类型（A 人物 / B 事件 / C 胚情节） |  |  |
| PA-03 | 主行动句（PL-01） | 一句 `某人想要 X，因为 Y 受阻，最终在 Z 事件上结算`；Z 是否不可逆；删掉任一副线后主落点是否仍被挣得 |  |  |
| PA-04 | 各线挂载与汇合（PL-01/PL-08） | 汇合类型（A 因果汇合 / B 对照并置 / C 伪多线）、共同落点或共享问题、各线收束方式；逐线明细填 §2；**中点场可选，不是 B 型成立条件** |  |  |
| PA-05 | 终点句（PL-02） | 终局句 `谁，在什么事件后，失去/得到什么，且不可撤销`、读者必须先知道的事实、删并清单、终局是否“意外但唯一正确” |  |  |
| PA-06 | 起点/打结/解结（PL-03） | 起点（第一场发生在哪一刻）、打结（哪件事让局面不可逆）、解结（什么手段、第几场）；类型 A/B/C/D；明细填 §3；**3/4 只是 B 型默认值，不是硬门** |  |  |
| PA-07 | 容器参数与分段预算（PL-13） | 载体、总词数或总时长、部/幕/章数、单章/单场上限、交稿或更新节奏、超限处置；分段大致相等，若有一段更长应是中段；不写死百分比；历史数字不作规范 |  |  |
| PA-08 | 开篇契约（PL-04） | 首段/首场契约句（谁 + 要什么 + 被什么挡 + 类型）、主元素（动作/人物/环境）、基调词、后置背景清单、首句位置、删首段测试；延迟揭示时问题是否已给 |  |  |
| PA-09 | 信息差（PL-09） | 谁知道什么/不知道什么、读者何时知道（明细填 §4）、主线策略（A 悬念 / B 惊奇，同一线程只选一个）、inkling 位置、兑现场、回看线索、反讽层 |  |  |
| PA-10 | 承诺结算与截断（PL-11） | 开篇承诺逐条结算（明细填 §5）、每条状态（兑现/未兑现/故意不兑现）、“效果完全达成”的句子、截断点、回补理由、多线收束段 |  |  |
| PA-11 | 判断权声明（PL-12） | 判断权（A 叙述者裁决 / B 事件裁决 / C 读者裁决）、保留/删的评断句、奖惩结构、与目标读者契约是否一致、C 型读法信号、删末段议论测试 |  |  |
| PA-12 | 未决项与证据缺口 | 未决项明细填 §6；缺什么（文本/决定/数据）、谁决定、影响哪些字段、临时处理 |  |  |

状态栏写 “已完成” / “部分” / “未知”；“未知” 不得当成 “已完成”。
