# C1｜新奇点的后果链（novum → cascade）

## 适用 / 不适用

**适用**：用户在设计一个新奇点（反重力、新驱动、生态作物、异星生理、社会技术），或诊断"设定很多但世界不动"。
**不适用**：用户只求氛围/奇观而无因果诉求；纯抒情科幻；已有完整后果链只需润色。

## 条件规则

### C1-1　先给可计算的量，再倒推世界
- **前提**：作品自称硬科幻，或读者会因为"数字不对"出戏。
- **F**：PG1013 L6601-6622 由"月球密度仅为地球五分之三"推出洞窟系统，再由洞窟推出月海在底部、空气在海绵状廊道里流动、日照侧外廊形成恒定东风——**社会形态是第三层推论**。PG44278 L2003-2010 与 L2112 先算一升火药产 400 升气体、高温下膨胀至 4000 升（体积比 1:4000），再算 1,600,000 磅火药产生 60 亿升气体，才谈炮弹。PG1906 L5713-5714 先给"曾经以火为终点、以岩石与水为终点"的历史序列，再谈意识的新渠道。
- **P**：写三行卡——「可计算的量」「直接后果」「二阶后果」；**二阶后果必须能被角色在场景里撞见**（例如 PG1013 里撞见的是被麻醉横陈的闲置工人 L7086-7123）。
- **不适用条件**：喜剧框架故意反着来（PG53035 L62-63 主电脑直接承认不知身在何处，是**故意**的反例）。

### C1-2　一次只推进一环，并把那一环写成可观察物
- **F**：PG53016 L277-279 揭示 carolla 幼虫提供一种"缺之则植株死亡"的酶——一个环节，就把"杀虫"从正确动作翻转成致命错误。PG1013 L7016-7048 把劳动分工写成体型学（单触手起重机手、巨听觉器官、平足踏工、纯肺风箱玻璃工）。
- **P**：每推进一环，问"角色会**看见**什么变化"；看不见就不算推进。

### C1-3　为制度自辩配一条生理/直觉的反声道
- **F**：PG1013 L7050-7068 Cavor 理性上承认罐中塑形"远比先让人长大再把他变成机器更人道"，却又被那只无力垂下的触手困扰；L7113-7123 理性上承认麻醉闲置工人解决了失业问题，却仍绕远路避开那条捷径。
- **H**：讽刺型世界的说服力来自**两条声道同时在场**——制度的自辩与叙述者的生理反感。
- **P**：每段制度说明后，补一句身体的、不可理喻的反应。
- **不适用条件**：作品不追求讽刺效果时（PG32615 只写恐惧，不写自辩）可省。

### C1-4　"完美计划"的自反装置（可选）
- **F**：PG51091 L13-14 把命题写在题记上——"生存计划里没有一个错误，而那正是最大的错误"。PG53016 L108-110 的疏漏是"被主角以死线驳回的试运建议"。
- **P**：若作品的自负点就是计划本身，把疏漏做成**被主角亲自否决的那条建议**，而不是凭空的笔误。
- **不适用条件**：PG44278 的弹道基本无疏漏，冲突来自未知——那也成立。**不要**强行加疏漏。

## 反例与冲突

- PG59587 L627-631：**小规模试验全部成功**正是灾难的成因（模型太小，问题只在弹体变大后才显形）；而 PG53016 L108-110 里"先小规模试运"被驳回才是灾难成因。→ **试验有用，但试验的尺度本身可能就是变量**。只能在该设定内部判断，本 Skill 不给通用答案。
- PG5699 L1639-1642（火＝解放整个种族）与 PG1906 L5953-5982（机器消失则人类六周灭绝）不可调和：前者是"被统治者新获得的能力"，后者是"统治者已内化的依赖"。写作者必须先声明自己的技术属于哪一类，再选后果方向。

## 检查清单（诊断用）

1. 新奇点有没有一个可计算的量？没有 → 读者凭什么信？
2. 二阶后果有没有被角色撞见？没有 → 世界是静止的布景。
3. 制度自辩有没有一条对位的不适感？没有 → 说教。
4. 有没有把单书机制当定律？（见 `sources.md` 末尾的孤证警告）
