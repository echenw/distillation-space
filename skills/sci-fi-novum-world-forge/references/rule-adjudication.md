# 规则裁决表（KEEP / REVISE / REJECT / NOT_PROVEN）

裁决对象两类：**A 类**＝兄弟批次 Skill（批次-01 `sci-fi-future-plot-forge`，来源与本任务不重叠）中仍在流通的核心规则，本轮用本任务 28 本重新回源；**B 类**＝科幻写作圈常见的"铁律"候选。
本任务**没有历史 Skill**（工作区下无 `output/`、无 `results/`、无 `skill.zip`），所以不存在"改错旧规则"的对象；A 类规则是作为**候选**被回源核验的，不是本任务的历史成果。
完整论证见 `notes/source-synthesis.md` §2；来源行号索引见 `sources.md`。

## 已丢弃的旧铁律（不要再套）

1. 必须有物理代价。
2. 必须有可反制漏洞。
3. 限制必须是倒计时。
4. 造物人格只能靠行为证明。
5. 关系只能靠共同事件推进。
6. 识别敌人＝安全。
7. 末世必须靠暴力高潮收束。
8. 技术必然带来自由。

以上八条在本批 28 本中**都有明确反例或只成立于特定条件**，全部降级为"条件性选项"，见 `failure-exit.md`。
