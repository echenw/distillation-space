# 逐条规则最小示例（DESIGN_EXAMPLE）

> 本文件为 RC-01…RC-21 每条给一个最小可执行示例，固定四行：输入 → 分支判断（为什么走 A 不走 B）→ 输出（字段/表）→ 失败出口。
> 全部为 **DESIGN_EXAMPLE**：人物、字数、情节均为演示用虚构数据；不是真实客户稿，不是真实运行记录，不证明任何效果（NOT_PROVEN）。
> 规则全文与锚点见 `references/rules.md`；字段落点见 `templates/*.md`。示例只演示“怎么落条件”，不是标准答案。

---

## RC-01 先判赛道：篇幅 / 媒介 / 类型 / 交付

- `DESIGN_EXAMPLE` 输入：80,000 词、周更、现实悬疑、手机阅读；作者问“能不能按短篇那样只写一个高潮”。
- 分支：走 B 长篇/连载，不走 A 短篇——多个不可合并的利害、章节钩子、追更交付；A 的反信号（多线、跨年、每章钩子）全部命中。
- 输出：`route: {length: "80,000 词 / 40 章", medium: "连载", genre: "现实悬疑", delivery: "追更", reader_promise: "每章一个可兑现的追问"}；borrowed_rules: []`。
- 失败出口：若 `genre` 与 `delivery` 未定 → 给短篇/长篇/舞台三方案与代价，不写具体场景与比例。

## RC-02 从素材到“一句胚故事”

- `DESIGN_EXAMPLE` 输入：素材是“夜班护士发现病人抽屉里有一封写给自己的信”，但事件只能按“然后”排。
- 分支：走 A 情节/情境入口，不走 B 人物驱动长篇——已有必须发生的场面（拆信）和外部压力（病人昏迷、医院规矩）；B 需要跨月人物生长，本稿没有。
- 输出：`premise=护士必须决定是否拆开写给自己的信，代价是失去工作或自我形象`；`effect=读者不敢立刻判断她是勇敢还是自欺`；`irreversible_change=拆/不拆`；`event_chain=[发现锁被撬→因此怀疑→因此找到信→因此必须选择]`。
- 失败出口：写不出 `premise` → 不写场景；列“人物/情境/终局/效果”四堆，指出哪堆最先出现；四堆都空 → 只给素材整理任务。

## RC-03 单一效果：短篇的取舍判据，不是跨篇幅通则

- `DESIGN_EXAMPLE` 输入：6,000 词单线悬疑，作者想同时写“爱情遗憾 + 医院黑幕 + 自我救赎”三个效果。
- 分支：走 A 单一效果，不走 B 长篇多线——≤10,000 词、单线、一个高潮；三条效果没有各自独立收束，B 的“主行动 + 语调统一”在这里用不上。
- 输出：`effect_unit=整篇`；`effect_statement=她是否敢知道自己是谁`；`competing_effects=[爱情遗憾（冲突）→删/并；医院黑幕（支撑）→降为背景；自我救赎（主导）→留]`；`deletion_log` 记三场删/并理由。
- 失败出口：说不出 `effect_statement` → 先不删，回 RC-02 重写 `premise/effect`；仍说不清 → 改问“读者读完最想带走的一个问题”。

## RC-04 结局先行：短篇定终场，长篇定方向

- `DESIGN_EXAMPLE` 输入：6,000 词侦探短篇，作者先想到“凶手是叙述者”的揭晓，但说不出最后一场。
- 分支：走 A 短篇/单线，不走 B 长篇/连载——一个终场、一个危机、一个可预设的揭示；B 的多线与章节发现不适用。
- 输出：`ending_mode=terminal scene`；`terminal_scene=她在值班室读到自己写的报案记录`；`last_line_direction=把记录折回抽屉`；`three_causal_links=[信→锁→值班记录]`；`latent_image=开头的撬锁痕迹`。
- 失败出口：A 写不出终场 → 改问“最后一个不可逆的动作是什么”；仍写不出 → 退回 RC-02 重写 `premise`。

## RC-05 人物—情节：先判入口，再双向校验

- `DESIGN_EXAMPLE` 输入：素材最先出现的是一对男女被困在停摆电梯里；两人都只有职业标签，换谁都能演。
- 分支：走 B 情境入口，不走 A 人物入口——人物不能生成后果（无三处“只有他会这样”的决定），但情境本身含对立力量（幽闭 + 其中一人带着不能曝光的文件）。
- 输出：`entry_type=B`；`entry_evidence=作者先想到电梯故障`；`situation_forces=文件暴露/救援时间`；`plot_forces_character=是`；`character_causes_turn=是`（她选择毁文件）。
- 失败出口：双向校验皆“否” → 停止细化情节，先给人物一个会反抗情境的欲望，或改情境对抗力量。

## RC-06 主行动与多线：主导线或等权多线，次线须交汇

- `DESIGN_EXAMPLE` 输入：120,000 词双时间线；次线“妹妹调查失踪”目前只在主题上和主线相似。
- 分支：走 B 多线交织，不走 A 单主线——次线在第 18 章交出证据，反转主线嫌疑人的条件，且有自己的小高潮；若它不改变主线条件，就降为 A 的背景或删。
- 输出：`main_action=姐姐要在诉讼时效前证明父亲无罪，阻力是唯一证人失踪`；`strands=[妹妹线：function=反转，intersection=第 18 章证据交换]`；`major_convergence=第 26 章庭审`；`cut_log` 记删掉的第三线。
- 失败出口：写不出 `main_action` → 先不列线，回 RC-02 填“最想要的东西 + 最大阻力 + 失败代价”；次线无 `intersection` → 删/并。

## RC-07 场景 / 概述 / 过渡：三种单元，按功能配比

- `DESIGN_EXAMPLE` 输入：一章 4,000 字，全部用概述交代“他们谈判失败”，包括全书的第一次正面对峙。
- 分支：走 A 场景，不走 B 概述——这场有人当场想要什么（停战）并遇到阻力（对方要交出证人）；B 只适用于信息量大、时间跨度长的次要过程。
- 输出：`unit_table=[段1 scene/推进主行动/900 字；段2 summary/必要信息/300 字；段3 transition/时间感/200 字]`；`scene_to_summary_log`；`transition_log` 带“季节/身体/物件”之一。
- 失败出口：分不清场景/概述 → 用“是否有人当场想要什么/被什么阻止”判定；仍分不清 → 标“混合单元”，先不删；写不成场景（缺阻力）→ 回 RC-05 补对抗。

## RC-08 单元收束：章 / 幕 / 折末的“暂解 + 未解”

- `DESIGN_EXAMPLE` 输入：周更连载第 12 章末，主角回到本章开头的位置，读者没有下一章理由。
- 分支：走 A 章末，不走 B 单场短篇——读者会在章末真实停下（追更）；B 只适用于一次读完、无单元切分的稿。
- 输出：`unit_end_table=[第12章/state_changed=否→改末事件/open_question=谁寄出第二封信/delay=已预判→删拖延]`；`payoff_log` 把“第二封信”标到第 14 章兑现。
- 失败出口：三查全“否” → 该章删/并；若坚持保留 → 给它一个状态改变或新信息，否则标为装饰章；钩子写不出 → 不用“突然一声枪响”硬造。

## RC-09 开篇契约：首段四职，晚入场不是通则

- `DESIGN_EXAMPLE` 输入：历史小说开篇直接写城门口混战；读者不认识两方阵营，也不知道谁在打谁。
- 分支：走 B 从头/典型场合，不走 A 晚入场——读者不懂前史就看不懂当下的动作（A 的反信号命中）；B 先给“典型一天”的秩序再打破。
- 输出：`opening_contract={who: 守城书记官, where-when: 围城第三日清晨, tone-type: 冷峻纪实, question: 他会不会开城门}`；`entry_point=典型换防`；`exposition_log=[阵营→换防口令；粮尽→粥棚]`。
- 失败出口：四职写不全 → 先写“谁 + 何处 + 什么不对劲”三句，不写完整开头；三句也写不出 → 回 RC-02。

## RC-10 高潮与结尾：四种模式，先选契约再选型

- `DESIGN_EXAMPLE` 输入：侦探短篇，作者想用“开放式结尾”收，但前文已抛出密室机关。
- 分支：走 B 解谜，不走 C 开放——类型承诺是答案，机关已在前文抛出，开放会违背契约；C 只适用于开头已埋 latent image、线头可收的文学稿。
- 输出：`ending_contract=答案`；`climax_scene=地下室对峙`；`post_climax_material=只解释密室手法两段`；`latent_image=第一章的钟表`；`ending_check=删末段仍成立→末段是补的`。
- 失败出口：说不清 `ending_contract` → 问“读者要答案/团圆/余味/惊叹”四选一；仍选不出 → 标“结尾未定”，不写结尾。

## RC-11 视角：信息合同 + 距离稳定 + 切换代价

- `DESIGN_EXAMPLE` 输入：6,000 词限知短篇，作者想中途切到对手脑内，交代他为什么藏信。
- 分支：走 A 单 reflector，不走 B 多 reflector——一个意识可承载全部信息，切过去只为传一句话（B 的反信号）；改用护士目击/听说/推断。
- 输出：`pov_contract={能知道: 护士所见所闻所想, 不能知道: 病人内心与走廊外电话}`；`distance_profile=贴身`；`switch_ledger=[]`；`pov_violations=[]`。
- 失败出口：写不出 `pov_contract` → 先选一个 reflector，把信息限制在其可见范围；若故事必须跨地同时发生 → 改多 reflector/全知，并逐次记 `switch_ledger`。

## RC-12 读者已知度：先画知识矩阵，再配悬念

- `DESIGN_EXAMPLE` 输入：悬疑短篇，标题已暗示“丈夫是凶手”，但正文仍按 A 悬疑写“读者不知道”。
- 分支：走 B 反讽，不走 A 悬疑——读者已从标题预知（A 的反信号），紧张感应改为“妻子会不会发现”；若坚持 A，则改标题与冲突。
- 输出：`knowledge_matrix=[读者: 丈夫是凶手；妻子: 不知；丈夫: 知]`；`suspense_mode=B`；`reveal_points=妻子在第 3 场发现车票`；`reader_question=她会不会说破`。
- 失败出口：矩阵填不满 → 先只填读者/主角/对手三行；A 分支发现读者已预知 → 改 B 或改冲突，不靠隐藏信息硬撑。

## RC-13 可信度审计：似真、巧合、类型豁免

- `DESIGN_EXAMPLE` 输入：写实短篇，侦探在结局靠“一辆出租车恰好经过”抓到凶手。
- 分支：走 A 写实，不走 B 传奇/闹剧——契约是“可能发生”，巧合出现在解结并直接决定胜负（A 的反信号）；B 只适用于明确放弃逼真且内部规则自洽的类型。
- 输出：`credibility_contract=可能发生`；`chance_audit=[出租车/解结/改为前文埋过的值班司机]`；`setup_log=第 2 场司机登记表`。
- 失败出口：契约说不清 → 按写实/不可能但自洽/夸张取笑三选一，选不出按最严写实；解结改不出人物因 → 换事件，不用“命运/天意”。

## RC-14 具体化与细节剂量：少而准，按视角过滤

- `DESIGN_EXAMPLE` 输入：1900 年代廉租公寓场景，作者查了 12 个历史细节；视角是饿了一天的孩子。
- 分支：走 A 现实主义，不走 B 快节奏——氛围与阶层真实是这场的效果；B 的“一句可成像”会删掉承载命运的细节；但仍按孩子此刻会注意什么过滤。
- 输出：`dominant_impression=油腻的冷`；`detail_table=[煤油味/气氛/是；墙纸霉斑/人物/是；房东的怀表/信息/是]`；`cut_log` 记删掉的 9 个查资料细节。
- 失败出口：写不出 `dominant_impression` → 先不写描写，回 RC-07 确认场景目标；细节都“很重要” → 只留三个，其余进 `cut_log`，看是否真损失。

## RC-15 文体：清晰得体是底线，节奏是耳朵的事

- `DESIGN_EXAMPLE` 输入：类型言情高潮戏，作者把句子改得极平实，编辑说“力度没了”。
- 分支：走 B 类型/浪漫，不走 A 说明散文——文体本身承担效果，华丽与事件相称；A 的反信号（声音/气氛为主）命中。
- 输出：`style_floor={clear: 是, appropriate: 是, readable: 是}`；`sentence_log=[原句/改句/理由]`；`register_check=高语域但主动词清楚`。
- 失败出口：朗读仍拗口且改不动 → 标“风格问题”，停止句层打转，回结构/场景；语域与人物不符 → 先写人物三行小传再改台词。

## RC-16 主题/道德：从行动长出，类型例外明示

- `DESIGN_EXAMPLE` 输入：小说结尾，女主在车站对朋友说“所以人必须对自己诚实”，前文没有对应选择。
- 分支：走 A 小说，不走 B 寓言/道德故事——类型没有承诺“教训”，点题句是人物口播作者结论（A 的反信号）；B 只在类型契约明确要教时允许明示。
- 输出：`theme_question=她能不能承受自己说过的话`；`proof_scene=她替朋友作伪证后又撤回`；`declarations_log=[删“人必须诚实”→改为她在压力下改口]`；`genre_exception=none`。
- 失败出口：写不出 `theme_question` → 先不写主题，从 `proof_scene` 反推“这场选择在回答什么”；删点题句后主题消失 → 回 RC-05/06 补选择与后果。

## RC-17 修订工序：冷却、单稿、分层改

- `DESIGN_EXAMPLE` 输入：80,000 词初稿刚写完，作者想立刻逐句润色。
- 分支：走 A 重度修订，不走 B 轻度——说不出每场功能（结构未成立），B 只适用于结构成立、仅句子/节奏问题；先冷却再分层。
- 输出：`revision_log=[结构层/第 7 场/原功能不明/改为“让证人翻供”/因果断]`；`cold_read_notes`；`rollback_points=第 7 场原稿`。
- 失败出口：说不出每场功能 → 不进句层，先做结构层（RC-06/07/08）；改到失去判断 → 停止、冷却/换读者；无回退原句 → 先建版本副本再动稿。

## RC-18 工作习惯：日课、素材簿、分段骨架、卡壳处理

- `DESIGN_EXAMPLE` 输入：100,000 词连载，作者“有灵感才写”，中段卡住两周。
- 分支：走 A 职业/长篇，不走 B 偶发/短篇——跨月交付、结构复杂；卡壳属 C，改做低负荷任务并补分段骨架。
- 输出：`daily_quota=每天 40 分钟或 300 字`；`notebook_index=情节/人物/描写/对白`；`section_map=8 段（历史默认，可增减）`；`stall_log=[卡点=第 5 段动机/替代=场景卡/恢复=换环境]`。
- 失败出口：设不出 `daily_quota` → 改“本周三次、每次 30 分钟”；仍做不到 → 只做素材/场景卡；低负荷无效 → 回 RC-05/06 查人物/主线，不硬写。

## RC-19 删减诊断：先分类删除对象，再决定删/压/并/留

- `DESIGN_EXAMPLE` 输入：120,000 词要删到 90,000；候选是“导师前史”支线，但它是最后背叛的唯一因。
- 分支：走 A 情节驱动，不走 B 氛围/素描——主行动/因果链优先；B 只在细节/语调本身是效果时保留；唯一因不能删，只能压。
- 输出：`deletion_table=[导师前史/event/改变主行动=否/唯一因=是/处置=压成两段回忆]`；`compression_log`；重复解释删。
- 失败出口：三问答不清 → 先不删，标“承重待定”，用“抽掉这段复述主行动”测试；删后主行动断裂 → 回退改压缩/合并。

## RC-20 类型契约：必要特征 + 读者承诺 + 市场约束分层

- `DESIGN_EXAMPLE` 输入：投稿被退“不符合悬疑”，作者想改标“文学跨类型”。
- 分支：走 A 商业/类型投稿，不走 B 文学/跨类型——必要特征（公平线索、可解答案）缺失且无补偿；B 需要有意偏离 + 补偿 + 明确目标读者。
- 输出：`genre_contract={必要特征: 公平线索/可解答案/危机升级, 承诺: 读者可参与推理, 可偏离: 无侦探}`；`market_constraints=字数/投稿栏目`；`deviation_log=[]`；`rejection_diagnosis=技艺`。
- 失败出口：写不出 3 个必要特征 → 先写“读者买这个类型最想得到什么”一句再反推；仍写不出 → 标“类型未定”，不用类型规则验收。

## RC-21 规则层级：判据、条件、反例，不输出无条件步骤

- `DESIGN_EXAMPLE` 输入：有人主张“每场都必须有反转”，理由是某大师每场都反转。
- 分支：先判层级，走 A 结构层检查（可指出文本证据），不走 C 天赋/判断层；该主张只有 1 个大师例、无 ≥2 反例，按本条降为“假设”，不升格为规则。
- 输出：`rule_card={layer: structure, scope: 短篇/连载待定, signals: 每场是否有状态改变, branches: A 结构层（B/C 未用）, failures: 无反转但状态改变, counterexamples: 待补 2 个, confidence: LOW}`；`exceptions_log=大师例外登记`。
- 失败出口：一条规则说不出两个反例 → 降为“假设”，不进正式规则；若已写入 → 标“证据不足”并移入待验证清单。
