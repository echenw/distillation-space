# 规划工作流：从素材到可写的骨架

> 适用：新作立项、从零构思、把一堆素材/梗概整理成可写结构、改编前重做骨架。
> 不适用：已有成稿的逐段诊断（转 `diagnosis.md`）、已定稿的删减（转 `revision.md`）、纯世界观设定（本 Skill 不交付）。
> 规则细节只在 `rules.md`；本文件只给“规划这一步怎么判断、写不出时往哪退、输出什么字段”。

---

## 0. 先收六项输入

规划不是从空白开始。先确认下表；缺项不要用“默认值”填满，写“未定”。

| 输入 | 要问什么 | 为什么需要 | 缺失时 |
|---|---|---|---|
| 素材 | 最先抓住你的是什么：一个人、一个困境、一个必须发生的场面、一个画面/情绪？ | 决定 RC-05 入口 | 让作者各写一句；四句都空，先做素材整理 |
| 长度 | 预计词数/章数/阅读时长？ | 决定 RC-01 赛道与 RC-03 取舍 | 给短篇/长篇/连载三档，各写代价 |
| 媒介 | 印刷、连载、舞台、口头、银幕？ | 决定 RC-07/08/09 的单元与开篇 | 按“读者是否中断”先分一次读完/追更/现场 |
| 类型 | 现实、传奇、侦探、闹剧、寓言、速写、混合？ | 决定 RC-20 契约与 RC-12 知识状态 | 标“类型未定”，先不写类型承诺 |
| 交付 | 一次交付、周更、月更、演出档期？ | 决定 RC-18 工序与 RC-08 钩子 | 按“是否有固定截稿”分 A/B |
| 约束 | 字数上限、审查、平台禁忌、必须保留的人物/场面？ | 区分技艺问题与市场约束（RC-20） | 标“未知”，不假装没有 |

**失败出口**：六项中“素材/长度/媒介/类型”缺三项以上 → 不给结构方案；先做一次 30 分钟的素材盘点，输出“人物/情境/终场/效果”四张卡，每张一句。

---

## 1. 定赛道（RC-01）

**判断信号**

- 一个主导问题、一个主角、一个终场 → 短篇/单线。
- 多个不可合并的利害、时间跨度、章节钩子 → 长篇/连载/多线。
- 分幕分折、场上演出、观众集体、时限 → 舞台/戏曲。
- 一次听觉/视觉交付、不可回看 → 口头/银幕。

**动作**

1. 写 `route`：`length / medium / genre / delivery / reader_promise`。
2. 写一句“这个赛道读者买什么”。
3. 标 `borrowed_rules`：哪些规则是同赛道，哪些只是类比（H）。

**写不出的失败出口**

- 四项缺两项以上 → 输出三种方案：
  - 短篇：单一效果、单主角、一个终场；代价是容纳不了多线/跨年。
  - 长篇：主行动 + 多线交汇 + 章节钩子；代价是工时/中段管理。
  - 舞台/连载：分幕/分章、单元收束、观众/读者中断；代价是每单元都要自足。
- 不要替作者选“看起来更高级”的赛道。

**输出字段**：`route`、`reader_promise`、`borrowed_rules`。

---

## 2. 写“胚故事”与效果（RC-02，必要时 RC-03）

**判断信号**

- 能否一句话说出：谁 + 什么处境 + 必须做什么选择 + 代价？
- 事件之间是“因此”还是“然后”？
- 读者读完带走的一个情绪/问题是什么？
- 短篇/单线：是否只有一个主导效果？长篇/多线：是否有主行动 + 语调/母题统一？

**动作**

1. 写 `premise`（一句）与 `effect`（一句，不是主题名词）。
2. 列 5–7 个候选事件，逐个问“是否改变主角的处境/选择”。
3. 按“因此”重排；只能“然后”排 → 换困境，不加事件。
4. 短篇/单线：写 `effect_unit` 与 `competing_effects`，按 RC-03 A 分支做删/并/降。
5. 长篇/多线：不要求单一效果；写 `hierarchy`（主导/支撑/对照）与一个可重复的语调/母题。

**写不出的失败出口**

- 写不出 `premise` → 不进入场景；回到第 0 步的“素材”四张卡。
- 写不出 `effect` → 改问“读者读完最想带走的一个问题是什么”，用问句；仍写不出，标“效果未定”，先只写主行动。
- 短篇有 3 个以上互不相让的效果 → 不是“丰富”，是赛道错配：要么改长篇，要么按 RC-03 A 删到 1 个主导 + 1 个对照。

**输出字段**：`premise`、`effect`、`irreversible_change`、`event_chain`（因此/然后）、`effect_unit`、`competing_effects`、`hierarchy`、`open_question`（B/C 用）。

---

## 3. 定终点（RC-04，必要时 RC-10）

**判断信号**

- 短篇/单线：能否说出最后一场的画面/最后一句的方向？
- 长篇/连载：能否说出“谁变成什么、什么不可逆、最后意象/决定”？
- 开头是否埋了结尾要回收的意象/问题（`latent_image`）？
- 结尾契约是什么：答案/团圆/余味/惊叹？

**动作**

1. 选 `ending_mode`：
   - A 短篇/单线/侦探/商业 → `terminal_scene` + `last_line_direction`。
   - B 长篇/连载/人物驱动 → `terminal_state`。
   - C 发现型 → 先标“discovery”，初稿后补 `terminal_state` 与 `latent_image`。
2. A 倒推 3 个必要因果环；每环写“前文必须埋什么”。
3. B 写 3 个里程碑转折，不写细节。
4. 写 `ending_contract`（RC-10）：答案/团圆/余味/惊叹；选对应模式（闭合/解谜/开放/仪式）。
5. 检查 `latent_image`：开头是否已埋下结尾要回收的物/问题/动作。

**写不出的失败出口**

- A 写不出终场 → 改问“最后一个不可逆的动作是什么”；仍写不出，退回第 2 步重写 `premise`。
- B 写不出终局状态 → 只写“最后谁必须做一个什么决定”；连这个也没有 → 标“终点未定”，暂停细纲，先写 3 个候选转折。
- 结尾契约选不出 → 不要写结尾；先问“读者被承诺的是什么”，四选一。

**输出字段**：`ending_mode`、`terminal_scene`/`terminal_state`、`three_causal_links`、`milestone_turns`、`latent_image`、`ending_contract`。

---

## 4. 选人物—情节入口（RC-05）

**判断信号**

- 素材里最先出现的是：一个人（A）/ 一个困境（B）/ 一个必须发生的场面（C）/ 一个画面或情绪（D）？
- 人物能否说出三处“只有他会这样”的决定？
- 情境是否已含对抗力量？
- 终局是否必须先发生？
- 人物是否只在传递信息/推动机关？

**动作**

1. 写 `entry_type` 与 `entry_evidence`。
2. 按入口做一次小练习：
   - A：人物三行小传 + 一次“不听话”的选择。
   - B：写对抗力量 + 让两三个不同人物进场，看谁把情境推到最大张力。
   - C：写终场，倒推 3 环，每环问“人物为什么必须这样做”。
   - D：写效果句，选能承载它的人，再给他一个独立于效果的欲望。
3. 双向校验：`plot_forces_character`、`character_causes_turn`。

**写不出的失败出口**

- 四入口都说不清 → 退出规划，做素材盘点；不要用“先写写看”掩盖没有故事。
- 双向校验皆“否” → 停止细化情节；先修人物欲望或情境对抗力量。
- 人物只有功能 → 按 RC-05 反例处置：删/并，或给他一个与功能冲突的私人目的。

**输出字段**：`entry_type`、`entry_evidence`、`character_card`、`situation_forces`、`plot_forces_character`、`character_causes_turn`。

---

## 5. 写主行动与各线挂载（RC-06）

**判断信号**

- 能否一句话说出主行动：谁要什么、谁阻止、失败代价？
- 每条次线是否有独立主角/独立高潮？
- 抽掉一条次线，主线是否变化？
- 多条线是否在同一场面/同一决定处汇合？
- 次线是否只在主题上相似、情节上不相干？

**动作**

1. 写 `main_action`。
2. 列 `strands`：每条写 `function`（反转/补足/对照/提供信息）与 `intersection`（哪一场、与谁、交换什么）。
3. 无交汇的线：删/并/降为背景；只靠主题相似的线不算交汇。
4. 标 `major_convergence`：主汇聚在哪；若在 3/4 处，按“前段蓄因、后段收果”检查——这是 PG30776 的单来源默认参考，不是硬门；侦探/开放式另算。
5. 做“抽线测试”：抽掉一条线，复述主线；完全不变 → 赘线。

**写不出的失败出口**

- 写不出主行动 → 回到第 2 步 `premise`；不要先列线。
- 次线无交汇 → 删/并；作者舍不得删 → 要求写“它改变了主线的哪个条件”，写不出就标背景。
- 多线等重但互不相干 → 改主次，或让它们共享一个终局/一个决定；不要用“群像”当无主线的借口。

**输出字段**：`main_action`、`strands[]`（name/function/intersection）、`major_convergence`、`cut_log`。

---

## 6. 排结构单元与章末（RC-07、RC-08）

**判断信号**

- 每个单元是场景、概述还是过渡？
- 关键对抗是否被概述掉？
- 时间跳跃是否有锚点？
- 每个单元末：状态是否改变？留下什么可兑现的问题？是否被读者预判又拖延？
- 短篇是否只需要一个总收束？长篇/连载是否需要“暂解 + 钩子”？

**动作**

1. 做 `unit_table`：段/场/章、type（scene/summary/transition）、function、字数。
2. 标关键对抗：若是 summary → 改成 scene（谁在场、要什么、谁阻止、代价）。
3. 场景若纯信息/纯装饰 → 降为 summary 或删。
4. 长篇两次高潮之间补 transition：季节/日常/身体变化，且携带新信息。
5. 做 `unit_end_table`：每章/幕/折末三查（state_changed/open_question/delay）。
6. 建 `payoff_log`：每个钩子写兑现章；不兑现的钩子删。

**写不出的失败出口**

- 分不清场景/概述 → 用“是否有人当场想要什么并被阻止”判定；仍分不清，标“混合单元”，先不删。
- 单元末三查全“否” → 该单元可删/并；作者坚持保留 → 加一个状态改变或新信息，否则标装饰。
- 钩子写不出 → 不用“突然出现一个人/一声枪响”硬造；改问“下一章最想知道什么”。

**输出字段**：`unit_table`、`scene_to_summary_log`、`transition_log`、`unit_end_table`、`payoff_log`。

---

## 7. 定开篇契约（RC-09）

**判断信号**

- 首段末读者是否知道：谁要紧、何时何地、什么调/什么类型、留下什么问题？
- 背景信息是否织进动作，而不是成块说明？
- 这个赛道适合晚入场、从头写、舞台动作、还是框架故事？
- 删掉第一段，故事是否仍能懂？

**动作**

1. 写 `opening_contract` 四职各一句。
2. 按赛道选入口：
   - A 印刷短篇/动作/商业 → 从第一次不可逆的动作/对话切入，前史拆成 1–3 处动作信息。
   - B 说明性/历史/传记/世界构建 → 从典型场合/典型一天开头，先给秩序再打破。
   - C 舞台 → 把 exposition 改成人物当下的利益冲突。
   - D 框架 → 先给“为什么现在讲”的压力，否则删框架。
3. 写 `entry_point` 与 `exposition_log`（每条信息 → 承载动作）。
4. 自检：删第一段是否仍能懂；若能懂，第一段可能只是装饰。

**写不出的失败出口**

- 四职写不全 → 只写“谁 + 何处 + 什么不对劲”三句，不写完整开头。
- 三句也写不出 → 素材还没有人物/处境，回到第 2 步。
- A 找不到正在发生的动作 → 改 B 的典型场合，或写三个候选入口让作者选；不要硬把背景塞进对话。

**输出字段**：`opening_contract`、`entry_point`、`exposition_log`。

## 7.5 定视角与信息差（RC-11、RC-12）

**判断信号**

- 这个故事由谁看？单 reflector、多 reflector、全知，还是混合？
- 每个 reflector 能知道什么、不能知道什么？
- 读者比人物知道得多、少，还是同步？
- 关键秘密何时揭、由谁说、说完改变什么？
- 切换是否有场景/章节标记，是否买回单视角拿不到的东西？

**动作**

1. 写 `pov_contract`：能知道/不能知道/能进入谁的意识；短篇默认一个 reflector，长篇 2–3 是默认，不是硬门。
2. 写 `distance_profile`：每章/每场的距离；变化处标“为什么变”。
3. 建 `switch_ledger`：每次切换写 trigger/benefit/marker/cost；缺 benefit 或 marker 就不切。
4. 画 `knowledge_matrix`：读者/主角/对手/关键配角 × 关键信息。
5. 选 `suspense_mode`（悬疑/反讽/惊奇/分层），写 `reveal_points`；所有“读者会……”标 H。

**写不出的失败出口**

- 写不出 `pov_contract` → 先选一个 reflector，把所有信息限制在他/她可见范围；必须跨地同时发生 → 改多 reflector/全知，并逐次记账。
- 填不满 `knowledge_matrix` → 先填读者/主角/对手三行；仍填不满 → 信息设计未定，不写揭晓。
- 切换无 benefit → 不切；改由当前视角人物目击/听说/推断。

**输出字段**：`pov_contract`、`distance_profile`、`switch_ledger`、`knowledge_matrix`、`suspense_mode`、`reveal_points`。

## 8. 定类型契约（RC-20）

**判断信号**

- 读者买这个类型时最想得到什么：答案/团圆/恐怖/知识/代入/惊叹？
- 作品的 3–5 个必要特征是什么？
- 哪些偏离是有意的？补偿是什么？
- 哪些约束是市场/审查，不是技艺？

**动作**

1. 写 `genre_contract`：3–5 个必要特征 + 读者承诺 + 可偏离项。
2. 写 `market_constraints`：字数、结局、禁忌、审查；与技艺问题分栏。
3. 逐条验收：必要特征是否兑现；偏离是否有补偿。
4. 类型混合：按“主导处理”判类，不按局部元素。
5. 退稿/投稿场景：先判“技艺/市场/审查”，不混判。

**写不出的失败出口**

- 写不出 3 个必要特征 → 先写“读者最想得到什么”一句，再反推；仍写不出 → 标“类型未定”，不拿类型规则验收。
- 必要特征与作者想写的冲突 → 给两条路：遵守契约（改特征）或有意偏离（写补偿与代价）；不替作者选。
- 市场约束与技艺缺陷混在一起 → 分栏；没有证据的栏标“未知”。

**输出字段**：`genre_contract`、`market_constraints`、`deviation_log`、`rejection_diagnosis`。

## 9. 定工序与风险（RC-18、RC-21）

**判断信号**

- 这个项目是否需要跨月管理？
- 是否有固定写作时段/字数、素材簿、分段骨架？
- 卡壳时是否有替代任务？
- 起草与修改是否分开？
- 哪些规则在这个项目里是例外？例外是否登记？

**动作**

1. 设 `daily_quota`（低到能持续）或最小承诺（每周三次/每次 30 分钟）。
2. 建 `notebook_index`：情节/人物/描写/对白分栏。
3. 长篇：写 `section_map`（8–9 段是历史默认，非硬门），允许写作中长大/缩小。
4. 起草与修改分时段；初稿只前进。
5. 写 `stall_log`：卡点/替代任务/恢复方式。
6. 建 `exceptions_log`：哪些规则被有意违反、代价、是否可学；不把例外升格为新规则。

**写不出的失败出口**

- 设不出日课 → 改最小承诺；仍做不到 → 先不设产量目标，只做场景卡。
- 卡壳且低负荷任务无效 → 回到第 4/5 步检查人物/主线，不用“硬写”掩盖结构问题。
- 例外说不清代价 → 不登记为“有意违反”，按缺陷处理；不要用“大师也这样”当理由。

**输出字段**：`daily_quota`、`notebook_index`、`section_map`、`stall_log`、`exceptions_log`。

## 10. 规划闸门（交付前 10 问）

只要有一项答“否”，不要进入起草；回到对应步骤。

| # | 问题 | 对应 | 答“否”时 |
|---|---|---|---|
| 1 | `route` 四项是否明确（缺项标未定）？ | RC-01 | 回到第 1 步，给三方案 |
| 2 | 能否一句话说出 `premise`？ | RC-02 | 回到第 2 步/素材盘点 |
| 3 | 短篇是否只有一个主导效果；长篇是否有主行动+语调统一？ | RC-03 | 短篇删/并；长篇补 hierarchy |
| 4 | 能否说出终点（终场/终局状态）？ | RC-04 | 回到第 3 步，至少写“最后决定” |
| 5 | 入口是否明确，双向校验是否至少一项为“是”？ | RC-05 | 回到第 4 步；两项皆否则停 |
| 6 | 主行动是否一句话；次线是否都有交汇？ | RC-06 | 删/并无线 |
| 7 | 关键对抗是否都是场景；章末是否有状态改变+可兑现问题？ | RC-07/08 | 改 summary 为 scene；补/删钩子 |
| 8 | 首段四职是否齐全？ | RC-09 | 补 contract；或换入口 |
| 9 | 类型契约是否有 3–5 个必要特征+补偿？ | RC-20 | 标未定；或改契约 |
| 10 | 是否有工序与例外登记？ | RC-18/21 | 设最小承诺；登记例外 |

**失败出口**：闸门 4 项以上答“否” → 不要写细纲；输出“规划未成立”的清单，列缺什么、下一步做什么。闸门 1–3 项答“否” → 可写“试点场景”，但标“结构未定”，不得对外称完成。
