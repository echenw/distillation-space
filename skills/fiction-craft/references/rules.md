# 21 条规则：唯一权威版本

> 本文件是 fiction-craft 的规则权威。`SKILL.md`、`planning.md`、`drafting.md`、`diagnosis.md`、`revision.md`、`scope-and-conflicts.md` 只引用 RC ID，不复制完整规则；若两处说法不一致，以本文件为准。
>
> **证据标记**：M = 作者明示的方法/主张；C = 评论、理论、批评判断（转成步骤时标 H）；FC = 作品现象/编者判词（升格为方法时标 H）；R = 分类表、书目、市场资料；MIX = 混合文本；H = 评论反推、跨域迁移、作者自述但不可验证。`N` 按书计，同书多段只算 1；同作者、转引、同编者造成的谱系重叠在条目内注明。
>
> **全域边界**：28 本材料标称跨度 1808–1929，主体是 1888–1928 英美印刷市场、短篇工艺、舞台/戏曲与古典文论；非西方现代小说、当代类型工业、网络长篇/系列、系统视角理论、影视/互动叙事、读者实验均未覆盖。凡越出此边界，一律标 H 或 NOT_PROVEN。
>
> **效果状态**：21 条规则的全部效果均 **NOT_PROVEN**；真实写作任务 **NOT_RUN**。锚点位置为 STATIC_CHECKED（本轮证据整理中回读/核对），不等于效果验证。
>
> 每条规则固定包含：层级、一句话规则、触发情境、可观察信号、分支与区分（含反信号）、操作步骤、输出字段、反例（≥2）、适用边界、失败出口、PG 锚点、独立来源数、来源类型、冲突状态、置信度。**不得把本条压成一句口号使用。**
>
> **计数口径**：`独立来源数`按本条锚点内的不同 PG 计；正面支持与用于界定分支边界的反证均可列入，并在括号注明角色；未进锚点的类比/反例不计入。任何情况下都不得把反证与正面来源相加冒充“多来源共识”。

## RC-01 先判赛道：篇幅 / 媒介 / 类型 / 交付

- **层级**：structure（分流门；不是文体规则）。
- **一句话规则**：动笔或诊断前，先给作品打“赛道标签”；所有后续规则只在该标签内生效，跨赛道必须重新取证。
- **触发情境**：新项目立项、接稿、改稿前；两人对“这故事该怎么写”争论不休；把短篇经验套长篇、把舞台经验套小说、把印刷经验套连载时。
- **可观察信号**：
  - 预计字数/阅读时长/是否分章分幕；
  - 交付媒介（印刷、连载、舞台、口头、银幕）；
  - 类型承诺（现实、传奇、侦探、闹剧、寓言、纯奇、速写）；
  - 读者进入方式（一次读完、追更、现场观看、听讲）；
  - 委托方是否已固定字数/媒介/交稿节奏。
- **分支与区分**：
  - **A 短篇/单线/一次读完**：区分信号 = 一个主导问题、一个主角、一个终场；反信号 = 多条独立因果线、跨年时间、群像调度、每章都要独立钩子。
  - **B 长篇/连载/多线**：区分信号 = 多个不可合并的利害、时间跨度、章节钩子、次线需要独立收束；反信号 = 单一线索可在一万字内解决、所有事件都指向同一场面。
  - **C 舞台/戏曲**：区分信号 = 场上演出、分幕分折、观众集体、时限、幕末停顿；反信号 = 只供案头阅读、可回看、可批注。
  - **D 口头/银幕**：区分信号 = 一次听觉/视觉交付、不可回看、时长固定；反信号 = 可反复阅读、可跳读、可做脚注。
  - **跨赛道**：图文、互动、影视小说、跨媒介改编允许并列两个标签，但每条规则要分别验收，不能取平均。
- **操作步骤**：
  1. 写下 `length`（词数/章数区间）、`medium`、`genre`、`delivery` 四项；缺一项就标“未定”，不得用默认值冒充。
  2. 用一句话说明该赛道“读者/观众买的是什么”（悬念、情绪、人物、场面、知识、陪伴）。
  3. 从本文件挑规则时，只挑“适用边界”含该赛道的；不含者降为“类比”，标 H。
  4. 若两个赛道冲突（如“短篇的单一效果” vs “长篇的多线”），以赛道标签裁决，不做折中。
  5. 把标签写入规划单/改稿单首行，后续每条诊断都回指它。
- **输出字段**：`route: {length, medium, genre, delivery, reader_promise}`；`borrowed_rules: []`（每条注明“同赛道/类比 H”）。
- **反例（≥2）**：
  1. **PG36580 L623 戏剧术不是小说术**：“The art of the playwright is not, then, the art of the novelist.” 把舞台的“每场一个主脑/幕末汇聚”直接当小说章法，会错配单位。处置：舞台规则只在 C 标签内使用；迁小说标 H，且只借结构层级。
  2. **PG25471 L1025 传奇为登场而设**：“填词之设，专为登场”。李渔的“减头绪/密针线/大收煞”对象是传奇演出；把它当小说通则，会误删小说需要的内心与时间跨度。处置：只保留结构层级，声容/居室/饮馔等不迁移。
  3. **PG72446 L809 短篇以情境为主**：“situation is the main concern of the short story”。这是短篇判断；用它要求长篇“每章一个情境”，会把长篇压成系列短篇。处置：长篇用 RC-06 的主行动/多线，不用本条 A 分支。
- **适用边界**：全部赛道；但 1900–1926 的“短篇/长篇”字数界线（短篇约 1,000–10,000 词，长篇 ≥50,000 词）只是当时市场约定，当代网文/短篇平台需重标；舞台/戏曲的“幕/折”不能直接换算成小说章。
- **失败出口**：四项中缺失 ≥2 项，或委托方拒绝给字数/媒介/类型 → 输出三种赛道方案（短篇/长篇/舞台或连载），各写读者承诺、结构代价、所需工时，不写具体场景与比例；等作者选定后再进入下一步。
- **PG 锚点**：
  - PG36580 L623 “The art of the playwright is not, then, the art of the novelist.”（M）
  - PG72446 L809-810 “situation is the main concern of the short story”（M）
  - PG30776 L5475-5477 “The aim of a short-story is to produce a single narrative effect…”（M）
  - PG64210 L742-744 “narratives fall naturally into two large divisions”（M/R）
  - PG25471 L1025 “填词之设，专为登场”（M，中文引文，戏曲）
  - PG70492 长篇对象（C；≥50,000 词为操作约定，非原文统计）
- **独立来源数**：6（PG36580、PG72446、PG30776、PG64210、PG70492、PG25471；PG13589 与 PG30776 同作者，未重复计）。
- **来源类型**：METHOD×4 / CRITICISM×1 / REFERENCE×1。
- **冲突状态**：CONDITIONAL（K-10 类型边界、K-11 开头策略均以赛道分流）。
- **置信度**：HIGH（“必须先分流”几乎无反对）；MEDIUM（具体字数/媒介分界是历史约定，不是统计）。

## RC-02 从素材到“一句胚故事”

- **层级**：structure（立意/前提层）。
- **一句话规则**：在作者需要先做结构设计时，把素材试压成一句可检验的“胚故事”；探索式起草可在初稿后回补：谁、在什么困境里、做了什么不可逆的选择、读者最后带走什么。
- **触发情境**：素材很多但不知从哪写；写了三场还没进入故事；编辑说“想法好，但不是故事”；大纲散成事件清单；人物小传写了很多，却说不清故事要干什么。
- **可观察信号**：
  - 能否用一句话说出主角与困境；
  - 能否指出一个不可逆的变化（不是“发生了很多事”）；
  - 能否说出读者读完后的主导情绪/问题；
  - 事件之间是“然后”还是“因此”；
  - 换一个主角，故事是否仍成立；删掉结尾，前文是否仍有张力。
- **分支与区分**：
  - **A 情节/情境驱动、短篇/类型**：区分信号 = 已有一个必须发生的场面或一个危机，且能说出外部压力；反信号 = 只有一个人物肖像、没有外部压力、事件只在展示性格。
  - **B 人物驱动、长篇/探索稿**：区分信号 = 人物能生成后果，但终局未定；反信号 = 人物只是作者传声筒，换谁都一样，或人物没有任何能改变处境的欲望。
  - **C 速写/印象主义**：区分信号 = 主导的是 tone/画面/语言节奏，不是事件；反信号 = 读者被引导去问“后来怎样”、文本靠悬念推进。
  - **A/B 区分**：A 的验收句是“谁必须做什么”；B 的验收句是“这个人会把处境变成什么”；两者都要有后果，不只是气氛。
- **操作步骤**：
  1. 写一句 `premise`：`某人 + 在什么处境 + 必须做什么选择 + 代价`。
  2. 写一句 `effect`：读者读完应带走的一个情绪或问题（不是“主题名词”，不是“人性”“命运”这类空词）。
  3. 列 5–7 个候选事件（操作默认，非硬门），逐个问“它是否改变主角的处境/选择”；不改变者删或降为背景。
  4. 把事件按“因此”重排；若只能按“然后”排，回到第 1 步换困境，而不是继续加事件。
  5. 用三问验收：换一个主角，故事是否还成立？删掉结尾，前文是否仍有张力？能否用一句话向编辑复述？
  6. B/C 分支允许 `premise` 只写“起点人物 + 终局方向”，但必须写 `open_question`，并在初稿后补一次完整 `premise`。
- **输出字段**：`premise`、`effect`、`irreversible_change`、`event_chain`（每环标“因此/然后”）、`open_question`（B/C 用）。
- **反例（≥2）**：
  1. **PG492 L1584《金银岛》边写边发现**：作者自述十五天十五章后卡住，换地后一章一天。这说明“先有完整胚故事”不是所有作者的必经工序；处置：允许 C 分支，但初稿后必须补写 `premise`/`terminal_state`，不能永远没有。
  2. **PG61625 L2941 结尾不在心**：“No, the ending is not clearly in mind.” 成熟作者也可不预知结尾；但该作家仍知道“要留下什么 mood”。处置：把“知道结尾”降为“知道效果/方向”，不把预知结尾当硬门。
  3. **PG68291 L669-670 速写是树、故事是链**：“The tale is a chain; the short-story is a tree.” 速写/印象主义本来就没有“不可逆变化”；强行加情节会毁掉 tone。处置：C 分支只要求 `effect` 与 `open_question`，不要求 `irreversible_change`。
- **适用边界**：短篇/类型/商业稿最硬；长篇/人物驱动可软化为“方向句”；舞台需要“可演的情境句”；口头故事需要“可复述的钩子”；速写/印象主义只要求 tone 与画面，不要求事件链。
- **失败出口**：写不出 `premise`（谁+困境+选择+代价）且任务是结构规划 → 暂不做确定性情节处方；如用户明确要探索式试写，可标 H 假设先写试验片段；回到素材层，列“人物/情境/终局/效果”四堆，指出哪一堆最先出现，再按 RC-05 选入口；若四堆都空，说明还没有故事，只给素材整理任务。
- **PG 锚点**：
  - PG61625 L11661-11670 “A plot attracts facts and characters as a magnet attracts iron filings.”（M）
  - PG72446 L878-879 “unless you have a salamander to show him”（M）
  - PG27224 L95-97 “A plot should work steadily forward to the end or denouement”（M）
  - PG30776 L5475-5477 “single narrative effect with the greatest economy of means”（M）
  - PG68291 L669-670 “The tale is a chain; the short-story is a tree.”（C/FC）
- **独立来源数**：5（PG61625、PG72446、PG27224、PG30776、PG68291）。
- **来源类型**：METHOD×4 / CRITICISM×1（含 FICTION_CASE 判词）。
- **冲突状态**：CONDITIONAL（K-02 人物/情节入口；K-11 开头策略）。
- **置信度**：MEDIUM（实践者一致，但“胚故事”质量无可测标准；PG21964 的单一效果定义与 PG30776 同谱系，未计为独立支持）。

## RC-03 单一效果：短篇的取舍判据，不是跨篇幅通则

- **层级**：structure（整体取舍）；在短篇/独幕是主判据，在长篇只是“整体统一”的一个选项。
- **一句话规则**：短篇/独幕/轶事用“一个主导效果”决定取舍；长篇/多线/速写改用“主行动统一 + 语调/母题统一”，不得把前者上推。
- **触发情境**：短篇写散了；每个场景都好看但互相抢；编辑说“焦点不集中”；长篇被要求“只能有一个主题”；删戏时不知哪场该留。
- **可观察信号**：
  - 独立因果线数量；
  - 高潮/情绪峰值数量；
  - 读者被要求同时追问的问题数量；
  - 是否存在“删掉也不影响主导效果”的整场；
  - 长篇是否有一个可重复变化的意象/语调把多线缝住。
- **分支与区分**：
  - **A 单一效果适用**：区分信号 = 篇幅 ≤10,000 词、单线、单一主导情绪/问题、独幕、轶事、商业短篇；反信号 = 多线交织、跨年、群像、百科式、每章各有独立高潮。
  - **B 单一效果不适用**：区分信号 = 长篇、多线、速写、印象主义、随笔式、以“生活广度”为目标；反信号 = 只是“作者舍不得删”，却说不出整体统一靠什么。
  - **C 中间态（novelette/长 short-story）**：区分信号 = 两三条线但只有一个高潮；反信号 = 每条线都要独立收束、每个主角都要完整弧线。
  - **A/B 区分**：A 问“删掉这场，主导效果是否更强”；B 问“删掉这条线，整体主行动/语调是否仍成立”。两问不能互换。
- **操作步骤**：
  1. 定 `effect_unit`：整篇 / 段落 / 场（三者不可混用；三处锚点分别是 PG21964 整篇、PG13589 场面、PG36580 段落，见 `source-index.md` 对应行）。
  2. 写 `effect_statement`：读者读完应得到的一个主导情绪/问题。
  3. 列 `competing_effects`：每个场景想产生的效果；标出与主导效果冲突者。
  4. A 分支：冲突者删/并/降为背景；B 分支：不删，改为 `hierarchy`（主导 > 支撑 > 对照），并检查每层是否服务整体。
  5. 做“删节测试”（PG1974 L467-473 的删/移测试）：删掉一场，主导效果是否更强？更强则删，不变则考虑并，变弱则留。
  6. 长篇另做“母题/语调”检查：是否有一个可重复变化的意象/语调把多线缝住（PG70492 论 pattern/rhythm（C；转步骤标 H））。
- **输出字段**：`effect_unit`、`effect_statement`、`competing_effects`、`hierarchy`、`deletion_log`（删/并/留及理由）。
- **反例（≥2）**：
  1. **PG32092 L4805-4813 同代手册内部反对**：“when it is stated that the short story … should manifest the unities and produce a single effect, the statement is false.” 戏剧型短篇不服从 Poe 式情绪统一。处置：A 分支只用于情绪/氛围型短篇；戏剧型短篇改用“冲突/危机”统一，不强行删成单一情绪。
  2. **PG32092 L5486 长篇小说不必一 idea**：“if I stated that the novel must embody one story-idea … the statement would be false”。处置：长篇用 B 分支，不拿“一个主题”砍线。
  3. **PG492 L1330 细节多职是最高艺术**：“the very highest order of creative art”；PG58471 L8591 要求 selection “typical, to be inclusive”。处置：B 分支保留“不服务主导效果但服务语调/生活面向”的细节；删节测试变弱即留。
  4. **PG68291 L9750 印象主义以 tone 统摄**：速写/印象主义的细节本身就是效果；处置：C 分支只检查 tone 是否同调，不做“删到只剩一个效果”。
- **适用边界**：短篇/独幕/轶事强；长篇只保留“整体统一”；速写/印象主义/随笔弱；舞台独幕强、多幕弱；电影/口头另有一套“注意力经济”（PG13589/PG15383），不可直接换算。
- **失败出口**：说不出 `effect_statement`，或每个场景都声称服务不同效果 → 先不要删；回到 RC-02 重写 `premise`/`effect`；若仍说不清，改问“读者读完最想带走的一个问题是什么”，用问题句代替主题名词。
- **PG 锚点**：
  - PG30776 L5475-5477 “The aim of a short-story is to produce a single narrative effect…”（M）
  - PG64210 L12740 “The effect should be single, not multiple.”（M）
  - PG21964 L167-169 引 Hamilton 同一定义（M/R，转引，与 PG30776 同谱系）
  - PG32092 L4805-4813 “the statement is false”（M，反证）
  - PG32092 L5486-5490 短篇一 idea、长篇不必（M，反证）
  - PG492 L1330-1331 “the very highest order of creative art”（M/C，反证）
  - PG58471 L8591 “typical, to be inclusive”（C，反证）
- **独立来源数**：6（按本条锚点内的不同 PG 汇总取证来源：PG30776、PG64210、PG21964 为正面支持；PG32092、PG492、PG58471 以反证界定 A 分支边界；PG21964 与 PG30776 同谱系，不作独立共识；PG68291 只作速写反例，不计入）。
- **来源类型**：METHOD×4 / CRITICISM×2 / REFERENCE×1。
- **冲突状态**：CONDITIONAL（K-01；“单一效果”只作短篇/独幕 A 分支的判据，不作跨篇幅普遍命题）。
- **置信度**：MEDIUM（条件本身有强反证支持；但“单一效果”支持方谱系重叠，不能算多来源共识）。

## RC-04 结局先行：短篇定终场，长篇定方向

- **层级**：structure（终点设计 + 验收判据）；不是所有作者的写作顺序。
- **一句话规则**：短篇/单线在起草前定“终场画面 + 末句方向”并倒推因果；长篇/连载只定“终局状态”，允许章节发现；“结尾须由开头逼出”是所有长度的验收判据。
- **触发情境**：写到最后收不住；中段塌；结尾像补上去的；连载写到后面人物失控；编辑问“这故事到底要走到哪”。
- **可观察信号**：
  - 能否说出最后一场戏的画面/最后一句的方向；
  - 能否说出“什么不可逆地改变了”；
  - 结尾是否回收了开头的意象/问题；
  - 中段事件是否在“倒推链”上；
  - 连载是否有“终局状态”而不是“永远下一章”。
- **分支与区分**：
  - **A 短篇/单线/侦探/商业类型**：区分信号 = 一个终场、一个危机、一个可预设的揭示；反信号 = 人物自己长出了新方向、连载需留钩子、结尾必须靠续集解释。
  - **B 长篇/连载/人物驱动**：区分信号 = 多线、时间跨度、人物会变、允许章节发现；反信号 = 所有线都指向同一个终场且无新发现、终局状态说不出“谁变成什么”。
  - **C 发现型写作**：区分信号 = 作者边写边发现（PG492 L1584）；反信号 = 反复卡壳、结构失控、写到哪算哪且没有初稿后补写。
  - **A/B 区分**：A 问“最后一场是什么画面”；B 问“最后什么不可逆地改变了、留下什么意象/决定”。B 不要求知道最后一场。
- **操作步骤**：
  1. A：写 `terminal_scene`（最后一场的可拍画面）与 `last_line_direction`（末句朝哪收）；B：写 `terminal_state`（谁变成什么、什么不可逆、最后意象/决定）。
  2. A：从终场倒推 3 个必要因果环（操作默认，非硬门），每环写“前文必须埋什么”；B：写 3 个里程碑转折，不写细节。
  3. 检查 `latent_image`：开头是否已埋下结尾要回收的意象/问题（PG72446 L1802）。
  4. 写作中允许改 `terminal_state`，但每次改都回写“前文哪一处需要补因”。
  5. 完稿验收：删掉最后一段，结尾是否仍成立？若成立，说明结尾是补的；若不成立，检查是否“高潮后只解释未解点”。
  6. C 分支：初稿后补写 `terminal_state` 与 `latent_image`，再做一次倒推校验。
- **输出字段**：`ending_mode`（terminal scene / terminal state / discovery）、`terminal_scene` 或 `terminal_state`、`three_causal_links`、`latent_image`、`ending_check`。
- **反例（≥2）**：
  1. **PG38887 L2541 Trollope 边写边定**：“my incidents are fabricated to fit my story as it goes on”。这说明连载可以没有预知终场；处置：B 分支只要求终局状态，不要求终场画面。
  2. **PG61625 L1189-1200 / L2941 人物生长、结尾不在心**：Montgomery 的长篇由人物生长；Stribling 说 “No, the ending is not clearly in mind.” 处置：人物驱动长篇用 B，不把“先定结局”当道德要求。
  3. **PG492 L1584-1615《金银岛》卡壳后换地**：十五天十五章后卡住，换地后一章一天；这说明“倒推”也可能卡住，换环境/换介质能恢复。处置：C 分支允许发现，但必须记录“已写了什么、还缺什么因”。
  4. **PG64210 L7578 侦探先抛谜面**：“propound your mystery at the beginning … work backwards to the first step”。侦探仍须知道终局，只是谜面在前；处置：A 分支中侦探型把“终场揭示”换成“谜面 + 机关”，倒推链照做。
- **适用边界**：短篇/类型/侦探最硬；长篇/连载软化为方向；人物驱动/流浪汉体/随笔式最弱；舞台需要“幕末暂解”而非单一终场。
- **失败出口**：A 分支写不出终场 → 改问“最后一个不可逆的动作是什么”；仍写不出，退回 RC-02 重写 `premise`。B 分支写不出终局状态 → 只写“谁在最后必须做一个什么决定”，不写结局；若连这个也没有，标“终点未定”，暂停结构细化。
- **PG 锚点**：
  - PG38887 L1108-1109 “Take your stand at the end of the story, and work it out backwards.”（M）
  - PG72910 L3034-3035 “see the end of your story before you begin to write it”（M）
  - PG61625 L1138-1139 “The climax; I always start with it”（M）
  - PG30776 L2187 “he must see the end of his story from the beginning”（M）
  - PG72446 L1802-1803 “no conclusion can be right which is not latent in the first page”（M）
  - 反例：PG492 L1584-1615；PG38887 L2541-2543；PG61625 L2941-2942。
- **独立来源数**：5（PG38887、PG72910、PG61625、PG30776、PG72446；PG492 只作反例，不计支持）。
- **来源类型**：METHOD×5。
- **冲突状态**：CONDITIONAL（K-02 起手顺序）。
- **置信度**：MEDIUM（短篇工序有多次自述；长篇“方向”是综合判断，无直接来源说“只需方向”）。

## RC-05 人物—情节：先判入口，再双向校验

- **层级**：structure（生成入口 + 校验）。
- **一句话规则**：不规定“人物永远优先”或“情节永远优先”；按素材里先出现的东西选入口（人物/情境/终局/效果），选后必须做双向校验：情节是否逼人物改变、人物是否促成转折。
- **触发情境**：不知从人物还是情节起笔；人物像道具；情节压得人物喘不过气；编辑说“人物不可信”或“故事没发生”；人物小传很厚，但一进情节就变成传声筒。
- **可观察信号**：
  - 素材最先抓住你的是什么（一个人、一个困境、一个必须发生的场面、一个情绪/画面）；
  - 人物能否说出三处“只有他会这样”的决定；
  - 情境是否已含对抗力量；
  - 终局场面是否必须先发生；
  - 人物是否只在传递信息/推动机关。
- **分支与区分**：
  - **A 人物入口**：区分信号 = 人物能生成后果、换情境仍成立、能说出三处“只有他会这样”的决定；反信号 = 人物只是类型标签、换谁都一样、所有决定都由情节需要解释。
  - **B 情境入口**：区分信号 = 困境本身含对立力量、人物一进场就被逼选择；反信号 = 人物被硬塞进情境（PG61625 L1102 的“doll-like characters”）、情境换谁都能演。
  - **C 终局入口**：区分信号 = 必须先发生某场面/揭示；反信号 = 终局只是作者想要的效果，与前文无因、人物为什么必须走到那里说不清。
  - **D 效果入口**：区分信号 = 先有主导情绪/画面；反信号 = 人物被效果压成符号、没有独立于效果的欲望。
  - **入口区分**：问“如果抽掉这个人物/这个场面/这个效果，素材还剩下什么？”剩下人物 → A；剩下困境 → B；剩下终场 → C；剩下画面/情绪 → D。
- **操作步骤**：
  1. 写 `entry_type` 与 `entry_evidence`（素材里最先出现的那一项）。
  2. 若 A：写人物小传三行（处境/欲望/教养），再让他对预定情境做一次“不听话”的选择；据此改情节。
  3. 若 B：写情境的对抗力量（谁/什么在阻止），再让不同人物进场，看谁把情境推到最大张力。
  4. 若 C：写终场，倒推 3 环；每环问“人物为什么必须这样做”。
  5. 若 D：写效果句，再选能承载它的人物；检查人物是否有独立于效果的欲望。
  6. 双向校验：`plot_forces_character`（情节是否逼人物改变）与 `character_causes_turn`（人物是否促成转折）；两者皆“否”则退回素材层。
- **输出字段**：`entry_type`、`entry_evidence`、`character_card`、`situation_forces`、`plot_forces_character`、`character_causes_turn`。
- **反例（≥2）**：
  1. **PG61625 L1101-1104 玩偶人物**：“inventing a situation and sticking doll-like characters in it” 是失败经验。处置：B 分支若人物只是被塞进情境，先给人物一个会反抗情境的欲望，再改情境。
  2. **PG70492 L2326-2329 Hardy 让人物 suspend their natures**：人物被情节/命运压干，失真。处置：检查 `plot_forces_character` 是否只有“外力推着走”，没有人物自己的选择；补一个代价明确的选择。
  3. **PG72446 L1501-1520 Assingham 夫妇为传递信息而造**：功能人物被读者看穿。处置：若人物只承担信息，删/并，或给他一个与信息冲突的私人目的。
  4. **PG61625 L13563-13575 通俗短篇反例**：以代理情绪为目标的短篇，“extreme character drawing is generally a mistake”。处置：短篇/类型可薄人物，但仍须有可信的欲望；不把“圆人物”当唯一标准（K-15 UNRESOLVED）。
- **适用边界**：短篇/类型偏终局/情境入口；长篇/心理小说偏人物入口；舞台偏情境入口（PG36580 “character is situation”）；连载偏人物入口 + 情节里程碑；速写/印象主义可弱化人物因果，但不能弱化 tone。
- **失败出口**：四入口都说不清 → 退回素材层，不写场景；先列“人物/情境/终场/效果”四张卡，每张只写一句，选最先能写出“后果”的那张。双向校验皆“否” → 停止细化情节，先修人物欲望或情境对抗力量。
- **PG 锚点**：
  - PG58471 L2469-2470 “character in itself is plot”（C，H 到步骤）
  - PG72446 L2306-2307 “what his characters, being what they are, would make of the situation”（M）
  - PG61625 L1473 “Character makes plot.”（M）
  - PG1974 L371-372 “Plot, then, is the first principle”（C）
  - PG32092 L211-213 “each incident functions in the development of a plot or dramatic problem”（M）
  - PG36580 L9526 “character is situation.”（M，舞台）
- **独立来源数**：6（PG58471、PG72446、PG61625、PG1974、PG32092、PG36580）。
- **来源类型**：METHOD×4 / CRITICISM×2。
- **冲突状态**：CONDITIONAL（K-02；K-15 人物扁/圆另立）。
- **置信度**：MEDIUM（入口诊断有跨来源支持；“哪种入口更好”无数据，且同书自相矛盾）。

## RC-06 主行动与多线：主导线或等权多线，次线须有功能关系

- **层级**：structure（长篇/多线骨架）。
- **一句话规则**：先检查是否存在主导行动；群像或多故事并重时允许多条等权主线，标注相互照应的主题/后果/汇聚方式；找不到共同目标时提供删、并、平行保留三案，不擅自删除。
- **触发情境**：长篇越写越散；次线抢戏；群像热闹但主线不动；改编时不知道删哪条线；连载写到后面每条线都要独立收束，主线却停滞。
- **可观察信号**：
  - 能否一句话说出主行动（谁要什么、谁阻止、代价）；
  - 每条次线是否有独立主角/独立高潮；
  - 抽掉一条次线，主线是否变化；
  - 多条线是否在同一场面/同一决定处汇合；
  - 是否存在只在主题上相似、情节上互不相干的线。
- **分支与区分**：
  - **A 单主线**：区分信号 = 一个核心决定/危机、所有次线服务它；反信号 = 多条线各有独立收束、每条都能单独成篇。
  - **B 多线交织**：区分信号 = 线之间有因果交换、共享终局、彼此改变对方的条件；反信号 = 各线只在主题上相似、情节上互不相干、删掉一条主线毫发无损。
  - **C 链条式（picaresque/tale）**：区分信号 = 事件串联、无真正高潮、主角穿过世界而非被世界逼选择；反信号 = 读者期待一个总收束、每条事件都在加码同一危机。
  - **A/B 区分**：问“次线是否改变主线的条件？”改变 → B；只提供对照/信息 → A 的次线或背景；完全不改变 → 删/并。
- **操作步骤**：
  1. 写 `main_action`：`某人 + 要什么 + 谁/什么阻止 + 失败代价`。
  2. 列 `strands`：每条线写 `function`（反转/补足/对照/提供信息）与 `intersection`（在哪一场、与谁、交换什么）。
  3. 无 `intersection` 的线：删、并、或降为背景；只靠“主题相似”的线不算交汇。
  4. 标 `major_convergence`：所有主线在何处汇合；若在 3/4 处，检查前段是否蓄因、后段是否只收果（PG30776 结构比例，**单来源默认参考，不是硬门**；侦探/开放式另算）。
  5. 检查 `equal_strands`：若多条线等重，必须像 PG30776 L2421-2430 那样交织；否则改主次。
  6. 完稿后做“抽线测试”：抽掉一条线，复述主线；若完全不变，该线是赘线。
- **输出字段**：`main_action`、`strands[]`（name/function/intersection）、`major_convergence`、`cut_log`。
- **反例（≥2）**：
  1. **PG30776 L2328 链条式不算 plot**：picaresque 单线串联不构成“编织”；此时不强行加交汇，改按 C 分支验收“每站是否改变主角处境”。
  2. **PG30776 L2421-2430 等重多线**：允许若干等重故事，但须交织；不能拿“多线”当“无主线”的借口。处置：等重线必须共享终局或互相改变条件，否则降为次线。
  3. **PG10865 L2931 舞台拉幕点**：要求在多线汇聚处拉幕；但传奇/情节剧可加 Prologue（作者自陈例外）。处置：舞台用“幕末汇聚”，小说不强制每章汇聚；迁小说标 H。
- **适用边界**：长篇/多线/群像/连载强；短篇只留一条主行动；舞台分幕需“幕末汇聚”；戏曲“一人一事”更严（PG25471 L128）；链条式/流浪汉体只要求“每站改变主角”，不要求总汇聚。
- **失败出口**：写不出 `main_action` → 先不要列线；回到 RC-02 写 `premise`，或把“主角最想要的东西 + 最大阻力 + 失败代价”三格填满。次线无 `intersection` → 删/并；作者舍不得删时，要求写出“它改变了主线的哪个条件”，写不出就标为背景，不进入结构。
- **PG 锚点**：
  - PG32092 L5561-5564 “the main course of the story must be single”（M）
  - PG30776 L2330-2332 “The word plot signifies a weaving together”（M）
  - PG30776 L2416-2418 “avoid a sub-plot, unless…”（M）
  - PG10865 L2931-2932 “the curtain should be raised at the point where separate lines have converged”（M，舞台）
  - PG25471 L128 “此一人一事，即作传奇之主脑也”（M，中文引文，戏曲）
- **独立来源数**：4（PG32092、PG30776、PG10865、PG25471）；PG70492 只作反例/对照。
- **来源类型**：METHOD×4。
- **冲突状态**：CONDITIONAL（K-01 单一/多线；K-11 舞台迁移）。
- **置信度**：MEDIUM（结构判据跨来源一致；3/4 汇聚比例是 Hamilton 一家的说法，且他把侦探除外）。

## RC-07 场景 / 概述 / 过渡：三种单元，按功能配比

- **层级**：structure（场景调度）；对话/描写的剂量另受 RC-14、RC-15 与 K-16 约束。
- **一句话规则**：把稿子拆成“场景（当下冲突）、概述（压缩信息）、过渡（时间流逝）”三种单元；关键对抗优先检验是否值得铺成场景；若体裁、节奏或视角要求可用概述，避免机械扩写；低价值场景可降为概述，长篇时间跨度用过渡页承接。
- **触发情境**：全篇都是概述，读者不进戏；全是场景，篇幅爆炸；时间跳跃生硬；中段发闷；该演出来的对峙被一句“他们谈了谈”带过。
- **可观察信号**：
  - 每段是否有连续的时间/地点/人物动作；
  - 是否存在“该演出来的对峙”被概述；
  - 是否有“只交代后来怎样”的长段；
  - 时间跳跃处是否有锚点（季节、身体、物件）；
  - 连续单元是否只加码、无缓解（K-13：短篇兴趣不减；长篇允许缓解，但须服务更大张力）；
  - 对话是否只在高潮/转折处承担主要功能（书面叙事；舞台另算）。
- **分支与区分**：
  - **A 场景优先**：区分信号 = 冲突当面发生、信息在对抗中交换、人物当场做选择；反信号 = 没有对抗、只是解释、人物在复述已知信息。
  - **B 概述优先**：区分信号 = 信息量大、时间跨度长、次要过程、需要快速交代；反信号 = 把高潮/转折也概述掉、读者被挡在戏外。
  - **C 过渡优先**：区分信号 = 两次高潮之间需要“时间过去”的感觉、需要呼吸；反信号 = 过渡无信息、纯拖延、只是“后来呢”的填空。
  - **A/B 区分**：问“这段是否有人当场想要什么并遇到阻力？”有 → 场景；没有但信息必要 → 概述；只是时间流逝 → 过渡。
- **操作步骤**：
  1. 逐段标 `unit_type`：scene / summary / transition。
  2. 标 `function`：推进主行动 / 揭示人物 / 提供必要信息 / 制造时间感 / 纯装饰。
  3. 关键对抗若是 summary → 改写为 scene（谁在场、想要什么、谁阻止、代价）。
  4. 场景若是纯信息/纯装饰 → 降为 summary 或删。
  5. 长篇两次高潮之间补 transition：写“季节/日常/身体变化”，但必须携带新信息（PG72446 L1603-1605 “colourless and quiet”）。
  6. 检查配比：短篇/动作场景多、概述少；长篇/跨年过渡多；对话只在高潮/转折处（PG72446 L1204，书面叙事；舞台 K-16 相反）。
- **输出字段**：`unit_table`（段号/type/function/字数）、`scene_to_summary_log`、`transition_log`。
- **反例（≥2）**：
  1. **PG61625 内部 23 人反对描写、6 人主张全描写**：配比无统一标准。处置：不规定“场景必须占多少”，只按功能与读者进入方式判断；把“比例”当诊断假设，不当硬门。
  2. **PG68291 的 tale/sketch 可以以概述为主**：强行场景化会破坏文体。处置：先按 RC-01 判赛道；tale/sketch 允许概述为主，但仍须“有某事在发生”。
  3. **PG72446 L1603 过渡要“colourless and quiet”**：不是无信息；纯拖延的过渡应删。处置：过渡必须携带时间/关系/身体变化中的至少一项新信息。
  4. **PG61625 L5390 “If I use more than one sentence of description I wince.”**：这是快节奏作者的反信号，不是通则。处置：动作短篇可极简；现实主义/氛围文本不照搬。
- **适用边界**：长篇/连载/多线最需要；短篇只需“关键场景 + 必要概述”；舞台没有“概述”，只有台词/动作/暗场；电影用镜头/剪辑替代；印象主义/速写可弱化场景对抗，但不能没有 tone 的推进。
- **失败出口**：分不清某段是场景还是概述 → 用“是否有人当场想要什么/被什么阻止”判定；仍分不清，标“混合单元”，先不删，留到结构层再看。关键对抗写不成场景（缺对抗力量）→ 回到 RC-05 补情境对抗，不硬写对话。
- **PG 锚点**：
  - PG32092 L3289-3292 描写随叙事逐项发生、不能一次做完（M）
  - PG72446 L1603-1605 “not fearing to go slowly”；“colourless and quiet”（M）

## RC-08 单元收束：章 / 幕 / 折末的“暂解 + 未解”

- **层级**：structure（单元边界）。
- **一句话规则**：有承诺延续的章节或连载单元末检查状态变化与待兑现问题；宁静过渡、氛围篇章或已完成段落可以不设钩子；短篇按整篇效果验收，不强制每章悬念。
- **触发情境**：章末平淡；读者不追下一章；幕末像断在原点；折末没有“且听下回”；连载每章都在重复“危机—解除—再危机”。
- **可观察信号**：
  - 单元首末状态是否同一；
  - 末句是否封死或留白墙；
  - 是否给出“cue for curtain”却继续演；
  - 下一单元是否兑现上一单元的承诺；
  - 读者是否早已预判却一直被拖。
- **分支与区分**：
  - **A 章/幕/折/连载**：区分信号 = 分单元交付、读者会中断、需要下次进入的理由；反信号 = 一次读完的短篇、单元只是排版切分。
  - **B 单场短篇/印象主义**：区分信号 = 只有一个总收束、不需要章末钩子；反信号 = 为分章而分章、每段都硬留悬念。
  - **C 舞台/戏曲**：区分信号 = 幕/折有演出停顿、观众会离场/换景；反信号 = 案头阅读本、无演出停顿。
  - **A/B 区分**：问“读者是否真的会在这里停下？”会 → A；不会 → B。网络连载/周更按 A，但钩子必须兑现。
- **操作步骤**：
  1. 列 `unit_ends`：每章/幕/折的最后一场、最后一句。
  2. 三查：`state_changed`（人物处境/认知是否变）、`open_question`（读者带走什么未解）、`delay_check`（是否已被预判却拖延）。
  3. A：若状态未变，改末事件使状态改变；若没有问题，留一个可见的下一步或明确谜题；若已预判，删拖延或补更强回报。
  4. 长篇/连载：在“小收煞”处“宜紧忌宽”（PG25471 L982），但不得靠虚假悬念；下一单元必须兑现。
  5. 全书/全剧末：“大收煞”要先解扣再起一次波澜，且不留“包括之痕”（PG25471 L994）。
  6. B：只检查总收束是否完成主导效果，不强行加钩子。
- **输出字段**：`unit_end_table`（unit/state_changed/open_question/delay）、`payoff_log`（承诺→兑现）。
- **反例（≥2）**：
  1. **PG70492 L4238 “opening out”**：反高潮/开放结尾可以成立；此时“未解”是设计，不是缺陷。处置：先声明结尾契约（RC-10），再判断“未解”是否被承诺。
  2. **PG10865 L5457-5462《Wild Duck》省掉“揭穿”必看场面**：改写反响仍成立；说明“幕末必须有大场面”不是硬规则。处置：若省略能产生更强反响，允许省略，但要在下一单元兑现后果。
  3. **PG30776 L4818-4827 悬念终须兑现**：为钩子而钩子、下一章不兑现，读者感到被骗。处置：每个 `open_question` 进 `payoff_log`，标兑现章；不兑现的钩子删。
- **适用边界**：长篇/连载/分幕剧/传奇强；短篇单场弱；戏曲“小收煞/大收煞”是类型专属，迁小说标 H；印象主义/速写可以无章末钩子，但要有 tone 的收束。
- **失败出口**：章末三查全“否” → 该章可删/并；若作者坚持保留，给它一个“状态改变”或“新信息”，否则标为装饰章。钩子写不出 → 不要用“突然出现一个人/一声枪响”硬造；改问“下一章最想知道什么”，写进 `open_question`。
- **PG 锚点**：
  - PG10865 L3281-3283 “An act… ought to consist either of a minor crisis, carried to its temporary solution”（M）
  - PG25471 L982 “宜紧忌宽”（M，中文引文，戏曲）
  - PG25471 L994 “七情俱备”（M，中文引文，戏曲）
  - PG20526 L4061-4062 “the quicker you terminate it the better”（M）
  - PG61625 L2546-2567 “I map everything out in advance.”（M，长篇分节）
  - PG72446 L1603-1605 过渡页（M）
- **独立来源数**：5（PG10865、PG25471、PG20526、PG61625、PG72446）。
- **来源类型**：METHOD×5。
- **冲突状态**：CONDITIONAL（K-06 闭合/开放；K-11 舞台迁移）。
- **置信度**：MEDIUM（舞台/戏曲证据强，小说章末是类比；缺连载数据）。

## RC-09 开篇契约：首段四职，晚入场不是通则

- **层级**：structure（入口设计）。
- **一句话规则**：在进入首个重要场景的适当位置（不规定固定段数）逐步交付“谁要紧、何时何地、什么调/什么类型、留下什么问题”；晚入场是印刷短篇的默认，不是所有体裁的法则。
- **触发情境**：开头软、读者进不去；编辑说“前三段没有故事”；说明性/历史叙事被要求“直接开打”；舞台开场交代生硬；框架故事不知从哪起。
- **可观察信号**：
  - 首段末读者是否知道时间/地点/主角；
  - 是否知道这是什么类型/什么情绪；
  - 是否有一个可追的问题；
  - 背景信息是否织进动作，而不是成块说明；
  - 第一段删掉后，故事是否仍能懂。
- **分支与区分**：
  - **A 晚入场（短篇/动作/商业）**：区分信号 = 有一个正在发生的场面可切入、前史可在动作中补；反信号 = 读者需要先懂一套规则/历史/族谱，晚入场会变成谜语。
  - **B 从头写（说明性/历史/传记/世界构建）**：区分信号 = 理解门槛高、需要典型场合/典型一天先给秩序；反信号 = 前史只是作者舍不得删、秩序段没有任何张力。
  - **C 舞台开场**：区分信号 = 观众需要人物关系/前情，且可以用动作/对白承载；反信号 = 用对话硬灌说明、人物只为交代而存在。
  - **D 框架故事**：区分信号 = 需要一个“为什么现在讲”的理由、框架本身有压力；反信号 = 框架只是装饰、删掉不影响。
  - **A/B 区分**：问“读者不懂前史，是否就看不懂当下的动作？”不懂 → B；懂 → A。不是按“高级/低级”选。
- **操作步骤**：
  1. 写 `first_paragraph_contract`：四职各一句；缺哪项补哪项。
  2. A：从“第一次不可逆的动作/对话”切入；把前史拆成 1–3 处动作中的信息。
  3. B：从“典型场合/典型一天”开头，先给秩序，再打破；不要为了“晚入场”跳过必要规则。
  4. C：把 exposition 改成人物当下的利益冲突（谁想从谁那里得到什么）。
  5. D：框架要给出“讲述者为什么现在讲”的压力；否则删框架。
  6. 自检：删掉第一段，故事是否仍能懂？若能懂，第一段可能只是装饰；若不能懂，检查是否信息过载。
- **输出字段**：`opening_contract`（who/where-when/tone-type/question）、`entry_point`、`exposition_log`（信息→承载动作）。
- **反例（≥2）**：
  1. **PG78424 L1846 要“尽可能晚”，同书 L367 又要“从故事开头写起”**：书级未调和，不能当通则。处置：按 A/B 条件选，引用时标明同书矛盾，不拿单句当普遍律。
  2. **PG21964 L581-656《Rip》两层框架、两段静态写景仍成立**：框架/多层叙事可以违反“晚入场”。处置：D 分支先给“为什么讲”的压力，静态写景可留。
  3. **PG13589 L2107 舞台开场每个要点说三遍**：因观众迟到/不专注；小说无此强制力。处置：只在 C 分支/现场演出使用；小说不得把“说三遍”当 exposition 规则。
  4. **PG76688 允许 withheld 开头**：但要求足够技巧与回报（L3546-3547）。处置：刻意悬置必须写清“读者被扣住的是什么问题、何时回报”；否则改晚入场。
- **适用边界**：印刷短篇/商业小说取 A；说明性/历史/传记取 B；舞台取 C；框架故事取 D。1900–1920 的“晚入场”是杂志市场习惯，不是跨时代法则；“首段 2–3 段”是历史默认，不是硬门。
- **失败出口**：四职写不全 → 先写“谁+何处+什么不对劲”三句，不写完整开头；若三句也写不出，说明素材还没有人物/处境，回到 RC-02。A 分支找不到“正在发生的动作” → 改 B 的典型场合，或写三个候选入口让作者选。
- **PG 锚点**：
  - PG78424 L1846-1847 “Begin as late in the story as you possibly can.”（MIX）
  - PG78424 L366-369 “begin at the beginning of the story”（MIX，反例）
  - PG20526 L2886-2888 “will seldom comprise more than two or three paragraphs”（M）
  - PG76688 L3513-3521 第一段给时间/地点/主角（M）
  - PG72446 L878-879 “unless you have a salamander to show him”（M）
  - PG13589 L2107-2111 舞台开场三遍法（M，舞台）
- **独立来源数**：6（PG78424、PG20526、PG76688、PG72446、PG13589、PG21964）。
- **来源类型**：METHOD×4 / MIXED×1 / REFERENCE×1。
- **冲突状态**：CONDITIONAL（K-11；PG78424 书级 UNRESOLVED）。
- **置信度**：HIGH（“首段四职”跨来源一致）；MEDIUM（“晚入场”只在短篇/商业语境成立）。

## RC-10 高潮与结尾：四种模式，先选契约再选型

- **层级**：structure（结尾契约）。
- **一句话规则**：结尾不是一种；先按类型契约选模式（闭合/解谜/开放/仪式），再做两条通用验收：结尾须 latent 于开头、高潮后只解释未解点。
- **触发情境**：结尾收不住；高潮后还在解释；侦探结尾没解谜；文学结尾被要求“给个交代”；戏曲/舞台收场散；开放结尾被读者当成没写完。
- **可观察信号**：
  - 高潮在哪一场；高潮后还有几段；
  - 未解问题是“需要解释”还是“需要留白”；
  - 开头埋的意象/问题是否回收；
  - 类型读者期待的是“答案/团圆/余味/惊叹”；
  - 删掉最后一段，结尾是否仍成立。
- **分支与区分**：
  - **A 闭合型（类型/古典/舞台）**：区分信号 = 读者要答案/团圆/正义、高潮与结论可同时；反信号 = 开放会显得未完成、类型承诺被违背。
  - **B 解谜型（侦探/悬疑）**：区分信号 = 有一个必须解释的机关、谜面已在前文抛出；反信号 = 解释会杀死余味、机关靠巧合。
  - **C 开放型（文学/现代）**：区分信号 = 结尾要“扩张”而非“收口”、开头已埋 latent image；反信号 = 线头未收是作者失控、开放只是写到哪算哪。
  - **D 仪式型（戏曲/舞台大收煞）**：区分信号 = 需要“七情俱备”的收场、逐人给落点；反信号 = 只靠总结陈词、先解扣后没有新波澜。
  - **A/B/C/D 区分**：先问“读者被承诺的是什么”（答案/机关/余味/仪式），再选型；不以“开放更高级/闭合更成熟”排名。
- **操作步骤**：
  1. 写 `ending_contract`：读者被承诺的是答案、团圆、余味还是惊叹。
  2. 标 `climax_scene` 与 `post_climax_material`：只保留“未解点”的解释；其余移入番外/删。
  3. A：高潮与结论尽量同时（PG20526 L4084）；若必须收束，限一段。
  4. B：把机关解释放在高潮后，但用动作/对白承载，不用说明书（PG64210 L7578）。
  5. C：检查 `latent_image` 是否回收；开放不等于任意收笔（PG72446 L1802）。
  6. D：先解扣，再起一次波澜，收时逐人给落点，不念总结（PG25471 L994）。
  7. 通用验收：删掉最后一段，结尾是否仍成立？成立则结尾是补的；不成立则检查是否只解释了未解点。
- **输出字段**：`ending_contract`、`climax_scene`、`post_climax_material`、`latent_image`、`ending_check`。
- **反例（≥2）**：
  1. **PG70492 L4238 “Not completion. Not rounding off but opening out.”**：开放结尾成立；但 Forster 也承认“几乎所有小说结尾都弱”（L2369）。处置：C 分支必须检查 latent image 与线头，不把“开放”当免检。
  2. **PG20526 L3866《Lady, or the Tiger?》开放是为幽默效果**：作者自己把它标为例外。处置：若用开放，写清“为什么这个类型/效果需要不揭”；否则按 A/B 收。
  3. **PG64210 L7578 侦探必须解释**：先抛谜面、倒推机关；不能用“开放”逃避解谜。处置：B 分支的机关必须可回读、可验证；不能靠巧合。
  4. **PG25471 L994 古典戏曲要团圆**：“七情俱备”；现代小说不必。处置：D 分支只用于戏曲/仪式型舞台；不把“团圆”当所有叙事的要求。
- **适用边界**：短篇/独幕/商业类型偏 A/B；侦探必须 B；文学/现代可 C；戏曲/舞台可 D。四者不是进化阶段，不能按时代排名；K-06 作为“哪种更好”的普遍命题 UNRESOLVED。
- **失败出口**：说不清 `ending_contract` → 先问“读者读完最想得到什么：答案、团圆、余味、惊叹？”四选一；仍选不出，标“结尾未定”，不要写结尾。结尾写完但删掉最后一段仍成立 → 结尾是补的；回到 RC-04 检查 `terminal_scene/terminal_state` 与 latent image。
- **PG 锚点**：
  - PG20526 L4061-4062 “the quicker you terminate it the better”（M）
  - PG20526 L4084 “conclusion and the climax should be as nearly simultaneous as possible”（M）
  - PG64210 L15665-15666 “add another word after the climax”（M）
  - PG1974 L910-911 “Every tragedy falls into two parts,--Complication and Unravelling”（C）
  - PG70492 L4238-4239 “Not completion. Not rounding off but opening out.”（C）
  - PG72446 L1802-1803 “no conclusion can be right which is not latent in the first page”（M）
  - PG25471 L994 “七情俱备”（M，中文引文，戏曲）
  - PG64210 L7578 “work backwards to the first step”（M，侦探）
  - PG68291 L10453-10457《The White Old Maid》以“秘密不揭”收束（C/FC，开放型例）
- **独立来源数**：7（PG20526、PG64210、PG1974、PG70492、PG72446、PG25471、PG68291）。
- **来源类型**：METHOD×4 / CRITICISM×2 / FICTION_CASE×1。
- **冲突状态**：UNRESOLVED（K-06 作为普遍美学命题；操作分型为 CONDITIONAL）。
- **置信度**：MEDIUM（四种模式有跨来源支持；“哪种更好”无证据，保留争议）。

## RC-11 视角：信息合同 + 距离稳定 + 切换代价

- **层级**：structure（信息权限）+ style（距离/语域）；两层不能混判。
- **一句话规则**：视角不是“禁止切换”，而是三件事：信息获取权限必须一致（合同）、叙述距离要可辨且重新锚定、每次故意切换都要有触发/收益/标记/代价。
- **触发情境**：限知视角突然写出人物不可能知道的事；全知与限知混用；多人视角切换生硬；第一人称写着写着变成作者；编辑说“视角乱了”；为了传信息临时换到配角脑子里。
- **可观察信号**：
  - 叙述者此刻能知道什么、不能知道什么；
  - 是否存在“越界知识”（别人的内心、远处发生的事、尚未发生的结局）；
  - 语域/距离是否与视角人物匹配；
  - 切换处是否有场景/章节/排版标记；
  - 切换买回了什么（范围、反讽、对照、信息）。
- **分支与区分**：
  - **A 限知/单一 reflector（短篇默认）**：区分信号 = 一个意识可承载全部信息、读者跟着他/她受限；反信号 = 需要多人内心/跨地同时发生、单视角必须靠巧合传信。
  - **B 多 reflector（长篇默认 2–3，非硬门）**：区分信号 = 单一意识无法知道/反应、每条视角有独立的信息与欲望；反信号 = 为了省事而切、切过去只为传一句话。
  - **C 全知/群像/史诗**：区分信号 = 需要社会全景/多线对照、叙述者可自由进出但仍有选择原则；反信号 = 全知变成“作者想说什么就说什么”、同一场景无标记滑入多人内心。
  - **D 故意混合/元叙述**：区分信号 = 混合本身产生效果（反讽、不可靠、间离）、读者被要求注意叙述行为；反信号 = 混合只是控制不住、作者没有设计标记。
  - **三层区分**：第一层“能不能知道”（合同，近硬）；第二层“距离/语域”（可调，须重新锚定）；第三层“故意切换”（交易，须四件套）。不要用第三层的“切换自由”去掩盖第一层的越界。
- **操作步骤**：
  1. 写 `pov_contract`：叙述者能知道什么、不能知道什么、能进入谁的意识。
  2. 写 `distance_profile`：每章/每场的叙述距离（贴身/中距/远距）；变化处标“为什么变”。
  3. 建 `switch_ledger`：每次切换写 `trigger`（当前 reflector 不可能知道/无法反应）、`benefit`（单视角拿不到的东西）、`marker`（场景/章节/排版）、`cost`（重新定向/认同转移）。
  4. 逐场审计：越界知识若无 marker/benefit，判为缺陷；有 benefit 但无 marker，判为读者会迷路。
  5. 短篇：默认一个 reflector；若必须切换，优先用框架/书信/档案，而不是中途换脑。
  6. 长篇：默认 2–3 个（操作默认，不是统计法则）；超过时检查是否群像/史诗，并确保每次切换都“买回”东西。
  7. 完稿：朗读切换段；若读者被弹出，补强度或改回同一意识过滤（PG70492 L1977 的“bounce”检验）。
- **输出字段**：`pov_contract`、`distance_profile`、`switch_ledger`（trigger/benefit/marker/cost）、`pov_violations`。
- **反例（≥2）**：
  1. **PG70492 L1979-2043《Bleak House》《War and Peace》频繁切换仍成立**：说明“一致性”不是绝对；处置：C/D 分支允许频繁切换，但每次仍要有 trigger/benefit/marker/cost；Forster 的批评判断转步骤标 H。
  2. **PG72446 L1501-1520 Assingham 夫妇为传递信息而造**：行为不可信；切换的代价高于收益。处置：若切换只为传信息，改回主视角，用动作/对白让信息自然出现。
  3. **PG78424 L3458 1926 选本仍有第一人称叙述者公开现身**：不是所有时代都禁“叙述者现身”。处置：D 分支允许，但须标清叙述者位置与可靠性；不把“作者退场”当绝对禁令。
  4. **PG61625 L14206-14243 第一人称三种禁用**：是逐篇选择，不是一刀切；处置：第一人称可用，但要检查“是否只能靠自述解释”“是否掩盖了场景缺失”“是否让读者无法验证”。
- **适用边界**：短篇/悬疑强（一个 reflector）；长篇 2–3（默认）；群像/史诗可多；19 世纪全知合法；后现代元叙述是 D；舞台没有严格视角，只有“观众知道多少”；影视的镜头视角是另一套，不直接换算。
- **失败出口**：写不出 `pov_contract`（能知道/不能知道）→ 先选一个 reflector，把所有信息限制在他/她可见范围内；若故事必须跨地同时发生，改多 reflector 或全知，并在 `switch_ledger` 逐次记账。切换无 benefit → 不切；改由当前视角人物目击/听说/推断。
- **PG 锚点**：
  - PG72446 L771 “record anything not naturally within his register”（M）
  - PG72446 L1451-1452 “it is best to shift as seldom as possible”（M）
  - PG72446 L1472-1475 “no convention is in itself objectionable”（M）
  - PG32092 L2320-2321 短篇不应改视角（M）
  - PG30776 L4316-4317 “there is always one best point of view”（M）
  - PG38887 L1538 视角看不见的不写（M）
  - PG70492 L1977 “bounce the reader into accepting what he says”（C）
  - PG78424 L3458 叙述者公开现身（MIX，反例）
- **独立来源数**：7（PG72446、PG32092、PG30776、PG38887、PG70492、PG78424、PG61625）。
- **来源类型**：METHOD×4 / CRITICISM×1 / MIXED×1 / REFERENCE×1。
- **冲突状态**：CONDITIONAL（K-04；“禁止一切切换”不成立，切换须按 `switch_ledger` 记账）。
- **置信度**：HIGH（“信息权限不能偷越”跨来源一致）；MEDIUM（切换数量 2–3 是 Wharton 一家，非统计）。

## RC-12 读者已知度：先画知识矩阵，再配悬念

- **层级**：structure（信息设计）；效果层全部 H。
- **一句话规则**：先确定“读者/人物/作者”各自知道什么，再选悬念模式（悬疑=读者少知、反讽=读者多知、惊奇=同步后揭晓）；所有读者主张标 H。
- **触发情境**：悬念不成立；读者早就猜到；揭秘时读者失望；舞台/小说同一场戏效果相反；改编时不知道哪些信息该提前给。
- **可观察信号**：
  - 读者进入时知道什么；
  - 人物知道什么；
  - 作者/叙述者知道什么；
  - 揭晓点在哪；揭晓后还剩什么；
  - 读者是否已从类型惯例预知。
- **分支与区分**：
  - **A 悬疑（读者少于人物）**：区分信号 = 读者不知道秘密/结局、人物知道但不说；反信号 = 读者已从类型惯例/副标题/章名预知、保密只靠人物不肯说。
  - **B 反讽（读者多于人物）**：区分信号 = 读者知道人物不知道的事，产生优越/恐惧/同情；反信号 = 读者知道后只剩等待、人物迟迟不发现且没有新代价。
  - **C 惊奇（读者与人物同步）**：区分信号 = 揭晓即转折、读者与人物同时获得信息；反信号 = 揭晓只是补常识、没有改变人物处境/读者理解。
  - **D 一般叙事（分层）**：区分信号 = 不同场景对不同人保密、知识状态随场景变化；反信号 = 全篇一个知识状态、所有角色共享作者脑。
  - **A/B 区分**：问“读者知道后，紧张感来自‘他会不会发现’（B）还是‘他能不能解决’（A）？”；两者不能混成“读者都知道但人物装不知道”。
- **操作步骤**：
  1. 画 `knowledge_matrix`：行=读者/主角/对手/配角，列=关键信息。
  2. 选 `suspense_mode`：A/B/C/D；写一句“读者此刻最想知道什么”。
  3. 定 `reveal_points`：每个秘密何时说、由谁说、说完改变什么。
  4. A：检查读者是否已从类型惯例预知；若已预知，改冲突使读者知情仍紧张。
  5. B：检查“读者知道”是否产生持续张力；若只是等待，缩短或改揭晓。
  6. C：检查揭晓是否改变人物处境/读者理解；若只是补信息，前移或删。
  7. 所有“读者会……”句加 H 标记；不得写“研究支持”。
- **输出字段**：`knowledge_matrix`、`suspense_mode`、`reveal_points`、`reader_question`。
- **反例（≥2）**：
  1. **PG13589 L2147 舞台要求观众全程知道秘密**：侦探若照搬会泄底（PG64210 L7578）。处置：B 分支只用于舞台/戏剧反讽；A 分支（悬疑）不得用“观众预知”规则。
  2. **PG66600 L2432 悬念有时靠“almost fabulous stupidity”**：这是市场观察，不是正面方法。处置：不把“读者会忘”当设计；关键信息该埋则埋，不靠读者健忘。
  3. **PG58471 L8267-8269 小说唯一可预设义务是“有趣”**：不能拿“读者会不懂”当删减借口，也不能拿“读者会懂”当免解释理由。处置：以知识矩阵为准，不以读者猜测为准。
  4. **侦探读者默认“会有答案”**：类型惯例本身是知识状态的一部分；处置：A 分支必须与类型惯例配合，不能把“读者知道类型”当“读者知道真相”。
- **适用边界**：舞台/商业短篇/悬疑/侦探强；文学长篇/实验叙事弱；儿童/成人读者模型不同；1900–1920 的“读者健忘”是历史观察，不是普遍心理；互动/游戏叙事未覆盖。
- **失败出口**：填不满 `knowledge_matrix` → 先只填“读者/主角/对手”三行；仍填不满，说明信息设计未定，不要写揭晓。A 分支发现读者已预知 → 改 B（让读者知道人物不知道）或改冲突；不要靠隐藏信息硬撑。
- **PG 锚点**：
  - PG13589 L2147-2148 “the audience must know the secret all the time”（M，舞台）
  - PG10865 L3903-3905 “the source of the highest pleasure”（M，舞台）
  - PG76688 L557-558 “The imposing of an illusion is the object and test of fiction”（M）
  - PG76688 L1225-1226 “The effects are cumulative”（M）
  - PG66600 L2432-2434 “almost fabulous stupidity of the large mass of readers”（C）
  - PG20526 L3567-3569 3,000 词内不设前置缓解、≥10,000 词可减压（M）
- **独立来源数**：5（PG13589、PG10865、PG76688、PG66600、PG20526；PG13589 与 PG30776 同作者，未与 RC-03 互证）。
- **来源类型**：METHOD×4 / CRITICISM×1。
- **冲突状态**：CONDITIONAL（K-14 预知 vs 保密）。
- **置信度**：LOW（全部读者主张为自述/轶事，无受控实验；只能作“设计选项”，不能作“效果保证”）。

## RC-13 可信度审计：似真、巧合、类型豁免

- **层级**：structure（因果可信度）。
- **一句话规则**：先定作品的“可信度契约”（写实/传奇/幻想/闹剧），再审计巧合：巧合常可作前提/起点，靠巧合解结则应增加可验证的前置因果；喜剧、寓言及自觉使用偶然性的文本须按自身契约另审；类型放弃逼真时，仍须内部逻辑。
- **触发情境**：读者说“太巧了”；真实事件改编被嫌假；幻想/闹剧被要求“合理”；侦探靠巧合破案；人物在关键时刻突然得到恰好需要的东西。
- **可观察信号**：
  - 作品承诺的是“可能发生”还是“不可能但自洽”/“夸张取笑”；
  - 巧合出现在前提、转折还是解结；
  - 巧合是否直接决定胜负/生死/婚配；
  - 是否有前文铺垫/人物因果可替代；
  - 类型内部规则是否前后一致。
- **分支与区分**：
  - **A 写实/悲剧/侦探**：区分信号 = 承诺“可能发生”、因果可追、人物选择能解释结果；反信号 = 用巧合解决核心危机、关键证据/人物恰好出现。
  - **B 传奇/幻想/童话/闹剧**：区分信号 = 明确放弃逼真、内部规则自洽、读者被承诺“奇迹/夸张”；反信号 = 用“类型”掩盖任意转折、人物动机突变。
  - **C 真实事件改编**：区分信号 = 事件确实发生、作者选择“按实”呈现；反信号 = 以“真事”为由跳过铺垫、把真实当免罪符。
  - **A/B 区分**：问“这个巧合如果删掉，危机是否仍能由人物/前史解决？”能 → 巧合可留；不能 → 它承担了解结，按 A 改写。
- **操作步骤**：
  1. 写 `credibility_contract`：读者被承诺的是“可能”、“不可能但自洽”还是“夸张取笑”。
  2. 列 `chances`：每个偶然相遇/误递/同时到达；标它出现在前提/转折/解结。
  3. A：与危机重合的巧合改写为由人物意志/前史因果驱动（PG10865 L6937）。
  4. C：把真事当奇事写，让人物也惊讶；补双倍铺垫（PG76688 L2109-2110）。
  5. B：保留奇迹，但检查内部规则是否前后一致；不能用“类型”解释人物动机突变。
  6. 完稿：问“读者会不会停下来怀疑”；会，则补因或换事件。
- **输出字段**：`credibility_contract`、`chance_audit`（位置/作用/替代方案）、`setup_log`。
- **反例（≥2）**：
  1. **Oedipus 的巧合是悲剧前提，不是解结**：命运框架可豁免；处置：把巧合放在前提/起点，不放在危机解决处；若放在解结，改写为人物选择。
  2. **PG10865 L6695-6700 允许“delightful improbability”**；PG68291 L6863 要求按 farce 评：闹剧/传奇可容偶然。处置：B 分支保留，但内部规则要一致；不把“好笑”当所有类型的通行证。
  3. **PG64210 L4838-4841 纯奇“probability is not called for”**：仍要求 magnificence/splendor/magic 的内部一致；处置：B 分支检查“世界规则是否自洽”，不检查“现实概率”。
  4. **PG76688 L2048-2052 “dime novel” 容忍度更高**：这是类型契约，不是写实规则；处置：先判类型，再定巧合配额；不把通俗类型的容忍度搬到写实/侦探。
- **适用边界**：写实/悲剧/侦探最严；传奇/幻想/童话/闹剧放宽；真实事件改编须补铺垫；新闻/史传另按“按实”标准（PG23822 L619-621）；当代类型/影视契约未覆盖。
- **失败出口**：说不清 `credibility_contract` → 先按 genre 选“写实/不可能但自洽/夸张取笑”三选一；选不出，按最严的写实处理，标“契约未定”。巧合在解结且改不出人物因 → 换事件/换解结方式；不要用“命运/天意”解释，除非前文已建立命运框架。
- **PG 锚点**：
  - PG20526 L1850 “verisimilitude, not verity, is wanted in fiction.”（M）
  - PG1974 L480-482 诗人写“可能发生”（C）
  - PG12743 L939-940 “true within his chosen convention, and not further.”（M）
  - PG76688 L2056 “Could it happen under the conditions?”（M）
  - PG10865 L6937-6939 “A coincidence… which coincides with a crisis… wholly inacceptable in serious art.”（M，舞台）
  - PG64210 L4838-4841 “probability is not called for”（M，纯奇）
  - PG68291 L6863 “as farce, which blithely assumes the improbable as true”（C/FC）
- **独立来源数**：7（PG20526、PG1974、PG12743、PG76688、PG10865、PG64210、PG68291）。
- **来源类型**：METHOD×5 / CRITICISM×2。
- **冲突状态**：CONDITIONAL（K-05 巧合；K-08 纪实/似真）。
- **置信度**：HIGH（“巧合不能解结”跨写实/舞台/短篇一致；类型豁免边界清楚）。

## RC-14 具体化与细节剂量：少而准，按视角过滤

- **层级**：style（描写/细节）；选择逻辑接近 structure。
- **一句话规则**：具体化不是细节堆量；选 3–5 个能暗示整体的具体细节（操作默认，非硬门），按视角人物“此刻会注意什么”过滤，删掉真实但无用的细节。
- **触发情境**：描写像清单；读者记不住场景；细节很真但不推动；视角人物是农妇却写出地质学细节；每个物件都被同等用力描写。
- **可观察信号**：
  - 每个细节是否可归到一个主导印象；
  - 是否是该视角人物会注意的；
  - 删掉后读者是否还能重建空间/气氛；
  - 细节是否彼此抵消/重复；
  - 细节是否只是作者查资料的证明。
- **分支与区分**：
  - **A 现实主义/地方色彩/氛围**：区分信号 = 细节承载真实感/文化/命运、可暗示整体；反信号 = 细节只是作者查资料、没有选择、每个都同等重要。
  - **B 情节驱动/快节奏**：区分信号 = 细节只用于定位/推进、一句可成像；反信号 = 长段静态描写、细节不改变行动。
  - **C 速写/印象主义**：区分信号 = 细节即 tone、彼此同调；反信号 = 细节彼此不同调、破坏单一印象。
  - **A/B 区分**：问“删掉这个细节，读者是否还能知道在哪/发生什么？”能 → B 可删；不能 → A 保留，但仍要按视角过滤。
- **操作步骤**：
  1. 写 `dominant_impression`：这场戏要让读者记住的一个印象。
  2. 列 `details`：每个细节标功能（定位/人物/气氛/象征/信息）。
  3. 按视角过滤：问“他/她此刻会注意这个吗”；不会则删，即使很生动（PG72446 L1420 Hardy 反例）。
  4. A：保留 3–5 个能暗示整体的细节（操作默认）；用一个具体物承载抽象（PG17470 的“具体名词”法，H 到小说）。
  5. B：把细节压到一句可成像；删掉不影响行动的描写。
  6. C：所有细节必须同调；不同调者删（PG30776 L3787-3790 氛围=严格筛选同质细节）。
  7. 完稿：做“一次成图”测试（PG27224 L805）；读者能否在脑中一次成形。
- **输出字段**：`dominant_impression`、`detail_table`（细节/功能/是否视角可见）、`cut_log`。
- **反例（≥2）**：
  1. **PG61625 有 6 人主张全描写**：在特定读者/类型中成立；处置：A 分支允许高密度，但必须有主导印象与视角过滤，不把“全描写”当普遍法则。
  2. **PG61625 L5390 “If I use more than one sentence of description I wince.”**：快节奏动作短篇成立；处置：B 分支可极简，但不把“一句上限”搬到现实主义/氛围文本。
  3. **PG27224 问题单 33（L826-830）要求删去真实但无用的细节**：不能以“我查过资料”为由保留；处置：真实但无功能 → 删/压；若它服务 tone，按 C 分支保留并检查同调。
  4. **PG27224 L815-818 允许技术说明的细节段（沉思体为 H 推断）**：此时“一次成图”不适用；处置：先判类型/文体，不拿本条的剂量当硬门。
- **适用边界**：现实主义/地方色彩/氛围强；情节驱动短篇“少而准”；速写/印象主义细节即效果；技术/说明文另论；电影/口头媒介是另一套“看”的规则；3–5 个是操作默认，不是统计结论。
- **失败出口**：写不出 `dominant_impression` → 先不写描写，回到场景目标（RC-07）；若场景没有目标，描写必然散。细节都“很重要” → 强制排序：只能留三个，删掉的放进 `cut_log`，看是否真的损失。

  - PG32092 L5683 “stating the concrete in detail”（M）
  - PG27224 L805-807 “bring the whole picture… into the mind at once”（M）

  - PG72446 L1413 “an event in the history of a soul”（M）

## RC-15 文体：清晰得体是底线，节奏是耳朵的事

- **层级**：style（句段/语域）；“什么是好文体”部分属 talent，不可立法。
- **一句话规则**：文体底线是清晰、得体、可朗读；在此之上按类型调音高（朴素/华丽），不把“短词”“简洁”当成唯一法则。
- **触发情境**：句子绕、名词化、套语多；描写词大于事件；朗读拗口；类型需要华丽但被要求“简洁”；作者用长句掩盖空洞。
- **可观察信号**：
  - 主语/主动词是否清楚；
  - 抽象名词是否可换成具体物；
  - 词级是否与事件相称；
  - 朗读是否拗口/单调；
  - 是否有“漂亮但可删”的句子。
- **分支与区分**：
  - **A 说明/叙事散文**：区分信号 = 以传达为主、读者要跟上事件；反信号 = 以声音/气氛为主、句子主要用来展示作者。
  - **B 类型/浪漫/纯奇**：区分信号 = 文体本身是效果、华丽与事件相称；反信号 = 华丽掩盖空洞、形容词多于动作。
  - **C 人物口语/方言**：区分信号 = 语域服务人物、可听可说；反信号 = 作者炫技/记音过度、读者需要注释才能懂。
  - **A/B 区分**：问“把这段改成平实句，事件是否受损？”受损 → B 可华丽；不受损 → A 应平实。
- **操作步骤**：
  1. 朗读一段；标出拗口、换气困难、重音落错处。
  2. 找每句的主语与主动词；名词化改成动词，抽象名词换成可触物（PG17470 L2741-2742）。
  3. 做“音高检查”：用一句话复述这段发生了什么；比较词级是否高于事件（据 PG17470 的 appropriate 标准；转步骤标 H）。
  4. 删套语、同页换称呼、装饰性形容词；删“得意句”前先判断它是否承担转折/揭示（PG17470 L6440 “Murder your darlings”）。
  5. B：允许华丽，但每一处华丽必须服务事件/人物；否则降调。
  6. C：方言只暗示、不记音；语域须与人物教养/场景一致。
- **输出字段**：`style_floor`（clear/appropriate/readable）、`sentence_log`（原句/改句/理由）、`register_check`。
- **反例（≥2）**：
  1. **PG17470 L3919-3931 否掉“短词/撒克逊词”绝对规则**：“I think them false in theory and likely to be fatal in practice.” 处置：不把“短词”当唯一标准；按得体/准确/可读选词。
  2. **PG492 L287-288 “the ear is the sole judge. It is impossible to lay down laws.”**：节奏无法完全立法；处置：给诊断问题与朗读检查，不给“每句不超过 X 词”的硬门。
  3. **PG64210 L4838-4841 纯奇故事文体可从极朴到极华丽**：不能一刀切；处置：B 分支允许华丽，但用“是否服务事件/人物”验收。
  4. **PG38887 L2352 “The style is the man.”**：风格不可教；处置：本 Skill 只改可诊断的清晰/得体/节奏问题，不承诺“造音感”。
- **适用边界**：书面叙事以清晰/得体为底；舞台/口头以可听/可说为底；类型允许华丽；翻译/方言/时代语另论；“简洁是唯一好文体”是 H，不是本规则。
- **失败出口**：朗读仍拗口且改不动 → 标“风格问题”，不要继续在句层打转；回到结构/场景，确认是否在用华丽掩盖缺失的冲突。语域与人物不符 → 先写人物三行小传（处境/欲望/教养），再改台词，不直接“加方言”。
- **PG 锚点**：
  - PG17470 L894-895 “accurate, perspicuous, persuasive, appropriate”（M）
  - PG20526 L4247 “simple, easy and concise”（M）
  - PG492 L287-288 “the ear is the sole judge”（M）
  - PG27224 L820-824 “Fine writing is especially to be avoided”（M）
  - PG23822 L1235-1236 “繁采寡情，味之必厭”（C，中文引文）
  - PG17470 L3919-3931 否掉短词规则（M，反例）
- **独立来源数**：6（PG17470、PG20526、PG492、PG27224、PG23822、PG38887）。
- **来源类型**：METHOD×5 / CRITICISM×1。
- **冲突状态**：CONDITIONAL（K-19 词句难度；K-07 自然/工艺）。
- **置信度**：HIGH（清晰/得体底线一致）；LOW（“什么是好文体”无法立法）。

## RC-16 主题/道德：从行动长出，类型例外明示

- **层级**：structure（主题承载）；价值判断部分不可立法。
- **一句话规则**：小说/短篇的主题应从人物选择与后果中长出；寓言/道德故事/宣传可以明示教训，但必须按该类型的契约验收。
- **触发情境**：结尾突然说教；人物替作者讲道理；主题正确但故事无聊；寓言被要求“藏起来”；讽刺被误读成宣传。
- **可观察信号**：
  - 主题能否写成一个问题而非口号；
  - 人物是否在关键处做出体现主题的选择；
  - 删掉点题句，行动是否仍成立；
  - 类型是否本来承诺“教训”；
  - 反讽标记是否足够。
- **分支与区分**：
  - **A 小说/短篇**：区分信号 = 主题通过选择/后果呈现、读者可自己得出结论；反信号 = 人物口播作者结论、结尾加 moral、行动与主题脱节。
  - **B 寓言/道德故事/宣传/教育**：区分信号 = 类型契约明确要教、教训由行动兑现；反信号 = 教训与行动脱节、只靠口号。
  - **C 讽刺/反讽**：区分信号 = 表面直陈、实则拆解、有足够标记；反信号 = 读者误读为真诚说教、标记不足。
  - **A/B 区分**：问“这个类型的读者是否被承诺‘教训’？”是 → B 可明示；否 → A 须隐；不确定 → 按 A 处理，标“类型未定”。
- **操作步骤**：
  1. 写 `theme_question`（不是 `theme_statement`）：故事在问什么。
  2. 找 `proof_scene`：哪一场的选择/后果最能回答这个问题；没有则补或改。
  3. 标 `declarations`：所有直接点题的句子；逐句删，读行动是否仍成立。
  4. A：删掉或改为人物在压力下的选择；保留最少必要说明。
  5. B：允许明示，但教训必须由行动兑现；否则改行动，不改口号。
  6. C：检查反讽标记是否足够；否则读者会当成宣传。
- **输出字段**：`theme_question`、`proof_scene`、`declarations_log`、`genre_exception`。
- **反例（≥2）**：
  1. **PG64210 L11168-11172 道德故事由“作者明显要教”定义**：“obvious concern about the lesson”；此时“藏主题”反而失败。处置：B 分支允许明示，但教训必须由行动兑现。
  2. **PG20526 L3460-3465 自己承认好故事含 “strong argument for good”**：只是反对把故事当伦理真理的载体；处置：不把“说教必败”当绝对律，也不把“有道德倾向”当缺陷。
  3. **PG76688 L2946-2947 主张小说塑造时代道德**：这是价值立场，不是事实；处置：不写成“小说必须无道德”，也不写成“小说必须有用”。
  4. **讽刺表面直陈可能是有意反讽**：不能一律删；处置：C 分支先检查标记与上下文，再判断是否说教。
- **适用边界**：小说/短篇取 A；寓言/道德故事/宣传取 B；讽刺取 C；儿童文学/教育叙事另有权衡；1900–1920 的道德审查语境不等于普遍法则；当代类型/影视的价值契约未覆盖。
- **失败出口**：写不出 `theme_question` → 先不写主题；从 `proof_scene` 反推“这场选择在回答什么”。删掉点题句后行动仍成立 → 点题句可删；若删后主题消失，说明主题没有落在行动里，回到 RC-05/RC-06 补选择与后果。
- **PG 锚点**：
  - PG20526 L3460-3465 “strong argument for good”；“didacticism in literature is always inartistic”（M）
  - PG64210 L11201-11202 “have the moral seem to grow naturally out of the action”（M）
  - PG23822 L1221 “為情而造文”（C，中文引文）
  - PG72446 L513-514 “a mere irrelevant happening”（M）
  - PG27224 L685-686 “any didactic purpose is not obtrusive”（M）
  - PG70492 L1044 “The story is neither moral”（C，反例）
- **独立来源数**：5（PG20526、PG64210、PG23822、PG72446、PG27224；PG70492 只作反例）。
- **来源类型**：METHOD×4 / CRITICISM×1。
- **冲突状态**：CONDITIONAL（K-09 道德目的）。
- **置信度**：MEDIUM（“从行动长出”跨来源一致；“说教必败”被同书与类型例外削弱）。

## RC-17 修订工序：冷却、单稿、分层改

- **层级**：process（生产工序）+ structure/style（分层对象）。
- **一句话规则**：完稿后允许冷却（急稿可缩短或跳过），再按“结构→场景→句子→校对”分层改；用单稿留痕，改动可回退，不把“改得多”当质量指标。
- **触发情境**：初稿写完不知从哪改；越改越乱；改到失去判断；誊清后找不到原句；一上来就改句子，结构问题没动。
- **可观察信号**：
  - 距完稿多久（是否冷却）；
  - 能否说出每场功能；
  - 改稿是否从结构开始；
  - 是否有可回退的原句；
  - 改动是否只动描写/对白，不动结构。
- **分支与区分**：
  - **A 重度修订（长篇/结构问题）**：区分信号 = 场景功能不清、因果断、主线不成立；反信号 = 只是句子别扭、结构其实成立。
  - **B 轻度修订（短篇/文体问题）**：区分信号 = 结构成立、句子/节奏/细节问题；反信号 = 改句掩盖结构缺陷、越改越花。
  - **C 连载/截稿**：区分信号 = 时间受限、必须按期刊/平台节奏交付；反信号 = 用“没时间”跳过结构检查。
  - **A/B 区分**：先做“每场功能一句话”测试；说不出 → A；说得出但句子差 → B。顺序不能倒。
- **操作步骤**：
  1. 冷却：完稿后放置数日到数周，不读（PG20526 L4756）。
  2. 以“陌生人稿”视角通读，标出“读者会不懂/不信/不想读”处（PG61625 L12194）。
  3. 结构层：逐场写功能；删/并/补；检查因果链与结尾 latent。
  4. 场景层：视角合同、细节剂量、对白是否只在高潮/转折。
  5. 句层：朗读、删套语、改主动词、一句一强调。
  6. 校对：错字、事实、格式。
  7. 单稿留痕：改动写在同一份稿上，保留原句以便回退（PG61625 L15386）。
- **输出字段**：`revision_log`（层级/段落/原句/改句/理由）、`cold_read_notes`、`rollback_points`。
- **反例（≥2）**：
  1. **PG61625 L3120-3143 修订 0 到 20+ 次并存**：修订次数不是质量指标；处置：不把“改得多”当敬业，也不把“零改稿”当天才；按结构需要决定。
  2. **PG492 L1584-1615《金银岛》卡壳/换地后一章一天**：速度与质量无稳定关系；处置：不把“慢”当保证，也不把“快”当草率；按完成度与结构检查判断。
  3. **PG23822 L1554 “自然会妙”**：对某些文本，过度修改会磨掉生气；处置：句层改动设“回退点”，改后朗读；若失去语气，回退。
  4. **连载/截稿**：工序可压缩，但不能用“没时间”跳过结构检查；处置：C 分支至少做“每场功能 + 结尾 latent”两项，句层可后补。
- **适用边界**：职业书面写作/长篇/连载强；短篇可缩短冷却；口头/即兴/截稿新闻弱；“修订提升质量”本身 NOT_PROVEN；没有对照实验。
- **失败出口**：说不出每场功能 → 不要进入句层；先做结构层（RC-06/07/08）。改到失去判断 → 停止，冷却/换读者/换顺序；不要用“再改一版”解决判断疲劳。没有可回退原句 → 先建版本副本，再动稿。
- **PG 锚点**：
  - PG20526 L4756-4757 “lay it away… let it get cold”（M）
  - PG61625 L15386 “the complete history of the fashioning of the thought”（M）
  - PG61625 L12194 “Lay it aside till it's cold”（M）
  - PG492 L925-926 “Nothing should be done in a hurry”（M）
  - PG25471 L818 “隔日一删，逾月一改”（M，中文引文）
  - PG17470 L6440 “Murder your darlings.”（M）
- **独立来源数**：5（PG20526、PG61625、PG492、PG25471、PG17470）。
- **来源类型**：METHOD×5。
- **冲突状态**：NONE（无人反对冷却/分层；只争强度）。
- **置信度**：MEDIUM（工序自述一致；质量收益无对照实验，NOT_PROVEN）。

## RC-18 工作习惯：日课、素材簿、分段骨架、卡壳处理

- **层级**：process（生产策略）；不是艺术价值判断。
- **一句话规则**：把写作当可管理的工作：有条件可固定日课、随手记素材、长篇可先用分段骨架、按任务需求区分起草与修改；卡壳时改做低负荷任务，不硬等灵感。
- **触发情境**：等灵感；三天打鱼两天晒网；长篇写到中段迷路；卡壳后放弃；初稿和修改混在一起，越写越慢。
- **可观察信号**：
  - 是否有固定写作时段/字数；
  - 是否有素材簿/闪念记录；
  - 长篇是否有分段骨架；
  - 卡壳时是否有替代任务；
  - 起草与修改是否混在一起。
- **分支与区分**：
  - **A 职业/长篇/连载**：区分信号 = 固定交付、结构复杂、需要持续产出；反信号 = 偶发短篇、一次成型、没有交付压力。
  - **B 偶发/短篇/口述**：区分信号 = 事件驱动、一次成型、口述/即兴；反信号 = 长期项目、复杂结构、需要跨月管理。
  - **C 卡壳**：区分信号 = 失去方向/人物不真/结构未定；反信号 = 只是懒/疲劳/外部打断。
  - **A/B 区分**：问“这个项目是否需要跨月管理？”需要 → A；不需要 → B。不是按“专业/业余”分。
- **操作步骤**：
  1. 设 `daily_quota`（时间或字数），低到能持续；“whether you are in the mood or not”（PG72910 L3026）。
  2. 建 `notebook`：情节/人物/描写/对白分栏；闪念即时记（PG61625 的素材簿建议）。
  3. 长篇：先 `section_map`（8–9 段为历史默认，非硬门；逐段人物/动作/场景），允许写作中长大或缩小（PG61625 L2546-2567）。
  4. 起草与修改分离：初稿只前进，不回改；修改另开时段。
  5. 卡壳：改做低负荷任务（场景卡、素材整理、读同类作品）；或换环境（PG492 L1584 的换地恢复，H）。
  6. 每周复盘：完成量、卡点、下周一段目标；不把“写得多”当质量。
- **输出字段**：`daily_quota`、`notebook_index`、`section_map`、`stall_log`（卡点/替代任务/恢复方式）。
- **反例（≥2）**：

## RC-19 删减诊断：先分类删除对象，再决定删/压/并/留

- **层级**：structure + style（删减对象跨层）。
- **一句话规则**：删削不是“越短越好”；先分四类对象（事件/场景、句子/词、解释/点题、人物/支线），逐类问“是否改变主行动、是否唯一承载必要事实、是否服务语调/人物”，再删/压/并/留。
- **触发情境**：稿子太长；编辑要求删 20%；删了之后情节断裂；保留了大量“真实但无用”的细节；连载越写越长，支线收不回。
- **可观察信号**：
  - 删除对象属于哪一类；
  - 删掉后主行动是否改变；
  - 该信息是否有第二个载体；
  - 该细节是否服务语调/人物；
  - 删除后读者是否还能重建。
- **分支与区分**：
  - **A 情节驱动**：区分信号 = 主行动/因果链优先、每个事件都要改变条件；反信号 = 删掉的是唯一因、删后因果断裂。
  - **B 氛围/素描/文学**：区分信号 = 细节/语调本身是效果、删描写即毁；反信号 = 以“氛围”保留赘笔、细节不同调。
  - **C 商业短篇**：区分信号 = 篇幅经济、读者要快速进入；反信号 = 删到人物扁平、删到类型承诺失效。
  - **A/B/C 区分**：先按 RC-01 判赛道；再用“删掉后主行动/语调/人物哪个受损”判断。三者不能同时最大化。
- **操作步骤**：
  1. 列 `deletion_candidates`：每条标类型（event/sentence/explanation/character）。
  2. 逐条三问：改变主行动？唯一承载必要事实？服务语调/人物？
  3. A：改变主行动者留；唯一因者留；其余删/压。
  4. B：服务语调者留，但检查是否同调；不同调者删。
  5. C：先删解释/重复，再压次要场景，最后才动人物。
  6. “必要但无趣”者只压缩不删（PG492 L1327-1328）。
  7. 删后复读：主行动是否仍清楚、人物是否仍可信、语调是否仍统一。
- **输出字段**：`deletion_table`（对象/类型/三问/处置）、`compression_log`。
- **反例（≥2）**：
  1. **PG58471 L8591 要求 “typical, to be inclusive”**：不能因体面/篇幅删掉生活面向；处置：B 分支保留“生活面向”的细节，但按语调同调筛选；不把“短”当唯一目标。
  2. **PG78424 L13586 素描的魅力在 atmosphere**：删描写即毁；处置：B 分支先保 tone，再压重复；不按情节驱动标准删素描。
  3. **PG27224 问题单 33（L826-830）要求删去真实但无用的细节**：与“保留真实”冲突，按类型裁决；处置：A/C 分支删真实但无用；B 分支看它是否服务 tone。
  4. **PG492 对“必要但无趣”只压缩；PG23822 “善删者字去而意留”**：不是越短越好；处置：必要信息保留，压缩表达；删后意缺则回退。
- **适用边界**：短篇/商业/舞台强；长篇/文学/素描弱；删除对象随体裁变（事件/句子/解释/人物）；连载还要考虑已发布承诺，不能回改已出版章节。
- **失败出口**：三问答不清 → 先不删，标“承重待定”；用“抽掉这一段，复述主行动”测试。删后主行动断裂 → 回退，改为压缩/合并；不要用“补一句解释”掩盖删错。作者拒绝删 → 给“删/压/并/留”四方案及代价，让作者选。
- **PG 锚点**：
  - PG20526 L3430-3431 “The art of omission is an important branch of the art of authorship.”（M）
  - PG72910 L1799-1800 “The great thing is to know what to leave out.”（M）
  - PG492 L1327-1328 “omit what is tedious or irrelevant, and suppress what is tedious and necessary”（M）
  - PG23822 L1255 “善刪者字去而意留”（C，中文引文）
  - PG58471 L8591 “typical, to be inclusive”（C，反例）
- **独立来源数**：5（PG20526、PG72910、PG492、PG23822、PG58471）。
- **来源类型**：METHOD×3 / CRITICISM×2。
- **冲突状态**：NONE（“删削是核心技艺”无反对；删什么按类型分流，见 K-01/K-03）。
- **置信度**：HIGH（跨来源最一致；具体剂量仍无定量）。

## RC-20 类型契约：必要特征 + 读者承诺 + 市场约束分层

- **层级**：structure（读者契约/市场层）；不是本体论。
- **一句话规则**：把类型当“读者契约 + 教学检索”，不是本体论硬边界；写前列少量可验的必要特征与承诺（3–5 项仅为可选工作量示例），写后逐条验收；市场/审查约束单独列，不与技艺混判。
- **触发情境**：投稿被退“不符合类型”；类型读者失望；想跨类型但不知代价；把市场禁忌当艺术规则；类型混合不知按哪类验收。
- **可观察信号**：
  - 读者买这个类型时期待什么（答案/团圆/恐怖/知识/代入）；
  - 作品是否兑现 3–5 个必要特征；
  - 偏离是否有补偿；
  - 退稿理由指向技艺还是市场/审查；
  - 类型混合时，主导处理是哪一类。
- **分支与区分**：
  - **A 商业/类型投稿**：区分信号 = 明确类型契约、读者预期强、平台/刊物有惯例；反信号 = 作者只想借类型外壳、必要特征缺失且无补偿。
  - **B 文学/跨类型**：区分信号 = 有意偏离并给出补偿（更强的效果/人物/主题）、目标读者清楚；反信号 = 用“文学”掩盖没写好、偏离没有代价说明。
  - **C 市场/审查约束**：区分信号 = 退稿理由指向广告/发行/审查/字数/禁忌；反信号 = 真是技艺缺陷，却怪市场。
  - **A/B/C 区分**：先判“退稿/失望的原因是特征缺失、偏离无补偿，还是市场约束”；三者分栏，不混成“写得不好”。
- **操作步骤**：
  1. 写 `genre_contract`：3–5 个必要特征 + 读者承诺 + 可偏离项。
  2. 标 `market_constraints`：字数、结局、禁忌、审查；与技艺问题分栏。
  3. 逐条验收：必要特征是否兑现；偏离项是否有补偿（更强的效果/人物/主题）。
  4. A：不兑现必要特征就改；B：保留偏离，但写清代价与目标读者。
  5. 退稿分析：先判“技艺/市场/审查”；市场问题不改技艺，技艺问题不怪市场。
  6. 类型混合：按“主导处理”判类（PG68291 编者判词），不按局部元素。
- **输出字段**：`genre_contract`、`market_constraints`、`deviation_log`（偏离/补偿/代价）、`rejection_diagnosis`。
- **反例（≥2）**：
  1. **PG58471 L8480 “clumsy separations”**：James 认为 novel/romance 二分对创作者无意义；处置：类型作契约工具，不作本体论；跨类型按主导处理验收。
  2. **PG64210 L12736 “not possible to make a hard and fast definition”**：类型无硬定义；处置：必要特征列 3–5 个即可，不追求穷尽；类型混合允许重叠。
  3. **PG66600 L2432 反“快乐结局”；PG76688 L3477 承认市场压力但自己怀疑**：两者都无统计；处置：快乐结局按 K-17 UNRESOLVED 处理，先声明目标市场，不写成“读者都要”。
  4. **PG66600 L1582 五条否定律**：这是 1920 年代美国杂志市场，不是普遍道德；处置：只作历史市场约束，不作当代创作法则。
- **适用边界**：1911/1900 印刷市场类型学；现代跨类型、网络长篇、影视类型需另立契约；类型作为教学/市场工具有效，作为本体论无效；3–5 个特征是操作默认，不是类型定义。
- **失败出口**：写不出 3 个必要特征 → 先写“读者买这个类型时最想得到什么”一句，再反推 3 个特征；仍写不出，标“类型未定”，不要用类型规则验收。退稿原因说不清 → 分“技艺/市场/审查”三栏，逐条找证据；没有证据的栏标“未知”。
- **PG 锚点**：
  - PG64210 L742-744 叙事两大门、34 型工作定义（M/R）
  - PG68291 L669-670 “The tale is a chain; the short-story is a tree.”（C/FC）
  - PG13589 L2763-2765 人物决定情节=悲剧、情节决定人物=melodrama（M）
  - PG58471 L8480-8497 “clumsy separations”（C，反例）
  - PG66600 L1582-1584 五条否定律（C/R，历史市场）
  - PG76688 L2782-2784 通俗读者要主角接近完美（M，历史市场）
- **独立来源数**：6（PG64210、PG68291、PG13589、PG58471、PG66600、PG76688）。
- **来源类型**：METHOD×2 / CRITICISM×3 / REFERENCE×1。
- **冲突状态**：CONDITIONAL（K-10 类型边界；K-17 快乐结局）。
- **置信度**：MEDIUM（契约工具可用；类型硬边界被同代来源否定；现代类型无覆盖）。

## RC-21 规则层级：判据、条件、反例，不输出无条件步骤

- **层级**：meta（元规则；约束本文件与其他流程的写法）。
- **一句话规则**：每条规则必须标层级（结构/文体/天赋）、适用域、失效条件、≥2 反例、可观察信号；遇到大师犯规，登记为例外，不升格为新规则。
- **触发情境**：写 Skill/教程/诊断清单；两人各引一条规则互相否定；新手问“到底听谁的”；看到大师犯规就想改规则。
- **可观察信号**：
  - 规则属于结构层还是文体/天赋层；
  - 是否有明确适用域；
  - 是否能说出至少两个反例；
  - 是否把“某大师这样做”当成“所有人都应这样做”；
  - 是否把“反规则”变成新教条。
- **分支与区分**：
  - **A 结构层**：区分信号 = 可拆解、可检查（因果、场景、视角、结尾）；反信号 = 只有品味判断、无法指出文本证据。
  - **B 文体层**：区分信号 = 可诊断、难立法（清晰/节奏/语域）；反信号 = 用“风格”掩盖结构问题。
  - **C 天赋/判断层**：区分信号 = 不可教、只能练（音感、眼光、幽默）；反信号 = 把不可教当不作为的借口。
  - **A/B/C 区分**：问“这条规则能否用文本证据检查？”能 → A/B；不能 → C。C 层不写成步骤，只写训练/阅读建议。
- **操作步骤**：
  1. 给规则打 `layer`（structure/style/talent）。
  2. 写 `scope`（篇幅/媒介/类型/时代）与 `failure_conditions`（≥2）。
  3. 写 `observable_signals`（读者/编辑能看到什么）。
  4. 写 `counterexamples`（至少两个真实 PG 反例）。
  5. 遇到大师犯规：记入 `exceptions_log`，注明“有意/无意、代价、是否可学”；不改规则。
  6. 两条规则冲突：按 RC-01 赛道分流；不能平均，也不能“辩证统一”。
- **输出字段**：`rule_card`（layer/scope/signals/branches/failures/counterexamples/confidence）、`exceptions_log`。
- **反例（≥2）**：
  1. **PG20526 L108 大师可有意犯规、新手须全守**：“大师豁免”不能变成“人人可犯规”；处置：例外登记，不升格为规则；新手仍按结构层检查。
  2. **PG61625 L9645 “no one rule applies to all writers alike.”**：任何“唯一正确方法”都被同一编者的问卷否定；处置：每条规则带条件/反例，不写“必须”。
  3. **PG72446 L1986 “the gist of the matter always escapes.”**：规则只能逼近，不能穷尽；处置：给判据与检查，不承诺“照做就成”。
  4. **PG76688 反公式却输出 18 条主张**：反规则也会变成规则；处置：把“反公式”本身也标为条件性立场，不写成新教条。
- **适用边界**：教学/诊断/编辑场景适用；大师创作/实验作品不适用；结构层比文体层更可教；跨时代须重标；本 Skill 不评价“艺术价值”，只做可观察诊断。
- **失败出口**：一条规则说不出两个反例 → 降为“假设”，不进入 `rules.md` 的正式规则；若已写入，标“证据不足”并移入待验证清单。两条规则冲突且无法按赛道分流 → 保留争议，给安全出口，不强行统一。
- **PG 锚点**：
  - PG61625 L9645-9646 “no one rule applies to all writers alike.”（M）
  - PG72446 L1986-1987 “the gist of the matter always escapes”（M）
  - PG20526 L108-110 大师犯规、新手全守（M）
  - PG32092 L290-297 结构比文笔更可教（M）
  - PG70492 L1977 “not into formulæ”（C）
  - PG78424 L3320 “far better than precept will be a careful study”（MIX）
- **独立来源数**：6（PG61625、PG72446、PG20526、PG32092、PG70492、PG78424）。
- **来源类型**：METHOD×4 / CRITICISM×1 / MIXED×1。
- **冲突状态**：NONE（元规则；具体规则冲突归各条）。
- **置信度**：HIGH（作为格式要求；不保证任何单条规则有效）。
