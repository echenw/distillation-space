# 人物心理与创伤叙事

本 Skill 是小说创作辅助，**不是医疗能力，也不是跨作品写作法典**。唯一文献是 PG2554《罪与罚》（Dostoyevsky, Crime and Punishment），它是文学案例，不是心理学教材，也不是写作手册。

标记约定：**F** = 原文观察（带行号，可回源）；**H** = 有限创作推断（必须给反证）；**P** = 可撤销的叙事操作（必须写成"若……则……，否则退出"）。

三条不可逾越的边界：
1. 不能从单部小说推出跨书共识、临床规律或固定创伤病程。
2. 不能把这部小说的情节设计（自首—受难—被爱更新）说成所有作品必须遵守的结构；同书内就有反例（另一人物以自杀收场）。
3. 不能替作者裁定作品内部未统一的冲突（见文末"保留的冲突"）。

## 触发条件（命中任一即可使用）

- 用户给出章节/场景/角色设定，要**规划**心理弧线、动机链或转变节点。
- 用户要**诊断**某处人物是否突然转向、动机是否断裂、反应是否可信。
- 用户要**改写**一个写坏了的高强度场景、对峙/审讯场景或创伤表现段落。
- 用户要写**沉默、颤抖、梦、回忆、自罚、求恕、和解**等敏感心理表现，需要边界与替代表达。
- 用户要**追溯**某条建议的原文依据。

## 负触发（命中即停止或转出，不得套用）

- 真实人物的精神健康、诊断、用药、风险评估、危机干预 → **停止**本工作流，指向合适的专业资源；不得把小说观察当临床依据。
- 要求"跨所有作品通用"的心理写作定律、固定创伤阶段或疗程时长 → 输出 `NOT_PROVEN`，不得编造共识。
- 要求把自伤/成瘾/暴力写成必要赎罪，或要求受害者必须原谅才能康复 → **拒绝**，改给有选择权的替代方案。
- 只有角色名/昵称、没有任何场景材料 → 输出 `NOT_OBSERVED`，只回一份需要补什么材料的清单。
- 用户要的是医学、心理学教材或流行病学结论 → 本 Skill 不适用。
- 用户使用别的译本或改写版本却要求精准行号 → 只给区间与情节定位，**不得冒充逐字校验**。

## 输入与权限

优先获取：用户提供的当前章节/场景及版本（哪一段、第几版）、角色的已知经历与关系、视角、目标与代价、拟完成任务（规划 / 诊断 / 建议 / 授权改写）。
可选：前后章节、敏感议题边界、锁定不可改的正典。
没有原文时：只提供候选问题清单和计划，**不捏造段落定位**。未授权写文件时只给建议，不落盘。

## 主流程（六步，不要跳步）

1. **锁定版本与时点**：填 [状态卡](templates/character-state-card.md)。把"人物此时知道的事实""读者知道而人物不知道的事实""外在限制"分栏；缺料写"未知"，禁止用"他有创伤"填空。
2. **分栏记 F**：他说了什么、他做了什么、叙述者断言了什么、旁人猜了什么，四栏分列。给每一条 F 标来源位置（章节/段落定位；用本 Skill 的原文依据时带行号）。
3. **提出至少两个互相竞争的 H**，各自写出反证。特别注意本 Skill 的四个高频误判：细节注视（P03 两种机制）、身体信号（P04 叙述层可并置）、沉默（P07 社会成因）、主观失控（P10 与文本已建立的因果分开）。
4. **按条件选 P**：
   - 转向/突变 → 先找**读者可见的触点**（P02）；
   - 说法与行动冲突 → 标注每个版本的说话时点与听众，后出版本也不自动为真（P01）；
   - 高强度场景 → 按"程序动作 → 短促清醒 → 微小物件触发退缩 → 再失控"四拍交替（P11）；
   - 对峙/审讯 → 让双方各提出一个可被对方反向利用的解释，指认落在可见的身体反应上（P12）；
   - 梦/回忆 → 记录梦前触发、梦中意象、醒后选择，但不要求梦必然推动情节（P05）；
   - 羞耻、暴力、自罚、和解 → 先读 [创伤边界](references/trauma-boundaries.md)，保留不和解、不自罚的分支（P06）。
5. **按任务交付**：规划给时点链与场景方案；诊断给原文定位、影响、反例、建议；修订给可撤销的最小段落建议与回归项。保持人物所知、叙述视角与前后因果一致。
6. **回归检查**：人物所知是否被越界、受限制的选择、行为代价、关系连续性、敏感叙事边界、作者硬设定。**出现反证就撤回假说**，不能用本 Skill 的解释强行压住原文。

## 输出合同

每次输出必须包含：任务与版本 / 事实 F（带定位） / 竞争推断 H（各带反证） / 建议动作 P（成立条件与反例） / 建议文本或蓝图 / 风险与未知 / 回归结论 / 状态（已完成 / 待证 / 需作者决定）。
没有证据不得声称"已核实原文全文"。使用示例一律标注 `DESIGN_EXAMPLE`，不能充当真实宿主验证。

## 失败出口

- 材料缺失 → 列待补段落，不编造证据，状态 `NOT_OBSERVED`。
- 正典互斥或缺少作者裁决 → 暂停受影响部分，输出冲突与补证项，**不自动改稿**。
- 单来源无法支持的跨书/科学命题 → 标 `NOT_PROVEN`。
- 真实人的健康与安全 → 停止本工作流，指向专业资源。
- 无编辑授权 → 只交建议，不写文件。
