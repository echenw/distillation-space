# 创伤题材的表现选择、适用边界和伦理检查

这是一份文学写作合同，不识别现实临床病症。所有 PG2554 观察都只是小说中的人物行为和叙述者语言，不能用于推断人的病名、风险或疗法。
本轮（round-p4-final-2026-10-30）在历史版本基础上新增两行硬约束（沉默的社会成因、转变≠悔改）与一行危险行为边界；原有六行全部保留。

| 场景信号 | 可进行的创作处理 | 不支持的推论 | 安全出口 |
|---|---|---|---|
| 颤抖、沉默、退缩 | 写发生何事、谁看见、对行动有什么影响（P02/P04/P07） | PTSD、人格障碍、特定疾病 | 没有原因时标未知 |
| **沉默/不反抗**（本轮新增） | 先写可见的社会与关系成因：谁长期压制、在场者是谁、她曾付出什么代价（P07） | "她本性顺从""她其实愿意""她内心平静" | 成因不明就标未知，不写性格结论 |
| 梦或旧事联想 | 回看梦前刺激和醒后选择（P05） | 梦是创伤诊断依据 | 象征叙事不必解码；梦不必然推动情节 |
| 以惩罚自辩 | 对照人物口头说法与后果（P01/P06） | 痛苦必然带来救赎 | 不浪漫化自伤，保留拒绝和解 |
| 旁人关怀或原谅 | 描写行为选择、边界与长期未决（P08） | 爱情自动治愈、受害者必须原谅 | 允许拒绝和解；**转变不等于悔改**（L22096-22126） |
| 受威胁或暴力胁迫 | 区分有权者、加害与被害、可选行动（P10） | 被迫者也必须担责 | 明确外在控制 |
| 自述"疯了" | 精确记录这是谁在何时对谁说的、他想用它达到什么（P04） | 现实医学诊断或病名 | 限定为角色/时代措辞 |
| **高度危险行为（自杀/自毁）**（本轮新增） | 只写人物如何自我美化与安排，并写出代价与未完成（P06/P08） | 把死亡/自毁渲染为美的完成 | 不提供方法细节，不写疗效或解脱承诺 |

具体步骤：先确定事件与视角 → 使用一个可辨的动作或沉默 → 展示对关系/安全/资源的实际代价 → 标明因观察角度而产生的误解 → 不强制固定恢复阶段 → 回读是否将痛苦当美德或将受害者当别人的成长工具。

不索取真实当事人不必要的创伤细节。若用户要求临床确诊、治疗或危机干预，不调用本 Skill 的心理创作结论；如用户要宣称创伤"必然"触发某症状或期限，标 NOT_PROVEN。

补充边界（本轮新增，来自原文复核）：
- 同一部作品里存在两条罪后结局（自首受刑 L21760-21860 / 自杀 L20856-20929）。**不得**把"自首—受难—被爱更新"写成唯一正确的创伤叙事结构。
- 结局可以同时写"关系带来更新"与"代价高昂、故事才刚开始"（L22308-22310 vs L22354-22359）。允许触点，禁止治愈结论。
