# 规划、诊断、修改与回归：三条可执行路径

## 未有正文：心理弧线规划
从 [状态卡](../templates/character-state-card.md) 填实际已知的关系、时点、目标、限制和冲突；给候选链 A/B：刺激 → 可见动作/反应 → 角色解释 → 真实代价 → 下一幕状态。缺原因不伪造台词或原文位置。作者可以选择保留动因作为悬念。

## 有正文：诊断
1. 明确实际读过的章节版本、句段位置（未给材料写 NOT_OBSERVED）。
2. F：把人物说法、动作、叙述者陈述、旁人的猜测分栏，区分所知信息。
3. H：至少两条有依据的竞争解释，并逐条给反证，例如新增消息、被胁迫、隐藏目的、不可靠叙述。
4. P：只修改可以解决因果断裂的最少场景节点，或给至少两条条件方案。不将"他有创伤"用作万能补丁。
5. 回归：谁知道什么、言行连续性、前后章伏笔和代价、作者硬设定、敏感描写限制。

## 已获改写授权：修订
使用 [修订单](../templates/revision-check.md)。先列原段落及冲突事实 → 阐明修改目标 → 给可撤销建议文本 → 标明不能同时满足的约束与作者裁决 → 与未改前后段落对照。没有授权只能交建议，不写文件。

| 判定信号 | A 解释与 P 分支 | B/反例与出口 |
|---|---|---|
| 怒意突然压过关爱 | 有新消息：展示信息进入人物认知的时点 | 若作为悬念：保留外在动作而不揭谜 |
| **情感在两句话内反转**（本轮新增） | 先找出并写出触发它的可见触点（一个目光/一句话/一个物件） | 新事实已解释时不加独白；作者要悬念就只写动作 |
| 身体颤抖但叙述称清醒 | 对照角色感知与读者可见动作 | 疲劳/疾病/外力也可能；叙述层可以合法并置二者，不是笔误 |
| 梦境之后改变选择 | 追踪梦前后可见差别 | 纯象征意象可不解释；**梦不必然导致转折** |
| **角色久久盯着一个小物件**（本轮新增） | 先判定是焦虑放大还是解离性抓小失大（P03） | 职业观察/审美注视不必写成创伤触发 |
| **受害者沉默、不反抗**（本轮新增） | 写明可见的社会与关系成因（P07） | 禁止写成"她本性顺从"；原因不明标未知 |
| 一味渴求受罚 | 展示其对关系的自辩及伤害后果 | 禁止赎罪美化，允许拒绝和解 |
| **高强度行动写得像流水账**（本轮新增） | 按四拍交替重写：程序动作 → 短促清醒 → 物件触发退缩 → 再失控（P11） | 全知冷叙述/喜剧/寓言不必采用 |
| **对峙戏只靠台词推进**（本轮新增） | 让双方各提一个可被对方反向利用的解释，指认落在身体反应上（P12） | 类型要求铁证推进时不采用 |
| 结局在关系中变化 | 只宣告转变开始和代价 | 后续未写不得强称已痊愈；**转变不等于悔改** |

缺资料的失败出口：列待补段落而不编造证据；互斥锁定设定：暂停受影响部分；临床判断请求：停止此工作流并换适当的求助资源。
