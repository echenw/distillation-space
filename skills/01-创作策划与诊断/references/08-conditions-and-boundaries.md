# 条件、历史知识与证据边界

## 十九个冲突的有效裁决

| 旧号 | 对象与裁决 |
|---|---|
| K01 单一/多重效果 | 区分集中情绪、戏剧冲突、长篇整体与tone；不是仅按字数分流 |
| K02 人物/情节先行 | 四种入口均可，写后检视相互作用 |
| K03 描写剂量 | 定位、人物、世界、气氛、语言功能决定剂量 |
| K04 视角一致 | 信息权限与距离不同；多视角和全知合法，切换可有多种收益 |
| K05 巧合 | 前提/经过/解结及契约分别审；不用一条舞台禁令覆盖所有小说 |
| K06 闭合/开放 | 按真实承诺，普遍优劣未决；开放不强求潜伏意象或全线收清 |
| K07 自然/工艺 | 成品观感与生产方法不同；不改与多改均不证明质量 |
| K08 纪实/似真 | 真实断言求证、虚构按契约；真实改编不伪造前因 |
| K09 道德目的 | 行动、议论、寓言、讽刺均有适用域，不强制说教或反说教 |
| K10 类型边界 | 标签用于契约和检索，可重叠，不是永久分类法 |
| K11 晚入/从头 | 根据理解所需前因和框架功能选择；相同作者不同语境未必矛盾 |
| K12 可教性 | 可检查方法可训练，天赋不可教是历史立场，效果不保证 |
| K13 张力 | 速度、紧张、兴趣和休息不同；短篇字数阈值是历史建议 |
| K14 预知/保密 | 都可产生悬念，按信息项和后果区分，不按舞台/悬疑硬分 |
| K15 扁/圆人物 | 分类非价值等级；主要人物也可不变，功能人物合法 |
| K16 对白 | 小说对白不只准高潮；信息、关系、节奏、声音均可承担功能 |
| K17 快乐结局 | 真实目标市场和作品逻辑分列；无当前证据不假定市场代价 |
| K18 效果粒度 | 整篇/场/段的取舍对象不同，相关不等于同一规则 |
| K19 词句难度 | 以目标读者与表达效果判断，不把年龄教育或媒介机械对应长短句 |

## 历史拒绝项仍有知识归属

A-02旧版以“单源”“标题不是结构”“不属小说”为由删除的内容不等于已证错误：标题apt/specific/attractive/new/short可作标题检查；地图与历书可作冒险情节生成；五段情节可作非强制分解；口头停顿、讲后静默可作演出选择；编年分期可作组织工具。“人物支配作者”“写离开的地方”保留为作者自述，不承诺效果。具体未给行号的原条目标NOT_PROVEN定位，不补造PG行号。声容、舞美或声音彩色的过时规范限历史媒介，不由本包推广。

同作者不等于每条意见完全相同，同编者问卷不自动抹去不同答者；直接转引和同一底层原件才可确认依赖。同一传统意味着外推受限，不足以证明两书互相抄引。PG数量、引用次数、可回读行数均不构成规则效果证明。

## 4. 证据边界

### 4.1 材料范围

- 28 本，约 2,675,498 tokens；标称跨度 1808–1929，**实际主体为 1888–1928 英语写作手册/批评、戏剧/短篇手册 + 古希腊诗学（Butcher 英译）+ 中国古典文论（《文心雕龙》《闲情偶寄》）**。
- 市场语境：1900–1926 英美印刷市场、杂志短篇、商业剧场；不是当代出版/平台。
- 来源类型：M 方法、C 评论、FC 作品现象/编者判词、R 分类/书目/市场；MIX 混合。
- 同作者/转引/同编者已去重：PG13589 与 PG30776 同为 Clayton Hamilton；PG21964 转引 Hamilton；PG61625 与 PG76688 同为 Hoffman；同书多段只算 1。

### 4.2 能支撑 / 不能支撑

| 域 | 状态 | 能说什么 | 不能说什么 |
|---|---|---|---|
| 短篇/中篇的构思、结构、场景、人物、视角操作、文体、修订 | **较强** | 可用 RC-01…RC-19 的条件式判据 | 不能保证效果/读者反应 |
| 长篇的“主行动/多线/过渡/结尾”诊断 | **中等** | 可做结构诊断与删减方案 | 不能给“完整长篇多线工序”；群像/系列/世界观未覆盖 |
| 舞台/戏曲的结构类比 | **中等** | 幕末暂解、拉幕汇聚、大收煞等结构层级 | 不能把舞台/戏曲规则直接当小说规则；声容/居室等不迁移 |
| 视角理论 | **弱** | 信息合同、距离、切换代价的操作层 | 不能给 Genette/Booth 级聚焦类型学、不可靠叙述者、自由间接引语 |
| 类型小说 | **弱/历史** | 类型作读者契约/教学检索；1911 前分类样本 | 不能给现代悬疑/科幻/奇幻/言情/恐怖/网文的必要特征；不能把 1920 美国市场当普遍 |
| 修订实证 | **弱** | 冷却、分层、单稿留痕的工序自述 | 不能证明“修订提升质量”；无草稿对照/过程日志/版本比较 |
| 读者反应 | **无实验** | 只能作设计假设，标 H | 不能写“读者研究支持/读者都会/读者留存会提高” |
| 非西方现代小说 | **缺** | 中国古典文论只作结构/文体参照 | 不能称“跨文化通用”；日本/印度/阿拉伯/非洲/拉美未覆盖 |
| 影视/互动/游戏 | **缺/历史** | 1916 无声片只作历史证据；结构类比标 H | 不能交付剧本格式、分镜、互动分支、影视类型契约 |
| 儿童文学 | **很弱** | 只借框架/道德故事的边界 | 不能给儿童小说结构论 |
| 翻译/多语 | **缺** | 无 | 不能给翻译叙事学 |
| 出版/营销/合同 | **缺** | 无 | 不交付；市场约束只作历史注 |

### 4.3 标记约定

| 标记 | 含义 | 用法 |
|---|---|---|
| **F / M** | 作者明示的方法/主张 | 可直接转成判据，但仍带条件 |
| **C** | 评论/理论/批评判断 | 可作判据；转成步骤标 H |
| **FC** | 作品现象/编者判词 | 只作现象/例证；升格为方法标 H |
| **R** | 分类/书目/市场资料 | 只作历史/检索；不作普遍规则 |
| **H** | 评论反推、跨域迁移、作者自述不可验证 | 不得写成“作者方法”或“研究结论” |
| **NOT_PROVEN** | 效果/因果未证明 | 所有规则效果、修订收益、读者反应 |
| **STATIC_CHECKED** | 锚点文本/位置在本轮证据整理中核对过 | 不是效果验证，不是本轮逐条重验 |
| **DESIGN_EXAMPLE** | 设计示例 | 不是真实客户稿/真实运行 |

### 4.4 不许做的外推

1. 不把“短篇单一效果”写成“所有叙事只有一个效果”。
2. 不把“晚入场”写成“所有小说都必须从中间开始”。
3. 不把“舞台观众预知”写成“悬疑应泄底”。
4. 不把“1920 年代美国杂志偏好（快乐结局、五条否定律、读者健忘）”写成“读者普遍想要/普遍如此”。
5. 不把“大师这样做”写成“人人应这样做”；例外登记，不升格。
6. 不把 C/FC 来源的评论反推写成“作者方法”。
7. 不把单来源参数（3/4、2–3 视角、3–5 细节、字数/章数）写成硬门。
8. 不写“研究支持/数据表明/读者实验证明”，除非真的引用了受控研究（本 Skill 没有）。
9. 不把类型契约当本体论硬边界；不把市场约束当艺术规则。
10. 不用“开放/闭合/扁/圆/快乐结局”的价值判断替代条件判断（K-06/K-15/K-17 UNRESOLVED）。


> **P4 修订使用说明**：跨媒介/不同年代的原规则必须按来源语境降为可选类比 H，不将 3–5、1–3 段、每章钩子当硬指标。


# 版本、来源与许可边界

## 原始材料固定性与引用规则

- 四件均以项目中的 PG ID、真实书名、作者和 `整本阅读版.txt` 固定版本；SHA 见 [source-index](source-index.md)，编制轮次已实测对齐。
- 书目和行位是**本项目阅读版定位**，不冒充其他网站或印刷页码；外部消费者无法访问该版本时应按书名、版本重新定位原文，不能伪造命中结果。
- 项目元数据将 Gutenberg 原件标为**美国公有领域**，并明确不对其他法域、后出的翻译或编订版本授予许可；再次传播前独立核权。
- 本 Skill 的流程与模板系重新编写，未引入原著大段原文（示例文件里的引文均为短段并标行号）；其存在不自动授予任何第三方素材的再分发权。
- F 是"该书在该处写了什么"，H 是编制者的比较判断，P 是具体查证工作流；对未知主张保持 `NOT_VERIFIABLE`。
- **静态结构验证不证明**本 Skill 已被真实宿主选中或有效提高核验正确率；R06–R19 的效果为 NOT_PROVEN。

## 外推红线

1. 不把单部作品的具体考据结论上升为普遍规律（例如不得由"现存汉人小说多伪托"推出"古书都不可信"）。
2. 不把某一部小说的情节设计变成所有作品都必须遵守的规则。
3. 不把 1920 年代的行业机制当现状。
4. 不把写作/投稿建议当核验方法。
5. 不宣称四本书共同主张了任何现代核验制度。
