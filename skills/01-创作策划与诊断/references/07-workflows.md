# 统一工作流：由任务决定检查范围

本流程将A-02的规划/起草/诊断/修订、C-07的G0–G8、C-08反馈流程和C-04研究协议合成一次任务链；相同契约、证据、修改日志只填写一次，专门字段按需展开。

## 1 规划与直接起草

1. 记录材料、交付长度与单位、媒介、类型目标、截止或连载节奏、不可改设定。普通缺项采用暂定假设；素材空白可原创，既有故事缺前文则不能保证承接。
2. 从人物/情境/终局/效果选主入口。写premise或一段探索稿；可列候选事件、最后决定与代价，发现型允许后补。
3. 按任务记录main_action/effect、终场或终局状态、各线功能与联系；联系含因果、主题、形式、年代后果和物件，不强制人物相遇。
4. 用unit_table选择场景/概述/过渡/反思等方式；列必要人物、时空和所需体验。行动场可用目标—阻力—转折，体验场可用注意—感受—关系或语调。场景卡未填满仍可写。
5. 记录叙述权限和knowledge_matrix、reveal_points。核对标题或类型已泄露的信息，揭晓后还可有行动悬念。巧合审计区分前提、途中、解结和作品世界规则。
6. 开头逐步建立所需人物、时空、语调、问题；结尾按承诺选择收束。章末可停顿或余波，已提出具体钩子才入payoff_log。
7. 写实际正文。按叙述权限选细节、对白、动作、内心和概述；卡壳处可留待核标记并先写可写部分，不用不相关的资料缺口阻塞整场。
8. 完成后检查人物连续、信息通道、空间、时间、承重因果及承诺。定额、section_map、素材簿、stall_log、exceptions_log仅在持续项目需要时展开。

## 2 有稿诊断：S1–S9

先界定实读范围和稿本。片段只诊断片段，梗概只诊断其结构，不凭开中结三段声称读完全部章节。问题记录为文本位置/观察→所用规则及条件→影响→最小验证→建议。严重度与证据强弱分列：能指出真正阻塞既定目标才标阻断；偏好或推测不能因语气强而升级。

| 症状 | 检查与操作 | 反证、例外和失败出口 |
|---|---|---|
| S1 主行动不清 | 一句话复述；抽线比较；逐事件标因果、时间、对照等联系 | “然后”超过一半不是因果不足证明；气氛、链条和复调不强制单主线；未读全线不宣称赘线 |
| S2 中段停滞 | 单元表、状态/关系/信息变化、读者预判与新增代价、终点方向；按需要展开被概述的重要过程 | 概述占比、连续三章无状态或两章无新信息只是警示练习，不是判死门槛；休息与反复可有作用 |
| S3 人物工具化 | 比较关键决定、所知、资源、代价；删人、遮名、假设情境练习 | 功能人物、扁人物、作者也在发现人物均合法；预测练习不是人格证明；观察者解释不等于动机事实 |
| S4 视角失守 | 知识审计、信息来源、叙述时点、切换trigger/benefit/marker/cost | 全知可以进入多个人物；清楚的隐性标记可足够；局部缺背景先列解释，不直接宣布全书违约 |
| S5 开篇定向不足 | 四功能、进入点、读者当下必要知识、删首段对照 | 首段不必四项齐全，风景和框架可有独有效果；删后读通不证明无用 |
| S6 结尾欠账/拖沓 | 承诺-兑现、终局决定、后果、尾声、新问题与收束范围；删末段对照 | 开放合法，后高潮关系与余波合法；潜伏意象非通用必需；按真实承诺判 |
| S7 偶然替代解决 | 巧合位置、解结功能、已设条件、可替代的人物因果 | 幻想、闹剧、命运或真实事件另审；不为似真篡改史实；契约未知不自动最严写实 |
| S8 类型失约 | 逐项对照项目实际承诺、偏离意图、目标读者、市场限制 | 3–5特征不是配额；悬疑不等于公平解谜；退稿原因可能未知或商业因素 |
| S9 语言空泛/失配 | 主谓、抽象与具体、语域、节奏、细节作用、主题与行动关系 | 形容词、抽象、长句、旁白议论、summary均非自动错误；声音收益也纳入判断 |

最小验证可为抽线、删段对照、决定表、知情表、复述或承诺表。15–30分钟、1–3句示范只是便于开始的建议。报告可以出现不在S1–S9的有证据症状，不为了旧标签改写事实。

## 3 修订与删减

确认目标、范围、锁定文本、最低可达字数和单位；先标唯一事实、前因、选择、类型承诺及声音承重处。按任务从结构、场景、句段、校对中选择所需层，不强制走全书流程。

删减对象分事件/场景、词句、解释、人物/支线，处置为删/压/并/留，辅以补/移。检查换载体后是否仍保留承重信息；桥接可用时间、空间、动作或说明，不限制必须一两句或必有新信息。先做与目标相关的较大改动，再检查连锁影响。

连载可用分段弧线、已发布承重清单、未兑承诺三张表；10–20章一弧只是例子。已发布可改与否以真实约束为准。若仅后40章可改，不能在方案中删第30–80章；先算不可改部分的字数下限，能达到目标才承诺总字数。压缩未来重复回顾、重复危机、重复对照，安排还需兑现的主线；番外能否承载尾声按读者契约判断。

回归六项：主行动或作品组织目标、人物、叙述权限、承诺、类型、声音；另加实际触及的事实与数字。比较原稿与改稿，失败修正或回退。L0定位、L1建议、L2句段示范、L3整场、L4结构重排是产物类型，不是额外审批级别。用户要求重写即按范围执行。

冷却、陌生人视角、换序阅读、换读者和每周复盘按条件使用。停止依据是当前目标已完成、后续改动无明确收益或损害声音，不按固定次数。记录实际检查结果与未验证效果。

## 4 研究与反馈接入

现实Claim调用研究协议；写作中虚构事件调用内部一致性检查。反馈调用C08记录；把“我不喜欢”保留为偏好，把“第三段人物位置互相矛盾”核到文本，把“肯定卖不动”标未证明预测。多条转载归并同一原始反馈，真实独立读者保留各自范围。

冲突反馈先找不同目标、预知程度、阅读范围与口味。可生成A/B改稿并标收益损失；没有真实再测只说已做文本复核。创作者收入目标与表达目标可以共存，不替作者作职业、伦理或商业成功判断。

## 5 十个旧失败出口的重新裁决（C07-E1–E10）

| 旧出口 | 保留的有效检查 | 现在怎样继续 |
|---|---|---|
| E1 无提纲 | scenario或入口澄清 | 探索试写合法；不强制停稿 |
| E2 只有设定 | 景物/世界的功能 | 世界主导可按自身契约写；不强迫人物化 |
| E3 动机未知 | 人物卡、秘密历史、情境练习 | 作者可在写作中发现，不以不可预测判不合格 |
| E4 经验缺口 | 承重现实事实缺证据 | 核查、待核、换写法；虚构事件不要求档案 |
| E5 两书分歧 | 分层比较、适用条件 | 不同目标可并存；未决只影响具体选择 |
| E6 类型/市场超源 | 历史来源不能证明当代行情 | 类型可用05，现实市场另取当前证据 |
| E7 弱情节/反情节 | 重新定义形式与体验目标 | 保留反思、抒情和世界，不强制退出 |
| E8 布道/反说教 | 区分角色观点、作者立场与叙述方法 | 尊重项目目标，不强制加或删道德 |
| E9 过度打磨 | 收益、声音、疲劳和停止理由 | 停止无收益轮次；不以次数评分 |
| E10 拒稿/销量差 | 市场与艺术、观察与预测分开 | 查实际原因；1884出版建议不继承为现状 |

## 6 不可自动判定的十项（C07-N1–N10）

读者是否受感动、人物是否在作者脑中生长、选择是否最优、风格是否美、经验边界、市场与艺术失败的因果、史实与虚构比例、道德与说教的界线、方言的受众成本、读者是否实现作者构想，都需要对应证据或项目判断。文本代理和设计试验可以帮助判断，不能伪装成人类内心或真实读者实验。


# 失败诊断与修复

每条给：症状 → 判定 → 修复动作（括号里是对应的核查动作编号）。

1. **只有搜索摘要或二手转述**：摘要先作检索线索，能在现有授权内取得原件就继续回查。可靠二手材料可支持限定于其证据范围的判断，标明尚未核原件；不能只因缺原件一律判不可核，也不能把转述冒充已核原文。
2. **三条报道却同一新闻稿**：依赖链只有一源；来源数量不能当可信度投票，补独立记录。（R10）
3. **历史人物动机被直写**：把"作者解释"与"人物可证动作"拆 Claim，不能读心。（R18、R19）
4. **译文引号不精确**：核原语言、译者、版次与译法；仅意译就去引号并标"译意"。（R11）
5. **旧版与新版数字不一致**：先查单位、统计截止与口径；同一来源正式修订则并列版本记录。
6. **虚构作品引用现实地名**：情节继续按虚构设定判断，真实地理 / 历史另建可核 Claim。
7. **医药、法律、个人名誉等涉及高风险**：未经可靠专业证据不作确定性结论；整理材料并指出必须由专业人员独立核对的部分。
8. **编辑没有授权**：保留原文，给精确定位与候选修订，不自动覆盖。
9. **来源只是评论观点**：只能证明有人提出该观点，不能把观点背后的经验事实一并认证。
10. **现代法规、统计、价格随时间变化**：缺最新权威资料时明确截至版本与未知，不能凭旧书或模型记忆作当前承诺。
11. **用一个故事证明一类人**：拆成个案与总体两条 Claim；可核个案只支持其范围。总体判断须有与该总体相称的分布证据，适用时记录样本规模、收集者和取得方式；证据不足标 `NOT_VERIFIABLE`，只有支持主干但代表性受限才用 `SUPPORTED_WITH_LIMITS`。（R06）
12. **“所有…都…”未查依据**：经验性全称断言查覆盖范围、样本取得方式、成功/存活例偏向及反例；数学、定义性命题或完整穷举按相应证明方式判断，不强制样本三项。（R07）
13. **被精确到个位的数字唬住**：记口径、谁在数、记录者距事件多远及舍入方式；区分来源的数值记载与实际人数。证据不足时只归因保留数字，真实数值另标 `NOT_VERIFIABLE`；确有主干支持与明确局限才用 `SUPPORTED_WITH_LIMITS`。（R08）
14. **把检出标志物当成危害本身**：拆成"检出了什么"与"它证明了什么"两行。（R09）
15. **用传播度当证据**："到处都在转 / 没人报道 / 编辑退了"一律不进证据栏；也不因材料枯燥而跳过核查。（R17）
16. **共变被写成因果**：检查时间顺序、机制证据、可能的替代解释和研究/记录设计；只见共变时不直接断因果。实验、自然实验和历史过程追踪可用不同证据组合，不硬造混淆变量，也不以有没有人为对照组作单一门槛。（R18）
17. **给“首创”下唯一结论**：先按争议对象拆定义、时间与范围；轮船的下水、首航、动力、班轮和商业持续性五维只用于该例，其他对象重建维度。范围明确且证据充分时可以给单一答案。（R16）
18. **“以前没有”被永久化**：时间敏感的已有/尚无/目前类断言标核查日期、对象与检索范围，在时效影响判断时复检；历史时点的确定事实不因日历翻页自动失效。（R15）
19. **拿题署当作者**：区分题署 / 目录著录 / 考定结论三层，只能支撑到实际所在层。（R11、R13）
20. **用今天的虚构观套古人**：按成书年代的归类与今天的归类分别陈述。（R12）
21. **原型属实即认证全书情节**：拆 Claim，分别判定。（R14）
22. **来源自陈的局限被抹掉**：准确保留或转述影响当前 Claim 的证据边界并给定位；不必全文照抄，也不因来源自陈局限自动降级。（C04-R02；范式见 PG25559 L6404-6406）
23. **只有模型记忆**：一律 `NOT_VERIFIABLE`，不得写"据某资料"。
