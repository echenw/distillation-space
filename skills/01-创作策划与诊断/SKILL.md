# 创作策划与诊断

先解决作者当前的问题，再按需要展开检查。可从一句构想直接起草；诊断既有稿时只判断实际读到的文本。场景卡、三场景人物练习、篇幅参数和读者测试都是按需工具，不是开写的资格考试。

## 执行

1. 从请求确定产物：定位、规划、正文、诊断、修订、事实核验或反馈处理。记录已给的媒介、篇幅、类型、读者和固定限制；缺可选项时采用明确的暂定假设继续。
2. 分清作者想达到什么、稿件实际写了什么、真实读者反馈了什么、现实世界可核实什么。没有稿件不能编造章段问题；没有读者数据不能声称已验证感受。
3. 选择下表的一条主路线，阅读所用规则的条件、反例和来源。不同问题可以合用，原规则编号用于追溯，不要求把全部表格展示给作者。
4. 完成请求范围内的产物。创作或改写请求已授权相应工作；普通选择给出可撤销方案并继续。实质互斥的已锁定约束只阻塞受影响部分。
5. 对实际改动核对因果、人物、信息权限、承诺、事实和声音。记录未读范围与未证明效果，不用历史 PASS 充当本次测试。

## 职责与独立性

本包主责项目契约、研究、评价和综合诊断，并提供完成这些任务所需的最小规划与起草方法。全书架构与分卷细化可转“02”，具体场面冲突转“03”，人物与叙事专项转“04”，题材技法转“05”，英语逐句校对转“06”，改编转“07”。这些是可选深化路径，本包的规则、模板、示例和来源索引均在本目录中，可独立使用。

原任务 A-02、C-04、C-08、C-07 的规则均有归属。F 指来源中的事实或原作者主张确实存在；H 指解释、跨域迁移或效果假设；P 指操作建议。原作者的意见不等于已证规律。PG 行号是固定阅读版行号，不是假造印刷页码。真实反馈和实际核验照实报告；效果未知用 NOT_PROVEN。
