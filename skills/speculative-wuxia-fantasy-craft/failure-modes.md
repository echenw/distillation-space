# 失败模式与出口（failure-modes）

> 当规则不成立、材料不足、用户目标冲突或证据越界时，按本文件停写/降级/转介。**不要用更多设定掩盖失败。**

## 1. 快速判断表

| 症状 | 最可能的失败 | 先查 | 出口 |
|---|---|---|---|
| 设定很酷，但读者记不住 | 规则太多/门槛不可计时 | F01、F02 | 删到 1 条硬法则+1 个门槛 |
| 主角为什么不用更强的东西 | 金手指无代价/无归属 | F03 | 填奇物合同；填不出就降为一次性道具 |
| 试炼像作者双标 | 成败条件/次数/惩罚未交底 | F05 | 补试炼卡；悬疑型可藏机关，不可藏成败 |
| 中段塌陷，反派越换越强 | 三拍只换敌人，不换选择 | F06 | 重排“更贵的选择”；每次报酬=下一关工具 |
| 身份揭示像巧合 | 只靠一件物证/作者安排 | F08、F09 | 补知识史+配对物证+凭证失效 |
| 反派纸糊 | 只有恶意，没有真诚/盲点 | F17 | 补真信仰/真勇气/真守约+抽象盲点；或降为儿童线纯恶 |
| 结尾泄气 | 愿望字面兑现/反圆满无铺垫 | F20 | 选偏移/反圆满/假圣物/价值重估；按读者契约 |
| 恐怖不吓人 | 过早显形/解释过满 | F21 | 短篇留白；长篇中段给一次形 |
| 读者问“这是武侠吗” | 把组织等价物当门派 | 边界 B1 | 明确 `NOT_PROVEN`；转介中国武侠原著 |
| 读者问“这一定好看吗” | 静态交付被当成效果证明 | 边界 B5 | 明确 `NOT_PROVEN`；不要承诺效果 |

## 2. 逐类失败出口

### FM-01 材料不足：用户只给一句点子

- **表现**：用户说“给我写个仙侠大纲”，没有主角、目标、世界规则、篇幅。
- **不要**：编人物/编结局/编门派谱系。
- **要做**：问 3 个最小问题——①主角最想要什么/最怕失去什么；②世界只有哪一条硬法则；③篇幅/读者（单本/连载/爽文/文学向）。
- **输出**：空白门槛卡+法则卡，让用户填；填完再进入 A 路径。
- **证据边界**：不要用本批“西方幻想”替用户决定“仙侠应该怎样”。

### FM-02 规则过载：超过 3 条硬法则

- **表现**：法宝有 5 个功能、世界有 7 种力量、禁忌有 10 条。
- **不要**：再加“例外条款”补漏洞。
- **要做**：只留 1 条硬法则 + 1 个边界补丁；把其他规则降为“地方风俗/一次性道具”；用 F02-R1 的 6 项日常后果测试。
- **输出**：删减后的法则卡 1 张。
- **来源依据**：PG697 只靠一条“失重”法则撑全篇（F02-R1）。

### FM-03 试炼不公平：读者不知道怎样算赢

- **表现**：主角突然通过/失败，原因是作者新加的规则。
- **不要**：让旁白解释“其实还有一条隐藏规则”。
- **要做**：补 F05-R1 的“地点/动作/次数/惩罚/受益”；如果必须藏，明确“这是骗局/反类型”，不是公平试炼；给受害者一次申诉/反打。
- **输出**：试炼卡 + 一句“这是骗局”的文体信号。
- **来源依据**：PG701 L697/L698 一次交底；PG1751 L1922 考试揭晓但失败即撤销所得。

### FM-04 金手指过强：法宝没有代价/归属/失去条件

- **表现**：主角有灯神/系统/神器，读者问“为什么不直接许愿通关”。
- **不要**：用“反派也有神器”平衡。
- **要做**：F03-R2 三件套——启动语法、持有凭证、失去条件；至少给一个“被夺/误用/反噬”场景；如果填不出，降为“一次性道具”（用完即毁）。
- **输出**：奇物合同 3 行；或“一次性道具”声明。
- **来源依据**：PG1751 L4167 蓝晶石可转手；PG128 L8195 灯被调包。

### FM-05 代价不痛：牺牲只是数字

- **表现**：主角献出“十年寿命”，读者无感。
- **不要**：加更多抽象代价（寿元/气运/因果）。
- **要做**：F07-R1 资产递减——每件代价对应一个有名有姓的受助者/受害者；让代价可见（白斑/失明/被逐）；最后一件不可逆。
- **输出**：代价账本 3–7 行。
- **来源依据**：PG902 L278 红宝石→眼睛→金叶；PG31795 L3159 黑斑。

### FM-06 身份像巧合：只靠一件信物

- **表现**：主角拿出玉佩，所有人立刻认亲。
- **不要**：让反派“突然相信”。
- **要做**：F08 三层——独特材质+公开匹配+知识史；F09-R1 先让凭证失效；让至少一个角色“不信”，直到第三层证据出现。
- **输出**：验身三层表 + 一个不信者。
- **来源依据**：PG1599 L211/L326；PG5314 L24463。

### FM-07 反派纸糊：只会喊“我更强”

- **表现**：反派没有信念、没有规则、没有盲点。
- **不要**：给他更多武力/更残忍的台词。
- **要做**：F17-R3 三件套+盲点；让他“真诚地”做一件好事；让他的失败来自盲点，不来自私德；如果写儿童/冒险线，明确“纯恶反派”并给具体恶行。
- **输出**：反派小传 4 行。
- **来源依据**：PG59239 L7557“No; I have no sense of human limitations.”。

### FM-08 结尾泄气：愿望字面兑现/反圆满无铺垫

- **表现**：主角许愿“世界和平”，世界立刻和平；或主角突然死掉，读者无感。
- **不要**：用旁白升华/加一段“很多年后”。
- **要做**：F20 四选一——偏移（主题兑现）/反圆满（代价真实）/假圣物（社会效果）/价值重估（官方估价打脸）；按读者契约选；反圆满必须在前文建立“代价真实”。
- **输出**：收束选择 1 段（谁受益/谁买单/代价留在哪里）。
- **来源依据**：PG701 L1090；PG873 L3331；PG67744 L8445；PG902 L444。

### FM-09 恐怖疲劳：长篇中段还不显形

- **表现**：读者已经不怕“脚步声”。
- **不要**：继续加“更怪的脚步声”。
- **要做**：F21-R1 只适用于短篇；长篇中段给一次形（部分显形/代价发生/见证者死亡）；结尾可以留白，但要有“代价已发生”的结算。
- **输出**：显形节点 1 个 + 结算 1 条。
- **来源依据**：PG40510 L1535 凹痕；PG40510 H1 自注“长篇需中途给形”。

### FM-10 价值越界：把时代偏见当规则

- **表现**：用户要求“按原著写野蛮人/奖品公主/残疾=恶”。
- **不要**：照搬。
- **要做**：明确 `REJECT`；解释这是 19–20 世纪殖民/性别/身体观；提供替代写法（给被殖民者主体性/给女性目标/去羞辱化）。
- **输出**：一段“不采纳理由+替代方案”。
- **来源依据**：PG149/PG96/PG540/PG27067/PG59239 的时代偏见；`counterexamples.md` M-02。

### FM-11 证据越界：用户要中国武侠专有设定

- **表现**：用户问“点穴在内功体系里怎么运行”“门派谱系怎么排”。
- **不要**：用本批“组织等价物/名号/试炼”硬套。
- **要做**：明确 `NOT_PROVEN`；说明本批 0 本中国武侠；建议改用《射雕》《笑傲》《蜀山》等原著；如果用户坚持，只做“结构类比”，并标注 `EXTRAPOLATION`。
- **输出**：边界声明 + 转介书目。
- **来源依据**：`references/06` B1。

### FM-12 效果承诺：用户问“用了能签约吗”

- **表现**：用户把静态 Skill 当效果证明。
- **不要**：承诺“提升可读性/签约率/爆款率”。
- **要做**：明确 `GQ5 NOT_PROVEN`、无真实任务、无对照实验；只承诺“提供检查清单/诊断路径”，不承诺结果。
- **输出**：一句“这是静态工具，不是效果保证”。

## 3. 停写信号（出现即停，不要硬写）

1. 用户无法回答“主角最想要什么/最怕失去什么”。
2. 世界规则超过 3 条，且用户拒绝删减。
3. 试炼的“怎样算赢”无法公开，且用户拒绝改成骗局线。
4. 法宝没有代价/归属/失去条件，且用户拒绝降级。
5. 用户要求把种族/性别/殖民偏见写成“世界观真理”。
6. 用户要求中国武侠专有设定的一手依据，但拒绝提供原著/拒绝接受 `NOT_PROVEN`。
7. 用户要求“自动写全文/自动判定设定”，而本 Skill 只有人工 workflow。

## 4. 降级路径（不能停时）

| 原目标 | 降级 | 标注 |
|---|---|---|
| 严密力量体系 | 一次性道具/低魔冒险 | `LOW_RULE` |
| 公平试炼 | 骗局/反类型 | `UNFAIR_BY_DESIGN` |
| 反圆满结尾 | 主题偏移/开放结算 | `CONDITIONAL_ENDING` |
| 多证人悬疑 | 单一受限视角 | `SINGLE_POV` |
| 中国门派制度 | 组织等价物（社团/行会/结义） | `EXTRAPOLATION` |
| 真实任务验证 | 静态检查/作者自审 | `GQ5_NOT_PROVEN` |

**底线**：降级不是失败，伪装成“完整体系”才是失败。所有降级都要在交付说明里写清 `LOW_RULE / UNFAIR_BY_DESIGN / EXTRAPOLATION / GQ5_NOT_PROVEN`。
