# B09 工作流、诊断、缺料与作者裁决

## W1 新作品设计（限定任务：年代/现实生活）

1. 输入 `时间/地点/社会制度的已知事实/人物A和B/时代与现代读者之间的距离/用户的体裁目标`。未给的史实一律 `RESEARCH_NEEDED`，不能通过六部小说当作事实来源。
2. 选一个压力源：经济生活、社会声望、共同体舆论、家庭责任、个人自由或政治制度。将其写成**人能失去的东西**，如住房、亲密关系、教育机会、工作或安全。
3. 生成两种具体情境：A 主角顺从或迂回制度，B 主角抵抗或重新定义责任；逐项附可视细节与代价。
4. 对话、家务、地理与职业不是时代标签清单，而是促进/阻碍主角行动的媒介。
5. 确认类型契约：若是神奇救赎，才使用类似 *A Christmas Carol* 的超常装置；若是现实成长，则选择小转变；若是政治悲剧，保留不能被个人意愿解决的历史约束。
6. 输出场景表：`场景/读者已有信息/社会约束/物质细节/角色选择/直接代价/关系变化/史实待查`。

## W2 已有稿件审查（不能假装修改全文）

- **输入**：原文节选、作者要求保持不变的角色与事件、定位格式；未给原文时仅可提出有条件的修改示例。
- **第一轮** 标出具体场景的制度细节，例如阶层称谓是否与作者设定一致、贫困是否真实限制选择、家人是否有独立目标、地理环境是否改变行动。
- **第二轮** 找到角色行为是否有现有前因；把无理由的突然转变与作者有意让人物反常的情况区分。
- **第三轮** 给两个可逆修改方案，说明其收益和对原有悬念、人物气质、历史准确性的风险。
- **停止条件**：如果关键年代事实没有证据，把未核实问题记在 `研究任务清单`，**不能用古典小说里的虚构细节冒充历史证明**。

## W3 收尾形态的冲突裁决

| 作品模式 | 可以学习的机制（H） | 禁止照搬 |
|---|---|---|
| PG45 乡土成长 | 角色变得能够面对未知，但世界仍开放 | 每个故事必须“道路有一个弯” |
| PG46 超常救赎 | 人物承诺通过之后的行为兑现 | 所有人物必须被鬼吓醒并变好 |
| PG514 家庭群像 | 多成员不完全相同的责任与愿望在生活中重组 | 女性角色必须承担单一历史角色 |
| PG76 反规训冒险 | 主角拒绝不认同的规范；个人自由留到终章 | 必须抄袭方言或以离开为唯一成熟 |
| PG98 历史传奇 | 外部大事件与个体牺牲交织 | 牺牲必定优于生存与日常建设 |
| PG1400 阶层成长 | 人物回看曾经的羞耻与期待 | 上升必然导致自我厌恶或恋爱收束 |

## W4 输出合同

任何任务至少给：`用户任务与约束`、`可核原文/PG 锚点`、`F-SCENE`、`H/P 判断`、`方案 A/B`、`适用条件/反例`、`风险`、`作者裁决和史实缺口`。

如果用户只要求小说**历史真实性**，本 Skill 只能列核对事项及资料请求，不能宣布史实正确。如果用户只问**通用文学理论**，不要混合原小说中的情节 F 与作者明确写下的批评论点；此 Skill 未拥有后者。真实读者评分、历史校勘、现代地方口音适配、真实社会科学归因皆不属于 P4 能力证明。
