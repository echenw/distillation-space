# 年代/现实题材已有原稿诊断模板（RD-01–RD-09）

输入必须包括原文段落或可定位章节；没有原文不写伪造的问题位置。

| ID | 核查维度 | 证据要求 / 可能的失败出口 |
|---|---|---|
| RD-01 | 历史制度真实性 | 有独立史实来源才断言，不然 `RESEARCH_NEEDED` |
| RD-02 | 角色所承受阶级/经济约束 | 连接具体的物品、义务、社交门槛，不凭作者形容词判断 |
| RD-03 | 情感与成长是否有前因 | 是否见到选择、代价、反复或转折；例外保留不可靠叙事 |
| RD-04 | 社区和家庭成员能否各自行动 | 既有帮助也有监督/压力，不做齐刷刷的好人坏人 |
| RD-05 | 第一人称/口语是否支撑人物契约 | 来源和文化定位清楚；不臆造地域、身份或族裔语汇 |
| RD-06 | 问题/解法与作者体裁一致吗 | 鬼故事、历史传奇、现实成长不可用一种结局裁决 |
| RD-07 | 历史偏见如何呈现 | 角色视角与作者意图分开，缺文本与来源不能断言 |
| RD-08 | 此场景的因果效用 | 包括氛围和陪伴等非动作功能，不能“无推进就删” |
| RD-09 | 修改方案 | A/B 两个可撤销建议、各自损失、作者裁决位和未决事项 |

对每条发现输出 `位置/原文证据/对应 PG 与来源行号/当前文本的因果风险/两案/可能的副作用/作者决策/史实是否待核`。如果某项与作品没有关系，填写 `N/A`，不得让项目因不套六种结局模板而判不合格。
