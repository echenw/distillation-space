# 年代与现实生活：新作品设计输入模板（RM-01–RM-10）

填空时区分作者已确定的设定、从古典小说中得到的 **H 启发** 与待查史料；没有用户确认不得臆定时代制度。

| ID | 需要的具体输入 | 填写要求或默认处理 |
|---|---|---|
| RM-01 | 年代、地域、社会变迁 | 明确哪些是外部史实待查；不将 PG98 小说当史料 |
| RM-02 | 财富、职业、住房及社会阶层 | 说明进入哪些空间/组织需要什么资源（PG1400 / PG514） |
| RM-03 | 角色当前愿望、不能舍弃的关系 | 给可检验的动作或对白，不只写品格标签 |
| RM-04 | 角色能做而制度不允许的事 | 为每个限制写可见代价和应对方式 |
| RM-05 | 社区支持与监督的两面 | 若没有社区就 N/A，不用 PG45 硬造邻居 |
| RM-06 | 语体/方言与叙述者位置 | 只能按作者给定文化语言知识选用；不可硬抄 PG76 |
| RM-07 | 家庭成员不同的优先级 | 使用 PG514 家庭多愿望思路，不要求人物照搬性别任务 |
| RM-08 | 场景与时间跨度 | 日常物件磨损、劳动变化、关系变化三者择其适用项 |
| RM-09 | 希望结尾开放、团圆、救赎、牺牲还是抗拒 | 先确定体裁和人物选择，再选机制；不强套六本任一结局 |
| RM-10 | 人物和时代局限的现代阅读风险 | 分开角色、叙述者和作者立场，标外部史实待查 |

**本模板输出**：场景清单 `社会条件/具体生活细节/角色可行选择/付出/读者看得到的影响/待核史实`，以及备选结局 A/B，附 `F-SCENE/H/P` 标签。
