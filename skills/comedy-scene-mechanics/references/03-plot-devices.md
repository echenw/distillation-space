# 03 情节与节拍：M6、M7、M8、M9、M10

返回 [SKILL](../SKILL.md)。行号指该来源 `整本阅读版.txt` 的行。

## 1. M6 重复签名与节拍（置信 高；戏剧可用）

<!-- CM-CLAIM:M6 -->
- **when**：需要给一章一个"读者会等着"的东西；对白需要节奏而不只是信息。
- **when_not**：重复会暴露结构（短篇里 3 次以上通常太多）。
- **断言（F）**：签名句出现 2–3 次，价值在第二次（第一次是信息，第二次是契约），第三次必须变形。
  - PG6836：Mortimer 每次被召唤只答一个词 "Hello?"（L1298、L1363、L1712、L1733、L2219），女孩随即派他去做事——应答者只提供节拍，不提供内容。
  - PG6836 L1224-1242：Sam 落水后，"您是湿的"这句话由老绅士、小孩、侍者、女服务员、最后是舱内的表弟依次说出——同一事实的五次递降重复，最后落到最不该说的人身上。
  - PG1026 L100、105、143、174：门前刮板反复绊倒不同的人（Gowing、Cummings、牧师、肉商），Pooter 一度决定不拆。
  - PG3189 L631-634 与 L668-671：陌生人两次说"我看不出这只青蛙有什么比别的青蛙好"。
  - PG2233 L455、L485-487：Reggie 的 "Oh, absolutely! One of the best."（且他自己不知词义）与 "Good, fruity train"——空壳应答。
- **H**：第三次起靠变化维持——换人说、换对象说、被打断、被字面理解。
- **P**：① 为每章指定一个签名句；② 规定它出现 2–3 次；③ 第 3 次必须变形（截断 / 抢说 / 字面理解）；④ 记录上次出现位置，防同章堆两次。
- **来源**：PG6836、PG2233（Wodehouse 族）；PG1026（Grossmith 族）；PG3189（Twain 族）；PG844 戏剧对白同源形态。≥3 族 → 置信高。

## 2. M7 错位对话（置信 中；**仅合谋位**）

<!-- CM-CLAIM:M7 -->
- **when**：叙述者与读者合谋（G1 判定为合谋位）；笑点想来自"读者同时占有两个语境"。
- **when_not**：笑柄位叙述者（读者不再信任他给的语境）；段落里有解释者角色。
- **断言（F）**：双方各持一个明确且互斥的话题，每一句在两边语境里都成立，谁也不察觉。
  - PG6836 L336-352：Mortimer 说"我必须单独跟您说一句"，Hignett 抢答"不可能，我绝不同意"——她以为谈租 Windles，他其实来报信婚礼。
  - PG6836 L4702-4734：Billie 说"你完全搞错了！"（你认错人了），Peters 答"请原谅，没有的事！"（拔枪必须快）——两边各自确认了错误。
  - PG6836 L4736-4738：叙述者随后给出通用原理："当两个人在小房间里谈论两件截然不同的事、谁也不知道对方到底想说什么时，必然会有一定程度的思维混乱。"
- **H**：笑点不靠人物愚蠢，靠**读者同时占有两个语境**；任一方察觉即失效，所以段落里不能有解释者。
- **P**：① 给两边各写一句"我到底在说什么"（写在草稿上，不进正文）；② 让每句台词在双方语境里都成立；③ 不加入第三方解释；④ 错位的解开放在段落外（换场或被事件打断），不要在段内点破。
- **来源**：PG6836、PG2233（Wodehouse 族）；PG1696（Chesterton 族，机构对话里的同名机制）。2 族 → 置信中。

## 3. M8 即兴谎言的自生长与反噬（置信 中；**仅合谋位**）

<!-- CM-CLAIM:M8 -->
- **when**：需要让一个角色的即兴决定产生 1–3 章的后续压力。
- **when_not**：论证型喜剧（PG5265 里伪装承担的是论证功能，不是喜剧功能）；短篇（来不及兑现）。
- **断言（F）**：谎言每加一层码，都是为了在当下可用；而每加一层码，都给后文欠下一件**必然要兑现的道具**。
  - PG6836 L4470-4481：Sam 为吓走 Billie 编造"他试图开枪打 Milliken 小姐"，并在对方惊呼后加码"他确实打中了——第三次。幸好只在手臂上"。
  - PG6836 L4493-4509：为了让谎言可用，他补进动机与一条规则——"我们发现他有一种固定观念：每个走进办公室的红发女人都是骗了他的那个女孩……如今红发这么时髦"。
  - PG6836 L4568-4572：Peters 打开手袋，"依次取出一本赞美诗、半磅什锦巧克力、一个舌头三明治和那把手枪"，且"按此顺序"。
  - PG6836 L4612-4618：进来的不是 Sam，而是"手里拿着人们在电影摄影棚之外见过的最大的手枪"的 Peters。
- **H**：反噬强度 = 加码层数。作者的责任不是设计反噬，而是**记账**：每一层加码都要在别处登记一件物件或一个人。
- **P**：① 写谎言时同步开一张"欠账表"（物件 / 人物 / 规则）；② 每一项安排在 1–3 章内兑现；③ 兑现方式选对角色最不方便的（当着第三方、在封闭空间、由被吓的人主动触发）。
- **反例**：PG5265（Chesterton）——喜剧服务于论证，此规则不适用。
- **来源**：PG6836（Wodehouse 族）为主证；PG3189（Twain 族，Jumping Frog 的骗局与"回译"是同族的弱例）。2 族 → 置信中。

## 4. M9 认知翻转（置信 中；戏剧可用）

<!-- CM-CLAIM:M9 -->
- **when**：需要一个转折点让前面的判断全部重读。
- **when_not**：读者尚未建立前一个框架时（翻转没有力度）。
- **断言（F）**：让角色在不知情时对某对象明确表态，再让该对象以新身份出现；翻转力度 = 前一个框架的强度。
  - PG6836 L1427-1447：Sam 刚听完表弟痛斥那个"因为没裤子就毁掉婚约"的 Wilhelmina Bennett，随即发现她就是自己在码头上爱上的红发女孩；L1438-1439 叙述者写"这令人不安。就像突然发现五卷本长片里的吸血鬼变成了女主角"。
  - PG844 L446-449：Jack 被揭穿"你发明了一个非常有用的弟弟叫 Ernest，好让你能随时进城"。
  - PG3189 L451-471 + L883-891：同篇故事以"法语版 → 译回英语版"双版本出现，读者对"原文"的认知被翻两次。
- **H**：先认真建框架再翻——骂得越狠、夸得越满，翻转越大。
- **P**：① 用一整段建立前一个框架（不要让角色轻描淡写）；② 翻转点放在该对象以新身份出现的同一句里；③ 不在同一段解释；④ 给一次"回看"的物证（一句旧台词被重新引用）。
- **来源**：PG6836（Wodehouse 族）；PG844（Wilde 族）；PG3189（Twain 族）。3 族，但 Wilde 与 Twain 各只有 1 例 → 置信中。

## 5. M10 荒诞前提 + 一本正经的机构/流程（置信 中）

<!-- CM-CLAIM:M10 -->
- **when**：设计"疯狂计划/荒诞组织"类主线；需要让不可能的前提获得短期可信度。
- **when_not**：前提是纯幻想设定（读者本就接受），此时机构化没有落差可用。
- **断言（F）**：给荒诞前提配一个**真实存在的文书/机构形式**，并让角色严格遵守它的格式。
  - PG1696 L816-817："您正站在'冒险与浪漫代理有限公司'的办公室里。"
  - PG1696 L105-107：法官宣判"我判你三年监禁……基于坚定、庄严、上帝所赐的信念：你所需要的是在海边待三个月"——判决书的庄重语气与内容的荒唐。
  - PG28149 L568-570：一头大象被写成"确切地说，一张由努比亚与红海航运公司两三天后在南安普顿码头交付的订单"。
  - PG8713 L73-108：为避免婚约而主动要求降薪，理由是"薪水一到一百五十镑我就得结婚"——用薪资表推出荒诞结论。
- **H**：机构名、单据、流程语言是"借来的可信度"；笑点来自借用对象与借用场景的级别差。
- **P**：① 前提压缩成一句能被复述的话；② 配一份真实格式的文书（订单 / 判决 / 章程 / 发票 / 行程单）；③ 让角色严格按格式填；④ 质疑只出现一次且立即被流程压过。
- **来源**：PG1696、PG5265（Chesterton 族，后者为弱例）；PG28149、PG8713（Wodehouse 族）。2 族 → 置信中。
