# 规则裁决全文（R1–R14）

裁决标记：**KEEP**＝本批来源支持，照做；**REVISE**＝原主张部分成立，需改写为条件式；**REJECT**＝来源明确反对，不得当作默认；**NOT_PROVEN**＝样本不足，只能给选择表，不能给确定建议。
每条含：裁决、依据（PG＋行号＋该行是什么意思）、可执行动作。

---

### R1 「穿越必须交代机制」— **REVISE**

依据：
- 不给机制而成立：PG7401 主角自报"来自 England、名叫 Smith"，长老从未听过（L441-493），全书不解释；靠长者权威与生活秩序立住。PG58784 同样不解释，靠"永久"这一恐惧锚（L1011-1013）。
- 给机制而成立：PG67652 的 HX-1 基于物质-能量-空间-时间对应理论（L6150-6160）；PG3055 的崖上裂口（L824-843）；PG37270 的系留气球与钢缆（L7419-7455）。

动作：二选一并写进大纲——①给机制，给到可核验（谁造、原理、限制）；②不给机制，就明确换成替代锚（长者的权威、不可逆的处境、或"追问本身被禁止"）。两者都没有 = FAIL。

### R2 「穿越者应当用现代知识改造异世界」— **REVISE**

依据：支持—PG86 到任第一天办专利局、学校、报纸（L1851-1856）。反对—PG67652 主角被过去吞没，葬在永远不会存在的 Haggershaven 旁（L7484-7493）；PG7401 未来人对他的来历毫无兴趣（L441-493）；PG58784 他的 1954 知识在 2054 只是旧事（L925-944）。

动作：改造是可选亚型，不是默认。选了就必须写明代价（PG86 的结局屠杀 L12651-12697；PG67652 的埋骨 L7484-7493）。没写代价 = FAIL。

### R3 「异界必须有自洽且可复用的规则」— **KEEP**

依据：PG11 蘑菇两侧分工、可反复校准（L1086-1103、L1201-1222）；PG3055 触碰禁忌（L1322-1342）；PG55505 中央球体与光照原理逐条自洽（L4401-4404、L4801-4807）；PG37270 城的高度与入口被精确给出（L6061-6063、L7441-7455）。

动作：至少写出一条"读者能预测下一次结果"的规则，并在正文里让它第二次生效（PG11 的蘑菇就是两次生效）。只出现一次的奇观不算规则。

### R4 「一定要有回家目标 / 归途」— **REJECT**（改为开局即定三态）

依据：关闭—PG58784 "He's there for good"（L1011-1013）；不可判定—PG70002 三分钟昏厥（L7125-7134）与洞穴骸骨（L7217-7234）并存；失败—PG67652 埋骨（L7484-7493）；自疑—PG4092 "应是在发热导致的暂时精神错乱中被带回"（L14512-14521）。

动作：写作前先定三态之一（开放 / 关闭 / 不可判定），并在正文前 1/3 让读者知道是哪一态。PR：三态未定 = FAIL（不是风格问题，是读者承诺问题）。

### R5 「穿越真实性可留白（梦 / 异象 / 谵妄）」— **KEEP（带条件）**

依据：PG70002 两种并存——她自陈"很高兴那只是梦"（L7144-7149），又在洞中找出骸骨、石矛与巨猫头骨（L7217-7234）；PG69394 整部为梦框（L404-439）；PG4092 自疑却仍断言国家存在（L14512-14521）。条件来自 PG11499：该书的"前世"由人物自述，且文本自我标注为"在他心中种下怀疑之籽"的诱导（L1668-1669）。

动作：留白可以，但必须在"留白 + 物证并存"与"明确二选一"之间挑一个；若留白而无人承担叙述责任（既无自述者被标注，也无物证），即判为欺骗，FAIL。

### R6 「异世界可以是讽刺／论政装置」— **KEEP（亚型）**

依据：PG4092 猴国议会与选举权论战（L11161-11214）、人以"是否有尾巴"受审（L10081-10103）；PG55505 金权塑造政党意见的批判（L8002-8016）；PG69737 的 Social Palace 辩论（L10005-10014，该书无跨界，仅作体裁佐证）。

动作：走讽刺亚型，就接受"信息密度 > 沉浸"，并给读者足够的现实对应物；同时监控说理占比——PG55505 的讲座段落明显挤压情节，走冒险型时必须压缩。

### R7 「异界居民应被奇观化」— **REVISE**

依据：奇观化会反噬作者自己的世界——PG4092 用"人是否有尾巴"审判人类（L10081-10103）、嘲笑"有大学却没尾"（L7201-7243）；PG4637 命名权归捕获者（Lulu＝"plain one" L1901、Chiquita＝"dark one" L2049），男人的四个判词 "Absurd / Dangerous / Unwomanly / Immodest"（L6401-6421）。

动作：奇观化必须同时写出它在权力关系里的后果（谁命名、谁审判、谁被排除）。只写"看起来很怪"不写后果 = FAIL。

### R8 「穿越者是被选者／拯救者」— **REJECT**

依据：PG1076 说书人是被绑在树上的俘虏、讲故事为了拖延被杀（L7-16、L75-81），讲完反被奉为护佑之神（L3020-3102）；PG37270 的核心人物是周薪十镑的记者（L1510-1531）；PG11499 主角是被放逐者（L284-297）；PG4637 的"异界者"是被捕获方（L1901-2049）。

动作：不要默认给"被选中"。若要用，必须写出它在本世界里的代价或反讽（PG1076 的"被奉为神"恰恰是绑架者临时改口）。

### R9 「古风／中世纪背景即等于穿越」— **REJECT**

依据：四份均无跨界机制——PG234（Oakenrealm 与 war-arrow 集结 L3234-3258、L3501-3535）、PG47030（Oneiria 的议会与加冕 L7962-7992、L8054-8096）、PG9488（Arques 封地与窗下求爱 L1001-1018、L3001-3032）、PG9663（domnei 侍奉之爱 L146-151，正文止于 L4241 "CAETERA DESUNT"）。

动作：判定"是否有跨界机制"，而不是看服化道。没有跨界 → 负触发，不用本 Skill。

### R10 「变形／跨物种可并入穿越规则」— **REVISE**

依据：PG10337 的变形发生在同一世界内，难点是"解释"而非"接受"（L47-48）；写她"外表上毫无狐狸气"以堵掉道德解释（L110）；Tebrick 最终悲悼的是"他那只离去的母狐"而非亡妻（L1530-1535）；他自己也被反向驯化，"常常几乎四肢着地"（L2150-2156）。

动作：可共享两条技法——**不可逆**与**亲历者视角**；不可共享"跨界机制"这一类规则。判型时不要把它算作穿越。

### R11 「长生／跨时代见证即穿越」— **REVISE**

依据：PG10368 的 Crowder 永为五十三岁，历仕薛西斯远征（L1800-1834）、爱尔兰园丁（L2404-2429）、与皮特拉克同席（L3004-3092），并预言自己终将把妻与友当长辈敬重（L1221-1237）。

动作：归为"补充"。可借"跨时代见证者"的信息组织方式（如何按年代排布见闻），不可借作穿越机制证据。

### R12 「异域自治必然生出私刑与合法性危机」— **KEEP**（新拟，两份独立来源同向）

依据：PG37270 城在法律之上/之外，三具尸体不会有 inquest（L7467-7476），尸体必须火化以保密（L7734-7735）；PG11573 自建土地授予与专利状（L11691-11716）后，宪法以一票之差通过、总督被架空（L15617-15656），终至整岛沉没（L16171-16175）。

动作：写了自治，就必须写它如何处理"不受外部法律约束"的那一类事件（死亡、惩罚、保密）。缺省不写 = FAIL。

### R13 「必须有一个'回到现实后无法解释'的收束」— **NOT_PROVEN**

依据：支持者仅两份且都被对冲——PG4092 自疑谵妄却仍断言国家存在（L14512-14521）；PG70002 留白与骸骨并存（L7125-7134、L7217-7234）。反例：PG86、PG3055、PG55505 都在异界内部收束（L12651-12697、L4496-4516）。

动作：不给确定建议。给选择表：①异界内部收束 ②现实侧留白＋物证 ③现实侧明确否定，并说明每种的代价。

### R14 「异界语言／命名必须由主角完成」— **NOT_PROVEN**

依据：三种处理并存且无多数——PG4637 命名权归捕获者（L1901、L2049）；PG7401 主角的名字与来历全部失效（L441-493）；PG37270 主角伪装成华人侍者自取 "Ah Sing"（L4001-4257）。

动作：不给确定建议。把"命名权在谁手里"作为一个要显式回答的问题，而不是默认值。
