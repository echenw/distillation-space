# 冲突、反例与"不可通用化"清单

## 1. 三处保留不统一的冲突（不要伪造共识）

### C1 穿越的真实性：留白 vs 物证
- PG70002 两者并存：Victoria 自陈"很高兴那只是梦"（L7144-7149），又在地震露出的洞中找到高大男子枯骨、石矛石刀石斧与巨猫 Oo 的头骨（L7217-7234）。
- PG69394 整部为梦框，叙述权在 L442 交接（L404-439）。
- PG4092 自疑"应是在发热导致的暂时精神错乱中被带回"，却仍断言"我相信确实存在利普高与利普洛这样的国家"（L14512-14521）。
- 对立面：PG58784 完全不留白，恐惧来自"永久"（L1011-1013）。
**取向问题**：你要不要让读者问"这真的发生了吗"。两种都可以，但必须选一种并让全书一致（PG70002 选的是"两种都在场"，这是第三种，不是回避）。

### C2 归途：开放 vs 关闭 vs 不可判定
PG86（失败，L12651-12697）、PG67652（被吞没，L7484-7493）、PG58784（关闭，L1011-1013）、PG3055（异界内部收束，L4496-4516）、PG70002（回而不入，L7156-7159）。
**没有多数**。规则 R4 因此被 REJECT，只保留"开局即定三态"这一动作要求。

### C3 决定论 vs 改造欲
PG67652 内部即并存：Tyss 主张无自由意志、时间可能如衔尾蛇（L1536-1581），而主角用 HX-1 去改写 Gettysburg 的战局（L7340-7357）。PG86 同样：主张"训练即全部、我里面真正原创的东西一个针尖就能盖住"（L4116-4140），却把整国改造当工程推进（L1851-1856）。
**不要替作者解决这对张力**；你的作品若两者都有，照写，但让读者看见两方各自的证据。

## 2. 四类反例（踩到就改）

1. **把主角当成"进入异界"的默认方向** → PG4637：五名飞女落到男人岛上被捕获，命名权归男人（L1901、L2049），飞行被判为 "Absurd / Dangerous / Unwomanly / Immodest"（L6401-6421）。
2. **把异界当成既定秩序** → PG11573：秩序是被主角新建又崩解的（土地授予 L11691-11716；宪法一票之差 L15617-15656；整岛沉没 L16171-16175）。
3. **把奇观当超自然** → PG37270 的入口是系留气球（L7419-7455）；PG4092 的异域制度是人类政治的镜像（L11161-11214）。
4. **把古风背景当跨界机制** → PG234、PG47030、PG9488、PG9663 四份均无跨界（见 source-index.md）。

## 3. 明确不通用化的情节设计（禁止升格为规则）

以下都是**单部小说的设计**，本批来源不足以把它们变成"所有作品都必须遵守"的规则：

- PG86 的"专利局 → 学校 → 报纸"三步（L1851-1856）：是 PG86 主角性格与 19 世纪美国语境的产物；PG7401（未来人对他无兴趣，L441-493）、PG58784（旧知识失效，L925-944）构成反例。
- PG11 的"吃/喝改变体型"（L1086-1103、L1201-1222）：服务于 Alice 的荒诞调性；PG3055 的异界靠禁忌而非尺寸规则（L1322-1342）。
- PG37270 的"云中城与同城并存"（L6061-6063）：飞地型的孤例样本，不能推出"异界必须与现实同城"。
- PG70002 的"三分钟 vs 十万年"（L7125-7134）：该书的叙述装置，不是时间换算规则。
- PG67652 的 HX-1 机制（L6150-6160）：与它自己的决定论设定（L1536-1581）共生，拆出来单用会失去张力。

## 4. 本 Skill 自身的边界（如实声明）

- 覆盖来自 27 份 1880s–1950s 的英语公版长篇，不覆盖 1990 年代以后的商业 light novel / web novel 传统；对后者给建议时必须声明样本限制。
- 覆盖判定基于全文阅读台账与逐字引文回源门禁，**不证明模型真实输入的每一行**；引文行号来自台账，可回查但不可视为"逐字已核"之外的保证。
- R13、R14 为 NOT_PROVEN：涉及这两条时只能给选择表，不能给确定建议。
