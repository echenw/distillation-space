# 年代与现实生活：把时代压力写进人物选择

适用任务：年代/现实小说、家庭群像、社区生活、阶层流动、劳动与照护、成长与结尾的构思、场景设计和修改。需要以社会条件推动情节时，可检查：**物质或制度条件 → 人物可行选项 → 具体选择 → 可见结果 → 关系与自我认同的变化或延续**。结果可以是收益、损失、缓解或维持；日常观察、陪伴、庆祝与有意停滞也能独立承担叙事功能。

先确认作者的年代、地域、人物关系、体裁、不可更改事件和希望保留的结尾。资料只足以支持构思时给有条件的方案；未见原稿不得伪造问题位置。社会背景没有改变人物行动时，先检查它是否承担氛围、陪伴或史诗视角等已约定功能，再决定删改。

## 操作路线

1. 构思先填 [设计与诊断模板](02-模板与示例.md) 的 RM 表，把作者事实、待查史实和创作推断分开。
2. 按 [条件规则与工作流](01-条件规则与工作流.md) 选取相关的经济/阶层、家庭/社区、声音/自由、体裁/结尾问题。限制若承担情节因果，说明它如何改变住房、时间、机会、安全、声誉、关系或其他实际选项；背景信息不必全部变成损失。
3. 依据作者目标选择顺从、迂回、抵抗、重定责任或其他路径，完成所求设计或文本。真正存在重要取舍时给 A/B 并说明得失；普通创作选择按授权直接推进。
4. 已有稿诊断要求实际段落定位，区分人物故意反常、不可靠叙述与缺乏动机；给适量的最小修法，授权改稿时实际落实。
5. 查 [来源与边界](03-来源与边界.md)，核对 F-SCENE/H/P、同作者族与体裁差异；最终保留研究任务与作者裁决栏。

## 输出合同和失败出口

按请求交付正文、大纲、设计表或诊断。解释重要判断时，可选用位置/设计前提、年代与身份条件、观察、人物选项、结果、来源、F-SCENE/H/P、适用边界和未决项；不要求每次展示全套字段。没有原稿只限制具体诊断，仍可标明假设完成原创；未给人物和地点时可提出可撤回设定继续。现实工资、法律等断言需核独立史料，具备检索条件时实际查证，缺证写 `RESEARCH_NEEDED`，不编造确定数字。

本题材材料为六部小说、四位作者。Dickens 三书归同一作者族；它们不是六次独立实验，也不能证明历史数据或现代读者效果。原文 PG 行号在本次融合中从已读 Skill 继承，未独立校勘六部原书；现代适用性和真实试读效果为 `H/NOT_PROVEN`。

## 旧规则的处置

旧规则并未因篇幅短而整批丢弃：九项机制的可用部分保留于规则文件“历史独有机制”，改为条件选项；旧字段的语义迁移见模板文件；不能证明的跨作者幽灵对比标 `NOT_PROVEN`，不冒充事实。新统一规则用 REAL-01–REAL-10，解决源 SKILL 与 references 中同名 RC 编号意义不同的问题。
