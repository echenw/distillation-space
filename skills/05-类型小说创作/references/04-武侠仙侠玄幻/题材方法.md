# 武侠仙侠玄幻：能力、行动与承认的条件化设计

## 使用范围与证据身份

本题材融合 A-05-B01～B05 的全部现存 Skill 版本与 references。它能支持原创世界的能力、法器、禁忌、师承、试炼、身份、门派或王权、旅程及结尾设计；实际来源主要是西方奇幻、童话、冒险及东方故事英译。中国内功、境界、宗门谱系与真实传统的考据并未由这些来源证明。用户要求原创中国风世界时，可明确建立本作设定；不能把原创设定冒称史实或古典武侠共识。

这里的规则是可选的创作方法，不是源书作者教过的教程。`F_SOURCE` 指源书中可定位的现象，`F_CANON` 指用户已经确定的本作事实；人物的信念、宣言与传说另标 `POV_BELIEF`；解释标 `H`，建议与新写示例标 `P/DESIGN`。`UNKNOWN` 是尚不知道，不能直接填成“没有”。原技能自报 FULL、旧阶段 PASS 只是上游记录，不代表本次独立读过全部 PG 原书。本次实际全读的是所有相关 Skill 文件及历史差异；原文定点复核见[原文复核与修订](原文复核与修订.md)。真实作者使用效果与独立审查仍为 `NOT_PROVEN / REVIEW_PENDING`。

## 从任务到交付

1. **确定当前工作。** 原创策划、场景续写、定位诊断、局部修改可以组合。记录受众、媒介、基调、已有事实及允许改动范围。原创允许没有原稿；诊断未提供的文本只能给条件方案，不能虚构“第几章”的缺陷。
2. **锁定问题对象。** 先问当前行动被什么阻碍：做不到、付不起、不知道、不被相信、不能被制度允许、不能承受关系后果？对象可能同时命中数项，不强迫一个主分支解决一切。
3. **建立最小状态表。** 写人物目标、当前能力和资源、已知信息、他人所信、适用规则、目前承诺、可用出口。引用用户已有设定；缺项列为假设，提供能继续写的替代方向。
4. **选择对应操作链。** 能力与代价读[能力与约束](能力与约束.md)；门派、身份、证据读[权力与证真](权力与证真.md)；旅程、场景与选择读[行动与人物](行动与人物.md)；结算、主题和叙述读[收束与表达](收束与表达.md)。每条规则按“条件→动作→产物→失败或替代”执行，不按编号填满所有表。
5. **跑一段因果。** 对一次关键行动，填“触发前状态→角色选择→实际执行→可观察结果→规则/关系/权限更新”。检查人物有没有当时不可能知道的信息，物品有没有无因转移，口头承诺有没有被当成既成事实。
6. **处理矛盾。** 同一规则、对象、时间与条件下结果相反，才需要修订或解释。不同小说采用不同规则是设计分支；同一件法器也可有多个已声明功能。不能把“原例不同”机械写成“新作不得组合”。
7. **交付具体成果。** 给修订后的能力卡、场景链、制度事件、段落或结局，附改变的理由、涉及的本作假设、对应规则及来源位置。用[模板与案例](模板与案例.md)填写实际字段；不靠一段通用免责声明覆盖仍然错误的步骤。

## 停止与继续的边界

无法核实引文时，保留原始出处主张并标 `NOT_PROVEN`，撤去该条的事实支持；仍可将合理机制写成明确原创选项。作者规则冲突时给出各分支会改变哪些场景，请其选择，先完成不受冲突影响的部分。没有读者实测时不宣称紧张度、质量或效率必然提高。史实、现实医学、宗教、法律与武术实操不能由虚构情节推出。

历史作品中的种族、性别、阶级、残障与精神疾病刻板印象可以作为文本立场分析，不能直接当作现实因果或人物道德的可靠判据。保留“谁这样想、因此做了什么、后文是否反证”；无需把所有含偏见人物或冲突的虚构写作一概拒绝。

## 阅读与独立使用

五个任务的原规则不再并列作为五套行为合同。当前唯一执行入口是本题材的 F01–F80、模板与案例；旧编号只在去重表与规则映射中用于追溯。来源身份见[来源索引](来源索引.md)，所有旧新文件与字节同源关系见[来源与文件映射](来源与文件映射.json)。相同作者、同一编者、同一传统不自动等于同一底层证据；实际转引、改写或重复文本才按可确认链条处理。没有依赖证据时记 `INDEPENDENCE_NOT_PROVEN`，不以“跨几本”“达到几族”替代语义论证。
