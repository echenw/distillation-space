# 可填写模板、条件案例与历史独有材料

本文件保留三类旧模板的有效字段并直接改写失效限制。空白处没有配额义务；填写数量由任务决定。案例分为 **SOURCE_CASE（来源 Skill 对原著的归纳）**、**PRIMARY_VERIFIED（本轮窄区间复核）** 和 **DESIGN_EXAMPLE（构造示范）**。设计示范不计原著证据，也不证明读者效果。

## T01 威胁与终局工作表

| 字段 | 要填的内容 | 缺失时怎样继续 |
|---|---|---|
| T01-01 任务合同 | 构思/章纲/起草/诊断；作者目标、可改范围、已有有效功能 | 缺稿可设计，不能编造现稿诊断 |
| T01-02 威胁与损失 | 实体/空间/人/流程/心理；实际失去什么 | 给有实质区别的备选，不强塞怪物 |
| T01-03 起因与关系 | 起因的时间/地点/事件；受影响者如何被选中（关系、血缘、行为、随机或未知）；动机、受益者、受损者 | 起因可未知，已知的行为链仍须清楚；不把遭遇当作受害者有罪的证明 |

| T01-13 四轴终局 | 兑现、解释、余留、人物与社会后果；作品中的复仇/悲剧/混合伦理怎样影响结局 | 不按物种指定唯一惩罚；伦理的变化须有语境，不强制全篇单一宇宙论 |
| T01-14 同情与责任 | 谁受害、谁解释自己、谁可以宽恕、谁承担后果 | 不用苦衷抵销受害事实 |

## T03 现稿诊断单

先写作者所选的终局与语气，再写真实稿件的问题位置。每项使用下列记录：

```text
诊断 ID：
原稿位置与实际观察：
作者目标 / 已有效功能 / 不可改项：
判断的条件（为什么这是本稿问题，而非风格差异）：
证据：原稿位置；必要时 PG、源文件、行号、F/P/H：
建议修改：具体动作；预期影响；会失去的功能：
备选修改（存在重要取舍、反信号或要求比选时）：具体动作；预期影响；会失去的功能：
未确定项：作者选择 / 缺正文 / 来源待核 / 效果未测：
建议采用与保留理由：
```

诊断可按以下对象选用上表字段：题材与语气定位；诅咒、禁问、遗物或框架形成的吸引力；显形与感官呈现；威胁变化与自救条件；证词的文类、矛盾和倒戈时点；解释者动机及解释时点；强度间隔；伦理关系；结局的物证呼应和有意拒述；巧合发生位置与作用；时代重构；具体规则对应的修订处方。每个诊断仍需填真实原句和本稿适用条件。

旧 MD-01–MD-12 已逐项映射。巧合按其承担的因果作用检验：建立困境、改变局面、作为作品主题或用无铺垫办法解开已经承诺的难题，不按超过一次判错；结局不限定四选一；不以同情、完全解释或婚姻结尾为自动降级。

## C01 继承衣物如何从同一题材分成两种故事（DESIGN_EXAMPLE）

**输入**：继承旧外套后出现亡亲呼声；作者想保留家庭恩怨但未定鬼是否真实。**方案 A**：外套纽扣藏有催债人暗号，亲属借传说阻止继承人调查；结尾解释声音来源但保留过去的胁迫。**方案 B**：声音只要求在一个具体节日把食物送到旧住处，履行后关系变化，但所有人对声音来源仍有不同理解。

**可执行场景**：人物先以为口袋里是钥匙，实际摸出一张被水浸过的名单；是否让名单有超常来历由终局合同决定。证据写其物态与持有者，不把“湿”直接等同死者。反制不预设付命或三次尝试。来源方法保留 B02 的遗赠、临终要求和家庭关系分支，不把示范冒充 PG 情节。

## C02 护理院交班：从感官清单改为责任与权限（DESIGN_EXAMPLE，保留 B03 历史独有场景）

**原设计材料**：交班册被删页、两种手迹、湿脚印、铃声、腕上瘀痕、影子数和开门。**融合处方**：将每项绑定问题：删页遮住谁授权转房；两手迹是不同班次还是补写；湿脚印是否因清洁路线产生；腕痕是否来自看护而非鬼。若影子数承担超常分支，必须由有观察权限的人看到并说明灯位。

**场景落点**：护士选择先开门救人还是先保全交班记录，两条行动都会改变证据和照护。不能要求恰好三痕迹、75% 才升级、只出现一次实体、结尾仅留一项未知。**反方案**：所有痕迹都有自然原因，但交班制度仍让无人愿意承担救助责任。护理者和病人各有立场，不以疾病本身作邪恶标记。

## C03 修复录音的档案员（DESIGN_EXAMPLE，保留 B03 历史独有场景）

旧目录的录制日期早于一次失踪，两种笔迹来自不同时期，几个证人的叙述年份冲突。先建事件时间与材料制作时间两轴；再比较拼接、记忆偏差、目录错录、未知声音四种解释。修复音频只增加可听内容，不自动识别发声者。

可改为档案员发现“失踪后录音”其实是早期蜡筒的转录日期；这一解答保留伤害的现实原因。也可让该解释只能处理时间，不能解释录音中的私人称谓。修改几场由原稿功能决定，不固定三场；不知道底层原件时，所有转录不算独立佐证。

## C04 医生、密封信与身体变化（SOURCE_CASE：PG43）

门后声音、破门、日常室内物件与不合身衣服让调查从空间转向身份；镜子、断钥匙、改写遗嘱及笔迹分别承担不同主张。封信的开启条件控制解释时点；代词裂隙和写作被另一自我打断改变叙述权限。药物杂质解释操作的不稳定，但不自动为道德心理作终极裁决（B02 PG43 L980–994、1911–1921、2194–2196、2437–2439、2527–2529）。

可借用“行动高点—普通房间—异常细节—解释高点”的顺序，也可提前展示变身，改为预知危险。前者不是所有恐怖必须的起伏。
