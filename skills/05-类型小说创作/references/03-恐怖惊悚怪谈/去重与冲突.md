# 语义去重、分支、错误与历史有效内容

裁决单位是“对象—条件—动作—限制—结果”，不是相似标题。MERGE 表示相同功能并入一个条件规则；KEEP_BRANCH 表示对象或条件不同而并存；REVISE 表示缩小结论或修正事实；REJECT_CLAIM 只淘汰指定断言，不删除历史源；NOT_PROVEN 表示证据不足。每项列目标，修改已经进入正文和模板。
