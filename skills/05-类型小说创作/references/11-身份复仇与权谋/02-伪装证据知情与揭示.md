# IDP-02 证据、秘密、信息通路与揭示

## IDP-02A 知情以具体命题和时间为单位

写清“某人何时、经什么渠道、知道或以为哪件事”。知道假葬礼不等于知道出生；知道化名不等于知道本名；知道私生关系不等于知道继承资格。读者知情单列，可领先、同步或落后。知情者数量与层级按故事需要决定，不固定三层、两人或至少一个无知盟友。

消息、信件、物证与凭证追踪制作者、内容、原件/副本、持有者、交付对象、访问权限及后来用途。错投通常改变接收者，不表示内容被改写；有人改内容须另有事件。PG1257黑红侍从送来的信暴露时间地点，却未自动证明寄信者；委任状的三次交接是先后行动，不能缩成同一场多人同时结算。材料被看见、被理解、被信任和被采纳是不同节点。

线索可先以日常用途出现，随后被重新解释；收集还可同时强化旧误判。铺设可细写、概述或由已有物件承担，不设固定三次。检查揭示时是否凭空添了此前不可能获得的知识；有意让读者暂不知，不等于角色没有取得路径。角色可以真正误信，不把所有错误判断当撒谎。

来源：B01 V3；B02 R4；B03 ID3/ID4；B06 R01/R02/R03/R11及旧渠道字段。PG102、PG1257、PG1806、PG786见07。

## IDP-02B 假死、失踪与追索变化

按本作情境写死亡/失踪说法从何而来、谁信、谁据此行动、记录如何形成以及归来会改动什么。尸体、验尸、报纸、陪审结论、战争混乱、葬礼、家属声明都只是可能路径；假死不必每次同时具备。没有官方死亡记录也可能让私人追捕停止，官方认定也不确保所有对手相信。

PG558通过遗体布景、结论和报纸制造“已死”的社会状态；PG1183以道具及临时隐蔽反转且有失控危险。这些只证明具体小说办法，不是现实死亡调查常识，更不要求新故事复制做法。虚构设计只交代叙事所需的可信度、参与者知情和后果，不提供现实逃避调查的技术操作。

同一例中空棺和替身遗体是不同分支，不能同时当成同一时点事实。若采用其中一个，见证者应只知道自己实际见过的部分。归来不必当众揭开，也可先通过私人关系、记录纠正或逐步恢复资格。

来源：B01 V4；B02 R3/T2与女继承人例；PG558/1183见07，当前一致实例见06。

## IDP-02C 识别与认可怎样发生

把每件证据的作用写成有限命题：证明某信是真的、某人认识旧习惯、某标记曾存在、某程序已完成。独特性、来源、可伪造性、观察条件和替代解释决定它能走多远。出生信物不能自己证明遗嘱有效；两位证人若只证明报纸刊过讣闻，就不能突然改当出生见证者。

证据冲突时可补查、质询、比较来源、寻求有权限的裁决、暂缓或接受不确定。不要求所有故事最终留下不可篡改实物，也不要求角色一定在公开对质赢下真相。PG1623的无熟人困境、PG59975文书后被推翻、PG1837习惯失败，说明要问本作谁能核验什么。私密知识可以传授、泄露或由共同经历共享；PG1837真王先报错御玺位置，Tom经物件描述认出它并提示往事，真王才回忆新位置，St. John取回实物，知识不是只属于一人的密码。权威也可接受别的证明，不能宣布只有真人能知道或只有某一印玺能结案。

担保改变风险分配：谁信担保者、他能承担什么、承诺由谁执行；担保者自己也可能受骗或利益相关。直攻证据、权威干预、群众承认和慢慢重建关系都可能有效，没有“必须先打倒担保者”路径。身体或文件不必先失败一次才准在结尾发挥作用。

### 涉及正式裁决时，分别记录状态

下表是对现有身份、证据和执行规则的设计检查 P，不是从某部小说推出的通用法律程序。只采用本作已设制度需要的环节；没有法庭的社群认可、私人揭示或自我归属不必套用。

| 状态 | 要说明的事实 | 尚不能自动推出 |
|---|---|---|
| 身份被认定 | 哪个主体认定此人是谁、具有什么资格，认定适用何种范围 | 所有机构都承认；继承或任职条件已全部满足 |
| 证据被接收或采信 | 接收者是否仅收件，还是已核真实性并采信某个有限命题 | 全部争点已证；裁决已经作出 |
| 裁决已经作出 | 有权者决定了什么、针对谁、以何权限决定 | 已满足本作规定的生效或执行条件 |
| 裁决已经生效或准予执行 | 本作要求的登记、通知、复核、期限等哪些适用且已完成；是否另有暂停执行 | 执行者已行动；所有财物已到手 |
| 财产或职位已交接 | 谁实际交出什么，受领者收到什么，账册、钥匙、占有及权限哪些改变 | 公共名声、私人信任、旧债及所有关系同时修复 |

一项决定可以在本作制度下立即生效并被执行，也可以只完成一部分；应把这个条件写明，而非强制加上上诉、拖延或另一道关卡。若生效与可执行在本作中不同，再拆成两项；实际占有先行也不自动使其合法。06工作表及继承人案例使用这些状态。

来源：B03 ID2/ID4；B04记录控制；B05 A2/A5/A7/A8/A9；B06证据与反证模板。

## IDP-02D 揭示改变哪些人、哪些权力

决定揭示的对象、时机和范围：让爱人知道、使法院改判、令组织撤权、让自己承认或让读者重读，目标不同。身份揭示可私人发生，公开仪式可只认证当前地位；PG60的盛装婚礼不能自动证明秘密身份已向公众揭露。新名字与旧身份也可合法并用，别强迫结尾必恢复唯一真名。

揭示之后检查实际后果：信息是否传播，信任是否改变，物件/档案/财产由谁接管，原承诺是否继续。交钥匙是实际占有，不当然是法律转移；证明说谎也不保证主角获职。揭露者可以保留秘密、提出条件或离开；主角可以选择公开承担风险。没有公众目击，不等于揭示失效。

当身份、政治胜负和关系修复同时收束，可以拆开时点，避免一个漂亮宣言替代所有因果。也可用一个事件完成多项，只要各效果有具体依据。宣言、握手、信件、沉默、远景与程序场景都能承载结尾，不按形式设禁令。

来源：B02 R9/R10/R14；B03 ID2/PM4；B05 A9/C5；B06 revelation-and-repair；PG95/60/1257/965见07。
