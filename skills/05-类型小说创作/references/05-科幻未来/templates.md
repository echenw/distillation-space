# 可填写模板库

以下为选用字段，不是每次全部填满的硬表；缺资料写未知/不适用，原创假设标P。相同字段只填一次再引用，避免重复填表。

| 模板 | 字段 | 规则 |
|---|---|---|
| 任务框 | 任务、篇幅/媒介、读者、目标、改写范围、已知/假设 | SF01/28 |
| 设定卡 | 反常、适用对象、条件、作用、未知、直接后果、反馈 | SF02 |
| 能力边界 | 冲突承诺、能力、范围/资源/权限/时间/信息、可观察边界、替代目标 | SF03 |
| 工程账 | 数值、单位、时点、参考系、来源、测量误差、计算式、复算、现实核验缺口 | SF04 |
| 试验尺度 | 小模型条件、全尺度差异、未测项、拒测原因、失败证据、修正 | SF04 |
| 战术观察 | 身体、感官、运动、地形、天气、工具、观察者、可行方案 | SF05 |
| 资源外部性 | 共享资源、瓶颈/冗余、分配者、事件用量、他处影响或无影响理由 | SF05 |
| 人格证据 | 自陈、内视、行为、记忆、社会/法律、可靠性、可伪造性、未决 | SF06 |
| 失控诊断 | 目标、输入、前提、传感器、权限、自修改、部署意图、后果 | SF07 |
| 身体账 | 原身/现身、记忆、自认、他认、债务、关系、法律权限 | SF08 |
| 认证表 | 信号、观察渠道、可伪造条件、误报、核查者、当前结论 | SF08 |
| 潜伏表 | 谁知什么、信息流、联系、暴露机制、选择、后果 | SF09 |
| 符号骗局 | 对方规则、如何学习、可验证痕迹、不可控项、披露对象 | SF09/14 |
| 接触表 | 双方感官/尺度/寿命、词汇、行为、解释、利益、确认或误读 | SF10 |
| 协议表 | 进入条件、交易/食品/身体禁忌、拒绝权、执行者、误解、修订 | SF10 |
| 制度反转 | 变化轴、身体/工作/家庭/档案、辩护说法、体验、例外 | SF11 |
| 制度运行 | 进入、日常、退出、支付、维护、权利、申诉、执行缺口 | SF12 |
| 保修分类 | 缺陷类别、期限起算、实际时长、条款、谁解释、反证、救济 | SF12 |
| 机构窗口 | 窗口、权限/行话、掌握信息、预算、反应、下一步骤 | SF12 |
| 资格障碍 | 谁管、缺什么、为何不批、法律/经济区别、取得/绕行/改革/失败 | SF12 |
| 系统图字段 | 输入、反馈、受益者、维持者、误判、观察、假说、预测、结果 | SF13 |
| 偏见表 | 分类话语、利益/恐惧、传播/执行、受害者、反例能改变什么、结构剩余 | SF13 |
| 话语账 | 原事实、报道/法条/教义、说话者、接收者、行为后果、立场 | SF14 |
| 时间账 | 世界时间规则、事件前后版本、身体/物件位置、记忆、档案、知情者 | SF15 |
| 历史冲突表 | 档案A/B、作者/日期/渠道、冲突、独立性、可靠性、验证 | SF15 |
| 说明表 | 信息、读者现知、叙述者权限、承载方式、当前用途、可错之处 | SF16 |
| 揭示位置 | 读者已知、视角可知、悬念对象、前置/后置/弥散/混合、取舍 | SF17 |
| 承载候选 | 物件/动作/关系/词语/声音/视角、剧情作用、可回溯变化 | SF17 |
| 反转表 | 结论、必要前提、首次可见位置、当时用途、可靠性、重读解释 | SF18 |
| 重复变奏 | 核心单元、出现位置、语境/状态/关系变化、比较入口、保留理由 | SF19 |
| 道具流转 | 场次、功能、持有人、物性/权限、因果、结尾是否需要回收 | SF19 |
| 感知表 | 事件、非人感知、可选人类类比、可选参数、边界 | SF20 |
| 半知识表 | 记得、不记得、以为记得、依据、行动影响、恢复机制 | SF20 |
| 词汇表 | 人物有/无概念、准确术语、迂回或错词、叙述层词汇、命名时机 | SF20 |
| 框架表 | 谁记录、如何得知、目的、权限、可靠性、正文/框架关系 | SF21 |
| 行动状态 | 目标、地点/时间、资源、权力、选择、所得认知、下一状态 | SF22 |
| 训练兑现 | 教过什么、承诺程度、练习/失败、实际应用或失效理由 | SF22 |
| 手艺工序 | 动作、材料、触感、难点、可见结果、现实未核项 | SF22 |
| 关系表 | 双方目标、意愿、对话/照护/共同选择、误解、修复、关系变化 | SF23 |
| 生命仪式 | 死亡/复苏规则、诊断者、仪式功能、前提、结果、公众与私人的解释 | SF24 |
| 结算矩阵 | 事件、关系、制度、概念、价值；各层承诺、证据、结果、留白范围 | SF25 |
| 灾后/战争 | 谁受影响、基础设施、身体/物资/关系/制度后果、原因知情范围、重建 | SF26 |
| 历史边界 | 书内立场、时代语境、可借结构、不可普遍化断言、当代证据缺口 | SF27 |
| 诊断单 | 原文位置、问题假设、触发条件、最小修改、反方案、回读结果 | SF28 |

通用规则卡：对象｜条件｜动作｜限制/反例｜期待结果｜F来源与PG锚｜H推断｜P建议｜未证项。数字阈值只有用户要求、世界正典或具体工程计算支持时采用，不从样本数推导。
