# PR-06 工作表、诊断与修正案例

## PR-06A 按需要取用的工作表

这些字段是思考工具，不是每次必须填满的问卷。相关字段未知时写 UNKNOWN/NOT_PROVEN；不存在或本场无关时写不适用。例子新增设定须标 DESIGN_PRESET，不能用 PG 引文充当用户原稿事实。

| 工作表 | 字段 | 何时使用 |
|---|---|---|
| 职业作用卡 | 作者承诺；职业改变的选择；背景/共同/主要；本场P/L/E问题 | 定位写作重点，不给整书贴永久类别 |
| 进入与认可链 | 机会；资格/访问；已有能力；成果；谁观察/判断；其权限；渠道；决定 | 能力与机会或名望不相称 |
| 学习卡 | 目标能力；起点；方法/材料；反馈；支持与约束；调整；下一次实际应用 | 能力跃迁需要说明 |
| 工序图 | 输入；动作；产物；交接；检查；责任；时间/资源限制 | 过程影响结果 |
| 人员网络 | 人物工作；能提供/拒绝什么；利益/职责；知情；关系变化 | 团队、导师、行业组织 |
| 账与合同表 | 金额/非现金资源；单位和周期；到期；触发条件；权利/义务；例外；实际决定者 | 钱或协议改变选择 |
| 比赛/检验卡 | 目标；资格；规则；资源；观察方式；判准；裁决；申诉；奖励/后果 | 正式或非正式检验，按场景省略 |
| 失败复盘 | 预期；行动；信息；前提；环境；结果；责任范围；后得信息；可改环节 | 区分推断错误、失误和外部限制 |
| 关系与结局账 | 各方要什么；兼容条件；可协商部分；得到/失去/未变；谁评价；后续 | 选择、职业中断与收束 |
| 修稿单 | 已读范围；原句/场位；证据；问题状态；实际修法；来源/边界；回看位置 | 一次实际交付 |

原十二类诊断在本体系的去向：只有职业标签→PR-01A；术语无动作→PR-02C；进入过顺→PR-01B（先确认是否承诺阻碍）；训练跳跃→PR-02A；生态单薄→PR-02C；钱模糊→PR-03；赛事规则冲突→PR-04A；成功只靠旁人→PR-02B（核分工而非禁援助）；伦理无后果→PR-05A（不强惩罚）；职业/关系偏轴→PR-01A/05A；结局强行修复→PR-05C；时代偏见当真理→PR-05B。严重度由实际承诺冲突和影响判断，不因缺一张表自动“致命”。

## PR-06B 六场逆袭骨架的可选用法

需要完整成长竞争弧时，可按“处境与目标—机会/规则—练习或准备—挫折与新认知—检验—结果与后续”规划。每场写人物选择、信息变化、资源和关系；可合并、倒序、跳过训练、无挫折或多轮竞争。私练、成熟高手、制度小说不必套此骨架。改变目标也不必证明主角技不如人；获奖与职业机会可以分开兑现。

## PR-06C 已融合的具体演示

### 1. 报馆与秘密消息：四本来源的组合练习

新设计可让记者先遇接待限制，借可核验消息获得短暂编辑窗口，在截稿、独家与消息来源保护之间选择，随后面对机构标准和公开责任。接待/独家取 PG9300；编辑分工、消息来源安全与是否刊出取 PG13731；周刊周期与不接受贿赂取 PG9195；模板化报道、实物收入或关系资本可另参 PG3733/PG1056。**这是组合设计，不能称 Jennie 在原书完整经历此四书链条。** 编辑可以公正或压制；也可不发生门禁。涉及诽谤、窃听、报道权利，用故事制度或待核项，不能虚构通行法律。

### 2. 拳赛与外行观看

用 PG1160 的赔率、体重差、节奏、疲劳、湿帆布和 Jenny 的观看局限设计对身体风险的逐步理解。观众可以误解也可以学懂；专业术语按其获知渠道安排。旧伤、特定战术前置或死亡若是作者新增，标新预设，并在比赛前后建立相应因果。不要因原书悲剧就要求本次比赛死人；可以让失误被纠正、平稳获胜或退出。

### 3. 医学生、工作机会与手术高手

PG3242 的带教与考试可启发授权和反馈，但教师保证不是患者安全证明。若新增学生换错敷料、复核和升级授权，要明示这是原创场景，并给合适监督，不能以历史处方作现代医疗建议。

用户只说“技术最强却没人请”时，先列可能解释：未被看见、资质限制、缺相关病例、需求不匹配、信任或资源问题；没有正文不诊断“主任嫉妒”。可设计窄领域能力展示、转诊介绍、沟通或工作机会，也可保持无人认可的主题。主任争权、没人愿接的夜班、主角前三年空等都属于新增，不是 PG1056 或 PG23108 已证明的用户事实。

### 4. 房地产、广告与董事会

房产佣金案例把交易额、佣金率、到账和支出写在同一周期；旧版本“肉价上涨”与后稿“房租上涨”属不同设定，未查原文不能互替作 F。PG1156 的政治圈子和被排斥可影响订单，但不强制有一次违规才会成功。

广告创业例分开客户需求、产品拆解、广告产物和企业收入；客户可以真诚欣赏，不必每人暗中谋利。董事会例若 Bobby 持2600、对方3000，应写已被稀释成少数；要演示多数股份仍失实际控制，必须另建股份类别、表决或董事任免的明确新制度，不能沿用该股数假证。

### 5. 电影长约与艺术关系

电影例保留工资/涨薪触发/公司选择权、选角压力、他人代担罪责和行业声望的不同机制。Grace 遭胁迫或控制，不把伤害归咎她不够专业；成功也不要求变脏。PG3472 对高雅表演的模仿可被制片转成喜剧卖点，未告知演员与替身劳动应分别呈现。

艺术恋爱例可用贫穷羞耻、商业绘画、三朵紫罗兰的关系意义，不自动改成画展竞赛。Kenny 与 Brian 的不同职业判断可相互改变，但不要求最终统一艺术标准。

### 6. 皇家婚礼甜点竞标：保留冲突并修复规则

**原创设定**：27岁的林岚离职后经营小店，左手有旧伤；周叙资源更多。皇家婚礼招标有三轮匿名评审和90分钟现场制作，评委三人，主评有明确范围的否决权。关键规则先说明：团队是“至多六人”或另有公开的小队资格，因此三人、后来两人不会无理由违反“必须六人”。匿名分数与事后曝光奖励属于不同环节；若有人把曝光塞入盲审，就写争议或违规。

时间预算可暂拟15/60/15分钟，按菜品与场地再调整，不作为所有比赛比例。林岚需要在手部状态、复杂主题、设备故障与稳定交付间选择；复杂方案失分、冰箱故障与身体限制分别分析，不合并为“主角判断错”。40分钟极限与必须手术若保留，只作虚构医疗设定；4℃不是本指南背书的食品安全通则。

导师陆师傅提供旧样、档案或演示，学徒检索家族食谱，都是合法协作设计；是否违反参赛协助规则须事先定义。团队警告、个人取消资格与共同惩处不可自动等同。周叙为自己利益提供冰块、靠规则胜出或争论配方原创性，可有正当动机；后续访谈的新证据须调整先前归因。

“三年不得接皇家订单”与“私人家庭聚餐”可以并存，写清后者非皇家订单；若仍为皇家订单，需要有效例外或违规后果。半数订金是否没收须有已建立条款。结局可以赢、输、联合承接、另定小店目标；不强迫林岚同时失业、受伤与失恋。

### 7. 救援调度、木作、私练与电竞

社区调度例可写实习生夜班记录、通信故障、团队复盘和领导分工，信息错误与环境断线分别归因，不把协作救援叫导师代打。

木工林禾投标时，缺烘干设备、贷款、混料返工、降雨、停发货和误读评分若原稿未给，全部标 DESIGN_PRESET。材料裂缝是质量后果，不必升级成致命事故。可只处理湿度与进度，不强制再加一次误读。私人编织、老木匠练习可停在生活目标；用户要求比赛则授权新规则设计，无需再请求允许。

电竞冠军题没有赛制资料时，可以写结构、虚构规则书或待核现实规则；不虚构真实联赛条款，也不以无来源停止整项创作。

### 8. 艺术指导与伪专家

艺术学生把导师想成圣人时，可用导师行动、双方理解差和视角距离显示操纵；不要擅改 PG9385 现有 F 来让导师纯善。日记中的观察可用，评价未必可靠；早到约会并不能单独证明爱情。

专家演示可分别运用 PG78245 的峰值样本外推、未核是否重复计数、道德推论越界、测试条件错配和声望背书。原文统计对象是提酒壶的人，不把“统计壶数冒充人数”当作已发生事实；依据见[PG78245 L680–715原文窗口](../../provenance/verification/history-and-profession-attribution.txt)。一个决定性反证即可削弱具体主张，不必凑三重揭穿；未能证明欺骗意图时写证据不足。记者写出并提交假报道，不自动等于已刊发或被判刑。回源 PG17020 L1670–1676 后可确认：Simpkins翻到的这一版《Banner》没有刊出他的假报道，已收到的通讯社消息阻止了刊发；L1693–1717仍给他派新任务，而他把没获重大案件任务理解为惩罚的开始。不要把未刊的稿说成已发表，也不要把人物害怕诽谤赔偿或拘禁写成实际判决。

### 9. 工业、乡村和城市全景

工厂例可以写产量、精度、储存、疲劳和战争伦理不同目标的冲突，事故原因据已给信息追溯，不套“怨恨工人必破坏”的模型。乡村教育与机械化例保留生计、旧经验、权威和制度安排的差异。改革可成功，不能在模板末尾重新禁掉系统改善。

城市一日路线可把广告、新闻、服务、协会与家庭账并置，同一物件可以串联，也可不用。真实路线需核实，虚构城市只需内部相容；职业全景不必终结成主角晋升。

### 10. 外派与失明画家

外派三年与照顾家人的冲突可给实际排班、照护支持、分段驻场、远程或放弃其一的不同方案。原设定若锁死不可兼顾，说明冲突；未锁死则不依据三本悲剧强迫二选一。每案标谁同意、资源从何来和剩余限制，不必让亲人受伤。

失明画家可继续艺术探索、换媒介、与合作者分工、从事教学或另选生活。若借 PG8664，正确关系是**有视力的妻子学习实验工作协助失明科学家**；不能把失明画家写成别人的视觉助手来假装移植成功。新案需要辅助技术或训练时另核现实可行性；身份、收入、日常和关系可以一起写。她可以保有自己的创作，无需先牺牲作品或伴侣。

## PR-06D 交付与回看

交付时给已读范围、原句/场位、问题成立条件、实际修文或方案、为何与作者目标相容、源案例与未证部分。改关键资格须回看入场和结果；改合同须回看触发和兑现；改能力须回看训练与后续应用；改关系须回看知情与同意。优先消除真实矛盾，不为了“完整”添满表格。原案例的历史成功记录不等于本次方案实测有效。
