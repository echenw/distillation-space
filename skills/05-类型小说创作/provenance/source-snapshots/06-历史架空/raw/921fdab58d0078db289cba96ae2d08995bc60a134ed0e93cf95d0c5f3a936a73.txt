# 历史架空长篇锻造箱（缝隙型）

17 部历史小说 / 历史言情 / 历史冒险**全文实读**（Scott、Dumas、Orczy、Buchan、Bulwer-Lytton、Haggard、Newman、Pater、Wilder、Frazer、Heyer；1790s–1920s 英语文本，223,498 行 / 2,681,750 o200k Token），归并为 **11 个独立来源族**，提炼 **23 个规则族**（17 ADOPT / 6 CONDITIONAL）、5 条 REJECT、5 条 UNRESOLVED。本 Skill 内全部引文**逐条回读原文核验：102/102 命中**（核验表见文末）。

**核心边界**：本批 17 本全部是"虚构人物嵌入真实事件、**不改 documented 结果**"。因此本 Skill 的"架空"= **缝隙虚构**（改过程、改代价、改私生活），**不是**结果改写型架空史；后者在本批 **NOT_PROVEN**，不得冒充。

**来源性质**：全部来源为 `FICTION_CASE`。所有规则都是从**文本现象（F）**升格的**推断（H）**，**没有任何一条是作者明确教授的写作方法**（NOT_PROVEN-2）。引用时必须说"这些文本里可复现的做法是……"，不得说"某某作家教导……"。

## 输入权限（when / when_not）

### when（可用）

1. 历史长篇 / 中篇的规划、诊断、改稿。
2. 真实事件 / 真实人物与虚构线的**接缝**设计。
3. 制度、文书、礼法、技术约束驱动的情节。
4. 战争、宫廷、围城、灾难、仪式的场面组织。
5. 时代语体分层与多载体叙事。
6. 历史偏见与暴力场面的伦理处理。
7. 系列续作 / 跨代长篇的连续性设计（F23，单源，须标 `[单源]`）。

### when_not（禁用，触发即走失败出口）

| 场景 | 为什么禁用 | 出口 |
|---|---|---|
| 现实历史咨询 / 对真实人物或事件做史实裁定 | 本 Skill 只覆盖**小说技法**；文本中的史料细节是 19–20 世纪文学装置 | 拒绝，并说明本 Skill 不给史实结论 |
| 结果改写型架空史（"如果黑斯廷斯赢了"） | 本批无证据（U1 / NOT_PROVEN-1） | 走 F20：另建 counterfactual 因果与代价系统，明确标"架空假设"，不得借用"缝隙法"的权威 |
| 把源文本的时代偏见（血统论、殖民/族裔偏见、性别秩序）迁移进新作 | 见 R1–R5 | 走 F19：只作时代话语登记 + 反证 + 副文本说明 |
| 给真实人物编造文献 / 名言并当史料用 | 史料混淆（R3） | 只对虚构人物伪造文件；真实人物只用真实文献或明确标注的"拟作" |
| 纯玄幻 / 历史仅作背景的言情 | 与本批技法族不重合 | 不适用 |
| 非西方、非近代题材（如唐代、江户） | 本批集中在西欧/地中海/北美，19–20 世纪英语文本（NOT_PROVEN-4） | 只迁移**结构机制**，不迁移时代细节 / 礼法 / 语体，并在交付时明确告知 |

1. **从头规划**：F1/F2 立契约与锚点 → F3/F4 找缝隙与机关 → F5/F15/F16 建多方与反派 → F6/F7/F13/F18 埋贯穿物与终场 → F8/F17 写大场面 → F19 做偏见反打。
2. **诊断已有稿**：先跑 `failure-modes.md` 的八问；命中症状 → 表 3 → 对应 reference 的「失效」栏。**不要先改文风，先修接缝与因果。**
3. **单点设计**：按表 2 直达规则；每条规则含 when / 操作 / 输出 / when_not / failure_exit。
4. **真实人物 / 敏感题材**：先读 `references/bias-violence-and-limits.md`，再动笔；R1–R5 是硬红线。

## 输出契约

每次应用本 Skill 须交付**五项**，缺一不可：

1. **选用规则 ID 列表**（F1–F23；单源技法标 `[单源]`）。
2. **每条规则在本作的具体化**：触发事件 / 操作改写 / 输出。
3. **失效条件核对**：该规则的失效条件在本作设定下是否闭合；未闭合的标 `风险`。
4. **证据锚点**：至少一条 `PG ID + 行号 + 逐字短引文`；**不得用"一般来说"替代**。
5. **边界声明**：若涉及结果改写、真实人物私生活、暴力/偏见、非西方题材，逐项标 ADOPT / CONDITIONAL / REJECT / NOT_PROVEN。

引述来源时的措辞规则：说"**在这些文本里可复现的做法是……**"，**不得**说"某某作家教导/主张应当……"。
