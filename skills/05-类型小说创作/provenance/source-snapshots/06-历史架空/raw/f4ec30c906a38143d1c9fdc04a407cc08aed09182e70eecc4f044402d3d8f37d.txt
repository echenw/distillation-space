# 05 · 反例、冲突与适用边界（A01–A08 / C1–C7 / U01–U04）

本文件是“不要怎么做”的清单，也是本 Skill 的自限制声明。每条反例都给出语料内依据与替代动作。

## 1. 反例（A01–A08，全部 REJECT 为通则）

| ID | 反例（常见写法） | 为什么不行（证据） | 替代动作 |
|---|---|---|---|
| A01 | 真实人物巡游：让拿破仑/国王/将军反复露脸，但不改变任何选项 | PG1374 的拿破仑只在“给庇护 + 划法律边界”时上场（L188-208），随后一句“Fifteen years elapsed”（L246-249）退场；PG840 连国王都不上场，只用“a new king arose”（L25643） | 用 H04 出场台账；无决策节点就写“离场压力” |
| A02 | 服饰/器物清单冒充历史 | PG1433（L184-186 纸币贬值）与 PG1374（L2046-2066 婚姻公证、L2439-2440 back pay）的沉浸主要来自制度与账本，不是服装目录 | 用 H02 制度清单 + H06 账本；器物只写关系（H07） |
| A03 | 精确日期堆叠，以为越精确越历史 | PG840 序言明确拒绝历史小说的编年负担（L18-21），仍成立为 romance；PG12175 只标“XVIIth CENTURY”（L3） | 按 C2 选精度：靠近可考事件才精确 |
| A04 | 全篇厚方言 | 只有 PG840（本地第一人称）采用厚方言（L6476-6480）；PG1374 几乎无方言，只在情感峰值转意大利语（L986-989） | 用 H13 语域表；方言按叙述者位置分配 |
| A05 | 让现代价值观直接裁决历史人物 | PG6872 的奴隶主视角（L7116-7120）若被现代旁白直接骂倒，会抹掉“人物如何自我安慰”的历史信息 | 用 H14 视角标注；让文本内反证出现，而非作者代言 |
| A06 | 把时代偏见当作者结论 | PG6872 L7116-7120 是人物/叙述者视角（FICTION_CASE），不是史实；PG1374 L460-470 的党派品格论也是叙述立场 | 引用时标“人物视角”；必要时加副文本（H10） |

## 2. 冲突裁决（C1–C7，摘要）

| # | 冲突 | 裁决 | 落地位置 |
|---|---|---|---|
| C1 | 历史小说 vs romance 的文体契约 | 开篇声明模式，二选一；不混用 | 04 副文本契约 |
| C2 | 日期精度 | 与可考事件的距离成反比 | H01、A03 |
| C3 | 真实人物上不上场 | 只在改变主角选项时上场，否则幕后 | H04 |
| C4 | 方言厚度 | 由叙述者位置与可读性决定 | H13 |
| C5 | 正义由谁执行 | 先定“哪个机构有强制力”，只让一套法生效 | H02、H08 |
| C6 | 结局调性 | 必须兑现已建立的赌注类型（生存/荣誉/爱情/复仇） | H15 |
| C7 | 叙述可靠性 | 时代偏见要么给反证，要么给框架，不能两者都不给 | H14、H10 |

## 3. 未决（U01–U04，如实保留，不得写成保证）

- **U01** 厚方言对现代读者的沉浸收益/损害：无语料内读者数据，`NOT_PROVEN`。
- **U02** 史料框架是否提高可信度：只有文本内证据（PG12175、PG388），无行为测试，`NOT_PROVEN`。
- **U03** PG5897《Castle Richmond》的饥荒“纪实性”只有导言自称（STRUCTURAL L33-34：“The value of the story is rather documentary than literary”），正文未读，不能评估。
- **U04** 21 世纪历史小说的适用性：语料止于 1923 年（PG67929 版权页），`modern_applicability: NOT_PROVEN`。

## 4. 证据边界（必须随交付一起声明）

1. **覆盖率**：实读 6 本 / 6,781 行 / 约 82,537 o200k tok = 全批 3.08%；11 本仅结构档案。任何“历史小说都……”的句式都超出证据。
2. **STRUCTURAL 用法**：只能引用档案中的书名页、章题、首尾取样。可用于结构对照（如 PG67929 三卷分法、PG864 第 V 章章题自带日期“FEBRUARY 27TH, 1757”、PG2034（STRUCTURAL）L7 书名页“'TIS SIXTY YEARS SINCE”（档案取样：struct-PG2034.md 开头取样）），不能推断正文手法。
3. **类型边界**：PG5343、PG8385 从档案看更像写作时当代题材，不作历史小说证据（档案未给出版年，标 UNVERIFIED）。
4. **来源族**：Balzac 2 本、Orczy 3 本、Scott 2 本各按 1 族计；引用时仍标具体 PG。
5. **文本性质**：全部为公版小说（含译本），是 FICTION_CASE，不是史料；不能用来担保历史准确性。

## 5. 低覆盖下的使用纪律

- 每条建议必须带**证据强度标签**（FULL / PARTIAL / STRUCTURAL）与 PG+行号；无标签的建议视为本 Skill 的推断（H/P），不是文本事实。
- 优先使用**跨族复现**的规则：H02、H03、H07、H10、H11、H12、H13、H14、H15 均有 ≥2 族支持；**H01、H06、H08、H09 主要来自 Balzac 一族**（PG1374/PG1433），只能作“同族强烈提示”；H04 主要来自 PG1374 单本，条件性最强。
- 引用引文 ≤25 词，逐字；不确定就写 UNVERIFIED，不补写。
- 遇到语料未覆盖的年代/地域（如中国历史、非洲史、20 世纪战争），只输出“可迁移的问题清单”，不输出“史实断言”。

## 6. 与相邻 Skill 的接口

- 本 Skill **未声明**与任何其他 Skill 的共享运行时接口；交叉引用仅单向指向本批证据卡与 `notes/fusion.md`。
