# 模板：历史人物入书审核表（Real-Figure Audit）

> 每行独立可填（RF-01..RF-12）。用于把真实历史人物写入小说前的合规审查。

| ID | 字段 | 填写内容 |
|---|---|---|
| RF-01 | 人物（生卒年/身份） | |
| RF-02 | 史料清单（传记/记录/书信） | |
| RF-03 | 人物在书中出场的事件（史实授权场景） | |
| RF-04 | 人物的台词与抉择（是否全部不改变历史） | |
| RF-05 | 与虚构主角的关系（恩人/对手/君主） | |
| RF-06 | 后人名誉风险（诽谤边界） | |
| RF-07 | 性格刻画与史载性格的偏差说明 | |
| RF-08 | 时间线核对（出场日期与史料一致） | |
| RF-09 | 若史料空白处的虚构行动（是否可证伪） | |
| RF-10 | 时代语汇（称谓/头衔准确性） | |
| RF-11 | 脚注/导言声明计划 | |
| RF-12 | 失效出口（史实冲突时撤回方案） | |
