# Historical-Fiction-Craft（历史架空写作技能 · 批次 B03）

## P4 专项操作入口（Agent B 静态修订）

本 Skill 保留既有可执行流程与参考资料，并添加一份从本批次原文中裁决的 [精简条件规则](references/p4-field-guide.md)。按用户任务选择主分支，只加载该分支所需参考资料；原始叙事实例是 **F（作品现象）**，提炼为作者可以采用的流程属于 **H/P（设计推断/建议）**，不能写成原作者明确教过的方法。

**优先取得已知信息；只有需要对既有稿逐段诊断时必须获得稿件**任务（写作/策划/诊断/改写）、目标受众与媒介、已知人物/事件/规则及既有稿（只有定位诊断时必需），并确定允许改写的范围。输出合同：`任务路由 → 输入事实/缺口 → 选择的规则ID → 有位置的文本证据或来源 → 可执行方案（含反方案） → 交付物 → 尚未验证的风险`。当用户没给原稿时不能虚构段落位置；要求改稿时默认只给方案或非覆盖的新稿；涉及权利、历史真实或危险现实建议时，划清故事创作与现实事实边界。

**退出方式**：缺关键剧情信息，给最小补料清单和两条可选方向；用户目标相互冲突，保留两个条件分支和取舍，不捏造统一结论；超出本 Skill 的类型/年代/媒介/读者条件，说明不能支持的结论，必要时只提供明确标为推断的结构类比；效果与真实用户任务未验证时标 `NOT_PROVEN`。这不是自动触发、自动运行或保证创作效果的程序。


基于 16 份 Project Gutenberg 历史小说来源（本轮可信 FULL 12/16，另4本只有扫描+关键章），并非全本可信证据（Scott×4、Stevenson×3、Dumas、Collins、Haggard、Buchan、Hough、Morris、Peacock、Balzac 等）全文提炼的历史小说写作技能。核心方法论来自 Collins《Antonina》序言（虚构载体律/事件顺序生长律）与 Scott 四部导言（原型考据/命题定调/史料引文/选代理由）。每条规则回指 PG ID+行号+逐字短引文。

## 触发
- 用户要写/起草以真实历史时期为背景的小说或短篇。
- 用户要诊断、修订历史小说（编年错误、时代细节、真人物处理问题）。
- 用户要把真实历史人物写入小说、改编历史悬案。
- 用户询问"历史小说如何平衡史实与虚构"。

## 负触发
- 纯架空世界（无真实历史锚点）——用奇幻技能。
- 学术论文/传记写作。
- 拟把虚构人物冒充真实历史人物发表（伦理出口：拒绝）。
- 殖民/族群压迫立场的复制（技法可吸收，立场重构）。

## 输入权限
- 需要：历史时期/地点、目标篇幅、主角位偏好（虚构载体/真人物，未指定时先问或默认虚构载体并声明）。
- 不需要：来源原文（引用已内置）。

## 工作分支
1. **从零构思** → templates/history-fiction-ratio.md（编年表+主角位+信物母题计划）。
2. **真人物入书** → templates/real-figure-audit.md（史料清单+行动边界）。
3. **诊断修订** → templates/historical-diagnosis.md（逐项审计+RH 处方）。
4. **冲突与边界** → references/scope-and-conflicts.md（C6–C10 裁决）。

## 输出
- 构思：HF 配比表（14 字段）+ 规则遵循说明。
- 人物：RF 审核表（12 字段）。
- 诊断：HD 诊断表（12 字段）+ RH 编号处方。

## 失败出口
- 用户要求把虚构人物冒充真实历史人物发表 → 拒绝并说明伦理边界。
- 用户拒绝提供编年表 → 如实说明 RH-03 无法执行，产出降级为"泛历史背景"。
- 引文行号与用户版本不一致 → 以 PG 整本阅读版.txt 为准。
- 道德宇宙/殖民立场冲突 → 交用户裁决，不代选（C10）。
