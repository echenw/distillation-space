## 6. 引文核验方法与结果

**方法**：从本 Skill 的 SKILL.md 与 references/01–04 中正则抽取 `PG ID + 行号 + 引文` 三元组，按行区间拼接原文做空白归一 + 直/弯引号归一 + 破折号归一后比对；工具为 `distill/_tools/kd32_ledger_gate.py`（`--book` 单本模式）。
原文路径（只读）：`distill/分类蒸馏/_来源批次/16-类型小说专项/06-历史架空/批次-05/<PG>-<Title>/整本阅读版.txt`。

| 指标 | 数值 |
|---|---|
| 抽取引文—锚点配对总数 | **66** |
| 回源命中（OK） | **66** |
| NOT_IN_RANGE / NOT_FOUND | **0** |
| 命中率 | **100%** |
| 覆盖来源 PG 数 | **10 / 18**（PG82、PG24973、PG4966、PG43076、PG40034、PG23675、PG6406、PG61484、PG1711、PG70124） |

**核验命令（本轮实跑）**：

```
python3 distill/_tools/kd32_ledger_gate.py \
  --book <round-p4-final-2026-10-30>/notes/reading/supp-<PG>-s<起>-<止>.md \
  --src distill/分类蒸馏/_来源批次/16-类型小说专项/06-历史架空/批次-05/<PG>-<Title>/整本阅读版.txt \
  --pg <PG> --start <起> --end <止>
```

10 份补充台账全部 `verdict: PASS`；逐条引文判定 `OK: 66 / NOT_IN_RANGE: 0 / NOT_FOUND: 0`。

其余 8 源（PG1377、PG20749、PG30939、PG31916、PG6944、PG24、PG1033、PG8147）的证据来自既有 FULL 台账（门禁 PASS），其引文核验由各自台账的门禁记录承担，本 Skill 引用时以"PG + 行号"形式给出，可在 `notes/reading/` 下回查。
