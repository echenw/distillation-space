# 模板：历史稿件诊断表（Historical Manuscript Diagnosis）

> 每行独立可填（HD-01..HD-12）。

| ID | 字段 | 填写内容 |
|---|---|---|
| HD-01 | 时期定位与编年表核对 | |
| HD-02 | 主角位审计（虚构/真人/混合；各自行为空白与来源边界） | |
| HD-03 | 真人物行动审计（有来源/合理填补/纯虚构；若架空则分歧点） | |
| HD-04 | 悬案/传说处理审计（解法兼容性） | |
| HD-05 | 时代细节审计（服装/交通/法律/货币错误清单） | |
| HD-06 | 时间错位审计（未声明脚注的挪移） | |
| HD-07 | 信物/母题回收审计 | |
| HD-08 | 群像清账审计 | |
| HD-09 | 视角与立场审计（殖民/性别/宗教再现） | |
| HD-10 | 读者辅助审计（词汇表/导言） | |
| HD-11 | 巧合与 deus ex machina 审计（真君主解围的伏笔） | |
| HD-12 | 修订处方（按 RH 编号逐条开出） | |
