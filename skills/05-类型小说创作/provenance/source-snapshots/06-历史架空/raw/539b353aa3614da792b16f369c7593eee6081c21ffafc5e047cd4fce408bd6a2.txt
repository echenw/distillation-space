## 2. 引文格式（强制）

```
PG####（强度）L###–###：“≤25 词逐字英文引文”
```

- 强度只能是 `FULL`、`PARTIAL`、`STRUCTURAL`。
- `PARTIAL` 引文必须落在下列窗口内，窗口外一律不得引用：
  - PG840：1–120；6424–6543；12848–12967；19272–19391；25577–25696
  - PG388：1–120；5890–6009；11781–11900；17672–17791；23444–23563
  - PG12175：1–120；2815–2934；5630–5749；8445–8564；11141–11260
  - PG6872：1–120；3527–3646；7054–7173；10581–10700；13989–14108
- `STRUCTURAL` 引文只能来自 `notes/structural/struct-PG####.md` 中的书名页/章题/首尾取样，并注明“档案取样”。（`####` 是 PG 编号占位符；该字符串是文件路径模板，不是引文。）
- 引文必须逐字（保留原始拼写与用词）；弯/直引号、撇号与破折号按 ASCII 归一（`’`→`'`、`“”`→`"`、`—`/`--`→`--`），不改变词形；不得补词、改词、合并两处不相邻文本。

## 3. 编号约定

- 规则：`H01–H15`（本 Skill 自有编号，不与外部 P 编号混用）。
- 反例：`A01–A08`；冲突：`C1–C7`；未决：`U01–U04`。
- 证据文件：FULL 书为 `notes/evidence/card-PG####.md`；PARTIAL 书为 `notes/evidence/partial-PG####.md`；STRUCTURAL 为 `notes/structural/struct-PG####.md`。
- 覆盖状态总表：`notes/coverage-ledger.md`（17 行，逐本）。

## 4. 引用核验路径（三级）

1. 本索引 → 对应 references 的规则段；
2. 规则段 → `notes/evidence/` 证据卡/窗口卡（同一行号）；
3. 证据卡 → `notes/coverage-ledger.md` → 原文 `整本阅读版.txt` 的对应行（FULL/PARTIAL 窗口内）。

任何一级对不上，引用即作废；不得用“大意如此”替代逐字引文。

## 5. 覆盖声明（不得省略）

- 本 Skill 的规则主要来自 **Balzac 两本（FULL）** 与 **四本 PARTIAL 窗口**；11 本 STRUCTURAL 未读正文。
- 因而：**不能**声称“17 本历史小说都如此”；**不能**把 STRUCTURAL 书的章题当正文风格证据；**不能**把 PARTIAL 窗口外的情节写进示例。
- 具体限制见 `05-antipatterns-and-boundaries.md` §4 与 `notes/structural-usage.md`。
