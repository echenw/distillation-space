# R7　结局收束、未决冲突与负例

## 一、结局落点：代价被承认，不是胜利被结算

### 证据（F）
| 来源 | 结局怎么收 | 位置 |
|---|---|---|
| PG36 | 入侵者死于地球细菌——"被上帝以其智慧置于地上的最低微之物"所败 | L5953-5978 |
| PG31976 | 主角失败入狱，却"知道有一个人逃掉了"，然后坐下来笑了 | L780 |

### H（跨 4 组支持：Wells / Nourse / Merwin / Boren）
这些书的结局都不解决威胁，而是**让某个人承认他付出的代价**。
胜败可以在此之前就分出；结局那一格留给代价。

### P：代价清单（模板）
| 字段 | 要求 |
|---|---|
| 被承认的代价 | 一句角色自己说出的话，或一次他不再辩解的动作 |
| 未解决的部分 | 至少一项，明明可以写圆满却故意留着 |
| 可带走的物件或动作 | 一件会留在读者记忆里的东西（花、南瓜头、沉默的机器、一个笑） |
| 来源参照 | PGXXXX + 位置 |

## 三、负例与禁止项

1. **PG31519 的族裔/种族贬称**（`"pollywog"`、`"Greenbacks"`）属文本现象 F。
   本批没有第二本提供可对照支持，且它与"角色要可核验"相冲。
   **不作为可被沿用的写法建议**，不提供模板，只作历史文本现象记录。
2. **PG20869 的"不交代原理"**不是通用许可：只有在已声明"尺度口味"时才可省略原理；
   在清单口味下省略原理等于失效。
3. **单部小说的情节设计不得升格为普遍规则**：本 Skill 所有规则都要求 ≥2 个独立作者组支持；
   只有一组支持的写法一律降级为"可参考的个案"，并在引用时注明。

## 四、NOT_PROVEN（本轮不写规则）

- 外星语言/翻译机制的正统写法：本批没有任何一本把翻译写成可见步骤；
  PG27595 让计算机"不到一日半破解语言"（是回避而非解释）；
  PG1329 直接跳过——"The words were delivered in a rough, foreign tongue,
  but were as intelligible to Maskull as if spoken in English."（本轮补读 L5413-5414）。
  证据不足，留给后续批次。
