# 失败出口（failure-modes.md）

情节卡壳、被质疑"为什么反派不直接……"、或终章无力时的自检顺序。按序执行，命中即修。

## 自检顺序（四查）

### 第一查：代价去向（铁律 1）

问：这场胜利/救援/奇迹的账单在哪里显示？
- 系统级救场 → 必须触发过载停摆（society 7；PG10662 全城停摆一小时）。
- 军事胜利 → 必须能换算成火力换员汇率（expedition 3；PG70691）。
- 幻术/伪装成功 → 必须有配重支出与必然毛边（mind-war 2；anti-example A4）。
- 修复失败 = 设定无成本 → 回 A2 反例。

### 第二查：免疫漏洞（铁律 2）

问：这个"无敌"设定的死穴是什么，读者何时能推到它？
- 唯心武器 → 认知疫苗（mind-war 3；PG72 知晓即免疫）。
- 绝对防御/禁制 → 设定级禁制词/条件（mind-war 6 Master-Word；PG10662 恶力说不出）。
- 无墙监狱 → 体质/知识门槛（expedition 16；PG32150）。
- 修复失败 = 无解之力 → 回 A1 反例（多半还混了档）。

### 第三查：时钟（铁律 3）

问：超常能力的倒计时在哪里？
- 潜伏 → 泄密时钟（identity 8；PG25550）。
- 心控/幻象 → 心控三限与维持成本（mind-war；PG25550 心控机三限律：范围/时长/人数受限）。
- 机器 → 剩余寿命自报（created-beings 7；PG50827）。
- 修复失败 = 能力万能化 → 回"结构性提醒 2"。

### 第四查：收束选式

问：终章用了哪种收束，选式依据是什么？
- 事件核心故事 → 物证留白/预告型（identity、history）。
- 意义核心故事 → 拒述/邀请补刀/双解释悬置（created-beings、history）。
- 长征/连载 → 动作中断/章末地标（expedition）。
- 社会/仪式题材 → 仪式反转/香水瓶意象（society），且反转机制必须已预埋（anti-example：无规则复活）。
- 修复失败 = 终章泄力 → 通常是把"事件故事"用"意义收束"或反之。

## 五类死法速查（详表见 anti-examples.md）

| 死法 | 一句话症状 | 修复入口 |
|---|---|---|
| A1 混档超自然 | 同一幻术忽强忽弱 | mind-war 定档三选一 |
| A2 无代价救援 | 救场后一切照旧 | society 文明命脉三律 |
| A3 宣言式人格 | 机器说"我痛"即成人 | created-beings 行为链 |
| A4 无配重伪装 | 骗局零毛边零成本 | mind-war 配重 + identity 指纹 |
| A5 裸告白 | 关系靠"我爱你"推进 | society 关系工程四件 |

## 终极出口

四查全过仍卡 → 回到主决策表重判文类档：多数"卡壳"实为文类错位（把论说引擎用于冒险，把悬置收束用于硬科幻）。重判后允许换引擎，但已写章节须回改其收束节与代价账目，不得仅追加新章遮盖。
