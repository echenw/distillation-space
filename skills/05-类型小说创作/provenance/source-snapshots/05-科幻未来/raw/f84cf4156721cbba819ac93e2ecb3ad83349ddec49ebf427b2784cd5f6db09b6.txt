# Sci-Fi Future Plot Forge — 科幻未来情节锻造术

> **P4 返工最终行为合同**：原全部核心规则已逐条核验；优先使用实际 references 内标为“P4 最终有效规则”的修正，而非旧的绝对配方。阅读证据与元数据见 references/version-and-provenance.md：可信 FULL 28/28。本包仅 P4 静态验证，P5/GQ5 NOT_PROVEN。 用户可无原稿直接请求原创；只有对既有稿的定位诊断必须先取得原稿。


## P4 专项操作入口（Agent B 静态修订）

本 Skill 保留既有可执行流程与参考资料，并添加一份从本批次原文中裁决的 [精简条件规则](references/p4-field-guide.md)。按用户任务选择主分支，只加载该分支所需参考资料；原始叙事实例是 **F（作品现象）**，提炼为作者可以采用的流程属于 **H/P（设计推断/建议）**，不能写成原作者明确教过的方法。

**必须先获得**任务（写作/策划/诊断/改写）、目标受众与媒介、已知人物/事件/规则及原稿（诊断时必需），并确定允许改写的范围。输出合同：`任务路由 → 输入事实/缺口 → 选择的规则ID → 有位置的文本证据或来源 → 可执行方案（含反方案） → 交付物 → 尚未验证的风险`。当用户没给原稿时不能虚构段落位置；要求改稿时默认只给方案或非覆盖的新稿；涉及权利、历史真实或危险现实建议时，划清故事创作与现实事实边界。

**退出方式**：缺关键剧情信息，给最小补料清单和两条可选方向；用户目标相互冲突，保留两个条件分支和取舍，不捏造统一结论；超出本 Skill 的类型/年代/媒介/读者条件，说明不能支持的结论，必要时只提供明确标为推断的结构类比；效果与真实用户任务未验证时标 `NOT_PROVEN`。这不是自动触发、自动运行或保证创作效果的程序。


基于 28 部历史科幻/相关来源的既有阅读证据重新整合（可信度在版本来源表）的情节工程方法（1879–1962,共 1,161,096 o200k tokens：Verne、Bellamy、Hodgson、Burroughs、Hawthorne、Norton、Leinster、Garrett、Shaara、S. Bond 等）。用于设计/诊断科幻小说的情节骨架：唯心作战、造物伦理、身份渗透、史料时间、远征作战、社会基建六大域。

## 使用须知（先读）

1. **规则编号语义**：`X-n` 形式为该域第 n 条规则；每条标注来源 PGID 与推断等级 H（设计推断，非原文明示）。所有规则均为从源文本观察 F 出发的 H 候选；本轮已对每个原核心模块逐条裁决，不是作者方法论宣言。
2. **时代语境**：来源含 1879-1962 年作品，部分叙事元素（性别奖赏结构、挞戒式情侣冲突、殖民视角）属时代语料。本 Skill 只采纳其结构功能（关系动力学、牺牲取信、双向照护），不采纳其权力包装。引用时代元素作示例时须按当代读者敏感度改写。
3. **不跨域混编**：非虚构技法（PG30267 史论）单列在 history-time.md 的"非虚构节"，不与小说规则混用。

## 六域导航

1. **mind-war.md — 唯心作战与群体情绪**：信念武器、真实感配重、善恶力可见化、预警音标符、群体情绪广播。用当故事里有"想出来的武器""集体信念场""心灵能力"。
2. **created-beings.md — 造物与被造物**：机器人/AI 人格证明的行为链、造物者止损-共存-放归三姿态、非人接触的沟通故障树。用当故事主角或对手是"造出来的心智"。
3. **identity-infiltration.md — 认证、测谎与潜伏**：双通道认证、安全词协议、死信箱纪律、泄密时钟、命名四律。用当情节靠"谁是内鬼/如何证明我是我"驱动。
4. **history-time.md — 史料、时间与因果**：历史可改性三梯度、史料对撞、悖论保险、末日前置叙事、时间喜剧字面化。用当故事动过去/未来。
5. **expedition-combat.md — 远征与生存作战**：欺敌五式、巨兽猎杀规格书、资源双刃律、求生包标准件、行军日程法。用当主角在路上、在荒星、在包围网里。
6. **society-love-craft.md — 社会基建与关系工程**：制度双引擎、文明命脉三律、关系推进靠共同事件、终局仪式反转、荣誉倒置。用当故事在写一个世界如何运转、一对人如何靠近。

每域末尾附"收束技法"节（中断/悬置/邀请/拒述/物证五式及选用判准）。

## 三条铁律（全域通用，违反即回到本表）

1. **无代价原则**：任何救援、反击、奇迹必须显示代价去向——系统过载要在别处停摆（PG10662），火力要在别处换员（PG70691），幻术要付真实感配重（PG72）。读者问"为什么不直接……"时，代价就是答案。
2. **免疫漏洞原则**：任何"无敌"设定（幻象/神判/装甲/规则）必须内建一个可发现的认知或结构漏洞（PG72 认知疫苗、PG10662 Master-Word 恶力说不出、PG32150 无墙监狱的体质门槛）。漏洞可在全文揭示，但必须存在。
3. **时钟原则**：潜伏、心控、地电流、剩余人格寿命——一切超常能力自带倒计时（PG25550 泄密时钟、PG50827 剩余寿命自报）。没有时钟的超能力不可用作情节引擎。

## 失败出口

当情节卡壳或被质疑时，按 failure-modes.md 的自检顺序走：先查代价去向 → 再查免疫漏洞 → 再查时钟 → 最后查收束选式。五类常见死法（混档超自然/无代价救援/宣言式人格/无配重幻术/裸告白恋爱）各配修复路径。
