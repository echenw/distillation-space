# R4 让“无词/错词”承担认知冲击 + R5 用见证框架换取信任额度

两条规则合在一处，因为它们在文本里总是同时出现：谁在讲（R5），决定了他能说出哪些词（R4）。

## R4：认知冲击来自“词不够用”，不是来自“形容词很猛”

**规则**：让视角人物缺少命名概念的那个词；读者从他“找不到词”的过程里感到概念的边界。反面做法是让角色流畅地说出专业名词——那是作者在讲，不是人物在撞。

### F 证据
| PG / 行号 | 现象 | 逐字引文 |
|---|---|---|
| PG51296 / 32–34 | 叙述用人物不懂的词，并当场标注其无意义 | "The stars--it was a meaningless concept to Rikud" |
| PG51296 / 174–180 | 社会已丢失“变化”一词，用对话演出磨损 | "Variability and change are two words without meaning." |
| PG51296 / 228–230 | 以“没有名字”代替描写 | "something for which Rikud had no name" |
| PG829 / 9497–9499 | 理性物种的语言里没有“骄傲”一词 | "have no name for this vice in their language" |
| PG32 / 4810–4814 | 对方“没有可怕观念”，冲击由此产生 | "we are not accustomed to horrible ideas" |
| PG36867 / 336–343 | 权力者不懂 IFF，用无知划出概念边界 | “"What's IFF?" he asked.” |

### 怎么用（P）
1. 列出概念的 3 个关键词，挑一个**从视角人物的词汇表里删掉**。
2. 让他用迂回说法指称它（“那个会发光的东西”“那个会响的牌子”），迂回说法要一致。
3. 只在结尾让一个外来者（或读者已信任的角色）说出那个词；说出即揭示。
4. 禁止叙述者替人物补词；如必须补，用斜体或引号标记为“外来词”。

### 适用 / 不适用
- 适用：认知受限视角、世代飞船、异文化接触、儿童/失忆/失语人物。
- 不适用：全知叙述的讽刺文（PG829、PG32 常用叙述者直接命名并评论）；技术惊悚（读者需要精确术语才能跟上）。

### 反例
- **PG16457 / 2874–2993**：人物对答如流地报出煤层厚度、冰层厚度，概念被“讲懂”而非“撞上”。
- 常见失败：人物一边说“我无法理解”，一边准确使用该术语——自相矛盾，读者立刻出戏。

## R5：见证框架先借出信任，再让读者发现信任被用在哪

**规则**：在概念出现前，先放一层“谁在记录”的框架（编辑、医生、史料、回忆、酒吧转述）；读者会因为“有人担保”而接受超常设定，随后才意识到担保本身是结构的一部分。

### F 证据
| PG / 行号 | 框架类型 | 逐字引文 |
|---|---|---|
| PG829 / 47–53 | 出版者背书 | "it was as true as if Mr. Gulliver had spoken it" |
| PG32 / 12–16 | 凭记忆写作（材料全丢） | "This is written from memory, unfortunately." |
| PG24121 / 26–29 | 医生/记录者转述病人 | "The patient sat stiffly in the leather chair on the other side of the desk." |
| PG51434 / 112–113（框架见 33–49） | 酒吧里的二手故事 | “"I'll tell you," he said. "After all, it's nothing to be really ashamed of."” |
| PG58980 / 28–36 | 史料引文作外框 | "I saw this faire young maide, Abigaile Goodyeare, standing yonder on ye gallows" |
| PG31587 / 73–87 | 失忆者的自述（信息缺口即框架） | "There was only a complete blank after that." |

### 怎么用（P）
1. 选一种担保者：**机构**（出版者/法庭/杂志）、**职业**（医生/律师）、**媒介**（史料/录音/信件）、**缺陷**（失忆/醉酒/恐惧）。
2. 在开头 100 词内交代担保者的**局限**（记不清、只听到一半、有立场），不要只交代其权威。
3. 让担保者的局限在结尾变成揭示的一部分（PG32 的“凭记忆”解释了为何细节可疑；PG58980 的史料解释了“变老”传闻）。
4. 不要用框架当免责声明（“以下故事纯属听说”）——那只是怯场。

### 适用 / 不适用
- 适用：概念过于离奇、需要读者先停止怀疑的作品；第一人称短篇。
- 不适用：需要读者全程紧张的惊悚（框架会降低即时性）；已经用动作场面开篇的故事（再加框架会双重减速）。

### 反例
- **PG24121** 的框架用得极好：医生既是担保者也是被循环者，框架最后与揭示合一；反例是那种开头写“这是我的日记”，之后再无回应的做法——框架成了装饰。

## 自检（R4+R5）
- [ ] 视角人物是否缺一个关键词？缺的是哪一个？
- [ ] 他的迂回说法前后一致吗？
- [ ] 担保者在 100 词内暴露了局限吗？
- [ ] 结尾有没有回收担保者的局限？
