# 失败出口与硬边界

## 1. 什么时候必须停下来要料

| 情况 | 处置 |
|---|---|
| 用户没给原稿却要求"第几段有问题" | **不能**虚构位置。只能给"这类问题的通用诊断清单"，或要求提供原稿。 |
| 任务类型 / 类型档 / 读者与媒介未定 | 给最小补料清单，最多 5 问，并按最常见档位给一条**标注了假设**的方向。 |
| 改写范围未定 | 默认只给方案或**非覆盖的新稿**，不改写用户原文。 |
| 用户既没给核心新奇点也没给情节 | 先回到 SKILL.md 的输入契约，不要从"帮他想想写什么"开始。 |

## 2. 目标冲突时保留分支，不伪造共识

- 例：既要"硬科幻严密"又要"法术不可解释" → 输出两个条件分支：① 严密路线（必须给可计算的量，走 C1+C5）② 不可知路线（必须写清"角色无法解决"的后果，走 C3-2 的不适用条件）。**不合并**。
- 例：既要"技术解放"又要"技术依赖" → PG5699 L1639-1642 与 PG1906 L5953-5982 是本批次**无法统一**的一对。写作者必须先声明技术属于"被统治者新获得的能力"还是"统治者已内化的依赖"，再选方向。

## 3. 覆盖不到时怎么说

- 1970 年后的赛博朋克 / 后人类 / 气候小说：**不适用**。可给结构类比，但必须标为 **H（推断）**，并写明"本批次无此语料"。
- 现实工程、航天、AI 安全、科技预测：**不适用**。本 Skill 的"可计算"仅指叙事内部自洽。
- 非虚构技法、论文、游戏数值平衡：**不适用**。

## 4. 孤证不许升级为定律（元规则）

以下机制在本批 28 本中**只有单一来源**，不得写成"科幻应该……"：

| 机制 | 唯一来源 | 许可用法 |
|---|---|---|
| 职能即肉身（教育＝外科塑形） | PG1013 L6935-6956 | 只作该类型（讽刺型异星社会）的样例 |
| 环形世界内外表面 | PG5699 L3427-3429 | 只作尺度揭晓的样例 |
| 生态耦合链（酶—虫—作物—人） | PG53016 L277-279、L449-450 | 只作"后果链"的样例 |
| psionic 日常化 | PG53035 L302-304、L447-448 | 只作"未给边界也成立"的孤证，**不据以立规则** |
| 语言习得难度阶梯（名词→动词→抽象名词） | PG1013 L6854-6874 | 只作 C4 的可选装置，不是沟通定律 |

## 5. 已拒绝的旧铁律（见到就改，不要套）

1. 必须有物理代价 → 见 C7-4，形式不限。
2. 必须有可反制漏洞 → 见 C3-2，只在悬念依赖"能否被击败"时才需要。
3. 限制必须是倒计时 → 本批无一例（见 `rule-adjudication.md` A3）。
4. 造物人格只能靠行为证明 → 见 C3-4，行为／自陈／物证任一可被核对即可。
5. 关系只能靠共同事件推进 → 已拒（A5）。
6. 识别敌人＝安全 → 已拒（B6 / C3-3）。
7. 末世必须靠暴力高潮收束 → 见 C6-5。
8. 技术必然带来自由 → 见 B2，本批次存在不可调和的冲突。

## 6. NOT_PROVEN 的标注义务

以下情形一律在输出中显式标 `NOT_PROVEN`，不得暗示已验证：

- 本 Skill 未跑过真实宿主行为测试（P5 GQ1–GQ5 未完成）。
- 任何"读者会觉得……""市场会接受……"的效果判断。
- 任何从单个来源推出的、本批次无第二例佐证的机制。
- 任何跨出 1826–1963 语料范围的外推。

## 7. 时代语料处理（硬性）

本批含 1826–1963 年作品，其中性别论述（PG1951 L1203-1206）、优生婚配令（PG5699 L1035-1039）、种族化描写（PG68）属年代表达。
**只采纳结构功能**（单轴反转、行政口吻、单器官夸张、尺度揭晓），**不采纳价值判断**；引用为例时必须按当代读者敏感度改写，并在输出中说明改写口径。
