# 科幻未来写法：机制、异质与代价（Sci-Fi Future Craft · Batch 03）

## 1. 这个 Skill 解决什么

科幻/未来题材最常见的失败不是"科学不准"，而是**叙事账目没建起来**：

- 科幻感**堆形容词**——"发着蓝光的巨大城市"，读者记不住、也判不出真假；
- 世界观说明**前置一大段**，读者没有提问的动机，说明变成说明书；
- 出现超常能力（时间机器、拟死、心灵投射、通用机器人）后**没有物证与代价**，故事可以随时想怎么用就怎么用；
- 机器人/自动化只写成"失控伤人"，结局一半靠砸、一半靠感动；
- 结局必须"威胁被解决"，于是作品只剩胜利结算，没有代价。

本 Skill 把这些换成**七条可核对的规则**（§4）与**六类体裁分叉**（§5），
产出物是四张表：设定回答表、异质三联表、机制账本、代价清单。

与同类 Skill 的分工：本 Skill 的证据底座是**批次-03 的 28 本**（1890s–1960s，
从 Wells、Bellamy、Jefferies 到 Galaxy/If 短篇），强项是**机制陌生化与制度/机器的不可修性**。
它不覆盖外星语言学的正统写法（本批证据不足，一律 NOT_PROVEN，见 §9）。

## 2. 触发 / 负触发

**触发**
- 新建或改写：近未来讽刺、乌托邦/反乌托邦制度推演、灾后退化、外星入侵、星际/异星探险、时间旅行伦理类小说。
- 诊断："设定像说明书"、"未来只有形容词"、"每一项技术都随时可用"、"机器人万能/只会失控"、
  "时间机器没有代价"、"科幻结局只会靠胜利结算"。
- 需要把未来社会写成**单一变量推到底**的工程问题，或把架空机制写成**有物证的账本**。

**负触发**
- 真实科技预测、工程/军事/医学/应急操作建议（本 Skill 只谈叙事）。
- 纯奇幻、纯战争、纯言情且无"未来/异质机制"承担压迫结构的作品。
- 要求引用本批次未台账化的行号、要求提供外星语言破解技术方案、要求我为没有台帐的情节编证据：
  **拒绝编造**，改引 `references/source-index.md` 的已读范围并标 NOT_PROVEN。

## 4. 七条硬规则

### R1　说明必须"可被触发"，不是"必须前置"
- **F**：PG624 的作者序要求读者暂时忘记旧世纪，每一段制度说明都由叙述者的一个具体困惑引出（马车比喻，L148-169）；
  PG13944 的 Part II 完全不解释地拉开场景（窗只有两三英寸玻璃，L1581-1595）；
  PG21873 直到物证链成型才揭晓设定。
- **H**：读者不需要"先知道"，需要"随时能问且问得到答案"。
- **P**：每条设定在 `references/01` 的**设定回答表**里占一行：[读者会在第几章问 / 谁答 / 答到什么颗粒度 / 允许被推翻吗]。
  答不了的行必须删掉或在书内标为未知。

### R2　异质感只认"运作三联"，不认形容词
- **F**：PG4340 把外星生命差异推到元素/液态水/温度（L2704-2736）；
  PG21873 用"社会朝向生态而非人际"（L2562-2565）；
  PG51623 用"能造斧头的文化必能发明锤子"（L299-300）——一句缺席的工具就是一整个文明的判断；
  PG64350 用气味而不是视觉识别他者（L64-66）。
- **H**（推断，跨 4 组来源）：可核验胜过可惊叹。
- **P**：每个异星/未来机制写满三格：**谁做它 — 多久做一次 — 做不成会怎样**。
  三格填不满的机制，不许进入正文，只能进惰性背景。

### R3　整本书只能用一种"证据口味"
- **F**：清单线——PG59438（绕飞两周制图、二十七天会议一致投票）、PG32636（Rule 编号体系）、PG59558（保修天数表）。
  尺度线——PG20869（撞暗星只给视直径 L4233-4234，跨距直接给数字 L5104）。
- **H**：两条线各自自洽，混用会互相取消效果。
- **P**：动笔前在封面页写明"本书证据口味：清单 / 尺度"。清单线必须给条款、天数、名额、票数；
  尺度线必须给**可代入的数字**（视直径、距离、耗时），并允许不必交代原理。

### R4　机制是一份账本：可回溯，且用一次付一次
- **F**：PG51460 "机器在那里存在两次" → 额外静电力场（L343-356）；
  PG51588 只能机—机对接、反向需太阳全功率（L348-363）；
  PG31976 由"能把软体压成那样的只有加速度"反推出真相（L451-457）。
- **H**：超常能力一旦没有物证，故事的张力来源会从"人物"滑到"作者心情"。
- **P**：机制账本每行写：[触发条件 / 必然的物证（残留、副作用、观测到的数字）/ 谁会因此受损 / 不可撤销性]。

### R5　敌人是"不可修理的制度"，不是"一件坏了的机器"
- **F**：PG59558 厂商明文"不必关心 android 的思想，它只是机器"（L227-230），保修条款把救济路径全部堵死；
  PG32636 的 Rule 编号把人格写成可执行脚本；
  PG29204 **反证**：严格守法的机器人反而清洗了腐败小镇（L753-766）。
- **H**：三种机器结局（秩序善 / 制度恶 / 善恶失效）在本批同时成立，**不得捏合成一种**。
- **P**：写机器先选它的结局类型（见 `references/04` 的三选一表），再回填"为什么这条路走不通"：
  条款、保修天数、厂商立场、可替换性、救济成本。

### R6　不要冲上限，要给限制
- **F**：PG31519 由双星辐射倒推技术形态——雷达与飞行器近乎无用，只能用大型飞艇与老式武器（台账第 3、8 块）。
- **H**：限制比上限更能产生可辨识的生活形态与战术。
- **P**：每项核心科技配一条**失效条件**（什么时候不能用 / 谁能让它不能用 / 环境到什么量级就废）。

### R7　结局收在"代价被承认"
- **F**：PG36 归因为"最低微之物"（L5953-5978）；
  PG31976 主角入狱却记着"有一个人逃掉了"（L780）；
  PG31215 选择"毕竟是我自己的"剩余人生（L846-848）；
  PG59558 一击把"完美仆人"降为沉默（L609-618）。
- **P**：结局清单必须包含 [被承认的代价 / 没被解决的部分 / 一个可带走的物件或动作]。

## 5. 体裁六分叉（先选一类，参数完全不同）

| 代号 | 体裁 | 压迫单位 | 主要失效模式 | 代表来源 |
|---|---|---|---|---|
| A | 制度推演（乌托邦/反乌托邦） | 论证与反驳 | 变成宣言、没有反驳章 | PG624、PG7303（同组） |
| B | 灾后 / 退化 | 二手叙事与失传 | 解释太多、退化后的日常没落地 | PG13944、PG79464 |
| C | 入侵 / 灾变 | 二手信息与尺度 | 全局视角过多、个体视角被冲掉 | PG36、PG22559 |
| D | 近未来讽刺（机器/消费/自动化） | 条款与计数 | 笑点有余、救济路径没写 | PG32636、PG59558、PG31038、PG29976、PG51460、PG51623 |
| E | 星际 / 异星冒险 | 物证与解剖 | 只有奇观、没有可核验的三联 | PG21873、PG31976、PG22512、PG31519、PG51344、PG1329、PG20869 |
| F | 时间旅行伦理 | 关系的账 | 物理机制写满、人际关系没代价 | PG35、PG31215、PG51460、PG51588、PG30963 |

选错分叉规则会互相打架：把 A 的"反驳章"要求套到 E 上会杀死探险节奏；

## 7. 最短执行路径（默认 7 步）

1. **定证据口味**（R3：清单 / 尺度）写在封面页。
2. **定体裁分叉**（§5 A–F，允许主 1 副 1）。
3. **列设定回答表**（R1）：每条设定 = 读者何时问 / 谁答 / 粒度 / 可否被推翻。
4. **填异质三联表**（R2）：每条机制 = 谁做 / 多久一次 / 做不成会怎样。
5. **建机制账本**（R4）：超常能力 = 触发条件 / 物证 / 受损者 / 不可撤销性。
6. **写不可修制度卡**（R5 + R6）：机器/自动化 = 条数/天数/厂商立场/失效条件/救济成本。
7. **收代价清单**（R7）：被承认的代价 / 未解决的部分 / 可带走的物件或动作。

每一步都要求产出**一张可逐行核验的表**，不接受"我大概知道了"。

## 9. 明确不做 / 明确禁止

- **不做**：外星语言破解技术的正统写法（本批证据不足，T11 = NOT_PROVEN）；
  真实科学技术趋势判断；把 Golden Age 小说当成"作者教你怎么写"的教范引用（所有来源均为 FICTION_CASE）。
- **禁止**：把任何单部小说的情节设计当成所有作品都必须遵守的规则（本 Skill 的规则全部要求 ≥2 个独立作者组支持）；
  禁止把 PG31519 的族裔/种族贬称写法当作可沿用的类型惯例（列为负例，不提供模板）；
  禁止伪造行号、伪造"我已核对"、把未跑的检查写成通过。
- **冲突保留**：机器结局三种（§ R5）、乌托邦 vs 退化（§5 A/B）、清单 vs 尺度（R3）——
  本 Skill 明确**不提供唯一答案**，只要求你选定并付代价。
