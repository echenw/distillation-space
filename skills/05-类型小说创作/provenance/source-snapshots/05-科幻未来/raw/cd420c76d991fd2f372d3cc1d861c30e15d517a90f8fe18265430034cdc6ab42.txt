# 科幻概念揭示（science-fiction-conceptual-reveal）

## P4 专项操作入口（Agent B 静态修订）

本 Skill 保留既有可执行流程与参考资料，并添加一份从本批次原文中裁决的 [精简条件规则](references/p4-field-guide.md)。按用户任务选择主分支，只加载该分支所需参考资料；原始叙事实例是 **F（作品现象）**，提炼为作者可以采用的流程属于 **H/P（设计推断/建议）**，不能写成原作者明确教过的方法。

**必须先获得**任务（写作/策划/诊断/改写）、目标受众与媒介、已知人物/事件/规则及原稿（诊断时必需），并确定允许改写的范围。输出合同：`任务路由 → 输入事实/缺口 → 选择的规则ID → 有位置的文本证据或来源 → 可执行方案（含反方案） → 交付物 → 尚未验证的风险`。当用户没给原稿时不能虚构段落位置；要求改稿时默认只给方案或非覆盖的新稿；涉及权利、历史真实或危险现实建议时，划清故事创作与现实事实边界。

**退出方式**：缺关键剧情信息，给最小补料清单和两条可选方向；用户目标相互冲突，保留两个条件分支和取舍，不捏造统一结论；超出本 Skill 的类型/年代/媒介/读者条件，说明不能支持的结论，必要时只提供明确标为推断的结构类比；效果与真实用户任务未验证时标 `NOT_PROVEN`。这不是自动触发、自动运行或保证创作效果的程序。


## 这个 Skill 解决什么
把“一个科幻想法”变成读者能记住的一次转折。核心启发是：概念既可以由事件、物件和关系被读者感到，也可由对话逐步阐明；选与体裁相符的揭示方式——读者先撞上一件具体的东西（物件、动作、一句话、一个差异镜头），才愿意接受背后的观念。

## 触发
- 用户有一个高概念（时间闭环、人造人格、世代飞船、非人评估者），但落地时只能靠人物对话解释。
- 结尾的“原来如此”读者没感觉，或读完只觉得“设定挺有意思”。
- 要判断揭示该放开头（先给概念，让读者看怎么发生）还是放结尾（先给现象，让读者等命名）。
- 要审一篇“点子好、执行平”的科幻短篇，需要可执行的诊断清单。

## 负触发（不要用）
- 非虚构科普、设定集、世界观百科——那里概念本来就该被讲清楚。
- 纯冒险/军事 SF，概念只作背景，不需要读者“撞上”。
- 长篇小说中段的日常推进：本 Skill 只管**揭示点**的设计与诊断，不管通篇节奏。
- 已经有明确真实作者任务书、且只要求执行具体改写指令时：按任务书做，不套本流程。

## 最短执行路径（6 步）
1. **尝试一句概念句**：`当____时，人类以为的____其实是____。` 若无法直接表述，可先用场景试写或提出两种可变假设。
2. **选承载方式**（R1）：从物件、动作、对话、身份差异等方式中挑可核回的一个；优先选会在故事里被用坏/用完的。
3. **定信息合同**（R2）：先写清读者已知什么、视角人物能知道什么、当前悬念对象是什么，再比较前置 / 后置 / 弥散三种方案。“是什么/怎么办”只作启发，不作为固定映射；同一故事可混合多种揭示位置。
4. **设计足够的可回溯证据**（R6）：可从物理信号、行动代价、关系变化、证词差异、语言/语义线索中选择；只要求足以支撑本作的留白或明示，不要求固定三层齐备。
5. **设计可回溯的变奏**（R3）：需要重复时，让后一次与前一次存在读者可识别的关键差异；次数和改变元素数由篇幅、因果和可辨识度决定，短篇一次逆转也可以成立。
6. **选择收束句或段落长度**（R6）：用裁定、命名或感受收尾；不要用“原来，这一切都是……”句式。

## 硬约束（写作时不可越过）
- 小说正文是 **FICTION_CASE**：本 Skill 的每条规则都来自“文本展示了什么”，不是作者自述的创作法则；不要把人物的话当成作者主张。
- 引文只能用于说明结构，不得替代你自己的场景。
- 不得把“留白”当成“没想清楚”的遮羞布：留白的前提是物证充分（R6）。

## 失败出口
出现以下任一情况，**停止套用本 Skill**，改为普通编辑判断：
1. 概念句写不出“以为/其实”的替换——说明还没有概念，先做设定。
2. 某类证据不适用——改用更符合本作信息合同的言语、行动、关系变化、证词或物理信号，不强制凑固定三层。
3. 收束仍只能靠解释段才能成立——回到 R6 检查前文是否已有足够可回溯证据；若读者合同本就要求明示，则直接明示而不是硬做留白。
4. 故事类型是讽刺游记/社会乌托邦（如 PG829、PG32 型）——本 Skill 的“禁止直陈”不适用，见 `02-reveal-timing.md` 的时代边界。
5. 证据边界：本批次 P2 已是 29/29 `TRUSTED_FULL`，但历史文本仍不能证明当代平台/市场效果；需要当代样本或跨语言结论时明确写“超出本 Skill 证据范围”。
