# 冲突、例外与不采纳清单

本批 28 份之间存在真实分歧。**不要伪造共识**：以下 4 条冲突被刻意保留，规则要求把它们写进文本。

---

## §1 被保留的四条真实冲突

### C-1 落难首日到底先做什么
- PG12170（寒带雪地）：火 → 干衣 → 庇护 → 热食（L698-717）。
- PG33903（热带盐沼）：水 → 遮阳 → 保火种 → 高处过夜（L272-321, L624-627）。
- PG61600/PG78017（海岛）：先按"背风/干燥/可封口/近淡水"选址，再谈火（L2018-2031）。
- PG60632（温带富饶岛，本轮实读）：先干燥与饮水，火不进首日第一优先（L306-321）。
- **怎么用**：按环境分派（R-A 表）。若用户坚持要唯一顺序 → 走 SKILL.md 的失败出口，说明强行统一是伪造共识。

### C-2 技术阶梯能有多快
- PG60860：数周内重建火药、弓、陶、舟（L1205-1223, L3880-3940）。
- PG22554：三天才给付一节原木盖上泥；火药第三次配方才成（L2418-2442）。
- **怎么用**：两者机制相同而速度相反，都成立。允许快，但必须声明代价；允许慢，但必须写出失败原因（R-C）。

### C-3 据点要"封得住"还是"撤得了"
- PG69191：出入口可封闭、巨石可内外开合（L1664-1670）。
- PG24859：洞口从内堵死 + 始终保有一条撤退船（L6391-6407, L7330-7375）。
- **怎么用**：同一据点必须同答两问；若只能满足其一，把这个缺口写成戏（R-E）。反例：PG50723 藏身树洞洞口朝下、被从外封死 = 自埋。

### C-4 分配伦理：牺牲算术 vs 弱者优先
- PG62382-R3：命令 → 执行 → 当场解释 → 幸存者记恨 → 后续反噬（功利）。
- PG4271：幼儿的水不减，掌水者从自己份里分给他（仁慈）。
- **怎么用**：两种立场各自成立，不要替读者选边，让后果说话（R-H）。

## §5 时代与体裁限定（引用时必须同句标注）

1. 全部来源出版于 1882–1951，涉及医疗、补给量、器材做法的内容均为**该时代的权宜做法**。
2. 现代设定（GPS / 卫星电话 / ELT / 直升机）下：R-F 的"直觉前兆"、R-I 的信号三件套、R-J 的搜救规则整体重估，只保留"误读/近失"两项。
3. PG51461 的气体分层设定违背真实物理（CO₂ 与 O₂ 的凝结顺序与文本相反）——只能借用"分层采集有致命错层"这一**戏剧机制**。
4. PG24880 的"救生艇倒扣生火取暖"在封闭空间有一氧化碳风险，原卡已自注，引用时必须保留该注释。
5. PG42389、PG32922、PG2950 的主体分别为 romance、殖民地公务、通俗情节剧，其"求生内容"应按"背景社会反应"使用，不作技术源。
