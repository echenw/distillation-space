# Wilderness-Disaster-Survival-Craft（荒野求生与灾变 · 批次-01）

本技能把 28 份 1882–1951 的荒岛、极地、海难、雪地、瘟疫与末日叙事，提炼为**写小说用的机制清单**：帮你把一段"人在绝境里活下来"的故事，写成读者能自己核算、能预判崩盘、能看见代价的结构。

**这些来源全是虚构叙事，不是生存手册。** 本技能输出的是叙事机制；任何涉及补给量、医疗、器材的做法，都只在"故事里的 1882–1951 情境"下成立，不得当现代野外操作建议（见"失败出口"）。

## 触发（用本技能）

- 写或改：荒岛/漂流、海难与弃船、极地与雪地、沙漠与丛林、瘟疫与城市灾难、末日据点、动物视角生存、被俘与逃亡。
- 需要：让"资源什么时候耗尽"可被读者推算；给求生段落排出可信的操作顺序；给灾难一个可复核的倒计时。
- 需要诊断：求生段落写得像开挂、资源凭空出现、绝境总靠巧合脱困、主角什么都会。
- 需要给据点、工具链、伤病、分配、搜救信号安排结构性冲突。

## 负触发（不要用本技能）

- 把书中做法当现代野外求生操作手册输出（这是本技能最常被误用的方向）。
- 抄写殖民/种族/性别套版：这些来源中大量"野蛮人/土著/女性作为奖品"的写法只登记为时代局限，不得采纳为人物设计。
- 需要真实急救、真实航海、真实流行病学数据——本技能给的是戏剧机制，不是事实；请改用专业资料。
- 现代背景（有卫星电话、直升机、GPS、ELT）：R-F 信号与 R-J 搜救规则需整体重估，不要照搬。

## 输入（少了就先问，不要猜）

1. **环境三要素**：温度带（寒带 / 温带 / 热带）+ 介质（海 / 岛 / 雪 / 林 / 城）+ 夜间威胁（有猛兽 / 有人 / 无）。
2. **时间尺度**：数小时 / 数日 / 数周 / 数年 → 决定启用哪些规则（短程不启用 R-C 工具阶梯）。
3. **现有材料**：已写好的场纲要、正文片段、或只是设定；诊断任务必须给正文。
4. **你要的产出类型**：构思（design）/ 诊断（diagnose）/ 单场戏（scene）。

## 任务路由（读完输入后先选一条）

| 你要什么 | 走哪条 | 加载哪份 reference |
|---|---|---|
| 从设定出发搭求生线 | **A 构思** | `references/rules.md` 全部 + `references/source-index.md`（挑同环境样本） |

## 执行步骤

### 步骤 1：定环境档位（决定首日顺序，不要套唯一顺序）
按"温度带 × 介质 × 夜间威胁"选档。规则 R-A：
- 寒带/雪地 → 火 → 干衣 → 庇护 → 热食（依据 PG12170-B4）
- 热带海岸/盐沼 → 水 → 遮阳 → 保火种 → 高处过夜（依据 PG33903-B3/B10）
- 海岛洞穴/岩屋 → 先按"背风 / 干燥 / 可封口 / 近淡水"选址，再谈火（依据 PG61600-B6/B7）
- 温带富饶岛 → 先干燥与饮水，火不进首日第一优先（依据本轮 PG60632 实读 L306-321）
**不输出一个"通用首日顺序"。** 若用户坚持要唯一顺序，走失败出口。

### 步骤 2：给每种稀缺资源开一张三列账（R-B）
存量 / 日耗 / 归零日；每次角色做重大决策后更新一行。
- 只输出模板，**不输出常数**：PG24859 的"4.5 品脱/日撑 16 天"和 PG215 的"1.5 磅鱼/日"都与各自船型、气候、体质绑定，换书即失效。
- 若用户问"多少水才够"，回答：按你的载具、人数、气温自己填，并在正文里让读者能复算。

### 步骤 3：给技术/工具链写"工时 + 失败 + 退路"（R-C）
凡写"他做出了 X"，必附工时与失败次数。
- 阶梯可快可慢，但速度必须声明：PG60860 数周重建火药与舟，PG22554 三天才给付一节原木盖上泥——机制相同、速度相反，两者都成立，抄其中一个而不同时说明代价就是开挂。
- 工时样本（PG69191-R6）：剥皮半日 / 鞣制多日 / 编盾一周。
- 若设定里有现代知识，必须写一次"现代技能失效"（PG22554：each deadly device absurdly impracticable）。

### 步骤 4：定火种与不可替代资产，并安排一次失去事件（R-D）
- 资产清单：火种、载具、药、信号工具（PG393-R4）。
- 必须设计一次"失去 / 差点失去"：PG33903-B10（最后一张火柴被用来点烟）、PG24880-B14（第三天晚上用掉最后一根火柴）。
- 火同时承担取暖 / 煮食 / 信号 / 驱兽四职——灭火一次丢四项（PG24880-H3）。

### 步骤 5：据点同答"能封"与"能退"（R-E）
模板：出入口可封闭性 / 单口还是双口 / 封存时是否留返回通道 / 撤退载具在哪 / 若夜间突破人从哪走。
- 这是本批唯一被强行保留的矛盾：PG69191 要求"可封"，PG24859 要求"始终有撤退船"。两者冲突不要调和，把它写成戏。
- 反例证据：PG50723-B18（藏身树洞洞口朝下、被从外封死 = 自埋）。

### 步骤 6：给灾难一个可复核的窗口（R-F）
征兆必须是 ≥3 项物理量 + 一个截止时间。
- 样本：PG24859（气压急降 / 云色 / 涌浪 / 死寂）、PG393（铅色云 / 鸟乱飞 / 远处如人群喧响）、PG8991（冰面每次下沉 6 英寸）。
- **"主角凭直觉预感"不得单独成立**（PG215-R3 判 NOT_PROVEN，仅 1 源支持且依赖动物视角）。要写预感，必须补物理量。

### 步骤 7：伤病写成"稳定 + 计划性后送"（R-G）
- 顺序样本：PG69191-B20 溪水洗创 → 判定伤口浅 → 真风险是感染 → 静养一周。PG14432 转运链四节点：担架—吊点—舱口宽度—接收床位，任一不通即换方案。
- **禁止输出**：口吸毒液、海水催吐、蒸汽浴发汗、现场截肢、火烤奔跑复温——这些是 1889–1908 年实践，引用时必须同句标注"时代实践，现代不可迁移"。

### 步骤 8：每上一档资源，做一次"谁先"的分配测试（R-H）
水 → 食 → 睡处 → 离岛工具，每一档至少一次分配冲突。
- 保留两种立场，不要替读者选边：牺牲算术（PG62382-R3：命令→执行→当场解释→幸存者记恨→后续反噬）vs 弱者优先（PG4271-B37：幼儿的水不减，掌水者从自己份里分给他）。

### 步骤 9：信号三件套（R-I）
可见性（最高 / 最白 / 最持续）+ 误读可能性 + 近失安排。
- 误读：PG159-H5（火山岛的烟被当成地质现象）、PG393-B34（持矛奔跑呼喊导致船长判定"是野人"而驶离）。
- 近失：PG69191-H12（搜救队沿谷地仔细搜索，没发现就在崖上的落难者）。
- 风暴后 24 小时内必须修复旗与火（PG33903-R4）。

### 步骤 10（可选，按题材）：制度线 / 双引擎
- 写城市灾难、瘟疫、社群 → 加 R-J 制度线：灾难第二落点是制度（封户的反效果、资源垄断、谁有资格作证）。主证据 PG17221、PG62382、PG2950。
- 写长篇 → 加 R-K 双引擎：人祸定时 + 天灾定时，两线在同一场景交汇一次（PG50723-R1）。

### 步骤 11：收尾与登记
- 结局母题三选一，不要并列：归来后遗症（PG159-R4）/ 传说化收尾（PG215-B26）/ 谐谑收尾（PG79222）。
- 引用 PG 电子文本时，登记"正文止行 + 附录性质"，别把出版书目当叙事证据（PG69191 / PG60632 均印证）。
- 输出末尾写清：本轮引用了哪些来源、哪些规则是 `SINGLE_SOURCE`、哪些是冲突未决。

## 输出合同（每次必须给这些）

1. **环境档位**：温度带 / 介质 / 夜间威胁 / 时间尺度，一行。
2. **规则命中表**：`规则 ID | 你打算怎么用 | 来源锚点（PG + 行号）| 是否 SINGLE_SOURCE`。
3. **资源账**（若涉资源）：三列账模板，含归零日。
4. **据点 / 工具 / 信号**三块中至少一块的完整检查项。
5. **冲突声明**：本方案里保留了哪条真实冲突（R-A / R-C / R-E / R-H 至少一条），打算怎么写成戏。
6. **不可迁移清单**：本方案引用了哪些 1882–1951 的做法，必须标注"时代实践"。
7. **未证明项**：凡 `NOT_PROVEN` / `SINGLE_SOURCE` 的规则，明确写出"未获多源支持"。

## 失败出口（做不到就明确说，不要硬编）

- 用户要"通用首日顺序"→ 拒绝并说明：本批四套清单分属寒带 / 热带 / 海岛 / 温带，强行统一是伪造共识（`conflicts-and-exceptions.md` §1）。
- 用户要具体补给数字（"一个人一天要多少水"）→ 不给常数；给模板并说明常数随载具/气候/体质变化。
- 用户要现代野外求生建议 → 明确退出："本技能来源是 1882–1951 虚构叙事，不是手册"，建议改用专业资料。
- 用户环境是现代（有 GPS / 卫星 / 直升机）→ R-I 信号与 R-J 搜救整体重估，标注"现代设定下本条失效"。
- 规则只有 1 份来源支持且无交叉印证 → 标 `SINGLE_SOURCE`，不包装成通则。
- 任何规则在本批 28 份中找不到锚点 → 标 `NOT_PROVEN`，不给结论。
