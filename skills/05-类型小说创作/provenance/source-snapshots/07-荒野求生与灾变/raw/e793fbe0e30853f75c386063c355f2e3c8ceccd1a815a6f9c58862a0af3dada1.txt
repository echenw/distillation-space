# 生存危机升级（Survival Crisis Escalation）

## 1. 这个 Skill 解决什么
把“主角一直很惨”改造成“每一步都更贵”的可核查升级链。核心不是堆灾难，而是让读者能算账：还剩多少、还能撑多久、这次脱险花掉了什么、下一次靠什么。

## 2. 触发 / 负触发
**触发**
- 设计或改写荒野求生、海难、极地、灾变、末日、异星落难类小说（长篇/短篇/章节群）。
- 诊断“中段疲软”“威胁重复”“结局像天降”“配给数字不可信”。
- 需要把群像生存写成治理问题（配给、权威、信息、禁忌）。

**负触发**
- 真实应急、野外生存、医疗、救援操作建议（本 Skill 只谈叙事）。
- 纯冒险寻宝、纯战争、纯言情，且没有资源约束与伤亡代价的故事。
- 要求引用未读原文：本 Skill 只能引用其证据底座内的 PG/行号。

## 5. 最短执行路径（默认 6 步）
1. **立账**：写清库存、耗率、期限三件套，并让至少一个数字在中段被证伪（R1、R2）。
2. **定期限**：用一个可观测环境信号当钟表（水位、日照、电量、弹药），不用旁白报时（R2）。
3. **排阶梯**：按“环境→资源→同类→内部→救援/反转”换类，同类威胁最多连续两次（R3）。
4. **标代价**：每个解决方案后面写“这次花掉了什么”，且该损失在后文生效（R4、R5）。
5. **立治理**：给群体写任命依据、配给权、异议渠道、继任规则；决定“最坏情况是否公开”（R8、R9、R10）。
6. **收束**：至少两种低概率求救信道；反转线索提前埋；结局保留损失清单（R13、R14、R15）。

时间分配建议：账本与阶梯占设计时间的一半；仪式/禁忌/求救是低成本高杠杆项，不要省。

## 6. 输出物表
| 输出 | 最小内容 | 验收 |
|---|---|---|
| 危机升级表 | 5–8 个节点，每节点：威胁类别/资源变化/不可逆损失/人物关系变化 | 任取两个节点，读者能算出“更贵了” |
| 资源账本 | 库存、耗率、期限、误差来源、被证伪处 | 数字能自洽，且至少一次改变决策 |
| 庇护所规则卡 | 入口规则、弱点、被对手利用方式、失守条件 | 规则可被角色反过来当武器 |
| 治理规则卡 | 任命依据、配给权、异议渠道、继任 | 权威更替不需作者旁白解释 |
| 士气/仪式表 | 每日/每周固定锚点、禁忌清单、公开讨论议程 | 最艰难阶段仍被角色执行 |
| 求救信道表 | ≥2 信道、概率、代价、被谁看到 | 获救不靠新信息 |
| 反转伏笔表 | 3 处前置线索（物理/文化/语言） | 反转句可在前文找到锚点 |

## 8. 失败出口
- 若用户要“真实生存建议”：停止，说明本 Skill 只处理叙事，并建议转向现实应急资料。
- 若用户要求引用本批次未读文本或超出证据底座的行号：拒绝编造，改引 `source-index.md` 标注的已读范围。
- 若故事不需要资源约束（纯言情/纯冒险）：只使用 R14/R15 的收束建议，不强行加账本。
- 若用户要求“每章都必须更惨”：先确认是否需要 R3 的换类原则；同质加码会钝化。
