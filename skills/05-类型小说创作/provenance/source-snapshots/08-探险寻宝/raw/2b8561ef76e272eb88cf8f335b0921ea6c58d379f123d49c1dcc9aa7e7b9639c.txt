# Adventure & Treasure Craft（探险寻宝创作法）

面向小说作者与写作 Agent 的**条件性冒险创作方法**：宝藏价值论、藏宝与劫掠工艺、海盗组织制度、反派类型学、远征队管理、生存极境、法律与取证、推理谜题、收束谱系。
本 Skill 是**工艺规则库**，不是作品摘要，也不提供"必灵配方"——每条规则带适用条件与反例。

证据基座：1720–1949 英语冒险正典 28 部（Defoe 伪纪实源头 1 部、dime novel 1 部、pulp SF 4 部），融合裁决见 round 资料夹 `notes/source-synthesis.md`（M01–M24，ADOPT 17 / CONDITIONAL 5 / REJECT 2 / UNRESOLVED 0）。

## 1. 何时使用

- 写探险/寻宝/海盗/荒野生存/太空冒险小说，需要设计宝藏、线索链、远征队、反派、劫掠线。
- 需要组织学工艺：海盗治理制度（分赃箱/禁赌/留守抵押/遗产权）、远征分工与否决权、地下会三防。
- 需要反派工艺：魅力型叛徒、储蓄型守财奴、间谍植入、威望泡沫、劫掠产业链。
- 需要生存极境五律与濒死意识三部曲（London 信号风格，已标警示）。
- 需要法律人类学（可变法/最小司法/麻烦隔离）与取证收网链（四步取证/钓鱼取证/信贷诱购）。
- 需要推理谜题（密码/物证/行为逻辑三型）与非人对手的科学破译。
- 需要"边界自检"：什么不是探险寻宝、俗套清单、headcraft-not-witchcraft 验收口径。

## 2. 负触发：不要用本 Skill

- 用户要写的是**言情冒险**（以感情线为纲）——本 Skill 的婚姻外壳（P565）只作潜入手段，不提供言情工艺。
- 纯求生指南向（非虚构 survival manual）——语料为小说工艺，非生存教程。
- 现代军事惊悚（无人机/卫星侦察级写实）——语料止于 1949，现代适用性 `NOT_PROVEN`。
- 童话/低龄冒险——边界反例卡（PG15072）只提供类型判据，不提供儿童文学工艺。
- 需要跨类时间叙事结构设计——见 C-05 接口说明（§7），本 Skill 只提供冒险语境的引用锚点。

## 3. 最短路径

1. **定目标物**（四选一，全篇不改）：物质宝藏 / 知识或信物 / 人 / 生存本身——M23 判据：正格必须保留"险途"，宝藏非必要项。
2. **定价值论位置**：囤积端（财富压倒生存）↔ 贬值端（生存压倒财富），角色沿轴移动——M01/references/01 §1。
3. **定反派类型**（六型择一为主）：魅力型 / 储蓄型 / 间谍型 / 表演型 / 天才型 / bully 型——M08/references/02 §1；反派 defeat 与类型强绑定。
4. **定组织结构**：海盗公司制度（≥2 项治理制度）/ 远征分工制 / 地下会三防——M05/M04/M22/references/03。
5. **定收束制式**：分派仪式 / 法理收束 / 名誉回环 / 谎言体面 / 三重揭秘 / 量刑空白——M21/references/06 §1。
6. **写完自查**：藏宝四问（谁藏→怎么藏→为何在那→怎么找到）、物证埋设-回收对账、时代口径三步剥离（M19）、headcraft-not-witchcraft 验收（一切超常可拆解至道具级）。

## 6. 输出合同

给用户的每条建议按固定四字段输出，不可只给结论：

```
定位：场景/章节 + 所用机制（复合规则 ID，如 M08/P318）
规则：条件性动作句（含 when / when_not）
风险：该规则在本稿的失效模式（引对应反例 R##）
出处：PG ID + 行号（或 卡·规则 ID）+ ≤15 词英文短引文
```
