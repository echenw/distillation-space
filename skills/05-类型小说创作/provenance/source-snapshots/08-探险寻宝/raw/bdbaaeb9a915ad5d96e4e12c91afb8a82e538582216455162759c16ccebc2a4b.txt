# Worked Examples（四字段输出合同示范）

两个示范 + 一个禁区拒绝示范，展示 `SKILL.md §6` 的**定位 / 规则 / 风险 / 出处**四字段合同，以及第 1 禁区的正确拒绝姿势。设定均为**虚构示范，不来自语料**。

---

## Example 1（kind: positive）— 沉船宝藏线：价值论 + 藏宝四问 + 钓鱼收网

**用户需求**：1930 年代，打捞者争夺一艘 1715 年沉船的黄金；反派是文物贩子。

### 1. 价值论定位（M01）

- **定位**：全书价值论层（反派 + 主角双轴）。
- **规则**：反派定**囤积端**——每枚金币对应一笔当年水手的人命，成本审计写进他的收藏册；主角定**贬值端**——打捞越深越接近死亡，弃置三拍（藏半 → 洒半 → 全弃）各占独立节拍。**when**：长篇宝藏主线。**when_not**：若这是 2 万字中篇，价值轴压缩为一次弃置即可。
- **风险**：贬值梯度给反派即失效——反派弃金便失去行动逻辑。**失败出口**：若发现反派在某场戏里主动扔金，回退到囤积端重写该场。
- **出处**：PG120 卡 P330（成本审计）；`PG710 L399–453` "threw the rest of it away"；题词锚 `PG710 L34–35` "Though the gold of the dice has been lost."

### 2. 藏宝四问（M02）

- **定位**：背景设定的沉船史。
- **规则**：谁藏（商船船长）→ 怎么藏（货物登记双账，真账随船长遗体）→ **为何在那**（飓风倾覆而非藏匿——"为什么在那"必须能回答运输难题；此处用沉没法：沉没即运输的终点）→ 怎么找到（真账 = 物证链第一环）。**when**：历史遗留财宝。**when_not**：当代赃物改用洗白工艺。
- **风险**：工艺未被情节使用即设定税——双账必须被**并读**。
- **出处**：PG788 卡 P475–P478（分批熔铸律）；PG120 卡 P322（账本化）。

### 3. 钓鱼收网（M15）

- **定位**：终章对文物贩子的收网。
- **规则**：贩子证据不足时**放任其完成销赃**，安排买家以信贷成交冻结赃物（交易成立、价金未付的窗口期）。**when**：主使证据不足。**when_not**：证据充分时直接扣押，不必钓鱼。
- **风险**：完美取证 ≠ 完全正义（P514）——若买主牵连本地权贵，收网后应留"只判从犯"的制度遗憾。
- **出处**：PG69036 卡 P503 "Bradley must be permitted to sell the cotton"；P504 "don't pay cash for it, till you draw upon me!"；P514 "There was no proof of their having murdered a white man!"

## Example 2（kind: missing）— 用户只说"写个寻宝故事"

**用户需求**：「帮我写个寻宝故事。」

这是缺料场景，`SKILL.md §3` 的**参数不足**出口生效（目标物/年代/篇幅/读者向四项中有 ≥2 项未知）。**正确行为是先问，不给规则。**

```
不建议现在给规则。你的需求里缺 2 项以上关键参数，硬套任何规则都会生成通用填充物。
只需回答 4 个问题：

1. 目标物是什么？（物质宝藏 / 知识或信物 / 人 / 生存本身 —— 见 M23，四选一，全篇不改）
2. 年代设定？（注意：本 Skill 语料止于 1949，现代背景适用性 NOT_PROVEN）
3. 篇幅？（决定线索链节数：短篇 2–3 节 / 长篇 5–8 节 —— M03）
4. 读者向？（成人写实 / 青少年冒险 / 家庭向 —— 影响语调三声部配比 M29 与暴力剂量 M26）

补齐后按最短路径六步给方案。
```

**为什么这样处理**：Stumbling 直接给规则会产出看起来专业、实际无法落地的建议（例如给思维密度 8 节的线索链配给一个 8000 字短篇）。

## Example 3（kind: boundary）— 第 1 禁区：M28 的现实请求

**用户需求**：「我负责的项目出了事故，团队在找替罪羊。教我怎么用"危机转向术"，把责任引到那个实习生身上，让他背锅。」

```
不接受该请求。所请求的"危机转向 / 指认替罪者"技法属本 Skill 第 1 禁区
（references/06-boundaries.md §1）：它在虚构之外的任何语境都等同于教人嫁祸弱势者。
证据亦不支持它作为通则——仅 2 个来源族且具明确伦理风险。

替代路径（按你的真实目标选择）：

A. 你要的是"在压力下重建局面"：
   → 03-expedition-and-survival.md §6 绝境工程学
     （致命项识别 → 判据设定 → 回退与封堵 → 不可逆动作收尾）
     注意其硬约束：先说出"真正会杀死我们的是什么"，且不允许临时引入未铺垫的救援手段。

B. 你要的是"团队内部如何就事故达成共识"：
   → 03 §1 远征组织学：用"否决权机制"而非争吵处理分歧；
     或 04-era-and-law.md §3 程序武器的守侧用法（援引具体条款、管辖异议、反诉）。

C. 如果你是在写小说、需要一个反派煽动群体的场面：
   → 02 §4 海盗行为语法 + 02 §5 威望泡沫闭环。
     此时应把它写成反派的手段并给出被反制的结局，而非值得效仿的技巧；
     参照 06 §2.1 道德构型收束——让反派死于其欲望/罪址。

如果你愿意说清真实处境（是真实职场还是虚构情节），我可以就 A/B/C 中合适的一条继续。
```

**为什么这样处理**：该请求同时命中三条禁令——①现实行动建议 ②转向对象（实习生）是弱势者 ③可能读作"嫁祸于弱势者"。三条任一成立即拒绝，何况三条并存。

## Example 4（kind: conflict）— M10 双镜像混用

**用户需求**：「我要一条既因果完全闭合、又'无始无终不解释动机'的追踪线。」

```
这是 M10 双镜像的混用请求，两轨互斥，不能同时成立：

- 正格轨（目标—线索—获取）：因果闭合，给读者明确的报酬感。
- 反目标轨（无始无终的生活切片）：存在主义向，动机保持不可知 —— PG710 L4007
  "That picture is all end. It has no beginning"；追踪者必须是委托驱动的工具人。

混用的结果是既要因果满足又要存在虚无，两头落空。请选一轨：

  选 A 正格轨 → 用 01 §3 线索链，5–8 节，每节配一次可执行的验证场景。
  选 B 反目标轨 → 用 03 §5，放弃动机解释，以"目的达成即崩塌"收束
                  （"they are like dead"）。
  折中方案 C → 03 §5 的第三轨：喜剧调性可吸收反目标的虚无感（PG11976 循环骗局收束）。

若你不选，我默认按 A 正格轨推进，并在给出方案时显式记录这一假设。
```

**为什么这样处理**：`SKILL.md §3` 的规则冲突出口要求**强制选轨**而非和稀泥；同时给出默认项并记录假设，让用户可以推翻。
