# Adventure & Treasure Craft（探险寻宝创作法）

面向小说作者与写作 Agent 的**条件性创作工艺库**。来自 1720–1949 英语探险寻宝 / 海盗 / 荒野生存正典及同期 pulp 共 28 本全文实读，按 20 个独立来源族融合裁决为 **32 条规则（M01–M32）**。

本 Skill **不是作品摘要，也不提供"必灵配方"**。每一条规则都带适用条件、反例、失败出口与可回读出处；条件不满足时，正确的行为是**换规则或明确退出**，而不是硬套。

## 0. 三条不可协商的总纪律

这三条先于一切具体规则执行。任何违反它们的产出，即使单条规则引用无误，也是不合格交付。

1. **时代口径三步剥离（M19）**——本语料年代跨 1720–1949，系统性携带殖民视角、种族本质化、奴隶制书写的平静语气与性别工具化。采纳本 Skill 任何规则时必须执行 `references/04-era-and-law.md §4` 的三步剥离：**语言剥离（种族称谓与本质化形容词不入正文）→ 结构保留（机制内核改写为个体/组织的专业化局限）→ 视角转换（不拟写他者声音，以角色地位而非种族标签定义人物）**。原 R47/R61/R65/R67/R70/R72/R74/R77/R79/R83/R85 十一条已全部裁决为 REJECT-as-rule，仅作《历史包袱说明书》存档。
2. **第 1 禁区（M28 危机转向术）**——指认替罪者转移即刻暴力的技法，**仅限虚构对抗场景**，且禁止写入通用技巧清单。详见 `references/06-boundaries.md §1`。命中该禁区的请求必须拒绝并提供替代路径。
3. **1870s 数据须标年代**——PG9150 中的象牙年出口 >200 吨、Sheffield 刀剪业耗 382,500 磅、对牙均重 28 磅、Kazonndé 有 165 磅者等数字是**1870 年代的当代知识**，引用时必须写明年代，不得作为现状陈述（`PG9150` L9304–9314）。满两年的当代知识不得写成调查报告口吻。

## 1. 何时使用（正触发）

- 写或改写**探险 / 寻宝 / 海盗 / 沉船打捞 / 失落文明 / 荒野求生 / 极地·沙漠历险 / pulp 太空冒险**题材。
- 需要设计**宝藏钩子**：藏宝工艺、线索链、藏宝与「为什么在那」的运输解答。
- 需要**远征队/掠夺组织**的组织学：分工分权、否决权、断退路、海盗治理制度、地下会三防。
- 需要**反派工艺**：六型反派选型、暴露机制、揭穿戏、终局的道德构型收束。
- 需要**绝境与灾难**：生存极境五律、濒死三部曲、绝境工程学四拍、海难/台风/塌方书写。
- 需要**法律与取证**：多法域设定、程序攻防、钓鱼取证、信贷冻结、收网链。
- 需要**谜题与未知**：推理三型、约束三链、非人对手的科学破译、可信度证据装置。
- 需要**收束**：八种收束制式的选型与其主题陈述含义。
- 需要**边界自检**：判断一个稿子到底是不是正格探险寻宝、有没有踩成规俗套。

## 2. 负触发：不要用本 Skill

| 用户实际要的是 | 为什么不用 | 建议去向 |
|---|---|---|
| **言情冒险**（以感情线为纲） | 本 Skill 的婚姻外壳只作潜入手段（P565），不提供言情工艺 | 言情专项 Skill |
| **非虚构求生手册** | 语料是小说工艺，不是 survival 教程；工艺优先于事实 | 求生手册 / 纪实写作 Skill |
| **现代军事惊悚**（无人机、卫星侦察级写实） | 语料止于 1949，现代适用性 `NOT_PROVEN` | 现代军事 / 惊悚 Skill |
| **童话 / 低龄冒险** | 边界反例（PG15072）只提供类型判据，不提供儿童文学工艺 | 儿童文学 Skill |
| **跨类时间叙事结构设计** | 本 Skill 只提供冒险语境的引用锚点，结构设计归 C-05 | C-05 非线性叙事 |
| **现实职场/人际的"危机公关"建议** | 第 1 禁区；M28 及相关技法不得出虚构场景 | 见 `06-boundaries.md §1` 替代路径 |

## 3. 最短路径（六步，含失败出口）

```
Step 1  类型检定   → 宝藏/险途/竞争 三要素……缺二即非正格，转 §2 负触发表退出
Step 2  定目标物   → 物质宝藏 / 知识信物 / 人 / 生存本身（四选一，全篇不改）
Step 3  定价值轴   → 囤积端 ↔ 贬值端（含财富反噬 / 祭坛态两种变体）
Step 4  定反派    → 六型择一为主型（可复合两型须定主）
Step 5  定组织    → 海盗治理 / 远征分工 / 地下会三防（按 Stage 选一套）
Step 6  定收束    → 按主线价值选制式 + 反派道德构型收束（全书限 1–2 次）
---- 每次给出建议前必过 ----
Gate A  时代口径三步剥离（M19）
Gate B  第 1 禁区扫描（M28 相关）
Gate C  1870s 数据是否标年代
Gate D  奇观是否已配可验证据装置 + headcraft-not-witchcraft 验收
```

**失败出口**：任一步无法确定时，**不要猜**。按下表处理：

| 缺料类型 | 判据 | 出口动作 |
|---|---|---|
| **类型错配** | Step 1 三要素缺二以上 | 停止给规则，出具"非正格判定 + 缺失要素清单"，建议改去对应题材 Skill |
| **参数不足** | 目标物/年代/篇幅/读者向中有 ≥2 项未知 | 只回 4 个最小必要提问，不给任何规则，避免生成通用填充建议 |
| **规则冲突** | 用户要求同时成立互斥规则（如正格因果闭合 + 反目标无终） | 显式说明冲突为 M10 双镜像冲突，**强制选轨**；用户不选则默认正格轨并记录该假设 |
