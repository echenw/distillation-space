# 模板：探险设计器（Expedition Designer）

> 每行独立可填（ED-01..ED-14）。

| ID | 字段 | 填写内容 |
|---|---|---|
| ED-01 | 子类型（海事/寻宝/失落文明/丛林/间谍/科幻） | |
| ED-02 | 开局类型（你-代入/落魄者聚齐/普通人入局/死刑犯换命/报道缺席） | |
| ED-03 | 主角（普通人/伪装大师/死刑犯/水手/少年） | |
| ED-04 | 探险目标（宝藏/逃出/营救/真相/归乡） | |
| ED-05 | 障碍类型（自然环境/人类敌人/超自然/科技失控） | |
| ED-06 | 信物/母题（三现计划） | |
| ED-07 | 路线（起-经-终；至少 3 个地理节点） | |
| ED-08 | 团队结构（独行/双人/团队；各自技能） | |
| ED-09 | 道德代价（暴力/背叛/牺牲） | |
| ED-10 | 结局类型（归乡/未归/死亡/回收/反讽收尾） | |
| ED-11 | 框架叙事（有/无；框架者身份） | |
| ED-12 | 殖民/帝国视角重构点 | |
| ED-13 | 失效出口 | |
| ED-14 | 读者辅助（地图/词汇表/航海术语表） | |
