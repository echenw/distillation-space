# 探险寻宝（批次-03）· 路由 → 证据 → 路线 → 正当性 → 结算

30 部公版来源（PG10736…PG79677）是**文学材料，不是现代地理、海况、民族与文化遗产的专业资料**。
本批是**工作量切分**（`batch_is_workload_partition_not_new_semantic_genre`），30 部里既有海盗寻宝、
也有太空冒险、异域间谍、北方荒野短篇和**完全没有寻宝**的传奇。**第一步永远是路由**，路由错了后面全错。

## 触发

- 策划/重写：寻宝目标、线索与线索公平性、探险路线与补给、危险与代价、结局结算。
- 诊断：旧稿里"宝藏来得太突然""路线说不通""谁都可以拿到""结尾没收"。
- 选型：海图/日志/信物/仪表/制度，哪一种当本书的证据系统。

## 负触发（明确不做，转给别的 Skill 或直接说明）

- 真实越野、潜水、航海实操路线与装备清单；真实文物发掘、物权与文化遗产法律意见。
- 医学、法律、金融的专业结论（本批里的"彩票开奖制度"只是叙事机制，不是法律意见）。
- 纯语言润色、纯人物对白打磨（不构成本 Skill 的判断对象）。
- 需要把 30 部里的殖民时代叙述当作客观事实引用时：**必须标注为角色认知**，不做价值判断。

## 输入（缺失就写 UNKNOWN，不要替用户补）

1. 子类型：海盗/海上寻宝 · 太空科幻 · 异域探索与间谍 · 荒野短篇 · 非寻宝传奇 · 其他。
2. 目标物：是什么、谁想要、为什么现在能找、失败损失什么。
3. 已知线索与其**持有链**（谁发现的、怎么传下来的、有第二来源吗）。
4. 世界规则：年代/技术上限/超自然是否属于正典/**作品是否自陈为讽刺**。
5. 人物能力与装备清单、时间与天气是否影响结果。
6. 授权范围：可改稿，还是只诊断。
7. 标记口径：**F**（原文或用户明确设定）/ **H**（待证推断）/ **P**（计划动作），三者不许混写。

## 执行步骤

**第 1 步｜路由（不可跳过）。** 按 [references/subtype-routing.md](references/subtype-routing.md)
判定子类型并选定证据系统。这一步会直接否决一批规则（例如"失落高科技解释宝藏"只在科幻子类有效）。

**第 2 步｜正当性（本批出现频率最高的维度，先看这个再看路线）。** 回答四个问题：
凭什么认为是你的？凭什么可以拿？谁被排除在外？撤退或绕行的代价是什么？
依据与反例见 [references/rules.md](references/rules.md) 的 N3 与 RE-03。

**第 3 步｜线索与证据。** 按选定的证据系统列出：发现者、可信度、呈现时间、可能误读、
下一验证动作。**物证在本批经常被改写**（船名被涂改、货物标签伪造、玉坠有副本）→ 必须留复核动作。

**第 4 步｜路线与资源。** 只计对剧情有作用的资源；写明每段起点/终点、交通工具、环境限制、
补给数字。不能把"实际高危指南"当虚构知识，也不能用奇迹消除先前写明的危险。

**第 5 步｜结算。** 结算 **不等于** 婚礼、返乡或封赏。允许开放式结尾，但已建立的主要危险、
资源与关系必须有回应。参考 [references/rules.md](references/rules.md) 的 N6 / RE-15。

**第 6 步｜输出诊断卡或设计卡。** 模板见
[templates/adventure-diagnosis.md](templates/adventure-diagnosis.md)；正向示例见
[examples/worked-example.md](examples/worked-example.md)。

## 规则速查（详细裁决、依据行号在 references/rules.md）

| 想做的事 | 该用的规则 | 一句话 |
|---|---|---|
| 决定开局 | RE-01 / RE-06 | 第二人称与海滩开局都不是必要条件；本批 30 部无一使用第二人称开局 |
| 写"人不见了" | RE-02 | 悬念来自信息分批到达与制度时序，不是"失踪"本身 |
| 用失落的科技解释宝藏 | RE-04 / RE-10 | 只在科幻子类成立；且必须先确认它不是讽刺 |
| 让某个道具反复出现 | RE-05 | 废止"必须三次"；只在确有因果作用时安排 |
| 章题怎么写 | RE-07 | 章题是风格选择，与信息节制无必然关系 |
| 写伪装/潜行 | RE-08 | 高频有效，但**必须**写入口、工具、他人已知信息、暴露代价、失败出口 |
| 让素人当主角 | RE-09 | 可以，但要有可观察的动机、学习渠道与技能成长 |
| 用祖传信物/海图当线索 | RE-11 / RE-17 | 见到 ≠ 取得权利；记录型物证既是最可靠的工具也是最典型的误导体 |
| 写歌谣/鼓声 | RE-12 / RE-18 | 多承担氛围、身份、凶兆；只有当它可被验证时才当线索 |
| 框架叙述者要不要死 | RE-14 | 废止"必须死"；本批三个存活的框架叙述者，其局限正是可信度来源 |
| 让主角不说话 | RE-16 | 废止"沉默更有力"；语言能改变他人决策时，沉默是缺动作 |

## 冲突与缺料出口（必须给用户条件分支，不许替他选）

- **两张地图/两个来源互斥**（本批 C1/C2）：输出最小冲突集合 + 两条条件路线 + 哪一段必须由作者选择；
  不得宣布"其中一个是真的"。
- **关键材料从未提供**：可以提出设计方案，**禁止**标注伪造的原文坐标或声称"已验证地理可达"。
- **只有审稿授权**：只交诊断卡，不改写正文。
- **跨子类搬规则**：明确拒绝并说明搬到本书会变成什么（通常是 deus ex machina）。
- **殖民/民族题材素材**：标角色认知、伦理与权利疑点，不用旧时代文本替真实族群做价值判断。

## 输出合同

1. 子类型路由结论 + 证据系统选择（1 段）。
2. 正当性四问的答案（4 条，标注 F/H/P）。
3. 线索表（发现者 / 可信度 / 呈现时间 / 可能误读 / 下一验证动作）。
4. 路线与资源表（段起止 / 工具 / 限制 / 代价）。
5. 结算清单（哪些危险、资源、关系必须被回应）。
6. 冲突/缺料分支（有几条写几条；没有就写"无"）。
7. 用到的规则编号 + 来源 PG 与行号（可回源）。

## 失败出口

- 输入不足以判定子类型 → **停在第 1 步**，列出缺什么，不给后续建议。
- 用户坚持要"无条件突然找到宝藏" → 给出该写法在本批的反例（PG13527 全书没有寻宝物件，
  悬念靠制度时序；PG79635 卷首声明是讽刺），并说明代价，不静默照做。
- 需要现实专业证据 → 明确移交，不硬答。
