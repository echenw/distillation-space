````text
# 示例：一次完整走查（合成快照，不是已执行的宿主运行记录）

> 用户问题（合成）："我写了一部 17 世纪加勒比寻宝小说的开头——主角在酒馆里从一名老水手手里
> 买到一封瓶中信，信里说财宝埋在尤卡坦某湾以南两里格。第二天他就带着三个人出发了。
> 请审一下有什么问题。"

## 第 1 步｜路由

- 目标物是埋藏财宝、主要交通是船 → **A 类：海盗 / 海上·荒岛寻宝**。
- 证据系统：**海图 + 航海日志 + 信物/船名 + 口供**。
- 路由依据：PG74835 L293-304（一瓶海盗信件指示财宝位置，本批最贴近的同型开场）；
  PG65385 L4442-4474（祖传海图）。
- 直接失效的规则：RE-04（失落高科技解释宝藏）在 A 类不成立。

## 第 2 步｜正当性四问（本批最该先看的一步）

| 问题 | 现状 | 判定 |
|---|---|---|
| 凭什么认为是你的？ | 只有一封来历不明的瓶中信 | **缺**。参照 PG74835 L2348-2353：法外状态下靠"私人信用"而非法律；你得先定"这封信凭什么算数" |
| 凭什么可以拿？ | 未写 | **缺**。参照 PG1965 L11595-11648：寻宝的正当性会被当庭审判，不能默认"找到就有" |
| 谁被排除在外？ | 未写 | **缺**。老水手的同伙、原主、当地政权都可能是排除对象 |
| 撤退代价？ | 未写 | **缺**。参照 PG29291 L3517-3601：真正可信的路线设计里包含"翻扣船体遮阳、靠海图自救"这类撤退/生存动作 |

## 第 3 步｜线索与证据（RE-11 / RE-17 / N4）

- 瓶中信是**单一来源**，且卖家是有利害关系的老水手 → 按 RE-11，必须补：
  信的保存路径（怎么到瓶子里的）、谁解读的、可否复核。
- 按 **N4**，物证会被改写：PG74835 L5581-5593 里得手后船名被涂改；PG61855 L139-154 里
  货物标签是伪造的。→ 建议给信加一个可复核的细节（纸张/印鉴/第二位知情者），并预留被改写的可能。
- 按 **RE-17 / C2**：这份信**没有第二可复核来源** → 只能当**角色信念**，不能当客观事实。
  若作者想让它可信，必须另设验证动作。

## 第 4 步｜路线与资源

- "第二天就带着三个人出发"缺补给与时间账。参照 PG1965 L2412-2416（面包/水桶/罗盘/象限仪/
  海图/沙漏/测程绳）与 PG3294 L9517-9520（五十四个桨位、二百五十名奴隶）——
  本批可信的远航都把**人力与物资写成数字**。三个人是什么角色、带什么、坏天气怎么办，必须给。
- 不能让顺风一路送到；PG164 L212-231 是"海图上没有的礁石"式的反例。

## 第 5 步｜结算

- 目前没有结尾，但要先定口径：结算 ≠ 婚礼/返乡。参照 PG2429 L2400-2477（婚礼在船底甲板、
  棺材就在旁边遮荫）与 PG74835 L6000-6016（叙述者自认非英雄）。
- 已建立的主要危险、资源、关系都要有回应（RE-15）。

## 第 6 步｜分支

- 分支 1（线索独占）：参照 PG2424 L3200-3238"见过此宝的只有一人" → 悬念来自唯一的知情者可信吗。
  代价：读者无法参与推理，必须给旁证。
- 分支 2（知识分散）：参照 PG74835 L2612-2613"还有三个人活着知道宝藏藏在哪" → 悬念来自争夺。
  代价：要管理多组动机与信息差。
- **必须由作者选**，Skill 不替他决定（冲突 C1）。

## 输出（给用户的答复要点）

1. 路由：A 类，证据系统＝海图+日志+口供。
2. 正当性四问**全部缺失** —— 这是本稿最大的问题，比路线更优先。
3. 瓶中信缺第二可复核来源 → 按 RE-17/C2 只能当角色信念。
4. 三个人+第二天出发 → 补人力与物资数字（PG1965 L2412-2416 式）。
5. 结算口径先定，不要用婚礼封口。
6. 引用规则：RE-11、RE-17、N3、N4、C1、C2；来源 PG74835 / PG65385 / PG1965 / PG2424 / PG164 / PG2429。

````

````text
# 保留的分歧、例外与未证明项

本批内部**无法统一**的观点在此原样保留。**不许为了给作者一个"确定答案"而伪造共识**。
每条都给出条件分支，让作者按自己的目标选，并说明各自的代价。

## C1 独占线索 vs 分散知识

- **F（独占）**：PG2424 L3200-3238 —— 主角身上带着一个秘密，"见过此宝的只有一人"，
  多少亡命之徒为它死于瘟疫、战阵、船难、饥馑、印第安酷刑与西班牙地牢。
- **F（分散）**：PG74835 L2612-2613 —— "There are three persons alive who know where that treasure is hid."
- **H**：两者都能成立，区别在于要写**揭示**还是**争夺**。
- **P（分支）**：
  - 选**独占** → 悬念来自"唯一的知情者是否可信/是否会死"；代价是读者无法参与推理，
    公平性弱，必须给可复核的旁证。
  - 选**分散** → 悬念来自"谁先到、谁会背刺"；代价是需要管理多组动机与信息差。
  - **不得**在同一部作品里既宣称唯一知情、又让第三方凭空知道位置。

## C2 海图/日志：可信工具还是误导源

- **F（可信）**：PG29291 L3517-3601 —— 用海图算出自己在 Loango 外海、距 St. Thomas 约七百里，据此自救。
- **F（误导）**：PG164 L212-231 —— 撞上**海图上没有的**礁石；
  PG65385 L4442-4474 —— Richard 判断海图确为水手手笔但"不足以尽信"。
- **H**：同一类物证在本批既是推进工具也是误导体，二者不矛盾。
- **P（条件判断）**：问一句"这张图/这份日志有没有第二可复核来源？"
  - 有 → 可当可靠工具（PG29291）。
  - 无 → 只能当**角色信念**，必须另设验证动作，否则揭示时会变成作者硬给答案。

## C3 歌谣/声音：线索还是凶兆

- **F（凶兆）**：PG73917 L2632-2675 岸上传来歌声，随后 Francis 听见兄长的死讯；
  PG34476 L3992-4033 起锚歌声中断成为警讯。
- **F（信息系统）**：PG47113 L7821-7847 鼓点被听成 Morse 的 dot and dash 并译出 Custom tune；
  PG79677 L557-560 鼓声是丛林部族的电报系统，白人一进 Kiridu 地界就被盯上。
- **P（分支）**：判断标准是"该声音在本书里**能否被验证**"。
  - 能（有译码者、有对照、可复现）→ 可作线索。
  - 不能 → 只作氛围/身份/凶兆，不得承担证据链。

## C4 讽刺作品的证据等级（本批最容易被误读的一条）

- **F**：PG79635《Space Rays》卷首 Gernsback 引言明说 Campbell 此篇是在**滑稽模仿**
  那些把科学可信度当无物、从帽子里变出各种射线的作者。
- **F**：同属科幻子类的 PG64052《Tonight the Stars Revolt!》的"黑池五万年前远古智慧"
  却是**世界观内给定的正典**。
- **P**：**不能因为同属一个子类就给同等证据等级**。把"作品是否自陈为讽刺"作为
  采用超自然/科技解释前的**前置检查**（与 RE-04 / RE-10 联动）。

## 例外：本批明确"不适用"的来源

- PG10736《Children of the Frost》、PG2429《Lost Face》是**北方荒野短篇集**，
  被分到本批是工作量划分的结果，**不构成**"探险寻宝包含荒野求生"的证据。
- PG13527《Ticket No. "9672"》全书**没有寻宝物件**，它是本批最重要的反例：
  证明"探险类叙事可以不靠藏宝点"（悬念来自开奖制度与信息延迟）。
````

````text
## 为什么必须先路由

- **F**：任务清单对本任务写明 `batch_is_workload_partition_not_new_semantic_genre: true`；

3. 目标是**穿越、追踪、送达、取证、赶上某个时间** → C 或 E；有明确藏宝点才归 A。
4. 是**短篇集**且主线是生存/部族/荒野 → D。
````
