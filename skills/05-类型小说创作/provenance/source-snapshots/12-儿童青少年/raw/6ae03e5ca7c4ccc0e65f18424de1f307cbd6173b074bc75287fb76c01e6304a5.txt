# 本批范围、硬边界、冲突保留与失败出口

## 1. 这批材料是什么

B-05-B02 的 29 本英语 / 英译 / 改编公版儿童文学，横跨童话、成长小说、动物叙事、玩具幻想、节日汇编、讲述方法书与作者对自己孩子的真实记录。
年代、读者、译者与文化环境差异极大。**不能把早期教育观点当作今天的年龄分级、心理健康或道德标准**。

## 3. 必须保留、不许强行统一的冲突

1. **教育手段**：PG3655 主张惊吓；PG18153 L1988-2003 用"勉强 vs 自愿"作判据；PG113 用环境行动替代训诫。→ 标立场，**不默认任一种**。
2. **暴力与死亡尺度**：PG23765 把杀戮写成玩笑；PG910 L353 "They jes' swallowed 'm alive" 写实；PG11162 把爆炸写成笑话；PG359 L7468-7469 小矮人咬下孩子的头。→ 只强制"标注 + 后果 + 可退出"，**不给统一阈值**。
3. **动物是道德载体还是行为主体**：PG7856 L75 按物种分配道德职责 vs PG910 L7468-7480 情境驱动 vs PG24592 L370 家族名誉约束。→ 由幻想契约自行声明。
4. **结局形态**：PG74 有 `CONCLUSION`；PG359 以书目与版权声明收尾；PG479 以成人自我改造收束。→ 这正是 RC-07 只能 REJECT、不能换成另一种强制的原因。

## 4. 不适用的来源

- **PG910 White Fang**：动物主角的成人向自然主义叙事，对"儿童视角 / 朗读复杂度 / 年龄适配"**不适用**；只用于危险描写与拟人边界。
- **PG58107 For the Story Teller**：L204-206 讨论"心智使陌生观念成为己有"的非自发过程——这是**成人讲述者的方法论**，不是儿童叙事规则；只用于 RC-11 的"教学提示 / 虚构内容分区"。

## 5. 情节分歧与安全出口

- **无读者年龄** → 给"可朗读版本"与"自主阅读版本"两套处理，标 UNKNOWN，不硬判"适合 X 岁"。
- **家长要求把儿童主角写成被欺凌后必须宽恕** → 指出伦理与角色目标冲突，给求助与建立边界的替代剧情，不以道德化剥夺儿童主体性。
- **历史故事包含危险行为** → 呈现风险、求助与成人责任，不写可模仿的步骤。
- **缺原稿或无改写授权** → 不虚构"第几段有问题"，不直接改稿。
- **用户要求复刻种族化命名 / 殖民表述 / 买卖儿童情节** → 明确拒绝原样复刻，给"保留结构、替换表述"的替代方案。
