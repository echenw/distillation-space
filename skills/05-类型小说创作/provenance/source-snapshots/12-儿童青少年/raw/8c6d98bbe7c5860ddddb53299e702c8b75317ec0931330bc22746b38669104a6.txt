# 儿童青少年向虚构 · 读者带先行的结构、因果与尊严

29 部 PG 公版来源（1870–1920）提供的是**上一批作者实际怎么写**的观察样本，不是现代出版规范。其中只有一本（PG474《How to Tell Stories to Children》）是方法书，其余 28 部是样本；**任何单部作品的有效桥段都不得升级为"所有作品必须这样"**（见 [conflicts-and-exclusions.md](references/conflicts-and-exclusions.md) R13）。本 Skill 不提供真实儿童测试、出版合规、版权或插画构图意见。

## 触发与排除

**适用**：策划或修订绘本（约 3–8 岁）、低中年级章节书、YA 前期作品；诊断"读不下去"、"重复得发木"、"说教味重"、"结局空降力量"、"救助对象尊严被踩"；把长篇、民间故事或经典材料改编成可朗读稿。

**不适用（显式拒答并转介）**：

- 真实出版的年龄分级、课程大纲、分级读物词汇控制 → 需教育专业规范；本 Skill 只有 1870–1920 的证据。
- 插图构图与图文配比 → 文本层只有 `[Illustration:]` 占位，**NOT_PROVEN**（R16）。
- 版权与许可状态 → 依所在法域自行确认；本 Skill 只附 PG 号、行号与 SHA，不携带原文。
- 纯成人文学、纯科普或纯宣教书核验 → 不在本 Skill 的方法论范围内。

## 输入预检（必须先做）

向用户索取；缺失写 `UNKNOWN`，**不得替用户补全**：

1. **读者年龄带**：A 绘本（3–8 岁）／ B 中年级 ／ C YA 前期。全套规则按此切换（依据 PG24545 L23-26 的自述年龄句；PG474 L144-262 的班级分档）。
2. 预计篇幅与是否用于**朗读**（朗读会触发改编规则 R8）。
3. 世界与设定信息、人物清单、必须保留的场景。
4. 用户已定下的**价值目标**（是否要明显传达某个品格主题）—— 决定走 C1 哪一支。
5. 授权范围：**只诊断**还是**可改写到正文**。

所有条目一律标记 **F**（来源或用户明确给出）／ **H**（推断）／ **P**（将执行的动作），输出中不得混用。

### 执行步骤

1. **判年龄带并锁规则**。A/B/C 三条带的重复、因果、结局规则不同（见 [age-band-rules.md](references/age-band-rules.md)）。年龄未知则输出分支，不猜。
2. **跑四问生成诊断卡**。前三条取自 PG474 L1980-1983：故事是什么？哪些事件是链上必需的？多少文字只是描写？第四条是本轮加的：**这条规则来自几部书？** 只有一部则不得升级为通用规则。
3. **检查四条硬规则**（违反必改，不是建议）：
   - **R9 不得用居高临下的甜嗓**（PG474 L2517-2527）。
   - **R5 危机只能聚焦已有习惯**（PG16540 L6675-6676）。
   - **R6 恐惧必须有出口**（PG16540 L4698-4731）。
   - **R13 单书桥段不得升级为通用规则**（PG17824、PG15575、PG16052 互为反例）。
4. **处理教训**。默认走"由后果与选择承载"（PG474 L492-494）。只有当用户明确要品格读本时才点破，且只用一句、不带诱导语气（见 C1）。
5. **交付**。按诊断卡给 F/H/P 三列、给出 PG 号与行号级证据、把未解决冲突列为条件分支。

## 冲突与缺料出口（原样输出，不得自行化解）

- **C1 娱乐优先 vs 教训优先**（PG474 L492-494 对 PG12591 L12-13 与 PG16073 体例）：**不统一**。输出两条分支并各自写出代价。
- **C2 完美闭合 vs 拒绝改造**（PG1874 对 PG17125 L4296）：不统一；唯一硬条件是"闭合不能靠忽然出现的新力量"。
- **C3 惩罚型因果 vs 尊严型因果**（PG14958 L1898-1914 对 PG1874 L4917、L4998）：按年龄带选；不得在同一部里混用而不说明。
- **C4 公版源中的种族、殖民与宣教语汇**：一律记录为"该文献在其时代的写法"，**不提炼为规则**；用户要求保留时须同时给出改写建议与风险说明。
- 只拿到诊断授权 → 只交诊断卡，不改正文。
- 用户要的效果在本来源集内没有证据（例如"提升阅读理解"）→ 标 NOT_PROVEN，并说明证据只到 PG474 的单方自述（L3027-3046）。

## 输出与许可

输出必须包含：**读者带判定（或 UNKNOWN 分支）**、**F/H/P 三列**、**每条建议的 PG 号与行号**、**冲突清单**、以及**尚未解决的开放项**。
