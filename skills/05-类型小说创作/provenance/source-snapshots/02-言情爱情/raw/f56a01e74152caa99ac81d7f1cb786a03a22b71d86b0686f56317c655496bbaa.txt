# examples — 合成示例（非真实任务）

> **声明**：以下四个示例均为作者按本 Skill 规则编写的**合成演练**，不对应任何真实作者委托、真实稿件或真实读者反馈。效果未经验证，`NOT_PROVEN`。

## 示例 1：当代都市（R01 拾物型 + R04 物件信号 + R05 职业延迟 + R14 结局）

**设定**：女主是夜班护士，男主是急救车司机。两人在医院后门相遇。

- 相遇（R01 拾物型）：她的工牌被风吹落，他捡起来，念错她的名字，她纠正一句就走。不给姓名以外的信息。
- 信号（R04）：他把工牌挂绳换成一条更结实的，说"下次别再掉了"。此后每次交接班，挂绳的颜色代表他当班/不当班。
- 延迟（R05）：他被调去另一个区三个月，调令有明确日期。她数着挂绳的颜色等。
- 结局（R14）：阻力可协商（排班、距离），选择"接受代价"→ 结合；代价写明：她放弃了调到日班的申请。

**对照锚点**：PG77271 L780-802（拾物不通名）、PG1608 L3003（物件状态=时间）、PG77271 L1935-1937（六个月期限）。

## 示例 2：民国背景（R06 数字 + R07 家族 + R13 契约）

**设定**：女主是绸缎庄独女，男主是洋行买办。

- 数字（R06）：舅父在席间报出"嫁妆三万银元"，男主的筷子停了一下——只有女主看见。
- 家族（R07）：舅父的资源是"介绍他进总商会"，条件是"娶我外甥女"；男主拒绝，代价是失去保荐。
- 契约（R13）：签约日，律师读出条款：铺面归女方，债务归男方；舅父当场说"这不合规矩"。
- 结局（R14）：阻力可协商，但代价是男主与家族决裂 → 婚配，末章写他失去的姓氏。

**对照锚点**：PG1437 L1156-1161（报数改态度）、PG77271 L1013-1020（资源换婚约）、PG1556 L2957（签约日才发现后果）。

## 示例 3：架空古代（R08 自述不配 + R10 嫉妒升级 + R12 牺牲 + R14 分离）

**设定**：女主是获罪官员之女，男主是即将袭爵的世子。

- 自述不配（R08）：她在最亲近的一夜说："你若娶我，你母亲的诰命会被收回。"——后文部分成真。
- 嫉妒升级（R10）：一级，他写信说"你我门第不同，何必再误"；二级，他在宴上当着众人称她为"罪眷"；三级，她连夜出城，不留话。
- 牺牲（R12）：她对外承认自己是细作，换取他家不被牵连；只有读者知道她在说谎。
- 结局（R14）：阻力不可协商（罪名），选择退出 → 终身分离；末章用见证人（老仆）交出她的信。

**对照锚点**：PG1608 L2739-2745（自陈后果）、L7392-7393（降格羞辱）、L7650（让他恨我）、L8015-8016（见证人接笔）。

## 示例 4：小城医馆（R03 三级信息差 + R13 继承 + R16 职业尊严）

**设定**：女主是镇卫生院医生，男主是回镇处理祖宅的律师。女主不知道自己是被收养的，生父留下一笔信托。

- 信息差（R03）：读者先知道信托存在；男主受委托查证，知道一半；女主最后知道。每级揭示都改变一次两人的关系——读者看悬念，男主看责任，女主看自己是谁。
- 继承（R13）：信托条款要求"她必须在镇上执业满三年"，否则财产归远亲。她一度想走，最后选择留下，但不是为了钱。
- 职业尊严（R16）：她拒绝男主"我养你"的提议，要求把诊所写进婚前协议；男主接受，但要求她每周留一天给他。
- 结局（R14）：两人结婚，诊所合并；末章写她第一次用信托的钱买了一台二手 B 超，而不是婚纱。

**对照锚点**：PG3166 L823-985（读者知/女主不知）、L15589-15639（男主知后仍选择）、L23796-23803（女主最后知）；PG1028 L7873-7930（婚前提出独立条件）。

## 使用说明

- 四个示例分别演示"轻阻力—中阻力—不可协商阻力—制度/职业型"四种配置；写自己的故事时先选阻力层级，再挑规则。
- 示例中的金额、职业、罪名、信托条款均为虚构，不对应任何真实制度细节；制度准确性请另查史料（本 Skill 不提供）。
- 每个示例只演示 3–4 条规则，不构成完整大纲；完整结构请按 `references/r2-beats-and-delay.md` 的十拍表自行扩展。
