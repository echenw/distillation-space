# 示例 · 两个完整走法（虚构设定，非任何 PG 小说情节）

## 示例 A（保留）· 婚姻与土地申诉不能互相替代

**DESIGN_EXAMPLE，完全虚构。** 背景为作者设定的架空沿海城，并非任何 PG 小说实际情节。

输入：A 家族经营码头，B 研究港口土地登记。A 喜欢 B，但 A 的监护人说"只要 B 肯结婚，我就撤回对 B 的土地投诉"。B 担心失业，暂时拒绝婚事。A 只收到监护人转述"B 说不愿公开宣布永不结婚"。

1. **R1/R4 信息判断**：只有 A 依据二手传话产生"也许被接受"信念；B 并未表示愿意。不能硬设两人对称误会，也不能以"B 没说绝不"作为接受证据。
2. **R7 权利边界**：土地申诉的合法性、受损渔民权益与 A/B 恋爱是三件事；婚姻不能自动处分渔民利益。应让 B 独立处理登记证据，A 明确不干预其调查。
3. **R2/R3 操作分支**：若 A 拿到原始登记页，先确认权利人、版本，再选择依法提供资料给 B 或权利代表。A 不通过强制长情书要求换承诺；B 更信任 A 也可能仍不接受恋爱。
4. **R5/R6 结局**：A 公开拒绝家族以婚姻换争端的条件，承担因此失去职位的代价；B 可以选择恋爱、暂缓或分别。三种都能完成成长线。
5. **回归**：检查 B 的土地维权是否因新版浪漫戏被静默取消；经济强迫未解除时婚约是否被误标自愿；A 的信息获取时间是否早于登记证据出现。

## 示例 B（本轮新增）· 当争议受理方不中立：把"澄清"换成"让有权的人亲耳听到"

**DESIGN_EXAMPLE，完全虚构**，但机制取自本轮实读的 PG3321《Children of the Whirlwind》（L1–11484）与本轮台账可对的行号。背景改为架空工业城，不复制原书人物与情节。

输入：男主 C 被城内稽查队以一桩伤人案通缉，同时被旧同伙认定为"告密者"。女主 D 正参与一个针对富家子 E 的婚骗；C 想阻止 D，但稽查队长曾当面要求 C 当线人并威胁构陷。D 以为 C 就是告密者。

按 SKILL.md §5 的门走：

| 门 | 判定 | 依据（PG3321） |
|---|---|---|
| G0 误读来源 | **被制造并维持**：标签由第三方贴出（L2431-2458），且递话者本人才是真正的线人（L7611-7630） | 先拆制造机制 |
| G1 受理方是否中立 | **不中立**：稽查队提出交易并威胁构陷（L2246-2259、L2298-2303），事后还能当众否认默契（L11036-11042） | 文书路线失效 |
| G2 层级 | 个人层（C/D 关系）+ 制度层（稽查队/旧同伙）分层记账 | 两表分开 |
| G3 成长 | 单侧起步：先改 C 的信息与选择，不替 D 造缺陷 | 不镜像化 |
| G4 退出权 | D 有出口但缺接收端：她的坦白被 E 主动截断（L7002-7004） | 先补接收端 |

执行动作（对应 §6 的 7 步）：

1. **拆制造机制**：安排让真正的递话者在可被听见的场合自述实绩（对应 L10292-10371 的自述结构），而不是让 C 去申辩。
2. **换载体**：不写"澄清信"（本场景中信件只会被用来误导，L3367-3398）；改为让稽查队长与旧同伙代表**在同一空间亲耳听到**（L9869-9872、L9919-9931）。
3. **转变由事件承担**：让 D 被她正在算计的人坦率接待（L6023-6033），或让她亲眼见到被她伤害的人的反应（L8788-8790、L8886-8911），而不是写一段"她重读旧信终于明白"。
4. **代价账**：C 明确否决报复，并把目标改成"尽量归还受害者被夺走的东西"（L8595-8612）；同时为"让关键人物旁听"写下第三方代价与失控出口——若失控，提前警告相关人（L5549-5552、L6323-6325）。
5. **告知四项判断**：若涉及 D 的身世/身份事实，先写 `归属/授权/知情权/安全风险`；书中三种处理（永不告知 / 撤销不告知 / 当事人要求不告知）都可成立，本 Skill 不替作者选（L5951-5983、L8407-8409、L8962-8969）。
6. **回归检查**：旁听者是否有权处置；被牵连的 E 与其家族会不会被拖进公开丑闻，若会，是否有退出安排（L11118-11130）；沉默与点头是否被误记为同意（L2472-2474）。

## 缺料版（两个示例共用）

若只有"家族不许两人恋爱"或"他被指控"，而没有：制造标签的人是谁、争议由谁受理、拒绝后的具体成本、坦白的接收端——则只输出四个待补问题：

1. 这个错误判断是谁制造、靠什么维持？
2. 争议由谁受理，该受理方是否与加害方有利害关系？
3. 拒绝后她/他会失去什么（住房、工作、安全、亲属关系）？
4. 坦白由谁接收，他/她是否愿意听、听了会不会转用于伤害？

未拿到答案前不写澄清信、不写身世揭露、不写和解场景；对应列写 `未知`，状态写 `NOT_PROVEN`。
