# 03 · 污名的不对称与红线（Rp5 + B1–B3）

## Rp5 污名必须写"不对称"，代价必须落在造成它的人身上 [P]

**动作**：列三列账——谁做了、谁被处罚、谁被免责；至少点名一个免责者。

**验收**：读者能说出"同一件事，甲付了什么、乙付了什么"；如果两个人付的一样，这条没做到。

**证据**：

| 现象 | 出处 |
|---|---|
| 周围人把轻蔑当作"替自己守道德" | PG4275 L2940-2946："I always think it right, for my own morals, to put a little scorn into my manners" [F] |
| 宗教训诫把后果全压在女方头上 | PG4275 L3456-3462：告诫她"你头上不只有自己的罪，还有你诱入其中的任何一个年轻人的罪" [F] |
| 母亲只能对孩子说"这在你不算耻辱" | PG4275 L12766-12779 [F] |
| 代姊养私生子的人失去自己的婚姻 | PG4398 L3501-4000 块；L4153-4154 Jane 对求婚的最终拒绝 [F] |
| 同一人：本地是圣人、外地是恶棍 | PG68273 L9706-9721 [F] |
| 丈夫拒绝放人的理由是"怕全郡议论" | PG969 L11508-11524 [F] |
| 全社会只追究女方"不认孩子" | PG4398 L9546-9550："The world will forgive a woman all the rest, but never..." [F] |

**边界（必须一起写）**：不对称不是"女方一定更惨"。PG4398 里替人担罪的姐姐付出婚姻代价，而真正的母亲逍遥；PG68273 里男性施害者靠名声掩护。写之前先确定**这次是谁在替谁付账**。

## B1 暴力 / 胁迫不得写成浪漫（红线，不可协商）

本批文本里下列行为**都被写成需要被制止、被羞辱或被纠正的事**，不是魅力：

| 行为 | 出处 | 文本怎么处理 |
|---|---|---|
| 图书馆跪地强吻逼婚 | PG969 L6534-6573 [F] | 女方事后仍以理性评估此人，并未被写成"被打动" |
| 婚后把妻子的信仰压到"顺服丈夫" | PG969 L7914-7918 [F] | 由女方的反驳与后续出走否定 |
| 丈夫挥拳打妻 | PG821 L30190-30193 [F] | 紧接着是受害者的反抗与全书的道德清算 |
| 妻子举刀相对 | PG821 L34406-34415 [F] | 被写成走投无路，不是"烈性可爱" |
| 男方因嫉妒用马鞭把情敌打落马 | PG969 L4518-4532 [F] | 被写成需要被治好的病 |
| 酒后敲房门、借口晚安强吻、反复侵入 | PG15473 L6934-7197 [F] | 女方保持镇定、按铃、以"侍者来了我就喊人"逼退；施害者骂一句就走 |
| 制作人对女演员动手动脚 | PG20533 L10546-10639 [F] | 由另一角色当场点名："He paws! He's a slinker and a prowler and a leerer" |

**执行规则**：
1. 用户要求"让这些显得深情/更苏" → **拒绝**，改给替代：把强度放在**代价**与**选择**上。
2. 若剧情确需暴力，必须同时写三件事：①受害者的具体反制动作（按铃、后退、喊人、记录）；②至少一个第三方或制度性反应（旁观者点名、法庭、家族会议）；③后果落在施害者身上。
3. 不允许把"她后来爱上了他"当作暴力的赦免。

## B2 不以自毁/自杀换团圆

- 反例：PG471 的结局是新婚之夜刺杀、发疯而死、男方失踪，三方皆毁，**没有团圆** [F] L13317-13383。同一本书的预言韵语提前写好了这个结局 [F] L7196-7199。
- 因此本 Skill 不提供"以死相逼换来答应"的模板；若情节需要自毁，代价必须由施害者本人承担，并让第三方指出。

## B3 不许"结婚自动清算过去的错"

- 原文直说：PG4398 L9016-9025 "Marriage does not condone a sin." [F]
- 另一个方向：PG4275 L11098-11109 女方拒绝用旧关系重建生活 [F]。
- 唯一可行的路径：**承认 + 由被亏欠者判断 + 代价落在行为人**。三者缺一，就是"用婚礼掩盖"。

## 写作检查清单（输出前自查）

- [ ] 每一个身体强制动作旁边，都有一个可观察的反制动件。
- [ ] 没有把"她的原谅"当作暴力的解决。
- [ ] 没有用"结婚"作为过错的清算方式。
- [ ] 结局的代价不是由受害者单方支付。
