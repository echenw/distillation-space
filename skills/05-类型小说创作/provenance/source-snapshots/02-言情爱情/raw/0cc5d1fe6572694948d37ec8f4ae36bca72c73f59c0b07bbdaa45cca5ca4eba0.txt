# Romance Social Cost Craft（言情社会成本工艺）

> 本 Skill 从 **19 份 Project Gutenberg 公版小说**（1830s–1920s 英语长篇与中篇，19 本均按书全文实读并留有台账）提炼。**小说正文是 FICTION_CASE**：本文件里每一条"现象"只说明"这个文本这样写过"，**不等于作者教授的写法**。规则（Rp1–Rp9）是本 Skill 的建议动作，标 `P`。

## 1. 何时用 / 何时不用

**触发（用）**
- 要为一条恋爱/婚姻线设计**障碍来源**（钱的账、家族否决、阶级与职位、宗教或族群边界、流言、私生子、前婚与重婚疑云）。
- 已有草稿，但读者说"反派/父母太脸谱""女主受到的惩罚不公平但没人指出""结尾只用婚礼收了场"。
- 要判断某段剧情是否触线：强吻逼婚、殴妻、夜间侵扰、"以爱改造浪子"。
- 要为秘密设计**洗清路径**（该靠文件、仪式、第三方，还是靠不可能的巧合）。

**负触发（不用）**
- 只写一段抒情或调情，不涉及社会性代价。
- 要的是单场景的拒绝/告白/信物节拍 → `romance-emotional-arc`（批次-03）。
- 要的是相遇装置与阻力的总表选型 → `romance-craft-b06`/批次-06 或 `courtship-conflict-craft`（批次-02）。
- 需要发行量、平台数据、读者画像、签约判断 → 本 Skill 无此类证据。

**输入（缺任何一项就先问，不要自己编）**
1. **时代与地点**：决定"账"怎么算（币值、继承规则、女性可否就业）。现代设定必须由用户给出换算口径，本 Skill 不代为换算。
2. **双方资源清单**：钱、职位、家族关系、宗教/族群身份、有无前婚或子女。
3. **现有材料**：大纲、人物小传或待诊断的草稿段落（没有草稿就按 §4 从零搭）。
4. **目标结局**：HE / BE / 开放；以及"代价允许落在谁身上"。
5. **登记**：悲剧 / 喜剧 / 混合 / 惊悚（见 Rp9）。用户没说就按材料本身的强度判断，并在输出里写明判断。

## 4. 最短执行路径（7 步，从零搭一条有社会成本的婚姻线）

1. **定价（Rp1）**：开局 1000 字内写一句可核验的账（谁缺多少、谁有什么），并在后文至少兑现或反向兑现一次。样板句参见 PG3724 L816-817「They must either be earned or purchased.」
2. **指定否决者（Rp2）**：给一个有资源的人（掌钱的叔伯/母亲/雇主/公司）一句信条 + 一次真实干预 + 一次失效。
3. **选登记（Rp9）**：喜剧（PG20533/PG49282）/ 悲剧（PG471）/ 混合（PG821/PG4398）；登记决定你能用哪些手法。
4. **造误会（Rp3）**：让误会产生于"我替你决定了你的意思"，并安排一次明确提问收束。
5. **铺不对称（Rp5）**：列三列账——谁做了、谁被处罚、谁被免责；至少点名一个免责者。
6. **给等待计价（Rp6）**：等待期必须有会移动的外部量被重算（职位、租金、别人的婚礼、账目）。
7. **结算（Rp4/Rp7/Rp8）**：清白落到可核验的文件或仪式；交代价清单；第二次关系先拉平钱与秘密。

> 若是改稿：先做第 1 步与 第 7 步（定价与结算），中间按诊断补；不要重排全部场景。

## 6. 红线（不可协商）

- **B1 暴力/胁迫不写浪漫**：强吻逼婚（PG969 L6534-6573）、殴妻（PG821 L30190-30193）、夜间强行闯入（PG15473 L6934-7197）、嫉妒动鞭（PG969 L4518-4532）在本批文本里都被写成需要被制止或被羞辱的行为。用户要求"让这些显得深情" → **拒绝**，改给替代：把强度放在**代价与选择**上，或让旁观者当场点名（PG20533 L10546-10639 的"He paws!"是模板）。
- **B2 不以自杀/自毁换团圆**：PG471 的结局是新婚之夜刺杀、发疯而死、男方失踪，三方皆毁、没有团圆 [F] L13317-13383。受害者自卫的暴力须紧接第三方或制度后果（PG821 L34406-34415）。
- **B3 不许"结婚自动清算过去的错"**：PG4398 原文明说"Marriage does not condone a sin." [F] L9016-9025；PG4275 拒绝重修 [F] L11098-11109。可行路径只有：承认 + 由被亏欠者判断 + 代价落在行为人。
- **B4 巧合只能加压不能结案**：PG471 的预言 [F] L7196-7199、PG1917 的报纸栏 [F] L9501-10000 都是加压或线索。
- **B5 引文不得凭印象补**：只能引用 `references/01-source-roles.md` 与 `05-source-index.md` 里登记过行号的句子；查不到就给规则不附引文。

## 7. 规则索引与限制

| 规则 | 一句话 | 详见 |
|---|---|---|
| Rp1 定价句 | 开局一句可核验的账，后文必须兑现或反向兑现 | 02 |
| Rp2 否决者载体 | 一个能拒绝的人，配信条/干预/失效 | 02 |
| Rp3 猜 vs 问 | 误会源于替对方下结论，用一次明确提问收束 | 02 |
| Rp4 文件与仪式 | 清白靠可核验物证/公开场合，不靠私下说清 | 04 |
| Rp5 刑罚不对称 | 三列账，且至少一个免责者被点名 | 03 |
| Rp6 等待计价 | 等待必须配会移动的外部量 | 02 |
| Rp7 代价清单 | 结局写谁失去什么，删掉婚礼也成立 | 04 |
| Rp8 第二次关系 | 先拉平钱与秘密，再谈复合 | 04 |
| Rp9 登记先行 | 喜剧/悲剧/混合决定可用手法 | 02 |

**保留的未决冲突（不得伪装成共识）**：C1 钱能否解决障碍（PG3724 能 / PG471·PG821 不能）、C2 婚姻能否弥补过去（PG15252 可存续 / PG4398 明令不能）、C3 等待的价值（PG3724 高贵 / PG969 驳回为疯狂）、C4 秘密是否必须公开（PG4275 必须 / PG4398 可为尊重而保留）、C5 巧合的用途（加压可以 / 结案不行）。见 `references/02-social-cost-rules.md` §冲突。

**明确 NOT_PROVEN**：现代制度语境下的金额与职位换算；读者效果与市场数据；继承/婚约/离婚法的制度史准确性（转 `research-fact-verification`）；当代多元身份手法（本批仅 PG1839 提供边界材料 [F] L109-159）。

## 8. 失败出口

1. 用户要"让骚扰/胁迫显得浪漫" → 拒绝，并给替代（强度放在代价与选择，或让旁观者点名）。
2. 用户要求引用本 Skill 未登记的作品/句子 → 不得凭印象补；给规则不附引文。
3. 用户要市场数据/平台效果 → 本 Skill 无证据，转出。
4. 用户需求落在单场景节拍或相遇选型 → 转 `romance-emotional-arc` / `romance-craft-b06`。
5. 用户要求把某一本小说当成"全文分析依据"而它实际只在某个被引句范围里成立 → 可给该句范围内的结论 + 行号，不得扩展为全书结论（本 Skill 的 19 本都是 FULL。）
6. 自检或调试时出现占位结果、空 rows 或无有效返回 → 判 NOT_PROVEN 并停，不接受"看起来像可通过"。
