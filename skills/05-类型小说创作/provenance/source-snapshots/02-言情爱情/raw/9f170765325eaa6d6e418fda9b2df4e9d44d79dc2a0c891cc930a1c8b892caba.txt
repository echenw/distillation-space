# romance-emotional-arc — 言情情感弧设计

> 本 Skill 从 18 份 Project Gutenberg 公版小说（19 世纪中后期至 20 世纪初的英语言情/求爱叙事）提炼。**小说正文是 FICTION_CASE**：本文件里的每一条"现象"都只说明"文本这样写过"，不等于"作者说过应该这样写"。规则（R1–R10）是本 Skill 的建议动作，标 `P`。

## 1. 何时用 / 何时不用

**触发（用）**
- 要新建一条恋爱主线，需要从"两人为什么不能在一起"开始排布节拍。
- 已有草稿，但读者反馈"感情来得突然""告白没分量""结局草率"。
- 要写拒绝、逼答、退场、等待、告白、解除婚约、婚礼收束等单场景。
- 要判断某段情感强度是否越界（尤其涉及自毁、强制、骚扰式追求）。

**负触发（不用）**
- 只写一段氛围抒情、没有关系变化。
- 非言情类型里的功能性婚配（一笔带过的联姻），没有情感弧。
- 需要市场/平台数据、签约判断、读者画像——本 Skill 无此类证据。

## 4. 最短执行路径（5 步，适用于"从零搭一条线"）

1. **定誓约（R1）**：写一句主要人物在开篇 800 字内说出、且可被证伪的公开表态（"我绝不嫁/我只要体面/我不嫁穷人"）。
2. **定障碍（R4）**：列出"一个人 + 一个物 + 一句话"——能拒绝的有资源者、可被拿起的物件、一句伤人的定性话。
3. **排空缺（R5）**：在中段让追求者**真的走掉**（退场/期限/失联），并让被动方做一件"她以前不会做"的事。
4. **压告白（R6+R8）**：把告白放进一个门关上了的房间/将死的床边/已开的船；让唯一信物在此完成第三次含义反转。
5. **结算（R7+R10）**：写"代价清单"（谁失去什么），用第三方之口说出；再用一场吃喝/天气/账目的反高潮落地，不许用旁白直接宣布幸福。

> 若是改稿：先做第 1 步与第 5 步（誓约与结算），中间三步按诊断结果补，不要重排全部场景。

## 5. 输出物表（每次任务交付什么）

| 交付物 | 内容要求 | 证据要求 |
|---|---|---|
| 情感弧节拍表 | 6–10 拍，每拍一句"谁做了什么/关系状态变了什么" | 每拍注明借用了哪条 R |
| 障碍清单 | 人 / 物 / 一句话，各 1 条 | 引用 R4 的对应案例（PGID+行号） |
| 关键场景稿或改稿 | 拒绝、逼答、退场、告白、结算中至少 2 场 | 场景内至少 1 个 R8 信物动作或 R3 不回应动作 |
| 代价清单 | 3–5 条"谁失去什么" | R7 的四种代价类型选 1–3 |
| 风险标注 | 是否触碰 §6 红线 | 逐条对照 C2/C3 |

## 6. 边界与红线（来自冲突裁决，不可协商）

- **C2 自毁胁迫**：原文中"以死相逼"有时换团圆（PG25726 L1935/L2113）、有时换双亡（PG768 L3112/L3169）。本 Skill **不提供**把它写成"深情证明"的任何模板；若情节需要，代价必须落在施害者本人身上，且由第三方指出。
- **C3 强制身体动作**：抓腕、拦路、围堵在 19 世纪中后期至 20 世纪初的文本里被叙述为浪漫（PG25726 L1332；PG15381 L1614/L1648/L2265），本 Skill **禁止**将其列为可复制技法。
- **C6 巧合解决**：事故可以加压，不能解决（PG25726 L2042–2054 是反例）。
- **C5 叙述者信用**：全知评论（PG25579 L5639）与不可靠叙述（PG15381 L41→L196）不能在同一篇里混用而不标记。

## 8. 失败出口

遇到以下情况，**停**，说明原因，不要硬产：
1. 用户要的是"如何让骚扰/胁迫显得浪漫"——拒绝，并给替代（把强度放在**代价**与**选择**上，而非身体强制）。
2. 用户要求引用本 Skill 未覆盖的作品/作者原话——不得凭印象补引文；只能给 R 规则，不附引文。
3. 用户要求"保证爆款/平台数据"——本 Skill 无市场证据，转交其他能力。
4. 需要 STRUCTURAL 书的句子级证据——只能给 `[STRUCTURAL]` 的章题/框架级判断，并明说"未读正文"。
5. 用户要求把某本 PARTIAL 书当"全文分析"——拒绝，改给窗口内结论并标注行号。

## 9. 引用格式（输出时强制）

- FULL/PARTIAL 证据：`[F] PG25726:1212 "she set her foot upon it"`
- 结构档案：`[STRUCTURAL] PG27:45 章题 "CHAPTER XIII. SORTES SANCTORUM—THE VALENTINE"`
- 建议动作：`[P] R5 …`
- 引文一律逐字、≤25 词、带行号；无法核实的写 `UNVERIFIED`。
