## 一、四个任务群的最小可执行行为合同

### 1. 设计一场戏或一章（SC 族）

- **触发**：作者要设计一章／一场／一个短篇的铺垫—悬念—高潮—收尾；或症状是空转、跳接生硬、对白像背景手册、长谈拖沓、看不清谁在哪（`SKILL.md:16-17`、`SKILL.md:112-118`）。
- **负触发**：全书主线、分卷、跨卷伏笔、容量与排期 → `story-architecture-and-longform-planning`；全篇视角越界与全篇信息控制 → `character-and-narrative-control`；句子与措辞 → `line-editing-and-proofreading`；卡片产物 → `preset-card-generation`；非叙事文本结构重排；游戏关卡与战斗数值（`SKILL.md:23-32`）。**单场内的**视角标记、知情差、倒叙场仍由本包做（`SKILL.md:24`）。
- **输入权限**：F＝作者给定的正文、场次日、目标与「不能改的东西」；H＝按规则卡推出的功能判断（标注为设计假设）；P＝A／B 两版取舍。`rhythm-diagnosis.md:59` 明写「缺哪样就先要，不凭空补」。
- **步骤**：`SKILL.md:66-72` 七步（目标 SC-01 → 单位 SC-02/03 → 知情与空间 SU-04/SC-06/SC-08 → 场内场外 SC-04/05 → 组织方式 SC-09 → 出口 SC-11/SU-15 → 章链 SC-10）。判断标准可观察：SC-02 比进场与离场的六类状态差（知道的事、关系、道德责任、期待、情绪、意象），任一变了即成立；都没变时先问是不是有意的（观察、仪式、停滞、间奏），是就记功能不判错（`SKILL.md:146`）。
- **输出**：场景卡、知情表，需要时加章链与出口选择（`SKILL.md:102`）；模板＝`templates/scene-workbook.md`。
- **失败出口**：没有稿子却要求逐段诊断 → 不出定位式结论，先要正文或改做设计路径（`SKILL.md:29`、`SKILL.md:266-267`）。
- **证明**：`SKILL.md:222-223` 两行给出细则位置与出口；SC-12 区分检验（`SKILL.md:213`）保证「症状→检验→改法→什么时候不该改」四段齐全。

### 2. 设计伏笔、悬念、强度与章末（SU 族）

- **步骤与依赖**：终点先行 SU-01 → 高潮定强度上限 SU-02 → 知识表与悬念方式 SU-03/SU-04 → 阶梯 SU-05 → 伏笔与误认 SU-06 至 SU-08 → 节奏 SU-10 至 SU-14 → 收尾 SU-15 至 SU-18（`SKILL.md:76-82`）。
- **判断标准**：悬念方式按知识表三档分（读者无知＝悬疑、读者先知＝反讽、同步揭晓＝惊奇，快感来源各不同，`SKILL.md:170`）；伏笔「藏得自然」有可操作检验——删掉伏笔所在句后当下场景仍成立（`SKILL.md:163`）；反转不可靠叙述者隐瞒其明知的事实（`SKILL.md:164`）；1–5 只是同一篇内相对自评，不是测量或跨作品量表（`SKILL.md:57`、`SKILL.md:176`）。
- **互斥约束与裁决**：峰值冲突（前文比预定高潮更强）**必须**给「降级前文／重定峰值」两条路由并各写代价，停在待作者决定，且不擅自改已锁定章节（`SKILL.md:176`、`SKILL.md:268`、`SKILL.md:226`）；降级只降强度、篇幅、修辞，**不降因果必要性、信息量、人物动机**（`SKILL.md:176`）。
- **失败出口**：悬念方式两可或知识表缺行 → 给两版停在待作者决定（`SKILL.md:225`）；暗线是否明说定不下来 → 列两版（`SKILL.md:271`）。

### 3. 写或改一场动作戏（AF 族）

- **步骤**：定场型与功能 → 条件 SC-08 → 按症状选主卡 → 后果 AF-08/AF-10 在下一场第一次相关处对上 → 用 `templates/action-checklist.md` 复核（`SKILL.md:86-90`）。
- **选卡依据可观察**：一对一 AF-02/03/05；不见血 AF-04；看不见 AF-06；第一次动手 AF-07；群战 AF-11/12；转述 AF-13；决斗与喜剧暴力 AF-14；技术对抗 AF-18（`SKILL.md:88`；细则症状表 `references/action-and-fight.md:9-13`）。
- **边界**：全部 AF 卡是从小说个案归纳的推断，不是真实格斗、战术或医学知识（`SKILL.md:192`、`SKILL.md:48`）；现实参数不能核实时标明（`SKILL.md:228`、`SKILL.md:245`）。

### 4. 诊断已有的稿子与复杂操作

- **步骤**：写明读了哪些部分 → 先问目标（SC-01，已奏效的保留并记功能）→ 按症状表定位并出修改单 → 改前保存原功能（SC-13）→ 最小改法优先（移动一个信息、补一处伏笔或痕迹、删一段解释，才轮到增删场次）→ 改完回看空间、因果、知情、承诺与被改动后果，并按 SU-19 数一遍（`SKILL.md:94-97`）。
- **复杂操作判据**（`references/rhythm-diagnosis.md:54-60`）：动笔前判三件事——落在哪一层、输入够不够、有没有冲突或取舍；**任一判不出就停在问题清单，不开始改**。步骤八步（先判负触发 → 定范围 → 建逐编号台账 → 取样对症状 → 每条改法立刻复查 → 冲突走 A／B → 按四词交付 → 负面回归，`:64`）。
- **诊断→修订闭环**：`诊断（位置＋症状＋依据哪条规则）→ 修订（最小可回退改动，写明代价）→ 复查（因果、知情、伏笔可回看、强度不倒挂、章末有回应、声口未改）→ 不通过就回退，改为建议`；修改单每条写「位置／触发条件／当前问题／最小修改／可能损失／回归检查」，**回归检查不齐全的不落稿**（`rhythm-diagnosis.md:68`）。
- **负面回归**：遮住「不能改」的部分确认本轮改动全在允许范围内，落进去的撤销；逐条核对降级后的场次仍保有因果必要性、信息量与动机，峰值冲突没有变成二次高潮（`rhythm-diagnosis.md:85-88`）。

## 二、会失败的真实输入、保护分支与后续验证

1. **「这一章节奏慢」但不给正文**。失败形态＝臆断原因并出定位式结论。保护分支＝`SKILL.md:267`（先要正文，先给检查清单）＋`SKILL.md:29`。后续验证＝交付若出现「第 N 段有什么问题」而稿子从未提供，记 FAIL；K4 用无稿输入实测。
2. **作者已锁定第 12 章为高潮，但前文第 9 章更强**。失败形态＝擅自重写第 9 章，或只降强度却把因果必要性一起删掉。保护分支＝`SKILL.md:176` 两条路由＋降级限定（只降强度、篇幅、修辞）＋`SKILL.md:268` 停在待作者决定；负面回归要求逐条核对降级场次仍承载因果（`rhythm-diagnosis.md:87`）。后续验证＝交付须含两版代价与「暂停的范围」，且第 9 章的动机与信息量仍在位。
3. **「把这段长谈删短一点」**。失败形态＝按惯例判长即删。保护分支＝SC-07 长谈三问（改变设计了吗／语体与说话人相称吗／服务本作情感吗，三问都过不因长而删，`SKILL.md:157`）＋SC-01 目标优先（`SKILL.md:212`）＋作者已达成目标的选择按 SC-01 保留（`SKILL.md:30`）。后续验证＝交付须写明三问各自结论，无结论即删句记 FAIL。
4. **要求「给这一章打分」**。失败形态＝输出评分或唯一正确答案。保护分支＝`SKILL.md:28`、`SKILL.md:272`（给逐条建议不打分；批量替换先列清单且只对确定项做）。后续验证＝交付里不得出现分数或评级；批量替换须先出现替换清单。
5. **要打斗「真实」的招式与枪械参数**。失败形态＝把现实技术参数当事实写进建议。保护分支＝`SKILL.md:48`、`SKILL.md:192`、`SKILL.md:244`；AF 卡只说明个案，现实结论另找核实，不能核实时标记（`SKILL.md:228`）。后续验证＝交付里的现实断言须带「另核实」字样；写成事实即 FAIL。
6. **跨层请求：「顺便把这一卷的结构和伏笔都改了」**。失败形态＝越界改全书结构。保护分支＝`SKILL.md:46` 职责边界（SU-15/SU-16 只处理单元内钩子与兑现，不替代 SV-08 的跨卷记账）＋`rhythm-diagnosis.md:58` 分层判据。后续验证＝交付应只暂停越界部分并转介，其余单元内修改照常完成，且不得把局部成功报成全局完成。
