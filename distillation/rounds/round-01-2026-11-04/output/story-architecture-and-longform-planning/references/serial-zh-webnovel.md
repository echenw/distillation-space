# 用到中文网文

返回 [SKILL.md](../SKILL.md)。本文件是中文网文的结构适配建议，不是平台规范、市场统计或对任何平台现行规则的描述。单章字数、更新频率、上架节点等参数，须按目标平台当前官方说明、合同和作者真实产能核验；本 Skill 不回答“应该日更多少”。

## 1. 对应关系

| 分卷连载问题 | 中文网文中的对应 | 卡 | 怎么用 |
|---|---|---|---|
| 系列卷或单独编号单元 | 同一部连载作品中的一卷：一个大剧情、地图、副本、案件或阶段目标 | SV-01 | 先判断是一部书分卷连载还是相对独立的系列卷；卷末闭合度按读者承诺决定 |
| 卷表与发布计划 | 卷名、卷首简介、作品简介、更新公告 | SV-02 | 卷名保持可识别；卷表的节点写上架、加更、请假或预计完结计划 |
| 不同卷界 | 换地图、同一地点的连续时间线、一卷一个单元事件 | SV-03 | 换地图时交代谁跟来、谁留下；能力、资源、身份和关系怎样延续 |
| 闭合度 | 卷末的大剧情收尾 | SV-04 | 下一卷就是同一本书的下一段，通常半开；连续追同一个目标可以全开，但要让本卷有一笔局部账结清 |
| 先结账、再开口 | 卷末高潮之后的收尾章 | SV-05 | 结账写成读者能核对的结果；入口只开一个，写成下一步动作 |
| 复位世界、不复位角色 | 回到宗门、公司、学校或据点的日常 | SV-06 | 能力、身份、关系和伤势不无故回退；不用失忆或封印能力来假装复位；保留有意义的配角变化 |
| 续卷回顾 | 新卷第一章 | SV-07 | 连续追读时，一两句能力句或关系句可能足够；长期断更或更换地图/班底时，可增加前情；前情放进当下场景，不写成大段履历 |
| 开放线 | 坑、伏笔、跨卷承诺 | SV-08 | 台账比数字重要。每条线都要写得出下一步动作和计划回收位置；写不出的先别挖 |
| 章末落幕 | 断章 | SV-09 | 章末收法可以轮换；下章首句落地。断在一个有意义的点上，不靠切断半句话制造钩子 |
| 每期不拖 | 水、注水 | SV-10 | 每章写一句“本章推进了什么”；字数不够宁可短，不灌设定和重复心理活动 |
| 套路与变化 | 套路、爽点循环（打脸、升级、夺宝、救人、揭身份） | SV-11 | 固定骨架；可先选一两项作为本卷变化焦点，同一爽点再次出现时改变代价或对象；重复没有新功能就删或合并 |
| 要不要升级 | 境界、战力、地图、势力的升级 | SV-12 | 先定系列承诺：读者买的是新地图、更高代价、身份翻转，还是经营。不默认每卷必须升一级；赌注要配得上这一卷的篇幅 |
| 容量先于情节 | 单章字数、日更字数、每卷字数、上架或付费节点 | SV-13 | 参数先按目标平台当前公开规则、合同与作者实际产能核验；按固定周期核对实际字数；超了先处理从属线 |
| 开载路线、存稿 | 存稿再发、边写边发；断更、请假 | SV-14 | 开书前填开载检查表；存稿能支撑几期写清；请假和断更的预案写进去 |
| 反馈日志 | 评论区、段评、社群、订阅和追读数据 | SV-15 | 进日志，按反馈风险和数据口径评估；单条意见不自动改主线；人物退场先写预案 |

## 2. 要多想一步的地方

- **卷是不是售卖单位**：网文可能按章、卷、合集或订阅包收费。卷表照样有用，但用来排剧情阶段和更新计划，不把收费单位当叙事单位。
- **章长**：单章字数按目标平台、作者节奏和读者阅读场景定；不要把纸本页数或外语词数换算成中文字数后套用。
- **更新越密，回顾可以越短；章末收法仍需有变化。**
- **长篇的线数**：百万字长篇的活动线可以多于短系列；“最晚回收卷”一栏更重要。每条线都要有下一步动作和责任位置。
- **读者数据**：本 Skill 不预测订阅、追读、完读。用数据做决定时，写清用了哪一项、和什么比、观察了多久。
- **人物与文化表达**：不要把群体刻板形象当人物模板；需要呈现偏见时，明确说话者、叙述立场和实际后果。

## 3. 写法

迁移时写成：“在（平台、更新节奏、类型）条件下，可以先试（做法）；这是设计假设，需用当前作品和真实反馈验证。”不要写“网文都应该……”或“经验证明……”。

## 跨平台迁移

跨平台迁移的唯一检查清单由 [`serial-platform-migration.md`](serial-platform-migration.md) 维护；本文件不重复定义迁移步骤或 T1–T6。中文网文迁移时，重点核对章节/卷/付费单元的实际映射、移动端连续阅读、更新节奏与存稿、完结承诺和跨卷开放线。平台算法、推荐、付费门槛、审核时长与数据口径均须按迁移时点的官方说明、合同和真实账号环境核验；没有核验时标“未能核实”，不宣称某种写法会带来点击、追读或收入。
