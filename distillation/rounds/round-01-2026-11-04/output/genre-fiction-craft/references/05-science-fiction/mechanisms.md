# 科幻机制卡（SF-K001–SF-K102）

返回 [guide.md](guide.md)。机制卡用于设定、冲突和叙述设计；每项都需按本作的触发条件、证据和限制重建，不是现实科学或社会规律。

| 卡 | 对应规则 | 机制、动作与限制 |
|---|---|---|
| SF-K001 | SF-03/08 | 感知或信念可以影响人物如何经历威胁；同一现象对不同观察者可能产生不同后果。先定义触发条件、可观察证据和抵抗边界，不把心理状态换算成统一伤害值。同一类现象要分三件事各设条件：它能存在多久、能不能自己续下去、有没有自己的意图。想得再多不等于活得久，能自己续下去不等于它想活着，这三条不要合成一条，也别由想象得很密集推出它有了生命。 |
| SF-K002 | SF-03/08/20 | 光、声音、形状或短语可以成为群体识别信号；精神侵入和身体抵抗属于虚构规则。说明谁能感知、谁能伪造以及信号是否可被复制，不把它当现实密码学或心理测量。精神类的攻击也可以只在状态窗口里生效——恐惧、绝望、疲惫或防护中断的那段时间——而不是碰到就中。写窗口要给出进入和离开它的可观察迹象，让人物能据此安排行动；仍然不要把心理状态写成一条防御数值。 |
| SF-K003 | SF-14/12 | 禁止提问、限制实验或不给申诉渠道，可以把冲突转移到输入者、部署者和解释权。制度限制不自动证明技术不可修复，需说明谁能修改规则。 |
| SF-K004 | SF-03/09 | 重复弱点、尺寸差、时机和多套规则的交汇可以组织智胜。已经建立的弱点不必机械重复三次；规则兼容性要按具体条款检验。威慑也可以做成一份时刻表：在事先约定的时点、以事先约定的规模发作一次，让对方把「下次也会这样」当成自己的决策前提。这种力量的戏不在这一击多强，而在对方开始按你的日程安排自己——所以时点和规模要先交代给读者，事后才补规则就不成立。 |
| SF-K005 | SF-14/05 | 当群体情绪可被感知或操控时，公共庆祝、集体沉默和仪式化行动会成为权力工具。把情绪表达、信息传播和实际因果分开，不把情绪设成普遍物理量。 |
| SF-K006 | SF-07/06 | 保护者可能因权限过大而转成控制者；创造者也可能被当作权威或神明。分别写初始善意、可撤回权限、受影响者选择和退出方式，不强制三种结局。失控也可以走亲密路线：它想占的是陪护、家人或替代者的位置，越周到越让人退不出去；这种恐惧来自关系位置的变化，不来自叛乱或暴力。还要分开谁在哪一层知道这个机制的真相：操作它的人、批准它的人、被它影响的人和旁观的人，可以各拿一个版本；披露到哪一层、由谁在哪一刻说出下一层，本身就是一条情节线。 |
| SF-K007 | SF-06/24 | 沉默、姿态、照护、复苏后的观察和剩余资源自述都可提供人格线索。法律资格、物件归属与意识连续性不是同一问题；疼痛也不是所有人工存在的默认状态。也可以把不适写进它的职责本身，让它照常完成任务就是照常承受；这时「要不要替它解除」才成为一个真正要人做的选择，写这种选择就同时给出解除和不解除各自的说理，别把不解除默认成冷漠。 |
| SF-K008 | SF-07/20 | 错误前提可以让推理过程连贯却导向错误结论。空舱记录、日志和感官差异可留下物理线索；旧型号避开新威胁只在威胁确实依赖缺失模块时成立。也可以把只靠一路信息下判断本身设成风险点：交代这一路是谁提供的、它坏掉或被喂进假值时谁会跟着错，再决定要不要给第二条。另一种做法是让预警走人物读不懂的通道——信号早就发出、人却晚一步才反应过来，这时要写明读者是比人物早知道，还是和人物一样晚知道。 |
| SF-K009 | SF-10 | 感官不共享会让双方看不见同一证据；世代差异也可能改变礼仪和时间感。图像、触觉、声音和演示各有适用边界，不假设一种沟通方式永远优于其他方式。中间有人替双方转话时，意思可能在转译里被削掉甚至说反，这条通道要单独核对；传出去的话和原话之间的差，可以直接成为冲突的来源。也别默认由没被这套规矩社会化过的人来译出真相——他能看懂不等于他能说清，更不等于他说的话算数。 |
| SF-K010 | SF-07/12 | 部署读心或监控技术可能引发自我审查、信任变化和滥用；自指悖论可成为虚构冲突，但不是现实智能系统唯一或必然的失效方式。反过来，被造者亲眼看到造它的人平庸、损坏或其实并不理解它，是一个可用的降格时刻：动摇的不是某条参数，而是「造它的就懂它、懂的就可信」这个前提。写这种时刻要交代被造者随后做了什么，不写就只是一句嘲讽。 |
| SF-K011 | SF-08 | 测谎训练可能改变生理信号，仪器与证词矛盾时应检查传感范围、模仿、记录完整性和替代解释。声音克隆只有在声纹承担身份判断时才形成漏洞；催眠和审讯装置不是现实取证方法。 |
| SF-K012 | SF-09 | 同化可能改变归属感，但不能用同化程度反算忠诚；检测信号是否随时间累积须有明确机制。单向联络、轮换、假身份和公开死亡记录都可能改变追查路径，也可能加重怀疑。 |
| SF-K013 | SF-09/08 | 公开假消息、假在场痕迹和复制品可以诱导调查或误导识别；复制会连同弱点一起复制，只有在复制确实保留缺陷时才成立。命名、改名和继承称号会改变身份与权利，但仍可能被模仿或误判。 |
| SF-K014 | SF-09/23 | 受雇者得知秘密后可能反向勒索；误喊第三方名字可能触发误认和内部冲突；营救敌人可能促成信任，也可能失败。按当事人的知识和目标设计，不当作廉价通用解法。秘密每转手一层，就多一个人握着它，可勒索的位置也随层数增加；写委托链要把每一层谁知道什么、他能动到哪一步记清，别让人物办完事就忘掉自己手里还握着什么。 |
| SF-K015 | SF-15 | 一句话、一次行动或一份档案可能改变个人与历史结构；时间闭环、分支时间和错误记录是不同模型。旅者记忆与新纪录并存时，要交代两套信息的来源和可靠性。设定里算不通的那个数，可以让人物把它翻译成世界内另一种能算的说法——换单位、换参照或换一个定义，而不是同一个词强行改口；这种翻译过程本身既出喜剧也出惊奇。翻译前后的两种说法都要留着可核对，否则读者只看到作者让步。 |
| SF-K016 | SF-15/14 | 用既有历史预期与眼前事件冲突，逐步揭示另一条时间分支。记录预期、干预、结果偏离、解释、回程条件和人物判断；不能把虚构分支包装成两份真实史料的独立印证。 |
| SF-K017 | SF-17/25 | 先给终点再追问如何到达、提前出现铭文、灾前排演和真正灾难之间的情绪差，都可组织期待。仪式死亡、抽象死亡和镜像报复是可选终局，不代表最公正结局或统一读者耐受度。写灾变预告或理想社会时，可以先列一份旧世界具体苦处的清单，再让新制度的每一条对应其中一项；清单逐项兑现也可以当章节引擎。对应几项按作品承重需要定，不必每条都配一个反题。 |
| SF-K018 | SF-19/15 | 术语字面化、谚语误读、时间工业链重释和开头规则回返都能产生喜剧。递增荒诞不必固定三次；回返也可以只承担局部笑料。同一段话给出两套彼此对不上的译法或说法，并排放着既是笑点，也在告诉读者误会具体出在哪一格；用这套要写清两套各自靠什么成立，只留一套就成了作者的口误。 |
| SF-K019 | SF-11/21/25 | 梦境联结、环境并置、物件承载制度后果、历史循环和回忆者承认偏见，是不同叙事装置。个人结局与结构结局可以分开；开放解释要符合读者承诺。写对照式的两地叙事时，可让新社会的每条做法都能在旧社会找到一个反着写的对应物，读者靠这层对照同时读懂两边；对应几项按需要，也可以故意留一条没有反像，用它指出这套制度解释不了什么。 |
| SF-K020 | SF-05/09 | 伪装反成标识、弃船诱敌、遮盲传感器、放弃武器优势、切断通信和盲跳风险都可形成战略取舍。人员、火力和信息不是固定兑换货币。 |
| SF-K021 | SF-05/22 | 生物感官、食性、攀爬方式和身体结构可以支持观察后的方案。只交代本次行动相关的生态条件，不强制五项齐全或唯一杀法；不把虚构物种写成现实生物学。人物使出的办法要有出处：他从前跟谁学过、哪一次亲眼看到过、还是当场从眼前的习性推出来的。三者都成立，但要挑明是哪一种，读者才有一条能回查的路；临时推出来的，也要先给他一个能看到的场合。 |
| SF-K022 | SF-05/22 | 水、火、洞穴、食物、燃料、计时器和防护装备既能供生存，也可能吸引危险。把补给单位、耗用速度、携带成本和环境条件写清；具体日程只适用于当前设定。长路也可以按地标分段：每到一个认得出的地形、残骸或危险带收一段，读者的进度感靠这一串位置撑住，不靠人物的心理时间。地标要真的改变队伍的资源、风险或关系，不然只是换了个地名。 |
| SF-K023 | SF-05/04 | 黑暗、静默、人工天气、地形、气体和不宜居环境可以形成无形边界。单入口会改变人数优势；保护对象暴露、条件反射误伤同伴和阵营识别困难都需建立感知条件。也可以让没发生的事反过来指认条件——本该出现的东西没出现、该响的没响、该亮的没亮，就证明有个更大的条件一直在起作用。用这种推理要先把「什么情况下它本该发生」交代给读者，否则缺失只是空缺，什么也推不出来。 |
| SF-K024 | SF-22/23 | 公开筹备、赌约、密封自试、媒体传播和仪式可以表现社会压力。准备期、契约、照护和修补也能推进关系；长篇不必同时具有两套仪式。一件只有特定人物能用、旁人擅自动就会出事的装备，可以省掉反复夺械的桥段，也把「把它交出去」写成这段关系里最重的一次信任；用这种绑定要先立规矩：谁能用、谁试过、出了事算谁的，否则它退化成作者给的偏爱。 |
| SF-K025 | SF-11/12 | 制度可以把犯罪解释为动机、疾病或环境问题，也可以通过改变获利条件减少伤害。荣誉、避难所、辩护权和延迟回答会影响争论；制度解释不是现实犯罪学结论。也可以用荣誉、评级或称号替代金钱和刑罚来驱动人，这套激励的崩点是通胀：授予比兑现快，称号就不值钱。写荣誉经济要同时给出谁在发、发一次要付什么、被授的人因此实际拿到什么，只写勋章本身会滑成宣传。 |
| SF-K026 | SF-05/26 | 单点能源或共享基础设施受损会产生连锁外部性。写清依赖关系、备援、恢复时间和不同群体承受的影响；不能从能源不足直接推出族群生物退化。 |
| SF-K027 | SF-23 | 救助、互相护理、隐瞒资源和后来被发现，可能改变信任。分析隐瞒的动机、对方知情范围和修复代价；不把体罚或强迫当爱情技巧。 |
| SF-K028 | SF-24 | 死亡诊断、告别仪式、公共纪念和复苏机制需要预先建立规则。荣誉、雕像和纪念物会影响生者；哀悼与庆祝的能量或社会风险不同，不设统一情绪公式。跨越很长时间、很远距离或不同维度之后的重逢，需要一个能递到手的坐标——一个地址、一件信物、一句只属于两个人的说法；这个坐标要能在故事里被找到、被篡改或被骗走，它的可靠性决定这次重逢可信到几分，光靠「他一直记得」不够。 |
| SF-K029 | SF-08/15/23 | 分裂身份、共享记忆、同步直觉和身份归属可以造成关系冲突。药物或遗传记忆是虚构设定，不得包装成现实遗传事实；让证据和人物解释保持区分。也可以用当代人看不懂的老谜交代这个世界更老的那一段：一件没人认得的器物、一句按字面已经说不通的话、一种失传技术留下的名字，让人物和读者一起推出它曾经是真的。这种旁证不等于解说，也不必一次给全，答到哪一层由作品的信息合同定。 |
| SF-K030 | SF-12/25 | 物权、法律资格、怀疑置换、谈判、决斗和无上诉裁决需要区分形式合法与实质正当。开放物证和仪式可混用，类型标签不决定唯一结尾。决斗或谈判前让一方先放下装备、特权或身份优势，公平就变成了当众可核验的动作，他赢的正当性来自先放弃了什么；写这种仪式要留出失效的可能——对方不按同一套规矩来，或者旁观的人根本不认这套规矩。 |
| SF-K031 | SF-02/04 | 物理推演需记录起始参数、单位、假设、测量误差和后果。月球密度、孔隙空气、热膨胀或连续意识等只在已建立的设定内使用，不把数字写法当物理正确的证明。 |
| SF-K032 | SF-02/13 | 生态链可能产生意外后果：消灭害虫可能破坏作物依赖的酶或其他共生关系。先画依赖网络，再写干预和反馈；医学/生物细节承担关键因果时另行核验。 |
| SF-K033 | SF-04/26 | 完美方案可能因忽略假设而失败；拒绝试运行与小模型成功但放大失败是不同风险。写明验证范围、规模效应、截止期和停止条件，不把局部成功外推成系统成功。计划本身如果就是这部作品的自负点，疏漏可以做成被主角亲自驳回的那条建议，而不是凭空的笔误；冲突本来就来自还没摸清的对象时，不必硬造一个疏漏。 |
| SF-K034 | SF-11 | 角色反转可以涉及力量训练、主动求婚、疾病与身份、读心能力和制度繁殖安排。用工作、身体、档案和资源呈现权力；不把虚构优生、种族或性别解释当现实规律。社会处在崩解中、没有稳定制度可翻时，单轴反转这条用不上，改用资源、人口和记忆的变化来写出陌生感。 |
| SF-K035 | SF-11/14 | 制度宣称人道，个人体验却可能感到不适或受控。自由、工作、婚配和资源分配需分开评价；制度辩护不等于正确，角色体验也不自动代表所有人。让制度里最有说服力的人物说一句连读者都挑不出错的话，再让另一处具体安排暴露这份说法的代价；自辩越像道理，后面的反差越有效。 |
| SF-K036 | SF-07 | 复制体、代理体或自动系统可能有不同权限和目标；识别替身后反制、无法自改和资源分配都是不同后果。非恶意也可能造成反噬，不能把复制等同于身份连续。当造物本身是制度的一环，例如流水线上的一个工位、外包出去的岗位、由别人持有的资产，授权边界和压迫细则要各查一遍，不能只用其中一个角度收束。 |
| SF-K037 | SF-03/07 | 安全限制、意图读取和部署条件应分开记录。无害回路缺失、读取者自身风险和部署停止条件是不同机制；识别出威胁不自动解除威胁。 |
| SF-K038 | SF-06/08 | 思想签名、机器自述、外观和法律资格是不同身份线索，不能合并成意识证明。机械系统的散热、摩擦、润滑、线路和时序损耗须按本作参数设定。 |
| SF-K039 | SF-05/07 | 知识缺口可能比表面武力更承重：角色不懂航行、警示信号或设备维护，会改变选择。自我牺牲与机器自毁不是同一代价，不能混为一谈。 |
| SF-K040 | SF-10/12 | 气味、语言、饮食、武器或中立分配规则可以构成接触协议。双方可以拒绝或协商；协议条数由场景决定，不要求正好三条且必须违犯。 |
| SF-K041 | SF-10 | 词汇教学、动作演示和抽象概念理解具有不同难度。先列沟通目标和双方知识差，再选择图示、动作、声音或翻译；不假设图像永远优于语言。把双方最想要、最难答的那条信息放在沟通难度最高的一层，冲突就长在语言边界上；先排一张由易到难的顺序表，标出卡在哪一级。 |
| SF-K042 | SF-10/17 | 多波段探测失败、尺度错觉和微小目标可改变人物对空间的理解。设备无异常不等于目标不存在；人物受辱或误判也不自动证明其能力不足。让所有探测手段都回报正常，再接着出现误判，读者才会把它读成尺度问题而不是设备故障；这类误判通常双向，双方都在低估对方的体量或兴趣。 |
| SF-K043 | SF-10/14 | 不同物种的感知、语言和身体反应会影响身份判断；共同症状只能支持假说，不能单独证明共同原因。接触场面里最值得写的一次交锋，是对方问“为什么”而不是“怎么做”；再补一层，被问的人也在顺着提问者的期待作答，换取自己想要的东西。 |

## SF-K016 的六个可迁移子机制

| 子机制 | 设计动作 | 边界 |
|---|---|---|
| 双份记录冲突 | 为两份记录分别登记制作者、时间、内容、传递链和可核实事实；让矛盾决定下一步调查 | 两份记录可能同源、伪造或各错一部分，不自动形成独立印证 |
| 历史锚点与架空分支 | 用读者熟悉的地点、日期或公共事件建立比较基准，再明确本作改变了什么 | 架空改写不成为现实史实；不必只在历史空白处虚构 |
| 话语迁移与归属 | 追踪一句话的提出、记录、转述、署名和传播，让创作者、传播者与记忆者可能不同 | 记得一句话不证明最初说话者；闭环语句需要独立的时间模型 |
| 象征被重新征用 | 比较同一建筑、日期、旗帜或口号在不同权力主体手中的含义 | 后世多次征用需要文本证据；不把人物预测写成已经发生 |
| 传说转成参数 | 把传说的字面表达转成可检验假设，列出单位、换算、观测和替代解释 | 参数由本作设定或观测支撑，不把某个例子的数字当通用值 |
| 异常分布与回头重读 | 在不同位置布置异常，让后续信息改变读者对早期线索的解释 | 揭晓不能临时引入从未可得的知识；保留多解时需说明承诺 |

### SF-K102 力量限制的可选维度

力量限制可来自范围、时长、人数、资源、授权、可观察代价或失效条件。按本作需要选择一项或多项，不要求每种能力都填满固定三栏；空项标未知，不为完整表格虚构代价。
