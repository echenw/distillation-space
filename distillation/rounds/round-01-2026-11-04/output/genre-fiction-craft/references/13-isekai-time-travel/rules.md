# 异世界与穿越规则（IS-01 至 IS-20）

返回 [guide.md](guide.md)。每一条的动作都是建议，条件是推断出来的；故事内怎么写，不自动成为普遍事实。

| 编号 | 对象与成立条件 | 动作、限制与预期结果 | 注意 |
|---|---|---|---|
| IS-01 | 需要判断是否发生越界 | 分别核对跨世界旅行、反向来访、造世、局部接触与单纯时代/地点变化。只借局部机制时，明确不把作品归入完整穿越类型。 | 古风、异地或年代跳跃不自动算跨界 |
| IS-02 | 需要设计进入方式 | 分离载体与结果；给装置原理和限制，或给身份失效、禁问、框架叙述、记忆缺口等替代入口。类型不明就标未知，不能自动算作没有入口。 | 分类用于找到叙事目标，不要把情节硬塞进分类 |
| IS-03 | 装置、器物或机构会重复使用 | 区分操作、维修、防护、观察和返程；机构另查参与方及其他人能否使用。记录物件所在位置、保管者和状态；未建立的位置标未知。 | 不把物件设成无限万能，也不把窥视自动算作旅行 |
| IS-04 | 读者依靠规则预测行动 | 写出条件、动作和结果；在另一个适用场景复用并检查条件是否改变。仅一次奇观不证明稳定规则；悖论型故事只需建立局部可核条件。 | 不强迫每个异象都能被学习或复制 |
| IS-05 | 契约、事故或隐藏代价推动情节 | 契约先定承诺；事故先写可观察后果再解释；隐藏代价保留线索与误判因果。分别记人物、叙述者和读者何时知道。 | 不要求所有代价都在越界前告知 |
| IS-06 | 梦、离魂或意识经验的真实性是读者问题 | 先选真实经历、可靠信息、启示体验或双重解释；为选定主张提供相称证据，不用局部锚点证明整段经历。 | 三种效果可以分别成立，不必合并 |
| IS-07 | 前世、梦境或解释争议 | 标谁叙述、谁否认、观察范围和哪些物证对冲；可以明确真假，也可以保留不决。完整解释不必然毁掉惊奇。 | 角色信念不自动成为世界规则 |
| IS-08 | 多机制短篇或长篇 | 同一组故事可以使用不同机制；长篇跨机制时给框架与局部范围，标出各自有效条件。 | 长篇框架是可选结构，不是所有故事的必需项 |
| IS-09 | 技术、财富或知识看似万能 | 分物理有效、资源可得、制度控制和战略尺度检查；给限制或代价，不硬排固定败点。 | 不把能力失效点固定在某个篇幅比例 |
| IS-10 | 主角要改造目的地 | 把改造当可选亚型；写制度扩张如何落地、怎样遇阻、谁付代价。 | 不把某一种工程顺序强行通用化 |
| IS-11 | 被选中、伪装或身份揭穿 | 身份需有命名者和动机；揭穿须改变选择、权力、信任或情感；不揭穿也可保留可读矛盾。 | 身份变化不自动等于命运转折 |
| IS-12 | 社会设想是叙事核心 | 选讽刺、建设、价值冲突或多制度对照；为主要制度写收益、代价、承担者、执行与例外。 | 不强制反乌托邦，也不强制固定数量的制度细节 |
| IS-13 | 制度细节需要转成场景 | 从税、工时、制服、历法、劳动、教育、语言和传播中抽取会改变行动的约束；少见机制保留为选项。 | 设定表不是场景本身 |
| IS-14 | 需要区分创作者表达、人物信念与叙述者立场 | 分开创作者公开说明、人物话语、叙述者判断、文本事实和读者推断；无法确认时只说文本呈现，不归因创作者信念。 | 叙述立场要看上下文，不凭单句定论 |
| IS-15 | 飞地、失落世界或自治空间 | 检查边界维持、入口、真假景、生产治理与外部法缺位后的内部机制；不把私刑视为自治的必然结局。 | 不把治理风险写成单一制度结论 |
| IS-16 | 文化差异、命名与论政 | 写谁命名、审判、排除以及其权力后果；讽刺保留现实对应，冒险检查讲座是否阻断行动。 | 谁拥有命名权需在本作中建立 |
| IS-17 | 归途与结尾 | 分通路、意愿、结果三轴；核对承诺、带回物、损失和现实变化，不强制回家或在前段提前明说。 | 披露时机不作硬阈值 |
| IS-18 | 到达后的情感主题 | 幻灭、留下、建设、羡慕和希望分别成立；先写追逐对象，再写抵达怎样改变它。 | 不把幻灭当结构定律 |
| IS-19 | 决定论与自由改造同场 | 保留两方证据与人物行为，不替创作者消灭主题张力；先检查两条主张是否处于同一叙述层。 | 两个分支可以并存 |
| IS-20 | 时间或传送悖论 | 明确局部规则、身份与生存代价、不能闭合的边界；不拿普通门径清单强行否决悖论。 | 不要求所有世界共享同一套时间规则 |

## 边界知识与局部设计选项

- **时间跳跃**：可以通过睡眠、失联、记忆缺口、时间差或环境变化实现；说明人物怎样确认经过时间，以及信息是否可靠。
- **非人社会**：死者、机器、异族或其他主体可以拥有自己的社会规则；其组织方式不必照搬人类制度，但要说明其行动和交流边界。
- **规则型超自然**：护符、仪式、契约、预言或异常能力可有固定条件；条件要能被人物观察或推断，不能在揭晓时临时改变。
- **引导与诱惑**：陌生人、声音、梦境、任务或承诺可以引导人物进入新世界；交代诱因、信息差和拒绝的可能。
- **归来与遗忘**：人物可以带回记忆、物件、伤痕或关系变化，也可以失去部分记忆；损失与后果按本作规则建立。
- **证词冲突**：不同人物可以对同一事件有不同版本；区分亲历、转述、推测和伪造，不把某一证词自动当全知档案。
- **预言与宿命**：预言可以准确、含混、误解或自我实现；保留人物选择和因果链，不用预言替代行动。
- **制度放逐**：群体可以用身份、法律、资源或仪式排除个体；写清执行者、受影响者、退出方式和后果。
- **时间计价**：时间可以被交换、储存或折算为资源；先定义单位、兑换条件和失效边界，不把比率当现实事实。
- **双向物件与因果闭环**：同一物件可以跨时段往返；记录其持有者、传递链、损耗和知情时间，避免凭空复制。
- **城市治理与传播系统**：报纸、学校、机构、仪式和公共空间可以影响社会运行；区分规则制定、执行和公众认知。

这些机制可单独或组合使用；多个故事使用相似机制，不等于现实效果已经验证。
