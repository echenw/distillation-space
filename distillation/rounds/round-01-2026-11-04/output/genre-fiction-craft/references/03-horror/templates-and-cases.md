# 可填写模板、条件案例与历史独有材料

返回 [guide.md](guide.md)。

空白处不是配额；填多少由任务决定。案例分为不同侧重的创作技法与推演范式，通过具体场景的构建与拆解展示规则的操作路径。

## HO-T01 威胁与终局工作表

| 字段 | 要填的内容 | 缺失时怎样继续 |
|---|---|---|
| HO-T01-01 任务合同 | 构思/章纲/起草/诊断；作者目标、可改范围、已有有效功能 | 缺稿可设计，不能编造现稿诊断 |
| HO-T01-02 威胁与损失 | 实体/空间/人/流程/心理；实际失去什么 | 给有实质区别的备选，不强塞怪物 |
| HO-T01-03 起因与关系 | 起因的时间/地点/事件；受影响者如何被选中（关系、血缘、行为、随机或未知）；动机、受益者、受损者 | 起因可未知，已知的行为链仍须清楚；不把遭遇当作受害者有罪的证明 |
| HO-T01-04 四层认识 | 确证规则、角色信念、观察事件、未知 | 保留未知，不补虚构的事实 |
| HO-T01-05 感知与显形 | 谁从何感官取得什么；时段、地点、触发条件、形态与出现频率；感官余像是否关联源起；显形改变什么 | 无须一次/末段才显形；局部或直接都可；关联源起是设计选项 |
| HO-T01-06 痕迹 | 前态、变化、见证、替代解释、证明范围；有关场次留下什么，终局回收哪项 | 不规定一个或多个物证，不要求每幕产出物证 |
| HO-T01-07 传播/递进 | 通路、权限、关系或资源怎样变化 | 不要求三级、三次或逐章死亡 |
| HO-T01-08 反制 | 可伤/可退/可封/可替代/可离开/可容纳/暂不可知；条件、操作步骤及失败分支 | 不用“肉身比例”推算可杀性；步骤可简可繁，不必付出代价 |
| HO-T01-09 代价与修复 | 谁承担、何时、可否恢复，或明确无偿恩惠 | 不强加不可逆损失 |
| HO-T01-10 证词链 | 每人亲见/听闻/否认；材料文类、原件与转引、矛盾及改变说法的时点；独立性待核 | 不设三人两源门槛，矛盾不自动证明有人说谎 |
| HO-T01-11 空间/时间 | 路径、权限、封锁、误认、时钟或回环；领域的感官特征、进入和逃离条件 | 无相关作用时可略；空间特征不等于超常机制已确证 |
| HO-T01-12 解释合同 | 要定案的是事件/身份/机制/动机/宇宙原因哪一层；解释者的动机、依据与解释时点 | 给竞争解释及缺口；可不解释，不强制四项排除 |
| HO-T01-13 四轴终局 | 兑现、解释、余留、人物与社会后果；作品中的复仇/悲剧/混合伦理怎样影响结局 | 不按物种指定唯一惩罚；伦理的变化须有语境，不强制全篇单一宇宙论 |
| HO-T01-14 同情与责任 | 谁受害、谁解释自己、谁可以宽恕、谁承担后果 | 不用苦衷抵销受害事实 |
| HO-T01-15 语气与时代重构 | 报告/古物/怪诞/敬畏/喜剧；历史立场与作者立场；移到新年代后制度、种族/性别/医学再现需怎样调整 | 不把残障、族群、性别当邪恶捷径；历史偏见可呈现，但须辨明谁持有此立场 |
| HO-T01-16 证据与退出 | 章节/场景定位；事实、设计、解释分开；证据不足之处与补证需求 | 先交不依赖疑点的部分 |

原有 16 个观察字段全部有逐项承接：强度间隔由 HO-T02-09 承接，机制失效由 HO-T01-16、HO-T02-11、HO-T02-12 承接。“形态次数上限、肉身公式、所有解咒代价、固定四项排除、最低见证人数”已从字段内撤销，不能通过旧字段名称恢复。

## HO-T02 单场景设计与修订

| 字段 | 内容 |
|---|---|
| HO-T02-01 真实位置和前后状态 | 新稿设计注明；修订填写原稿定位与原句 |
| HO-T02-02 本场任务与恐怖机制 | 求证、接近、逃离、照护、谈判、仪式、等待、解释、告别或其他；本场采用显形、纠缠、罪案、领域闭合或其他机制 |
| HO-T02-03 入场认识与权限 | 人物和读者各知道什么；能看/听/接触什么 |
| HO-T02-04 观察与感官 | 具体可见事实、身体反应、他人反应及其差异 |
| HO-T02-05 主动选择 | 自救/祈求/求援/告知/逃离/隐瞒/冒险/拒绝，及可理解的理由；哪些行动被谁或什么条件封锁，哪些仍可尝试 |
| HO-T02-06 物件、空间和证据 | 每项承担什么功能；不限制数量，不强制有物件 |
| HO-T02-07 显形或不发生 | 发生改变什么；未发生让谁改变什么 |
| HO-T02-08 证词与规则 | 谁目击、谁否认、谁解释；材料属于哪种文类；本场触发什么已确证规则、什么只是猜测 |
| HO-T02-09 节奏 | 冲击/累积/回环/缓冲/持续高压；与相邻场的关系 |
| HO-T02-10 后果、责任与时代再现 | 人物、身体、资源、关系、认识、社会影响；谁受伤害及其伦理语境；种族/性别/医学再现是否需要调整 |
| HO-T02-11 失效诊断与修订取舍 | 读者可能识破什么：有意让读者先知，还是机制穿帮；具体修法及增强、失去的功能；存在重要取舍或要求比选时比较 A/B |
| HO-T02-12 场景出口与验证退出 | 事件如何接入下一场：行动、问题、余波、时间跳跃或停顿；所需稿件/当前文本/作者选择；效果未测 |

原有模板的位置、类型、感官、自救、物件、显形、证词、规则、缓冲、道德、证据、失败、时代偏见、出口字段均在此保留。“道具≤1”“结尾只出现一次”不作要求。场景不因超额而自动失败。

## HO-T03 现稿诊断单

先写作者所选的终局与语气，再写真实稿件的问题位置。每项使用下列记录：

```text
诊断 ID：原稿位置与实际观察：作者目标 / 已有效功能 / 不可改项：判断的条件（为什么这是本稿问题，而非风格差异）：证据：原稿位置；必要时章节/场景定位，事实、设计、解释分开：建议修改：具体动作；预期影响；会失去的功能：备选修改（存在重要取舍、反信号或要求比选时）：具体动作；预期影响；会失去的功能：未确定项：作者选择 / 缺正文 / 来源待核 / 效果未测：建议采用与保留理由：
```

诊断可按以下对象选用上表字段：题材与语气定位；诅咒、禁问、遗物或框架形成的吸引力；显形与感官呈现；威胁变化与自救条件；证词的文类、矛盾和倒戈时点；解释者动机及解释时点；强度间隔；伦理关系；结局的物证呼应和有意拒述；巧合发生位置与作用；时代重构；具体规则对应的修订处方。每个诊断仍需填真实原句和本稿适用条件。

巧合按其承担的因果作用检验：建立困境、改变局面、作为作品主题或用无铺垫办法解开已经承诺的难题，不按超过一次判错；结局不限定四选一；不以同情、完全解释或婚姻结尾为自动降级。

## HO-T04 证据链和反解释表

| 主张 ID | 原始观察/原件 | 知情者及权限 | 转引链 | 直接支持什么 | 不能支持什么 | 竞争解释/反证 | 状态 |
|---|---|---|---|---|---|---|---|
| 自填 | 精确到对象、时间、位置 | 亲见/听闻/推测 | 同一原件则关联，不重复计独立 | 事件/身份/机制等 | 不跳层 | 能覆盖与缺口 | 事实/设计/解释；已知/未知/证据不足 |

多个案例来自同一情境或同一组材料或同一传统不自动判相关；同一报道的重印、同一人转述则记录共享底层来源。没有追查过是否真正独立，就写明“来源关系未查”。

## HO-C01 继承物件与家庭记忆

- **机制：** 一件衣物、家具或遗物既有实用价值，也承载家庭关系和未解决的记忆。
- **怎么用：** 先写清物件由谁保管、谁能接触、人物为何不愿丢弃；再让异常声响或痕迹改变继承人的选择。遗赠也可以按受赠人所贪之物定向：把对方最想要的那样东西留给对方，接受即接害；同一批遗物对不同继承人成立不同的关系，谁拿到什么要按人写清，不能合并成一句家产尽失。
- **边界：** 物件的存在不证明亡者仍在场；家庭恩怨与超自然解释可以分开。

## HO-C02 照护交班与责任空隙

- **机制：** 多人轮班照护时，交接、记录和权限边界可能产生信息缺口。
- **怎么用：** 记录每一班知道什么、做了什么、谁负责确认；恐惧可从“没人承认自己负责”而非怪物直接出现。
- **边界：** 不把真实照护者群体污名化；程序缺口需要具体条件，不把所有疏忽都解释成阴谋。

## HO-C03 修复录音与被遗漏的声音

- **机制：** 修复、降噪或转录可能让此前不清楚的声音变得可辨，也可能放大噪声和误判。
- **怎么用：** 记录原始载体、处理步骤、前后差异和无法确认的部分；让听者的期待影响解释，但不替代音频证据。
- **边界：** 修复结果不是自动更真实；不把噪点或模型补全当成原始录音。

## HO-C04 医疗判断、密封信息与身体变化

- **机制：** 医疗记录、密封信件和身体变化可能被不同人物分别掌握，形成知识不对称。
- **怎么用：** 分开记录症状、观察者、专业判断、当事人信念和延迟披露；让身体变化影响行动窗口。
- **边界：** 虚构病程不冒充医学事实；医生的判断也可能有范围和不确定性。

## HO-C05 建筑痕迹与重复声音

- **机制：** 裂缝、回声、潮湿、门缝和重复声响可以让空间逐渐显出异常。
- **怎么用：** 先建立房屋的正常声学与使用方式，再让一处可复核的变化反复出现；每次重复都改变人物理解。
- **边界：** 不把所有旧房噪声都当作灵异证据；空间的物理条件要自洽。

## HO-C06 婚姻、监护与继承形成的封闭关系

- **机制：** 婚约、监护、财产和居住安排可能让人物难以退出关系。
- **怎么用：** 写清谁掌握资源、谁能拒绝、拒绝的实际代价，以及制度/家族如何执行限制。
- **边界：** 不把虚构制度当现实法律；恐怖来自具体控制链，不是婚姻或家庭本身。

## HO-C07 见证与替代位置

- **机制：** 一张床、一个座位或一份签名被替代，可能暴露谁曾经在场、谁被排除。
- **怎么用：** 记录原本应在的位置、实际占据者、替代发生时间和可观察痕迹。
- **边界：** 替代物只能证明位置变化，不自动证明身份或死亡。

## HO-C08 迁移者与失物清单

- **机制：** 搬迁会让人物重新整理身份、物件和记忆；失物清单可以成为叙事中的证据表。
- **怎么用：** 分列携带、遗失、转交、被认领和无法确认的物件，并标明每项由谁知道。
- **边界：** 清单遗漏不自动等于有人偷窃；不同人的记忆可以互相矛盾。

## HO-C09 运输中的身体与错误身份

- **机制：** 道路颠簸、遮挡、低光和匆忙会让运输者误判所载物体或身份。
- **怎么用：** 先让运输中的运动和触感符合物理条件，再让身份判断被新证据推翻。
- **边界：** 误认需要可理解的视线/信息限制；揭晓不能临时改写人物已经明确看见的事实。

## HO-C10 多种材料链的拼接

- **机制：** 日记、证词、公告、录音、照片和叙述者评论可以组成不同信息链。
- **怎么用：** 为每种材料标记制作人、时间、受众、保留理由和可信范围；让材料之间有互补或冲突。
- **边界：** 材料数量不等于证据强度；同源转述不算独立印证。

## HO-C11 反恐怖边界也能制造张力

- **机制：** 亲密、善意、日常秩序和安全感可以成为恐怖的对照面。
- **怎么用：** 先建立人物珍惜的生活，再让风险威胁其边界；也可以让善意行为成为真正的结局。
- **边界：** 不是每个故事都必须反转成恐怖；温情不等于“伪装”。

## HO-C12 隐形袭击与事后判断

- **机制：** 人物看不到威胁时，只能依据身体反应、现场痕迹和他人证词判断。
- **怎么用：** 分开写袭击、受害者感知、旁观者观察和事后解释；让调查者说明证据的证明范围。
- **边界：** 不把无法解释的症状直接判为超自然；也不把虚构法医程序写成现实指南。

## HO-C13 预言、选择与未发生的未来

- **机制：** 预言可能改变人物选择，即使其内容最终没有发生。
- **怎么用：** 记录预言内容、人物解释、采取的行动和可观察后果；比较字面兑现、误读、延迟和失败。
- **边界：** 预言不是事实证据；不能因人物相信就让预言自动成真。

## HO-C14 物态变化与规则边界

- **机制：** 物件、身体或环境状态的改变，可以让超常规则变得可见。
- **怎么用：** 先定义变化前后、触发条件、持续时间和代价；每次变化都要遵守同一规则。
- **边界：** 不用任意变形替代因果；物态变化不能随剧情需要无成本切换。

## HO-C15 温情、持续与有条件回归

- **机制：** 告别未必等于彻底消失；人物可以在保留记忆的同时重新建立生活。
- **怎么用：** 说明回归需要什么条件、谁能感知、会带来什么变化；也可以选择只留下记忆或物件。
- **边界：** 不强迫永久告别，也不强迫幽灵持续出现；结尾服务人物关系和类型契约。

## HO-C16 古宅与多种终局

- **机制：** 同一空间可以支持人类阴谋、规则性幽灵、开放解释或温情持续等不同终局。
- **怎么用：** 先建立共同输入（空间、声音、禁问、遗物），再为不同终局列出各自必须成立的证据。
- **边界：** 不把互斥解释混成一个“全都是真的”；如果要混合，写明各自作用范围。

## HO-C17 假神迹、真实消息与自我参与

- **机制：** 一场骗局可能利用真实但无关的信息提高可信度；人物也可能在不知情时参与了流程。
- **怎么用：** 分开记录真实消息、错误推断、操作者的安排和当事人的实际参与。
- **边界：** 真实细节不证明神迹；不提供现实诈骗、下药或规避调查的操作步骤。

## HO-C18 可见性、创造者与被讲述者

- **机制：** 谁创造、谁控制叙述、谁被描述，会形成权力和伦理关系。
- **怎么用：** 分开记录创造者的责任、被创造者的自主性、叙述者的知识范围和被讲述者的反驳机会。
- **边界：** 不把创造者意图当成被创造者的真实身份；梦境或自述也可能不可靠。

## HO-C19 声音负空间与残留痕迹

- **机制：** 声音缺席、异常轻响和无法清除的痕迹，可以比直接显形更有压力。
- **怎么用：** 先建立正常声响，再指出哪一种声音本应出现却没有；保留可重复检查的残留。残留也可以设计成再生的：除掉一次又回到原处，而且回得比上次更快、更多，让清除本身变成读者能数出来的一条进度线。这种痕迹要落在人物控制不了的地方才成立，否则只是重复打扫；它可以指认罪责，也可以只是尚未查明的物理原因，两条读法都要留。
- **边界：** 缺少声音不自动证明有东西；人物的听觉条件和环境噪声要交代。

## HO-C20 日常灾难、异常尺度与荒诞并置

- **机制：** 巨大灾难与日常流程并置，可以显示制度惯性、人的麻木或荒诞。
- **怎么用：** 让日常活动与灾难后果在同一时间线中相遇，并说明人物为何继续工作、照护或等待。
- **边界：** 不用喜剧语气抹去受害者；荒诞是叙事选择，不是对灾难的事实轻描淡写。

## HO-C21 假鬼之后的真警告

- **机制：** 一次误认被揭穿后，另一条警告仍可能成立；两个解释不必同时为真。
- **怎么用：** 分开追踪骗局的证据链和警告的证据链，让前一条被推翻时不自动抹掉后一条。
- **边界：** 不为了反转临时增加新威胁；每条链都要有自己的线索。

## HO-C22 奇异生物、民俗解释与接力叙述

- **机制：** 不同人物可以用民俗、医学、自然观察或个人经历解释同一生物/异常。
- **怎么用：** 让解释随人物知识和立场变化，保留各自的证据范围；多个讲述者可以逐步补足信息。
- **边界：** 民俗解释不自动是真实生物学；医生、猎人或专家也不必全知。

## 证据不足时的写法

如果只能确认一个概念或二手转述，标记为“待核”或“设计假设”，不要写成已经核验的作品事实。没有取得完整材料时，不推断作者意图、版本差异或历史制度。
