# MY-07 解谜设计案例机制库

返回 [guide.md](guide.md)。本文件只保留可迁移的设计机制与限制，不记录具体作品、作者或原句。它不是另一套规则，也不穷尽推理悬疑作品。

| 机制 | 可迁移的设计价值 | 必须检查的边界 |
|---|---|---|
| 颜色与身份识别 | 颜色、衣物、标记可以形成回声线索 | 同色或同源不等于两条独立识别链；先交代谁能看见、谁能辨认 | 
| 影像与相貌确认 | 照片、视频或肖像可以参与身份推断 | 核对影像取得、清晰度、时间、遮挡和辨认条件；“看起来像”不是唯一证明 | 
| 身体特征与能力推断 | 伤痕、步态、握力、感官或耐力可成为线索 | 不把文学观察写成医学定律；能力若承担解答，须提前建立且允许替代解释 | 
| 自白与文字谜题 | 自白后再揭示文字细节，可以改变读者对过程的理解 | 解码、理解、验证和回应分开；后置解释不能冒充读者早已可解的线索 | 
| 私密信息与亲缘识别 | 亲密信息、外貌或共同记忆可以改变身份判断 | 信息从何而来、谁能接触、是否存在模仿或误认，必须说明 | 
| 梦境与直觉 | 梦或直觉可以提供人物动机、恐惧或主题线索 | 梦不是独立物证；不得用梦境替代事实链 | 
| 公开披露改变知情分布 | 新闻、公告或公开声明会改变谁知道什么 | 公开不等于真实；披露时间、受众范围和二次转述要可追踪 | 
| 选择性毁损与保存偏差 | 留存或毁损本身可能暴露人物的接触范围和目的 | 先判断谁能接触、谁决定保存；不能从缺失自动推断内容 | 
| 数字、距离与时间 | 数字陈述可以产生可复核的检验任务 | 单位、换算、起止点和测量误差要一致；不自行修正不确定数据后再据此定案 | 
| 身体标记与心理暗示 | 胎记、习惯、暗示或记忆可能影响人物判断 | 单一标记不自动认证身份；心理暗示不等于可控或可靠的现实技术 | 
| 部分损毁的信件 | 残缺文本可让读者比较可见内容与缺失内容 | 不把未出现的句子补成事实；烧毁/剪裁由谁造成、何时发生要可解释 | 
| 身份确认与替身 | 身份确认可由多条证据逐步累积 | 不在揭晓时临时引入未建立的技能、关系或设备 | 
| 死亡确认与姓名确认 | 遗体、身份和死亡事实是不同的证明链 | 谁实际看见、依据什么辨认、记录由谁制作，分别核对 | 
| 证人、报告与利益 | 证言、报告和调查者可能受到利益影响 | 证人数量不是可靠性公式；同源转述不算独立证据 | 
| 单一线索与竞争解释 | 一条观察可以有两个以上解释，后续信息再区分 | 替代解释必须来自人物可知信息，不能只靠作者临时隐瞒 | 

## 使用边界

- 以上是创作设计检查，不是现实侦查、医学、法律或证据规则。
- 案例机制不能证明某类写法一定有效；目标读者效果需真实试读。
- 任何严格解谜承诺，都要检查揭晓前读者是否能接触必要信息。
