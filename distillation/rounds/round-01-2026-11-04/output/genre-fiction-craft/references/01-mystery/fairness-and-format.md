# 公平性核验

### 公平性核验记录

每个关键推理结论可用五栏记录：

| 栏位 | 核对问题 |
|---|---|
| 主张 | 侦探/读者此刻认为发生了什么？ |
| 线索 | 哪个可观察事实支持该主张？ |
| 可及性 | 读者是否在揭晓前有机会接触该线索？ |
| 替代解释 | 还有哪些解释尚未排除？ |
| 结论 | 后续证据如何支持、修正或推翻主张？ |

记录的目的不是把所有线索提前解释，而是确保关键结论有可追溯的证据链，且揭晓不依赖读者无法获得的信息。

### 篇幅与技法匹配

根据作品长度选择谜题复杂度，而不是先堆线索再压缩篇幅：

- **短篇：**聚焦一个核心问题、少量关键线索和一次主要解释转折。
- **中篇：**可以设置有限的子问题、误导和阶段性发现，但每条线索都应服务主谜题。
- **长篇：**允许多层证据、人物关系和并行调查；需要更清楚的回收与时间线管理。
- **连载：**每阶段既要有局部兑现，也要保留主谜题的持续动力。

这不是字数门槛；以读者能否记住线索、理解推理和感到公平为准。

### 公平性 Finding 五字段

每条已确认的公平性缺陷，按以下五字段成条记录，避免只写“读者没猜到”：

| 字段 | 要写什么 |
|---|---|
| **严重度** | 对解答、公平承诺或理解造成的实际影响；证据不足时标待验证 |
| **读者缺失的信息** | 揭晓所依赖、但读者当时无法获得或无法区分的具体信息 |
| **首次出现位置** | 线索、规则或必要事实第一次在文本中可见的位置；从未出现则写“未出现” |
| **为何是解答必要事实** | 它怎样排除竞争解释、支持唯一/较优解，或改变推理条件 |
| **最小修法** | 补前置线索、澄清边界、调整视角/信息权限或降低唯一解承诺 |

公平性不以读者是否猜中、猜中率或是否喜欢反转单独判定；先核对读者在揭晓前是否有机会接触必要信息。
