# 具体机制与历史条件

返回 [guide.md](guide.md)。这些卡供设计时选用；箭头右边是对应的 AT 规则。每卡只取当前场景需要的机制，不要求凑齐项目数。虚构参数和现实航海、工程、法律、安全知识分开处理。

## 一、机制卡 AT-M01–AT-M32

| 卡→对应规则 | 可迁移机制、使用条件与边界 |
|---|---|
| AT-M01→AT-02 | **财富与价值转化**：用清点、搬运、藏匿、放弃或交换把贪欲具象化；财货成本可以落在人命、关系、时间或道德选择上。财富不是唯一目标，也可以一步放弃，不强制逐级弃财。 |
| AT-M02→AT-03 | **物件与保存链**：记录、口头传闻、环境痕迹和物件状态可以互相印证或冲突。检查谁制作、谁保管、如何保存、为何在此、谁能发现；移动、损坏或重新埋藏会改变问题。不是每件物件都需要运输机关。 |
| AT-M03→AT-04 | **谜题解法链**：发现异常→提出假设→选择工具→尝试还原→核对语义→采取行动。碎片、印记、账册、谜语或行为都可承载线索；不强制逐步演示，也不设固定链节数。 |
| AT-M04→AT-06 | **队伍准入与职责**：成员可以凭专业能力、照护、补给或关系获得参与机会；同时说明责任、退出条件、否决权和信息权限。缺席者是否有决策权，取决于此前承诺。决策权可以随专业领域移动，谁当场解决一个只有他能解决的具体问题，谁的判断就多一分分量，他也要接着承担这件事的责任。 |
| AT-M05→AT-06 | **共同资产与分配**：财产登记、共同启用、债务上限、离队结算、遗留份额和担保会改变忠诚与背叛激励。凭证也可能被伪造；分配规则涉及强迫劳动或人身买卖时，保留压迫后果，不把它包装成理想契约。 |
| AT-M06→AT-08 | **供应链与秘密设施**：合法职业、运输、接应、遮蔽、伪装和废弃设施可以构成可调查的因果网。只按主角当前可知顺序揭示必要环节，并交代谁掌握哪一段。用恐怖传闻盖住一处真实用途时，给传闻留一条可查的物质来源，读者能在信灵异和信人之间自己选，不必由叙述者裁定。 |
| AT-M07→AT-07/11 | **俘虏政策与组织声望**：组织如何对待俘虏，会影响劳力、情报、赎回、威慑和声望成本。让不同成员围绕政策发生争论；角色的时代判断不等于现实伦理建议。 |
| AT-M08→AT-07 | **反派的多层动机**：公共说法、私下目标、忠诚关系、怯懦表演、伪装和专业能力可以互相错位。没有固定的反派类型或必然败法；让弱点来自本作已建立的行为和资源条件。 |
| AT-M09→AT-07 | **名声作为资源**：人物可以借名声获得资源、避让或谈判优势；实际接触也可能戳穿名声，或使其继续兑现。检查谁相信、凭什么相信、信念改变了什么。 |
| AT-M10→AT-17 | **目标线与生活线**：目标线兑现线索和获取；生活线把追踪转为人物关系、日常和动机变化。目标完成后可能空虚、改道或发现目标本身不再重要；也可以不安排这种反转。 |
| AT-M11→AT-08 | **逃亡与合法表面**：身份掩护、资产转换、供应路线、终点接纳和退出方式都是候选机制。路线受地理、交通、制度和人物知识制约；离队、返还物件或允许自由离去也能体现治理。 |
| AT-M12→AT-09 | **环境推断与心理残留**：心图、太阳、星象、重复计数、动物反应、噩梦和身体习惯可以提供线索或表现焦虑。区分观测与人物解释；救援后保留的行为变化不等于临床诊断。两个都失去主动能力、又都得等对方先倒下的人互相尾随，等待本身可以成为对决；这份对称只在双方同样濒死时成立，一方占优就换别的解法。 |
| AT-M13→AT-09 | **自我叙述与压力变化**：人物可能把现实任务重写成神话、英雄故事或自我辩护；外部感官刺激可以打断其叙述，再转向环境推理。刺激不限暴烈事件，不设固定心理阶段。 |
| AT-M14→AT-11 | **制度变化前后的行为差异**：同一行为在不同制度下可能有不同后果；小型组织也可能兼任证人、评议者和执行者。分别检查授权、程序、外部见证、法律边界和资源控制。 |
| AT-M15→AT-04/11 | **证据链与责任门槛**：残片、身份、物证、交易记录和观察结果可以串接调查；区分过失、意图、责任和证明标准。可以使用销赃、信用、监视和救援线索，但不要求每案都全套出现。手头的东西接不到指使者时，可以让他亲手完成一次处分，人和物就连进同一条链；成交已定、价款未付的那段时间是行动窗口。水底或废墟里的残留按层起出，新旧各成一层，读者看得出先后。 |
| AT-M16→AT-11 | **程序与管辖争议**：证人缺席、证据不完整、管辖异议、反诉、审理权限和执行责任都能形成攻防。释放或判决不必解决所有社会问题；也不要求每个受影响者都获得对等救济。 |
| AT-M17→AT-04/05 | **能力缺口与规则复用**：人物可能在某一领域缺少能力、在另一领域有优势；固定试验或操作惯例也可能成为危险来源。约束要在解决问题前建立，不能事后随意改变；能力差异不外推为现实群体本质。被设定为不会说谎的人物仍可只说一部分真话来误导，解套不能靠他突然改口。几条约束同时成立时，让满足全部条件的去处只剩一个，读者自己能收窄，不用等人物临时拿到新消息。 |
| AT-M18→AT-12 | **方法失效本身是信息**：工具失灵、攻击无效、误判或未能征服对手，都可以改变人物对威胁的理解。死亡不是证明方法有效的必要条件；对手未知也可以保留。 |
| AT-M19→AT-18 | **时代偏见与伦理边界**：殖民、种族化、奴役、性别工具化和能力本质化可作为历史话语或反派立场呈现；不得当作现实规律。保留受影响者的处境和后果，不把偏见包装成通用技法。只从旧偏见的说法里才找得到的机制，先分出哪层是立场、哪层是可迁移的动作，再把动作的主体换成这个人物或这个组织的具体局限，最后检查由别人代述的那段是否改回本人自述。 |
| AT-M20→AT-10/06 | **拆解奇观**：人物可以把看似超常的现象拆成可观察道具、操作和限制；也可以保留真正的奇幻解释。理性承诺下可提供可检验线索，奇幻作品不因未机械化就判错。作品把某套技术或治理写成普惠方案时，用最弱成员的实际处境验收：他有没有分到食物、照料和退出机会；只报总量增长不算验收。 |
| AT-M21→AT-17 | **多类型结算**：仪式、预言、回到开场地点、名誉回环、体面谎言、身份变化、法律缺口、技术去留、家庭封存和秘密消失都是不同收束方式。按本作承诺选择，不设固定结尾顺序。 |
| AT-M22→AT-13 | **权力系统的可见限制**：隐形、遥控、制度控制、知识封锁和武力优势都需要边界；让反抗者知道限制如何影响行动。不得提供现实伤害或压迫操作教程。 |
| AT-M23→AT-01 | **冒险目标不止宝藏**：知识、信物、人物、地名、生存、自由或修复关系都可成为目标。不要用宝藏、险途和竞争三件套强制判定“正格冒险”。 |
| AT-M24→AT-12 | **恐惧、诱饵与群体情绪**：诱饵、自我暗示、广播、群体传言和情感锚点可以改变行动。区分人物信念、可观察证据和世界规则；不把“爱强于恐惧”等角色判断写成强度定律。 |
| AT-M25→AT-09 | **封闭环境与生存条件**：空气、压力、通道、堵塞、探测和位置变化可以形成危险链。参数按虚构设定核算；现实潜水、工程和安全操作需独立专业资料。 |
| AT-M26→AT-15 | **叙述者暂停与道德重估**：叙述者可以短暂停下动作、承认敌手的人性或改变观看距离；宁静环境也能与暴力错位。不能因此抹掉读者理解代价所需的信息。 |
| AT-M27→AT-04/10/16 | **伪造文书与机械揭底**：折痕、印记、材料、维修痕迹和记录链可以暴露伪造；先建立物理条件，再揭示欺骗。先揭一个假谜可能增加后续真谜，也可能误导，按公平承诺判断。 |
| AT-M28→AT-18/11 | **替罪羊与群体解释权**：群体可能把失败转嫁给弱势者；营救、恶作剧、迷信和公开指认属于不同伦理情境。可以写复杂主角和受害者后果，不将陷害包装成现实建议。这类转向要成立，群体得先有一套现成可引用的解释，指认也发生在自己的方案刚失效、暴力即将落地的当口；指认者事后要承担可见代价，不能写成无损脱身。 |
| AT-M29→AT-15 | **冒险中的喜剧声部**：危险、误听、夸张、身体闹剧、语言游戏和关系竞争可以承载喜剧；同一角色可以在不同场景跨越语调。喜剧不自动取消后果。 |
| AT-M30→AT-15 | **信号降级与信息缺席**：警报、灯光、消息中断、突然发现船或队伍不在，都能把灾难转到知觉和信息层。交代信号如何被理解，不让缺席成为无因果的惊奇。 |
| AT-M31→AT-16 | **插入章节的尺度**：整章被掳、航程、夜间仪式、哗变、审理、自供或脚注，可以改变叙述节奏。选择插入的尺度应服务人物经济理性、信仰、尊严和悲剧，不规定固定篇幅百分比。 |
| AT-M32→AT-17 | **诗性正义与反噬**：反派的欲望、背誓、回到旧罪现场、受害者遗存或自毁，可以形成因果回环；提前铺设行程和选择以减轻巧合。超自然惩罚不等于已证物理事实。 |

## 二、补充卡 AT-RE01–AT-RE18

| 卡→对应规则 | 可迁移动作、反例与边界 |
|---|---|
| AT-RE01→AT-14 | 第二人称“日常→危险”可作体验式开场；普通人物偶然进入也可。第三人称、第一人称和框架叙述都是可选入口，不因缺少某种人称而禁用。 |
| AT-RE02→AT-05 | 报道只有不相关简讯，可能暗示被压下的事件；假消息、伤情信或助手报告也可作为绑架线索。可以隐去答案，但不能伪造已经确立的材料。 |
| AT-RE03→AT-11 | 以一项资源或人身自由交换另一项利益，是特殊的虚构交易；需写清谁有权同意、谁承担代价、能否撤回。不得把强迫交易写成普遍制度模板。 |
| AT-RE04→AT-10 | 神话功能可以迁移到科技或太空设定；变形装置先给外壳线索，再展示功能。保留人物的神话/科学并列解释，不强制遗迹科技化。 |
| AT-RE05→AT-04 | 标题物象可以反复改义，不设固定出现次数。物件首次承担普通功能，后来在新语境中改变意义；若成为解谜线索，仍要有公平提示。 |
| AT-RE06→AT-14 | 落魄处境、化名、未知前史和共同困境可组合成开场；不把某一地理位置或某类场所规定为唯一开局。 |
| AT-RE07→AT-14 | 目录、预告或开篇说明可以改变读者知情范围；也可以只给地点或留白。提前透露会把悬念从“是什么”转为“如何发生”，按目标选择。 |
| AT-RE08→AT-08 | 变装可涉及外貌、姿态、声音、习惯和身份材料；援救、再次潜入或计划失败都要有资源和信息条件，不把“伪装大师”当万能解释。 |
| AT-RE09→AT-09 | 普通人的旧技能、职业反射和日常经验可以成为生存资源；说明技能如何迁移、何时失效，不要求所有人物都完成同一成长弧。 |
| AT-RE10→AT-17 | 结尾可以保留人物对技术、神秘现象或动机的不同解释；若事件已经结算，仍可让解释保持未知。 |
| AT-RE11→AT-04 | 字母、纹章、胎记、信物和徽号可以引出身世；保存链、复制、解释和权利分开。身份符号不自动证明亲缘或所有权。 |
| AT-RE12→AT-14 | 歌谣、口述和诗句可以提供地方记忆与余韵；依它解谜时要建立传承和解码条件。章末诗是局部形式，不是每章必需。 |
| AT-RE13→AT-09 | 感官线索可以连接梦、越界与现实，也可以有意跳切；醒来后的推测仍需标明是人物猜测还是已确认事实。时间定位需说明参照条件。 |
| AT-RE14→AT-16/17 | 年长者口述、幸存报告或死亡闭合都是可选框架；不强迫叙述者死亡，也不让口述自动证明全部事实。 |
| AT-RE15→AT-17 | 未归、目标抵达、关系去向与运输结算可以分别开放或闭合。某条线未完成，不等于其他线都不能结算。 |
| AT-RE16→AT-14/17 | 丢弃名单、信件、工具或拒绝自述，都可以成为行动结尾；人物沉默的理由可以不同，不要求所有角色都道德高尚。 |
| AT-RE17→AT-09 | 日期、方向、天气和缺失日可以控制信息；地图或日志可能被操纵。记录来源、传递和可核实范围，不把一份日志当成全知档案。 |
| AT-RE18→AT-14 | 演出、仪式和公共活动可以映照主线人物的反应；歌声、静默和环境声同样有效，不强制终章必须安排表演。 |

## 三、其他机制：满足条件时接入

| 机制 | 可迁移内容与边界 |
|---|---|
| 目标与证据路由 | 海图、仪表、制度文书和口述按实际功能选择；目标可以是长生、知识、逃生、自由或身份。区分证据、人物解释和传闻，不把分类表当互斥类型。 |
| 正当性独立 | 授权、程序、关系、伦理和实际控制是不同层；让角色用法律或荣誉为行动辩护时，仍要检查受影响者和执行者。 |
| 物证可改写 | 船名、货标、复制品、旧图和笔迹都可能被伪造；增加复核路径，不强制每件物证都不可信。 |
| 制度时序 | 消息延迟、抽签顺序、公开排名和接近目标的差距可以形成悬念；说明规则、知情人和结果，不把偶然误写成公平。 |
| 非标准结算 | 婚礼、葬礼、物件交接、离开或拒绝都能成为结算；不要求所有冒险以婚姻、财富或胜利结束。 |
| 独占与分散 | 一人见过物件和多人知道位置是不同信息结构；在同一作品内说明传递、保管和误认。知情者离场也会改变调查路线。两种安排代价不同：走独占，读者插不上手，要另外给出可核对的旁证；走分散，就得同时管住几组动机和信息差。 |
| 海图与撤离 | 地图定位、自救、未记载地形、资源清单和运输条件会改变路线；不把虚构航海数字认证成现实参数。 |
| 声音四用 | 歌声、警报、地名、节拍和通信信号可以承担凶兆、警报、身份或信息功能；读者未解码不等于人物不能据此行动。 |
| 伪装成功与失败 | 宴会身份、服装、发型、货物、航线和船名都可能被伪装；交代检查者、可见线索和失败成本，不要求每次伪装都成功。 |
| 多种框架与开场 | 步行离乡、酒馆谈话、客栈、密闭空间、湖底或接舷都可以开场；框架叙述、幸存报告和非英雄自评也可用，不按篇幅固定。 |
| 讽刺与信念 | 开篇可以明示戏仿；人物对科技、神迹或护符的信念可以与可观察事实并列。按本作承诺判断真伪，不因体裁标签自动裁决。 |

## 四、跨题材接口与读者辅助

时间账本、时区反转、倒计时和日记切换保留为时间结构接口；鬼地掩护可接恐怖，间谍、洗白和身份置换可接身份权谋。混用时仍按信息持有者、世界条件和行动后果检查，不把跨题材接口当作已经验证的现实机制。异域头衔、一见钟情、赌局救场、连串绑架、英雄被擒、易容、赎身、讣告式收束和情绪武器夸张这类常见成规不设绝对禁写清单；在本作里承担新功能并产生新的后果就可以用，只照搬套路而不改变任何后果的，按无效铺陈处理。
