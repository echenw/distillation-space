# CO-04 开篇、重复、兑现与形式

返回 [guide.md](guide.md)。

## CO-04A 开篇建立可读关系

开篇可给期待、距离、规则、人物冲突、气氛、悬念或既有系列联系，可以单用或组合，未立即识别机制不自动失败。伪精确清单、元叙述声明、通感/比喻冷开场都是选项；抒情开场无需给另外两型当装饰。承接既有系列关系、直接家务争论和戏仿族谱，是不同进入方式。

作者想立即危险或哀伤时，不强塞喜剧预告。想写缓慢进入也可渐建期待。预告到兑现没有固定行数、场次数或章节上限；某个外观或身份线索可以在较晚场景才显露，时点取决于信息、节奏和前置铺垫。

## CO-04B 重复先查功能，再决定变奏

记录每次出现的位置、对象、语气、代价、主动权、关系、用途、索取者及作者目的。变化可以支持推进，但变化本身不证明有效；完全不变也可形成仪式、习惯、累积、刻意停滞或荒诞。不因同一机制连用、双归属、称谓重说或两项清单未变自动删。

需要变奏时，可换人说、换对象、打断、抢答、照字面执行、让角色自己识破，或改变后来对前文的理解。同一句话或同一件事实还可以交给一串说话人依次说出，身份一档档下降、或者一个比一个更不该说这句话，最后落到最不合适的那个人身上；这种排列靠的是说话人序列，与只换一次人说不是同一种手段。重复签名能从信息变熟悉契约，称号可成为第三方承认的身份，物件或词语可被不断记账。角色把某件物品视为厄运标记，只说明人物如何解释，不自动证明故事世界中存在相应因果；同一物件从提示物转为口令载体或身份凭证时，应逐次展示功能变化。

当用户报告“读累了”，这份体验本身是已提供信息；未证明的是重复怎样导致它。可检查冗余、预期过易、信息不清、情绪单调、无目的中断或节奏不符，然后给可比较的改稿。拿到问题稿先分三类再开方：整场没有笑点是缺供给，笑点都在却互相抵消或重复疲劳是缺调度，该笑的地方不笑、不该解释的地方抢先解释是站位与信息问题；三类修法不同，一律用“再加几个包袱”处理会掩盖前两类。角色的一项短期冲动迅速耗尽，不是阅读疲劳实验。故事内出现别的人物模仿、接管或批量复制某人的招牌做法时，把它当作人物处境的变化来写：谁被顶替、损失落在谁的合同或名声上；不要由这条情节推出读者会因为重复某个招数而疲劳，两者不是同一件事。

## CO-04C 节拍与兑现位置

可以试用三拍递增、两拍突转、多拍清单、递减、延迟、断句、最强末句或弱结尾。三拍不是最小必要单位，七连也不证明三拍。选择末位句要考虑场景目标：有时笑点收束，有时让余韵、悬念、哀伤或平淡继续。舞台观众反应不能直接变成小说章末命令。双人搭档结构里还有一个可试排的动作：把一句笑点分给负责冷静回应的一方之后，紧接着让制造者一方给出更强的回应，使这一轮的落点回到主动者；只有单一视角、没有稳定回应位时不适用，此时不要为补齐这一对而临时塞一个插话者。

同场反转、后场解释、画外回响、读者独知或有意留白均可。POV约束谁能合法知道、怎样呈现，不唯一决定何时兑现。现场发生、回忆转述和事后文件各能有节拍；不能把讲出来的幽默一律改成演出来。解题者需要与其作用相容的信息、推断、资源或既定神奇能力，未必逐项提前解释；若依赖公平谜题契约则另核所需线索，不能仅因不符合某种固定机智角色范型就禁用聪明解法。另一种可试排的先后是：让读者先掌握某个机制或规则，再让后续结果由这个已被了解的机制自行落地，收束时不再补解释；采用时核两件事，机制到场是否真的早于结果，以及它有没有退化成一个纯说明段。

## CO-04D 省略、拒写与文件

篇幅短会限制容量，长篇也有注意和节奏限制；两者都可铺陈或省略，按目的取舍。拒写可以给理由、替代内容、结果、转述、记者迷路或有意不解释，也可以升格为全书“不写天气”的体裁玩笑。作者承诺交代的关键因果须能理解；单纯省略不是没想清楚的证据。

文件层可放报纸、译者注、声明、附录或函件，让它与其他声部在事实、态度、遗漏或语气上产生关系。完整报头日期签名是一种拟真选择，节录也有效；不要求至少一处客观事实矛盾、不准仲裁或固定文件数量。旧事实和文件可相互拆台，读者也可在后文得到裁决。

## CO-04E 舞台节奏只作试排，不换算成小说公式

舞台段落的时长与节拍受语言、停顿、动作、演员调度和观众反馈影响。可通过排练记录实际表现；不要把历史舞台口径当现代实测或长篇公式。表演性场次可以按「先让看的人知道要发生什么、再当场做出来、事后用一句回顾确认」三段排；这只是一种容器，小说段落不要求照搬，三段也不要求都到场。

| 可调参数 | 适用方式与边界 |
|---|---|
| 独白/独幕时长 | 按实际语速与停顿计时；不把词数硬换算成时长或小说字数 |
| 音乐/群戏结构 | 可交替安排情节推进、独唱/群戏、喜剧节拍、高潮、解决与闭幕；比例按本作调整 |
| 尾声长度 | 句数服务于余味与收束目标，不设统一最短/最长 |
| 笑点节拍 | 可试递增、递减、重复、突转、延迟或弱结尾；不设必笑次数 |
| 表演分工 | 主要表演者与回应者可互相衬托，也可打破固定分工 |
| 信息呈现 | 若需要观众先于人物知道某个行动者或物件，可先展示；不是全部视角定律 |
| 结局期待 | 误认、反击、快乐结局等属于可选设计；按当前体裁承诺处理，不推断市场偏好 |



规则可以保留例外，让熟练人物在条件允许时超越公式。保留例外成立的前提，不把某个数值制定成小说硬门槛。
