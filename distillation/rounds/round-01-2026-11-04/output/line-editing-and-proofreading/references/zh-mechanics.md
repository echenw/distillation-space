# 中文机械校对（SR-13 至 SR-15）

返回 [SKILL.md](../SKILL.md)。

机械校对放在最后一轮做：句子还在大改时，标点会跟着变。

**依据**：标点按国家标准 GB/T 15834-2011（标点符号用法），数字按国家标准 GB/T 15835-2011（出版物上数字用法），字形和词形参考国家通用规范汉字表、异形词整理规范和规范现代汉语词典。下面是这些标准的通行要点，没有逐条对照标准原文。出版社或平台有自己的体例时，以它们为准；让渡只到体例层——外部体例改变“同一类写法选哪种”，不覆盖错别字、引文原貌和事实、专业含义方面的错误。

**总原则**：先分清“错误”和“体例差异”。错误要改；体例差异只要求全稿统一，不判对错。拿不准时，以稿子里占多数的写法为准。

## SR-13 标点

### 全角与半角

- 中文正文用全角标点（，。？！：；“”‘’（）《》——……）。输入法切换造成的半角逗号、句号、引号（`,` `.` `"`）要改成全角。
- 阿拉伯数字、英文字母、英文引文用半角。英文引文内部的标点按英文。

### 引号

- 用“”，引号里再引用时用‘’。不用「」『』，除非全稿体例如此。
- 本包用「」标记术语与条目名，稿件引号仍按 SR-13。
- 引用的话独立成句时，句末标点放在引号里面：他说：“我明天走。”
- 引用的部分只是句子的一个成分时，句末标点放在引号外面：他说的“明天再说”，其实就是不想去。
- 表示特殊含义、反语的引号（所谓的“朋友”）不要用得太多，用多了就没有效果。

### 对白格式（SR-14）

| 提示语位置 | 写法 | 说明 |
|---|---|---|
| 在前 | 他说：“我明天走。” | 提示语后用冒号 |
| 在中间，是“说”类动词 | “我明天走，”他说，“你别送。” | 前半句末尾用逗号，放在引号内；提示语后用逗号 |
| 在中间，是动作描写 | “我明天走。”他把行李往门口推了推。“你别送。” | 动作是独立的句子，前后各自成句 |
| 在后 | “我明天走。”他说。／“我明天走，”他说。 | 两种写法都常见，选一种全稿统一 |
| 没有提示语 | “我明天走。” | 连续多轮无提示语对白，每隔几轮让读者确认一次谁在说话 |

- 一个人连续说好几段话：每段开头用前引号，只有最后一段末尾用后引号。
- 内心独白可以不用引号，也可以用引号或改变字体，全稿统一即可。
- 电话、隔墙等听到的声音，按普通对白处理；书信、短信、纸条可以用引号，也可以另起段缩进，全稿统一。

### 省略号与破折号

- 省略号是“……”（六个点，占两个字的位置）。不用“...”“。。。”“…”（三个点）。
- 省略号前的逗号、顿号不再保留；省略的内容是完整的句子时，省略号前的句号、问号、叹号保留：“屋里很静。……他忽然笑了。”“你到底想说什么？……算了，当我没问。”
- 省略号不和“等”“等等”连用。
- 破折号是“——”（占两个字的位置）。不用“--”“—”（单个）或“一一”。
- 对白里，省略号表示话没说完、吞吞吐吐、声音渐弱；破折号表示话被打断、突然转折、声音拉长（“救——命——”）。两者混用时，按这个区别统一。

### 顿号、逗号、分号

- 顿号用于并列的词语之间：桌上摆着碗、筷子、一壶酒。
- 并列的书名号之间、并列的引号之间，通常不用顿号，直接紧挨排列即可。
- 相邻两个数字连用表示概数，不用顿号：三四个人、十五六岁、七八十里。
- 一逗到底的长句：意思已经转了几层，就在合适的地方断成句号；不要用顿号代替逗号。
- 分号用于并列分句之间；小说叙述里用得少，用多了显得像公文。

### 问号与叹号

- 选择问句中间用逗号，末尾用一个问号：你走，还是我走？
- 疑问中带强烈感情时可以用“？！”。叠用问号、叹号不超过三个；叙述部分通常只用一个。
- 不是疑问句的句末不用问号（“我不知道他去哪了？”→“我不知道他去哪了。”）。

### 书名号、间隔号、括号、连接号

- 书名号用于书名、篇名、报刊、电影、戏剧、歌曲、文件名，小说里虚构的书和功法典籍也用书名号。会议、奖项、商品、课程、机构的名称不用书名号。
- 间隔号用于外国人名、少数民族人名内部的分界，例如自拟的音译人名“玛丽亚·罗西”。
- 括号注释句中某个词时，紧跟在那个词后面，括号内末尾不用句号；注释整句时，放在句末标点之后，括号内可以有自己的句号。小说正文里尽量少用括号，插入说明可以改成破折号或拆句。
- 时间、地点的起止通常用一字线“—”，数值范围通常用浪纹线“～”：1999—2005年；30～40人。

## SR-15 的地得、数字、错别字、体例

### 的、地、得

| 字 | 用在哪里 | 例 |
|---|---|---|
| 的 | 定语和名词之间 | 冰冷的手、他的刀 |
| 地 | 状语和动词之间 | 慢慢地走、狠狠地瞪了他一眼 |
| 得 | 动词或形容词和补语之间 | 跑得快、气得发抖、冷得说不出话 |

- 判断：“的”后面是名词，“地”后面是动作，“得”后面是程度或结果。
- 有的作者把“地”都写成“的”，这是旧习惯或个人体例。全稿一致时保留，混用时按上表统一。

### 数字

- 小说叙述中的数量、年龄、时间、日期，通常用汉字数字：三个人、二十岁、五点钟、腊月二十三。
- 统计、编号、计量、需要醒目的场合用阿拉伯数字：第 3 号房间、37.5 度、2048 年（科幻、都市背景里常见）。
- 成语、惯用语和固定说法里的数字只能用汉字：三心二意、一五一十、九死一生。
- 概数用汉字，不加顿号（三五天）；“约”和“左右”不同时用（“约三十人左右”删一个）。
- 汉字数字的年份用“〇”（二〇〇八年），数值里的零用“零”（三百零五）。年份不简写（“19年”写成“2019年”或“二〇一九年”，按全稿体例）。
- 同一稿件里，同类数字要统一，不要前面“三个人”、后面“3个人”。

### 常见错别字与易混词

**容易用错的字**

| 错 | 对 | 说明 |
|---|---|---|
| 再家等着 | 在家等着 | “在”表示处所和进行，“再”表示重复和以后 |
| 好象 | 好像 | “像”表示相似，“象”用于大象、形象、现象、象征 |
| 自已 | 自己 | “己”是自己，“已”是已经，“巳”是地支 |
| 既使 | 即使 | 即使、即便、立即；既然、既……又…… |
| 带帽子 | 戴帽子 | 戴：帽子、眼镜、手套、首饰、爱戴；带：携带、带路 |
| 一幅眼镜 | 一副眼镜 | 副：成套、成对或表情（一副笑脸）；幅：布帛、字画（一幅画） |
| 截止昨天 | 截至昨天 | “截至”后接时间点，“截止”指到时停止（报名已经截止） |
| 必需完成 | 必须完成 | 必须＝一定要；必需＝不可缺少（必需品） |

**常见错别字（右边是正确写法）**

震憾→震撼、松驰→松弛、寒喧→寒暄、安祥→安详、气慨→气概、霎那→刹那、暮然回首→蓦然回首、座落→坐落、陷井→陷阱、针贬→针砭、蜇伏→蛰伏、竞然→竟然、幅射→辐射、布署→部署、迫不急待→迫不及待、再接再励→再接再厉、莫明其妙→莫名其妙、走头无路→走投无路、甘败下风→甘拜下风、一愁莫展→一筹莫展、不径而走→不胫而走、按步就班→按部就班、一如继往→一如既往、声名雀起→声名鹊起、金榜提名→金榜题名、黄梁一梦→黄粱一梦、容光涣发→容光焕发、发人深醒→发人深省。

**常被误用意思的成语**（标出来请作者确认，不直接改）

| 成语 | 实际意思 | 常见误用 |
|---|---|---|
| 差强人意 | 大体上还能使人满意 | 当成“不能让人满意” |
| 美轮美奂 | 形容建筑物高大华美 | 用来形容普通事物美好 |
| 首当其冲 | 最先受到攻击或遭遇灾难 | 当成“首先”“带头” |
| 万人空巷 | 人们都从家里出来（聚到某处） | 当成“街上空无一人” |
| 七月流火 | 农历七月天气转凉 | 当成“天气炎热” |

人物在对白里用错成语，可能是作者有意刻画，先问再改。

### 异形词

同一个词有几种写法时，以通用规范与权威词典推荐写法为准，例如：身份（不作“身分”）、成分（不作“成份”）、交代（不作“交待”）、倒霉（不作“倒楣”）、糊涂（不作“胡涂”）、笔画（不作“笔划”）、折中（不作“折衷”）。拿不准时，不强行改，只保证全稿一致。
