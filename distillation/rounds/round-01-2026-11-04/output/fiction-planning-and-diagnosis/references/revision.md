# 修订工作流：分层改、可回退、能回归

> 适用：已有成稿，要删减、压缩、重排结构、修场景/句段；连载超长要收缩；编辑要求“删到 X 字”。
> 不适用：还没诊断就改（先 `references/diagnosis.md`）、没有授权就整章重写、纯校对、出版排版。
> 规则细节见 FC 规则的正文（四个 rules- 开头的参考文件，按编号找，见 SKILL.md §6）；本文件只给修订顺序、删减判据、回归项与版本纪律。

---

## 0. 修订前置：冻结、范围、授权

| 项 | 要求 | 缺失时 |
|---|---|---|
| 原稿 | 只读；另建修订版/修订单 | 先复制版本，标 `v1` |
| 范围 | 全书/某几章/某场；目标字数/章数 | 只说“太长” → 给三个删减方案与代价 |
| 授权 | 定位/建议/最小改写/整场重写/结构重排，哪一级？ | 默认只到“定位+建议+可选最小改写” |
| 必须保留 | 已发布章节、关键场面、类型承诺、作者底线 | 标“未知”，不擅自删 |
| 回归项 | 改后必须仍成立的：主行动/视角/承诺/类型契约 | 先列 3–5 项，否则改完无法验收 |

**卡住时**：没有目标字数/必须保留项 → 不直接删；先做“删减方案 A/B/C”，各写删什么、代价、风险，让作者选。没有授权 → 只出修订单，不动正文。

## 1. 三个层级（不要跳层）

| 层级 | 改什么 | 典型问题 | 对应规则 |
|---|---|---|---|
| **结构层** | 主行动、线、终点、单元、章末、开篇 | 无主行动、中段塌、结尾欠账 | FC-03/04/06/07/08/09/10 |
| **场景层** | 视角、信息差、可信度、细节、主题、类型承诺 | 视角失守、巧合解结、人物工具化、类型失约 | FC-05/11/12/13/14/16/20 |
| **句段层** | 句子、语域、节奏、套语、点题句 | 文体空泛、朗读拗口、说教 | FC-14/15/16 |

**顺序**：结构 → 场景 → 句段 → 校对。跳层的典型症状：句子越改越漂亮，中段仍然塌；删了很多形容词，主行动仍然不清。

**卡住时**：说不清每场功能 → 不要进句段层；先做结构层（R1）。结构层改不动 → 只做“诊断+方案”，不要用句段润色冒充修订。

---

## 2. R1 结构层：先定“承重”，再谈删

### 2.1 结构诊断（这一步只诊断，不动正文）

1. 写 `主行动`（FC-06）；写不出 → 回 `references/planning.md` 第 5 步。
2. 列 `线[]`（function/intersection）；无交汇 → 删/并。
3. 标 `终场/终局状态`（FC-04）与 `结尾约定`（FC-10）。
4. 做 `单元表`（FC-07）与 `单元收束表`（FC-08）：每章/场 type/function/state_changed。
5. 标 `开篇约定`（FC-09）：四职是否齐全。

### 2.2 结构处置

- **删线**：次线不改变主线条件 → 删/并/降背景；不要因为“人物可爱”保留。
- **并章**：两章功能相同/状态都未变 → 并；并后仍无状态改变 → 删。
- **补交汇**：多线应共享终局 → 补一场“同一决定/同一场面”；补不出 → 降为次线。
- **移终点**：高潮过早/过晚 → 调 `主汇合`；3/4 是操作默认参考，不是硬门。
- **换开篇**：四职缺失 → 按 FC-09 换入口；不要靠加“爆炸/尸体”解决。

**卡住时**：结构层改完仍说不清主行动 → 停止修订，回到规划；不要继续删句子。作者拒绝删线 → 要求写“它改变了主线的哪个条件”；写不出 → 标为背景，不进入主线。

---

## 3. R2 场景层：逐场过五关

对每个保留场景，按顺序检查：

1. **目标/阻力/转折**（FC-07）：缺一项 → 这场不成立；改或删。
2. **视角合同**（FC-11）：越界/无标记切换 → 改回/补标记；切换无 benefit → 不切。
3. **信息差**（FC-12）：读者/人物知识状态是否清楚；揭晓是否改变处境。
4. **可信度**（FC-13）：巧合是否在解结；类型豁免是否内部自洽。
5. **细节/主题/类型**（FC-14/16/20）：细节是否按视角过滤；点题是否落在行动；类型承诺是否推进。

**场景处置**

- **删场**：功能重复/无状态改变/纯装饰 → 删。
- **并场**：两场同一目标/同一对抗 → 并成一场。
- **压场**：必要但无趣 → 压成概述（FC-19 “必要但无趣只压缩不删”）。
- **补场**：关键对抗被概述/转折缺因 → 补一场。
- **换视角**：当前视角拿不到关键信息 → 换 reflector 或改框架；不要临时“换脑”。

**卡住时**：五关中任一关缺证据 → 标“待验证”，不要凭感觉改；先做最小验证（见 `references/diagnosis.md`）。场景目标写不出 → 这场可删/并；不要用对话硬撑。

---

## 4. R3 句段层：只改可诊断的

1. **朗读**：标拗口/换气/重音落错处。
2. **主谓**：每句找主语/主动词；名词化改动词；无主语补主语或改句。
3. **删套语/装饰**：套语、同页换称呼、装饰性形容词；删“得意句”前判断是否承担转折/揭示。
4. **语域**：是否与视角人物/场景一致；不一致 → 改回人物语域，不直接加方言。
5. **点题句**：逐句删，读行动是否仍成立；成立 → 删/改人物选择（FC-16）。
6. **类型音高**：华丽是否服务事件/人物；不服务 → 降调（FC-15 B 分支）。

**卡住时**：朗读仍拗口且改不动 → 标“风格问题”，停止句层打转；回结构/场景。删点题句后主题消失 → 主题没落在行动里，回 FC-16 `证明场`，不要加更多点题句。

## 5. R4 删减：四类对象，四种处置（FC-19）

### 5.1 先分类

| 类别 | 例子 | 先问 |
|---|---|---|
| **事件/场景** | 整场追逐、整章支线、重复的危机 | 删掉后主行动是否改变？是否唯一因？ |
| **句子/词** | 套语、重复解释、装饰性形容词、同义反复 | 删掉后意思是否缺？是否服务节奏/语气？ |
| **解释/点题** | 作者总结、人物口播主题、背景说明块 | 是否有第二个载体？删后行动是否仍成立？ |
| **人物/支线** | 功能人物、无交汇次线、重复对照 | 删掉后主线是否变？是否唯一提供某信息？ |

### 5.2 三问与处置

对每条候选：

1. **是否改变主行动？** 是 → 留；否 → 进第 2 问。
2. **是否唯一承载必要事实？** 是 → 留/压；否 → 进第 3 问。
3. **是否服务语调/人物？** 是 → 留（检查同调）；否 → 删/并。

处置只有四种：**删 / 压 / 并 / 留**。不要用“改写得更好”代替删除；改写会保留篇幅，可能不解决超长。

### 5.3 分赛道

- **A 情节驱动**：先删解释/重复，再压次要场景，最后才动人物；唯一因不能删。
- **B 氛围/素描/文学**：先保 tone，再压重复；删描写即毁的段落不按 A 标准删。
- **C 商业短篇**：先删解释/重复，再压场景，最后动人物；不能删到人物扁平/类型承诺失效。

### 5.4 特殊规则

- **“必要但无趣”只压缩不删**：保留信息，压表达。
- **“真实但无用”可删**：不能以“我查过资料”为由保留。
- **inclusive 的生活面向**：B 分支保留，但按语调同调筛选；不因体面删生活。
- **已发布章节**：不能回改；只能在未发布部分补过渡/补偿，或在新版本中标注“已发布版不改”。

**卡住时**：三问答不清 → 不删，标“承重待定”；做“抽掉这一段，复述主行动”测试。删后主线断 → 回退，改压/并；不要用“补一句解释”掩盖删错。作者拒绝删 → 给四方案与代价，不替作者选。

## 6. R5 回归/复验：改完必须能通过

回归不是“再读一遍”，而是按固定项验收。至少做以下 6 项：

| # | 回归项 | 怎么验 | 失败时 |
|---|---|---|---|
| 1 | 主行动仍清楚 | 一句话复述；抽线测试 | 回 R1，不要句层修补 |
| 2 | 人物仍可信 | 三决定测试；删人测试 | 回 R2 场景目标/人物欲望 |
| 3 | 视角合同未破 | 知识审计 + 切换账本 | 回 R2 视角 |
| 4 | 承诺已兑现 | `兑现记录` 逐条勾 | 补/删钩子 |
| 5 | 类型契约仍成立 | 3–5 必要特征 + 偏离补偿（FC-20） | 改契约或补补偿 |
| 6 | 文体底线 | 朗读 + 主谓抽样 | 回 R3 |

**回归纪律**

- 回归项在修订前就写进 `RV-10`；改完逐项勾，不能改完再想“要保留什么”。
- 回归失败时，先回退到 `回退点`，不要在坏版本上继续叠改。
- 回归通过 ≠ 效果验证；只证明“改动没有破坏已声明的结构/契约”，不证明读者会喜欢。

**卡住时**：回归项 3 项以上失败 → 回退到上一版，重新做结构诊断；不要“边改边救”。类型契约与作者意图冲突 → 标未决，让作者选；不擅自改类型。

## 7. R6 修订循环与版本（FC-17、FC-21）

### 7.1 循环

1. **冷却**：完稿/大改后放置数日到数周；短篇可缩短，但不能当天改完当天定。
2. **冷读**：以陌生人视角通读，标“不懂/不信/不想读”处；不边读边改。
3. **分层改**：R1 → R2 → R3；每层结束做一次回归。
4. **单稿留痕**：同一份修订版保留原句/原段（删除线/批注/版本对照）；不要誊清后丢失原句。
5. **停止规则**：连续两轮没有新的结构发现 → 停止结构层，转句层/校对；不要用“再改一版”解决判断疲劳。

### 7.2 版本

- `v1` 原稿（只读）→ `v2` 结构修订 → `v3` 场景修订 → `v4` 句段/校对；每版写“改了什么/为什么/回归结果”。
- 每版至少一个 `回退点`（可回退的原句/原段/原章）。
- 版本号不证明质量；修订次数不是指标——有的改一遍就停，有的反复多轮，何时停按目标已完成、继续改没有明确收益来判断，不按次数。
- 例外登记：哪些规则被有意违反、代价、是否可学（FC-21）；不把例外写成新规则。

### 7.3 停止/退出

- 目标字数已达到但回归失败 → 不加字数，先修结构。
- 目标字数达不到且不能删承重段 → 重设目标，或改结构（加线/并线），不要硬删。
- 作者失去判断 → 停止，换读者/冷却/换顺序；不继续叠改。
- 修订的整体效果记“未能核实”：没有对照实验证明“改得多=更好”。

## 8. 介入级别（默认不越权）

| 级别 | 交付 | 何时使用 |
|---|---|---|
| **L0 定位** | 指出位置/症状/证据，不改字 | 诊断、作者要自己改 |
| **L1 建议** | 定位 + 方向 + 可选方案 | 默认 |
| **L2 最小改写** | 1–3 句示范，标“可选” | 作者要求举例/句段问题 |
| **L3 整场重写** | 重写一场，保留原场对照 | 明确授权 + 结构/场景已定 |
| **L4 结构重排** | 新大纲/章序/线表，不直接写全文 | 明确授权 + 先出方案 |

**默认只到 L1**；L2 需作者同意；L3/L4 必须有明确授权。任何级别都不覆盖原稿。

**卡住时**：作者要求“直接改好”但不给授权级别 → 先给 L1 方案 + 问“要不要 L2 示例”；不要默认 L3/L4。改后作者说“不是这个意思” → 回退到 `回退点`，不要在原改上继续猜。

## 9. 超长连载的特别处理

> 这是本 Skill 最接近“结构工程”的部分；连载数据/平台契约未覆盖，本节方法的效果记“未能核实”。

### 9.1 先画三张图

1. **弧线图**：每 10–20 章一个弧，标主行动/次线/终点；找重复弧/无交汇弧。
2. **承重图**：标“已发布/不可改”“未发布/可改”“必须保留的承诺”。
3. **承诺图**：`兑现记录` 全部钩子/伏笔；未兑现标欠账。

### 9.2 删减顺序

1. 删重复解释/回顾（连载常见）；保留新信息。
2. 并/删无交汇支线；不能删的降为背景。
3. 压重复危机（同一类型危机出现 3 次以上 → 合并/升级）。
4. 并章（两章同一状态 → 并）；保留章末钩子，但钩子必须兑现。
5. 最后才动人物；主角/对手不能删到动机不清。

### 9.3 不能做

- 不回改已发布章节的既成事实；只能在后续补过渡/补偿，或在新版标“重启版”。
- 不为“缩短”删掉类型承诺（侦探不解释、言情无情感落点、升级流无升级）。
- 不用“回忆杀/番外”填主线欠账；番外不能替代主线兑现。
- 不把“章末钩子”全删成平章；连载读者需要进入下一章的理由。

**卡住时**：目标字数与承重承诺冲突 → 重设目标/分卷，不硬删；已发布承诺无法兑现 → 标“欠账”，在后续补，不假装没发生；作者未授权结构重排 → 只出方案。

## 11. 修订交付清单

- [ ] 原稿是否只读？新版本/修订单是否独立？
- [ ] 是否先结构、后场景、再句段？
- [ ] 删减对象是否分四类？是否用了删/压/并/留四种处置？
- [ ] 承重段/唯一因是否标出并保留？
- [ ] 每个改动是否有位置、原句、理由、回归项？
- [ ] 改写级别是否与授权匹配？是否默认只到 L1？
- [ ] 回归 6 项是否逐项勾？失败是否回退？
- [ ] 版本/回退点/例外是否记录？
- [ ] 是否说明了哪些判断只是假设、需要试读检验？
- [ ] 是否误用操作默认值（3/4、2–3 视角、3–5 细节、字数/章数）当硬门？
