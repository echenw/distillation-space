# 动作场面检查表

返回 [SKILL.md](../SKILL.md)。动笔前填 A 组，写完后填 B 组，回看时只看 C 组。每一项写“适用 / 结论”或“不适用”；和场景工作表重复的项，直接引用那张表。规则见 [action-and-fight.md](../references/action-and-fight.md)。

## A 组：动笔前

| 编号 | 检查项 | 结论 |
|---|---|---|
| A1 | 场型：一对一 / 小队（伏击、追逃、突入）/ 群体（会战、溃退） | |
| A2 | 谁在哪：相对的位置，不是编制（SC-08） | |
| A3 | 关键的障碍或出口是什么 | |
| A4 | 双方还剩什么：弹药、马力、退路、人手（AF-10） | |
| A5 | 这场戏的功能：后果 / 推进 / 性格 / 悬念 / 感官体验 / 别的；可以兼有几项 | |
| A6 | 主卡：选哪一张 AF？为什么是它，而不是相邻的那张 | |
| A7 | 后果：这一下之后有哪些收益、损失、持续的状态或未知（伤、武器、关系、时间、名声）；无损的胜利也可以成立 | |
| A8 | 视角与感官：视角人物此刻能看见、听见、闻到什么，感知不到什么（AF-06） | |
| A9 | 年代与技术：出现的器械、通信、坐骑，在设定的年代里是否可用 | |

## B 组：写完后

| 编号 | 检查项 | 结论 |
|---|---|---|
| B1 | 需要追踪优势的变化时，关键处有没有身体、位置或距离的读数；连续的动作可以承担速度或混乱，不要求每次打击后都停 | |
| B2 | “迅猛地、凌厉地、狠狠地”这类概括有没有完成本场的声音或信息功能；只在还缺所需的体验、对象或变化时，才补具体的细节（AF-05） | |
| B3 | 赢了以后，战后的风险相关时，有没有适量的局面确认和后果；不要求每场都有诈死（AF-08） | |
| B4 | 伤的位置、对能力的影响、处置，在第一次相关时是否清楚、前后一致；医学细节另外核实；轻伤、延后发现、本场不处置都可以 | |
| B5 | 武器、弹药和别的资源，用到时是否和已经立下的状态相容；写准确的数量或足够清楚的定性状态都行 | |
| B6 | 有巧合、外力或对手犯错时，登记它的作用和前因，检查它有没有破坏本作的因果承诺；可以有后果，也可以没有直接的代价 | |

## C 组：回看

| 编号 | 检查项 | 结论 |
|---|---|---|
| C1 | 需要看清优势时，关键的依据能不能从文本里复述出来；“一句话说出谁占上风”是自检，不是配额，没有试读就不说读者已经看懂 | |
| C2 | 按实际的叙述目标，关键的决策和变化能不能跟上；有意的限知可以保留未知 | |
| C3 | 有没有写到本 skill 要转出去的部分：现代武器的细节、非虚构的战史、镜头与舞台调度、真实的格斗教学、武侠仙侠的武打体系 | |

C3 为“有”时，把超出范围的那一部分交给可靠的资料或相应的 skill（见 SKILL.md §1）；这一场里属于本 skill 的创作和修改照常完成，不因为局部要转交就整个停下。
