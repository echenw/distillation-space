# 伏笔与兑现（SU-01、SU-06、SU-07、SU-08）

返回 [SKILL.md](../SKILL.md)。

每条规则按「规则 / 用于 / 怎么做 / 不用 / 反例 / 检查 / 自拟例 / 出口」写。「用于」和「不用」是区分条件：先判断这一处落在哪一边，再决定改不改。例子都是为说明而自创的。

## SU-01 终点先行

- **规则**：动笔前可以先确定最后一拍——最后一个画面、动作或一句话，以及它要留给读者的情绪；再从那里倒推必要事件。这是规划工具，不是所有写作方法的硬要求。
- **用于**：设计短篇或一个阅读单元的铺垫、悬念、高潮和收尾；中段散、不知道该删哪一段；结局写出来读者不信、能轻易想出另一个同样成立的结局。
- **怎么做**：
  1. 写一到三句「最后一拍」，尽量使用画面、动作或具体物件，不用主题总结代替场景。
  2. 标出目标情绪，例如不甘、释然、发冷或怅然。
  3. 列出到达这一拍必须先发生的事件和信息。
  4. 逐段倒推：读者要先知道什么，才会相信下一步？不在必需清单里的事件降为可选。
  5. 检查是否存在同样成立的替代结局；若有，决定是否保留多解，或补足前置条件。
- **不用**：
  - 短篇、单章、单场景：可先定终场画面和最后一句的方向。
  - 长篇、连载：可先定终局状态，也允许在写作中发现；每个阅读单元另定自己的结束状态。
  - 推理作品：作者应先确定谜底和机关，再检查读者是否能接触必要线索。
  - 发现式写作可以先写初稿，改稿时再确定终点；真实历史或传记题材可以先定叙述截止位置，不改已发生的结局。
- **反例**（自创）：把最后一拍写成「他终于明白了信任的可贵」——这是论文式总结，不是画面；倒推时列不出任何「必须先发生」的事件，于是每一场都写成闲谈，结尾只能靠一句感悟收束。
- **检查**：不看稿能复述最后一拍；最后一拍有具体动作或物件；每一场都能回答「它怎样把人物推向这一拍」；最后一拍是「意外但唯一正确」，不是随便换一个结局也成立。
- **自拟例**（自创）：最后一拍写成「她把备用钥匙放回桌面，没再锁门」，情绪词标「释然」；倒推出三件必需事件：钥匙曾被拿走、一次没说出口的质问、门外有人等过。
- **出口**：最后一拍写不出来时，给两三个候选并各写一句代价，停在待作者决定；发现式写作可以先往下做设计，标明「结局待定」；没有依据的地方按作者判断，不替作者定主题。

## SU-06 伏笔要有当下的用处

- **规则**：后续揭晓需要的人、物件、信息或能力，可以提前出现；首次出现时应有当下功能，不能只为未来埋线索。
- **用于**：反转像作弊、揭晓后回看不成立；伏笔像硬塞；要判断一个线索太显眼还是太隐蔽；纯惊奇结构要留可回查的条件。
- **怎么做**：
  1. 列出揭晓所需的关键条件：谁知道什么、谁持有什么、物件在哪里、规则如何运行。
  2. 让条件以自然方式进入当前场景，例如正在使用的工具、闲谈、误会、工作流程或人物习惯。
  3. 揭晓时让旧信息获得新意义，不要重新介绍一套临时规则。
  4. 事后回看：前文是否有可定位线索？它是否既能支持揭晓，也不至于过早暴露答案？揭晓后，前文至少两处获得新的意义。
  5. 拿不准时，请一个没看过大纲的人读，问他事后能不能找到伏笔、事前有没有猜到；模型模拟不等于真实试读。
- **不用**：
  - 太显眼：叙述停下来特别强调，或人物无缘无故提起。可让它参与当前动作，或与更醒目的信息并列。
  - 太隐蔽：揭晓后仍找不到前置线索。可增加一次不同语境的出现，或降低唯一解承诺。
  - 惊奇结构可以延迟解释，但揭晓仍应有可回查的条件；不可靠叙述可以暂存信息，但要让读者有机会识别其知识边界。
  - 不设「每个揭晓必须几处伏笔」的硬门槛；数字只用来发现问题。
- **反例**（自创）：为了让结尾的锁能被打开，前面专写一段「他仔细端详那把旧钥匙，觉得日后一定有用」——叙述停下来为伏笔让路，读者当场就记住了它；另一种错法是揭晓时第一次出现「原来他一直带着开锁的工具」，前文翻不到任何一处。
- **检查**：每个揭晓都能在前文找到至少一处可定位的伏笔；每处伏笔出现时都有当下的功能；删掉伏笔所在的那句，当下的场景仍然成立；揭晓后至少两处前文获得新意义。
- **自拟例**（自创）：登记表上被顺手改过的日期，第一次出现只用来解释「为什么排班对不上」；结尾发现改日期的人就是内应时，那一行闲笔和前面一句「他那天没在岗」同时获得新意义。
- **出口**：伏笔是太显眼还是太隐蔽判断不清、或需要补一处原稿没有的信息时，标未能核实，把「读者能不能回看」列为问题交作者，不擅自加一段提示。

## SU-07 误认与修正可回查

- **规则**：误认可以延长好奇、制造反讽或推动关系。先写清是谁误认：人物、叙述者，还是读者也被引向同一判断。误认要改变某个选择；修正时给出新的依据。
- **用于**：反转像作弊、揭晓后回看不成立；悬念靠「作者不说」而不是藏信息；要判断一处误认是有意设计，还是叙述者隐瞒了他明明知道的事实。
- **怎么做**：
  1. 记录被误认对象、实际情况、各方当时凭什么判断、何时修正。
  2. 让误认推动动作、决定、情绪或读者期待；不必每次都落到行动。
  3. 修正通道可以是新观察、第三方信息、文件、行动结果或人物自我纠正。
  4. 回看前文：误认是否符合人物当时的知识和感官条件？
- **不用**：不靠叙述者隐瞒他明明知道的事实；也不要求所有误认都由恶意造成。真实误读、信息延迟和故意欺骗要分开。
- **反例**（自创）：揭晓时才第一次交代「原来他一直认错了人」，前文找不到让他误认的依据，也找不到修正的新信息；另一种错法是把所有误认都写成有人故意欺骗。
- **检查**：能说清谁在误认、误认改变了哪个选择、修正依据是什么；回看前文，误认符合人物当时的知识和感官条件；不靠叙述者隐瞒他明明知道的事实。
- **自拟例**（自创）：读者与人物都把窗外一闪而过的影子当成同一个人，人物因此决定不追问；后来一张写着别的名字的签收单成了新的依据，人物修正判断，回去查当晚的记录。误认改变了「要不要追问」这个选择，修正有可回查的依据。
- **出口**：误认回查不成立、或修正需要补一处原稿没有的依据时，标未能核实，把「凭什么修正」列为问题交作者，不擅自补一段解释；没有依据的地方按作者判断，不替作者裁决是误认还是隐瞒。

## SU-08 保留两种读法时，配一条现实解释线

- **规则**：若希望读者同时保留超自然解释与现实解释，两条解释都要有可观察支持和边界；不能只靠不解释制造含混。
- **用于**：故事里出现离奇或超常的事；要保留「也可能是巧合」的通道；担心含混变成作者没想清楚。
- **怎么做**：
  - 列出解释 A 和解释 B 各自能解释的事实、不能解释的部分和需要的假设。
  - 让人物依据其知识选择相信某一解释，但不把人物信念直接当成作品结论。
  - 让人物先按其中一条现实解释行动一次：检查窗户、问对方是谁、找机关。
  - 结尾可以确认一条、保留两条或拒绝裁决；选择应符合类型契约。
- **不用**：
  - 多解不等于任意解；如果两条解释都能解释全部事实，需说明作者希望保留的张力。
  - 公平解谜承诺与开放式恐怖承诺不同，不能混用标准。
  - 设定本身就超常的作品，现实解释会破坏世界规则；此时改为守住设定的内部规则。
  - 不删掉其中一条读法去「图省事」，也不给每条解释硬配固定数量的细节。
- **反例**（自创）：夜里门自己开了，作者全程不写风、门闩、谁的脚步，只写「说不清为什么」，结尾直接宣布是预兆——两种读法都没有可回查的细节，含混变成空缺；另一种错法是把所有异常都用「电路老化」解释完，还硬留一句「也许不是」。
- **检查**：重读时，读者能指出至少两个「当时就可以这样解释」的细节；两条解释各有能解释与不能解释的部分；结尾的裁决符合本作的类型契约。
- **自拟例**（自创）：仓库夜里响动，可以先查到松脱的门闩（风）和值班表上被划掉的一行（有人来过）；人物按「风」去加固门闩，读者仍可保留另一条读法，结尾不改写已经发生的物理因果。
- **出口**：两条解释冲突到无法并存、或题材契约不允许现实解释时，停在待作者决定，给「只留一条」和「换设定内部规则」两版；不替作者裁决超常与否。
