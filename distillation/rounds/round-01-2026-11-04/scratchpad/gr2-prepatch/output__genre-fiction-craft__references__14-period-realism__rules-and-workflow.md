# 年代与现实生活规则与工作流（RL-01 至 RL-10）

返回 [guide.md](guide.md)。每条规则分“技法范式”（典型创作手法）、“推断”（机制逻辑分析）、“怎么做”（作者可选的动作），并写明不适用的情况和反例。

## RL-01 阶层变化、自我感与人际关系

- **故事内场景**：角色被他人用职业、阶层或资源称谓定位；当其进入新的社交场合后，逐渐内化标签并改变自我评价。称谓、动作、资源使用和关系变化可共同呈现这一过程，不将其升格为现实社会学定律。
- **推断**：希望书写社会上升的作者可以检查**经济条件变化 → 允许进入的新场合 → 人物为过去/亲人感到羞耻 → 自我辩护或修复关系**的因果路径。
- **怎么做**：在相关段落记录 `资源变化/谁能进入新场合/旧关系的得失/情绪与行为证据/人物后果`。作者需要同情、批判、喜剧或疏离时分别安排叙述距离，不强制每章填写或让所有人物值得同情。
- **不适用**：角色没有阶层上升愿望、或故事采用不以社会身份作冲突的类型时，不硬套羞耻与野心。
- **不要这样用**：换了一身高级衣服就让角色突然鄙视亲人，若前文无心理铺垫，只是编剧为制造冲突而断裂人物。

## RL-02 贫困怎样影响日常选择

- **技法范式**：匮乏的微观烟火气——家庭成员围绕有限预算、日常必需品和彼此优先级进行具体交谈；贫困通过生活选择与人物关系进入场景，而非干瘪的经济史数字。
- **推断**：若贫困承担推动选择的功能，检查它如何影响**时间、物品、义务或选项**；仅说“家里很穷”未必足以解释关键行动。作为背景、语气或社会对照时可以简写，不要求每次提及都有新损失。
- **怎么做**：需要解释经济选择时，记录具体资源、成员优先级、各自所得所失和后续关系；共同目标也可成立。劳动负担与照护责任按人物处境展开，不要求每人牺牲或赞美牺牲。
- **不适用**：富裕角色、寓言或轻喜剧作品也可以不把经济账写到明面；若声称某金额代表真实历史水平，需相应数据，否则写 “需要查史料”；虚构故事的暂设金额应明确为创作设定。
- **不要这样用**：同一个孩子在一章无法负担生活、下一章却无缘无故购买昂贵物品；这是需核对的内部因果而非时代风格问题。

## RL-03 社会制度的叙事作用与人物后果

- **技法范式**：宏观动荡与微观个体命运——让公共制度、权力变化与个人选择在不同叙述层互相照应，使宏观历史与人物承担的代价产生联系。
- **推断**：希望把历史动荡转成角色压力时，可连接其安全、关系、迁移、职业或信誉。宏观公共事件也可承担史诗视角、对照、说明和节奏作用，不以没有即时个人代价自动删去。
- **怎么做**：分析承担因果作用的制度冲突时，可写 `宏观条件 → 角色能知道的事 → 可行选择 → 即时结果 → 长期后果`，标出需外部史料支持的节点。
- **不适用**：纯纪事、作者刻意采用高视角史诗时，不必强迫每段都回到一个角色内心。
- **不要这样用**：历史年表越写越详细，角色实际活动和人际关系始终未受影响，读者无法理解史事为何属于这个故事。

**重要边界**：上述范式是可选的叙事设计模型；规划表和通过条件均为创作建议，需结合具体作品的时代语境与风格灵活取舍。

## RL-04 社区同时能提供照顾与监督

- **技法范式**：社区的庇护与全景式监视——日常互助、公共空间、熟人往来与对他人行动的持续观察，可能同时提供照顾通道和评价压力，形成可见的社区关系网络。
- **推断**：可分别检查社区的人际**帮助通道**和**评价压力**，判断本作是否需要一方或双方。温暖、疏离、压迫、互助或冷漠共同体均可成立，不用两面俱全认证可信度。
- **怎么做**：做 `人物/在社区担任的角色/能够给予的资源/监督或误解的代价/可以改变看法的事件` 表。不能仅用几个地名、习俗词汇假装社区存在。
- **不适用**：极度孤立的故事或私人独白不必构建大社区；宗教活动若只是人物既定生活的一部分，不必把它转成当代社会结构的通用必选项。
- **不要这样用**：前文已给邻居不同利益和承诺，后文却只用“所有人忽然一样想”抹去关键差异，导致行动缺前因。单纯温暖或普遍敌意本身不是错误；先核是否符合本作设定和表达目标。

## RL-05 家庭群像的共同目标与个体处境

- **技法范式**：声音反差与代际担当——面对共同的物质匮乏，不同性格的家庭成员展现出截然不同的口吻与追求，并在漫长成长中逐步将青春浪漫转化为对下一代的生活担当。
- **推断**：同一资源约束可以显出不同欲望与妥协，也可以显出共同目标下不同能力、信息、责任或贡献。合唱式声音和共同信念可有意采用；需要塑造个体差异时，才检查重复发言是否抹掉已有差异。
- **怎么做**：做六栏 `角色/当时想要的东西/不可舍弃的原则/实际能做的事/与他人冲突/本章变化`；保留自私、矛盾和未解决成长，而非强迫人人成圣。
- **不适用**：短篇只有一个聚焦者或没有家庭，不需要硬造兄妹姐妹结构；时代性性别分工不等于当代作者应赞同。
- **不要这样用**：把所有姐妹变成一个“奉献型女性”模板，会抹掉群像中不同人物的愿望和矛盾动力。

## RL-06 成长结尾不要求愿望完全兑现

- **故事内场景**：一种成长结尾通过道路、机会或未完成的选择保留未来开放；另一种通过承诺、后续行动与可信叙述概括表现人物改变。两种结尾的闭合程度不同。
- **推断**：区分 **情感承诺得到验证** 与 **所有人生问题都解决**；成长可以通过获得新的责任而非提高地位完成。
- **怎么做**：按作者目标选生活开放、关系修复、愿望充分兑现或其他结尾；有重要取舍时再并列方案，说明对前文伏笔、人物选择和读者预期的影响。
- **不适用**：悲剧、拒绝回归家庭、政治动荡题材或作者明确的反圆满结局，不必复制儿童成长或圣诞救赎。
- **不要这样用**：人物前文始终只追求自由，终章却无过程地宣称“真正幸福是回归家庭”，违背既定人物问题。

## RL-07 叙述者的声音本身可与制度冲突

- **故事内场景**：第一人称叙述者以自己的口语、词汇与判断定位故事和自我；结尾拒绝某种社会规训，使自由意图与制度规范产生摩擦。
- **推断**：第一人称的语言选择可以让读者看到人物与所在制度之间的距离，但这不是所有现实题材都必须采用方言的证明。
- **怎么做**：为主角建立 `公开说的话/心里认定的正当与不正当/制度要求/实际行动/叙述语调` 五栏；根据作者所设计的文化与人物身份选择语调，不要直接复制某个文本中的种族化语言作为本作的默认声音。
- **不适用**：非英语创作、翻译、本土民族/地域方言等要求独立研究；不能通过标签“南方口音”自动制造刻板语汇。
- **不要这样用**：作者给角色随意贴上历史口音，但行为和思想完全是外部全知说教；这不是建立真实声音。

## RL-08 拒绝体制可以成为结尾，不必“回归文明”

- **技法范式**：抵抗教化与保持本真——角色在结尾明确表达对重新规训或被纳入既定制度的抵触，使个人独立追求与社会制度压力并存。
- **推断**：成长结尾可以是得到自由、维持开放问题或选择新地平线，而非每人均纳入既定家庭/社区。
- **怎么做**：核 `人物开篇的拘束/过程中发生的变化/结尾选择的后果/与前文价值的关系`。留在共同体或离开都是选项；作者已选定时直接发展该案，不强制再提供相反结尾。
- **不适用**：既定体裁要求回家团圆、人物主动承担照护责任时，离开不一定是更成熟的答案。
- **不要这样用**：为了追求“自由”让人物抛弃前文珍惜的所有人，却没有内心矛盾或选择成本。

## RL-09 人物改变的承诺、后续表现与叙述依据

- **技法范式**：承诺与概括叙述的双重闭环——先给出当场对当事人的具体物质承诺与加薪帮扶，再通过叙述者跨年份的概括叙述证明其不仅兑现了承诺而且做得更多，使性格转变具备无可辩驳的行动说服力。小说结合场景与可靠叙述概括，不是只许直演后续行动。
- **推断**：如果作者要读者相信改变已经兑现，可用后续行动、可信的叙述概括、关系反应或互相支持的材料。人物自称觉悟只证明其说法；结尾也可以有意只留承诺，暂不保证未来表现。
- **怎么做**：需要用行动展示变化时，可回访早先错过的机会，写新的选择及后果；也可用可信概述交代时间跨度。次数、观察者和是否展示全部修复由本次任务决定。
- **不适用**：悬疑、现实主义悲剧、不救赎叙事不能被强迫加入“醒悟了就做好人”的圆满逻辑。
- **不要这样用**：贪婪角色在最后一页独白忏悔，此后所有关系无条件修好，前文伤害没有代价。

## RL-10 开放、回望、共同体、牺牲四种结局不可混成模板

- **故事内场景**：可分别采用开放未来、汇拢下一代、假设性预言与牺牲余韵、情感/前程与阶层线交织等结尾方式；不同结构各自承担不同的余味与结算功能。
- **推断**：结局是**用最后的角色行动/视角，重新解释前面投入的代价**，并非必定婚恋、牺牲或家庭圆满。
- **怎么做**：按需要列 `开篇愿望/中段发展/最后机会/人物最终得失/社会问题的结果或余留/预期余味`，选符合当前目标的结尾。有实际取舍再给备选，不强制所有故事留下社会问题。
- **不适用**：纯喜剧/幻想可显式圆满；纪实社会小说可保留结构性困境；所有选择优先满足作者已有体裁承诺。
- **不要这样用**：不区分开放成长、回家团圆、牺牲和逆转，而把不同结局机械总结为“先受苦最终道德成功”的统一公式。

## 统一执行流程

以下 RL-W1–RL-W4 按当前任务类型选用，不要求全部执行。

## RL-W1 新作品设计（限定任务：年代/现实生活）

1. 采用已给的 `时间/地点/社会条件/人物/文化距离/体裁目标`。没给的原创设定，可以明确作为暂定的建议；需要作外部历史断言的内容另核史料。小说可以证明其文本呈现，不能单独确证工资、法律等现实细节。
2. 按目标选择经济生活、社会声望、共同体、家庭责任、个人自由、政治制度或其他生活对象；可以写压力，也可以写互助、喜悦和持续日常。承担情节压力时，说明哪些选项被限制、哪些资源或关系会得失。
3. 生成与任务匹配的具体情境和文本。顺从、迂回、抵抗、重新定义责任都是候选；重要分歧再比较两案及各自结果。
4. 选择对话、家务、地理与职业细节的作用：影响行动、呈现日常、营造氛围、组织声音或建立社会对照。诊断堆砌须指出其与本作目标的具体冲突。
5. 核体裁与世界契约。真实幽灵需与世界设定相容；梦、比喻、故事中故事也能借用三时态回看而不新增客观超自然事实。现实成长可以有大变化，须有相应前因；政治悲剧可以保留结构约束，也可以按作者新目标改写其虚构因果。
6. 交付请求的正文、规划或设计。需要场景表时可选 `场景/读者已有信息/社会条件/生活细节/角色选择/结果/关系变化或延续/史实待查`，无关项省略。

## RL-W2 已有稿件审查（不能假装修改全文）

- **输入**：当前文本节选、作者要求保持不变的角色与事件、定位格式；未给当前文本时仅可提出有条件的修改示例。
- **第一轮** 标出具体场景的制度细节，例如阶层称谓是否与作者设定一致、贫困是否真实限制选择、家庭成员的共同或不同目标是否成立、地理环境承担的功能是否明确。
- **第二轮** 找到角色行为是否有现有前因；把无理由的突然转变与作者有意让人物反常的情况区分。
- **第三轮** 给最小可执行修法并说明收益与风险；需要实质取舍时提供备选，已授权改稿则实际修改。
- **局部失败出口**：关键年代事实缺证时，记录具体研究项并暂停依赖该结论的判断；继续其他创作或已证部分。小说的虚构情节不能单独认证外部史实。

## RL-W3 收尾形态的冲突裁决

| 作品模式 | 可以学的机制（推断） | 禁止照搬 |
|---|---|---|
| 乡土成长 | 角色变得能够面对未知，但世界仍开放 | 每个故事必须“道路有一个弯” |
| 超常救赎 | 场景与可靠概括共同交代承诺兑现 | 所有人物必须被鬼吓醒并变好 |
| 家庭群像 | 多成员不完全相同的责任与愿望在生活中重组 | 女性角色必须承担单一历史角色 |
| 反规训冒险 | 主角拒绝不认同的规范；个人自由留到终章 | 必须抄袭方言或以离开为唯一成熟 |
| 历史传奇 | 外部大事件与个体牺牲交织 | 牺牲必定优于生存与日常建设 |
| 阶层成长 | 人物回看曾经的羞耻与期待 | 上升必然导致自我厌恶或恋爱收束 |

## RL-W4 交付

按用户要求交付正文、规划或诊断。重要判断需要可追溯依据时，提供相关的任务约束、当前文本位置、技法范式与推断建议的区分、适用条件与未决项；不把全套字段强加给只要故事正文的请求。

用户要求小说**历史真实性**时，按具体断言取得合适史料并核查；无法取得时列核对事项与证据缺口，不能只凭小说文本宣布史实正确。如果用户只问**通用文学理论**，不要把小说里的情节和作者明确写下的批评论点混在一起；本题材未拥有后者。真实读者评分、历史校勘、现代地方口音适配、真实社会科学归因皆不在本题材能证明的范围内。

## 单书机制（RL-M1 至 RL-M9）：有条件可用，不是通用门槛

| 编号 | 具体操作 | 适用条件与对应规则 |
|---|---|---|
| RL-M1 | 超自然访客依过去/现在/未来次序重看人生，再回到改变后的日常 | 客观幽灵适用于允许此装置的世界契约；现实作品也可借梦、回忆或故事中故事组织三时态回看。属于 RL-09 的一种铺排，不要求加入幽灵。 |
| RL-M2 | “道路转弯”意象使成长收束而未来开放 | 可学意象与开放余味的配合，不复制结尾句式；RL-06/10。 |
| RL-M3 | 拒绝再次被文明化、走向未知 | 若已建立责任或关系承诺，交代选择怎样影响它们；不强制所有离开都受罚或受损。RL-08。 |
| RL-M4 | 以未来代际讲述想象牺牲者的记忆延续 | 其开头是假设性思想框架、其后是未来图景，不是实际跨到后代的已发生场景。可借此写预期、愿望或预言；非强迫死亡公式。RL-10。 |
| RL-M5 | 社会上升线与情感线同时收拢；雾等环境意象参与回望 | 两线已铺设时可交会；社会问题可解决、缓解或余留，按已给因果与作者目标决定。RL-01/10。 |
| RL-M6 | 母亲/祖母观察下一代，使群像空间聚拢 | 仅在作者选择的聚焦者与家庭架构下成立，不能变成女性应承担的统一义务；RL-05/10。 |
| RL-M7 | 叙述者持续使用自身口语，不随意切换成外部标准语注释 | 依本作语言契约和文化证据决定，翻译/跨文化需要重新研究；RL-07。 |
| RL-M8 | 期望→实现→幻灭→接受四段社会流动 | 仅为一种成长弧，不要求所有上升者羞耻或幻灭；各段须有资源、关系、时间痕迹；RL-01。 |
| RL-M9 | 道德意义由角色经历与选择生成 | 允许有意的叙述者评论，但不让空洞宣言代替已承诺的行动后果；RL-09。 |
