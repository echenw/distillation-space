# MY-05 动机、人物、灵异与收束

返回 [guide.md](guide.md)。

## MY-05A 动机不等于身份证据

区分欲望、利益、压力、可行性、行为与后果。钱、继承、救亲、复仇、忠诚、恐惧、羞耻与理念可组合；有动机不等于做了，没有明显利益也不等于无行动。所谓“同情度高/低”不作客观分数，跨书的观众效果都没有证据。

| 分支 | 保留的具体设计选择 | 反例与限度 |
|---|---|---|
| 保险与婚姻 | 婚约/保单、受益与实际支配、调查者的错误排除分时揭露 | 受益人是外人也能成立，不强加一层信托或再婚 |
| 勒索与身份破口 | 旧识、假死、未达/半烧信构成杠杆，金额/目标可变化；灭口、反勒索、公开、拒付、求助都是分支 | 一笔交易也可完整，不强制分期勒索 |
| 婚约换沉默/合作 | 分权力、强迫、知情、所护对象和人物选择；侦探公开假说会改变谁的处境 | 胁迫婚约不需要受压者真好感，不把交易包装成自愿爱情 |
| 救亲与顶罪 | 被保护者知不知、能否拒绝、行动代价、真相揭露时谁获得选择 | 同上；不得称自动道德豁免、最高动机，受惠者知情不必人物“破产” |
| 继承期待 | 条款、无嗣条件、旧债/期限/新继承者等压力与人物反应 | 财务败象是一个压力来源，不是杀亲动机必需 |
| 复仇/私了 | 伤害归因、当前目标、边界、替代处置、执行者及后果各自成立 | 杀人/自白/自尽仅是特定作品的结局，不强制“正当”或读者同情 |
| 组织惩戒 | 内部命令、拒令后果、目标完成定义、解脱仪式与成员选择 | 自称契约不认证合法性，组织也可能任意或违约 |
| 错杀与转赠 | 追踪物/消息每次转移的理由、误认与责任归属 | 意外伤害对象不自动免除原行动者责任，法律结论不由小说推出 |
| 复仇节制 | 对峙、劝止、自主放弃、实际替代方案及未解决感情 | 放下可以兼原谅或自保，不强制第三方、小额补偿、执行后才可停手 |
| 善行的坏后果 | 推荐、让房、隐瞒等动作经信息差进入悲剧链，追踪施害者与被影响者 | 善意者可能有疑虑或自保，不要求全程无私利，不能自动把恶果责任转给无辜者 |

## MY-05B 人物关系与有限视角

女性、仆役、儿童、助手、职业者与受害人都按具体目标、资源、知识、选择和约束设计，不按性别或阶级排“主动性阶梯”。同一能力在一个情境有效、另一个受限不等于角色工具化。

- **渗透角色**：外壳、被查技能、盟友、危机应对及退出条件；守丧/老妪/护士扮演和信任交换可作历史场面选择，不要求女性必须靠自损或交易身体。
- **协作执行者**：技能来源可由经历、当前行动或职业关系给出，忠诚可源自亲情、信念、报酬或恩义；女仆技术与协作可作案例，不要求一句出身说明、世代忠仆或晋升收束。
- **择偶与价值观**：宣言、实际选择、改变原因三者相互解释；故事内人物的具体择偶标准不是所有女性标准。人物成长可以改变旧宣言，不叫人物破产。
- **对照伪证**：护兄与护爱人可以形成横截面。相同动机也能通过承担代价和信息差形成对照，不强迫两女主互相冲突。
- **假扮关系转真情**：此前行动、越界或心态可回读，终局台词可重解释表演。不固定三处伏笔或一定一句点破。
- **竞争信物**：同一杯/承诺承载不同职业价值与人物选择。不限定多男一女，也不以选富人自动否定主体性。
- **婚事与案件并行**：开端冲突、中段变化、结尾状态可以互相牵引。不规定中段两次改期，关系线可以非婚礼。
- **未达的和解信**：写出、传递受阻、发现、由此可推的反事实各有信息范围。阻断可来自罪案、偶然或制度，不强制截信者就是主反派；收到也不保证必和解。

## MY-05C 灵异与自然解释按具体因果分层

先写哪些现象最终认定为自然、超自然、人物误解或有意未知。全书可以不同现象用不同机制；“全部现象都自然解释”与“同一现象最终确定由超自然造成”才构成同范围的冲突。谜面误导不等于最终事实矛盾。严格公平若依赖非现实规则，应按MY-03C先交可推理范围；不要把“灵异真实”直接等于不可解。

| 装置 | 保留的独有形状 | 条件与反例 |
|---|---|---|
| 显灵序次 | 分别儿童斑点、血亲失眠、选择性闻臭、凶手见象 | 可将反应与人物关系关联，不视为普遍罪距测量函数；先后可改变且须有本作意义 |
| 气味与物理残留 | 香水/腐败等复合气味在地窖、房号、显灵与开密室阶段回响 | 记录谁闻到、观察条件与解释范围；无源头也可有意留白，不自动假法证 |
| 声音可被伪造 | 腹语/口技让人误认密会与证词 | 听见什么与来源推断分开；受骗者没有验证机会不等于愚蠢，不强制“本可验证”情节 |
| 催眠作为时代假说 | — | 仅人物/作品设定，不借此主张现实催眠控制；可以被自然解释、幻想设定或未知替代 |
| 预言与梦魇 | 三段谶语、多种死法与“它”的歧义 | 三段/五死法是原例，不是配额；明确预言可把悬念转成如何/能否避开，不判全书报废 |
| 鬼象与受益者 | 仆役离开、游客变化、警方介入，观察传闻让谁获利 | 无受益者也可自然事件或气氛；阴谋分支才需具体传播/执行，不强制三反应俱备 |
| 恐怖作为后勤掩护 | 将鬼传闻与疾病隔离等不同限制组合 | 情节人物可由不信、职责、偶然、共同谋划进入，不只留“一个不信邪”入口 |

有的作品既被读作真灵异又被读作焚稿留白，证据不足以替作者统一成确定真鬼；保留叙事反应和结尾开放性。异象与证词冲突的记录保留为本书解答边界，不据此禁止所有超自然推理。

## MY-05D 藏匿、追踪与竞技罪案分支

藏身地点按本作可达资源、熟人网络、可见性、生活需要与追查条件选；不把宅邸、城市、边荒排现实安全等级。有的作品提供宅邸、城市、边荒三种环境。宅内协作可主动带搜、谎报、引开、承担检查；一人慌乱未必全线崩，临时应变也可成立。沿途消费形成信息链或被故意留下；追踪者实际取得什么、误认什么逐段写清。

竞技罪案保留四种独有场面：

1. 双马计划、作弊与动物自主性使计划落空。马的性格、赛况或训练可支撑反转，不要求一定倔强，也不提供现实伤害动物步骤。
2. 被收买者用行业惯例、对方有罪等说辞自辩；自辩可内心、独白、争论，失败后也可能继续合理化，不强制一听见就显蠢。
3. 反伦理导师谈负债、大小鱼与“诚实是一条路”。原三课可按需要选；导师也可卷入凶案，不能由此宣判整书道德坐标崩塌。
4. 假名参观、专业动作暴露目的与被识破后的对抗。专业圈查验是压力条件，识破后可以谈判、回避或冲突，不强制杀意。

## MY-05E 解答、证明、裁决与人物后果分别收束

| 维度 | 应回答什么 | 可用分支 |
|---|---|---|
| 认识闭合 | 哪些核心事实已明确、哪些解释仍竞争 | 唯一解、部分解、多个层次、开放未知 |
| 证据闭合 | 谁持何种依据，能排哪些替代，尚缺什么 | 重新检验、追踪独立来源、自白补强、承认不足 |
| 制度结果 | 谁受理/裁决/执行，理由是否在世界规则中成立 | 庭审、逮捕、暂缓、失败、拒绝、正式不裁决 |
| 公共与私人版本 | 不同受众知道什么，谁选择隐瞒，何种权力维持 | 公开、局部公开、私了、删去细节、被迫沉默 |
| 人物后果 | 伤害、资源、关系、名声和选择如何变化 | 修复、继续冲突、逃离、失去、和解、放下、暂时不变 |

不把三种结局互斥、五种揭晓只选一、四种补法穷尽。客厅复原、法庭、文书、自首、对质、双重逮捕、暴力或事后启事可以分阶段使用。物证、证言、自白可共同构成故事内证据；自白即自杀说明执行被中断，不证明自白天然不可采。

原案对照：有的说证据不足定罪；有的承认只有猜测；有的列动机/机会/对话/鹦鹉/指纹；有的自首后死亡；有的救人还依赖最后行动。不同制度条件各自核，不宣称某一种是所有推理必做收束。

末章逻辑/自白/判词、制度未决而已拘人、意外因果无预想凶手、谜句自指、日记可信性说法，各示不同闭合维度。文书很长与亲属认笔迹不证明不可伪造；自称“这是我的谜”不等于全部事实为假。

私了或放逐可以列条件、拒绝点、执行者、回流及被害方选择；放走者不因后来再犯罪自动成帮凶，命运也不必最后封死。天罚、偶然死亡或恐惧崩溃是文学结果，若希望有因果回声可提前建立位置、行为或风险；不必每个反派都“自己走到那里”，也不把自杀写成签名供状后应然处置或司法零成本。

全员归位、数周后、开场空间回环、酬金或婚讯可收长线。只收必要角色承诺，不强制人人一句、必须留一处伤痕或绝不能完美结束。
