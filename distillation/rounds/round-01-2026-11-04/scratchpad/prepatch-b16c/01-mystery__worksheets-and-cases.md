# MY-06 可裁剪工作表与自建案例

返回 [guide.md](guide.md)。

以下字段用于记录一次推理设计或诊断。一次任务只选影响本次判断的表；未知不是零、未写不是不存在、设计方案不是原稿事实。不以凑齐表格代替正文交付。本次问题对不上任何一行判断时，就写证据不足并指出是哪一处对不上；不套用最接近的一条凑成结论，也不为给出改法而虚构稿件里没有的前提。

## MY-06A 建案和诊断表

| 表 | 字段 | 如何使用与出口 |
|---|---|---|
| 任务卡 | 已读版本/范围；题材与时代；目标读者承诺；创作者目标；可改位置；禁动事实；待定设定 | 缺稿可做设计预设；依赖原稿的诊断写明“没有原稿，不能判断”；不擅扩改稿授权 |
| 答案命题 | 谁/做了什么/何时何地/如何/为何；哪些属于核心谜题；哪条是已锁定事实 | 不将所有字段强制变读者测验；开放项明确开放范围 |
| 人物候选 | 身份与关系；动机/机会/能力的实际依据；可见行为；知道什么；误信什么；隐瞒什么；替代解释 | 候选数量、每人秘密数及嫌疑权重按作品需要；缺某项不是自动排除 |
| 线索账 | 编号；原稿位置；观察原貌；发现者；读者可见部分；初解；真解；其他解释；区分信息；终局用途；揭晓处由谁复述复原 | 感官细节、证词、文书与元信息分型；同源线索不可假装独立；严格契约查核心信息是否可用 |
| 信息时间链 | 发生、感知、记录、转述、人物知悉、读者获知、推断与行动时点；每段可靠性 | 不要求所有时点有精确钟数；说明顺序、时区/钟差或区间就足够时不伪造精度 |
| 时空边界 | 入口/出口/视线/间隔；谁检验；方式和权限；盲区；可能改变边界的动作；前提可信度 | 人物误排可以推翻；作者已保证的客观事实不能无说明反写；死者/施害者/工具/作用时点分别看 |
| 因果与替代 | 观察；候选因果；各解释预测；已知区分点；缺失点；可行核查；能证明与不能证明的范围 | 一条决定性证据可以够，多条同源也可以不够；不强制两种物证、三本书、两名专家 |
| 证物流转 | 形成；持有/接触；复制/替换/污染；存放/运输；检验；使用者；尚存副本或旁证 | 缺口降低相关推论强度，按具体替换可能评价；不是全案自动无效，也不保证连续即真实 |
| 证词与表达 | 原话；说话对象/目的；直接观察或转述；省略/虚构/误认；诱导条件；独立核对；角色/读者各自能知 | 片段可作线索；定案需解释其指向；人物说谎、叙述者省略分别按契约处理 |
| 检验或陷阱 | 要检验的命题；预期反应；非罪犯也可能反应的原因；观察权限；结果；替代解释；伦理/程序后果 | 不能把恐惧、镇静、逃跑或“自投罗网”直接等同犯罪；虚构中用过不等于现实合法有效 |
| 调查场景 | 进入前假设/资源/关系；行动和阻力；取得或失去的信息；反应/决策；未变项；下一步 | 可推进知识、关系、风险或主题；重复问话/仪式不因未新增物证自动删，先看其实际功能 |
| 收束账 | 读者理解；人物理解；证据状态；机构裁决；公开版本；私人代价；未偿承诺；后续风险 | 多种结局维度可并用；不把知道凶手=能逮捕=能定罪=已获正义 |

## MY-06B 专门装置补充字段

- **痕迹/足迹**：先在场景中定义可留下与可保存痕迹的材料、天气、通行及清理条件，再记录形状、方向、覆盖关系、步幅、负重等真正给出的属性。无痕只有在本应有痕且检查可靠时才支持排除；国籍、阶层或性格不能由步态直接推出。进入—停留—离开可有未知段，不强制每段一件物证。
- **消耗计时**：初始量、开始时刻、速率条件、中断/补充/替换、结束观察和误差。蜡烛/烟/炉火提供区间须有对应设定；“三个条件齐全”也不是万能充分条件。
- **食物与接触**：分配、先后、份量、实际摄入、共享/独享、接触机会、检测与替代路径。某人没中毒可约束路径，不能自动指认下毒者；虚构药理另标，真实药理需另核。
- **身体与医学**：观察者能力、观察条件、时间误差、已有病史、死因假说、检验限制与本作世界规则。伤口主要支持工具/作用方式，身体标记还要排模仿、误认和记录问题；不由本资料给现实诊断。
- **密室和不在场**：封闭对象、封闭时间、目击范围、钟表来源、行动/作用/发现时刻、验证者及可被误排的前提。清单可证伪“密闭”本身；不要求先认定真密室再给自然出口。
- **文件/录音/密码**：载体、作者/保管者、生成时点、复制和编辑能力、密钥或识读规则、内容何时对谁可用、真实性与内容真伪分别验证。仅让读者看见一封信存在，不等于已公开用于唯一解的关键句。
- **身份/伪装**：主张、观察者旧识、可变/较稳定/制度登记标记、语言/动作训练可能、代认者利益、公开资料传播、识别后谁有权认定。两个名字不自动两个人，不同时间出现也不证明同一人。
- **误导复核**：误导来自事实歧义、人物误解、叙事选择还是故意说谎；它是否在当前契约内；真相后能否重读成立；是否需要修正文或调整承诺。无需每个红鲱鱼都回连凶手。

## MY-06C 自建诊断案例

以下情境均为本 Skill 自建的教学示例，不对应既有作品或真实案件。它们用于展示怎样区分观察、推断、替代解释和设计补强，不构成现实侦查、医学或法律建议。

### 1. 档案室印章失窃：封闭不等于排除链完整

**设计预设**：一枚登记印章在闭馆后从档案室失踪。门上的编号封条看似完整；窗边有一小片纸纤维；值班记录显示最后一次盘点在 18:10；墙钟显示 19:20。三名工作人员有不同程度的出入权限。

**观察与推断分开**：封条外观完整是观察；“无人进入”是推断。墙钟与值班记录若使用同一时钟，不构成两条独立时间证据。纸纤维可能来自封套、清洁材料或窗框维修，不能直接证明有人从窗户进出。三名工作人员有权限，也不等于三人都具备相同机会。

**公平性缺口**：若终局直接宣布某人从窗户进入，前文尚未建立窗扣、外侧可达性、纸纤维来源和该人物的接触链，唯一解就没有足够区分信息。

**最小补强**：提前让读者看见窗扣的具体结构；记录封条由谁、何时、在谁见证下贴上；让纸纤维的材料属性与某一候选解释形成可复核关联，同时保留替代解释的排除过程。若不准备补写这些信息，就把结论降为“可疑路径”，不要宣称唯一解成立。

### 2. 手稿去向：找回位置不等于证明意图

**设计预设**：一份手稿在整理后不见，数日后出现在另一只档案盒中。登记表记录了盒号，但没有记录搬运者；两份副本的页码顺序不同。

**判断路径**：先核对盒号、目录版本、搬运记录和副本差异，再区分误放、临时借阅、替换和故意隐藏。手稿被找回只证明当前位置，不自动证明从未被取走，也不自动证明某人有恶意。

**可用结论**：如果现有材料只能确定错放位置，就只交付位置结论；动机保持未知。要证明故意隐藏，需要独立的行为、知情或收益证据。

### 3. 重复异常：模式不等于因果

**设计预设**：同一机构在三个不同时段出现相似事故，记录中有时间重叠和人员交接，但尚未证明它们由同一原因造成。

**判断路径**：把“发生了什么”“谁造成”“目前能证明什么”“机构如何处理”分开。先核各次记录的定义、观察者、时间口径和缺失项，再比较共同条件与差异。重复出现可支持调查方向，不能仅凭相似就证明共同责任人。

**边界**：若情节涉及真实医疗、工程或安全机制，虚构设定与现实专业判断分开；不要从剧情设计推出现实处置方法。

### 4. 读者提前猜中：公平不等于惊奇

**设计预设**：试读者在中段猜到嫌疑人，但仍想知道证据怎样闭合、人物如何选择以及制度会如何处理。

**判断路径**：先确定本作承诺的是“猜凶手”“参与推理”还是“知道凶手后的悬念”。读者提前猜中不自动表示失败；反之，若核心解答依赖未出现的信息，终局再惊奇也不能补成公平。

**修订出口**：可调整披露顺序、补足区分线索、改变后半段的风险或明确作品并非公平解谜；不必为了延迟答案而删除所有可推理信息。

### 5. 限定范围改稿：新增事实不能伪装成原稿

**设计预设**：作者只授权改开头和揭晓，现有中段没有说明关键物件何时被接触。

**处理路径**：先按已给文本标记事实与未知；开头可以建立读者需要观察的线索，揭晓只能使用当前已经建立的关联。若唯一解必须依赖中段新增事实，列出依赖位置和最小补写建议，等待作者扩大授权；不得把新设定写成原稿已有。

### 6. 重复问话：没有新物证不等于没有场景功能

**设计预设**：调查中连续出现三次相似问话。第一场确认人物口径，第二场出现证词矛盾，第三场改变人物关系或行动风险。

**判断路径**：逐场记录新增信息、关系变化、风险变化、人物选择和读者理解。若第二、三场只重复同一信息且不改变任何后果，可以合并；若重复本身用于压迫、仪式或关系变化，可以保留并说明功能。

### 7. 多条线索：同源信息不自动独立

**设计预设**：三名证人都复述同一条传闻，另有一份登记记录也由其中一名证人填写。

**判断路径**：先画出信息传递关系。三个转述如果都来自同一人，不是三份独立证词；登记记录若照抄该人的说法，也没有增加独立性。需要独立核验时，寻找不同形成过程的材料或明确承认无法独立确认。

### 8. 时间与单位：换算错误不能静默修正

**设计预设**：一份虚构记录同时写“200 英尺”和“60 码”，两者并不相等。

**处理路径**：若是在分析用户原稿，先保留原文并指出换算差异，不擅自改写原句；若是创作方案，统一单位并核算数值，再检查这个距离是否真的影响行动和证据。一个单位错误不自动推翻无关线索，也不能被忽略后继续推出精确时间线。

## MY-06D 交付文本模板

```text
任务／创作者目标／已读范围：本次可改范围与实际承诺：定位与观察：解释与替代解释：诊断状态：成立／条件成立／证据不足／不适用
实际修文或设计（新增事实显式标记）：为何能改善本次目标，何时会失效：案例来源（用户稿件观察或本 Skill 自建设计；新演示标“自建示例”）：回看：信息、时空、身份、保管、程序、人物后果
仍缺的具体材料或待创作者取舍：
```

不把模板状态预填为已完成，不以历史检查记录替代本次核查。对无法核验的现实事实，保留虚构前提或提出外部核查项；其余已授权创作继续完成。
