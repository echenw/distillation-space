# MY-03 时间、空间与不可能性

返回 [guide.md](guide.md)。

## MY-03A 时间链与不在场证明

把行为实施、影响开始、被发现、记录生成、人物相信与读者获知分别标时点及误差。异地设备记录不自动证明人在当地；投递、盖邮戳、收件、实际写信不是同一时刻。毒物施加/摄入/起效也可能不同，不能把人物台词“犯罪时间等于下毒”当现实法律定义。多次施加或延时装置分别列依赖，不要求所有人在发作时都有不在场证明。在这类结构里还有一个不依赖现实法条的人物信号：有人过早交出一份与发作时刻无关的完美不在场证明，恰好说明他知道自己该防哪个时刻；把这条破绽交给侦查方按本作设定去发现，不要写成读者本该懂行的常识。

| 专用分支 | 具体动作 | 原例与失败边界 |
|---|---|---|
| 时间锚：公共参照与私人证词 | 列实际固定时间的事件（钟声/汽笛/列车时刻表/登记记录或私人对表），谁感知、能否被他人核验 | （车站查列车时刻表）、（临别对表定 11:33）、（晚报—警方记录链）；（“三点前后”证词区间）。两证人加一记录不是硬配方，私人目击也可可靠；把不在场证明挂在公共信号上时，要同时写出这个信号在什么条件下会被读成另一个时刻，谁都读不出歧义的信号只是背景时间，撑不起一条能被击破的不在场证明。 |
| 钟声歧义与证词更改 | 分听到几响、信号制度、证人把它解释成何时；更改可因记忆、隐瞒或压力 | 拥有表不等于当时看过且表准；不从不一致直接认定说谎；证词修正还要有幅度和方向——改动部分小、并且能指回他为什么现在才改，一次改太多或改向随机，读者读到的是作者失手，不是有人在动这条时间线。 |
| 消耗型计时物 | 起点、规格、剩余量、速率及中断/替换/移动因素共同决定区间 | 蜡烛、蜡烛/积尘/清洁。缺项未必还能量化区间，充分信息也不保证精确死时 |
| 第三方记录 | 校记录来源、完整性、可代发/改写、生成时点和载体→人的关联 | 邮戳，电话回函；并线反例。没日志要先证本应记且未删漏 |
| 医学时间与目击矛盾 | 先核故事中允许的误差，再比搬移、错认、记错、欺骗等假说 | 医学不确定大时不能硬排到分钟，小说不认证现实死时方法；区间宽度是双向的：宽到人人都还在候选里就没有排除力，窄到只剩一人就过早收束，新证据到手时逐次收窄，并写明这一次排除了谁、还剩谁。 |
| 时间伪造的目的 | 分自保、栽赃、遮掩关系等目标；栽赃要查行动者如何知道目标的行程 | 4:02投递/8:30取件；拨钟。目的可并存 |
| 时间习惯作为人物线 | 分钟癖、守约、总晚到可兼具性格与旁证，复现频次依篇幅 | 行为习惯不独定身份，不固定两次 |
| 延时声音/影像 | 区分录制时间、播放时间、设备空档与被认为仍活着的时间 | 故事机制先公开其可推理规则 |

足迹可提供方向、次序、覆盖、步幅或负重差。先辨介质何时形成、哪些区域受污染、谁的痕迹可独立识别，再核通行权限。污染、仿靴、袜印、后印盖前印各有分别案例；不因一块地被踩乱判整条案件证据作废。国籍/地区步态只能是故事内刻板解释，不能作现实身份推断。

## MY-03B 空间与观察边界

需要空间推理时，写清相关位置、朝向、遮挡、距离、入口、出口和权限；情绪与对白可以先后穿插，不规定150字、死人先报名字或次章必复演。坐标复演可以让描述成为可查证条件，日常用途可自然带出结构。现场只剩死者一人时，坐标项退化为姿态、手持物与可核对的时间窗三样；没有第二个见证者，可复核性就交给时间链，不必硬造空间关系。

边界本身是待证命题：谁检查了门窗，何时，检查了什么，是否有未完成检验或不可靠陈述。密室可以最终被证明从来不密；人物误排真出口可被已给反证推翻，作者客观保证的封闭事实不能无解释改写。候选动作不一定被读者亲眼看见，只需核心结论有事先可用的区分依据。不可能性本身也要能复述：揭晓前读者应能说出这个现场排除了哪几条路、每条路是谁在何时排除的；说不出来，说明穷举还没成立，后面的解答再巧也不构成解谜。

| 装置分支 | 可组合的条件与操作 | 独有例与反例 |
|---|---|---|
| 入口/停留/出口 | 分三段列可能路径、时间窗、观察或记录，不强制每段一件物证 | 先排移尸/抛尸；排外侵。开放场所也能查路线，但不能套封闭集 |
| 破坏方向为出口 | 比内外破坏、碎片或门禁状态，重新评估谁原已在内 | “破出”与死者烛台。外部入侵者也可能后破出，不自动排除外人，不强加权威先错 |
| 结构型不可能 | 气密、门锁、保险箱、隔断等各有可检验性质和日常用途 | 窒息说被此前死亡的伤口推翻；结构可在发现后、核心解答前交付，不必尸体前独段 |
| 视线不对等 | 画观察点/高度/遮挡/可见部分，记录变化 | 操舵者看见牌室一部分但非地板。盲区可发生动作，不能让角色无变化突然看见；不要求之后所有动作只在可见区 |
| 不可观察窗口 | 黑暗、噪声、注意力、距离、跳切、值班空档或演出遮掩 | 灯灭/再亮名单；注意力；停电只感觉有人；投影。窗口主要说明可行性，若与唯一接触者等条件结合也可帮助识别。同一处盲区还可以解释在场者为什么没有防备：对方按自己关于来客身份或施害方式的既有假设行动，黑暗与噪声才变成机会；这条假设是谁、在什么时候给出的，读者要能在回看时指出；要读者复核在场范围时，另记一条分界：进出动作放进窗口，在场范围与各自位置留在窗口外，窗口重开后的头一处描写回到还剩谁，这份分界本身可以单独交付 |
| 同权限反问 | 指控者和嫌疑者拥有同等密码/钥匙/知识时，检验“只有你”的排他前提 | “或你”。无需地位更高者先说、六词反弹、外人打断或故意延后解释 |
| 双谜共享机制 | 把两谜的条件及共享资源映射，检查交叉机会是否成立 | 双密室；可共享机制或关系而非同一把物证，也不必插红鲱鱼 |
| 历史建筑藏道 | 结构来历、容量、连接、可用条件与先前征象一并设计；再指定这条通道承担哪一类行动——让搜查扑空、让人藏住、还是把两处连通，并写清一次能通过几人、要走多久、开启会留下什么；容量和行动需求对不上时，它只是布景而不是装置。 | 擦肩一次不自动给足唯一解信息 |
| 文献/记录开启法 | 相关记录、检索路径和必要规则分别披露；解释可以迟到 | 物件身份、编号、登记或借阅痕迹等记录线索；只提前提及记录名称仍可能不足 |
| 内部人自演 | 独处权限、道具、传闻与其他在场者行动组成骗局；收束时把道具逐件收回——谁摆的、何时摆的、每次在哪个环节起作用，一件件交代去处，读者才知道这不是没有来路的灵异。 | 多仆役不自动穿帮，须查观察与串通；机制不强制驱走全部仆人 |
| 机关未按计划工作 | 分原计划、实际中断、结果与错误判断 | 录音假在场与忘开法窗。失误需有本作原因，血量等旧医学说法只算故事内写法 |
| 身份/文书错位形成密室感 | 人物过往与名称、页码/缺页/借阅记录分开 | 身份机制可与物理机制共用，不能把三种密室解法宣布互斥 |
| 尸位与现场整理 | 分死亡地、发现地、移动、急救、日常整理和事后装修 | 转移未必留下可发现血拖痕，不强加万能“无痕”解释 |

尸体上的手持物、异常物、缺失物可作线索也可作气氛。烛台、假眼、遗物清单、衣鞋质量反差需有相关信息与观察者；不要求三项全写，不把没有后续作用的每件物都判噪声。神秘徽章与衣着反差范式：列遗物、数字与特殊缩写字母；把优质但改过的旧衣、劣质新鞋、真假饰物及缩写的不同解释并置。缩写可以指姓名，也可以指地址；物品质量不同可引出借用或雇佣关系的假说，不能单凭外观就武断断定阶层、身份或罪行。这是物证推演的典型设计，不当作僵化通则。

## MY-03C 技术装置只作虚构因果检查

这些分支保留原案例的叙事作用，不补现实操作参数或认证技术可行性。现实取证、医学、毒理、法律须另有可靠来源；暂时没有时写明“现实事实未核实”。

- **伪装死因**：工序顺序、工具/持物手、遗书、接近路径、利益及可替代解释共同检查。以操作顺序挑战事故/自杀结论；假遗书和接近装置各有案例；第二专家撤回惯用手判断。无需凑五查或强造二专家。
- **表面创口与实际死因错开**：“死后刺入”把注意力移向错误手段；分创口形成与死亡的时点。单凭一句“内出血”不证完整机制，旧文本结论不等于现代鉴识事实。伪装死因的人常是在保护谁，而伪装本身会放大暴露风险；要写明他为什么仍选这条路，否则这个动作读起来不像绝望，只像作者需要一具看起来暴力的尸体。
- **共食而结果不同**：记录各人的份额、杯具/食物对应、接触时点与可能替代解释。分布谜只支持这些作品本身；吃安全那份不独证谁实施，清洗也不必令全部其他证据失效。
- **载体、表面合法购买与阴性检验**：瓶、介质、成药壳与替换的载体案例，味觉解释，知识资格，都区分“来源、内容、接触、能力”。不复述成现实安全/剂量指南；阴性只排测试覆盖的项。一路阴性会把“东西从哪来”变成中段承重的断点，这条断点要在解答处补上一个读者能回看的来源；不补就只能把悬念写成作者不说。
- **医疗机构痕迹与记录**：常规煮沸使该痕迹线失效，不等于器械库存/流转不能取证。供应商未售、图书未借，不排存货、别处采购、已读或其他学习渠道。先查接触者是本案排序，不是所有案子的通用优先级。这里还要配一条交代义务：某类痕迹在本作根本取不到时，把取不到的原因在发现场景就写给读者，例如常规处理已经毁掉它可能留下的可检物质；否则读者会一直等一条永远不会出现的证据线，把作品自带的限制当成作者漏写。
- **工具组合与可重复展示**：把日常物的不同部件与现场痕迹连接。创作时只需列故事内功能、可见征象、使用机会、收束痕迹、竞争解释和现实未核项，不把文学结构变为现实制作说明。故事内几何要能反过来被痕迹检阅：长度、角度、深浅和作用方式对不上，读者一比对就发现这套工程立不住，这比现实可行性更早决定这个装置能不能用。
- **专业或超自然规则**：读者需在核心解答前获得足以推理的能力范围、限制、条件和可观察结果。解释混合熔点后使用是披露结构；保留未知感官空间则不能用未知能力证明此前唯一可解。失明侦探感官、瞳孔定时、机器人设定都仅属作品设定；前置规则可以支持幻想推理，不强制标签为非公平。
