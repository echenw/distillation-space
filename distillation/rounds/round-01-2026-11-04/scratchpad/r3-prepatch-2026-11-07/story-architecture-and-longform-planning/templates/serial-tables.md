## 3. 卷末四问（SV-05）

| 问 | 通过标准 | 本卷答案 | 不通过时 |
|---|---|---|---|
| 1. 主线能核对地结账了吗？ | 有比分、案、物、交付可以指认 |  | 补账本，不补解释 |
| 2. 只开了一个口吗？ | 只有一条下一步，而且能执行 |  | 删到一条；多的转台账或砍掉 |
| 3. 结账和开口之间有收束动作吗？ | 一段对话、一次结算或一个选择 |  | 加一个；已发表就在下一卷开头补 |
| 4. 下一卷第一步明确吗？ | 一句委任、承诺、实物或坐标 |  | 说不出来就全闭合，不写空钩子 |

单线卷：第 2 问记“不适用”。下一卷没定：第 4 问记“不适用”，本卷全闭合。

## 4. 复位四问（SV-06）

| 问 | 通过标准 | 本卷答案 | 不通过时 |

| 1. 本卷主要对手移除或降级了吗？ | 被捕、死亡、失势、转性，有文本结果 |  | “逃走了”不算移除，进台账；跨卷宿敌逃走不算本问失败 |
| 2. 据点、组织、载具恢复了吗？ | 能继续用 |  | 用“暂缓”“代管”，不撤销 |
| 3. 下一卷第一步还能执行吗？ | 同卷末四问第 4 问 |  | 同卷末四问第 4 问；只核一次，不重复判 |

## 12. 系列—卷—章依赖矩阵（SV-02、SV-08；接手旧稿或跨卷改动时用）

一张表看清哪条线跨哪些卷、各卷各章承担什么、改一处会牵动哪些承诺。逐列说明：

| 列 | 说明 |
|---|---|
| 正典版本 | 本行按哪个版本核对（用户当前稿件或已发表章节）；缺料写“未知” |
| 系列目标 | 长线要回答的问题或主题，以及不可破坏的约束 |
| 卷 | 本行所属卷：读者承诺与预计结束处（SV-02） |
| 章 | 支撑本卷承诺的事件或场景定位 |
| 人物状态变化 | 人物所知、目标、关系的前后对照（SV-06） |
| 世界状态变化 | 组织、地理、物件、制度规则的前后对照 |
| 开放线 | 只记实际打开的悬念或承诺，及首次出现的卷、章（SV-08） |
| 依赖 | 兑现这条线必须先发生的事件，以及谁消费它 |
| 回收候选 | 回收、转化、延期、放弃的候选，作者定 |
| 证据类型 | 稿件内可核位置／推断／建议，分开记录 |
| 下一步动作 | 下一章或下一卷有意义的行动，不必然是钩子 |
| 容量假设 | 合同定值与推断数值分开记（SV-13） |
| 作者决定 | 已确认／未能核实／待作者决定／不适用 |

| 正典版本 | 系列目标 | 卷 | 章 | 人物状态变化 | 世界状态变化 | 开放线 | 依赖 | 回收候选 | 证据类型 | 下一步动作 | 容量假设 | 作者决定 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |

回归与结果：按前卷实际存在的行动、读者已经收到的承诺、后卷人物信息和版本逐项确认；发现冲突不写成已修正，列出可逆的方案和影响范围，作者定。活动线数量、收束动作是否单独成章，都不作为跨题材的失败条件（SV-05、SV-08）。“证据类型”一列只指向用户当前稿件或已发表章节；推测写“假设”，没读到的写“未读”，不知道的写“未知”。
