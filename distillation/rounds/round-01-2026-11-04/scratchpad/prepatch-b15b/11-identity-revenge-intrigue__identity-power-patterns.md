# 身份、权谋、复仇与制度博弈机制库（IR-07A–IR-07G）

返回 [guide.md](guide.md)。本文件将身份置换、误认、伪装、家庭归属、机构控制、复仇闭环和权力重组整理为可迁移的戏剧机制。所有例子均为概括性设计，不对应特定作品或真实项目。

## IR-07A 身份、误认、伪装与证据

| 机制 | 怎么用 | 限制与反例 |
|---|---|---|
| 标签固化 | 一句玩笑、一次失误或一种收藏习惯被旁人反复引用，逐渐固化成身份标签；再让新证据改变标签的含义。 | 社会标签不是客观身份；身体标记、职业或血统不能单独证明人格或能力。 |
| 改名与旧名触发 | 长期改名可以被社会接受；熟人、旧物、旧称呼或共同经历可能重新触发身份危机。 | 不要让改名必然露馅，也不要假设所有亲属都会认出或拒绝承认。 |
| 假门第与外在凭证 | 肖像、制服、徽章、家谱、礼仪或随行人员可以营造身份外观。 | 外在凭证只证明有人制作或持有它，不自动证明持有人真实身份。 |
| 敌方命名与自我身份 | 敌人可能把人物称作骗子、叛徒或强盗；人物本人和同伴可能有不同理解。 | 敌方标签不等于客观职业或事实认定。 |
| 双生、分离与视觉识别 | 长期分离、不同成长经历和有限接触可以造成身份错认；共同记忆或身体特征可能成为线索。 | 不要求所有替身都是双胞胎；相貌相同不等于经历、意图和法律身份相同。 |
| 局部身体矛盾 | 瘦腕、旧伤、步态、声音、手部习惯等局部细节可以动摇伪装。 | 单一身体特征不应成为永远可靠的身份测试；要说明观察者为何注意到它。 |
| 假死与社会接受 | 假死可能由身体证据、官方记录、报纸、追捕和公众反应共同建立。 | 法院或公众接受一个版本，不代表所有人都掌握真相；后续仍可能出现识别风险。 |
| 表演身份与观众知情 | 角色可以主动扮演新身份，观众可能先于其他角色知道真相。 | 若承诺公平推理，需留可回看的线索；若是惊奇结构，则要明确其信息契约。 |
| 真实文件与错误持有人 | 来信、契约、证明或档案可能真实，但持有人、解释或使用目的错误。 | 文件真实性不等于持有人身份真实，也不等于文件内容为真。 |
| 身份确认的多段证据 | 身体记忆、共同经历、物件位置、正式记录和第三方证词可以逐步累积。 | 单一答错或单一答对不必决定身份；揭晓应解释每条证据的证明范围。 |
| 声音、习惯与物件 | 声音、口头禅、敲击习惯或熟悉物件可能帮助识别，也可能被模仿。 | 习惯观察不自动比外貌可靠；观察者可能受期待影响。 |
| 社会承认与私人关系 | 群众、家人、雇主和机构可能先后承认或拒绝同一身份。 | 社交接受不等于法律确认；公开仪式也不自动让所有人得知秘密。 |
| 长期冒名与信任 | 长期替身可能依赖资源、担保、习惯和他人利益维持身份。 | 不要把“没有熟人”写成“没有身份风险”；需要交代档案、旧同事和身体变化。 |
| 组织背书与身份义务 | 某组织的徽章、推荐或担保可以带来身份认可，也会产生服从、责任和退出成本。 | 组织认可不等于真实血统或合法权利；担保人也可能撤回支持。由对手一方签发的通行凭证、委任或推荐信是双刃的：它给持有者便利或免检，同时把他登记进签发方的名册和命令链；接受时要写出激活了什么义务、留下什么记录，日后抽身得先否认这份档案。 |
| 身份退出与关系余波 | 真身回归、假身份退场或公开真名后，仍要处理工作、财产、亲属和信任。 | 不把揭晓当成自动复位；新身份可能留下新的义务。 |

## IR-07B 家庭、继承、记录与归属

| 机制 | 怎么用 | 限制与反例 |
|---|---|---|
| 代际受益与知情 | 家族成员可能从旧不公中获益；当他们得知事实后，是否修复、沉默或继续获益成为新的选择。 | 不把血缘写成自动传递罪责，也不把诅咒当现实证据。 |
| 婚约与物件契约 | 小物件、婚约条款、日常供给、衣物和嫁妆保管可以具体化家庭权力。 | 物件和条款应影响人物选择；不能从一项约定推导出整个时代的法律。 |
| 长辈控制与家庭工具化 | 父母或长辈可能把子女当成达成目的的工具，或通过财产和婚姻控制选择。 | 不把所有长辈都写成反派；控制行为要有具体资源和动机。 |
| 秘密婚约与情感孤独 | 关系秘密可以制造家庭信息差，也可能让人物在伴侣死亡或离开后失去支持。 | 秘密婚约不自动解决继承和社会承认；关系的情感后果与制度效力分开。 |
| 债务、供货与物件支配 | 债务、珠宝、供货、保管和使用权可能由不同人掌握。 | 所有权、借贷、保管和实际控制不是同一件事；不把人物评论当会计或法律事实。 |
| 家庭成员的工具化 | 家庭成员可能被用来保职、换资源或维持名声；被利用者也可能重新谈判。 | 不要求每个家庭都以牺牲某人来维系，也不把婚姻自动等同交易。 |
| 收养、监护与照护 | 照护关系、血缘关系和法律监护可能冲突；当事人可以用亲子关系表达拒绝或承诺。 | 虚构程序不等于现代监护法；谁有权决定需按故事设定核实。 |
| 公共羞耻与私人罪感 | 人物可能在公众面前承受羞辱，却在私下有另一种理解和负担。 | 不把羞耻自动等同真实罪责；叙述者也可能不可靠。 |
| 同意与强制忠诚 | 关系中的承诺需要考虑是否能自由拒绝、撤回或重新谈判。 | 被胁迫的服从不等于同意；保护、依赖和控制可以同时存在。 |
| 自我辩护与道德优越感 | 叙述者可能把控制说成爱，把支配说成保护，或把自己描述为唯一正直者。 | 叙述者的解释不是事实；用行动、代价和他人反应检验。 |
| 痛苦与罪责 | 人物受旧事折磨，不足以证明他就是加害者或有罪者。 | 情绪强度不能替代证据。 |
| 部分知情与家庭判断 | 人物只知道家庭事件的一半，可能对婚姻、继承和责任作出不公平判断。 | 不把半知变成普遍心理定律；补足谁能获得什么信息。 |

## IR-07C 机构、政治和信息控制

| 机制 | 怎么用 | 限制与反例 |
|---|---|---|
| 公平口号与实际操盘 | 人物公开宣称公平，私下却安排人选、资金或舆论。 | 不推出所有改革都是骗局；用实际行动证明差异。 |
| 操作者与制度力量 | 角色可能把机器、法律、组织或公众力量误当成自己能控制的东西。 | 叙述者对人物权力的质疑不自动成为客观结论。 |
| 未完成计划与推断 | 作品可能中断在计划、猜测或未兑现行动处。 | 不把角色脸红、沉默或闪躲当确定罪证；结局未证实的事项保持未决。 |
| 序言立场与故事行动 | 作者/编者说明、人物理论、实际行动和后果可以不同。 | 前言中的政治目的不等于故事中每个人都认可它。 |
| 婚姻、支持与政治义务 | 联姻、保护、赠与和政治站位可能交织。 | 不把婚姻同意写成政治所有权；遗命和赠与仍需区分自述、法律效力和当事人接受。 |
| 错投信件与信息分层 | 信件可能被错投、截留或只被部分人读到；空白文件、授权书和口头命令也可能先后转手。 | 不把错投等同改写内容；每个人的知情时间需可追踪。 |
| 组织、资金和媒体 | 组织可能通过募资、报纸、禁令、广告或宣传塑造公共议题。 | 反向利用制度只是一个策略，不是唯一反抗路径；不提供现实操纵或违法流程。 |
| 声望与资源交换 | 名望、道德声誉、资金和组织多数可能彼此转换，也可能互相失效。 | 受欢迎不等于事实正确；喝彩不等于长期支持。 |
| 党内依赖与多数变化 | 盟友支持可能随时间、议题或利益改变；少数派可以短暂掌握关键节点。 | 不把单次投票或多数变化写成永久制度规律。 |
| 地方控制与公权力 | 地方经济、媒体和雇主可能影响司法、选举或公共服务的实际运行。 | 法律存在与法律可及性分开；个案不能概括所有机构。 |
| 私人把柄与公共攻击 | 私怨可能被包装成公共指控；把柄也可能让攻击者彼此克制。 | 证据链要清楚；不能把人物指控当作已证事实。 |
| 强制、威胁与自愿 | 角色可能在威胁下作出表面自愿的选择。 | 不把被迫行动描述成稳定忠诚；写出拒绝的代价和权力差。 |
| 传播入口与身份核验 | 一个普通人可能成为消息传播入口，或因记录、标签和组织关系被误判。 | 不要求固定数量的核验条件；信息来源要按实际可得性安排。 |
| 公开宣言与隐蔽行动 | 角色可能公开否认、私下安排行动，或让第三方代为执行。 | 不把角色宣言当事实，也不把旁观者的推断当全知。 |
| 司法荒诞与制度反讽 | 小说可以通过不对称程序、证据误读或惩罚失衡表现制度荒诞。 | 角色评论不等于现实司法规律；历史法制需单独核实。 |

## IR-07D 胜利后的控制、工程权力与追随者

### 政治修辞与现实纪律

人物可以赞美情感，同时要求纪律；盟友暂时融洽不代表长期忠诚。检查支持者的动机、命令链、信息延迟和自主诉求。若一场冲突中有人越境、拒绝命令或擅自处置，分别记录决策、执行和事后责任，不把它们压成“胜利必然失败”。

### 忠诚测试与长期信任

极端测试只能说明某一时刻的选择，不能保证长期忠诚。若组织通过公开承诺、共同等级或秘密结社建立权力，要分别记录成员同意、退出条件、监督方式和问责机制。要让这类考验成立，被试者必须在不知道那是考验时作出选择，揭示只放在选择之后；他自己猜到那是假行刑，这一次测试就不产生结论。测试给出的只是那一刻的取向，别用它反推往后的可靠。

### 技术替身与身份连续性

技术可以复制外貌、知识或行为模式，却不自动复制情感、记忆、责任和自我认同。分别设计身体标记、信息植入、法律身份、资源控制和退出权限；不把虚构工程设定写成现实技术结论。

### 伪神崇拜与社会承认

救助、否认私情、追随者威胁、地方权威和多年后的集体传说，可能共同塑造“神迹”或领袖形象。区分证词、信仰、社会效力和客观事实；反对者的证词也要交代其位置与动机。

### 隐瞒旧恶与证据操纵

旧恶可能被用作职位、金钱或关系的把柄；伤口、证词和档案也可能被操纵。保留照护、机会、证词和档案的结构，不提供伤害、伪造或逃避调查的现实操作步骤。

### 地缘、路线与悬赏

地理险阻、路线、部族关系、统治者和赏金能给行动增加约束。地图、职位和资源要限制角色行动；架空地缘不能冒充真实历史地图。推进一段行动时按节点记下每一段实际握着命令和补给的是谁：出发前、行动中和得手后常常不是同一个人，别把一次集会的口头决定当成全队服从。路线、地形和赏金同样要落到谁据此改动作上，否则只是地图描述。

### 旧部重逢与仪式造权

旧友重逢可通过外貌、随行人员、财产和言行互相试探；仪式、信条和圣地也可重构政治权威。把观察与推断分开，仪式承认与法律身份分开；猜测不自动成为事实。

## IR-07E 复仇、修复、制度与劳动

| 机制 | 怎么用 | 限制与反例 |
|---|---|---|
| 复仇后的赠与与修复 | 角色可以在复仇后请求他人赠与、分配继承财产、向弱者补偿或重新开始。 | 分清谁拥有财产、谁作出请求、谁同意；不要把请求写成已执行的捐赠。 |
| 嫉妒、证据与裁决 | 物件、信件、证人和机构裁断可以洗清指控或暴露加害者。 | 口头裁断不等于完整制度救济；受害者不必为真相付出死亡或失去一切。 |
| 复仇的自我耗损 | 复仇者可能在胜利后失去关系、身体或社会位置。 | 不把自毁设为复仇的必然结局，也不将受害者的修复简化成“复位”。 |
| 土地驱逐与登记 | 法院、警长、定居者、命名和登记可能共同制造排斥。 | 法律/登记可以参与压迫，但不代表所有法院都相同；保留可指名的执行者和受害者声音。 |
| 债务、土地与性别权力 | 债务、劳动许可、土地控制和性别规范可能共同限制家庭选择。 | 个别观察不能当人口统计；后段概述不能冒称逐项直接观察。 |
| 集体运动与个人选择 | 工人、村落或组织可能形成集体行动；个人也可能拒绝加入或与同伴冲突。 | 不把所有压迫归罪某一个群体；角色纲领与组织实际行动分开。 |
| 司法/结构清算 | 法庭或公共程序可以揭示地方权力、经济控制和不公。 | 判决、关系修复和经济改变不是同一件事；一次裁决不自动清除所有压迫。 |
| 工业劳动与身体代价 | 工作环境、收入、安全和家庭照护可以把宏观制度落到个人身上。 | 具体职业规则和职业病需要核验；个案不代表全部行业。 |
| 国家强制与个人后果 | 强征、失踪、拒绝、改名和新生活可以呈现国家权力对关系的影响。 | 不把国家暴力简化成单一人物恶意，也不把新名字写成自动摆脱所有制度风险。 |
| 重新进入社会 | 角色可以在旧身份、旧仇和新关系之间选择重新开始。 | 不要求所有人原谅，也不把公开澄清当作自动恢复信任。 |

## IR-07F 阶层博弈与公私利益冲突

- **利益联姻与职位筹码：** 家庭成员可能被用于保住职位或资金；分别写被利用者的同意、拒绝成本和替代方案。
- **垄断资本与公权力：** 资本可以影响立法、交通或公共设施；要写清控制渠道和反作用，不把宏观阴谋变成无证据的万能解释。
- **政治盟友与婚姻纽带：** 情感、派系和家族资产可能互相牵制；盟友不必自动牺牲，也不必永远忠诚。
- **克制的书面拒绝：** 一封尊重但坚决的函件可以拒绝追求、职位或交易；拒绝不必以羞辱、背叛或恶意为前提。
- **和平修辞与战备：** 公开外交辞令和实际准备可以不一致；记录谁知道、谁授权、谁承担代价。
- **竞选声誉管理：** 公开材料可以反驳流言，但澄清动作与公众是否采信必须分开。

## IR-07G 制度异化、社会压迫与叙述立场

- **荣誉与规训：** 勋章、称号或组织荣誉可能包装服从和制度化精神压力；不把荣誉话语当成真实价值证明。
- **人身买卖与债务连带：** 经济驱动力、法律身份和被商品化者的处境要分开呈现；不把历史立场粉饰成中立事实。
- **财富神话与阶层断层：** 二手传闻、记忆偏差和资本流动可能制造财富神话；区分传闻、实际交易和宏观推断。
- **叙述者立场：** 叙述者可以自辩、讽刺、沉默或公开评价；角色的意识形态不自动等于作品的立场。
- **制度性压迫：** 用执行者、程序、资源和受害者后果展示制度如何运作，不把所有责任简化为抽象的“时代”。

## 使用检查

1. 身份、法律资格、社会承认、自我认同和外貌标记是否分开？
2. 文件、证词、物件和身体特征各自能证明什么、不能证明什么？
3. 公开理由与私人利益是否有可观察的差异？
4. 忠诚、同意、依赖和胁迫是否被区分？
5. 复仇之后是否处理了修复、制度、劳动和关系的持续后果？
6. 是否把虚构案例写成现实法律、医学、技术或社会学结论？
